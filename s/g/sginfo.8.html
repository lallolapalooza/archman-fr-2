NOM

sginfo - accède aux informations des pages de mode pour un périphérique SCSI (ou ATAPI)

SYNTAXE

sginfo [OPTIONS] [PÉRIPHÉRIQUE] [PARAMÈTRES_DE_REMPLACEMENT]

DESCRIPTION

sginfo est un portage du programme scsiinfo pour Linux par Eric Youngdale. Il utilise les périphériques génériques SCSI (sg) ; cependant dans certains cas, le nom du périphérique de haut niveau (c.-à-d. sd, sr, st, osst, ou hd) peut aussi être utilisé. Le rôle principal de ce programme est d'accéder aux informations des pages de mode. Si autorisé, les informations des pages de mode peuvent être modifiées. En outre, les informations des commandes INQUIRY et READ DEFECTS sont également disponibles.

Cet utilitaire est en mode hérité, seuls les bugs évidents seront corrigés. Les options telles que -l (pour lister les périphériques) ne fonctionnent plus dans les versions récentes de Linux (par exemple, série 2.6 et ultérieures) ; l'utilitaire lsscsi(8) peut être utilisé à la place. De plus, les pages de mode ne sont pas mises à jour car https://www.t10.org ajoute et modifie les champs des pages de mode. Ceux qui s'intéressent aux pages de mode SCSI trouveront l'utilitaire sdparm plus à jour et plus facile à utiliser, en particulier pour modifier les paramètres.

Quatre ensembles de valeurs sont maintenus par un périphérique SCSI pour chaque page de mode : actuelle (active), par défaut (valeurs fournies par le fabricant), sauvegardée (valeurs conservées si le périphérique SCSI est hors tension), et changeable (masque indiquant les valeurs qui peuvent être modifiées). Par défaut, lorsque une page de mode est affichée, les valeurs actuelles sont montrées. Ceci peut être outrepassé par "-M" (valeurs par défaut), "-S" (sauvegardées) ou "-m" (modifiables (c.-à-d. changeables)).

De nombreuses pages de mode sont décodées : pour les disques (voir SBC-2), pour les CD/DVD (voir MMC-2/3/4/5), pour les bandes (voir SSC-2) et pour les boîtiers (voir SES-2). Certaines pages de mode communes à tous les types de périphériques SCSI sont définies dans SPC-4 (commandes primaires). Une page de mode décodée a ses noms de champs dans la première colonne et la valeur correspondante dans la deuxième colonne. Une page de mode "hexadécimal" (et sous-page) a sa position d'octet dans la première colonne (en hexadécimal et commençant à 0x2) et la valeur hexadécimale correspondante dans la deuxième colonne. Les pages décodées peuvent être vues avec l'option '-t' ou avec une option spécifique (par exemple, 'c' pour la page de mode de mise en cache). Naturellement, les pages décodées doivent être fournies par le PÉRIPHÉRIQUE et reconnues par ce programme. Si supportées par le périphérique, les pages décodées peuvent être modifiées. Toutes les pages de mode (et sous-pages) supportées par le périphérique peuvent être vues en hexadécimal (et potentiellement modifiées) via l'option "-u"

Si aucune option n'est donnée pour afficher les pages de mode ou les données INQUIRY, une brève réponse INQUIRY est générée. Celle-ci inclut le fournisseur, le produit et le niveau de révision du périphérique.

OPTIONS

-6
Effectue des commandes MODE SENSE et MODE SELECT de 6 octets ; par défaut, les variantes de 10 octets sont utilisées.
-a
Affiche certaines données INQUIRY et le numéro de série de l'unité, suivis de toutes les pages de mode signalées par le périphérique. C'est similaire à l'option '-t 0x3f'. Si la page de mode est connue, elle est affichée sous forme décodée, sinon sous forme hexadécimale.
-A
Affiche certaines données INQUIRY et le numéro de série de l'unité, suivis de toutes les pages de mode et de toutes les sous-pages de mode signalées par le périphérique. C'est similaire à l'option '-t 0x3f,0xff'. Si une page (sous-)mode est connue, elle est affichée sous forme décodée, sinon sous forme hexadécimale.
-c
Accède aux informations dans la page de mode Caching.
-C
Accède aux informations dans la page de mode Control.
-d
Affiche les listes de défauts (format par défaut : index).
-D
Accède aux informations dans la page de mode Disconnect-Reconnect.
-e
Accède aux informations dans la page de mode Error Recovery.
-E
Accède aux informations dans la page de mode Control Extension.
-f
Accède aux informations dans la page de mode Format Device.
-Farg
Format des listes de défauts :
-Flogical - adresses de bloc logique (32 bits)
-Flba64 - adresses de bloc logique (64 bits)
-Fphysical - blocs physiques
-Findex - octets de défaut depuis l'index
-Fhead - trier par tête
Utilisé conjointement avec "-d" ou "-G". Si un format n'est pas donné, "index" est supposé.
-g
Accède aux informations dans la page de mode Rigid Disk Drive Geometry.
-G
Affiche la liste des défauts issus de la croissance (format par défaut : index).
-i
Affiche la réponse à une commande INQUIRY standard.
-I
Accède à la page de mode Informational Exceptions.
-l
Obsolète. Utilisez uniquement dans les anciennes versions de Linux (par exemple, 2.4 et antérieures). Veuillez utiliser lsscsi(8) dans la série Linux 2.6 et ultérieures. Liste les périphériques SCSI connus sur le système.
-n
Accède aux informations dans la page de mode Notch and Partition.
-N
Négation (c'est-à-dire arrêt) de l'enregistrement des modifications des pages de mode dans la page "sauvegardée" (par défaut, les modifications vont à la page actuelle et sauvegardée). Actif uniquement lorsqu'il est utilisé avec '-R'.
-P
Accède aux informations dans la page de mode Power Condition.
-r
Affiche tous les noms bruts (ou primaires) des périphériques SCSI visibles dans le répertoire /dev. Les exemples sont /dev/sda, /dev/st1 et /dev/scd2. Ne liste pas les noms des périphériques sg, donc les périphériques tels qu'un boîtier SCSI qui n'a qu'un nom de périphérique sg ne sont pas listés.
-s
Affiche les informations de la page du numéro de série de l'unité, qui est une variante de la commande INQUIRY.
-t PN[,SPN]
Affiche les informations de la page de mode numéro PN (et éventuellement de sous-page SPN) sous forme décodée (si connue, sinon sous forme hexadécimale). PN est un numéro de page de mode décimal de 0 à 63 inclus. SPN est le numéro de sous-page de mode et est supposé être 0 s'il n'est pas donné. SPN est un nombre décimal de 1 à 255 inclus. Un numéro de page de 63 renvoie toutes les pages supportées par le périphérique dans l'ordre croissant, sauf pour la page 0 qui, si elle est présente, est la dernière. La page 0 est spécifique au vendeur et n'est pas nécessairement au format de page de mode. Alternativement, des valeurs hexadécimales peuvent être données pour PN et SPN (toutes deux préfixées par '0x').
-T
Traque les commandes pour obtenir une sortie plus détaillée (pour le débogage). Lorsqu'elle est utilisée une fois, les commandes SCSI sont affichées (en hexadécimal) et toute erreur de ces commandes SCSI est expliquée (c'est-à-dire avec un tampon de sens décodé et brut). Lorsqu'elle est utilisée deux fois, les données supplémentaires envoyées avec mode select et la réponse de mode sense sont affichées (en hexadécimal).
-u PN[,SPN]
Affiche les informations de la page de mode numéro PN (et éventuellement SPN) sous forme hexadécimale. PN est un numéro de page de mode décimal de 0 à 63 inclus. SPN est le numéro de sous-page de mode et est supposé être 0 s'il n'est pas donné. SPN est un nombre décimal de 1 à 255 inclus. Un numéro de page de 63 renvoie toutes les pages supportées par le périphérique dans l'ordre croissant, sauf pour la page 0 qui, si elle est présente, est la dernière. La page 0 est spécifique au vendeur et n'est pas nécessairement au format de page de mode. Alternativement, des valeurs hexadécimales peuvent être données pour PN et SPN (toutes deux préfixées par '0x'). Par exemple, 63 et 0x3f sont équivalents.
-v
Affiche la chaîne de version puis quitte. [N.B. Cette option augmente la verbosité pour la plupart des autres utilitaires de ce paquet, comme décrit dans 'man 8 sg3_utils'. Cet usage inhabituel est pour la compatibilité descendante avec l'utilitaire scsiinfo.]
-V
Accède aux informations dans la page de mode Verify Error Recovery. [N.B. Cette option affiche la chaîne de version puis quitte dans la plupart des autres utilitaires de ce paquet, comme décrit dans 'man 8 sg3_utils'. Cet usage inhabituel est pour

-z
effectue une seule récupération des pages de mode (en surestimant la longueur attendue de la réponse retournée). L'action par défaut est d'effectuer une double récupération, la première récupération servant à déterminer la longueur de réponse pouvant être retournée. Les périphériques qui adhèrent strictement aux normes SCSI ne devraient pas nécessiter cette option, mais certains périphériques du monde réel en ont besoin.

OPTIONS AVANCÉES

Une seule des trois options suivantes peut être spécifiée. Aucune de ces trois options n'implique que les valeurs actuelles sont retournées.

-m
Affiche les champs modifiables au lieu des valeurs actuelles
-M
Affiche les valeurs par défaut du fabricant au lieu des valeurs actuelles
-S
Affiche les valeurs par défaut enregistrées au lieu des valeurs actuelles

Les options suivantes sont avancées et généralement peu adaptées à la plupart des utilisateurs :

-X
Affiche les valeurs de sortie sous forme de liste. Les rend appropriées pour être modifiées et réutilisées avec la commande '-R' (remplacer).
-R
Remplace les paramètres - à utiliser de préférence avec -X (utilisation experte uniquement)

MODIFICATION DES PARAMÈTRES DES PAGES DE MODE

Tout d'abord, vous devez savoir ce que vous faites avant de modifier les paramètres existants. En prenant la page de contrôle comme exemple, listez-la d'abord normalement (par exemple, "sginfo -C /dev/sda") et décidez quel paramètre doit être modifié (notez sa position par rapport aux autres lignes de sortie). Ensuite, exécutez la même commande sginfo avec l'option "-X" ajoutée ; cela affichera les valeurs des paramètres sur une seule ligne, dans les mêmes positions relatives que la commande précédente. Exécutez maintenant "sginfo -CXR /dev/sda ..." en remplaçant "..." par la ligne unique de valeurs affichées par la commande précédente, avec le paramètre pertinent modifié. Voici un exemple simplifié :


$ sginfo -C /dev/sda
Page de mode de contrôle (0xa)
-----------------------
TST 0
D_SENSE 0
GLTSD 1
RLEC 0

[En fait, la page de contrôle contient plus de paramètres que ceux affichés ci-dessus.] Ensuite, affichez ces paramètres sous forme de ligne unique :


$ sginfo -CX /dev/sda
0 0 1 0

Supposons que le bit GLTSD doive être effacé. La commande qui l'effacera est :


$ sginfo -CXR /dev/sda 0 0 0 0

Le même nombre de paramètres que ceux renvoyés par la commande "-CX" doit être placé à la fin de la ligne de commande "-CXR" (après le nom du périphérique). Vérifiez maintenant que le changement a pris effet :


$ sginfo -C /dev/sda
Page de mode de contrôle (0xa)
-----------------------
TST 0
D_SENSE 0
GLTSD 0
RLEC 0

Lorsqu'une page de mode est "remplacée", l'action par défaut est de modifier à la fois la page actuelle et la page enregistrée. [Pour une raison quelconque, les versions de sginfo et scsiinfo antérieures à 2.0 ne modifiaient pas la page "enregistrée".] Pour modifier uniquement la page de mode actuelle mais pas la page enregistrée correspondante, utilisez l'option "-N".

GÉNÉRATION DE FICHIERS DE SCRIPT ET DE PAGES HEX

L'option "-aX" ou "-AX" génère une sortie appropriée pour un fichier de script. Les pages de mode sont affichées au format liste (après le NUMÉRO DE MODÈLE et le numéro de série) une page par ligne. Pour faciliter l'exécution de la sortie comme partie d'un fichier script afin de définir des valeurs de pages de mode choisies, chaque ligne est précédée de "sginfo -t PN[,SPN] -XR ". Lorsqu'un tel fichier script est exécuté, il aura pour effet de réaffirmer les valeurs des pages de mode à ce qu'elles étaient lorsque le "-aX" a généré la sortie.

Toutes les pages de mode (et sous-pages) prises en charge par le périphérique peuvent être accessibles via les options -t et -u. Pour voir toutes les pages de mode prises en charge par le périphérique, utilisez "-u 63". [Pour voir toutes les pages de mode et toutes les sous-pages, utilisez "-u 63,255".] Pour lister la page de mode de contrôle en hexadécimal (l'index de la page de mode dans la première colonne et la valeur d'octet correspondante dans la seconde colonne), utilisez "-u 0xa". Les pages de mode (sous-pages) (code de sous-page == 0) commencent à la position d'index 2 tandis que les sous-pages commencent à la position d'index 4. Si l'option "-Xu ..." est utilisée, une liste de valeurs hexadécimales, chaque valeur précédée de "@", est affichée. Les valeurs des pages de mode (sous-pages) peuvent alors être modifiées avec l'option "-RXu ...".

RESTRICTIONS

La commande SCSI MODE SENSE renvoie des descripteurs de bloc ainsi que des pages de mode. Cet utilitaire ignore les descripteurs de bloc et ne les affiche pas. Le commutateur "disable block descriptor" (DBD) dans la commande MODE SENSE n'est pas activé car certains périphériques génèrent des erreurs lorsqu'il est activé. Lorsque les valeurs des pages de mode sont modifiées (option "-R"), le même descripteur de bloc obtenu en lisant la page de mode (c'est-à-dire via une commande MODE SENSE) est renvoyé lors de l'écriture de la page de mode (c'est-à-dire via une commande MODE SELECT).

RÉFÉRENCES

Les normes SCSI (brouillon) peuvent être trouvées sur https://www.t10.org . Les documents pertinents sont SPC-4 (pages de mode communes à tous les types de périphériques), SBC-2 (périphériques d'accès direct [par exemple, disques]), MMC-4 (CD et DVD) et SSC-2 (bandes).

HISTORIQUE

La version 1.0 de scsiinfo a été publiée par Eric Youngdale le 1er novembre 1993. La version la plus récente de scsiinfo est la version 1.7 avec les derniers correctifs de Michael Weller. sginfo est dérivé de scsiinfo et utilise l'interface sg pour contourner la limite de tampon de 4 Ko de scsiinfo qui cramped l'affichage des listes de défauts en particulier. sginfo a été écrit par Douglas Gilbert avec des correctifs de Kurt Garloff. Ce manpage correspond à la version 2.25 de sginfo.
