sous-routine sgelsy (entier m, entier n, entier nrhs, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb, entier, dimension( * ) jpvt, réel rcond, entier rank, réel, dimension( * ) work, entier lwork, entier info)

SGELSY résout les systèmes surdéterminés ou sousdéterminés pour les matrices GE

Objectif:

!>
!> SGELSY calcule la solution de norme minimale pour un problème de
!> moindres carrés linéaires réels :
!>     minimiser || A * X - B ||
!> en utilisant une factorisation orthogonale complète de A.  A est une
!> matrice M par N qui peut être de rang déficient.
!>
!> Plusieurs vecteurs membres de droite b et vecteurs solution x peuvent
!> être traités en un seul appel ; ils sont stockés comme colonnes de la
!> matrice B de membres de droite M par NRHS et de la matrice solution X
!> N par NRHS.
!>
!> La routine calcule d'abord une factorisation QR avec pivotement de colonne :
!>     A * P = Q * [ R11 R12 ]
!>                 [  0  R22 ]
!> avec R11 défini comme la plus grande sous-matrice principale dont le
!> numéro de condition estimé est inférieur à 1/RCOND. L'ordre de R11, RANK,
!> est le rang effectif de A.
!>
!> Ensuite, R22 est considéré comme négligeable, et R12 est annihilé
!> par des transformations orthogonales par la droite, arrivant à la
!> factorisation orthogonale complète :
!>    A * P = Q * [ T11 0 ] * Z
!>                [  0  0 ]
!> La solution de norme minimale est alors
!>    X = P * Z**T [ inv(T11)*Q1**T*B ]
!>                 [        0         ]
!> où Q1 comprend les RANK premières colonnes de Q.
!>
!> Cette routine est fondamentalement identique à la xGELSX originale, sauf
!> pour trois différences :
!>   o L'appel à la sous-routine xGEQPF a été remplacé par l'appel à la
!>     sous-routine xGEQP3. Cette sous-routine est une version Blas-3
!>     de la factorisation QR avec pivotement de colonne.
!>   o La matrice B (membre de droite) est mise à jour avec Blas-3.
!>   o Le pivotement de la matrice B (membre de droite) est plus rapide et
!>     plus simple.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de
!>          colonnes des matrices B et X. NRHS >= 0.
!>

A

!>          A est tableau REEL, dimension (LDA,N)
!>          À l'entrée, la matrice A M par N.
!>          À la sortie, A a été écrasée par les détails de sa
!>          factorisation orthogonale complète.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

B

!>          B est tableau REEL, dimension (LDB,NRHS)
!>          À l'entrée, la matrice B des membres de droite M par NRHS.
!>          À la sortie, la matrice solution X N par NRHS.
!>          Si M = 0 ou N = 0, B n'est pas référencé.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,M,N).
!>

JPVT

!>          JPVT est tableau ENTIER, dimension (N)
!>          À l'entrée, si JPVT(i) .ne. 0, la i-ème colonne de A est pivotée
!>          vers le début de AP, sinon la colonne i est une colonne libre.
!>          À la sortie, si JPVT(i) = k, alors la i-ème colonne de AP
!>          était la k-ème colonne de A.
!>

RCOND

!>          RCOND est REEL
!>          RCOND est utilisé pour déterminer le rang effectif de A, qui
!>          est défini comme l'ordre de la plus grande sous-matrice triangulaire
!>          principale R11 dans la factorisation QR avec pivotement de A,
!>          dont le numéro de condition estimé est < 1/RCOND.
!>

RANK

!>          RANK est ENTIER
!>          Le rang effectif de A, c'est-à-dire l'ordre de la sous-matrice
!>          R11.  Ceci est identique à l'ordre de la sous-matrice T11
!>          dans la factorisation orthogonale complète de A.
!>          Si NRHS = 0, RANK = 0 à la sortie.
!>

WORK

!>          WORK est tableau REEL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.
!>          La stratégie non bloquée nécessite que :
!>             LWORK >= MAX( MN+3*N+1, 2*MN+NRHS ),
!>          où MN = min( M, N ).
!>          L'algorithme par blocs nécessite que :
!>             LWORK >= MAX( MN+2*N+NB*(N+1), 2*MN+NB*NRHS ),
!>          où NB est une borne supérieure de la taille de bloc renvoyée
!>          par ILAENV pour les routines SGEQP3, STZRZF, STZRQF, SORMQR,
!>          et SORMRZ.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>
