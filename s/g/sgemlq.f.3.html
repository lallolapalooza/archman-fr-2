Documentation de la fonction/sous-programme

sous-programme sgemlq (caractère side, caractère trans, entier m, entier n, entier k, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) t, entier tsize, réel, dimension( ldc, * ) c, entier ldc, réel, dimension( * ) work, entier lwork, entier info)

SGEMLQ

But:

!>
!>     SGEMLQ écrase la matrice réelle générale M-par-N C avec
!>
!>                    SIDE = 'L'     SIDE = 'R'
!>    TRANS = 'N':      Q * C          C * Q
!>    TRANS = 'T':      Q**T * C       C * Q**T
!>    où Q est une matrice réelle orthogonale définie comme le produit
!>    de réflecteurs élémentaires bloqués calculés par la factorisation LQ courte et large
!>    (SGELQ)
!>
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**T à Gauche ;
!>          = 'R': appliquer Q ou Q**T à Droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': Pas de transposée, appliquer Q ;
!>          = 'T': Transposée, appliquer Q**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >=0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau REAL, de dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          Partie de la structure de données pour représenter Q tel que renvoyé par SGELQ.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

T

!>          T est un tableau REAL, de dimension (MAX(5,TSIZE)).
!>          Partie de la structure de données pour représenter Q tel que renvoyé par SGELQ.
!>

TSIZE

!>          TSIZE est INTEGER
!>          La dimension du tableau T. TSIZE >= 5.
!>

C

!>          C est un tableau REAL, de dimension (LDC,N)
!>          À l'entrée, la matrice M-par-N C.
!>          À la sortie, C est écrasé par Q*C ou Q**T*C ou C*Q**T ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          (espace de travail) tableau DOUBLE PRECISION, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK minimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée. La routine
!>          calcule uniquement la taille du tableau WORK, renvoie cette
!>          valeur comme WORK(1), et aucun message d'erreur lié à WORK
!>          n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
