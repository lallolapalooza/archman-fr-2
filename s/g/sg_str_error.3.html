NOM

sg_get_error, sg_get_error_arg, sg_get_error_errno, sg_str_error, sg_get_error_details, sg_strperror - obtenir le dernier état d'erreur

SYNTAXE

#include <statgrab.h>


sg_error sg_get_error
(void);


const char *sg_get_error_arg
(void);


int sg_get_error_errno
(void);


sg_error sg_get_error_details
(sg_error_details *err_details);


const char *sg_str_error
(sg_error code);


char *sg_strperror
(char **buf, const sg_error_details * const err_details);

DESCRIPTION

Il y a quatre fonctions pour obtenir des informations sur la dernière erreur survenue : sg_get_error, sg_get_error_arg, sg_get_error_errno et sg_get_error_details. Les fonctions restantes sont destinées à améliorer l'interface homme-machine (par exemple, le journal des erreurs ou une boîte de message) : sg_str_error fournit un nom d'erreur lisible par l'homme et sg_strperror prépare un message d'erreur complet pour l'impression.

L'argument d'erreur (sg_get_error_arg) est stocké par thread et est réutilisé chaque fois qu'une erreur se produit. Si une utilisation ultérieure est prévue, sa duplication est une stratégie appropriée. Il en va de même pour l'argument d'erreur de sg_error_details fourni par sg_get_error_details.

Lorsque quelqu'un appelle la fonction sg_get_error_details avec un pointeur NULL, la dernière erreur est écrasée par une nouvelle décrivant que sg_get_error_details est appelée avec des arguments invalides. Soyez prudent.

La fonction sg_strperror peut être appelée avec ou sans détails d'erreur collectés (err_details est NULL). Dans ce dernier cas, la dernière erreur survenue dans ce thread est utilisée pour préparer le message d'erreur. Attention, le pointeur de tampon doit être non-NULL (pointe vers une lvalue char* existante), mais la lvalue char* vers laquelle il pointe doit être NULL. Lorsqu'elle est invoquée correctement, seules deux conditions d'erreur possibles peuvent faire échouer sg_strperror : ENOMEM (manque de mémoire) et EINVAL (code d'erreur invalide).

Exemple

if( NULL == sg_get_cpu_stats() ) {
    char *buf = NULL;
    if( NULL != sg_strperror( &buf, NULL ) ) {
        fprintf( stderr, "erreur lors de l'obtention des statistiques CPU : %s\n", buf );
        free(buf);
        exit(255);
    }
    else {
        fprintf( stderr, "erreur lors de l'obtention des statistiques CPU et des informations d'erreur\n" );
        exit(255);
    }
}

VALEURS DE RETOUR

Les détails de l'erreur contiennent les informations suivantes :

typedef struct sg_error_details {
        sg_error error;
        int errno_value;
        const char *error_arg;
} sg_error_details;
error
Le code d'erreur de la bibliothèque statgrab.
errno_value
Le code d'erreur du système d'exploitation.
error_arg
Informations supplémentaires définies lors de la signalisation de l'erreur.
