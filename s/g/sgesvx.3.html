SGESVX calcule la solution du système d'équations linéaires A * X = B pour les matrices GE

Objectif :

!>
!> SGESVX utilise la factorisation LU pour calculer la solution d'un système d'équations linéaires réelles
!>    A * X = B,
!> où A est une matrice N par N et X et B sont des matrices N par NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de condition sont également
!> fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    L'équilibrage du système sera effectué ou non en fonction de
!>    la mise à l'échelle de la matrice A, mais si l'équilibrage est utilisé, A est
!>    écrasée par diag(R)*A*diag(C) et B par diag(R)*B (si TRANS='N')
!>    ou diag(C)*B (si TRANS = 'T' ou 'C').
!>
!> 2. Si FACT = 'N' ou 'E', la décomposition LU est utilisée pour factoriser
!>    la matrice A (après équilibrage si FACT = 'E') en
!>       A = P * L * U,
!>    où P est une matrice de permutation, L est une matrice triangulaire inférieure unitaire
!>    et U est triangulaire supérieure.
!>
!> 3. Si un U(i,i)=0, de sorte que U soit exactement singulier, alors la routine
!>    retourne avec INFO = i. Sinon, la forme factorisée de A est utilisée
!>    pour estimer le nombre de condition de la matrice A. Si la
!>    réciproque du nombre de condition est inférieure à la précision machine,
!>    INFO = N+1 est retourné comme avertissement, mais la routine continue
!>    à résoudre pour X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 5. Un raffinement itératif est appliqué pour améliorer la matrice solution calculée
!>    et calculer les bornes d'erreur et les estimations d'erreur arrière
!>    pour celle-ci.
!>
!> 6. Si l'équilibrage a été utilisé, la matrice X est pré-multipliée par
!>    diag(C) (si TRANS = 'N') ou diag(R) (si TRANS = 'T' ou 'C') de sorte
!>    qu'elle résolve le système original avant l'équilibrage.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est fournie
!>          en entrée, et si ce n'est pas le cas, si la matrice A doit être
!>          équilibrée avant d'être factorisée.
!>          = 'F':  En entrée, AF et IPIV contiennent la forme factorisée de A.
!>                  Si EQUED n'est pas 'N', alors la matrice A a été
!>                  équilibrée avec les facteurs d'échelle donnés par R et C.
!>                  A, AF et IPIV ne sont pas modifiés.
!>          = 'N':  La matrice A sera copiée dans AF et factorisée.
!>          = 'E':  La matrice A sera équilibrée si nécessaire, puis
!>                  copiée dans AF et factorisée.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N':  A * X = B     (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Transposée conjuguée)
!>

N

!>          N est un ENTIER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre
!>          de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          En entrée, la matrice A de taille N par N.  Si FACT = 'F' et EQUED
!>          n'est pas 'N', alors A doit avoir été équilibrée par les
!>          facteurs d'échelle dans R et/ou C.  A n'est pas modifié si FACT = 'F' ou
!>          'N', ou si FACT = 'E' et EQUED = 'N' en sortie.

!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDA

NAME

sgesvx - high level interface to solve a general system of linear equations

SYNOPSIS

        SUBROUTINE SGESVX( FACT, TRANS, EQUED, N, NRHS, A, LDA, AF, LDAF,
                           IPIV, EQUED, R, RIDIS, SR, LPSV, B, LDB, X, LDX,
                           RCOND, FERR, BERR, WORK, IWORK, INFO )

        CHARACTER * 1 FACT, TRANS, EQUED
        INTEGER N, NRHS, LDA, LDAF, LDB, LDX
        REAL    A(LDA,*), AF(LDAF,*), R(*), RIDIS(*), SR(*), LPSV(*)
        INTEGER IPIV(*)
        REAL    B(LDB,*), X(LDX,*), RCOND, FERR(*), BERR(*)
        REAL    WORK(*)
        INTEGER IWORK(*)
        INTEGER INFO

The subroutine call and its parameters are described in the following sections.

Function/Subroutine Documentation

SGESVX is used to solve the system of linear equations AX = B. If FACT is not equal to 'N', it equilibrates the system. Then, it computes the factorization of A and uses it to compute the solution X.

Arguments:

FACT

CHARACTER*1.

Specifies the form of the problem input:

  • 'E': The vectors R and C (for row and column equilibration) are provided by the user.
  • 'F': The routine must first compute the equilibrium state of the matrix A.
  • 'N': The natural logarithm of the equilibrium row scaling factors R and the equilibrium column scaling factors C.

TRANS

CHARACTER*1.

Specifies the type of problem to be solved:

  • 'N': AX = B (no transpose)
  • 'T': ATX = B (transpose)
  • 'C': AHX = B (conjugate transpose)

EQUED

CHARACTER*1.

Specifies the equilibrium state of the matrix A:

  • 'N': None of the row or column scalings are computed.
  • 'R': The row scalings are computed.
  • 'C': The column scalings are computed.
  • 'B': Both row and column scalings are computed.

N

INTEGER.

The order of the matrix A. N >= 0.

NRHS

INTEGER.

The number of right hand sides, i.e. the number of columns of the matrices B and X. NRHS >= 0.

A

REAL array, dimension (LDA,N).

On entry, the coefficient matrix A of size N x N. If FACT = 'F', then A must be square and the number of columns must be equal to N.

LDA

INTEGER.

The leading dimension of the array A. LDA >= max(1,N).

AF

REAL array, dimension (LDAF,N).

If FACT = 'F', AF is the factored matrix A.

If FACT = 'E', AF is the factored matrix R or C.

If FACT = 'N', AF is not accessed.

If FACT = 'F', the LU factorization of A is in the array AF.

If FACT = 'E', the LU factorization of R or C is in the array AF.

LDAF

INTEGER.

The leading dimension of the array AF. LDAF >= max(1,N).

IPIV

INTEGER array, dimension (N).

Details of the LU factorization of A. On exit, the pivot indices for the LU factorization of A. For 1 <= K <= N, the pivot for the K-th column is in index IPIV(K).

If FACT = 'F', IPIV contains pivot indices for the LU factorization of A.

If FACT = 'E', IPIV contains pivot indices for the LU factorization of R or C.

If FACT = 'N', IPIV is not accessed.

EQUED

CHARACTER*1.

equed specifies the scaling options:

  • 'N': None of the row or column scalings are computed.
  • 'R': The row scalings are computed.
  • 'C': The column scalings are computed.
  • 'B': Both row and column scalings are computed.

On entry, EQUED specifies the scaling options. On exit, EQUED tells you whether the matrix A has been row-scaled, column-scaled, or both. If FACT = 'F', EQUED is output. If FACT = 'E', EQUED is input.

If EQUED = 'R' or 'B', each element of R must be positive.

C

REAL array, dimension (N)

C is the column scale factors for A. If EQUED = 'C' or 'B', A is multiplied on the right by diag(C); if EQUED = 'N' or 'R', C is not accessed. C is an input argument if FACT = 'F'; otherwise, C is an output argument. If FACT = 'F' and EQUED = 'C' or 'B', each element of C must be positive.

B

REAL array, dimension (LDB,NRHS)

On entry, the right hand side matrix B.

On exit,

  • if EQUED = 'N', B is not modified;
  • if TRANS = 'N' and EQUED = 'R' or 'B', B is overwritten by diag(R)*B;
  • if TRANS = 'T' or 'C' and EQUED = 'C' or 'B', B is overwritten by diag(C)*B.

LDB

INTEGER.

The leading dimension of the array B. LDB >= max(1,N).

X

REAL array, dimension (LDX,NRHS).

If INFO = 0 or INFO = N+1, the solution matrix X to the original system of equations. Note that A and B are modified on exit if EQUED .ne. 'N', and the solution to the equilibrated system is inv(diag(C))*X if TRANS = 'N' and EQUED = 'C' or 'B', or inv(diag(R))*X if TRANS = 'T' or 'C' and EQUED = 'R' or 'B'.

LDX

INTEGER.

The leading dimension of the array X. LDX >= max(1,N).

RCOND

REAL.

The estimate of the reciprocal condition number of the matrix A after equilibration (if done). If RCOND is less than the machine precision (in particular, if RCOND = 0), the matrix is singular to working precision. This condition is indicated by a return code of INFO > 0.

FERR

REAL array, dimension (NRHS).

The estimated forward error bound for each solution vector X(j) (the j-th column of the solution matrix X). If XTRUE is the true solution corresponding to X(j), FERR(j) is an estimated upper bound for the magnitude of the largest element in (X(j) - XTRUE) divided by the magnitude of the largest element in X(j). The estimate is as reliable as the estimate for RCOND, and is almost always a slight overestimate of the true error.

BERR

REAL array, dimension (NRHS).

The componentwise relative backward error of each solution vector X(j) (i.e., the smallest relative change in any element of A or B that makes X(j) an exact solution).

WORK

REAL array, dimension (MAX(1,4*N)).

On exit, WORK(1) contains the reciprocal pivot growth factor norm(A)/norm(U). The norm is used. If WORK(1) is much less than 1, then the stability of the LU factorization of the (equilibrated) matrix A could be poor. This also means that the solution X, condition estimator RCOND, and forward error bound FERR could be unreliable. If factorization fails with 0<INFO<=N, then WORK(1) contains the reciprocal pivot growth factor for the leading INFO columns of A.

IWORK

INTEGER array, dimension (N).

INFO

INTEGER.

  • = 0: successful exit
  • < 0: if INFO = -i, the i-th argument had an illegal value
  • > 0: if INFO = i, and i is
    • <= N: U(i,i) is exactly zero. The factorization has been completed, but the factor U is exactly singular, so the solution and error bounds could not be computed. RCOND = 0 is returned.
    • = N+1: U is nonsingular, but RCOND is less than machine precision, meaning that the matrix is singular to working precision. Nevertheless, the solution and error bounds are computed because there are a number of situations where the computed solution can be more accurate than the value of RCOND would suggest.

L'appel à la sous-routine et ses paramètres sont décrits dans les sections suivantes.

Function/Subroutine Documentation

SGESVX est utilisée pour résoudre le système d'équations linéaires AX = B. Si FACT n'est pas égal à 'N', elle équilibre le système. Ensuite, elle calcule la factorisation de A et l'utilise pour calculer la solution X.

Arguments:

FACT

CHARACTER*1.

Spécifie la forme de l'entrée du problème :

  • 'E': Les vecteurs R et C (pour l'équilibrage des lignes et des colonnes) sont fournis par l'utilisateur.
  • 'F': La routine doit d'abord calculer l'état d'équilibre de la matrice A.
  • 'N': Le logarithme naturel des facteurs d'échelle de ligne d'équilibre R et des facteurs d'échelle de colonne d'équilibre C.

TRANS

CHARACTER*1.

Spécifie le type de problème à résoudre :

  • 'N': AX = B (pas de transposée)
  • 'T': ATX = B (transposée)
  • 'C': AHX = B (conjuguée transposée)

EQUED

CHARACTER*1.

Spécifie l'état d'équilibre de la matrice A :

  • 'N': Aucune des mises à l'échelle des lignes ou des colonnes n'est calculée.
  • 'R': Les mises à l'échelle des lignes sont calculées.
  • 'C': Les mises à l'échelle des colonnes sont calculées.
  • 'B': Les mises à l'échelle des lignes et des colonnes sont calculées.

N

INTEGER.

L'ordre de la matrice A. N >= 0.

NRHS

INTEGER.

Le nombre de membres de droite, c'est-à-dire le nombre de colonnes des matrices B et X. NRHS >= 0.

A

Tableau REAL, dimension (LDA,N).

À l'entrée, la matrice des coefficients A de taille N x N. Si FACT = 'F', alors A doit être carrée et le nombre de colonnes doit être égal à N.

LDA

INTEGER.

La dimension principale du tableau A. LDA >= max(1,N).

AF

Tableau REAL, dimension (LDAF,N).

Si FACT = 'F', AF est la matrice factorisée A.

Si FACT = 'E', AF est la matrice factorisée R ou C.

Si FACT = 'N', AF n'est pas accédé.

Si FACT = 'F', la factorisation LU de A se trouve dans le tableau AF.

Si FACT = 'E', la factorisation LU de R ou C se trouve dans le tableau AF.

LDAF

INTEGER.

La dimension principale du tableau AF. LDAF >= max(1,N).

IPIV

Tableau INTEGER, dimension (N).

Détails de la factorisation LU de A. En sortie, les indices des pivots pour la factorisation LU de A. Pour 1 <= K <= N, le pivot pour la K-ième colonne est dans l'indice IPIV(K).

Si FACT = 'F', IPIV contient les indices des pivots pour la factorisation LU de A.

Si FACT = 'E', IPIV contient les indices des pivots pour la factorisation LU de R ou C.

Si FACT = 'N', IPIV n'est pas accédé.

EQUED

CHARACTER*1.

equed spécifie les options de mise à l'échelle :

  • 'N': Aucune des mises à l'échelle des lignes ou des colonnes n'est calculée.
  • 'R': Les mises à l'échelle des lignes sont calculées.
  • 'C': Les mises à l'échelle des colonnes sont calculées.
  • 'B': Les mises à l'échelle des lignes et des colonnes sont calculées.

À l'entrée, EQUED spécifie les options de mise à l'échelle. En sortie, EQUED vous indique si la matrice A a été mise à l'échelle des lignes, des colonnes, ou les deux.

Si FACT = 'F', EQUED est en sortie.

Si FACT = 'E', EQUED est en entrée.

Si EQUED = 'R' ou 'B', chaque élément de R doit être positif.

C

Tableau REAL, dimension (N)

C sont les facteurs d'échelle des colonnes pour A. Si EQUED = 'C' ou 'B', A est multiplié à droite par diag(C); si EQUED = 'N' ou 'R', C n'est pas accédé. C est un argument d'entrée si FACT = 'F'; sinon, C est un argument de sortie. Si FACT = 'F' et EQUED = 'C' ou 'B', chaque élément de C doit être positif.

B

Tableau REAL, dimension (LDB,NRHS)

À l'entrée, la matrice du membre de droite B.

En sortie,

  • si EQUED = 'N', B n'est pas modifié;
  • si TRANS = 'N' et EQUED = 'R' ou 'B', B est écrasé par diag(R)*B;
  • si TRANS = 'T' ou 'C' et EQUED = 'C' ou 'B', B est écrasé par diag(C)*B.

LDB

INTEGER.

La dimension principale du tableau B. LDB >= max(1,N).

X

Tableau REAL, dimension (LDX,NRHS).

Si INFO = 0 ou INFO = N+1, la matrice solution X du système d'équations original. Notez que A et B sont modifiés en sortie si EQUED .ne. 'N', et la solution du système équilibré est inv(diag(C))*X si TRANS = 'N' et EQUED = 'C' ou 'B', ou inv(diag(R))*X si TRANS = 'T' ou 'C' et EQUED = 'R' ou 'B'.

LDX

INTEGER.

La dimension principale du tableau X. LDX >= max(1,N).

RCOND

REAL.

L'estimation de l'inverse du nombre de conditionnement de la matrice A après équilibrage (si effectué). Si RCOND est inférieur à la précision machine (en particulier, si RCOND = 0), la matrice est singulière à la précision de travail. Cette condition est indiquée par un code de retour INFO > 0.

FERR

Tableau REAL, dimension (NRHS).

La borne d'erreur avant estimée pour chaque vecteur solution X(j) (la j-ième colonne de la matrice solution X). Si XTRUE est la vraie solution correspondant à X(j), FERR(j) est une borne supérieure estimée pour la magnitude du plus grand élément de (X(j) - XTRUE) divisé par la magnitude du plus grand élément de X(j). L'estimation est aussi fiable que l'estimation pour RCOND, et est presque toujours une légère surestimation de l'erreur réelle.

BERR

Tableau REAL, dimension (NRHS).

L'erreur arrière relative composante par composante de chaque vecteur solution X(j) (c'est-à-dire le plus petit changement relatif dans n'importe quel élément de A ou B qui rend X(j) une solution exacte).

Tableau REAL, dimension (MAX(1,4*N)).

En sortie, WORK(1) contient le facteur de croissance des pivots inverse norm(A)/norm(U). La norme est utilisée. Si WORK(1) est beaucoup inférieur à 1, alors la stabilité de la factorisation LU de la matrice A (équilibrée) pourrait être faible. Cela signifie également que la solution X, l'estimateur de condition RCOND et la borne d'erreur avant FERR pourraient être peu fiables. Si la factorisation échoue avec 0<INFO<=N, alors WORK(1) contient le facteur de croissance des pivots pour les INFO premières colonnes de A.

    • = N+1: U est non singulier, mais RCOND est inférieur à la précision machine, ce qui signifie que la matrice est singulière à la précision de travail. Néanmoins, la solution et les bornes d'erreur sont calculées car il existe un certain nombre de situations où la solution calculée peut être plus précise que ne le suggérerait la valeur de RCOND.
