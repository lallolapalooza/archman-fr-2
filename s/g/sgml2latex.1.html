sgml2latex(1)

Paquet: linuxdoc-tools

Licences: GPL

SGML2LATEX(1) Manuel des commandes générales SGML2LATEX(1)

NOM

sgml2latex - créer une sortie LaTeX, DVI, PostScript ou PDF à partir d'un fichier source SGML DTD LinuxDoc

SYNTAXE

sgml2latex [option-générique...] [--output=tex|dvi|ps|pdf] [--bibtex] [--makeindex] [--pagenumber=n] --quick [--latex=hlatexp|platex] [--dvips=dvips|dvi2ps] [--verbosity=n] fichier[.sgml]

DESCRIPTION

sgml2latex est une forme ancienne et obsolète de la commande de conversion latex de LinuxDoc-Tools (son nom peut être trompeur, car ce n'est pas un outil pour n'importe quelle DTD SGML, il ne prend en charge que la DTD LinuxDoc SGML). Il est recommandé d'utiliser maintenant la nouvelle forme linuxdoc -B latex. Il convertit un fichier source SGML DTD LinuxDoc en sortie LaTeX, en utilisant l'analyseur nsgmls(1) ou onsgmls(1), et le traducteur sgmlsasp(1). En utilisant la sortie LaTeX, et le formateur de texte latex(1), vous pouvez ensuite créer une sortie DVI, et une sortie PostScript en utilisant le convertisseur dvips(1). La sortie apparaîtra dans fichier.tex pour la sortie LaTeX, fichier.dvi pour la sortie DVI, ou fichier.ps pour la sortie PostScript, où fichier est le nom du fichier source SGML.

En utilisant la sortie LaTeX, et le formateur de texte pdflatex(1), vous pouvez ensuite créer une belle sortie PDF, adaptée à la visualisation avec des visualiseurs PDF tels que xpdf(1), acroread(1) ou ghostview(1).

La paire attribut/valeur "output=latex2e" est définie pour les conditionnels.

OPTIONS

sgml2latex accepte toutes les options génériques décrites dans linuxdoc(1), et les options spécifiques suivantes :

--output=fmt, -o
Spécifie le format de sortie désiré. Le spécificateur fmt peut être ``tex'', ``dvi'', ``ps'', ou ``pdf''.

Note : Cette version ne supprime pas/n'écrase pas les fichiers intermédiaires : fichier tex pour la sortie dvi, ou fichiers tex/dvi pour la sortie ps. C'est un comportement différent de celui de SGML-Tools 1.0.9 d'origine, donc vous êtes prévenu ici.

--bibtex, -b
Traite le TeX généré avec bibtex(1).
--makeindex, -m
Génère un fichier d'index TeX adapté au traitement avec makeindex(1) à partir des balises <idx> et <cdx> présentes dans la source SGML.
--pagenumber, -n
Définit le numéro de page de départ dans le fichier DVI ou PS de sortie.
--quick, -q
Ne fait qu'une seule passe de formatage LaTeX. Ce n'est souvent pas suffisant pour produire une sortie finale (à cause des références, etc.) mais c'est utile pour repérer les erreurs TeX et les problèmes de justification.
--pass, -P
L'argument de l'option pass est inséré juste après le préambule LaTeX généré par la balise de type de document. Spécifie le format de sortie désiré. Le spécificateur fmt peut être ``tex'', ``dvi'', ``ps'', ou ``pdf''.
--latex=commande_latex_alternative, -x
Cette option est actuellement pour le coréen et le japonais. La commande_latex_alternative peut être ``latex'' (par défaut), ``hlatexp'' (pour le coréen), ``platex'' ou ``jlatex'' (pour le japonais). Cette option peut être utilisée pour rendre un document coréen en utilisant HLaTeXp, ou pour rendre un document japonais en utilisant pLaTeX/jLaTeX. Sinon, HLaTeX doit être installé pour rendre un document coréen. D'autre part, un document japonais peut être rendu avec jLaTeX (qui est par défaut lorsque ``-c nippon'' est spécifié), donc si vous avez déjà jLaTeX, vous n'avez peut-être pas besoin d'installer pLaTeX.
--dvips=commande_dvips_alternative, -s
Cette option est actuellement pour le japonais. La commande_dvips_alternative peut être ``dvips'' ou ``dvi2ps''. Si vous ne savez pas cela, alors vous n'avez peut-être pas besoin de cette option.
--verbosity, -V
Définit la verbosité. '0' (par défaut) n'affichera les informations sur l'exécution LaTeX qu'en cas d'erreurs. '1' affichera toujours les informations de la dernière exécution. '2' affichera les informations de toutes les exécutions.
fichier
Le fichier source SGML, nommé soit fichier, soit fichier.sgml

FICHIERS

De nombreux fichiers et exécutables dans /usr/share/linuxdoc-tools et /usr/bin sont utilisés.
