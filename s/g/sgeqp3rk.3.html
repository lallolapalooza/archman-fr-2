subroutine sgeqp3rk (m, n, nrhs, kmax, abstol, reltol, a, lda, k, maxc2nrmk, relmaxc2nrmk, jpiv, tau, work, lwork, iwork, info)
SGEQP3RK calcule une factorisation QR tronquée de Householder avec pivot de colonnes en utilisant BLAS de niveau 3 et écrase une matrice réelle m-par-nrhs B avec Q**T * B.

Documentation de la fonction/sous-programme

sous-programme sgeqp3rk (integer m, integer n, integer nrhs, integer kmax, real abstol, real reltol, real, dimension( lda, * ) a, integer lda, integer k, real maxc2nrmk, real relmaxc2nrmk, integer, dimension( * ) jpiv, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

SGEQP3RK calcule une factorisation QR tronquée de Householder avec pivot de colonnes d'une matrice réelle m-par-n A en utilisant BLAS de niveau 3 et écrase une matrice réelle m-par-nrhs B avec Q**T * B.

Objectif :

!>
!> SGEQP3RK effectue deux tâches simultanément :
!>
!> Tâche 1 : La routine calcule une factorisation QR tronquée (de rang K) ou de plein rang
!> Householder avec pivot de colonnes d'une matrice réelle
!> M-par-N A en utilisant BLAS de niveau 3. K est le nombre de colonnes
!> qui ont été factorisées, c'est-à-dire le rang de factorisation de
!> facteur R, K <= min(M,N).
!>
!>  A * P(K) = Q(K) * R(K)  =
!>
!>        = Q(K) * ( R11(K) R12(K) ) = Q(K) * (   R(K)_approx    )
!>                 ( 0      R22(K) )          ( 0  R(K)_residual ),
!>
!> où :
!>
!>  P(K)            est une matrice de permutation N-par-N ;
!>  Q(K)            est une matrice orthogonale M-par-M ;
!>  R(K)_approx   = ( R11(K), R12(K) ) est une approximation de rang K du
!>                    facteur de plein rang R avec R11(K) triangulaire supérieure K-par-K
!>                    et R12(K) rectangulaire K-par-N. Les entrées diagonales
!>                    de R11(K) apparaissent dans un ordre non croissant
!>                    de valeur absolue, et les valeurs absolues de toutes
!>                    d'entre elles dépassent la norme 2 de colonne maximale de R22(K)
!>                    à une erreur d'arrondi près.
!>  R(K)_residual = R22(K) est le résidu d'une approximation de rang K
!>                    du facteur de plein rang R. C'est une
!>                    matrice rectangulaire (M-K)-par-(N-K) ;
!>  0               est une matrice nulle (M-K)-par-K.
!>
!> Tâche 2 : En même temps, la routine écrase une matrice réelle M-par-NRHS
!> B avec Q(K)**T * B en utilisant BLAS de niveau 3.
!>
!> =====================================================================
!>
!> Les matrices A et B sont stockées en entrée dans le tableau A comme
!> les blocs gauche et droit A(1:M,1:N) et A(1:M, N+1:N+NRHS)
!> respectivement.
!>
!>                                  N     NRHS
!>             tableau_A   =   M  [ mat_A, mat_B ]
!>
!> Les critères de troncature (c'est-à-dire quand arrêter la factorisation)
!> peuvent être l'un des suivants :
!>
!>   1) Le paramètre d'entrée KMAX, le nombre maximum de colonnes
!>      KMAX à factoriser, c'est-à-dire que le rang de factorisation est limité
!>      à KMAX. Si KMAX >= min(M,N), le critère n'est pas utilisé.
!>
!>   2) Le paramètre d'entrée ABSTOL, la tolérance absolue pour
!>      la norme 2 de colonne maximale de la matrice résiduelle R22(K). Cela
!>      signifie que la factorisation s'arrête si cette norme est inférieure ou
!>      égale à ABSTOL. Si ABSTOL < 0.0, le critère n'est pas utilisé.
!>
!>   3) Le paramètre d'entrée RELTOL, la tolérance pour la norme 2 de colonne maximale
!>      de la matrice résiduelle R22(K) divisée
!>      par la norme 2 de colonne maximale de la matrice originale A, qui
!>      est égale à abs(R(1,1)). Cela signifie que la factorisation s'arrête
!>      lorsque le rapport de la norme 2 de colonne maximale de R22(K) à
!>      la norme 2 de colonne maximale de A est inférieur ou égal à RELTOL.
!>      Si RELTOL < 0.0, le critère n'est pas utilisé.
!>
!>   4) Si les deux critères d'arrêt ABSTOL ou RELTOL ne sont pas utilisés,
!>      et lorsque la matrice résiduelle R22(K) est une matrice nulle dans
!>      une étape de factorisation K. (Ce critère d'arrêt est implicite.)
!>
!>  L'algorithme s'arrête lorsque l'une de ces conditions est satisfaite en premier,
!>  sinon la matrice entière A est factorisée.
!>
!>  Pour factoriser la matrice entière A, utilisez les valeurs
!>  KMAX >= min(M,N), ABSTOL < 0.0 et RELTOL < 0.0.
!>
!>  La routine retourne :
!>     a) Q(K), R(K)_approx = ( R11(K), R12(K) ),
!>        R(K)_residual = R22(K), P(K), c'est-à-dire les matrices résultantes
!>        de la factorisation ; P(K) est représentée par JPIV,
!>        ( si K = min(M,N), R(K)_approx est le facteur R complet,
!>        et il n'y a pas de matrice résiduelle R(K)_residual) ;
!>     b) K, le nombre de colonnes qui ont été factorisées,
!>        c'est-à-dire le rang de factorisation ;
!>     c) MAXC2NRMK, la norme 2 de colonne maximale de la matrice résiduelle
!>        R(K)_residual = R22(K),
!>        ( si K = min(M,N), MAXC2NRMK = 0.0 ) ;
!>     d) RELMAXC2NRMK égale MAXC2NRMK divisée par MAXC2NRM, la norme 2 de colonne maximale
!>        de la matrice originale A, qui est égale
!>        à abs(R(1,1)), ( si K = min(M,N), RELMAXC2NRMK = 0.0 ) ;
!>     e) Q(K)**T * B, la matrice B avec la transformation orthogonale
!>        Q(K)**T appliquée à gauche.
!>
!> La matrice de permutation N-par-N P(K) est stockée sous forme compacte dans
!> le tableau d'entiers JPIV. Pour 1 <= j <= N, la colonne j
!> de la matrice A a été échangée avec la colonne JPIV(j).
!>
!> La matrice orthogonale M-par-M Q est représentée comme un produit
!> de réflecteurs de Householder élémentaires
!>
!>     Q(K) = H(1) *  H(2) * . . . * H(K),
!>
!> où K est le nombre de colonnes qui ont été factorisées.
!>
!> Chaque H(j) a la forme
!>
!>     H(j) = I - tau * v * v**T,
!>
!> où 1 <= j <= K et
!>   I    est une matrice identité M-par-M,
!>   tau  est un scalaire réel,
!>   v    est un vecteur réel avec v(1:j-1) = 0 et v(j) = 1.
!>
!> v(j+1:M) est stocké à la sortie dans A(j+1:M,j) et tau dans TAU(j).
!>
!> Voir la section Détails supplémentaires pour plus d'informations.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de
!>          colonnes de la matrice B. NRHS >= 0.
!>

KMAX

!>          KMAX est INTEGER
!>
!>          Le premier critère d'arrêt de la factorisation. KMAX >= 0.
!>
!>          Le nombre maximum de colonnes de la matrice A à factoriser,
!>          c'est-à-dire le rang de factorisation maximal.
!>
!>          a) Si KMAX >= min(M,N), alors ce critère d'arrêt
!>                n'est pas utilisé, la routine factorise des colonnes
!>                en fonction de ABSTOL et RELTOL.
!>
!>          b) Si KMAX = 0, alors ce critère d'arrêt est
!>                satisfait à l'entrée et la routine sort immédiatement.
!>                Cela signifie que la factorisation n'est pas effectuée,
!>                les matrices A et B ne sont pas modifiées, et
!>                la matrice A est elle-même le résidu.
!>

ABSTOL

!>          ABSTOL est REAL
!>
!>          Le deuxième critère d'arrêt de la factorisation, ne peut pas être NaN.
!>
!>          La tolérance absolue (seuil d'arrêt) pour
!>          la norme 2 de colonne maximale de la matrice résiduelle R22(K).
!>          L'algorithme converge (arrête la factorisation) lorsque
!>          la norme 2 de colonne maximale de la matrice résiduelle R22(K)
!>          est inférieure ou égale à ABSTOL. Soit SAFMIN = SLAMCH('S').
!>
!>          a) Si ABSTOL est NaN, alors aucun calcul n'est effectué
!>                et un message d'erreur ( INFO = -5 ) est émis
!>                par XERBLA.
!>
!>          b) Si ABSTOL < 0.0, alors ce critère d'arrêt n'est pas
!>                utilisé, la routine factorise des colonnes en fonction
!>                de KMAX et RELTOL.
!>                Cela inclut le cas ABSTOL = -Inf.

Ceci signifie que la !> factorisation n'est pas effectuée, les matrices A et B ne sont pas !> modifiées, et la matrice A est elle-même le résidu. !>

RELTOL

!>          RELTOL est REAL
!>
!>          Le troisième critère d'arrêt de la factorisation, ne peut pas être NaN.
!>
!>          La tolérance (seuil d'arrêt) pour le rapport
!>          abs(R(K+1,K+1))/abs(R(1,1)) de la norme euclidienne maximale de colonne de
!>          la matrice résiduelle R22(K) à la norme euclidienne maximale de colonne de
!>          la matrice originale A. L'algorithme converge (arrête la
!>          factorisation), lorsque abs(R(K+1,K+1))/abs(R(1,1)) est inférieur
!>          ou égal à RELTOL. Soit EPS = SLAMCH('E').
!>
!>          a) Si RELTOL est NaN, alors aucun calcul n'est effectué
!>                et un message d'erreur ( INFO = -6 ) est émis
!>                par XERBLA.
!>
!>          b) Si RELTOL < 0.0, alors ce critère d'arrêt n'est pas
!>                utilisé, la routine factorise des colonnes en fonction
!>                de KMAX et ABSTOL.
!>                Ceci inclut le cas RELTOL = -Inf.
!>
!>          c) Si 0.0 <= RELTOL < EPS, alors RELTOL = EPS est utilisé.
!>                Ceci inclut le cas RELTOL = -0.0.
!>
!>          d) Si EPS <= RELTOL alors la valeur d'entrée de RELTOL
!>                est utilisée.
!>
!>          Soit MAXC2NRM la norme euclidienne maximale de colonne de la
!>          matrice originale entière A.
!>          Si RELTOL choisi ci-dessus est >= 1.0, alors ce critère d'arrêt
!>          est satisfait à l'entrée et la routine sort
!>          immédiatement après le calcul de MAXC2NRM.
!>          La routine retourne MAXC2NRM dans MAXC2NORMK,
!>          et 1.0 dans RELMAXC2NORMK.
!>          Ceci inclut le cas RELTOL = +Inf. Ceci signifie que la
!>          factorisation n'est pas effectuée, les matrices A et B ne sont pas
!>          modifiées, et la matrice A est elle-même le résidu.
!>
!>          NOTE: Nous recommandons que RELTOL satisfasse
!>                min( max(M,N)*EPS, sqrt(EPS) ) <= RELTOL
!>

A

!>          A est un tableau REAL, dimension (LDA,N+NRHS)
!>
!>          À l'entrée :
!>
!>          a) Le sous-tableau A(1:M,1:N) contient la matrice A de taille M x N.
!>          b) Le sous-tableau A(1:M,N+1:N+NRHS) contient la matrice B de taille M x NRHS.
!>
!>                                  N     NRHS
!>              tableau_A   =   M  [ mat_A, mat_B ]
!>
!>          À la sortie :
!>
!>          a) Le sous-tableau A(1:M,1:N) contient des parties des facteurs
!>             de la matrice A :
!>
!>            1) Si K = 0, A(1:M,1:N) contient la matrice originale A.
!>            2) Si K > 0, A(1:M,1:N) contient des parties des
!>               facteurs :
!>
!>              1. Les éléments en dessous de la diagonale du sous-tableau
!>                 A(1:M,1:K) ainsi que TAU(1:K) représentent la
!>                 matrice orthogonale Q(K) comme un produit de K réflecteurs
!>                 élémentaires de Householder.
!>
!>              2. Les éléments sur et au-dessus de la diagonale du
!>                 sous-tableau A(1:K,1:N) contiennent une matrice de
!>                 taille K x N, de forme trapézoïdale supérieure
!>                 R(K)_approx = ( R11(K), R12(K) ).
!>                 NOTE : Si K=min(M,N), c'est-à-dire factorisation de rang complet,
!>                       alors R_approx(K) est le facteur R complet qui
!>                       est de forme trapézoïdale supérieure. Si, en plus, M>=N,
!>                       alors R est de forme triangulaire supérieure.
!>
!>              3. Le sous-tableau A(K+1:M,K+1:N) contient une matrice
!>                 rectangulaire R(K)_residual = R22(K) de taille (M-K) x (N-K).
!>
!>          b) Si NRHS > 0, le sous-tableau A(1:M,N+1:N+NRHS) contient
!>             le produit Q(K)**T * B de taille M x NRHS.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>          C'est la dimension principale pour les deux matrices, A et B.
!>

K

!>          K est un entier (INTEGER)
!>          Rang de factorisation de la matrice A, c'est-à-dire le rang de
!>          la matrice R, qui est le même que le nombre de lignes non nulles
!>          de la matrice R. 0 <= K <= min(M,KMAX,N).
!>
!>          K représente également le nombre de vecteurs de Householder non nuls.
!>
!>          NOTE : Si K = 0, a) les tableaux A et B ne sont pas modifiés ;
!>                          b) le tableau TAU(1:min(M,N)) est mis à ZÉRO,
!>                             si la matrice A ne contient pas de NaN,
!>                             sinon les éléments TAU(1:min(M,N))
!>                             sont indéfinis ;
!>                          c) les éléments du tableau JPIV sont définis
!>                             comme suit : pour j = 1:N, JPIV(j) = j.
!>

MAXC2NRMK

!>          MAXC2NRMK est REAL
!>          La norme euclidienne maximale de colonne de la matrice résiduelle R22(K),
!>          lorsque la factorisation s'est arrêtée au rang K. MAXC2NRMK >= 0.
!>
!>          a) Si K = 0, c'est-à-dire que la factorisation n'a pas été effectuée,
!>             la matrice A n'a pas été modifiée et est elle-même une matrice résiduelle,
!>             alors MAXC2NRMK est égale à la norme euclidienne maximale de colonne
!>             de la matrice originale A.
!>
!>          b) Si 0 < K < min(M,N), alors MAXC2NRMK est retournée.
!>
!>          c) Si K = min(M,N), c'est-à-dire que toute la matrice A a été
!>             factorisée et qu'il n'y a pas de matrice résiduelle,
!>             alors MAXC2NRMK = 0.0.
!>
!>          NOTE : MAXC2NRMK à l'étape de factorisation K serait égal à
!>                R(K+1,K+1) à la prochaine étape de factorisation K+1.
!>

RELMAXC2NRMK

!>          RELMAXC2NRMK est REAL
!>          Le rapport MAXC2NRMK / MAXC2NRM de la norme euclidienne maximale de colonne
!>          de la matrice résiduelle R22(K) (lorsque la factorisation
!>          s'est arrêtée au rang K) à la norme euclidienne maximale de colonne de la
!>          matrice originale entière A. RELMAXC2NRMK >= 0.
!>
!>          a) Si K = 0, c'est-à-dire que la factorisation n'a pas été effectuée,
!>             la matrice A n'a pas été modifiée et est elle-même une matrice résiduelle,
!>             alors RELMAXC2NRMK = 1.0.
!>
!>          b) Si 0 < K < min(M,N), alors
!>                RELMAXC2NRMK = MAXC2NRMK / MAXC2NRM est retourné.
!>
!>          c) Si K = min(M,N), c'est-à-dire que toute la matrice A a été
!>             factorisée et qu'il n'y a pas de matrice résiduelle,
!>             alors RELMAXC2NRMK = 0.0.
!>
!>         NOTE : RELMAXC2NRMK à l'étape de factorisation K serait égal à
!>               abs(R(K+1,K+1))/abs(R(1,1)) à la prochaine étape de factorisation
!>               K+1.
!>

JPIV

!>          JPIV est un tableau INTEGER, dimension (N)
!>          Indices de permutation des colonnes. Pour 1 <= j <= N, la colonne j
!>          de la matrice A a été échangée avec la colonne JPIV(j).
!>
!>          Les éléments du tableau JPIV(1:N) sont toujours définis
!>          par la routine, par exemple, même lorsque aucune colonne
!>          n'a été factorisée, c'est-à-dire lorsque K = 0, les éléments sont
!>          définis comme JPIV(j) = j pour j = 1:N.
!>

TAU

!>          TAU est un tableau REAL, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>
!>          Si 0 < K <= min(M,N), seuls les éléments TAU(1:K) du
!>          tableau TAU sont modifiés par la factorisation.
!>          Après l'achèvement de la factorisation, si aucun NaN n'a été trouvé
!>          pendant la factorisation, les éléments restants
!>          TAU(K+1:min(M,N)) sont mis à zéro, sinon les
!>          éléments TAU(K+1:min(M,N)) ne sont pas définis et sont donc
!>          indéfinis.
!>          ( Si K = 0, tous les éléments de TAU sont mis à zéro, si
!>          la matrice A ne contient pas de NaN. )
!>

WORK

!>          WORK est un tableau REAL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La dimension du tableau WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, et
!>          LWORK >= (3*N+NRHS-1), sinon.
!>          Pour des performances optimales LWORK >= (2*N + NB*( N+NRHS+1 )),
!>          où NB est la taille de bloc optimale pour SGEQP3RK retournée
!>          par ILAENV. La taille de bloc minimale MINNB=2.
!>
!>          NOTE : La décision d'utiliser le code BLAS 2 non bloqué
!>          ou le code BLAS 3 bloqué est basée non seulement sur la dimension
!>          LWORK de l'espace de travail disponible WORK, mais aussi sur la
!>          dimension N de la matrice A via le point de croisement NX retourné
!>          par ILAENV. (Pour N inférieur à NX, le code non bloqué doit être
!>          utilisé.)
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule uniquement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK, et aucun
!>          message d'erreur lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (N-1).
!>          C'est un tableau de travail. ( IWORK est utilisé pour stocker les indices
!>          des colonnes pour la mise à jour descendante de la norme dans la matrice
!>          résiduelle dans la sous-routine auxiliaire bloquée SLAQP3RK ).
!>

INFO

!>          INFO est un entier (INTEGER)
!>          1) INFO = 0 : sortie réussie.
!>          2) INFO < 0 : si INFO = -i, le i-ème argument avait une
!>                       valeur illégale.
!>          3) Si INFO = j_1, où 1 <= j_1 <= N, alors un NaN a été
!>             détecté et la routine arrête le calcul.
!>             La j_1-ème colonne de la matrice A ou le j_1-ème
!>             élément du tableau TAU contient la première occurrence
!>             de NaN à l'étape de factorisation K+1 ( lorsque K colonnes
!>             ont été factorisées ).
!>
!>             À la sortie :
!>             K                  est défini comme le nombre de
!>                                   colonnes factorisées sans
!>                                   exception.
!>             MAXC2NRMK          est défini comme NaN.
!>             RELMAXC2NRMK       est défini comme NaN.
!>             TAU(K+1:min(M,N))  n'est pas défini et contient des
!>                                   éléments indéfinis. Si j_1=K+1, TAU(K+1)
!>                                   peut contenir NaN.
!>          4) Si INFO = j_2, où N+1 <= j_2 <= 2*N, alors aucun NaN
!>             n'a été détecté, mais +Inf (ou -Inf) a été détecté et
!>             la routine continue le calcul jusqu'à son achèvement.
!>             La (j_2-N)-ème colonne de la matrice A contient la première
!>             occurrence de +Inf (ou -Inf) à l'étape de factorisation
!>     
        étape K+1 (quand K colonnes ont été factorisées).
!>

Détails supplémentaires :

!> SGEQP3RK est basé sur le même algorithme de factorisation QR par réflexions de Householder
!> avec pivotement de colonnes que la routine SGEQP3, qui utilise la routine SLARFG
!> pour générer des réflexions de Householder pour la factorisation QR.
!>
!> On peut aussi écrire :
!>
!>   A = A_approx(K) + A_residual(K)
!>
!> La matrice d'approximation de rang faible A(K)_approx de la factorisation QR tronquée
!> de rang K de la matrice A est :
!>
!>   A(K)_approx = Q(K) * ( R(K)_approx ) * P(K)**T
!>                        (     0     0 )
!>
!>               = Q(K) * ( R11(K) R12(K) ) * P(K)**T
!>                        (      0      0 )
!>
!> Le résidu A_residual(K) de la matrice A est :
!>
!>   A_residual(K) = Q(K) * ( 0              0 ) * P(K)**T =
!>                          ( 0  R(K)_residual )
!>
!>                 = Q(K) * ( 0        0 ) * P(K)**T
!>                          ( 0   R22(K) )
!>
!> La factorisation tronquée (de rang K) garantit que la norme euclidienne maximale
!> de colonne de A_residual(K) est inférieure ou égale à MAXC2NRMK, à une erreur d'arrondi près.
!>
!> NOTE : Une approximation des vecteurs nuls de A peut être facilement calculée à partir
!>       de R11(K) et R12(K) :
!>
!>       Null( A(K) )_approx = P * ( inv(R11(K)) * R12(K) )
!>                                 (         -I           )
!>
!>
