Documentation de la fonction/sous-routine

sous-routine sgqrts (entier n, entier m, entier p, reel, dimension( lda, * ) a, reel, dimension( lda, * ) af, reel, dimension( lda, * ) q, reel, dimension( lda, * ) r, entier lda, reel, dimension( * ) taua, reel, dimension( ldb, * ) b, reel, dimension( ldb, * ) bf, reel, dimension( ldb, * ) z, reel, dimension( ldb, * ) t, reel, dimension( ldb, * ) bwk, entier ldb, reel, dimension( * ) taub, reel, dimension( lwork ) work, entier lwork, reel, dimension( * ) rwork, reel, dimension( 4 ) result)

SGQRTS

But :

!>
!> SGQRTS teste SGGQRF, qui calcule la factorisation GQR d'une
!> matrice A de taille N-par-M et d'une matrice B de taille N-par-P : A = Q*R et B = Q*T*Z.
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre de lignes des matrices A et B.  N >= 0.
!>

M

!>          M est un ENTIER
!>          Le nombre de colonnes de la matrice A.  M >= 0.
!>

P

!>          P est un ENTIER
!>          Le nombre de colonnes de la matrice B.  P >= 0.
!>

A

!>          A est un tableau de REELS, dimension (LDA,M)
!>          La matrice A de taille N-par-M.
!>

AF

!>          AF est un tableau de REELS, dimension (LDA,N)
!>          Détails de la factorisation GQR de A et B, tels que retournés
!>          par SGGQRF, voir SGGQRF pour plus de détails.
!>

Q

!>          Q est un tableau de REELS, dimension (LDA,N)
!>          La matrice orthogonale Q de taille M-par-M.
!>

R

!>          R est un tableau de REELS, dimension (LDA,MAX(M,N))
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, R et Q.
!>          LDA >= max(M,N).
!>

TAUA

!>          TAUA est un tableau de REELS, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires, tels que retournés
!>          par SGGQRF.
!>

B

!>          B est un tableau de REELS, dimension (LDB,P)
!>          En entrée, la matrice A de taille N-par-P.
!>

BF

!>          BF est un tableau de REELS, dimension (LDB,N)
!>          Détails de la factorisation GQR de A et B, tels que retournés
!>          par SGGQRF, voir SGGQRF pour plus de détails.
!>

Z

!>          Z est un tableau de REELS, dimension (LDB,P)
!>          La matrice orthogonale Z de taille P-par-P.
!>

T

!>          T est un tableau de REELS, dimension (LDB,max(P,N))
!>

BWK

!>          BWK est un tableau de REELS, dimension (LDB,N)
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale des tableaux B, BF, Z et T.
!>          LDB >= max(P,N).
!>

TAUB

!>          TAUB est un tableau de REELS, dimension (min(P,N))
!>          Les facteurs scalaires des réflecteurs élémentaires, tels que retournés
!>          par SGGRQF.
!>

WORK

!>          WORK est un tableau de REELS, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK, LWORK >= max(N,M,P)**2.
!>

RWORK

!>          RWORK est un tableau de REELS, dimension (max(N,M,P))
!>

RESULT

!>          RESULT est un tableau de REELS, dimension (4)
!>          Les ratios de test :
!>            RESULT(1) = norm( R - Q'*A ) / ( MAX(M,N)*norm(A)*ULP)
!>            RESULT(2) = norm( T*Z - Q'*B ) / (MAX(P,N)*norm(B)*ULP)
!>            RESULT(3) = norm( I - Q'*Q ) / ( M*ULP )
!>            RESULT(4) = norm( I - Z'*Z ) / ( P*ULP )
!>
