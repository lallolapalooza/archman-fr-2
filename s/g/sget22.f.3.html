SGET22

But :

!>
!> SGET22 vérifie les vecteurs propres.
!>
!> Le test de base est :
!>
!>    RESULTAT(1) = | A E  -  E W | / ( |A| |E| ulp )
!>
!> en utilisant la norme 1. Il vérifie également la normalisation de E :
!>
!>    RESULTAT(2) = max | m-norm(E(j)) - 1 | / ( n ulp )
!>                 j
!>
!> où E(j) est le j-ième vecteur propre, et m-norm est la max-norm d'un
!> vecteur. Si un vecteur propre est complexe, tel que déterminé par WI(j)
!> non nul, alors la max-norm du vecteur ( er + i*ei ) est le maximum de
!>    |er(1)| + |ei(1)|, ... , |er(n)| + |ei(n)|
!>
!> W est une matrice diagonale par blocs, avec un bloc de 1x1 pour chaque valeur propre réelle
!> et un bloc de 2x2 pour chaque paire conjuguée complexe.
!> Si les valeurs propres j et j+1 forment une paire conjuguée complexe, de sorte que
!> WR(j) = WR(j+1) = wr et WI(j) = - WI(j+1) = wi, alors le bloc de 2x2
!> correspondant à la paire sera :
!>
!>    (  wr  wi  )
!>    ( -wi  wr  )
!>
!> Un tel bloc multipliant une matrice de taille nx2 ( ur ui ) à droite
!> sera équivalent à multiplier  ur + i*ui  par  wr + i*wi.
!>
!> Pour gérer divers schémas de stockage des vecteurs propres gauches, il existe
!> des options pour utiliser la transposée de A au lieu de A, la transposée de E au lieu de E,
!> et/ou la transposée de W au lieu de W.
!>

Paramètres

TRANSA 
!>          TRANSA est CHARACTER*1
!>          Spécifie si A est transposée ou non.
!>          = 'N':  Pas de transposition
!>          = 'T':  Transposée
!>          = 'C':  Transposée conjuguée (= Transposée)
!>

TRANSE

!>          TRANSE est CHARACTER*1
!>          Spécifie si E est transposée ou non.
!>          = 'N':  Pas de transposition, les vecteurs propres sont dans les colonnes de E
!>          = 'T':  Transposée, les vecteurs propres sont dans les lignes de E
!>          = 'C':  Transposée conjuguée (= Transposée)
!>

TRANSW

!>          TRANSW est CHARACTER*1
!>          Spécifie si W est transposée ou non.
!>          = 'N':  Pas de transposition
!>          = 'T':  Transposée, utiliser -WI(j) au lieu de WI(j)
!>          = 'C':  Transposée conjuguée, utiliser -WI(j) au lieu de WI(j)
!>

N

!>          N est un ENTIER
!>          Ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          La matrice dont les vecteurs propres sont dans E.
!>

LDA

!>          LDA est un ENTIER
!>          Dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau REEL, de dimension (LDE,N)
!>          Le tableau des vecteurs propres. Si TRANSE = 'N', les vecteurs propres
!>          sont stockés dans les colonnes de E, si TRANSE = 'T' ou 'C', les
!>          vecteurs propres sont stockés dans les lignes de E.
!>

LDE

!>          LDE est un ENTIER
!>          Dimension principale du tableau E.  LDE >= max(1,N).
!>

WR

!>          WR est un tableau REEL, de dimension (N)
!>

WI

!>          WI est un tableau REEL, de dimension (N)
!>
!>          Les parties réelle et imaginaire des valeurs propres de A.
!>          Les valeurs propres purement réelles sont indiquées par WI(j) = 0.
!>          Les paires conjuguées complexes sont indiquées par WR(j)=WR(j+1) et
!>          WI(j) = - WI(j+1) non nul ; la partie réelle est supposée être
!>          stockée dans la j-ème ligne/colonne et la partie imaginaire dans
!>          la (j+1)-ème ligne/colonne.
!>

WORK

!>          WORK est un tableau REEL, de dimension (N*(N+1))
!>

RESULT

!>          RESULT est un tableau REEL, de dimension (2)
!>          RESULT(1) = | A E  -  E W | / ( |A| |E| ulp )
!>          RESULT(2) = max | m-norm(E(j)) - 1 | / ( n ulp )
!>                       j
!>
