DESCRIPTION

Les fonctions sg_get_process_stats fournissent des statistiques sur les processus en cours d'exécution. Les deux fonctions, sg_get_process_stats() et sg_get_process_stats_r(), prennent un paramètre optionnel d'entrées, qui pointe (lorsqu'il est fourni) vers un size_t pour obtenir le nombre d'entrées du vecteur retourné.

Les fonctions sg_get_process_count_of() et sg_get_process_count_r() fournissent une vue agrégée de la table des processus - elles délivrent la quantité de processus par état de processus. sg_get_process_count() est en fait une macro préprocesseur pour la compatibilité ascendante et appelle sg_get_process_count_of() avec le paramètre pcs de sg_entire_process_count pour émuler le comportement jusqu'à la version 0.17.

Raccourci API

fonction retourne propriétaire des données
sg_get_process_stats sg_process_stats * libstatgrab (local au thread)
sg_get_process_stats_r sg_process_stats * appelant
sg_get_process_count_of sg_process_count * libstatgrab (local au thread)
sg_get_process_count_r sg_process_count * appelant

Les vecteurs sg_process_stats reçus de sg_get_process_stats_r() ou les résumés sg_process_count reçus de sg_get_process_count_r doivent être libérés en utilisant sg_free_process_stats() ou sg_free_process_count() respectivement. L'appelant est responsable de le faire lorsque les données ne sont plus nécessaires.

Ces fonctions comparent deux entrées sg_process_stats, et retournent un int pour représenter laquelle est plus grande. L'utilisation principale de ces fonctions est d'être passées à qsort pour trier les sg_process_stats par le type donné.

Exemple

size_t entries;
sg_process_stats *proc_stats = NULL;
while( NULL != ( proc_stats = sg_get_process_stats_r(&entries) ) ) {
    /* trier les entrées en comparant l'identifiant du processus */
    qsort( proc_stats, entries, sizeof(proc_stats[0]), &sg_process_compare_pid );
    show_proc_stats( proc_stats );
    sg_free_process_stats( proc_stats );
}

VALEURS DE RETOUR

La structure retournée par sg_get_process_stats est de type sg_process_stats.

typedef struct {
        char *process_name;
        char *proctitle;
        pid_t pid;    /* identifiant du processus */
        pid_t parent; /* PID du parent */
        pid_t pgid;   /* PID du leader du groupe de processus */
        pid_t sessid; /* ID de session du processus */
        uid_t uid;
        uid_t euid;
        gid_t gid;
        gid_t egid;
        unsigned long long context_switches;
        unsigned long long voluntary_context_switches;
        unsigned long long involuntary_context_switches;
        unsigned long long proc_size; /* en octets */
        unsigned long long proc_resident; /* en octets */
        time_t start_time; /* Moment de démarrage du processus */
        time_t time_spent; /* temps passé en secondes */
        double cpu_percent;
        int nice;
        sg_process_state state;
        time_t systime;
} sg_process_stats;

typedef enum {
        SG_PROCESS_STATE_RUNNING,
        SG_PROCESS_STATE_SLEEPING,
        SG_PROCESS_STATE_STOPPED,
        SG_PROCESS_STATE_ZOMBIE,
        SG_PROCESS_STATE_UNKNOWN
} sg_process_state;
process_name
Le nom de la commande exécutée. Le contenu de ce champ dépend fortement du système d'exploitation sous-jacent, certains stockent le nom de base que l'exécutable passe à l'appel système exec(2), d'autres le chemin complet. La plupart des OS restreignent la taille de ce champ - certains comme la famille *BSD à une valeur très faible de 15 octets.

Ce champ est généralement immuable pour les processus en espace utilisateur.

proctitle
La ligne de commande (le "titre") du processus. Attention - ceci peut être modifié par le processus, donc il n'est pas garanti que ce soit la ligne de commande d'origine.
pid
L'identifiant du processus.
parent
L'identifiant du processus parent.
pgid
L'identifiant du processus du leader du groupe de processus.
sessid
L'identifiant de session auquel le processus appartient.
uid
L'identifiant de l'utilisateur sous lequel le processus s'exécute.
euid
L'identifiant de l'utilisateur effectif sous lequel le processus s'exécute.
gid
L'identifiant du groupe sous lequel le processus s'exécute.
egid
L'identifiant du groupe effectif sous lequel le processus s'exécute.
context_switches
Le nombre de changements de contexte de ce processus (volontaires et involontaires).
voluntary_context_switches
Le nombre de changements de contexte volontaires de ce processus (par ex. en appelant sched_yield() ou sleep()).
involuntary_context_switches
Le nombre de changements de contexte involontaires de ce processus (par ex. temps d'exécution écoulé ou signal envoyé).
proc_size
La taille de la mémoire virtuelle du processus en octets.
proc_resident
La taille du processus qui réside en mémoire.
start_time
L'heure de démarrage du processus, en secondes depuis l'époque.
time_spent
Le nombre de secondes pendant lesquelles le processus a été exécuté (temps utilisateur + système, sans le temps passé par les processus enfants).
cpu_percent
Le pourcentage actuel du CPU utilisé par le processus.
nice
La valeur nice du processus.
state
L'état actuel du processus. Voir sg_process_state pour les valeurs permises.
systime
Le temps en secondes depuis l'époque du moment où la statistique actuelle a été créée. Il peut s'agir (mais pas nécessairement) du même moment pour toutes les entrées retournées, qu'elles aient été récupérées avec une instantané ou assemblées à partir d'une sorte de procfs.

La structure retournée par sg_get_process_count_of et sg_get_process_count_r est de type sg_process_count.

typedef enum sg_process_count_source {
        sg_entire_process_count,
        sg_last_process_count
} sg_process_count_source;

typedef struct{
        unsigned long long total;
        unsigned long long running;
        unsigned long long sleeping;
        unsigned long long stopped;
        unsigned long long zombie;
        unsigned long long unknown;
        time_t systime;
}sg_process_count;
total
Le nombre total de processus.
running
Le nombre de processus en cours d'exécution.
sleeping
Le nombre de processus en sommeil.
stopped
Le nombre de processus arrêtés.
zombie
Le nombre de processus zombies.
unknown
Le nombre de processus ne correspondant à aucune des catégories nommées ci-dessus.
systime
Le temps en secondes depuis l'époque du moment où la statistique actuelle a été créée.

BOGUES

Le tout premier appel à sg_get_process_count_of(sg_last_process_count) retournera le même résultat que sg_get_process_count_of(sg_entire_process_count).

Les fonctions de comparaison existent plutôt pour des raisons de compatibilité descendante que pour des améliorations de fonctionnalités. Une flexibilité limitée (par exemple, ordre inverse) et le manque d'opportunités d'optimisation pour le compilateur conduisent à la recommandation d'implémenter les routines de comparaison requises localement.
