SGSVJ0 pré-processeur pour la sous-routine sgesvj.

Documentation de la fonction/sous-routine

sous-routine sgsvj0 (character*1 jobv, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( n ) d, real, dimension( n ) sva, integer mv, real, dimension( ldv, * ) v, integer ldv, real eps, real sfmin, real tol, integer nsweep, real, dimension( lwork ) work, integer lwork, integer info)

SGSVJ0 est un pré-processeur appelé depuis SGESVJ.

Objectif :

!>
!> SGSVJ0 est appelé depuis SGESVJ comme pré-processeur et c'est son but principal.
!> Il applique des rotations de Jacobi de la même manière que SGESVJ, mais
!> il ne vérifie pas la convergence (critère d'arrêt). Peu de paramètres d'ajustement
!> (marqués par [TP]) sont disponibles pour l'implémenteur.
!>

Paramètres

JOBV 
!>          JOBV est CHARACTER*1
!>          Spécifie si la sortie de cette procédure est utilisée
!>          pour calculer la matrice V:
!>          = 'V': le produit des rotations de Jacobi est accumulé
!>                 en post-multipliant le tableau N x N, V.
!>                (Voir la description de V.)
!>          = 'A': le produit des rotations de Jacobi est accumulé
!>                 en post-multipliant le tableau MV x N, V.
!>                (Voir les descriptions de MV et V.)
!>          = 'N': les rotations de Jacobi ne sont pas accumulées.
!>

M

!>          M est un INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. M >= 0.
!>

N

!>          N est un INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>          En entrée, matrice A de taille M x N, telle que A*diag(D) représente
!>          la matrice d'entrée.
!>          En sortie,
!>          A_sortie * D_sortie représente la matrice d'entrée A*diag(D)
!>          post-multipliée par une séquence de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de balayages sont donnés
!>          dans TOL et NSWEEP, respectivement.
!>          (Voir les descriptions de D, TOL et NSWEEP.)
!>

LDA

!>          LDA est un INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

D

!>          D est un tableau REAL, dimension (N)
!>          Le tableau D accumule les facteurs de mise à l'échelle des rotations
!>          de Jacobi rapides et mises à l'échelle.
!>          En entrée, A*diag(D) représente la matrice d'entrée.
!>          En sortie, A_sortie*diag(D_sortie) représente la matrice d'entrée
!>          post-multipliée par une séquence de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de balayages sont donnés
!>          dans TOL et NSWEEP, respectivement.
!>          (Voir les descriptions de A, TOL et NSWEEP.)
!>

SVA

!>          SVA est un tableau REAL, dimension (N)
!>          En entrée, SVA contient les normes euclidiennes des colonnes de
!>          la matrice A*diag(D).
!>          En sortie, SVA contient les normes euclidiennes des colonnes de
!>          la matrice A_sortie*diag(D_sortie).
!>

MV

!>          MV est un INTEGER
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'N',   alors MV n'est pas référencé.
!>

V

!>          V est un tableau REAL, dimension (LDV,N)
!>          Si JOBV = 'V' alors N lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'A' alors MV lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'N',   alors V n'est pas référencé.
!>

LDV

!>          LDV est un INTEGER
!>          La dimension principale du tableau V, LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!>

EPS

!>          EPS est REAL
!>          EPS = SLAMCH('Epsilon')
!>

SFMIN

!>          SFMIN est REAL
!>          SFMIN = SLAMCH('Safe Minimum')
!>

TOL

!>          TOL est REAL
!>          TOL est le seuil pour les rotations de Jacobi. Pour une paire
!>          de colonnes pivots A(:,p), A(:,q), la rotation de Jacobi est
!>          appliquée uniquement si ABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!>

NSWEEP

!>          NSWEEP est un INTEGER
!>          NSWEEP est le nombre de balayages de rotations de Jacobi à effectuer.
!>

WORK

!>          WORK est un tableau REAL, dimension (LWORK)
!>

LWORK

!>          LWORK est un INTEGER
!>          LWORK est la dimension de WORK. LWORK >= M.
!>

INFO

!>          INFO est un INTEGER
!>          = 0:  exécution réussie.
!>          < 0:  si INFO = -i, alors le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires :

SGSVJ0 est utilisé juste pour permettre à SGESVJ d'appeler une version simplifiée de lui-même pour travailler sur une sous-matrice de la matrice d'origine.
