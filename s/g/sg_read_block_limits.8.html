SG_READ_BLOCK_LIMITS(8) SG3_UTILS SG_READ_BLOCK_LIMITS(8)

NOM

sg_read_block_limits - envoie la commande SCSI READ BLOCK LIMITS

SYNTAXE

sg_read_block_limits [--aide] [--hex] [--mloi] [--brut] [--lecture-seule] [--verbeux] [--version] APPAREIL

DESCRIPTION

Envoie une commande SCSI READ BLOCK LIMITS à APPAREIL et affiche la réponse. Cette commande est définie pour les bandes (lecteurs) et sa description se trouve dans les documents SSC sur https://www.t10.org .

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-h, --aide
affiche le message d'utilisation puis quitte.
-H, --hex
affiche la réponse en hexadécimal (au lieu de la décoder).
-m, --mloi
définit le bit MLOI dans la commande READ BLOCK LIMITS et si cela réussit, affiche la valeur Maximum Logical Object Identifier (MLOI). Le bit MLOI a été introduit dans le projet ssc4r02.pdf.
-r, --brut
affiche la réponse en binaire sur la sortie standard.
-R, --lecture-seule
ouvre APPAREIL en mode lecture seule. Par défaut, il est ouvert en mode lecture-écriture.
-v, --verbeux
augmente le niveau de verbosité (c'est-à-dire les messages de débogage).
-V, --version
affiche la chaîne de version puis quitte.

STATUT DE SORTIE

Le statut de sortie de sg_read_block_limits est 0 en cas de succès. Sinon, consultez la page de manuel sg3_utils(8).

EXEMPLES

Il est généralement acceptable de ne pas utiliser d'options. Voici une invocation (sur la première ligne après l'invite de commande « # ») suivie d'une sortie typique :


# sg_read_block_limits /dev/st0
Résultats de Read Block Limits :
Taille de bloc minimale : 1 octet(s)
Taille de bloc maximale : 16777215 octet(s), 16383 Ko, 15 Mo
Granularité : 0
