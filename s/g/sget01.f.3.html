Documentation de la fonction/sous-programme

sous-programme sget01 (entier m, entier n, reel, dimension( lda, * ) a, entier lda, reel, dimension( ldafac, * ) afac, entier ldafac, entier, dimension( * ) ipiv, reel, dimension( * ) rwork, reel resid)

SGET01

But:

!>
!> SGET01 reconstruit une matrice A à partir de sa factorisation L*U et
!> calcule le résidu
!>    norme(L*U - A) / ( N * norme(A) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          La matrice originale M x N A.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

AFAC

!>          AFAC est un tableau REEL, dimension (LDAFAC,N)
!>          La forme factorisée de la matrice A.  AFAC contient les facteurs
!>          L et U de la factorisation L*U calculée par SGETRF.
!>          Est écrasé par la matrice reconstruite, puis par la différence
!>          L*U - A.
!>

LDAFAC

!>          LDAFAC est un ENTIER
!>          La dimension principale du tableau AFAC.  LDAFAC >= max(1,M).
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N)
!>          Les indices de pivot de SGETRF.
!>

RWORK

!>          RWORK est un tableau REEL, dimension (M)
!>

RESID

!>          RESID est un REEL
!>          norme(L*U - A) / ( N * norme(A) * EPS )
!>
