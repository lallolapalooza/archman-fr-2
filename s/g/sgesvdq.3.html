Documentation de la fonction/sous-programme

sous-programme sgesvdq (caractère joba, caractère jobp, caractère jobr, caractère jobu, caractère jobv, entier m, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) s, réel, dimension( ldu, * ) u, entier ldu, réel, dimension( ldv, * ) v, entier ldv, entier numrank, entier, dimension( * ) iwork, entier liwork, réel, dimension( * ) work, entier lwork, réel, dimension( * ) rwork, entier lrwork, entier info)

SGESVDQ calcule la décomposition en valeurs singulières (SVD) d'une matrice réelle M par N, où M >= N. La SVD de A est écrite comme [++] [xx] [x0] [xx] A = U * SIGMA * V^*, [++] = [xx] * [ox] * [xx] [++] [xx] où SIGMA est une matrice diagonale N par N, U est une matrice orthogonale M par N, et V est une matrice orthogonale N par N. Les éléments diagonaux de SIGMA sont les valeurs singulières de A. Les colonnes de U et V sont les vecteurs singuliers gauches et droits de A, respectivement.

Objectif :

!>
!> SGESVDQ calcule la décomposition en valeurs singulières (SVD) d'une matrice réelle
!> M par N, où M >= N. La SVD de A est écrite comme
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^*,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> où SIGMA est une matrice diagonale N par N, U est une matrice orthogonale M par N,
!> et V est une matrice orthogonale N par N. Les éléments diagonaux
!> de SIGMA sont les valeurs singulières de A. Les colonnes de U et V sont les
!> vecteurs singuliers gauches et droits de A, respectivement.
!>

Paramètres

JOBA 
!>  JOBA est CHARACTER*1
!>  Spécifie le niveau de précision de la SVD calculée
!>  = 'A' La précision demandée correspond à une erreur arrière
!>        limitée par || delta A ||_F <= f(m,n) * EPS * || A ||_F,
!>        où EPS = SLAMCH('Epsilon'). Ceci autorise CGESVDQ à
!>        tronquer le facteur triangulaire calculé dans une factorisation
!>        QR révélatrice de rang chaque fois que la partie tronquée est inférieure au
!>        seuil de l'ordre de EPS * ||A||_F. Ceci est un niveau de troncature agressif.
!>  = 'M' Similairement à 'A', mais la troncature est plus douce : elle
!>        n'est autorisée que lorsqu'il y a une chute sur la diagonale du
!>        facteur triangulaire dans la factorisation QR. Ceci est un niveau de troncature moyen.
!>  = 'H' Haute précision demandée. Aucune détermination numérique de rang basée
!>        sur la factorisation QR révélatrice de rang n'est tentée.
!>  = 'E' Identique à 'H', et en plus le nombre de condition du A échelonné par colonne
!>        est estimé et retourné dans RWORK(1).
!>        N^(-1/4)*RWORK(1) <= ||pinv(A_échelonné)||_2 <= N^(1/4)*RWORK(1)
!>

JOBP

!>  JOBP est CHARACTER*1
!>  = 'P' Les lignes de A sont ordonnées par ordre décroissant par rapport à
!>        ||A(i,:)||_\infty. Ceci améliore la précision numérique au prix de mouvements de données supplémentaires. Recommandé pour la robustesse numérique.
!>  = 'N' Pas de pivotement de ligne.
!>

JOBR

!>          JOBR est CHARACTER*1
!>          = 'T' Après la factorisation QR pivotée initiale, SGESVD est appliquée à
!>          la transposée R**T du facteur triangulaire calculé R. Cela implique
!>          des mouvements de données supplémentaires (transpositions de matrices). Utile pour
!>          des expériences, de la recherche et du développement.
!>          = 'N' Le facteur triangulaire R est donné en entrée à SGESVD. Ceci peut être
!>          préféré car cela implique moins de mouvements de données.
!>

JOBU

!>          JOBU est CHARACTER*1
!>          = 'A' Tous les M vecteurs singuliers gauches sont calculés et retournés dans
!>          la matrice U. Voir la description de U.
!>          = 'S' ou 'U' N = min(M,N) vecteurs singuliers gauches sont calculés et retournés
!>          dans la matrice U. Voir la description de U.
!>          = 'R' Le rang numérique NUMRANK est déterminé et seulement NUMRANK vecteurs singuliers
!>          gauches sont calculés et retournés dans la matrice U.
!>          = 'F' Les N vecteurs singuliers gauches sont retournés sous forme factorisée comme le
!>          produit du facteur Q de la factorisation QR initiale et des
!>          N vecteurs singuliers gauches de (R**T , 0)**T. Si un pivotement de ligne est utilisé,
!>          alors les informations nécessaires sur le pivotement de ligne sont stockées dans
!>          IWORK(N+1:N+M-1).
!>          = 'N' Les vecteurs singuliers gauches ne sont pas calculés.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          = 'A', 'V' Tous les N vecteurs singuliers droits sont calculés et retournés dans
!>          la matrice V.
!>          = 'R' Le rang numérique NUMRANK est déterminé et seulement NUMRANK vecteurs singuliers
!>          droits sont calculés et retournés dans la matrice V. Cette option est
!>          autorisée uniquement si JOBU = 'R' ou JOBU = 'N'; sinon elle est illégale.
!>          = 'N' Les vecteurs singuliers droits ne sont pas calculés.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.  M >= N >= 0.
!>

A

!>          A est un tableau de REAL de dimensions LDA x N
!>          En entrée, la matrice d'entrée A.
!>          En sortie, si JOBU .NE. 'N' ou JOBV .NE. 'N', le triangle inférieur de A contient
!>          les vecteurs de Householder tels que stockés par SGEQP3. Si JOBU = 'F', ces vecteurs de
!>          Householder, ainsi que WORK(1:N), peuvent être utilisés pour restaurer les facteurs Q de
!>          la factorisation QR pivotée initiale de A. Voir la description de U.
!>

LDA

!>          LDA est INTEGER.
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

S

!>          S est un tableau de REAL de dimension N.
!>          Les valeurs singulières de A, ordonnées de telle sorte que S(i) >= S(i+1).
!>

U

!>          U est un tableau de REAL, de dimension
!>          LDU x M si JOBU = 'A'; voir la description de LDU. Dans ce cas,
!>          en sortie, U contient les M vecteurs singuliers gauches.
!>          LDU x N si JOBU = 'S', 'U', 'R' ; voir la description de LDU. Dans ce
!>          cas, U contient les N vecteurs singuliers gauches principaux ou les NUMRANK vecteurs
!>          singuliers gauches principaux.
!>          LDU x N si JOBU = 'F' ; voir la description de LDU. Dans ce cas U
!>          contient la matrice orthogonale N x N qui peut être utilisée pour former les vecteurs
!>          singuliers gauches.
!>          Si JOBU = 'N', U n'est pas référencé.
!>

LDU

!>          LDU est INTEGER.
!>          La dimension principale du tableau U.
!>          Si JOBU = 'A', 'S', 'U', 'R',  LDU >= max(1,M).
!>          Si JOBU = 'F',                 LDU >= max(1,N).
!>          Sinon,                         LDU >= 1.
!>

V

!>          V est un tableau de REAL, de dimension
!>          LDV x N si JOBV = 'A', 'V', 'R' ou si JOBA = 'E' .
!>          Si JOBV = 'A', ou 'V',  V contient la matrice orthogonale N x N  V**T ;

NAME

sgesvdq — the general-purpose singular value decomposition (SVD) routine

SYNOPSIS

SUBROUTINE SGESVDQ(
 JOBU, JOBV, JOBA, M, N, A, LDA, S, U, LDU, V, LDV,
 WORK, LWORK, IWORK, LIWORK, RWORK, LRWORK, INFO)
 SUBROUTINE SGESVDQ( CHARACTER(1) :: JOBU, CHARACTER(1) :: JOBV, CHARACTER(1) :: JOBA, INTEGER :: M, INTEGER :: N, REAL, DIMENSION(LDA,*) :: A, INTEGER :: LDA, REAL, DIMENSION(*) :: S, REAL, DIMENSION(*) :: U, INTEGER :: LDU, REAL, DIMENSION(*) :: V, INTEGER :: LDV, REAL, DIMENSION(*) :: WORK, INTEGER :: LWORK, INTEGER, DIMENSION(*) :: IWORK, INTEGER :: LIWORK, REAL, DIMENSION(*) :: RWORK, INTEGER :: LRWORK, INTEGER :: INFO )

Function/Subroutine Documentation

Purpose:

 The subroutine SGESVDQ computes the singular value decomposition (SVD) of a
 real M-by-N matrix A:
 A = U * S * V**T
 where S is an M-by-N diagonal matrix with non-negative real numbers on the
 diagonal (the singular values), and U and V are orthogonal matrices
 whose columns are the left and right singular vectors, respectively.
 Several variants of the SVD problem are discussed in the "Further Details"
 section. This routine is designed to be accurate and efficient.

Arguments:

JOBU

CHARACTER*1.Input

Specifies the generation of the unitary matrix U.

  • 'U': The first min(M,N) columns of U are returned in U.
  • 'A': The full M-by-M unitary matrix U is returned in U.
  • 'S': The first min(M,N) columns of U are returned in U and the remaining columns of U are implicitly defined by the columns of V.
  • 'N': No columns of U are returned (the result is computed in-place in A).

JOBU can also be used to request computation of a scaled condition number estimate. If JOBU = 'C', then RWORK(1) contains an estimate for the condition number of A. This option is only available when JOBA = 'E'.

Note: JOBU = 'S' is only valid if M >= N.

JOBV

CHARACTER*1.Input

Specifies the generation of the unitary matrix V.

  • 'V': The first min(M,N) columns of V are returned in V.
  • 'A': The full N-by-N unitary matrix V is returned in V.
  • 'S': The first min(M,N) columns of V are returned in V and the remaining columns of V are implicitly defined by the columns of U.
  • 'N': No columns of V are returned (the result is computed in-place in A).

JOBV can also be used to request computation of a scaled condition number estimate. If JOBV = 'C', then RWORK(1) contains an estimate for the condition number of A. This option is only available when JOBA = 'E'.

Note: JOBV = 'S' is only valid if N >= M.

JOBA

CHARACTER*1.Input

Specifies the computation of a scaled condition number estimate.

  • 'E': The scaled condition number estimate is computed.
  • 'N': The scaled condition number estimate is not computed.

Note that if JOBA = 'E', then JOBU and/or JOBV must be set to 'C' to enable the computation of the condition number estimate.

M

INTEGER.Input

The number of rows of A. M >= 0.

N

INTEGER.Input

The number of columns of A. N >= 0.

A

REAL array, dimension at least (LDA,N).

On entry, the M-by-N matrix A whose SVD is to be computed.

On exit, if JOBU = 'N' and JOBV = 'N', then A is overwritten with the result of the SVD computation.

If JOBU != 'N' or JOBV != 'N', the contents of A are destroyed.

LDA

INTEGER.

The leading dimension of the array A. LDA >= max(1,M).

S

REAL array, dimension at least (min(M,N)).

On exit, the singular values, sorted in descending order. For i from 1 to min(M,N), S(i) contains the i-th singular value of A.

U

REAL array, dimension at least (LDU, K).

Where K is defined as follows:

  • If JOBU = 'A', K = M.
  • If JOBU = 'S', K = min(M,N).
  • If JOBU = 'U', K = min(M,N).
  • If JOBU = 'N', K = 0.

On exit, if JOBU != 'N', then the leading columns of U form the unitary matrix U.

LDU

INTEGER.

The leading dimension of the array U. LDU >= max(1,M).

V

REAL array, dimension at least (LDV, K).

Where K is defined as follows:

  • If JOBV = 'A', K = N.
  • If JOBV = 'S', K = min(M,N).
  • If JOBV = 'V', K = min(M,N).
  • If JOBV = 'N', K = 0.

On exit, if JOBV != 'N', then the leading columns of V form the unitary matrix V.

LDV

INTEGER.

The leading dimension of the array V. LDV >= max(1,N).

WORK

REAL array, dimension at least (max(2, LWORK)).

Used as workspace.

On exit, if LWORK is sufficiently large, then

WORK(1) contains the optimal LWORK.
WORK(2) contains the minimum LWORK.

If LWORK = -1, then WORK(1:2) returns the minimal and optimal dimensions for LWORK.

LWORK

INTEGER.

The dimension of the array WORK.

LWORK >= 1.

If LWORK = -1, then a workspace query is assumed; the routine only calculates and returns the optimal and minimal sizes for the WORK, IWORK, and RWORK arrays, and no error message related to LWORK is issued by XERBLA.

The minimal value of LWORK is:

MINLWORK = N + MAX( MAX( 3*N+1, 3*N ),                     &

The optimal value of LWORK is approximately the same as the minimal value, but may be larger. If LWORK is specified as -1, then WORK(1) and WORK(2) will contain the optimal and minimal values, respectively.

IWORK

INTEGER array, dimension at least (max(1, LIWORK)).

Used as workspace.

On exit, IWORK(1:N) contains column pivoting permutation of the rank revealing QR factorization.

If JOBP = 'P', IWORK(N+1:N+M-1) contains the indices of the sequence of row swaps used in row pivoting. These can be used to restore the left singular vectors in the case JOBU = 'F'.

If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0, IWORK(1) returns the minimal LIWORK.

LIWORK

INTEGER.

The dimension of the array IWORK.

LIWORK >= N + M - 1, if JOBP = 'P' and JOBA .NE. 'E';

LIWORK >= N, if JOBP = 'N' and JOBA .NE. 'E';

LIWORK >= N + M - 1 + N, if JOBP = 'P' and JOBA = 'E';

LIWORK >= N + N, if JOBP = 'N' and JOBA = 'E'.

If LIWORK = -1, then a workspace query is assumed; the routine only calculates and returns the optimal and minimal sizes for the WORK, IWORK, and RWORK arrays, and no error message related to LWORK is issued by XERBLA.

RWORK

REAL array, dimension at least (max(1, LRWORK)).

Used as workspace.

On exit,

1. If JOBA = 'E', RWORK(1) contains an estimate of the condition number of column scaled A. If A = C * D where D is diagonal and C has unit columns in the Euclidean norm, then, assuming full column rank, N^(-1/4) * RWORK(1) <= ||pinv(C)||_2 <= N^(1/4) * RWORK(1). Otherwise, RWORK(1) = -1.

2. RWORK(2) contains the number of singular values computed as exact zeros in SGESVD applied to the upper triangular or trapezoidal R (from the initial QR factorization). In case of early exit (no call to SGESVD, such as in the case of zero matrix) RWORK(2) = -1.

If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0, RWORK(1) returns the minimal LRWORK.

LRWORK

INTEGER.

The dimension of the array RWORK.

If JOBP ='P', then LRWORK >= MAX(2, M).

Otherwise, LRWORK >= 2.

If LRWORK = -1, then a workspace query is assumed; the routine only calculates and returns the optimal and minimal sizes for the WORK, IWORK, and RWORK arrays, and no error message related to LWORK is issued by XERBLA.

INFO

INTEGER.

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: if SBDSQR did not converge, INFO specifies how many superdiagonals of an intermediate bidiagonal form B (computed in SGESVD) did not converge to zero.

Further Details:

   1. The data movement (matrix transpose) is coded using simple nested
   DO-loops because BLAS and LAPACK do not provide corresponding subroutines.
   Those DO-loops are easily identified in this source code - by the CONTINUE
   statements labeled with 11**. In an optimized version of this code, the
   nested DO loops should be replaced with calls to an optimized subroutine.
   2. This code scales A by 1/SQRT(M) if the largest ABS(A(i,j)) could cause
   column norm overflow. This is the minial precaution and it is left to the
   SVD routine (CGESVD) to do its own preemptive scaling if potential over-
   or underflows are detected. To avoid repeated scanning of the array A,
   an optimal implementation would do all necessary scaling before calling
   CGESVD and the scaling in CGESVD can be switched off.
   3. Other comments related to code optimization are given in comments in the
   code, enclosed in [[double brackets]].
