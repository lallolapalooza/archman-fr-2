NOM

sg_timestamp - rapporter ou définir l'horodatage sur un périphérique SCSI

SYNTAXE

sg_timestamp [--elapsed] [--help] [--hex] [--milliseconds=MS] [--no-timestamp] [--origin] [--raw] [--readonly] [--seconds=SECS] [--srep] [--verbose] [--version] PÉRIPHÉ

DESCRIPTION

Envoie une commande SCSI REPORT TIMESTAMP ou SET TIMESTAMP au PÉRIPHÉ. Ces commandes se trouvent dans la norme préliminaire SPC-5, révision 7 (spc5r07.pdf).

Si l'option --milliseconds=MS ou --seconds=SECS est donnée (et les deux ne peuvent pas être données), alors la commande SET TIMESTAMP est envoyée ; sinon, la commande REPORT TIMESTAMP est envoyée.

L'horodatage est envoyé et reçu du PÉRIPHÉ sous forme du nombre de millisecondes écoulées depuis l'époque du 1970-01-01 00:00:00 UTC et est stocké dans un entier non signé de 48 bits. La même époque est utilisée par les machines Unix, mais elles stockent généralement le nombre de secondes depuis cette époque. La commande Unix date et surtout son format ""+%s"" sont utiles pour convertir des horodatages en et depuis des formes plus lisibles par l'homme. Voir la section EXEMPLES ci-dessous.

Un utilitaire compagnon appelé sg_sat_datetime avec des options similaires est disponible pour accéder ou définir la date et l'heure dans un périphérique ATA (généralement un disque SATA). sg_sat_datetime émet des commandes ATA via la couche SCSI vers ATA Translation (SAT).

OPTIONS

Les arguments des options longues sont obligatoires, même pour les options courtes.

-e, --elapsed
suppose que l'horodatage dans REPORT TIMESTAMP est un temps écoulé depuis un événement tel qu'un cycle d'alimentation ou une réinitialisation matérielle, et formate la sortie comme '<n> jours hh:mm:ss.xxx' où hh sont les heures (00 à 23 inclus) ; mm sont les minutes (00 à 59 inclus) ; ss sont les secondes (00 à 59 inclus) et xxx sont les millisecondes (000 à 999 inclus). Si le nombre de jours est 0, alors '0 jours' n'est pas affiché, sauf si cette option est donnée deux fois ou plus.
-h, --help
affiche le message d'utilisation puis quitte.
-H, --hex
affiche la réponse à REPORT TIMESTAMP en hexadécimal ASCII sur stderr. La réponse n'est pas décodée.
-m, --milliseconds=MS
où MS est le nombre de millisecondes depuis le 1970-01-01 00:00:00 UTC à définir dans le PÉRIPHÉ avec la commande SCSI SET TIMESTAMP.
-N, --no-timestamp
lorsque REPORT TIMESTAMP est appelé, cette option supprime l'affichage de la valeur de l'horodatage (en secondes ou en millisecondes). Cela peut être utile pour désencombrer la sortie lors de la tentative de décodage de l'origine de l'horodatage (voir l'option --origin).
-o, --origin
les données du paramètre renvoyé par REPORT TIMESTAMP contiennent un champ "origine de l'horodatage". Lorsque cette option est donnée, ce champ est décodé et imprimé avant que la valeur de l'horodatage ne soit affichée. L'action par défaut (c'est-à-dire lorsque l'option n'est pas donnée) est de ne pas afficher ce champ décodé.
T10 définit ce champ comme "l'événement le plus récent qui a initialisé l'horloge de périphérique renvoyée". La valeur 0 indique une mise sous tension ou une réinitialisation matérielle a initialisé l'horloge ; 2 indique que SET TIMESTAMP a initialisé l'horloge, tandis que 3 indique qu'une autre méthode a initialisé l'horloge.
Lorsqu'il est utilisé une fois, une chaîne descriptive est affichée (sur une ligne avant la valeur de l'horodatage). Lorsqu'il est utilisé deux fois, la valeur du champ TIMESTAMP ORIGIN est affichée (en décimal, une valeur entre 0 et 7 inclus). Lorsqu'il est utilisé trois fois, une ligne de la forme 'TIMESTAMP_ORIGIN=<valeur>' est affichée.
-r, --raw
affiche la réponse SCSI REPORT TIMESTAMP (c'est-à-dire le tampon de sortie de données) en binaire (vers stdout). Notez que les options --origin et --srep sont ignorées lorsque cette option est donnée. De plus, tous les messages d'erreur et de verbosité sont affichés sur stderr.
-R, --readonly
ouvre le PÉRIPHÉ en lecture seule. L'action par défaut est d'ouvrir le PÉRIPHÉ en lecture-écriture.
-s, --seconds=SECS
où SECS est le nombre de secondes depuis le 1970-01-01 00:00:00 UTC à définir dans le PÉRIPHÉ avec la commande SCSI SET TIMESTAMP. SECS est multiplié par 1000 avant d'être utilisé dans la commande SET TIMESTAMP.
-S, --srep
rapporte le nombre de secondes depuis le 1970-01-01 00:00:00 UTC. Ceci est fait en divisant par 1000 la valeur renvoyée par la commande SCSI REPORT TIMESTAMP.
-v, --verbose
augmente le niveau de verbosité (c'est-à-dire les messages de débogage).
-V, --version
imprime la chaîne de version puis quitte.

VALEUR DE RETOUR

La valeur de retour de sg_timestamp est 0 en cas de succès. Sinon, voir la page de manuel de sg3_utils(8).

NOTES

Les bits TCMOS et SCSIP dans la page de mode d'extension de contrôle (voir sdparm) modifient les actions de l'horodatage détenu par un PÉRIPHÉ.

Actuellement, seuls les paramètres "Taux d'utilisation basé sur la date et l'heure" dans la page de journalisation de l'utilisation (sbc4r09.pdf) utilisent des horodatages. Voir l'utilitaire sg_logs. Les commandes et pages spécifiques au fournisseur peuvent également utiliser des horodatages.

EXEMPLES

Sur les machines Unix (par exemple, Linux, FreeBSD et Solaris), la commande date est utile pour travailler avec des horodatages.

Pour récupérer l'horodatage d'un PÉRIPHÉ et l'afficher sous une forme lisible par l'homme, on pourrait utiliser ceci :


# sg_timestamp -S /dev/sdb
1448993950
# date --date=@1448993950
mar. déc. 1 13:19:10 EST 2015
# date -R --date="@1448993950"
Tue, 01 Dec 2015 13:19:10 -0500

Les deux dernières commandes date montrent différentes formes de la même date (c'est-à-dire 1448993950 secondes depuis le 1970-01-01 00:00:00 UTC). Les commandes sg_timestamp et date peuvent être combinées en utilisant des apostrophes inversées :


# date -R --date=@`sg_timestamp -S /dev/sdc`
Wed, 16 Dec 2015 20:12:59 -0500

Pour définir l'horodatage sur le PÉRIPHÉ à l'heure actuelle (approximativement), on pourrait utiliser ceci :


# date +%s
1448993955
# sg_timestamp --seconds=1448993955 /dev/sdb

Ces deux lignes de commande pourraient être combinées en une seule en utilisant des apostrophes inversées :


# sg_timestamp --seconds=`date +%s` /dev/sdb
