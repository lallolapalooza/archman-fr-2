sous-programme sgesvd (caractère jobu, caractère jobvt, entier m, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) s, réel, dimension( ldu, * ) u, entier ldu, réel, dimension( ldvt, * ) vt, entier ldvt, réel, dimension( * ) work, entier lwork, entier info)

SGESVD calcule la décomposition en valeurs singulières (SVD) pour les matrices GE

Objectif :

!>
!> SGESVD calcule la décomposition en valeurs singulières (SVD) d'une matrice réelle
!> M par N, en calculant éventuellement les vecteurs singuliers gauche et/ou droit. La SVD est écrite
!>
!>      A = U * SIGMA * transpose(V)
!>
!> où SIGMA est une matrice M par N qui est nulle sauf sur ses
!> éléments diagonaux min(m,n), U est une matrice orthogonale M par M, et
!> V est une matrice orthogonale N par N. Les éléments diagonaux de SIGMA
!> sont les valeurs singulières de A ; elles sont réelles et non négatives, et
!> sont retournées dans l'ordre décroissant. Les premières min(m,n) colonnes de
!> U et V sont les vecteurs singuliers gauche et droit de A.
!>
!> Notez que la routine retourne V**T, pas V.
!>

Paramètres

JOBU 
!>          JOBU est CHARACTER*1
!>          Spécifie les options pour le calcul de tout ou partie de la matrice U :
!>          = 'A' : toutes les M colonnes de U sont retournées dans le tableau U.
!>          = 'S' : les premières min(m,n) colonnes de U (les vecteurs singuliers
!>                  gauche) sont retournées dans le tableau U.
!>          = 'O' : les premières min(m,n) colonnes de U (les vecteurs singuliers
!>                  gauche) écrasent le tableau A.
!>          = 'N' : aucune colonne de U (aucun vecteur singulier gauche) n'est
!>                  calculée.
!>

JOBVT

!>          JOBVT est CHARACTER*1
!>          Spécifie les options pour le calcul de tout ou partie de la matrice
!>          V**T :
!>          = 'A' : toutes les N lignes de V**T sont retournées dans le tableau VT.
!>          = 'S' : les premières min(m,n) lignes de V**T (les vecteurs singuliers
!>                  droit) sont retournées dans le tableau VT.
!>          = 'O' : les premières min(m,n) lignes de V**T (les vecteurs singuliers
!>                  droit) écrasent le tableau A.
!>          = 'N' : aucune ligne de V**T (aucun vecteur singulier droit) n'est
!>                  calculée.
!>
!>          JOBVT et JOBU ne peuvent pas être tous deux 'O'.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.  N >= 0.
!>

A

!>          A est un tableau REAL de dimension (LDA,N)
!>          À l'entrée, la matrice A de M par N.
!>          À la sortie,
!>          si JOBU = 'O', A est écrasée par les premières min(m,n)
!>                          colonnes de U (les vecteurs singuliers
!>                          gauche, stockés par colonne).
!>          si JOBVT = 'O', A est écrasée par les premières min(m,n)
!>                          lignes de V**T (les vecteurs singuliers
!>                          droit, stockés par ligne).
!>          si JOBU .ne. 'O' et JOBVT .ne. 'O', le contenu de A
!>                          est détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

S

!>          S est un tableau REAL de dimension (min(M,N))
!>          Les valeurs singulières de A, triées de sorte que S(i) >= S(i+1).
!>

U

!>          U est un tableau REAL de dimension (LDU,UCOL)
!>          (LDU,M) si JOBU = 'A' ou (LDU,min(M,N)) si JOBU = 'S'.
!>          Si JOBU = 'A', U contient la matrice orthogonale M par M, U.
!>          Si JOBU = 'S', U contient les premières min(m,n) colonnes de
!>          U (les vecteurs singuliers gauche, stockés par colonne).
!>          Si JOBU = 'N' ou 'O', U n'est pas référencé.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U.  LDU >= 1 ; si
!>          JOBU = 'S' ou 'A', LDU >= M.
!>

VT

!>          VT est un tableau REAL de dimension (LDVT,N)
!>          Si JOBVT = 'A', VT contient la matrice orthogonale N par N,
!>          V**T.
!>          Si JOBVT = 'S', VT contient les premières min(m,n) lignes de
!>          V**T (les vecteurs singuliers droit, stockés par ligne).
!>          Si JOBVT = 'N' ou 'O', VT n'est pas référencé.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT.  LDVT >= 1 ; si
!>          JOBVT = 'A', LDVT >= N ; si JOBVT = 'S', LDVT >= min(M,N).
!>

WORK

!>          WORK est un tableau REAL de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>          Si INFO > 0, WORK(2:MIN(M,N)) contient les éléments de la superdiagonale
!>          non convergés d'une matrice bidiagonale B
!>          dont la diagonale est dans S (pas nécessairement triée). B
!>          satisfait A = U * B * VT, donc elle a les mêmes valeurs singulières
!>          que A, et des vecteurs singuliers liés par U et VT.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= MAX(1,5*MIN(M,N)) pour les chemins (voir les commentaires dans le code) :
!>             - CHEMIN 1  (M beaucoup plus grand que N, JOBU='N')
!>             - CHEMIN 1t (N beaucoup plus grand que M, JOBVT='N')
!>          LWORK >= MAX(1,3*MIN(M,N)+MAX(M,N),5*MIN(M,N)) pour les autres chemins.
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si SBDSQR n'a pas convergé, INFO spécifie combien de
!>                superdiagonales d'une forme bidiagonale intermédiaire B
!>                n'ont pas convergé vers zéro. Voir la description de WORK
!>                ci-dessus pour les détails.
!>

NOM

sgesvd - Calcule la décomposition en valeurs singulières (SVD) d'une matrice réelle générale.

SYNOPSIS

CALL sgesvd( JOBu, JOBv, M, N, a, lda, s, u, ldu, v, ldv, work, lwork, info )

Documentation de fonction/sous-routine

JOBu
CHARACTER*1. Spécifie les vecteurs singuliers gauches à calculer.
JOBv
CHARACTER*1. Spécifie les vecteurs singuliers droits à calculer.
M
INTEGER. Le nombre de lignes de la matrice A.
N
INTEGER. Le nombre de colonnes de la matrice A.
a
REAL. Le tableau de taille (lda,N). Sur l'entrée, le tableau de taille (lda,N) contient la matrice A à décomposer.
lda
INTEGER. La largeur de la première dimension de A.
s
REAL. Le tableau de taille min(M,N). Sur la sortie, s contient les valeurs singulières de A en ordre décroissant.
u
REAL. Le tableau de taille (ldu,M) ou (ldu,K). Sur la sortie, si JOBu est 'A' ou 'S', u contient les vecteurs singuliers gauches.
ldu
INTEGER. La largeur de la première dimension de U.
v
REAL. Le tableau de taille (ldv,N) ou (ldv,K). Sur la sortie, si JOBv est 'A' ou 'S', v contient les vecteurs singuliers droits.
ldv
INTEGER. La largeur de la première dimension de V.
work
REAL. Le tableau de taille (lwork). Sur la sortie, work(1) contient la taille requise pour lwork.
lwork
INTEGER. La taille du tableau work.
info
INTEGER. info = 0 : succès ; info < 0 : erreur.
