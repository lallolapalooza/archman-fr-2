NOM

sg_rmsn - envoie la commande SCSI READ MEDIA SERIAL NUMBER

SYNTAXE

sg_rmsn [--help] [--raw] [--readonly] [--verbose] [--version] PÉRIPHÉRIQUE

DESCRIPTION

Envoie une commande SCSI READ MEDIA SERIAL NUMBER au PÉRIPHÉRIQUE et affiche la réponse.

Cette commande est décrite dans SPC-3, consultable sur www.t10.org. Elle a été ajoutée à l'origine à SPC-3 dans la révision 11 (2003/02/12). Ce n'est pas une commande obligatoire et l'auteur n'a vu aucun périphérique SCSI qui la prenne en charge.

OPTIONS

Les arguments des options longues sont également obligatoires pour les options courtes.

-h, --help
affiche le message d'utilisation puis quitte.
-r, --raw
envoie le numéro de série (s'il est trouvé) vers la sortie standard. Cette sortie peut contenir des caractères non imprimables (par exemple, le numéro de série est rempli avec des NULL à la fin de sorte que sa longueur est un multiple de 4). L'action par défaut est d'afficher le numéro de série en hexadécimal ASCII avec les caractères ASCII sur la droite. Tous les messages d'erreur sont envoyés vers la sortie d'erreur standard.
-R, --readonly
ouvre le PÉRIPHÉRIQUE en lecture seule plutôt qu'en lecture-écriture ce qui est le défaut. Le pilote sg Linux a besoin d'un accès en lecture-écriture pour la commande SCSI READ MEDIA SERIAL NUMBER, mais d'autres méthodes d'accès peuvent nécessiter un accès en lecture seule.
-v, --verbose
augmente le niveau de verbosité (c'est-à-dire la sortie de débogage).
-V, --version
affiche la chaîne de version puis quitte.

NOTES

Les informations d'identification du périphérique se trouvent également dans une réponse standard INQUIRY et ses pages VPD (voir sg_vpd). Les pages VPD pertinentes sont la « page d'identification du périphérique » (page VPD 0x83) et la page « numéro de série de l'unité » (page VPD 0x80).

L'ensemble de commandes MMC-4 pour les lecteurs CD/DVD/HD-DVD/BD possède une fonctionnalité « numéro de série du média » (0x109) [et une fonctionnalité « numéro de série de l'unité logique »]. Celles-ci peuvent être visualisées avec sg_get_config.

STATUT DE SORTIE

Le statut de sortie de sg_rmsn est 0 en cas de succès. Sinon, voir la page man sg3_utils(8).
