NOM

sg_get_user_stats, sg_get_user_stats_r, sg_free_user_stats - obtenir les utilisateurs actuellement connectés

SYNOPSIS

#include <statgrab.h>


sg_user_stats *sg_get_user_stats
(size_t *entries);


sg_user_stats *sg_get_user_stats_r
(size_t *entries);


sg_error sg_free_user_stats
(sg_user_stats *data);

DESCRIPTION

Le module de statistiques utilisateur fournit des informations sur les utilisateurs connectés. Chaque connexion est traitée séparément. Les deux fonctions de statistiques, sg_get_user_stats() et sg_get_user_stats_r(), renvoient un vecteur de sg_user_stats avec entries éléments.

Raccourci API

fonction renvoie propriétaire des données
sg_get_user_stats sg_user_stats * libstatgrab (thread local)
sg_get_user_stats_r sg_user_stats * l'appelant

Le vecteur sg_user_stats reçu de sg_get_user_stats_r() doit être libéré en utilisant sg_free_user_stats() lorsqu'il n'est plus nécessaire. L'appelant est responsable de cette opération.

VALEURS DE RETOUR

La structure retournée est de type sg_user_stats.

typedef struct {
        char *login_name;
        char *record_id;
        size_t record_id_size;
        char *device;
        char *hostname;
        pid_t pid;
        time_t login_time;
        time_t systime;
} sg_user_stats;
login_name
Le nom d'utilisateur utilisé pour se connecter
record_id
Identifiant d'enregistrement de la base de données de l'hôte contenant les informations de connexion (pas nécessairement terminé par un zéro)
record_id_size
Taille de l'identifiant d'enregistrement
device
Nom du périphérique (par ex. « pts/0 ») du terminal attribué à la session de connexion
hostname
Nom d'hôte (distant) depuis lequel l'utilisateur est connecté, par ex. « infoterm7.some.kind.of.domain.local », « localhost », « 10.42.17.4 » ou « :0.0 » (dans le cas d'une connexion locale via un nouveau xterm)
pid
Identifiant du processus qui a créé l'entrée dans la base de données des utilisateurs connectés
login_time
Horodatage (temps en secondes depuis l'époque) auquel l'utilisateur s'est connecté
systime
L'horodatage auquel les statistiques ci-dessus ont été collectées en secondes depuis l'époque
