sous-programme sget38 (real, dimension( 3 ) rmax, integer, dimension( 3 ) lmax, integer, dimension( 3 ) ninfo, integer knt, integer nin)

SGET38

Objectif :

!>
!> SGET38 teste STRSEN, une routine pour estimer les nombres de condition d'un
!> cluster de valeurs propres et/ou son sous-espace invariant à droite associé
!>
!> Les matrices de test sont lues à partir d'un fichier avec le numéro logique NIN.
!>

Paramètres

RMAX 
!>          RMAX est un tableau REEL, dimension (3)
!>          Valeurs des plus grands ratios de test.
!>          RMAX(1) = plus grands résidus de SHST01 ou comparaison
!>                    entre différents appels à STRSEN
!>          RMAX(2) = plus grande erreur dans le nombre de condition réciproque
!>                    en tenant compte de son conditionnement
!>          RMAX(3) = plus grande erreur dans le nombre de condition réciproque
!>                    sans tenir compte de son conditionnement (peut être plus grand que RMAX(2))
!>

LMAX

!>          LMAX est un tableau ENTIER, dimension (3)
!>          LMAX(i) est le numéro d'exemple où le plus grand ratio de test
!>          RMAX(i) est atteint. Aussi :
!>          Si SGEHRD renvoie INFO non nul pour l'exemple i, LMAX(1)=i
!>          Si SHSEQR renvoie INFO non nul pour l'exemple i, LMAX(2)=i
!>          Si STRSEN renvoie INFO non nul pour l'exemple i, LMAX(3)=i
!>

NINFO

!>          NINFO est un tableau ENTIER, dimension (3)
!>          NINFO(1) = Nombre de fois où SGEHRD a renvoyé INFO non nul
!>          NINFO(2) = Nombre de fois où SHSEQR a renvoyé INFO non nul
!>          NINFO(3) = Nombre de fois où STRSEN a renvoyé INFO non nul
!>

KNT

!>          KNT est un ENTIER
!>          Nombre total d'exemples testés.
!>

NIN

!>          NIN est un ENTIER
!>          Numéro logique d'entrée.
!>
