NOM

sgmldiff - Trouver les différences dans le balisage de deux fichiers SGML

SYNTAXE

sgmldiff [ options ... ] fichier1 fichier2 [ -a | --attributs
| -c [ attributs | imbrication | pos_texte ] | --contexte [ attributs | imbrication | pos_texte ]
| -s | --statistiques
| -h | --aide
| -v | --version ]

DESCRIPTION

Ce script perl permet de déterminer les différences structurelles entre deux fichiers SGML. Il compare les fichiers, indépendamment de ce qui se trouve entre les balises, pour se concentrer uniquement sur le balisage. Sa sortie est similaire à celle de diff(1).

L'utilisation typique de sgmldiff est de comparer un fichier SGML avec sa traduction dans une autre langue. Si la traduction a été effectuée proprement, sgmldiff se termine sans trouver de différence dans le balisage.

Un exemple d'appel typique à sgmldiff est :

      sgmldiff english.sgml italiano.sgml

S'il y a des différences dans le balisage entre les deux fichiers, sgmldiff affichera une série de rapports de différences résumés par des lignes de la forme :

169a164
À la ligne 169 du premier fichier, la ligne 164 du second fichier a été ajoutée.
8a12,15
À la ligne 8 du premier fichier, les lignes 12 à 15 du second fichier ont été ajoutées.
41d28
La ligne 41 du premier fichier a été supprimée, pour obtenir la ligne 28 du second fichier.
63,66d61
Les lignes 63 à 66 du premier fichier ont été supprimées. pour obtenir la ligne 61 du second fichier.
52c51
La ligne 52 du premier fichier a été changée en la ligne 51 du second fichier.
5,7c8,10
Les lignes 5 à 7 du premier fichier ont été changées en les lignes 8 à 10 du second fichier. En plus de ces résumés, les lignes du premier fichier sont affichées précédées de '<' et les lignes du second fichier sont affichées précédées de '>".

OPTIONS

Voici la liste des actions qui peuvent être demandées à sgmldiff :

[ -a | --attributs ]
Inclure les valeurs des attributs dans les tests de différence. Ne pas définir cette valeur si les attributs sont susceptibles d'être traduits. Définir cette valeur si les valeurs des attributs ne devraient pas changer entre les deux fichiers. Par défaut, les attributs ne sont pas inclus dans les tests de différence.
[ -c [ attributs | imbrication | pos_texte ] | --contexte [ attributs | imbrication | pos_texte ] ]
Ajouter plus de contexte à la différence. Étant donné que chaque test entre les balises est supprimé avant de tester les différences, sgmldiff risque de se resynchroniser au mauvais endroit, en pensant que la position dans les deux fichiers correspond, alors que ce n'est pas le cas. En ajoutant plus de contexte à la zone comparée, ce risque est diminué.

Les valeurs autorisées pour l'option --contexte sont :

attributs
Prendre en compte les noms des attributs. Les valeurs des attributs sont contrôlées par l'option attributs.
imbrication
Prendre en compte le niveau d'imbrication de toutes les balises comparées.
pos_texte
Prendre en compte la position dans le texte.
[ -s | --statistiques ]
Afficher quelques informations SGML à la fin.
[ -h | --aide ]
Afficher un court message d'aide et quitter
[ -v | --version ]
Afficher l'identifiant de la version et quitter
