NOM

sg_stpg - envoie la commande SCSI SET TARGET PORT GROUPS

SYNTAXE

sg_stpg [--actif] [--aide] [--hex] [--hors_ligne] [--optimisé] [--brut] [--veille] [--état=E,E...] [--tp=P,P...] [--indisponible] [--verbeux] [--version] PÉRIPHÉRIQUE

DESCRIPTION

Envoie une commande SCSI SET TARGET PORT GROUPS au PÉRIPHÉRIQUE. Cet utilitaire a différents modes selon que l'option --tp= est donnée ou non.

Si --tp= est donné, le bloc de paramètres de la commande SET TARGET PORT GROUPS est construit avec un descripteur pour chaque élément de la liste donnée à --tp=. La valeur de l'état d'accès asymétrique correspondante est soit prise dans la liste --état=, soit, si celle-ci n'est pas donnée, d'une des options d'état explicites (par exemple, --indisponible), utilisée de manière répétée si nécessaire.

Si --tp= n'est pas donné, une séquence de commandes SCSI est envoyée au PÉRIPHÉRIQUE menant à la commande SET TARGET PORT GROUPS. D'abord, une INQUIRY est envoyée pour récupérer la page VPD d'identification du périphérique afin de trouver le groupe de ports cible (primaire) associé au PÉRIPHÉRIQUE. Ensuite, une commande REPORT TARGET PORT GROUPS est émise pour trouver l'état actuel et si une transition vers l'état demandé est supportée. Si c'est le cas, la commande SET TARGET PORT GROUPS est envoyée.

L'accès aux groupes de ports cibles est décrit dans SPC-4 disponible sur www.t10.org dans les sections 5.8 et 5.16 (dans la révision 36e datée du 2012/8/24). La commande SET TARGET PORT GROUPS est également décrite dans la section 6.45 de ce document.

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également. Les options sont disposées par ordre alphabétique basé sur le nom de l'option longue.

-a, --actif
définit l'état actif/non optimisé.
-h, --aide
affiche le message d'utilisation puis quitte.
-H, --hex
affiche la réponse à la commande REPORT TARGET PORT GROUPS en hexadécimal puis quitte.
-O, -l, --hors_ligne
définit l'état hors ligne. C'est l'état approprié à définir pour un port cible avant de retirer le périphérique. Notez qu'un identifiant de port cible relatif doit être donné avec cet état (plutôt qu'un identifiant de groupe de ports cible que tous les autres états prennent).
-o, --optimisé
définit l'état actif/optimisé. Si aucune autre option d'état ou option --tp= n'est donnée, alors actif/optimisé est l'état par défaut.
-r, --brut
affiche la réponse à la commande REPORT TARGET PORT GROUPS en binaire sur stdout puis quitte.
-s, --veille
définit l'état de veille. Le groupe de ports doit accepter les commandes listées pour l'état "indisponible" plus les commandes LOG SELECT/SENSE, MODE SELECT/SENSE, RECEIVE DIAGNOSTIC RESULTS, SEND DIAGNOSTIC, PERSISTENT RESERVE IN/OUT.
-S, --état=E,E...
spécifie une liste séparée par des virgules (un ou plusieurs éléments) d'états. Un nombre ou une abréviation peuvent être donnés. Un nombre est supposé être un nombre décimal sauf s'il est préfixé par "0x" ou a un "h" final, auquel cas une valeur hexadécimale est supposée. Seules les valeurs 0, 1, 2, 3 ou 14 sont acceptées. Les abréviations acceptées sont "an", "ao", "o", "s" ou "u"; qui représentent respectivement actif/non optimisé(1), actif/optimisé(0), hors ligne(14), veille(2) ou indisponible(3).
-t, --tp=P,P...
spécifie une liste séparée par des virgules (un ou plusieurs éléments). Chaque élément est soit un identifiant de groupe de ports cibles (lorsque l'état correspondant est différent de "hors ligne") soit un identifiant de port cible relatif (lorsque l'état correspondant est "hors ligne"). Chaque élément est supposé être un nombre décimal sauf s'il est préfixé par "0x" ou a un "h" final, auquel cas une valeur hexadécimale est supposée.
-u, --indisponible
définit l'état indisponible. Le groupe de ports ne doit accepter que les commandes INQUIRY, REPORT LUNS, REPORT/SET TARGET PORT GROUPS, REQUEST SENSE et READ/WRITE BUFFER.
-v, --verbeux
augmente le niveau de verbosité (c'est-à-dire les messages de débogage).
-V, --version
affiche la chaîne de version puis quitte.

NOTES

La commande SET TARGET PORT GROUPS doit être supportée chaque fois que la valeur TPGS dans une réponse INQUIRY standard est 2 ou 3. [Visualiser avec l'utilitaire sg_inq.]

Remarquez que l'état hors ligne est appelé un "état d'accès asymétrique de port cible secondaire" et prend un identifiant de port cible relatif (c'est-à-dire qu'il agit sur un seul port cible). Tous les autres états sont appelés "états d'accès asymétrique de port cible primaire" et chacun prend un identifiant de groupe de ports cible (c'est-à-dire qu'il agit sur un ou plusieurs ports cibles).

Lorsque --tp= est donné, le même nombre d'éléments doit être donné à l'option --état=. Si plus d'un élément de liste est donné à --tp= et qu'un nombre égal d'éléments n'est _pas_ donné à l'option --état=, alors si un seul état est spécifié, il est répété.

STATUT DE SORTIE

Le statut de sortie de sg_stpg est 0 en cas de succès. Sinon, voir la page de manuel sg3_utils(8).
