NOM

(sg_cpu_percents *data);


sg_cpu_stats *sg_get_cpu_stats
(size_t *entries);


sg_cpu_stats *sg_get_cpu_stats_diff
(size_t *entries);

(size_t *entries);

DESCRIPTION

Ce sont les catégories de données fournies par le module de statistiques CPU : sg_get_cpu_stats() et sg_get_cpu_stats_r() fournissent des compteurs CPU natifs depuis le démarrage de la machine, sg_get_cpu_stats_diff() et sg_get_cpu_stats_diff_between() fournissent des compteurs CPU natifs entre deux appels à sg_get_cpu_stats(), et sg_get_cpu_percents_of() et sg_get_cpu_percents_r() fournissent des compteurs relatifs (où le total est de 100%) corrélés.

Raccourci API

fonction renvoie propriétaire des données
sg_get_cpu_stats sg_cpu_stats * libstatgrab (local au thread)
sg_get_cpu_stats_r sg_cpu_stats * l'appelant
sg_get_cpu_stats_diff sg_cpu_stats * libstatgrab (local au thread)
sg_get_cpu_stats_diff_between sg_cpu_stats * l'appelant
sg_get_cpu_percents_of sg_cpu_percents * libstatgrab (local au thread)
sg_get_cpu_percents_r sg_cpu_percents * l'appelant

Le tampon sg_cpu_stats reçu de sg_get_cpu_stats_r() et sg_get_cpu_stats_diff_between(), ainsi que le tampon sg_cpu_percents reçu de sg_get_cpu_percents_r() doivent être libérés à l'aide de sg_free_cpu_stats() ou sg_free_cpu_percents(), respectivement, lorsqu'ils ne sont plus nécessaires. L'appelant est responsable de le faire.

La valeur stockée (les « ticks ») varie selon les systèmes d'exploitation. Par exemple, Solaris a un total de 100 par seconde, tandis que Linux en a considérablement plus. De plus, différents systèmes d'exploitation stockent des informations différentes - vous ne trouverez pas de « nice cpu » sur Solaris, par exemple.

Les systèmes modernes devraient fournir des informations sur la résolution des ticks d'horloge en appelant sysconf(_SC_CLK_TCK).

VALEURS DE RETOUR

Il y a deux structures renvoyées par les fonctions de statistiques CPU.

typedef struct {
        unsigned long long user;
        unsigned long long kernel;
        unsigned long long idle;
        unsigned long long iowait;
        unsigned long long swap;
        unsigned long long nice;
        unsigned long long total;
        unsigned long long context_switches;
        unsigned long long voluntary_context_switches;
        unsigned long long involuntary_context_switches;
        unsigned long long syscalls;
        unsigned long long interrupts;
        unsigned long long soft_interrupts;
        time_t systime;
} sg_cpu_stats;

typedef struct {
        double user;
        double kernel;
        double idle;
        double iowait;
        double swap;
        double nice;
        time_t time_taken;
} sg_cpu_percents;
user kernel idle iowait swap nice total
Les différents états du CPU.
context_switches voluntary_context_switches involuntary_context_switches syscalls interrupts soft_interrupts
Les différentes actions de programme sur le CPU.
systime time_taken
Le temps écoulé en secondes depuis le dernier appel de la fonction, ou le temps système.
