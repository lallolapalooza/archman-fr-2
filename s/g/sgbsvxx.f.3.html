Documentation de la fonction/sous-programme

sous-programme sgbsvxx (character fact, character trans, integer n, integer kl, integer ku, integer nrhs, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, character equed, real, dimension( * ) r, real, dimension( * ) c, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx , * ) x, integer ldx, real rcond, real rpvgrw, real, dimension( * ) berr, integer n_err_bnds, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, integer nparams, real, dimension( * ) params, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SGBSVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices GB

Objectif :

!>
!>    SGBSVXX utilise la factorisation LU pour calculer la solution d'un
!>    système d'équations linéaires réelles  A * X = B,  où A est une
!>    matrice N-par-N et X et B sont des matrices N-par-NRHS.
!>
!>    Si demandé, des bornes d'erreur normées et des bornes d'erreur des composantes maximales sont retournées. SGBSVXX retournera une solution avec une petite
!>    erreur garantie (O(eps) où eps est la précision de la machine de travail)
!>    sauf si la matrice est très mal conditionnée, auquel cas un avertissement est retourné. Les nombres de condition pertinents sont également
!>    calculés et retournés.
!>
!>    SGBSVXX accepte les factorisations et les facteurs d'équilibrage fournis par l'utilisateur ; voir les définitions des options FACT et EQUED.
!>    Résoudre avec raffinement et utiliser une factorisation d'un appel précédent
!>    à SGBSVXX produira également une solution avec soit des erreurs O(eps)
!>    soit des avertissements, mais nous ne pouvons pas faire cette affirmation pour des factorisations et des facteurs d'équilibrage
!>    généraux fournis par l'utilisateur s'ils diffèrent de ce que SGBSVXX produirait lui-même.
!>

Description :

!>
!>    Les étapes suivantes sont effectuées :
!>
!>    1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Que le système soit équilibré ou non dépend de la
!>    mise à l'échelle de la matrice A, mais si l'équilibrage est utilisé, A est
!>    écrasé par diag(R)*A*diag(C) et B par diag(R)*B (si TRANS='N')
!>    ou diag(C)*B (si TRANS = 'T' ou 'C').
!>
!>    2. Si FACT = 'N' ou 'E', la décomposition LU est utilisée pour factoriser
!>    la matrice A (après équilibrage si FACT = 'E') comme
!>
!>      A = P * L * U,
!>
!>    où P est une matrice de permutation, L est une matrice triangulaire inférieure unitaire
!>    et U est triangulaire supérieure.
!>
!>    3. Si U(i,i)=0, de sorte que U est exactement singulier, alors le
!>    sous-programme retourne avec INFO = i. Sinon, la forme factorisée de A
!>    est utilisée pour estimer le nombre de condition de la matrice A (voir
!>    l'argument RCOND). Si l'inverse du nombre de condition est inférieur à la
!>    précision de la machine, le sous-programme continue de résoudre pour X
!>    et de calculer les bornes d'erreur comme décrit ci-dessous.
!>
!>    4. Le système d'équations est résolu pour X en utilisant la forme factorisée de A.
!>
!>    5. Par défaut (sauf si PARAMS(LA_LINRX_ITREF_I) est mis à zéro),
!>    le sous-programme utilisera le raffinement itératif pour essayer d'obtenir une petite
!>    erreur et des bornes d'erreur. Le raffinement calcule le résidu à
!>    au moins deux fois la précision de travail.
!>
!>    6. Si l'équilibrage a été utilisé, la matrice X est pré-multipliée par
!>    diag(C) (si TRANS = 'N') ou diag(R) (si TRANS = 'T' ou 'C') de sorte
!>    qu'elle résolve le système d'origine avant l'équilibrage.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment le raffinement est effectué, mais souvent les
!>     valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>     Spécifie si la forme factorisée de la matrice A est fournie ou non
!>     à l'entrée, et sinon, si la matrice A doit être
!>     équilibrée avant d'être factorisée.
!>       = 'F' : À l'entrée, AF et IPIV contiennent la forme factorisée de A.
!>               Si EQUED n'est pas 'N', la matrice A a été
!>               équilibrée avec des facteurs d'échelle donnés par R et C.
!>               A, AF et IPIV ne sont pas modifiés.
!>       = 'N' : La matrice A sera copiée dans AF et factorisée.
!>       = 'E' : La matrice A sera équilibrée si nécessaire, puis
!>               copiée dans AF et factorisée.
!>

TRANS

!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N':  A * X = B     (Pas de transposée)
!>       = 'T':  A**T * X = B  (Transposée)
!>       = 'C':  A**H * X = B  (Transposée conjuguée = Transposée)
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est tableau REAL, dimension (LDAB,N)
!>     À l'entrée, la matrice A en stockage bande, dans les lignes 1 à KL+KU+1.
!>     La j-ème colonne de A est stockée dans la j-ème colonne du
!>     tableau AB comme suit :
!>     AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU)<=i<=min(N,j+kl)
!>
!>     Si FACT = 'F' et EQUED n'est pas 'N', alors AB doit avoir été
!>     équilibré par les facteurs d'échelle dans R et/ou C. AB n'est pas
!>     modifié si FACT = 'F' ou 'N', ou si FACT = 'E' et
!>     EQUED = 'N' à la sortie.
!>
!>     À la sortie, si EQUED .ne. 'N', A est mis à l'échelle comme suit :
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est tableau REAL, dimension (LDAFB,N)
!>     Si FACT = 'F', alors AFB est un argument d'entrée et à l'entrée
!>     contient les détails de la factorisation LU de la matrice bande
!>     A, telle que calculée par SGBTRF. U est stocké comme une matrice triangulaire supérieure
!>     bande avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1,
!>     et les multiplicateurs utilisés pendant la factorisation sont stockés
!>     dans les lignes KL+KU+2 à 2*KL+KU+1. Si EQUED .ne. 'N', alors AFB est
!>     la forme factorisée de

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale du tableau AFB.  LDAFB >= KL+KU+1.
!>

IPIV

!>          IPIV est tableau INTEGER, dimension (N)
!>     Si FACT = 'F', alors IPIV est un argument d'entrée et contient les
!>     détails des permutations effectuées par SGBTRF. IPIV(i) contient
!>     l'entier indiquant la ligne dans la colonne i de U contenant le pivot.
!>     Si FACT = 'N' ou 'E', alors IPIV est une sortie et contient les détails
!>     des permutations effectuées. IPIV(i) contient l'entier indiquant la
!>     ligne dans la colonne i de U contenant le pivot.
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie les détails de l'équilibrage de la matrice A.
!>     Si FACT = 'F', EQUED est un argument d'entrée et doit spécifier
!>     les détails de l'équilibrage.
!>       = 'N': Aucune mise à l'échelle n'a été effectuée.
!>       = 'R': La ligne gauche a été mise à l'échelle, càd : A := diag(R)*A.
!>       = 'C': La colonne droite a été mise à l'échelle, càd : A := A*diag(C).
!>       = 'B': Les deux lignes gauche et droite ont été mises à l'échelle, càd : A := diag(R)*A*diag(C).
!>     Si FACT = 'E', EQUED est une sortie et spécifie les détails de
!>     l'équilibrage.
!>       = 'N': Aucune mise à l'échelle n'est nécessaire.
!>       = 'R': La ligne gauche a été mise à l'échelle.
!>       = 'C': La colonne droite a été mise à l'échelle.
!>       = 'B': Les deux lignes gauche et droite ont été mises à l'échelle.
!>

R

!>          R est tableau REAL, dimension (*)
!>     Si FACT = 'F', R est un argument d'entrée et contient les facteurs
!>     de mise à l'échelle des lignes. Si EQUED = 'R' ou 'B', R contient
!>     les facteurs utilisés.
!>     Si FACT = 'E', R est une sortie et contient les facteurs de mise
!>     à l'échelle des lignes utilisés pour équilibrer la matrice A.
!>     Si EQUED = 'N' ou 'C', R n'est pas utilisé.
!>

C

!>          C est tableau REAL, dimension (*)
!>     Si FACT = 'F', C est un argument d'entrée et contient les facteurs
!>     de mise à l'échelle des colonnes. Si EQUED = 'C' ou 'B', C contient
!>     les facteurs utilisés.
!>     Si FACT = 'E', C est une sortie et contient les facteurs de mise
!>     à l'échelle des colonnes utilisés pour équilibrer la matrice A.
!>     Si EQUED = 'N' ou 'R', C n'est pas utilisé.
!>

B

!>          B est tableau REAL, dimension (LDB,NRHS)
!>     Le côté droit des équations linéaires A*X = B.
!>     A la sortie, si l'équilibrage est effectué (EQUED = 'R' ou 'B')
!>     et TRANS = 'N', B est écrasé par diag(R)*B.
!>     À la sortie, si l'équilibrage est effectué (EQUED = 'C' ou 'B')
!>     et TRANS = 'T' ou 'C', B est écrasé par diag(C)*B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est tableau REAL, dimension (LDX,NRHS)
!>     À la sortie, X contient la solution du système d'équations linéaires.
!>     Si l'équilibrage est effectué et TRANS = 'N', X est mis à l'échelle
!>     par diag(C).
!>     Si l'équilibrage est effectué et TRANS = 'T' ou 'C', X est mis à l'échelle
!>     par diag(R).
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>     À la sortie, RCOND est une estimation du nombre de condition inverse
!>     de la matrice A.
!>

RPVGRW

!>          RPVGRW est REAL
!>     À la sortie, RPVGRW est une estimation de la condition relative
!>     pour le calcul de la solution de X.
!>

BERR

!>          BERR est tableau REAL, dimension (*)
!>     À la sortie, BERR contient une estimation de l'erreur relative
!>     sur la solution X. Pour chaque colonne j du côté droit, BERR(j)
!>     est une estimation de la quantité
!>     || X(j) - X_true(j) || / || X_true(j) ||.
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Le nombre d'estimations de borne d'erreur retournées dans
!>     ERR_BNDS_NORM et ERR_BNDS_COMP.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est tableau REAL, dimension (NRHS, N_ERR_BNDS)
!>     À la sortie, ERR_BNDS_NORM contient des bornes d'erreur normées.
!>     ERR_BNDS_NORM(j,k) est une borne supérieure de l'erreur relative
!>     sur la solution X(j) de la k-ème équation résolue.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est tableau REAL, dimension (NRHS, N_ERR_BNDS)
!>     À la sortie, ERR_BNDS_COMP contient des bornes d'erreur composantes.
!>     ERR_BNDS_COMP(j,k) est une borne supérieure de l'erreur relative
!>     sur la solution X(j) de la k-ème équation résolue, où l'erreur
!>     est calculée par composante.
!>

NPARAMS

!>          NPARAMS est INTEGER
!>     Le nombre de paramètres optionnels disponibles dans PARAMS.
!>     Si NPARAMS = 0, alors PARAMS n'est pas utilisé.
!>

PARAMS

!>          PARAMS est tableau REAL, dimension (NPARAMS)
!>     Tableau des paramètres optionnels. Voir les instructions ci-dessus
!>     pour une description détaillée.
!>

WORK

!>          WORK est tableau REAL, dimension (max(1,LWORK))
!>     Si LWORK = -1, alors WORK(1) contient la taille de travail requise.
!>

LWORK

!>          LWORK est INTEGER
!>     La taille du tableau WORK. LWORK >= max(1, N).
!>

IWORK

!>          IWORK est tableau INTEGER, dimension (max(1,LIWORK))
!>     Si LIWORK = -1, alors IWORK(1) contient la taille de travail requise.
!>

LIWORK

!>          LIWORK est INTEGER
!>     La taille du tableau IWORK. LIWORK >= max(1, N).
!>

INFO

!>          INFO est INTEGER
!>     INFO = 0:  Traitement réussi.
!>     INFO < 0: Si INFO = -i, l'i-ème argument avait une valeur illégale.
!>     INFO > 0: Si INFO = i, alors U(i,i) était zéro.  La matrice U est singulière
!>             et la décomposition LU n'a pas pu être complétée.
!>             Les conditions de raffinement et les bornes d'erreur ne peuvent pas être
!>             calculées.
!>

!>          EQUED est une chaîne d'un seul caractère (CHARACTER*1)
!>     Spécifie la forme d'équilibration qui a été effectuée.

!>     argument de sortie.

R

!>          R est un tableau de réels (REAL array) de dimension (N)
!>     Les facteurs d'échelle des lignes pour A. Si EQUED = 'R' ou 'B', A est
!>     multiplié à gauche par diag(R) ; si EQUED = 'N' ou 'C', R
!>     n'est pas accédé. R est un argument d'entrée si FACT = 'F';
!>     sinon, R est un argument de sortie. Si FACT = 'F' et
!>     EQUED = 'R' ou 'B', chaque élément de R doit être positif.
!>     Si R est en sortie, chaque élément de R est une puissance de la base.
!>     Si R est en entrée, chaque élément de R doit être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances de la base ne provoque pas d'erreurs d'arrondi, sauf si le
!>     résultat sous-dépasse ou dépasse la capacité. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

C

!>          C est un tableau de réels (REAL array) de dimension (N)
!>     Les facteurs d'échelle des colonnes pour A. Si EQUED = 'C' ou 'B', A est
!>     multiplié à droite par diag(C) ; si EQUED = 'N' ou 'R', C
!>     n'est pas accédé. C est un argument d'entrée si FACT = 'F';
!>     sinon, C est un argument de sortie. Si FACT = 'F' et
!>     EQUED = 'C' ou 'B', chaque élément de C doit être positif.
!>     Si C est en sortie, chaque élément de C est une puissance de la base.

!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est un tableau de réels (REAL array) de dimension (LDB,NRHS)
!>     À l'entrée, la matrice second membre B de taille N-par-NRHS.
!>     À la sortie,
!>     si EQUED = 'N', B n'est pas modifié ;
!>     si TRANS = 'N' et EQUED = 'R' ou 'B', B est écrasé par
!>        diag(R)*B ;
!>     si TRANS = 'T' ou 'C' et EQUED = 'C' ou 'B', B est
!>        écrasé par diag(C)*B.
!>

LDB

!>          LDB est un entier (INTEGER)
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau de réels (REAL array) de dimension (LDX,NRHS)
!>     Si INFO = 0, la matrice solution X de taille N-par-NRHS du système
!>     d'équations original. Notez que A et B sont modifiés à la sortie
!>     si EQUED .ne. 'N', et la solution du système équilibré est
!>     inv(diag(C))*X si TRANS = 'N' et EQUED = 'C' ou 'B', ou
!>     inv(diag(R))*X si TRANS = 'T' ou 'C' et EQUED = 'R' ou 'B'.
!>

LDX

!>          LDX est un entier (INTEGER)
!>     La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est un réel (REAL)
!>     Conditionnement réciproque mis à l'échelle. C'est une estimation du
!>     conditionnement de Skeel réciproque de la matrice A après
!>     équilibration (si effectuée). Si celui-ci est inférieur à la précision machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut toujours être petite même
!>     si ce nombre est très petit et que la matrice semble mal
!>     conditionnée.
!>

RPVGRW

!>          RPVGRW est un réel (REAL)
!>     Croissance réciproque des pivots. À la sortie, ceci contient le facteur de
!>     croissance réciproque des pivots norm(A)/norm(U). La
!>     norme utilisée est . Si ceci est beaucoup plus petit que 1, alors la stabilité de
!>     la factorisation LU de la matrice A (équilibrée) pourrait être médiocre.
!>     Cela signifie également que la solution X, les conditionnements estimés,
!>     et les bornes d'erreur pourraient ne pas être fiables. Si la factorisation échoue avec
!>     0<INFO<=N, alors ceci contient le facteur de croissance réciproque des pivots
!>     pour les INFO premières colonnes de A. Dans SGESVX, cette quantité est
!>     renvoyée dans WORK(1).
!>

BERR

!>          BERR est un tableau de réels (REAL array) de dimension (NRHS)
!>     Erreur relative par composante à rebours. C'est l'erreur relative par composante
!>     de chaque vecteur solution X(j)
!>     (c'est-à-dire le plus petit changement relatif dans un élément quelconque de A ou B qui
!>     fait de X(j) une solution exacte).

!>     Pour chaque second membre, ce tableau contient des informations sur

!>     définie comme suit :

!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit

!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois champs suivants :

!>              sqrt(n) * slamch('Epsilon').

!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur 10 de l'erreur réelle

!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne doit être
!>              utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Conditionnement réciproque : Conditionnement normal réciproque estimé.

!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces conditionnements réciproques sont
!>              1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une certaine
!>              matrice Z appropriée.
