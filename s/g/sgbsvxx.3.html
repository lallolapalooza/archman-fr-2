sous-routine sgbsvxx (character fact, character trans, integer n, integer kl, integer ku, integer nrhs, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, character equed, real, dimension( * ) r, real, dimension( * ) c, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx , * ) x, integer ldx, real rcond, real rpvgrw, real, dimension( * ) berr, integer n_err_bnds, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, integer nparams, real, dimension( * ) params, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SGBSVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices GB

Objectif :

!>
!>    SGBSVXX utilise la factorisation LU pour calculer la solution d'un
!>    système linéaire réel  A * X = B,  où A est une matrice de taille
!>    N-par-N et X et B sont des matrices de taille N-par-NRHS.
!>
!>    Si demandé, des bornes d'erreur normées et des bornes d'erreur composantes maximales
!>    sont retournées. SGBSVXX retournera une solution avec une petite erreur garantie (O(eps)
!>    où eps est la précision de machine de travail) sauf si la matrice est très mal conditionnée,
!>    auquel cas un avertissement est retourné. Les nombres de conditionnement pertinents sont
!>    également calculés et retournés.
!>
!>    SGBSVXX accepte les factorisations et les facteurs d'équilibrage fournis par l'utilisateur ;
!>    voir les définitions des options FACT et EQUED.
!>    La résolution avec raffinement et l'utilisation d'une factorisation provenant d'un appel précédent
!>    à SGBSVXX produiront également une solution avec des erreurs O(eps) ou des avertissements,
!>    mais nous ne pouvons pas affirmer cela pour des factorisations et des facteurs d'équilibrage
!>    généraux fournis par l'utilisateur s'ils diffèrent de ce que SGBSVXX produirait lui-même.
!>

Description :

!>
!>    Les étapes suivantes sont effectuées :
!>
!>    1. Si FACT = 'E', des facteurs de mise à l'échelle réels sont calculés pour équilibrer
!>    le système :
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle de la matrice A,
!>    mais si l'équilibrage est utilisé, A est écrasée par diag(R)*A*diag(C) et B par diag(R)*B
!>    (si TRANS='N') ou diag(C)*B (si TRANS = 'T' ou 'C').
!>
!>    2. Si FACT = 'N' ou 'E', la décomposition LU est utilisée pour factoriser
!>    la matrice A (après équilibrage si FACT = 'E') comme suit :
!>
!>      A = P * L * U,
!>
!>    où P est une matrice de permutation, L est une matrice triangulaire inférieure unitaire,
!>    et U est triangulaire supérieure.
!>
!>    3. Si un U(i,i)=0, de sorte que U soit exactement singulier, alors la
!>    routine retourne avec INFO = i. Sinon, la forme factorisée de A
!>    est utilisée pour estimer le nombre de conditionnement de la matrice A (voir
!>    l'argument RCOND). Si l'inverse du nombre de conditionnement est inférieur à la précision machine,
!>    la routine continue quand même à résoudre pour X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!>    4. Le système d'équations est résolu pour X en utilisant la forme factorisée de A.
!>
!>    5. Par défaut (sauf si PARAMS(LA_LINRX_ITREF_I) est mis à zéro),
!>    la routine utilise le raffinement itératif pour tenter d'obtenir une petite erreur
!>    et de petites bornes d'erreur. Le raffinement calcule le résidu avec une précision au moins double de la précision de travail.
!>
!>    6. Si l'équilibrage a été utilisé, la matrice X est prémultipliée par
!>    diag(C) (si TRANS = 'N') ou diag(R) (si TRANS = 'T' ou 'C') de sorte qu'elle résolve le système d'origine avant équilibrage.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent la manière dont le raffinement est effectué, mais souvent les
!>     valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>     Spécifie si la forme factorisée de la matrice A est fournie en entrée, et si ce n'est pas le cas, si la matrice A doit être équilibrée avant d'être factorisée.
!>       = 'F':  En entrée, AF et IPIV contiennent la forme factorisée de A.
!>               Si EQUED n'est pas 'N', la matrice A a été équilibrée avec les facteurs d'échelle donnés par R et C.
!>               A, AF et IPIV ne sont pas modifiés.
!>       = 'N':  La matrice A sera copiée dans AF et factorisée.
!>       = 'E':  La matrice A sera équilibrée si nécessaire, puis copiée dans AF et factorisée.
!>

TRANS

!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N':  A * X = B     (Pas de transposée)
!>       = 'T':  A**T * X = B  (Transposée)
!>       = 'C':  A**H * X = B  (Transposée conjuguée = Transposée)
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est tableau REAL, dimension (LDAB,N)
!>     En entrée, la matrice A en stockage bande, dans les lignes 1 à KL+KU+1.
!>     La j-ième colonne de A est stockée dans la j-ième colonne du
!>     tableau AB comme suit :
!>     AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU)<=i<=min(N,j+kl)
!>
!>     Si FACT = 'F' et EQUED n'est pas 'N', alors AB doit avoir été
!>     équilibré par les facteurs d'échelle dans R et/ou C.  AB n'est pas
!>     modifié si FACT = 'F' ou 'N', ou si FACT = 'E' et
!>     EQUED = 'N' à la sortie.
!>
!>     À la sortie, si EQUED .ne. 'N', A est mise à l'échelle comme suit :
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est tableau REAL, dimension (LDAFB,N)
!>     Si FACT = 'F', alors AFB est un argument d'entrée et contient à l'entrée
!>     les détails de la factorisation LU de la matrice bande
!>     A, tels que calculés par SGBTRF.  U est stockée comme une matrice bande triangulaire supérieure
!>     avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1,
!>     et les multiplicateurs utilisés pendant la factorisation sont stockés
!>     dans les lignes KL+KU+2 à 2*KL+KU+1. Si EQUED .ne. 'N', alors AFB est
!>     la forme factorisée de
la matrice équilibrée A. !> !> Si FACT = 'N', alors AF est un argument de sortie et retourne à la sortie !> les facteurs L et U de la factorisation A = P*L*U !> de la matrice originale A. !> !> Si FACT = 'E', alors AF est un argument de sortie et retourne à la sortie !> les facteurs L et U de la factorisation A = P*L*U !> de la matrice équilibrée A (voir la description de A pour !> la forme de la matrice équilibrée). !>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension de tête du tableau AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Si FACT = 'F', alors IPIV est un argument d'entrée et à l'entrée
!>     contient les indices de pivot de la factorisation A = P*L*U
!>     tels que calculés par SGETRF ; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>
!>     Si FACT = 'N', alors IPIV est un argument de sortie et à la sortie
!>     contient les indices de pivot de la factorisation A = P*L*U
!>     de la matrice originale A.
!>
!>     Si FACT = 'E', alors IPIV est un argument de sortie et à la sortie
!>     contient les indices de pivot de la factorisation A = P*L*U
!>     de la matrice équilibrée A.
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibration qui a été effectuée.
!>       = 'N':  Aucune équilibration (toujours vrai si FACT = 'N').
!>       = 'R':  Équilibrage des lignes, c'est-à-dire que A a été pré-multiplié par
!>               diag(R).
!>       = 'C':  Équilibrage des colonnes, c'est-à-dire que A a été post-multiplié
!>               par diag(C).
!>       = 'B':  Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(R) * A * diag(C).
!>     EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un
!>     argument de sortie.
!>

R

!>          R est un tableau REAL, dimension (N)
!>     Les facteurs d'échelle des lignes de A.  Si EQUED = 'R' ou 'B', A est
!>     multiplié à gauche par diag(R) ; si EQUED = 'N' ou 'C', R
!>     n'est pas accédé.  R est un argument d'entrée si FACT = 'F' ;
!>     sinon, R est un argument de sortie.  Si FACT = 'F' et
!>     EQUED = 'R' ou 'B', chaque élément de R doit être positif.
!>     Si R est en sortie, chaque élément de R est une puissance du radix.
!>     Si R est en entrée, chaque élément de R doit être une puissance du radix
!>     pour assurer une solution et des estimations d'erreur fiables. La mise à
!>     l'échelle par des puissances du radix ne provoque pas d'erreurs
!>     d'arrondi, sauf si le résultat est sous-évalué ou surévalué. Les erreurs
!>     d'arrondi lors de la mise à l'échelle conduisent à un raffinement avec une
!>     matrice qui n'est pas équivalente à la matrice d'entrée, produisant des
!>     estimations d'erreur qui pourraient ne pas être fiables.
!>

C

!>          C est un tableau REAL, dimension (N)
!>     Les facteurs d'échelle des colonnes de A.  Si EQUED = 'C' ou 'B', A est
!>     multiplié à droite par diag(C) ; si EQUED = 'N' ou 'R', C
!>     n'est pas accédé.  C est un argument d'entrée si FACT = 'F' ;
!>     sinon, C est un argument de sortie.  Si FACT = 'F' et
!>     EQUED = 'C' ou 'B', chaque élément de C doit être positif.
!>     Si C est en sortie, chaque élément de C est une puissance du radix.
!>     Si C est en entrée, chaque élément de C doit être une puissance du radix
!>     pour assurer une solution et des estimations d'erreur fiables. La mise à
!>     l'échelle par des puissances du radix ne provoque pas d'erreurs
!>     d'arrondi, sauf si le résultat est sous-évalué ou surévalué. Les erreurs
!>     d'arrondi lors de la mise à l'échelle conduisent à un raffinement avec une
!>     matrice qui n'est pas équivalente à la matrice d'entrée, produisant des
!>     estimations d'erreur qui pourraient ne pas être fiables.
!>

B

!>          B est un tableau REAL, dimension (LDB,NRHS)
!>     À l'entrée, la matrice membre de droite B de taille N-par-NRHS.
!>     À la sortie,
!>     si EQUED = 'N', B n'est pas modifié ;
!>     si TRANS = 'N' et EQUED = 'R' ou 'B', B est écrasé par
!>        diag(R)*B ;
!>     si TRANS = 'T' ou 'C' et EQUED = 'C' ou 'B', B est
!>        écrasé par diag(C)*B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension de tête du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau REAL, dimension (LDX,NRHS)
!>     Si INFO = 0, la matrice solution X de taille N-par-NRHS du système
!>     d'équations original.  Notez que A et B sont modifiés à la sortie
!>     si EQUED .ne. 'N', et la solution du système équilibré est
!>     inv(diag(C))*X si TRANS = 'N' et EQUED = 'C' ou 'B', ou
!>     inv(diag(R))*X si TRANS = 'T' ou 'C' et EQUED = 'R' ou 'B'.
!>

LDX

!>          LDX est INTEGER
!>     La dimension de tête du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>     Conditionnement réciproque échelonné. C'est une estimation du
!>     conditionnement réciproque de Skeel de la matrice A après
!>     équilibration (si effectuée). S'il est inférieur à la précision machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut toujours être faible même
!>     si ce nombre est très petit et que la matrice semble mal conditionnée.
!>

RPVGRW

!>          RPVGRW est REAL
!>     Croissance réciproque du pivot. À la sortie, contient le facteur de
!>     croissance réciproque du pivot norm(A)/norm(U). La
!>     norme est utilisée. Si c'est beaucoup moins que 1, alors la stabilité de
!>     la factorisation LU de la matrice A (équilibrée) pourrait être médiocre.
!>     Cela signifie également que la solution X, les conditionnements estimés
!>     et les bornes d'erreur pourraient ne pas être fiables. Si la factorisation
!>     échoue avec 0<INFO<=N, alors ceci contient le facteur de croissance réciproque
!>     du pivot pour les INFO premières colonnes de A. Dans SGESVX, cette quantité
!>     est retournée dans WORK(1).
!>

BERR

!>          BERR est un tableau REAL, dimension (NRHS)
!>     Erreur relative par composante de retour. C'est l'erreur
!>     relative par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire le plus petit changement relatif dans un élément de A ou B qui
!>     fait de X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à retourner pour chaque membre de droite
!>     et chaque type (global ou par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau REAL, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et conditionnements correspondant à l'erreur
!>     relative globale, qui est définie comme suit :
!>
!>     Erreur relative globale dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              faite confiance que si le booléen précédent est vrai.
!>
!>     err = 3  Conditionnement réciproque : Conditionnement réciproque global
!>              estimé. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation d'erreur
!>              est . Ces conditionnements réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une certaine
!>              matrice Z appropriément échelonnée.
!>              Soit Z = S*A, où S échelonne chaque ligne par une puissance du
!>              radix de sorte que toutes les sommes de lignes absolues de Z soient
!>              approximativement 1.
!>
!>     Voir la note de travail Lapack 165 pour plus de détails et des précautions
!>     supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau REAL, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et conditionnements correspondant à l'erreur
!>     relative par composante, qui est définie comme suit :
!>
!>     Erreur relative par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le membre de droite i (dont dépend l'erreur
!>     relative par composante), et le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations retournées pour
!>     chaque membre de droite. Si la précision par composante n'est pas demandée
!>     (PARAMS(3) = 0.0), alors ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3,
!>     alors au plus les premières (:,N_ERR_BNDS) entrées sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              faite confiance que si le booléen précédent est vrai.
!>
!>     err = 3  Conditionnement réciproque : Conditionnement réciproque par
!>              composante estimé. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation d'erreur
!>              est . Ces conditionnements réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une certaine
!>              matrice Z appropriément échelonnée.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              membre de droite courant et S échelonne chaque ligne de
!>              A*diag(x) par une puissance du radix de sorte que toutes les sommes
!>              de lignes absolues de Z soient approximativement 1.
!>
!>     Voir la note de travail Lapack 165 pour plus de détails et des précautions
!>     supplémentaires.
!>

NPARAMS

!>          NPARAMS est INTEGER
!>     Spécifie le nombre de paramètres définis dans PARAMS. Si <= 0, le
!>     tableau PARAMS n'est jamais référencé et les valeurs par défaut sont utilisées.
!>

PARAMS

!>          PARAMS est un tableau REAL, dimension NPARAMS
!>     Spécifie les paramètres de l'algorithme. Si une entrée est < 0.0, alors
!>     cette entrée sera remplie avec la valeur par défaut utilisée pour cette
!>     



NAME


sgbsvxx -  sgbsvxx






SYNOPSIS


SUBROUTINE SGBSVXX(
     ROW PURCHASES, COL PURCHASES, AB, LDAB, DI , V , LDBV , A , LDAA , B , LDBB , X , LDXB ,
     PERR , TERR , INFO )





Function/Subroutine Documentation


 sgbsvxx (3)


LAPACK routine (argument   list)


Purpose 

 SGBSVXX computes the solution to a general band system of linear
 equations


 A * X = B



where A is an N-by-N band matrix with KL subdiagonals and KU
 superdiagonals, and X and B are N-by-NRHS matrices. 


Error bounds are computed for the solution X, and there is an option to
 improve the accuracy of the solution by iterative refinement.


 Arguments



Parameters


       LWORK = 12*N


Description


 This routine is in the sgb type. When the dimension of the problem is
 large, each call to sgbsvxx involves many operations, and it is
 therefore desirable to minimize the number of calls to
 subroutine. 


For the description of the arguments and the computation of
 the error bounds and iterative refinement, see sgbsvxx.f.


Author


Univ. of Tennessee

Univ. of California Berkeley


Univ. of Colorado Denver


NAG Ltd.

Parameters


       LA_LINRX_ITREF_I = 1 : Whether to perform iterative
            refinement or not.
         Default: 1.0
            = 0.0:  No refinement is performed, and no error bounds are
                    computed.
            = 1.0:  Use the double-precision refinement algorithm,
                    possibly with doubled-single computations if the
                    compilation environment does not support DOUBLE
                    PRECISION.
              (other values are reserved for future use)
       LA_LINRX_ITHRESH_I = 2 : Maximum number of residual
            computations allowed for refinement.
         Default: 10
         Aggressive: Set to 100 to permit convergence using approximate
                     factorizations or factorizations other than LU. If
                     the factorization uses a technique other than
                     Gaussian elimination, the guarantees in
                     err_bnds_norm and err_bnds_comp may no longer be
                     trustworthy.
       LA_LINRX_CWISE_I = 3 : Flag determining if the code
            will attempt to find a solution with small componentwise
            relative error in the double-precision algorithm.  Positive
            is true, 0.0 is false.
         Default: 1.0 (attempt componentwise convergence)



WORK


          WORK is REAL array, dimension (4*N)



IWORK


          IWORK is INTEGER array, dimension (N)



INFO


          INFO is INTEGER
       = 0:  Successful exit. The solution to every right-hand side is
         guaranteed.
       < 0:  If INFO = -i, the i-th argument had an illegal value
       > 0 and <= N:  U(INFO,INFO) is exactly zero.  The factorization
         has been completed, but the factor U is exactly singular, so
         the solution and error bounds could not be computed. RCOND = 0
         is returned.
