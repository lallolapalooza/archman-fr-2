Documentation de fonction/sous-programme

sous-programme sgtt01 (entier n, reel, dimension( * ) dl, reel, dimension( * ) d, reel, dimension( * ) du, reel, dimension( * ) dlf, reel, dimension( * ) df, reel, dimension( * ) duf, reel, dimension( * ) du2, entier, dimension( * ) ipiv, reel, dimension( ldwork, * ) work, entier ldwork, reel, dimension( * ) rwork, reel resid)

SGTT01

Objectif :

!>
!> SGTT01 reconstruit une matrice tridiagonale A à partir de sa factorisation LU
!> et calcule le résidu
!>    norm(L*U - A) / ( norm(A) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

DL

!>          DL est un tableau REEL, dimension (N-1)
!>          Les (n-1) sous-diagonales de A.
!>

D

!>          D est un tableau REEL, dimension (N)
!>          Les éléments diagonaux de A.
!>

DU

!>          DU est un tableau REEL, dimension (N-1)
!>          Les (n-1) super-diagonales de A.
!>

DLF

!>          DLF est un tableau REEL, dimension (N-1)
!>          Les (n-1) multiplicateurs qui définissent la matrice L à partir de la
!>          factorisation LU de A.
!>

DF

!>          DF est un tableau REEL, dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire supérieure U issue de la
!>          factorisation LU de A.
!>

DUF

!>          DUF est un tableau REEL, dimension (N-1)
!>          Les (n-1) éléments de la première super-diagonale de U.
!>

DU2

!>          DU2 est un tableau REEL, dimension (N-2)
!>          Les (n-2) éléments de la seconde super-diagonale de U.
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= n, la ligne i de la matrice a été
!>          échangée avec la ligne IPIV(i).  IPIV(i) sera toujours soit
!>          i soit i+1 ; IPIV(i) = i indique qu'aucun échange de ligne n'était
!>          requis.
!>

WORK

!>          WORK est un tableau REEL, dimension (LDWORK,N)
!>

LDWORK

!>          LDWORK est un ENTIER
!>          La dimension principale du tableau WORK.  LDWORK >= max(1,N).
!>

RWORK

!>          RWORK est un tableau REEL, dimension (N)
!>

RESID

!>          RESID est un REEL
!>          Le résidu mis à l'échelle :  norm(L*U - A) / (norm(A) * EPS)
!>
