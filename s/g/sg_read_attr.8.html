NOM

sg_read_attr - envoie la commande SCSI READ ATTRIBUTE

SYNTAXE

sg_read_attr [--cache] [--enumerate] [--ea=EA] [--filter=FL] [--first=FAI] [--help] [--hex] [--in=FN] [--lvn=LVN] [--maxlen=LEN] [--pn=PN] [--quiet] [--raw] [--readonly] [--sa=SA] [--verbose] [--version] DEVICE

DESCRIPTION

Envoie une commande SCSI READ ATTRIBUTE à DEVICE et affiche les données retournées. Cette commande a été introduite dans la révision 1 de SPC-3 et s'applique donc à tous les périphériques SCSI. En pratique, elle est principalement utilisée pour les systèmes de bande. Cet utilitaire est basé sur la version 17 du projet de norme SPC-5 (spc5r17.pdf).

OPTIONS

Les arguments des options longues sont obligatoires, même pour les options courtes correspondantes.

-c, --cache
définit le bit CACHE dans le cdb de READ ATTRIBUTE. Cela demande au serveur de périphérique de retourner les attributs mis en cache. Par défaut, ce bit est effacé, ce qui demande au serveur de périphérique de ne pas retourner les attributs mis en cache.
-e, --enumerate
énumère tous les attributs et actions de service connus. Les attributs incluent un identifiant, une longueur, un format et un nom tels que définis par T10. Si DEVICE est spécifié, il est ignoré.
-E, --ea=EA
où EA est une adresse d'élément placée dans le cdb de READ ATTRIBUTE. Ce champ ne se trouve que dans les projets SMC-2 et SMC-3 pour les changeurs de médias généralement associés aux bibliothèques de bande. Par défaut, ce champ est mis à zéro.
-f, --filter=FL
où FL est un identifiant d'attribut dans la plage de 0 à 65535 ou -1. Les identifiants d'attributs sont généralement donnés en hexadécimal, auquel cas le nombre hexadécimal doit être précédé de "0x" ou se terminer par "h". "-1" est la valeur par défaut et signifie 'tout correspondre'; pour toutes les autres valeurs de FL, seul l'attribut correspondant est affiché.
-F, --first=FAI
où FAI est le champ "premier identifiant d'attribut" dans le cdb. Il semble que l'intention de ce champ soit que seuls les attributs dont les identifiants sont supérieurs ou égaux à FAI soient retournés. La valeur par défaut de FAI est zéro. Les attributs sont retournés dans l'ordre croissant des identifiants.
-h, --help
affiche le message d'utilisation puis quitte.
-H, --hex
affiche la réponse en hexadécimal sur la sortie standard. Utilisé une fois, toute la réponse est affichée en hexadécimal ASCII avec une adresse de début (à partir de 0) sur chaque ligne. Utilisé deux fois, chaque descripteur d'attribut dans la réponse est affiché séparément en hexadécimal. Utilisé trois fois, toute la réponse est affichée en hexadécimal sans adresse de début (sur chaque ligne).
La sortie générée par '-HHH' (ou --hex utilisé trois fois) peut être redirigée vers un fichier. Ce fichier sera dans un format approprié pour que --in=FN l'utilise dans une invocation ultérieure.
-i, --in=FN
FN est traité comme un nom de fichier (ou '-' pour stdin) qui contient des données hexadécimales ASCII ou binaires représentant la réponse à une commande READ ATTRIBUTE avec l'action de service 0x0 (c'est-à-dire les valeurs d'attributs (fetch)). Lorsque cette option est donnée, DEVICE (s'il est également donné) est ignoré.
Par défaut, FN est supposé contenir de l'hexadécimal ASCII organisé en octets séparés par des espaces, des tabulations ou des virgules. Tous les caractères à partir de (et y compris) "#" jusqu'à la fin de la ligne sont ignorés. Si l'option --raw est également donnée, alors FN est supposé contenir des données binaires. Lorsque l'option --raw est donnée, après traitement de l'entrée, la variable interne `raw` est réinitialisée à 0, donc elle n'a aucun effet sur la sortie.
Étant donné que la réponse de READ ATTRIBUTE ne contient pas le numéro de l'action de service à laquelle elle répond, --sa=SA doit être donné (sinon l'action de service 0 (valeurs d'attributs) est supposée).
-l, --lvn=LVN
où LVN est placé dans le champ "numéro de volume logique" du cdb. La valeur par défaut est zéro, ce qui est requis comme numéro de volume logique si le périphérique n'a qu'un seul volume.
-m, --maxlen=LEN
où LEN est la longueur (maximale) de la réponse en octets. Elle est placée dans le champ "allocation length" du cdb. Si non donnée (ou si LEN est zéro), 8192 est utilisé. La valeur maximale autorisée de LEN est 1048576.
-p, --pn=PN
où PN est placé dans le champ "numéro de partition" du cdb. Si le DEVICE n'a qu'une partition, son numéro de partition doit être zéro. La valeur par défaut de PN est zéro.
-q, --quiet
cette option réduit la quantité d'informations affichées. Par exemple, utilisée une fois (SA=0), elle supprime la ligne d'en-tête annonçant la sortie des attributs ; utilisée deux fois, elle supprime le nom de chaque attribut, ne laissant que les valeurs d'attributs (ou chaînes) associées.
-r, --raw
affiche la réponse SCSI (c'est-à-dire le tampon de sortie de données) en binaire (sur la sortie standard).
-R, --readonly
ouvre le DEVICE en lecture seule (par exemple, sous Unix avec le flag O_RDONLY). Par défaut, il est ouvert en lecture-écriture.
-s, --sa=SA
où SA est placé dans le champ "service action" du cdb. Les valeurs de 0 à 63 sont acceptées, avec une valeur par défaut de 0. spc5r08.pdf définit cinq actions de service : 0 pour les valeurs d'attributs ; 1 pour une liste d'attributs (noms, pas valeurs), 2 pour la liste des volumes logiques ; 3 pour la liste des partitions ; 4 est réservé pour SMC-3 ; et 5 pour la liste des attributs supportés.
Alternativement, un acronyme peut être donné pour SA. L'acronyme doit être l'un des "av", "al", "lvl", "pn", "smc" ou "sa" pour les actions de service 0 à 5 respectivement. Les acronymes peuvent également être donnés en majuscules.
-v, --verbose
augmente le niveau de verbosité (c'est-à-dire la sortie de débogage).
-V, --version
affiche la chaîne de version puis quitte.

NOTES

Seuls les systèmes de bande semblent implémenter la commande SCSI READ ATTRIBUTE. La grande majorité de sa définition se trouve dans la norme SPC, donc d'autres types de périphériques pourraient l'utiliser.

Une grande partie des informations fournies par READ ATTRIBUTE peut également être trouvée dans les pages retournées par LOG SENSE (voir l'utilitaire sg_logs) et dans les pages VPD retournées par la commande INQUIRY.

EXEMPLES

Pour lister les attributs d'une unité de bande dont le DEVICE est /dev/sg1 , on peut utiliser ce qui suit :


# sg_read_attr -s al /dev/sg1
Attribute list:
Remaining capacity in partition [MiB]
Maximum capacity in partition [MiB]
TapeAlert flags
Load count
MAM space remaining [B]
Assigning organization
Format density code
...

Pour vérifier le nombre de partitions :


# sg_read_attr -s pl /dev/sg1
Partition number list:
First partition number: 0
Number of partitions available: 2

Et pour voir les valeurs des attributs (ce qui est l'action de service par défaut) :


# sg_read_attr /dev/sg1
Attribute values:
Remaining capacity in partition [MiB]: 1386103
Maximum capacity in partition [MiB]: 1386103
TapeAlert flags: 0
....

Pour rediriger la réponse des valeurs d'attributs vers un fichier pour un décodage ultérieur :


# sg_read_attr -HHH /dev/sg1 > av.hex

Et plus tard, la réponse contenue dans le fichier av.hex pourra être décodée

avec :


# sg_read_attr -s av --in=av.hex

Capacité maximale dans la partition [MiB] : 1386103
Indicateurs TapeAlert : 0
....

STATUT DE SORTIE

Le statut de sortie de sg_read_attr est 0 en cas de succès. Sinon, voir la page de manuel sg3_utils(8).
