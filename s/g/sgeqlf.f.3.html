Documentation de la fonction/sous-routine

sous-routine sgeqlf (integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SGEQLF

Objectif :

!>
!> SGEQLF calcule une factorisation QL d'une matrice réelle M par N A:
!> A = Q * L.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          En entrée, la matrice M par N A.
!>          En sortie,
!>          si m >= n, le triangle inférieur du sous-tableau
!>          A(m-n+1:m,1:n) contient la matrice triangulaire inférieure N par N L ;
!>          si m <= n, les éléments sur et sous la (n-m)-ième
!>          superdiagonale contiennent la matrice trapézoïdale inférieure L M par N ;
!>          les éléments restants, avec le tableau TAU, représentent la
!>          matrice orthogonale Q comme un produit de réflecteurs élémentaires
!>          (voir Détails supplémentaires).
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau REEL, de dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires (voir Détails
!>          supplémentaires).
!>

WORK

!>          WORK est un tableau REEL, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille LWORK optimale.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, et LWORK >= N sinon.
!>          Pour des performances optimales, LWORK >= N*NB, où NB est la
!>          taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  La matrice Q est représentée comme un produit de réflecteurs élémentaires
!>
!>     Q = H(k) . . . H(2) H(1), où k = min(m,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**T
!>
!>  où tau est un scalaire réel, et v est un vecteur réel avec
!>  v(m-k+i+1:m) = 0 et v(m-k+i) = 1 ; v(1:m-k+i-1) est stocké en sortie dans
!>  A(1:m-k+i-1,n-k+i), et tau dans TAU(i).
!>
