Documentation de la fonction/sous-routine

sous-routine sgetsls (caractère trans, entier m, entier n, entier nrhs, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( * ) work, entier lwork, entier info)

SGETSLS

But :

!>
!> SGETSLS résout des systèmes linéaires réels surdéterminés ou sous-déterminés
!> impliquant une matrice A de taille M par N, en utilisant une factorisation QR
!> "tall-skinny" (haute et étroite) ou LQ "short-wide" (courte et large) de A.
!>
!> On suppose que A est de rang plein, et seule une protection rudimentaire
!> contre les matrices de rang déficient est fournie. Cette sous-routine ne détecte
!> que la déficience de rang exacte, où un élément diagonal du facteur triangulaire
!> de A est exactement zéro.
!>
!> Il est concevable qu'un (ou plusieurs) des éléments diagonaux du facteur triangulaire
!> de A soient des nombres extrêmement petits sans que cette sous-routine ne signale
!> une erreur. Les solutions calculées pour de telles matrices presque de rang déficient
!> peuvent être moins précises en raison d'une perte de précision numérique.
!>
!>
!> Les options suivantes sont fournies :
!>
!> 1. Si TRANS = 'N' et m >= n : trouver la solution des moindres carrés d'un
!>    système surdéterminé, c'est-à-dire résoudre le problème des moindres carrés
!>                 minimiser || B - A*X ||.
!>
!> 2. Si TRANS = 'N' et m < n : trouver la solution de norme minimale d'un
!>    système sous-déterminé A * X = B.
!>
!> 3. Si TRANS = 'T' et m >= n : trouver la solution de norme minimale d'un
!>    système sous-déterminé A**T * X = B.
!>
!> 4. Si TRANS = 'T' et m < n : trouver la solution des moindres carrés d'un
!>    système surdéterminé, c'est-à-dire résoudre le problème des moindres carrés
!>                 minimiser || B - A**T * X ||.
!>
!> Plusieurs vecteurs de second membre b et vecteurs solution x peuvent être
!> traités en un seul appel ; ils sont stockés comme colonnes de la
!> matrice B de second membre de taille M x NRHS et de la matrice X de solution
!> de taille N x NRHS.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N' : le système linéaire implique A ;
!>          = 'T' : le système linéaire implique A**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes des matrices B et X. NRHS >=0.
!>

A

!>          A est tableau REEL, dimension (LDA,N)
!>          En entrée, la matrice A de taille M x N.
!>          En sortie,
!>          A est écrasée par les détails de sa factorisation QR ou LQ
!>          renvoyés par SGEQR ou SGELQ.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

B

!>          B est tableau REEL, dimension (LDB,NRHS)
!>          En entrée, la matrice B des vecteurs de second membre, stockée
!>          colonne par colonne ; B est de taille M x NRHS si TRANS = 'N', ou N x NRHS
!>          si TRANS = 'T'.
!>          En sortie, si INFO = 0, B est écrasée par les vecteurs solution,
!>          stockés colonne par colonne :
!>          si TRANS = 'N' et m >= n, les lignes 1 à n de B contiennent les vecteurs
!>          solution des moindres carrés.
!>          si TRANS = 'N' et m < n, les lignes 1 à N de B contiennent les
!>          vecteurs solution de norme minimale ;
!>          si TRANS = 'T' et m >= n, les lignes 1 à M de B contiennent les
!>          vecteurs solution de norme minimale ;
!>          si TRANS = 'T' et m < n, les lignes 1 à M de B contiennent les
!>          vecteurs solution des moindres carrés.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= MAX(1,M,N).
!>

WORK

!>          (espace de travail) tableau REEL, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale (ou
!>          minimale ou optimale, si la requête était supposée) de LWORK.
!>          Voir LWORK pour les détails.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>          Si LWORK = -1 ou -2, alors une requête d'espace de travail est supposée.
!>          Si LWORK = -1, la routine calcule la taille optimale de WORK pour
!>          une performance optimale et renvoie cette valeur dans WORK(1).
!>          Si LWORK = -2, la routine calcule la taille minimale de WORK et
!>          renvoie cette valeur dans WORK(1).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO =  i, le i-ème élément diagonal du
!>                facteur triangulaire de A est exactement zéro, donc A n'a pas
!>                de rang plein ; la solution des moindres carrés n'a pas pu
!>                être calculée.
!>
