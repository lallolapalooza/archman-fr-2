sous-routine sget39 (real rmax, integer lmax, integer ninfo, integer knt)

SGET39

But:

!>
!> SGET39 teste SLAQTR, une routine pour résoudre le système quasi triangulaire réel ou
!> complexe supérieur
!>
!>      op(T)*p = scale*c,
!> ou
!>      op(T + iB)*(p+iq) = scale*(c+id),
!>
!> en arithmétique réelle. T est quasi triangulaire supérieur.
!> S'il est complexe, alors le premier bloc diagonal de T doit être
!> 1 par 1, B a la structure spéciale
!>
!>                B = [ b(1) b(2) ... b(n) ]
!>                    [       w            ]
!>                    [           w        ]
!>                    [              .     ]
!>                    [                 w  ]
!>
!> op(A) = A ou A', où A' dénote la transposée conjuguée de
!> la matrice A.
!>
!> En entrée, X = [ c ]. En sortie, X = [ p ].
!>               [ d ]                  [ q ]
!>
!> Scale est une sortie inférieure ou égale à 1, choisie pour éviter
!> le débordement dans X.
!> Cette sous-routine est spécialement conçue pour l'estimation du numéro de condition
!> dans la routine de problème propre STRSNA.
!>
!> Le code de test vérifie que le résidu suivant est de l'ordre de 1 :
!>
!>      ||(T+i*B)*(x1+i*x2) - scale*(d1+i*d2)||
!>    -----------------------------------------
!>        max(ulp*(||T||+||B||)*(||x1||+||x2||),
!>            (||T||+||B||)*smlnum/ulp,
!>            smlnum)
!>
!> (Le terme (||T||+||B||)*smlnum/ulp prend en compte un éventuel
!>  sous-dépassement (graduel ou non) de x1 et x2.)
!>

Paramètres

RMAX 
!>          RMAX est REAL
!>          Valeur du rapport de test le plus grand.
!>

LMAX

!>          LMAX est INTEGER
!>          Numéro de l'exemple où le rapport de test le plus grand est atteint.
!>

NINFO

!>          NINFO est INTEGER
!>          Nombre d'exemples pour lesquels INFO est non nul.
!>

KNT

!>          KNT est INTEGER
!>          Nombre total d'exemples testés.
!>
