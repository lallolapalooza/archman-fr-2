sous-programme sgelqt (entier m, entier n, entier mb, reel, dimension( lda, * ) a, entier lda, reel, dimension( ldt, * ) t, entier ldt, reel, dimension( * ) work, entier info)

SGELQT

But:

!>
!> SGELQT calcule une factorisation LQ bloquée d'une matrice réelle M par N, A,
!> en utilisant la représentation WY compacte de Q.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

MB

!>          MB est un ENTIER
!>          La taille de bloc à utiliser pour la factorisation LQ bloquée.  MIN(M,N) >= MB >= 1.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          En entrée, la matrice A de M par N.
!>          En sortie, les éléments sur et sous la diagonale du tableau
!>          contiennent la matrice L trapézoïdale inférieure M par MIN(M,N) (L est
!>          triangulaire inférieure si M <= N) ; les éléments au-dessus de la diagonale
!>          sont les lignes de V.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

T

!>          T est un tableau REEL, de dimension (LDT,MIN(M,N))
!>          Les facteurs de réflecteurs de blocs triangulaires supérieurs stockés sous forme compacte
!>          en tant que séquence de blocs triangulaires supérieurs.  Voir ci-dessous
!>          pour plus de détails.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T.  LDT >= MB.
!>

WORK

!>          WORK est un tableau REEL, de dimension (MB*N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires:

!>
!>  La matrice V stocke les réflecteurs élémentaires H(i) dans la i-ème ligne
!>  au-dessus de la diagonale. Par exemple, si M=5 et N=3, la matrice V est
!>
!>               V = (  1  v1 v1 v1 v1 )
!>                   (     1  v2 v2 v2 )
!>                   (         1 v3 v3 )
!>
!>
!>  où les vi's représentent les vecteurs qui définissent H(i), qui sont retournés
!>  dans la matrice A.  Les 1's le long de la diagonale de V ne sont pas stockés dans A.
!>  Soit K=MIN(M,N).  Le nombre de blocs est B = ceiling(K/MB), où chaque
!>  bloc est de taille MB sauf le dernier bloc, qui est de taille
!>  IB = K - (B-1)*MB.  Pour chacun des B blocs, un facteur de réflecteur
!>  de bloc triangulaire supérieur est calculé : T1, T2, ..., TB.  Les T de taille
!>  MBxMB (et IBxIB pour le dernier bloc) sont stockés dans la matrice T de taille
!>  MBxK comme suit :
!>
!>               T = (T1 T2 ... TB).
!>
