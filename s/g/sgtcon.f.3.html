Documentation de la fonction/sous-programme

sous-programme sgtcon (caractère norm, entier n, réel, dimension( * ) dl, réel, dimension( * ) d, réel, dimension( * ) du, réel, dimension( * ) du2, entier, dimension( * ) ipiv, réel anorm, réel rcond, réel, dimension( * ) work, entier, dimension( * ) iwork, entier info)

SGTCON

Objectif :

!>
!> SGTCON estime l'inverse du nombre de condition d'une matrice réelle
!> tridiagonale A en utilisant la factorisation LU calculée par
!> SGTTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et l'inverse du
!> nombre de condition est calculé comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

NORM 
!>          NORM est CHARACTER*1
!>          Spécifie si le nombre de condition 1-norme ou
!>          l'infini-norme est requis :
!>          = '1' ou 'O':  1-norme ;
!>          = 'I':         Infini-norme.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

DL

!>          DL est un tableau REAL, de dimension (N-1)
!>          Les (n-1) multiplicateurs qui définissent la matrice L de la
!>          factorisation LU de A calculée par SGTTRF.
!>

D

!>          D est un tableau REAL, de dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire supérieure U
!>          de la factorisation LU de A.
!>

DU

!>          DU est un tableau REAL, de dimension (N-1)
!>          Les (n-1) éléments de la première superdiagonale de U.
!>

DU2

!>          DU2 est un tableau REAL, de dimension (N-2)
!>          Les (n-2) éléments de la deuxième superdiagonale de U.
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= n, la ligne i de la matrice
!>          a été échangée avec la ligne IPIV(i). IPIV(i) sera toujours
!>          soit i soit i+1 ; IPIV(i) = i indique qu'un échange de ligne
!>          n'était pas nécessaire.
!>

ANORM

!>          ANORM est REAL
!>          Si NORM = '1' ou 'O', la 1-norme de la matrice originale A.
!>          Si NORM = 'I', l'infini-norme de la matrice originale A.
!>

RCOND

!>          RCOND est REAL
!>          L'inverse du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la 1-norme de inv(A) calculée par cette routine.
!>

WORK

!>          WORK est un tableau REAL, de dimension (2*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
