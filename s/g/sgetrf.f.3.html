sous-routine sgetrf (integer m, integer n, real, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, integer info)

SGETRF

Purpose:

!>
!> SGETRF calcule une factorisation LU d'une matrice générale M-par-N A
!> en utilisant un pivotage partiel avec échanges de lignes.
!>
!> La factorisation a la forme
!>    A = P * L * U
!> où P est une matrice de permutation, L est triangulaire inférieure avec des éléments
!> diagonaux unitaires (trapézoïdale inférieure si m > n), et U est
!> triangulaire supérieure (trapézoïdale supérieure si m < n).
!>
!> C'est la version de l'algorithme de niveau 3 BLAS de type "right-looking".
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de réels (REAL), de dimension (LDA,N)
!>          À l'entrée, la matrice M-par-N à factoriser.
!>          À la sortie, les facteurs L et U de la factorisation
!>          A = P*L*U ; les éléments diagonaux unitaires de L ne sont pas stockés.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

IPIV

!>          IPIV est un tableau d'entiers (INTEGER), de dimension (min(M,N))
!>          Les indices de pivot ; pour 1 <= i <= min(M,N), la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, U(i,i) est exactement zéro. La factorisation
!>                a été complétée, mais le facteur U est exactement
!>                singulier, et une division par zéro se produira si il est utilisé
!>                pour résoudre un système d'équations.
!>
