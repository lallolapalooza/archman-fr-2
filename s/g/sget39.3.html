sous-programme sget39 (real rmax, integer lmax, integer ninfo, integer knt)

SGET39

But :

!>
!> SGET39 teste SLAQTR, une routine pour résoudre le système quasi triangulaire supérieur réel ou complexe spécial
!>
!>      op(T)*p = scale*c,
!> ou
!>      op(T + iB)*(p+iq) = scale*(c+id),
!>
!> en arithmétique réelle. T est quasi triangulaire supérieure.
!> Si elle est complexe, alors le premier bloc diagonal de T doit être
!> 1 par 1, B a la structure spéciale
!>
!>                B = [ b(1) b(2) ... b(n) ]
!>                    [       w            ]
!>                    [           w        ]
!>                    [              .     ]
!>                    [                 w  ]
!>
!> op(A) = A ou A', où A' désigne la transposée conjuguée de
!> la matrice A.
!>
!> En entrée, X = [ c ]. En sortie, X = [ p ].
!>               [ d ]                  [ q ]
!>
!> Scale est une sortie inférieure ou égale à 1, choisie pour éviter
!> le débordement dans X.
!> Ce sous-programme est spécialement conçu pour l'estimation du conditionnement
!> dans la routine du problème aux valeurs propres STRSNA.
!>
!> Le code de test vérifie que le résidu suivant est de l'ordre de 1 :
!>
!>      ||(T+i*B)*(x1+i*x2) - scale*(d1+i*d2)||
!>    -----------------------------------------
!>        max(ulp*(||T||+||B||)*(||x1||+||x2||),
!>            (||T||+||B||)*smlnum/ulp,
!>            smlnum)
!>
!> (Le terme (||T||+||B||)*smlnum/ulp prend en compte le possible
!>  sous-dépassement (progressif ou non) dans x1 et x2.)
!>

Paramètres

RMAX 
!>          RMAX est REAL
!>          Valeur du plus grand ratio de test.
!>

LMAX

!>          LMAX est INTEGER
!>          Numéro de l'exemple où le plus grand ratio de test est atteint.
!>

NINFO

!>          NINFO est INTEGER
!>          Nombre d'exemples où INFO est non nul.
!>

KNT

!>          KNT est INTEGER
!>          Nombre total d'exemples testés.
!>
