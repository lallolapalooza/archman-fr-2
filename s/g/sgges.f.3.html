sous-programme sgges (character jobvsl, character jobvsr, character sort, external selctg, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, integer sdim, real, dimension( * ) alphar, real, dimension( * ) alphai, real, dimension( * ) beta, real, dimension( ldvsl, * ) vsl, integer ldvsl, real, dimension( ldvsr, * ) vsr, integer ldvsr, real, dimension( * ) work, integer lwork, logical, dimension( * ) bwork, integer info)

SGGES calcule les valeurs propres, la forme de Schur, et, éventuellement, la matrice des vecteurs de Schur pour les matrices GE

Objectif :

!>
!> SGGES calcule pour une paire de matrices réelles non symétriques (A,B) de taille N par N,
!> les valeurs propres généralisées, la forme de Schur réelle généralisée (S,T),
!> et éventuellement, les matrices des vecteurs de Schur gauches et/ou droits (VSL et
!> VSR). Ceci donne la factorisation de Schur généralisée
!>
!>          (A,B) = ( (VSL)*S*(VSR)**T, (VSL)*T*(VSR)**T )
!>
!> Éventuellement, elle ordonne également les valeurs propres de sorte qu'un cluster
!> sélectionné de valeurs propres apparaisse dans les blocs diagonaux principaux de la matrice
!> quasi-triangulaire supérieure S et de la matrice triangulaire supérieure T. Les
!> colonnes principales de VSL et VSR forment alors une base orthonormée pour les
!> sous-espaces gauche et droits correspondants (sous-espaces défléchissants).
!>
!> (Si seules les valeurs propres généralisées sont nécessaires, utilisez plutôt le pilote
!> SGGEV, qui est plus rapide.)
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un ratio alpha/beta = w, tel que A - w*B est singulier. Elle est
!> généralement représentée par la paire (alpha,beta), car il existe une
!> interprétation raisonnable pour beta=0 ou les deux étant zéro.
!>
!> Une paire de matrices (S,T) est en forme de Schur généralisée réelle si T est
!> triangulaire supérieure avec une diagonale non négative et S est en bloc triangulaire
!> supérieure avec des blocs de 1x1 et 2x2. Les blocs de 1x1 correspondent
!> aux valeurs propres généralisées réelles, tandis que les blocs de 2x2 de S seront
!>
!>         [  a  b  ]
!>         [  c  d  ]
!>
!> pour rendre les éléments correspondants de T de la forme :
!>         [  a  0  ]
!>         [  0  b  ]
!>
!> et la paire de blocs 2x2 correspondants dans S et T aura
!> une paire de valeurs propres généralisées complexes conjuguées.
!>
!>

Paramètres

JOBVSL 
!>          JOBVSL est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur gauches ;
!>          = 'V' : calculer les vecteurs de Schur gauches.
!>

JOBVSR

!>          JOBVSR est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur droits ;
!>          = 'V' : calculer les vecteurs de Schur droits.
!>

SORT

!>          SORT est CHARACTER*1
!>          Spécifie si les valeurs propres doivent être ordonnées sur la
!>          diagonale de la forme de Schur généralisée.
!>          = 'N' : les valeurs propres ne sont pas ordonnées ;
!>          = 'S' : les valeurs propres sont ordonnées (voir SELCTG) ;
!>

SELCTG

!>          SELCTG est une FONCTION LOGIQUE de trois arguments REELS
!>          SELCTG doit être déclarée EXTERNE dans le sous-programme appelant.
!>          Si SORT = 'N', SELCTG n'est pas référencée.
!>          Si SORT = 'S', SELCTG est utilisée pour sélectionner les valeurs propres à trier
!>          en haut à gauche de la forme de Schur.
!>          Une valeur propre (ALPHAR(j)+ALPHAI(j))/BETA(j) est sélectionnée si
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) est vraie ; c'est-à-dire si l'une
!>          d'une paire de valeurs propres complexes conjuguées est sélectionnée,
!>          alors les deux valeurs propres complexes sont sélectionnées.
!>
!>          Notez que dans le cas mal conditionné, une valeur propre complexe sélectionnée
!>          peut ne plus satisfaire SELCTG(ALPHAR(j),ALPHAI(j),
!>          BETA(j)) = .VRAI. après l'ordonnancement. INFO doit être mis à N+2
!>          dans ce cas.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A, B, VSL et VSR. N >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA, N)
!>          En entrée, la première matrice de la paire.
!>          En sortie, A est remplacée par sa forme de Schur généralisée S.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A. LDA >= max(1,N).
!>

B

!>          B est un tableau REEL, de dimension (LDB, N)
!>          En entrée, la seconde matrice de la paire.
!>          En sortie, B est remplacée par sa forme de Schur généralisée T.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de B. LDB >= max(1,N).
!>

SDIM

!>          SDIM est INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = nombre de valeurs propres (après tri)
!>          pour lesquelles SELCTG est vrai. (Les paires de complexes conjugués pour lesquelles
!>          SELCTG est vrai pour l'une ou l'autre valeur propre comptent pour 2.)
!>

ALPHAR

!>          ALPHAR est un tableau REEL, de dimension (N)
!>

ALPHAI

!>          ALPHAI est un tableau REEL, de dimension (N)
!>

BETA

!>          BETA est un tableau REEL, de dimension (N)
!>          En sortie, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, seront
!>          les valeurs propres généralisées. ALPHAR(j) + ALPHAI(j)*i,
!>          et BETA(j), j=1,...,N sont les éléments diagonaux de la forme de Schur complexe
!>          (S,T) qui résulterait si les blocs diagonaux 2x2
!>          de la forme de Schur réelle de (A,B) étaient réduits davantage
!>          en forme triangulaire en utilisant des transformations unitaires complexes 2x2.
!>          Si ALPHAI(j) est zéro, alors la j-ième valeur propre est réelle ; si
!>          positive, alors la j-ième et la (j+1)-ième valeurs propres sont une
!>          paire complexe conjuguée, avec ALPHAI(j+1) négatif.
!>
!>          Note : les quotients ALPHAR(j)/BETA(j) et ALPHAI(j)/BETA(j)
!>          peuvent facilement déborder ou sous-déborder, et BETA(j) peut même être zéro.
!>          Par conséquent, l'utilisateur doit éviter de calculer naïvement le ratio.
!>          Cependant, ALPHAR et ALPHAI seront toujours inférieurs et
!>          généralement comparables en magnitude à norm(A), et BETA toujours
!>          inférieur et généralement comparable à norm(B).
!>

VSL

!>          VSL est un tableau REEL, de dimension (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contiendra les vecteurs de Schur gauches.
!>          Non référencé si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL est INTEGER
!>          La dimension principale de la matrice VSL. LDVSL >=1, et
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR est un tableau REEL, de dimension (LDVSR,N)
!>          Si JOBVSR = 'V', VSR contiendra les vecteurs de Schur droits.
!>          Non référencé si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR est INTEGER
!>          La dimension principale de la matrice VSR. LDVSR >= 1, et
!>          si JOBVSR = 'V', LDVSR >= N.
!>

WORK

!>          WORK est un tableau REEL, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si N = 0, LWORK >= 1, sinon LWORK >= max(8*N,6*N+16).
!>

BWORK

!>          BWORK est un tableau LOGIQUE, de dimension (N)
!>          Ce tableau est utilisé comme espace de travail interne si SELCTG est
!>          utilisé.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : exécution réussie.
!>          < 0 : si INFO = -i, le i-ème argument était invalide.
!>          = 1 : le calcul a pris trop de pas d'itération pour converger ; les valeurs propres
!>                ne sont pas calculées précisément.
!>          = 2 : le calcul a pris trop de pas d'itération pour converger ; la forme de Schur
!>                généralisée n'est pas calculée précisément.
!>          = 3 : la forme de Schur généralisée a été calculée, mais les valeurs propres
!>                n'ont pas convergé.
!>          = 4 : la sélection des valeurs propres a échoué, car le problème est mal
!>                conditionné.
!>          = N+1 : une des matrices de Schur n'a pas été calculée car il y avait des problèmes
!>                de convergence dans la réduction initiale.
!>          = N+2 : Une valeur propre sélectionnée n'a pas satisfait le critère de sélection
!>                après l'ordonnancement en raison d'un mauvais conditionnement.
!>

Pour de bonnes performances, LWORK doit généralement être plus grand. !> !> Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine !> calcule seulement la taille optimale du tableau WORK, retourne !> cette valeur comme première entrée du tableau WORK, et aucun message d'erreur !> lié à LWORK n'est émis par XERBLA. !>

BWORK

!>          BWORK est un tableau LOGIQUE, de dimension (N)
!>          Non référencé si SORT = 'N'.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          = 1,...,N :
!>                L'itération QZ a échoué. (A,B) ne sont pas sous forme de Schur
!>                , mais ALPHAR(j), ALPHAI(j) et BETA(j) devraient
!>                être corrects pour j=INFO+1,...,N.
!>          > N :  =N+1 : l'échec de l'itération QZ dans SHGEQZ.
!>                =N+2 : après réordonnancement, les arrondis ont changé les valeurs de
!>                      certaines valeurs propres complexes de sorte que les valeurs propres
!>                      principales de la forme de Schur généralisée
!>                      ne satisfont plus SELCTG=.TRUE. Ceci pourrait aussi
!>                      être causé par la mise à l'échelle.
!>                =N+3 : le réordonnancement a échoué dans STGSEN.
!>
