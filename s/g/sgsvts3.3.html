SGSVTS3

Purpose:

!>
!> SGSVTS3 teste SGGSVD3, qui calcule la GSVD d'une matrice M par N A
!> et une matrice P par N B :
!>              U'*A*Q = D1*R et V'*B*Q = D2*R.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

P

!>          P est un ENTIER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,M)
!>          La matrice A de taille M par N.
!>

AF

!>          AF est un tableau REEL, dimension (LDA,N)
!>          Détails de la GSVD de A et B, tels que retournés par SGGSVD3,
!>          voir SGGSVD3 pour plus de détails.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A et AF.
!>          LDA >= max( 1,M ).
!>

B

!>          B est un tableau REEL, dimension (LDB,P)
!>          À l'entrée, la matrice B de taille P par N.
!>

BF

!>          BF est un tableau REEL, dimension (LDB,N)
!>          Détails de la GSVD de A et B, tels que retournés par SGGSVD3,
!>          voir SGGSVD3 pour plus de détails.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale des tableaux B et BF.
!>          LDB >= max(1,P).
!>

U

!>          U est un tableau REEL, dimension(LDU,M)
!>          La matrice orthogonale U de taille M par M.
!>

LDU

!>          LDU est un ENTIER
!>          La dimension principale du tableau U. LDU >= max(1,M).
!>

V

!>          V est un tableau REEL, dimension(LDV,M)
!>          La matrice orthogonale V de taille P par P.
!>

LDV

!>          LDV est un ENTIER
!>          La dimension principale du tableau V. LDV >= max(1,P).
!>

Q

!>          Q est un tableau REEL, dimension(LDQ,N)
!>          La matrice orthogonale Q de taille N par N.
!>

LDQ

!>          LDQ est un ENTIER
!>          La dimension principale du tableau Q. LDQ >= max(1,N).
!>

ALPHA

!>          ALPHA est un tableau REEL, dimension (N)
!>

BETA

!>          BETA est un tableau REEL, dimension (N)
!>
!>          Les paires de valeurs singulières généralisées de A et B, les
!>          matrices ``diagonales'' D1 et D2 sont construites à partir de
!>          ALPHA et BETA, voir la sous-routine SGGSVD3 pour les détails.
!>

R

!>          R est un tableau REEL, dimension(LDQ,N)
!>          La matrice triangulaire supérieure R.
!>

LDR

!>          LDR est un ENTIER
!>          La dimension principale du tableau R. LDR >= max(1,N).
!>

IWORK

!>          IWORK est un tableau ENTIER, dimension (N)
!>

WORK

!>          WORK est un tableau REEL, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK,
!>          LWORK >= max(M,P,N)*max(M,P,N).
!>

RWORK

!>          RWORK est un tableau REEL, dimension (max(M,P,N))
!>

RESULT

!>          RESULT est un tableau REEL, dimension (6)
!>          Les ratios de test :
!>          RESULT(1) = norm( U'*A*Q - D1*R ) / ( MAX(M,N)*norm(A)*ULP)
!>          RESULT(2) = norm( V'*B*Q - D2*R ) / ( MAX(P,N)*norm(B)*ULP)
!>          RESULT(3) = norm( I - U'*U ) / ( M*ULP )
!>          RESULT(4) = norm( I - V'*V ) / ( P*ULP )
!>          RESULT(5) = norm( I - Q'*Q ) / ( N*ULP )
!>          RESULT(6) = 0        si ALPHA est dans l'ordre décroissant ;
!>                    = ULPINV   sinon.
!>
