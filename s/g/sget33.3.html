sous-programme sget33 (real rmax, integer lmax, integer ninfo, integer knt)

SGET33

But :

!>
!> SGET33 teste SLANV2, une routine pour mettre des blocs de 2 par 2
!> en forme standard. En d'autres termes, elle calcule une rotation de
!> deux par deux [[C,S] 
[-S,C]] où dans
!>
!>    [ C S ][T(1,1) T(1,2)][ C -S ] = [ T11 T12 ]
!>    [-S C ][T(2,1) T(2,2)][ S  C ]   [ T21 T22 ]
!>
!> soit
!>    1) T21=0 (valeurs propres réelles), soit
!>    2) T11=T22 et T21*T12<0 (valeurs propres complexes conjuguées).
!> Nous vérifions également que le résidu est petit.
!>

Paramètres

RMAX 
!>          RMAX est REAL
!>          Valeur du plus grand rapport de test.
!>

LMAX

!>          LMAX est INTEGER
!>          Numéro de l'exemple où le plus grand rapport de test est atteint.
!>

NINFO

!>          NINFO est INTEGER
!>          Nombre d'exemples renvoyés avec INFO .NE. 0.
!>

KNT

!>          KNT est INTEGER
!>          Nombre total d'exemples testés.
!>
