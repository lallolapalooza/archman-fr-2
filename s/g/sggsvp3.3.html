sous-routine sggsvp3 (caractère jobu, caractère jobv, caractère jobq, entier m, entier p, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb, réel tola, réel tolb, entier k, entier l, réel, dimension( ldu, * ) u, entier ldu, réel, dimension( ldv, * ) v, entier ldv, réel, dimension( ldq, * ) q, entier ldq, entier, dimension( * ) iwork, réel, dimension( * ) tau, réel, dimension( * ) work, entier lwork, entier info)

SGGSVP3

Objectif:

!>
!> SGGSVP3 calcule les matrices orthogonales U, V et Q telles que
!>
!>                    N-K-L  K    L
!>  U**T*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**T*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> où la matrice KxK A12 et la matrice LxL B13 sont des matrices triangulaires
!> supérieures non singulières ; A23 est triangulaire supérieure LxL si M-K-L >= 0,
!> sinon A23 est une matrice trapézoïdale supérieure (M-K)xL. K+L = le rang
!> numérique effectif de la matrice (M+P)xN (A**T,B**T)**T.
!>
!> Cette décomposition est l'étape de prétraitement pour le calcul de la
!> Décomposition en Valeurs Singulières Généralisées (GSVD), voir la sous-routine
!> SGGSVD3.
!>

Paramètres

JOBU 
!>          JOBU est CHARACTER*1
!>          = 'U':  La matrice orthogonale U est calculée ;
!>          = 'N':  U n'est pas calculée.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          = 'V':  La matrice orthogonale V est calculée ;
!>          = 'N':  V n'est pas calculée.
!>

JOBQ

!>          JOBQ est CHARACTER*1
!>          = 'Q':  La matrice orthogonale Q est calculée ;
!>          = 'N':  Q n'est pas calculée.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!>

A

!>          A est tableau REEL, dimension (LDA,N)
!>          En entrée, la matrice M par N A.
!>          En sortie, A contient la matrice triangulaire (ou trapézoïdale)
!>          décrite dans la section Objectif.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est tableau REEL, dimension (LDB,N)
!>          En entrée, la matrice P par N B.
!>          En sortie, B contient la matrice triangulaire décrite dans
!>          la section Objectif.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,P).
!>

TOLA

!>          TOLA est REEL
!>

TOLB

!>          TOLB est REEL
!>
!>          TOLA et TOLB sont les seuils pour déterminer le rang numérique
!>          effectif de la matrice B et d'un sous-bloc de A. Généralement,
!>          ils sont définis comme
!>             TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          La taille de TOLA et TOLB peut affecter les erreurs inverses
!>          de la décomposition.
!>

K

!>          K est INTEGER
!>

L

!>          L est INTEGER
!>
!>          En sortie, K et L spécifient la dimension des sous-blocs
!>          décrits dans la section Objectif.
!>          K + L = rang numérique effectif de (A**T,B**T)**T.
!>

U

!>          U est tableau REEL, dimension (LDU,M)
!>          Si JOBU = 'U', U contient la matrice orthogonale U.
!>          Si JOBU = 'N', U n'est pas référencé.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= max(1,M) si
!>          JOBU = 'U' ; LDU >= 1 sinon.
!>

V

!>          V est tableau REEL, dimension (LDV,P)
!>          Si JOBV = 'V', V contient la matrice orthogonale V.
!>          Si JOBV = 'N', V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V. LDV >= max(1,P) si
!>          JOBV = 'V' ; LDV >= 1 sinon.
!>

Q

!>          Q est tableau REEL, dimension (LDQ,N)
!>          Si JOBQ = 'Q', Q contient la matrice orthogonale Q.
!>          Si JOBQ = 'N', Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q' ; LDQ >= 1 sinon.
!>

IWORK

!>          IWORK est tableau INTEGER, dimension (N)
!>

TAU

!>          TAU est tableau REEL, dimension (N)
!>

WORK

!>          WORK est tableau REEL, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  exécution réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>
