Documentation de la fonction/sous-routine

sous-routine sgtt05 (character trans, integer n, integer nrhs, real, dimension( * ) dl, real, dimension( * ) d, real, dimension( * ) du, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real, dimension( ldxact, * ) xact, integer ldxact, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) reslts)

SGTT05

Objectif :

!>
!> SGTT05 teste les bornes d'erreur de l'affinement itératif pour la
!> solution calculée d'un système d'équations A*X = B, où A est une
!> matrice tridiagonale générale d'ordre n et op(A) = A ou A**T,
!> selon TRANS.
!>
!> RESLTS(1) = test de la borne d'erreur
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Une valeur élevée est retournée si ce ratio n'est pas inférieur à un.
!>
!> RESLTS(2) = résidu de la routine d'affinement itératif
!>           = le maximum de BERR / ( NZ*EPS + (*) ), où
!>             (*) = NZ*UNFL / (min_i (abs(op(A))*abs(X) +abs(b))_i )
!>             et NZ = nombre max. d'éléments non nuls dans chaque ligne de A, plus 1
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations.
!>          = 'N':  A * X = B     (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Conjuguée transposée = Transposée)
!>

N

!>          N est INTEGER
!>          Le nombre de lignes des matrices X et XACT.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de colonnes des matrices X et XACT.  NRHS >= 0.
!>

DL

!>          DL est un tableau REAL de dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de A.
!>

D

!>          D est un tableau REAL de dimension (N)
!>          Les éléments diagonaux de A.
!>

DU

!>          DU est un tableau REAL de dimension (N-1)
!>          Les (n-1) éléments super-diagonaux de A.
!>

B

!>          B est un tableau REAL de dimension (LDB,NRHS)
!>          Les vecteurs du second membre pour le système d'équations
!>          linéaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau REAL de dimension (LDX,NRHS)
!>          Les vecteurs solutions calculés. Chaque vecteur est stocké comme
!>          une colonne de la matrice X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

XACT

!>          XACT est un tableau REAL de dimension (LDX,NRHS)
!>          Les vecteurs solutions exacts. Chaque vecteur est stocké comme
!>          une colonne de la matrice XACT.
!>

LDXACT

!>          LDXACT est INTEGER
!>          La dimension principale du tableau XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR est un tableau REAL de dimension (NRHS)
!>          Les bornes d'erreur avant estimées pour chaque vecteur solution
!>          X.  Si XTRUE est la solution vraie, FERR borne la magnitude
!>          de la plus grande entrée dans (X - XTRUE) divisée par la magnitude
!>          de la plus grande entrée dans X.
!>

BERR

!>          BERR est un tableau REAL de dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur solution
!>          (c'est-à-dire, le plus petit changement relatif dans n'importe quelle entrée de A
!>          ou B qui rend X une solution exacte).
!>

RESLTS

!>          RESLTS est un tableau REAL de dimension (2)
!>          Le maximum sur les NRHS vecteurs solutions des ratios :
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( NZ*EPS + (*) )
!>
