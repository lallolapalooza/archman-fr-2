Documentation de fonction/sous-routine

sous-routine sget07 (caractère trans, entier n, entier nrhs, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( ldx, * ) x, entier ldx, réel, dimension( ldxact, * ) xact, entier ldxact, réel, dimension( * ) ferr, logique chkferr, réel, dimension( * ) berr, réel, dimension( * ) reslts)

SGET07

Objectif :

!>
!> SGET07 teste les bornes d'erreur de l'affinement itératif pour la
!> solution calculée d'un système d'équations op(A)*X = B, où A est une
!> matrice générale n par n et op(A) = A ou A**T, selon TRANS.
!>
!> RESLTS(1) = test de la borne d'erreur
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Une grande valeur est retournée si ce ratio n'est pas inférieur à un.
!>
!> RESLTS(2) = résidu de la routine d'affinement itératif
!>           = le maximum de BERR / ( (n+1)*EPS + (*) ), où
!>             (*) = (n+1)*UNFL / (min_i (abs(op(A))*abs(X) +abs(b))_i )
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations.
!>          = 'N':  A * X = B     (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Conjuguée transposée = Transposée)
!>

N

!>          N est INTEGER
!>          Le nombre de lignes des matrices X et XACT.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de colonnes des matrices X et XACT.  NRHS >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>          La matrice d'origine A de taille n par n.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau REAL, dimension (LDB,NRHS)
!>          Les vecteurs du second membre pour le système d'équations
!>          linéaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau REAL, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés. Chaque vecteur est stocké comme
!>          une colonne de la matrice X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

XACT

!>          XACT est un tableau REAL, dimension (LDXACT,NRHS)
!>          Les vecteurs solution exacts. Chaque vecteur est stocké comme
!>          une colonne de la matrice XACT.
!>

LDXACT

!>          LDXACT est INTEGER
!>          La dimension principale du tableau XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR est un tableau REAL, dimension (NRHS)
!>          Les bornes d'erreur avant estimées pour chaque vecteur solution
!>          X. Si XTRUE est la vraie solution, FERR borne la magnitude de la
!>          plus grande entrée dans (X - XTRUE) divisée par la magnitude de
!>          la plus grande entrée dans X.
!>

CHKFERR

!>          CHKFERR est LOGICAL
!>          Mis à .TRUE. pour vérifier FERR, .FALSE. pour ne pas vérifier FERR.
!>          Lorsque le système de test est mal conditionné, la
!>          solution dans XACT peut être incorrecte.
!>

BERR

!>          BERR est un tableau REAL, dimension (NRHS)
!>          L'erreur relative composante par composante de chaque vecteur solution
!>          (c'est-à-dire, le plus petit changement relatif dans toute entrée de A
!>          ou B qui rend X une solution exacte).
!>

RESLTS

!>          RESLTS est un tableau REAL, dimension (2)
!>          Le maximum sur les vecteurs solutions NRHS des ratios :
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( (n+1)*EPS + (*) )
!>
