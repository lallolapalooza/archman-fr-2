sous-routine sgeqrfp (integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SGEQRFP

But:

!>
!> SGEQR2P calcule une factorisation QR d'une matrice reelle M-par-N A:
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> où:
!>
!>    Q est une matrice orthogonale M-par-M;
!>    R est une matrice triangulaire superieure N-par-N avec des entrees diagonales non negatives;
!>    0 est une matrice nulle (M-N)-par-N, si M > N.
!>
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          En entree, la matrice M-par-N A.
!>          En sortie, les elements sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice trapezoidale superieure min(M,N)-par-N R (R est
!>          triangulaire superieure si m >= n). Les entrees diagonales de R
!>          sont non negatives ; les elements en dessous de la diagonale,
!>          avec le tableau TAU, representent la matrice orthogonale Q comme un
!>          produit de min(m,n) reflecteurs elementaires (voir Details supplementaires).
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau REEL, dimension (min(M,N))
!>          Les facteurs scalaires des reflecteurs elementaires (voir Details supplementaires).
!>

WORK

!>          WORK est un tableau REEL, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne la taille optimale de LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, et LWORK >= N sinon.
!>          Pour des performances optimales LWORK >= N*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requete d'espace de travail est supposee ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme premiere entree du tableau WORK, et aucun message d'erreur
!>          relatif a LWORK n'est emis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0:  sortie reussie
!>          < 0:  si INFO = -i, le i-eme argument etait invalide
!>

Details supplementaires:

!>
!>  La matrice Q est representee comme un produit de reflecteurs elementaires
!>
!>     Q = H(1) H(2) . . . H(k), où k = min(m,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**T
!>
!>  où tau est un scalaire reel, et v est un vecteur reel avec
!>  v(1:i-1) = 0 et v(i) = 1 ; v(i+1:m) est stocké en sortie dans A(i+1:m,i),
!>  et tau dans TAU(i).
!>
!> Voir la Note de travail Lapack 203 pour les details.
!>
