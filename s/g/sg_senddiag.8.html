NAME

sg_senddiag - exécute une commande SCSI SEND DIAGNOSTIC

SYNOPSIS

sg_senddiag [--doff] [--extdur] [--help] [--hex] [--list] [--maxlen=LEN] [--page=PG] [--pf] [--raw=H,H...] [--raw=-] [--selftest=ST] [--test] [--timeout=SECS] [--uoff] [--verbose] [--version] PÉRIPH

sg_senddiag [-doff] [-e] [-h] [-H] [-l] [-pf] [-raw=H,H...] [-raw=-] [-s=ST] [-t] [-T=SECS] [-uoff] [-v] [-V] [-?] PÉRIPH

DESCRIPTION

Cet utilitaire envoie une commande SCSI SEND DIAGNOSTIC au PÉRIPH. Il peut lancer des auto-tests, trouver des pages de diagnostic supportées ou envoyer des pages de diagnostic arbitraires.

Lorsque l'option --list et un PÉRIPH sont donnés, l'utilitaire envoie une commande SCSI RECEIVE DIAGNOSTIC RESULTS pour récupérer la réponse (c'est-à-dire les numéros de pages des pages de diagnostic supportées).

Lorsque l'option --list est donnée sans PÉRIPH, une liste des noms de pages de diagnostic et de leurs numéros, connus par cet utilitaire, est affichée.

Cet utilitaire supporte deux syntaxes de ligne de commande, la préférée est montrée en premier dans le synopsis et expliquée dans cette section. Une section ultérieure sur la syntaxe de commande ancienne décrit le deuxième groupe d'options.

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-d, --doff
définit le bit hors ligne du périphérique (DevOffL) (par défaut, il est effacé). N'a de signification que lorsque l'option --test est définie pour l'auto-test par défaut. Lorsqu'il est défini, d'autres opérations sur toutes les unités logiques contrôlées par ce serveur de périphérique (cible) peuvent être affectées (retardées) pendant qu'un auto-test par défaut est en cours.
-e, --extdur
affiche la durée attendue du test automatique étendu. La durée est donnée en secondes (et minutes entre parenthèses). Ce chiffre est obtenu à partir de la page de mode 0xa (c'est-à-dire la page de mode de contrôle).
-h, --help
affiche le message d'aide puis quitte.
-H, --hex
affiche la réponse de RECEIVE DIAGNOSTIC RESULTS en hexadécimal plutôt que de la décoder. Seule la page de diagnostic des pages de diagnostic supportées (c'est-à-dire page_code=0) est décodée ; d'autres pages (par exemple, celles utilisées par SES) sont affichées en hexadécimal.
Si --hex est utilisé une fois, la sortie hexadécimale a une adresse relative au début de chaque ligne. Si --hex est utilisé deux fois, alors l'ASCII est affiché à droite de chaque ligne hexadécimale. Si --hex est utilisé trois fois ou plus, seul l'hexadécimal est affiché, en paires de deux caractères (c'est-à-dire un octet) séparés par des espaces et jusqu'à 16 octets par ligne. Cette dernière forme, si elle est placée dans un fichier ou redirigée vers une autre invocation, convient à l'option --raw=-.
-l, --list
lorsqu'un PÉRIPH est également donné, liste les noms de toutes les pages de diagnostic supportées par ce périphérique. La requête est envoyée via une commande SEND DIAGNOSTIC (avec le bit "pF" défini) et la réponse est récupérée par une commande RECEIVE DIAGNOSTIC RESULTS. Lorsqu'elle est utilisée en l'absence d'argument --list, une liste des noms de pages de diagnostic et de leurs numéros, connus par cet utilitaire, est affichée.
-m, --maxlen=LEN
où LEN est la valeur placée dans le champ de longueur de la liste de paramètres d'une commande SEND DIAGNOSTIC ou dans le champ de longueur d'allocation d'une commande RECEIVE DIAGNOSTIC RESULTS. Cela se produit uniquement lorsque les autres options impliquent qu'il y aura des données envoyées ou reçues par la commande. La valeur par défaut est de 4096 octets. LEN ne peut pas dépasser 65535 ou 0xffff en hexadécimal.
-O, --old
passe aux options de style ancien. Veuillez utiliser comme première option.
-P, --page=PG
où PG est le champ du code de page de la commande RECEIVE DIAGNOSTIC RESULTS. Si cette option est donnée, le bit PCV de cette commande est défini. Lorsque cette option est donnée, aucune commande SEND DIAGNOSTIC n'est envoyée (contrairement à --list). Si PG est 0, la réponse est décodée comme s'il s'agissait de la page de diagnostic des pages de diagnostic supportées SPC. D'autres valeurs de PG (c'est-à-dire 1 à 255) ont leurs réponses affichées en hexadécimal.
-p, --pf
définit le bit Page Format (PF). Par défaut, il est effacé (c'est-à-dire 0) sauf si l'option --list est donnée, auquel cas le bit Page Format est défini (comme requis par SPC-3).
-r, --raw=H,H...
chaîne de nombres hexadécimaux séparés par des virgules, chacun devant se résoudre en une valeur d'octet (c'est-à-dire de 0 à ff inclus). Une chaîne d'octets hexadécimaux séparés par des espaces est également autorisée, mais la liste doit être entre guillemets. Cette séquence forme une page de diagnostic à envoyer avec la commande SCSI SEND DIAGNOSTIC. L'option --pf devrait très probablement également être donnée.
-r, --raw=-
lit une séquence d'octets depuis l'entrée standard. La séquence peut être séparée par des virgules, des espaces, des tabulations ou des sauts de ligne. Si une ligne contient "#", les caractères restants sur cette ligne sont ignorés. Sinon, chaque caractère non séparateur devrait se résoudre en une valeur d'octet (c'est-à-dire de 0 à ff inclus). Cette séquence forme une page de diagnostic à envoyer avec la commande SCSI SEND DIAGNOSTIC. L'option --pf devrait très probablement également être donnée.
-s, --selftest=ST
où ST est le code d'auto-test. La valeur par défaut est 0, ce qui est inactif. Certaines autres valeurs :
1 : auto-test court en arrière-plan
2 : auto-test étendu en arrière-plan
4 : abandonne un auto-test (en arrière-plan) en cours
5 : auto-test court en premier plan
6 : auto-test étendu en premier plan

Cette option est mutuellement exclusive avec l'auto-test par défaut (c'est-à-dire qu'on ne peut pas avoir (ST > 0) et --test).

-t, --test
définit le bit d'auto-test par défaut (SelfTest). Par défaut, il est effacé (0). L'option --selftest=ST ne doit pas être active en même temps que cette option. Les options --doff et/ou --uoff peuvent être utilisées avec cette option.
-T, --timeout=SECS
où SECS est une valeur de délai d'attente (en secondes) pour les opérations d'auto-test en premier plan. La valeur par défaut est de 7200 secondes (2 heures) et toute valeur de SECS inférieure à la valeur par défaut est ignorée.
-u, --uoff
définit le bit hors ligne de l'unité (UnitOffL) (par défaut, il est effacé). N'a de signification que lorsque l'option --test est définie pour l'auto-test par défaut. Lorsqu'il est défini, d'autres opérations sur cette unité logique peuvent être affectées (retardées) pendant qu'un auto-test par défaut est en cours. Certains périphériques (par exemple, les disques Fujitsu) effectuent davantage de tests lorsque ce bit est défini.
-v, --verbose
augmente le niveau de verbosité. Peut être utilisé plusieurs fois.
-V, --version
affiche la chaîne de version puis quitte.

NOTES

Tous les périphériques devraient supporter l'auto-test par défaut. Les codes d'auto-test 'court' devraient se terminer en 2 minutes ou moins. La durée maximale des codes d'auto-test 'étendu' est spécifique au vendeur (par exemple, un peu plus de 10 minutes avec les disques de l'auteur). Les codes d'auto-test en premier plan attendent leur achèvement tandis que les codes d'auto-test en arrière-plan reviennent immédiatement. Les résultats des codes d'auto-test en premier plan et en arrière-plan sont placés dans la page de journal 'résultats de l'auto-test' (voir sg_logs(8)). Le délai d'attente de la commande SCSI pour cet utilitaire est réglé à 60 minutes pour permettre des auto-tests étendus lents en premier plan.

Si le PÉRIPH est un disque, aucun système de fichiers résidant sur ce disque ne doit être monté pendant un auto-test en premier plan. La raison est que d'autres commandes SCSI peuvent être mises en file d'attente derrière l'auto-test en premier plan et expirer.

sg_senddiag(8)

NOM

sg_senddiag - envoyer une commande SCSI SEND DIAGNOSTIC

SYNOPSIS

sg_senddiag [OPTIONS] DEVICE

DESCRIPTION

Ce programme utilitaire de la suite sg3_utils envoie une commande SCSI DIAGNOSTIC à un périphérique SCSI.

La commande SCSI SEND DIAGNOSTIC est définie dans la norme SCSI-3 Primary Commands (SPC-3). Elle est utilisée pour demander à un périphérique SCSI d'effectuer des diagnostics internes, comme lancer un auto-test.

Le périphérique cible est spécifié par DEVICE.

OPTIONS

--doff
Définit le bit Device Offline (DevOffL) dans la commande. Par défaut, il est effacé. Cette option n'est significative que lorsque l'option -t est utilisée pour un auto-test par défaut.
--extdur
Demande la durée attendue d'un auto-test étendu. Utile pour les tests qui doivent s'exécuter en arrière-plan.
--hex
Affiche la réponse de la commande RECEIVE DIAGNOSTIC RESULTS en format hexadécimal au lieu de tenter de la décoder.
--help
Affiche un message d'aide puis quitte.
--list
Liste les noms des pages de diagnostic supportées par le périphérique. La demande est envoyée via une commande SEND DIAGNOSTIC (avec le bit "pf" défini) et la réponse est récupérée par une commande RECEIVE DIAGNOSTIC RESULTS. Si aucun périphérique n'est spécifié, une liste des pages de diagnostic connues de l'utilitaire est affichée.
--old
Utilise les anciennes options de ligne de commande (avant la version 1.23).
--pf
Définit le bit Page Format (PF). Par défaut, il est effacé (0), sauf si l'option --list est utilisée, auquel cas il est défini (conformément à SPC-3).
--raw=H,H...
Spécifie une page de diagnostic à envoyer sous forme de séquence d'octets hexadécimaux (séparés par des virgules). L'option --pf est généralement nécessaire.
--raw=-
Lit la séquence d'octets depuis l'entrée standard (stdin). Les octets peuvent être séparés par des virgules, des espaces, des tabulations ou des sauts de ligne. Les lignes commençant par '#' sont ignorées. L'option --pf est généralement nécessaire.
--selftest=ST
Spécifie le code de l'auto-test (ST). La valeur par défaut est 0 (inactif). Les valeurs courantes sont : 1 (auto-test court en arrière-plan), 2 (auto-test étendu en arrière-plan), 5 (auto-test court au premier plan), 6 (auto-test étendu au premier plan), 4 (interrompre un auto-test en cours). Cette option est mutuellement exclusive avec l'option -t.
--test
Définit le bit d'auto-test par défaut (SelfTest). Par défaut, il est effacé (0). Les options --doff et/ou --uoff peuvent être utilisées avec cette option.
--timeout=SECS
Définit une valeur de temps d'attente en secondes pour les opérations d'auto-test au premier plan.
--uoff
Définit le bit Unit Offline (UnitOffL). Par défaut, il est effacé.
--verbose
Augmente le niveau de verbosité. Peut être utilisé plusieurs fois.
--version
Affiche la version de l'utilitaire puis quitte.
-?
Affiche le message d'utilisation puis quitte.

NOTES

L'utilisation de la commande SEND DIAGNOSTIC avec des options spécifiques peut dépendre de la norme implémentée par le périphérique. Par exemple, pour interroger ou définir des paramètres spécifiques, les normes comme SES-2 (SCSI Enclosure Services) peuvent être pertinentes.

Si l'option --raw est utilisée avec un code de page de diagnostic valide, mais sans l'option --pf, le périphérique peut interpréter cela différemment. La spécification SPC-3 indique que la page de diagnostic doit être envoyée avec le bit PF (Page Format) défini si le code de page est donné (ce qui est le cas avec --raw). La longueur de la page de diagnostic envoyée est dérivée du nombre d'octets fournis à l'option --raw. Le code (numéro) de la page de diagnostic doit être le premier octet de la séquence (conformément au format de page de diagnostic SPC-3).

Des pages de diagnostic arbitraires peuvent être lues (en hex) avec l'utilitaire sg_ses(8) (pas seulement celles définies dans SES-2).

Si l'utilitaire est utilisé sans aucune option (par exemple, "sg_senddiag /dev/sg1"), une commande SCSI SEND DIAGNOSTIC dégénérée est envoyée avec des zéros dans tous ses champs, à l'exception de l'opcode. Certains périphériques signalent cela comme une erreur, tandis que d'autres l'ignorent. Il n'est pas entièrement clair selon SPC-3 si l'envoi d'une telle commande est invalide.

Dans la série 2.4 des noyaux Linux, DEVICE doit être un périphérique générique SCSI (sg). Dans la série 2.6, des périphériques de bloc (par exemple, disques SCSI et lecteurs DVD) peuvent également être spécifiés.

Pour accéder aux boîtiers SCSI, consultez l'utilitaire sg_ses(8). sg_ses utilise les commandes SCSI SEND DIAGNOSTIC et RECEIVE DIAGNOSTIC RESULTS telles que décrites dans la norme SES-2 (brouillon).

STATUT DE SORTIE

Le statut de sortie de sg_senddiag est 0 en cas de succès. Sinon, consultez la page de manuel sg3_utils(8).

OPTIONS DE LIGNE DE COMMANDE ANCIENNES

Les options dans cette section étaient les seules disponibles avant la version 1.23 de sg3_utils. Depuis lors, cet utilitaire utilise par défaut les options de ligne de commande plus récentes qui peuvent être remplacées en utilisant --old (ou -O) comme première option. Consultez la section VARIABLES D'ENVIRONNEMENT pour une autre façon de forcer l'utilisation de ces anciennes options de ligne de commande.

-doff
Définit le bit Device Offline (DevOffL) (par défaut, effacé). Significatif uniquement lorsque l'option -t est définie pour l'auto-test par défaut. Équivalent à --doff dans la description principale.
-e
Affiche la durée attendue d'un auto-test étendu. Équivalent à --extdur dans la description principale.
-h
Affiche la réponse de RECEIVE DIAGNOSTIC RESULTS en hexadécimal au lieu de la décoder.
-H
Affiche la réponse de RECEIVE DIAGNOSTIC RESULTS en hexadécimal au lieu de la décoder.
-l
Lorsqu'un DEVICE est également fourni, liste les noms de toutes les pages de diagnostic supportées par ce périphérique. La requête est envoyée via une commande SEND DIAGNOSTIC (avec le bit "pf" défini) et la réponse est récupérée par une commande RECEIVE DIAGNOSTIC RESULTS. Utilisé en l'absence d'argument DEVICE, une liste des noms de pages de diagnostic et de leurs numéros, connus de cet utilitaire, est affichée.
-N, --new
Passe aux options de style plus récent.
-pf
Définit le bit Page Format (PF). Par défaut, il est effacé (i.e. 0), sauf si l'option -l est donnée, auquel cas le bit Page Format est défini (comme requis par SPC-3).
-raw=H,H...
Séquence de nombres hexadécimaux séparés par des virgules, chacun devant se résoudre en une valeur d'octet (c'est-à-dire de 0 à ff inclus). Cette séquence forme une page de diagnostic à envoyer avec la commande SCSI SEND DIAGNOSTIC. Il est fort probable que l'option -pf doive également être fournie.
-raw=-
Lit une séquence d'octets depuis l'entrée standard. La séquence peut être séparée par des virgules, des espaces, des tabulations ou des sauts de ligne (newline). Si une ligne contient "#", les caractères restants sur cette ligne sont ignorés. Sinon, chaque caractère non séparateur doit se résoudre en une valeur d'octet (c'est-à-dire de 0 à ff inclus). Cette séquence forme une page de diagnostic à envoyer avec la commande SCSI SEND DIAGNOSTIC. Il est fort probable que l'option -pf doive également être fournie.
-s=ST
où ST est le code de l'auto-test. La valeur par défaut est 0, ce qui est inactif. Une valeur de 1 sélectionne un auto-test court en arrière-plan ; 2 sélectionne un auto-test étendu en arrière-plan ; 5 sélectionne un auto-test court au premier plan ; 6 sélectionne un test étendu au premier plan. Une valeur de 4 interrompra un auto-test (en arrière-plan) en cours. Cette option est mutuellement exclusive avec l'auto-test par défaut (c'est-à-dire -t).
-t
Définit le bit d'auto-test par défaut (SelfTest). Par défaut, il est effacé (0). L'option -s=ST ne doit pas être active en même temps que cette option. Les options -doff et/ou -uoff peuvent être utilisées avec cette option.
-T=SECS
où SECS est une valeur de temps d'attente (en secondes) pour les opérations d'auto-test au premier plan. Voir l'option --timeout=SECS ci-dessus.
-uoff
Définit le bit Unit Offline (UnitOffL) (par défaut, effacé). Équivalent à --uoff dans la description principale.
-v
Augmente le niveau de verbosité. Peut être utilisé plusieurs fois.
-V
Affiche la chaîne de version puis quitte.
-?
Affiche le message d'utilisation. Ignore tous les autres paramètres.

EXEMPLES

Le sous-répertoire examples du package sg3_utils contient deux scripts d'exemple qui activent le CJTPAT (jitter pattern) sur certains disques SAS (un script pour chaque phy). Une invocation possible pour le phy 1 est :


sg_senddiag --pf --raw=- /dev/sg2 < sdiag_sas_p1_cjtpat.txt

Il existe également un script d'exemple qui active le motif IDLE. Une fois qu'un motif de test a été démarré, il peut être désactivé en réinitialisant le phy ou avec la fonction STOP phy pattern :


sg_senddiag --pf --raw=- /dev/sg2 < sdiag_sas_p1_stop.txt

VARIABLES D'ENVIRONNEMENT

Depuis la version 1.23 de sg3_utils, la variable d'environnement SG3_UTILS_OLD_OPTS peut être définie. Lorsqu'elle est présente, cet utilitaire s'attend aux anciennes options de ligne de commande. La présence de cette variable d'environnement est donc équivalente à l'utilisation de --old (ou -O) comme première option de ligne de commande.
