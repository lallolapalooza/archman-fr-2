NOM

sg_rdac - afficher ou modifier la page de mode du contrôleur redondant SCSI RDAC

SYNTAXE

sg_rdac [-6] [-a] [-f=LUN] [-v] [-V] PÉRIPHÉRIQUE

DESCRIPTION

sg_rdac affiche ou modifie les paramètres du contrôleur RDAC via la page de mode du contrôleur redondant (0x2C). Lors de la modification des paramètres, il permet de transférer la propriété des disques individuels au contrôleur sur lequel la commande a été reçue.

OPTIONS

-6
Utilise les variantes de commande CDB de 6 octets des commandes SCSI MODE SENSE et MODE SELECT. L'action par défaut (en l'absence de cette option) est d'utiliser les variantes de commande CDB de 10 octets.
-a
Transférer tous les périphériques (visibles).
-f=LUN
Transférer le périphérique identifié par LUN. Cette commande ne fonctionnera que si le contrôleur prend en charge le « Dual Active Mode  » (également appelé mode actif/actif). LUN est un nombre décimal qui ne peut pas dépasser 31 si l'option -6 est donnée, sinon il ne peut pas dépasser 255.
-v
être verbeux.
-V
afficher la chaîne de version puis quitter.

STATUT DE SORTIE

Le statut de sortie de sg_rdac est 0 en cas de succès. Sinon, voir la page man sg3_utils(8).
