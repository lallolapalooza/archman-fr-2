NOM

sgml2lyx - créer une sortie LyX à partir d'un fichier source SGML DTD LinuxDoc

SYNTAXE

sgml2lyx [option-générique...] fichier[.sgml]

DESCRIPTION

sgml2lyx est une ancienne forme obsolète de la commande lyx de LinuxDoc-Tools (son nom peut être trompeur, car ce n'est pas un outil pour n'importe quelle DTD SGML, il ne supporte que la DTD SGML LinuxDoc). Il est recommandé d'utiliser la nouvelle forme linuxdoc -B lyx maintenant. Il convertit un fichier source SGML DTD LinuxDoc en sortie LyX. La sortie apparaîtra dans fichier.lyx où fichier est le nom du fichier source SGML.

La paire attribut/valeur « output=lyx » est définie pour les conditionnels.

OPTIONS

sgm2lyx accepte toutes les options génériques décrites dans linuxdoc(1).

fichier
Le fichier source SGML, nommé soit fichier soit fichier.sgml

FICHIERS

De nombreux fichiers et exécutables dans /usr/share/linuxdoc-tools et /usr/bin sont utilisés.

BOGUES

Aucun connu.

AUTEUR
