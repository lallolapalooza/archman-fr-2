sous-programme sgtsvx (character fact, character trans, integer n, integer nrhs, real, dimension( * ) dl, real, dimension( * ) d, real, dimension( * ) du, real, dimension( * ) dlf, real, dimension( * ) df, real, dimension( * ) duf, real, dimension( * ) du2, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SGTSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices GT

Objectif:

!>
!> SGTSVX utilise la factorisation LU pour calculer la solution d'un système
!> linéaire réel A * X = B ou A**T * X = B, où A est une matrice tridiagonale
!> d'ordre N et X et B sont des matrices N-par-NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de la condition sont
!> également fournies.
!>

Description:

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la décomposition LU est utilisée pour factoriser la matrice A
!>    en A = L * U, où L est un produit de matrices de permutation et
!>    bidiagonales inférieures unitaires et U est triangulaire supérieure
!>    avec des non-zéros uniquement sur la diagonale principale et les deux
!>    superdiagonales.
!>
!> 2. Si un U(i,i)=0, rendant U singulière, la routine
!>    retourne avec INFO = i. Sinon, la forme factorisée de A est utilisée
!>    pour estimer le nombre de conditionnement de la matrice A. Si le
!>    réciproque du nombre de conditionnement est inférieur à la précision machine,
!>    INFO = N+1 est retourné comme avertissement, mais la routine continue
!>    quand même à résoudre pour X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 4. Un raffinement itératif est appliqué pour améliorer la solution calculée
!>    et calculer les bornes d'erreur et les estimations d'erreur arrière
!>    pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de A a été fournie ou non en entrée.
!>          = 'F':  DLF, DF, DUF, DU2 et IPIV contiennent la forme factorisée
!>                  de A; DL, D, DU, DLF, DF, DUF, DU2 et IPIV ne seront pas modifiés.
!>          = 'N':  La matrice sera copiée dans DLF, DF et DUF
!>                  et factorisée.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N':  A * X = B     (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Conjuguée transposée = Transposée)
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

DL

!>          DL est tableau REAL, dimension (N-1)
!>          Les éléments sous-diagonaux (n-1) de A.
!>

D

!>          D est tableau REAL, dimension (N)
!>          Les éléments diagonaux n de A.
!>

DU

!>          DU est tableau REAL, dimension (N-1)
!>          Les éléments superdiagonaux (n-1) de A.
!>

DLF

!>          DLF est tableau REAL, dimension (N-1)
!>          Si FACT = 'F', alors DLF est un argument d'entrée et contient en entrée
!>          les multiplicateurs (n-1) qui définissent la matrice L de
!>          la factorisation LU de A calculée par SGTTRF.
!>
!>          Si FACT = 'N', alors DLF est un argument de sortie et contient en sortie
!>          les multiplicateurs (n-1) qui définissent la matrice L de
!>          la factorisation LU de A.
!>

DF

!>          DF est tableau REAL, dimension (N)
!>          Si FACT = 'F', alors DF est un argument d'entrée et contient en entrée
!>          les éléments diagonaux n de la matrice triangulaire supérieure
!>          U de la factorisation LU de A.
!>
!>          Si FACT = 'N', alors DF est un argument de sortie et contient en sortie
!>          les éléments diagonaux n de la matrice triangulaire supérieure
!>          U de la factorisation LU de A.
!>

DUF

!>          DUF est tableau REAL, dimension (N-1)
!>          Si FACT = 'F', alors DUF est un argument d'entrée et contient en entrée
!>          les éléments (n-1) de la première superdiagonale de U.
!>
!>          Si FACT = 'N', alors DUF est un argument de sortie et contient en sortie
!>          les éléments (n-1) de la première superdiagonale de U.
!>

DU2

!>          DU2 est tableau REAL, dimension (N-2)
!>          Si FACT = 'F', alors DU2 est un argument d'entrée et contient en entrée
!>          les éléments (n-2) de la deuxième superdiagonale de
!>          U.
!>
!>          Si FACT = 'N', alors DU2 est un argument de sortie et contient en sortie
!>          les éléments (n-2) de la deuxième superdiagonale de
!>          U.
!>

IPIV

!>          IPIV est tableau INTEGER, dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et contient en entrée
!>          les indices de pivot de la factorisation LU de A, calculés par SGTTRF.
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et contient en sortie
!>          les indices de pivot de la factorisation LU de A ;
!>          la ligne i de la matrice a été échangée avec la ligne IPIV(i).
!>          IPIV(i) sera toujours i ou i+1 ; IPIV(i) = i indique qu'un échange
!>          de ligne n'était pas requis.
!>

B

!>          B est tableau REAL, dimension (LDB,NRHS)
!>          La matrice des membres de droite B, de taille N-par-NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est tableau REAL, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N-par-NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>          L'estimation du réciproque du nombre de conditionnement de la matrice
!>          A.  Si RCOND est inférieur à la précision machine (en
!>          particulier, si RCOND = 0), la matrice est singulière à la précision
!>          de travail. Cette condition est indiquée par un code de retour
!>          INFO > 0.
!>

FERR

!>          FERR est tableau REAL, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).

!>          élément de X(j).  L'estimation est aussi fiable que
