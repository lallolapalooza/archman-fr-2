Documentation de la fonction/sous-programme

sous-programme sgetrs (caractère trans, entier n, entier nrhs, réel, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, réel, dimension( ldb, * ) b, entier ldb, entier info)

SGETRS

But:

!>
!> SGETRS résout un système d'équations linéaires
!>    A * X = B  ou  A**T * X = B
!> avec une matrice N par N générale A en utilisant la factorisation LU calculée
!> par SGETRF.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N':  A * X = B  (Pas de transposée)
!>          = 'T':  A**T* X = B  (Transposée)
!>          = 'C':  A**T* X = B  (Conjuguée transposée = Transposée)
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          Les facteurs L et U de la factorisation A = P*L*U
!>          tels que calculés par SGETRF.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N)
!>          Les indices de pivot de SGETRF ; pour 1<=i<=N, la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

B

!>          B est un tableau REEL, dimension (LDB,NRHS)
!>          En entrée, la matrice du côté droit B.
!>          En sortie, la matrice solution X.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
