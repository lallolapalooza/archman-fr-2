Documentation de la fonction/sous-routine

sous-routine sgtrfs (caractère trans, entier n, entier nrhs, réel, dimension( * ) dl, réel, dimension( * ) d, réel, dimension( * ) du, réel, dimension( * ) dlf, réel, dimension( * ) df, réel, dimension( * ) duf, réel, dimension( * ) du2, entier, dimension( * ) ipiv, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( ldx, * ) x, entier ldx, réel, dimension( * ) ferr, réel, dimension( * ) berr, réel, dimension( * ) work, entier, dimension( * ) iwork, entier info)

SGTRFS

Objectif :

!>
!> SGTRFS améliore la solution calculée pour un système d'équations linéaires
!> lorsque la matrice des coefficients est tridiagonale, et fournit
!> des bornes d'erreur et des estimations d'erreur à rebours pour la solution.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N':  A * X = B     (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Conjuguée transposée = Transposée)
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

DL

!>          DL est un tableau de REEL, dimension (N-1)
!>          Les éléments sous-diagonaux (n-1) de A.
!>

D

!>          D est un tableau de REEL, dimension (N)
!>          Les éléments diagonaux de A.
!>

DU

!>          DU est un tableau de REEL, dimension (N-1)
!>          Les éléments superdiagonaux (n-1) de A.
!>

DLF

!>          DLF est un tableau de REEL, dimension (N-1)
!>          Les multiplicateurs (n-1) qui définissent la matrice L à partir de la
!>          factorisation LU de A calculée par SGTTRF.
!>

DF

!>          DF est un tableau de REEL, dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire supérieure U issue de
!>          la factorisation LU de A.
!>

DUF

!>          DUF est un tableau de REEL, dimension (N-1)
!>          Les éléments (n-1) de la première superdiagonale de U.
!>

DU2

!>          DU2 est un tableau de REEL, dimension (N-2)
!>          Les éléments (n-2) de la seconde superdiagonale de U.
!>

IPIV

!>          IPIV est un tableau d'ENTIERS, dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= n, la ligne i de la matrice a été
!>          échangée avec la ligne IPIV(i).  IPIV(i) sera toujours égal à
!>          i ou i+1 ; IPIV(i) = i indique qu'aucun échange de ligne n'était
!>          nécessaire.
!>

B

!>          B est un tableau de REEL, dimension (LDB,NRHS)
!>          La matrice des membres de droite B.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau de REEL, dimension (LDX,NRHS)
!>          En entrée, la matrice solution X, telle que calculée par SGTTRS.
!>          En sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est un ENTIER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

FERR

!>          FERR est un tableau de REEL, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ième colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément dans (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément dans X(j).  L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          surestimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau de REEL, dimension (NRHS)
!>          L'erreur relative composante par composante à rebours de chaque vecteur solution
!>          X(j) (c'est-à-dire le plus petit changement relatif dans
!>          n'importe quel élément de A ou B qui fait de X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau de REEL, dimension (3*N)
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, dimension (N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Paramètres internes :

!>  ITMAX est le nombre maximum d'étapes de raffinement itératif.
!>
