NOM

sg_rep_density - envoie la commande SCSI REPORT DENSITY SUPPORT

SYNTAXE

sg_rep_density [--help] [--hex] [--inhex=FN] [--maxlen=LEN] [--media] [--raw] [--readonly] [--typem] [--verbose] [--version] DEVICE

DESCRIPTION

Envoie une commande SCSI REPORT DENSITY à DEVICE et affiche les données retournées. Cette commande est spécifique aux lecteurs de bande. Elle est présente dans le projet de norme SSC-5, révision 6 (ssc5r06.pdf). Elle était présente dans la norme SSC-2 (ANSI INCITS 380-2003).

Par défaut, cet utilitaire demande les descripteurs de codes de densité supportés par DEVICE (par exemple, un lecteur de bande) et décode la réponse. Si l'option --typem est spécifiée, il récupère les descripteurs de types de média supportés par DEVICE et décode la réponse. Lorsque l'option --media est spécifiée, les descripteurs de code de densité ou de type de média supportés par le média à l'intérieur de DEVICE (par exemple, une cartouche de bande) sont récupérés.

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-h, --help
affiche le message d'utilisation puis quitte.
-H, --hex
affiche la réponse en hexadécimal sur stdout. Utilisée une fois, toute la réponse est affichée en hexadécimal ASCII, précédée d'une adresse (commençant à 0) sur chaque ligne. Utilisée deux fois, toute la réponse est affichée en hexadécimal sans adresse de préfixe (sur chaque ligne).
Utiliser cette option trois fois produira une sortie qui peut être redirigée vers un fichier et ensuite donnée à une autre invocation en utilisant l'option --inhex=FN.
-i, --inhex=FN
où FN est un nom de fichier dont le contenu est supposé être en hexadécimal ASCII. Si DEVICE est également spécifié, alors DEVICE est ignoré, un avertissement est émis et l'utilitaire continue, décodant le fichier nommé FN. Voir la section « HEX, BINARY AND JSON FORMATS » dans la page man de sg3_utils pour plus d'informations. Si l'option --raw est également spécifiée, le contenu de FN est traité comme binaire.
-m, --maxlen=LEN
où LEN est la longueur (maximale) de la réponse en octets. Elle est placée dans le champ « allocation length » du cdb. Si non spécifié (ou si LEN est zéro), 8192 est utilisé. La valeur maximale autorisée de LEN est 65535.
-M, --media
définit le bit MEDIA dans le cdb, ce qui provoque la mise dans la réponse des codes de densité (ou des types de média) supportés par la cartouche de bande dans le lecteur. Par défaut, ce sont les codes de densité (ou les types de média) supportés par le lecteur de bande lui-même qui sont demandés.
S'il n'y a pas de « média » (par exemple, de cartouche de bande) présent dans le lecteur, la commande SCSI échouera avec une clé de requête « not ready ».
-r, --raw
affiche la réponse SCSI (c'est-à-dire le tampon de données de sortie) en binaire (sur stdout) à moins que l'option --inhex=FN ne soit spécifiée.
Lorsqu'il est utilisé avec l'option --inhex=FN, le contenu de FN est traité comme binaire (plutôt qu'hexadécimal).
-R, --readonly
ouvre DEVICE en lecture seule (par exemple, sous Unix avec le flag O_RDONLY). Par défaut, il est ouvert en lecture-écriture.
-t, --typem
définit le bit MEDIUM TYPE dans le cdb, ce qui provoque la mise dans la réponse des types de média supportés par le lecteur de bande (ou la cartouche de bande). Par défaut, ce sont les codes de densité qui sont demandés.
-v, --verbose
augmente le niveau de verbosité (c'est-à-dire la sortie de débogage).
-V, --version
affiche la chaîne de version puis quitte.

STATUT DE SORTIE

Le statut de sortie de sg_rep_density est 0 en cas de succès. Sinon, voir la page man de sg3_utils(8).
