SGGSVD3 calcule la décomposition en valeurs singulières (SVD) pour D'AUTRES matrices

sous-routine sggsvd3 (character jobu, character jobv, character jobq, integer m, integer n, integer p, integer k, integer l, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) alpha, real, dimension( * ) beta, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldv, * ) v, integer ldv, real, dimension( ldq, * ) q, integer ldq, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

SGGSVD3 calcule la décomposition en valeurs singulières généralisée (GSVD) de la matrice réelle M par N de A et de la matrice réelle P par N de B :

Objectif :

!>
!> SGGSVD3 calcule la décomposition en valeurs singulières généralisée (GSVD)
!> d'une matrice réelle M par N A et d'une matrice réelle P par N B :
!>
!>       U**T*A*Q = D1*( 0 R ),    V**T*B*Q = D2*( 0 R )
!>
!> où U, V et Q sont des matrices orthogonales.
!> Soit K+L = le rang numérique effectif de la matrice (A**T,B**T)**T,
!> alors R est une matrice triangulaire supérieure non singulière de taille K+L par K+L, D1 et
!> D2 sont des matrices de taille M par (K+L) et P par (K+L) respectivement,
!> ayant les structures suivantes :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N), et R33 est stocké
!!>   ( 0  R22 R23 )
!>   dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> La routine calcule C, S, R, et optionnellement les matrices de transformation
!> orthogonales U, V et Q.
!>
!> En particulier, si B est une matrice carrée inversible N par N, alors la GSVD de
!> A et B donne implicitement la SVD de A*inv(B) :
!>                      A*inv(B) = U*(D1*inv(D2))*V**T.
!> Si ( A**T,B**T)**T  a des colonnes orthonormées, alors la GSVD de A et B est
!> aussi égale à la décomposition CS de A et B. De plus, la GSVD
!> peut être utilisée pour dériver la solution du problème aux valeurs propres :
!>                      A**T*A x = lambda* B**T*B x.
!> Dans certaines littératures, la GSVD de A et B est présentée sous la forme
!>                  U**T*A*X = ( 0 D1 ),   V**T*B*X = ( 0 D2 )
!> où U et V sont orthogonales et X est inversible, D1 et D2 sont
!> « diagonales ». La forme GSVD précédente peut être convertie en la forme tardive
!> en prenant la matrice inversible X comme
!>
!>                      X = Q*( I   0    )
!>                            ( 0 inv(R) ).
!>
