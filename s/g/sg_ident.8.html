NOM

sg_ident - envoie la commande SCSI REPORT/SET IDENTIFYING INFORMATION

SYNTAXE

sg_ident [--ascii] [--clear] [--help] [--itype=IT] [--raw] [--set] [--verbose] [--version] PÉRIPH

DESCRIPTION

Envoie une commande SCSI REPORT IDENTIFYING INFORMATION ou SET IDENTIFYING INFORMATION au PÉRIPH. Avant SPC-4 (révision 7), ces commandes étaient nommées REPORT DEVICE IDENTIFIER et SET DEVICE IDENTIFIER respectivement. Les périphériques SCSI qui prennent en charge ces deux commandes permettent aux utilisateurs d'écrire (définir) des informations d'identification et de les signaler ultérieurement. Les informations sont persistantes (c'est-à-dire stockées sur un support non volatil dans le périphérique SCSI qui survivra à une coupure de courant).

Généralement, l'espace alloué aux informations est limité : SPC-4 (révision 7) stipule que pour le type d'information 0, la longueur minimale est de 64 octets et la longueur maximale est de 512 octets. Pour les autres types d'informations (1 à 126 inclus), la longueur maximale est de 256 octets. De plus, les types d'informations 1 à 126 (inclus) doivent contenir une chaîne UTF-8 terminée par un caractère nul. L'auteur a vu des anciens disques qui ne prennent en charge que 16 octets.

L'action par défaut lorsque aucune option n'est donnée est d'invoquer la commande Report Identifying Information avec le type d'information défini par défaut à zéro. Les rapports d'erreurs sont envoyés sur stderr. Par défaut, les informations sont affichées en ASCII-HEX (jusqu'à 16 octets par ligne) avec une représentation ASCII sur la droite, les caractères non imprimables étant remplacés par des points.

OPTIONS

Les arguments des options longues sont également obligatoires pour les options courtes.

-A, --ascii
invoque la commande Report Identifying Information et si quelque chose est trouvé, l'interprète comme ASCII (ou UTF-8, dépendant de la locale) et affiche les informations sur stdout.
-C, --clear
invoque la commande Set Identifying Information avec une longueur d'information de zéro. Cela a pour effet de supprimer les informations existantes.
-h, --help
affiche le message d'utilisation puis quitte.
-i, --itype=IT
où IT est le type d'information. Par défaut à zéro. La valeur maximale est 127, ce qui est spécial et ne peut pas être utilisé avec --set ou --clear. Le type d'information 127 (s'il est pris en charge) fait que la commande REPORT IDENTIFYING INFORMATION répond par une liste des types d'informations disponibles et leurs longueurs maximales en octets. Les types d'informations impairs entre 3 et 125 (inclus) ne doivent pas être utilisés (car ils entrent en conflit avec la norme SCC-2).
-r, --raw
invoque la commande Report Identifying information et si quelque chose est trouvé, envoie les informations (qui peuvent être binaires) sur stdout. Rien d'autre n'est envoyé sur stdout, cependant les rapports d'erreurs, s'il y en a, sont envoyés sur stderr.
-S, --set
lit d'abord stdin jusqu'à ce qu'un EOF soit détecté, puis invoque la commande Set Identifying Information pour définir ce qui a été lu depuis stdin comme information. La quantité de données lues doit être comprise entre 1 et 512 octets (inclus).
-v, --verbose
augmente le niveau de verbosité (c'est-à-dire la sortie de débogage).
-V, --version
affiche la chaîne de version puis quitte.

Cet utilitaire permet aux utilisateurs d'écrire leurs propres informations d'identification sur leurs périphériques SCSI. Il existe plusieurs autres types de descripteurs (ou identifiants) que l'utilisateur ne peut pas modifier. Ceux-ci incluent la commande SCSI INQUIRY avec ses chaînes standard d'identification de vendeur et de produit, ainsi que le niveau de révision du produit ; plus la grande quantité d'informations fournies par la page « Device Identification » (voir sg_vpd). Il existe également la commande READ MEDIA SERIAL NUMBER (voir sg_rmsn). L'ensemble de commandes MMC-4 pour CD et DVD possède une fonctionnalité « media serial number » (0x109) [et une fonctionnalité « logical unit serial number »]. Celles-ci peuvent être consultées avec l'utilitaire sg_get_config.

EXEMPLES

Pour commencer, pour voir s'il existe une information existante dont le format est inconnu (pour le type d'information 0), utilisez aucune option :


# sg_ident /dev/sdb
00 31 32 33 34 35 36 37 38 39 30 1234567890

Si c'est de l'ASCII, cela peut être affiché comme tel :


# sg_ident --ascii /dev/sdb
1234567890

Les informations peuvent être copiées dans un fichier, effacées puis ré-assertées avec cette séquence :


# sg_ident --raw /dev/sdb > t
# sg_ident --clear /dev/sdb
# cat t | sg_ident --set /dev/sdb

VALEUR DE RETOUR

La valeur de retour de sg_ident est 0 en cas de succès. Sinon, voir la page de manuel sg3_utils(8).
