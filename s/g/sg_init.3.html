NOM

sg_init, sg_snapshot, sg_shutdown, sg_drop_privileges - initialiser libstatgrab

SYNOPSIS

#include <statgrab.h>


void sg_log_init
(const char *properties_pfx, const char *env_name, const char *argv0);


sg_error sg_init
(int ignore_init_errors);


sg_error sg_snapshot
(void);


sg_error sg_shutdown
(void);


sg_error sg_drop_privileges
(void);

DESCRIPTION

sg_init() initialise la bibliothèque statgrab et met le compteur d'initialisation à 1, s'il n'a pas déjà été fait, ou incrémente le compteur d'initialisation. Si elle est appelée pour la première fois (en fait : si elle est appelée lorsque le compteur d'initialisation est à 0), le constructeur (routine d'initialisation) de chaque composant enregistré est invoqué, des variables globales sont initialisées, les sémaphores d'exclusion mutuelle demandés sont initialisés, etc. sg_init() est protégée par le mutex nommé "statgrab".

sg_log_init() permet une configuration de journalisation spécifique à l'application. Elle est destinée aux projets comportant plusieurs applications ou commandes qui pourraient avoir des destinations différentes. Notez que sg_log_init doit être appelée avant sg_init, mais après que votre application ait initialisé son framework de journalisation.

sg_snapshot() est uniquement disponible sous Win32 et disparaîtra probablement.

sg_shutdown() décrémente le compteur d'initialisation. Si le compteur atteint zéro, les destructeurs des composants sont appelés, les sémaphores d'exclusion mutuelle (sauf "statgrab") sont détruits, etc. sg_shutdown() est protégée par le mutex nommé "statgrab".

sg_drop_privileges() abandonne les privilèges élevés.

VALEURS DE RETOUR

Toutes les fonctions retournent un code d'erreur statgrab. Soit SG_ERROR_NONE lorsque tout s'est bien passé, soit le code d'erreur approprié provenant d'un constructeur/destructeur.

EXEMPLE

Séquence d'initialisation/désinitialisation typique lors de l'utilisation avec log4cplus :

static void *l4cplus_initializer;
static void
cleanup_logging(void)
{
       log4cplus_deinitialize(l4cplus_initializer);
}
int
main(int argc, char const *argv[])
{
    l4cplus_initializer = log4cplus_initialize();
    atexit((void (*)(void))cleanup_logging);
    sg_log_init("saidar", "SAIDAR_LOG_PROPERTIES", argv[0]);
    sg_init(1);
    if(sg_drop_privileges() != 0) {
	die("Échec de l'abandon des privilèges setuid/setgid");
    }
    do_something();
    sg_shutdown();
    return 0;
}
