sous-programme sget37 (real, dimension( 3 ) rmax, integer, dimension( 3 ) lmax, integer, dimension( 3 ) ninfo, integer knt, integer nin)

SGET37

Objectif :

!>
!> SGET37 teste STRSNA, une routine pour estimer les nombres de condition
!> des valeurs propres et/ou des vecteurs propres droits d'une matrice.
!>
!> Les matrices de test sont lues à partir d'un fichier avec le numéro
!> d'unité logique NIN.
!>

Paramètres

RMAX 
!>          RMAX est un tableau REEL, dimension (3)
!>          Valeur du plus grand rapport de test.
!>          RMAX(1) = plus grand rapport comparant différents appels à STRSNA
!>          RMAX(2) = plus grande erreur dans le nombre de condition réciproque
!>                    en tenant compte de leur conditionnement
!>          RMAX(3) = plus grande erreur dans le nombre de condition réciproque
!>                    sans tenir compte de leur conditionnement (peut être
!>                    plus grand que RMAX(2))
!>

LMAX

!>          LMAX est un tableau ENTIER, dimension (3)
!>          LMAX(i) est le numéro d'exemple où le plus grand rapport de test
!>          RMAX(i) est atteint. Aussi :
!>          Si SGEHRD retourne INFO non nul pour l'exemple i, LMAX(1)=i
!>          Si SHSEQR retourne INFO non nul pour l'exemple i, LMAX(2)=i
!>          Si STRSNA retourne INFO non nul pour l'exemple i, LMAX(3)=i
!>

NINFO

!>          NINFO est un tableau ENTIER, dimension (3)
!>          NINFO(1) = Nombre de fois où SGEHRD a retourné INFO non nul
!>          NINFO(2) = Nombre de fois où SHSEQR a retourné INFO non nul
!>          NINFO(3) = Nombre de fois où STRSNA a retourné INFO non nul
!>

KNT

!>          KNT est un ENTIER
!>          Nombre total d'exemples testés.
!>

NIN

!>          NIN est un ENTIER
!>          Numéro d'unité logique d'entrée
!>
