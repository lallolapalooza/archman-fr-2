SGEDMD calcule la décomposition de mode dynamique (DMD) pour une paire de matrices de données instantanées.

But :

!>    SGEDMD calcule la décomposition de mode dynamique (DMD) pour
!>    une paire de matrices de données instantanées. Pour les matrices
!>    d'entrée X et Y telles que Y = A*X avec une matrice A inaccessible,
!>    SGEDMD calcule un certain nombre de paires de Ritz de A en utilisant
!>    l'extraction standard de Rayleigh-Ritz d'un sous-espace
!>    de range(X) qui est déterminé à l'aide des vecteurs singuliers gauches
!>    principaux de X. Optionnellement, SGEDMD retourne les résidus
!>    des paires de Ritz calculées, les informations nécessaires au
!>    raffinement des vecteurs de Ritz, ou les vecteurs propres
!>    de la DMD exacte.
!>    Pour plus de détails, voir les références ci-dessous. Pour plus de détails
!>    sur l'implémentation, voir [3].
!>

!>    Les K premières entrées (K<=N) de REIG contiennent
!>    les parties réelles des valeurs propres calculées
!>    REIG(1:K) + sqrt(-1)*IMEIG(1:K).
!>    Voir les descriptions de K, IMEIG et Z.
!>

IMEIG

!>    IMEIG (sortie) REAL(KIND=WP) Tableau N-par-1
!>    Les K premières entrées (K<=N) de IMEIG contiennent
!>    les parties imaginaires des valeurs propres calculées
!>    REIG(1:K) + sqrt(-1)*IMEIG(1:K).
!>    Les valeurs propres sont déterminées comme suit :
!>    Si IMEIG(i) == 0, alors la valeur propre correspondante est
!>    réelle, LAMBDA(i) = REIG(i).
!>    Si IMEIG(i)>0, alors la paire de valeurs propres complexes conjuguées
!>    correspondantes est :
!>    LAMBDA(i)   = REIG(i) + sqrt(-1)*IMAG(i)
!>    LAMBDA(i+1) = REIG(i) - sqrt(-1)*IMAG(i)
!>    C'est-à-dire que les paires de conjugués complexes ont des indices consécutifs
!>    (i,i+1), la partie imaginaire positive étant listée en premier.
!>    Voir les descriptions de K, REIG et Z.
!>

Z

!>    Z (espace de travail/sortie) REAL(KIND=WP) Tableau M-par-N
!>    Si JOBZ =='V' alors
!>       Z contient des vecteurs de Ritz réels comme suit :
!>       Si IMEIG(i)=0, alors Z(:,i) est un vecteur propre de
!>       la i-ème valeur de Ritz ; ||Z(:,i)||_2=1.
!>       Si IMEIG(i) > 0 (et IMEIG(i+1) < 0) alors
!>       [Z(:,i) Z(:,i+1)] englobent un sous-espace invariant et
!>       les valeurs de Ritz extraites de ce sous-espace sont
!>       REIG(i) + sqrt(-1)*IMEIG(i) et
!>       REIG(i) - sqrt(-1)*IMEIG(i).
!>       Les vecteurs propres correspondants sont
!>       Z(:,i) + sqrt(-1)*Z(:,i+1) et
!>       Z(:,i) - sqrt(-1)*Z(:,i+1), respectivement.
!>       || Z(:,i:i+1)||_F = 1.
!>    Si JOBZ == 'F', alors les descriptions ci-dessus s'appliquent aux
!>    colonnes de X(:,1:K)*W(1:K,1:K), où les colonnes
!>    de W(1:k,1:K) sont les vecteurs propres calculés du
!>    quotient de Rayleigh K-par-K. Les colonnes de W(1:K,1:K)
!>    sont structurées de manière similaire : Si IMEIG(i) == 0 alors
!>    X(:,1:K)*W(:,i) est un vecteur propre, et si IMEIG(i)>0
!>    alors X(:,1:K)*W(:,i)+sqrt(-1)*X(:,1:K)*W(:,i+1) et
!>         X(:,1:K)*W(:,i)-sqrt(-1)*X(:,1:K)*W(:,i+1)
!>    sont les vecteurs propres de LAMBDA(i), LAMBDA(i+1).
!>    Voir les descriptions de REIG, IMEIG, X et W.
!>

LDZ

!>    LDZ (entrée) INTEGER , LDZ >= M
!>    La dimension principale du tableau Z.
!>

RES

!>    RES (sortie) REAL(KIND=WP) Tableau N-par-1
!>    RES(1:K) contient les résidus des K paires de Ritz calculées.
!>    Si LAMBDA(i) est réelle, alors
!>       RES(i) = || A * Z(:,i) - LAMBDA(i)*Z(:,i))||_2.
!>    Si [LAMBDA(i), LAMBDA(i+1)] est une paire de conjugués complexes
!>    alors
!>    RES(i)=RES(i+1) = || A * Z(:,i:i+1) - Z(:,i:i+1) *B||_F
!>    où B = [ real(LAMBDA(i)) imag(LAMBDA(i)) ]
!>              [-imag(LAMBDA(i)) real(LAMBDA(i)) ].
!>    Il est vrai que
!>    RES(i)   = || A*ZC(:,i)   - LAMBDA(i)  *ZC(:,i)   ||_2
!>    RES(i+1) = || A*ZC(:,i+1) - LAMBDA(i+1)*ZC(:,i+1) ||_2
!>    où ZC(:,i)   =  Z(:,i) + sqrt(-1)*Z(:,i+1)
!>          ZC(:,i+1) =  Z(:,i) - sqrt(-1)*Z(:,i+1)
!>    Voir la description de REIG, IMEIG et Z.
!>

B

!>    B (sortie) REAL(KIND=WP) Tableau M-par-N.
!>    SI JOBF =='R', B(1:M,1:K) contient A*U(:,1:K), et peut
!>    être utilisé pour calculer les vecteurs affinés ; voir plus de
!>    détails dans les références fournies.
!>    Si JOBF == 'E', B(1:M,1;K) contient
!>    A*U(:,1:K)*W(1:K,1:K), qui sont les vecteurs issus du
!>    DMD exact, à l'échelle près par l'inverse des valeurs propres.
!>    Si JOBF =='N', alors B n'est pas référencé.
!>    Voir les descriptions de X, W, K.
!>

LDB
