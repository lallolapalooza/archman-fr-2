subroutine sgelsy (m, n, nrhs, a, lda, b, ldb, jpvt, rcond, rank, work, lwork, info)
SGELSY résout des systèmes surdéterminés ou sousdéterminés pour des matrices GE

Documentation de la fonction/sous-programme

sous-programme sgelsy (integer m, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, integer, dimension( * ) jpvt, real rcond, integer rank, real, dimension( * ) work, integer lwork, integer info)

SGELSY résout des systèmes surdéterminés ou sousdéterminés pour des matrices GE

Objectif:

!>
!> SGELSY calcule la solution de norme minimale d'un problème de moindres carrés linéaires réels :
!>     min || A * X - B ||
!> en utilisant une factorisation orthogonale complète de A. A est une matrice M-par-N
!> qui peut être de rang déficient.
!>
!> Plusieurs vecteurs second membre b et vecteurs solution x peuvent être
!> traités en un seul appel ; ils sont stockés comme colonnes de la matrice
!> second membre B de M-par-NRHS et de la matrice solution X de N-par-NRHS.
!>
!> La routine calcule d'abord une factorisation QR avec pivot de colonnes :
!>     A * P = Q * [ R11 R12 ]
!>                 [  0  R22 ]
!> avec R11 défini comme la plus grande sous-matrice principale dont le numéro de condition
!> estimé est inférieur à 1/RCOND. L'ordre de R11, RANK,
!> est le rang effectif de A.
!>
!> Ensuite, R22 est considéré comme négligeable, et R12 est annihilé
!> par des transformations orthogonales par la droite, arrivant à la
!> factorisation orthogonale complète :
!>    A * P = Q * [ T11 0 ] * Z
!>                [  0  0 ]
!> La solution de norme minimale est alors
!>    X = P * Z**T [ inv(T11)*Q1**T*B ]
!>                 [        0         ]
!> où Q1 est constitué des RANK premières colonnes de Q.
!>
!> Cette routine est essentiellement identique à la xGELSX originale, sauf
!> trois différences :
!>   o L'appel au sous-programme xGEQPF a été substitué par
!>     l'appel au sous-programme xGEQP3. Ce sous-programme est une version Blas-3
!>     de la factorisation QR avec pivot de colonnes.
!>   o La matrice B (second membre) est mise à jour avec Blas-3.
!>   o La permutation de la matrice B (second membre) est plus rapide et
!>     plus simple.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>          À l'entrée, la matrice A M-par-N.
!>          À la sortie, A a été écrasé par les détails de sa
!>          factorisation orthogonale complète.
!>

LDA

!>          LDA est INTEGER
!>          La dimension de tête du tableau A.  LDA >= max(1,M).
!>

B

!>          B est un tableau REAL, dimension (LDB,NRHS)
!>          À l'entrée, la matrice second membre B M-par-NRHS.
!>          À la sortie, la matrice solution X N-par-NRHS.
!>          Si M = 0 ou N = 0, B n'est pas référencé.
!>

LDB

!>          LDB est INTEGER
!>          La dimension de tête du tableau B. LDB >= max(1,M,N).
!>

JPVT

!>          JPVT est un tableau INTEGER, dimension (N)
!>          À l'entrée, si JPVT(i) .ne. 0, la i-ème colonne de A est permutée
!>          au début de AP, sinon la colonne i est une colonne libre.
!>          À la sortie, si JPVT(i) = k, alors la i-ème colonne de AP
!>          était la k-ème colonne de A.
!>

RCOND

!>          RCOND est REAL
!>          RCOND est utilisé pour déterminer le rang effectif de A, qui
!>          est défini comme l'ordre de la plus grande sous-matrice triangulaire
!>          principale R11 dans la factorisation QR avec pivotement de A,
!>          dont le numéro de condition estimé est < 1/RCOND.
!>

RANK

!>          RANK est INTEGER
!>          Le rang effectif de A, c'est-à-dire l'ordre de la sous-matrice
!>          R11.  Ceci est identique à l'ordre de la sous-matrice T11
!>          dans la factorisation orthogonale complète de A.
!>          Si NRHS = 0, RANK = 0 en sortie.
!>

WORK

!>          WORK est un tableau REAL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          La stratégie sans bloc nécessite que :
!>             LWORK >= MAX( MN+3*N+1, 2*MN+NRHS ),
!>          où MN = min( M, N ).
!>          L'algorithme par blocs nécessite que :
!>             LWORK >= MAX( MN+2*N+NB*(N+1), 2*MN+NB*NRHS ),
!>          où NB est une borne supérieure de la taille de bloc retournée
!>          par ILAENV pour les routines SGEQP3, STZRZF, STZRQF, SORMQR,
!>          et SORMRZ.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>          < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>
