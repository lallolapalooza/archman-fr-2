subroutine sgesvj (character*1 joba, character*1 jobu, character*1 jobv, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( n ) sva, integer mv, real, dimension( ldv, * ) v, integer ldv, real, dimension( lwork ) work, integer lwork, integer info)

SGESVJ

But :

!>
!> SGESVJ calcule la décomposition en valeurs singulières (SVD) d'une matrice réelle
!> M par N, où M >= N. La SVD de A est écrite comme
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^t,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> où SIGMA est une matrice diagonale N par N, U est une matrice orthonormée M par N,
!> et V est une matrice orthogonale N par N. Les éléments diagonaux
!> de SIGMA sont les valeurs singulières de A. Les colonnes de U et V sont les
!> vecteurs singuliers gauches et droits de A, respectivement.
!> SGESVJ peut parfois calculer des valeurs singulières très petites et leurs vecteurs singuliers beaucoup
!> plus précisément que d'autres routines SVD, voir ci-dessous dans Détails supplémentaires.
!>

Paramètres

JOBA 
!>          JOBA est CHARACTER*1
!>          Spécifie la structure de A.
!>          = 'L': La matrice d'entrée A est triangulaire inférieure ;
!>          = 'U': La matrice d'entrée A est triangulaire supérieure ;
!>          = 'G': La matrice d'entrée A est une matrice générale M par N, M >= N.
!>

JOBU

!>          JOBU est CHARACTER*1
!>          Spécifie si les vecteurs singuliers gauches doivent être calculés
!>          (colonnes de U) :
!>          = 'U': Les vecteurs singuliers gauches correspondant aux valeurs
!>                 singulières non nulles sont calculés et retournés dans les
!>                 colonnes principales de A. Voir plus de détails dans la description de A.
!>                 Le seuil d'orthogonalité numérique par défaut est défini à
!>                 environ TOL=CTOL*EPS, CTOL=SQRT(M), EPS=SLAMCH('E').
!>          = 'C': Analogue à JOBU='U', sauf que l'utilisateur peut contrôler le
!>                 niveau d'orthogonalité numérique des vecteurs singuliers gauches calculés.
!>                 TOL peut être défini à TOL = CTOL*EPS, où
!>                 CTOL est donné en entrée dans le tableau WORK.
!>                 Aucun CTOL inférieur à UN n'est autorisé. CTOL supérieur
!>                 à 1 / EPS n'a pas de sens. L'option 'C'
!>                 peut être utilisée si M*EPS est une orthogonalité satisfaisante
!>                 des vecteurs singuliers gauches calculés, donc CTOL=M pourrait
!>                 économiser quelques rotations de Jacobi.
!>                 Voir les descriptions de A et WORK(1).
!>          = 'N': La matrice U n'est pas calculée. Cependant, voir la
!>                 description de A.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          Spécifie si les vecteurs singuliers droits doivent être calculés, c'est-à-dire
!>          la matrice V :
!>          = 'V':  la matrice V est calculée et retournée dans le tableau V
!>          = 'A':  les rotations de Jacobi sont appliquées au tableau
!>                  MV par N V. En d'autres termes, la matrice des vecteurs
!>                  singuliers droits V n'est pas calculée explicitement ; elle est
!>                  appliquée à une matrice MV par N initialement stockée dans
!>                  les MV premières lignes de V.
!>          = 'N':  la matrice V n'est pas calculée et le tableau V n'est pas
!>                  référencé.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. 1/SLAMCH('E') > M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>          En entrée, la matrice M par N A.
!>          En sortie,
!>          Si JOBU = 'U' .OU. JOBU = 'C':
!>                 Si INFO = 0 :
!>                 Les RANKA colonnes orthonormées de U sont retournées dans les
!>                 RANKA colonnes principales du tableau A. Ici RANKA <= N
!>                 est le nombre de valeurs singulières calculées de A qui sont
!>                 au-dessus du seuil de sous-dépassement SLAMCH('S'). Les vecteurs singuliers
!>                 correspondant aux valeurs singulières sous-dépassées ou nulles
!>                 ne sont pas calculés. La valeur de RANKA est retournée
!>                 dans le tableau WORK comme RANKA=NINT(WORK(2)). Voir aussi les
!>                 descriptions de SVA et WORK. Les colonnes calculées de U
!>                 sont mutuellement numériquement orthogonales jusqu'à environ
!>                 TOL=SQRT(M)*EPS (par défaut) ; ou TOL=CTOL*EPS (JOBU = 'C'),
!>                 voir la description de JOBU.
!>                 Si INFO > 0,
!>                 la procédure SGESVJ n'a pas convergé dans le nombre donné
!>                 d'itérations (passes). Dans ce cas, les colonnes calculées de U
!>                 peuvent ne pas être orthogonales jusqu'à TOL. La sortie
!>                 U (stockée dans A), SIGMA (donnée par les valeurs singulières calculées dans
!>                 SVA(1:N)) et V est toujours une décomposition de la
!>                 matrice d'entrée A dans le sens où le résidu
!>                 ||A-SCALE*U*SIGMA*V^T||_2 / ||A||_2 est petit.
!>          Si JOBU = 'N':
!>                 Si INFO = 0 :
!>                 Notez que les vecteurs singuliers gauches sont 'gratuits' dans l'algorithme SVD Jacobi unidirectionnel. Cependant, si seules les
!>                 valeurs singulières sont nécessaires, le niveau d'orthogonalité numérique de U n'est pas un problème et les itérations sont
!>                 arrêtées lorsque les colonnes de la matrice itérée sont
!>                 numériquement orthogonales jusqu'à environ M*EPS. Ainsi,
!>                 à la sortie, A contient les colonnes de U mises à l'échelle avec les
!>                 valeurs singulières correspondantes.
!>                 Si INFO > 0 :
!>                 la procédure SGESVJ n'a pas convergé dans le nombre donné
!>                 d'itérations (passes).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

SVA

!>          SVA est un tableau REAL, dimension (N)
!>          En sortie,
!>          Si INFO = 0 :
!>          selon la valeur de SCALE = WORK(1), nous avons :
!>                 Si SCALE = ONE :
!>                 SVA(1:N) contient les valeurs singulières calculées de A.
!>                 Pendant le calcul, SVA contient les normes euclidiennes des colonnes
!>                 des matrices itérées dans le tableau A.
!>                 Si SCALE .NE. ONE :
!>                 Les valeurs singulières de A sont SCALE*SVA(1:N), et cette
!>                 représentation factorisée est due au fait que certaines des
!>                 valeurs singulières de A pourraient sous-dépasser ou sur-dépasser.
!>
!>          Si INFO > 0 :
!>          la procédure SGESVJ n'a pas convergé dans le nombre donné
!>          d'itérations (passes) et SCALE*SVA(1:N) peut ne pas être précise.
!>

MV

!>          MV est INTEGER
!>          Si JOBV = 'A', alors le produit des rotations de Jacobi dans SGESVJ
!>          est appliqué aux MV premières lignes de V. Voir la description de JOBV.
!>

V

!>          V est un tableau REAL, dimension (LDV,N)
!>          Si JOBV = 'V', alors V contient à la sortie la matrice N par N des
!>                         vecteurs singuliers droits ;
!>          Si JOBV = 'A', alors V contient le produit de la matrice des vecteurs
!>                         singuliers droits calculée et de la matrice initiale dans
!>                         le tableau V.
!>          Si JOBV = 'N', alors V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V, LDV >= 1.
!>          Si JOBV = 'V', alors LDV >= max(1,N).
!>          Si JOBV = 'A', alors LDV >= max(1,MV).
!>

WORK

!>          WORK est un tableau REAL, dimension (LWORK)
!>          Si JOBU = 'C', WORK(1) contient la valeur CTOL, voir la description de JOBU.
!>          WORK(2) contient le rang de la matrice A calculé.
!>          Lors de l'appel, WORK(1) peut être mis à zéro. Dans ce cas, la routine
!>          choisit une valeur par défaut pour CTOL.
!>          Les éléments restants de WORK sont utilisés comme espace de travail.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si LWORK = -1, alors le dimensionnement optimal de WORK est calculé.
!>          LWORK doit être au moins MAX(2, N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès.
!>          > 0 : Si INFO = i, la procédure SGESVJ n'a pas convergé en i itérations (passes).
!>

sgesvj(3) LAPACK

NAME

sgesvj - computes the singular value decomposition (SVD) of a real general rectangular matrix

SYNOPSIS

subroutine sgesvj(
  jobv, jobu, jobc, m, n, a, lda, sva, u, ldu, v, ldv, work, lwork, info)
character(len=1) :: jobv, jobu, jobc
integer :: m, n, lda, ldu, ldv, lwork, info
real, dimension(lda,*) :: a
real, dimension(*) :: sva, work
real, dimension(ldu,*) :: u
real, dimension(ldv,*) :: v

Function/Subroutine Documentation

Purpose:

The routine computes the Singular Value Decomposition (SVD) of a real M-by-N matrix A, as:

A = U * S * V**T

where S is an M-by-N matrix with non-negative diagonal elements s_i such that

s_1 >= s_2 >= ... >= s_min(m,n) >= 0,

U is an M-by-M orthogonal matrix, and V is an N-by-N orthogonal matrix.

V**T denotes the transpose of V.

The routine computes the singular values in the array SVA and optionally the left singular vectors in U and the right singular vectors in V.

This routine uses a block Jacobi SVD algorithm, which is suitable for the accurate computation of SVD, especially for ill-conditioned matrices.

Arguments:

JOBV

character(len=1) :: JOBV

Specifies whether to compute the vectors V.
= 'N': Do not compute V.
= 'A': Compute V.

JOBU

character(len=1) :: JOBU

Specifies whether to compute the vectors U.
= 'N': Do not compute U.
= 'A': Compute U.

JOBC

character(len=1) :: JOBC

Specifies whether to compute the threshold for convergence.
= 'N': no threshold is computed.
= 'C': compute the threshold CTOL for convergence.

M

integer :: M

The number of rows of A. M >= 0.

N

integer :: N

The number of columns of A. N >= 0.

A

real, dimension(lda,*) :: A

The M-by-N matrix A. On exit, A is overwritten by the matrices U and V, or by the Jacobi rotation information. If JOBU = 'A' and JOBV = 'A', A contains U on its left as u and V on its right as V. More precisely, if M >= N, A contains the matrix U, and V is stored in the lower triangle of A. If M < N, A contains U, and V is stored in the upper triangle of A. The diagonal elements of S are stored in SVA.

LDA

integer :: LDA

The leading dimension of the array A. LDA >= max(1,M).

SVA

real, dimension(*) :: SVA

The array SVA has dimension max(1,min(M,N)). On exit, SVA(i) contains the i-th singular value of A. The singular values are ordered in descending order.

U

real, dimension(ldu,*) :: U

The M-by-M orthogonal matrix U. If JOBU = 'N', U is not computed.

LDU

integer :: LDU

The leading dimension of the array U. LDU >= max(1,M) if JOBU = 'A'.

V

real, dimension(ldv,*) :: V

The N-by-N orthogonal matrix V. If JOBV = 'N', V is not computed.

LDV

integer :: LDV

The leading dimension of the array V. LDV >= max(1,N) if JOBV = 'A'.

WORK

real, dimension(*) :: WORK

WORK is a REAL array, dimension (MAX(1,LWORK))

On entry,

If JOBU = 'C' :

WORK(1) = CTOL, where CTOL defines the threshold for convergence. The process stops if all columns of A are mutually orthogonal up to CTOL*EPS, EPS=SLAMCH('E'). It is required that CTOL >= ONE, i.e. it is not allowed to force the routine to obtain orthogonality below EPSILON.

On exit,

WORK(1) = SCALE is the scaling factor such that SCALE*SVA(1:N) are the computed singular values of A. (See description of SVA().)

WORK(2) = NINT(WORK(2)) is the number of the computed nonzero singular values.

WORK(3) = NINT(WORK(3)) is the number of the computed singular values that are larger than the underflow threshold.

WORK(4) = NINT(WORK(4)) is the number of sweeps of Jacobi rotations needed for numerical convergence.

WORK(5) = max_{i.NE.j} |COS(A(:,i),A(:,j))| in the last sweep. This is useful information in cases when SGESVJ did not converge, as it can be used to estimate whether the output is still useful and for post festum analysis.

WORK(6) = the largest absolute value over all sines of the Jacobi rotation angles in the last sweep. It can be useful for a post festum analysis.

LWORK

integer :: LWORK

Length of WORK. LWORK >= 1, if MIN(M,N) = 0, and LWORK >= MAX(6,M+N), otherwise.

If on entry LWORK = -1, then a workspace query is assumed and no computation is done; WORK(1) is set to the minial (and optimal) length of WORK.

INFO

integer :: INFO

= 0: successful exit.

< 0: if INFO = -i, then the i-th argument had an illegal value

> 0: SGESVJ did not converge in the maximal allowed number (30) of sweeps. The output may still be useful. See the description of WORK.

Further Details:

The orthogonal N-by-N matrix V is obtained as a product of Jacobi plane rotations. The rotations are implemented as fast scaled rotations of Anda and Park [1]. In the case of underflow of the Jacobi angle, a modified Jacobi transformation of Drmac [4] is used. Pivot strategy uses column interchanges of de Rijk [2]. The relative accuracy of the computed singular values and the accuracy of the computed singular vectors (in angle metric) is as guaranteed by the theory of Demmel and Veselic [3]. The condition number that determines the accuracy in the full rank case is essentially min_{D=diag} kappa(A*D), where kappa(.) is the spectral condition number. The best performance of this Jacobi SVD procedure is achieved if used in an accelerated version of Drmac and Veselic [5,6], and it is the kernel routine in the SIGMA library [7]. Some tuning parameters (marked with [TP]) are available for the implementer.
The computational range for the nonzero singular values is the machine number interval ( UNDERFLOW , OVERFLOW ). In extreme cases, even denormalized singular values can be computed with the corresponding gradual loss of accurate digits.
