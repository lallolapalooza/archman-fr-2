DESCRIPTION

sg_vector_create() alloue et initialise un nouveau vecteur statgrab avec initial_used éléments prêts à être utilisés. L'espace pour alloc_count éléments est initialement alloué (pour éviter trop d'appels à realloc() lors des appels ultérieurs à sg_vector_resize()). La valeur de block_size doit être une puissance de 2, elle est arrondie à la puissance de 2 supérieure si ce n'est pas le cas. Si alloc_count n'est pas un multiple de block_size, il est arrondi au multiple supérieur de block_size. La fonction renvoie un pointeur vers le vecteur nouvellement créé.

sg_vector_clear() détruit tous les éléments contenus dans le vecteur donné. Contrairement à sg_vector_resize( x, 0 ), la taille allouée du vecteur reste inchangée.

sg_vector_resize() augmente ou diminue le nombre d'éléments alloués dans le vecteur spécifié. Le nombre d'éléments alloués est toujours un multiple du paramètre d'initialisation block_size. Dans le cas spécial où sg_vector_resize() est appelé avec 0 comme argument new_count, le vecteur est libéré après la destruction de tous ses éléments. La fonction renvoie le pointeur vers le vecteur redimensionné.

sg_vector_free() détruit tous les éléments du vecteur et désalloue le stockage appartenant au vecteur donné.

sg_vector_clone() clone tous les éléments du vecteur donné dans un nouveau vecteur créé avec la même spécification que celui référencé. La fonction renvoie un pointeur vers le vecteur cloné.

sg_vector_clone_into() clone tous les éléments du vecteur source donné dans le vecteur cible donné. Le vecteur cible doit être créé pour le même type de données d'élément que le vecteur source. La fonction renvoie un code d'erreur différent de SG_ERROR_NONE si quelque chose s'est mal passé.

sg_vector_compute_diff() calcule un vecteur de différence entre le vecteur contenant les statistiques actuelles et un autre vecteur contenant des statistiques plus anciennes. Si un élément existe dans le vecteur actuel mais pas dans l'autre, il est cloné dans le vecteur résultat. Si un élément existe uniquement dans le vecteur opposé, il n'apparaît pas dans le vecteur cible. sg_vector_compute_diff() renvoie un code d'erreur différent de SG_ERROR_NONE si quelque chose s'est mal passé.

sg_prove_vector() prouve si un pointeur vers un vecteur pointe réellement vers un vecteur. Dans le cas où le pointeur de vecteur donné pointe vers des données corrompues, le programme est arrêté. Lorsque sg_prove_vector() revient, il renvoie SG_ERROR_NONE.

sg_get_nelements() renvoie le nombre d'éléments que la zone de données donnée, englobée par un vecteur statgrab, contient. L'en-tête du vecteur est calculé en interne à partir du pointeur donné vers le premier élément du vecteur.

sg_free_stats_buf() libère le vecteur englobant la zone de données donnée.

NOTES

À l'exception de sg_get_nelements() et sg_free_stats_buf(), aucune des fonctions ci-dessus ne peut être appelée depuis l'extérieur des sources de libstatgrab. Les structures et les API documentées peuvent changer sans préavis. La description de toutes les autres API est destinée à être lue uniquement par les développeurs de libstatgrab.

Chaque vecteur est créé à partir de deux éléments : les informations du vecteur et la liste des éléments :

template <class T, class Impl>
struct sg_vector {
        size_t used_count;
        size_t alloc_count;
        size_t block_shift;
        Impl vector_implementation;
        T elements[alloc_count];
};

Bien entendu, ce n'est pas du C valide, donc la solution a été d'être astucieux :

typedef struct sg_vector {
	size_t used_count;
	size_t alloc_count;
	size_t block_shift;
	struct sg_vector_init_info info;
} sg_vector;
struct sg_vector_size_helper {
	struct sg_vector v;
	long long ll;
};
#define VECTOR_SIZE offsetof(struct sg_vector_size_helper,ll)
/* Renvoie le pointeur de données d'un vecteur */
#define VECTOR_DATA(vector) \
	(vector ? (void *)(((char *)vector)+VECTOR_SIZE) : NULL)
#define VECTOR_ADDR_ARITH(ptr) \
	(sg_vector *)(((char *)(ptr))-VECTOR_SIZE)
/* Renvoie le vecteur pour des données */
#define VECTOR_ADDRESS(ptr) \
	((ptr) ? (SG_ERROR_NONE == sg_prove_vector(VECTOR_ADDR_ARITH(ptr)) ? VECTOR_ADDR_ARITH(ptr) : NULL ) : NULL)

Cela permet également aux fonctions utilisateur telles que sg_get_nelements() et sg_free_stats_buf() de passer facilement de la structure du vecteur au contenu.

LA STRUCTURE DE SPÉCIALISATION DU VECTEUR

Comme mentionné, l'implémentation du vecteur utilise des stratégies du concept de programmation orientée objet nommé "polymorphisme". Un vecteur est décrit par un petit objet contenant des attributs inhérents comme la taille des éléments et un ensemble de "méthodes virtuelles" pour effectuer des tâches liées aux éléments, comme l'initialisation ou la destruction d'éléments.

typedef void (*vector_init_function)(void *item);
typedef sg_error (*vector_copy_function)(const void *src, void *dst);
typedef sg_error (*vector_compute_diff_function)(void *dst, const void *src);
typedef int (*vector_compare_function)(const void *a, const void *b);
typedef void (*vector_destroy_function)(void *item);
struct sg_vector_init_info {
        size_t item_size;
        vector_init_function init_fn;
        vector_copy_function copy_fn;
        vector_compute_diff_function compute_diff_fn;
        vector_compare_function compare_fn;
        vector_destroy_function destroy_fn;
};

Les instances de struct sg_vector_init_info sont conceptuellement initialisées statiquement en utilisant soit la macro préprocesseur VECTOR_INIT_INFO_FULL_INIT(type) soit VECTOR_INIT_INFO_EMPTY_INIT(type). Voici quelques exemples pour démontrer comment cela est censé fonctionner :

Initialisation de la description du vecteur de statistiques CPU

VECTOR_INIT_INFO_EMPTY_INIT(sg_cpu_stats);

static void sg_os_stats_item_init(sg_os_stats *d);
static void sg_os_stats_item_destroy(sg_os_stats *d);
#define sg_os_stats_item_copy NULL
#define sg_os_stats_item_compute_diff NULL
#define sg_os_stats_item_compare NULL

static void sg_disk_io_stats_item_init(sg_disk_io_stats *d);

DESCRIPTION

These functions are macro definitions that are built upon the sg_vector functions.

The argument types are defined in the sg_vector.h header file.

The function prototypes are defined above. The macros are defined below.

VECTOR_CREATE

(struct sg_vector *vector, size_t alloc_count, identifier type);

This macro calls sg_vector_create().

VECTOR_CLEAR

(struct sg_vector *vector);

This macro calls sg_vector_clear().

VECTOR_CREATE_OR_RESIZE

(struct sg_vector *vector, size_t new_count, identifier type);

This macro calls sg_vector_create() when the given vector pointer points to NULL, or sg_vector_resize() otherwise. The result of the appropriate function is returned.

VECTOR_UPDATE

(struct sg_vector **vectorptr, size_t new_count, datatype *data, identifier datatype);

This macro calls VECTOR_CREATE_OR_RESIZE() and sets data to the first element of the resulting vector when a non-NULL pointer got, to NULL otherwise. When VECTOR_CREATE_OR_RESIZE() returns a NULL pointer and new_count is not equal to 0 (zero), the instructions from the macro VECTOR_UPDATE_ERROR_CLEANUP are executed to cleanup before returning from current subroutine with the error which has been occurred.

VECTOR_ITEM_COUNT

(struct sg_vector *vector);

This macro returns 0 for a non-existing vector (vector == 0) and the number of containing elements otherwise.

NOTES

The macros defined below are for convenience and to simplify common operations.

The argument types for the macros are defined in the <statgrab.h> header file.

VECTOR_CREATE_OR_RESIZE

(struct sg_vector *vector, size_t new_count, identifier type);

VECTOR_CREATE() calls sg_vector_create() with alloc_count = block_size and initial_used = 0 using the vector specialisation type##_vector_init_info.

VECTOR_CLEAR() simply calls sg_vector_clear(). This macro exists only for conformity.

VECTOR_CREATE_OR_RESIZE() calls sg_vector_create() when the given vector pointer points to NULL or sg_vector_resize() otherwise. The result of the appropriate function is returned.

VECTOR_UPDATE() calls VECTOR_CREATE_OR_RESIZE() and sets data to the first element of the resulting vector when a non-NULL pointer got, to NULL otherwise. When VECTOR_CREATE_OR_RESIZE() returns a NULL pointer and new_count is not equal to 0 (zero), the instructions from the macro VECTOR_UPDATE_ERROR_CLEANUP are executed to cleanup before returning from current subroutine with the error which has been occurred.

VECTOR_ITEM_COUNT() returns 0 for a non-existing vector (vector == 0) and the number of containing elements otherwise.

RETURN VALUES

Beside error codes, the return values, if any, are always a pointer to vector structures (struct sg_vector *).
