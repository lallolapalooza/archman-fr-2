sous-programme sgeqrfp (integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SGEQRFP

But:

!>
!> SGEQR2P calcule une factorisation QR d'une matrice A réelle M-par-N :
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> où :
!>
!>    Q est une matrice orthogonale M-par-M ;
!>    R est une matrice triangulaire supérieure N-par-N avec des entrées diagonales non négatives ;
!>    0 est une matrice nulle (M-N)-par-N, si M > N.
!>
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          En entrée, la matrice A de taille M-par-N.
!>          En sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice trapézoïdale supérieure R de taille min(M,N)-par-N (R est
!>          triangulaire supérieure si m >= n). Les entrées diagonales de R
!>          sont non négatives ; les éléments en dessous de la diagonale,
!>          avec le tableau TAU, représentent la matrice orthogonale Q sous forme de produit
!>          de min(m,n) réflexions élémentaires (voir Détails supplémentaires).
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau REEL, de dimension (min(M,N))
!>          Les facteurs scalaires des réflexions élémentaires (voir Détails supplémentaires).
!>

WORK

!>          WORK est un tableau REEL, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, et LWORK >= N, sinon.
!>          Pour des performances optimales, LWORK >= N*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires:

!>
!>  La matrice Q est représentée comme un produit de réflexions élémentaires
!>
!>     Q = H(1) H(2) . . . H(k), où k = min(m,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**T
!>
!>  où tau est un scalaire réel, et v est un vecteur réel avec
!>  v(1:i-1) = 0 et v(i) = 1 ; v(i+1:m) est stocké en sortie dans A(i+1:m,i),
!!>  et tau dans TAU(i).
!>
!> Voir le document de travail Lapack 203 pour les détails.
!>
