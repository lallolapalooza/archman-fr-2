Documentation de la fonction/sous-routine

sous-routine sgrqts (integer m, integer p, integer n, real, dimension( lda, * ) a, real, dimension( lda, * ) af, real, dimension( lda, * ) q, real, dimension( lda, * ) r, integer lda, real, dimension( * ) taua, real, dimension( ldb, * ) b, real, dimension( ldb, * ) bf, real, dimension( ldb, * ) z, real, dimension( ldb, * ) t, real, dimension( ldb, * )bwk, integer ldb, real, dimension( * ) taub, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( 4 ) result)

SGRQTS

But :

!>
!> SGRQTS teste SGGRQF, qui calcule la factorisation GRQ de la matrice M-par-N A
!> et de la matrice P-par-N B : A = R*Q et B = Z*T*Q.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

P

!>          P est un entier
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!>

A

!>          A est un tableau de réels, dimension (LDA,N)
!>          La matrice A de taille M-par-N.
!>

AF

!>          AF est un tableau de réels, dimension (LDA,N)
!>          Détails de la factorisation GRQ de A et B, tels que retournés
!>          par SGGRQF, voir SGGRQF pour plus de détails.
!>

Q

!>          Q est un tableau de réels, dimension (LDA,N)
!>          La matrice orthogonale Q de taille N-par-N.
!>

R

!>          R est un tableau de réels, dimension (LDA,MAX(M,N))
!>

LDA

!>          LDA est un entier
!>          La dimension principale des tableaux A, AF, R et Q.
!>          LDA >= max(M,N).
!>

TAUA

!>          TAUA est un tableau de réels, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires, tels que retournés
!>          par SGGQRC.
!>

B

!>          B est un tableau de réels, dimension (LDB,N)
!>          À l'entrée, la matrice A de taille P-par-N.
!>

BF

!>          BF est un tableau de réels, dimension (LDB,N)
!>          Détails de la factorisation GQR de A et B, tels que retournés
!>          par SGGRQF, voir SGGRQF pour plus de détails.
!>

Z

!>          Z est un tableau de réels, dimension (LDB,P)
!>          La matrice orthogonale Z de taille P-par-P.
!>

T

!>          T est un tableau de réels, dimension (LDB,max(P,N))
!>

BWK

!>          BWK est un tableau de réels, dimension (LDB,N)
!>

LDB

!>          LDB est un entier
!>          La dimension principale des tableaux B, BF, Z et T.
!>          LDB >= max(P,N).
!>

TAUB

!>          TAUB est un tableau de réels, dimension (min(P,N))
!>          Les facteurs scalaires des réflecteurs élémentaires, tels que retournés
!>          par SGGRQF.
!>

WORK

!>          WORK est un tableau de réels, dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>          La dimension du tableau WORK, LWORK >= max(M,P,N)**2.
!>

RWORK

!>          RWORK est un tableau de réels, dimension (M)
!>

RESULT

!>          RESULT est un tableau de réels, dimension (4)
!>          Les rapports de test :
!>            RESULT(1) = norm( R - A*Q' ) / ( MAX(M,N)*norm(A)*ULP)
!>            RESULT(2) = norm( T*Q - Z'*B ) / (MAX(P,N)*norm(B)*ULP)
!>            RESULT(3) = norm( I - Q'*Q ) / ( N*ULP )
!>            RESULT(4) = norm( I - Z'*Z ) / ( P*ULP )
!>
