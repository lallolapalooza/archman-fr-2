NOM

sg_safte - accéder aux périphériques SAF-TE (SCSI Accessed Fault-Tolerant Enclosure)

SYNTAXE

sg_safte [--config] [--devstatus] [--encstatus] [--flags] [--help] [--hex] [--insertions] [--raw] [--usage] [--verbose] [--version] PÉRIPHÉRIQUE

DESCRIPTION

Récupère l'état de l'enceinte (via une commande SCSI READ BUFFER). Le PÉRIPHÉRIQUE doit être un périphérique SAF-TE qui peut être un contrôleur de baie de stockage (type de périphérique périphérique INQUIRY 0xc) ou un périphérique processeur générique (type de périphérique périphérique INQUIRY 0x3).

Si aucune option n'est donnée (seulement l'argument PÉRIPHÉRIQUE), alors l'état global de l'enceinte tel que rapporté par l'option --config est affiché.

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également. Les options sont arrangées par ordre alphabétique basé sur le nom de l'option longue.

-c, --config
émettra une commande Read Enclosure Configuration (READ BUFFER ID 0) vers le périphérique, qui retourne une liste des ressources matérielles de l'enceinte.
-d, --devstatus
émettra une commande Read Device Slot Status (READ BUFFER ID 4) vers le périphérique, qui retourne des informations sur l'état actuel de chaque disque ou slot.
-s, --encstatus
émettra une commande Read Enclosure Status (READ BUFFER ID 1) vers le périphérique, qui retourne l'état opérationnel des composants.
-f, --flags
émettra une commande Read Global Flags (READ BUFFER ID 5) vers le périphérique, qui lit le dernier état des drapeaux globaux du périphérique processeur RAID.
-h, --help
affiche le message d'utilisation puis quitte.
-H, --hex
affiche la réponse à une commande READ BUFFER en hexadécimal ASCII sur la sortie standard. Si utilisé une fois, affiche la réponse de la première commande READ BUFFER (c'est-à-dire avec buffer_id=0). Ce devrait être la configuration de l'enceinte. Si utilisé deux fois (ou plus), les réponses aux commandes READ BUFFER subséquentes sont affichées.
-i, --insertions
émettra une commande Read Device Insertions (READ BUFFER ID 3) vers le périphérique, qui retourne des informations sur le nombre de fois où des périphériques ont été insérés pendant que le système RAID était alimenté.
-r, --raw
affiche la réponse à une commande READ BUFFER en binaire sur la sortie standard. Si utilisé une fois, affiche la réponse de la première commande READ BUFFER (c'est-à-dire avec buffer_id=0). Ce devrait être la configuration de l'enceinte. Si utilisé deux fois (ou plus), les réponses aux commandes READ BUFFER subséquentes sont affichées.
-u, --usage
émettra une commande Read Usage Statistics (READ BUFFER ID 2) vers le périphérique, qui retourne des informations sur le temps d'utilisation total et le nombre de cycles d'alimentation du périphérique RAID.
-v, --verbose
augmente le niveau de verbosité (c'est-à-dire les messages de débogage).
-V, --version
affiche la chaîne de version puis quitte.

NOTES

Cette implémentation est basée sur le document d'examen intermédiaire daté du 19970414 et nommé "SR041497.pdf". Elle est donc assez ancienne. Intel et nStor en sont les auteurs. Intel propose une archive zip contenant ce document et des documents connexes dans la section "SAF-TE: SCSI Accessed Fault Tolerant Enclosures Interface Specification" de cette page :

https://www.intel.com/content/www/us/en/servers/ipmi/ipmi-technical-resources.html

Des fonctionnalités similaires sont fournies par les périphériques SES (SCSI Enclosure Services) de SPC-4 (type de périphérique périphérique 0xd), qui peuvent être interrogés avec l'utilitaire sg_ses.

EXEMPLES

Pour afficher la configuration :


sg_safte /dev/sg1

Pour afficher l'état des slots de périphériques :


sg_safte --devstatus /dev/sg1

STATUT DE SORTIE

Le statut de sortie de sg_safte est 0 en cas de succès. Sinon, consultez la page de manuel sg3_utils(8).
