sous-routine sgbrfs (caractère trans, entier n, entier kl, entier ku, entier nrhs, réel, dimension( ldab, * ) ab, entier ldab, réel, dimension( ldafb, * ) afb, entier ldafb, entier, dimension( * ) ipiv, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( ldx, * ) x, entier ldx, réel, dimension( * ) ferr, réel, dimension( * ) berr, réel, dimension( * ) work, entier, dimension( * ) iwork, entier info)

SGBRFS

But:

!>
!> SGBRFS améliore la solution calculée d'un système d'équations linéaires
!> lorsque la matrice des coefficients est bande, et fournit des bornes d'erreur et
!> des estimations d'erreur arrière pour la solution.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations:
!>          = 'N':  A * X = B     (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Transposée conjuguée = Transposée)
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

KL

!>          KL est ENTIER
!>          Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est ENTIER
!>          Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est tableau REAL, dimension (LDAB,N)
!>          La matrice bande originale A, stockée dans les lignes 1 à KL+KU+1.
!>          La j-ème colonne de A est stockée dans la j-ème colonne du
!>          tableau AB comme suit:
!>          AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku)<=i<=min(n,j+kl).
!>

LDAB

!>          LDAB est ENTIER
!>          La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est tableau REAL, dimension (LDAFB,N)
!>          Détails de la factorisation LU de la matrice bande A, tels que
!>          calculés par SGBTRF. U est stockée comme une matrice bande triangulaire
!>          supérieure avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1, et
!>          les multiplicateurs utilisés lors de la factorisation sont stockés dans
!>          les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAFB

!>          LDAFB est ENTIER
!>          La dimension principale du tableau AFB.  LDAFB >= 2*KL*KU+1.
!>

IPIV

!>          IPIV est tableau ENTIER, dimension (N)
!>          Les indices de pivot de SGBTRF; pour 1<=i<=N, la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

B

!>          B est tableau REAL, dimension (LDB,NRHS)
!>          La matrice des membres de droite B.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est tableau REAL, dimension (LDX,NRHS)
!>          En entrée, la matrice solution X, telle que calculée par SGBTRS.
!>          En sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

FERR

!>          FERR est tableau REAL, dimension (NRHS)
!>          La borne d'erreur directe estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j). L'estimation est aussi fiable que
!>          l'estimation de RCOND, et est presque toujours une légère
!>          sur-estimation de l'erreur réelle.
!>

BERR

!>          BERR est tableau REAL, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire le plus petit changement relatif dans
!>          n'importe quel élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est tableau REAL, dimension (3*N)
!>

IWORK

!>          IWORK est tableau ENTIER, dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Paramètres internes:

!>  ITMAX est le nombre maximum d'étapes de raffinement itératif.
!>
