SG(1) Commandes utilisateur SG(1)

NOM

sg - exécute une commande avec un identifiant de groupe différent

SYNTAXE

sg [-] [groupe [-c ] commande]

DESCRIPTION

La commande sg fonctionne de manière similaire à newgrp mais accepte une commande. La commande sera exécutée avec le shell /bin/sh. Avec la plupart des shells que vous pouvez utiliser pour exécuter sg, vous devez entourer les commandes composées de plusieurs mots par des guillemets. Une autre différence entre newgrp et sg est que certains shells traitent newgrp de manière spéciale, en se remplaçant par une nouvelle instance d'un shell que newgrp crée. Cela ne se produit pas avec sg, donc à la sortie d'une commande sg, vous êtes ramené à votre identifiant de groupe précédent.

CONFIGURATION

Les variables de configuration suivantes dans /etc/login.defs modifient le comportement de cet outil :

SYSLOG_SG_ENAB (booléen)

Active la journalisation "syslog" de l'activité de sg.
