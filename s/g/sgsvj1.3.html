sous-programme sgsvj1 (character*1 jobv, integer m, integer n, integer n1, real, dimension( lda, * ) a, integer lda, real, dimension( n ) d, real, dimension( n ) sva, integer mv, real, dimension( ldv, * ) v, integer ldv, real eps, real sfmin, real tol, integer nsweep, real, dimension( lwork ) work, integer lwork, integer info)

SGSVJ1 pré-processeur pour la routine sgesvj, applique des rotations de Jacobi ciblant seulement des pivots particuliers.

Objectif :

!>
!> SGSVJ1 est appelée depuis SGESVJ comme pré-processeur et c'est son objectif principal. Elle applique des rotations de Jacobi de la même manière que SGESVJ, mais elle cible seulement des pivots particuliers et ne vérifie pas la convergence (critère d'arrêt). Quelques paramètres d'ajustement (marqués par [TP]) sont disponibles pour l'implémenteur.
!>
!> Détails supplémentaires
!> ~~~~~~~~~~~~~~~~~~~
!> SGSVJ1 applique quelques balayages de rotations de Jacobi dans l'espace des colonnes de la matrice d'entrée M par N, A. Les paires de pivots sont prises du bloc hors-diagonale (1,2) dans la matrice de Gram correspondante N par N, A^T * A. Les entrées de bloc (tuiles) du bloc hors-diagonale (1,2) sont marquées par les [x] dans le schéma suivant :
!>
!>    | *  *  * [x] [x] [x]|
!>    | *  *  * [x] [x] [x]|    Balayage ligne par ligne dans les blocs [x] nblr par nblc.
!>    | *  *  * [x] [x] [x]|    Pivots ligne-cycliques à l'intérieur de chaque bloc [x].
!>    |[x] [x] [x] *  *  * |
!>    |[x] [x] [x] *  *  * |
!>    |[x] [x] [x] *  *  * |
!>
!> En termes de colonnes de A, les N1 premières colonnes sont pivotées 'contre' les N-N1 colonnes restantes, essayant d'augmenter l'angle entre les sous-espaces correspondants. Le bloc hors-diagonale est N1 par (N-N1) et il est tuilé en utilisant des tuiles quadratiques de côté KBL. Ici, KBL est un paramètre d'ajustement. Le nombre de balayages est donné par NSWEEP et le seuil d'orthogonalité est donné par TOL.
!>

Paramètres

JOBV 
!>          JOBV est CHARACTER*1
!>          Spécifie si la sortie de cette procédure est utilisée
!>          pour calculer la matrice V :
!>          = 'V' : le produit des rotations de Jacobi est accumulé
!>                 en post-multipliant le tableau N par N, V.
!>                (Voir la description de V.)
!>          = 'A' : le produit des rotations de Jacobi est accumulé
!>                 en post-multipliant le tableau MV par N, V.
!>                (Voir les descriptions de MV et V.)
!>          = 'N' : les rotations de Jacobi ne sont pas accumulées.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!>

N1

!>          N1 est INTEGER
!>          N1 spécifie la partition du bloc 2x2, les N1 premières colonnes sont
!>          pivotées 'contre' les N-N1 colonnes restantes de A.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>          À l'entrée, la matrice M par N A, telle que A*diag(D) représente
!>          la matrice d'entrée.
!>          À la sortie,
!>          A_sortie * D_sortie représente la matrice d'entrée A*diag(D)
!>          post-multipliée par une séquence de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de balayages sont donnés dans
!>          TOL et NSWEEP, respectivement.
!>          (Voir les descriptions de N1, D, TOL et NSWEEP.)
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

D

!>          D est un tableau REAL, dimension (N)
!>          Le tableau D accumule les facteurs d'échelle des rotations de Jacobi rapides et mises à l'échelle.
!>          À l'entrée, A*diag(D) représente la matrice d'entrée.
!>          À la sortie, A_sortie*diag(D_sortie) représente la matrice d'entrée
!>          post-multipliée par une séquence de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de balayages sont donnés dans
!>          TOL et NSWEEP, respectivement.
!>          (Voir les descriptions de N1, A, TOL et NSWEEP.)
!>

SVA

!>          SVA est un tableau REAL, dimension (N)
!>          À l'entrée, SVA contient les normes euclidiennes des colonnes de
!>          la matrice A*diag(D).
!>          À la sortie, SVA contient les normes euclidiennes des colonnes de
!>          la matrice de sortie*diag(D_sortie).
!>

MV

!>          MV est INTEGER
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'N',   alors MV n'est pas référencé.
!>

V

!>          V est un tableau REAL, dimension (LDV,N)
!>          Si JOBV = 'V', alors N lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'N',   alors V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V,  LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!>

EPS

!>          EPS est REAL
!>          EPS = SLAMCH('Epsilon')
!>

SFMIN

!>          SFMIN est REAL
!>          SFMIN = SLAMCH('Safe Minimum')
!>

TOL

!>          TOL est REAL
!>          TOL est le seuil pour les rotations de Jacobi. Pour une paire
!>          A(:,p), A(:,q) de colonnes de pivot, la rotation de Jacobi est
!>          appliquée seulement si ABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!>

NSWEEP

!>          NSWEEP est INTEGER
!>          NSWEEP est le nombre de balayages de rotations de Jacobi à effectuer.
!>

WORK

!>          WORK est un tableau REAL, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          LWORK est la dimension de WORK. LWORK >= M.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale.
!>
