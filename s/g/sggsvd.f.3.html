sous-programme sggsvd (character jobu, character jobv, character jobq, integer m, integer n, integer p, integer k, integer l, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) alpha, real, dimension( * ) beta, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldv, * ) v, integer ldv, real, dimension( ldq, * ) q, integer ldq, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SGGSVD calcule la décomposition en valeurs singulières généralisée (GSVD) d'une matrice réelle M par N, A, et d'une matrice réelle P par N, B :

U**T*A*Q = D1*( 0 R ), V**T*B*Q = D2*( 0 R )

où U, V et Q sont des matrices orthogonales.

Soit K+L = le rang numérique effectif de la matrice (A**T,B**T)**T, alors R est une matrice triangulaire supérieure non singulière de (K+L)x(K+L), D1 et D2 sont des matrices M x (K+L) et P x (K+L) de la forme suivante, respectivement :

Si M-K-L >= 0,

K L

D1 = K ( I 0 )

L ( 0 C )

M-K-L ( 0 0 )

K L

D2 = L ( 0 S )

P-L ( 0 0 )

N-K-L K L

( 0 R ) = K ( 0 R11 R12 )

L ( 0 0 R22 )

où

C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),

S = diag( BETA(K+1), ... , BETA(K+L) ),

C**2 + S**2 = I.

R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.

Si M-K-L < 0,

K M-K K+L-M

D1 = K ( I 0 0 )

M-K ( 0 C 0 )

K M-K K+L-M

D2 = M-K ( 0 S 0 )

K+L-M ( 0 0 I )

P-L ( 0 0 0 )

N-K-L K M-K K+L-M

( 0 R ) = K ( 0 R11 R12 R13 )

M-K ( 0 0 R22 R23 )

K+L-M ( 0 0 0 R33 )

où

C = diag( ALPHA(K+1), ... , ALPHA(M) ),

S = diag( BETA(K+1), ... , BETA(M) ),

C**2 + S**2 = I.

(R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N), et R33 est stocké

( 0 R22 R23 )

dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.

La routine calcule C, S, R, et éventuellement les matrices de transformation orthogonales U, V et Q.

En particulier, si B est une matrice carrée non singulière N x N, alors la GSVD de A et B donne implicitement la SVD de A*inv(B) :

A*inv(B) = U*(D1*inv(D2))*V**T.

Si ( A**T,B**T)**T a des colonnes orthonormées, alors la GSVD de A et B est aussi égale à la décomposition CS de A et B. De plus, la GSVD peut être utilisée pour dériver la solution du problème aux valeurs propres :

A**T*A x = lambda* B**T*B x.

Dans certaines littératures, la GSVD de A et B est présentée sous la forme

U**T*A*X = ( 0 D1 ), V**T*B*X = ( 0 D2 )

où U et V sont orthogonales et X est non singulière, D1 et D2 sont ``diagonales''. L'ancienne forme de GSVD peut être convertie à la forme ultérieure en prenant la matrice non singulière X comme

X = Q*( I 0 )

( 0 inv(R) ).

NAME

sggsvd - Generalized singular value decomposition

SYNOPSIS

       $                   TOLA, TOLB, K, L, U, LDU, V, LDV, WORK,
       $                   IWORK, INFO )
Authors:
Univ. of Tennessee
Univ. of California Berkeley
Univ. of Colorado Denver
NAG Ltd.
Contributors:
Ming Gu and Huan Ren, Computer Science Division, University of California at Berkeley, USA

Description:

SGGsvd computes the generalized singular value decomposition (GSVD) of two real upper trapezoidal matrices X and Y, of dimensions M-by-N and P-by-N, respectively.

The GSVD is defined by the orthogonal matrices U and V and the nonnegative diagonal matrices (with possible k + l diagonal entries) S1 and S2 such that

    
    X = U S1 VT
    
    
    Y = V S2 VT

where

    
    S1 = ( Ik  0  0 )
               ( 0  D1  0 )
               ( 0  0  0 )
    
    
    S2 = ( 0  0  0 )
               ( 0  D2  0 )
               ( 0  0  Il )

Here Ik is the identity matrix with dimension k, k+l is the effective rank of the matrix (XT, YT)T. D1 is diagonal with k nonnegative diagonal entries. D2 is diagonal with l nonnegative diagonal entries.

SGGsvd is the reduced version of the GSVD. It is assumed that rank(X,Y) = k + l.

Singular values are returned in terms of alpha = diag(S1) and beta = diag(S2). Thus, for i = 1 to k, the i-th singular values of X and Y are alpha(i) and 0. For i = k+1 to k+l, the i-th singular values are alpha(i) and beta(i). And for i = k+l+1 to N, the i-th singular values are 0 and 0.

The diagonal entries of alpha and beta are related by:

    
    alpha(i)**2 + beta(i)**2 = 1

for i = 1 to k+l.

The routine differs from the LAPACK routine DGGsvd by the presence of the fourth argument JOBZ. It is assumed that X and Y are in upper trapezoidal form.

If JOBZ = 'N', the routines compute the GSVD.

If JOBZ = 'V', the routines compute the GSVD and the matrices U and V.

If JOBZ = 'A', the routines compute the GSVD and the matrices U and V.

If JOBZ = 'O', the routines compute the GSVD and the matrices U and V.

If JOBZ = 'U', the routines compute the GSVD and the matrices U and V.

If JOBZ = 'P', the routines compute the GSVD and the matrices U and V.

If JOBZ = 'Q', the routines compute the GSVD and the matrices U and V.

If JOBZ = 'R', the routines compute the GSVD and the matrices U and V.

If JOBZ = 'S', the routines compute the GSVD and the matrices U and V.

If JOBZ = 'T', the routines compute the GSVD and the matrices U and V.

If JOBZ = 'X', the routines compute the GSVD and the matrices U and V.

If JOBZ = 'Y', the routines compute the GSVD and the matrices U and V.

Function/Subroutine Documentation

Arguments

JOBU

CHARACTER*1. On entry, JOBU specifies whether to compute the orthogonal matrix U:

  • 'N': U is not computed.
  • 'U': U is computed.
JOV

CHARACTER*1. On entry, JOV specifies whether to compute the orthogonal matrix V:

  • 'N': V is not computed.
  • 'V': V is computed.
JOBZ

CHARACTER*1. On entry, JOBZ specifies whether to compute the singular values and auxiliary matrices:

  • 'N': Compute singular values only.
  • 'A': Compute singular values and matrices U and V.
M

INTEGER. On entry, M is the number of rows of X. M >= 0.

N

INTEGER. On entry, N is the number of columns of X and Y. N >= 0.

P

INTEGER. On entry, P is the number of rows of Y. P >= 0.

X

REAL array, dimension (LDA,N). On entry, the M-by-N matrix X. On exit, X is overwritten by the results of the decomposition.

LDA

INTEGER. On entry, LDA is the leading dimension of the array X. LDA >= max(1,M).

Y

REAL array, dimension (LDB,N). On entry, the P-by-N matrix Y. On exit, Y is overwritten by the results of the decomposition.

LDB

INTEGER. On entry, LDB is the leading dimension of the array Y. LDB >= max(1,P).

TOLA

REAL.

TOLB

REAL.

K

INTEGER. On exit, K is the number of diagonal entries of S1 and S2 which are equal to 1.

L

INTEGER. On exit, L is the number of diagonal entries of S1 and S2 which are less than 1 and greater than 0.

U

REAL array, dimension (LDU,N). On exit, U is the M-by-M orthogonal matrix. If JOBU = 'N', U is not accessed.

LDU

INTEGER. On entry, LDU is the leading dimension of the array U. LDU >= max(1,M).

V

REAL array, dimension (LDV,N). On exit, V is the P-by-P orthogonal matrix. If JOV = 'N', V is not accessed.

LDV

INTEGER. On entry, LDV is the leading dimension of the array V. LDV >= max(1,P).

WORK

REAL array, dimension (N).

IWORK

INTEGER array, dimension (N). On exit, IWORK stores the sorting information. More precisely, the following loop will sort ALPHA for I = K+1, min(M,K+L) swap ALPHA(I) and ALPHA(IWORK(I)) endfor such that ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).

INFO

INTEGER.

  • = 0: successful exit
  • < 0: if INFO = -i, the i-th argument had an illegal value.
  • > 0: if INFO = 1, the Jacobi-type procedure failed to converge. For further details, see subroutine STGSJA.

Internal Parameters:

TOLA REAL
TOLB REAL
        TOLA and TOLB are the thresholds to determine the effective
        rank of (A**T,B**T)**T. Generally, they are set to
                 TOLA = MAX(M,N)*norm(A)*MACHEPS,
                 TOLB = MAX(P,N)*norm(B)*MACHEPS.
        The size of TOLA and TOLB may affect the size of backward
        errors of the decomposition.
