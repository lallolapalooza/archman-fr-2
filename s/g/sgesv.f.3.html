Documentation de la fonction/sous-routine

sous-routine sgesv (integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, integer info)

But:

!>
!> SGESV calcule la solution d'un système d'équations linéaires réelles
!>    A * X = B,
!> où A est une matrice N-par-N et X et B sont des matrices N-par-NRHS.
!>
!> La décomposition LU avec pivotage partiel et échanges de lignes est
!> utilisée pour factoriser A en
!>    A = P * L * U,
!> où P est une matrice de permutation, L est triangulaire inférieure unitaire, et U est
!> triangulaire supérieure. La forme factorisée de A est ensuite utilisée pour résoudre le
!> système d'équations A * X = B.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un entier (INTEGER)
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau réel (REAL), de dimension (LDA,N)
!>          À l'entrée, la matrice de coefficients A de taille N-par-N.
!>          À la sortie, les facteurs L et U de la factorisation
!>          A = P*L*U ; les éléments diagonaux unitaires de L ne sont pas stockés.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau d'entiers (INTEGER), de dimension (N)
!>          Les indices de pivot qui définissent la matrice de permutation P ;
!>          la ligne i de la matrice a été échangée avec la ligne IPIV(i).
!>

B

!>          B est un tableau réel (REAL), de dimension (LDB,NRHS)
!>          À l'entrée, la matrice des membres de droite B de taille N-par-NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N-par-NRHS.
!>

LDB

!>          LDB est un entier (INTEGER)
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, U(i,i) est exactement zéro. La factorisation
!>                a été complétée, mais le facteur U est exactement
!>                singulier, donc la solution n'a pas pu être calculée.
!>
