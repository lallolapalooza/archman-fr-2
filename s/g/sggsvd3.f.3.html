SGGSVD3 calcule la décomposition en valeurs singulières généralisée (GSVD)
de la matrice réelle M-par-N A et de la matrice réelle P-par-N B :

Objectif :

!>
!> SGGSVD3 calcule la décomposition en valeurs singulières généralisée (GSVD)
!> d'une matrice réelle M-par-N A et d'une matrice réelle P-par-N B :
!>
!>       U**T*A*Q = D1*( 0 R ),    V**T*B*Q = D2*( 0 R )
!>
!> où U, V et Q sont des matrices orthogonales.
!> Soit K+L = le rang numérique effectif de la matrice (A**T,B**T)**T,
!> alors R est une matrice triangulaire supérieure non singulière de taille K+L par K+L, D1 et
!> D2 sont des matrices de taille M par (K+L) et P par (K+L) respectivement,
!> des structures suivantes :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N), et R33 est stocké
!!>   ( 0  R22 R23 )
!>   dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> La routine calcule C, S, R, et optionnellement les matrices de transformation
!> orthogonales U, V et Q.
!>
!> En particulier, si B est une matrice carrée non singulière N-par-N, alors la GSVD de
!> A et B donne implicitement la SVD de A*inv(B) :
!>                      A*inv(B) = U*(D1*inv(D2))*V**T.
!> Si ( A**T,B**T)**T a des colonnes orthonormales, alors la GSVD de A et B est
!> aussi égale à la décomposition CS de A et B. De plus, la GSVD
!> peut être utilisée pour dériver la solution du problème de valeurs propres :
!>                      A**T*A x = lambda* B**T*B x.
!> Dans certaines littératures, la GSVD de A et B est présentée sous la forme
!>                  U**T*A*X = ( 0 D1 ),   V**T*B*X = ( 0 D2 )
!> où U et V sont orthogonales et X est non singulière, D1 et D2 sont
!> « diagonales ». L'ancienne forme de la GSVD peut être convertie à la nouvelle
!> forme en prenant la matrice non singulière X comme
!>
!>                      X = Q*( I   0    )
!>                            ( 0 inv(R) ).
!>

NAME

SGGSVD3

calculates the singular value decomposition of a general rectangular matrix

SYNOPSIS

 SUBROUTINE SGGSVD3( JOBU, JOBV, JOBUA, JOBVB, M, N, P, A, LDA, B, LDB, ALPHA,
                  BETA, U, LDU, V, LDV, UA, LDUA, VB, LDVB, WORK, LWORK,
                  IWORK, INFO )
  CHARACTER(LEN=1) :: JOBU, JOBV, JOBUA, JOBVB
  INTEGER :: LDA, LDB, LDU, LDV, LDUA, LDVB, M, N, P, LWORK, INFO
  REAL :: A( LDA, * ), B( LDB, * ), ALPHA( * ), BETA( * ), U( LDU, * ),
          V( LDV, * ), UA( LDUA, * ), VB( LDVB, * ), WORK( * )
  INTEGER IWORK( * )

Function/Subroutine Documentation

SGGSVD3 computes the singular value decomposition of a general rectangular matrix A and B, where A and B are P-by-N and M-by-N, respectively.

This subroutine is the equivalent of LAPACK routines DGEES, DGESVD and DGESDD for the generalized singular value decomposition.

The routine has the ability to compute different forms of the generalized singular value decomposition. The most general form is:

   A = U * Sigma_A * V_A^T
   B = V * Sigma_B * V_B^T

where:

Sigma_A = ( A11 A12 ) Sigma_B = ( B11 B12 )

           (   0   0 )
           (   0   0 )
           (   0   0 )
           (   0   0 )

A11 is k-by-k upper triangular, A12 is k-by-l upper triangular,

B11 is l-by-l upper triangular, B12 is l-by-k upper triangular.

Here, k is the number of calculated singular values and l is the number of computed generalized singular values.

The decomposition is performed by the routine STGSJA, which computes the generalized Schur decomposition of A and B.

SGGSVD3 performs the following steps:

  1. Computes the generalized Schur decomposition of A and B using STGSJA.
  2. Computes the SVD of the diagonal blocks of the generalized Schur form of A and B.
  3. Combines the results to obtain the SVD of A and B.

Parameters:

JOBU

CHARACTER*1.

Input parameter.

On entry, JOBU specifies whether to compute the left singular vectors.

JOBU = 'U': The left singular vectors U are computed and returned.

JOBU = 'N': The left singular vectors U are not computed.

JOBV

CHARACTER*1.

Input parameter.

On entry, JOBV specifies whether to compute the left singular vectors V.

JOBV = 'V': The left singular vectors V are computed and returned.

JOBV = 'N': The left singular vectors V are not computed.

JOBUA

CHARACTER*1.

Input parameter.

On entry, JOBUA specifies whether to compute the left singular vectors of A.

JOBUA = 'U': The left singular vectors UA are computed and returned.

JOBUA = 'N': The left singular vectors UA are not computed.

JOBVB

CHARACTER*1.

Input parameter.

On entry, JOBVB specifies whether to compute the left singular vectors of B.

JOBVB = 'V': The left singular vectors VB are computed and returned.

JOBVB = 'N': The left singular vectors VB are not computed.

M

INTEGER.

Input parameter.

On entry, M is the number of rows of A.

N

INTEGER.

Input parameter.

On entry, N is the number of columns of A and B.

P

INTEGER.

Input parameter.

On entry, P is the number of rows of B.

A

REAL array, dimension (LDA, N).

On entry, the M-by-N matrix A.

On exit, A is overwritten by the results of the SVD.

LDA

INTEGER.

Input parameter.

On entry, LDA is the leading dimension of the array A.

B

REAL array, dimension (LDB, N).

On entry, the P-by-N matrix B.

On exit, B is overwritten by the results of the SVD.

LDB

INTEGER.

Input parameter.

On entry, LDB is the leading dimension of the array B.

ALPHA

REAL array, dimension (N).

On exit, ALPHA(i) is the i-th singular value of A.

BETA

REAL array, dimension (N).

On exit, BETA(i) is the i-th singular value of B.

U

REAL array, dimension (LDU, K).

On exit, U is the M-by-K matrix of left singular vectors of A, where K = min(M,N).

U is only computed if JOBU = 'U'.

LDU

INTEGER.

Input parameter.

On entry, LDU is the leading dimension of the array U.

V

REAL array, dimension (LDV, L).

On exit, V is the P-by-L matrix of left singular vectors of B, where L = min(P,N).

V is only computed if JOBV = 'V'.

LDV

INTEGER.

Input parameter.

On entry, LDV is the leading dimension of the array V.

UA

REAL array, dimension (LDUA, N).

On exit, UA is the M-by-M unitary matrix U_A.

UA is only computed if JOBUA = 'U'.

LDUA

INTEGER.

Input parameter.

On entry, LDUA is the leading dimension of the array UA.

VB

REAL array, dimension (LDVB, N).

On exit, VB is the P-by-P unitary matrix V_B.

VB is only computed if JOBVB = 'V'.

LDVB

INTEGER.

Input parameter.

On entry, LDVB is the leading dimension of the array VB.

WORK

REAL array, dimension (LWORK).

On exit, if LWORK = -1, then WORK(1) contains the optimal LWORK.

LWORK

INTEGER.

Input parameter.

The dimension of the array WORK. LWORK >= 1.

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

IWORK

INTEGER array, dimension (N).

On exit, IWORK stores the sorting information. More precisely, the following loop will sort ALPHA

           for I = K+1, min(M,K+L)
               swap ALPHA(I) and ALPHA(IWORK(I))
           endfor

such that ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).

INFO

INTEGER.

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: if INFO = 1, the Jacobi-type procedure failed to converge. For further details, see subroutine STGSJA.

Internal Parameters:

 TOLA    REAL
 TOLB    REAL

TOLA and TOLB are the thresholds to determine the effective rank of (A**T,B**T)**T. Generally, they are set to

 TOLA = MAX(M,N)*norm(A)*MACHEPS,
 TOLB = MAX(P,N)*norm(B)*MACHEPS.

The size of TOLA and TOLB may affect the size of backward errors of the decomposition.
