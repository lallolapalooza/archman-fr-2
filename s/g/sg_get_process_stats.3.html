DESCRIPTION

Les fonctions sg_get_process_stats fournissent des statistiques sur les processus en cours d'exécution. Les deux fonctions, sg_get_process_stats() et sg_get_process_stats_r(), prennent un paramètre facultatif entries, qui pointe (lorsqu'il est fourni) vers un size_t pour obtenir le nombre d'entrées du vecteur retourné.

Les fonctions sg_get_process_count_of() et sg_get_process_count_r() fournissent une vue agrégée de la table des processus - elles livrent la quantité de processus par état de processus. La fonction sg_get_process_count() est en fait une macro de préprocesseur pour des raisons de compatibilité descendante et appelle sg_get_process_count_of() avec le paramètre pcs de sg_entire_process_count pour émuler le comportement jusqu'à la version 0.17.

Raccourci API

fonction retourne propriétaire des données
sg_get_process_stats sg_process_stats * libstatgrab (thread local)
sg_get_process_stats_r sg_process_stats * appelant
sg_get_process_count_of sg_process_count * libstatgrab (thread local)
sg_get_process_count_r sg_process_count * appelant

Les vecteurs sg_process_stats reçus de sg_get_process_stats_r() ou les résumés sg_process_count reçus de sg_get_process_count_r doivent être libérés en utilisant sg_free_process_stats() ou sg_free_process_count(), respectivement. L'appelant est responsable de le faire lorsque les données ne sont plus nécessaires.

Ces fonctions comparent deux entrées sg_process_stats et retournent un int pour représenter laquelle est supérieure. L'utilisation principale de ces fonctions est de les passer à qsort pour trier sg_process_stats par le type donné.

Exemple

size_t entries;
sg_process_stats *proc_stats = NULL;
while( NULL != ( proc_stats = sg_get_process_stats_r(&entries) ) ) {
    /* trier les entrées en comparant l'identifiant du processus */
    qsort( proc_stats, entries, sizeof(proc_stats[0]), &sg_process_compare_pid );
    show_proc_stats( proc_stats );
    sg_free_process_stats( proc_stats );
}

VALEURS DE RETOUR

La structure retournée par sg_get_process_stats est de type sg_process_stats.

typedef struct {
        char *process_name;
        char *proctitle;
        pid_t pid;    /* identifiant du processus */
        pid_t parent; /* PID du parent */
        pid_t pgid;   /* PID du leader du groupe de processus */
        pid_t sessid; /* ID de session du processus */
        uid_t uid;
        uid_t euid;
        gid_t gid;
        gid_t egid;
        unsigned long long context_switches;
        unsigned long long voluntary_context_switches;
        unsigned long long involuntary_context_switches;
        unsigned long long proc_size; /* en octets */
        unsigned long long proc_resident; /* en octets */
        time_t start_time; /* Heure de démarrage du processus */
        time_t time_spent; /* temps d'exécution en secondes */
        double cpu_percent;
        int nice;
        sg_process_state state;
        time_t systime;
} sg_process_stats;

typedef enum {
        SG_PROCESS_STATE_RUNNING,
        SG_PROCESS_STATE_SLEEPING,
        SG_PROCESS_STATE_STOPPED,
        SG_PROCESS_STATE_ZOMBIE,
        SG_PROCESS_STATE_UNKNOWN
} sg_process_state;
process_name
Le nom de la commande exécutée. Le contenu de ce champ dépend fortement du système d'exploitation sous-jacent, certains stockent le nom de base que l'exécutable passe à l'appel système exec(2), d'autres le chemin complet. La plupart des OS restreignent la taille de ce champ - certains comme la famille *BSD à une valeur très basse de 15 octets.

Ce champ est généralement immuable pour les processus utilisateur.

proctitle
La ligne de commande (le "titre") du processus. Attention - cela peut être modifié par le processus, il n'est donc pas garanti que ce soit la ligne de commande d'origine.
pid
L'identifiant du processus.
parent
L'identifiant du processus parent.
pgid
L'identifiant du leader du groupe de processus.
sessid
L'identifiant de session auquel le processus appartient.
uid
L'identifiant de l'utilisateur sous lequel le processus s'exécute.
euid
L'identifiant de l'utilisateur effectif sous lequel le processus s'exécute.
gid
L'identifiant du groupe sous lequel le processus s'exécute.
egid
L'identifiant du groupe effectif sous lequel le processus s'exécute.
context_switches
Le nombre de changements de contexte de ce processus (volontaires et involontaires).
voluntary_context_switches
Le nombre de changements de contexte volontaires de ce processus (par exemple, en appelant sched_yield() ou sleep()).
involuntary_context_switches
Le nombre de changements de contexte involontaires de ce processus (par exemple, tranche de temps épuisée ou signal envoyé).
proc_size
La taille de la mémoire virtuelle du processus en octets.
proc_resident
La taille de la mémoire résidente (physique) du processus en octets.
start_time
L'heure à laquelle le processus a été démarré.
time_spent
Le temps total passé par le processus à s'exécuter, en secondes.
cpu_percent
Le pourcentage d'utilisation du CPU par le processus. Les valeurs peuvent dépasser 100% sur les systèmes multi-cœurs.
nice
La priorité "nice" du processus. Une valeur plus faible indique une priorité plus élevée.
state
L'état actuel du processus, représenté par une valeur de l'énumération sg_process_state.
systime
Le temps total passé par le processus dans le noyau (temps système) en secondes.

Les structures retournées par sg_get_process_count sont de type sg_process_count.

typedef struct {
        unsigned long long total;
        unsigned long long running;
        unsigned long long sleeping;
        unsigned long long stopped;
        unsigned long long zombie;
} sg_process_count;
total
Nombre total de processus.
running
Nombre de processus en cours d'exécution.
sleeping
Nombre de processus en attente (endormis).
stopped
Nombre de processus arrêtés.
zombie
Nombre de processus zombies.

Les fonctions de comparaison retournent 0 si les deux éléments sont égaux, une valeur négative si va est inférieur à vb, et une valeur positive si va est supérieur à vb.

Les fonctions `sg_get_*_r` retournent un pointeur vers les données qui doivent être libérées par l'appelant, tandis que les fonctions `sg_get_*` sans `_r` retournent un pointeur vers des données globales gérées par libstatgrab. Dans ce dernier cas, l'appelant ne doit pas libérer les données. Pour les fonctions `sg_get_*_r`, les données retournées sont garanties d'être valides jusqu'à ce que la fonction `sg_free_*` soit appelée.

ERREURS

Les fonctions qui peuvent échouer retournent NULL et définissent sg_error.

DESCRIPTION

The sg_get_process_stats() function returns a list of sg_process_stats structures. Each structure represents a process running on the system.

The sg_get_process_count_of() function returns a pointer to a sg_process_count structure. The argument source specifies which process count to return. If source is sg_entire_process_count, the function returns the total count of processes running on the system. If source is sg_last_process_count, the function returns the count of processes running on the system since the last call to sg_get_process_count_of().

The sg_get_process_count_r() function returns a pointer to a sg_process_count structure. This function is the thread-safe version of sg_get_process_count_of() with the sg_entire_process_count source.

The sg_get_process_count_r_by_pid() function returns a pointer to a sg_process_count structure. This function is the thread-safe version of sg_get_process_count_of() with the sg_entire_process_count source, but it only counts processes belonging to the specified pid.

The following functions return information about a specific process:

pid
The process ID.
uid
The effective user ID of the process.
ppid
The process ID of the parent process.
login
The login name of the user running the process.
command
The command line of the process.
exe
The path to the executable of the process.
root
The root directory of the process.
name
The name of the process.
proc_resident
La taille du processus qui réside en mémoire.
start_time
L'heure de démarrage du processus en secondes depuis l'époque.
time_spent
Le nombre de secondes pendant lesquelles le processus a été exécuté (temps utilisateur+système, sans le temps passé par les processus enfants).
cpu_percent
Le pourcentage actuel du CPU utilisé par le processus.
nice
La valeur nice du processus.
state
L'état actuel du processus. Voir sg_process_state pour les valeurs autorisées.
systime
L'heure en secondes depuis l'époque du moment où la statistique actuelle a été créée. Ce moment peut être (mais n'est pas obligé de l'être) le même pour toutes les entrées retournées, qu'elles soient récupérées avec un seul instantané ou assemblées à partir d'une sorte de procfs.

BUGS

Le tout premier appel à sg_get_process_count_of(sg_last_process_count) retournera le même résultat que sg_get_process_count_of(sg_entire_process_count).

Les fonctions de comparaison existent plutôt pour la compatibilité descendante que pour l'amélioration des fonctionnalités. La flexibilité limitée (par exemple, l'ordre inverse) et le manque d'opportunités d'optimisation pour le compilateur conduisent à la recommandation d'implémenter les routines de comparaison requises localement.
