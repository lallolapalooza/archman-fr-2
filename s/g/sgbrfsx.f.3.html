SGBRFSX

But :

!>
!>    SGBRFSX améliore la solution calculée d'un système d'équations linéaires
!>    et fournit des bornes d'erreur et des estimations d'erreur arrière
!>    pour la solution. En plus de la borne d'erreur normwise, le code
!>    fournit une borne d'erreur composante par composante maximale si possible. Voir
!>    les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des
!>    bornes d'erreur.
!>
!>    Le système d'équations linéaires original peut avoir été équilibré
!>    avant d'appeler cette routine, tel que décrit par les arguments EQUED, R
!>    et C ci-dessous. Dans ce cas, la solution et les bornes d'erreur retournées
!>    sont pour le système original non équilibré.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment le raffinement est effectué, mais souvent les
!>     valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N':  A * X = B     (Pas de transposée)
!>       = 'T':  A**T * X = B  (Transposée)
!>       = 'C':  A**H * X = B  (Conjuguée transposée = Transposée)
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibration qui a été effectuée sur A
!>     avant d'appeler cette routine. Ceci est nécessaire pour calculer
!>     correctement la solution et les bornes d'erreur.
!>       = 'N':  Pas d'équilibration
!>       = 'R':  Équilibration des lignes, c.-à-d. que A a été multiplié
!>               par diag(R).
!>       = 'C':  Équilibration des colonnes, c.-à-d. que A a été post-multiplié
!>               par diag(C).
!>       = 'B':  Équilibration des lignes et des colonnes, c.-à-d. que A a été
!>               remplacé par diag(R) * A * diag(C).
!>               Le membre de droite B a été modifié en conséquence.
!>

N

!>          N est INTEGER
!>     L'ordre de la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c.-à-d. le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est tableau REAL, dimension (LDAB,N)
!>     La matrice bande originale A, stockée dans les lignes 1 à KL+KU+1.
!>     La j-ième colonne de A est stockée dans la j-ième colonne du
!>     tableau AB comme suit :
!>     AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku)<=i<=min(n,j+kl).
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est tableau REAL, dimension (LDAFB,N)
!>     Détails de la factorisation LU de la matrice bande A, telle que
!>     calculée par SGBTRF.  U est stockée comme une matrice bande triangulaire
!>     supérieure avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1, et
!>     les multiplicateurs utilisés pendant la factorisation sont stockés dans
!>     les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale du tableau AFB.  LDAFB >= 2*KL*KU+1.
!>

IPIV

!>          IPIV est tableau INTEGER, dimension (N)
!>     Les indices de pivot de SGETRF ; pour 1<=i<=N, la ligne i de la
!>     matrice a été échangée avec la ligne IPIV(i).
!>

R

!>          R est tableau REAL, dimension (N)
!>     Les facteurs d'échelle des lignes de A. Si EQUED = 'R' ou 'B', A est
!>     multiplié à gauche par diag(R) ; si EQUED = 'N' ou 'C', R
!>     n'est pas accédé.  R est un argument d'entrée si FACT = 'F' ;
!>     sinon, R est un argument de sortie. Si FACT = 'F' et
!>     EQUED = 'R' ou 'B', chaque élément de R doit être positif.
!>     Si R est en sortie, chaque élément de R est une puissance de la base.
!>     Si R est en entrée, chaque élément de R doit être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances de la base ne provoque pas d'erreurs d'arrondi à moins que le
!>     résultat ne déborde (sous-dépassement ou sur-dépassement). Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

C

!>          C est tableau REAL, dimension (N)
!>     Les facteurs d'échelle des colonnes de A. Si EQUED = 'C' ou 'B', A est
!>     multiplié à droite par diag(C) ; si EQUED = 'N' ou 'R', C
!>     n'est pas accédé.  C est un argument d'entrée si FACT = 'F' ;
!>     sinon, C est un argument de sortie. Si FACT = 'F' et
!>     EQUED = 'C' ou 'B', chaque élément de C doit être positif.
!>     Si C est en sortie, chaque élément de C est une puissance de la base.
!>     Si C est en entrée, chaque élément de C doit être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances de la base ne provoque pas d'erreurs d'arrondi à moins que le
!>     résultat ne déborde (sous-dépassement ou sur-dépassement). Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est tableau REAL, dimension (LDB,NRHS)
!>     La matrice membre de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est tableau REAL, dimension (LDX,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par SGETRS.
!>     À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>     Conditionnement relatif mis à l'échelle. C'est une estimation du
!>     conditionnement de Skeel relatif de la matrice A après
!>     équilibration (si effectuée). Si cela est inférieur à la précision de la machine
!>     (en particulier, s'il est zéro), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut encore être petite même
!>     si ce nombre

Function/Subroutine Documentation

SG BRFSX

!>
!> \brief \brief Solves a system of equations with a general band matrix, M x = B, and provides
!>        error bounds and condition estimates.
!>
!> This subroutine is similar to SGBRFS, but it provides more detailed error
!> information. It solves the system of linear equations M*X = B, where M is an
!> N x N general band matrix with KBL subdiagonals and KBR superdiagonals.
!> The subroutine computes the solution vectors X for each of the NRHS right-hand
!> side vectors B. In addition, it provides estimates of both the normwise and
!> componentwise relative backward errors, as well as condition numbers.
!> Iterative refinement is used to improve the accuracy of the solution.
!>
!> \param[in] UPLO Character string indicating whether the matrix is upper ('U') or
!>                 lower ('L') triangular.
!> \param[in] TRANS Character string indicating the form of the system to be solved:
!>                  'N': M*X = B (No transpose)
!>                  'T': M**T*X = B (Transpose)
!>                  'C': M**H*X = B (Conjugate transpose)
!> \param[in] DIAG Character string indicating whether the matrix has unit diagonals:
!>                 'U': Upper triangular matrix with unit diagonals.
!>                 'N': Upper triangular matrix.
!> \param[in] N Integer, the order of the matrix M.
!> \param[in] KBL Integer, the number of subdiagonals of M.
!> \param[in] KBR Integer, the number of superdiagonals of M.
!> \param[in] NRHS Integer, the number of right-hand sides, i.e., the number of
!>                 columns in the matrices B, X, and BERR.
!> \param[in,out] AB Real array, dimension (LDAB, KBL+KBR+1). On entry, the N x N
!>                   band matrix M, stored in the first KBL+KBR+1 rows.
!>                   On exit, AB is overwritten by details of the LU factorization.
!> \param[in] LDAB Integer, the leading dimension of the array AB.
!> \param[in,out] B Real array, dimension (LDB, NRHS). On entry, the N x NRHS
!>                  right-hand side matrix B.
!>                  On exit, B is overwritten by the solution matrix X.
!> \param[in] LDB Integer, the leading dimension of the array B.
!> \param[out] X Real array, dimension (LDX, NRHS). The N x NRHS solution matrix X.
!> \param[in] LDX Integer, the leading dimension of the array X.
!> \param[out] BERR Real array, dimension (NRHS). Componentwise relative backward
!>                  error of each solution vector X(j).
!> \param[out] N_ERR_BNDS Integer. Number of error bounds to return for each
!>                          right-hand side and each type (normwise or componentwise).
!> \param[out] ERR_BNDS_NORM Real array, dimension (NRHS, N_ERR_BNDS). Contains
!>                             information about normwise relative error bounds and
!>                             condition numbers for each right-hand side.
!> \param[out] ERR_BNDS_COMP Real array, dimension (NRHS, N_ERR_BNDS). Contains
!>                             information about componentwise relative error bounds and
!>                             condition numbers for each right-hand side.
!> \param[in] NPARAMS Integer. Specifies the number of parameters set in PARAMS.
!> \param[in,out] PARAMS Real array, dimension NPARAMS. Specifies algorithm parameters.
!>                        If an entry is < 0.0, it is filled with the default value.
!>                        PARAMS(1): Iterative refinement toggle (1.0 = on, 0.0 = off).
!>                        PARAMS(2): Maximum number of residual computations for refinement.
!>                        PARAMS(3): Flag for componentwise accuracy in double precision.
!> \param[out] WORK Real array, dimension (4*N). Workspace array.
!> \param[out] IWORK Integer array, dimension (N). Workspace array.
!> \param[out] INFO Integer.
!>                  = 0: Successful exit.
!>                  < 0: If INFO = -i, the i-th argument was illegal.
!>                  > 0 and <= N: U(INFO,INFO) is exactly zero; the matrix is singular.
!>                  = N+J: The Jth solution is not guaranteed.
!>
!> \par UPLO
!>          UPLO is CHARACTER*1
!>     Specifies whether the matrix AB in array arguments is upper or lower
!>     band triangular.
!>     = 'U': Upper band triangular
!>     = 'L': Lower band triangular
!>
!> \par TRANS
!>          TRANS is CHARACTER*1
!>     Specifies the form of the system of equations:
!>     = 'N': New system, M X = B.
!>     = 'T': Transposed system, M**T X = B.
!>     = 'C': Conjugate transposed system, M**H X = B.
!>
!> \par DIAG
!>          DIAG is CHARACTER*1
!>     Specifies whether the matrix AB in array arguments has unit diagonals:
!>     = 'U': Upper band triangular matrix with unit diagonals.
!>     = 'N': Upper band triangular matrix is not assumed to have unit diagonals.
!>
!> \par N
!>          N is INTEGER
!>     The order of the matrix M. The number of rows and columns of the matrix.
!>     N >= 0.
!>
!> \par KBL
!>          KBL is INTEGER
!>     The number of subdiagonals of the matrix M.
!>     KBL >= 0.
!>
!> \par KBR
!>          KBR is INTEGER
!>     The number of superdiagonals of the matrix M.
!>     KBR >= 0.
!>
!> \par NRHS
!>          NRHS is INTEGER
!>     The number of right hand sides, i.e., the number of columns of the
!>     arrays B, X, and BERR. NRHS >= 0.
!>
!> \par AB
!>          AB is REAL array, dimension (LDAB, KBL+KBR+1)
!>     On entry, the N-by-N band matrix A in the band format. A is stored
!>     such that AB(i, kbl+1+j) = A(i, j), where kbl is the number of sub-
!>     diagonals and i-kbl <= j <= i+kbr. See Further Details section.
!>
!> \par LDAB
!>          LDAB is INTEGER
!>     The leading dimension of the array AB. LDAB >= max(1, N).
!>
!> \par B
!>          B is REAL array, dimension (LDB, NRHS)
!>     On entry, the N-by-NRHS right hand side matrix B.
!>
!> \par LDB
!>          LDB is INTEGER
!>     The leading dimension of the array B. LDB >= max(1, N).
!>
!> \par X
!>          X is REAL array, dimension (LDX, NRHS)
!>     On exit, if INFO = 0, the N-by-NRHS solution matrix X corresponding
!>     to the right hand sides in the original array B.
!>
!> \par LDX
!>          LDX is INTEGER
!>     The leading dimension of the array X. LDX >= max(1, N).
!>
!> \par BERR
!>          BERR is REAL array, dimension (NRHS)
!>     Componentwise relative backward error. This is the componentwise
!>     relative backward error of each solution vector X(j).
!>     For each right hand side j, BERR(j) is the largest value of
!>
!>                  abs( real( A*x )(i) - b(i) ) / ( abs(A)*abs(x) + abs(b) )(i)
!>
!>     over the components i, where x is the j-th solution vector X(j), A is
!>     the matrix in AB, and b is the j-th column of B.
!>
!> \par N_ERR_BNDS
!>          N_ERR_BNDS is INTEGER
!>     Number of error bounds to return for each right hand side and each
!>     type (normwise or componentwise).
!>
!> \par ERR_BNDS_NORM
!>          ERR_BNDS_NORM is REAL array, dimension (NRHS, N_ERR_BNDS)
!>     For each right hand side j, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     normwise relative error, which is defined as follows:
!>
!>     Normwise relative error in the j-th solution vector:
!>             max_i (abs(XTRUE(i,j) - X(i,j))) / max_i (abs(X(j,i)))
!>
!>     The array is indexed by the type of error information as described
!>     below. There currently are up to three pieces of information returned.
!>
!>     The first index in ERR_BNDS_NORM(j,:) corresponds to the j-th
!>     right hand side.
!>
!>     The second index in ERR_BNDS_NORM(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated normwise
!>              reciprocal condition number. Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is reliable. These reciprocal condition
!>              numbers are 1 / (norm(Z**-1,inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*A, where S scales each row by a power of the
!>              radix so all absolute row sums of Z are approximately 1.
!>
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>
!> \par ERR_BNDS_COMP
!>          ERR_BNDS_COMP is REAL array, dimension (NRHS, N_ERR_BNDS)
!>     For each right hand side j, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     componentwise relative error, which is defined as follows:
!>
!>     Componentwise relative error in the j-th solution vector:
!>                    abs(XTRUE(i,j) - X(i,j))
!>             max_i ----------------------
!>                         abs(X(j,i))
!>
!>     The array is indexed by the right-hand side j (on which the
!>     componentwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right hand side. If
!>     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_COMP is not accessed. If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_COMP(j,:) corresponds to the j-th
!>     right hand side.
!>
!>     The second index in ERR_BNDS_COMP(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated componentwise
!>              reciprocal condition number. Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is reliable. These reciprocal condition
!>              numbers are 1 / (norm(Z**-1,inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*(A*diag(x)), where x is the solution for the
!>              current right hand side and S scales each row of
!>              A*diag(x) by a power of the radix so all absolute row
!>              sums of Z are approximately 1.
!>
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>
!> \par NPARAMS
!>          NPARAMS is INTEGER
!>     Specifies the number of parameters set in PARAMS. If <= 0, the
!>     PARAMS array is never referenced and default values are used.
!>
!> \par PARAMS
!>          PARAMS is REAL array, dimension NPARAMS
!>     Specifies algorithm parameters. If an entry is < 0.0, then
!>     that entry will be filled with default value used for that
!>     parameter. Only positions up to NPARAMS are accessed; defaults
!>     are used for higher-numbered parameters.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
!>            refinement or not.
!>         Default: 1.0
!>            = 0.0: No refinement is performed, and no error bounds are
!>                   computed.
!>            = 1.0: Use the double-precision refinement algorithm,
!>                   possibly with doubled-single computations if the
!>                   compilation environment does not support DOUBLE
!>                   PRECISION.
!>              (other values are reserved for future use)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual
!>            computations allowed for refinement.
!>         Default: 10
!>         Aggressive: Set to 100 to permit convergence using approximate
!>                     factorizations or factorizations other than LU. If
!>                     the factorization uses a technique other than
!>                     Gaussian elimination, the guarantees in
!>                     ERR_BNDS_NORM and ERR_BNDS_COMP may no longer be
!>                     trustworthy.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code
!>            will attempt to find a solution with small componentwise
!>            relative error in the double-precision algorithm. Positive
!>            is true, 0.0 is false.
!>         Default: 1.0 (attempt componentwise convergence)
!>
!> \par WORK
!>          WORK is REAL array, dimension (4*N)
!>     Workspace array.
!>
!> \par IWORK
!>          IWORK is INTEGER array, dimension (N)
!>     Workspace array.
!>
!> \par INFO
!>          INFO is INTEGER
!>     = 0: Successful exit. The solution to every right-hand side is
!>          guaranteed.
!>     < 0: If INFO = -i, the i-th argument had an illegal value.
!>     > 0 and <= N: U(INFO,INFO) is exactly zero. The factorization
!>        has been completed, but the factor U is exactly singular, so
!>        the solution and error bounds could not be computed. RCOND = 0
!>        is returned.
!>     = N+J: The solution corresponding to the Jth right-hand side is
!>        not guaranteed. The solutions corresponding to other right-
!>        hand sides K with K > J may not be guaranteed as well, but
!>        only the first such right-hand side is reported. If a small
!>        componentwise error is not requested (PARAMS(3) = 0.0) then
!>        the Jth right-hand side is the first with a normwise error
!>        bound that is not guaranteed (the smallest J such
!>        that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
!>        the Jth right-hand side is the first with either a normwise or
!>        componentwise error bound that is not guaranteed (the smallest
!>        J such that either ERR_BNDS_NORM(J,1) = 0.0 or
!>        ERR_BNDS_COMP(J,1) = 0.0). See the definition of
!>        ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
!>        about all of the right-hand sides check ERR_BNDS_NORM or
!>        ERR_BNDS_COMP.
!>
