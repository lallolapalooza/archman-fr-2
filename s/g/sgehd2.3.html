Documentation de la fonction/sous-routine

sous-routine sgehd2 (entier n, entier ilo, entier ihi, reel, dimension( lda, * ) a, entier lda, reel, dimension( * ) tau, reel, dimension( * ) work, entier info)

SGEHD2 réduit une matrice carrée générale à la forme de Hessenberg supérieure en utilisant un algorithme non bloqué.

But :

!>
!> SGEHD2 réduit une matrice générale réelle A à la forme de Hessenberg supérieure H
!> par une transformation d'équivalence orthogonale :  Q**T * A * Q = H .
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

ILO

!>          ILO est ENTIER
!>

IHI

!>          IHI est ENTIER
!>
!>          On suppose que A est déjà triangulaire supérieure dans les lignes
!>          et les colonnes 1:ILO-1 et IHI+1:N. ILO et IHI sont normalement
!>          définis par un appel précédent à SGEBAL ; sinon, ils devraient
!>          être définis à 1 et N respectivement. Voir Détails supplémentaires.
!>          1 <= ILO <= IHI <= max(1,N).
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          En entrée, la matrice générale n x n à réduire.
!>          En sortie, le triangle supérieur et la première sous-diagonale de A
!>          sont écrasés par la matrice de Hessenberg supérieure H, et les
!>          éléments sous la première sous-diagonale, avec le tableau TAU,
!>          représentent la matrice orthogonale Q comme un produit de
!>          réflecteurs élémentaires. Voir Détails supplémentaires.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau REEL, dimension (N-1)
!>          Les facteurs scalaires des réflecteurs élémentaires (voir Détails
!>          supplémentaires).
!>

WORK

!>          WORK est un tableau REEL, dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires :

!>
!>  La matrice Q est représentée comme un produit de (ihi-ilo) réflecteurs
!>  élémentaires
!>
!>     Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**T
!>
!>  où tau est un scalaire réel, et v est un vecteur réel avec
!>  v(1:i) = 0, v(i+1) = 1 et v(ihi+1:n) = 0 ; v(i+2:ihi) est stocké à la
!>  sortie dans A(i+2:ihi,i), et tau dans TAU(i).
!>
!>  Le contenu de A est illustré par l'exemple suivant, avec
!>  n = 7, ilo = 2 et ihi = 6 :
!>
!>  à l'entrée,                       à la sortie,
!>
!>  ( a   a   a   a   a   a   a )    (  a   a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      h   h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  v4  h   h   h )
!>  (                         a )    (                          a )
!>
!>  où a dénote un élément de la matrice originale A, h dénote un
!>  élément modifié de la matrice de Hessenberg supérieure H, et vi dénote un
!>  élément du vecteur définissant H(i).
!>
