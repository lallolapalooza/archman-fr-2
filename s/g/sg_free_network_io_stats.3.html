sg_get_network_io_stats(3) sg_get_network_io_stats(3)

NOM

sg_get_network_io_stats, sg_get_network_io_stats_r, sg_get_network_io_stats_diff, sg_get_network_io_stats_diff_between, sg_free_network_io_stats, sg_network_io_compare_name - obtenir des statistiques réseau

SYNTAXE

#include <statgrab.h>


sg_network_io_stats *sg_get_network_io_stats
(size_t *entries);


sg_network_io_stats *sg_get_network_io_stats_r
(size_t *entries);


sg_network_io_stats *sg_get_network_io_stats_diff
(size_t *entries);


sg_network_io_stats *sg_get_network_io_stats_diff_between
(const sg_network_io_stats *cur, const sg_network_io_stats *last, size_t *entries);


sg_error sg_free_network_io_stats
(sg_network_iface_stats *data);


int sg_network_io_compare_name
(const void *va, const void *vb);

DESCRIPTION

Les fonctions sg_get_network_io_stats fournissent des statistiques d'entrée/sortie des interfaces réseau, par interface. Toutes les fonctions get et diff prennent un paramètre d'entrées optionnel, qui pointe (si fourni) vers une variable de type size_t pour indiquer le nombre d'entrées du vecteur retourné.

Les fonctions sg_get_network_io_stats() et sg_get_network_io_stats_r() fournissent les statistiques d'entrée/sortie depuis que l'interface a été attachée au système. Les fonctions sg_get_network_io_stats_diff() et sg_get_network_io_stats_diff_between() fournissent la différence entre deux appels à sg_get_network_io_stats() ou sg_get_network_io_stats_r(), respectivement.

Raccourci API

fonction retourne propriétaire des données
sg_get_network_io_stats sg_network_io_stats * libstatgrab (local au thread)
sg_get_network_io_stats_r sg_network_io_stats * l'appelant
sg_get_network_io_stats_diff sg_network_io_stats * libstatgrab (local au thread)
sg_get_network_io_stats_diff_between sg_network_io_stats * l'appelant

Les vecteurs sg_network_io_stats reçus de sg_get_network_io_stats_r() ou sg_get_network_io_stats_diff_between() doivent être libérés à l'aide de sg_free_network_io_stats() lorsqu'ils ne sont plus nécessaires. L'appelant est responsable de cette opération.

De plus, une fonction de support pour qsort(3) est disponible : sg_network_io_compare_name().

Exemple

size_t entries;
sg_network_io_stats *network_stats = NULL;
while( NULL != ( network_stats = sg_get_network_io_stats_diff(&entries) ) ) {
    /* trier les interfaces par nom */
    qsort( network_stats, entries, sizeof(network_stats[0]), &sg_network_io_compare_name );
    show_network_io_stats( network_stats );
}

sg_get_network_io_stats retourne le trafic réseau stocké dans le noyau, qui contient la quantité de données transférées depuis que le périphérique a été attaché. Sur certaines plateformes, comme Solaris 7, cette valeur est stockée dans un entier 32 bits et se rembobine donc lorsqu'elle atteint 4 Go. D'autres plateformes, comme Solaris 8, stockent la valeur dans un entier 64 bits, qui se rembobine près de 17 millions de téraoctets. La fonction sg_get_network_io_stats_diff() et la fonction sg_get_network_io_stats_diff_between() tiennent compte de ces débordements et essaient de les détecter lors du calcul de la différence.

VALEURS RETOURNÉES

Toutes les statistiques réseau retournent un pointeur vers une structure de type sg_network_io_stats.

typedef struct {
        char *interface_name;
        unsigned long long tx;
        unsigned long long rx;
        unsigned long long ipackets;
        unsigned long long opackets;
        unsigned long long ierrors;
        unsigned long long oerrors;
        unsigned long long collisions;
        time_t systime;
} sg_network_io_stats;
interface_name
Le nom connu du système d'exploitation. (par exemple, sous Linux il peut s'agir de eth0, sous AIX de en0 et sous FreeBSD de fxp0)
tx
Le nombre d'octets transmis.
rx
Le nombre d'octets reçus.
ipackets
Le nombre de paquets reçus.
opackets
Le nombre de paquets transmis.
ierrors
Le nombre d'erreurs de réception.
oerrors
Le nombre d'erreurs de transmission.
collisions
Le nombre de collisions.
systime
L'horodatage lorsque les statistiques ci-dessus ont été collectées en secondes depuis l'époque, ou la période de temps pendant laquelle tx et rx ont été transférés.

BOGUES

sg_get_network_io_stats_diff et sg_get_network_io_stats_diff_between comparent deux listes de statistiques d'E/S relatives aux interfaces réseau. Chaque entrée n'apparaissant que dans la seconde liste est transmise à la liste résultante comme si elle avait été comparée à une entrée avec toutes les valeurs statistiques mises à 0. Cela implique que lors du tout premier appel, sg_get_network_io_stats_diff retournera la même chose que sg_get_network_io_stats.

Sur les systèmes d'exploitation qui ne stockent que 32 bits de données, il y a un problème si les valeurs se rembobinent deux fois. Par exemple, sur Solaris 7, si 9 Go sont transférés et que le système d'exploitation se rembobine à 4 Go, la fonction sg_get_network_io_stats_diff retournera 5 Go.
