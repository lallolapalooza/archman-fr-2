sous-routine sgbsvx (caractere fact, caractere trans, entier n, entier kl, entier ku, entier nrhs, reel, dimension( ldab, * ) ab, entier ldab, reel, dimension( ldafb, * ) afb, entier ldafb, entier, dimension( * ) ipiv, caractere equed, reel, dimension( * ) r, reel, dimension( * ) c, reel, dimension( ldb, * ) b, entier ldb, reel, dimension( ldx, * ) x, entier ldx, reel rcond, reel, dimension( * ) ferr, reel, dimension( * ) berr, reel, dimension( * ) work, entier, dimension( * ) iwork, entier info)

SGBSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices GB

Objectif :

!>
!> SGBSVX utilise la factorisation LU pour calculer la solution d'un système linéaire réel
!> A * X = B, A**T * X = B, ou A**H * X = B,
!> où A est une matrice bande d'ordre N avec KL sous-diagonales et KU
!> super-diagonales, et X et B sont des matrices N-par-NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de la condition sont également
!> fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées par cette sous-routine :
!>
!> 1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle de la matrice A,
!>    mais si l'équilibrage est utilisé, A est écrasée par diag(R)*A*diag(C) et B par diag(R)*B (si TRANS='N')
!>    ou diag(C)*B (si TRANS = 'T' ou 'C').
!>
!> 2. Si FACT = 'N' ou 'E', la décomposition LU est utilisée pour factoriser
!>    la matrice A (après équilibrage si FACT = 'E') comme suit :
!>       A = L * U,
!>    où L est un produit de matrices de permutation et triangulaires inférieures unitaires avec KL sous-diagonales, et U est triangulaire supérieure avec
!>    KL+KU super-diagonales.
!>
!> 3. Si certains U(i,i)=0, rendant U singulière, la routine
!>    renvoie avec INFO = i. Sinon, la forme factorisée de A est utilisée
!>    pour estimer le nombre de condition de la matrice A. Si le
!>    réciproque du nombre de condition est inférieur à la précision machine,
!>    INFO = N+1 est renvoyé comme avertissement, mais la routine continue
!>    à résoudre pour X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 5. Un raffinement itératif est appliqué pour améliorer la solution calculée
!>    matrice et calculer les bornes d'erreur et les erreurs résiduelles
!>    pour celle-ci.
!>
!> 6. Si l'équilibrage a été utilisé, la matrice X est prémultipliée par
!>    diag(C) (si TRANS = 'N') ou diag(R) (si TRANS = 'T' ou 'C') de sorte
!>    qu'elle résolve le système original avant l'équilibrage.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est fournie en entrée,
!>          et si ce n'est pas le cas, si la matrice A doit être équilibrée avant d'être factorisée.
!>          = 'F':  En entrée, AFB et IPIV contiennent la forme factorisée de
!>                  A.  Si EQUED n'est pas 'N', la matrice A a été
!>                  équilibrée avec les facteurs d'échelle donnés par R et C.
!>                  AB, AFB et IPIV ne sont pas modifiés.
!>          = 'N':  La matrice A sera copiée dans AFB et factorisée.
!>          = 'E':  La matrice A sera équilibrée si nécessaire, puis
!>                  copiée dans AFB et factorisée.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations.
!>          = 'N':  A * X = B     (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Transposée)
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>          Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>          Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est un tableau REAL, dimension (LDAB,N)
!>          En entrée, la matrice A en stockage bande, dans les lignes 1 à KL+KU+1.
!>          La j-ème colonne de A est stockée dans la j-ème colonne du
!>          tableau AB comme suit :
!>          AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU)<=i<=min(N,j+kl)
!>
!>          Si FACT = 'F' et EQUED n'est pas 'N', alors A doit avoir été
!>          équilibrée par les facteurs d'échelle dans R et/ou C.  AB n'est pas
!>          modifié si FACT = 'F' ou 'N', ou si FACT = 'E' et
!>          EQUED = 'N' à la sortie.
!>
!>          En sortie, si EQUED .ne. 'N', A est mise à l'échelle comme suit :
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est un tableau REAL, dimension (LDAFB,N)
!>          Si FACT = 'F', alors AFB est un argument d'entrée et contient en entrée
!>          les détails de la factorisation LU de la matrice bande
!>          A, tels que calculés par SGBTRF.  U est stockée comme une matrice bande triangulaire supérieure
!>          avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1,
!>          et les multiplicateurs utilisés lors de la factorisation sont stockés
!>          dans les lignes KL+KU+2 à 2*KL+KU+1.  Si EQUED .ne. 'N', alors AFB
!>          est la forme factorisée de la matrice A équilibrée.
!>
!>          Si FACT = 'N', alors AFB est un argument de sortie et renvoie en sortie
!>          les détails de la factorisation LU de A.
!>
!>          Si FACT = 'E', alors AFB est un argument de sortie et renvoie en sortie
!>          les détails de la factorisation LU de la matrice équilibrée
!>          A (voir la description de AB pour la forme de la
!>          matrice équilibrée).
!>

LDAFB

!>          LDAFB est INTEGER
!>          La dimension principale du tableau AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et contient en entrée
!>          les indices de pivot de la factorisation A = L*U
!>          tels que calculés par SGBTRF ; la ligne i de la matrice a été échangée
!>          avec la ligne IPIV(i).
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et contient en sortie
!>          les indices de pivot de la factorisation A = L*U
!>          de la matrice originale A.
!>
!>          Si FACT = 'E', alors IPIV est un argument de sortie et contient en sortie
!>          les indices de pivot de la factorisation A = L*U
!>          de la matrice équilibrée A.
!>

EQUED

!>          EQUED est CHARACTER*1
!>

R

!>          R est un tableau REEL, de dimension (N)
!>          Les facteurs d'échelle des lignes de A. Si EQUED = 'R' ou 'B', A est
!>          multiplié à gauche par diag(R) ; si EQUED = 'N' ou 'C', R
!>          n'est pas accédé. R est un argument d'entrée si FACT = 'F' ;
!>          sinon, R est un argument de sortie. Si FACT = 'F' et
!>          EQUED = 'R' ou 'B', chaque élément de R doit être positif.
!>

C

!>          C est un tableau REEL, de dimension (N)
!>          Les facteurs d'échelle des colonnes de A. Si EQUED = 'C' ou 'B', A est
!>          multiplié à droite par diag(C) ; si EQUED = 'N' ou 'R', C
!>          n'est pas accédé. C est un argument d'entrée si FACT = 'F' ;
!>          sinon, C est un argument de sortie. Si FACT = 'F' et
!>          EQUED = 'C' ou 'B', chaque élément de C doit être positif.
!>

B

!>          B est un tableau REEL, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice du second membre B.
!>          À la sortie,
!>          si EQUED = 'N', B n'est pas modifié ;
!>          si TRANS = 'N' et EQUED = 'R' ou 'B', B est écrasé par
!>          diag(R)*B ;
!>          si TRANS = 'T' ou 'C' et EQUED = 'C' ou 'B', B est
!>          écrasé par diag(C)*B.
!>

LDB

!>          LDB est un entier
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau REEL, de dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution N x NRHS X
!>          du système d'équations original. Notez que A et B sont
!>          modifiés à la sortie si EQUED .ne. 'N', et la solution du
!>          système équilibré est inv(diag(C))*X si TRANS = 'N' et
!>          EQUED = 'C' ou 'B', ou inv(diag(R))*X si TRANS = 'T' ou 'C'
!>          et EQUED = 'R' ou 'B'.
!>

LDX

!>          LDX est un entier
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est un REEL
!>          L'estimation du nombre de condition inverse de la matrice
!>          A après équilibration (si elle a été effectuée). Si RCOND est inférieur à la
!>          précision de la machine (en particulier, si RCOND = 0), la matrice
!>          est singulière à la précision de travail. Cette condition est
!>          indiquée par un code de retour INFO > 0.
!>

FERR

!>          FERR est un tableau REEL, de dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisé par la magnitude du plus grand
!>          élément de X(j). L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          surestimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau REEL, de dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire le plus petit changement relatif dans
!>          un élément de A ou B qui fait de X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau REEL, de dimension (MAX(1,3*N))
!>          À la sortie, WORK(1) contient le facteur de croissance du pivot réciproque
!>          norm(A)/norm(U). La norme
!>          est utilisée. Si WORK(1) est bien inférieur à 1, alors la stabilité
!>          de la factorisation LU de la matrice A (équilibrée)
!>          pourrait être médiocre. Cela signifie également que la solution X, l'estimateur de condition
!>          RCOND, et la borne d'erreur avant FERR pourraient être
!>          peu fiables. Si la factorisation échoue avec 0 < INFO <= N, alors
!>          WORK(1) contient le facteur de croissance du pivot réciproque pour les
!>          colonnes principales INFO de A.
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (N)
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= N : U(i,i) est exactement zéro. La factorisation
!>                       a été complétée, mais le facteur U est exactement
!>                       singulier, donc la solution et les bornes d'erreur
!>                       n'ont pas pu être calculées. RCOND = 0 est renvoyé.
!>                = N+1 : U est non singulier, mais RCOND est inférieur à la précision de la machine,
!>                       ce qui signifie que la matrice est singulière
!>                       à la précision de travail. Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car
!>                       il existe un certain nombre de situations où la
!>                       solution calculée peut être plus précise que la
