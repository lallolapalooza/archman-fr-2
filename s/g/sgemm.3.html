SGEMM

Documentation de la fonction/sous-routine

sous-routine sgemm (caractère transa, caractère transb, entier m, entier n, entier k, réel alpha, réel, dimension(lda,*) a, entier lda, réel, dimension(ldb,*) b, entier ldb, réel beta, réel, dimension(ldc,*) c, entier ldc)

SGEMM

Objectif :

!>
!> SGEMM  effectue l'une des opérations matricielles-matricelles
!>
!>    C := alpha*op( A )*op( B ) + beta*C,
!>
!> où  op( X ) est l'une des suivantes :
!>
!>    op( X ) = X   ou   op( X ) = X**T,
!>
!> alpha et beta sont des scalaires, et A, B et C sont des matrices, avec op( A )
!> une matrice m par k,  op( B )  une matrice  k par n et  C une matrice m par n.
!>

Paramètres

TRANSA 
!>          TRANSA est CHARACTER*1
!>           En entrée, TRANSA spécifie la forme de op( A ) à utiliser dans
!>           la multiplication matricielle comme suit :
!>
!>              TRANSA = 'N' ou 'n',  op( A ) = A.
!>
!>              TRANSA = 'T' ou 't',  op( A ) = A**T.
!>
!>              TRANSA = 'C' ou 'c',  op( A ) = A**T.
!>

TRANSB

!>          TRANSB est CHARACTER*1
!>           En entrée, TRANSB spécifie la forme de op( B ) à utiliser dans
!>           la multiplication matricielle comme suit :
!>
!>              TRANSB = 'N' ou 'n',  op( B ) = B.
!>
!>              TRANSB = 'T' ou 't',  op( B ) = B**T.
!>
!>              TRANSB = 'C' ou 'c',  op( B ) = B**T.
!>

M

!>          M est INTEGER
!>           En entrée,  M  spécifie  le nombre  de lignes  de la  matrice
!>           op( A )  et de la  matrice  C.  M  doit  être  au moins zéro.
!>

N

!>          N est INTEGER
!>           En entrée,  N  spécifie  le nombre  de colonnes  de la matrice
!>           op( B ) et le nombre de colonnes de la matrice C. N doit être
!>           au moins zéro.
!>

K

!>          K est INTEGER
!>           En entrée,  K  spécifie  le nombre de colonnes de la matrice
!>           op( A ) et le nombre de lignes de la matrice op( B ). K doit
!>           être au moins zéro.
!>

ALPHA

!>          ALPHA est REAL
!>           En entrée, ALPHA spécifie le scalaire alpha.
!>

A

!>          A est un tableau de REAL, dimension ( LDA, ka ), où ka est
!>           k  lorsque  TRANSA = 'N' ou 'n',  et est  m  sinon.
!>           Avant l'entrée avec  TRANSA = 'N' ou 'n',  la partie  principale  m par k
!>           du tableau  A  doit contenir la matrice  A,  sinon
!>           la partie principale  k par m  du tableau  A  doit contenir la
!>           matrice A.
!>

LDA

!>          LDA est INTEGER
!>           En entrée, LDA spécifie la première dimension de A telle que déclarée
!>           dans le programme appelant (sous-programme). Lorsque  TRANSA = 'N' ou 'n' alors
!>           LDA doit être au moins  max( 1, m ), sinon  LDA doit être
!>           au moins  max( 1, k ).
!>

B

!>          B est un tableau de REAL, dimension ( LDB, kb ), où kb est
!>           n  lorsque  TRANSB = 'N' ou 'n',  et est  k  sinon.
!>           Avant l'entrée avec  TRANSB = 'N' ou 'n',  la partie  principale  k par n
!>           du tableau  B  doit contenir la matrice  B,  sinon
!>           la partie principale  n par k  du tableau  B  doit contenir la
!>           matrice B.
!>

LDB

!>          LDB est INTEGER
!>           En entrée, LDB spécifie la première dimension de B telle que déclarée
!>           dans le programme appelant (sous-programme). Lorsque  TRANSB = 'N' ou 'n' alors
!>           LDB doit être au moins  max( 1, k ), sinon  LDB doit être
!>           au moins  max( 1, n ).
!>

BETA

!>          BETA est REAL
!>           En entrée,  BETA  spécifie le scalaire  beta.  Lorsque  BETA  est
!>           fourni comme zéro alors C n'a pas besoin d'être défini en entrée.
!>

C

!>          C est un tableau de REAL, dimension ( LDC, N )
!>           Avant l'entrée, la partie principale  m par n  du tableau  C doit
!>           contenir la matrice  C,  sauf lorsque  beta  est zéro, dans quel cas C
!>           n'a pas besoin d'être défini en entrée.
!>           En sortie, le tableau  C  est écrasé par la matrice  m par n
!>           ( alpha*op( A )*op( B ) + beta*C ).
!>

LDC

!>          LDC est INTEGER
!>           En entrée, LDC spécifie la première dimension de C telle que déclarée
!>           dans le programme  appelant (sous-programme).   LDC  doit être
!>           au moins  max( 1, m ).
!>
