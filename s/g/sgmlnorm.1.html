NOM

osgmlnorm - Normaliseur de documents SGML/XML

SYNTAXE

osgmlnorm [-CdeghmnrRvx] [-atype_lien] [-Aarchitecture] [-bbctf] [-ccatalogue] [-Drépertoire...] [-Emax_erreurs...] [-inom...] [-fnom...] [-wavertissement...] [sysid...]

DESCRIPTION

osgmlnorm imprime sur la sortie standard une instance normalisée pour le document SGML contenu dans la concaténation des entités avec les identificateurs système

Lorsque l'instance normalisée est préfixée par la déclaration SGML et le prologue d'origine, elle aura le même ESIS que le document SGML d'origine, à l'exception des points suivants :

* La sortie d'osgmlnorm ne protège pas contre la reconnaissance des délimiteurs de références courtes, donc toute déclaration USEMAP doit être retirée de la DTD.

* L'instance normalisée utilisera les délimiteurs de références, même si l'instance d'origine ne le faisait pas.

* Si des sections marquées sont incluses dans la sortie à l'aide de l'option -m, les noms réservés de référence seront utilisés pour les mots-clés d'état, même si l'instance d'origine ne le faisait pas.

* Toute information ESIS relative à la fonctionnalité SGML LINK sera perdue.

L'instance normalisée n'utilisera aucune fonctionnalité de minimisation de balisage, sauf que :

* Tous les attributs qui n'étaient pas spécifiés dans l'instance d'origine ne seront pas inclus dans l'instance normalisée. (Les attributs actuels seront inclus.)

* Si la valeur déclarée d'un attribut était un groupe de jetons de nom, et qu'une valeur a été spécifiée qui était la même que le nom de l'attribut, alors le nom de l'attribut et l'indicateur de valeur seront omis. Par exemple, avec HTML, osgmlnorm produirait <DL COMPACT> plutôt que <DL COMPACT="COMPACT">

Partie d'un système SGML conforme à la norme internationale ISO 8879 -- Standard Generalized Markup Language. Un système SGML Extended Facilities conforme à l'annexe A de la norme internationale ISO/IEC 10744 -- Hypermedia/Time-based Structuring Language.

Les options suivantes sont disponibles :

-anom, --activate=nom

Rend le doctype ou le linktype nom actif.

-Aarchitecture, --architecture=architecture

Analyse par rapport à l'architecture architecture.

-bbctf, --bctf=bctf

Utilise le BCTF avec le nom bctf pour la sortie.

-csysid, --catalog=sysid

Mappe les identificateurs publics et les noms d'entités vers les identificateurs système en utilisant le fichier d'entrée de catalogue dont l'identificateur système est sysid.

-C, --catalogs

A le même effet que dans onsgmls(1).

-d, --dtd

Produit une déclaration de type de document avec le même identificateur externe que le document d'entrée, et sans sous-ensemble de déclaration interne. Aucune vérification n'est effectuée quant à la validité de l'instance du document par rapport à cette DTD.

-Drépertoire, --directory=répertoire

Recherche dans le répertoire les fichiers spécifiés dans les identificateurs système.

A le même effet que dans onsgmls(1).

-e, --open-entities

Décrit les entités ouvertes dans les messages d'erreur.

--error-numbers

Affiche les numéros d'erreur dans les messages d'erreur.

-h, --help

Affiche un texte d'aide et quitte.

-inom, --include=nom

A le même effet que dans onsgmls(1).

-m, --marked-sections

Produit les sections marquées qui étaient dans l'instance du document d'entrée.

-n, --comments

Produit les commentaires qui étaient dans l'instance du document d'entrée.

-r, --raw

Sortie brute. Ne procède à aucune conversion sur les RS et RE lors de l'impression de l'entité. L'entité aurait typiquement les enregistrements d'attributs du gestionnaire de stockage records=asis.

-R, --restricted

A le même effet que dans onsgmls(1).

-v, --version

Affiche le numéro de version.

-wtype

Contrôle les avertissements et les erreurs selon le type. A le même effet que dans onsgmls(1).
