NOM

sg_map - affiche le mappage entre les périphériques sg et les autres périphériques SCSI

SYNTAXE

sg_map [-a] [-h] [-i] [-n] [-scd] [-sd] [-sr] [-st] [-V] [-x]

DESCRIPTION

Il est parfois difficile de déterminer à quel périphérique SCSI un nom de périphérique sg (par exemple, /dev/sg0) correspond. Cette commande parcourt les périphériques sg et trouve le nom du périphérique disque, lecteur CD ou bande SCSI correspondant (le cas échéant). Les scanners sont un exemple de périphériques SCSI qui n'ont pas de nom de périphérique SCSI alternatif autre que leur nom de périphérique sg.

Cet utilitaire est déprécié et n'a pas été mis à jour depuis des années, seuls les bugs très évidents seront corrigés. Sauf si vous utilisez une ancienne version de Linux (par exemple, série 2.4 ou antérieure), veuillez utiliser un utilitaire comme lsscsi(8) ou les fonctionnalités offertes par udev(8).

OPTIONS

-a
suppose que les périphériques sg ont des noms de périphériques alphabétiques et parcourt /dev/sga, /dev/sgb, etc. Par défaut, le scan est numérique. Notez que les nœuds de périphérique sg avec un index alphabétique sont dépréciés depuis la série 2.2 du noyau Linux.
-h
affiche le message d'utilisation puis quitte.
-i
en plus, effectue une commande INQUIRY standard et affiche les chaînes de fournisseur, produit et révision pour les périphériques trouvés.
-n
suppose que les périphériques sg ont des noms de périphériques numériques et parcourt /dev/sg0, /dev/sg1, etc. Par défaut, le scan est numérique.
-scd
affiche les mappages vers les noms de périphériques de lecteurs CD SCSI de la forme /dev/scd0, /dev/scd1, etc.
-sd
affiche les mappages vers les noms de périphériques de disques SCSI.
-sr
affiche les mappages vers les noms de périphériques de lecteurs CD SCSI de la forme /dev/sr0, /dev/sr1, etc.
-st
affiche les mappages vers les noms de périphériques de bandes SCSI.
-V
affiche la chaîne de version puis quitte (sans autre forme de procès).
-x
après chaque nom de périphérique sg actif, cinq chiffres sont affichés : <numéro_hôte> <bus> <id_scsi> <lun> <type_scsi>

NOTES

Si aucune option commençant par "-s" n'est donnée, le mappage vers tous les noms de périphériques de disques, lecteurs CD et bandes SCSI est affiché.

Si le système de fichiers devfs est présent, une ligne le notant est affichée. La hiérarchie SCSI "native" de devfs rend la relation entre un nom de périphérique sg et tout nom de périphérique disque, lecteur CD ou bande correspondant facile à établir. Cela remplace le besoin de cette commande. Cependant, de nombreuses applications continueront à rechercher les noms de périphériques SCSI Linux dans leurs emplacements traditionnels. [Devfs fournit un démon de compatibilité appelé devfsd dont la configuration par défaut restaure les noms de périphériques Linux dans leurs positions traditionnelles.

Très souvent, les informations de mappage peuvent être obtenues en observant la sortie de la commande : "sg_map". Cependant, si des périphériques ont été ajoutés depuis le démarrage, cela peut être trompeur.

Dans la série 2.6 du noyau Linux, quelque chose de proche du mappage affiché par cet utilitaire peut être trouvé en analysant sysfs. La principale différence est que l'analyse de sysfs montrera le mappage entre les nœuds sg et les autres nœuds de périphériques SCSI en termes de numéros majeurs et mineurs. Alors que majeur 8, mineur 16 sera généralement /dev/sdb, ce n'est pas nécessairement le cas. Les fonctionnalités associées à udev peuvent assigner d'autres noms de nœuds de périphérique au majeur 8, mineur 16. Cette version de sg_map a été étendue pour gérer les noms de nœuds de périphériques disques épars de la forme "/dev/sd<str>" où <str> peut être l'un de [a-z,aa-zz,aaa-zzz]. Voir l'utilitaire sg_map26 pour une méthode plus précise (c'est-à-dire moins de scan de répertoire) pour mapper entre les noms de nœuds sg et les noms de niveau supérieur ; y compris la recherche de noms définis par l'utilisateur.

Cet utilitaire a été écrit à une époque où la connexion à chaud des périphériques SCSI n'était pas prise en charge sous Linux. Il utilisait un algorithme simple pour scanner les nœuds de périphériques sg par ordre numérique ou alphabétique croissant, s'arrêtant après 5 erreurs consécutives.

Dans la série 2.6 du noyau Linux, cet utilitaire utilise sysfs pour trouver les nœuds de périphériques sg actifs et ne vérifie que ceux-ci. Par conséquent, il peut y avoir de grands "trous" dans la numérotation des nœuds de périphériques sg (par exemple, après la suppression d'un adaptateur) et tous les nœuds de périphériques sg actifs seront toujours listés. Cet utilitaire suppose que les nœuds de périphériques sg sont nommés selon les conventions normales et recherche de /dev/sg0 à /dev/sg4095 inclus.

EXEMPLES

Mon système a un disque SCSI, un graveur CD et un lecteur DVD :
$ sg_map
# Note : le pseudo système de fichiers devfs est présent
/dev/sg0 /dev/sda
/dev/sg1 /dev/sr0
/dev/sg2 /dev/sr1

Afin de trouver quel nom de périphérique sg correspond au disque :
$ sg_map -sd
# Note : le pseudo système de fichiers devfs est présent
/dev/sg0 /dev/sda
/dev/sg1
/dev/sg2

L'option "-x" donne la sortie suivante :
sg_map -x
# Note : le pseudo système de fichiers devfs est présent
/dev/sg0 1 0 1 0 0 /dev/sda
/dev/sg1 2 0 4 0 5 /dev/sr0
/dev/sg2 2 0 6 0 5 /dev/sr1

Lorsqu'un scanner SCSI est ajouté, la sortie devient :
$ sg_map
# Note : le pseudo système de fichiers devfs est présent
/dev/sg0 /dev/sda
/dev/sg1 /dev/sr0
/dev/sg2 /dev/sr1
/dev/sg3

Par élimination, /dev/sg3 doit être le scanner.

STATUT DE SORTIE

Le statut de sortie de sg_map est 0 lorsqu'il réussit. Sinon, voir la page de manuel sg3_utils(8).

sg_map -- Mapper les périphériques SCSI

SYNTAXE

sg_map [OPTIONS]

DESCRIPTION

Le programme sg_map liste les périphériques SCSI et leur mappage sur des périphériques de bloc Linux. Il peut être utilisé pour comprendre comment les périphériques SCSI sont présentés au système d'exploitation.

OPTIONS

Actuellement, sg_map n'accepte aucune option spécifique.

STATUT DE SORTIE

0 en cas de succès, un code d'erreur différent en cas d'échec.

EXEMPLES

Pour afficher les périphériques SCSI mappés :

sg_map

ENVIRONNEMENT

Aucune variable d'environnement spécifique n'affecte sg_map.

FICHIERS

Aucun fichier spécifique n'est utilisé par sg_map.
