sous-programme sbdt02 (integer m, integer n, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldc, * ) c, integer ldc, real, dimension( ldu, * ) u, integer ldu, real, dimension( * ) work, real resid)

SBDT02

But:

!>
!> SBDT02 teste le changement de base C = U**H * B en calculant le
!> résidu
!>
!>    RESID = norm(B - U * C) / ( max(m,n) * norm(B) * EPS ),
!>
!> où B et C sont des matrices M par N, U est une matrice orthogonale M par M,
!> et EPS est la précision machine.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes des matrices B et C et l'ordre de
!>          la matrice Q.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes des matrices B et C.
!>

B

!>          B est un tableau REEL, de dimension (LDB,N)
!>          La matrice M par N, B.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,M).
!>

C

!>          C est un tableau REEL, de dimension (LDC,N)
!>          La matrice M par N, C, supposée contenir U**H * B.
!>

LDC

!>          LDC est un ENTIER
!>          La dimension principale du tableau C.  LDC >= max(1,M).
!>

U

!>          U est un tableau REEL, de dimension (LDU,M)
!>          La matrice orthogonale M par M, U.
!>

LDU

!>          LDU est un ENTIER
!>          La dimension principale du tableau U.  LDU >= max(1,M).
!>

WORK

!>          WORK est un tableau REEL, de dimension (M)
!>

RESID

!>          RESID est un REEL
!>          RESID = norm(B - U * C) / ( max(m,n) * norm(B) * EPS ),
!>
