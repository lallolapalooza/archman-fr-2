SBSIGN(1) Commandes utilisateur SBSIGN(1)

NOM

sbsign - Outil de signature pour le démarrage sécurisé UEFI

SYNTAXE

sbsign [options] --key <fichier-clé> --cert <fichier-cert> <image-démarrage-efi>

DESCRIPTION

Signe une image de démarrage EFI pour l'utilisation avec le démarrage sécurisé.

OPTIONS

--engine <moteur>
utilise le moteur spécifié pour charger la clé
--key <fichier-clé>
clé de signature (clé privée RSA encodée en PEM)
--cert <fichier-cert>
certificat (certificat x509)

--addcert <fichier-cert-ajout> certificats intermédiaires supplémentaires dans un fichier

--detached
écrit une signature détachée, au lieu d'un binaire signé
--output <fichier>
écrit les données signées dans <fichier> (par défaut <image-démarrage-efi>.signed, ou <image-démarrage-efi>.pk7 pour les signatures détachées)
