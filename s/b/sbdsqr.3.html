Documentation de la fonction/sous-routine

subroutine sbdsqr (character uplo, integer n, integer ncvt, integer nru, integer ncc, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldvt, * ) vt, integer ldvt, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer info)

SBDSQR

Objectif :

!>
!> SBDSQR calcule les valeurs singulières et, éventuellement, les vecteurs singuliers à droite et/ou à gauche
!> à partir de la décomposition en valeurs singulières (SVD) d'une matrice bidiagonale réelle NxN (supérieure ou inférieure)
!> en utilisant l'algorithme QR implicite à décalage nul. La SVD de B a la forme
!>
!>    B = Q * S * P**T
!>
!> où S est la matrice diagonale des valeurs singulières, Q est une matrice orthogonale de vecteurs singuliers à gauche,
!> et P est une matrice orthogonale de vecteurs singuliers à droite. Si des vecteurs singuliers à gauche sont demandés,
!> cette sous-routine renvoie en fait U*Q au lieu de Q, et, si des vecteurs singuliers à droite sont demandés,
!> cette sous-routine renvoie P**T*VT au lieu de P**T, pour les matrices d'entrée réelles données U et VT.
!> Lorsque U et VT sont les matrices orthogonales qui réduisent une matrice générale A à une forme bidiagonale : A = U*B*VT,
!> comme calculé par SGEBRD, alors
!>
!>    A = (U*Q) * S * (P**T*VT)
!>
!> est la SVD de A. Éventuellement, la sous-routine peut aussi calculer Q**T*C pour une matrice d'entrée réelle C donnée.
!>
!> Voir par J. Demmel et W. Kahan,
!> LAPACK Working Note #3 (ou SIAM J. Sci. Statist. Comput. vol. 11,
!> no. 5, pp. 873-912, sept. 1990) et
!> par
!> B. Parlett et V. Fernando, Technical Report CPAM-554, Mathematics
!> Department, University of California at Berkeley, juillet 1992
!> pour une description détaillée de l'algorithme.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' :  B est supérieurement bidiagonale ;
!>          = 'L' :  B est inférieurement bidiagonale.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice B.  N >= 0.
!>

NCVT

!>          NCVT est INTEGER
!>          Le nombre de colonnes de la matrice VT. NCVT >= 0.
!>

NRU

!>          NRU est INTEGER
!>          Le nombre de lignes de la matrice U. NRU >= 0.
!>

NCC

!>          NCC est INTEGER
!>          Le nombre de colonnes de la matrice C. NCC >= 0.
!>

D

!>          D est tableau REAL, dimension (N)
!>          En entrée, les N éléments diagonaux de la matrice bidiagonale B.
!>          En sortie, si INFO=0, les valeurs singulières de B dans l'ordre décroissant.
!>

E

!>          E est tableau REAL, dimension (N-1)
!>          En entrée, les N-1 éléments hors diagonale de la matrice bidiagonale B.
!>          En sortie, si INFO = 0, E est détruit ; si INFO > 0, D et E contiendront les éléments diagonaux et superdiagonaux
!>          d'une matrice bidiagonale orthogonalement équivalente à celle donnée en entrée.
!>

VT

!>          VT est tableau REAL, dimension (LDVT, NCVT)
!>          En entrée, une matrice VT de dimensions N x NCVT.
!>          En sortie, VT est remplacé par P**T * VT.
!>          Non référencé si NCVT = 0.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT.
!>          LDVT >= max(1,N) si NCVT > 0 ; LDVT >= 1 si NCVT = 0.
!>

U

!>          U est tableau REAL, dimension (LDU, N)
!>          En entrée, une matrice U de dimensions NRU x N.
!>          En sortie, U est remplacé par U * Q.
!>          Non référencé si NRU = 0.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U.  LDU >= max(1,NRU).
!>

C

!>          C est tableau REAL, dimension (LDC, NCC)
!>          En entrée, une matrice C de dimensions N x NCC.
!>          En sortie, C est remplacé par Q**T * C.
!>          Non référencé si NCC = 0.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C.
!>          LDC >= max(1,N) si NCC > 0 ; LDC >=1 si NCC = 0.
!>

WORK

!>          WORK est tableau REAL, dimension (LWORK)
!>          LWORK = 4*N, si NCVT = NRU = NCC = 0, et
!>          LWORK = 4*(N-1), sinon
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  fin de succès
!>          < 0 :  Si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :
!>             si NCVT = NRU = NCC = 0,
!>                = 1, une division a été marquée par une valeur positive dans E
!>                = 2, le bloc actuel de Z n'a pas été diagonalisé après 30*N
!>                     itérations (dans la boucle interne while)
!>                = 3, le critère de terminaison de la boucle externe while n'a pas été satisfait
!>                     (le programme a créé plus de N blocs non réduits)
!>             sinon si NCVT = NRU = NCC = 0,
!>                   l'algorithme n'a pas convergé ; D et E contiennent les
!>                   éléments d'une matrice bidiagonale orthogonalement similaire
!>                   à la matrice d'entrée B ;  si INFO = i, i
!>                   éléments de E n'ont pas convergé vers zéro.
!>

Paramètres internes :

!>  TOLMUL  REAL, défaut = max(10,min(100,EPS**(-1/8)))
!>          TOLMUL contrôle le critère de convergence de la boucle QR.
!>          S'il est positif, TOLMUL*EPS est la précision relative souhaitée
!>             dans les valeurs singulières calculées.
!>          S'il est négatif, abs(TOLMUL*EPS*sigma_max) est la précision absolue souhaitée
!>             dans les valeurs singulières calculées (correspond à une précision relative
!>             abs(TOLMUL*EPS) dans la plus grande valeur singulière.
!>          abs(TOLMUL) doit être compris entre 1 et 1/EPS, et de préférence
!>             entre 10 (pour une convergence rapide) et .1/EPS
!>             (pour qu'il y ait une certaine précision dans les résultats).
!>          Le défaut est de perdre soit un huitième, soit 2 des
!>             chiffres décimaux disponibles dans chaque valeur singulière calculée
!>             (le plus petit des deux).
!>
!>  MAXITR  INTEGER, défaut = 6
!>          MAXITR contrôle le nombre maximum de passages de l'algorithme
!>          dans sa boucle interne. L'algorithme s'arrête
!>          (et échoue donc à converger) si le nombre de passages
!>          dans la boucle interne dépasse MAXITR*N**2.
!>

Note :

!>  Rapport de bug de Cezary Dendek.
!>  Le 23 mars 2017, la variable INTEGER MAXIT = MAXITR*N**2 a été
!>  supprimée car elle pouvait facilement déborder (pour N supérieur ou égal
!>  à 18 919). Nous utilisons à la place MAXITDIVN = MAXITR*N.
!>
