programme sblat3

SBLAT3

Objectif :

!>
!> Programme de test pour les Blas de Niveau 3 REELS.
!>
!> Le programme doit être piloté par un court fichier de données. Les 14 premières
!> lignes du fichier sont lues en utilisant l'entrée par liste dirigée, les 7 dernières
!> lignes sont lues en utilisant le format ( A7, L2 ). Un exemple annoté d'un fichier de
!> données peut être obtenu en supprimant les 3 premiers caractères des
!> 20 lignes suivantes :
!> 'sblat3.out'      NOM DU FICHIER DE SORTIE RÉSUMÉ
!> 6                 NUMÉRO D'UNITÉ DU FICHIER RÉSUMÉ
!> 'SBLAT3.SNAP'     NOM DU FICHIER DE SORTIE INSTANTANÉ
!> -1                NUMÉRO D'UNITÉ DU FICHIER INSTANTANÉ (NON UTILISÉ SI .LT. 0)
!> F        INDICATEUR LOGIQUE, T POUR REMbobiner le FICHIER INSTANTANÉ APRÈS CHAQUE ENREGISTREMENT.
!> F        INDICATEUR LOGIQUE, T POUR ARRÊTER EN CAS D'ÉCHEC.
!> T        INDICATEUR LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR SEUIL DU RAPPORT DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 3                 NOMBRE DE VALEURS D'ALPHA
!> 0.0 1.0 0.7       VALEURS D'ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> 0.0 1.0 1.3       VALEURS DE BETA
!> SGEMM  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> SSYMM  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> STRMM  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> STRSM  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> SSYRK  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> SSYR2K T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> SGEMMTR T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!>
!> Détails Supplémentaires
!> =======================
!>
!> Voir :
!>
!>    Dongarra J. J., Du Croz J. J., Duff I. S. et Hammarling S.
!>    Un Ensemble de Sous-programmes de Base d'Algèbre Linéaire de Niveau 3.
!>
!>    Memorandum Technique No.88 (Révision 1), Division Mathématiques et
!>    Informatique, Argonne National Laboratory, 9700
!>    South Cass Avenue, Argonne, Illinois 60439, US.
!>
!> -- Écrit le 8 février 1989.
!>    Jack Dongarra, Argonne National Laboratory.
!>    Iain Duff, AERE Harwell.
!>    Jeremy Du Croz, Numerical Algorithms Group Ltd.
!>    Sven Hammarling, Numerical Algorithms Group Ltd.
!>
!>    10-9-00 : Changer STATUS='NEW' en 'UNKNOWN' afin que les testeurs
!>              puissent être exécutés plusieurs fois sans supprimer les fichiers
!>              de sortie générés (susan)
!>
