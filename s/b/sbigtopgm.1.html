NOM

sbigtopgm - convertir un fichier SBIG CCDOPS en PGM

SYNTAXE

sbigtopgm

[fichier_sbig]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

sbigtopgm lit un fichier image dans le format natif utilisé par les caméras CCD astronomiques de Santa Barbara Instrument Group (SBIG), et produit une image PGM en sortie. Des informations supplémentaires sur les caméras SBIG et la documentation du format de fichier sont disponibles sur le site Web, http://www.sbig.com/ .

VOIR AUSSI

pgm(5)
