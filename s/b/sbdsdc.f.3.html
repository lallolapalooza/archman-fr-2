Documentation de la fonction/sous-programme

sous-routine sbdsdc (character uplo, character compq, integer n, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldvt, * ) vt, integer ldvt, real, dimension( * ) q, integer, dimension( * ) iq, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SBDSDC

Objectif :

!>
!> SBDSDC calcule la décomposition en valeurs singulières (SVD) d'une matrice
!> bidiagonale réelle N-par-N (supérieure ou inférieure) B :  B = U * S * VT,
!> en utilisant une méthode de diviser pour régner, où S est une matrice diagonale
!> avec des éléments diagonaux non négatifs (les valeurs singulières de B), et
!> U et VT sont des matrices orthogonales de vecteurs singuliers gauches et droits,
!> respectivement. SBDSDC peut être utilisé pour calculer toutes les valeurs singulières,
!> et optionnellement, les vecteurs singuliers ou les vecteurs singuliers sous forme compacte.
!>
!> Le code appelle actuellement SLASDQ si seules les valeurs singulières sont désirées.
!> Cependant, il peut être légèrement modifié pour calculer les valeurs singulières
!> en utilisant la méthode de diviser pour régner.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' :  B est supérieure bidiagonale.
!>          = 'L' :  B est inférieure bidiagonale.
!>

COMPQ

!>          COMPQ est CHARACTER*1
!>          Spécifie si les vecteurs singuliers doivent être calculés
!>          comme suit :
!>          = 'N' : Calculer uniquement les valeurs singulières ;
!>          = 'P' : Calculer les valeurs singulières et calculer les vecteurs
!>                  singuliers sous forme compacte ;
!>          = 'I' : Calculer les valeurs singulières et les vecteurs singuliers.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice B.  N >= 0.
!>

D

!>          D est un tableau REAL, dimension (N)
!>          En entrée, les n éléments diagonaux de la matrice bidiagonale B.
!>          En sortie, si INFO=0, les valeurs singulières de B.
!>

E

!>          E est un tableau REAL, dimension (N-1)
!>          En entrée, les éléments de E contiennent les éléments hors diagonale
!>          de la matrice bidiagonale dont la SVD est désirée.
!>          En sortie, E est détruit.
!>

U

!>          U est un tableau REAL, dimension (LDU,N)
!>          Si  COMPQ = 'I', alors :
!>             En sortie, si INFO = 0, U contient les vecteurs singuliers gauches
!>             de la matrice bidiagonale.
!>          Pour les autres valeurs de COMPQ, U n'est pas référencé.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U.  LDU >= 1.
!>          Si des vecteurs singuliers sont désirés, alors LDU >= max( 1, N ).
!>

VT

!>          VT est un tableau REAL, dimension (LDVT,N)
!>          Si  COMPQ = 'I', alors :
!>             En sortie, si INFO = 0, VT**T contient les vecteurs singuliers
!>             droits de la matrice bidiagonale.
!>          Pour les autres valeurs de COMPQ, VT n'est pas référencé.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT.  LDVT >= 1.
!>          Si des vecteurs singuliers sont désirés, alors LDVT >= max( 1, N ).
!>

Q

!>          Q est un tableau REAL, dimension (LDQ)
!>          Si  COMPQ = 'P', alors :
!>             En sortie, si INFO = 0, Q et IQ contiennent les vecteurs
!>             singuliers gauches et droits sous forme compacte,
!>             nécessitant un espace O(N log N) au lieu de 2*N**2.
!>             En particulier, Q contient toutes les données REAL dans
!>             LDQ >= N*(11 + 2*SMLSIZ + 8*INT(LOG_2(N/(SMLSIZ+1))))
!>             mots de mémoire, où SMLSIZ est retourné par ILAENV et
!>             est égal à la taille maximale des sous-problèmes au bas
!>             de l'arbre de calcul (généralement environ 25).
!>          Pour les autres valeurs de COMPQ, Q n'est pas référencé.
!>

IQ

!>          IQ est un tableau INTEGER, dimension (LDIQ)
!>          Si  COMPQ = 'P', alors :
!>             En sortie, si INFO = 0, Q et IQ contiennent les vecteurs
!>             singuliers gauches et droits sous forme compacte,
!>             nécessitant un espace O(N log N) au lieu de 2*N**2.
!>             En particulier, IQ contient toutes les données INTEGER dans
!>             LDIQ >= N*(3 + 3*INT(LOG_2(N/(SMLSIZ+1))))
!>             mots de mémoire, où SMLSIZ est retourné par ILAENV et
!>             est égal à la taille maximale des sous-problèmes au bas
!>             de l'arbre de calcul (généralement environ 25).
!>          Pour les autres valeurs de COMPQ, IQ n'est pas référencé.
!>

WORK

!>          WORK est un tableau REAL, dimension (MAX(1,LWORK))
!>          Si COMPQ = 'N' alors LWORK >= (4 * N).
!>          Si COMPQ = 'P' alors LWORK >= (6 * N).
!>          Si COMPQ = 'I' alors LWORK >= (3 * N**2 + 4 * N).
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (8*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : l'algorithme n'a pas réussi à calculer une valeur singulière.
!>                Le processus de mise à jour de diviser pour régner a échoué.
!>
