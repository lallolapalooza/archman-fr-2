sous-programme sbdt03 (caractère uplo, entier n, entier kd, réel, dimension( * ) d, réel, dimension( * ) e, réel, dimension( ldu, * ) u, entier ldu, réel, dimension( * ) s, réel, dimension( ldvt, * ) vt, entier ldvt, réel, dimension( * ) work, réel resid)

SBDT03

But:

!>
!> SBDT03 reconstruit une matrice bidiagonale B à partir de sa SVD :
!>    S = U' * B * V
!> où U et V sont des matrices orthogonales et S est diagonale.
!>
!> Le rapport de test pour tester la décomposition en valeurs singulières est
!>    RESID = norm( B - U * S * VT ) / ( n * norm(B) * EPS )
!> où VT = V' et EPS est la précision machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice B est bidiagonale supérieure ou inférieure.
!>          = 'U':  Bidiagonale supérieure
!>          = 'L':  Bidiagonale inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice B.
!>

KD

!>          KD est INTEGER
!>          La bande de la matrice bidiagonale B. Si KD = 1, la
!>          matrice B est bidiagonale, et si KD = 0, B est diagonale et E n'est
!>          pas référencée. Si KD est supérieur à 1, il est supposé être
!>          1, et si KD est inférieur à 0, il est supposé être 0.
!>

D

!>          D est un tableau REAL de dimension (N)
!>          Les n éléments diagonaux de la matrice bidiagonale B.
!>

E

!>          E est un tableau REAL de dimension (N-1)
!>          Les (n-1) éléments superdiagonaux de la matrice bidiagonale B
!>          si UPLO = 'U', ou les (n-1) éléments sous-diagonaux de B si
!>          UPLO = 'L'.
!>

U

!>          U est un tableau REAL de dimension (LDU,N)
!>          La matrice orthogonale n par n, U, dans la réduction B = U'*A*P.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= max(1,N)
!>

S

!>          S est un tableau REAL de dimension (N)
!>          Les valeurs singulières de la SVD de B, triées par ordre
!>          décroissant.
!>

VT

!>          VT est un tableau REAL de dimension (LDVT,N)
!>          La matrice orthogonale n par n, V', dans la réduction
!>          B = U * S * V'.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT.
!>

WORK

!>          WORK est un tableau REAL de dimension (2*N)
!>

RESID

!>          RESID est REAL
!>          Le rapport de test : norm(B - U * S * V') / ( n * norm(A) * EPS )
!>
