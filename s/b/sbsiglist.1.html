NOM

sbsiglist - Créer des bases de données de signatures EFI_SIGNATURE_LIST

SYNTAXE

sbsiglist [options] --owner <guid> --type <type> <sig-file>

DESCRIPTION

Crée une EFI_SIGNATURE_LIST à partir d'un fichier de signatures. Options :

--owner <guid>
GUID du propriétaire de la signature
--type <type>
Type de signature. Un parmi : x509 sha256
--output <fichier>
écrire les données signées dans <fichier> (par défaut <sig-file>.siglist)
