programme sblat2

SBLAT2

Objectif :

!>
!> Programme de test pour les BLAS Réels de Niveau 2.
!>
!> Le programme doit être piloté par un court fichier de données. Les 18 premiers enregistrements
!> du fichier sont lus en utilisant une entrée dirigée par liste, les 16 derniers enregistrements
!> sont lus en utilisant le format ( A6, L2 ). Un exemple annoté d'un fichier de données
!> peut être obtenu en supprimant les 3 premiers caractères des
!> 34 lignes suivantes :
!> 'sblat2.out'      NOM DU FICHIER DE SORTIE RÉCAPITULATIF
!> 6                 NUMÉRO D'UNITÉ DU FICHIER DE SORTIE RÉCAPITULATIF
!> 'SBLAT2.SNAP'     NOM DU FICHIER DE SORTIE SNAPSHOT
!> -1                NUMÉRO D'UNITÉ DU FICHIER SNAPSHOT (NON UTILISÉ SI .LT. 0)
!> F        INDICATEUR LOGIQUE, T POUR REMbobiner le FICHIER SNAPSHOT APRÈS CHAQUE ENREGISTREMENT.
!> F        INDICATEUR LOGIQUE, T POUR ARRÊTER EN CAS D'ÉCHEC.
!> T        INDICATEUR LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR SEUIL DU RAPPORT DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 4                 NOMBRE DE VALEURS DE K
!> 0 1 2 4           VALEURS DE K
!> 4                 NOMBRE DE VALEURS DE INCX ET INCY
!> 1 2 -1 -2         VALEURS DE INCX ET INCY
!> 3                 NOMBRE DE VALEURS DE ALPHA
!> 0.0 1.0 0.7       VALEURS DE ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> 0.0 1.0 0.9       VALEURS DE BETA
!> SGEMV  T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> SGBMV  T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> SSYMV  T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> SSBMV  T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> SSPMV  T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> STRMV  T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> STBMV  T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> STPMV  T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> STRSV  T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> STBSV  T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> STPSV  T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> SGER   T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> SSYR   T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> SSPR   T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> SSYR2  T PUT F POUR PAS DE TEST. MÊMES COLONNES.
!> SSPR2  T PUT F POUR PAS DE TEST. MÊMES COLONNES.
