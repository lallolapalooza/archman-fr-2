sous-routine sbdt01 (entier m, entier n, entier kd, reel, dimension( lda, * ) a, entier lda, reel, dimension( ldq, * ) q, entier ldq, reel, dimension( * ) d, reel, dimension( * ) e, reel, dimension( ldpt, * ) pt, entier ldpt, reel, dimension( * ) work, reel resid)

SBDT01

But:

!>
!> SBDT01 reconstruit une matrice générale A à partir de sa forme bidiagonale
!>    A = Q * B * P**T
!> où Q (m par min(m,n)) et P**T (min(m,n) par n) sont des matrices orthogonales
!> et B est bidiagonale.
!>
!> Le ratio de test pour vérifier la réduction est
!>    RESID = norm(A - Q * B * P**T) / ( n * norm(A) * EPS )
!> où EPS est la précision de la machine.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes des matrices A et Q.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes des matrices A et P**T.
!>

KD

!>          KD est ENTIER
!>          Si KD = 0, B est diagonale et le tableau E n'est pas référencé.
!>          Si KD = 1, la réduction a été effectuée par xGEBRD ; B est upper
!>          bidiagonale si M >= N, et lower bidiagonale si M < N.
!>          Si KD = -1, la réduction a été effectuée par xGBBRD ; B est
!>          toujours upper bidiagonale.
!>

A

!>          A est tableau REEL, dimension (LDA,N)
!>          La matrice A de taille m par n.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

Q

!>          Q est tableau REEL, dimension (LDQ,N)
!>          La matrice orthogonale Q de taille m par min(m,n) dans la réduction
!>          A = Q * B * P**T.
!>

LDQ

!>          LDQ est ENTIER
!>          La dimension principale du tableau Q.  LDQ >= max(1,M).
!>

D

!>          D est tableau REEL, dimension (min(M,N))
!>          Les éléments diagonaux de la matrice bidiagonale B.
!>

E

!>          E est tableau REEL, dimension (min(M,N)-1)
!>          Les éléments superdiagonaux de la matrice bidiagonale B si
!>          m >= n, ou les éléments sous-diagonaux de B si m < n.
!>

PT

!>          PT est tableau REEL, dimension (LDPT,N)
!>          La matrice orthogonale P**T de taille min(m,n) par n dans la réduction
!>          A = Q * B * P**T.
!>

LDPT

!>          LDPT est ENTIER
!>          La dimension principale du tableau PT.
!>          LDPT >= max(1,min(M,N)).
!>

WORK

!>          WORK est tableau REEL, dimension (M+N)
!>

RESID

!>          RESID est REEL
!>          Le ratio de test:
!>          norm(A - Q * B * P**T) / ( n * norm(A) * EPS )
!>
