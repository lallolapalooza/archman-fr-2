sbcast(1) Commandes Slurm sbcast(1)

NOM

sbcast - transmet un fichier aux nœuds alloués pour un job Slurm.

SYNTAXE

sbcast [-CfFjpstvV] SOURCE DEST

DESCRIPTION

sbcast est utilisé pour transmettre un fichier à tous les nœuds alloués pour le job Slurm actif. Cette commande ne doit être exécutée qu'à l'intérieur d'un job batch Slurm ou dans le shell lancé après une allocation de ressources d'un job Slurm. SOURCE est le nom d'un fichier sur le nœud courant. DEST doit être le chemin d'accès complet pour la copie du fichier à créer sur chaque nœud. Si un chemin d'accès complet n'est pas fourni, le fichier sera créé dans le répertoire spécifié par le paramètre BcastParameters dans le fichier slurm.conf (si disponible), sinon il sera créé dans le répertoire de travail courant depuis lequel la commande sbcast est invoquée. DEST doit se trouver sur un système de fichiers local à ce nœud. Notez que les systèmes de fichiers parallèles *peuvent* offrir de meilleures performances que ce que sbcast peut fournir, bien que les performances varient en fonction de la taille du fichier, du degré de parallélisme et du type de réseau.

OPTIONS

-C, --compress[=bibliothèque]
Compresse le fichier transmis. L'argument optionnel spécifie la bibliothèque de compression de données à utiliser. Les valeurs supportées sont "lz4" (par défaut) et "none". Certaines bibliothèques de compression peuvent ne pas être disponibles sur certains systèmes. La bibliothèque de compression par défaut (et l'activation de la compression elle-même) peut être définie dans le fichier slurm.conf en utilisant l'option BcastParameters.
--exclude=<AUCUN|chemin1,...,cheminN>
Liste séparée par des virgules de chemins de répertoires absolus à exclure lors de la détection automatique et de la diffusion des dépendances d'objets partagés exécutables. Si le mot-clé "AUCUN" est configuré, aucun chemin de répertoire ne sera exclu. La valeur par défaut est celle de slurm.conf BcastExclude et cette option la remplace. Voir aussi --send-libs.
-f, --force
Si le fichier de destination (et le répertoire de bibliothèques de destination lors de l'utilisation de --send-libs) existe déjà, il est remplacé.
-j, --jobid=<jobID[+hetjobOffset].[stepID]>
Spécifie l'ID du job à utiliser avec un décalage hetjob et/ou un ID d'étape optionnels. S'il est exécuté dans une allocation, ceci est inutile car l'ID du job sera lu depuis l'environnement.
-Z, --no-allocation
Transmet des fichiers à une liste de nœuds indépendamment des jobs qu'ils pourraient exécuter. Ceci ne peut être fait que par SlurmUser/root.

--nodelist doit être utilisé avec cette option.

-w, --nodelist=<liste_noms_nœuds>
Liste des hôtes auxquels transmettre les fichiers. Ces nœuds doivent être un sous-ensemble du job ciblé, ou l'option --no-allocation doit être utilisée.
-p, --preserve
Préserve les temps de modification, les temps d'accès et les modes du fichier d'origine.
--send-libs[=oui|non]
Si défini sur oui (ou sans argument), détecte et diffuse les dépendances d'objets partagés de l'exécutable vers les nœuds de calcul alloués. Les fichiers sont placés dans un répertoire à côté de l'exécutable. Ceci remplace le comportement par défaut configuré dans slurm.conf SbcastParameters send_libs. Voir aussi --exclude.
-s, --size=<taille>
Spécifie la taille du bloc utilisée pour la diffusion du fichier. La taille peut avoir un suffixe de k ou m pour kilooctets ou mégaoctets respectivement (par défaut en octets). Cette taille est sujette à des arrondis et à des limites de plage pour maintenir de bonnes performances. La valeur par défaut est la taille du fichier ou 8 Mo, le plus petit des deux. Cette valeur peut devoir être définie sur les systèmes avec une mémoire très limitée.
-t, --timeout=<secondes>
Spécifie le délai d'attente du message en secondes. La valeur par défaut est MessageTimeout telle que rapportée par "scontrol show config". Définir une valeur plus élevée peut être nécessaire en raison de performances d'E/S relativement lentes sur les disques des nœuds de calcul.
-F, --treewidth=<nombre>
Spécifie la largeur de l'arbre des messages utilisés pour le transfert de fichiers. La valeur maximale est actuellement de 64. Une valeur de "off" désactive la diffusion en éventail.
-v, --verbose
Fournit des journaux d'événements détaillés tout au long de l'exécution du programme.
-V, --version
Affiche les informations de version et quitte.

PERFORMANCE

L'exécution de sbcast envoie un appel de procédure distante à slurmctld. Si suffisamment d'appels provenant de sbcast ou d'autres commandes client Slurm qui envoient des appels de procédure distante au démon slurmctld arrivent simultanément, cela peut entraîner une dégradation des performances du démon slurmctld, pouvant potentiellement entraîner un déni de service.

N'exécutez pas sbcast ou d'autres commandes client Slurm qui envoient des appels de procédure distante à slurmctld à partir de boucles dans des scripts shell ou d'autres programmes. Assurez-vous que les programmes limitent les appels à sbcast au minimum nécessaire pour les informations que vous essayez de collecter.

VARIABLES D'ENVIRONNEMENT

Certaines options de sbcast peuvent être définies via des variables d'environnement. Ces variables d'environnement, ainsi que leurs options correspondantes, sont listées ci-dessous. (Note : les options en ligne de commande remplacent toujours ces paramètres.)

SBCAST_COMPRESS
-C, --compress
SBCAST_EXCLUDE
--exclude=<AUCUN|chemin1,...,cheminN>
SBCAST_FANOUT
-F nombre, --fanout=nombre
SBCAST_FORCE
-f, --force
SBCAST_SEND_LIBS
--send-libs[=oui|non]
SBCAST_PRESERVE
-p, --preserve
SBCAST_SIZE
-s taille, --size=taille
SBCAST_TIMEOUT
-t secondes, --timeout=secondes
SBCAST_TREewidth
-F nombre, --treewidth=nombre
SBCAST_VERBOSE
-v, --verbose

EXEMPLES

Transmet le fichier ./my_data.txt à tous les nœuds de l'allocation actuelle, en le nommant /tmp/my_data.txt sur chaque nœud.

sbcast ./my_data.txt /tmp/my_data.txt

Transmet le fichier ./my_program à tous les nœuds de l'allocation actuelle, en le nommant ./my_program sur chaque nœud, et transmet également les bibliothèques partagées nécessaires.

sbcast --send-libs ./my_program ./my_program

Transmet le fichier ./my_program à tous les nœuds de l'allocation actuelle, en le nommant ./my_program sur chaque nœud, en utilisant la compression lz4 et en remplaçant les fichiers existants.

sbcast -C -f --send-libs ./my_program ./my_program

AUTORISATION

Lors de l'utilisation de SlurmDBD, les utilisateurs ayant un AdminLevel défini (Opérateur ou Admin) sont autorisés à invoquer sbcast sur les tâches d'autres utilisateurs.

EXEMPLES

Utilisation d'un script de traitement par lots pour transmettre le fichier local my.prog vers /tmp/my.prog sur les nœuds locaux, puis pour l'exécuter.

$ cat my.job
#!/bin/bash
sbcast my.prog /tmp/my.prog
srun /tmp/my.prog
$ sbatch --nodes=8 my.job
srun: jobid 12345 submitted
