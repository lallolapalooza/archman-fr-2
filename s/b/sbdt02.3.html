Documentation de la fonction/sous-routine

sous-routine sbdt02 (integer m, integer n, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldc, * ) c, integer ldc, real, dimension( ldu, * ) u, integer ldu, real, dimension( * ) work, real resid)

SBDT02

Objectif :

!>
!> SBDT02 teste le changement de base C = U**H * B en calculant le
!> résidu
!>
!>    RESID = norm(B - U * C) / ( max(m,n) * norm(B) * EPS ),
!>
!> où B et C sont des matrices de taille M par N, U est une matrice orthogonale
!> M par M, et EPS est la précision machine.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes des matrices B et C et l'ordre de la matrice Q.
!>

N

!>          N est un entier
!>          Le nombre de colonnes des matrices B et C.
!>

B

!>          B est un tableau de réels, dimension (LDB,N)
!>          La matrice B de taille m par n.
!>

LDB

!>          LDB est un entier
!>          La dimension principale du tableau B.  LDB >= max(1,M).
!>

C

!>          C est un tableau de réels, dimension (LDC,N)
!>          La matrice C de taille m par n, supposée contenir U**H * B.
!>

LDC

!>          LDC est un entier
!>          La dimension principale du tableau C.  LDC >= max(1,M).
!>

U

!>          U est un tableau de réels, dimension (LDU,M)
!>          La matrice orthogonale U de taille m par m.
!>

LDU

!>          LDU est un entier
!>          La dimension principale du tableau U.  LDU >= max(1,M).
!>

WORK

!>          WORK est un tableau de réels, dimension (M)
!>

RESID

!>          RESID est un réel
!>          RESID = norm(B - U * C) / ( max(m,n) * norm(B) * EPS ),
!>
