programme sblat2

SBLAT2

Objectif :

!>
!> Programme de test pour le Niveau 2 BLAS REEL.
!>
!> Le programme doit être piloté par un court fichier de données. Les 18 premières lignes
!> du fichier sont lues en utilisant l'entrée dirigée par liste, les 16 dernières lignes
!> sont lues en utilisant le format ( A6, L2 ). Un exemple annoté d'un fichier de données
!> peut être obtenu en supprimant les 3 premiers caractères des
!> 34 lignes suivantes :
!> 'sblat2.out'      NOM DU FICHIER DE SOMMAIRE
!> 6                 NUMÉRO D'UNITÉ DU FICHIER DE SOMMAIRE
!> 'SBLAT2.SNAP'     NOM DU FICHIER DE SORTIE DEistantANÉ
!> -1                NUMÉRO D'UNITÉ DU FICHIER DEistantANÉ (NON UTILISÉ SI .LT. 0)
!> F        INDICATEUR LOGIQUE, T POUR REMbobiner le FICHIER DEistantANÉ APRÈS CHAQUE LIGNE.
!> F        INDICATEUR LOGIQUE, T POUR ARRÊTER EN CAS D'ÉCHEC.
!> T        INDICATEUR LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR SEUIL DU RAPPORT DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 4                 NOMBRE DE VALEURS DE K
!> 0 1 2 4           VALEURS DE K
!> 4                 NOMBRE DE VALEURS DE INCX ET INCY
!> 1 2 -1 -2         VALEURS DE INCX ET INCY
!> 3                 NOMBRE DE VALEURS DE ALPHA
!> 0.0 1.0 0.7       VALEURS DE ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> 0.0 1.0 0.9       VALEURS DE BETA
!> SGEMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> SGBMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> SSYMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> SSBMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> SSPMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> STRMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> STBMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> STPMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> STRSV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> STBSV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> STPSV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> SGER   T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> SSYR   T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> SSPR   T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> SSYR2  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> SSPR2  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
