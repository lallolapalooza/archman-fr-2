sous-programme sbdt04 (caractère uplo, entier n, réel, dimension( * ) d, réel, dimension( * ) e, réel, dimension( * ) s, entier ns, réel, dimension( ldu, * ) u, entier ldu, réel, dimension( ldvt, * ) vt, entier ldvt, réel, dimension( * ) work, réel resid)

SBDT04

But :

!>
!> SBDT04 reconstruit une matrice bidiagonale B à partir de sa SVD (partielle) :
!>    S = U' * B * V
!> où U et V sont des matrices orthogonales et S est diagonale.
!>
!> Le rapport de test pour tester la décomposition en valeurs singulières est
!>    RESID = norm( S - U' * B * V ) / ( n * norm(B) * EPS )
!> où VT = V' et EPS est la précision machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice B est supérieure ou inférieure bidiagonale.
!>          = 'U' : Bidiagonale supérieure
!>          = 'L' : Bidiagonale inférieure
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice B.
!>

D

!>          D est tableau REEL, dimension (N)
!>          Les n éléments diagonaux de la matrice bidiagonale B.
!>

E

!>          E est tableau REEL, dimension (N-1)
!>          Les (n-1) éléments superdiagonaux de la matrice bidiagonale B
!>          si UPLO = 'U', ou les (n-1) éléments subdiagonaux de B si
!>          UPLO = 'L'.
!>

S

!>          S est tableau REEL, dimension (NS)
!>          Les valeurs singulières de la SVD (partielle) de B, triées par
!>          ordre décroissant.
!>

NS

!>          NS est ENTIER
!>          Le nombre de valeurs/vecteurs singuliers de la SVD (partielle)
!>          de B.
!>

U

!>          U est tableau REEL, dimension (LDU,NS)
!>          La matrice orthogonale n x ns, U, dans S = U' * B * V.
!>

LDU

!>          LDU est ENTIER
!>          La dimension principale du tableau U. LDU >= max(1,N)
!>

VT

!>          VT est tableau REEL, dimension (LDVT,N)
!>          La matrice orthogonale n x ns, V, dans S = U' * B * V.
!>

LDVT

!>          LDVT est ENTIER
!>          La dimension principale du tableau VT.
!>

WORK

!>          WORK est tableau REEL, dimension (2*N)
!>

RESID

!>          RESID est REEL
!>          Le rapport de test : norm(S - U' * B * V) / ( n * norm(B) * EPS )
!>
