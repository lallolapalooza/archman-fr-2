NOM

sbvarsign - Outil de signature de variable UEFI authentifiée

SYNOPIS

sbvarsign [options] --key <fichier-clé> --cert <fichier-cert> <nom-var> <fichier-données-var>

DESCRIPTION

Signe un bloc de données pour utilisation dans SetVariable().

OPTIONS

--engine <moteur>
utilise le moteur spécifié pour charger la clé
--key <fichier-clé>
clé de signature (clé privée RSA encodée en PEM)
--cert <fichier-cert>
certificat (certificat x509)
--include-attrs
inclut les attributs au début du fichier de sortie
--guid <GUID>
GUID EFI pour la variable. Si omis, EFI_IMAGE_SECURITY_DATABASE ou EFI_GLOBAL_VARIABLE (selon <nom-var>) sera utilisé.
--attr <attributs>
attributs de la variable. Un ou plusieurs parmi : NON_VOLATILE BOOTSERVICE_ACCESS RUNTIME_ACCESS TIME_BASED_AUTHENTICATED_WRITE_ACCESS APPEND_WRITE
Séparez plusieurs attributs par une virgule,
par défaut, tous les attributs sont inclus, TIME_BASED_AUTH... est toujours inclus.
--output <fichier>
écrit les données signées dans <fichier> (par défaut <fichier-données-var>.signed)
