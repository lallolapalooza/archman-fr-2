SBATTACH(1) Commandes utilisateur SBATTACH(1)

NOM

sbattach - Outil de signature détachée pour le démarrage sécurisé UEFI

SYNTAXE

sbattach --attach <fichier_sig> <image_de_démarrage_efi>
sbattach --detach <fichier_sig> [--remove] <image_de_démarrage_efi>
sbattach --remove <image_de_démarrage_efi>

DESCRIPTION

Attache ou détache un fichier de signature à/depuis une image de démarrage.

OPTIONS

--attach <fichier_sig>
définit <fichier_sig> comme table de signature de l'image de démarrage.
--detach <fichier_sig>
copie la table de signature de l'image de démarrage vers <fichier_sig>.
--remove
supprime la table de signature de l'image de démarrage du fichier d'origine.
--signum
signature à utiliser (par défaut la première).
