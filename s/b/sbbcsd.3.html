But :

!>
!> SBBCSD calcule la décomposition CS d'une matrice orthogonale sous forme
!> de bloc bidiagonal,
!>
!>
!>     [ B11 | B12 0  0 ]
!>     [  0  |  0 -I  0 ]
!> X = [----------------]
!>     [ B21 | B22 0  0 ]
!>     [  0  |  0  0  I ]
!>
!>                               [  C | -S  0  0 ]
!>                   [ U1 |    ] [  0 |  0 -I  0 ] [ V1 |    ]**T
!>                 = [---------] [---------------] [---------]   .
!>                   [    | U2 ] [  S |  C  0  0 ] [    | V2 ]
!>                               [  0 |  0  0  I ]
!>
!> X est de taille M par M, son bloc supérieur gauche est de taille P par Q,
!> et Q ne doit pas être plus grand que P, M-P, ou M-Q. (Si Q n'est pas
!> l'indice le plus petit, alors X doit être transposée et/ou permutée.
!> Ceci peut être fait en temps constant en utilisant les options TRANS
!> et SIGNS. Voir SORCSD pour les détails.)
!>
!> Les matrices bidiagonales B11, B12, B21 et B22 sont représentées
!> implicitement par les angles THETA(1:Q) et PHI(1:Q-1).
!>
!> Les matrices orthogonales U1, U2, V1T et V2T sont en entrée/sortie.
!> Les matrices d'entrée sont pré- ou post-multipliées par les matrices
!> de vecteurs singuliers appropriées.
!>

Paramètres

JOBU1 
!>          JOBU1 est CARACTERE
!>          = 'Y' : U1 est mis à jour ;
!>          sinon : U1 n'est pas mis à jour.
!>

JOBU2

!>          JOBU2 est CARACTERE
!>          = 'Y' : U2 est mis à jour ;
!>          sinon : U2 n'est pas mis à jour.
!>

JOBV1T

!>          JOBV1T est CARACTERE
!>          = 'Y' : V1T est mis à jour ;
!>          sinon : V1T n'est pas mis à jour.
!>

JOBV2T

!>          JOBV2T est CARACTERE
!>          = 'Y' : V2T est mis à jour ;
!>          sinon : V2T n'est pas mis à jour.
!>

TRANS

!>          TRANS est CARACTERE
!>          = 'T' : X, U1, U2, V1T et V2T sont stockés en ordre ligne par ligne ;
!>          sinon : X, U1, U2, V1T et V2T sont stockés en ordre colonne par colonne.
!>

M

!>          M est ENTIER
!>          Le nombre de lignes et de colonnes de X, la matrice orthogonale
!>          sous forme de bloc bidiagonal.
!>

P

!>          P est ENTIER
!>          Le nombre de lignes du bloc supérieur gauche de X. 0 <= P <= M.
!>

Q

!>          Q est ENTIER
!>          Le nombre de colonnes du bloc supérieur gauche de X.
!>          0 <= Q <= MIN(P,M-P,M-Q).
!>

THETA

!>          THETA est tableau REEL, dimension (Q)
!>          En entrée, les angles THETA(1),...,THETA(Q) qui, avec
!>          PHI(1), ...,PHI(Q-1), définissent la matrice sous forme de bloc
!>          bidiagonal. En sortie, les angles dont les cosinus et sinus définissent
!>          les blocs diagonaux de la décomposition CS.
!>

PHI

!>          PHI est tableau REEL, dimension (Q-1)
!>          Les angles PHI(1),...,PHI(Q-1) qui, avec THETA(1),...,
!>          THETA(Q), définissent la matrice sous forme de bloc bidiagonal.
!>

U1

!>          U1 est tableau REEL, dimension (LDU1,P)
!>          En entrée, une matrice P-par-P. En sortie, U1 est post-multipliée
!>          par la matrice de vecteurs singuliers gauches commune à [ B11 ; 0 ] et
!>          [ B12 0 0 ; 0 -I 0 0 ].
!>

LDU1

!>          LDU1 est ENTIER
!>          La dimension principale du tableau U1, LDU1 >= MAX(1,P).
!>

U2

!>          U2 est tableau REEL, dimension (LDU2,M-P)
!>          En entrée, une matrice (M-P)-par-(M-P). En sortie, U2 est
!>          post-multipliée par la matrice de vecteurs singuliers gauches commune à
!>          [ B21 ; 0 ] et [ B22 0 0 ; 0 0 I ].
!>

LDU2

!>          LDU2 est ENTIER
!>          La dimension principale du tableau U2, LDU2 >= MAX(1,M-P).
!>

V1T

!>          V1T est tableau REEL, dimension (LDV1T,Q)
!>          En entrée, une matrice Q-par-Q. En sortie, V1T est pré-multipliée
!>          par la transposée de la matrice de vecteurs singuliers
!>          droits commune à [ B11 ; 0 ] et [ B21 ; 0 ].
!>

LDV1T

!>          LDV1T est ENTIER
!>          La dimension principale du tableau V1T, LDV1T >= MAX(1,Q).
!>

V2T

!>          V2T est tableau REEL, dimension (LDV2T,M-Q)
!>          En entrée, une matrice (M-Q)-par-(M-Q). En sortie, V2T est
!>          pré-multipliée par la transposée de la matrice de vecteurs singuliers
!>          droits commune à [ B12 0 0 ; 0 -I 0 ] et
!>          [ B22 0 0 ; 0 0 I ].
!>

LDV2T

!>          LDV2T est ENTIER
!>          La dimension principale du tableau V2T, LDV2T >= MAX(1,M-Q).
!>

B11D

!>          B11D est tableau REEL, dimension (Q)
!>          Lorsque SBBCSD converge, B11D contient les cosinus de THETA(1),
!>          ..., THETA(Q). Si SBBCSD échoue à converger, alors B11D
!>          contient la diagonale du bloc supérieur gauche partiellement réduit.
!>

B11E

!>          B11E est tableau REEL, dimension (Q-1)
!>          Lorsque SBBCSD converge, B11E contient des zéros. Si SBBCSD échoue
!>          à converger, alors B11E contient la superdiagonale du bloc
!>          supérieur gauche partiellement réduit.
!>

B12D

!>          B12D est tableau REEL, dimension (Q)
!>          Lorsque SBBCSD converge, B12D contient les sinus négatifs de
!>          THETA(1), ..., THETA(Q). Si SBBCSD échoue à converger, alors
!>          B12D contient la diagonale du bloc supérieur droit
!>          partiellement réduit.
!>

B12E

!>          B12E est tableau REEL, dimension (Q-1)
!>          Lorsque SBBCSD converge, B12E contient des zéros. Si SBBCSD échoue
!>          à converger, alors B12E contient la sous-diagonale du bloc
!>          supérieur droit partiellement réduit.
!>

B21D

!>          B21D est tableau REEL, dimension (Q)
!>          Lorsque SBBCSD converge, B21D contient les sinus négatifs de
!>          THETA(1), ..., THETA(Q). Si SBBCSD échoue à converger, alors
!>          B21D contient la diagonale du bloc inférieur gauche
!>          partiellement réduit.
!>

B21E

!>          B21E est tableau REEL, dimension (Q-1)
!>          Lorsque SBBCSD converge, B21E contient des zéros. Si SBBCSD échoue
!>          à converger, alors B21E contient la superdiagonale du bloc
!>          inférieur gauche partiellement réduit.
!>

B22D

!>          B22D est tableau REEL, dimension (Q)
!>          Lorsque SBBCSD converge, B22D contient les cosinus de THETA(1),
!>          ..., THETA(Q). Si SBBCSD échoue à converger, alors B22D
!>          contient la diagonale du bloc inférieur droit
!>          partiellement réduit.
!>

B22E

!>          B22E est tableau REEL, dimension (Q-1)
!>          Lorsque SBBCSD converge, B22E contient des zéros. Si SBBCSD échoue
!>          à converger, alors B22E contient la sous-diagonale du bloc
!>          inférieur droit partiellement réduit.
!>

WORK

!>          WORK est tableau REEL, dimension (LWORK)
!>          Tableau de travail.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK. LWORK >= M*M + MAX(P, M-P, Q, M-Q) +
!>          MAX(Q, M-Q) + MAX(Q,M-P)+3.
!>          Si LWORK = -1, alors la taille optimale pour WORK est calculée
!>          et retournée dans WORK(1).
!>

INFO

!>          INFO est ENTIER
!>          = 0 : succès ;
!>          < 0 : si le i-ème argument avait une valeur illégale, alors il
!>                valait abs(INFO) ;
!>          > 0 : si la décomposition par valeurs singulières a échoué à
!>                converger ; SBBCSD retourne alors la version courante de
!>                la matrice bidiagonale de blocs dans les blocs B11, B12,
!>                B21, B22.
!>
t; B21E est un tableau REEL, de dimension (Q-1) !> Lorsque SBBCSD converge, B21E contient des zéros. Si SBBCSD !> ne parvient pas à converger, B21E contient la sous-diagonale du !> bloc inférieur gauche partiellement réduit. !>

B22D

!>          B22D est un tableau REEL, de dimension (Q)
!>          Lorsque SBBCSD converge, B22D contient les sinus négatifs de
!>          THETA(1), ..., THETA(Q). Si SBBCSD ne parvient pas à converger,
!>          B22D contient la diagonale du bloc inférieur droit
!>          partiellement réduit.
!>

B22E

!>          B22E est un tableau REEL, de dimension (Q-1)
!>          Lorsque SBBCSD converge, B22E contient des zéros. Si SBBCSD
!>          ne parvient pas à converger, B22E contient la sous-diagonale du
!>          bloc inférieur droit partiellement réduit.
!>

WORK

!>          WORK est un tableau REEL, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK. LWORK >= MAX(1,8*Q).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule seulement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK, et
!>          aucun message d'erreur relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, alors le i-ème argument a une valeur illégale.
!>          > 0 : si SBBCSD n'a pas convergé, INFO spécifie le nombre
!>                d'entrées non nulles dans PHI, et B11D, B11E, etc.,
!>                contiennent la matrice partiellement réduite.
!>

Paramètres Internes :

!>  TOLMUL  REEL, par défaut = MAX(10,MIN(100,EPS**(-1/8)))
!>          TOLMUL contrôle le critère de convergence de la boucle QR.
!>          Les angles THETA(i), PHI(i) sont arrondis à 0 ou PI/2 lorsqu'ils
!>          sont à moins de TOLMUL*EPS de l'une ou l'autre borne.
!>

Références :
