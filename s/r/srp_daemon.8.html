SRP_DAEMON(8) COMMANDES UTILISATEUR SRP_DAEMON(8)

NOM

srp_daemon - Découvre les cibles SRP dans un Fabric InfiniBand

SYNTAXE

srp_daemon [-vVcaeon] [-d périphérique-umad | -i périphérique-infiniband [-p num-port] | -j dev:port] [-t timeout(ms)] [-r réessais] [-R temps-rescan] [-f fichier-règles]

DESCRIPTION

Découvre et se connecte aux cibles InfiniBand SCSI RDMA Protocol (SRP) dans un fabric IB.

Chaque instance de srp_daemon opère sur un port local. Au démarrage, il effectue un réexamen complet du fabric, puis attend un événement srp_daemon. Un événement srp_daemon peut être la connexion d'une nouvelle machine au fabric, un changement dans les capacités d'une machine, un changement SA ou l'expiration d'un délai prédéfini.

Lorsqu'une nouvelle machine rejoint le fabric, srp_daemon vérifie si c'est une cible SRP. Lorsqu'il y a un changement de capacités, srp_daemon vérifie si la machine est devenue une cible SRP. Lorsqu'il y a un changement SA ou une expiration de délai, srp_daemon effectue un réexamen complet du fabric.

Pour chaque cible que srp_daemon trouve, il vérifie s'il doit se connecter à cette cible selon ses règles (le fichier de règles par défaut est /etc/srp_daemon.conf) et s'il est déjà connecté au port local. S'il doit se connecter à cette cible et s'il n'est pas encore connecté, srp_daemon peut soit afficher les détails de la cible, soit s'y connecter.

OPTIONS

-v
Affiche une sortie plus détaillée
-V
Affiche une sortie encore plus détaillée (mode débogage)
-i périphérique-infiniband
Travailler sur périphérique-infiniband. Cette option ne doit pas être utilisée avec -d ni avec -j.
-p num-port
Travailler sur le port num-port (par défaut 1). Cette option doit être utilisée avec -i et ne doit pas être utilisée avec -d ni avec -j.
-j dev:port
Travailler sur le port numéro port du périphérique InfiniBand dev. Cette option ne doit pas être utilisée avec -d, -i ni avec -p.
-d périphérique-umad
Utiliser le fichier périphérique périphérique-umad (par défaut /dev/infiniband/umad0). Cette option ne doit pas être utilisée avec -i, -p ni avec -j.
-c
Génère une sortie adaptée pour être redirigée directement vers un fichier /sys/class/infiniband_srp/srp-<périphérique>-<port>/add_target.
-a
Affiche toutes les cibles dans le fabric, pas seulement celles qui ne sont pas connectées via le port local. C'est le même comportement que celui de ibsrpdm.
-e
Exécute la commande de connexion, c'est-à-dire établit la connexion à la cible.
-o
Effectue un seul réexamen et quitte, comme ibsrpdm.
-R temps-rescan
Force un réexamen complet toutes les temps-rescan secondes. Si -R n'est pas spécifié, aucun réexamen basé sur un délai d'attente ne sera effectué.
-T délai-réessai
Réessaie de se connecter à une cible existante après délai-réessai secondes. Si -R n'est pas spécifié, utilise un délai d'attente de 5 secondes. Si délai-réessai est 0, ne tentera pas de reconnecter. La raison pour laquelle srp_daemon réessaie de se connecter à la cible est qu'il peut y avoir un scénario rare dans lequel srp_daemon essaie de se connecter pour ajouter une cible alors que la cible est sur le point d'être supprimée, mais n'est pas encore supprimée.
-f fichier-règles
Décide quelles cibles contacter en fonction des règles du fichier-règles. Si -f n'est pas spécifié, utilise le fichier de règles par défaut /etc/srp_daemon.conf. Chaque ligne du fichier-règles est une règle qui peut être une autorisation de connexion ou une interdiction de connexion selon le premier caractère de la ligne (respectivement 'a' ou 'd'). Le reste de la ligne contient les valeurs pour id_ext, ioc_guid, dgid, service_id. Veuillez consulter la section exemples pour un exemple de fichier. srp_daemon décide d'autoriser ou d'interdire chaque cible en fonction de la première règle qui correspond à la cible. Si aucune règle ne correspond à la cible, la cible est autorisée et sera contactée. Dans une règle d'autorisation, il est possible de définir des attributs pour la connexion à la cible. Les attributs pris en charge sont max_cmd_per_lun et max_sect.
-t timeout
Utilise un délai d'attente de timeout ms pour les réponses MAD (par défaut : 5 sec).
-r réessais
Effectue réessais réessais sur chaque envoi de MAD (par défaut : 3 réessais).
-n
Nouveau format - utilise également initiator_ext dans la commande de connexion.
--systemd
Active l'intégration systemd.

FICHIERS

/etc/srp_daemon.conf - Fichier de configuration des règles par défaut qui indique quelles cibles contacter. Peut être remplacé en utilisant l'option -f fichier-règles. Chaque ligne de ce fichier est une règle qui peut être une autorisation de connexion ou une interdiction de connexion selon le premier caractère de la ligne (respectivement 'a' ou 'd'). Le reste de la ligne contient les valeurs pour id_ext, ioc_guid, dgid, service_id. Veuillez consulter la section exemples pour un exemple de fichier. srp_daemon décide d'autoriser ou d'interdire chaque cible en fonction de la première règle qui correspond à la cible. Si aucune règle ne correspond à la cible, la cible est autorisée et sera contactée. Dans une règle d'autorisation, il est possible de définir des attributs pour la connexion à la cible. Les attributs pris en charge sont max_cmd_per_lun et max_sect.

EXEMPLES

srp_daemon -e -i mthca0 -p 1 -R 60 (Se connecte aux cibles accessibles via le port 1 de mthca0. Effectue un réexamen complet toutes les minutes)

srp_daemon -o -c -a (Affiche les commandes de connexion pour les cibles dans le fabric et quitte - similaire à ibsrpdm)

srp_daemon -e -f rules.txt (Se connecte aux cibles autorisées dans le fichier de règles rules.txt)

Un exemple de fichier de configuration des règles (tel que /etc/srp_daemon.conf)
------------------------------------------------------------------------
# Fichier de règles exemple
# Ceci est un commentaire
# interdire le dgid suivant
d       dgid=fe800000000000000002c90200402bd5
# autoriser la cible avec l'ioc_guid suivant
a       ioc_guid=00a0b80200402bd7
# autoriser la cible avec id_ext et ioc_guid suivants. Et définir max_cmd_per_lun à 31.
a       id_ext=200500A0B81146A1,ioc_guid=00a0b80200402bef,max_cmd_per_lun=31
# interdire tout le reste
d
