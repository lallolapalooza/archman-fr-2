real function srzt02 (integer m, integer n, real, dimension( lda, * ) af, integer lda, real, dimension( * ) tau, real, dimension( lwork ) work, integer lwork)

SRZT02

Objectif:

!>
!> SRZT02 retourne
!>      || I - Q'*Q || / ( M * eps)
!> où la matrice Q est définie par les transformations de Householder
!> générées par STZRZF.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice AF.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice AF.
!>

AF

!>          AF est un tableau REAL, dimension (LDA,N)
!>          La sortie de STZRZF.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau AF.
!>

TAU

!>          TAU est un tableau REAL, dimension (M)
!>          Détails des transformations de Householder retournés par
!>          STZRZF.
!>

WORK

!>          WORK est un tableau REAL, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          longueur du tableau WORK. LWORK >= N*N+N*NB.
!>
