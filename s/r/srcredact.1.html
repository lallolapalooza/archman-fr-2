SRCREDACT(1) Outils de texte SRCREDACT(1)

NOM

srcredact - un programme de rédaction de fichiers texte

SYNTAXE

srcredact [OPTIONS] -e audience [fichier_complet]

srcredact [OPTIONS] -u audience fichier_complet [fichier_rédigé]

srcredact -l [fichier_complet]

srcredact -h|-v

DESCRIPTION

srcredact est le programme permettant d'extraire des ``versions rédigées'' du fichier maître (option -e) ou d'incorporer les modifications des versions rédigées dans le fichier maître (``dé-rédaction'', option -u).

Le fichier maître est composé de morceaux destinés à différentes audiences. Chaque audience a un nom, par exemple "classified", "unclssified", "expert", etc. Les morceaux sont délimités par des lignes de garde. Chaque ligne de garde a le format (pour la syntaxe TeX par défaut)

%<*nom1|nom2|...>

ou

%</nom1|nom2|...>

Dans le premier cas, le texte suivant la garde est inclus pour les audiences "nom1", "nom2", .... Dans le second cas, il est exclu pour ces audiences.

Il existe une audience spéciale "ALL" : un joker pour toutes les audiences. Ainsi, l'idiome

%</ALL>
%<*classified>

signifie que le morceau est exclu pour toutes les audiences sauf "classified".

Exactement une des options -e (extraire) ou -u (dé-extraire) doit être présente. En mode d'extraction, l'argument ne contenant pas d'option est le nom du fichier complet. S'il est absent, ou est "-", l'entrée standard est utilisée. En mode de dé-rédaction, le premier argument ne contenant pas d'option

OPTIONS

-c liste de motifs de commentaires
Utilise le motif donné pour les lignes de commentaire afin de rechercher les gardes au lieu du motif par défaut "TeX". Les motifs reconnus sont :
c
/*<garde>*/
cpp
//<garde>
fortran
C<garde>
shell
#<garde>
TeX
%<garde>

Les noms des motifs doivent être séparés par des virgules, et la liste peut être entourée de guillemets pour empêcher l'expansion par le shell, par exemple

-c "TeX, c, shell"
-d
Mode de débogage activé.
-e audience
Extrait le contenu pour l'audience actuelle dans le fichier fichier. L'audience actuelle est devinée à partir du nom du fichier, si ce dernier a la structure base-audience.extension, par exemple "rapport-nonclassifié.tex". La clé -a remplace cette supposition et doit être utilisée si le nom du fichier ne suit pas ce modèle. Le nom de fichier "-" signifie la sortie standard.
-h
Affiche les informations d'aide et quitte.
-l
Liste toutes les audiences définies dans le fichier (une par ligne) et quitte.
-u audience
Prend un fichier édité destiné à l'audience (le second argument sans option) et y incorpore les modifications dans le fichier complet (le premier argument sans option). Si le second argument est absent, l'entrée standard est utilisée à la place. Comme d'habitude, "-" signifie également l'entrée standard. Notez qu'un seul des deux arguments de fichier dans ce cas peut être l'entrée standard.
-v
Affiche les informations de version et quitte.
-w on|off|1|0|true|false
Si "on", 1 ou "true" (par défaut), encapsule implicitement le document complet dans les gardes 
%<*ALL>
...
%</ALL>

VALEUR DE RETOUR

Le programme retourne 0 en cas de succès, 1 si des conflits ont été trouvés en mode "dé-extraction" et 2 en cas de problèmes.

CONFLITS EN MODE DE REDACTION

Comme l'outil standard diff3(1), le programme peut trouver des conflits entre la version complète et celle éditée en mode -u. Le fichier résultant encadrera alors les conflits de la manière habituelle, par exemple :

<<<<<<< /tmp/BrjXo0hMOB/full
%</nobonds>
Quarante-cinq tonnes de bonnes vieilles obligations gouvernementales sèches,
conviennent pour la chaudière, or
7 pour cent., 1864, préférentielles.
%<*nobonds>
||||||| /tmp/BrjXo0hMOB/extracted
Quarante-cinq tonnes de bonnes vieilles obligations gouvernementales sèches,
conviennent pour la chaudière, or
7 pour cent., 1864, préférentielles.
=======
>>>>>>> /tmp/BrjXo0hMOB/new

Ici, "full" est le document complet, "extracted" est le fichier extrait pour l'audience donnée, et "new" est le fichier édité.
