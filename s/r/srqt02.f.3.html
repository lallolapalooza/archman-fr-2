Documentation de la fonction/sous-programme

subroutine srqt02 (integer m, integer n, integer k, real, dimension( lda, * ) a, real, dimension( lda, * ) af, real, dimension( lda, * ) q, real, dimension( lda, * ) r, integer lda, real, dimension( * ) tau, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

SRQT02

Objectif :

!>
!> SRQT02 teste SORGRQ, qui génère une matrice m par n, Q, avec
!> des lignes orthogonales qui est définie comme le produit de k
!> réflecteurs élémentaires.
!>
!> Étant donné la factorisation RQ d'une matrice m par n, A, SRQT02 génère
!> la matrice orthogonale Q définie par la factorisation des k dernières
!> lignes de A ; elle compare R(m-k+1:m,n-m+1:n) avec
!> A(m-k+1:m,1:n)*Q(n-m+1:n,1:n)', et vérifie que les lignes de Q
!> sont orthogonales.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice Q à générer.  M >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice Q à générer.
!>          N >= M >= 0.
!>

K

!>          K est un entier
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q. M >= K >= 0.
!>

A

!>          A est un tableau de réels, de dimension (LDA,N)
!>          La matrice m par n, A, qui a été factorisée par SRQT01.
!>

AF

!>          AF est un tableau de réels, de dimension (LDA,N)
!>          Détails de la factorisation RQ de A, tels que retournés par SGERQF.
!>          Voir SGERQF pour plus de détails.
!>

Q

!>          Q est un tableau de réels, de dimension (LDA,N)
!>

R

!>          R est un tableau de réels, de dimension (LDA,M)
!>

LDA

!>          LDA est un entier
!>          La dimension principale des tableaux A, AF, Q et L. LDA >= N.
!>

TAU

!>          TAU est un tableau de réels, de dimension (M)
!>          Les facteurs scalaires des réflecteurs élémentaires correspondant
!>          à la factorisation RQ dans AF.
!>

WORK

!>          WORK est un tableau de réels, de dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau de réels, de dimension (M)
!>

RESULT

!>          RESULT est un tableau de réels, de dimension (2)
!>          Les rapports de test :
!>          RESULT(1) = norm( R - A*Q' ) / ( N * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q*Q' ) / ( N * EPS )
!>
