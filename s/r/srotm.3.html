sous-programme srotm (entier n, reel, dimension(*) sx, entier incx, reel, dimension(*) sy, entier incy, reel, dimension(5) sparam)

SROTM

Objectif :

!>
!>    APPLIQUE LA TRANSFORMATION DE GIVENS MODIFIÉE, H, À LA MATRICE 2 PAR N
!>
!>    (SX**T) , OÙ **T SIGNIFIE TRANSPOSE. LES ÉLÉMENTS DE SX SONT DANS
!>    (SX**T)
!>
!>    SX(LX+I*INCX), I = 0 À N-1, OÙ LX = 1 SI INCX .GE. 0, SINON
!>    LX = (-INCX)*N, ET SIMILAIREMENT POUR SY EN UTILISANT LY ET INCY.
!>    AVEC SPARAM(1)=SFLAG, H A UNE DES FORMES SUIVANTES..
!>
!>    SFLAG=-1.E0     SFLAG=0.E0        SFLAG=1.E0     SFLAG=-2.E0
!>
!>      (SH11  SH12)    (1.E0  SH12)    (SH11  1.E0)    (1.E0  0.E0)
!>    H=(          )    (          )    (          )    (          )
!>      (SH21  SH22),   (SH21  1.E0),   (-1.E0 SH22),   (0.E0  1.E0).
!>    VOIR SROTMG POUR UNE DESCRIPTION DU STOCKAGE DES DONNÉES DANS SPARAM.
!>
!>

Paramètres

N 
!>          N est ENTIER
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

SX

!>          SX est tableau REEL, dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est ENTIER
!>         espacement de stockage entre les éléments de SX
!>

SY

!>          SY est tableau REEL, dimension ( 1 + ( N - 1 )*abs( INCY ) )
!>

INCY

!>          INCY est ENTIER
!>         espacement de stockage entre les éléments de SY
!>

SPARAM

!>          SPARAM est tableau REEL, dimension (5)
!>     SPARAM(1)=SFLAG
!>     SPARAM(2)=SH11
!>     SPARAM(3)=SH21
!>     SPARAM(4)=SH12
!>     SPARAM(5)=SH22
!>
