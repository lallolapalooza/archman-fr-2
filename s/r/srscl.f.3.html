Documentation de la fonction/sous-programme

sous-programme srscl (integer n, real sa, real, dimension( * ) sx, integer incx)

SRSCL multiplie un vecteur réel de n éléments par le scalaire réel 1/a.

Objectif :

!>
!> SRSCL multiplie un vecteur réel de n éléments x par le scalaire réel 1/a.
!> Ceci est effectué sans dépassement de capacité ou sous-dépassement, tant que
!> le résultat final x/a ne dépasse pas les capacités ou ne sous-dépasse pas.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          Le nombre de composantes du vecteur x.
!>

SA

!>          SA est un réel (REAL)
!>          Le scalaire a utilisé pour diviser chaque composante de x.
!>          SA doit être supérieur ou égal à 0, sinon le sous-programme divisera par zéro.
!>

SX

!>          SX est un tableau réel (REAL array), de dimension
!>                         (1+(N-1)*abs(INCX))
!>          Le vecteur x de n éléments.
!>

INCX

!>          INCX est un entier (INTEGER)
!>          L'incrément entre les valeurs successives du vecteur SX.
!>          > 0 :  SX(1) = X(1) et SX(1+(i-1)*INCX) = x(i),     1< i<= n
!>
