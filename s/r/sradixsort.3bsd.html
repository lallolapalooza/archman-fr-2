sradixsort(3bsd)

Paquet: libbsd

Licences: custom

radixsort(3bsd) 3bsd radixsort(3bsd)

NOM

radixsort, sradixsort — tri par radix

BIBLIOTHÈQUE

bibliothèque « libbsd »

SYNOPIS

#include <limits.h>
#include <stdlib.h> (Voir libbsd(7) pour l'utilisation de l'inclusion.)
int
radixsort(const unsigned char **base, int nmemb, const unsigned char *table, unsigned endbyte);

int
sradixsort(const unsigned char **base, int nmemb, const unsigned char *table, unsigned endbyte);

DESCRIPTION

Les fonctions radixsort() et sradixsort() sont des implémentations du tri par radix.

Ces fonctions trient un tableau de nmemb éléments de pointeurs vers des chaînes d'octets, le membre initial étant référencé par base. Les chaînes d'octets peuvent contenir n'importe quelles valeurs. La fin des chaînes est dénotée par un caractère qui a le même poids que la valeur spécifiée par l'utilisateur endbyte. endbyte doit être compris entre 0 et 255.

Les applications peuvent spécifier un ordre de tri en fournissant l'argument table. S'il n'est pas NULL, table doit référencer un tableau de UCHAR_MAX + 1 octets qui contient le poids de tri de chaque valeur d'octet possible. L'octet de fin de chaîne doit avoir un poids de tri de 0 ou 255 (pour trier dans l'ordre inverse). Plus d'un octet peut avoir le même poids de tri. L'argument table est utile pour les applications qui souhaitent trier différents caractères de manière égale, par exemple, fournir une table avec les mêmes poids pour A-Z que pour a-z entraînera un tri insensible à la casse. Si table est NULL, le contenu du tableau est trié par ordre croissant selon l'ordre ASCII des chaînes d'octets qu'ils référencent et endbyte a un poids de tri de 0.

La fonction sradixsort() est stable, c'est-à-dire que si deux éléments sont égaux, leur ordre dans le tableau trié n'est pas modifié. La fonction sradixsort() utilise une mémoire supplémentaire suffisante pour contenir nmemb pointeurs.

La fonction radixsort() n'est pas stable, mais n'utilise pas de mémoire supplémentaire.

Ces fonctions sont des variantes du tri par radix basé sur l'octet le plus significatif ; en particulier, voir l'Algorithme R de D.E. Knuth et l'exercice 10 de la section 5.2.5. Elles prennent un temps linéaire par rapport au nombre d'octets dans les chaînes.

VALEURS DE RETOUR

La fonction radixsort() retourne la valeur 0 si succès ; sinon, la valeur -1 est retournée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

[EINVAL]
La valeur de l'élément endbyte de table n'est ni 0 ni 255.

De plus, la fonction sradixsort() peut échouer et définir errno pour toutes les erreurs spécifiées pour la routine de bibliothèque malloc(3).

VOIR AUSSI

Knuth, D.E., Sorting and Searching, The Art of Computer Programming, Vol. 3, pp. 170-178, 1968.

Paige, R., Three Partition Refinement Algorithms, SIAM J. Comput., No. 6, Vol. 16, 1987.

McIlroy, P., Computing Systems, Engineering Radix Sort, Vol. 6:1, pp. 5-27, 1993.

HISTORIQUE
