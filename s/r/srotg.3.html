sous-routine srotg (real(wp) a, real(wp) b, real(wp) c, real(wp) s)

SROTG

Objectif :

!>
!> SROTG construit une rotation de plan
!>    [  c  s ] [ a ] = [ r ]
!>    [ -s  c ] [ b ]   [ 0 ]
!> satisfaisant c**2 + s**2 = 1.
!>
!> Le calcul utilise les formules
!>    sigma = sgn(a)    si |a| >  |b|
!>          = sgn(b)    si |b| >= |a|
!>    r = sigma*sqrt( a**2 + b**2 )
!>    c = 1; s = 0      si r = 0
!>    c = a/r; s = b/r  si r != 0
!> La sous-routine calcule également
!>    z = s    si |a| > |b|,
!>      = 1/c  si |b| >= |a| et c != 0
!>      = 1    si c = 0
!> Cela permet de reconstruire c et s à partir de z comme suit :
!>    Si z = 1, définir c = 0, s = 1.
!>    Si |z| < 1, définir c = sqrt(1 - z**2) et s = z.
!>    Si |z| > 1, définir c = 1/z et s = sqrt( 1 - c**2).
!>
!>
