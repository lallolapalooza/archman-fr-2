sous-routine srqt03 (integer m, integer n, integer k, real, dimension( lda, * ) af, real, dimension( lda, * ) c, real, dimension( lda, * ) cc, real, dimension( lda, * ) q, integer lda, real, dimension( * ) tau, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

SRQT03

But :

!>
!> SRQT03 teste SORMRQ, qui calcule Q*C, Q'*C, C*Q ou C*Q'.
!>
!> SRQT03 compare les résultats d'un appel à SORMRQ avec les résultats de
!> la formation explicite de Q par un appel à SORGRQ, puis de la multiplication matricielle
!> par un appel à SGEMM.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes ou de colonnes de la matrice C ; C est n-par-m si
!>          Q est appliqué par la gauche, ou m-par-n si Q est appliqué par la
!>          droite.  M >= 0.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice orthogonale Q.  N >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflexions élémentaires dont le produit définit la
!>          matrice orthogonale Q.  N >= K >= 0.
!>

AF

!>          AF est un tableau REEL, dimension (LDA,N)
!>          Détails de la factorisation RQ d'une matrice m-par-n, comme
!>          retourné par SGERQF. Voir SGERQF pour plus de détails.
!>

C

!>          C est un tableau REEL, dimension (LDA,N)
!>

CC

!>          CC est un tableau REEL, dimension (LDA,N)
!>

Q

!>          Q est un tableau REEL, dimension (LDA,N)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux AF, C, CC et Q.
!>

TAU

!>          TAU est un tableau REEL, dimension (min(M,N))
!>          Les facteurs scalaires des réflexions élémentaires correspondant
!>          à la factorisation RQ dans AF.
!>

WORK

!>          WORK est un tableau REEL, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur de WORK.  LWORK doit être au moins M, et devrait être
!>          M*NB, où NB est la taille du bloc pour cet environnement.
!>

RWORK

!>          RWORK est un tableau REEL, dimension (M)
!>

RESULT

!>          RESULT est un tableau REEL, dimension (4)
!>          Les rapports de test comparent deux techniques de multiplication d'une
!>          matrice aléatoire C par une matrice orthogonale n-par-n Q.
!>          RESULT(1) = norm( Q*C - Q*C )  / ( N * norm(C) * EPS )
!>          RESULT(2) = norm( C*Q - C*Q )  / ( N * norm(C) * EPS )
!>          RESULT(3) = norm( Q'*C - Q'*C )/ ( N * norm(C) * EPS )
!>          RESULT(4) = norm( C*Q' - C*Q' )/ ( N * norm(C) * EPS )
!>
