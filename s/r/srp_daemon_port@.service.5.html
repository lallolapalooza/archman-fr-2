SRP_DAEMON_PORT@.SERVICE(5) srp_daemon_port@.service SRP_DAEMON_PORT@.SERVICE(5)

NOM

srp_daemon_port@.service - service systemd srp_daemon_port@ qui contrôle un port unique

SYNTAXE

srp_daemon_port@.service

DESCRIPTION

Le service srp_daemon_port@.service contrôle si un processus srp_daemon surveille ou non le port RDMA spécifié comme argument du modèle. Le format du nom du port RDMA est dev:port où dev est le nom d'un périphérique RDMA et port est un numéro de port commençant à un. Démarrer une instance de ce modèle démarrera un processus srp_daemon. Arrêter une instance de ce modèle arrêtera le processus srp_daemon pour le port spécifié. Il est possible d'empêcher le démarrage de srp_daemon pour un port donné en masquant le service systemd correspondant, par exemple avec systemctl mask srp_daemon_port@mlx4_0:1.

Une liste de toutes les paires de périphériques RDMA et de numéros de port peut être obtenue par exemple comme suit :

$ (cd /sys/class/infiniband >&/dev/null && for p in */ports/*; do
   [ -e "$p" ] && echo "${p/\/ports\//:}"; done)
mlx4_0:1
mlx4_0:2
mlx4_1:1
mlx4_1:2
