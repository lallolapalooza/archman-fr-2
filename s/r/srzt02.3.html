fonction réelle srzt02 (entier m, entier n, réel, dimension( lda, * ) af, entier lda, réel, dimension( * ) tau, réel, dimension( lwork ) work, entier lwork)

SRZT02

Objectif :

!>
!> SRZT02 retourne
!>      || I - Q'*Q || / ( M * eps)
!> où la matrice Q est définie par les transformations de Householder
!> générées par STZRZF.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice AF.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice AF.
!>

AF

!>          AF est un tableau RÉEL, dimension (LDA,N)
!>          La sortie de STZRZF.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau AF.
!>

TAU

!>          TAU est un tableau RÉEL, dimension (M)
!>          Détails des transformations de Householder retournées par
!>          STZRZF.
!>

WORK

!>          WORK est un tableau RÉEL, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          longueur du tableau WORK. LWORK >= N*N+N*NB.
!>
