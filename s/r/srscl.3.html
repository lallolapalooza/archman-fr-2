Documentation de la fonction/sous-programme

sous-programme srscl (entier n, reel sa, reel, dimension( * ) sx, entier incx)

SRSCL multiplie un vecteur par l'inverse d'un scalaire réel.

Objectif :

!>
!> SRSCL multiplie un vecteur réel de n éléments x par le scalaire réel 1/a.
!> Ceci est fait sans dépassement de capacité ni sous-dépassement tant que
!> le résultat final x/a ne dépasse pas la capacité ni ne sous-dépasse pas.
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre de composantes du vecteur x.
!>

SA

!>          SA est un REEL
!>          Le scalaire a utilisé pour diviser chaque composante de x.
!>          SA doit être >= 0, sinon la sous-routine divisera par zéro.
!>

SX

!>          SX est un tableau REEL, dimension
!>                         (1+(N-1)*abs(INCX))
!>          Le vecteur x de n éléments.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les valeurs successives du vecteur SX.
!>          > 0 :  SX(1) = X(1) et SX(1+(i-1)*INCX) = x(i),     1< i<= n
!>
