NOM

src2man - extrait des pages man des fichiers source.

SYNTAXE

src2man [-n][-d date][-v volume][-r release] [fichier_src ...]

DESCRIPTION

src2man analyse le fichier source fichier_src. Seuls les fichiers source C sont pris en charge pour le moment. Les blocs de commentaires commençant par "/** num", où num est un numéro de section, sont convertis en fichier man, en utilisant txt2man(1).

La première ligne du bloc de commentaires doit contenir le nom de la page man, généralement le nom de la fonction, suivi d'un "-" et d'une courte description. Les lignes suivantes sont le contenu de la section "DESCRIPTION", sauf si elles sont en majuscules, auquel cas elles définissent une nouvelle section.

Si la ligne suivante après un bloc de commentaires est vide, alors aucune section "SYNOPSIS" ne sera générée. Sinon, src2man recherchera dans les lignes sources suivantes un prototype de fonction ou une définition de type (struct, union, typedef, ...) correspondant au nom de la page man, et l'inclura dans une section "SYNOPSIS". Cela évite de dupliquer le prototype de type ou de fonction dans le bloc de commentaires.

Le meilleur endroit pour la documentation du code est dans le fichier source, où le corps est implémenté, pas dans le fichier d'en-tête qui ne contient que le prototype. src2man recherche automatiquement la présence d'un prototype dans le fichier d'en-tête correspondant, et s'il est trouvé, il imprimera une instruction "#include" dans le synopsis.

OPTIONS

-d date
Définit la date des pages man. Par défaut, la date actuelle.
-n
Aucune page man n'est créée. Les noms des pages man qui seraient créées sont imprimés.
-v volume
Spécifie le nom du volume à imprimer dans l'en-tête central des pages man générées.
-r version
Spécifie le nom du projet et le numéro de version pour la page man générée.

ENVIRONNEMENT

SOURCE_DATE_EPOCH
Horodatage Unix utilisé pour la date dans l'en-tête au lieu de la date actuelle.

EXEMPLE

L'exemple suivant affiche du code C et des commentaires pour générer une page man foobar.3 :

/** 3

  • foobar - une fonction factice d'exemple
  • Cette ligne est maintenant la première de la section description.
  • Notez que les paramètres de fonction parm1 et parm2 sont mis en évidence
  • dans la page man générée.

*/

int foobar(char *parm1, int parm2)

{

...

return 0;

}
