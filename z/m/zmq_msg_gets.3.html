NOM

zmq_msg_gets - obtenir une propriété de métadonnées de message

SYNOPSIS

const char *zmq_msg_gets (zmq_msg_t *message, const char *propriété);

DESCRIPTION

La fonction zmq_msg_gets() renverra la valeur de chaîne de caractères pour la propriété de métadonnées spécifiée par l'argument propriété pour le message pointé par l'argument message. Les arguments propriété et valeur seront des chaînes de caractères encodées en UTF8 et terminées par un caractère nul.

Les métadonnées sont définies sur une base par connexion lors de la négociation de connexion ZeroMQ, comme spécifié dans <rfc.zeromq.org/spec:37>. Les applications peuvent définir des propriétés de métadonnées à l'aide de l'option zmq_setsockopt(3) ZMQ_METADATA. Les propriétés de métadonnées de l'application doivent être précédées de X-.

En plus des métadonnées de l'application, les propriétés ZMTP suivantes peuvent être récupérées avec la fonction zmq_msg_gets() :

Socket-Type
Routing-Id

Note : Identity est un alias obsolète pour Routing-Id.

De plus, lorsqu'elle est disponible pour le transport sous-jacent, la propriété Peer-Address renverra l'adresse IP du point de terminaison distant telle que retournée par getnameinfo(2).

Les noms de ces propriétés sont également définis dans zmq.h comme ZMQ_MSG_PROPERTY_SOCKET_TYPE, ZMQ_MSG_PROPERTY_ROUTING_ID et ZMQ_MSG_PROPERTY_PEER_ADDRESS. Actuellement, ces définitions ne sont disponibles qu'en tant qu'API DRAFT.

D'autres propriétés peuvent être définies en fonction du mécanisme de sécurité sous-jacent, voir l'exemple de connexion authentifiée ZAP ci-dessous.

VALEUR RETOURNEE

La fonction zmq_msg_gets() renverra la valeur de chaîne de caractères de la propriété si l'opération réussit. Sinon, elle renverra NULL et définira errno sur l'une des valeurs définies ci-dessous. L'appelant ne doit pas modifier ni libérer la valeur retournée, qui appartient au message. L'encodage de la propriété et de la valeur sera UTF8.

ERREURS

EINVAL

La propriété demandée est inconnue.

EXEMPLE

Obtenir l'identifiant utilisateur authentifié ZAP pour un message :.

zmq_msg_t msg;
zmq_msg_init (&msg);
rc = zmq_msg_recv (&msg, dealer, 0);
assert (rc != -1);
const char *user_id = zmq_msg_gets (&msg, ZMQ_MSG_PROPERTY_USER_ID);
zmq_msg_close (&msg);
