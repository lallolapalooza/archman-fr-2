NOM

zmq_tipc - transport unicast 0MQ utilisant TIPC

SYNOPSIS

TIPC est un protocole IPC de cluster avec un schéma d'adressage transparent à la localisation.

ADRESSAGE

Un point d'accès 0MQ est une chaîne constituée d'un transport:// suivi d'une adresse. Le transport spécifie le protocole sous-jacent à utiliser. L'adresse spécifie l'adresse spécifique au transport à laquelle se connecter.

Pour le transport TIPC, le transport est tipc, et la signification de la partie adresse est définie ci-dessous.

Attribution d'un nom de port à une socket

Lors de l'attribution d'un nom de port à une socket en utilisant zmq_bind() avec le transport tipc, le point d'accès est défini sous la forme : {type, lower, upper}

•Type est l'ID numérique (u32) de votre service.
•Lower et Upper spécifient une plage pour votre service.

La publication du même service avec des ID lower/upper qui se chevauchent provoquera la distribution des demandes de connexion entre eux de manière circulaire.

Connexion d'une socket

Lors de la connexion d'une socket à une adresse de pair en utilisant zmq_connect() avec le transport tipc, le point d'accès sera interprété comme un ID de service, suivi d'une virgule et de l'ID d'instance.

L'ID d'instance doit être compris dans la plage inférieure/supérieure d'un nom de port publié pour que le point d'accès soit valide.

EXEMPLES

Attribution d'une adresse locale à une socket.

//  Publication de l'ID de service TIPC 5555
rc = zmq_bind(socket, "tipc://{5555,0,0}");
assert (rc == 0);
//  Publication de l'ID de service TIPC 5555 avec une plage de service de 0-100
rc = zmq_bind(socket, "tipc://{5555,0,100}");
assert (rc == 0);

Connexion d'une socket.

//  Connexion au service 5555, ID d'instance 50
rc = zmq_connect(socket, "tipc://{5555,50}");
assert (rc == 0);
