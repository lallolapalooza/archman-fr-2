NOM

zmq_msg_set_routing_id - définir la propriété de l'identifiant de routage sur un message

SYNTAXE

int zmq_msg_set_routing_id (zmq_msg_t *message, uint32_t routing_id);

DESCRIPTION

La fonction zmq_msg_set_routing_id() définit l'identifiant de routage routing_id spécifié sur le message pointé par l'argument message. L'identifiant de routage routing_id doit être supérieur à zéro. Pour obtenir un identifiant de routage valide, vous devez recevoir un message d'une socket ZMQ_SERVER et utiliser la méthode libzmq:zmq_msg_routing_id. Les identifiants de routage sont transitoires.

VALEUR DE RETOUR

La fonction zmq_msg_set_routing_id() retourne zéro en cas de succès. Sinon, elle retourne -1 et définit errno à l'une des valeurs ci-dessous.

ERREURS

EINVAL

L'identifiant de routage routing_id fourni est zéro.
