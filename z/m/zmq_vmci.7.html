NOM

zmq_vmci - Transport 0MQ sur l'interface de communication des machines virtuelles (VMCI) à l'aide de sockets

SYNOPSIS

Le transport VMCI passe des messages entre les machines virtuelles VMware exécutées sur le même hôte, entre la machine virtuelle et l'hôte, et au sein des machines virtuelles (transport inter-processus comme ipc).


Note

La communication entre une machine virtuelle et l'hôte n'est pas prise en charge sur Mac OS X 10.9 et versions ultérieures.

ADRESSAGE

Un point de terminaison 0MQ est une chaîne composée d'un transport:// suivi d'une adresse. Le transport spécifie le protocole sous-jacent à utiliser. L'adresse spécifie l'adresse spécifique au transport à laquelle se connecter.

Pour le transport VMCI, le transport est vmci, et la signification de la partie adresse est définie ci-dessous.

Liaison d'un socket

Lors de la liaison d'un socket à une adresse locale à l'aide de zmq_bind() avec le transport vmci, le point de terminaison sera interprété comme une interface suivie d'un deux-points et du numéro de port TCP à utiliser.

Une interface peut être spécifiée par l'un des éléments suivants :

•Le caractère générique *, signifiant toutes les interfaces disponibles.
•Un entier renvoyé par VMCISock_GetLocalCID ou @ (ZeroMQ appellera VMCISock_GetLocalCID en interne).

Le port peut être spécifié par :

•Une valeur numérique, généralement supérieure à 1024 sur les systèmes POSIX.
•Le caractère générique *, signifiant un port éphémère assigné par le système.

Déliaison d'une adresse caractère générique d'un socket

Lorsque le point de terminaison * caractère générique a été utilisé dans zmq_bind(), l'appelant doit utiliser le vrai point de terminaison obtenu de l'option de socket ZMQ_LAST_ENDPOINT pour délier ce point de terminaison d'un socket à l'aide de zmq_unbind().

Connexion d'un socket

Lors de la connexion d'un socket à une adresse de pair à l'aide de zmq_connect() avec le transport vmci, le point de terminaison sera interprété comme une adresse de pair suivie d'un deux-points et du numéro de port à utiliser.

Une adresse de pair doit être le CID (identifiant de console) du pair.

EXEMPLES

Attribution d'une adresse locale à un socket.

// Port VMCI 5555 sur toutes les interfaces disponibles
rc = zmq_bind(socket, "vmci://*:5555");
assert (rc == 0);
// Port VMCI 5555 sur l'interface de boucle locale sur toutes les plateformes
cid = VMCISock_GetLocalCID();
sprintf(endpoint, "vmci://%d:5555", cid);
rc = zmq_bind(socket, endpoint);
assert (rc == 0);

Connexion d'un socket.

// Connexion à l'aide d'un CID
sprintf(endpoint, "vmci://%d:5555", cid);
rc = zmq_connect(socket, endpoint);
assert (rc == 0);
