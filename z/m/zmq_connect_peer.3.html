ZMQ_CONNECT_PEER(3) Manuel 0MQ ZMQ_CONNECT_PEER(3)

NOM

zmq_connect_peer - crée une connexion sortante depuis une socket et retourne l'identifiant de routage de la connexion de manière thread-safe et atomique.

SYNOPSIS

uint32_t zmq_connect_peer (void *socket, const char *endpoint);

DESCRIPTION

La fonction zmq_connect_peer() connecte une socket ZMQ_PEER à un endpoint et retourne ensuite l'routing_id de l'endpoint.

L'endpoint est une chaîne de caractères constituée d'un transport:// suivi d'une adresse. Le transport spécifie le protocole sous-jacent à utiliser. L'adresse spécifie l'adresse spécifique au transport à laquelle se connecter.

La fonction n'est supportée que sur le type de socket ZMQ_PEER et retournerait 0 avec errno défini à ENOTSUP sinon.

La fonction zmq_connect_peer() supporte les transports suivants :

tcp

transport unicast utilisant TCP, voir zmq_tcp(7)

ipc

transport local de communication inter-processus, voir zmq_ipc(7)

inproc

transport local de communication intra-processus (inter-threads), voir zmq_inproc(7)

ws

transport unicast utilisant WebSockets, voir zmq_ws(7)

wss

transport unicast utilisant WebSockets sur TLS, voir zmq_wss(7)

VALEUR DE RETOUR

La fonction zmq_connect_peer() retourne l'routing_id du pair en cas de succès. Sinon, elle retourne 0 et définit errno à l'une des valeurs définies ci-dessous.

ERREURS

EINVAL

L'endpoint fourni est invalide.

EPROTONOSUPPORT

Le protocole de transport demandé n'est pas supporté avec ZMQ_PEER.

ENOCOMPATPROTO

Le protocole de transport demandé n'est pas compatible avec le type de socket.

ETERM

Le contexte 0MQ associé à la socket spécifiée a été terminé.

ENOTSOCK

La socket fournie était invalide.

EMTHREAD

Aucun thread d'E/S n'est disponible pour accomplir la tâche.

ENOTSUP

La socket n'est pas de type ZMQ_PEER.

EFAULT

L'option ZMQ_IMMEDIATE est définie sur la socket.

EXEMPLE

Connexion d'une socket peer à un transport TCP et envoi d'un message.

/* Création d'une socket ZMQ_SUB */
void *socket = zmq_socket (context, ZMQ_PEER);
assert (socket);
/* Connexion à l'hôte server001, port 5555 en utilisant un transport TCP */
uint32_t routing_id = zmq_connect (socket, "tcp://server001:5555");
assert (routing_id == 0);
/* Envoi d'un message au pair  */
zmq_msg_t msg;
int rc = zmq_msg_init_data (&msg, "BONJOUR", 5, NULL, NULL);
assert (rc == 0);
rc = zmq_msg_set_routing_id (&msg, routing_id);
assert (rc == 0);
rc = zmq_msg_send (&msg, socket, 0);
assert (rc == 5);
rc = zmq_msg_close (&msg);
assert (rc == 0);
