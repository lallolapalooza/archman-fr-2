zmq_close(3)

Paquet: zeromq

Licences: MPL2

NOM

zmq_close - fermer une socket 0MQ

SYNTAXE

int zmq_close (void *socket);

DESCRIPTION

La fonction zmq_close() doit détruire la socket référencée par l'argument socket. Tous les messages en cours, physiquement reçus du réseau mais pas encore reçus par l'application avec zmq_recv(), seront ignorés. Le comportement de l'ignorance des messages envoyés par l'application avec zmq_send() mais pas encore physiquement transférés vers le réseau dépend de la valeur de l'option de socket ZMQ_LINGER pour la socket spécifiée.

zmq_close() doit être appelée exactement une fois pour chaque socket. Si elle n'est jamais appelée, zmq_ctx_term() sera bloquée pour toujours. Si elle est appelée plusieurs fois pour la même socket ou si socket ne pointe pas vers une socket, le comportement est indéfini.


Note

Le réglage par défaut de ZMQ_LINGER n'ignore pas les messages non envoyés ; ce comportement peut entraîner le blocage de l'application lors de l'appel à zmq_ctx_term(). Pour plus de détails, voir zmq_setsockopt(3) et zmq_ctx_term(3).


Note

Cette API s'achèvera de manière asynchrone, donc tout ne sera pas désalloué après son retour. Voir ci-dessus pour les détails sur le délai.

VALEUR DE RETOUR

La fonction zmq_close() renvoie zéro en cas de succès. Sinon, elle renvoie -1 et définit errno à l'une des valeurs définies ci-dessous.

ERREURS

ENOTSOCK

La socket fournie était NULL.
