NOM

zmq_msg_routing_id - retourne l'ID de routage du message, le cas échéant

SYNOPIS

uint32_t zmq_msg_routing_id (zmq_msg_t *message);

DESCRIPTION

La fonction zmq_msg_routing_id() retourne l'ID de routage du message, le cas échéant. L'ID de routage est défini sur tous les messages reçus d'une socket ZMQ_SERVER. Pour envoyer un message à une socket ZMQ_SERVER, vous devez définir l'ID de routage d'un pair ZMQ_CLIENT connecté. Les IDs de routage sont transitoires.

VALEUR DE RETOUR

La fonction zmq_msg_routing_id() renverra zéro s'il n'y a pas d'ID de routage, sinon elle renverra un entier non signé de 32 bits supérieur à zéro.

EXEMPLE

Réception d'un message client et de son ID de routage.

void *ctx = zmq_ctx_new ();
assert (ctx);
void *server = zmq_socket (ctx, ZMQ_SERVER);
assert (server);
int rc = zmq_bind (server, "tcp://127.0.0.1:8080");
assert (rc == 0);
zmq_msg_t message;
rc = zmq_msg_init (&message);
assert (rc == 0);
//  Recevoir un message de la socket
rc = zmq_msg_recv (server, &message, 0);
assert (rc != -1);
uint32_t routing_id = zmq_msg_routing_id (&message);
assert (routing_id);
