NOM

zmq_ctx_set_ext - définit des options de contexte étendues

SYNTAXE

int zmq_ctx_set_ext (void *contexte, int nom_option, const void *valeur_option, size_t len_option);

DESCRIPTION

La fonction zmq_ctx_set_ext() définit l'option spécifiée par l'argument nom_option à la valeur pointée par l'argument valeur_option pour le contexte 0MQ pointé par l'argument contexte. L'argument len_option est la taille de la valeur de l'option en octets. Pour les options qui prennent une valeur de type « chaîne de caractères », les données binaires fournies ne doivent contenir aucun octet nul, ou se terminer par un seul octet nul (caractère de fin NUL ASCII).

La fonction zmq_ctx_set_ext() accepte tous les noms d'options acceptés par zmq_ctx_set(). Les options qui ont le plus de sens à définir avec zmq_ctx_set_ext() plutôt qu'avec zmq_ctx_set() sont les suivantes :

ZMQ_THREAD_NAME_PREFIX: Définit un préfixe de nom pour les threads I/O

L'argument ZMQ_THREAD_NAME_PREFIX définit un préfixe de chaîne à chaque thread créé pour le pool de threads du contexte interne. Cette option n'est prise en charge que sous Linux. Cette option est utile pour aider au débogage effectué via « top -H » ou « gdb » ; dans le cas où plusieurs processus sur le système utilisent ZeroMQ, il est utile de fournir via cette option de contexte un préfixe spécifique à l'application pour distinguer les threads d'arrière-plan ZeroMQ qui appartiennent à différents processus. Cette option ne s'applique qu'avant la création de tout socket sur le contexte.

Type de valeur d'option chaîne de caractères
Unité de valeur d'option N/A
Valeur par défaut chaîne vide

VALEUR DE RETOUR

La fonction zmq_ctx_set_ext() retourne zéro en cas de succès. Sinon, elle retourne -1 et définit errno à l'une des valeurs définies ci-dessous.

ERREURS

EINVAL

Le nom d'option option_name demandé est inconnu.

EFAULT

Le contexte context fourni est invalide.

EXEMPLE

Définir un préfixe pour les noms de threads internes ZMQ :.

void *context = zmq_ctx_new ();
const char prefix[] = "MyApp";
size_t prefixLen = sizeof(prefix);
zmq_ctx_set (context, ZMQ_THREAD_NAME_PREFIX, &prefix, &prefixLen);
char buff[256];
size_t buffLen = sizeof(buff);
int rc = zmq_ctx_get (context, ZMQ_THREAD_NAME_PREFIX, &buff, &buffLen);
assert (rc == 0);
assert (buffLen == prefixLen);
