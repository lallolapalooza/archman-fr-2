ZMQ_MSG_GET(3) Manuel 0MQ ZMQ_MSG_GET(3)

NOM

zmq_msg_get - obtenir une propriété de message

SYNTAXE

int zmq_msg_get (zmq_msg_t *message, int propriété);

DESCRIPTION

La fonction zmq_msg_get() retourne la valeur de la propriété spécifiée par l'argument propriété pour le message pointé par l'argument message.

Les propriétés suivantes peuvent être récupérées avec la fonction zmq_msg_get() :

ZMQ_MORE

Indique qu'il y a d'autres trames de message à suivre après le message.

ZMQ_SRCFD

Retourne le descripteur de fichier du socket à partir duquel le message a été lu. Cela permet à l'application de récupérer le point de terminaison distant via getpeername(2). Soyez conscient que le socket respectif pourrait être déjà fermé, voire réutilisé. Actuellement implémenté uniquement pour les sockets TCP.

ZMQ_SHARED

Indique qu'un message PEUT partager le stockage sous-jacent avec une autre copie de ce message.

VALEUR DE RETOUR

La fonction zmq_msg_get() retourne la valeur de la propriété en cas de succès. Sinon, elle retourne -1 et définit errno à l'une des valeurs définies ci-dessous.

ERREURS

EINVAL

La propriété demandée est inconnue.

EXEMPLE

Réception d'un message multi-trames.

zmq_msg_t frame;
while (true) {
    //  Créer un message 0MQ vide pour contenir la trame du message
    int rc = zmq_msg_init (&frame);
    assert (rc == 0);
    //  Bloquer jusqu'à ce qu'un message soit disponible à recevoir du socket
    rc = zmq_msg_recv (socket, &frame, 0);
    assert (rc != -1);
    if (zmq_msg_get (&frame, ZMQ_MORE))
        fprintf (stderr, "plus\n");
    else {
        fprintf (stderr, "fin\n");
        break;
    }
    zmq_msg_close (&frame);
}
