NOM

zmq_msg_init - initialiser un message 0MQ vide

SYNTAXE

int zmq_msg_init (zmq_msg_t *msg);

DESCRIPTION

La fonction zmq_msg_init() initialise l'objet message référencé par msg pour représenter un message vide. Cette fonction est plus utile lorsqu'elle est appelée avant de recevoir un message avec zmq_msg_recv().


Attention

Ne jamais accéder directement aux membres de zmq_msg_t, utilisez toujours la famille de fonctions zmq_msg.


Attention

Les fonctions zmq_msg_init(), zmq_msg_init_data(), zmq_msg_init_size() et zmq_msg_init_buffer() sont mutuellement exclusives. N'initialisez jamais le même zmq_msg_t deux fois.

VALEUR DE RETOUR

La fonction zmq_msg_init() retourne toujours zéro.

ERREURS

Aucune erreur n'est définie.

EXEMPLE

Recevoir un message d'une socket.

zmq_msg_t msg;
rc = zmq_msg_init (&msg);
assert (rc == 0);
int nbytes = zmq_msg_recv (socket, &msg, 0);
assert (nbytes != -1);
