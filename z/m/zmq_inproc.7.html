NOM

zmq_inproc - transport de communication 0MQ local inter-processus (inter-threads)

SYNTAXE

Le transport in-process passe les messages via la mémoire directement entre les threads partageant un unique contexte 0MQ.


Note

Aucun thread d'E/S n'est impliqué dans le passage des messages utilisant le transport inproc. Par conséquent, si vous utilisez un contexte 0MQ uniquement pour la messagerie inter-processus, vous pouvez initialiser le contexte avec zéro threads d'E/S. Voir zmq_init(3) pour plus de détails.

ADRESSAGE

Un point d'accès 0MQ est une chaîne de caractères composée d'un transport:// suivi d'une adresse. Le transport spécifie le protocole sous-jacent à utiliser. L'adresse spécifie l'adresse spécifique au transport à connecter.

Pour le transport in-process, le transport est inproc, et la signification de la partie adresse est définie ci-dessous.

Assignation d'une adresse locale à un socket

Lors de l'assignation d'une adresse locale à un socket en utilisant zmq_bind() avec le transport inproc, le point d'accès sera interprété comme une chaîne de caractères arbitraire identifiant le nom à créer. Le nom doit être unique au sein du contexte 0MQ associé au socket et peut avoir jusqu'à 256 caractères de longueur. Aucune autre restriction n'est placée sur le format du nom.

Connexion d'un socket

Lors de la connexion d'un socket à une adresse distante en utilisant zmq_connect() avec le transport inproc, le point d'accès sera interprété comme une chaîne de caractères arbitraire identifiant le nom auquel se connecter. Avant la version 4.0, le nom devait avoir été précédemment créé en l'assignant à au moins un socket au sein du même contexte 0MQ que le socket en cours de connexion. Depuis la version 4.0, l'ordre de zmq_bind() et zmq_connect() n'a pas d'importance, tout comme pour le type de transport tcp.

EXEMPLES

Assignation d'une adresse locale à un socket.

//  Assigner le nom in-process "#1"
rc = zmq_bind(socket, "inproc://#1");
assert (rc == 0);
//  Assigner le nom in-process "my-endpoint"
rc = zmq_bind(socket, "inproc://my-endpoint");
assert (rc == 0);

Connexion d'un socket.

//  Se connecter au nom in-process "#1"
rc = zmq_connect(socket, "inproc://#1");
assert (rc == 0);
//  Se connecter au nom in-process "my-endpoint"
rc = zmq_connect(socket, "inproc://my-endpoint");
assert (rc == 0);
