NOM

zmq_unbind - Arrêter l'acceptation des connexions sur une socket

SYNTAXE

int zmq_unbind (void *socket, const char *endpoint);

DESCRIPTION

La fonction zmq_unbind() désassocie une socket spécifiée par l'argument socket du point d'extrémité spécifié par l'argument endpoint.

De plus, la file d'attente des messages entrants associée au point d'extrémité sera supprimée. Cela signifie qu'après avoir désassocié un point d'extrémité, il est possible de recevoir des messages provenant de ce même point d'extrémité s'ils étaient déjà présents dans la file d'attente des messages entrants avant le désassemblage.

L'argument endpoint est tel que décrit dans zmq_bind(3)

Désassemblage d'une adresse wildcard d'une socket

Lorsque l'adresse wildcard * endpoint (décrite dans zmq_tcp(7), zmq_ipc(7), zmq_udp(7) et zmq_vmci(7)) a été utilisée dans zmq_bind(), l'appelant doit utiliser le vrai endpoint obtenu depuis l'option de socket ZMQ_LAST_ENDPOINT pour désassocier cet endpoint de la socket.

VALEUR DE RETOUR

La fonction zmq_unbind() retourne zéro en cas de succès. Sinon, elle retourne -1 et définit errno à l'une des valeurs définies ci-dessous.

ERREURS

EINVAL

Le point d'extrémité fourni est invalide.

ETERM

Le contexte 0MQ associé à la socket spécifiée a été terminé.

ENOTSOCK

La socket fournie était invalide.

ENOENT

Le point d'extrémité fourni n'était pas précédemment associé.

EXEMPLES

Désassocier une socket de type subscriber d'un transport TCP.

/* Créer une socket ZMQ_SUB */
void *socket = zmq_socket (context, ZMQ_SUB);
assert (socket);
/* La connecter au serveur server001, port 5555 en utilisant un transport TCP */
rc = zmq_bind (socket, "tcp://127.0.0.1:5555");
assert (rc == 0);
/* Déconnecter du point d'extrémité précédemment connecté */
rc = zmq_unbind (socket, "tcp://127.0.0.1:5555");
assert (rc == 0);

Désassocier une socket bindée avec wildcard *.

/* Créer une socket ZMQ_SUB */
void *socket = zmq_socket (context, ZMQ_SUB);
assert (socket);
/* La bind avec le port éphémère attribué par le système en utilisant un transport TCP */
rc = zmq_bind (socket, "tcp://127.0.0.1:*");
assert (rc == 0);
/* Obtenir le point d'extrémité réel */
const size_t buf_size = 32;
char buf[buf_size];
rc = zmq_getsockopt (socket, ZMQ_LAST_ENDPOINT, buf, (size_t *)&buf_size);
assert (rc == 0);
/* Désassocier la socket par le point d'extrémité réel */
rc = zmq_unbind (socket, buf);
assert (rc == 0);

NOTE

Notez que bien que l'implémentation soit similaire à zmq_disconnect(), les sémantiques sont différentes et les deux fonctions ne devraient pas être utilisées de manière interchangeable. Les sockets associées devraient être désassociées, et les sockets connectées devraient être déconnectées.
