NOM

zmq_proxy_steerable - proxy 0MQ intégré avec flux de contrôle

SYNOPSIS

int zmq_proxy_steerable (const void *frontend, const void *backend, const void *capture, const void *control);

DESCRIPTION

La fonction zmq_proxy_steerable() est une variante de la fonction zmq_proxy(). Elle accepte un quatrième socket de contrôle. Lorsque le socket de contrôle est NULL, les deux fonctions fonctionnent de manière identique.

Lorsqu'un socket de contrôle de type REP est fourni à la fonction proxy, l'application peut envoyer des commandes au proxy. Les commandes suivantes sont prises en charge.

PAUSE

Le proxy cessera de transférer les messages entre ses points d'extrémité.

RESUME

Le proxy reprendra le transfert des messages entre ses points d'extrémité.

TERMINATE

La fonction proxy se terminera avec une valeur de retour de 0.

STATISTICS

Le comportement du proxy restera inchangé et répondra avec un ensemble de valeurs récapitulatives simples des messages qui ont été envoyés via le proxy, comme décrit ci-dessous.

Il y a huit valeurs statistiques, chacune de taille uint64_t dans le message multi-parties renvoyé à la commande STATISTICS. Ce sont :

•nombre de messages reçus par le socket frontend
•nombre d'octets reçus par le socket frontend
•nombre de messages envoyés par le socket frontend
•nombre d'octets envoyés par le socket frontend
•nombre de messages reçus par le socket backend
•nombre d'octets reçus par le socket backend
•nombre de messages envoyés par le socket backend
•nombre d'octets envoyés par le socket backend

VALEUR DE RETOUR

La fonction zmq_proxy_steerable() retourne 0 si TERMINATE est reçu sur son socket de contrôle. Sinon, elle retourne -1 et errno est défini sur ETERM ou EINTR (le contexte 0MQ associé à l'un des sockets spécifiés a été terminé) ou EFAULT (le frontend ou le backend fourni était invalide).

EXEMPLE

Créer une fonction pour exécuter le proxy.

// Créer les sockets frontend et backend à proxifier
void *frontend = zmq_socket (context, ZMQ_ROUTER);
void *backend = zmq_socket (context, ZMQ_DEALER);
// Créer le socket de contrôle du proxy
void *control = zmq_socket (context, ZMQ_REP);
// Lier les sockets.
zmq_bind (frontend, "tcp://*:5555");
zmq_bind (backend, "tcp://*:5556");
zmq_bind (control, "tcp://*:5557");
zmq_proxy_steerable(frontend, backend, NULL, control);

Code dans un autre thread/processus pour diriger le proxy.

void *control = zmq_socket (context, ZMQ_REQ);
zmq_connect (control, "tcp://*:5557");
zmq_msg_t msg;
zmq_send (control, "PAUSE", 5, 0);
zmq_msg_recv (&msg, control, 0));
zmq_send (control, "RESUME", 6, 0);
zmq_msg_recv (&msg, control, 0));
zmq_send (control, "STATISTICS", 10, 0);
while (1) {
    zmq_msg_recv (&msg, control, 0));
    printf(" %lu", *(uint64_t *)zmq_msg_data (&msg));
    if (!zmq_msg_get (&msg, ZMQ_MORE))
        break;
}
printf("\n");
zmq_send (control, "TERMINATE", 9, 0);
zmq_msg_recv (&msg, control, 0));
zmq_close(frontend);
zmq_close(backend);
zmq_close(control);
