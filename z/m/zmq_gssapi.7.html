NOM

zmq_gssapi - authentification et confidentialité sécurisées

SYNOPSIS

Le mécanisme GSSAPI définit un moyen d'authentification et de confidentialité sécurisées pour les communications entre un client et un serveur utilisant l'interface de programmation d'application de services de sécurité génériques (GSSAPI). Le mécanisme GSSAPI peut être utilisé sur des réseaux publics et privés. GSSAPI est défini dans la RFC-2743 de l'IETF : http://tools.ietf.org/html/rfc2743. Le mécanisme GSSAPI de ZeroMQ est défini dans ce document : http://rfc.zeromq.org/spec:38.

ROLES CLIENT ET SERVEUR

Une socket utilisant GSSAPI peut être soit client, soit serveur, mais pas les deux.

Pour devenir un serveur GSSAPI, l'application définit l'option ZMQ_GSSAPI_SERVER sur la socket.

Pour devenir un client GSSAPI, l'application définit l'option ZMQ_GSSAPI_SERVICE_PRINCIPAL avec le nom du principal sur le serveur auquel elle a l'intention de se connecter.

Sur le client ou le serveur, l'application peut éventuellement définir l'option ZMQ_GSSAPI_PRINCIPAL pour fournir à la socket le nom du principal pour lequel les identifiants GSSAPI doivent être acquis. Si cette option n'est pas définie, les identifiants par défaut sont utilisés.

CHIFFREMENT OPTIONNEL

Par défaut, le mécanisme GSSAPI chiffrera toutes les communications entre le client et le serveur. Si le chiffrement n'est pas souhaité (par exemple, sur des réseaux privés), les applications client et serveur peuvent le désactiver en définissant l'option ZMQ_GSSAPI_PLAINTEXT. Le client et le serveur doivent tous deux définir cette option à la même valeur.

NOMS DE PRINCIPAUX

Les noms de principaux spécifiés avec les options ZMQ_GSSAPI_SERVICE_PRINCIPAL ou ZMQ_GSSAPI_PRINCIPAL sont interprétés comme des types de noms "basés sur l'hôte" par défaut. Les options ZMQ_GSSAPI_PRINCIPAL_NAMETYPE et ZMQ_GSSAPI_SERVICE_PRINCIPAL_NAMETYPE peuvent être utilisées pour changer le type de nom en l'un des suivants :

ZMQ_GSSAPI_NT_HOSTBASED

Le nom doit être de la forme "service" ou "service@hostname", qui sera analysé en un principal de "service/hostname" dans le domaine local. C'est le type de nom par défaut.

ZMQ_GSSAPI_NT_USER_NAME

Le nom doit être un nom d'utilisateur local, qui sera analysé en un principal à composante unique dans le domaine local.

ZMQ_GSSAPI_NT_KRB5_PRINCIPAL

Le nom est une chaîne de nom de principal. Ce type de nom ne fonctionne qu'avec le mécanisme GSSAPI krb5.
