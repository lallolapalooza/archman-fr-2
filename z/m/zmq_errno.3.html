NOM

zmq_errno - récupérer la valeur de errno pour le thread appelant

SYNOPSIS

int zmq_errno (void);

DESCRIPTION

La fonction zmq_errno() récupère la valeur de la variable errno pour le thread appelant.

La fonction zmq_errno() est fournie pour aider les utilisateurs sur les systèmes non-POSIX qui rencontrent des problèmes pour récupérer la bonne valeur de errno directement. Plus précisément, les utilisateurs sur systèmes Win32 dont l'application utilise une bibliothèque d'exécution C différente de celle utilisée par 0MQ devront utiliser zmq_errno() pour un fonctionnement correct.


Important

Les utilisateurs qui ne rencontrent pas de problèmes pour récupérer la bonne valeur de errno ne doivent pas utiliser cette fonction et devraient plutôt accéder directement à la variable errno.

VALEUR DE RETOUR

La fonction zmq_errno() renvoie la valeur de la variable errno pour le thread appelant.

ERREURS

Aucune erreur n'est définie.
