NOM

zmq_strerror - obtenir la chaîne de message d'erreur 0MQ

SYNTAXE

const char *zmq_strerror (int errnum);

DESCRIPTION

La fonction zmq_strerror() renvoie un pointeur vers une chaîne de message d'erreur correspondant au numéro d'erreur spécifié par l'argument errnum. Comme 0MQ définit des numéros d'erreur supplémentaires en plus de ceux définis par le système d'exploitation, les applications doivent préférer zmq_strerror() à la fonction standard strerror().

VALEUR DE RETOUR

La fonction zmq_strerror() renvoie un pointeur vers une chaîne de message d'erreur.

ERREURS

Aucune erreur n'est définie.

EXEMPLE

Afficher un message d'erreur lorsqu'un contexte 0MQ ne peut pas être initialisé.

void *ctx = zmq_init (1, 1, 0);
if (!ctx) {
    printf ("Une erreur s'est produite lors de zmq_init() : %s\n", zmq_strerror (errno));
    abort ();
}
