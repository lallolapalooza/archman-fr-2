NOM

zmq_ctx_destroy - terminer un contexte 0MQ

SYNTAXE

int zmq_ctx_destroy (void *context);

DESCRIPTION

La fonction zmq_ctx_destroy() termine le contexte 0MQ context.

La terminaison du contexte s'effectue en plusieurs étapes :

1.Toutes les opérations bloquantes actuellement en cours sur les sockets ouverts dans context retourneront immédiatement avec un code d'erreur ETERM. À l'exception de zmq_close(), toute autre opération sur les sockets ouverts dans context échouera avec un code d'erreur ETERM.
2.Après avoir interrompu tous les appels bloquants, zmq_ctx_destroy() bloquera jusqu'à ce que les conditions suivantes soient satisfaites :
•Tous les sockets ouverts dans context ont été fermés avec zmq_close().
•Pour chaque socket dans context, tous les messages envoyés par l'application avec zmq_send() ont été soit transférés physiquement à un pair réseau, soit la période d'attente (linger) du socket définie avec l'option de socket ZMQ_LINGER a expiré.

Pour plus de détails sur le comportement de la période d'attente des sockets, veuillez vous référer à l'option ZMQ_LINGER dans zmq_setsockopt(3).

Cette fonction est dépréciée par zmq_ctx_term(3).

VALEUR DE RETOUR

La fonction zmq_ctx_destroy() retourne zéro en cas de succès. Sinon, elle retourne -1 et définit errno à l'une des valeurs ci-dessous.

ERREURS

EFAULT

Le context fourni était invalide.

EINTR

La terminaison a été interrompue par un signal. Elle peut être redémarrée si nécessaire.
