NOM

zmq_msg_init_data - initialiser un message 0MQ à partir d'un tampon fourni

SYNOPSIS

typedef void (zmq_free_fn) (void *data, void *hint);

int zmq_msg_init_data (zmq_msg_t *msg, void *data, size_t size, zmq_free_fn *ffn, void *hint);

DESCRIPTION

La fonction zmq_msg_init_data() initialise l'objet message référencé par msg pour représenter le contenu référencé par le tampon situé à l'adresse data, d'une taille de size octets. Aucune copie de data n'est effectuée et 0MQ prend possession du tampon fourni.

Si elle est fournie, la fonction de désallocation ffn sera appelée une fois que le tampon de données ne sera plus requis par 0MQ, avec les arguments data et hint fournis à zmq_msg_init_data().


Attention

Ne jamais accéder directement aux membres de zmq_msg_t, mais toujours utiliser la famille de fonctions zmq_msg.


Attention

La fonction de désallocation ffn doit être thread-safe, car elle sera appelée depuis un thread arbitraire.


Attention

Si la fonction de désallocation n'est pas fournie, la mémoire allouée ne sera pas libérée, ce qui peut entraîner une fuite de mémoire.


Attention

Les fonctions zmq_msg_init(), zmq_msg_init_data(), zmq_msg_init_size() et zmq_msg_init_buffer() sont mutuellement exclusives. Ne jamais initialiser le même zmq_msg_t deux fois.

VALEUR DE RETOUR

La fonction zmq_msg_init_data() retourne zéro en cas de succès. Sinon, elle retourne -1 et définit errno à l'une des valeurs définies ci-dessous.

ERREURS

ENOMEM

Espace de stockage insuffisant disponible.

EXEMPLE

Initialisation d'un message à partir d'un tampon fourni.

void my_free (void *data, void *hint)
{
    free (data);
}
    /*  ...  */
void *data = malloc (6);
assert (data);
memcpy (data, "ABCDEF", 6);
zmq_msg_t msg;
rc = zmq_msg_init_data (&msg, data, 6, my_free, NULL);
assert (rc == 0);
