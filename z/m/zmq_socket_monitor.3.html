NOM

zmq_socket_monitor - surveiller les événements de socket

SYNTAXE

int zmq_socket_monitor (void *socket, char *endpoint, int events);

DESCRIPTION

La méthode zmq_socket_monitor() permet à un thread d'application de suivre les événements de socket (comme les connexions) sur un socket ZeroMQ. Chaque appel à cette méthode crée un socket ZMQ_PAIR et le lie au endpoint inproc:// spécifié. Pour collecter les événements de socket, vous devez créer votre propre socket ZMQ_PAIR et le connecter à l'endpoint.

Notez qu'il existe également une fonction DRAFT, zmq_socket_monitor_versioned(3), qui permet de s'abonner à des événements fournissant plus d'informations. Appeler zmq_socket_monitor est équivalent à appeler zmq_socket_monitor_versioned avec le paramètre event_version défini sur 1, à l'exception des cas d'erreur.

L'argument events est un masque de bits des événements de socket que vous souhaitez surveiller, voir Événements supportés ci-dessous. Pour surveiller tous les événements, utilisez la valeur d'événement ZMQ_EVENT_ALL. NOTE : à mesure que de nouveaux événements sont ajoutés, la valeur "tout capturer" commencera à les retourner. Une application qui repose sur une séquence d'événements stricte et fixe ne doit pas utiliser ZMQ_EVENT_ALL afin de garantir la compatibilité avec les versions futures.

Chaque événement est envoyé sous forme de deux trames. La première trame contient un numéro d'événement (16 bits) et une valeur d'événement (32 bits) qui fournit des données supplémentaires selon le numéro d'événement. La seconde trame contient une chaîne qui spécifie l'endpoint affecté.

La méthode _zmq_socket_monitor()_ ne prend en charge que les transports
orientés connexion, c'est-à-dire TCP, IPC et TIPC.

ÉVÉNEMENTS SUPPORTÉS

ZMQ_EVENT_CONNECTED

Le socket s'est connecté avec succès à un pair distant. La valeur d'événement est le descripteur de fichier (FD) du socket réseau sous-jacent. Attention : il n'y a aucune garantie que le FD soit encore valide lorsque votre code reçoit cet événement.

ZMQ_EVENT_CONNECT_DELAYED

Une demande de connexion sur le socket est en attente. La valeur d'événement n'est pas spécifiée.

ZMQ_EVENT_CONNECT_RETRIED

Une demande de connexion a échoué et est maintenant en cours de réessai. La valeur d'événement est l'intervalle de reconnexion en millisecondes. Notez que l'intervalle de reconnexion est recalculé à chaque tentative.

ZMQ_EVENT_LISTENING

Le socket a été lié avec succès à une interface réseau. La valeur d'événement est le FD du socket réseau sous-jacent. Attention : il n'y a aucune garantie que le FD soit encore valide lorsque votre code reçoit cet événement.

ZMQ_EVENT_BIND_FAILED

Le socket n'a pas pu être lié à une interface donnée. La valeur d'événement est l'errno généré par l'appel système bind.

ZMQ_EVENT_ACCEPTED

Le socket a accepté une connexion d'un pair distant. La valeur d'événement est le FD du socket réseau sous-jacent. Attention : il n'y a aucune garantie que le FD soit encore valide lorsque votre code reçoit cet événement.

ZMQ_EVENT_ACCEPT_FAILED

Le socket a rejeté une connexion d'un pair distant. La valeur d'événement est l'errno généré par l'appel accept.

ZMQ_EVENT_CLOSED

Le socket a été fermé. La valeur d'événement est le FD du socket réseau (maintenant fermé).

ZMQ_EVENT_CLOSE_FAILED

La fermeture du socket a échoué. La valeur d'événement est l'errno retourné par l'appel système. Notez que cet événement ne se produit que sur les transports IPC.

ZMQ_EVENT_DISCONNECTED

Le socket a été déconnecté de manière inattendue. La valeur d'événement est le FD du socket réseau sous-jacent. Attention : ce socket sera fermé.

ZMQ_EVENT_MONITOR_STOPPED

La surveillance sur ce socket s'est terminée.

ZMQ_EVENT_HANDSHAKE_FAILED_NO_DETAIL

Erreur non spécifiée pendant la négociation. La valeur d'événement est un errno.

ZMQ_EVENT_HANDSHAKE_SUCCEEDED

La négociation du mécanisme de sécurité ZMTP a réussi. La valeur d'événement n'est pas spécifiée.

ZMQ_EVENT_HANDSHAKE_FAILED_PROTOCOL

La négociation du mécanisme de sécurité ZMTP a échoué en raison d'une erreur de protocole du mécanisme, soit entre les pairs du mécanisme ZMTP, soit entre le serveur du mécanisme et le gestionnaire ZAP. Cela indique une erreur de configuration ou d'implémentation dans l'un ou l'autre pair ou dans le gestionnaire ZAP. La valeur d'événement est l'une des valeurs ZMQ_PROTOCOL_ERROR_* : ZMQ_PROTOCOL_ERROR_ZMTP_UNSPECIFIED ZMQ_PROTOCOL_ERROR_ZMTP_UNEXPECTED_COMMAND ZMQ_PROTOCOL_ERROR_ZMTP_INVALID_SEQUENCE ZMQ_PROTOCOL_ERROR_ZMTP_KEY_EXCHANGE ZMQ_PROTOCOL_ERROR_ZMTP_MALFORMED_COMMAND_UNSPECIFIED ZMQ_PROTOCOL_ERROR_ZMTP_MALFORMED_COMMAND_MESSAGE ZMQ_PROTOCOL_ERROR_ZMTP_MALFORMED_COMMAND_HELLO ZMQ_PROTOCOL_ERROR_ZMTP_MALFORMED_COMMAND_INITIATE ZMQ_PROTOCOL_ERROR_ZMTP_MALFORMED_COMMAND_ERROR ZMQ_PROTOCOL_ERROR_ZMTP_MALFORMED_COMMAND_READY ZMQ_PROTOCOL_ERROR_ZMTP_MALFORMED_COMMAND_WELCOME ZMQ_PROTOCOL_ERROR_ZMTP_INVALID_METADATA ZMQ_PROTOCOL_ERROR_ZMTP_CRYPTOGRAPHIC ZMQ_PROTOCOL_ERROR_ZMTP_MECHANISM_MISMATCH ZMQ_PROTOCOL_ERROR_ZAP_UNSPECIFIED ZMQ_PROTOCOL_ERROR_ZAP_MALFORMED_REPLY ZMQ_PROTOCOL_ERROR_ZAP_BAD_REQUEST_ID ZMQ_PROTOCOL_ERROR_ZAP_BAD_VERSION ZMQ_PROTOCOL_ERROR_ZAP_INVALID_STATUS_CODE ZMQ_PROTOCOL_ERROR_ZAP_INVALID_METADATA

ZMQ_EVENT_HANDSHAKE_FAILED_AUTH

La négociation du mécanisme de sécurité ZMTP a échoué en raison d'une défaillance d'authentification. La valeur d'événement est le code de statut renvoyé par le gestionnaire ZAP (c'est-à-dire 300, 400 ou 500).

VALEUR DE RETOUR

La fonction zmq_socket_monitor() retourne une valeur de 0 ou plus si elle réussit. Sinon, elle retourne -1 et définit errno à l'une des valeurs définies ci-dessous.

ERREURS

ETERM

Le contexte 0MQ associé au socket spécifié a été terminé.

EPROTONOSUPPORT

Le protocole de transport demandé n'est pas supporté. Les sockets de surveillance doivent utiliser le transport inproc://.

EINVAL

L'endpoint fourni est invalide.
