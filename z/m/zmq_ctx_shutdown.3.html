NOM

zmq_ctx_shutdown - arrêter un contexte 0MQ

SYNTAXE

int zmq_ctx_shutdown (void *contexte);

DESCRIPTION

La fonction zmq_ctx_shutdown() arrête le contexte 0MQ contexte.

L'arrêt du contexte entraînera le retour immédiat de toute opération bloquante en cours sur les sockets ouverts dans contexte avec un code d'erreur ETERM. À l'exception de zmq_close(), toute opération ultérieure sur les sockets ouverts dans contexte échouera avec un code d'erreur ETERM. Aucun autre socket ne peut être créé à l'aide de zmq_socket() sur un contexte pour lequel zmq_ctx_shutdown() a été appelé, elle retournera et définira errno à ETERM.

Cette fonction est facultative, le code client est toujours tenu d'appeler la fonction zmq_ctx_term(3) pour libérer toutes les ressources allouées par zeromq.

VALEUR DE RETOUR

La fonction zmq_ctx_shutdown() retourne zéro en cas de succès. Sinon, elle retourne -1 et définit errno à l'une des valeurs définies ci-dessous.

ERREURS

EFAULT

Le contexte fourni était invalide.
