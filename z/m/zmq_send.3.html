NOM

zmq_send - envoyer une partie de message sur une socket

SYNTAXE

int zmq_send (void *socket, const void *buf, size_t len, int flags);

DESCRIPTION

La fonction zmq_send() mettra en file d'attente un message créé à partir du tampon référencé par les arguments buf et len. L'argument flags est une combinaison des drapeaux définis ci-dessous :

ZMQ_DONTWAIT

Pour les types de sockets (DEALER, PUSH) qui bloquent (soit avec l'option ZMQ_IMMEDIATE définie et aucun pair disponible, soit tous les pairs ayant atteint leur marque haute pleine), spécifie que l'opération doit être effectuée en mode non bloquant. Si le message ne peut pas être mis en file d'attente sur la socket, la fonction zmq_send() échouera avec errno défini à EAGAIN.

ZMQ_SNDMORE

Spécifie que le message envoyé est un message multi-parties, et que d'autres parties de message vont suivre. Reportez-vous à la section concernant les messages multi-parties ci-dessous pour une description détaillée.

Note

Une invocation réussie de zmq_send() n'indique pas que le message a été transmis sur le réseau, seulement qu'il a été mis en file d'attente sur la socket et que 0MQ en a pris la responsabilité.

Messages multi-parties

Un message 0MQ est composé de 1 ou plusieurs parties de message. 0MQ assure la livraison atomique des messages : les pairs recevront soit toutes les parties de message d'un message, soit aucune. Le nombre total de parties de message est illimité, sauf par la mémoire disponible.

Une application qui envoie des messages multi-parties doit utiliser le drapeau ZMQ_SNDMORE lors de l'envoi de chaque partie de message, sauf la dernière.

VALEUR DE RETOUR

La fonction zmq_send() retournera le nombre d'octets dans le message si elle réussit. Sinon, elle retournera -1 et définira errno à l'une des valeurs définies ci-dessous.

ERREURS

EAGAIN

Le mode non bloquant a été demandé et le message ne peut pas être envoyé pour le moment.

ENOTSUP

L'opération zmq_send() n'est pas prise en charge par ce type de socket.

EINVAL

L'expéditeur a essayé d'envoyer des données multi-parties, ce que le type de socket ne permet pas.

EFSM

L'opération zmq_send() ne peut pas être effectuée sur cette socket pour le moment car la socket n'est pas dans l'état approprié. Cette erreur peut survenir avec les types de sockets qui basculent entre plusieurs états, tels que ZMQ_REP. Voir la section modèles de messagerie de zmq_socket(3) pour plus d'informations.

ETERM

Le contexte 0MQ associé à la socket spécifiée a été terminé.

ENOTSOCK

La socket fournie était invalide.

EINTR

L'opération a été interrompue par la livraison d'un signal avant que le message ne soit envoyé.

EHOSTUNREACH

Le message ne peut pas être routé.

EXEMPLE

Envoi d'un message multi-parties.

/* Envoie un message multi-parties composé de trois parties à la socket */
rc = zmq_send (socket, "ABC", 3, ZMQ_SNDMORE);
assert (rc == 3);
rc = zmq_send (socket, "DEFGH", 5, ZMQ_SNDMORE);
assert (rc == 5);
/* Dernière partie ; aucune partie à suivre */
rc = zmq_send (socket, "JK", 2, 0);
assert (rc == 2);
