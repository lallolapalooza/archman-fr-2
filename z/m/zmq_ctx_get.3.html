NOM

zmq_ctx_get - obtenir les options du contexte

SYNTAXE

int zmq_ctx_get (void *context, int option_name);

DESCRIPTION

La fonction zmq_ctx_get() renvoie l'option spécifiée par l'argument option_name.

La fonction zmq_ctx_get() accepte les noms d'options suivants :

ZMQ_IO_THREADS: Obtenir le nombre de threads d'I/O

L'argument ZMQ_IO_THREADS renvoie la taille du pool de threads 0MQ pour ce contexte.

ZMQ_MAX_SOCKETS: Obtenir le nombre maximal de sockets

L'argument ZMQ_MAX_SOCKETS renvoie le nombre maximal de sockets autorisé pour ce contexte.

ZMQ_MAX_MSGSZ: Obtenir la taille maximale des messages

L'argument ZMQ_MAX_MSGSZ renvoie la taille maximale d'un message autorisé pour ce contexte. La valeur par défaut est INT_MAX.

ZMQ_ZERO_COPY_RECV: Obtenir la stratégie de décodage des messages

L'argument ZMQ_ZERO_COPY_RECV renvoie si le décodeur de message utilise une stratégie de copie zéro lors de la réception des messages. La valeur par défaut est 1. NOTE : en état DRAFT, pas encore disponible dans les versions stables.

ZMQ_SOCKET_LIMIT: Obtenir le plus grand nombre configurable de sockets

L'argument ZMQ_SOCKET_LIMIT renvoie le plus grand nombre de sockets que zmq_ctx_set(3) acceptera.

ZMQ_IPV6: Définir l'option IPv6

L'argument ZMQ_IPV6 renvoie l'option IPv6 pour le contexte.

ZMQ_BLOCKY: Obtenir le paramètre blocky

L'argument ZMQ_BLOCKY renvoie 1 si le contexte bloquera lors de la terminaison, zéro si le pari "bloquer indéfiniment lors de la terminaison du contexte" a été désactivé en définissant ZMQ_BLOCKY à faux sur tous les nouveaux contextes.

ZMQ_THREAD_SCHED_POLICY: Obtenir la politique de planification pour les threads d'I/O

L'argument ZMQ_THREAD_SCHED_POLICY renvoie la politique de planification pour le pool de threads interne du contexte.

ZMQ_THREAD_NAME_PREFIX: Obtenir le préfixe de nom pour les threads d'I/O

L'argument ZMQ_THREAD_NAME_PREFIX obtient le préfixe numérique de chaque thread créé pour le pool de threads interne du contexte.

ZMQ_MSG_T_SIZE: Obtenir la taille de zmq_msg_t à l'exécution

L'argument ZMQ_MSG_T_SIZE renvoie la taille de la structure zmq_msg_t à l'exécution, telle que définie dans l'en-tête public include/zmq.h. Ceci est utile par exemple pour les liaisons FFI qui ne peuvent pas simplement faire un sizeof().

VALEUR DE RETOUR

La fonction zmq_ctx_get() renvoie une valeur de 0 ou supérieure en cas de succès. Sinon, elle renvoie -1 et définit errno à l'une des valeurs définies ci-dessous.

ERREURS

EINVAL

L'option demandée option_name est inconnue.

EFAULT

Le context fourni est invalide.

EXEMPLE

Définir une limite sur le nombre de sockets.

void *context = zmq_ctx_new ();
zmq_ctx_set (context, ZMQ_MAX_SOCKETS, 256);
int max_sockets = zmq_ctx_get (context, ZMQ_MAX_SOCKETS);
assert (max_sockets == 256);

Désactiver le pari de blocage du contexte.

zmq_ctx_set (ctx, ZMQ_BLOCKY, false);
