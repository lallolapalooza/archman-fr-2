NOM

zmq_bind - accepter des connexions entrantes sur une socket

SYNTAXE

int zmq_bind (void *socket, const char *endpoint);

DESCRIPTION

La fonction zmq_bind() lie la socket à un endpoint local, puis accepte les connexions entrantes sur cet endpoint.

L'endpoint est une chaîne de caractères composée d'un transport:// suivi d'une adresse. Le transport spécifie le protocole sous-jacent à utiliser. L'adresse spécifie l'adresse spécifique au transport à laquelle se lier.

0MQ fournit les transports suivants :

tcp

transport unicast utilisant TCP, voir zmq_tcp(7)

ipc

transport de communication inter-processus locale, voir zmq_ipc(7)

inproc

transport de communication intra-processus (inter-threads) locale, voir zmq_inproc(7)

pgm, epgm

transport multicast fiable utilisant PGM, voir zmq_pgm(7)

vmci

interface de communication de machine virtuelle (VMCI), voir zmq_vmci(7)

udp

unicast et multicast non fiable utilisant UDP, voir zmq_udp(7)

Tous les types de sockets 0MQ, à l'exception de ZMQ_PAIR et ZMQ_CHANNEL, prennent en charge les sémantiques un-à-plusieurs et plusieurs-à-un. Les sémantiques précises dépendent du type de socket et sont définies dans zmq_socket(3).

Les transports ipc, tcp, vmci et udp acceptent les adresses génériques : voir zmq_ipc(7), zmq_tcp(7), zmq_vmci(7) et zmq_udp(7) pour les détails.


Note

la syntaxe de l'adresse peut différer pour zmq_bind() et zmq_connect(), notamment pour les transports tcp, pgm et epgm.


Note

suite à un zmq_bind(), la socket entre dans un état muet jusqu'à ce qu'au moins une connexion entrante ou sortante soit établie, moment où la socket entre dans un état prête. Dans l'état muet, la socket bloque ou rejette les messages selon le type de socket, comme défini dans zmq_socket(3). En revanche, suite à un appel libzmq:zmq_connect[3], la socket entre dans l'état prête.

VALEUR DE RETOUR

La fonction zmq_bind() renvoie zéro en cas de succès. Sinon, elle renvoie -1 et définit errno à l'une des valeurs définies ci-dessous.

ERREURS

EINVAL

L'endpoint fourni est invalide.

EPROTONOSUPPORT

Le protocole de transport demandé n'est pas supporté.

ENOCOMPATPROTO

Le protocole de transport demandé n'est pas compatible avec le type de socket.

EADDRINUSE

L'adresse demandée est déjà utilisée.

EADDRNOTAVAIL

L'adresse demandée n'était pas locale.

ENODEV

L'adresse demandée spécifie une interface inexistante.

ETERM

Le contexte 0MQ associé à la socket spécifiée a été terminé.

ENOTSOCK

La socket fournie était invalide.

EMTHREAD

Aucun thread I/O n'est disponible pour accomplir la tâche.

EXEMPLE

Lier une socket publisher à un transport in-process et un transport TCP.

/* Créer une socket ZMQ_PUB */
void *socket = zmq_socket (context, ZMQ_PUB);
assert (socket);
/* La lier à un transport in-process avec l'adresse 'my_publisher' */
int rc = zmq_bind (socket, "inproc://my_publisher");
assert (rc == 0);
/* La lier à un transport TCP sur le port 5555 de l'interface 'eth0' */
rc = zmq_bind (socket, "tcp://eth0:5555");
assert (rc == 0);
