NOM

zmq_atomic_counter_destroy - détruit un compteur atomique

SYNTAXE

void zmq_atomic_counter_destroy (void **counter_p);

DESCRIPTION

La fonction zmq_atomic_counter_destroy détruit un compteur atomique et annule sa référence. Passez l'adresse d'un compteur atomique (void **) plutôt que le compteur lui-même. Vous devez détruire tous les compteurs que vous créez, afin d'éviter les fuites de mémoire. Cette fonction utilise des opérations atomiques spécifiques à la plateforme.

VALEUR DE RETOUR

La fonction zmq_atomic_counter_destroy() n'a pas de valeur de retour.

EXEMPLE

Code de test pour les compteurs atomiques.

void *counter = zmq_atomic_counter_new ();
assert (zmq_atomic_counter_value (counter) == 0);
assert (zmq_atomic_counter_inc (counter) == 0);
assert (zmq_atomic_counter_inc (counter) == 1);
assert (zmq_atomic_counter_inc (counter) == 2);
assert (zmq_atomic_counter_value (counter) == 3);
assert (zmq_atomic_counter_dec (counter) == 1);
assert (zmq_atomic_counter_dec (counter) == 1);
assert (zmq_atomic_counter_dec (counter) == 0);
zmq_atomic_counter_set (counter, 2);
assert (zmq_atomic_counter_dec (counter) == 1);
assert (zmq_atomic_counter_dec (counter) == 0);
zmq_atomic_counter_destroy (&counter);
return 0;
