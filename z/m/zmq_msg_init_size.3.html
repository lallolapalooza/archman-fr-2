NOM

zmq_msg_init_size - initialiser un message 0MQ d'une taille spécifiée

SYNTAXE

int zmq_msg_init_size (zmq_msg_t *msg, size_t size);

DESCRIPTION

La fonction zmq_msg_init_size() doit allouer toutes les ressources nécessaires pour stocker un message de size octets et initialiser l'objet message référencé par msg pour représenter le message nouvellement alloué.

L'implémentation doit choisir si le contenu du message est stocké sur la pile (petits messages) ou sur le tas (gros messages). Pour des raisons de performance, zmq_msg_init_size() ne doit pas effacer les données du message.


Attention

Ne jamais accéder aux membres de zmq_msg_t directement, utilisez toujours la famille de fonctions zmq_msg.


Attention

Les fonctions zmq_msg_init(), zmq_msg_init_data(), zmq_msg_init_size() et zmq_msg_init_buffer() s'excluent mutuellement. N'initialisez jamais le même zmq_msg_t deux fois.

VALEUR DE RETOUR

La fonction zmq_msg_init_size() doit retourner zéro en cas de succès. Sinon, elle doit retourner -1 et définir errno à l'une des valeurs définies ci-dessous.

ERREURS

ENOMEM

Espace de stockage insuffisant disponible.
