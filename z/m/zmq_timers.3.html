ZMQ_TIMERS(3) Manuel 0MQ ZMQ_TIMERS(3)

NOM

zmq_timers - fonctions utilitaires pour les rappels de minuteurs multiplateformes

SYNTAXE

typedef void(zmq_timer_fn) (int id_minuteur, void *arg);

void *zmq_timers_new (void);

int zmq_timers_destroy (void **pointeur_minuteurs);

int zmq_timers_add (void *minuteurs, size_t intervalle, zmq_timer_fn gestionnaire, void *arg);

int zmq_timers_cancel (void *minuteurs, int id_minuteur);

int zmq_timers_set_interval (void *minuteurs, int id_minuteur, size_t intervalle);

int zmq_timers_reset (void *minuteurs, int id_minuteur);

long zmq_timers_timeout (void *minuteurs);

int zmq_timers_execute (void *minuteurs);

DESCRIPTION

Les fonctions zmq_timers*_ fournissent un accès multiplateforme aux rappels de minuteurs. Une fois qu'un minuteur a été enregistré, il se répétera à l'intervalle spécifié jusqu'à ce qu'il soit annulé manuellement. Pour exécuter les rappels, zmq_timers_execute doit être appelé.

zmq_timers_new et zmq_timers_destroy gèrent la durée de vie d'une instance de minuteur. zmq_timers_new crée et retourne une nouvelle instance de minuteur, tandis que zmq_timers_destroy la détruit. Un pointeur vers un minuteur valide doit être passé comme argument pointeur_minuteurs de zmq_timers_destroy. En particulier, zmq_timers_destroy ne doit pas être appelé plusieurs fois pour la même instance de minuteur. zmq_timers_destroy met le pointeur passé à NULL en cas de succès.

zmq_timers_add et zmq_timers_cancel gèrent les minuteurs enregistrés.

zmq_timers_add enregistre un nouveau minuteur avec une instance donnée. minuteurs doit pointer vers un objet minuteurs valide. Le paramètre intervalle spécifie l'expiration du minuteur en millisecondes. gestionnaire et arg spécifient le rappel qui sera appelé à l'expiration et le paramètre optionnel qui sera passé. Le rappel doit être une fonction valide implémentant le prototype zmq_timer_fn. Un ID sera retourné qui pourra être utilisé pour modifier ou annuler le minuteur.

zmq_timers_cancel annulera le minuteur associé à id_minuteur à partir de l'instance minuteurs.

zmq_timers_set_interval définira l'expiration du minuteur associé à id_minuteur à partir de l'instance minuteurs à intervalle millisecondes dans le futur.

zmq_timers_reset redémarrera le minuteur associé à id_minuteur à partir de l'instance minuteurs.

zmq_timers_timeout retournera le temps restant en millisecondes avant l'expiration du prochain minuteur enregistré avec minuteurs.

zmq_timers_execute exécutera les rappels de tous les minuteurs expirés à partir de l'instance minuteurs.

SURETÉ THREAD

Comme la plupart des autres objets 0MQ, les minuteurs ne sont pas thread-safe. Toutes les opérations doivent être appelées à partir du même thread. Sinon, le comportement est indéfini.

VALEUR DE RETOUR

zmq_timers_new retourne toujours un pointeur valide vers un poller.

Toutes les fonctions qui retournent un entier retournent -1 en cas d'échec. Dans ce cas, zmq_errno() peut être utilisé pour interroger le type d'erreur comme décrit ci-dessous.

zmq_timers_timeout retourne le temps restant en millisecondes avant l'expiration du prochain minuteur enregistré avec minuteurs, ou -1 s'il n'y a plus de minuteurs.

Toutes les autres fonctions retournent 0 en cas de succès.

ERREURS

Sur zmq_timers_destroy, zmq_poller_cancel, zmq_timers_set_interval, zmq_timers_reset, zmq_timers_timeout_, et zmq_timers_execute: EFAULT:: minuteurs ne pointait pas vers un minuteur valide. Notez que passer un pointeur invalide (par exemple, un pointeur vers de la mémoire désallouée) peut entraîner un comportement indéfini (par exemple, une violation d'accès).

Sur zmq_timers_add: EFAULT:: minuteurs ne pointait pas vers un minuteur valide ou gestionnaire ne pointait pas vers une fonction valide.

Sur zmq_poller_cancel, zmq_timers_set_interval et zmq_timers_timeout_: EINVAL:: id_minuteur n'existait pas ou avait déjà été annulé.

EXEMPLE

Ajouter un minuteur avec une fonction de rappel simple qui modifie un booléen..

    void handler (int timer_id_, void *arg_)
    {
        (void) timer_id_; //  Évite les avertissements du compilateur sur 'non utilisé'
        *((bool *) arg_) = true;
    }
    ...
    void *timers = zmq_timers_new ();
    assert (timers);
    bool timer_invoked = false;
    const unsigned long full_timeout = 100;
    int timer_id =
      zmq_timers_add (timers, full_timeout, handler, &timer_invoked);
    assert (timer_id);
    //  Le minuteur ne devrait pas avoir été appelé encore
    int rc = zmq_timers_execute (timers);
    assert (rc == 0);
    //  Attendre la moitié du temps et vérifier à nouveau
    long timeout = zmq_timers_timeout (timers);
    assert (rc != -1);
    msleep (timeout / 2);
    rc = zmq_timers_execute (timers);
    assert (rc == 0);
    // Attendre jusqu'à la fin
    rc = msleep (zmq_timers_timeout (timers));
    assert (rc == 0);
    assert (timer_invoked);
    rc = zmq_timers_destroy (&timers);
    assert (rc == 0);
