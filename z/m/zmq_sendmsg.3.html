NOM

zmq_sendmsg - envoyer une partie de message sur une socket

SYNTAXE

int zmq_sendmsg (void *socket, zmq_msg_t *msg, int flags);

DESCRIPTION

La fonction zmq_sendmsg() mettra en file d'attente le message référencé par l'argument msg pour l'envoi à la socket référencée par l'argument socket. L'argument flags est une combinaison des indicateurs définis ci-dessous :

ZMQ_DONTWAIT

Pour les types de sockets (DEALER, PUSH) qui bloquent (soit avec l'option ZMQ_IMMEDIATE définie et aucun pair disponible, soit tous les pairs ayant une marque de fin de file pleine), spécifie que l'opération doit être effectuée en mode non bloquant. Si le message ne peut pas être mis en file d'attente sur la socket, la fonction zmq_sendmsg() échouera avec errno défini à EAGAIN.

ZMQ_SNDMORE

Spécifie que le message envoyé est un message multipart, et que d'autres parties de message vont suivre. Référez-vous à la section concernant les messages multipart ci-dessous pour une description détaillée.

La structure zmq_msg_t passée à zmq_sendmsg() est nullifiée pendant l'appel. Si vous souhaitez envoyer le même message à plusieurs sockets, vous devez le copier (par exemple, en utilisant zmq_msg_copy()).


Note

Une invocation réussie de zmq_sendmsg() n'indique pas que le message a été transmis sur le réseau, seulement qu'il a été mis en file d'attente sur la socket et que 0MQ a pris la responsabilité du message.


Note

cette méthode d'API est dépréciée en faveur de zmq_msg_send(3).

Messages multipart

Un message 0MQ est composé de 1 ou plusieurs parties de message. Chaque partie de message est une zmq_msg_t indépendante en soi. 0MQ assure la livraison atomique des messages : les pairs recevront soit toutes les parties de message d'un message, soit aucune. Le nombre total de parties de message est illimité, sauf par la mémoire disponible.

Une application qui envoie des messages multipart doit utiliser l'indicateur ZMQ_SNDMORE lors de l'envoi de chaque partie de message sauf la dernière.

VALEUR DE RETOUR

La fonction zmq_sendmsg() retournera le nombre d'octets dans le message en cas de succès. Sinon, elle retournera -1 et définira errno à l'une des valeurs définies ci-dessous.

ERREURS

EAGAIN

Le mode non bloquant a été demandé et le message ne peut pas être envoyé pour le moment.

ENOTSUP

L'opération zmq_sendmsg() n'est pas prise en charge par ce type de socket.

EINVAL

L'expéditeur a tenté d'envoyer des données multipart, ce que le type de socket ne permet pas.

EFSM

L'opération zmq_sendmsg() ne peut pas être effectuée sur cette socket pour le moment car la socket n'est pas dans l'état approprié. Cette erreur peut survenir avec des types de sockets qui basculent entre plusieurs états, tels que ZMQ_REP. Voir la section modèles de messagerie de zmq_socket(3) pour plus d'informations.

ETERM

Le contexte 0MQ associé à la socket spécifiée a été terminé.

ENOTSOCK

La socket fournie était invalide.

EINTR

L'opération a été interrompue par la livraison d'un signal avant que le message ne soit envoyé.

EFAULT

Message invalide.

EHOSTUNREACH

Le message ne peut pas être acheminé.

EXEMPLE

Remplissage d'un message et envoi à une socket.

/* Créer un nouveau message, allouer 6 octets pour le contenu du message */
zmq_msg_t msg;
int rc = zmq_msg_init_size (&msg, 6);
assert (rc == 0);
/* Remplir le contenu du message avec 'AAAAAA' */
memset (zmq_msg_data (&msg), 'A', 6);
/* Envoyer le message à la socket */
rc = zmq_sendmsg (socket, &msg, 0);
assert (rc == 6);

Envoi d'un message multipart.

/* Envoyer un message multipart composé de trois parties à la socket */
rc = zmq_sendmsg (socket, &part1, ZMQ_SNDMORE);
rc = zmq_sendmsg (socket, &part2, ZMQ_SNDMORE);
/* Partie finale ; aucune autre partie à suivre */
rc = zmq_sendmsg (socket, &part3, 0);
