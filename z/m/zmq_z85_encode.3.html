NOM

zmq_z85_encode - encode une clé binaire en texte imprimable Z85

SYNOPSIS

char *zmq_z85_encode (char *dest, const uint8_t *data, size_t size);

DESCRIPTION

La fonction zmq_z85_encode() doit encoder le bloc binaire spécifié par data et size dans une chaîne en dest. La taille du bloc binaire doit être divisible par 4. dest doit disposer de suffisamment d'espace pour size * 1.25 plus 1 pour un terminateur nul. Une clé CURVE de 32 octets est encodée en 40 caractères ASCII plus un terminateur nul.

L'encodage doit suivre la spécification ZMQ RFC 32.

VALEUR DE RETOUR

La fonction zmq_z85_encode() doit retourner dest en cas de succès, sinon elle doit retourner NULL.

EXEMPLE

Encodage d'une clé CURVE.

#include <sodium.h>
uint8_t public_key [32];
uint8_t secret_key [32];
int rc = crypto_box_keypair (public_key, secret_key);
assert (rc == 0);
char encoded [41];
zmq_z85_encode (encoded, public_key, 32);
puts (encoded);
