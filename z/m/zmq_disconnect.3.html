NOM

zmq_disconnect - Déconnecter une socket d'un point d'accès

SYNTAXE

int zmq_disconnect (void *socket, const char *endpoint);

DESCRIPTION

La fonction zmq_disconnect() déconnecte la socket spécifiée par l'argument socket du point d'accès spécifié par l'argument endpoint. Notez que l'appel système de déconnexion réel peut survenir plus tard.

Lors de la déconnexion, la socket cessera également de recevoir les messages provenant de ce point d'accès. De plus, la socket ne pourra plus mettre en file d'attente les messages sortants vers ce point d'accès. La file d'attente des messages sortants associée au point d'accès sera supprimée. Cependant, si la période de latence (linger period) de la socket est non nulle, libzmq tentera toujours de transmettre ces messages supprimés, jusqu'à l'expiration de la période de latence.

L'argument endpoint est tel que décrit dans zmq_connect(3)


Note

Le réglage par défaut de ZMQ_LINGER ne supprime pas les messages non envoyés ; ce comportement peut entraîner le blocage de l'application lors de l'appel à zmq_ctx_term(). Pour plus de détails, voir zmq_setsockopt(3) et zmq_ctx_term(3).

VALEUR DE RETOUR

La fonction zmq_disconnect() retourne zéro en cas de succès. Sinon, elle retourne -1 et définit errno à l'une des valeurs définies ci-dessous.

ERREURS

EINVAL

Le point d'accès fourni est invalide.

ETERM

Le contexte 0MQ associé à la socket spécifiée a été terminé.

ENOTSOCK

La socket fournie était invalide.

ENOENT

Le point d'accès fourni n'est pas utilisé par la socket.

EXEMPLE

Connexion d'une socket d'abonné à un transport intra-processus et un transport TCP.

/* Créer une socket ZMQ_SUB */
void *socket = zmq_socket (context, ZMQ_SUB);
assert (socket);
/* La connecter au serveur host001, port 5555 en utilisant un transport TCP */
rc = zmq_connect (socket, "tcp://server001:5555");
assert (rc == 0);
/* Se déconnecter du point d'accès précédemment connecté */
rc = zmq_disconnect (socket, "tcp://server001:5555");
assert (rc == 0);
