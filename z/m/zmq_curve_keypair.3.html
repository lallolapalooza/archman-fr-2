NOM

zmq_curve_keypair - générer une nouvelle paire de clés CURVE

SYNTAXE

int zmq_curve_keypair (char *z85_public_key, char *z85_secret_key);

DESCRIPTION

La fonction zmq_curve_keypair() renvoie une nouvelle paire de clés aléatoire générée, composée d'une clé publique et d'une clé secrète. L'appelant fournit deux buffers, chacun d'au moins 41 octets, dans lesquels cette méthode stockera les clés. Les clés sont encodées en utilisant zmq_z85_encode(3).

VALEUR DE RETOUR

La fonction zmq_curve_keypair() renvoie 0 en cas de succès, sinon elle renvoie -1 et définit errno à l'une des valeurs définies ci-dessous.

ERREURS

ENOTSUP

La bibliothèque libzmq n'a pas été compilée avec le support cryptographique (libsodium).

EXEMPLE

Générer une nouvelle paire de clés CURVE.

char public_key [41];
char secret_key [41];
int rc = zmq_curve_keypair (public_key, secret_key);
assert (rc == 0);
