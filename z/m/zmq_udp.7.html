NOM

zmq_udp - Transport UDP multicast et unicast 0MQ

SYNTAXE

UDP est un protocole de transport de données non fiable sur les réseaux IP. UDP prend en charge la communication unicast et multicast.

DESCRIPTION

Le transport UDP ne peut être utilisé qu'avec les types de sockets ZMQ_RADIO et ZMQ_DISH.

ADRESSAGE

Un point de terminaison 0MQ est une chaîne composée d'un transport:// suivi d'une adresse. Le transport spécifie le protocole sous-jacent à utiliser. L'adresse spécifie l'adresse spécifique au transport à laquelle se connecter.

Pour le transport UDP, le transport est udp. La signification de la partie adresse est définie ci-dessous.

LIAISON D'UNE PRISE

Avec udp, nous ne pouvons lier que le type de socket ZMQ_DISH. Lors de la liaison d'une prise à l'aide de zmq_bind() avec le transport udp, le point de terminaison doit être interprété comme une interface suivie d'un deux-points et du numéro de port UDP à utiliser.

Une interface peut être spécifiée par l'un des éléments suivants :

•Le caractère générique *, signifiant toutes les interfaces disponibles.
•Le nom de l'interface réseau (par exemple, eth0, lo, wlan0, etc.)
•L'adresse principale attribuée à l'interface, sous sa forme numérique.
•L'adresse multicast sous sa forme numérique à laquelle la prise doit se joindre.

Le numéro de port UDP peut être spécifié comme une valeur numérique, généralement supérieure à 1024 sur les systèmes POSIX.

CONNEXION D'UNE PRISE

Avec udp, nous ne pouvons connecter que le type de socket ZMQ_RADIO. Lors de la connexion d'une prise à une adresse de pair à l'aide de zmq_connect() avec le transport udp, le point de terminaison doit être interprété comme une adresse de pair suivie d'un deux-points et du numéro de port UDP à utiliser.

Une adresse de pair peut être spécifiée par l'un des éléments suivants :

•L'adresse IPv4 ou IPv6 du pair, sous sa forme numérique ou en utilisant son nom d'hôte.
•L'adresse multicast sous sa forme numérique.

EXEMPLES

Liaison d'une prise.

//  Unicast - Port UDP 5555 sur toutes les interfaces disponibles
rc = zmq_bind(dish, "udp://*:5555");
assert (rc == 0);
//  Unicast - Port UDP 5555 sur l'interface de bouclage locale
rc = zmq_bind(dish, "udp://127.0.0.1:5555");
assert (rc == 0);
//  Unicast - Port UDP 5555 sur l'interface eth1
rc = zmq_bind(dish, "udp://eth1:5555");
assert (rc == 0);
//  Multicast - Port UDP 5555 sur une adresse Multicast
rc = zmq_bind(dish, "udp://239.0.0.1:5555");
assert (rc == 0);
//  Identique à ci-dessus mais en se joignant uniquement sur l'interface eth0
rc = zmq_bind(dish, "udp://eth0;239.0.0.1:5555");
assert (rc == 0);
//  Identique à ci-dessus en utilisant le multicast IPv6
rc = zmq_bind(dish, "udp://eth0;[ff02::1]:5555");
assert (rc == 0);

Connexion d'une prise.

//  Connexion à l'aide d'une adresse IP Unicast
rc = zmq_connect(radio, "udp://192.168.1.1:5555");
assert (rc == 0);
//  Connexion à l'aide d'une adresse Multicast
rc = zmq_connect(socket, "udp://239.0.0.1:5555);
assert (rc == 0);
//  Connexion à l'aide d'une adresse Multicast en utilisant l'interface locale wlan0
rc = zmq_connect(socket, "udp://wlan0;239.0.0.1:5555);
assert (rc == 0);
//  Connexion au multicast IPv6
rc = zmq_connect(socket, "udp://[ff02::1]:5555);
assert (rc == 0);
