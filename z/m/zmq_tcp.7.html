NOM

zmq_tcp - Transport 0MQ unifié utilisant TCP

SYNTAXE

TCP est un transport unifié, fiable, universel. Lorsque vous connectez des applications distribuées sur un réseau avec 0MQ, l'utilisation du transport TCP sera probablement votre premier choix.

ADRESSAGE

Un point d'accès 0MQ est une chaîne composée d'un transport:// suivi d'une adresse. Le transport spécifie le protocole sous-jacent à utiliser. L'adresse spécifie l'adresse spécifique au transport à laquelle se connecter.

Pour le transport TCP, le transport est tcp, et la signification de la partie adresse est définie ci-dessous.

Assignation d'une adresse locale à une socket

Lors de l'assignation d'une adresse locale à une socket à l'aide de zmq_bind() avec le transport tcp, le point d'accès sera interprété comme une interface suivie d'un deux-points et du numéro de port TCP à utiliser.

Une interface peut être spécifiée par l'un des éléments suivants :

•Le joker *, signifiant toutes les interfaces disponibles.
•L'adresse IPv4 ou IPv6 principale assignée à l'interface, sous sa forme numérique.
•Le nom d'interface non portable tel que défini par le système d'exploitation.

Le numéro de port TCP peut être spécifié par :

•Une valeur numérique, généralement supérieure à 1024 sur les systèmes POSIX.
•Le joker *, signifiant un port éphémère assigné par le système.

En utilisant des ports éphémères, l'appelant doit récupérer le port réellement assigné en utilisant l'option de socket ZMQ_LAST_ENDPOINT. Voir zmq_getsockopt(3) pour plus de détails.

Désaffectation d'une adresse joker d'une socket

Lorsque le joker * point d'accès a été utilisé dans zmq_bind(), l'appelant doit utiliser le vrai point d'accès obtenu à partir de l'option de socket ZMQ_LAST_ENDPOINT pour désaffecter ce point d'accès d'une socket à l'aide de zmq_unbind().

Connexion d'une socket

Lors de la connexion d'une socket à une adresse de pair à l'aide de zmq_connect() avec le transport tcp, le point d'accès sera interprété comme une adresse de pair suivie d'un deux-points et du numéro de port TCP à utiliser. Vous pouvez éventuellement spécifier un point d'accès source qui sera utilisé comme adresse source pour votre connexion ; tcp://point_d_accès_source;'point d'accès', voir la description de l'*interface* ci-dessus pour plus de détails.

Une adresse de pair peut être spécifiée par l'un des éléments suivants :

•Le nom DNS du pair.
•L'adresse IPv4 ou IPv6 du pair, sous sa forme numérique.

Note : Une description du protocole de transport ZeroMQ (ZMTP) utilisé par le transport TCP peut être trouvée à l'adresse http://rfc.zeromq.org/spec:23

HWM

Pour le transport TCP, le mécanisme de seuil élevé (HWM - High Water Mark) fonctionne en conjonction avec les tampons de socket TCP gérés au niveau du système d'exploitation. En fonction du système d'exploitation et de plusieurs autres facteurs, la taille de ces tampons TCP sera différente. De plus, les tampons TCP fournis par le système d'exploitation peuvent accueillir un nombre variable de messages en fonction de la taille des messages (contrairement aux paramètres HWM de ZMQ, les tampons de socket TCP sont mesurés en octets et non en messages).

Cela peut entraîner des comportements apparemment inexplicables : par exemple, vous pourriez vous attendre à ce que la définition de ZMQ_SNDHWM à 100 sur une socket utilisant le transport TCP bloque la transmission du 101e message si le récepteur est lent. Ceci est très peu probable lors de l'utilisation du transport TCP, car les tampons TCP du système d'exploitation fourniront généralement un buffer suffisant pour vous permettre d'envoyer beaucoup plus de 100 messages.

Bien sûr, si le récepteur est lent, la transmission sur une socket ZMQ TCP finira par déclencher l'"état muet" de la socket ; ne vous fiez pas à la valeur HWM exacte.

Évidemment, les mêmes considérations s'appliquent au HWM de réception (voir ZMQ_RCVHWM).

EXEMPLES

Assignation d'une adresse locale à une socket.

//  Port TCP 5555 sur toutes les interfaces disponibles
rc = zmq_bind(socket, "tcp://*:5555");
assert (rc == 0);
//  Port TCP 5555 sur l'interface de boucle locale sur toutes les plateformes
rc = zmq_bind(socket, "tcp://127.0.0.1:5555");
assert (rc == 0);
//  Port TCP 5555 sur la première interface réseau Ethernet sous Linux
rc = zmq_bind(socket, "tcp://eth0:5555");
assert (rc == 0);

Connexion d'une socket.

//  Connexion à l'aide d'une adresse IP
rc = zmq_connect(socket, "tcp://192.168.1.1:5555");
assert (rc == 0);
//  Connexion à l'aide d'un nom DNS
rc = zmq_connect(socket, "tcp://server1:5555");
assert (rc == 0);
//  Connexion à l'aide d'un nom DNS et liaison à eth1
rc = zmq_connect(socket, "tcp://eth1:0;server1:5555");
assert (rc == 0);
//  Connexion à l'aide d'une adresse IP et liaison à une adresse IP
rc = zmq_connect(socket, "tcp://192.168.1.17:5555;192.168.1.1:5555");
assert (rc == 0);
