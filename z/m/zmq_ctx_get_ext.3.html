NOM

zmq_ctx_get_ext - obtenir les options étendues du contexte

SYNOPSIS

int zmq_ctx_get_ext (void *context, int option_name, void *option_value, size_t *option_len);

DESCRIPTION

La fonction zmq_ctx_get() récupère la valeur de l'option spécifiée par l'argument option_name et la stocke dans le tampon pointé par l'argument option_value. L'argument option_len est la taille en octets du tampon pointé par option_value ; en cas de succès, zmq_ctx_get_ext() modifie l'argument option_len pour indiquer la taille réelle de la valeur de l'option stockée dans le tampon.

La fonction zmq_ctx_get_ext() accepte tous les noms d'options acceptés par zmq_ctx_get(). Les options qui ont le plus de sens à récupérer à l'aide de zmq_ctx_get_ext() plutôt que de zmq_ctx_get() sont :

ZMQ_THREAD_NAME_PREFIX : Obtenir le préfixe du nom des fils d’E/S

L'argument ZMQ_THREAD_NAME_PREFIX récupère le préfixe de chaîne de chaque fil d'exécution créé pour le pool de fils internes du contexte.

Type de valeur d'option chaîne de caractères
Unité de valeur d'option N/A
Valeur par défaut chaîne vide

VALEUR DE RETOUR

La fonction zmq_ctx_get_ext() retourne une valeur de 0 ou plus si elle réussit. Sinon, elle retourne -1 et définit errno à l'une des valeurs définies ci-dessous.

ERREURS

EINVAL

L'option demandée option_name est inconnue.

EFAULT

Le context fourni est invalide.

EXEMPLE

Définir un préfixe pour les noms des fils internes ZMQ :.

void *context = zmq_ctx_new ();
const char prefix[] = "MyApp";
size_t prefixLen = sizeof(prefix);
zmq_ctx_set (context, ZMQ_THREAD_NAME_PREFIX, &prefix, &prefixLen);
char buff[256];
size_t buffLen = sizeof(buff);
int rc = zmq_ctx_get (context, ZMQ_THREAD_NAME_PREFIX, &buff, &buffLen);
assert (rc == 0);
assert (buffLen == prefixLen);
