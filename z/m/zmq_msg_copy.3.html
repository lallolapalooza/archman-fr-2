NOM

zmq_msg_copy - copie le contenu d'un message vers un autre message

SYNOPIS

int zmq_msg_copy (zmq_msg_t *dest, zmq_msg_t *src);

DESCRIPTION

La fonction zmq_msg_copy() copie l'objet message référencé par src vers l'objet message référencé par dest. Le contenu original de dest, s'il existe, sera libéré. Vous devez initialiser dest avant de copier dedans.


Attention

L'implémentation peut choisir de ne pas copier physiquement le contenu du message, mais plutôt de partager le tampon sous-jacent entre src et dest. Évitez de modifier le contenu du message après qu'il ait été copié avec zmq_msg_copy(), car cela pourrait entraîner un comportement indéfini. Si vous avez besoin d'une copie physique réelle, initialisez un nouveau message en utilisant zmq_msg_init_buffer() avec le contenu du message.


Attention

N'accédez jamais directement aux membres de zmq_msg_t, utilisez toujours la famille de fonctions zmq_msg.

VALEUR RENVOYÉE

La fonction zmq_msg_copy() renvoie zéro en cas de succès. Sinon, elle renvoie -1 et définit errno à l'une des valeurs définies ci-dessous.

ERREURS

EFAULT

Message invalide.

EXEMPLE

Copie d'un message.

zmq_msg_t msg;
zmq_msg_init_buffer (&msg, "Bonjour, Monde", 12);
zmq_msg_t copy;
zmq_msg_init (&copy);
zmq_msg_copy (&copy, &msg);
...
zmq_msg_close (&copy);
zmq_msg_close (&msg);
