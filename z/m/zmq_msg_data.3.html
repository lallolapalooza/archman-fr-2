NOM

zmq_msg_data - récupérer le pointeur vers le contenu du message

SYNTAXE

void *zmq_msg_data (zmq_msg_t *msg);

DESCRIPTION

La fonction zmq_msg_data() renverra un pointeur vers le contenu du message de l'objet message référencé par msg.


Attention

N'accédez jamais directement aux membres de zmq_msg_t, utilisez toujours la famille de fonctions zmq_msg.

VALEUR DE RETOUR

En cas de succès, zmq_msg_data() renverra un pointeur vers le contenu du message.

ERREURS

Aucune erreur définie.
