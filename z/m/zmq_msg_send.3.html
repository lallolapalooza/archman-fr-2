NOM

zmq_msg_send - envoyer une partie de message sur un socket

SYNTAXE

int zmq_msg_send (zmq_msg_t *msg, void *socket, int flags);

DESCRIPTION

La fonction zmq_msg_send() est identique à zmq_sendmsg(3), qui sera dépréciée dans les futures versions. zmq_msg_send() est plus cohérente avec d'autres fonctions de manipulation de messages.

La fonction zmq_msg_send() met en file d'attente le message référencé par l'argument msg pour être envoyé au socket référencé par l'argument socket. L'argument flags est une combinaison des indicateurs définis ci-dessous :

ZMQ_DONTWAIT

Pour les types de sockets (DEALER, PUSH) qui bloquent (soit avec l'option ZMQ_IMMEDIATE définie et aucun pair disponible, soit tous les pairs ayant la marque haute pleine), spécifie que l'opération doit être effectuée en mode non bloquant. Si le message ne peut pas être mis en file d'attente sur le socket, la fonction zmq_msg_send() échouera avec errno défini à EAGAIN.

ZMQ_SNDMORE

Spécifie que le message envoyé est un message multipart, et que d'autres parties du message suivront. Reportez-vous à la section sur les messages multipart ci-dessous pour une description détaillée.

La structure zmq_msg_t passée à zmq_msg_send() est nullifiée en cas d'appel réussi. Si vous souhaitez envoyer le même message à plusieurs sockets, vous devez le copier (par exemple, en utilisant zmq_msg_copy()). Si l'appel échoue, la structure zmq_msg_t reste intacte, et doit être consommée par un autre appel à zmq_msg_send() sur le même socket ou un autre, ou libérée à l'aide de zmq_msg_close() pour éviter une fuite de mémoire.


Note

Une invocation réussie de zmq_msg_send() n'indique pas que le message a été transmis au réseau, seulement qu'il a été mis en file d'attente sur le socket et que 0MQ a assumé la responsabilité du message. Vous n'avez pas besoin d'appeler zmq_msg_close() après un zmq_msg_send() réussi.

Messages multipart

Un message 0MQ est composé de 1 ou plusieurs parties de message. Chaque partie de message est une zmq_msg_t indépendante en soi. 0MQ garantit la livraison atomique des messages : les pairs recevront soit toutes les parties du message d'un message, soit aucune. Le nombre total de parties de message est illimité, sauf par la mémoire disponible.

Une application qui envoie des messages multipart doit utiliser l'indicateur ZMQ_SNDMORE lors de l'envoi de chaque partie du message sauf la dernière.

VALEUR DE RETOUR

La fonction zmq_msg_send() renverra le nombre d'octets dans le message en cas de succès (si le nombre d'octets est supérieur à MAX_INT, la fonction renverra MAX_INT). Sinon, elle renverra -1 et définira errno à l'une des valeurs définies ci-dessous.

ERREURS

EAGAIN

Le mode non bloquant a été demandé et le message ne peut pas être envoyé pour le moment.

ENOTSUP

L'opération zmq_msg_send() n'est pas prise en charge par ce type de socket.

EINVAL

L'expéditeur a tenté d'envoyer des données multipart, ce que le type de socket ne permet pas.

EFSM

L'opération zmq_msg_send() ne peut pas être effectuée sur ce socket pour le moment car le socket n'est pas dans l'état approprié. Cette erreur peut survenir avec les types de sockets qui basculent entre plusieurs états, comme ZMQ_REP. Voir la section sur les modèles de messagerie de zmq_socket(3) pour plus d'informations.

ETERM

Le contexte 0MQ associé au socket spécifié a été terminé.

ENOTSOCK

Le socket fourni était invalide.

EINTR

L'opération a été interrompue par la livraison d'un signal avant que le message ne soit envoyé.

EFAULT

Message invalide.

EHOSTUNREACH

Le message ne peut pas être routé.

EXEMPLE

Remplir un message et l'envoyer à un socket.

/* Créer un nouveau message, allouant 6 octets pour le contenu du message */
zmq_msg_t msg;
int rc = zmq_msg_init_size (&msg, 6);
assert (rc == 0);
/* Remplir le contenu du message avec 'AAAAAA' */
memset (zmq_msg_data (&msg), 'A', 6);
/* Envoyer le message au socket */
rc = zmq_msg_send (&msg, socket, 0);
assert (rc == 6);

Envoyer un message multipart.

/* Envoyer un message multipart composé de trois parties au socket */
rc = zmq_msg_send (&part1, socket, ZMQ_SNDMORE);
rc = zmq_msg_send (&part2, socket, ZMQ_SNDMORE);
/* Partie finale ; aucune autre partie à suivre */
rc = zmq_msg_send (&part3, socket, 0);
