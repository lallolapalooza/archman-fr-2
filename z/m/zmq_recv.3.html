NOM

zmq_recv - recevoir une partie de message d'une socket

SYNOPSIS

int zmq_recv (void *socket, void *buf, size_t len, int flags);

DESCRIPTION

La fonction zmq_recv() doit recevoir un message de la socket référencée par l'argument socket et le stocker dans le tampon référencé par l'argument buf. Les octets excédant la longueur spécifiée par l'argument len seront tronqués. S'il n'y a pas de messages disponibles sur la socket spécifiée, la fonction zmq_recv() se bloquera jusqu'à ce que la requête puisse être satisfaite. L'argument flags est une combinaison des drapeaux définis ci-dessous : L'argument buf peut être nul si len est zéro.

ZMQ_DONTWAIT

Spécifie que l'opération doit être effectuée en mode non bloquant. S'il n'y a pas de messages disponibles sur la socket spécifiée, la fonction zmq_recv() échouera avec errno défini sur EAGAIN.

Messages multi-parties

Un message 0MQ est composé de 1 ou plusieurs parties de message. 0MQ assure la livraison atomique des messages : les pairs recevront soit toutes les parties de message d'un message, soit aucune. Le nombre total de parties de message est illimité, sauf limitation par la mémoire disponible.

Une application qui traite des messages multi-parties doit utiliser l'option ZMQ_RCVMORE de zmq_getsockopt(3) après avoir appelé zmq_recv() pour déterminer s'il y a d'autres parties à recevoir.

VALEUR DE RETOUR

La fonction zmq_recv() retournera le nombre d'octets dans le message en cas de succès. Notez que la valeur peut dépasser la valeur du paramètre len si le message a été tronqué. En cas d'échec, la fonction retournera -1 et définira errno sur l'une des valeurs définies ci-dessous.

ERREURS

EAGAIN

Soit le délai d'attente défini via l'option de socket ZMQ_RCVTIMEO (voir zmq_setsockopt(3)) a été atteint (drapeau ZMQ_DONTWAIT non défini) sans pouvoir lire un message de la socket, soit il n'y a pas de messages disponibles pour le moment (drapeau ZMQ_DONTWAIT défini) et l'opération bloquerait.

ENOTSUP

L'opération zmq_recv() n'est pas prise en charge par ce type de socket.

EFSM

L'opération zmq_recv() ne peut pas être effectuée sur cette socket pour le moment car la socket n'est pas dans l'état approprié. Cette erreur peut survenir avec des types de sockets qui basculent entre plusieurs états, comme ZMQ_REP. Voir la section modèles de messagerie de zmq_socket(3) pour plus d'informations.

ETERM

Le contexte 0MQ associé à la socket spécifiée a été terminé.

ENOTSOCK

La socket fournie était invalide.

EINTR

L'opération a été interrompue par la livraison d'un signal avant qu'un message ne soit disponible.

EXEMPLE

Réception d'un message à partir d'une socket.

char buf [256];
nbytes = zmq_recv (socket, buf, 256, 0);
assert (nbytes != -1);
