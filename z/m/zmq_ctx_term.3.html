NOM

zmq_ctx_term - terminer un contexte 0MQ

SYNTAXE

int zmq_ctx_term (void *contexte);

DESCRIPTION

La fonction zmq_ctx_term() détruit le contexte 0MQ contexte.

La terminaison du contexte s'effectue en plusieurs étapes :

1.Toute opération bloquante en cours sur les sockets ouverts dans contexte sera interrompue immédiatement avec un code d'erreur ETERM. À l'exception de zmq_close(), toute autre opération sur les sockets ouverts dans contexte échouera avec un code d'erreur ETERM.
2.Après avoir interrompu tous les appels bloquants, zmq_ctx_term() *bloquera* jusqu'à ce que les conditions suivantes soient remplies :
•Tous les sockets ouverts dans contexte ont été fermés avec zmq_close().
•Pour chaque socket dans contexte, tous les messages envoyés par l'application avec zmq_send() ont été soit physiquement transférés à un pair réseau, soit la période d'attente (linger) du socket définie avec l'option de socket ZMQ_LINGER a expiré.

Pour plus de détails sur le comportement de la période d'attente (linger) des sockets, reportez-vous à l'option ZMQ_LINGER dans zmq_setsockopt(3).

Cette fonction remplace les fonctions obsolètes zmq_term(3) et zmq_ctx_destroy(3).

VALEUR DE RETOUR

La fonction zmq_ctx_term() retourne zéro en cas de succès. Sinon, elle retourne -1 et définit errno à l'une des valeurs ci-dessous.

ERREURS

EFAULT

Le contexte fourni était invalide.

EINTR

La terminaison a été interrompue par un signal. Elle peut être redémarrée si nécessaire.

VOIR AUSSI
