sous-routine ztpmv (caractere uplo, caractere trans, caractere diag, entier n, complexe*16, dimension(*) ap, complexe*16, dimension(*) x, entier incx)

ZTPMV

Objectif:

!>
!> ZTPMV  effectue l'une des opérations de multiplication matrice-vecteur suivantes :
!>
!>    x := A*x,   ou   x := A**T*x,   ou   x := A**H*x,
!>
!> où x est un vecteur de n éléments et A est une matrice triangulaire unitaire,
!> ou non unitaire, supérieure ou inférieure de taille n par n, fournie sous
!> forme compacte.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>           À l'entrée, UPLO spécifie si la matrice est supérieure ou
!>           inférieure comme suit :
!>
!>              UPLO = 'U' ou 'u'   A est une matrice triangulaire supérieure.
!>
!>              UPLO = 'L' ou 'l'   A est une matrice triangulaire inférieure.
!>

TRANS

!>          TRANS est CHARACTER*1
!>           À l'entrée, TRANS spécifie l'opération à effectuer comme suit :
!>
!>              TRANS = 'N' ou 'n'   x := A*x.
!>
!>              TRANS = 'T' ou 't'   x := A**T*x.
!>
!>              TRANS = 'C' ou 'c'   x := A**H*x.
!>

DIAG

!>          DIAG est CHARACTER*1
!>           À l'entrée, DIAG spécifie si A est unitaire ou non
!>           triangulaire comme suit :
!>
!>              DIAG = 'U' ou 'u'   A est supposée être unitaire.
!>
!>              DIAG = 'N' ou 'n'   A n'est pas supposée être unitaire.
!>

N

!>          N est INTEGER
!>           À l'entrée, N spécifie l'ordre de la matrice A.
!>           N doit être supérieur ou égal à zéro.
!>

AP

!>          AP est un tableau de COMPLEX*16, de dimension au moins
!>           ( ( n*( n + 1 ) )/2 ).
!>           Avant l'entrée avec UPLO = 'U' ou 'u', le tableau AP doit
!>           contenir la matrice triangulaire supérieure compactée séquentiellement,
!>           colonne par colonne, de telle sorte que AP( 1 ) contienne a( 1, 1 ),
!>           AP( 2 ) et AP( 3 ) contiennent a( 1, 2 ) et a( 2, 2 )
!>           respectivement, et ainsi de suite.
!>           Avant l'entrée avec UPLO = 'L' ou 'l', le tableau AP doit
!>           contenir la matrice triangulaire inférieure compactée séquentiellement,
!>           colonne par colonne, de telle sorte que AP( 1 ) contienne a( 1, 1 ),
!>           AP( 2 ) et AP( 3 ) contiennent a( 2, 1 ) et a( 3, 1 )
!>           respectivement, et ainsi de suite.
!>           Notez que lorsque DIAG = 'U' ou 'u', les éléments diagonaux de
!>           A ne sont pas référencés, mais sont supposés être à l'unité.
!>

X

!>          X est un tableau de COMPLEX*16, de dimension au moins
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Avant l'entrée, le tableau incrémenté X doit contenir le vecteur
!>           x de n éléments. À la sortie, X est écrasé par le vecteur
!>           transformé x.
!>

INCX

!>          INCX est INTEGER
!>           À l'entrée, INCX spécifie l'incrément pour les éléments de
!>           X. INCX ne doit pas être nul.
!>
