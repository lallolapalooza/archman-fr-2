Documentation de la fonction/sous-routine

sous-routine ztbcon (caractère norm, caractère uplo, caractère diag, entier n, entier kd, complexe*16, dimension( ldab, * ) ab, entier ldab, double précision rcond, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier info)

ZTBCON

But:

!>
!> ZTBCON estime la réciproque du nombre de condition d'une matrice
!> triangulaire bande A, en norme 1 ou en norme infinie.
!>
!> La norme de A est calculée et une estimation est obtenue pour
!> norm(inv(A)), puis la réciproque du nombre de condition est
!> calculée comme suit :
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Paramètres

NORM 
!>          NORM est CHARACTER*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme
!>          infinie est requis :
!>          = '1' ou 'O':  norme 1 ;
!>          = 'I':         norme infinie.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  A est triangulaire supérieure ;
!>          = 'L':  A est triangulaire inférieure.
!>

DIAG

!>          DIAG est CHARACTER*1
!>          = 'N':  A est triangulaire non unitaire ;
!>          = 'U':  A est triangulaire unitaire.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est un ENTIER
!>          Le nombre de super-diagonales ou de sous-diagonales de la
!>          matrice triangulaire bande A.  KD >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, de dimension (LDAB,N)
!>          La matrice triangulaire bande supérieure ou inférieure A,
!>          stockée dans les kd+1 premières lignes du tableau. La j-ième
!>          colonne de A est stockée dans la j-ième colonne du tableau
!>          AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>          Si DIAG = 'U', les éléments diagonaux de A ne sont pas référencés
!>          et sont supposés valoir 1.
!>

LDAB

!>          LDAB est un ENTIER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

RCOND

!>          RCOND est un DOUBLE PRÉCISION
!>          La réciproque du nombre de condition de la matrice A,
!>          calculée comme RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, de dimension (N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
