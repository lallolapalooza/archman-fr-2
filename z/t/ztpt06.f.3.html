sous-routine ztpt06 (double precision rcond, double precision rcondc, character uplo, character diag, integer n, complex*16, dimension( * ) ap, double precision, dimension( * ) rwork, double precision rat)

ZTPT06

But :

!>
!> ZTPT06 calcule un ratio de test comparant RCOND (le nombre de condition réciproque
!> de la matrice triangulaire A) et RCONDC, l'estimation calculée par ZTPCON.
!> Les informations sur la matrice triangulaire sont utilisées
!> si une estimation est nulle et l'autre non nulle pour décider si
!> le sous-dépassement dans l'estimation est justifié.
!>

Paramètres

RCOND 
!>          RCOND est DOUBLE PRECISION
!>          L'estimation du nombre de condition réciproque obtenue en
!>          formant l'inverse explicite de la matrice A et en calculant
!>          RCOND = 1/( norm(A) * norm(inv(A)) ).
!>

RCONDC

!>          RCONDC est DOUBLE PRECISION
!>          L'estimation du nombre de condition réciproque calculée par
!>          ZTPCON.
!>

UPLO

!>          UPLO est CHARACTER
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

DIAG

!>          DIAG est CHARACTER
!>          Spécifie si la matrice A est triangulaire unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, stockée de manière compacte
!>          colonne par colonne dans un tableau linéaire.  La j-ème colonne de A est stockée dans le tableau
!>          AP comme suit :
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) pour j<=i<=n.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (N)
!>

RAT

!>          RAT est DOUBLE PRECISION
!>          Le ratio de test.  Si RCOND et RCONDC sont tous deux non nuls,
!>             RAT = MAX( RCOND, RCONDC )/MIN( RCOND, RCONDC ) - 1.
!>          Si RAT = 0, les deux estimations sont exactement les mêmes.
!>
