sous-programme ztpcon (caractère norm, caractère uplo, caractère diag, entier n, complexe*16, dimension( * ) ap, double précision rcond, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier info)

ZTPCON

Objectif:

!>
!> ZTPCON estime l'inverse du nombre de condition d'une matrice triangulaire
!> triangulaire A, soit en norme 1, soit en norme infini.
!>
!> La norme de A est calculée et une estimation est obtenue pour
!> norm(inv(A)), puis l'inverse du nombre de condition est
!> calculé comme suit :
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Paramètres

NORM 
!>          NORM est CARACTERE*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme
!>          infini est requis :
!>          = '1' ou 'O':  Norme 1 ;
!>          = 'I':         Norme infinie.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          = 'U':  A est triangulaire supérieure ;
!>          = 'L':  A est triangulaire inférieure.
!>

DIAG

!>          DIAG est CARACTERE*1
!>          = 'N':  A est triangulaire non unitaire ;
!>          = 'U':  A est triangulaire unitaire.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, compactée
!>          par colonne dans un tableau linéaire. La j-ème colonne de A est
!>          stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Si DIAG = 'U', les éléments diagonaux de A ne sont pas référencés
!>          et sont supposés être 1.
!>

RCOND

!>          RCOND est DOUBLE PRÉCISION
!>          L'inverse du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK est tableau COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK est tableau DOUBLE PRÉCISION, dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>
