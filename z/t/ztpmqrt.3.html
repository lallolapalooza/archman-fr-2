Documentation de la fonction/sous-routine

sous-routine ztpmqrt (caractère side, caractère trans, entier m, entier n, entier k, entier l, entier nb, complexe*16, dimension( ldv, * ) v, entier ldv, complexe*16, dimension( ldt, * ) t, entier ldt, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( * ) work, entier info)

ZTPMQRT

But:

!>
!> ZTPMQRT applique une matrice orthogonale complexe Q obtenue à partir d'un
!>  réflecteur bloc complexe H à une matrice complexe générale
!> C, qui est composée de deux blocs A et B.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**H à gauche ;
!>          = 'R': appliquer Q ou Q**H à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N':  Pas de transposée, appliquer Q ;
!>          = 'C':  Transposée conjuguée, appliquer Q**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice B. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice B. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>

L

!>          L est INTEGER
!>          L'ordre de la partie trapézoïdale de V.
!>          K >= L >= 0.  Voir Détails supplémentaires.
!>

NB

!>          NB est INTEGER
!>          La taille de bloc utilisée pour le stockage de T.  K >= NB >= 1.
!>          Cela doit être la même valeur de NB utilisée pour générer T
!>          dans CTPQRT.
!>

V

!>          V est un tableau COMPLEX*16, dimension (LDV,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          CTPQRT dans B.  Voir Détails supplémentaires.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V.
!>          Si SIDE = 'L', LDV >= max(1,M) ;
!>          si SIDE = 'R', LDV >= max(1,N).
!>

T

!>          T est un tableau COMPLEX*16, dimension (LDT,K)
!>          Les facteurs triangulaires supérieurs des réflecteurs blocs
!>          tels que retournés par CTPQRT, stockés comme une matrice NBxK.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T.  LDT >= NB.
!>

A

!>          A est un tableau COMPLEX*16, dimension
!>          (LDA,N) si SIDE = 'L' ou
!>          (LDA,K) si SIDE = 'R'
!>          À l'entrée, la matrice KxN ou MxK A.
!>          À la sortie, A est écrasé par le bloc correspondant de
!>          Q*C ou Q**H*C ou C*Q ou C*Q**H.  Voir Détails supplémentaires.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDC >= max(1,K) ;
!>          Si SIDE = 'R', LDC >= max(1,M).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,N)
!>          À l'entrée, la matrice MxN B.
!>          À la sortie, B est écrasé par le bloc correspondant de
!>          Q*C ou Q**H*C ou C*Q ou C*Q**H.  Voir Détails supplémentaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX*16. La dimension de WORK est
!>           N*NB si SIDE = 'L', ou M*NB si SIDE = 'R'.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires:

!>
!>  Les colonnes de la matrice pentagonale V contiennent les réflecteurs
!>  élémentaires H(1), H(2), ..., H(K) ; V est composée d'un bloc rectangulaire V1 et d'un
!>  bloc trapézoïdal V2 :
!>
!>        V = [V1]
!>            [V2].
!>
!>  La taille du bloc trapézoïdal V2 est déterminée par le paramètre L,
!>  où 0 <= L <= K ; V2 est trapézoïdale supérieure, consistant des L premières
!>  lignes d'une matrice triangulaire supérieure KxK.  Si L=K, V2 est triangulaire supérieure ;
!>  si L=0, il n'y a pas de bloc trapézoïdal, donc V = V1 est rectangulaire.
!>
!>  Si SIDE = 'L' :  C = [A]  où A est KxN,  B est MxN et V est MxK.
!>                      [B]
!>
!>  Si SIDE = 'R' :  C = [A B]  où A est MxK, B est MxN et V est NxK.
!>
!>  La matrice orthogonale complexe Q est formée à partir de V et T.
!>
!>  Si TRANS='N' et SIDE='L', C est remplacé à la sortie par Q * C.
!>
!>  Si TRANS='C' et SIDE='L', C est remplacé à la sortie par Q**H * C.
!>
!>  Si TRANS='N' et SIDE='R', C est remplacé à la sortie par C * Q.
!>
!>  Si TRANS='C' et SIDE='R', C est remplacé à la sortie par C * Q**H.
!>
