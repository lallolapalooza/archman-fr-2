sous-routine ztgsja (character jobu, character jobv, character jobq, integer m, integer p, integer n, integer k, integer l, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, double precision tola, double precision tolb, double precision, dimension( * ) alpha, double precision, dimension( * ) beta, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( * ) work, integer ncycle, integer info)

ZTGSJA

But :

!>
!> ZTGSJA calcule la décomposition en valeurs singulières généralisées (GSVD)
!> de deux matrices complexes triangulaires supérieures (ou trapézoïdales) A et B.
!>
!> À l'entrée, on suppose que les matrices A et B ont les formes suivantes,
!> qui peuvent être obtenues par la sous-routine de prétraitement ZGGSVP
!> à partir d'une matrice générale M-par-N A et d'une matrice P-par-N B :
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) si M-K-L >= 0;
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) si M-K-L < 0;
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> où la matrice K-par-K A12 et la matrice L-par-L B13 sont triangulaires
!> supérieures non singulières; A23 est triangulaire supérieure L-par-L si M-K-L >= 0,
!> sinon A23 est trapézoïdale supérieure (M-K)-par-L.
!>
!> À la sortie,
!>
!>        U**H *A*Q = D1*( 0 R ),    V**H *B*Q = D2*( 0 R ),
!>
!> où U, V et Q sont des matrices unitaires.
!> R est une matrice triangulaire supérieure non singulière, et D1
!> et D2 sont des matrices « diagonales », qui ont les structures suivantes :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                    K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stockée dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> où
!> C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!> S = diag( BETA(K+1),  ... , BETA(M) ),
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) est stockée dans A(1:M, N-K-L+1:N) et R33 est stockée
!>     (  0  R22 R23 )
!> dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> Le calcul des matrices de transformation unitaires U, V ou Q
!> est optionnel. Ces matrices peuvent être formées explicitement, ou elles
!> peuvent être post-multipliées dans les matrices d'entrée U1, V1, ou Q1.
!>

Paramètres

JOBU 
!>          JOBU est CHARACTER*1
!>          = 'U':  U doit contenir une matrice unitaire U1 à l'entrée, et
!>                  le produit U1*U est retourné ;
!>          = 'I':  U est initialisée à la matrice identité, et la
!>                  matrice unitaire U est retournée ;
!>          = 'N':  U n'est pas calculée.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          = 'V':  V doit contenir une matrice unitaire V1 à l'entrée, et
!>                  le produit V1*V est retourné ;
!>          = 'I':  V est initialisée à la matrice identité, et la
!>                  matrice unitaire V est retournée ;
!>          = 'N':  V n'est pas calculée.
!>

JOBQ

!>          JOBQ est CHARACTER*1
!>          = 'Q':  Q doit contenir une matrice unitaire Q1 à l'entrée, et
!>                  le produit Q1*Q est retourné ;
!>          = 'I':  Q est initialisée à la matrice identité, et la
!>                  matrice unitaire Q est retournée ;
!>          = 'N':  Q n'est pas calculée.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!>

K

!>          K est INTEGER
!>

L

!>          L est INTEGER
!>
!>          K et L spécifient les sous-blocs dans les matrices d'entrée A et B :
!>          A23 = A(K+1:MIN(K+L,M),N-L+1:N) et B13 = B(1:L,,N-L+1:N)
!>          de A et B, dont la GSVD sera calculée par ZTGSJA.
!>          Voir Détails supplémentaires.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la matrice M-par-N A.
!>          À la sortie, A(N-K+1:N,1:MIN(K+L,M) ) contient la matrice
!>          triangulaire R ou une partie de R. Voir But pour les détails.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,N)
!>          À l'entrée, la matrice P-par-N B.
!>          À la sortie, si nécessaire, B(M-K+1:L,N+M-K-L+1:N) contient
!>          une partie de R. Voir But pour les détails.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,P).
!>

TOLA

!>          TOLA est DOUBLE PRECISION
!>

TOLB

!>          TOLB est DOUBLE PRECISION
!>
!>          TOLA et TOLB sont les critères de convergence pour la procédure
!>          d'itération de Jacobi-Kogbetliantz. Généralement, ils sont les
!>          mêmes que ceux utilisés dans l'étape de prétraitement, par exemple
!>              TOLA = MAX(M,N)*norm(A)*MAZHEPS,
!>              TOLB = MAX(P,N)*norm(B)*MAZHEPS.
!>

ALPHA

!>          ALPHA est un tableau DOUBLE PRECISION, dimension (N)
!>

BETA

!>          BETA est un tableau DOUBLE PRECISION, dimension (N)
!>
!>          À la sortie, ALPHA et BETA contiennent les paires de valeurs singulières
!>          généralisées de A et B ;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          et si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = diag(C),
!>            BETA(K+1:K+L)  = diag(S),
!>          ou si M-K-L < 0,
!>            ALPHA(K+1:M)= C, ALPHA(M+1:K+L)= 0
!>            BETA(K+1:M) = S, BETA(M+1:K+L) = 1.
!>          De plus, si K+L < N,
!>            ALPHA(K+L+1:N) = 0 et
!>            BETA(K+L+1:N)  = 0.
!>

U

!>          U est un tableau COMPLEX*16, dimension (LDU,M)
!>          À l'entrée, si JOBU = 'U', U doit contenir une matrice U1 (généralement
!>          la matrice unitaire retournée par ZGGSVP).
!>          À la sortie,
!>          si JOBU =
'U', U contient la matrice unitaire U ; !> si JOBU = 'U', U contient le produit U1*U. !> Si JOBU = 'N', U n'est pas référencé. !>

LDU

!>          LDU est un entier.
!>          La dimension principale du tableau U. LDU >= max(1,M) si
!>          JOBU = 'U' ; LDU >= 1 sinon.
!>

V

!>          V est un tableau COMPLEX*16, de dimension (LDV,P).
!>          À l'entrée, si JOBV = 'V', V doit contenir une matrice V1 (généralement
!>          la matrice unitaire renvoyée par ZGGSVP).
!>          À la sortie,
!>          si JOBV = 'I', V contient la matrice unitaire V ;
!>          si JOBV = 'V', V contient le produit V1*V.
!>          Si JOBV = 'N', V n'est pas référencé.
!>

LDV

!>          LDV est un entier.
!>          La dimension principale du tableau V. LDV >= max(1,P) si
!>          JOBV = 'V' ; LDV >= 1 sinon.
!>

Q

!>          Q est un tableau COMPLEX*16, de dimension (LDQ,N).
!>          À l'entrée, si JOBQ = 'Q', Q doit contenir une matrice Q1 (généralement
!>          la matrice unitaire renvoyée par ZGGSVP).
!>          À la sortie,
!>          si JOBQ = 'I', Q contient la matrice unitaire Q ;
!>          si JOBQ = 'Q', Q contient le produit Q1*Q.
!>          Si JOBQ = 'N', Q n'est pas référencé.
!>

LDQ

!>          LDQ est un entier.
!>          La dimension principale du tableau Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q' ; LDQ >= 1 sinon.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N).
!>

NCYCLE

!>          NCYCLE est un entier.
!>          Le nombre de cycles requis pour la convergence.
!>

INFO

!>          INFO est un entier.
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          = 1 : la procédure ne converge pas après MAXIT cycles.
!>

Paramètres internes :

!>  MAXIT   ENTIER
!>          MAXIT spécifie le nombre total de boucles que la procédure itérative
!>          peut effectuer. Si après MAXIT cycles, la routine ne parvient pas
!>          à converger, nous renvoyons INFO = 1.
!>

Détails supplémentaires :

!>
!>  ZTGSJA utilise essentiellement une variante de l'algorithme de Kogbetliantz pour réduire
!>  la matrice triangulaire (ou trapézoïdale) A23 de taille min(L,M-K)-par-L et la matrice B13 de taille L-par-L
!>  à la forme :
!>
!>           U1**H *A13*Q1 = C1*R1 ; V1**H *B13*Q1 = S1*R1,
!>
!>  où U1, V1 et Q1 sont des matrices unitaires.
!>  C1 et S1 sont des matrices diagonales satisfaisant
!>
!>                C1**2 + S1**2 = I,
!>
!>  et R1 est une matrice triangulaire supérieure non singulière de taille L-par-L.
!>
