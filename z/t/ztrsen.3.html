Documentation de la fonction/sous-routine

subroutine ztrsen (character job, character compq, logical, dimension( * ) select, integer n, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( * ) w, integer m, double precision s, double precision sep, complex*16, dimension( * ) work, integer lwork, integer info)

ZTRSEN

Purpose:

!>
!> ZTRSEN réorganise la factorisation de Schur d'une matrice complexe
!> A = Q*T*Q**H, de sorte qu'un amas sélectionné de valeurs propres apparaisse dans
!> les positions de tête sur la diagonale de la matrice triangulaire supérieure
!> T, et que les colonnes de tête de Q forment une base orthonormée du
!> sous-espace invariant droit correspondant.
!>
!> Optionnellement, la routine calcule les nombres de condition réciproques de
!> l'amas de valeurs propres (S) et/ou du sous-espace invariant (SEP).
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>          Spécifie si les nombres de condition sont requis pour
!>          l'amas de valeurs propres (S) ou le sous-espace invariant (SEP):
!>          = 'N': aucun;
!>          = 'E': pour les valeurs propres seulement (S);
!>          = 'V': pour le sous-espace invariant seulement (SEP);
!>          = 'B': pour les valeurs propres et le sous-espace invariant (S et
!>                 SEP).
!>

COMPQ

!>          COMPQ est CHARACTER*1
!>          = 'V': met à jour la matrice Q des vecteurs de Schur;
!>          = 'N': ne met pas à jour Q.
!>

SELECT

!>          SELECT est un tableau LOGICAL, de dimension (N)
!>          SELECT spécifie les valeurs propres dans l'amas sélectionné. Pour
!>          sélectionner la j-ème valeur propre, SELECT(j) doit être mis à .TRUE..
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un tableau COMPLEX*16, de dimension (LDT,N)
!>          En entrée, la matrice triangulaire supérieure T.
!>          En sortie, T est écrasé par la matrice T réordonnée, avec les
!>          valeurs propres sélectionnées comme éléments diagonaux principaux.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

Q

!>          Q est un tableau COMPLEX*16, de dimension (LDQ,N)
!>          En entrée, si COMPQ = 'V', la matrice Q des vecteurs de Schur.
!>          En sortie, si COMPQ = 'V', Q a été post-multiplié par la
!>          matrice de transformation unitaire qui réordonne T; les M
!>          colonnes de tête de Q forment une base orthonormée pour
!>          le sous-espace invariant spécifié.
!>          Si COMPQ = 'N', Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q.
!>          LDQ >= 1; et si COMPQ = 'V', LDQ >= N.
!>

W

!>          W est un tableau COMPLEX*16, de dimension (N)
!>          Les valeurs propres réordonnées de T, dans le même ordre qu'elles
!>          apparaissent sur la diagonale de T.
!>

M

!>          M est INTEGER
!>          La dimension du sous-espace invariant spécifié.
!>          0 <= M <= N.
!>

S

!>          S est DOUBLE PRECISION
!>          Si JOB = 'E' ou 'B', S est une borne inférieure du nombre de condition
!>          réciproque pour l'amas sélectionné de valeurs propres.
!>          S ne peut pas sous-estimer le nombre de condition réciproque réel
!>          de plus d'un facteur de sqrt(N). Si M = 0 ou N, S = 1.
!>          Si JOB = 'N' ou 'V', S n'est pas référencé.
!>

SEP

!>          SEP est DOUBLE PRECISION
!>          Si JOB = 'V' ou 'B', SEP est le nombre de condition réciproque estimé
!>          du sous-espace invariant spécifié. Si
!>          M = 0 ou N, SEP = norm(T).
!>          Si JOB = 'N' ou 'E', SEP n'est pas référencé.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si JOB = 'N', LWORK >= 1;
!>          si JOB = 'E', LWORK = max(1,M*(N-M));
!>          si JOB = 'V' ou 'B', LWORK >= max(1,2*M*(N-M)).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires:

!>
!>  ZTRSEN collecte d'abord les valeurs propres sélectionnées en calculant une transformation unitaire
!>  Z pour les déplacer dans le coin supérieur gauche de T. Autrement dit, les valeurs propres sélectionnées sont les valeurs propres de T11 dans:
!>
!>          Z**H * T * Z = ( T11 T12 ) n1
!>                         (  0  T22 ) n2
!>                            n1  n2
!>
!>  où N = n1+n2. Les n1 premières colonnes de Z forment le sous-espace invariant spécifié de T.
!>
!>  Si T provient de la factorisation de Schur d'une matrice
!>  A = Q*T*Q**H, alors la factorisation de Schur réordonnée de A est donnée par
!>  A = (Q*Z)*(Z**H*T*Z)*(Q*Z)**H, et les n1 premières colonnes de Q*Z forment le
!>  sous-espace invariant correspondant de A.
!>
!>  Le nombre de condition réciproque de la moyenne des valeurs propres de
!>  T11 peut être retourné dans S. S se situe entre 0 (très mal conditionné)
!>  et 1 (très bien conditionné). Il est calculé comme suit. D'abord, nous calculons R tel que
!>
!>                         P = ( I  R ) n1
!>                             ( 0  0 ) n2
!>                               n1 n2
!>
!>  soit le projecteur sur le sous-espace invariant associé à T11.
!>  R est la solution de l'équation de Sylvester:
!>
!>                        T11*R - R*T22 = T12.
!>
!>  Soit F-norm(M) la norme de Frobenius de M et 2-norm(M) la norme 2 de M. Alors S est calculé comme la borne inférieure
!>
!>                      (1 + F-norm(R)**2)**(-1/2)
!>
!>  de l'inverse de la norme 2 de P, le nombre de condition réciproque réel.
!>  S ne peut pas sous-estimer 1 / 2-norm(P) de plus d'un facteur de
!>  sqrt(N).
!>
!>  Une borne d'erreur approximative pour la moyenne calculée des
!>  valeurs propres de T11 est
!>
!>                         EPS * norm(T) / S
!>
!>  où EPS est la précision machine.
!>
!>  Le nombre de condition réciproque du sous-espace invariant droit
!>  formé par les n1 premières colonnes de Z (ou de Q*Z) est retourné dans SEP.
!>  SEP est défini comme la séparation de T11 et T22:
!>
!>                     sep( T11, T22 ) = sigma-min( C )
!>
!>  où sigma-min(C) est la plus petite valeur singulière de la matrice
!>  n1*n2 par n1*n2
!>
!>     C  = kprod( I(n2), T11 ) - kprod( transpose(T22), I(n1) )
!>
!>  I(m) est une matrice identité m par m, et kprod représente le produit de Kronecker. Nous estimons sigma-min(C) par l'inverse d'une estimation
!>  de la norme 1 de inverse(C). La norme 1 réelle de inverse(C) ne peut pas différer de sigma-min(C) de plus d'un facteur de sqrt(n1*n2).
!>
!>  Lorsque SEP est petit, de petits changements dans T peuvent entraîner de grands changements dans
!>  le sous-espace invariant. Une borne approximative de l'erreur angulaire maximale dans
