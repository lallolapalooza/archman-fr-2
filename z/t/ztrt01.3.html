Documentation de la fonction/sous-routine

sous-routine ztrt01 (character uplo, character diag, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldainv, * ) ainv, integer ldainv, double precision rcond, double precision, dimension( * ) rwork, double precision resid)

ZTRT01

But:

!>
!> ZTRT01 calcule le résidu pour une matrice triangulaire A multipliée par son
!> inverse:
!>    RESID = norm( A*AINV - I ) / ( N * norm(A) * norm(AINV) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Non unitaire
!>          = 'U':  Unitaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie triangulaire
!>          supérieure de n par n de la matrice A contient la matrice
!>          triangulaire supérieure, et la partie strictement triangulaire
!>          inférieure de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          triangulaire inférieure de n par n de la matrice A contient la
!>          matrice triangulaire inférieure, et la partie strictement
!>          triangulaire supérieure de A n'est pas référencée.  Si DIAG = 'U',
!>          les éléments diagonaux de A ne sont pas non plus référencés et
!>          sont supposés valoir 1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AINV

!>          AINV est un tableau COMPLEX*16, dimension (LDAINV,N)
!>          En entrée, l'inverse (triangulaire) de la matrice A, dans le
!>          même format de stockage que A.
!>          En sortie, le contenu de AINV est détruit.
!>

LDAINV

!>          LDAINV est INTEGER
!>          La dimension principale du tableau AINV.  LDAINV >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          Le nombre de condition inversé de A, calculé comme
!>          1/(norm(A) * norm(AINV)).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          norm(A*AINV - I) / ( N * norm(A) * norm(AINV) * EPS )
!>
