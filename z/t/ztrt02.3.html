sous-programme ztrt02 (caractère uplo, caractère trans, caractère diag, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldx, * ) x, entier ldx, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, double précision resid)

ZTRT02

Objectif :

!>
!> ZTRT02 calcule le résidu pour la solution calculée d'un système d'équations
!> linéaires triangulaires op(A)*X = B, où A est une matrice triangulaire.
!> Le rapport de test est le maximum sur
!>    norm(b - op(A)*x) / ( ||op(A)||_1 * norm(x) * EPS ),
!> où op(A) = A, A**T, ou A**H, b est la colonne de B, x est le
!> vecteur solution, et EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  A    * X = B  (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Transposée conjuguée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire triangulaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          des matrices X et B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie supérieure
!>          triangulaire n x n de tête du tableau A contient la matrice
!>          triangulaire supérieure, et la partie strictement triangulaire
!>          inférieure de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          inférieure triangulaire n x n de tête du tableau A contient la
!>          matrice triangulaire inférieure, et la partie strictement
!>          triangulaire supérieure de A n'est pas référencée.  Si DIAG = 'U',
!>          les éléments diagonaux de A ne sont pas non plus référencés et
!>          sont supposés être 1.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Les vecteurs solutions calculés pour le système d'équations
!>          linéaires.
!>

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          Les vecteurs du côté droit pour le système d'équations
!>          linéaires.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRÉCISION
!>          Le maximum sur le nombre de côtés droits de
!>          norm(op(A)*X - B) / ( norm(op(A)) * norm(X) * EPS ).
!>
