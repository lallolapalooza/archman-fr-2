Documentation de la fonction/sous-routine

sous-routine ztpt01 (caractere uplo, caractere diag, entier n, complexe*16, dimension( * ) ap, complexe*16, dimension( * ) ainvp, real double precision rcond, real double precision, dimension( * ) rwork, real double precision resid)

ZTPT01

Objectif :

!>
!> ZTPT01 calcule le résidu pour une matrice triangulaire A multipliée par son
!> inverse lorsque A est stockée au format compact :
!>    RESID = norm(A*AINV - I) / ( N * norm(A) * norm(AINV) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N' : Triangulaire non unitaire
!>          = 'U' : Triangulaire unitaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          La matrice triangulaire originale A, stockée de manière compacte
!>          par colonne dans un tableau linéaire. La j-ème colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) pour j<=i<=n.
!>

AINVP

!>          AINVP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          À l'entrée, l'inverse (triangulaire) de la matrice A, stocké de manière compacte
!>          par colonne dans un tableau linéaire comme dans AP.
!>          À la sortie, le contenu de AINVP est détruit.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          Le nombre de condition réciproque de A, calculé comme
!>          1/(norm(A) * norm(AINV)).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          norm(A*AINV - I) / ( N * norm(A) * norm(AINV) * EPS )
!>
