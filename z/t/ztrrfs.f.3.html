sous-programme ztrrfs (caractère uplo, caractère trans, caractère diag, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldx, * ) x, entier ldx, double précision, dimension( * ) ferr, double précision, dimension( * ) berr, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier info)

ZTRRFS

Objectif:

!>
!> ZTRRFS fournit des bornes d'erreur et des estimations d'erreur arrière pour la
!> solution d'un système d'équations linéaires avec une matrice de coefficient triangulaire.
!>
!> La matrice solution X doit être calculée par ZTRTRS ou par un autre
!> moyen avant d'entrer dans cette routine. ZTRRFS n'effectue pas de raffinement itératif
!> car cela ne peut pas améliorer l'erreur arrière.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  A est triangulaire supérieure;
!>          = 'L':  A est triangulaire inférieure.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations:
!>          = 'N':  A * X = B     (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Transposée conjuguée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          = 'N':  A est une matrice triangulaire non unitaire;
!>          = 'U':  A est une matrice triangulaire unitaire.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice triangulaire A. Si UPLO = 'U', la partie triangulaire
!>          supérieure N par N de la matrice A contient la matrice triangulaire
!>          supérieure, et la partie strictement triangulaire inférieure de
!>          A n'est pas référencée. Si UPLO = 'L', la partie triangulaire
!>          inférieure N par N de la matrice A contient la matrice triangulaire
!>          inférieure, et la partie strictement triangulaire supérieure de A n'est pas
!>          référencée. Si DIAG = 'U', les éléments diagonaux de A
!>          ne sont pas non plus référencés et sont supposés être 1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          La matrice des membres de droite B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          La matrice solution X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

FERR

!>          FERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j). L'estimation est aussi fiable que
!>          l'estimation de RCOND, et est presque toujours une légère
!>          surestimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire la plus petite modification relative dans
!>          n'importe quel élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
