Documentation de la fonction/sous-programme

sous-programme ztbt05 (character uplo, character trans, character diag, integer n, integer kd, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldxact, * ) xact, integer ldxact, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) reslts)

ZTBT05

Objectif:

!>
!> ZTBT05 teste les limites d'erreur de l'affinement itératif pour la
!> solution calculée d'un système d'équations A*X = B, où A est une
!> matrice bande triangulaire.
!>
!> RESLTS(1) = test de la limite d'erreur
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Une grande valeur est retournée si ce rapport n'est pas inférieur à un.
!>
!> RESLTS(2) = résidu de l'affinement itératif
!>           = le maximum de BERR / ( NZ*EPS + (*) ), où
!>             (*) = NZ*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>             et NZ = nombre max. de non-zéros dans une ligne de A, plus 1
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations.
!>          = 'N':  A * X = B  (Pas de transposée)
!>          = 'T':  A'* X = B  (Transposée)
!>          = 'C':  A'* X = B  (Conjuguée transposée = Transposée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Non-unitaire
!>          = 'U':  Unitaire
!>

N

!>          N est INTEGER
!>          Le nombre de lignes des matrices X, B et XACT, et l'ordre de la
!>          matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de colonnes des matrices X, B et XACT.
!>          NRHS >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, de dimension (LDAB,N)
!>          La matrice bande triangulaire supérieure ou inférieure A, stockée
!>          dans les kd+1 premières lignes du tableau. La j-ème colonne de A est
!>          stockée dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>          Si DIAG = 'U', les éléments diagonaux de A ne sont pas référencés
!>          et sont supposés valoir 1.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>          Les vecteurs du second membre pour le système d'équations linéaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, de dimension (LDX,NRHS)
!>          Les vecteurs solution calculés.  Chaque vecteur est stocké comme
!>          une colonne de la matrice X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

XACT

!>          XACT est un tableau COMPLEX*16, de dimension (LDX,NRHS)
!>          Les vecteurs solution exacts.  Chaque vecteur est stocké comme
!>          une colonne de la matrice XACT.
!>

LDXACT

!>          LDXACT est INTEGER
!>          La dimension principale du tableau XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>          Les estimations des limites d'erreur avant pour chaque vecteur
!>          solution X.  Si XTRUE est la vraie solution, FERR borne la magnitude
!>          du plus grand élément de (X - XTRUE) divisé par la magnitude
!>          du plus grand élément de X.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>          L'erreur arrière relative par composante de chaque vecteur
!>          solution (c'est-à-dire, le plus petit changement relatif dans
!>          un élément de A ou B qui rend X une solution exacte).
!>

RESLTS

!>          RESLTS est un tableau DOUBLE PRECISION, de dimension (2)
!>          Le maximum sur les vecteurs solutions NRHS des rapports :
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( NZ*EPS + (*) )
!>
