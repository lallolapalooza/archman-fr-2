Documentation de la fonction/sous-routine

sous-routine ztzrzf (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, integer info)

ZTZRZF

But :

!>
!> ZTZRZF réduit la matrice complexe supérieure trapézoïdale M-par-N ( M<=N ) A
!> en forme triangulaire supérieure au moyen de transformations unitaires.
!>
!> La matrice trapézoïdale supérieure A est factorisée comme suit :
!>
!>    A = ( R  0 ) * Z,
!>
!> où Z est une matrice unitaire N-par-N et R est une matrice triangulaire
!> supérieure M-par-M.
!>

Paramètres

M 
!>          M est un ENTIER (INTEGER)
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER (INTEGER)
!>          Le nombre de colonnes de la matrice A.  N >= M.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, la partie supérieure trapézoïdale M-par-N de A
!>          doit contenir la matrice à factoriser.
!>          À la sortie, la partie supérieure triangulaire M-par-M de A
!>          contient la matrice triangulaire supérieure R, et les éléments
!>          M+1 à N des M premières lignes de A, avec le tableau TAU,
!>          représentent la matrice unitaire Z comme un produit de M
!>          réflecteurs élémentaires.
!>

LDA

!>          LDA est un ENTIER (INTEGER)
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEX*16, de dimension (M)
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur LWORK optimale.
!>

LWORK

!>          LWORK est un ENTIER (INTEGER)
!>          La dimension du tableau WORK.  LWORK >= max(1,M).
!>          Pour une performance optimale, LWORK >= M*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule seulement la taille optimale du tableau WORK,
!>          renvoie cette valeur comme première entrée du tableau WORK,
!>          et aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER (INTEGER)
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  La matrice N-par-N Z peut être calculée par
!>
!>     Z =  Z(1)*Z(2)* ... *Z(M)
!>
!>  où chaque Z(k) N-par-N est donné par
!>
!>     Z(k) = I - tau(k)*v(k)*v(k)**H
!>
!>  avec v(k) le k-ième vecteur ligne de la matrice M-par-N
!>
!>     V = ( I   A(:,M+1:N) )
!>
!>  I est la matrice identité M-par-M, A(:,M+1:N)
!>  est la sortie stockée dans A à la sortie de ZTZRZF,
!>  et tau(k) est le k-ième élément du tableau TAU.
!>
!>

Définition à la ligne 150 du fichier ztzrzf.f.
