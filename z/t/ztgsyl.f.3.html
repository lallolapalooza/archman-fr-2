Documentation de la fonction/sous-programme

sous-programme ztgsyl (caractère trans, entier ijob, entier m, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldc, * ) c, entier ldc, complexe*16, dimension( ldd, * ) d, entier ldd, complexe*16, dimension( lde, * ) e, entier lde, complexe*16, dimension( ldf, * ) f, entier ldf, double précision scale, double précision dif, complexe*16, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier info)

ZTGSYL

Objectif :

!>
!> ZTGSYL résout l'équation de Sylvester généralisée :
!>
!>             A * R - L * B = scale * C            (1)
!>             D * R - L * E = scale * F
!>
!> où R et L sont des matrices inconnues de taille m x n, (A, D), (B, E) et
!> (C, F) sont des paires de matrices données de taille m x m, n x n et m x n,
!> respectivement, avec des entrées complexes. A, B, D et E sont triangulaires
!> supérieures (c.-à-d. (A,D) et (B,E) sous forme de Schur généralisée).
!>
!> La solution (R, L) écrase (C, F). 0 <= SCALE <= 1
!> est un facteur d'échelle de sortie choisi pour éviter les dépassements.
!>
!> En notation matricielle, (1) est équivalent à résoudre Zx = scale*b, où Z
!> est défini comme
!>
!>        Z = [ kron(In, A)  -kron(B**H, Im) ]        (2)
!>            [ kron(In, D)  -kron(E**H, Im) ],
!>
!> Ici, Ix est la matrice identité de taille x et X**H est la transposée conjuguée de X.
!> Kron(X, Y) est le produit de Kronecker entre les matrices X et Y.
!>
!> Si TRANS = 'C', on résout y dans le système transposé conjugué Z**H *y = scale*b,
!> ce qui est équivalent à résoudre pour R et L dans
!>
!>             A**H * R + D**H * L = scale * C           (3)
!>             R * B**H + L * E**H = scale * -F
!>
!> Ce cas (TRANS = 'C') est utilisé pour calculer une estimation basée sur la norme
!> de un de Dif[(A,D), (B,E)], la séparation entre les paires de matrices (A,D)
!> et (B,E), en utilisant ZLACON.
!>
!> Si IJOB >= 1, ZTGSYL calcule une estimation basée sur la norme de Frobenius de
!> Dif[(A,D),(B,E)]. C'est-à-dire, l'inverse d'une borne inférieure de l'inverse
!> de la plus petite valeur singulière de Z.
!>
!> Ceci est un algorithme BLAS de niveau 3.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N': résout l'équation de Sylvester généralisée (1).
!>          = 'C': résout le système (3).
!>

IJOB

!>          IJOB est INTEGER
!>          Spécifie le type de fonctionnalité à effectuer.
!>          =0 : résout (1) uniquement.
!>          =1 : Les fonctionnalités de 0 et 3.
!>          =2 : Les fonctionnalités de 0 et 4.
!>          =3 : Seule une estimation de Dif[(A,D), (B,E)] est calculée.
!>              (la stratégie d'anticipation est utilisée).
!>          =4 : Seule une estimation de Dif[(A,D), (B,E)] est calculée.
!>              (ZGECON sur les sous-systèmes est utilisé).
!>          Non référencé si TRANS = 'C'.
!>

M

!>          M est INTEGER
!>          L'ordre des matrices A et D, et la dimension des lignes des
!>          matrices C, F, R et L.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices B et E, et la dimension des colonnes des
!>          matrices C, F, R et L.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, M)
!>          La matrice triangulaire supérieure A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1, M).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB, N)
!>          La matrice triangulaire supérieure B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1, N).
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC, N)
!>          À l'entrée, C contient le membre de droite de la première matrice
!>          de l'équation (1) ou (3).
!>          À la sortie, si IJOB = 0, 1 ou 2, C a été écrasé par
!>          la solution R. Si IJOB = 3 ou 4 et TRANS = 'N', C contient R,
!>          la solution obtenue lors du calcul de l'estimation
!>          Dif.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1, M).
!>

D

!>          D est un tableau COMPLEX*16, dimension (LDD, M)
!>          La matrice triangulaire supérieure D.
!>

LDD

!>          LDD est INTEGER
!>          La dimension principale du tableau D. LDD >= max(1, M).
!>

E

!>          E est un tableau COMPLEX*16, dimension (LDE, N)
!>          La matrice triangulaire supérieure E.
!>

LDE

!>          LDE est INTEGER
!>          La dimension principale du tableau E. LDE >= max(1, N).
!>

F

!>          F est un tableau COMPLEX*16, dimension (LDF, N)
!>          À l'entrée, F contient le membre de droite de la seconde matrice
!>          de l'équation (1) ou (3).
!>          À la sortie, si IJOB = 0, 1 ou 2, F a été écrasé par
!>          la solution L. Si IJOB = 3 ou 4 et TRANS = 'N', F contient L,
!>          la solution obtenue lors du calcul de l'estimation
!>          Dif.
!>

LDF

!>          LDF est INTEGER
!>          La dimension principale du tableau F. LDF >= max(1, M).
!>

DIF

!>          DIF est DOUBLE PRECISION
!>          À la sortie, DIF est l'inverse d'une borne inférieure de
!>          l'inverse de la fonction Dif, c'est-à-dire que DIF est une borne supérieure de
!>          Dif[(A,D), (B,E)] = sigma-min(Z), où Z est comme en (2).
!>          SI IJOB = 0 ou TRANS = 'C', DIF n'est pas référencé.
!>

SCALE

!>          SCALE est DOUBLE PRECISION
!>          À la sortie, SCALE est le facteur d'échelle en (1) ou (3).
!>          Si 0 < SCALE < 1, C et F contiennent les solutions R et L, respectivement,
!>          d'un système légèrement perturbé mais les matrices d'entrée A, B,
!>          D et E n'ont pas été modifiées. Si SCALE = 0, R et L contiendront
!>          les solutions du système homogène avec C = F = 0.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK > = 1.
!>          Si IJOB = 1 ou 2 et TRANS = 'N', LWORK >= max(1,2*M*N).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (M+N+2)
!>

INFO

!>          INFO est INTEGER
!>            =0 : sortie réussie
!>            <0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>            >0 : (A, D) et (B, E) ont des valeurs propres communes ou très proches.
!>
