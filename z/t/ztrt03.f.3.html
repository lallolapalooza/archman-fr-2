Documentation de la fonction/sous-routine

sous-routine ztrt03 (caractere uplo, caractere trans, caractere diag, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, double precision scale, double precision, dimension( * ) cnorm, double precision tscal, complexe*16, dimension( ldx, * ) x, entier ldx, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( * ) work, double precision resid)

ZTRT03

Objectif :

!>
!> ZTRT03 calcule le résidu pour la solution d'un système triangulaire mis à l'échelle
!> d'équations A*x = s*b,  A**T *x = s*b,  ou  A**H *x = s*b.
!> Ici, A est une matrice triangulaire, A**T dénote la transposée de A, A**H
!> dénote la transposée conjuguée de A, s est un scalaire, et x et b sont
!> des matrices de N par NRHS. Le rapport de test est le maximum sur le nombre de
!> seconds membres de
!>    norm(s*b - op(A)*x) / ( norm(op(A)) * norm(x) * EPS ),
!> où op(A) dénote A, A**T, ou A**H, et EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  A *x = s*b     (Pas de transposée)
!>          = 'T':  A**T *x = s*b  (Transposée)
!>          = 'C':  A**H *x = s*b  (Transposée conjuguée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire triangulaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          des matrices X et B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie supérieure triangulaire
!>          principale de n par n du tableau A contient la matrice triangulaire supérieure,
!>          et la partie strictement inférieure triangulaire de A n'est pas référencée.
!>          Si UPLO = 'L', la partie inférieure triangulaire principale de n par n du tableau A
!>          contient la matrice triangulaire inférieure, et la partie strictement supérieure
!>          triangulaire de A n'est pas référencée.  Si DIAG = 'U', les éléments diagonaux
!>          de A ne sont pas non plus référencés et sont supposés être 1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

SCALE

!>          SCALE est DOUBLE PRECISION
!>          Le facteur d'échelle s utilisé pour résoudre le système triangulaire.
!>

CNORM

!>          CNORM est un tableau DOUBLE PRECISION, dimension (N)
!>          Les normes 1 des colonnes de A, sans compter la diagonale.
!>

TSCAL

!>          TSCAL est DOUBLE PRECISION
!>          Le facteur d'échelle utilisé pour calculer les normes 1 dans CNORM.
!>          CNORM contient en fait les normes des colonnes de TSCAL*A.
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés pour le système d'équations
!>          linéaires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          Les vecteurs du second membre pour le système d'équations
!>          linéaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          Le maximum sur le nombre de seconds membres de
!>          norm(op(A)*x - s*b) / ( norm(op(A)) * norm(x) * EPS ).
!>
