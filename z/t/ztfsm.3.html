sous-programme ztfsm (caractère transr, caractère side, caractère uplo, caractère trans, caractère diag, entier m, entier n, complexe*16 alpha, complexe*16, dimension( 0: * ) a, complexe*16, dimension( 0: ldb-1, 0: * ) b, entier ldb)

ZTFSM résout une équation matricielle (un opérande est une matrice triangulaire au format RFP).

Objectif :

!>
!> Routine de niveau 3 BLAS pour A au format RFP.
!>
!> ZTFSM résout l'équation matricielle
!>
!>    op( A )*X = alpha*B  ou  X*op( A ) = alpha*B
!>
!> où alpha est un scalaire, X et B sont des matrices m par n, A est une matrice
!> triangulaire unitaire ou non unitaire, supérieure ou inférieure, et op( A )
!> est l'une des suivantes :
!>
!>    op( A ) = A   ou   op( A ) = A**H.
!>
!> A est au format Rectangular Full Packed (RFP).
!>
!> La matrice X est écrasée sur B.
!>

Paramètres

TRANSR 
!>          TRANSR est CHARACTER*1
!>          = 'N' : La forme normale de RFP A est stockée ;
!>          = 'C' : La forme conjuguée transposée de RFP A est stockée.
!>

SIDE

!>          SIDE est CHARACTER*1
!>           À l'entrée, SIDE spécifie si op( A ) apparaît à gauche
!>           ou à droite de X comme suit :
!>
!>              SIDE = 'L' ou 'l'   op( A )*X = alpha*B.
!>
!>              SIDE = 'R' ou 'r'   X*op( A ) = alpha*B.
!>
!>           Inchangé à la sortie.
!>

UPLO

!>          UPLO est CHARACTER*1
!>           À l'entrée, UPLO spécifie si la matrice RFP A provient
!>           d'une matrice triangulaire supérieure ou inférieure comme suit :
!>           UPLO = 'U' ou 'u' RFP A provient d'une matrice triangulaire supérieure
!>           UPLO = 'L' ou 'l' RFP A provient d'une matrice triangulaire inférieure
!>
!>           Inchangé à la sortie.
!>

TRANS

!>          TRANS est CHARACTER*1
!>           À l'entrée, TRANS spécifie la forme de op( A ) à utiliser
!>           dans la multiplication matricielle comme suit :
!>
!>              TRANS  = 'N' ou 'n'   op( A ) = A.
!>
!>              TRANS  = 'C' ou 'c'   op( A ) = conjg( A' ).
!>
!>           Inchangé à la sortie.
!>

DIAG

!>          DIAG est CHARACTER*1
!>           À l'entrée, DIAG spécifie si RFP A est unitaire
!>           triangulaire ou non comme suit :
!>
!>              DIAG = 'U' ou 'u'   A est supposée être unitaire triangulaire.
!>
!>              DIAG = 'N' ou 'n'   A n'est pas supposée être unitaire
!>                                  triangulaire.
!>
!>           Inchangé à la sortie.
!>

M

!>          M est INTEGER
!>           À l'entrée, M spécifie le nombre de lignes de B. M doit être
!>           supérieur ou égal à zéro.
!>           Inchangé à la sortie.
!>

N

!>          N est INTEGER
!>           À l'entrée, N spécifie le nombre de colonnes de B. N doit être
!>           supérieur ou égal à zéro.
!>           Inchangé à la sortie.
!>

ALPHA

!>          ALPHA est COMPLEX*16
!>           À l'entrée, ALPHA spécifie le scalaire alpha. Lorsque alpha est
!>           zéro, A n'est pas référencé et B n'a pas besoin d'être défini avant
!>           l'entrée.
!>           Inchangé à la sortie.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>           NT = N*(N+1)/2 si SIDE='R' et NT = M*(M+1)/2 sinon.
!>           À l'entrée, la matrice A au format RFP.
!>           Le format RFP est décrit par TRANSR, UPLO et N comme suit :
!>           Si TRANSR='N' alors RFP A est (0:N,0:K-1) lorsque N est pair ;
!>           K=N/2. RFP A est (0:N-1,0:K) lorsque N est impair ; K=N/2. Si
!>           TRANSR = 'C' alors RFP est la transposée conjuguée de RFP A telle que
!>           définie lorsque TRANSR = 'N'. Le contenu de RFP A est défini
!>           par UPLO comme suit : Si UPLO = 'U' RFP A contient les
!>           NT éléments de A supérieure compactée soit en format normal soit
!>           en format conjugué transposé. Si UPLO = 'L' RFP A contient
!>           les NT éléments de A inférieure compactée soit en format normal soit
!>           en format conjugué transposé. Le LDA de RFP A est (N+1)/2 lorsque
!>           TRANSR = 'C'. Lorsque TRANSR est 'N', le LDA est N+1 lorsque N est
!>           pair et est N lorsqu'il est impair.
!>           Voir la Note ci-dessous pour plus de détails. Inchangé à la sortie.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,N)
!>           Avant l'entrée, la partie principale m par n du tableau B doit
!>           contenir la matrice B du second membre, et à la sortie elle est
!>           écrasée par la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>           À l'entrée, LDB spécifie la première dimension de B telle que déclarée
!>           dans le programme appelant (sous-programme). LDB doit être au moins
!>           max( 1, m ).
!>           Inchangé à la sortie.
!>

NAME

ztfsm - complex version of zfsm

SYNOPSIS

SUBROUTINE ZTFSM(
   SIDE, TRANS, UPLO, DIAG, M, N, ALPHA, A, LDA, B, LDB, INFO
)
CHARACTER*1       :: SIDE
CHARACTER*1       :: TRANS
CHARACTER*1       :: UPLO
CHARACTER*1       :: DIAG
INTEGER           :: M
INTEGER           :: N
COMPLEX*16        :: ALPHA
COMPLEX*16        :: A( LDA, * )
INTEGER           :: LDA
COMPLEX*16        :: B( LDB, * )
INTEGER           :: LDB
INTEGER           :: INFO

Function/Subroutine Documentation

This subroutine is a wrapper to call the complex version of zfsm.

The purpose of ZTFSM is to solve one of the matrix-matrix equations:

   If SIDE = 'L' or 'l':
      Op(A) * X = alpha * B
   If SIDE = 'R' or 'r':
      X * Op(A) = alpha * B
where

Op(A) is one of:

   Op(A) = A   if TRANS = 'N' or 'n'
   Op(A) = A**H if TRANS = 'C' or 'c'

and X is an M by N matrix of unknowns. A is a lower or upper triangular matrix and is N by N if SIDE='L' or 'l' and M by M if SIDE='R' or 'r'.

Alpha is a scalar.

B is an M by N matrix, and X is an M by N matrix.

If DIAG = 'U' or 'u', A is assumed to be unit triangular (the diagonal elements are assumed to be 1).

If DIAG = 'N' or 'n', the diagonal elements of A are used.

A is N by N if SIDE = 'L' or 'l', and M by M if SIDE = 'R' or 'r'.

This routine is in the following range of routines: 3.3.1

This is just an example of how to call the complex conjugate transpose. It is not meant to be an exhaustive list. It is assumed that the matrix is stored in the standard format (i.e. A(I,J) is stored at address &A + (I-1)*LDA + J-1) and that the conjugate transpose means that the element at row I, column J is replaced by the complex conjugate of the element at row J, column I.

It is also assumed that the matrix A is stored in the lower triangle if UPLO = 'L' or 'l' and in the upper triangle if UPLO = 'U' or 'u'.

Consider A(0:1,1:2) consists of conjugate-transpose of the last two columns of AP lower. To denote conjugate we place -- above the element. This covers the case N odd and TRANSR = 'N'.

RFP A RFP A

02 03 04 00 33 43

12 13 14 10 11 44

22 23 24 20 21 22

00 33 34 30 31 32

01 11 44 40 41 42

Now let TRANSR = 'C'. RFP A in both UPLO cases is just the conjugate-transpose of RFP A above. One therefore gets:

RFP A RFP A

02 12 22 00 01 00 10 20 30 40 50

03 13 23 33 11 33 11 21 31 41 51

04 14 24 34 44 43 44 22 32 42 52
