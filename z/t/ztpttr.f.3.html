sous-routine ztpttr (uplo, n, ap, a, lda, info)
ZTPTTR copie une matrice triangulaire du format compact standard (TP) au format complet standard (TR).

Documentation de la fonction/sous-routine

sous-routine ztpttr (caractère uplo, entier n, complexe*16, dimension( * ) ap, complexe*16, dimension( lda, * ) a, entier lda, entier info)

ZTPTTR copie une matrice triangulaire du format compact standard (TP) au format complet standard (TR).

Objectif :

!>
!> ZTPTTR copie une matrice triangulaire A du format compact standard (TP)
!> au format complet standard (TR).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' :  A est triangulaire supérieure.
!>          = 'L' :  A est triangulaire inférieure.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, de dimension ( N*(N+1)/2 ),
!>          En entrée, la matrice triangulaire A, supérieure ou inférieure,
!>          compactée colonne par colonne dans un tableau linéaire. La j-ième
!>          colonne de A est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>

A

!>          A est un tableau COMPLEX*16, de dimension ( LDA, N )
!>          En sortie, la matrice triangulaire A. Si UPLO = 'U', la partie
!>          supérieure triangulaire de A de taille N x N contient la partie
!>          supérieure triangulaire de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L',
!>          la partie inférieure triangulaire de A de taille N x N contient
!>          la partie inférieure triangulaire de la matrice A, et la partie
!>          strictement supérieure triangulaire de A n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
