sous-programme ztzrqf (entier m, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) tau, entier info)

ZTZRQF

But:

!>
!> Cette routine est obsolète et a été remplacée par la routine ZTZRZF.
!>
!> ZTZRQF réduit la matrice complexe supérieure trapézoïdale M par N ( M<=N ) A
!> en forme triangulaire supérieure au moyen de transformations unitaires.
!>
!> La matrice supérieure trapézoïdale A est factorisée comme suit :
!>
!>    A = ( R  0 ) * Z,
!>
!> où Z est une matrice unitaire N par N et R est une matrice triangulaire
!> supérieure M par M.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= M.
!>

A

!>          A est un tableau COMPLEXE*16, dimension (LDA,N)
!>          À l'entrée, la partie supérieure trapézoïdale M par N de la
!>          matrice A doit contenir la matrice à factoriser.
!>          À la sortie, la partie supérieure triangulaire M par M de A
!>          contient la matrice triangulaire supérieure R, et les éléments
!>          M+1 à N des M premières lignes de A, avec le tableau TAU,
!>          représentent la matrice unitaire Z comme un produit de M
!>          réflecteurs élémentaires.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEXE*16, dimension (M)
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>

Détails supplémentaires:

!>
!>  La factorisation est obtenue par la méthode de Householder. La k-ième
!>  matrice de transformation, Z( k ), dont la transposée conjuguée est utilisée
!>  pour introduire des zéros dans la (m - k + 1)-ième ligne de A, est donnée
!>  sous la forme :
!>
!>     Z( k ) = ( I     0   ),
!>              ( 0  T( k ) )
!>
!>  où
!>
!>     T( k ) = I - tau*u( k )*u( k )**H,   u( k ) = (   1    ),
!>                                                   (   0    )
!>                                                   ( z( k ) )
!>
!>  tau et z( k ) sont choisis pour annuler les éléments de la k-ième ligne
!>  de X.
!>
!>  Le scalaire tau est retourné dans le k-ième élément de TAU et le vecteur
!>  u( k ) dans la k-ième ligne de A, de telle sorte que les éléments de z( k )
!>  se trouvent dans a( k, m + 1 ), ..., a( k, n ). Les éléments de R sont
!>  retournés dans la partie triangulaire supérieure de A.
!>
!>  Z est donné par :
!>
!>     Z =  Z( 1 ) * Z( 2 ) * ... * Z( m ).
!>
