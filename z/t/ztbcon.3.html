sous-routine ztbcon (norm, uplo, diag, n, kd, ab, ldab, rcond, work, rwork, info)
ZTBCON

Documentation de la fonction/sous-routine

sous-routine ztbcon (caractere norm, caractere uplo, caractere diag, entier n, entier kd, complexe*16, dimension( ldab, * ) ab, entier ldab, reeldouble pr rcond, complexe*16, dimension( * ) work, reeldouble pr, dimension( * ) rwork, entier info)

ZTBCON

Objectif:

!>
!> ZTBCON estime l'inverse du nombre de condition d'une matrice bande triangulaire A,
!> soit en norme 1, soit en norme infinie.
!>
!> La norme de A est calculée et une estimation est obtenue pour
!> norm(inv(A)), puis l'inverse du nombre de condition est
!> calculé comme suit :
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Paramètres

NORM 
!>          NORM est CARACTERE*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme
!>          infinie est requis :
!>          = '1' ou 'O':  Norme 1 ;
!>          = 'I':         Norme infinie.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          = 'U':  A est triangulaire supérieure ;
!>          = 'L':  A est triangulaire inférieure.
!>

DIAG

!>          DIAG est CARACTERE*1
!>          = 'N':  A est triangulaire non unitaire ;
!>          = 'U':  A est triangulaire unitaire.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est ENTIER
!>          Le nombre de superdiagonales ou sous-diagonales de la
!>          matrice bande triangulaire A.  KD >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, dimension (LDAB,N)
!>          La matrice bande triangulaire supérieure ou inférieure A, stockée dans les
!>          kd+1 premières lignes du tableau. La j-ième colonne de A est stockée
!>          dans la j-ième colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>          Si DIAG = 'U', les éléments diagonaux de A ne sont pas référencés
!>          et sont supposés être 1.
!>

LDAB

!>          LDAB est ENTIER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

RCOND

!>          RCOND est REELDOUBLE PR
!>          L'inverse du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau REELDOUBLE PR, dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
