Documentation de fonction/sous-routine

sous-routine ztrsyl3 (caractère trana, caractère tranb, entier isgn, entier m, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldc, * ) c, entier ldc, double précision scale, double précision, dimension( ldswork, * ) swork, entier ldswork, entier info)

ZTRSYL3

Objectif :

!>
!>  ZTRSYL3 résout l'équation matricielle complexe de Sylvester :
!>
!>     op(A)*X + X*op(B) = scale*C ou
!>     op(A)*X - X*op(B) = scale*C,
!>
!>  où op(A) = A ou A**H, et A et B sont toutes deux triangulaires supérieures. A est
!>  une matrice M-par-M et B est une matrice N-par-N ; C est le membre de droite
!>  et X la solution, matrices M-par-N ; et scale est un facteur d'échelle
!>  en sortie, défini à <= 1 pour éviter le dépassement de capacité dans X.
!>
!>  Ceci est la version en blocs de l'algorithme.
!>

Paramètres

TRANA 
!>          TRANA est CHARACTER*1
!>          Spécifie l'option op(A) :
!>          = 'N': op(A) = A    (Pas de transposer)
!>          = 'C': op(A) = A**H (Conjugué transposé)
!>

TRANB

!>          TRANB est CHARACTER*1
!>          Spécifie l'option op(B) :
!>          = 'N': op(B) = B    (Pas de transposer)
!>          = 'C': op(B) = B**H (Conjugué transposé)
!>

ISGN

!>          ISGN est INTEGER
!>          Spécifie le signe dans l'équation :
!>          = +1: résoudre op(A)*X + X*op(B) = scale*C
!>          = -1: résoudre op(A)*X - X*op(B) = scale*C
!>

M

!>          M est INTEGER
!>          L'ordre de la matrice A, et le nombre de lignes des
!>          matrices X et C. M >= 0.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice B, et le nombre de colonnes des
!>          matrices X et C. N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,M)
!>          La matrice triangulaire supérieure A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,N)
!>          La matrice triangulaire supérieure B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC,N)
!>          En entrée, la matrice C du membre de droite M-par-N.
!>          En sortie, C est écrasé par la matrice solution X.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M)
!>

SCALE

!>          SCALE est DOUBLE PRECISION
!>          Le facteur d'échelle, scale, défini à <= 1 pour éviter le
!>          dépassement de capacité dans X.
!>

SWORK

!>          SWORK est un tableau DOUBLE PRECISION, dimension (MAX(2, LIGNES),
!>          MAX(1,COLONNES)).
!>          En sortie, si INFO = 0, SWORK(1) renvoie la valeur optimale LIGNES
!>          et SWORK(2) renvoie la valeur optimale COLONNES.
!>

LDSWORK

!>          LDSWORK est INTEGER
!>          LDSWORK >= MAX(2,LIGNES), où LIGNES = ((M + NB - 1) / NB + 1)
!>          et NB est la taille de bloc optimale.
!>
!>          Si LDSWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les dimensions optimales du tableau SWORK,
!>          renvoie ces valeurs comme première et deuxième entrées du tableau
!>          SWORK, et aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>          = 1: A et B ont des valeurs propres communes ou très proches ; des
!>               valeurs perturbées ont été utilisées pour résoudre l'équation (mais les matrices
!>               A et B restent inchangées).
!>
