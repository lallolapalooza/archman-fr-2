sous-routine ztrttp (uplo, n, a, lda, ap, info)
ZTRTTP copie une matrice triangulaire du format standard complet (TR) au format standard compacté (TP).

Documentation de la fonction/sous-routine

sous-routine ztrttp (caractère uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) ap, entier info)

ZTRTTP copie une matrice triangulaire du format standard complet (TR) au format standard compacté (TP).

Objectif :

!>
!> ZTRTTP copie une matrice triangulaire A du format complet (TR) au format
!> compacté standard (TP).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' :  A est triangulaire supérieure ;
!>          = 'L' :  A est triangulaire inférieure.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices AP et A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          En entrée, la matrice triangulaire A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire N-par-N de tête de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          triangulaire inférieure de A n'est pas référencée.  Si UPLO = 'L',
!>          la partie inférieure triangulaire N-par-N de tête de A contient la
!>          partie triangulaire inférieure de la matrice A, et la partie
!>          strictement triangulaire supérieure de A n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AP

!>          AP est un tableau COMPLEX*16, de dimension ( N*(N+1)/2 ),
!>          En sortie, la matrice triangulaire supérieure ou inférieure A, compactée
!>          par colonnes dans un tableau linéaire. La j-ème colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  succès de l'exécution
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>
