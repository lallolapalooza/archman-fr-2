sous-routine ztpt03 (caractère uplo, caractère trans, caractère diag, entier n, entier nrhs, complexe*16, dimension( * ) ap, double précision scale, double précision, dimension( * ) cnorm, double précision tscal, complexe*16, dimension( ldx, * ) x, entier ldx, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( * ) work, double précision resid)

ZTPT03

Objectif :

!>
!> ZTPT03 calcule le résidu de la solution d'un système triangulaire mis à l'échelle
!> A*x = s*b,  A**T *x = s*b,  ou  A**H *x = s*b,
!> lorsque la matrice triangulaire A est stockée au format compacté. Ici A**T
!> dénote la transposée de A, A**H dénote la transposée conjuguée de
!> A, s est un scalaire, et x et b sont des matrices de N par NRHS. Le rapport de test
!> est le maximum sur le nombre de membres de droite de
!>    norm(s*b - op(A)*x) / ( norm(op(A)) * norm(x) * EPS ),
!> où op(A) dénote A, A**T, ou A**H, et EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  A *x = s*b     (Pas de transposée)
!>          = 'T':  A**T *x = s*b  (Transposée)
!>          = 'C':  A**H *x = s*b  (Transposée conjuguée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Non unitaire
!>          = 'U':  Unitaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices X et B.  NRHS >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, compactée colonne par colonne dans
!>          un tableau linéaire. La j-ème colonne de A est stockée dans le tableau
!>          AP comme suit :
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) pour j<=i<=n.
!>

SCALE

!>          SCALE est DOUBLE PRECISION
!>          Le facteur d'échelle s utilisé pour résoudre le système triangulaire.
!>

CNORM

!>          CNORM est un tableau DOUBLE PRECISION, dimension (N)
!>          Les normes 1 des colonnes de A, sans compter la diagonale.
!>

TSCAL

!>          TSCAL est DOUBLE PRECISION
!>          Le facteur d'échelle utilisé pour calculer les normes 1 dans CNORM.
!>          CNORM contient en fait les normes de colonnes de TSCAL*A.
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Les vecteurs solutions calculés pour le système d'équations
!>          linéaires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          Les vecteurs membres de droite pour le système d'équations
!!>          linéaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          Le maximum sur le nombre de membres de droite de
!>          norm(op(A)*x - s*b) / ( norm(op(A)) * norm(x) * EPS ).
!>
