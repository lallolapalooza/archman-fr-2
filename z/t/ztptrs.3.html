sous-routine ztptrs (character uplo, character trans, character diag, integer n, integer nrhs, complex*16, dimension( * ) ap, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZTPTRS

But :

!>
!> ZTPTRS résout un système triangulaire de la forme
!>
!>    A * X = B,  A**T * X = B,  ou  A**H * X = B,
!>
!> où A est une matrice triangulaire d'ordre N stockée au format compressé, et B est une matrice N-par-NRHS.
!>
!> Cette sous-routine vérifie que A est non singulière, mais les appelants doivent noter que seule la
!> singularité exacte est détectée. Il est concevable que l'un ou plusieurs éléments diagonaux de A soient
!> des nombres anormalement petits sans que cette sous-routine ne signale une erreur.
!>
!> Si une perte possible de précision numérique due à des matrices quasi-singulières est une préoccupation,
!> l'appelant doit vérifier que A est non singulière dans une certaine tolérance avant d'appeler cette sous-routine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  A est triangulaire supérieure ;
!>          = 'L':  A est triangulaire inférieure.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N':  A * X = B     (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Transposée conjuguée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          = 'N':  A est une matrice triangulaire non unitaire ;
!>          = 'U':  A est une matrice triangulaire unitaire.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, compressée par colonne dans
!>          un tableau linéaire. La j-ème colonne de A est stockée dans le tableau
!>          AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          À l'entrée, la matrice du côté droit B.
!>          À la sortie, si INFO = 0, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, le i-ème élément diagonal de A est exactement zéro,
!>                indiquant que la matrice est singulière et que les
!>                solutions X n'ont pas été calculées.
!>
