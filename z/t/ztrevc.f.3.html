sous-routine ztrevc (character side, character howmny, logical, dimension( * ) select, integer n, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZTREVC

But :

!>
!> ZTREVC calcule certains ou tous les vecteurs propres à droite et/ou à gauche
!> d'une matrice triangulaire supérieure complexe T.
!> Les matrices de ce type sont produites par la factorisation de Schur d'une
!> matrice générale complexe :  A = Q*T*Q**H, telle que calculée par ZHSEQR.
!>
!> Les vecteurs propres à droite x et à gauche y de T correspondant
!> à une valeur propre w sont définis par :
!>
!>              T*x = w*x,     (y**H)*T = w*(y**H)
!>
!> où y**H dénote la transposée conjuguée du vecteur y.
!> Les valeurs propres ne sont pas des entrées de cette routine, mais sont lues
!> directement sur la diagonale de T.
!>
!> Cette routine retourne les matrices X et/ou Y des vecteurs propres à droite et
!> à gauche de T, ou les produits Q*X et/ou Q*Y, où Q est une matrice d'entrée.
!> Si Q est le facteur unitaire qui réduit une matrice A en forme de Schur T,
!> alors Q*X et Q*Y sont les matrices des vecteurs propres à droite et à gauche
!> de A.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R':  calculer uniquement les vecteurs propres à droite ;
!>          = 'L':  calculer uniquement les vecteurs propres à gauche ;
!>          = 'B':  calculer les vecteurs propres à droite ET à gauche.
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A':  calculer tous les vecteurs propres à droite et/ou à gauche ;
!>          = 'B':  calculer tous les vecteurs propres à droite et/ou à gauche,
!>                  rétro-transformés en utilisant les matrices fournies dans
!>                  VR et/ou VL ;
!>          = 'S':  calculer les vecteurs propres à droite et/ou à gauche sélectionnés,
!>                  comme indiqué par le tableau logique SELECT.
!>

SELECT

!>          SELECT est un tableau LOGICAL, de dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les vecteurs propres à calculer.
!>          Le vecteur propre correspondant à la j-ième valeur propre
!>          est calculé si SELECT(j) = .VRAI..
!>          Non référencé si HOWMNY = 'A' ou 'B'.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un tableau COMPLEX*16, de dimension (LDT,N)
!>          La matrice triangulaire supérieure T.  T est modifiée, mais restaurée
!>          à la sortie.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

VL

!>          VL est un tableau COMPLEX*16, de dimension (LDVL,MM)
!>          À l'entrée, si SIDE = 'L' ou 'B' et HOWMNY = 'B', VL doit
!>          contenir une matrice Q de taille N x N (généralement la matrice unitaire Q des
!>          vecteurs de Schur retournée par ZHSEQR).
!>          À la sortie, si SIDE = 'L' ou 'B', VL contient :
!>          si HOWMNY = 'A', la matrice Y des vecteurs propres à gauche de T ;
!>          si HOWMNY = 'B', la matrice Q*Y ;
!>          si HOWMNY = 'S', les vecteurs propres à gauche de T spécifiés par
!>                           SELECT, stockés consécutivement dans les colonnes
!>                           de VL, dans le même ordre que leurs
!>                           valeurs propres.
!>          Non référencé si SIDE = 'R'.
!>

LDVL

!>          LDVL est INTEGER
!>          La dimension principale du tableau VL.  LDVL >= 1, et si
!>          SIDE = 'L' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau COMPLEX*16, de dimension (LDVR,MM)
!>          À l'entrée, si SIDE = 'R' ou 'B' et HOWMNY = 'B', VR doit
!>          contenir une matrice Q de taille N x N (généralement la matrice unitaire Q des
!>          vecteurs de Schur retournée par ZHSEQR).
!>          À la sortie, si SIDE = 'R' ou 'B', VR contient :
!>          si HOWMNY = 'A', la matrice X des vecteurs propres à droite de T ;
!>          si HOWMNY = 'B', la matrice Q*X ;
!>          si HOWMNY = 'S', les vecteurs propres à droite de T spécifiés par
!>                           SELECT, stockés consécutivement dans les colonnes
!>                           de VR, dans le même ordre que leurs
!>                           valeurs propres.
!>          Non référencé si SIDE = 'L'.
!>

LDVR

!>          LDVR est INTEGER
!>          La dimension principale du tableau VR.  LDVR >= 1, et si
!>          SIDE = 'R' ou 'B'; LDVR >= N.
!>

MM

!>          MM est INTEGER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est INTEGER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR réellement
!>          utilisées pour stocker les vecteurs propres.  Si HOWMNY = 'A' ou 'B', M
!>          est mis à N.  Chaque vecteur propre sélectionné occupe une
!>          colonne.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  L'algorithme utilisé dans ce programme est essentiellement une substitution
!>  inverse (directe), avec mise à l'échelle pour rendre le code robuste contre
!>  un éventuel débordement.
!>
!>  Chaque vecteur propre est normalisé de telle sorte que l'élément de plus grande
!>  magnitude ait une magnitude de 1 ; ici la magnitude d'un nombre complexe
!>  (x,y) est considérée comme |x| + |y|.
!>
