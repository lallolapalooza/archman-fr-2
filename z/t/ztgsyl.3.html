ZTGSYL

But :

!>
!> ZTGSYL résout l'équation de Sylvester généralisée :
!>
!>             A * R - L * B = scale * C            (1)
!>             D * R - L * E = scale * F
!>
!> où R et L sont des matrices inconnues de dimension m par n, (A, D), (B, E) et
!> (C, F) sont des paires de matrices données de dimensions m par m, n par n et m par n,
!> respectivement, avec des entrées complexes. A, B, D et E sont triangulaires
!> supérieurs (c'est-à-dire que (A,D) et (B,E) sont sous forme de Schur généralisée).
!>
!> La solution (R, L) écrase (C, F). 0 <= SCALE <= 1
!> est un facteur de mise à l'échelle de sortie choisi pour éviter le débordement.
!>
!> En notation matricielle, (1) est équivalent à résoudre Zx = scale*b, où Z
!> est défini comme
!>
!>        Z = [ kron(In, A)  -kron(B**H, Im) ]        (2)
!>            [ kron(In, D)  -kron(E**H, Im) ],
!>
!> Ici Ix est la matrice identité de taille x et X**H est la transposée
!> conjuguée de X. Kron(X, Y) est le produit de Kronecker entre les
!> matrices X et Y.
!>
!> Si TRANS = 'C', y dans le système conjugué transposé Z**H *y = scale*b
!> est résolu, ce qui est équivalent à résoudre pour R et L dans
!>
!>             A**H * R + D**H * L = scale * C           (3)
!>             R * B**H + L * E**H = scale * -F
!>
!> Ce cas (TRANS = 'C') est utilisé pour calculer une estimation basée sur la norme 1
!> de Dif[(A,D), (B,E)], la séparation entre les paires de matrices (A,D)
!> et (B,E), en utilisant ZLACON.
!>
!> Si IJOB >= 1, ZTGSYL calcule une estimation basée sur la norme de Frobenius de
!> Dif[(A,D),(B,E)]. C'est-à-dire, le réciproque d'une borne inférieure sur le
!> réciproque de la plus petite valeur singulière de Z.
!>
!> Il s'agit d'un algorithme BLAS de niveau 3.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N' : résout l'équation de Sylvester généralisée (1).
!>          = 'C' : résout le système (3).
!>

IJOB

!>          IJOB est INTEGER
!>          Spécifie le type de fonctionnalité à effectuer.
!>          =0 : résout (1) uniquement.
!>          =1 : La fonctionnalité de 0 et 3.
!>          =2 : La fonctionnalité de 0 et 4.
!>          =3 : Seule une estimation de Dif[(A,D), (B,E)] est calculée.
!>              (la stratégie de look ahead est utilisée).
!>          =4 : Seule une estimation de Dif[(A,D), (B,E)] est calculée.
!>              (ZGECON sur les sous-systèmes est utilisé).
!>          Non référencé si TRANS = 'C'.
!>

M

!>          M est INTEGER
!>          L'ordre des matrices A et D, et la dimension des lignes des
!>          matrices C, F, R et L.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices B et E, et la dimension des colonnes
!>          des matrices C, F, R et L.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, M)
!>          La matrice triangulaire supérieure A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1, M).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB, N)
!>          La matrice triangulaire supérieure B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1, N).
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC, N)
!>          À l'entrée, C contient le membre de droite de la première équation
!>          matricielle dans (1) ou (3).
!>          À la sortie, si IJOB = 0, 1 ou 2, C a été écrasé par
!>          la solution R. Si IJOB = 3 ou 4 et TRANS = 'N', C contient R,
!>          la solution obtenue lors du calcul de
!>          l'estimation Dif.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1, M).
!>

D

!>          D est un tableau COMPLEX*16, dimension (LDD, M)
!>          La matrice triangulaire supérieure D.
!>

LDD

!>          LDD est INTEGER
!>          La dimension principale du tableau D. LDD >= max(1, M).
!>

E

!>          E est un tableau COMPLEX*16, dimension (LDE, N)
!>          La matrice triangulaire supérieure E.
!>

LDE

!>          LDE est INTEGER
!>          La dimension principale du tableau E. LDE >= max(1, N).
!>

F

!>          F est un tableau COMPLEX*16, dimension (LDF, N)
!>          À l'entrée, F contient le membre de droite de la deuxième équation
!>          matricielle dans (1) ou (3).
!>          À la sortie, si IJOB = 0, 1 ou 2, F a été écrasé par
!>          la solution L. Si IJOB = 3 ou 4 et TRANS = 'N', F contient L,
!>          la solution obtenue lors du calcul de
!>          l'estimation Dif.
!>

LDF

!>          LDF est INTEGER
!>          La dimension principale du tableau F. LDF >= max(1, M).
!>

DIF

!>          DIF est DOUBLE PRECISION
!>          À la sortie, DIF est le réciproque d'une borne inférieure du
!>          réciproque de la fonction Dif, c'est-à-dire que DIF est une borne supérieure de
!>          Dif[(A,D), (B,E)] = sigma-min(Z), où Z est comme dans (2).
!>          SI IJOB = 0 ou TRANS = 'C', DIF n'est pas référencé.
!>

SCALE

!>          SCALE est DOUBLE PRECISION
!>          À la sortie, SCALE est le facteur de mise à l'échelle dans (1) ou (3).
!>          Si 0 < SCALE < 1, C et F contiennent les solutions R et L, respectivement,
!>          pour un système légèrement perturbé mais les matrices d'entrée A, B,
!>          D et E n'ont pas été modifiées. Si SCALE = 0, R et L contiendront
!>          les solutions du système homogène avec C = F = 0.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>          Si IJOB = 1 ou 2 et TRANS = 'N', LWORK >= max(1,2*M*N).
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (M+N+2)
!>

INFO

!>          INFO est INTEGER
!>            =0 : sortie réussie
!>            <0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>            >0 : (A, D) et (B, E) ont des valeurs propres communes ou très proches.
!>

Function/Subroutine Documentation

Purpose:

ztgsyl solves the generalized Sylvester equation:

A X B + C X D = E

or

A X B - C X D = E

where A, B, C, D, E, X and R are complex matrices and X is the unknown matrix.

A, B, C, D are matrices in Hessenberg form and E is any matrix. The dimensions of A, B, C, D and E are n-by-n, n-by-n, m-by-m, m-by-m and n-by-m, respectively. Q, Z, R, S are matrices of dimensions n-by-n, m-by-m, m-by-m, n-by-n respectively.

Note that the order of the matrices is significant.

Arguments:

trans (input) character*(*)
Specifies whether to solve the standard or transpose system.

transsyl (input) character*(*)
Specifies whether to solve the standard or transpose system.

ijob (input) integer
Specifies the task to be performed:

  • ijob = 0: solve the generalized Sylvester equation AXB + CXD = E and compute the condition number estimate R.
  • ijob = 1: solve the generalized Sylvester equation AXB + CXD = E.
  • ijob = 2: compute the condition number estimate R.

jobc (input) integer
Specifies whether to compute the condition number estimate R for the generalized Sylvester equation.

  • jobc = 0: do not compute the condition number estimate.
  • jobc = 1: compute the condition number estimate.

a (input) complex*16 array, dimension (lda, n)
The upper triangular matrix A.

b (input) complex*16 array, dimension (ldb, n)
The upper triangular matrix B.

c (input) complex*16 array, dimension (ldc, m)
The upper triangular matrix C.

d (input) complex*16 array, dimension (ldd, m)
The upper triangular matrix D.

e (input) complex*16 array, dimension (ldc, m)
The right hand side matrix E.

lda (input) integer
The leading dimension of the array A.

ldb (input) integer
The leading dimension of the array B.

ldc (input) integer
The leading dimension of the array C.

ldd (input) integer
The leading dimension of the array D.

lde (input) integer
The leading dimension of the array E.

ldf (input) integer
The leading dimension of the array F.

sd (output) complex*16 array, dimension (n*m)
The solution matrix X. If ijob = 1 or ijob = 2, the solution matrix X is stored in the array sd. The solution matrix is stored in the array sd as a lower triangular matrix. If ijob = 0, the solution matrix X is stored in the array sd. The solution matrix is stored in the array sd as a lower triangular matrix.

svl (output) complex*16 array, dimension (n)
The left singular vector matrix Q.

svr (output) complex*16 array, dimension (m)
The right singular vector matrix R.

scal (output) double precision
The scaling factor. If the input matrix E is scaled, then the solution X is computed for the scaled matrix E.

info (output) integer
= 0: successful exit
< 0: if info = -i, the i-th argument had an illegal value.
> 0: if info = i, then the i-th diagonal element of the Schur diagonal
matrix S is zero. The equation may not have a unique solution.

Authors:

June 2016. Based on LAPACK routines ZTGSYL and ZTRSYL.

Further Details:

The generalized Sylvester equation is a set of n*m linear equations of the form:

A X B + C X D = E

where A, B are n-by-n and C, D are m-by-m matrices. Let X be partitioned into n-by-m blocks:

X = [ X_11 X_12 ... X_1m ]

[ X_21 X_22 ... X_2m ]

[ ... ]

[ X_n1 X_n2 ... X_nm ]

The equation can be written as:

sum_{k=1}^n sum_{l=1}^m ( A_ik B_jl + C_kl D_lm ) X_kj = E_ij

where A_ik, B_jl, C_kl, D_lm, X_kj and E_ij are the corresponding blocks of the matrices A, B, C, D, X and E. The system is solved by first reducing the matrices to upper triangular form using the generalized Schur decomposition. Then, the equation is solved in a triangular form.
