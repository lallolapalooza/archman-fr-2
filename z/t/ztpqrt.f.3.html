Documentation de fonction/sous-routine

subroutine ztpqrt (integer m, integer n, integer l, integer nb, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( * ) work, integer info)

ZTPQRT

Objectif :

!>
!> ZTPQRT calcule une factorisation QR bloquée d'une matrice complexe
!> C, qui est composée d'un bloc triangulaire A et d'un bloc pentagonal B,
!> en utilisant la représentation WY compacte pour Q.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice B.
!>          M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice B, et l'ordre de la
!>          matrice triangulaire A.
!>          N >= 0.
!>

L

!>          L est INTEGER
!>          Le nombre de lignes de la partie trapézoïdale supérieure de B.
!>          MIN(M,N) >= L >= 0. Voir Détails supplémentaires.
!>

NB

!>          NB est INTEGER
!>          La taille de bloc à utiliser dans la QR bloquée. N >= NB >= 1.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la matrice triangulaire supérieure A de taille N x N.
!>          À la sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice triangulaire supérieure R.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,N)
!>          À l'entrée, la matrice pentagonale B de taille M x N. Les M-L premières
!>          lignes sont rectangulaires, et les L dernières lignes sont trapézoïdales
!>          supérieures.
!>          À la sortie, B contient la matrice pentagonale V. Voir Détails
!>          supplémentaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,M).
!>

T

!>          T est un tableau COMPLEX*16, dimension (LDT,N)
!>          Les réflecteurs de blocs triangulaires supérieurs stockés sous forme
!>          compacte sous forme d'une séquence de blocs triangulaires supérieurs.
!>          Voir Détails supplémentaires.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= NB.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (NB*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  Succès
!>          < 0:  Si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires :

!>
!>  La matrice d'entrée C est une matrice (N+M)-par-N
!>
!>               C = [ A ]
!>                   [ B ]
!>
!>  où A est une matrice triangulaire supérieure N x N, et B est une matrice
!>  pentagonale M x N composée d'une matrice rectangulaire (M-L) x N, B1,
!>  en haut d'une matrice trapézoïdale supérieure L x N, B2 :
!>
!>               B = [ B1 ]  <- rectangulaire (M-L) x N
!>                   [ B2 ]  <- trapézoïdale supérieure     L x N.
!>
!>  La matrice trapézoïdale supérieure B2 est composée des L premières lignes
!>  d'une matrice triangulaire supérieure N x N, où 0 <= L <= MIN(M,N). Si L=0,
!>  B est rectangulaire M x N ; si M=L=N, B est triangulaire supérieure.
!>
!>  La matrice W stocke les réflecteurs élémentaires H(i) dans la i-ème colonne
!>  en dessous de la diagonale (de A) dans la matrice d'entrée C (N+M) x N
!>
!>               C = [ A ]  <- triangulaire supérieure N x N
!>                   [ B ]  <- pentagonale M x N
!>
!>  de sorte que W puisse être représentée comme
!>
!>               W = [ I ]  <- identité, N x N
!>                   [ V ]  <- M x N, même forme que B.
!>
!>  Ainsi, toutes les informations nécessaires pour W sont contenues à la sortie
!>  dans B, que nous appelons V ci-dessus. Notez que V a la même forme que B ;
!>  c'est-à-dire,
!>
!>               V = [ V1 ] <- rectangulaire (M-L) x N
!>                   [ V2 ] <- trapézoïdale supérieure     L x N.
!>
!>  Les colonnes de V représentent les vecteurs qui définissent les H(i).
!>
!>  Le nombre de blocs est B = ceiling(N/NB), où chaque
!>  bloc est d'ordre NB sauf le dernier bloc, qui est d'ordre
!>  IB = N - (B-1)*NB. Pour chacun des B blocs, un facteur de réflecteur
!>  de bloc triangulaire supérieur est calculé : T1, T2, ..., TB. Les T
!>  de taille NB x NB (et IB x IB pour le dernier bloc) sont stockés dans
!>  la matrice T de taille NB x N comme
!>
!>               T = [T1 T2 ... TB].
!>
