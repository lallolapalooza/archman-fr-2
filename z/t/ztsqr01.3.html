sous-programme ztsqr01 (caractere tssw, entier m, entier n, entier mb, entier nb, double precision, dimension(6) result)

ZTSQR01

Objectif:

!>
!> ZTSQR01 teste ZGEQR , ZGELQ, ZGEMLQ et ZGEMQR.
!>

Paramètres

TSSW 
!>          TSSW est CHARACTER
!>          'TS' pour tester QR étroit et long
!>               et tout autre chose pour tester LQ large et court
!>

M

!>          M est INTEGER
!>          Nombre de lignes dans la matrice de test.
!>

N

!>          N est INTEGER
!>          Nombre de colonnes dans la matrice de test.
!>

MB

!>          MB est INTEGER
!>          Nombre de lignes dans le bloc de ligne dans la matrice de test.
!>

NB

!>          NB est INTEGER
!>          Nombre de colonnes dans la matrice de test par bloc de colonne.
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, de dimension (6)
!>          Résultats de chacun des six tests ci-dessous.
!>
!>          RESULT(1) = | A - Q R | ou | A - L Q |
!>          RESULT(2) = | I - Q^H Q | ou | I - Q Q^H |
!>          RESULT(3) = | Q C - Q C |
!>          RESULT(4) = | Q^H C - Q^H C |
!>          RESULT(5) = | C Q - C Q |
!>          RESULT(6) = | C Q^H - C Q^H |
!>
