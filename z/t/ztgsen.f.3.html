Documentation de fonction/sous-programme

sous-programme ztgsen (integer ijob, logical wantq, logical wantz, logical, dimension( * ) select, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( ldz, * ) z, integer ldz, integer m, double precision pl, double precision pr, double precision, dimension( * ) dif, complex*16, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

ZTGSEN

Objectif :

!>
!> ZTGSEN réordonne la décomposition de Schur généralisée d'une paire
!> de matrices complexes (A, B) (en termes d'une transformation d'équivalence
!> unitaire Q**H * (A, B) * Z), de sorte qu'un cluster sélectionné de valeurs
!> propres apparaisse dans les blocs diagonaux principaux de la paire (A,B).
!> Les colonnes principales de Q et Z forment des bases unitaires des
!> sous-espaces propres gauche et droits correspondants (sous-espaces déflants).
!> (A, B) doit être sous forme canonique de Schur généralisée, c'est-à-dire
!> que A et B sont toutes deux triangulaires supérieures.
!>
!> ZTGSEN calcule également les valeurs propres généralisées
!>
!>          w(j)= ALPHA(j) / BETA(j)
!>
!> de la paire de matrices réordonnée (A, B).
!>
!> Optionnellement, la routine calcule des estimations des nombres de condition
!> réciproques pour les valeurs propres et les sous-espaces propres. Ce sont
!> Difu[(A11,B11), (A22,B22)] et Difl[(A11,B11), (A22,B22)], c'est-à-dire la
!> séparation(s) entre les paires de matrices (A11, B11) et (A22,B22) qui
!> correspondent au cluster sélectionné et aux valeurs propres en dehors du
!> cluster, respectivement, et les normes de sur les sous-espaces propres
!> gauches et droits par rapport au cluster sélectionné dans le bloc (1,1).
!>
!>

Paramètres

IJOB 
!>          IJOB est INTEGER
!>          Spécifie si les nombres de condition sont requis pour le
!>          cluster de valeurs propres (PL et PR) ou pour les sous-espaces
!>          déflants (Difu et Difl):
!>           =0: Réordonner uniquement par rapport à SELECT. Pas d'extras.
!>           =1: Réciproque des normes de sur les sous-espaces propres
!>               gauches et droits par rapport au cluster sélectionné (PL et PR).
!>           =2: Bornes supérieures sur Difu et Difl. Estimation basée sur la
!>               norme F (DIF(1:2)).
!>           =3: Estimation de Difu et Difl. Estimation basée sur la norme 1
!>               (DIF(1:2)).
!>               Environ 5 fois plus coûteux que IJOB = 2.
!>           =4: Calculer PL, PR et DIF (c'est-à-dire 0, 1 et 2 ci-dessus):
!>               Version économique pour tout obtenir.
!>           =5: Calculer PL, PR et DIF (c'est-à-dire 0, 1 et 3 ci-dessus)
!>

WANTQ

!>          WANTQ est LOGICAL
!>          .VRAI. : met à jour la matrice de transformation gauche Q ;
!>          .FAUX. : ne met pas à jour Q.
!>

WANTZ

!>          WANTZ est LOGICAL
!>          .VRAI. : met à jour la matrice de transformation droite Z ;
!>          .FAUX. : ne met pas à jour Z.
!>

SELECT

!>          SELECT est tableau LOGICAL, dimension (N)
!>          SELECT spécifie les valeurs propres dans le cluster sélectionné. Pour
!>          sélectionner une valeur propre w(j), SELECT(j) doit être mis à
!>          .VRAI..
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B. N >= 0.
!>

A

!>          A est tableau COMPLEX*16, dimension(LDA,N)
!>          En entrée, la matrice triangulaire supérieure A, sous forme canonique
!>          de Schur généralisée.
!>          En sortie, A est écrasée par la matrice réordonnée A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est tableau COMPLEX*16, dimension(LDB,N)
!>          En entrée, la matrice triangulaire supérieure B, sous forme canonique
!>          de Schur généralisée.
!>          En sortie, B est écrasée par la matrice réordonnée B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

ALPHA

!>          ALPHA est tableau COMPLEX*16, dimension (N)
!>

BETA

!>          BETA est tableau COMPLEX*16, dimension (N)
!>
!>          Les éléments diagonaux de A et B, respectivement,
!>          lorsque la paire (A,B) a été réduite à la forme canonique
!>          de Schur généralisée. ALPHA(i)/BETA(i) i=1,...,N sont les valeurs
!>          propres généralisées.
!>

Q

!>          Q est tableau COMPLEX*16, dimension (LDQ,N)
!>          En entrée, si WANTQ = .VRAI., Q est une matrice N x N.
!>          En sortie, Q a été post-multipliée par la matrice de transformation
!>          unitaire gauche qui réordonne (A, B) ; Les M colonnes principales
!>          de Q forment des bases orthonormées pour la paire sélectionnée de
!>          sous-espaces propres gauches (sous-espaces déflants).
!>          Si WANTQ = .FAUX., Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= 1.
!>          Si WANTQ = .VRAI., LDQ >= N.
!>

Z

!>          Z est tableau COMPLEX*16, dimension (LDZ,N)
!>          En entrée, si WANTZ = .VRAI., Z est une matrice N x N.
!>          En sortie, Z a été post-multipliée par la matrice de transformation
!>          unitaire gauche qui réordonne (A, B) ; Les M colonnes principales
!>          de Z forment des bases orthonormées pour la paire sélectionnée de
!>          sous-espaces propres gauches (sous-espaces déflants).
!>          Si WANTZ = .FAUX., Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1.
!>          Si WANTZ = .VRAI., LDZ >= N.
!>

M

!>          M est INTEGER
!>          La dimension de la paire sélectionnée de sous-espaces propres
!>          gauches et droits (sous-espaces déflants) 0 <= M <= N.
!>

PL

!>          PL est DOUBLE PRECISION
!>

PR

!>          PR est DOUBLE PRECISION
!>
!>          Si IJOB = 1, 4 ou 5, PL, PR sont des bornes inférieures de la
!>          réciproque de la norme de sur le sous-espace propre gauche et droit
!>          par rapport au cluster sélectionné.
!>          0 < PL, PR <= 1.
!>          Si M = 0 ou M = N, PL = PR = 1.
!>          Si IJOB = 0, 2 ou 3 PL, PR ne sont pas référencés.
!>

DIF

!>          DIF est tableau DOUBLE PRECISION, dimension (2).
!>          Si IJOB >= 2, DIF(1:2) stockent les estimations de Difu et Difl.
!>          Si IJOB = 2 ou 4, DIF(1:2) sont des bornes supérieures basées sur la
!>          norme F de Difu et Difl. Si IJOB = 3 ou 5, DIF(1:2) sont des
!>          estimations basées sur la norme 1 de Difu et Difl, calculées en
!>          utilisant la communication inversée avec ZLACN2.
!>          Si M = 0 ou N, DIF(1:2) = norme F([A, B]).
!>          Si IJOB = 0 ou 1, DIF n'est pas référencé.
!>

WORK

!>          WORK est tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK
. LWORK >= 1 !> Si IJOB = 1, 2 ou 4, LWORK >= 2*M*(N-M) !> Si IJOB = 3 ou 5, LWORK >= 4*M*(N-M) !> !> Si LWORK = -1, alors une requête d'espace de travail est supposée; la routine !> calcule seulement la taille optimale du tableau WORK, retourne !> cette valeur comme première entrée du tableau WORK, et aucun message d'erreur !> lié à LWORK n'est émis par XERBLA. !>

IWORK

!>          IWORK est un tableau d'entiers, de dimension (MAX(1,LIWORK))
!>          En sortie, si INFO = 0, IWORK(1) retourne le LIWORK optimal.
!>

LIWORK

!>          LIWORK est un entier. La dimension du tableau IWORK. LIWORK >= 1.
!>          Si IJOB = 1, 2 ou 4, LIWORK >=  N+2;
!>          Si IJOB = 3 ou 5, LIWORK >= MAX(N+2, 2*M*(N-M));
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée; la
!>          routine calcule seulement la taille optimale du tableau IWORK,
!>          retourne cette valeur comme première entrée du tableau IWORK, et
!>          aucun message d'erreur lié à LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un entier
!>            =0: Sortie réussie.
!>            <0: Si INFO = -i, le i-ème argument avait une valeur illégale.
!>            =1: Le réordonnancement de (A, B) a échoué car la paire de matrices
!>                transformée (A, B) serait trop éloignée de la forme de Schur généralisée;
!>                le problème est très mal conditionné.
!>                (A, B) a pu être partiellement réordonnée.
!>                Si demandé, 0 est retourné dans DIF(*), PL et PR.
!>

Détails supplémentaires:

!>
!>  ZTGSEN collecte d'abord les valeurs propres sélectionnées en calculant des matrices unitaires
!>  U et W qui les déplacent dans le coin supérieur gauche de (A, B). Autrement dit, les valeurs propres
!>  sélectionnées sont les valeurs propres de (A11, B11) dans
!>
!>              U**H*(A, B)*W = (A11 A12) (B11 B12) n1
!>                              ( 0  A22),( 0  B22) n2
!>                                n1  n2    n1  n2
!>
!>  où N = n1+n2 et U**H désigne la transposée conjuguée de U. Les n1 premières colonnes
!>  de U et W engendrent les sous-espaces propres gauche et droit spécifiés
!>  (sous-espaces déflateurs) de (A, B).
!>
!>  Si (A, B) a été obtenu à partir de la décomposition de Schur généralisée réelle d'une paire de matrices
!>  (C, D) = Q*(A, B)*Z**H, alors la forme de Schur généralisée réordonnée de (C, D) est donnée par
!>
!>           (C, D) = (Q*U)*(U**H *(A, B)*W)*(Z*W)**H,
!>
!>  et les n1 premières colonnes de Q*U et Z*W engendrent les sous-espaces déflateurs correspondants
!>  de (C, D) (Q et Z stockent Q*U et Z*W, respectivement).
!>
!>  Notez que si la valeur propre sélectionnée est suffisamment mal conditionnée,
!>  sa valeur peut différer significativement de sa valeur avant réordonnancement.
!>
!>  Les inverses des nombres de condition des sous-espaces propres gauche et droit
!>  engendrés par les n1 premières colonnes de U et W (ou Q*U et Z*W) peuvent
!>  être retournés dans DIF(1:2), correspondant à Difu et Difl, respectivement.
!>
!>  Difu et Difl sont définis comme suit :
!>
!>       Difu[(A11, B11), (A22, B22)] = sigma-min( Zu )
!>  et
!>       Difl[(A11, B11), (A22, B22)] = Difu[(A22, B22), (A11, B11)],
!>
!>  où sigma-min(Zu) est la plus petite valeur singulière de la matrice
!>  (2*n1*n2)-par-(2*n1*n2)
!>
!>       Zu = [ kron(In2, A11)  -kron(A22**H, In1) ]
!>            [ kron(In2, B11)  -kron(B22**H, In1) ].
!>
!>  Ici, Inx est la matrice identité de taille nx et A22**H est la
!>  transposée conjuguée de A22. kron(X, Y) est le produit de Kronecker entre
!>  les matrices X et Y.
!>
!>  Lorsque DIF(2) est petit, de petits changements dans (A, B) peuvent entraîner de grands changements
!>  dans le sous-espace déflateur. Une borne approximative (asymptotique) de l'erreur angulaire maximale
!>  dans les sous-espaces déflateurs calculés est
!>
!>       EPS * norm((A, B)) / DIF(2),
!>
!>  où EPS est la précision de la machine.
!>
!>  Les inverses des normes des projecteurs sur les sous-espaces propres gauche et droit
!>  associés à (A11, B11) peuvent être retournés dans PL et PR.
!>  Ils sont calculés comme suit. On calcule d'abord L et R tels que
!>  P*(A, B)*Q est bloc-diagonal, où
!>
!>       P = ( I -L ) n1           Q = ( I R ) n1
!>           ( 0  I ) n2    et        ( 0 I ) n2
!>             n1 n2                    n1 n2
!>
!>  et (L, R) est la solution de l'équation de Sylvester généralisée
!>
!>       A11*R - L*A22 = -A12
!>       B11*R - L*B22 = -B12
!>
!>  Alors PL = (F-norm(L)**2+1)**(-1/2) et PR = (F-norm(R)**2+1)**(-1/2).
!>  Une borne approximative (asymptotique) de l'erreur absolue moyenne des
!>  valeurs propres sélectionnées est
!>
!>       EPS * norm((A, B)) / PL.
!>
!>  Il existe également des bornes d'erreur globales valides pour des perturbations
!>  jusqu'à une certaine restriction : une borne inférieure (x) sur la plus petite
!>  F-norm(E,F) pour laquelle une valeur propre de (A11, B11) peut bouger et
!>  fusionner avec une valeur propre de (A22, B22) sous perturbation (E,F),
!>  (c'est-à-dire (A + E, B + F), est
!>
!>   x = min(Difu,Difl)/((1/(PL*PL)+1/(PR*PR))**(1/2)+2*max(1/PL,1/PR)).
!>
!>  Une borne approximative de x peut être calculée à partir de DIF(1:2), PL et PR.
!>
!>  Si y = ( F-norm(E,F) / x) <= 1, les angles entre les sous-espaces déflateurs gauche et droit perturbés
!>  (L', R') et non perturbés (L, R) associés au cluster sélectionné dans les blocs (1,1) peuvent
!>  être bornés par
!>
!>   max-angle(L, L') <= arctan( y * PL / (1 - y * (1 - PL * PL)**(1/2))
!>   max-angle(R, R') <= arctan( y * PR / (1 - y * (1 - PR * PR)**(1/2))
!>
!>  Voir la section 4.11 du Manuel de l'utilisateur LAPACK ou les références suivantes
!>  pour plus d'informations.
!>
!>  Notez que si la méthode par défaut pour calculer l'estimation basée sur la norme de Frobenius
!>  DIF n'est pas souhaitée (voir ZLATDF), alors le paramètre
!>  IDIFJB (voir ci-dessous) doit être changé de 3 à 4 (la routine ZLATDF
!>  (IJOB = 2 sera utilisée)). Voir ZTGSYL pour plus de détails.
!>
