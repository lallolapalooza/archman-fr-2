Documentation de la fonction/sous-programme

sous-programme ztplqt2 (integer m, integer n, integer l, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldt, * ) t, integer ldt, integer info)

ZTPLQT2 calcule une factorisation LQ d'une matrice réelle ou complexe "triangulaire-pentagonale", qui est composée d'un bloc triangulaire et d'un bloc pentagonal, en utilisant la représentation WY compacte pour Q.

Objectif :

!>
!> ZTPLQT2 calcule une factorisation LQ d'une matrice complexe 
!> C, composée d'un bloc triangulaire A et d'un bloc pentagonal B,
!> en utilisant la représentation WY compacte pour Q.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre total de lignes de la matrice B.
!>          M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice B, et l'ordre de
!>          la matrice triangulaire A.
!>          N >= 0.
!>

L

!>          L est un ENTIER
!>          Le nombre de lignes de la partie trapézoïdale inférieure de B.
!>          MIN(M,N) >= L >= 0. Voir Détails supplémentaires.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,M)
!>          À l'entrée, la matrice triangulaire inférieure M par M, A.
!>          À la sortie, les éléments sur et sous la diagonale du tableau
!>          contiennent la matrice triangulaire inférieure L.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,N)
!>          À l'entrée, la matrice pentagonale M par N, B. Les N-L premières colonnes
!>          sont rectangulaires, et les L dernières colonnes sont trapézoïdales inférieures.
!>          À la sortie, B contient la matrice pentagonale V. Voir Détails supplémentaires.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,M).
!>

T

!>          T est un tableau COMPLEX*16, de dimension (LDT,M)
!>          Le facteur triangulaire supérieur N par N du réflecteur de bloc.
!>          Voir Détails supplémentaires.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T. LDT >= max(1,M)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>

Détails supplémentaires :

!>
!> La matrice d'entrée C est une matrice M par (M+N)
!>
!>               C = [ A ][ B ]
!>
!>
!> où A est une matrice M par M triangulaire inférieure, et B est une matrice
!> pentagonale M par N composée d'une matrice rectangulaire B1 de M par (N-L)
!> à gauche d'une matrice B2 trapézoïdale inférieure de M par L :
!>
!>               B = [ B1 ][ B2 ]
!>                   [ B1 ]  <-     M par (N-L) rectangulaire
!>                   [ B2 ]  <-     M par L trapézoïdale inférieure.
!>
!> La matrice trapézoïdale inférieure B2 est composée des L premières colonnes d'une
!> matrice triangulaire inférieure N par N, où 0 <= L <= MIN(M,N). Si L=0,
!> B est rectangulaire M par N ; si M=L=N, B est triangulaire inférieure.
!>
!> La matrice W stocke les réflecteurs élémentaires H(i) dans la i-ème
!> ligne au-dessus de la diagonale (de A) dans la matrice d'entrée C de M par (M+N)
!>
!>               C = [ A ][ B ]
!>                   [ A ]  <- M par M triangulaire inférieure
!>                   [ B ]  <- M par N pentagonale
!>
!> de sorte que W peut être représentée comme
!>
!>               W = [ I ][ V ]
!>                   [ I ]  <- identité, M par M
!>                   [ V ]  <- M par N, même forme que B.
!>
!> Ainsi, toutes les informations nécessaires pour W sont contenues à la sortie dans B,
!> que nous appelons V ci-dessus. Notez que V a la même forme que B ; c'est-à-dire,
!>
!>               W = [ V1 ][ V2 ]
!>                   [ V1 ] <-     M par (N-L) rectangulaire
!>                   [ V2 ] <-     M par L trapézoïdale inférieure.
!>
!> Les lignes de V représentent les vecteurs qui définissent les H(i).
!> Le réflecteur de bloc H de taille (M+N) par (M+N) est alors donné par
!>
!>               H = I - W**T * T * W
!>
!> où W**T est la transposée conjuguée de W et T est le facteur triangulaire supérieur
!> du réflecteur de bloc.
!>
