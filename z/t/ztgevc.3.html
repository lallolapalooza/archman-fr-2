sous-routine ztgevc (character side, character howmny, logical, dimension( * ) select, integer n, complex*16, dimension( lds, * ) s, integer lds, complex*16, dimension( ldp, * ) p, integer ldp, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZTGEVC

But:

!>
!> ZTGEVC calcule tout ou partie des vecteurs propres droits et/ou gauches
!> d'une paire de matrices complexes (S,P), où S et P sont triangulaires supérieures.
!> Les paires de matrices de ce type sont produites par la factorisation de Schur généralisée
!> d'une paire de matrices complexe (A,B):
!>
!>    A = Q*S*Z**H,  B = Q*P*Z**H
!>
!> calculées par ZGGHRD + ZHGEQZ.
!>
!> Le vecteur propre droit x et le vecteur propre gauche y de (S,P)
!> correspondant à une valeur propre w sont définis par :
!>
!>    S*x = w*P*x,  (y**H)*S = w*(y**H)*P,
!>
!> où y**H désigne la transposée conjuguée de y.
!> Les valeurs propres ne sont pas fournies en entrée de cette routine, mais sont calculées
!> directement à partir des éléments diagonaux de S et P.
!>
!> Cette routine retourne les matrices X et/ou Y des vecteurs propres droits et gauches
!> de (S,P), ou les produits Z*X et/ou Q*Y,
!> où Z et Q sont des matrices d'entrée.
!> Si Q et Z sont les facteurs unitaires de la factorisation de Schur généralisée
!> d'une paire de matrices (A,B), alors Z*X et Q*Y
!> sont les matrices des vecteurs propres droits et gauches de (A,B).
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R': calculer uniquement les vecteurs propres droits ;
!>          = 'L': calculer uniquement les vecteurs propres gauches ;
!>          = 'B': calculer les deux vecteurs propres droits et gauches.
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A': calculer tous les vecteurs propres droits et/ou gauches ;
!>          = 'B': calculer tous les vecteurs propres droits et/ou gauches,
!>                 transformés en arrière par les matrices dans VR et/ou VL ;
!>          = 'S': calculer les vecteurs propres droits et/ou gauches sélectionnés,
!>                 spécifiés par le tableau logique SELECT.
!>

SELECT

!>          SELECT est un tableau LOGIQUE, de dimension (N)
!>          Si HOWMNY='S', SELECT spécifie les vecteurs propres à calculer.
!>          Le vecteur propre correspondant à la j-ème valeur propre est calculé si SELECT(j) = .VRAI..
!>          Non référencé si HOWMNY = 'A' ou 'B'.
!>

N

!>          N est un ENTIER
!>          L'ordre des matrices S et P.  N >= 0.
!>

S

!>          S est un tableau COMPLEX*16, de dimension (LDS,N)
!>          La matrice triangulaire supérieure S d'une factorisation de Schur
!>          généralisée, calculée par ZHGEQZ.
!>

LDS

!>          LDS est un ENTIER
!>          La dimension principale du tableau S.  LDS >= max(1,N).
!>

P

!>          P est un tableau COMPLEX*16, de dimension (LDP,N)
!>          La matrice triangulaire supérieure P d'une factorisation de Schur
!>          généralisée, calculée par ZHGEQZ. P doit avoir des éléments diagonaux réels.
!>

LDP

!>          LDP est un ENTIER
!>          La dimension principale du tableau P.  LDP >= max(1,N).
!>

VL

!>          VL est un tableau COMPLEX*16, de dimension (LDVL,MM)
!>          En entrée, si SIDE = 'L' ou 'B' et HOWMNY = 'B', VL doit
!>          contenir une matrice Q de taille N*N (généralement la matrice unitaire Q
!>          des vecteurs de Schur gauches retournée par ZHGEQZ).
!>          En sortie, si SIDE = 'L' ou 'B', VL contient :
!>          si HOWMNY = 'A', la matrice Y des vecteurs propres gauches de (S,P) ;
!>          si HOWMNY = 'B', la matrice Q*Y ;
!>          si HOWMNY = 'S', les vecteurs propres gauches de (S,P) spécifiés par
!>                      SELECT, stockés consécutivement dans les colonnes de
!>                      VL, dans le même ordre que leurs valeurs propres.
!>          Non référencé si SIDE = 'R'.
!>

LDVL

!>          LDVL est un ENTIER
!>          La dimension principale du tableau VL.  LDVL >= 1, et si
!>          SIDE = 'L' ou 'l' ou 'B' ou 'b', LDVL >= N.
!>

VR

!>          VR est un tableau COMPLEX*16, de dimension (LDVR,MM)
!>          En entrée, si SIDE = 'R' ou 'B' et HOWMNY = 'B', VR doit
!>          contenir une matrice Z de taille N*N (généralement la matrice unitaire Z
!>          des vecteurs de Schur droits retournée par ZHGEQZ).
!>          En sortie, si SIDE = 'R' ou 'B', VR contient :
!>          si HOWMNY = 'A', la matrice X des vecteurs propres droits de (S,P) ;
!>          si HOWMNY = 'B', la matrice Z*X ;
!>          si HOWMNY = 'S', les vecteurs propres droits de (S,P) spécifiés par
!>                      SELECT, stockés consécutivement dans les colonnes de
!>                      VR, dans le même ordre que leurs valeurs propres.
!>          Non référencé si SIDE = 'L'.
!>

LDVR

!>          LDVR est un ENTIER
!>          La dimension principale du tableau VR.  LDVR >= 1, et si
!>          SIDE = 'R' ou 'B', LDVR >= N.
!>

MM

!>          MM est un ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est un ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR effectivement
!>          utilisées pour stocker les vecteurs propres. Si HOWMNY = 'A' ou 'B', M
!>          est défini à N. Chaque vecteur propre sélectionné occupe une colonne.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (2*N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>
