ZTPT06

Documentation de fonction/sous-routine

sous-routine ztpt06 (double précision rcond, double précision rcondc, caractère uplo, caractère diag, entier n, complexe*16, dimension( * ) ap, double précision, dimension( * ) rwork, double précision rat)

ZTPT06

Objectif :

!>
!> ZTPT06 calcule un ratio de test comparant RCOND (le nombre conditionnel
!> réciproque de la matrice triangulaire A) et RCONDC, l'estimation
!> calculée par ZTPCON. Les informations sur la matrice triangulaire sont
!> utilisées si une estimation est nulle et l'autre non nulle pour décider si
!> un sous-dépassement dans l'estimation est justifié.
!>

Paramètres :

RCOND 
!>          RCOND est DOUBLE PRECISION
!>          L'estimation du nombre conditionnel réciproque obtenu en
!>          formant l'inverse explicite de la matrice A et en calculant
!>          RCOND = 1/( norm(A) * norm(inv(A)) ).
!>

RCONDC

!>          RCONDC est DOUBLE PRECISION
!>          L'estimation du nombre conditionnel réciproque calculée par
!>          ZTPCON.
!>

UPLO

!>          UPLO est CHARACTER
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U' : Supérieure triangulaire
!>          = 'L' : Inférieure triangulaire
!>

DIAG

!>          DIAG est CHARACTER
!>          Spécifie si la matrice A est unitaire triangulaire ou non.
!>          = 'N' : Non-unitaire triangulaire
!>          = 'U' : Unitaire triangulaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est COMPLEX*16 array, dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, packed par
!>          colonne dans un tableau linéaire. La j-ème colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) pour j<=i<=n.
!>

RWORK

!>          RWORK est DOUBLE PRECISION array, dimension (N)
!>

RAT

!>          RAT est DOUBLE PRECISION
!>          Le ratio de test. Si RCOND et RCONDC sont tous deux non nuls,
!>             RAT = MAX( RCOND, RCONDC )/MIN( RCOND, RCONDC ) - 1.
!>          Si RAT = 0, les deux estimations sont exactement les mêmes.
!>
