Documentation de la fonction/sous-routine

subroutine ztrevc3 (character side, character howmny, logical, dimension( * ) select, integer n, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer lrwork, integer info)

ZTREVC3

But :

!>
!> ZTREVC3 calcule certaines ou toutes les vecteurs propres droits et/ou
!> gauches d'une matrice triangulaire supérieure complexe T.
!> Les matrices de ce type sont produites par la factorisation de Schur
!> d'une matrice générale complexe : A = Q*T*Q**H, telle que calculée par ZHSEQR.
!>
!> Le vecteur propre droit x et le vecteur propre gauche y de T correspondant
!> à une valeur propre w sont définis par :
!>
!>              T*x = w*x,     (y**H)*T = w*(y**H)
!>
!> où y**H désigne la transposée conjuguée du vecteur y.
!> Les valeurs propres ne sont pas fournies en entrée à cette routine, mais sont lues directement
!> depuis la diagonale de T.
!>
!> Cette routine retourne les matrices X et/ou Y des vecteurs propres droits et
!> gauches de T, ou les produits Q*X et/ou Q*Y, où Q est une
!> matrice fournie en entrée. Si Q est le facteur unitaire qui réduit une matrice A à la
!> forme de Schur T, alors Q*X et Q*Y sont les matrices des vecteurs propres droits et
!> gauches de A.
!>
!> Cela utilise une version de niveau 3 BLAS de la transformation inverse.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R' :  calcule uniquement les vecteurs propres droits ;
!>          = 'L' :  calcule uniquement les vecteurs propres gauches ;
!>          = 'B' :  calcule à la fois les vecteurs propres droits et gauches.
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A' :  calcule tous les vecteurs propres droits et/ou gauches ;
!>          = 'B' :  calcule tous les vecteurs propres droits et/ou gauches,
!>                  transformés à l'aide des matrices fournies dans
!>                  VR et/ou VL ;
!>          = 'S' :  calcule les vecteurs propres droits et/ou gauches sélectionnés,
!>                  comme indiqué par le tableau logique SELECT.
!>

SELECT

!>          SELECT est un tableau LOGICAL, dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les vecteurs propres à
!>          calculer.
!>          Le vecteur propre correspondant à la j-ième valeur propre est
!>          calculé si SELECT(j) = .TRUE..
!>          Non référencé si HOWMNY = 'A' ou 'B'.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un tableau COMPLEX*16, dimension (LDT,N)
!>          La matrice triangulaire supérieure T. T est modifiée, mais restaurée
!>          à la sortie.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

VL

!>          VL est un tableau COMPLEX*16, dimension (LDVL,MM)
!>          À l'entrée, si SIDE = 'L' ou 'B' et HOWMNY = 'B', VL doit
!>          contenir une matrice Q de taille N par N (généralement la matrice unitaire Q des
!>          vecteurs de Schur retournée par ZHSEQR).
!>          À la sortie, si SIDE = 'L' ou 'B', VL contient :
!>          si HOWMNY = 'A', la matrice Y des vecteurs propres gauches de T ;
!>          si HOWMNY = 'B', la matrice Q*Y ;
!>          si HOWMNY = 'S', les vecteurs propres gauches de T spécifiés par
!>                           SELECT, stockés consécutivement dans les colonnes
!>                           de VL, dans le même ordre que leurs
!>                           valeurs propres.
!>          Non référencé si SIDE = 'R'.
!>

LDVL

!>          LDVL est INTEGER
!>          La dimension principale du tableau VL.
!>          LDVL >= 1, et si SIDE = 'L' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau COMPLEX*16, dimension (LDVR,MM)
!>          À l'entrée, si SIDE = 'R' ou 'B' et HOWMNY = 'B', VR doit
!>          contenir une matrice Q de taille N par N (généralement la matrice unitaire Q des
!>          vecteurs de Schur retournée par ZHSEQR).
!>          À la sortie, si SIDE = 'R' ou 'B', VR contient :
!>          si HOWMNY = 'A', la matrice X des vecteurs propres droits de T ;
!>          si HOWMNY = 'B', la matrice Q*X ;
!>          si HOWMNY = 'S', les vecteurs propres droits de T spécifiés par
!>                           SELECT, stockés consécutivement dans les colonnes
!>                           de VR, dans le même ordre que leurs
!>                           valeurs propres.
!>          Non référencé si SIDE = 'L'.
!>

LDVR

!>          LDVR est INTEGER
!>          La dimension principale du tableau VR.
!>          LDVR >= 1, et si SIDE = 'R' ou 'B', LDVR >= N.
!>

MM

!>          MM est INTEGER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est INTEGER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR réellement
!>          utilisées pour stocker les vecteurs propres.
!>          Si HOWMNY = 'A' ou 'B', M est défini à N.
!>          Chaque vecteur propre sélectionné occupe une colonne.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,2*N).
!>          Pour des performances optimales, LWORK >= N + 2*N*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (LRWORK)
!>

LRWORK

!>          LRWORK est INTEGER
!>          La dimension du tableau RWORK. LRWORK >= max(1,N).
!>
!>          Si LRWORK = -1, une interrogation d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau RWORK, retourne
!>          cette valeur comme première entrée du tableau RWORK, et aucun message d'erreur
!>          lié à LRWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>

!>
!>  L'algorithme utilisé dans ce programme est essentiellement une substitution
!>  arrière (avant), avec une mise à l'échelle pour rendre le code robuste contre
!>  un débordement possible.
!>
!>  Chaque vecteur propre est normalisé de sorte que l'élément de plus grande
!>  magnitude ait une magnitude de 1 ; ici, la magnitude d'un nombre complexe
!>  (x,y) est définie comme |x| + |y|.
!>
