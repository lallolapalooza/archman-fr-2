ZTPQRT2 calcule une factorisation QR d'une matrice réelle ou complexe "triangulaire-pentagonale", qui est composée d'un bloc triangulaire et d'un bloc pentagonal, en utilisant la représentation compacte WY pour Q.

Objectif :

!>
!> ZTPQRT2 calcule une factorisation QR d'une matrice complexe C, composée d'un bloc triangulaire A et d'un bloc pentagonal B,
!> en utilisant la représentation compacte WY pour Q.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre total de lignes de la matrice B.
!>          M >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice B, et l'ordre de
!>          la matrice triangulaire A.
!>          N >= 0.
!>

L

!>          L est un entier
!>          Le nombre de lignes de la partie trapézoïdale supérieure de B.
!>          MIN(M,N) >= L >= 0. Voir Détails supplémentaires.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          En entrée, la matrice triangulaire supérieure A de taille N x N.
!>          En sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice triangulaire supérieure R.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,N)
!>          En entrée, la matrice pentagonale B de taille M x N. Les M-L premières lignes
!>          sont rectangulaires, et les L dernières lignes sont trapézoïdales supérieures.
!>          En sortie, B contient la matrice pentagonale V. Voir Détails supplémentaires.
!>

LDB

!>          LDB est un entier
!>          La dimension principale du tableau B. LDB >= max(1,M).
!>

T

!>          T est un tableau COMPLEX*16, de dimension (LDT,N)
!>          Le facteur triangulaire supérieur T de taille N x N du réflecteur de bloc.
!>          Voir Détails supplémentaires.
!>

LDT

!>          LDT est un entier
!>          La dimension principale du tableau T. LDT >= max(1,N)
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  La matrice d'entrée C est une matrice (N+M)-par-N
!>
!>               C = [ A ]
!>                   [ B ]
!>
!>  où A est une matrice triangulaire supérieure N x N, et B est une matrice pentagonale M x N
!>  composée d'une matrice rectangulaire B1 de taille (M-L) x N en haut et d'une
!>  matrice trapézoïdale supérieure B2 de taille L x N en bas :
!>
!>               B = [ B1 ]  <- (M-L) x N rectangulaire
!>                   [ B2 ]  <-     L x N trapézoïdale supérieure.
!>
!>  La matrice trapézoïdale supérieure B2 est constituée des L premières lignes d'une
!>  matrice triangulaire supérieure N x N, où 0 <= L <= MIN(M,N). Si L=0,
!>  B est rectangulaire M x N ; si M=L=N, B est triangulaire supérieure.
!>
!>  La matrice W stocke les réflecteurs élémentaires H(i) dans la i-ème colonne
!>  sous la diagonale (de A) dans la matrice d'entrée C de taille (N+M) x N
!>
!>               C = [ A ]  <- triangulaire supérieure N x N
!>                   [ B ]  <- pentagonale M x N
!>
!>  de telle sorte que W puisse être représentée comme
!>
!>               W = [ I ]  <- identité, N x N
!>                   [ V ]  <- M x N, même forme que B.
!>
!>  Ainsi, toutes les informations nécessaires pour W sont contenues en sortie dans B,
!>  que nous appelons V ci-dessus. Notez que V a la même forme que B ; c'est-à-dire,
!>
!>               V = [ V1 ] <- (M-L) x N rectangulaire
!>                   [ V2 ] <-     L x N trapézoïdale supérieure.
!>
!>  Les colonnes de V représentent les vecteurs qui définissent les H(i).
!>  Le réflecteur de bloc H de taille (M+N) x (M+N) est alors donné par
!>
!>               H = I - W * T * W**H
!>
!>  où W**H est la transposée conjuguée de W et T est le facteur triangulaire supérieur
!>  du réflecteur de bloc.
!>
