Documentation de la fonction/sous-programme

sous-programme ztrevc (caractère side, caractère howmny, logique, dimension( * ) select, entier n, complexe*16, dimension( ldt, * ) t, entier ldt, complexe*16, dimension( ldvl, * ) vl, entier ldvl, complexe*16, dimension( ldvr, * ) vr, entier ldvr, entier mm, entier m, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier info)

ZTREVC

Objectif :

!>
!> ZTREVC calcule certains ou tous les vecteurs propres droits et/ou gauches
!> d'une matrice triangulaire supérieure complexe T.
!> Les matrices de ce type sont produites par la factorisation de Schur d'une
!> matrice générale complexe :  A = Q*T*Q**H, telle que calculée par ZHSEQR.
!>
!> Le vecteur propre droit x et le vecteur propre gauche y de T correspondant
!> à une valeur propre w sont définis par :
!>
!>              T*x = w*x,     (y**H)*T = w*(y**H)
!>
!> où y**H dénote la transposée conjuguée du vecteur y.
!> Les valeurs propres ne sont pas des entrées de cette routine, mais sont lues
!> directement sur la diagonale de T.
!>
!> Cette routine retourne les matrices X et/ou Y des vecteurs propres droits et/ou
!> gauches de T, ou les produits Q*X et/ou Q*Y, où Q est une matrice d'entrée.
!> Si Q est le facteur unitaire qui réduit une matrice A en forme de Schur T,
!> alors Q*X et Q*Y sont les matrices des vecteurs propres droits et gauches de A.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R' : calculer uniquement les vecteurs propres droits ;
!>          = 'L' : calculer uniquement les vecteurs propres gauches ;
!>          = 'B' : calculer les vecteurs propres droits et gauches.
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A' : calculer tous les vecteurs propres droits et/ou gauches ;
!>          = 'B' : calculer tous les vecteurs propres droits et/ou gauches,
!>                  rétrotransformés à l'aide des matrices fournies dans
!>                  VR et/ou VL ;
!>          = 'S' : calculer des vecteurs propres droits et/ou gauches
!>                  sélectionnés, comme indiqué par le tableau logique SELECT.
!>

SELECT

!>          SELECT est un tableau LOGICAL, de dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les vecteurs propres à calculer.
!>          Le vecteur propre correspondant à la j-ème valeur propre est
!>          calculé si SELECT(j) = .TRUE..
!>          Non référencé si HOWMNY = 'A' ou 'B'.
!>

N

!>          N est un entier
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un tableau COMPLEX*16, de dimension (LDT,N)
!>          La matrice triangulaire supérieure T. T est modifiée, mais restaurée
!>          à la sortie.
!>

LDT

!>          LDT est un entier
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

VL

!>          VL est un tableau COMPLEX*16, de dimension (LDVL,MM)
!>          À l'entrée, si SIDE = 'L' ou 'B' et HOWMNY = 'B', VL doit
!>          contenir une matrice Q de taille N*N (généralement la matrice unitaire Q des
!>          vecteurs de Schur retournée par ZHSEQR).
!>          À la sortie, si SIDE = 'L' ou 'B', VL contient :
!>          si HOWMNY = 'A', la matrice Y des vecteurs propres gauches de T ;
!>          si HOWMNY = 'B', la matrice Q*Y ;
!>          si HOWMNY = 'S', les vecteurs propres gauches de T spécifiés par
!>                           SELECT, stockés consécutivement dans les
!>                           colonnes de VL, dans le même ordre que leurs
!>                           valeurs propres.
!>          Non référencé si SIDE = 'R'.
!>

LDVL

!>          LDVL est un entier
!>          La dimension principale du tableau VL. LDVL >= 1, et si
!>          SIDE = 'L' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau COMPLEX*16, de dimension (LDVR,MM)
!>          À l'entrée, si SIDE = 'R' ou 'B' et HOWMNY = 'B', VR doit
!>          contenir une matrice Q de taille N*N (généralement la matrice unitaire Q des
!>          vecteurs de Schur retournée par ZHSEQR).
!>          À la sortie, si SIDE = 'R' ou 'B', VR contient :
!>          si HOWMNY = 'A', la matrice X des vecteurs propres droits de T ;
!>          si HOWMNY = 'B', la matrice Q*X ;
!>          si HOWMNY = 'S', les vecteurs propres droits de T spécifiés par
!>                           SELECT, stockés consécutivement dans les
!>                           colonnes de VR, dans le même ordre que leurs
!>                           valeurs propres.
!>          Non référencé si SIDE = 'L'.
!>

LDVR

!>          LDVR est un entier
!>          La dimension principale du tableau VR. LDVR >= 1, et si
!>          SIDE = 'R' ou 'B' ; LDVR >= N.
!>

MM

!>          MM est un entier
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est un entier
!>          Le nombre de colonnes dans les tableaux VL et/ou VR réellement
!>          utilisées pour stocker les vecteurs propres. Si HOWMNY = 'A' ou 'B', M
!>          est mis à N. Chaque vecteur propre sélectionné occupe une
!>          colonne.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (N)
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  L'algorithme utilisé dans ce programme est essentiellement une substitution
!>  arrière (avant), avec mise à l'échelle pour rendre le code robuste contre
!>  d'éventuels débordements.
!>
!>  Chaque vecteur propre est normalisé de sorte que l'élément de plus grande
!>  magnitude ait une magnitude de 1 ; ici la magnitude d'un nombre complexe
!>  (x,y) est prise comme |x| + |y|.
!>
