NOM

ztee - tampon et répartiteur de sortie

SYNTAXE

ztee [ OPTIONS... ] [ FICHIER... ]

DESCRIPTION

ZTee est un tampon et répartiteur de sortie destiné à être utilisé avec les données de sortie de ZMap. ZTee doit être utilisé chaque fois que ZMap est redirigé vers un scanner d'application, placé entre ZMap et le scanner d'application. ZTee écrit la sortie transformée sur stdout, et écrit la sortie originale dans FICHIER.

Voir --help pour des exemples.

TRAITEMENT CSV ET MODE BRUT

ZTee fonctionne par défaut sur la sortie au format CSV de ZMap. Il n'envoie que les adresses IP (du champ ip ou saddr de l'entrée) vers stdout, tout en écrivant toutes les entrées dans le fichier de sortie. ZTee n'affiche pas la première ligne de l'entrée sur stdout, car cette ligne est l'en-tête CSV.

Pour traiter des données dans tout autre format, utilisez l'indicateur --raw. En mode brut, ztee se comporte comme tee : il ne transformera ni n'essaiera d'analyser les données d'entrée.

OPTIONS

OPTIONS DE BASE

-r, --raw
Ignore le formatage de l'entrée et transmet l'entrée brute. Cela fait que ztee se comporte exactement comme tee, avec l'ajout de mise en tampon.
--success-only
Écrit uniquement sur stdout les lignes où success=1 ou success=true. Invalide en combinaison avec --raw.
-m, --monitor
Affiche les données de surveillance sur stderr
-u, --status-updates-file
Écrit les mises à jour de statut (données de surveillance) dans le fichier donné, au format CSV
-l, --log-file=nom
Écrit les erreurs, etc. dans le fichier donné. S'il n'y en a pas, ZTee enregistre sur stderr.

OPTIONS SUPPLÉMENTAIRES

-h, --help
Affiche l'aide
-V, --version
Affiche la version
