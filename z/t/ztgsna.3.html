sous-routine ztgsna (caractère job, caractère howmny, logique, dimension( * ) select, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldvl, * ) vl, entier ldvl, complexe*16, dimension( ldvr, * ) vr, entier ldvr, double précision, dimension( * ) s, double précision, dimension( * ) dif, entier mm, entier m, complexe*16, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier info)

ZTGSNA

But :

!>
!> ZTGSNA estime les nombres de condition réciproques pour des
!> valeurs propres et/ou vecteurs propres spécifiés d'une paire de matrices (A, B).
!>
!> (A, B) doit être sous forme canonique généralisée de Schur, c'est-à-dire que A et
!> B sont toutes deux triangulaires supérieures.
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>          Spécifie si les nombres de condition sont requis pour
!>          les valeurs propres (S) ou les vecteurs propres (DIF) :
!>          = 'E' : pour les valeurs propres uniquement (S) ;
!>          = 'V' : pour les vecteurs propres uniquement (DIF) ;
!>          = 'B' : pour les valeurs propres et les vecteurs propres (S et DIF).
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A' : calculer les nombres de condition pour toutes les paires propres ;
!>          = 'S' : calculer les nombres de condition pour les paires propres sélectionnées
!>                 spécifiées par le tableau SELECT.
!>

SELECT

!>          SELECT est un tableau LOGIQUE, de dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les paires propres pour lesquelles
!>          les nombres de condition sont requis. Pour sélectionner les nombres de condition
!>          pour la j-ième valeur propre et/ou vecteur propre correspondant,
!>          SELECT(j) doit être mis à .TRUE..
!>          Si HOWMNY = 'A', SELECT n'est pas référencé.
!>

N

!>          N est un ENTIER
!>          L'ordre de la paire de matrices carrées (A, B). N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          La matrice triangulaire supérieure A dans la paire (A,B).
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,N)
!>          La matrice triangulaire supérieure B dans la paire (A, B).
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

VL

!>          VL est un tableau COMPLEX*16, de dimension (LDVL,M)
!>          Si JOB = 'E' ou 'B', VL doit contenir les vecteurs propres gauches
!>          de (A, B), correspondant aux paires propres spécifiées par HOWMNY
!>          et SELECT. Les vecteurs propres doivent être stockés dans des colonnes
!>          consécutives de VL, tels que retournés par ZTGEVC.
!>          Si JOB = 'V', VL n'est pas référencé.
!>

LDVL

!>          LDVL est un ENTIER
!>          La dimension principale du tableau VL. LDVL >= 1; et
!>          Si JOB = 'E' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau COMPLEX*16, de dimension (LDVR,M)
!>          Si JOB = 'E' ou 'B', VR doit contenir les vecteurs propres droits
!>          de (A, B), correspondant aux paires propres spécifiées par HOWMNY
!>          et SELECT. Les vecteurs propres doivent être stockés dans des colonnes
!>          consécutives de VR, tels que retournés par ZTGEVC.
!>          Si JOB = 'V', VR n'est pas référencé.
!>

LDVR

!>          LDVR est un ENTIER
!>          La dimension principale du tableau VR. LDVR >= 1;
!>          Si JOB = 'E' ou 'B', LDVR >= N.
!>

S

!>          S est un tableau DOUBLE PRÉCISION, de dimension (MM)
!>          Si JOB = 'E' ou 'B', les nombres de condition réciproques des
!>          valeurs propres sélectionnées, stockés dans des éléments consécutifs du
!>          tableau.
!>          Si JOB = 'V', S n'est pas référencé.
!>

DIF

!>          DIF est un tableau DOUBLE PRÉCISION, de dimension (MM)
!>          Si JOB = 'V' ou 'B', les nombres de condition réciproques estimés des
!>          vecteurs propres sélectionnés, stockés dans des éléments consécutifs du
!>          tableau.
!>          Si les valeurs propres ne peuvent pas être réordonnées pour calculer DIF(j),
!>          DIF(j) est mis à 0 ; cela ne peut se produire que lorsque la valeur réelle
!>          serait déjà très petite.
!>          Pour chaque valeur propre/vecteur propre spécifié par SELECT, DIF stocke
!>          une estimation de Difl basée sur la norme de Frobenius.
!>          Si JOB = 'E', DIF n'est pas référencé.
!>

MM

!>          MM est un ENTIER
!>          Le nombre d'éléments dans les tableaux S et DIF. MM >= M.
!>

M

!>          M est un ENTIER
!>          Le nombre d'éléments des tableaux S et DIF utilisés pour stocker
!>          les nombres de condition spécifiés ; un élément est utilisé pour chaque valeur propre sélectionnée. Si HOWMNY = 'A', M est mis à N.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient le LWORK optimal.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>          Si JOB = 'V' ou 'B', LWORK >= max(1,2*N*N).
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (N+2)
!>          Si JOB = 'E', IWORK n'est pas référencé.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : Sortie réussie
!>          < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!> Le réciproque du nombre de condition de la i-ème valeur propre généralisée
!> w = (a, b) est défini comme suit :
!>
!>          S(I) = (|v**HAu|**2 + |v**HBu|**2)**(1/2) / (norm(u)*norm(v))
!>
!> où u et v sont les vecteurs propres droit et gauche de (A, B)
!> correspondant à w ; |z| désigne la valeur absolue du nombre complexe,
!> et norm(u) désigne la norme 2 du vecteur u. La paire
!> (a, b) correspond à une valeur propre w = a/b (= v**HAu/v**HBu) de la
!> paire de matrices (A, B). Si a et b sont tous deux égaux à zéro, alors (A,B) est
!> singulier et S(I) = -1 est retourné.
!>
!> Une borne d'erreur approximative sur la distance chordale entre la i-ème
!> valeur propre généralisée calculée w et la valeur propre exacte correspondante
!> lambda est :
!>
!>          chord(w, lambda) <=   EPS * norm(A, B) / S(I),
!>
!> où EPS est la précision machine.
!>
!> Le réciproque du nombre de condition du vecteur propre droit u
!> et du vecteur propre gauche v correspondant à la valeur propre généralisée w
!> est défini comme suit. Supposons
!>
!>                   (A, B) = ( a   *  ) ( b  *  )  1
!>                            ( 0  A22 ),( 0 B22 )  n-1
!>                              1  n-1     1 n-1
!>
!> Alors le nombre de condition réciproque DIF(I) est
!>
!>          Difl[(a, b), (A22, B22)]  = sigma-min( Zl )
!>
!> où sigma-min(Zl) désigne la plus petite valeur singulière de
!>
!>         Zl = [ kron(a, In-1) -kron(1, A22) ]

NOM

ZTGSNA - pour estimer le conditionnement des vecteurs propres droits et gauches pour une paire de matrices généralisée de Schur.

SYNTAXIS

SUBROUTINE ZTGSNA( JOB, HOWMNY, SELECT, N, A, LDA, B, LDB, Q, LDQ, Z,
 LDZ, RWORK, SSUP, SFAC, WORK, LWORK, IWORK, INFO )

Les sous-programmes ZTGSNA, ZTGSA2, ZTGSF2, ZTGSF3, ZTGSTB, ZTGSV, ZTGXY et ZTGSX sont des utilitaires pour le calcul des valeurs singulières et des conditionnements estimés.

Fonction/Documentation de sous-programme

!>
!>  Les fonctions ZTGSNA, ZTGSA2, ZTGSF2, ZTGSF3, ZTGSTB, ZTGSV, ZTGXY et ZTGSX
!>  calculent les valeurs singulières de la matrice Zl, qui est une
!>  matrice triangulaire supérieure de taille N-1, définie comme suit :
!>
!>     Zl = [ -kron(1, B22)      A12       ]
!>          [ -kron(T21, I(N-1)) I(N-1) - kron(1, B22) ]
!>
!>  où T est la matrice triangulaire supérieure issue de la décomposition
!>  de Schur généralisée de la paire (A, B), et où
!>
!>     A = [ A11  A12 ]   et   B = [ B11  B12 ]
!>         [ A21  A22 ]           [ B21  B22 ]
!>
!>  sont des sous-matrices de A et B, respectivement.
!>  I(N-1) est la matrice identité de taille N-1 et X**H est la transposée
!>  conjuguée de X. kron(X, Y) est le produit de Kronecker entre les
!>  matrices X et Y.
!>
!>  Nous approximons la plus petite valeur singulière de Zl avec une borne
!>  supérieure. Ceci est fait par ZLATDF.
!>
!>  Une borne d'erreur approximative pour un vecteur propre calculé VL(i) ou
!>  VR(i) est donnée par
!>
!>                      EPS * norm(A, B) / DIF(i).
!>
!>  Voir réf. [2-3] pour plus de détails et d'autres références.
!>
