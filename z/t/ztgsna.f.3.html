subroutine ztgsna (character job, character howmny, logical, dimension( * ) select, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, double precision, dimension( * ) s, double precision, dimension( * ) dif, integer mm, integer m, complex*16, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

ZTGSNA

Objectif :

!>
!> ZTGSNA estime les nombres de condition réciproques pour les
!> valeurs propres et/ou les vecteurs propres spécifiés d'une paire de matrices (A, B).
!>
!> (A, B) doit être sous forme canonique généralisée de Schur, c'est-à-dire que A et
!> B sont toutes deux triangulaires supérieures.
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>          Spécifie si les nombres de condition sont requis pour
!>          les valeurs propres (S) ou les vecteurs propres (DIF) :
!>          = 'E' : pour les valeurs propres seulement (S) ;
!>          = 'V' : pour les vecteurs propres seulement (DIF) ;
!>          = 'B' : pour les deux valeurs propres et vecteurs propres (S et DIF).
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A' : calcule les nombres de condition pour toutes les paires propres ;
!>          = 'S' : calcule les nombres de condition pour les paires propres sélectionnées
!>                 spécifiées par le tableau SELECT.
!>

SELECT

!>          SELECT est un tableau LOGIQUE, de dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les paires propres pour lesquelles
!>          des nombres de condition sont requis. Pour sélectionner les nombres de condition
!>          pour la j-ème valeur propre et/ou vecteur propre correspondant,
!>          SELECT(j) doit être mis à .VRAI..
!>          Si HOWMNY = 'A', SELECT n'est pas référencé.
!>

N

!>          N est un ENTIER
!>          L'ordre de la paire de matrices carrées (A, B). N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          La matrice triangulaire supérieure A dans la paire (A,B).
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,N)
!>          La matrice triangulaire supérieure B dans la paire (A, B).
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

VL

!>          VL est un tableau COMPLEX*16, de dimension (LDVL,M)
!>          Si JOB = 'E' ou 'B', VL doit contenir les vecteurs propres gauches
!>          de (A, B), correspondant aux paires propres spécifiées par HOWMNY
!>          et SELECT. Les vecteurs propres doivent être stockés dans des colonnes
!>          consécutives de VL, tel que retourné par ZTGEVC.
!>          Si JOB = 'V', VL n'est pas référencé.
!>

LDVL

!>          LDVL est un ENTIER
!>          La dimension principale du tableau VL. LDVL >= 1; et
!>          Si JOB = 'E' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau COMPLEX*16, de dimension (LDVR,M)
!>          Si JOB = 'E' ou 'B', VR doit contenir les vecteurs propres droits
!>          de (A, B), correspondant aux paires propres spécifiées par HOWMNY
!>          et SELECT. Les vecteurs propres doivent être stockés dans des colonnes
!>          consécutives de VR, tel que retourné par ZTGEVC.
!>          Si JOB = 'V', VR n'est pas référencé.
!>

LDVR

!>          LDVR est un ENTIER
!>          La dimension principale du tableau VR. LDVR >= 1;
!>          Si JOB = 'E' ou 'B', LDVR >= N.
!>

S

!>          S est un tableau DOUBLE PRECISION, de dimension (MM)
!>          Si JOB = 'E' ou 'B', les nombres de condition réciproques des
!>          valeurs propres sélectionnées, stockés dans des éléments consécutifs du
!>          tableau.
!>          Si JOB = 'V', S n'est pas référencé.
!>

DIF

!>          DIF est un tableau DOUBLE PRECISION, de dimension (MM)
!>          Si JOB = 'V' ou 'B', les nombres de condition réciproques estimés des
!>          vecteurs propres sélectionnés, stockés dans des éléments consécutifs du
!>          tableau.
!>          Si les valeurs propres ne peuvent pas être réordonnées pour calculer DIF(j),
!>          DIF(j) est mis à 0 ; cela ne peut se produire que lorsque la valeur réelle
!>          serait de toute façon très petite.
!>          Pour chaque valeur propre/vecteur propre spécifié par SELECT, DIF stocke
!>          une estimation de Difl basée sur la norme de Frobenius.
!>          Si JOB = 'E', DIF n'est pas référencé.
!>

MM

!>          MM est un ENTIER
!>          Le nombre d'éléments dans les tableaux S et DIF. MM >= M.
!>

M

!>          M est un ENTIER
!>          Le nombre d'éléments des tableaux S et DIF utilisés pour stocker
!>          les nombres de condition spécifiés ; pour chaque valeur propre sélectionnée,
!>          un élément est utilisé. Si HOWMNY = 'A', M est mis à N.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient LWORK optimal.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>          Si JOB = 'V' ou 'B', LWORK >= max(1,2*N*N).
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (N+2)
!>          Si JOB = 'E', IWORK n'est pas référencé.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : Sortie réussie
!>          < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale
!>

ztgsna.f(3)

NAME

ztgsna - ztgsna est une sous-routine qui calcule les normes des vecteurs de droite et de gauche correspondant aux petits valeurs propres d'une paire de matrices générales réelles (A, B).

SYNOPSIS

SUBROUTINE ZTGSNA(
 JOB, HOWMNY, SELECT, N, A, LDA, B, LDB, VL, VLL, VR, VLR,
 RISES, RWORK, SSES, SES, WORK, LWORK, IWORK, LIWORK, INFO )

CHARACTER * 1 JOB, HOWMNY
LOGICAL SELECT( * )
INTEGER N, LDA, LDB, VLL, VLR, LIWORK, INFO
COMPLEX*16 A( LDA, * ), B( LDB, * ), VL( VLL, * ), VR( VLR, * )
REAL*8 RISES( * ), RWORK( * ), SSES( * ), SES( * )
COMPLEX*16 WORK( * )
INTEGER IWORK( * )

Function/Subroutine Documentation

ZTGSNA calcule les normes des vecteurs singuliers de droite et de gauche correspondants aux petites valeurs propres d'une paire de matrices générales réelles (A, B) sous forme généralisée de Schur.

Les paires de matrices (A, B) sont supposées être sous forme généralisée de Schur réelle, c'est-à-dire que A et B sont des matrices triangulaires supérieures par blocs dont les blocs diagonaux sont soit des matrices 1x1, soit des matrices 2x2.

Pour un eigenvalue i, le vecteur propre droit (ou gauche) VL(i) (ou VR(i)) est le vecteur propre correspondant à la paire (A, B) défini comme l'ensemble des vecteurs x tels que Ax = lambda * Bx.

La sous-routine calcule les normes des composantes des vecteurs propres généraux VL(i) et VR(i) des petites valeurs propres de la paire de matrices (A, B) sous forme généralisée de Schur réelle.

Les valeurs propres et les vecteurs propres généraux sont obtenus à partir de la mise en œuvre de la méthode de Kagstrom et Poromaa [1].

La sous-routine utilise la fonction auxiliaire ZLATDF pour calculer les séparations de valeurs propres et pour fournir un nouveau ordre des petites valeurs propres.

Les valeurs propres peuvent être triées de manière sélective en utilisant le tableau SELECT.

Les norms des vecteurs propres VL et VR sont calculées en utilisant les séparations de valeurs propres calculées par ZLATDF.

Un estimation de l'erreur pour le vecteur propre calculé VL(i) ou VR(i) est donnée par:

EPS * norm(A, B) / DIF(i).

Voir les références [2-3] pour plus de détails et d'autres références.

!>  Dans cette formule, In-1 est la matrice identité de taille n-1 et X**H est la
!>  transposée conjuguée de X. kron(X, Y) est le produit de Kronecker entre les
!>  matrices X et Y.
!>
!>  Nous approximons la plus petite valeur propre singulière de Zl avec une borne
!>  supérieure. Ceci est fait par ZLATDF.
!>
!>  Une borne d'erreur approximative pour un vecteur propre calculé VL(i) ou
!>  VR(i) est donnée par
!>
!>                      EPS * norm(A, B) / DIF(i).
!>
!>  Voir les références [2-3] pour plus de détails et d'autres références.
!>
