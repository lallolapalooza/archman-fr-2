sous-programme ztrt01 (caractère uplo, caractère diag, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldainv, * ) ainv, entier ldainv, double précision rcond, double précision, dimension( * ) rwork, double précision resid)

ZTRT01

But :

!>
!> ZTRT01 calcule le résidu pour une matrice triangulaire A fois son
!> inverse :
!>    RESID = norm( A*AINV - I ) / ( N * norm(A) * norm(AINV) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie triangulaire
!>          supérieure de la matrice de dimension n x n dans le tableau A
!>          contient la matrice triangulaire supérieure, et la partie
!>          strictement triangulaire inférieure de A n'est pas référencée.
!>          Si UPLO = 'L', la partie triangulaire inférieure de la matrice de
!>          dimension n x n dans le tableau A contient la matrice triangulaire
!>          inférieure, et la partie strictement triangulaire supérieure de A
!>          n'est pas référencée.  Si DIAG = 'U', les éléments diagonaux de A
!>          ne sont pas référencés et sont supposés être 1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AINV

!>          AINV est un tableau COMPLEX*16, dimension (LDAINV,N)
!>          À l'entrée, l'inverse (triangulaire) de la matrice A, dans le
!>          même format de stockage que A.
!>          À la sortie, le contenu de AINV est détruit.
!>

LDAINV

!>          LDAINV est INTEGER
!>          La dimension principale du tableau AINV.  LDAINV >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          Le nombre de conditionnement réciproque de A, calculé comme
!>          1/(norm(A) * norm(AINV)).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          norm(A*AINV - I) / ( N * norm(A) * norm(AINV) * EPS )
!>
