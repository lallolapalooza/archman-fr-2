zip_set_file_compression(3)

Paquet: libzip

Licences: BSD

ZIP_SET_FILE_COMPRESSION(3) Manuel des fonctions de bibliothèque ZIP_SET_FILE_COMPRESSION(3)

NOM

zip_set_file_compression — définir la méthode de compression pour un fichier dans une archive zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

int
zip_set_file_compression(zip_t *archive, zip_uint64_t index, zip_int32_t comp, zip_uint32_t comp_flags);

DESCRIPTION

La fonction zip_set_file_compression() définit la méthode de compression pour le fichier à la position index dans l'archive zip à comp avec les comp_flags spécifiques à la méthode de compression. comp est le même que celui retourné par zip_stat(3). Pour l'argument comp, seules les valeurs suivantes sont actuellement prises en charge :

ZIP_CM_DEFAULT
compression par défaut ; actuellement identique à ZIP_CM_DEFLATE, mais les flags sont ignorés.
ZIP_CM_STORE
Stocker le fichier sans compression.
ZIP_CM_BZIP2
Compresser le fichier en utilisant l'algorithme bzip2(1).
ZIP_CM_DEFLATE
Décompresser le fichier avec l'algorithme zlib(3) et les options par défaut.
ZIP_CM_XZ
Utiliser l'algorithme xz(1) pour la compression
ZIP_CM_ZSTD
Utiliser l'algorithme zstd(1) pour la compression

NOTE: Seules les méthodes de décompression et de stockage peuvent être supposées être universellement prises en charge.

L'argument comp_flags définit le niveau de compression. Cette valeur dépend de l'algorithme de compression. En général, les nombres plus bas signifient une décompression/compression plus rapide et les nombres plus élevés signifient une décompression/compression plus lente. Pour ZIP_CM_BZIP, ZIP_CM_DEFLATE et ZIP_CM_XZ, 1 est la compression la plus rapide et 9 la meilleure, 0 choisit le défaut. Pour ZIP_CM_ZSTD, les valeurs possibles sont ZSTD_minCLevel(3) à ZSTD_maxCLevel(3) ; les valeurs négatives doivent être converties en zip_uint32_t.

D'autres indicateurs spécifiques à la méthode de compression pourraient être ajoutés au fil du temps.

La méthode de compression actuelle pour un fichier dans une archive zip peut être déterminée à l'aide de zip_stat(3).

VALEURS DE RETOUR

En cas de succès, 0 est retourné. Sinon, -1 est retourné et les informations d'erreur dans archive sont définies pour indiquer l'erreur.

ERREURS

zip_set_file_compression() échoue si :

[ZIP_ER_COMPNOTSUPP]
Méthode de compression non prise en charge demandée.
[ZIP_ER_INVAL]
index n'est pas un index de fichier valide dans archive, ou la combinaison d'arguments est invalide.
[ZIP_ER_RDONLY]
Fichier zip en lecture seule, aucune modification autorisée.

VOIR AUSSI

libzip(3), zip_compression_method_supported(3), zip_stat(3)

HISTORIQUE

zip_set_file_compression() a été ajoutée dans libzip 0.11.
