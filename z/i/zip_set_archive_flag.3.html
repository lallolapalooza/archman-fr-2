zip_set_archive_flag(3)

Paquet: libzip

Licences: BSD

ZIP_SET_ARCHIVE_FLAG(3) Manuel des fonctions de bibliothèque ZIP_SET_ARCHIVE_FLAG(3)

NOM

zip_set_archive_flag — définir un indicateur d'archive zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

int
zip_set_archive_flag(zip_t *archive, zip_flags_t flag, int value);

DESCRIPTION

La fonction zip_set_archive_flag() définit l'indicateur flag pour l'archive archive à la valeur value.

Les indicateurs pris en charge sont les suivants :

ZIP_AFL_CREATE_OR_KEEP_FILE_FOR_EMPTY_ARCHIVE
Si cet indicateur est effacé, le fichier archive sera supprimé si l'archive est vide. S'il est défini, une archive vide sera créée, ce qui n'est pas recommandé par la spécification zip.
ZIP_AFL_RDONLY
Si cet indicateur est défini, aucune modification de l'archive n'est autorisée. Cet indicateur ne peut être effacé que s'il a été défini manuellement avec zip_set_archive_flag, et non si l'archive a été ouverte en lecture seule.
ZIP_AFL_WANT_TORRENTZIP
Si cet indicateur est défini, l'archive sera écrite au format torrentzip.

VALEURS DE RETOUR

En cas de succès, 0 est retourné, et -1 si une erreur s'est produite.

VOIR AUSSI

libzip(3), zip_get_archive_flag(3)

HISTORIQUE

zip_set_archive_flag() a été ajoutée dans libzip 0.9. Dans libzip 0.11, le type de flag a été changé de int à zip_flags_t. ZIP_AFL_CREATE_OR_KEEP_FILE_FOR_EMPTY_ARCHIVE et ZIP_AFL_WANT_TORRENTZIP ont été ajoutés dans libzip 1.10.0.
