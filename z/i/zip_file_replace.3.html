zip_file_replace(3)

Paquet: libzip

Licences: BSD

ZIP_FILE_ADD(3) Manuel des fonctions de bibliothèque ZIP_FILE_ADD(3)

NOM

zip_file_add, zip_file_replace — ajouter un fichier à une archive zip ou remplacer un fichier dans une archive zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

zip_int64_t
zip_file_add(zip_t *archive, const char *name, zip_source_t *source, zip_flags_t flags);

int
zip_file_replace(zip_t *archive, zip_uint64_t index, zip_source_t *source, zip_flags_t flags);

DESCRIPTION

La fonction zip_file_add() ajoute un fichier à une archive zip, tandis que zip_file_replace() remplace un fichier existant dans une archive zip. L'argument archive spécifie l'archive zip à laquelle le fichier doit être ajouté. name est le nom du fichier dans l'archive zip (pour zip_file_add()), tandis que index spécifie quel fichier doit être remplacé (pour zip_file_replace()). L'argument flags peut être une combinaison de ZIP_FL_OVERWRITE avec l'une des ZIP_FL_ENC_* :

ZIP_FL_OVERWRITE
Écrase tout fichier existant portant le même nom. Pour zip_file_add uniquement.
ZIP_FL_ENC_GUESS
Devine l'encodage de name (par défaut). (Seuls CP-437 et UTF-8 sont reconnus.)
ZIP_FL_ENC_UTF_8
Interprète name comme UTF-8.
ZIP_FL_ENC_CP437
Interprète name comme page de code 437 (CP-437).
Les données sont obtenues à partir de l'argument source, voir zip_source(5).

NOTE: zip_source_free(3) ne doit pas être appelé sur une source après qu'elle ait été utilisée avec succès dans un appel à zip_file_add ou zip_file_replace.

Veuillez également noter qu'en utilisant zip_replace, les informations des champs supplémentaires du fichier cible seront supprimées car elles dépendent généralement du contenu du fichier. Si vous souhaitez les conserver, interrogez-les au préalable avec zip_file_extra_field_get(3) et restaurez-les après zip_replace avec zip_file_extra_field_set(3).

VALEURS DE RETOUR

En cas de succès, zip_file_add() retourne l'index du nouveau fichier dans l'archive, et zip_file_replace() retourne 0. Sinon, -1 est retourné et le code d'erreur dans archive est défini pour indiquer l'erreur.

EXEMPLES

zip_source_t *s;
const char buf[]="teststring";

if ((s=zip_source_buffer(archive, buf, sizeof(buf), 0)) == NULL ||
    zip_file_add(archive, name, s, ZIP_FL_ENC_UTF_8) < 0) {
    zip_source_free(s);
    printf("erreur lors de l'ajout du fichier : %s\n", zip_strerror(archive));
}

ERREURS

zip_file_add() et zip_file_replace() échouent si :

[ZIP_ER_EXISTS]
Il existe déjà un fichier nommé name dans l'archive. (S'applique uniquement à zip_file_add(), et uniquement si ZIP_FL_OVERWRITE n'est pas fourni).
[ZIP_ER_INVAL]
source ou name sont NULL, ou index est invalide.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.
[ZIP_ER_RDONLY]
L'archive a été ouverte en mode lecture seule.

VOIR AUSSI

libzip(3), zip_source(5)

HISTORIQUE

zip_file_add() et zip_file_replace() ont été ajoutées dans libzip 0.11.
