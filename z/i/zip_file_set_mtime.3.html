Paquet: libzip

Licences: BSD

ZIP_FILE_SET_MTIME(3) Manuel des fonctions de bibliothèque ZIP_FILE_SET_MTIME(3)

NOM

zip_file_set_dostime, zip_file_set_mtime — définir l'heure de dernière modification (mtime) pour un fichier dans une archive zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

int
zip_file_set_dostime(zip_t *archive, zip_uint64_t index, zip_uint16_t dostime, zip_uint16_t dosdate, zip_flags_t flags);

int
zip_file_set_mtime(zip_t *archive, zip_uint64_t index, time_t mtime, zip_flags_t flags);

DESCRIPTION

La fonction zip_file_set_mtime() définit l'heure de dernière modification (mtime) pour le fichier à la position index dans l'archive zip à mtime. Actuellement, aucun support pour des flags n'est implémenté.

Dans l'archive zip, l'heure et la date sont enregistrées sous forme de deux entiers de 16 bits. Pour définir les valeurs directement, appelez la fonction zip_file_set_dostime(). Les valeurs des octets de temps sont définies comme suit :

0-4
secondes divisées par deux (1-2 = 1, 3-4 = 2, ...)
5-10
minute (0-59)
11-15
heure (0-23)

Les valeurs des octets de date sont définies comme suit :

0-4
jour du mois (1-31)
5-8
mois (Janvier = 1, Février = 2, ...)
9-15
année offset depuis 1980 (1980 = 0, 1981 = 1, ...)

VALEURS DE RETOUR

En cas de succès, 0 est retourné. Sinon, -1 est retourné et les informations d'erreur dans archive sont définies pour indiquer l'erreur.

ERREURS

zip_file_set_dostime() et zip_file_set_mtime() échouent si :

[ZIP_ER_INVAL]
index n'est pas un index de fichier valide dans archive.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.
[ZIP_ER_OPNOTSUPP]
Le chiffrement traditionnel PKWare utilise le mtime du fichier, par conséquent il ne peut pas être modifié sans ré-encoder les données.
[ZIP_ER_RDONLY]
L'archive a été ouverte en mode lecture seule.

VOIR AUSSI

libzip(3), zip_stat(3)

HISTORIQUE

La fonction zip_file_set_mtime() a été ajoutée dans libzip 1.0. La fonction zip_file_set_dostime() a été ajoutée dans libzip 1.6.

AUTEURS

Dieter Baron <dillo@nih.at> et Thomas Klausner <wiz@gatalith.at>

CAVEATS

Conformément à la pratique historique, la fonction zip_file_set_mtime() traduit l'heure de l'archive zip vers le fuseau horaire local. Si vous souhaitez éviter cela, utilisez plutôt la fonction zip_file_set_dostime().
