NOM

ziproxylogtool - un analyseur de logs de bas niveau

SYNTAXE

ziproxylogtool [options_générales] [options_filtrage]

DESCRIPTION

ziproxylogtool est un analyseur de logs de bas niveau, son but est d'être appelé par des scripts. Il est censé être raisonnablement rapide et générique.

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

OPTIONS GÉNÉRALES

-m, --mode mode
Mode de sortie : 
"g" - Statistiques globales
"h" - Statistiques par hôte (accès, octets_entrants, octets_sortants, taux de compression %, nom d'hôte)
"f" - Mode filtre (filtrer les entrées de log selon les options de filtrage)
-i, --in-file nom_fichier
Fichier d'entrée (fichier de log Ziproxy). Si non spécifié, utilise stdin.
-o, --out-file nom_fichier
Fichier de sortie (sortie des statistiques). Si non spécifié, utilise stdout.
-h, --help
Afficher l'aide résumée

OPTIONS DE FILTRAGE

Si omises, elles ne seront pas appliquées.

-1, --epoch-min epoch_unix
Filtrer les entrées à partir de cette epoch.
-2, --epoch-max epoch_unix
Filtrer les entrées plus anciennes que cette epoch.
-3, --bytes-in-min octets
Filtrer les entrées dont incoming_bytes >= <octets>
-4, --bytes-in-max octets
Filtrer les entrées dont incoming_bytes < <octets>
-5, --bytes-out-min octets
Filtrer les entrées dont outgoing_bytes >= <octets>
-6, --bytes-out-max octets
Filtrer les entrées dont outgoing_bytes < <octets>
-7, --delay-min milisecondes
Filtrer les entrées dont le délai >= <milisecondes>
-8, --delay-max milisecondes
Filtrer les entrées dont le délai < <milisecondes>
