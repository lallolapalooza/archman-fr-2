zip_error_set(3)

Paquet: libzip

Licences: BSD

ZIP_ERROR_SET(3) Manuel des fonctions de bibliothèque ZIP_ERROR_SET(3)

NOM

zip_error_set — remplir la structure zip_error

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

void
zip_error_set(zip_error_t *ze, int le, int se);

DESCRIPTION

La fonction zip_error_set() définit l'erreur zip pointée par ze au code d'erreur libzip le et au code d'erreur système se.

ze doit être alloué et initialisé avec zip_error_init(3) avant d'appeler zip_error_set().

VOIR AUSSI

libzip(3), zip_error_init(3), zip_error_set_from_source(3)

HISTORIQUE

zip_error_set() a été ajoutée dans libzip 1.0.
