NOM

zip_get_archive_comment — obtenir le commentaire d'une archive zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

const char *
zip_get_archive_comment(zip_t *archive, int *lenp, zip_flags_t flags);

DESCRIPTION

La fonction zip_get_archive_comment() retourne le commentaire de l'archive zip entière. La valeur de retour est encodée en UTF-8 sauf si ZIP_FL_ENC_RAW a été spécifié (voir ci-dessous). Ce pointeur ne doit pas être modifié ni libéré avec free(3), et devient invalide lorsque archive est fermé. Si lenp n'est pas NULL, l'entier pointé par celui-ci sera défini à la longueur du commentaire. Si flags est défini à ZIP_FL_UNCHANGED, le commentaire original non modifié est retourné.

De plus, les flags suivants sont supportés :

ZIP_FL_ENC_RAW
Retourne le commentaire d'archive non modifié tel qu'il est dans l'archive ZIP.
ZIP_FL_ENC_GUESS
(Par défaut.) Devine l'encodage du commentaire d'archive dans l'archive ZIP et le convertit en UTF-8, si nécessaire. (Seuls CP-437 et UTF-8 sont reconnus.)
ZIP_FL_ENC_STRICT
Suit la spécification ZIP pour les noms de fichiers et l'étend au commentaire d'archive, s'attendant donc également à ce qu'il soit en encodage CP-437. Le convertit en UTF-8.
Note : ASCII est un sous-ensemble de CP-437 et de UTF-8.

VALEURS DE RETOUR

En cas de succès, un pointeur vers le commentaire est retourné, ou NULL s'il n'y a pas de commentaire.

VOIR AUSSI

libzip(3), zip_file_get_comment(3)

HISTORIQUE

zip_get_archive_comment() a été ajouté dans libzip 0.7. Dans libzip 0.11, le type de flags a été changé de int à zip_flags_t.
