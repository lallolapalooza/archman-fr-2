zip_fopen_index(3)

Paquet: libzip

Licences: BSD

ZIP_FOPEN(3) Manuel des fonctions de bibliothèque ZIP_FOPEN(3)

NOM

zip_fopen, zip_fopen_index — ouvrir un fichier dans une archive zip en lecture

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

zip_file_t *
zip_fopen(zip_t *archive, const char *fname, zip_flags_t flags);

zip_file_t *
zip_fopen_index(zip_t *archive, zip_uint64_t index, zip_flags_t flags);

DESCRIPTION

La fonction zip_fopen() ouvre le fichier nommé fname dans archive. L'argument flags spécifie comment la recherche du nom doit être effectuée, selon les valeurs décrites dans zip_name_locate(3). De plus, les valeurs suivantes peuvent être ouées à celui-ci.

ZIP_FL_COMPRESSED
Lit les données compressées. Sinon, les données sont décompressées par zip_fread().
ZIP_FL_UNCHANGED
Lit les données originales de l'archive zip, en ignorant toute modification apportée au fichier ; ceci n'est pas pris en charge par toutes les sources de données.

La fonction zip_fopen_index() ouvre le fichier à la position index.

Si des données chiffrées sont rencontrées, les fonctions appellent zip_fopen_encrypted(3) ou zip_fopen_index_encrypted(3) respectivement, en utilisant le mot de passe par défaut défini avec zip_set_default_password(3).

VALEURS DE RETOUR

En cas de succès, un pointeur vers une struct zip_file est retourné. Sinon, NULL est retourné et le code d'erreur dans archive est défini pour indiquer l'erreur.

ERREURS

[ZIP_ER_CHANGED]
Les données du fichier ont été modifiées et la source de données ne prend pas en charge la relecture des données.
[ZIP_ER_COMPNOTSUPP]
La méthode de compression utilisée n'est pas prise en charge.
[ZIP_ER_ENCRNOTSUPP]
La méthode de chiffrement utilisée n'est pas prise en charge.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.
[ZIP_ER_NOPASSWD]
Le fichier est chiffré, mais aucun mot de passe n'a été fourni.
[ZIP_ER_READ]
Une erreur de lecture de fichier s'est produite.
[ZIP_ER_SEEK]
Une erreur de recherche de fichier s'est produite.
[ZIP_ER_WRONGPASSWD]
Le mot de passe fourni ne correspond pas au mot de passe utilisé pour le chiffrement. Notez que certains mots de passe incorrects ne sont pas détectés par la vérification effectuée par zip_fopen().
[ZIP_ER_ZLIB]
L'initialisation du flux zlib a échoué.

La fonction zip_fopen() peut également échouer et définir zip_err pour toute erreur spécifiée pour la routine zip_name_locate(3).

La fonction zip_fopen_index() peut également échouer avec ZIP_ER_INVAL si index est invalide.

VOIR AUSSI

libzip(3), zip_fclose(3), zip_fread(3), zip_fseek(3), zip_get_num_entries(3), zip_name_locate(3), zip_set_default_password(3)

HISTORIQUE

zip_fopen() et zip_fopen_index() ont été ajoutées dans libzip 1.0.
