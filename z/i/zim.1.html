ZIM(1) Commandes utilisateur ZIM(1)

NOM

zim - Éditeur de Wiki de bureau

SYNTAXE

usage: zim [OPTIONS] [CARNET [LIEN_PAGE]]
ou: zim --gui [OPTIONS] [CARNET [LIEN_PAGE]]
ou: zim --server [OPTIONS] [CARNET]
ou: zim --export [OPTIONS] CARNET [PAGE]
ou: zim --import [OPTIONS] CARNET PAGE FICHIERS
ou: zim --search [OPTIONS] CARNET REQUÊTE
ou: zim --index [OPTIONS] CARNET
ou: zim --plugin PLUGIN [ARGUMENTS]
ou: zim --manual [OPTIONS] [LIEN_PAGE]
ou: zim --help

CARNET peut être un chemin de fichier local, une URI de fichier local ou un nom de carnet PAGE peut être un nom de page entièrement spécifié PAGE_LIEN est un nom de page entièrement spécifié éventuellement étendu avec un ID d'ancre

DESCRIPTION

Zim est un éditeur de texte graphique utilisé pour maintenir une collection de pages wiki. Chaque page peut contenir des liens vers d'autres pages, un formatage simple et des images. Les pages sont stockées dans une structure de dossiers, comme dans un planificateur, et peuvent avoir des pièces jointes. La création d'une nouvelle page est aussi facile que de créer un lien vers une page inexistante. Toutes les données sont stockées dans des fichiers texte brut avec un formatage wiki. Divers plugins fournissent des fonctionnalités supplémentaires, comme un gestionnaire de listes de tâches, un éditeur d'équations, une icône de zone de notification et la prise en charge du contrôle de version.

Zim peut être utilisé pour :

•
Conserver une archive de notes
•
Conserver un journal quotidien ou hebdomadaire
•
Prendre des notes lors de réunions ou de conférences
•
Organiser des listes de tâches
•
Rédiger des brouillons d'articles de blog et d'e-mails
•
Faire du brainstorming

OPTIONS

Options générales :
--gui exécute l'éditeur (c'est le comportement par défaut)
--server exécute le serveur web
--export exporter vers un format différent
--import importer un ou plusieurs fichiers dans un carnet
--search lancer une requête de recherche sur un carnet
--index construire un index pour un carnet
--plugin appeler une fonction de plugin spécifique
--manual ouvrir le manuel de l'utilisateur
-V, --verbose afficher des informations dans le terminal
-D, --debug afficher les messages de débogage
-v, --version afficher la version et quitter
-h, --help afficher ce texte

Options de l'interface graphique :
--list afficher la liste des carnets au lieu de
ouvrir le carnet par défaut
--geometry taille et position de la fenêtre au format LxA+X+Y
--fullscreen démarrer en mode plein écran
--non-unique démarrer un nouveau processus, ne pas se connecter à un processus existant
--standalone démarrer un nouveau processus par carnet, implique --non-unique

Options du serveur :
--port port à utiliser (par défaut 8080)
--template nom ou chemin du modèle à utiliser
--private servir uniquement à localhost
--gui exécuter le wrapper graphique pour le serveur

Options d'exportation :
-o, --output répertoire de sortie (option obligatoire)
--format format à utiliser (par défaut 'html')
--template nom ou chemin du modèle à utiliser
--root-url URL à utiliser pour la racine du document
--index-page nom de la page d'index
-r, --recursive lors de l'exportation d'une page, exporter également les sous-pages
-s, --singlefile exporter toutes les pages vers un seul fichier de sortie
-O, --overwrite forcer l'écrasement des fichiers existants

Options d'importation :
--format format à lire (par défaut 'wiki')
--assubpage importer les fichiers comme sous-pages de PATH, c'est implicitement vrai
quand PATH se termine par un ":" ou quand plusieurs fichiers sont donnés

Options de recherche :
-s, --with-scores afficher le score pour chaque page, trier par score

Options d'indexation :
-f, --flush vider l'index d'abord et forcer la reconstruction

Essayez 'zim --manual' pour plus d'aide.
