NOM

zip_source — structure de source de données zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNOPSIS

#include <zip.h>

zip_source_t *source;

DESCRIPTION

Un zip_source_t représente une source de données (ou une destination lors de l'écriture). libzip(3) l'utilise pour ajouter ou remplacer le contenu d'un fichier dans une archive zip. Si la source supporte la recherche, elle peut également être utilisée pour ouvrir des archives zip à partir de celles-ci.

Les données peuvent provenir d'un fichier sur disque (zip_source_file(3), zip_source_file_create(3), zip_source_filep(3), ou zip_source_filep_create(3)), de la mémoire (zip_source_buffer(3), zip_source_buffer_create(3), zip_source_buffer_fragment(3), ou zip_source_buffer_fragment_create(3)), d'un fichier à l'intérieur d'une archive (zip_source_zip(3)), ou fournies via une fonction de rappel (zip_source_function(3) ou zip_source_function_create(3)). zip_source_window(3) ou zip_source_window_create(3) peuvent être utilisés pour restreindre l'accès à une partie des données contenues.

Ils peuvent également être utilisés comme filtre pour traiter les données fournies par un zip_source_t sous-jacent (par exemple, pour les compresser ou calculer une somme de contrôle), créés avec zip_source_layered(3) ou zip_source_layered_create(3)).

Les sources sont libérées avec zip_source_free(3).

Les sources doivent supporter la lecture et peuvent optionnellement supporter la recherche et l'écriture.

zip_source_t est compté par référence, et créé avec un compteur de références de 1. zip_open_from_source(3), zip_file_add(3), et zip_file_replace(3) prendront possession de la source passée (décrémenteront le compteur de références lorsqu'ils auront fini de l'utiliser), donc zip_source_free(3) ne devra être appelée que lorsque ces fonctions retournent une erreur. Les données sous-jacentes (fichier ou tampon) doivent rester valides jusqu'à ce que l'archive soit fermée. Utilisez zip_source_keep(3) pour augmenter le compteur de références, par exemple si vous avez besoin de la source après la fermeture de l'archive avec zip_close(3).
