zip_add(3)

Paquet: libzip

Licences: BSD

ZIP_ADD(3) Manuel des fonctions de bibliothèque ZIP_ADD(3)

NOM

zip_add, zip_replace — ajouter un fichier à une archive zip ou remplacer un fichier dans une archive zip (interface obsolète)

BIBLIOTHEQUE

libzip (-lzip)

SYNOPSIS

#include <zip.h>

zip_int64_t
zip_add(zip_t *archive, const char *name, zip_source_t *source);

int
zip_replace(zip_t *archive, zip_uint64_t index, zip_source_t *source);

DESCRIPTION

La fonction zip_add() est la version obsolète de zip_file_add(3). Elle est identique à l'appel de zip_file_add(3) avec un argument flags vide. De même, la fonction zip_replace() est la version obsolète de zip_file_replace(3). Elle est identique à l'appel de zip_file_replace(3) avec un argument flags vide.

VOIR AUSSI

libzip(3), zip_file_add(3), zip_file_replace(3)

HISTORIQUE

zip_add() a été ajoutée dans libzip 0.6. Dans libzip 0.10, le type de retour a été modifié de int à zip_int64_t. Elle a été dépréciée dans libzip 0.11, utilisez zip_file_add() à la place.

zip_replace() a été ajoutée dans libzip 0.6. Dans libzip 0.10, le type de index a été modifié de int à zip_uint64_t. Elle a été dépréciée dans libzip 0.11, utilisez zip_file_replace() à la place.
