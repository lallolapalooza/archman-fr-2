NOM

zip_source_layered, zip_source_layered_create — créer une source de données superposée à partir d'une fonction

BIBLIOTHÈQUE

libzip (-lzip)

SYNOPSIS

#include <zip.h>

zip_source_t *
zip_source_layered(zip_t *archive, zip_source_t *source, zip_source_layered_callback fn, void *userdata);

zip_source_t *
zip_source_layered_create(zip_source_t *source, zip_source_layered_callback fn, void *userdata, zip_error_t *error);

DESCRIPTION

Les fonctions zip_source_layered() et zip_source_layered_create() créent une source zip superposée à partir de la fonction fournie par l'utilisateur fn, qui doit être du type suivant :

typedef zip_int64_t (*p_source_layered_callback)(zip_source_t *source, void *userdata, void *data, zip_uint64_t length, zip_source_cmd_t cmd);

archive ou error sont utilisés pour signaler les erreurs et peuvent être NULL.

Lorsqu'elle est appelée par la bibliothèque, le premier argument est la source de la couche inférieure, le second argument est l'argument userdata fourni à la fonction. Les deux arguments suivants sont un tampon data de taille length lorsque des données sont transmises ou attendues en retour, sinon NULL et 0. Le dernier argument, cmd, spécifie l'action que la fonction doit effectuer.

Voir zip_source_function(3) pour une description des commandes.

Une source superposée transforme les données ou les métadonnées de la source inférieure d'une manière ou d'une autre. Les sources superposées ne peuvent pas prendre en charge l'écriture et ne sont pas suffisantes pour ajouter proprement la prise en charge de méthodes de compression ou de chiffrement supplémentaires. Cela peut être révisé dans une version ultérieure de libzip.

En cas de succès, la source superposée prend possession de source. L'appelant ne doit pas la libérer.

L'interaction avec la couche inférieure dépend de la commande :

ZIP_SOURCE_ACCEPT_EMPTY

Si la source superposée prend en charge cette commande, la couche inférieure n'est pas appelée automatiquement. Sinon, la valeur de retour de la source inférieure est utilisée.

ZIP_SOURCE_CLOSE

La couche inférieure est fermée après le retour du rappel.

ZIP_SOURCE_ERROR

La couche inférieure n'est pas appelée automatiquement. Si vous devez récupérer des informations d'erreur de la couche inférieure, utilisez zip_error_set_from_source(3) ou zip_source_pass_to_lower_layer(3).

ZIP_SOURCE_FREE

La couche inférieure est libérée après le retour du rappel.

ZIP_SOURCE_GET_FILE_ATTRIBUTES

Les attributs de la couche inférieure sont fusionnés avec les attributs renvoyés par le rappel : les informations définies par le rappel l'emportent sur la couche inférieure, à l'exception suivante : la plus haute version_needed est utilisée, et general_purpose_bit_flags sont seulement écrasés si le bit correspondant est défini dans general_purpose_bit_mask.

ZIP_SOURCE_OPEN

La couche inférieure est ouverte avant que le rappel ne soit appelé.

ZIP_SOURCE_READ

La couche inférieure n'est pas appelée automatiquement.

ZIP_SOURCE_SEEK

La couche inférieure n'est pas appelée automatiquement.

ZIP_SOURCE_STAT

data contient les informations de statut de la couche inférieure lorsque le rappel est appelé.

ZIP_SOURCE_SUPPORTS

data contient le masque de bits des commandes prises en charge par la couche inférieure lorsque le rappel est appelé. Étant donné que les sources superposées ne peuvent pas prendre en charge l'écriture, toutes les commandes relatives à l'écriture sont supprimées du masque de support renvoyé.

ZIP_SOURCE_TELL

La couche inférieure n'est pas appelée automatiquement.

VALEURS DE RETOUR

En cas de succès, la source créée est renvoyée. Sinon, NULL est renvoyé et le code d'erreur dans archive ou error est défini pour indiquer l'erreur (sauf s'il est NULL).

ERREURS

zip_source_layered() échoue si :

[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.

VOIR AUSSI

libzip(3), zip_file_add(3), zip_file_attributes_init(3), zip_file_replace(3), zip_source(5), zip_source_function(3), zip_source_pass_to_lower_layer(3)

zip_source_layered_create(3)

NAME

zip_source_layered_create â€” create a layered zip source

LIBRARY

libzip, libzip/zip.h

SYNOPSIS

#include <zip.h>

struct zip_source *
zip_source_layered_create(struct zip_t *za,
    struct zip_source *source,
    zip_error_t *error);

DESCRIPTION

The function zip_source_layered_create() creates a new zip source for layer on top of an existing zip source. This is useful for implementing custom source logic that needs to wrap existing zip source implementations.

The source parameter is the underlying zip source that the new layered source will wrap. The new layered source will call the methods of the source parameter when needed.

See zip_source_layered(3) for more information on layered zip sources.

RETURN VALUES

On success, the newly created layered zip source is returned. On failure, NULL is returned and the error is set in error.

ERRORS

ZIP_ER_INVAL
The parameter za or source was NULL.
ZIP_ER_MEMORY
There was not enough memory to create the layered zip source.

SEE ALSO

zip_source(3), zip_source_layered(3), zip_source_function(3), zip_source_file(3), zip_open_from_source(3)

HISTORY

zip_source_layered_create() was added in libzip 1.10.

NOM

zip_source_layered â€” créer une source zip superposée

BIBLIOTHÈQUE

libzip, libzip/zip.h

SYNOPIS

#include <zip.h>

struct zip_source *
zip_source_layered(struct zip_t *za,
    struct zip_source *source,
    zip_error_t *error);

DESCRIPTION

La fonction zip_source_layered() crée une nouvelle source zip pour superposer une source zip existante. Ceci est utile pour implémenter une logique de source personnalisée qui doit encapsuler des implémentations de source zip existantes.

Le paramètre source est la source zip sous-jacente que la nouvelle source superposée encapsulera. La nouvelle source superposée appellera les méthodes du paramètre source lorsque nécessaire.

Voir zip_source_layered_create(3) pour plus d'informations sur les sources zip superposées.

VALEURS DE RETOUR

En cas de succès, la nouvelle source zip superposée créée est retournée. En cas d'échec, NULL est retourné et l'erreur est définie dans error.

ERREURS

ZIP_ER_INVAL
Le paramètre za ou source était NULL.
ZIP_ER_MEMORY
Il n'y avait pas assez de mémoire pour créer la source zip superposée.

VOIR AUSSI

zip_source(3), zip_source_layered_create(3), zip_source_function(3), zip_source_file(3), zip_open_from_source(3)
