Paquet: libzip

Licences: BSD

ZIP_SOURCE_ZIP_FILE(3) Manuel des fonctions de bibliothèque ZIP_SOURCE_ZIP_FILE(3)

NOM

zip_source_zip_file, zip_source_zip_file_create — créer une source de données à partir d'un fichier zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

zip_source_t *
zip_source_zip_file(zip_t *archive, zip_t *srcarchive, zip_uint64_t srcidx, zip_flags_t flags, zip_uint64_t start, zip_int64_t length, const char *password);

zip_source_t *
zip_source_zip_file_create(zip_t *srcarchive, zip_uint64_t srcidx, zip_flags_t flags, zip_uint64_t start, zip_int64_t length, const char *password, zip_error_t *error);

DESCRIPTION

Les fonctions zip_source_zip_file() et zip_source_zip_file_create() créent une source zip à partir d'un fichier dans une archive zip. L'argument srcarchive est l'archive zip (ouverte) contenant le fichier zip source à l'index srcidx. length octets à partir de l'offset start seront utilisés dans la zip_source. Si length est -1, le reste du fichier, à partir de start, est utilisé.

Si vous avez l'intention de copier un fichier d'une archive à une autre, l'utilisation du drapeau ZIP_FL_COMPRESSED est plus efficace, car elle évite de recompresser les données du fichier.

Les drapeaux pris en charge sont :

ZIP_FL_COMPRESSED
Obtenir les données compressées. Ceci n'est pris en charge que si toutes les données du fichier sont demandées (start == 0 et length == -1). Ceci n'est pas pris en charge pour les données modifiées. Par défaut, les données sont décompressées.
ZIP_FL_ENCRYPTED
Obtenir les données chiffrées. (Ce drapeau implique ZIP_FL_COMPRESSED.) Ceci n'est pris en charge que si toutes les données du fichier sont demandées (start == 0 et length == -1). Par défaut, les données sont déchiffrées.
ZIP_FL_UNCHANGED
Essayer d'obtenir les données originales sans aucune modification qui aurait pu être apportée à srcarchive après son ouverture.

VALEURS DE RETOUR

En cas de succès, la source créée est retournée. Sinon, NULL est retourné et le code d'erreur dans archive ou error est défini pour indiquer l'erreur.

ERREURS

zip_source_zip_file() et zip_source_zip_file_create() échouent si :

[ZIP_ER_CHANGED]
Des données inchangées ont été demandées, mais elles ne sont pas disponibles.
[ZIP_ER_INVAL]
srcarchive, srcidx, start, ou length sont invalides.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.
De plus, elles peuvent retourner tous les codes d'erreur de zip_stat_index() et zip_fopen_index().

VOIR AUSSI

libzip(3), zip_file_add(3), zip_file_replace(3), zip_source(5)

HISTORIQUE

zip_source_zip_file() et zip_source_zip_file_create() ont été ajoutées dans libzip 1.10.0.
