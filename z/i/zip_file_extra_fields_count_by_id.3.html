zip_file_extra_fields_count_by_id(3)

Paquet: libzip

Licences: BSD

ZIP_FILE_EXTRA_FIELDS_COUNT(3) Manuel des fonctions de bibliothèque ZIP_FILE_EXTRA_FIELDS_COUNT(3)

NOM

zip_file_extra_fields_count, zip_file_extra_fields_count_by_id — compte les champs supplémentaires pour un fichier dans une archive zip

BIBLIOTHEQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

zip_int16_t
zip_file_extra_fields_count(zip_t *archive, zip_uint64_t index, zip_flags_t flags);

zip_int16_t
zip_file_extra_fields_count_by_id(zip_t *archive, zip_uint64_t index, zip_uint16_t extra_field_id, zip_flags_t flags);

DESCRIPTION

La fonction zip_file_extra_fields_count() compte les champs supplémentaires pour le fichier à la position index dans l'archive zip.

Les flags suivants sont supportés :

ZIP_FL_CENTRAL
Compte les champs supplémentaires du répertoire central de l'archive.
ZIP_FL_LOCAL
Compte les champs supplémentaires des en-têtes de fichier locaux.
ZIP_FL_UNCHANGED
Compte les champs supplémentaires originaux non modifiés, ignorant toute modification apportée.

La fonction zip_file_extra_fields_count_by_id() compte les champs supplémentaires avec l'identifiant (signature de deux octets) extra_field_id. Les autres arguments sont identiques à ceux de zip_file_extra_fields_count().

Les champs supplémentaires qui sont identiques dans le répertoire central et l'en-tête de fichier local sont fusionnés en un seul. Par conséquent, les comptes avec ZIP_FL_CENTRAL et ZIP_FL_LOCAL n'ont pas besoin de s'ajouter pour obtenir la même valeur que lorsqu'on donne ZIP_FL_CENTRAL|ZIP_FL_LOCAL simultanément.

VALEUR DE RETOUR

En cas de succès, le nombre demandé de champs supplémentaires est retourné. Sinon, -1 est retourné et le code d'erreur dans archive est défini pour indiquer l'erreur.

ERREURS

zip_file_extra_fields_count() et zip_file_extra_fields_count_by_id() échouent si :

[ZIP_ER_NOENT]
index n'est pas un index de fichier valide dans archive.

VOIR AUSSI

libzip(3), zip_file_extra_field_delete(3), zip_file_extra_field_get(3), zip_file_extra_field_set(3)

HISTORIQUE

zip_file_extra_fields_count() et zip_file_extra_fields_count_by_id() ont été ajoutées dans libzip 0.11.
