NOM

zip_source_tell_write — indiquer la position d'écriture actuelle dans une source zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNOPSIS

#include <zip.h>

zip_int64_t
zip_source_tell_write(zip_source_t *source);

DESCRIPTION

La fonction zip_source_tell_write() retourne la position d'écriture actuelle pour source. La valeur de retour peut être passée à zip_source_seek_write(3) avec whence réglé à SEEK_SET pour revenir au même emplacement dans la source.

VALEURS DE RETOUR

En cas de succès, la position d'écriture actuelle est retournée. Sinon, -1 est retourné et les informations d'erreur dans source sont définies pour indiquer l'erreur.

VOIR AUSSI

libzip(3), zip_source(5), zip_source_begin_write(3), zip_source_commit_write(3), zip_source_rollback_write(3), zip_source_tell(3), zip_source_write(3)

HISTORIQUE

zip_source_tell_write() a été ajoutée dans libzip 1.0.
