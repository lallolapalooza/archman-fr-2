zip_source_win32handle_create(3)

Paquet: libzip

Licences: BSD

ZIP_SOURCE_WIN32HANDLE(3) Manuel des fonctions de bibliothèque ZIP_SOURCE_WIN32HANDLE(3)

NOM

zip_source_win32handle, zip_source_win32handle_create — créer une source de données à partir d'un descripteur de fichier Windows

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

zip_source_t *
zip_source_win32handle(zip_t *archive, HANDLE h, zip_uint64_t start, zip_int64_t len);

zip_source_t *
zip_source_win32handle_create(HANDLE h, zip_uint64_t start, zip_int64_t len, zip_error_t *error);

DESCRIPTION

Les fonctions zip_source_win32handle() et zip_source_win32handle_create() créent une source zip à partir d'un descripteur de fichier Windows. Elles lisent len octets à partir de l'offset start de celui-ci. Si len est 0 ou -1, le fichier entier (à partir de start) est utilisé.

Si le fichier supporte la recherche, la source peut être utilisée pour ouvrir une archive zip.

Le fichier est ouvert et lu lorsque les données de la source sont utilisées, généralement par zip_close() ou zip_open_from_source().

VALEURS DE RETOUR

En cas de succès, la source créée est retournée. Sinon, NULL est retourné et le code d'erreur dans archive ou error est défini pour indiquer l'erreur.

ERREURS

zip_source_w32handle() et zip_source_w32handle_create() échouent si :

[ZIP_ER_INVAL]
h, start, ou len sont invalides.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.

VOIR AUSSI

libzip(3), zip_file_add(3), zip_file_replace(3), zip_source(5), zip_source_win32a(3), zip_source_win32w(3)

HISTORIQUE

zip_source_win32handle() et zip_source_win32handle_create() ont été ajoutées dans libzip 1.0.
