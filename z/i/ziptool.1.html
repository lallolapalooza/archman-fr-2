ZIPTOOL(1) Manuel des commandes générales ZIPTOOL(1)

NOM

ziptool — modifier les archives zip

SYNTAXE

ziptool [-ceghnrst] [-l longueur] [-o décalage] archive-zip commande [args-commande ...] [commande [args-commande ...] ...]

DESCRIPTION

ziptool modifie l'archive zip archive-zip conformément aux commandes fournies.

Options supportées :

-c
Vérifie la cohérence de l'archive zip lors de son ouverture.
-e
Erreur si l'archive existe déjà (uniquement utile avec -n).
-g
Devine le codage du nom de fichier (pour la commande stat).
-h
Affiche l'aide.
-l longueur
Lit seulement longueur octets de l'archive. Voir aussi -o.
-n
Crée l'archive si elle n'existe pas. Voir aussi -e.
-o décalage
Commence à lire l'archive d'entrée à partir du décalage. Voir aussi -l.
-r
Affiche le codage brut du nom de fichier sans traduction (pour la commande stat).
-s
Suit strictement la convention de nom de fichier (pour la commande stat).
-t
Ignore le contenu actuel du fichier, le cas échéant. Note : utilisez cette option avec précaution, elle supprime tout contenu de fichier existant lorsque vous modifiez l'archive.

Commandes

Pour toutes les commandes ci-dessous, l'index est basé sur zéro. En d'autres termes, la première entrée dans l'archive zip a l'index 0.

Commandes et arguments supportés :

ajouter nom contenu
Ajoute un fichier nommé nom en utilisant la chaîne contenu de la ligne de commande comme données.
ajouter_répertoire nom
Ajoute le répertoire nom.
ajouter_fichier nom fichier_à_ajouter décalage longueur
Ajoute le fichier nom à l'archive, en utilisant longueur octets du fichier fichier_à_ajouter comme données d'entrée, en commençant à l'décalage.
ajouter_depuis_zip nom nom_archive index décalage longueur
Ajoute un fichier nommé nom à l'archive en utilisant les données d'une autre archive zip nom_archive en utilisant l'entrée avec l'index index et en lisant longueur octets à partir du décalage.
cat index
Affiche le contenu du fichier pour l'entrée index sur la sortie standard.
compter_extras index drapeaux
Affiche le nombre de champs supplémentaires pour l'entrée d'archive index en utilisant les drapeaux.
compter_extras_par_id index id_extra drapeaux
Affiche le nombre de champs supplémentaires de type id_extra pour l'entrée d'archive index en utilisant les drapeaux.
supprimer index
Supprime l'entrée à l'index de l'archive zip.
supprimer_extra index idx_extra drapeaux
Supprime le champ supplémentaire numéro idx_extra de l'entrée d'archive index en utilisant les drapeaux.
supprimer_extra_par_id index id_extra index_extra drapeaux
Supprime le champ supplémentaire numéro index_extra de type id_extra de l'entrée d'archive index en utilisant les drapeaux.
lire_commentaire_archive
Affiche le commentaire de l'archive.
lire_drapeau_archive drapeau
Affiche l'état du drapeau d'archive drapeau.
lire_extra index index_extra drapeaux
Affiche le champ supplémentaire numéro index_extra pour l'entrée d'archive index en utilisant les drapeaux.
lire_extra_par_id index id_extra index_extra drapeaux
Affiche le champ supplémentaire numéro index_extra de type id_extra pour l'entrée d'archive index en utilisant les drapeaux.
lire_commentaire_fichier index
Lit le commentaire de fichier pour l'entrée d'archive index.
compter_entrées drapeaux
Affiche le nombre d'entrées dans l'archive en utilisant les drapeaux.
localiser_nom nom drapeaux
Trouve l'entrée dans l'archive avec le nom de fichier nom en utilisant les drapeaux et affiche son index.
renommer index nom
Renomme l'entrée d'archive index en nom.
remplacer_contenu_fichier index données
Remplace le contenu du fichier pour l'entrée d'archive index par la chaîne données.
définir_commentaire_archive commentaire
Définit le commentaire de l'archive à commentaire.
définir_drapeau_archive drapeau valeur
Définit le drapeau d'archive drapeau à valeur.
définir_extra index id_extra index_extra drapeaux valeur
Définit le champ supplémentaire numéro index_extra de type id_extra pour l'entrée d'archive index en utilisant les drapeaux à valeur.
définir_commentaire_fichier index commentaire
Définit le commentaire de fichier pour l'entrée d'archive index à la chaîne commentaire.
définir_compression_fichier

ziptool(1) — outils d'archive zip

NAME

ziptool — manipuler des archives zip

SYNOPSIS

ziptool archive command [ arguments … ]

DESCRIPTION

L'utilitaire ziptool permet d'interagir avec des archives zip. Vous pouvez l'utiliser pour obtenir des informations sur l'archive, ajouter ou supprimer des fichiers, modifier les propriétés des fichiers, etc.

Les commandes disponibles sont:

add filename [data]
Ajouter un fichier filename à l'archive. Si data est spécifié, le fichier sera créé avec ce contenu, sinon le fichier filename sera lu depuis le disque. Les caractères d'échappement comme `\n` sont interprétés si les données sont citées.
cat index
Imprimer le contenu de l'entrée d'archive à l'index index sur la sortie standard.
delete index
Supprimer l'entrée d'archive à l'index index.
get_archive_flag flag
Obtenir la valeur du drapeau d'archive spécifié par flag.
get_file_compression index
Obtenir la méthode de compression de l'entrée d'archive à l'index index.
get_file_encryption index
Obtenir la méthode de chiffrement de l'entrée d'archive à l'index index.
get_file_mtime index
Obtenir l'heure de modification du fichier de l'entrée d'archive à l'index index.
get_file_size index
Obtenir la taille décompressée du fichier de l'entrée d'archive à l'index index.
get_file_zip_size index
Obtenir la taille compressée du fichier de l'entrée d'archive à l'index index.
list [flags]
Lister toutes les entrées de l'archive. Les flags peuvent être utilisés pour modifier le comportement de listage.
rename index newname
Renommer l'entrée d'archive à l'index index en newname.
set_archive_flag flag value
Définir la valeur du drapeau d'archive spécifié par flag à value.
set_file_comment index comment
Définir le commentaire pour l'entrée d'archive à l'index index à comment.
set_file_compression index method compression_flags
Définir la méthode de compression du fichier pour l'entrée d'archive index à method en utilisant compression_flags. Note: Actuellement, compression_flags sont ignorés.
set_file_encryption index method password
Définir la méthode de chiffrement du fichier pour l'entrée d'archive index à method avec le mot de passe password.
set_file_mtime index timestamp
Définir l'heure de modification du fichier pour l'entrée d'archive index au mtime UNIX timestamp.
set_file_mtime_all timestamp
Définir l'heure de modification du fichier pour toutes les entrées d'archive au mtime UNIX timestamp.
set_password password
Définir le mot de passe par défaut pour le chiffrement/déchiffrement à password.
stat index
Imprimer les informations sur l'entrée d'archive à l'index index.

Flags

Certaines commandes acceptent des arguments de drapeau. Chaque caractère dans l'argument définit le drapeau correspondant. Utilisez 0 ou une chaîne vide pour aucun drapeau.

Les drapeaux pris en charge sont:

4
ZIP_FL_ENC_CP437
8
ZIP_FL_ENC_UTF_8
C
ZIP_FL_NOCASE
c
ZIP_FL_CENTRAL
d
ZIP_FL_NODIR
l
ZIP_FL_LOCAL
r
ZIP_FL_ENC_RAW
s
ZIP_FL_ENC_STRICT
u
ZIP_FL_UNCHANGED

Drapeaux d'archive

get_archive_flag et set_archive_flag agissent sur les drapeaux suivants:

  • create-or-keep-empty-file-for-archive
  • is-torrentzip
  • rdonly
  • want-torrentzip

Méthodes de compression

Certaines commandes acceptent des arguments de méthode de compression. Les méthodes prises en charge sont:

  • default
  • deflate
  • store

Méthodes de chiffrement

Certaines commandes acceptent des arguments de méthode de chiffrement. Les méthodes prises en charge sont:

  • none
  • AES-128
  • AES-192
  • AES-256

STATUS DE SORTIE

L'utilitaire ziptool se termine avec le statut 0 en cas de succès, et >0 en cas d'erreur.

EXEMPLES

Ajouter un fichier nommé teststring.txt à l'archive zip testbuffer.zip avec les données “This is a test.\n” où “\n” est remplacé par un caractère de nouvelle ligne:

ziptool testbuffer.zip add teststring.txt \"This is a test.\n\"

Supprimer le premier fichier de l'archive zip testfile.zip:

ziptool testfile.zip delete 0

VOIR AUSSI

zipcmp(1), zipmerge(1), libzip(3)

HISTORIQUE

ziptool a été ajouté dans libzip 1.1.
