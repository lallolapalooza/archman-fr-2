zip_get_file_comment(3)

Paquet: libzip

Licences: BSD

ZIP_GET_FILE_COMMENT(3) Manuel des fonctions de bibliothèque ZIP_GET_FILE_COMMENT(3)

NOM

zip_get_file_comment — récupérer le commentaire d'un fichier dans une archive zip (interface obsolète)

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

const char *
zip_get_file_comment(zip_t *archive, zip_uint64_t index, int *lenp, int flags);

DESCRIPTION

La fonction zip_get_file_comment() est la version obsolète de zip_file_get_comment(3). Les seules différences concernent les types des arguments lenp et flags.

VOIR AUSSI

libzip(3), zip_file_get_comment(3)

HISTORIQUE

zip_get_file_comment() a été ajoutée dans libzip 0.7. Dans libzip 0.10, le type de index a été changé de int à zip_uint64_t. Elle a été dépréciée dans libzip 0.11, utilisez zip_file_get_comment() à la place.
