Paquet: libzip

Licences: BSD

ZIP_SOURCE_FUNCTION(3) Manuel des fonctions de bibliothèque ZIP_SOURCE_FUNCTION(3)

NOM

zip_source_function, zip_source_function_create — créer une source de données à partir d'une fonction

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

zip_source_t *
zip_source_function(zip_t *archive, zip_source_callback fn, void *userdata);

zip_source_t *
zip_source_function_create(zip_source_callback fn, void *userdata, zip_error_t *error);

DESCRIPTION

Les fonctions zip_source_function() et zip_source_function_create() créent une source zip à partir de la fonction fournie par l'utilisateur fn, qui doit être du type suivant :

typedef zip_int64_t (*zip_source_callback)(void *userdata, void *data, zip_uint64_t len, zip_source_cmd_t cmd);

archive ou error sont utilisés pour signaler les erreurs et peuvent être NULL.

Lorsqu'elle est appelée par la bibliothèque, le premier argument est l'argument userdata fourni à la fonction. Les deux arguments suivants sont un tampon data de taille len lorsque des données sont passées ou attendues en retour, ou bien NULL et 0. Le dernier argument, cmd, spécifie l'action que la fonction doit effectuer.

Selon les utilisations, il existe trois ensembles utiles de commandes à prendre en charge par une zip_source_callback():

source de lecture
Fournit des données en flux (pour les données de fichiers ajoutées aux archives). Doit prendre en charge ZIP_SOURCE_OPEN, ZIP_SOURCE_READ, ZIP_SOURCE_CLOSE, ZIP_SOURCE_STAT, et ZIP_SOURCE_ERROR.

Si votre source utilise de la mémoire allouée (y compris userdata), elle devrait également implémenter ZIP_SOURCE_FREE pour éviter les fuites de mémoire.

source de lecture indexable
Identique à la précédente, mais à partir d'une source permettant la lecture à partir d'offsets arbitraires (également pour une archive zip en lecture seule). Doit en outre prendre en charge ZIP_SOURCE_SEEK, ZIP_SOURCE_TELL, et ZIP_SOURCE_SUPPORTS.
source de lecture/écriture
Identique à la précédente, mais permettant en outre l'écriture (également pour les archives zip modifiables). Doit en outre prendre en charge ZIP_SOURCE_BEGIN_WRITE, ZIP_SOURCE_COMMIT_WRITE, ZIP_SOURCE_ROLLBACK_WRITE, ZIP_SOURCE_SEEK_WRITE, ZIP_SOURCE_TELL_WRITE, et ZIP_SOURCE_REMOVE.

En plus de ce qui précède, la prise en charge de la pseudo-commande ZIP_SOURCE_SUPPORTS_REOPEN permet d'appeler à nouveau zip_source_open() après avoir appelé zip_source_close().

ZIP_SOURCE_ACCEPT_EMPTY

Retourne 1 si une source vide doit être acceptée comme une archive zip valide. C'est le comportement par défaut si cette commande n'est pas prise en charge par une source. Les sources basées sur le système de fichiers devraient retourner 0.

ZIP_SOURCE_BEGIN_WRITE

Prépare la source pour l'écriture. Utilisez ceci pour créer des fichiers temporaires.

ZIP_SOURCE_BEGIN_WRITE_CLONING

Prépare la source pour l'écriture, en conservant les premiers len octets du fichier d'origine. N'implémentez cette commande que si elle est plus efficace que la copie des données, et si elle ne modifie pas le fichier d'origine de manière destructive (vous devez toujours pouvoir exécuter ZIP_SOURCE_ROLLBACK_WRITE).

La prochaine écriture devrait se produire à l'octet offset.

ZIP_SOURCE_CLOSE

La lecture est terminée.

ZIP_SOURCE_COMMIT_WRITE

Termine l'écriture dans la source. Remplace les données d'origine par les données nouvellement écrites. Nettoie les fichiers temporaires ou les tampons internes. La lecture ultérieure à partir de la source devrait retourner les données nouvellement écrites.

ZIP_SOURCE_ERROR

Obtient les informations sur l'erreur. data pointe vers un tableau de deux entiers, qui doivent être remplis avec le code d'erreur libzip et le code d'erreur système correspondant à l'erreur survenue. Voir zip_errors(3) pour les détails sur les codes d'erreur. Si la source stocke des informations d'erreur dans un zip_error_t, utilisez zip_error_to_data(3) et retournez sa valeur de retour. Sinon, retournez 2 * sizeof(int).

ZIP_SOURCE_FREE

Nettoie et libère toutes les ressources, y compris userdata. La fonction de rappel ne sera plus appelée.

ZIP_SOURCE_GET_FILE_ATTRIBUTES

Fournit des informations sur divers éléments de données. Les données doivent ensuite être placées dans l'entrée appropriée de l'argument zip_file_attributes_t passé, et la valeur ZIP_FILE_ATTRIBUTES_* appropriée doit être ajoutée (OR-ed) au membre valid pour indiquer que les données correspondantes ont été fournies. Une structure zip_file_attributes_t peut être initialisée à l'aide de zip_file_attributes_init(3).

Mode ASCII
Si un fichier est un fichier texte en ASCII. Peut être utilisé par les outils d'extraction pour convertir automatiquement les terminaisons de ligne (faisant partie des attributs internes du fichier). Membre ascii, drapeau ZIP_FILE_ATTRIBUTES_ASCII.
Indicateurs généraux de bits (limités aux indicateurs de compression)
L'indicateur général de bits dans le zip des en-têtes de répertoire local et central contient des informations sur la méthode de compression. Membre general_purpose_bit_flags

ZIP_SOURCE_ATTRIBUTES

Get file attributes for the input data. data points to an allocated struct zip_file_attributes, which should be initialized using zip_file_attributes_init(3) and then filled in. All members are optional. The following members can be set:

General Purpose Bit Mask
Used for various features like compression, encryption, and filename encoding. Member general_purpose_bit_mask and general_purpose_bit_mask to denote which members have been set; flag ZIP_FILE_ATTRIBUTES_GENERAL_PURPOSE_BIT_FLAGS.
External File Attributes
The external file attributes (usually operating system-specific). Member external_file_attributes, flag ZIP_FILE_ATTRIBUTES_EXTERNAL_FILE_ATTRIBUTES.
Version Needed
A minimum version needed required to unpack this entry (in the usual "major * 10 + minor" format). Member version_needed, flag ZIP_FILE_ATTRIBUTES_VERSION_NEEDED.
Operating System
One of the operating systems as defined by the ZIP_OPSYS_* variables (see zip.h). This value affects the interpretation of the external file attributes. Member host_system, flag ZIP_FILE_ATTRIBUTES_HOST_SYSTEM.

ZIP_SOURCE_OPEN

Prepare for reading.

ZIP_SOURCE_READ

Read data into the buffer data of size len. Return the number of bytes placed into data on success, and zero for end-of-file.

ZIP_SOURCE_REMOVE

Remove the underlying file. This is called if a zip archive is empty when closed.

ZIP_SOURCE_ROLLBACK_WRITE

Abort writing to the source. Discard written data. Clean up temporary files or internal buffers. Subsequently opening and reading from the source should return the original data.

ZIP_SOURCE_SEEK

Specify position to read next byte from, like fseek(3). Use ZIP_SOURCE_GET_ARGS(3) to decode the arguments into the following struct:

struct zip_source_args_seek {
    zip_int64_t offset;
    int whence;
};

If the size of the source's data is known, use zip_source_seek_compute_offset(3) to validate the arguments and compute the new offset.

ZIP_SOURCE_SEEK_WRITE

Specify position to write next byte to, like fseek(3). See ZIP_SOURCE_SEEK for details.

ZIP_SOURCE_STAT

Get meta information for the input data. data points to an allocated struct zip_stat, which should be initialized using zip_stat_init(3) and then filled in.

For uncompressed, unencrypted data, all information is optional. However, fill in as much information as is readily available.

If the data is compressed, ZIP_STAT_COMP_METHOD, ZIP_STAT_SIZE, and ZIP_STAT_CRC must be filled in.

If the data is encrypted, ZIP_STAT_ENCRYPTION_METHOD, ZIP_STAT_COMP_METHOD, ZIP_STAT_SIZE, and ZIP_STAT_CRC must be filled in.

Information only available after the source has been read (e.g., size) can be omitted in an earlier call. NOTE: zip_source_function() may be called with this argument even after being called with ZIP_SOURCE_CLOSE.

Return sizeof(struct zip_stat) on success.

ZIP_SOURCE_SUPPORTS

Return bitmap specifying which commands are supported. Use zip_source_make_command_bitmap(3). If this command is not implemented, the source is assumed to be a read source without seek support.

ZIP_SOURCE_TELL

Return the current read offset in the source, like ftell(3).

ZIP_SOURCE_TELL_WRITE

Return the current write offset in the source, like ftell(3).

ZIP_SOURCE_WRITE

Write data to the source. Return number of bytes written.

ZIP_SOURCE_SUPPORTS_REOPEN

This command is never actually invoked, support for it signals the ability to handle multiple open/read/close cycles.

Return Values

Commands should return -1 on error. ZIP_SOURCE_ERROR will be called to retrieve the error code. On success, commands return 0, unless specified otherwise in the description above.

Calling Conventions

The library will always issue ZIP_SOURCE_OPEN before issuing ZIP_SOURCE_READ, ZIP_SOURCE_SEEK, or ZIP_SOURCE_TELL. When it no longer wishes to read from this source, it will issue ZIP_SOURCE_CLOSE. If the library wishes to read the data again, it will issue ZIP_SOURCE_OPEN a second time. If the function is unable to provide the data again, it should return -1.

ZIP_SOURCE_BEGIN_WRITE or ZIP_SOURCE_BEGIN_WRITE_CLONING will be called before ZIP_SOURCE_WRITE, ZIP_SOURCE_SEEK_WRITE, or ZIP_SOURCE_TELL_WRITE. When writing is complete, either ZIP_SOURCE_COMMIT_WRITE or ZIP_SOURCE_ROLLBACK_WRITE will be called.

ZIP_SOURCE_ACCEPT_EMPTY, ZIP_SOURCE_GET_FILE_ATTRIBUTES, and ZIP_SOURCE_STAT can be issued at any time.

ZIP_SOURCE_ERROR will only be issued in response to the function returning -1.

ZIP_SOURCE_FREE will be the last command issued; if ZIP_SOURCE_OPEN was called and succeeded, ZIP_SOURCE_CLOSE will be called before ZIP_SOURCE_FREE, and similarly for ZIP_SOURCE_BEGIN_WRITE or ZIP_SOURCE_BEGIN_WRITE_CLONING and ZIP_SOURCE_COMMIT_WRITE or ZIP_SOURCE_ROLLBACK_WRITE.

VALEURS DE RETOUR

Au succès, la source créée est retournée. Sinon, NULL est retourné et le code d'erreur dans archive ou error est défini pour indiquer l'erreur (sauf si c'est NULL).

ERREURS

zip_source_function() échoue si :

[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.
