zip_file_rename(3)

Paquet: libzip

Licences: BSD

ZIP_FILE_RENAME(3) Manuel des fonctions de bibliothèque ZIP_FILE_RENAME(3)

NOM

zip_file_rename — renommer un fichier dans une archive zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNOPSIS

#include <zip.h>

int
zip_file_rename(zip_t *archive, zip_uint64_t index, const char *name, zip_flags_t flags);

DESCRIPTION

Le fichier à la position index dans l'archive zip archive est renommé en name. L'argument flags peut être l'une des valeurs suivantes :

ZIP_FL_ENC_GUESS
Devine l'encodage de name (par défaut). (Seuls CP-437 et UTF-8 sont reconnus.)
ZIP_FL_ENC_UTF_8
Interprète name comme UTF-8.
ZIP_FL_ENC_CP437
Interprète name comme page de code 437 (CP-437).

VALEUR DE RETOUR

En cas de succès, 0 est retourné. Sinon, -1 est retourné et le code d'erreur dans archive est défini pour indiquer l'erreur.

ERREURS

zip_file_rename() échoue si :

[ZIP_ER_DELETED]
Le fichier à renommer a été supprimé de l'archive.
[ZIP_ER_EXISTS]
Il existe déjà un fichier nommé name dans l'archive.
[ZIP_ER_INVAL]
index n'est pas un index de fichier valide dans archive, name est NULL, la chaîne vide, ou n'est pas une chaîne encodée en UTF-8 valide. De plus, un fichier ne peut pas être renommé en répertoire ni vice versa. Les répertoires sont indiqués par une barre oblique finale.

VOIR AUSSI

libzip(3), zip_unchange(3)

HISTORIQUE

zip_file_rename() a été ajouté dans libzip 0.11.
