zip_file_get_external_attributes(3)

Paquet: libzip

Licences: BSD

ZIP_FILE_GET_EXTERNAL_ATTRIBUTES(3) Manuel des fonctions de bibliothèque ZIP_FILE_GET_EXTERNAL_ATTRIBUTES(3)

NOM

zip_file_get_external_attributes — obtient les attributs externes pour un fichier dans une archive zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

int
zip_file_get_external_attributes(zip_t *archive, zip_uint64_t index, zip_flags_t flags, zip_uint8_t *opsys, zip_uint32_t *attributes);

DESCRIPTION

La fonction zip_file_get_external_attributes() renvoie le système d'exploitation et les attributs externes pour le fichier à la position index dans l'archive zip. Les attributs externes contiennent généralement les permissions de fichier spécifiques au système d'exploitation. Si flags est défini sur ZIP_FL_UNCHANGED, les valeurs originales non modifiées sont renvoyées. Si opsys ou attributes sont NULL, ils ne sont pas remplis.

Les systèmes d'exploitation suivants sont définis par la spécification zip :

  • ZIP_OPSYS_ACORN_RISC
  • ZIP_OPSYS_ALTERNATE_MVS
  • ZIP_OPSYS_AMIGA
  • ZIP_OPSYS_ATARI_ST
  • ZIP_OPSYS_BEOS
  • ZIP_OPSYS_CPM
  • ZIP_OPSYS_DOS
  • ZIP_OPSYS_MACINTOSH
  • ZIP_OPSYS_MVS
  • ZIP_OPSYS_OPENVMS
  • ZIP_OPSYS_OS_2
  • ZIP_OPSYS_OS_400
  • ZIP_OPSYS_OS_X
  • ZIP_OPSYS_TANDEM
  • ZIP_OPSYS_UNIX
  • ZIP_OPSYS_VFAT
  • ZIP_OPSYS_VM_CMS
  • ZIP_OPSYS_VSE
  • ZIP_OPSYS_WINDOWS_NTFS (peu commun, utiliser ZIP_OPSYS_DOS à la place)
  • ZIP_OPSYS_Z_SYSTEM

Les définitions ci-dessus suivent l'Appnote de PKWARE Inc. ; veuillez noter que l'Appnote d'InfoZIP a une cartographie légèrement différente.

VALEURS DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné et le code d'erreur dans archive est défini pour indiquer l'erreur.

EXEMPLES

Le code suivant peut être utilisé pour développer attributes si le système d'exploitation est ZIP_OPSYS_DOS.

#include <sys/stat.h>

#define FA_RDONLY       0x01            // FILE_ATTRIBUTE_READONLY
#define FA_DIREC        0x10            // FILE_ATTRIBUTE_DIRECTORY

static mode_t
_zip_dos_attr2mode(zip_uint32_t attr)
{
   mode_t m = S_IRUSR | S_IRGRP | S_IROTH;
   if (0 == (attr & FA_RDONLY))
      m |= S_IWUSR | S_IWGRP | S_IWOTH;

   if (attr & FA_DIREC)
      m = (S_IFDIR | (m & ~S_IFMT)) | S_IXUSR | S_IXGRP | S_IXOTH;

   return m;
}

ERREURS

zip_file_get_external_attributes() échoue si :

[ZIP_ER_INVAL]
L'index n'est pas un index de fichier valide dans archive.
