zip_libzip_version(3)

Paquet: libzip

Licences: BSD

ZIP_LIBZIP_VERSION(3) Manuel des fonctions de bibliothèque ZIP_LIBZIP_VERSION(3)

NOM

zip_libzip_version — retourne la version d'exécution de la bibliothèque

BIBLIOTHÈQUE

libzip (-lzip)

SYNOPIS

#include <zip.h>

const char *
zip_libzip_version(void);

DESCRIPTION

zip_libzip_version retourne le numéro de version de la bibliothèque sous forme de chaîne de caractères dans le format “$MAJOR.$MINOR.$MICRO$SUFFIX” où $MAJOR est la version majeure, $MINOR la mineure, $MICRO la micro, et $SUFFIX un suffixe qui n'est défini que pour les versions de développement.

VOIR AUSSI

libzip(3)

HISTORIQUE

zip_libzip_version() a été ajouté dans libzip 1.3.1.
