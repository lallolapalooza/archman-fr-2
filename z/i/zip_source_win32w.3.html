ZIP_SOURCE_WIN32W(3) Manuel des fonctions de bibliothèque ZIP_SOURCE_WIN32W(3)

NOM

zip_source_win32w, zip_source_win32w_create — créer une source de données à partir d'un nom de fichier Unicode Windows

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

zip_source_t *
zip_source_win32w(zip_t *archive, const wchar_t *fname, zip_uint64_t start, zip_int64_t len);

zip_source_t *
zip_source_win32w_create(const wchar_t *fname, zip_uint64_t start, zip_int64_t len, zip_error_t *error);

DESCRIPTION

Les fonctions zip_source_win32w() et zip_source_win32w_create() créent une source zip sous Windows en utilisant un nom Unicode Windows. Elles ouvrent fname et lisent len octets à partir du décalage start de celui-ci. Pour une description de l'argument len, voir zip_source_file(3).

Si le fichier supporte le déplacement, la source peut être utilisée pour ouvrir une archive zip.

Le fichier est ouvert et lu lorsque les données de la source sont utilisées, généralement par zip_close() ou zip_open_from_source().

VALEUR DE RETOUR

En cas de succès, la source créée est retournée. Sinon, NULL est retourné et le code d'erreur dans archive ou error est défini pour indiquer l'erreur.

ERREURS

zip_source_win32w() et zip_source_win32w_create() échouent si :

[ZIP_ER_INVAL]
fname, start, ou len sont invalides.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.
[ZIP_ER_OPEN]
L'ouverture de fname a échoué.

VOIR AUSSI

libzip(3), zip_file_add(3), zip_file_replace(3), zip_source(5), zip_source_file(3), zip_source_win32a(3), zip_source_win32handle(3)

HISTORIQUE

zip_source_win32w() a été ajoutée dans libzip 1.0.

ZIP_LENGTH_TO_END et ZIP_LENGTH_UNCHECKED ont été ajoutés dans libzip 1.10.1.
