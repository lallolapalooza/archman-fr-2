NOM

zip_file_attributes_init — initialiser la structure des attributs de fichier zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNOPSIS

#include <zip.h>

void
zip_file_attributes_init(zip_file_attributes_t *attributes);

DESCRIPTION

La fonction zip_file_attributes_init() initialise une structure zip_file_attributes_t avec des valeurs par défaut. Elle doit être appelée avant de modifier une telle structure pour la première fois.

VOIR AUSSI

libzip(3), zip_source_function(3)

HISTORIQUE

zip_file_attributes_init() a été ajoutée dans libzip 1.7.0.
