NOM

zipcloak - Chiffre les entrées dans un fichier zip

SYNTAXE

zipcloak [-d] [-b chemin] [-h] [-v] [-L] fichier_zip

ARGUMENTS


fichier_zip Fichier zip dans lequel chiffrer les entrées

OPTIONS

-b chemin
--temp-path chemin
Utilise le répertoire indiqué par chemin pour le fichier zip temporaire.
-d
--decrypt
Déchiffre les entrées chiffrées (copie si le mot de passe est erroné).
-h
--help 
Affiche une brève aide.
-L
--license
Affiche la licence du logiciel.
-O chemin
--output-file fichier_zip
Écrit la sortie dans un nouvel archive fichier_zip, laissant l'archive d'origine intacte.
-q
--quiet
Fonctionnement silencieux. Supprime certains messages d'information.
-v
--version
Affiche les informations de version.

DESCRIPTION

zipcloak chiffre toutes les entrées non chiffrées dans le fichier zip. C'est l'action par défaut.

L'option -d est utilisée pour déchiffrer les entrées chiffrées dans le fichier zip.
zipcloak utilise le chiffrement zip d'origine qui est considéré comme faible.

BOGUES

Les gros fichiers (> 2 Go) et les grosses archives ne sont pas encore pris en charge.

Les archives divisées ne sont pas encore prises en charge. Une solution de contournement consiste à convertir l'archive divisée en une archive unique à l'aide de zip, puis à utiliser zipcloak sur l'archive unique. Si nécessaire, l'archive résultante peut ensuite être divisée à nouveau à l'aide de zip.
