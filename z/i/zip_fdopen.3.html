zip_fdopen(3)

Paquet: libzip

Licences: BSD

ZIP_FDOPEN(3) Manuel des fonctions de bibliothèque ZIP_FDOPEN(3)

NOM

zip_fdopen — ouvre une archive zip en utilisant un descripteur de fichier ouvert

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

zip_t *
zip_fdopen(int fd, int flags, int *errorp);

DESCRIPTION

L'archive zip spécifiée par le descripteur de fichier ouvert fd est ouverte et un pointeur vers une structure zip, utilisée pour manipuler l'archive, est retourné. Contrairement à zip_open(3), en utilisant zip_fdopen, l'archive ne peut être ouverte qu'en mode lecture seule. Le descripteur fd ne doit plus être utilisé après l'appel à zip_fdopen. Les flags sont spécifiés par ouisant les valeurs suivantes, ou 0 pour aucune d'entre elles.

ZIP_CHECKCONS
Effectue des vérifications de cohérence plus strictes supplémentaires sur l'archive, et retourne une erreur si elles échouent.

Si une erreur se produit et que errorp n'est pas non-NULL, il sera défini pour indiquer le code d'erreur correspondant.

VALEURS DE RETOUR

En cas de succès, zip_fdopen() retourne un pointeur vers une structure zip, et fd ne doit plus être utilisé, ni passé à close(2). Sinon, NULL est retourné et *errorp est défini pour indiquer l'erreur. En cas d'erreur, fd reste inchangé.

ERREURS

Le fichier spécifié par fd est préparé pour être utilisé par libzip(3) sauf si :

[ZIP_ER_INCONS]
Des incohérences ont été trouvées dans le fichier spécifié par path. Cette erreur est souvent causée par la spécification de ZIP_CHECKCONS mais peut aussi survenir sans.
[ZIP_ER_INVAL]
L'argument flags est invalide. Tous les drapeaux de zip_open(3) ne sont pas autorisés pour zip_fdopen, voir DESCRIPTION.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.
[ZIP_ER_NOZIP]
Le fichier spécifié par fd n'est pas une archive zip.
[ZIP_ER_OPEN]
Le fichier spécifié par fd n'a pas pu être préparé pour être utilisé par libzip(3).
[ZIP_ER_OPNOTSUPP]
Cette fonctionnalité a été désactivée lors de la compilation.
[ZIP_ER_READ]
Une erreur de lecture s'est produite ; voir errno pour les détails.
[ZIP_ER_SEEK]
Le fichier spécifié par fd n'autorise pas les seek.

VOIR AUSSI

libzip(3), zip_close(3), zip_error_strerror(3), zip_open(3)

HISTORIQUE

zip_fdopen() a été ajouté dans libzip 1.0.
