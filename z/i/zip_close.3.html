zip_close(3)

Paquet: libzip

Licences: BSD

ZIP_CLOSE(3) Manuel des fonctions de bibliothèque ZIP_CLOSE(3)

NOM

zip_close — fermer une archive zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNOPIS

#include <zip.h>

int
zip_close(zip_t *archive);

DESCRIPTION

La fonction zip_close() écrit toutes les modifications apportées à archive sur le disque. Si archive ne contient aucun fichier, le fichier est complètement supprimé (aucune archive vide n'est écrite), sauf si le drapeau d'archive ZIP_AFL_CREATE_OR_KEEP_FILE_FOR_EMPTY_ARCHIVE est défini. En cas de succès, archive est libérée. Sinon, archive reste inchangée et doit toujours être libérée.

Pour fermer et libérer une archive zip sans enregistrer les modifications, utilisez zip_discard(3).

Les mises à jour de progression pour les interfaces graphiques peuvent être implémentées à l'aide de zip_register_progress_callback_with_state(3). L'annulation de l'écriture d'une archive pendant zip_close peut être implémentée à l'aide de zip_register_cancel_callback_with_state(3).

VALEURS DE RETOUR

En cas de succès, 0 est retourné. Sinon, -1 est retourné et le code d'erreur dans archive est défini pour indiquer l'erreur.

ERREURS

zip_close() échouera si :

[ZIP_ER_EOF]
Fin de fichier inattendue rencontrée lors de la lecture d'un fichier.
[ZIP_ER_INTERNAL]
La fonction de rappel d'un fichier ajouté ou remplacé a retourné une erreur mais n'a pas réussi à indiquer laquelle.
[ZIP_ER_INVAL]
L'argument path est NULL.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.
[ZIP_ER_NOZIP]
Le fichier n'est pas une archive zip.
[ZIP_ER_READ]
Une lecture de fichier a échoué.
[ZIP_ER_RENAME]
Un fichier temporaire n'a pas pu être renommé pour son nom final.
[ZIP_ER_SEEK]
Un positionnement dans le fichier a échoué.
[ZIP_ER_TMPOPEN]
Un fichier temporaire n'a pas pu être créé.
[ZIP_ER_WRITE]
Une écriture de fichier a échoué.
[ZIP_ER_ZLIB]
Une erreur s'est produite lors de la (dé)compression d'un flux avec zlib(3).
De plus, toutes les erreurs retournées par la fonction de rappel pour les fichiers ajoutés ou remplacés seront transmises.

VOIR AUSSI

HISTORIQUE

zip_close() a été ajoutée dans libzip 0.6.

AUTEURS

Dieter Baron <dillo@nih.at> et Thomas Klausner <wiz@gatalith.at>

ATTENTION

Veuillez noter que tous les indices, informations de zip_stat(3) et autres données sur l'archive ne sont plus valides après zip_close. Lorsque vous rouvrirez le même fichier, ce sera une structure zip_t complètement nouvelle.
