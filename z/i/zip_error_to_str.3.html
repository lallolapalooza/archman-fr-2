zip_error_to_str(3)

Paquet: libzip

Licences: BSD

ZIP_ERROR_TO_STR(3) Manuel des fonctions de bibliothèque ZIP_ERROR_TO_STR(3)

NOM

zip_error_to_str — obtenir la représentation textuelle d'une erreur zip (interface obsolète)

BIBLIOTHÈQUE

libzip (-lzip)

SYNOPSIS

#include <zip.h>

int
zip_error_to_str(char *buf, zip_uint64_t len, int ze, int se);

DESCRIPTION

La fonction zip_error_to_str() est dépréciée ; utilisez zip_error_init_with_code(3) et zip_error_strerror(3) à la place.

Remplacez

char buf[BUFSIZE];
zip_error_to_str(buf, sizeof(buf), ze, se);
printf("%s", buf);
par 
zip_error_t error;
zip_error_init_with_code(&error, ze);
printf("%s", zip_error_strerror(&error));
zip_error_fini(&error);

VOIR AUSSI

libzip(3), zip_error_init_with_code(3), zip_error_strerror(3)

HISTORIQUE

zip_error_to_str() a été ajoutée dans libzip 0.6. Dans libzip 0.10, le type de len a été changé de size_t à zip_uint64_t. Elle a été dépréciée dans libzip 1.0, utilisez zip_error_init_with_code() et zip_error_strerror() à la place.
