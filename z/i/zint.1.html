ZINT(1) Manuel des commandes générales ZINT(1)

NOM

zint - encoder des données sous forme d'image de code-barres

SYNTAXE

zint [-h | --help]

zint [options]

DESCRIPTION

zint prend les données d'entrée depuis la ligne de commande ou un fichier pour les encoder dans un code-barres qui est ensuite exporté dans un fichier image.

Les données d'entrée sont en UTF-8, sauf si --binary est spécifié.

Le texte lisible par l'homme (HRT) est affiché par défaut pour les codes-barres qui le supportent, sauf si --notext est spécifié.

Le fichier image de sortie (spécifié avec -o | --output) peut être dans l'un des formats suivants : Bitmap Windows (BMP), Enhanced Metafile Format (EMF), Encapsulated PostScript (EPS), Graphics Interchange Format (GIF), ZSoft Paintbrush (PCX), Portable Network Format (PNG), Scalable Vector Graphic (SVG), ou Tagged Image File Format (TIF).

OPTIONS

-h, --help
Affiche les informations d'utilisation résumant les options de la ligne de commande.
-b TYPE, --barcode=TYPE
Définit la symbologie du code-barres qui sera utilisée pour encoder les données. TYPE est le numéro ou le nom de la symbologie du code-barres. Si non spécifié, la symbologie est par défaut 20 (Code 128). Pour voir les types disponibles, utilisez l'option -t | --types. Les noms de type ne sont pas sensibles à la casse, et les caractères non alphanumériques sont ignorés.
--addongap=INTEGER
Pour les symbologies EAN/UPC, définit l'espace entre les données principales et le complément. INTEGER est en multiples entiers de la dimension X. L'espace maximum qui peut être défini est de 12. Le minimum est de 7, sauf pour UPC-A, où le minimum est de 9.
--batch
Traite chaque ligne d'un fichier d'entrée spécifié avec -i | --input comme un ensemble de données distinct et produit une image de code-barres pour chacune. Les images de code-barres sont exportées par défaut vers des noms de fichiers numérotés commençant par « 00001.png », « 00002.png », etc., ce qui peut être modifié en utilisant l'option -o | --output.
--bg=COLOUR
Spécifie une couleur d'arrière-plan (papier) où COLOUR est au format hexadécimal RRGGBB ou RRGGBBAA ou au format décimal de pourcentages C,M,J,N.
--binary
Traite les données d'entrée comme des données binaires brutes de 8 bits au lieu de UTF-8 par défaut. La traduction automatique de la table de caractères vers une page ECI est désactivée, et aucune validation de l'encodage des caractères des données n'a lieu.
--bind
Ajoute des barres de délimitation horizontales (également appelées barres porteuses) au symbole. La largeur des barres de délimitation est spécifiée par l'option --border. --bind peut également être utilisé pour ajouter des barres de séparation de lignes aux symboles empilés avec plusieurs entrées -d | --data, auquel cas la largeur des barres de séparation est spécifiée avec l'option --separator.
--bindtop
Ajoute une barre de délimitation horizontale en haut du symbole. La largeur de la barre de délimitation est spécifiée par l'option --border.
--bold
Utilise une police grasse pour le texte lisible par l'homme (HRT).
--border=INTEGER
Définit la largeur des barres de délimitation (--bind ou --bindtop) ou des bordures de boîte (--box), où INTEGER est en multiples entiers de la dimension X. La valeur par défaut est zéro.
--box
Ajoute une boîte autour du symbole. La largeur des bordures est spécifiée par l'option --border.
--cmyk
Utilise l'espace colorimétrique CMJN lors de l'exportation vers des fichiers Encapsulated PostScript (EPS) ou TIF.
--cols=INTEGER
Définit le nombre de colonnes de données dans le symbole à INTEGER. Affecte les symboles Codablock-F, DotCode, GS1 DataBar Expanded Stacked (DBAR_EXPSTK), MicroPDF417 et PDF417.
--compliantheight
Avertit si la hauteur spécifiée par l'option --height n'est pas conforme à la spécification du code-barres, ou si --height n'est pas donné, utilise par défaut la hauteur spécifiée par la spécification (si elle existe).
-d, --data=DATA
Spécifie les DONNÉES d'entrée à encoder. L'option --esc peut être utilisée pour entrer des caractères non imprimables à l'aide de séquences d'échappement. Les DONNÉES doivent être en UTF-8, sauf si l'option --binary est donnée, auquel cas elles peuvent être n'importe quoi.
--direct
Envoie la sortie vers stdout, qui dans la plupart des cas devrait être redirigée vers un pipe ou un fichier. Utilisez --filetype pour spécifier le format de sortie.
--dmiso144
Pour les symboles Data Matrix, utilise le placement des octets de code standard ISO/IEC pour les symboles de taille 144 x 144 (--vers=24), au lieu du placement « de facto » par défaut (qui fait pivoter le placement des octets de code ECC).
--dmre
Pour les symboles Data Matrix, autorise les tailles Data Matrix Rectangular Extended (DMRE) lors de la prise en compte des tailles automatiques. Voir également --square.
--dotsize=NUMBER
Définit le rayon des points en mode pointillé (--dotty). NUMBER est en dimensions X, et peut être un nombre flottant. La valeur par défaut est 0.8.
--dotty
Utilise des points au lieu de carrés pour les symboles matriciels. DotCode est toujours en mode pointillé.
--dump
Exportation d'une représentation hexadécimale de l'encodage du symbole vers stdout. La même représentation peut être exportée vers un fichier en utilisant l'extension .txt avec -o | --output ou en spécifiant --filetype=txt.
-e, --ecinos
Affiche le tableau des ECI (Extended Channel Interpretations).
--eci=INTEGER
Définit le code ECI pour les données d'entrée à INTEGER. Voir -e | --ecinos pour une liste des ECI disponibles. Les ECI sont pris en charge par Aztec Code, Code One, Data Matrix, DotCode, Grid Matrix, Han Xin Code, MaxiCode, MicroPDF417, PDF417, QR Code, rMQR et Ultracode.
--embedfont
Pour la sortie vectorielle, intègre la police dans le fichier pour la portabilité. Actuellement uniquement disponible pour la sortie SVG.
--esc
Traite les caractères d'échappement dans les données d'entrée. Les séquences d'échappement sont :
\0       (0x00)    NUL  Caractère nul
\E       (0x04)    EOT  Fin de Transmission
\a       (0x07)    BEL  Sonnerie
\b       (0x08)    BS   Retour arrière
\t       (0x09)    HT   Tabulation horizontale
\n       (0x0A)    LF   Saut de ligne
\v       (0x0B)    VT   Tabulation verticale
\f       (0x0C)    FF   Saut de page
\r       (0x0D)    CR   Retour chariot
\e       (0x1B)    ESC  Échap
\G       (0x1D)    GS   Séparateur de groupe
\R       (0x1E)    RS   Séparateur d'enregistrement
\\       (0x5C)    \    Antislash
\dNNN    (NNN)          Tout caractère 8 bits où NNN est
                        décimal (000-255)
\oNNN    (0oNNN)        Tout caractère 8 bits où NNN est
                        octal (000-377)
\xNN     (0xNN)         Tout caractère 8 bits où NN est
                        hexadécimal (00-FF)
\uNNNN   (U+NNNN)       Tout caractère Unicode BMP 16 bits
                        où NNNN est hexadécimal
\UNNNNNN (U+NNNNNN)     Tout caractère Unicode 21 bits
                        où NNNNNN est hexadécimal
--extraesc
Pour le Code 128 uniquement, en plus du traitement des séquences d'échappement normales ci-dessus, traiter les séquences d'échappement spéciales \^A, \^B, \^C et \^@ qui permettent de passer manuellement des Jeux de Codes, et la séquence d'échappement spéciale \^1 qui insère un caractère FNC1. La séquence \@ désactive le passage manuel. La séquence \^^ peut être utilisée pour encoder des données contenant des séquences d'échappement spéciales.
--fast
Utiliser un encodage plus rapide, potentiellement moins optimal, ou d'autres raccourcis (affecte uniquement Data Matrix, MicroPDF417, PDF417, QRCODE et UPNQR).
--fg=COLOUR
Spécifier une couleur de premier plan (encre) où COLOUR est au format hexadécimal RRGGBB ou RRGGBBAA ou au format de pourcentages décimaux C,M,J,N.
--filetype=TYPE
Définir le type de fichier de sortie sur TYPE, qui est l'un des suivants : BMP, EMF, EPS, GIF, PCX, PNG, SVG, TIF, TXT.
--fullmultibyte
Utiliser les modes multi-octets de Grid Matrix, Han Xin et QR Code pour les données non ASCII.
--gs1
Traiter l'entrée comme des données compatibles GS1. Les Identificateurs d'Application (IA) doivent être placés entre crochets "[]" (voir cependant --gs1parens).
--gs1nocheck
Ne pas vérifier la validité des données GS1.
--gs1parens
Traiter les parenthèses "()" comme délimiteurs d'IA GS1, plutôt que les crochets "[]". Les données d'entrée ne doivent pas contenir d'autres parenthèses.
--gssep
Pour Data Matrix en mode GS1, utiliser GS (0x1D) comme séparateur de données GS1 au lieu de FNC1.
--guarddescent=NUMBER
Pour les symboles EAN/UPC, définir la hauteur à laquelle les barres de garde descendent sous les barres principales, où NUMBER est en dimensions X. NUMBER peut être un nombre à virgule flottante.
--guardwhitespace
Pour les symboles EAN/UPC, ajouter des indicateurs de zone calme "<" et/ou ">" au HRT si applicable.
--height=NUMBER
Définir la hauteur du symbole en dimensions X. NUMBER peut être un nombre à virgule flottante.
--heightperrow
Traiter la hauteur par ligne. Affecte Codablock-F, Code 16K, Code 49, GS1 DataBar Expanded Stacked (DBAR_EXPSTK), MicroPDF417 et PDF417.
-i, --input=FILE
Lire les données d'entrée depuis FILE. Spécifier un simple trait d'union (-) pour FILE afin de lire depuis stdin.
--init
Créer un symbole d'Initialisation du Lecteur (Programmation).
--mask=INTEGER
Définir le modèle de masquage à utiliser pour DotCode, Han Xin ou QR Code à INTEGER, en remplaçant la sélection automatique.
--mirror
Utiliser les données par lots pour déterminer le nom de fichier en mode lot (--batch). L'option -o | --output peut être utilisée pour spécifier un répertoire de sortie (tout nom de fichier sera ignoré).
--mode=INTEGER
Pour les symboles MaxiCode et GS1 Composite, définir le mode d'encodage sur INTEGER.

Pour MaxiCode (SCM est Structured Carrier Message, avec 3 champs : code postal, code pays ISO 3166-1 à 3 chiffres, code de service à 3 chiffres) :

2   SCM avec code postal numérique à 9 chiffres
3   SCM avec code postal alphanumérique à 6 caractères
4   ECC amélioré pour la partie principale du message
5   ECC amélioré pour l'ensemble du message
6   Initialisation du Lecteur (Programmation)

Pour les symboles GS1 Composite (les noms se terminent par _CC, c'est-à-dire EANX_CC, GS1_128_CC, DBAR_OMN_CC etc.) :

1   CC-A
2   CC-B
3   CC-C (GS1_128_CC uniquement)
--nobackground
Supprimer la couleur d'arrière-plan (uniquement pour EMF, EPS, GIF, PNG, SVG et TIF).
--noquietzones
Désactiver toute zone calme pour les symboles qui les définissent par défaut.
--notext
Supprimer le Texte Lisible par l'Homme (HRT).
-o, --output=FILE
Envoyer la sortie vers FILE. En dehors du mode lot, le défaut est “out.png” (ou “out.gif” si zint est compilé sans support PNG). En mode lot (--batch), des caractères spéciaux peuvent être utilisés pour formater les noms de fichiers de sortie :
~           Insérer un numéro ou 0
#           Insérer un numéro ou un espace
@           Insérer un numéro ou * (+ sur Windows)
Autre       Insérer littéralement
--primary=STRING
Pour MaxiCode, définir le contenu du message principal. Pour les symboles GS1 Composite, définir le contenu du symbole linéaire.
--quietzones
Ajouter des zones calmes conformes pour les symboles qui en spécifient. Ceci s'ajoute à tout espace blanc spécifié par -w | --whitesp ou --vwhitesp.
-r, --reverse
Inverser les couleurs de premier plan et d'arrière-plan (blanc sur noir). Connu sous le nom de “inversion de réflectance” ou “réflectance inversée”.
--rotate=INTEGER
Faire pivoter le symbole de INTEGER degrés, où INTEGER peut être 0, 90, 270 ou 360.
--rows=INTEGER
Définir le nombre de lignes pour Codablock-F ou PDF417 à INTEGER. Cela définira également le nombre minimum de lignes pour Code 16K ou Code 49, et le nombre maximum de lignes pour GS1 DataBar Expanded Stacked (DBAR_EXPSTK).
--scale=NUMBER
Ajuster la taille de la dimension X. NUMBER peut être un nombre à virgule flottante, et est multiplié par 2 (sauf pour MaxiCode) avant d'être appliqué. L'échelle par défaut est 1.

Pour MaxiCode, l'échelle est multipliée par 10 pour la sortie raster, par 40 pour la sortie EMF, et par 2 autrement.

Des incréments de 0,5 (demi-entiers) sont recommandés pour la sortie raster non-MaxiCode (BMP, GIF, PCX, PNG et TIF). Le texte lisible par l'homme (HRT) pour la sortie raster ne sera pas affiché pour les échelles inférieures à 1.

Voir également --scalexdimdp ci-dessous.

--scalexdimdp=X[,R]
Mettre à l'échelle l'image en fonction de la dimension X X et de la résolution R, où X est en mm et R est en dpmm (points par mm). X et R peuvent être des nombres à virgule flottante. R est facultatif et vaut par défaut 12 dpmm (environ 300 dpi). X peut être zéro, auquel cas un défaut spécifique à la symbologie est utilisé.

La mise à l'échelle prend en compte le type de fichier de sortie et gère tous les détails mentionnés ci-dessus. Les unités peuvent être spécifiées pour X en ajoutant “in” (pouce) ou “mm”, et pour R en ajoutant “dpi” (points par pouce) ou “dpmm” - par exemple, --scalexdimdp=0.013in,300dpi.

--scmvv=INTEGER
Pour MaxiCode, préfixer le Structured Carrier Message (SCM) avec "[)>\R01\Gvv", où vv est un INTEGER à 2 chiffres.
--secure=INTEGER
Définir
le niveau de correction d'erreur (ECC) à INTEGER. La signification est spécifique aux symboles matriciels suivants (tous sauf PDF417 sont approximatifs) : 
Code Aztec      1 à 4 (10%, 23%, 36%, 50%)
Matrice de grille 1 à 5 (10% à 50%)
Han Xin         1 à 4 (8%, 15%, 23%, 30%)
Micro QR        1 à 3 (7%, 15%, 25%) (L, M, Q)
PDF417          0 à 8 (2^(INTEGER + 1) mots de code)
Code QR         1 à 4 (7%, 15%, 25%, 30%) (L, M, Q, H)
rMQR            2 ou 4 (15% ou 30%) (M ou H)
Ultracode       1 à 6 (0%, 5%, 9%, 17%, 25%, 33%)
--segN=ECI,DATA
Définit le contenu ECI & DATA pour le segment N, où N est de 1 à 9. -d | --data doit toujours être donné et compte comme segment 0, son ECI étant donné par --eci. Les segments doivent être consécutifs.
--separator=INTEGER
Définit la hauteur des barres de séparation de ligne pour les symbologies empilées, où INTEGER est en multiples entiers de la dimension X. La valeur par défaut est zéro.
--small
Utilise une police plus petite pour le texte lisible par l'homme (HRT).
--square
Pour les symboles Data Matrix, exclut les tailles rectangulaires lors de la prise en compte des tailles automatiques. Voir aussi --dmre.
--structapp=I,C[,ID]
Définit les informations d'annexe structurée, où I est l'index basé sur 1, C est le nombre total de symboles dans la séquence, et ID, qui est facultatif, est l'identifiant que tous les symboles de la séquence partagent. L'annexe structurée est prise en charge par Aztec Code, Code One, Data Matrix, DotCode, Grid Matrix, MaxiCode, MicroPDF417, PDF417, QR Code et Ultracode.
-t, --types
Affiche le tableau des types de codes-barres (symbologies). Les numéros ou noms peuvent être utilisés avec -b | --barcode.
--textgap=NUMBER
Ajuste l'écart entre le code-barres et le texte lisible par l'homme (HRT). NUMBER est en dimensions X, et peut être un nombre à virgule flottante. Le maximum est de 10 et le minimum est de -5. La valeur par défaut est 1.
--vers=INTEGER
Définit la version du symbole (taille, chiffres de contrôle, autres options) à INTEGER. La signification est spécifique au symbole.

-v, --version
Affiche la version de zint.
--vwhitesp=INTEGER
Définit la hauteur de l'espace blanc vertical au-dessus et au-dessous du code-barres, où INTEGER est en multiples entiers de la dimension X.
-w, --whitesp=INTEGER
Définit la largeur de l'espace blanc horizontal de chaque côté du code-barres, où INTEGER est en multiples entiers de la dimension X.
--werror
Convertit tous les avertissements en erreurs.

STATUT DE SORTIE

0
Succès (y compris lors de l'utilisation des options d'information -h | --help, -e | --ecinos, -t | --types, -v | --version).
-1
Le texte lisible par l'homme a été généré sous forme de texte brut (ZINT_WARN_HRT_RAW_TEXT)
1

EXEMPLES

Crée “out.png” (ou “out.gif” si zint est compilé sans prise en charge PNG) dans le répertoire courant, en tant que symbole Code 128.

zint -d 'This Text'

Crée “qr.svg” dans le répertoire courant, en tant que symbole QR Code.

zint -b QRCode -d 'This Text' -o 'qr.svg'

Utilise le mode lot pour lire à partir d'un fichier d'entrée “ean13nos.txt” contenant une liste de GTINs à 13 chiffres, chacun sur une ligne distincte, pour créer une série de codes-barres EAN-13, en formatant les noms de fichiers de sortie en “ean001.gif”, “ean002.gif” etc. en utilisant le caractère spécial “~”.

zint -b EANX --batch -i 'ean13nos.txt' -o 'ean~~~.gif'
