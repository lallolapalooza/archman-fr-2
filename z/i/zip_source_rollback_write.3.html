NOM

zip_source_rollback_write — annuler les modifications apportées à une source zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

void
zip_source_rollback_write(zip_source_t *source);

DESCRIPTION

La fonction zip_source_rollback_write() annule les modifications écrites dans source, restaurant les données telles qu'elles étaient avant l'appel à zip_source_begin_write(3). Généralement, cela supprime les fichiers temporaires ou libère les tampons.

VOIR AUSSI

libzip(3), zip_source(5), zip_source_begin_write(3), zip_source_commit_write(3), zip_source_seek_write(3), zip_source_tell_write(3), zip_source_write(3)

HISTORIQUE

La fonction zip_source_rollback_write() a été ajoutée dans libzip 1.0.
