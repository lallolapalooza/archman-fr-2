zip_file_extra_field_delete_by_id(3)

Paquet: libzip

Licences: BSD

ZIP_FILE_EXTRA_FIELD_DELETE(3) Manuel des fonctions de bibliothèque ZIP_FILE_EXTRA_FIELD_DELETE(3)

NOM

zip_file_extra_field_delete, zip_file_extra_field_delete_by_id — supprimer un champ supplémentaire pour un fichier dans une archive zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

int
zip_file_extra_field_delete(zip_t *archive, zip_uint64_t index, zip_uint16_t extra_field_index, zip_flags_t flags);

int
zip_file_extra_field_delete_by_id(zip_t *archive, zip_uint64_t index, zip_uint16_t extra_field_id, zip_uint16_t extra_field_index, zip_flags_t flags);

DESCRIPTION

La fonction zip_file_extra_field_delete() supprime le champ supplémentaire avec l'index extra_field_index pour le fichier à la position index dans l'archive zip.

Si extra_field_index est ZIP_EXTRA_FIELD_ALL, alors tous les champs supplémentaires seront supprimés.

Les flags suivants sont supportés :

ZIP_FL_CENTRAL
Supprimer les champs supplémentaires du répertoire central de l'archive.
ZIP_FL_LOCAL
Supprimer les champs supplémentaires des en-têtes de fichiers locaux.

La fonction zip_file_extra_field_delete_by_id() supprime le champ supplémentaire avec l'identifiant (signature de deux octets) extra_field_id et l'index extra_field_index (c'est-à-dire, le extra_field_indexème champ supplémentaire avec l'ID extra_field_id). Les autres arguments sont les mêmes que pour zip_file_extra_field_delete() (ZIP_EXTRA_FIELD_ALL supprimera tous les champs supplémentaires de l'ID spécifié).

Veuillez noter qu'en raison de la conception de la bibliothèque, l'index d'un champ supplémentaire peut être différent entre le répertoire central et les en-têtes de fichiers locaux. Pour cette raison, il n'est pas autorisé de spécifier à la fois ZIP_FL_CENTRAL et ZIP_FL_LOCAL dans flags, sauf lors de la suppression de tous les champs supplémentaires (c'est-à-dire lorsque extra_field_index est ZIP_EXTRA_FIELD_ALL).

VALEURS DE RETOUR

En cas de succès, 0 est retourné. Sinon, -1 est retourné et le code d'erreur dans archive est défini pour indiquer l'erreur.

ERREURS

zip_file_extra_field_delete() et zip_file_extra_field_delete_by_id() échouent si :

ZIP_ER_NOENT
index n'est pas un index de fichier valide dans archive.

VOIR AUSSI

libzip(3), zip_file_extra_field_get(3), zip_file_extra_field_set(3), zip_file_extra_fields_count(3)

HISTORIQUE

zip_file_extra_field_delete() et zip_file_extra_field_delete_by_id() ont été ajoutées dans libzip 0.11.
