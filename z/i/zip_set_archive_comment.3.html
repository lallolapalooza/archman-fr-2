zip_set_archive_comment(3)

Paquet: libzip

Licences: BSD

ZIP_SET_ARCHIVE_COMMENT(3) Manuel des fonctions de bibliothèque ZIP_SET_ARCHIVE_COMMENT(3)

NOM

zip_set_archive_comment — définir le commentaire de l'archive zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

int
zip_set_archive_comment(zip_t *archive, const char *comment, zip_uint16_t len);

DESCRIPTION

La fonction zip_set_archive_archive_comment() définit le commentaire pour l'ensemble de l'archive zip. Si comment est NULL et len est 0, le commentaire de l'archive sera supprimé. comment doit être encodé en ASCII ou UTF-8.

VALEURS DE RETOUR

En cas de succès, 0 est retourné. Sinon, -1 est retourné et les informations d'erreur dans archive sont définies pour indiquer l'erreur.

ERREURS

zip_set_archive_comment() échoue si :

[ZIP_ER_INVAL]
len est inférieur à 0 ou plus long que la longueur maximale du commentaire dans un fichier zip (65535), ou comment n'est pas une chaîne encodée en UTF-8 valide.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.

VOIR AUSSI

libzip(3), zip_file_get_comment(3), zip_file_set_comment(3), zip_get_archive_comment(3)

HISTORIQUE

zip_set_archive_comment() a été ajouté dans libzip 0.7. Dans libzip 0.11, le type de len a été changé de int à zip_uint16_t.
