ZIP_ERROR_SET_FROM_SOURCE(3) Manuel des fonctions de bibliothèque ZIP_ERROR_SET_FROM_SOURCE(3)

NOM

zip_error_set_from_source — remplit la structure zip_error à partir de la source

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

void
zip_error_set_from_source(zip_error_t *ze, zip_source_t *src);

DESCRIPTION

La fonction zip_error_set_from_source() définit l'erreur zip_error pointée par ze à l'erreur rapportée par src telle que renvoyée par zip_error_source(3). ze doit être alloué et initialisé avec zip_error_init(3) avant d'appeler zip_error_set_from_source().

VOIR AUSSI

libzip(3), zip_error_init(3), zip_error_set(3)

HISTORIQUE

zip_error_set_from_source() a été ajoutée dans libzip 1.10.
