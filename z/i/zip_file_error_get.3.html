zip_file_error_get(3)

Paquet: libzip

Licences: BSD

ZIP_ERROR_GET(3) Manuel des fonctions de bibliothèque ZIP_ERROR_GET(3)

NOM

zip_error_get, zip_file_error_get — obtenir les codes d'erreur pour une archive ou un fichier (interface obsolète)

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

void
zip_error_get(zip_t *archive, int *zep, int *sep);

void
zip_file_error_get(zip_file_t *file, int *zep, int *sep);

DESCRIPTION

Les fonctions zip_error_get() et zip_file_error_get() sont obsolètes. Utilisez plutôt zip_error_code_system(3), zip_error_code_zip(3), zip_file_get_error(3), et zip_get_error(3).

Pour zip_error_get(), remplacez

int ze, se;
zip_error_get(za, &ze, &se);
par 
int ze, se;
zip_error_t *error = zip_get_error(za);
ze = zip_error_code_zip(error);
se = zip_error_code_system(error);
Pour zip_file_error_get(), remplacez 
int ze, se;
zip_file_error_get(zf, &ze, &se);
par 
int ze, se;
zip_error_t *error = zip_file_get_error(zf);
ze = zip_error_code_zip(error);
se = zip_error_code_system(error);

VOIR AUSSI

libzip(3), zip_error_code_system(3), zip_error_code_zip(3), zip_file_get_error(3), zip_get_error(3)

HISTORIQUE

zip_error_get() a été ajoutée dans libzip 0.6. Elle a été déclarée obsolète dans libzip 1.0, utilisez zip_get_error(), zip_error_code_zip(), / zip_error_code_system() à la place.

zip_file_error_get() a été ajoutée dans libzip 0.6. Elle a été déclarée obsolète dans libzip 1.0, utilisez zip_file_get_error(), zip_error_code_zip(), / zip_error_code_system() à la place.
