zip_stat_index(3)

Paquet: libzip

Licences: BSD

ZIP_STAT(3) Manuel des fonctions de bibliothèque ZIP_STAT(3)

NOM

zip_stat, zip_stat_index — obtenir des informations sur un fichier

BIBLIOTHÈQUE

libzip (-lzip)

SYNOPIS

#include <zip.h>

int
zip_stat(zip_t *archive, const char *fname, zip_flags_t flags, zip_stat_t *sb);

int
zip_stat_index(zip_t *archive, zip_uint64_t index, zip_flags_t flags, zip_stat_t *sb);

DESCRIPTION

La fonction zip_stat() obtient des informations sur le fichier nommé fname dans archive. L'argument flags spécifie comment la recherche du nom doit être effectuée. Ses valeurs sont décrites dans zip_name_locate(3). De plus, ZIP_FL_UNCHANGED peut être ou_é pour demander des informations sur le fichier d'origine dans l'archive, ignorant toute modification apportée.

La fonction zip_stat_index() obtient des informations sur le fichier à la position index.

L'argument sb est un pointeur vers une struct zip_stat (voir ci-dessous), dans laquelle les informations sur le fichier sont placées.

struct zip_stat {
    zip_uint64_t valid;                 /* quels champs ont des valeurs valides */
    const char *name;                   /* nom du fichier */
    zip_uint64_t index;                 /* index dans l'archive */
    zip_uint64_t size;                  /* taille du fichier (non compressé) */
    zip_uint64_t comp_size;             /* taille du fichier (compressé) */
    time_t mtime;                       /* heure de modification */
    zip_uint32_t crc;                   /* crc des données du fichier */
    zip_uint16_t comp_method;           /* méthode de compression utilisée */
    zip_uint16_t encryption_method;     /* méthode de chiffrement utilisée */
    zip_uint32_t flags;                 /* réservé pour une utilisation future */
};
La structure pointée par sb doit être allouée avant d'appeler zip_stat() ou zip_stat_index().

Le champ valid de la structure spécifie quels autres champs sont valides. Vérifiez si l'indicateur défini par les définitions suivantes se trouve dans valid avant d'accéder aux champs :

ZIP_STAT_NAME
name
ZIP_STAT_INDEX
index
ZIP_STAT_SIZE
size
ZIP_STAT_COMP_SIZE
comp_size
ZIP_STAT_MTIME
mtime
ZIP_STAT_CRC
crc
ZIP_STAT_COMP_METHOD
comp_method
ZIP_STAT_ENCRYPTION_METHOD
encryption_method
ZIP_STAT_FLAGS
flags

VALEURS DE RETOUR

En cas de succès, 0 est retourné. Sinon, -1 est retourné et les informations d'erreur dans archive sont définies pour indiquer l'erreur.

ERREURS

La fonction zip_stat() peut échouer pour l'une des erreurs spécifiées pour la routine zip_name_locate(3).

La fonction zip_stat_index() échoue et définit les informations d'erreur à ZIP_ER_INVAL si index est invalide. Si ZIP_FL_UNCHANGED n'est pas défini et qu'aucune information ne peut être obtenue à partir du rappel source, les informations d'erreur sont définies à ZIP_ER_CHANGED.

VOIR AUSSI

libzip(3), zip_get_num_entries(3), zip_name_locate(3), zip_stat_init(3)

HISTORIQUE

zip_stat() a été ajoutée dans libzip 0.6. Dans libzip 0.11, le type de flags a été changé de int à zip_flags_t.

zip_stat_index() a été ajoutée dans libzip 0.6. Dans libzip 0.10, le type de index a été changé de int à zip_uint64_t. Dans libzip 0.11, le type de flags a été changé de int à zip_flags_t.
