zip_source_stat(3)

Paquet: libzip

Licences: BSD

ZIP_SOURCE_STAT(3) Manuel des fonctions de bibliothèque ZIP_SOURCE_STAT(3)

NOM

zip_source_stat — obtenir des informations sur une source zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

int
zip_source_stat(zip_source_t *source, zip_stat_t *sb);

DESCRIPTION

La fonction zip_source_stat() obtient des informations sur la source zip source

L'argument sb est un pointeur vers une structure zip_source_stat (montrée ci-dessous), dans laquelle les informations sur la source zip sont placées.

struct zip_source_stat {
    zip_uint64_t valid;                 /* quels champs ont des valeurs valides */
    const char *name;                   /* nom du fichier */
    zip_uint64_t index;                 /* index dans l'archive */
    zip_uint64_t size;                  /* taille du fichier (non compressé) */
    zip_uint64_t comp_size;             /* taille du fichier (compressé) */
    time_t mtime;                       /* date de modification */
    zip_uint32_t crc;                   /* crc des données du fichier */
    zip_uint16_t comp_method;           /* méthode de compression utilisée */
    zip_uint16_t encryption_method;     /* méthode de chiffrement utilisée */
    zip_uint32_t flags;                 /* réservé pour une utilisation future */
};
La structure pointée par sb doit être initialisée avec zip_stat_init(3) avant d'appeler zip_source_stat().

Le champ valid de la structure spécifie quels autres champs sont valides. Vérifiez si le drapeau défini par les définitions suivantes se trouve dans valid avant d'accéder aux champs :

ZIP_STAT_NAME
name
ZIP_STAT_INDEX
index
ZIP_STAT_SIZE
size
ZIP_STAT_COMP_SIZE
comp_size
ZIP_STAT_MTIME
mtime
ZIP_STAT_CRC
crc
ZIP_STAT_COMP_METHOD
comp_method
ZIP_STAT_ENCRYPTION_METHOD
encryption_method
ZIP_STAT_FLAGS
flags

NOTE: Certains champs ne peuvent être remplis qu'après que toutes les données ont été lues depuis la source, par exemple les champs crc ou size.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. Sinon, -1 est retourné et les informations d'erreur dans source sont définies pour indiquer l'erreur.

VOIR AUSSI

libzip(3), zip_source(5)

HISTORIQUE

zip_source_stat() a été ajoutée dans libzip 1.0.
