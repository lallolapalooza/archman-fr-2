Paquet: libzip

Licences: BSD

ZIP_UNCHANGE_ALL(3) Manuel des fonctions de bibliothèque ZIP_UNCHANGE_ALL(3)

NOM

zip_unchange_all — annule toutes les modifications dans une archive zip

BIBLIOTHEQUE

libzip (-lzip)

SYNOPSIS

#include <zip.h>

int
zip_unchange_all(zip_t *archive);

DESCRIPTION

Toutes les modifications apportées aux fichiers et aux informations globales de l'archive sont annulées.

VALEURS DE RETOUR

En cas de succès, 0 est retourné. Sinon, -1 est retourné et le code d'erreur dans l'archive est défini pour indiquer l'erreur.

VOIR AUSSI

libzip(3), zip_unchange(3), zip_unchange_archive(3)

HISTORIQUE

zip_unchange_all() a été ajoutée dans libzip 0.6.
