NOM

zip2st - convertir un répertoire ou une archive .zip en image disque .st

SYNOPSIS

zip2st <répertoire|srcname.zip> [dstname.st]

DESCRIPTION

zip2st peut être utilisé pour générer une image disque Atari .st à partir du contenu d'un répertoire et d'une archive .zip.

Si le nom du fichier de destination n'est pas donné, il est basé sur le nom source, avec l'extension .zip retirée et le préfixe .st ajouté. Si l'outil basename est présent, le fichier est enregistré dans le répertoire courant, sinon dans le répertoire où se trouve le répertoire/l'archive source.

Tous les répertoires uniques (autres que 'auto') dans la hiérarchie du zip source / du répertoire sont parcourus, afin d'éviter d'ajouter des répertoires intermédiaires redondants à l'image disque générée.

L'image disque .st est une image disque brute, et peut être écrite sur une disquette à l'aide de dd(1), ou convertie en une image disque .msa avec hmsa(1).

Le contenu du fichier zip décompressé doit être inférieur à 2,88 Mo (la plus grande taille d'image de disquette prise en charge par Hatari).

Si les noms de fichiers source sont plus longs que 8+3, utilisez le script atari-convert-dir pour les convertir en noms compatibles Atari. Si les fichiers se trouvent dans une archive .zip, vous devez les extraire avant la conversion.

VOIR AUSSI

hmsa(1), atari-convert-dir(1), atari-hd-image(1), hatari(1), unzip(1), mtools(1), basename(1), dd(1).
