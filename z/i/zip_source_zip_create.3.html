zip_source_zip_create(3)

Paquet: libzip

Licences: BSD

ZIP_SOURCE_ZIP(3) Manuel des fonctions de bibliothèque ZIP_SOURCE_ZIP(3)

NOM

zip_source_zip, zip_source_zip_create — créer une source de données à partir d'un fichier zip (interface obsolète)

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

zip_source_t *
zip_source_zip(zip_t *archive, zip_t *srcarchive, zip_uint64_t srcidx, zip_flags_t flags, zip_uint64_t start, zip_int64_t len);

zip_source_t *
zip_source_zip_create(zip_t *srcarchive, zip_uint64_t srcidx, zip_flags_t flags, zip_uint64_t start, zip_int64_t len, zip_error_t *error);

DESCRIPTION

Les fonctions zip_source_zip() et zip_source_zip_create() sont les versions obsolètes de zip_source_zip_file(3) ou zip_source_zip_file_create(3) respectivement. Si vous souhaitez obtenir les données compressées du fichier complet, utilisez

zip_source_zip_file(za, source_archive, source_index, ZIP_FL_COMPRESSED, 0, -1, NULL)

Les fonctions zip_source_zip() et zip_source_zip_create() créent une source zip à partir d'un fichier dans une archive zip. L'argument srcarchive est l'archive zip (ouverte) contenant le fichier zip source à l'index srcidx. len octets à partir de l'offset start seront utilisés dans la zip_source. Si len est 0 ou -1, le reste du fichier, à partir de start, est utilisé. Si start est zéro et len est -1, le fichier entier sera copié sans décompression.

Les indicateurs pris en charge sont :

ZIP_FL_UNCHANGED
Demande les données originales sans aucune modification qui aurait pu être apportée à srcarchive après son ouverture.

VALEURS DE RETOUR

En cas de succès, la source créée est retournée. Sinon, NULL est retourné et le code d'erreur dans archive ou error est défini pour indiquer l'erreur.

ERREURS

zip_source_zip() et zip_source_zip_create() échouent si :

[ZIP_ER_CHANGED]
Des données inchangées ont été demandées, mais elles ne sont pas disponibles.
[ZIP_ER_INVAL]
srcarchive, srcidx, start, ou len sont invalides.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.
De plus, elles peuvent retourner tous les codes d'erreur de zip_stat_index() et zip_fopen_index().

VOIR AUSSI

libzip(3), zip_file_add(3), zip_file_replace(3), zip_source(5)

HISTORIQUE

zip_source_zip() a été ajouté dans libzip 1.0. zip_source_zip_create() a été ajouté dans libzip 1.8.0. Les deux ont été dépréciés dans libzip 1.10.0. Utilisez plutôt zip_source_zip_file() ou zip_source_zip_file_create().
