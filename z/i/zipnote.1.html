zipnote(1) Manuel des commandes générales zipnote(1)

NOM

zipnote - écrit les commentaires dans un fichier zip sur la sortie standard, modifie les commentaires et renomme les fichiers dans un fichier zip

SYNTAXE

zipnote [-w] [-b chemin] [-h] [-v] [-L] fichier.zip

ARGUMENTS


fichier.zip Fichier zip à lire les commentaires ou à modifier.

OPTIONS

-w
Écrit les commentaires dans un fichier zip depuis l'entrée standard (voir ci-dessous).
-b chemin
Utilise chemin pour le fichier zip temporaire.
-h
Affiche une aide courte.
-v
Affiche les informations de version.
-L
Affiche la licence du logiciel.

DESCRIPTION

zipnote écrit les commentaires d'un fichier zip sur la sortie standard. C'est le mode par défaut. Un second mode permet de mettre à jour les commentaires d'un fichier zip, ainsi que de changer les noms des fichiers dans le fichier zip. Ces modes sont décrits ci-dessous.

EXEMPLES

Pour écrire tous les commentaires d'un fichier zip sur la sortie standard, utilisez par exemple

     zipnote foo.zip > foo.tmp

Ceci écrit tous les commentaires du fichier zip foo.zip dans le fichier foo.tmp dans un format spécifique.

Si désiré, ce fichier peut ensuite être modifié pour changer les commentaires, puis utilisé pour mettre à jour le fichier zip.

     zipnote -w foo.zip < foo.tmp

Les noms des fichiers dans le fichier zip peuvent également être modifiés de cette manière. Ceci est fait en suivant les lignes comme

     "@ nom"
dans le fichier temporaire créé (appelé foo.tmp ici) par des lignes comme 
     "@=nouveau_nom"
et en utilisant ensuite l'option -w comme ci-dessus.

BOGUES

Le format du fichier temporaire est assez spécifique et zipnote est assez pointilleux à son sujet. Il devrait être plus facile de changer les noms de fichiers dans un script.

Ne supporte pas encore les archives volumineuses (> 2 Go) ou divisées.
