NOM

ziproxy - un serveur proxy HTTP compressant

SYNTAXE

ziproxy <-d|-i|-k> [-c fichier_config] [-u nom_utilisateur] [-g nom_groupe] [-p fichier_pid] [-h]

DESCRIPTION

ziproxy est un serveur proxy HTTP de transfert, sans mise en cache et compressant. Fondamentalement, il réduit la taille des images en les convertissant en JPEG de moindre qualité et compresse (gzip) le HTML et autres données textuelles.

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-d, --daemon-mode
Utilisé lors de l'exécution en mode autonome.
-i, --inetd-mode
Utilisé lors de l'exécution depuis inetd ou xinetd.
-k, --stop-daemon
Arrête le démon.
-c, --config-file fichier_config
Chemin complet du fichier ziproxy.conf (au lieu de celui par défaut).
-u, --user nom_utilisateur
Exécute le démon en tant qu'utilisateur spécifié. Si non spécifié et que nom_utilisateur est spécifié, utilise le groupe de nom_utilisateur.
-g, --group nom_groupe
Exécute le démon en tant que groupe spécifié.
-p, --pid-file fichier_pid
Utilise le fichier PID spécifié pour le contrôle du démon.
-h, --help
Affiche une aide résumée.
