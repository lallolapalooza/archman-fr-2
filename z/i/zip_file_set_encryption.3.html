zip_file_set_encryption(3)

Paquet: libzip

Licences: BSD

ZIP_FILE_SET_ENCRYPTION(3) Manuel des fonctions de bibliothèque ZIP_FILE_SET_ENCRYPTION(3)

NOM

zip_file_set_encryption — définir la méthode de chiffrement pour un fichier dans une archive zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNOPSIS

#include <zip.h>

int
zip_file_set_encryption(zip_t *archive, zip_uint64_t index, zip_uint16_t method, const char *password);

DESCRIPTION

La fonction zip_file_set_encryption() définit la méthode de chiffrement pour le fichier à la position index dans l'archive zip à method en utilisant le mot de passe password. Le method est le même que celui retourné par zip_stat(3). Pour l'argument method, seules les valeurs suivantes sont actuellement prises en charge :

ZIP_EM_NONE
Pas de chiffrement.
ZIP_EM_AES_128
Chiffrement Winzip AES-128.
ZIP_EM_AES_192
Chiffrement Winzip AES-192.
ZIP_EM_AES_256
Chiffrement Winzip AES-256.
ZIP_EM_TRAD_PKWARE
Chiffrement traditionnel PKWare. N'utilisez pas cette méthode, elle n'est pas sécurisée. Elle est fournie uniquement pour des raisons de compatibilité ascendante.

Si password est NULL, le mot de passe par défaut fourni par zip_set_default_password(3) est utilisé.

La méthode de chiffrement actuelle pour un fichier dans une archive zip peut être déterminée à l'aide de zip_stat(3).

VALEURS DE RETOUR

En cas de succès, 0 est retourné. Sinon, -1 est retourné et les informations d'erreur dans archive sont définies pour indiquer l'erreur.

ERREURS

zip_file_set_encryption() échoue si :

[ZIP_ER_ENCRNOTSUPP]
Méthode de compression non prise en charge demandée.
[ZIP_ER_INVAL]
index n'est pas un index de fichier valide dans archive, ou la combinaison des arguments est invalide.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.
[ZIP_ER_RDONLY]
Fichier zip en lecture seule, aucune modification autorisée.

VOIR AUSSI

libzip(3), zip_encryption_method_supported(3), zip_fopen_encrypted(3), zip_fopen_index_encrypted(3), zip_set_default_password(3), zip_stat(3)

HISTORIQUE

zip_file_set_encryption() a été ajoutée dans libzip 1.2.0.
