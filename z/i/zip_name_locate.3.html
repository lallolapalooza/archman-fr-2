ZIP_NAME_LOCATE(3) Manuel des fonctions de bibliothèque ZIP_NAME_LOCATE(3)

NOM

zip_name_locate — obtenir l'index d'un fichier par son nom

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

zip_int64_t
zip_name_locate(zip_t *archive, const char *fname, zip_flags_t flags);

DESCRIPTION

La fonction zip_name_locate() renvoie l'index du fichier nommé fname dans archive. Si archive ne contient pas de fichier portant ce nom, -1 est renvoyé.

Si ni ZIP_FL_ENC_RAW ni ZIP_FL_ENC_STRICT ne sont spécifiés, tente de deviner l'encodage du nom dans l'archive ZIP et le convertit en UTF-8, si nécessaire, avant de le comparer.

Si ni ZIP_FL_ENC_CP437 ni ZIP_FL_ENC_UTF_8 ne sont spécifiés, tente de deviner l'encodage de fname.

Seuls CP-437 et UTF-8 sont reconnus.

Les flags sont spécifiés en combinant avec un OU logique (OR) les valeurs suivantes, ou 0 pour aucune d'entre elles.

ZIP_FL_NOCASE
Ignore la distinction entre majuscules et minuscules. (Ne fonctionnera bien que si les noms de fichiers sont en ASCII.) Avec ce drapeau, zip_name_locate() sera lent pour les archives contenant de nombreux fichiers.
ZIP_FL_NODIR
Ignore la partie répertoire du nom de fichier dans l'archive. Avec ce drapeau, zip_name_locate() sera lent pour les archives contenant de nombreux fichiers.
ZIP_FL_ENC_GUESS
Ce drapeau n'a aucun effet (sa valeur est 0); il peut être utilisé pour indiquer explicitement l'absence de drapeaux d'encodage.
ZIP_FL_ENC_RAW
Compare fname aux noms non modifiés tels qu'ils se trouvent dans l'archive ZIP, sans les convertir en UTF-8.
ZIP_FL_ENC_STRICT
Suit la spécification ZIP et attend des noms encodés en CP-437 dans l'archive ZIP (sauf s'ils sont explicitement marqués comme UTF-8). Les convertit en UTF-8 avant la comparaison.
ZIP_FL_ENC_CP437
fname est encodé en CP-437.
ZIP_FL_ENC_UTF_8
fname est encodé en UTF-8.

Note: L'ASCII est un sous-ensemble de CP-437 et d'UTF-8.

VALEURS RENVOYÉES

zip_name_locate() renvoie l'index du fichier nommé fname ou -1 si archive ne contient aucune entrée de ce nom.

ERREURS

zip_name_locate() échoue si :

[ZIP_ER_INVAL]
L'un des arguments est invalide.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.
[ZIP_ER_NOENT]
Aucune entrée du nom fname n'est trouvée dans l'archive.

VOIR AUSSI

libzip(3), zip_get_name(3)

HISTORIQUE

zip_name_locate() a été ajoutée dans libzip 0.6. Dans libzip 0.11, le type de retour a été changé de int à zip_int64_t. Dans libzip 0.11, le type de flags a été changé de int à zip_flags_t.
