zip_file_set_comment(3)

Paquet: libzip

Licences: BSD

ZIP_FILE_SET_COMMENT(3) Manuel des fonctions de bibliothèque ZIP_FILE_SET_COMMENT(3)

NOM

zip_file_set_comment — définir le commentaire pour un fichier dans l'archive zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

int
zip_file_set_comment(zip_t *archive, zip_uint64_t index, const char *comment, zip_uint16_t len, zip_flags_t flags);

DESCRIPTION

La fonction zip_file_set_comment() définit le commentaire pour le fichier à la position index dans l'archive zip sur comment de longueur len. Si comment est NULL et len est 0, le commentaire du fichier sera supprimé. L'argument flags peut être l'un des suivants :

ZIP_FL_ENC_GUESS
Deviner le codage de comment (par défaut). (Seuls CP-437 et UTF-8 sont reconnus.)
ZIP_FL_ENC_UTF_8
Interpréter comment comme UTF-8.
ZIP_FL_ENC_CP437
Interpréter comment comme page de code 437 (CP-437).

VALEURS DE RETOUR

En cas de succès, 0 est retourné. Sinon, -1 est retourné et les informations d'erreur dans archive sont définies pour indiquer l'erreur.

ERREURS

zip_file_set_comment() échoue si :

[ZIP_ER_INVAL]
index n'est pas un index de fichier valide dans archive, ou len est inférieur à 0 ou supérieur à la longueur maximale du commentaire dans un fichier zip (65535), ou comment n'est pas une chaîne encodée en UTF-8 valide.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.
[ZIP_ER_RDONLY]
L'archive a été ouverte en lecture seule.

VOIR AUSSI

libzip(3), zip_file_get_comment(3), zip_get_archive_comment(3), zip_set_archive_comment(3)

HISTORIQUE

zip_file_set_comment() a été ajouté dans libzip 0.11.
