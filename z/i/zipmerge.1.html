ZIPMERGE(1) Manuel des commandes générales ZIPMERGE(1)

NOM

zipmerge — fusionner des archives zip

SYNOPIS

zipmerge [-DhIiSsV] archive-cible.zip archive-source.zip [archive-source.zip ...]

DESCRIPTION

zipmerge copie des fichiers des archives zip source archive-source.zip vers l'archive zip cible archive-cible.zip. Par défaut, les fichiers dans les archives source écrasent les fichiers existants du même nom dans l'archive zip cible. Par défaut, les fichiers compressés dans l'archive source sont copiés directement sans recompresion, les fichiers non compressés sont compressés en utilisant l'algorithme de compression par défaut.

Options supportées :

-D
Ignorer les composants de répertoire dans les comparaisons de noms de fichiers. Cette option est lente pour les archives contenant de nombreux fichiers.
-h
Afficher un court message d'aide et quitter.
-I
Ignorer la casse dans les comparaisons de noms de fichiers. Cette option est lente pour les archives contenant de nombreux fichiers.
-i
Demander avant d'écraser des fichiers. Voir aussi -s.
-k
Ne pas compresser les fichiers qui étaient non compressés dans archive-source.zip, sinon ils sont compressés avec la méthode de compression par défaut.
-S
Ne pas écraser les fichiers ayant le même nom, la même taille et le même CRC32 dans les archives source et cible.
-s
Lorsque -i est donné, ne pas demander avant d'écraser les fichiers ayant le même nom, la même taille et le même CRC32.
-V
Afficher les informations de version et quitter.

CODE DE SORTIE

zipmerge retourne 0 en cas de succès et >1 en cas d'erreur.

VOIR AUSSI

zipcmp(1), ziptool(1), libzip(3)

HISTORIQUE

zipmerge a été ajouté dans libzip 0.6.

AUTEURS

Dieter Baron <dillo@nih.at> et Thomas Klausner <wiz@gatalith.at>

AVERTISSEMENTS

zipmerge utilise un descripteur de fichier ouvert par archive zip. Si vous devez fusionner beaucoup d'archives zip, vérifiez l'ulimit de descripteurs de fichiers de votre shell et soit augmentez-le, soit exécutez zipmerge plusieurs fois avec par exemple 1000 archives zip source à chaque fois.
