Paquet: libzip

Licences: BSD

ZIP_GET_ERROR(3) Manuel des fonctions de bibliothèque ZIP_GET_ERROR(3)

NOM

zip_get_error — obtenir l'erreur zip pour une archive

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

zip_error_t *
zip_get_error(zip_t *archive);

DESCRIPTION

La fonction zip_get_error() renvoie l'erreur zip pour l'archive zip archive.

VOIR AUSSI

libzip(3), zip_error_code_system(3), zip_error_code_zip(3)

HISTORIQUE

zip_get_error() a été ajoutée dans libzip 1.0.
