zip_register_cancel_callback_with_state(3)

ZIP_REGISTER_CANCEL_CALLBACK_WITH_STATE(3) Manuel des fonctions de bibliothèque ZIP_REGISTER_CANCEL_CALLBACK_WITH_STATE(3)

NOM

zip_register_cancel_callback_with_state — permettre l'annulation lors de zip_close

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

typedef int (*zip_cancel_callback)(zip_t *, void *);

void
zip_register_cancel_callback_with_state(zip_t *archive, zip_cancel_callback callback, void (*ud_free)(void *), void *ud);

DESCRIPTION

Cette fonction peut être utilisée pour annuler l'écriture d'une archive zip pendant zip_close(3).

La fonction zip_register_cancel_callback_with_state() enregistre une fonction de rappel callback pour l'archive zip archive. La fonction ud_free est appelée lors du nettoyage pour supprimer les données utilisateur fournies dans ud.

La fonction de rappel est appelée pendant zip_close(3) à intervalles réguliers (après chaque entrée de l'archive zip complètement écrite sur disque, et pendant l'écriture des données pour les entrées) avec l'archive zip archive et les données utilisateur fournies ud comme arguments. Lorsque la fonction de rappel renvoie une valeur non nulle, l'écriture est annulée et zip_close(3) renvoie une erreur.

La fonction de rappel doit être rapide, car elle sera appelée souvent.

VOIR AUSSI

libzip(3), zip_close(3), zip_register_progress_callback_with_state(3)

HISTORIQUE

zip_register_cancel_callback_with_state() a été ajoutée dans libzip 1.6.0.
