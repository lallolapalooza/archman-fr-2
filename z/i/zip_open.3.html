zip_open(3)

Paquet: libzip

Licences: BSD

ZIP_OPEN(3) Manuel des fonctions de bibliothèque ZIP_OPEN(3)

NOM

zip_open, zip_open_from_source — ouvrir une archive zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

zip_t *
zip_open(const char *path, int flags, int *errorp);

zip_t *
zip_open_from_source(zip_source_t *zs, int flags, zip_error_t *ze);

DESCRIPTION

La fonction zip_open() ouvre l'archive zip spécifiée par path et renvoie un pointeur vers une struct zip, utilisée pour manipuler l'archive. Les flags sont spécifiés en en'trelassant les valeurs suivantes, ou 0 pour aucune d'entre elles.

ZIP_CHECKCONS
Effectue des vérifications de cohérence plus strictes sur l'archive, et renvoie une erreur si elles échouent.
ZIP_CREATE
Crée l'archive si elle n'existe pas.
ZIP_EXCL
Renvoie une erreur si l'archive existe déjà.
ZIP_TRUNCATE
Si l'archive existe, ignore son contenu actuel. En d'autres termes, la traite comme une archive vide.
ZIP_RDONLY
Ouvre l'archive en mode lecture seule.

En cas d'erreur et si errorp n'est pas NULL, il sera défini avec le code d'erreur correspondant.

La fonction zip_open_from_source() ouvre une archive zip encapsulée par le zip_source zs en utilisant les flags fournis. En cas d'erreur, le zip_error ze est rempli.

VALEURS DE RETOUR

En cas de succès, zip_open() et zip_open_from_source() renvoient un pointeur struct zip. Sinon, NULL est renvoyé et zip_open() définit *errorp pour indiquer l'erreur, tandis que zip_open_from(source) définit ze pour indiquer l'erreur.

EXEMPLES

Voici un exemple de la façon dont vous pourriez signaler des erreurs lors de zip_open:

    zip_t *za;
    int err;

    if ((za = zip_open(name, 0, &err)) == NULL) {
        zip_error_t error;
        zip_error_init_with_code(&error, err);
        fprintf(stderr, "%s: impossible d'ouvrir l'archive zip '%s': %s\n",
	        progname, name, zip_error_strerror(&error));
        zip_error_fini(&error);
        return -1;
    }

ERREURS

L'archive spécifiée par path est ouverte sauf si :

[ZIP_ER_EXISTS]
Le fichier spécifié par path existe et ZIP_EXCL est défini.
[ZIP_ER_INCONS]
Des incohérences ont été trouvées dans le fichier spécifié par path. Cette erreur est souvent causée par la spécification de ZIP_CHECKCONS mais peut également se produire sans celui-ci.
[ZIP_ER_INVAL]
L'argument path est NULL.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.
[ZIP_ER_NOENT]
Le fichier spécifié par path n'existe pas et ZIP_CREATE n'est pas défini.
[ZIP_ER_NOZIP]
Le fichier spécifié par path n'est pas une archive zip.
[ZIP_ER_OPEN]
Le fichier spécifié par path n'a pas pu être ouvert.
[ZIP_ER_READ]
Une erreur de lecture s'est produite ; voir errno pour plus de détails.
[ZIP_ER_SEEK]
Le fichier spécifié par path ne permet pas les opérations de recherche.
Pour les archives nouvellement créées, zip_open() n'essaie pas de créer le fichier ; cela est fait lors de l'appel à zip_close(3) et toute erreur, comme un manque de permissions d'écriture, sera rapportée alors.
