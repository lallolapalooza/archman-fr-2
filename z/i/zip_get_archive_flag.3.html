ZIP_GET_ARCHIVE_FLAG(3) Manuel des fonctions de bibliothèque ZIP_GET_ARCHIVE_FLAG(3)

NOM

zip_get_archive_flag — obtenir les indicateurs d'état pour zip

BIBLIOTHÈQUE

libzip (-lzip)

SYNOPSIS

#include <zip.h>

int
zip_get_archive_flag(zip_t *archive, zip_flags_t flag, zip_flags_t flags);

DESCRIPTION

La fonction zip_get_archive_flag() retourne si l'indicateur flag est défini pour l'archive archive. Les indicateurs d'archive ont pu être modifiés avec zip_set_archive_flag(); si flags est défini sur ZIP_FL_UNCHANGED, les indicateurs d'origine non modifiés sont testés.

Les indicateurs pris en charge sont :

ZIP_AFL_CREATE_OR_KEEP_FILE_FOR_EMPTY_ARCHIVE
Si cet indicateur est effacé, le fichier archive sera supprimé si l'archive est vide. S'il est défini, une archive vide sera créée, ce qui n'est pas recommandé par la spécification zip. Cet indicateur est toujours effacé sauf s'il est explicitement défini par l'utilisateur avec zip_set_archive_flag(3).
ZIP_AFL_IS_TORRENTZIP
L'archive est au format torrentzip.
ZIP_AFL_RDONLY
L'archive est en lecture seule.
ZIP_AFL_WANT_TORRENTZIP
Si l'indicateur est défini, l'archive sera écrite au format torrentzip. Cet indicateur est toujours effacé sauf s'il est explicitement défini par l'utilisateur avec zip_set_archive_flag(3).

VALEUR DE RETOUR

zip_get_archive_flag() retourne 1 si flag est défini pour archive, 0 si non, et -1 si une erreur s'est produite.

VOIR AUSSI

libzip(3), zip_set_archive_flag(3)

HISTORIQUE

zip_get_archive_flag() a été ajoutée dans libzip 0.9. Dans libzip 0.11, le type de flag a été modifié de int à zip_flags_t m et le type de flags a été modifié de int à zip_flags_t. ZIP_AFL_CREATE_OR_KEEP_FILE_FOR_EMPTY_ARCHIVE, ZIP_AFL_IS_TORRENTZIP, et ZIP_AFL_WANT_TORRENTZIP ont été ajoutés dans libzip 1.10.0.
