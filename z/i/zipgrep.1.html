ZIPGREP(1L) ZIPGREP(1L)

NOM

zipgrep - rechercher dans les fichiers d'une archive ZIP des lignes correspondant à un motif

SYNTAXE

zipgrep [options_egrep] motif fichier[.zip] [fichier(s) ...] [-x fichier(s)_exclus ...]

DESCRIPTION

zipgrep recherchera dans les fichiers d'une archive ZIP des lignes correspondant à la chaîne ou au motif donné. zipgrep est un script shell et nécessite egrep(1) et unzip(1L) pour fonctionner. Sa sortie est identique à celle de egrep(1).

ARGUMENTS

motif
Le motif à localiser dans une archive ZIP. Toute chaîne ou expression régulière acceptée par egrep(1) peut être utilisée. fichier[.zip] Chemin de l'archive ZIP. (Les expressions génériques pour le nom de l'archive ZIP ne sont pas prises en charge.) Si le nom de fichier littéral n'est pas trouvé, le suffixe .zip est ajouté. Notez que les fichiers ZIP auto-extractibles sont pris en charge, comme toute autre archive ZIP ; spécifiez simplement l'extension .exe (si elle existe) explicitement.
[fichier(s)]
Une liste optionnelle de membres de l'archive à traiter, séparés par des espaces. Si aucun fichier membre n'est spécifié, tous les membres de l'archive ZIP sont recherchés. Des expressions régulières (caractères génériques) peuvent être utilisées pour faire correspondre plusieurs membres :
*
correspond à une séquence de 0 caractères ou plus
?
correspond à exactement 1 caractère
[...]
correspond à n'importe quel caractère unique trouvé entre les crochets ; les plages sont spécifiées par un caractère de début, un tiret et un caractère de fin. Si un point d'exclamation ou un accent circonflexe (`!' ou `^') suit le crochet ouvrant, alors la plage de caractères entre les crochets est complétée (c'est-à-dire que tout sauf les caractères entre les crochets est considéré comme une correspondance).
(Assurez-vous de mettre entre guillemets tout caractère qui pourrait autrement être interprété ou modifié par le système d'exploitation.)
[-x fichier(s)_exclus]
Une liste optionnelle de membres de l'archive à exclure du traitement. Les caractères génériques correspondant aux séparateurs de répertoires (`/'), cette option peut être utilisée pour exclure tous les fichiers qui se trouvent dans des sous-répertoires. Par exemple, ``zipgrep grumpy foo *.[ch] -x */*'' rechercherait la chaîne ``grumpy'' dans tous les fichiers sources C du répertoire principal de l'archive ``foo'', mais aucun dans les sous-répertoires. Sans l'option -x, tous les fichiers sources C de tous les répertoires du fichier zip seraient recherchés.

OPTIONS

Toutes les options précédant le nom de fichier de l'archive ZIP sont transmises à egrep(1).
