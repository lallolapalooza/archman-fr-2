ZIP_SOURCE_BUFFER(3) Manuel des fonctions de bibliothèque ZIP_SOURCE_BUFFER(3)

NOM

zip_source_buffer, zip_source_buffer_create — créer une source zip à partir d'un tampon

BIBLIOTHÈQUE

libzip (-lzip)

SYNTAXE

#include <zip.h>

zip_source_t *
zip_source_buffer(zip_t *archive, const void *data, zip_uint64_t len, int freep);

zip_source_t *
zip_source_buffer_create(const void *data, zip_uint64_t len, int freep, zip_error_t *error);

DESCRIPTION

Les fonctions zip_source_buffer() et zip_source_buffer_create() créent une source zip à partir du tampon data de taille len. Si freep est différent de zéro, le tampon sera libéré lorsqu'il ne sera plus nécessaire. data doit rester valide pendant toute la durée de vie de la source créée.

La source peut être utilisée pour ouvrir une archive zip.

VALEURS DE RETOUR

En cas de succès, la source créée est retournée. Sinon, NULL est retourné et le code d'erreur dans archive ou error est défini pour indiquer l'erreur.

ERREURS

zip_source_buffer() et zip_source_buffer_create() échouent si :

[ZIP_ER_INVAL]
len est supérieur à zéro et data est NULL.
[ZIP_ER_MEMORY]
La mémoire requise n'a pas pu être allouée.

VOIR AUSSI

libzip(3), zip_file_add(3), zip_file_replace(3), zip_open_from_source(3), zip_source(5)

HISTORIQUE

zip_source_buffer() et zip_source_buffer_create() ont été ajoutées dans libzip 1.0.
