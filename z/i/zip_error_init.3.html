zip_error_init(3)

Paquet: libzip

Licences: BSD

ZIP_ERROR_INIT(3) Manuel des fonctions de bibliothèque ZIP_ERROR_INIT(3)

NOM

zip_error_init, zip_error_init_with_code — initialise une structure zip_error

BIBLIOTHÈQUE

libzip (-lzip)

SYNOPIS

#include <zip.h>

void
zip_error_init(zip_error_t *error);

void
zip_error_init_with_code(zip_error_t *error, int ze);

DESCRIPTION

La fonction zip_error_init() initialise la structure zip_error pointée par error. *error doit être alloué avant d'appeler zip_error_init().

La fonction zip_error_init_with_code() fait la même chose, mais définit en plus le code d'erreur zip à ze et le code d'erreur système à la valeur actuelle de errno(3), si approprié.

VOIR AUSSI

libzip(3), zip_error_fini(3)

HISTORIQUE

zip_error_init() et zip_error_init_with_code() ont été ajoutées dans libzip 1.0.
