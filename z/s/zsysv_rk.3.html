sous-programme zsysv_rk (character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) e, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) work, integer lwork, integer info)

ZSYSV_RK calcule la solution du système d'équations linéaires A * X = B pour les matrices SY complexes

Objectif :

!> ZSYSV_RK calcule la solution d'un système d'équations linéaires complexes A * X = B,
!> où A est une matrice symétrique N par N et X et B sont des matrices N par NRHS.
!>
!> La méthode de pivotement diagonal bornée de Bunch-Kaufman (rook) est utilisée
!> pour factoriser A comme suit :
!>    A = P*U*D*(U**T)*(P**T),  si UPLO = 'U', ou
!>    A = P*L*D*(L**T)*(P**T),  si UPLO = 'L',
!> où U (ou L) est une matrice triangulaire supérieure (ou inférieure) unitaire,
!> U**T (ou L**T) est la transposée de U (ou L), P est une matrice de permutation,
!> P**T est la transposée de P, et D est symétrique et bloc-diagonale avec des
!> blocs diagonaux de 1x1 et 2x2.
!>
!> ZSYTRF_RK est appelée pour calculer la factorisation d'une matrice symétrique
!> complexe. La forme factorisée de A est ensuite utilisée pour résoudre le
!> système d'équations A * X = B en appelant la routine BLAS3 ZSYTRS_3.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée :
!>          = 'U':  La partie supérieure de A est stockée ;
!>          = 'L':  La partie inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          En entrée, la matrice symétrique A.
!>            Si UPLO = 'U' : la partie supérieure N par N de A contient la partie
!>            triangulaire supérieure de la matrice A, et la partie strictement
!>            inférieure triangulaire de A n'est pas référencée.
!>
!>            Si UPLO = 'L' : la partie inférieure N par N de A contient la partie
!>            triangulaire inférieure de la matrice A, et la partie strictement
!>            supérieure triangulaire de A n'est pas référencée.
!>
!>          En sortie, si INFO = 0, la diagonale de la matrice bloc-diagonale
!>          D et les facteurs U ou L tels que calculés par ZSYTRF_RK :
!>            a) UNIQUEMENT les éléments diagonaux de la matrice bloc-diagonale
!>               symétrique D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k) ;
!>               (les éléments superdiagonaux (ou sous-diagonaux) de D
!>                sont stockés en sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : le facteur U dans la partie superdiagonale de A.
!>               Si UPLO = 'L' : le facteur L dans la partie sous-diagonale de A.
!>
!>          Pour plus d'informations, voir la description de la routine ZSYTRF_RK.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau COMPLEX*16, de dimension (N)
!>          En sortie, contient les sorties calculées par la routine de factorisation
!>          ZSYTRF_RK, c'est-à-dire les éléments superdiagonaux (ou sous-diagonaux)
!>          de la matrice bloc-diagonale symétrique D avec des blocs diagonaux
!>          de 1x1 ou 2x2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i), i=2:N, E(1) est mis à 0 ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          NOTE : Pour un bloc diagonal 1x1 D(k), où
!>          1 <= k <= N, l'élément E(k) est mis à 0 dans les cas
!>          UPLO = 'U' ou UPLO = 'L'.
!>
!>          Pour plus d'informations, voir la description de la routine ZSYTRF_RK.
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          Détails des échanges et de la structure bloc de D,
!>          tels que déterminés par ZSYTRF_RK.
!>
!>          Pour plus d'informations, voir la description de la routine ZSYTRF_RK.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>          En entrée, la matrice membre de droite B de taille N par NRHS.
!>          En sortie, si INFO = 0, la matrice solution X de taille N par NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension ( MAX(1,LWORK) ).
!>          Tableau de travail utilisé dans l'étape de factorisation.
!>          En sortie, si INFO = 0, WORK(1) renvoie la valeur LWORK optimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur de WORK.  LWORK >= 1. Pour une meilleure performance
!>          de l'étape de factorisation, LWORK >= max(1,N*NB), où NB est
!>          la taille de bloc optimale pour ZSYTRF_RK.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule uniquement la taille optimale du tableau WORK
!>          pour l'étape de factorisation, renvoie cette valeur comme
!>          première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>
!>          < 0 : Si INFO = -k, le k-ième argument avait une valeur illégale
!>
!>          > 0 : Si INFO = k, la matrice A est singulière, car :
!>                 Si UPLO = 'U' : la colonne k dans la partie
!>                 triangulaire supérieure de A contient uniquement des zéros.
!>                 Si UPLO = 'L' : la colonne k dans la partie
!>                 triangulaire inférieure de A contient uniquement des zéros.
!>
!>               Par conséquent, D(k,k) est exactement zéro, et les éléments
!>               superdiagonaux de la colonne k de U (ou sous-diagonaux de
!>               la colonne k de L) sont tous des zéros. La factorisation a
!>               été complétée, mais la matrice bloc-diagonale D est
!>               exactement singulière, et une division par zéro se produira si
!>               elle est utilisée pour résoudre un système d'équations.
!>
!>               NOTE : INFO ne stocke que la première occurrence d'une
!>               singularité ; toute occurrence ultérieure de singularité
!>               n'est pas stockée dans INFO, même si la factorisation
!>               s'achève toujours.
!>

zsysv_rk(3)

NOM

zsysv_rk - Résout un système d'équations linéaires avec un sous-module symétrique et une matrice de covariance définie positive.

SYNTAXE

SUBROUTINE ZSYSV_RK( UPLO, N, NB, A, LDA, D, X, LDWORK, WORK, LWORK, INFO )

    CHARACTER * 1           :: UPLO
    INTEGER                 :: N, NB, LDA, LDWORK, LWORK, INFO
    COMPLEX*16              :: A( LDA, * ), D( * ), X( LDWORK, * ), WORK( * )

Documentation des fonctions/sous-routines

Cette sous-routine résout un système d'équations linéaires Ax=B où A est une matrice hermitienne (ou symétrique) et B est un vecteur.

Les arguments sont les suivants :

  • UPLO : Caractère spécifiant si la partie supérieure ou inférieure de la matrice est stockée. 'U' pour la partie supérieure, 'L' pour la partie inférieure.
  • N : Ordre de la matrice.
  • NB : Taille du bloc utilisé pour le calcul.
  • A : Matrice d'entrée.
  • LDA : Premier indice de la dimension de A.
  • D : Vecteur des valeurs propres diagonales de la matrice de covariance.
  • X : Vecteur de sortie.
  • LDWORK : Premier indice de la dimension de X.
  • WORK : Tableau de travail.
  • LWORK : Taille du tableau WORK.
  • INFO : Indicateur d'erreur. 0 si succès, un entier négatif sinon.
