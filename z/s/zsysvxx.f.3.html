!>    ZSYSVXX utilise la factorisation par pivotement diagonal pour calculer
!>    la solution d'un système d'équations linéaires complex*16 A * X = B, où
!>    A est une matrice symétrique N x N et X et B sont des matrices N x NRHS.
!>
!>    Si demandé, des bornes d'erreur normées et des bornes d'erreur
!>    composantes maximales sont retournées. ZSYSVXX retournera une
!>    solution avec une petite erreur garantie (O(eps) où eps est la
!>    précision de la machine de travail) à moins que la matrice ne soit
!>    très mal conditionnée, auquel cas un avertissement est retourné.
!>    Les numéros de condition pertinents sont également calculés et
!>    retournés.
!>
!>    ZSYSVXX accepte des factorisations et des facteurs d'équilibrage
!>    fournis par l'utilisateur ; voir les définitions des options FACT
!>    et EQUED. La résolution avec raffinement et l'utilisation d'une
!>    factorisation d'un appel précédent à ZSYSVXX produiront également
!>    une solution avec soit des erreurs O(eps), soit des avertissements,
!>    mais nous ne pouvons pas affirmer cela pour des factorisations et
!>    des facteurs d'équilibrage généralement fournis par l'utilisateur
!>    s'ils diffèrent de ce que ZSYSVXX produirait lui-même.
!>

Description :

!>
!>    Les étapes suivantes sont effectuées :
!>
!>    1. Si FACT = 'E', des facteurs d'échelle en double précision sont calculés
!>    pour équilibrer le système :
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle
!>    de la matrice A, mais si l'équilibrage est utilisé, A est écrasé par
!>    diag(S)*A*diag(S) et B par diag(S)*B.
!>
!>    2. Si FACT = 'N' ou 'E', la décomposition LU est utilisée pour factoriser
!>    la matrice A (après équilibrage si FACT = 'E') comme suit :
!>
!>       A = U * D * U**T,  si UPLO = 'U', ou
!>       A = L * D * L**T,  si UPLO = 'L',
!>
!>    où U (ou L) est un produit de matrices de permutation et triangulaires
!>    unitaires supérieures (inférieures), et D est une matrice symétrique
!>    et bloc-diagonale avec des blocs diagonaux de 1x1 et 2x2.
!>
!>    3. Si un D(i,i)=0, rendant D singulière, la routine retourne avec
!>    INFO = i. Sinon, la forme factorisée de A est utilisée pour estimer
!>    le numéro de condition de la matrice A (voir l'argument RCOND).
!>    Si l'inverse du numéro de condition est inférieur à la précision de
!>    la machine, la routine continue à résoudre pour X et à calculer des
!>    bornes d'erreur comme décrit ci-dessous.
!>
!>    4. Le système d'équations est résolu pour X en utilisant la forme
!>    factorisée de A.
!>
!>    5. Par défaut (sauf si PARAMS(LA_LINRX_ITREF_I) est mis à zéro),
!>    la routine utilisera le raffinement itératif pour tenter d'obtenir
!>    une petite erreur et des bornes d'erreur. Le raffinement calcule le
!>    résidu avec une précision au moins double de la précision de travail.
!>
!>    6. Si l'équilibrage a été utilisé, la matrice X est prémultipliée par
!>    diag(R) de sorte qu'elle résolve le système original avant
!>    l'équilibrage.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS.
!>     Ces réglages déterminent comment le raffinement est effectué, mais
!>     les valeurs par défaut sont souvent acceptables. Si les valeurs par
!>     défaut sont acceptables, les utilisateurs peuvent passer NPARAMS = 0
!>     ce qui empêche le code source d'accéder à l'argument PARAMS.
!>

Function/Subroutine Documentation

ZSYSVXX computes the solution to a complex system of linear equations A * X = B, A * X = B, where A is an N-by-N complex symmetric indefinite matrix, and X and B are N-by-NRHS matrices. Error bounds on the solution are computed, and perturbations of the input are considered.

It uses the partial pivoting block inversion method.

Arguments:

  • FACT
    Specifies whether or not the factored form of the matrix A is supplied on entry. See Parameters below.

  • UPLO
    CHARACTER*1. Specifies whether the matrix A is upper or lower triangular.
    ='U': Upper triangular
    ='L': Lower triangular

  • N
    INTEGER. The order of the matrix A. N >= 0.

  • NRHS
    INTEGER. The number of right hand sides, i.e., the number of columns of the matrices B and X. 0 <= NRHS <= N.

  • A
    COMPLEX*16 array, dimension (LDA,N). On entry, the symmetric matrix A. On exit, if FACT ='F', A is overwritten by details of its factorization.

  • LDA
    INTEGER. The leading dimension of the array A. LDA >= max(1,N).

  • AF
    COMPLEX*16 array, dimension (LDAF,N). If FACT ='F', AF is the factored form of A. If FACT ='N', AF is used to store the factored form of A. On exit, AF is the factored form of A.

  • LDAF
    INTEGER. The leading dimension of the array AF. LDAF >= max(1,N).

  • IPIV
    INTEGER array, dimension (N). If FACT ='F', the pivot indices array previously computed and saved by ZSYSVX. If FACT ='N', IPIV is used to store the pivot indices computed by ZSYSVXX. On exit, IPIV contains the pivot indices.

  • C
    COMPLEX*16 array, dimension (LDC,NRHS). On exit, the solution matrix X to the system of equations. Rows 1 to N of C contain the solution matrix X.

  • LDC
    INTEGER. The leading dimension of the array C. LDC >= max(1,N).

  • R
    DOUBLE PRECISION array, dimension (LDR,NRHS). On exit, the estimate of the relative backward error of each solution C(j), j=1:NRHS. With double precision, R(j) is an estimate of the largest relative perturbation in the i-th equation of the system matrix A or the i-th element of the right hand side vector b_i, that is needed in order to satisfy the equation A*x = b. For example, if the i-th row and column of A were scaled by a factor of (1 + delta_i) where |delta_i|= R(j), then the i-th equation would be exactly satisfied. R(j) is returned equal to the smallest value of max_i |delta_i| that is required for the j-th solution. If R(j) is large, it may indicate that the column j of A is small, or that A is ill-conditioned. R(j) is computed from the equation:

    R(j) = max_i(|A*x - b|_i) / (|A|_op * |x|_op * eps)

    where eps is the machine epsilon for the data type of A. This is the componentwise backward error.

    The term |A|_op is the infinity norm of A, and |x|_op is the infinity norm of x. The term max_i(|A*x - b|_i) is the infinity norm of the residual vector r = Ax - b.

    If R(j) is the quantity computed above, then the solution is guaranteed to be non singular if R(j) < 1. Note that this is not the same as the condition number of the matrix A.

    If R(j) is small (e.g. R(j) < 1), the solution C(j) is likely to be accurate. If R(j) is large, then the solution C(j) may have very few accurate digits, or the system may be singular.

    The algorithm can compute R(j) using either the infinity norm or the 1-norm. The algorithm defaults to the infinity norm.

  • LDR
    INTEGER. The leading dimension of the array R. LDR >= max(1,NRHS).

  • EQN
    DOUBLE PRECISION array, dimension (N). On exit, EQN(i) contains the equilibrium norm of the i-th row of A. The equilibrium norm is defined as:

    EQN(i) = max(|A(i,j)| * sqrt(N), |A(i,i)|)

    This is used in computing the componentwise error bound. If the i-th row and column of A are scaled by a factor of (1 + delta_i) where max_i |delta_i| = SE(j), then the j-th solution is exact.
