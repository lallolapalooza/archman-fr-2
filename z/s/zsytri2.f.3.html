sous-programme zsytri2 (caractère uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, complexe*16, dimension( * ) work, entier lwork, entier info)

ZSYTRI2

Purpose:

!>
!> ZSYTRI2 calcule l'inverse d'une matrice symétrique indéfinie COMPLEX*16
!> A en utilisant la factorisation A = U*D*U**T ou A = L*D*L**T calculée par
!> ZSYTRF. ZSYTRI2 définit la DIMENSION PRINCIPALE de l'espace de travail
!> avant d'appeler ZSYTRI2X qui calcule réellement l'inverse.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure, forme est A = U*D*U**T;
!>          = 'L':  Triangulaire inférieure, forme est A = L*D*L**T.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, la matrice diagonale par blocs D et les multiplicateurs
!>          utilisés pour obtenir le facteur U ou L calculés par ZSYTRF.
!>
!>          À la sortie, si INFO = 0, l'inverse (symétrique) de la matrice originale.
!>          Si UPLO = 'U', la partie triangulaire supérieure de l'inverse est formée
!>          et la partie de A sous la diagonale n'est pas référencée ; si UPLO = 'L',
!>          la partie triangulaire inférieure de l'inverse est formée et la partie
!>          de A au-dessus de la diagonale n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          Détails des échanges et de la structure par blocs de D
!>          tels que déterminés par ZSYTRF.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (N+NB+1)*(NB+3)
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          WORK a une taille >= (N+NB+1)*(NB+3)
!>          Si LDWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>           calcule :
!>              - la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK,
!>              - et aucun message d'erreur lié à LDWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) = 0 ; la matrice est singulière et son
!>               inverse n'a pas pu être calculé.
!>
