subroutine zsyconvf (uplo, way, n, a, lda, e, ipiv, info)
ZSYCONVF

Documentation de la fonction/sous-programme

sous-programme zsyconvf (character uplo, character way, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) e, integer, dimension( * ) ipiv, integer info)

ZSYCONVF

But:

!> Si le paramètre WAY = 'C':
!> ZSYCONVF convertit le format de sortie de la factorisation utilisé dans
!> ZSYTRF fourni en entrée dans le paramètre A dans le format de sortie de la factorisation
!> utilisé dans ZSYTRF_RK (ou ZSYTRF_BK) qui est stocké en sortie dans les paramètres A et E.
!> Il convertit également sur place les détails des échanges stockés dans IPIV du format
!> utilisé dans ZSYTRF vers le format utilisé dans ZSYTRF_RK (ou ZSYTRF_BK).
!>
!> Si le paramètre WAY = 'R':
!> ZSYCONVF effectue la conversion dans la direction inverse, c'est-à-dire
!> convertit le format de sortie de la factorisation utilisé dans ZSYTRF_RK
!> (ou ZSYTRF_BK) fourni en entrée dans les paramètres A et E dans le format de sortie de la factorisation
!> utilisé dans ZSYTRF qui est stocké en sortie dans le paramètre A.
!> Il convertit également sur place les détails des échanges stockés dans IPIV du format
!> utilisé dans ZSYTRF_RK (ou ZSYTRF_BK) vers le format utilisé dans ZSYTRF.
!>
!> ZSYCONVF peut également convertir dans le cas de matrices hermitiennes, c'est-à-dire entre
!> les formats utilisés dans ZHETRF et ZHETRF_RK (ou ZHETRF_BK).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont
!>          stockés sous forme de matrice triangulaire supérieure ou inférieure A.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

WAY

!>          WAY est CHARACTER*1
!>          = 'C': Convertir
!>          = 'R': Revertir (annuler la conversion)
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>
!>          1) Si WAY ='C':
!>
!>          En entrée, contient les détails de la factorisation dans le format utilisé dans
!>          ZSYTRF:
!>            a) tous les éléments de la matrice diagonale par blocs symétrique
!>               D sur la diagonale de A et sur la supradiagonale
!>               (ou sous-diagonale) de A, et
!>            b) Si UPLO = 'U': multiplicateurs utilisés pour obtenir le facteur U
!>               dans la partie supradiagonale de A.
!>               Si UPLO = 'L': multiplicateurs utilisés pour obtenir le facteur L
!>               dans la partie sous-diagonale de A.
!>
!>          En sortie, contient les détails de la factorisation dans le format utilisé dans
!>          ZSYTRF_RK ou ZSYTRF_BK:
!>            a) UNIQUEMENT les éléments diagonaux de la matrice diagonale par blocs symétrique
!>               D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k);
!>               (les éléments supradiagonaux (ou sous-diagonaux) de D
!>                sont stockés en sortie dans le tableau E), et
!>            b) Si UPLO = 'U': le facteur U dans la partie supradiagonale de A.
!>               Si UPLO = 'L': le facteur L dans la partie sous-diagonale de A.
!>
!>          2) Si WAY = 'R':
!>
!>          En entrée, contient les détails de la factorisation dans le format utilisé dans
!>          ZSYTRF_RK ou ZSYTRF_BK:
!>            a) UNIQUEMENT les éléments diagonaux de la matrice diagonale par blocs symétrique
!>               D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k);
!>               (les éléments supradiagonaux (ou sous-diagonaux) de D
!>                sont stockés en sortie dans le tableau E), et
!>            b) Si UPLO = 'U': le facteur U dans la partie supradiagonale de A.
!>               Si UPLO = 'L': le facteur L dans la partie sous-diagonale de A.
!>
!>          En sortie, contient les détails de la factorisation dans le format utilisé dans
!>          ZSYTRF:
!>            a) tous les éléments de la matrice diagonale par blocs symétrique
!>               D sur la diagonale de A et sur la supradiagonale
!>               (ou sous-diagonale) de A, et
!>            b) Si UPLO = 'U': multiplicateurs utilisés pour obtenir le facteur U
!>               dans la partie supradiagonale de A.
!>               Si UPLO = 'L': multiplicateurs utilisés pour obtenir le facteur L
!>               dans la partie sous-diagonale de A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau COMPLEX*16, dimension (N)
!>
!>          1) Si WAY ='C':
!>
!>          En entrée, juste un espace de travail.
!>
!>          En sortie, contient les éléments supradiagonaux (ou sous-diagonaux)
!>          de la matrice diagonale par blocs symétrique D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) est mis à 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          2) Si WAY = 'R':
!>
!>          En entrée, contient les éléments supradiagonaux (ou sous-diagonaux)
!>          de la matrice diagonale par blocs symétrique D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U': E(i) = D(i-1,i),i=2:N, E(1) n'est pas référencé;
!>          Si UPLO = 'L': E(i) = D(i+1,i),i=1:N-1, E(N) n'est pas référencé.
!>
!>          En sortie, n'est pas modifié.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>
!>          1) Si WAY ='C':
!>          En entrée, détails des échanges et de la structure par blocs de D
!>          dans le format utilisé dans ZSYTRF.
!>          En sortie, détails des échanges et de la structure par blocs de D
!>          dans le format utilisé dans ZSYTRF_RK
!>          ( ou ZSYTRF_BK).
!>
!>          1) Si WAY ='R':
!>          En entrée, détails des échanges et de la structure par blocs de D
!>          dans le format utilisé dans ZSYTRF_RK
!>          ( ou ZSYTRF_BK).
!>          En sortie, détails des échanges et de la structure par blocs de D
!>          dans le format utilisé dans ZSYTRF.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  Sortie réussie
!>          < 0:  Si INFO = -i, le i-ème argument avait une valeur illégale.
!>
