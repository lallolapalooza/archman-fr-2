sous-routine zspt01 (caractère uplo, entier n, complexe*16, dimension( * ) a, complexe*16, dimension( * ) afac, entier, dimension( * ) ipiv, complexe*16, dimension( ldc, * ) c, entier ldc, double précision, dimension( * ) rwork, double précision resid)

ZSPT01

But :

!>
!> ZSPT01 reconstruit une matrice indéfinie symétrique A à partir de sa
!> factorisation par pivotement diagonal A = U*D*U' ou A = L*D*L' et calcule
!> le résidu
!>    norme( C - A ) / ( N * norme(A) * EPS ),
!> où C est la matrice reconstruite et EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice hermitienne A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          La matrice symétrique d'origine A, stockée sous forme de matrice
!>          triangulaire empactée.
!>

AFAC

!>          AFAC est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          La forme factorisée de la matrice A, stockée sous forme de matrice
!>          triangulaire empactée. AFAC contient la matrice diagonale par blocs D
!>          et les multiplicateurs utilisés pour obtenir le facteur L ou U à partir de
!>          la factorisation L*D*L' ou U*D*U' telle que calculée par ZSPTRF.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot de ZSPTRF.
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC,N)
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C.  LDC >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          Si UPLO = 'L', norme(L*D*L' - A) / ( N * norme(A) * EPS )
!>          Si UPLO = 'U', norme(U*D*U' - A) / ( N * norme(A) * EPS )
!>
