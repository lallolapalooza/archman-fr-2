sous-programme zsyequb (caractère uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, double précision, dimension( * ) s, double précision scond, double précision amax, complexe*16, dimension( * ) work, entier info)

ZSYEQUB

Objectif :

!>
!> ZSYEQUB calcule les échelles de ligne et de colonne destinées à équilibrer une
!> matrice symétrique A (par rapport à la norme euclidienne) et à réduire
!> son nombre de conditionnement. Les facteurs d'échelle S sont calculés par
!> l'algorithme BIN (voir références) de sorte que la matrice mise à l'échelle B
!> avec les éléments B(i,j) = S(i)*A(i,j)*S(j) ait un nombre de
!> conditionnement dans un facteur N du plus petit nombre de conditionnement
!> possible sur toutes les mises à l'échelle diagonales possibles.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          La matrice symétrique N-par-N dont les facteurs d'échelle doivent être
!>          calculés.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

S

!>          S est un tableau DOUBLE PRÉCISION, de dimension (N)
!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!>

SCOND

!>          SCOND est DOUBLE PRÉCISION
!>          Si INFO = 0, S contient le rapport du S(i) le plus petit au
!>          S(i) le plus grand. Si SCOND >= 0.1 et AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas utile de mettre à l'échelle avec S.
!>

AMAX

!>          AMAX est DOUBLE PRÉCISION
!>          La plus grande valeur absolue de n'importe quel élément de matrice. Si AMAX est
!>          très proche du dépassement de capacité ou de la sous-fluctuation, la
!>          matrice doit être mise à l'échelle.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>          > 0 : si INFO = i, le i-ème élément diagonal est non positif.
!>
