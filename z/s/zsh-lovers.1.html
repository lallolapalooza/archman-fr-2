SCRIPTING DE SHELL

Cette section fournit quelques exemples pour les éléments de scripts shell souvent nécessaires. Notez que vous ne devriez pas sinon la plupart des exemples ne fonctionneront pas. Analyser les options dans les scripts shell. Exemple tiré de ZWS par Adam Chodorowski (http://www.chodorowski.com/projects/zws/):

parse_options()
{
    o_port=(-p 9999)
    o_root=(-r WWW)
    o_log=(-d ZWS.log)
    zparseopts -K -- p:=o_port r:=o_root l:=o_log h=o_help
    if [[ $? != 0 || "$o_help" != "" ]]; then
        echo Usage: $(basename "$0") "[-p PORT] [-r DIRECTORY]"
        exit 1
    fi
    port=$o_port[2]
    root=$o_root[2]
    log=$o_log[2]
    if [[ $root[1] != '/' ]]; then root="$PWD/$root"; fi
}

# maintenant utiliser la fonction :

parse_options $*

ALIAS

Les alias de suffixe sont pris en charge dans zsh depuis la version 4.2.0. Quelques exemples :

alias -s tex=vim
alias -s html=w3m
alias -s org=w3m

Maintenant, appuyer sur la touche retour après avoir entré foobar.tex démarre vim avec foobar.tex. Appeler un fichier html exécute le navigateur w3m. www.zsh.org et appuyer sur entrée démarre w3m avec l'argument www.zsh.org. Les alias globaux peuvent être utilisés n'importe où dans la ligne de commande. Exemple :

$ alias -g C='| wc -l'
$ grep alias ~/.zsh/* C
443

COMPLETION

Voir aussi les manuels 1 zshcompctl zshcompsys zshcompwid. zshcompctl est l'ancien style de complétion programmable zsh, zshcompsys est le nouveau système de complétion, zshcompwid sont les widgets de complétion zsh.

Certaines fonctions, comme _apt et _dpkg, sont très lentes. Vous pouvez utiliser un cache pour proxyfier la liste des résultats (comme la liste des paquets debian disponibles). Utiliser un cache :

zstyle ':completion:*' use-cache on
zstyle ':completion:*' cache-path ~/.zsh/cache

Empêcher les fichiers/répertoires CVS d'être complétés :

zstyle ':completion:*:(all-|)files' ignored-patterns '(|*/)CVS'
zstyle ':completion:*:cd:*' ignored-patterns '(*/)#CVS'

Correspondance floue des complétions lorsqu'elles sont mal tapées :

zstyle ':completion:*' completer _complete _match _approximate
zstyle ':completion:*:match:*' original only
zstyle ':completion:*:approximate:*' max-errors 1 numeric

Et si vous voulez que le nombre d'erreurs autorisées par _approximate augmente avec la longueur de ce que vous avez tapé jusqu'à présent :

zstyle -e ':completion:*:approximate:*' \
        max-errors 'reply=($((($#PREFIX+$#SUFFIX)/3))numeric)'

Ignorer les fonctions de complétion pour les commandes que vous n'avez pas :

zstyle ':completion:*:functions' ignored-patterns '_*'

Avec des fonctions d'aide comme :

xdvi() { command xdvi ${*:-*.dvi(om[1])} }

vous pouvez éviter d'avoir à compléter dans de nombreux cas, mais si vous le faites, vous pourriez vouloir tomber immédiatement dans la sélection de menu et avoir les mots triés par date :

zstyle ':completion:*:*:xdvi:*' menu yes select
zstyle ':completion:*:*:xdvi:*' file-sort time

Compléter les identifiants de processus avec sélection de menu :

zstyle ':completion:*:*:kill:*' menu yes select
zstyle ':completion:*:kill:*'   force-list always

Si vous finissez par utiliser un répertoire comme argument, cela supprimera la barre oblique finale (utile dans ln)

zstyle ':completion:*' squeeze-slashes true

cd ne sélectionnera jamais le répertoire parent (par exemple : cd ../<TAB>) :

zstyle ':completion:*:cd:*' ignore-parents parent pwd

Une autre méthode pour le *changement rapide de répertoire*. Ajoutez ceci à votre ~/.zshrc, puis tapez simplement « cd ..../dir »

rationalise-dot() {
  if [[ $LBUFFER = *.. ]]; then
    LBUFFER+=/..
  else
    LBUFFER+=.
  fi
}
zle -N rationalise-dot
bindkey . rationalise-dot

(Récursif) Globbing - Exemples

Une liste des qualificateurs de glob valides se trouve dans zshexpn(1). Remarque : **/ est équivalent à (*/)#! Par exemple :

$ print (*/)#zsh_us.ps
zsh-4.2.3/Doc/zsh_us.ps
$ print **/zsh_us.ps
zsh-4.2.3/Doc/zsh_us.ps
# Rechercher `README' dans tous les sous-répertoires
  $ ls -l **/README
# trouver les répertoires qui contiennent à la fois ``index.php'' et ``index.html'', ou en
# général, les répertoires qui contiennent plus d'un fichier correspondant à ``index.*''

  # ou
  $ ls **/*(D/e:'l=($REPLY/index.*(N)); (( $#l >= 2 ))':)
# Commande find pour rechercher le nom du répertoire au lieu du nom de base

Utilisation des modificateurs

Les modificateurs sont un mécanisme puissant qui vous permet de modifier les résultats renvoyés par l'expansion de paramètres, de noms de fichiers et d'historique. Voir zshexpn(1) pour plus de détails.

# NOTE : Zsh 4.3.4 nécessaire !
  $ autoload -U age
# fichiers modifiés aujourd'hui
  $ print *(e:age today now:)
# fichiers modifiés depuis 17h
  $ print *(e-age 17:00 now-)
# ... depuis 17h hier
  $ print *(e-age yesterday,17:00 now-)
# ... depuis Noël dernier avant aujourd'hui
  $ print *(e-age 2006/12/25 today-)
# ... avant-hier
  $ print *(e-age 1970/01/01 yesterday-)
# tous les fichiers modifiés entre le début et la fin de ces dates
  $ print *(e:age 2006/10/04 2006/10/09:)
# tous les fichiers modifiés à cette date
  $ print *(e:age 2006/10/04:)
# Fournir les heures.
  $ print *(e-age 2006/10/04:10:15 2006/10/04:10:45-)
# Supprimer un composant de chemin d'accès final, en laissant la tête. Cela fonctionne comme
# `dirname'.
  $ echo =ls(:h)
  /bin
# Supprimer tous les composants de chemin d'accès initiaux, en laissant la queue. Cela fonctionne
# comme `basename'.
  $ echo =ls(:t)
  ls
# Supprimer le suffixe de chaque fichier (*.sh dans cet exemple)
   $f:e est l'extension de fichier de $f
   :h --> head (dirname)
   :t --> tail (basename)
   :r --> rest (extension supprimée)
  $ for f (*.sh) mv $f $f:r
# Supprimer une extension de nom de fichier de la forme `.xxx', en laissant le nom racine.
  $ echo $PWD
  /usr/src/linux
  $ echo $PWD:t
  linux
# Supprimer tout sauf l'extension.
  $ foo=23.42
  $ echo $foo
  23.42
  $ echo $foo:e
  42
# Afficher la nouvelle commande mais ne pas l'exécuter. Ne fonctionne qu'avec l'expansion de l'historique.
  $ echo =ls(:h)
  /bin
  $ !echo:p
  $ echo =ls(:h)
# Mettre entre guillemets les mots substitués, en échappant les substitutions ultérieures.
  $ bar="23'42"
  $ echo $bar
  23'42
  $ echo $bar:q
  23\'42
# Convertir les mots en minuscules.
  $ bar=FOOBAR
  $ echo $bar
  FOOBAR
  $ echo $bar:l
  foobar
# Convertir les mots en majuscules.
  $ bar=foobar
  $ echo $bar
  foobar
  $ echo $bar:u
  FOOBAR
# convertir le 1er caractère d'un mot en majuscule
  $ foo="one two three four"
  $ print -r -- "${(C)foo}"
  One Two Three Four

# envoie à la commande nommée les chaînes données en entrée
  $ zpty -w PW $2
  $ zpty -r PW z '*mot de passe:'
  $ zpty -w PW $2
# La seconde forme, avec l'option -d, est utilisée pour supprimer des commandes
# précédemment démarrées, en fournissant une liste de leurs noms. Si aucun nom
# n'est donné, toutes les commandes sont supprimées. La suppression d'une commande provoque l'envoi du signal HUP
# au processus correspondant.
  $ zpty -d PW

Pour migrer votre invite de commande bash vers zsh, utilisez le script bash2zshprompt situé dans la distribution source de zsh sous Misc.

Pour la migration de (t)csh vers zsh, utilisez l'outil c2z qui convertit les alias, les variables d'environnement et shell de csh en zsh. Il fonctionne en exécutant csh et en lui demandant de rapporter les alias et les variables. Le script convertit ensuite ces informations en fichiers de démarrage zsh. Il présente quelques problèmes et informations d'utilisation qui sont documentés en haut de ce script.

Voici des fonctions pour définir le titre et le statut matériel (hardstatus) d'un XTerm ou de GNU Screen à zsh et au répertoire courant, respectivement, lorsque l'invite de commande s'affiche, et au nom de la commande et au reste de la ligne de commande, respectivement, lorsqu'une commande est exécutée :

function title {
      if [[ $TERM == "screen" ]]; then
        # Utilisez ces deux commandes pour GNU Screen :
        print -nR $' 33k'$1$' 33'\
        print -nR $' 33]0;'$2$''
      elif [[ $TERM == "xterm" || $TERM == "rxvt" ]]; then
        # Utilisez celle-ci à la place pour les XTerms :
        print -nR $' 33]0;'$*$''
      fi
}
function precmd { title zsh "$PWD" }
function preexec {
    emulate -L zsh
    local -a cmd; cmd=(${(z)1})
    title $cmd[1]:t "$cmd[2,-1]"
}

Insérez la ligne suivante dans votre ~/.screenrc pour voir ce magnifique statut matériel :

caption always "%3n %t%? (%u)%?%?: %h%?"
