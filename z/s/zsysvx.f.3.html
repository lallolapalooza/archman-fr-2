sous-routine zsysvx (character fact, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer info)

ZSYSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices SY

Objectif:

!>
!> ZSYSVX utilise la factorisation par pivotement diagonal pour calculer la
!> solution d'un système linéaire complexe A * X = B,
!> où A est une matrice symétrique N-par-N et X et B sont des matrices N-par-NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de condition sont également
!> fournies.
!>

Description:

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la méthode de pivotement diagonal est utilisée pour factoriser A.
!>    La forme de la factorisation est
!>       A = U * D * U**T,  si UPLO = 'U', ou
!>       A = L * D * L**T,  si UPLO = 'L',
!>    où U (ou L) est un produit de matrices de permutation et triangulaires supérieures (inférieures) unitaires, et D est symétrique et bloc-diagonale avec
!>    des blocs diagonaux de 1-par-1 et 2-par-2.
!>
!> 2. Si un D(i,i)=0, de sorte que D soit exactement singulier, alors la routine
!>    retourne avec INFO = i. Sinon, la forme factorisée de A est utilisée
!>    pour estimer le nombre de condition de la matrice A. Si le
!>    réciproque du nombre de condition est inférieur à la précision machine,
!>    INFO = N+1 est retourné à titre d'avertissement, mais la routine continue
!>    à résoudre pour X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 4. Un raffinement itératif est appliqué pour améliorer la solution calculée
!>    et calculer les bornes d'erreur et les estimations d'erreur arrière
!>    pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de A a été fournie ou non à l'entrée.
!>          = 'F':  À l'entrée, AF et IPIV contiennent la forme factorisée
!>                  de A.  A, AF et IPIV ne seront pas modifiés.
!>          = 'N':  La matrice A sera copiée dans AF et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice symétrique A.  Si UPLO = 'U', la partie triangulaire
!>          supérieure N-par-N de A contient la partie triangulaire
!>          supérieure de la matrice A, et la partie strictement triangulaire
!>          inférieure de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          triangulaire inférieure N-par-N de A contient la partie triangulaire
!>          inférieure de la matrice A, et la partie strictement triangulaire
!>          supérieure de A n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>          Si FACT = 'F', alors AF est un argument d'entrée et à l'entrée
!>          contient la matrice bloc-diagonale D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L de la factorisation
!>          A = U*D*U**T ou A = L*D*L**T, tel que calculé par ZSYTRF.
!>
!>          Si FACT = 'N', alors AF est un argument de sortie et à la sortie
!>          retourne la matrice bloc-diagonale D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L de la factorisation
!>          A = U*D*U**T ou A = L*D*L**T.
!>

LDAF

!>          LDAF est INTEGER
!>          La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et à l'entrée
!>          contient les détails des échanges et de la structure de bloc
!>          de D, tels que déterminés par ZSYTRF.
!>          Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k) ont été
!>          échangées et D(k,k) est un bloc diagonal 1-par-1.
!>          Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0, alors les lignes et
!>          colonnes k-1 et -IPIV(k) ont été échangées et D(k-1:k,k-1:k)
!>          est un bloc diagonal 2-par-2.  Si UPLO = 'L' et IPIV(k) =
!>          IPIV(k+1) < 0, alors les lignes et colonnes k+1 et -IPIV(k) ont été
!>          échangées et D(k:k+1,k:k+1) est un bloc diagonal 2-par-2.
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et à la sortie
!>          contient les détails des échanges et de la structure de bloc
!>          de D, tels que déterminés par ZSYTRF.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          La matrice membre de droite B de taille N-par-NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N-par-NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'estimation du réciproque du nombre de condition de la matrice
!>          A.  Si RCOND est inférieur à la précision machine (en
!>          particulier, si RCOND = 0), la matrice est singulière à la précision
!>          de travail.  Cette condition est indiquée par un code de retour
!>          INFO > 0.
!>

FERR

!>          FERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j).  L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          majoration de l'erreur réelle.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur
!>          solution X(j) (c'est-à-dire le plus petit changement relatif dans
!>          tout élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

        IMPLICIT NONE
        CHARACTER * 1          :: FACT, UPLO
        INTEGER                :: LDA, LDAF, LDB, LDX, N
        INTEGER                :: IPIV( * )
        INTEGER                :: INFO
        DOUBLE PRECISION       :: RCOND
        DOUBLE PRECISION       :: AF( * ), A( * ), B( * ), FERR( * ), X( * ), WORK( * ), RWORK( * )

Function/Subroutine Documentation

zsysvx is a subroutine in LAPACK used for solving systems of linear equations with a complex Hermitian matrix, possibly ill-conditioned. It uses the full matrix factor of A to compute the solution X to the system of linear equations AX = B. It also computes an estimate of the reciprocal condition number, RCOND, and the error bounds FERR and BERR for the computed solution X.

Arguments:

FACT
        CHARACTER*1
        Specifies whether or not the factored form of the matrix A is
        provided on entry.
        = 'E':  On entry, A is an n x n matrix. The return value
                of ZSYSUX contains the factored form AF of A.
        = 'F':  On entry, AF is an n x n matrix. The factorization
                of A is already computed and stored in AF.
UPLO
        CHARACTER*1
        Specifies whether the matrix A is upper or lower triangular.
        = 'U':  Upper triangle of A is stored.
        = 'L':  Lower triangle of A is stored.
N
        INTEGER
        The order of the matrix A. N >= 0.
A
        COMPLEX*16 array, dimension (LDA,N)
        On entry, the n x n matrix A.
        If FACT = 'E', A is overwritten by the factors L (from
        an L*D*L**H factorization) of A.
LDA
        INTEGER
        The leading dimension of the array A. LDA >= max(1,N).
AF
        COMPLEX*16 array, dimension (LDAF,N)
        On exit, if FACT = 'E', AF contains the factored form of A.
        AF is not referenced if FACT = 'F'.
LDAF
        INTEGER
        The leading dimension of the array AF. LDAF >= max(1,N).
IPIV
        INTEGER array, dimension (N)
        Details of the partial pivoting obtained from the factorization.
        The correct column swaps are determined by the entries of IPIV.
        More precisely, the i-th row swap is given by IPIV(I).
        IPIV is not referenced if FACT = 'F'.
B
        COMPLEX*16 array, dimension (LDB,NRHS)
        On entry, the n x n right hand side matrix of the system.
        On exit, B is overwritten by the solution matrix X.
LDB
        INTEGER
        The leading dimension of the array B. LDB >= max(1,N).
X
        COMPLEX*16 array, dimension (LDX,NRHS)
        On entry, the n x n matrix of approximate solutions.
        On exit, the matrix X of solutions.
LDX
        INTEGER
        The leading dimension of the array X. LDX >= max(1,N).
RCOND
        DOUBLE PRECISION
        On exit, an estimate of the reciprocal of the condition number
        of A. RCOND is always positive.
FERR
        DOUBLE PRECISION array, dimension (NRHS)
        On exit, FERR(j) is an estimate of the forward error bound for
        the j-th solution vector, and is computed as
        FERR(j) = norm(X(j) - Xhat(j)) / norm(X(j))
        where Xhat(j) is the j-th solution computed by the routine. If
        norm(X(j)) is not in the range [emin, rmax], FERR(j) is not
        computed, and is set to +inf.
BERR
        DOUBLE PRECISION array, dimension (NRHS)
        On exit, BERR(j) is the componentwise forward error bound for
        the j-th solution vector x(j) of the system Ax=b, one computed
        by this routine.
        BERR(j) = max( abs( X(i,j) - Xhat(i,j) ) ) /
                  ( max( abs( X(i,j) ) ) * ( 1 + abs(dx(i)/x(i)) ) )
        If DLAMCH('E') is the machine epsilon, the error is computed
        as follows:
        If norm(ABERRI(j)) is not in the range [emin, rmax],
        then BERR(j) is not computed, and is set to +inf.
WORK
        COMPLEX*16 array, dimension (MAX(1,LWORK))
        On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
LWORK
        INTEGER
        The length of WORK. LWORK >= max(1,2*N), and for best
        performance, when FACT = 'N', LWORK >= max(1,2*N,N*NB), where
        NB is the optimal blocksize for ZSYTRF.
        If LWORK = -1, then a workspace query is assumed; the routine
        only calculates the optimal size of the WORK array, returns
        this value as the first entry of the WORK array, and no error
        message related to LWORK is issued by XERBLA.
RWORK
        DOUBLE PRECISION array, dimension (N)
INFO
        INTEGER
        = 0: successful exit
        < 0: if INFO = -i, the i-th argument had an illegal value
        > 0: if INFO = i, and i is
              <= N:  D(i,i) is exactly zero.  The factorization
                     has been completed but the factor D is exactly
                     singular, so the solution and error bounds could
                     not be computed. RCOND = 0 is returned.
              = N+1: D is nonsingular, but RCOND is less than machine
                     precision, meaning that the matrix is singular
                     to working precision.  Nevertheless, the
                     solution and error bounds are computed because
                     there are a number of situations where the
                     computed solution can be more accurate than the
                     value of RCOND would suggest.
