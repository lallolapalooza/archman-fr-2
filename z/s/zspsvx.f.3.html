Documentation de la fonction/sous-routine

sous-routine zspsvx (character fact, character uplo, integer n, integer nrhs, complex*16, dimension( * ) ap, complex*16, dimension( * ) afp, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZSPSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices symétriques autres stockées sous forme compacte

Objectif :

!>
!> ZSPSVX utilise la factorisation par pivotement diagonal A = U*D*U**T ou
!> A = L*D*L**T pour calculer la solution d'un système linéaire complexe
!> A * X = B, où A est une matrice symétrique N-par-N stockée sous forme
!> compacte et X et B sont des matrices N-par-NRHS.
!>
!> Les bornes d'erreur sur la solution et une estimation de la condition sont
!> également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la méthode de pivotement diagonal est utilisée pour
!>    factoriser A comme suit :
!>       A = U * D * U**T, si UPLO = 'U', ou
!>       A = L * D * L**T, si UPLO = 'L',
!>    où U (ou L) est un produit de matrices triangulaires supérieures (ou
!>    inférieures) unitaires et de permutation, et D est une matrice
!>    symétrique et bloc-diagonale avec des blocs diagonaux de 1x1 et 2x2.
!>
!> 2. Si un D(i,i)=0, de sorte que D est exactement singulier, alors la
!>    routine retourne avec INFO = i. Sinon, la forme factorisée de A est
!>    utilisée pour estimer le nombre de condition de la matrice A. Si
!>    l'inverse du nombre de condition est inférieur à la précision de la
!>    machine, INFO = N+1 est retourné comme avertissement, mais la routine
!>    continue quand même à résoudre pour X et à calculer les bornes d'erreur
!>    comme décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme
!>    factorisée de A.
!>
!> 4. Le raffinement itératif est appliqué pour améliorer la solution
!>    calculée et calculer les bornes d'erreur et les erreurs arrières
!>    correspondantes.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de A a été fournie ou non en
!>          entrée.
!>          = 'F' : En entrée, AFP et IPIV contiennent la forme factorisée
!>                  de A. AP, AFP et IPIV ne seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans AFP et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké.
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!>

AP

!>          AP est COMPLEX*16 array, dimension (N*(N+1)/2)
!>          Le triangle supérieur ou inférieur de la matrice symétrique A,
!>          stocké en colonne dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>

AFP

!>          AFP est COMPLEX*16 array, dimension (N*(N+1)/2)
!>          Si FACT = 'F', alors AFP est un argument d'entrée et contient en
!>          entrée la matrice bloc-diagonale D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L à partir de la factorisation
!>          A = U*D*U**T ou A = L*D*L**T calculée par ZSPTRF, stockée sous
!>          forme de matrice triangulaire compacte dans le même format de
!>          stockage que A.
!>
!>          Si FACT = 'N', alors AFP est un argument de sortie et contient en
!>          sortie la matrice bloc-diagonale D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L à partir de la factorisation
!>          A = U*D*U**T ou A = L*D*L**T calculée par ZSPTRF, stockée sous
!>          forme de matrice triangulaire compacte dans le même format de
!>          stockage que A.
!>

IPIV

!>          IPIV est INTEGER array, dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et contient en
!>          entrée les détails des échanges et de la structure en blocs de
!>          D, tels que déterminés par ZSPTRF.
!>          Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k) ont été
!>          échangées et D(k,k) est un bloc diagonal 1x1.
!>          Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0, alors les lignes et
!>          colonnes k-1 et -IPIV(k) ont été échangées et D(k-1:k,k-1:k)
!>          est un bloc diagonal 2x2. Si UPLO = 'L' et IPIV(k) =
!>          IPIV(k+1) < 0, alors les lignes et colonnes k+1 et -IPIV(k) ont été
!>          échangées et D(k:k+1,k:k+1) est un bloc diagonal 2x2.
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et contient en
!>          sortie les détails des échanges et de la structure en blocs de
!>          D, tels que déterminés par ZSPTRF.
!>

B

!>          B est COMPLEX*16 array, dimension (LDB,NRHS)
!>          La matrice du côté droit B, N-par-NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est COMPLEX*16 array, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X, N-par-NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'estimation du nombre de condition réciproque de la matrice
!>          A. Si RCOND est inférieur à la précision de la machine
!>          (en particulier, si RCOND = 0), la matrice est singulière à la
!>          précision de travail. Cette condition est indiquée par un code de
!>          retour INFO > 0.
!>

FERR

!>          FERR est DOUBLE PRECISION array, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisé par la magnitude du plus grand
!>          élément de X(j). L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          surentimation de l'erreur réelle.
!>

BERR

!>          BERR est DOUBLE PRECISION array, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque
!>          vecteur solution X(j) (c'est-à-dire le plus petit changement
!>          relatif dans n'importe quel élément de A ou B qui fait de X(j)
!>          une solution exacte).
!>

WORK

!>          WORK est COMPLEX*16 array, dimension (2*N)
!>

RWORK

!>          RWORK est DOUBLE PRECISION array, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>          < 0 : si INFO = -i
