Documentation Fonction/Sous-programme

sous-programme zsptrs (caractère uplo, entier n, entier nrhs, complexe*16, dimension( * ) ap, entier, dimension( * ) ipiv, complexe*16, dimension( ldb, * ) b, entier ldb, entier info)

ZSPTRS

But :

!>
!> ZSPTRS résout un système d'équations linéaires A*X = B avec une matrice complexe
!> symétrique A stockée en format compacté en utilisant la factorisation
!> A = U*D*U**T ou A = L*D*L**T calculée par ZSPTRF.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure, forme est A = U*D*U**T;
!>          = 'L':  Triangulaire inférieure, forme est A = L*D*L**T.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AP

!>          AP est COMPLEX*16 array, dimension (N*(N+1)/2)
!>          La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>          obtenir le facteur U ou L tels que calculés par ZSPTRF, stockés sous forme de
!>          matrice triangulaire compactée.
!>

IPIV

!>          IPIV est INTEGER array, dimension (N)
!>          Détails des échanges et de la structure par blocs de D
!>          tels que déterminés par ZSPTRF.
!>

B

!>          B est COMPLEX*16 array, dimension (LDB,NRHS)
!>          À l'entrée, la matrice des membres de droite B.
!>          À la sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
