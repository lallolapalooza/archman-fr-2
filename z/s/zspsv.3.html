sous-programme zspsv (uplo, n, nrhs, ap, ipiv, b, ldb, info)
ZSPSV calcule la solution du système d'équations linéaires A * X = B pour les matrices AUTRES

Documentation de la fonction/sous-programme

sous-programme zspsv (caractère uplo, entier n, entier nrhs, complexe*16, dimension( * ) ap, entier, dimension( * ) ipiv, complexe*16, dimension( ldb, * ) b, entier ldb, entier info)

ZSPSV calcule la solution du système d'équations linéaires A * X = B pour les matrices AUTRES

Objectif :

!>
!> ZSPSV calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice symétrique N-par-N stockée en format compact et X
!> et B sont des matrices N-par-NRHS.
!>
!> La méthode de pivotement diagonal est utilisée pour factoriser A comme suit :
!>    A = U * D * U**T, si UPLO = 'U', ou
!>    A = L * D * L**T, si UPLO = 'L',
!> où U (ou L) est un produit de matrices de permutation et de matrices triangulaires
!> unitaires supérieures (inférieures). D est symétrique et à blocs diagonale avec des blocs
!> diagonaux 1-par-1 et 2-par-2. La forme factorisée de A est ensuite utilisée pour
!> résoudre le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U': le triangle supérieur de A est stocké ;
!>          = 'L': le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice symétrique
!>          A, compacté colonne par colonne dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>
!>          À la sortie, la matrice diagonale par blocs D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L à partir de la factorisation
!>          A = U*D*U**T ou A = L*D*L**T calculée par ZSPTRF, stockés comme
!>          une matrice triangulaire compactée dans le même format de stockage que A.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure des blocs de D, tels que
!>          déterminés par ZSPTRF. Si IPIV(k) > 0, alors les lignes et colonnes
!>          k et IPIV(k) ont été échangées, et D(k,k) est un bloc diagonal 1-par-1.
!>          Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0,
!>          alors les lignes et colonnes k-1 et -IPIV(k) ont été échangées et
!>          D(k-1:k,k-1:k) est un bloc diagonal 2-par-2. Si UPLO = 'L' et
!>          IPIV(k) = IPIV(k+1) < 0, alors les lignes et colonnes k+1 et
!>          -IPIV(k) ont été échangées et D(k:k+1,k:k+1) est un bloc diagonal 2-par-2.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          À l'entrée, la matrice du membre de droite B de taille N-par-NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N-par-NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0: si INFO = i, D(i,i) est exactement zéro. La factorisation
!>                a été complétée, mais la matrice diagonale par blocs D est
!>                exactement singulière, donc la solution n'a pas pu être
!>                calculée.
!>

!>  quand N = 4, UPLO = 'U' :
!>
!>  Stockage bidimensionnel de la matrice symétrique A :
!>
!>     a11 a12 a13 a14
!>         a22 a23 a24
!>             a33 a34     (aij = aji)
!>                 a44
!>
!>  Stockage compact du triangle supérieur de A :
!>
!>  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
!>
