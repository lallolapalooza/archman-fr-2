subroutine zspsvx (character fact, character uplo, integer n, integer nrhs, complex*16, dimension( * ) ap, complex*16, dimension( * ) afp, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZSPSVX calcule la solution du système d'équations linéaires A * X = B pour des matrices AUTRES

Objectif :

!>
!> ZSPSVX utilise la factorisation par pivot de diagonale A = U*D*U**T ou
!> A = L*D*L**T pour calculer la solution d'un système linéaire complexe
!> A * X = B, où A est une matrice symétrique N par N stockée
!> au format compact et X et B sont des matrices N par NRHS.
!>
!> Les bornes d'erreur sur la solution et une estimation de la condition sont
!> également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la méthode de pivot de diagonale est utilisée pour factoriser A comme
!>       A = U * D * U**T,  si UPLO = 'U', ou
!>       A = L * D * L**T,  si UPLO = 'L',
!>    où U (ou L) est un produit de matrices de permutation et triangulaires supérieures (inférieures) unitaires
!>    et D est symétrique et à blocs diagonaux avec
!>    des blocs diagonaux de 1x1 et 2x2.
!>
!> 2. Si un D(i,i)=0, donc D est exactement singulier, la routine
!>    retourne avec INFO = i. Sinon, la forme factorisée de A est utilisée
!>    pour estimer le nombre de condition de la matrice A. Si le
!>    réciproque du nombre de condition est inférieur à la précision machine,
!>    INFO = N+1 est retourné comme avertissement, mais la routine continue
!>    quand même à résoudre pour X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 4. Un raffinement itératif est appliqué pour améliorer la solution calculée
!>    et calculer les bornes d'erreur et les erreurs résiduelles pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de A a été
!>          fournie en entrée ou non.
!>          = 'F' : En entrée, AFP et IPIV contiennent la forme factorisée
!>                  de A. AP, AFP et IPIV ne seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans AFP et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          Le triangle supérieur ou inférieur de la matrice symétrique A, stocké
!>          en colonne dans un tableau linéaire. La j-ème colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>

AFP

!>          AFP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          Si FACT = 'F', alors AFP est un argument d'entrée et contient en entrée
!>          la matrice diagonale par blocs D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L de la factorisation
!>          A = U*D*U**T ou A = L*D*L**T calculée par ZSPTRF, stockée comme
!>          une matrice triangulaire compacte dans le même format de stockage que A.
!>
!>          Si FACT = 'N', alors AFP est un argument de sortie et contient en sortie
!>          la matrice diagonale par blocs D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L de la factorisation
!>          A = U*D*U**T ou A = L*D*L**T calculée par ZSPTRF, stockée comme
!>          une matrice triangulaire compacte dans le même format de stockage que A.
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et contient en entrée
!>          les détails des échanges et la structure par blocs
!>          de D, tels que déterminés par ZSPTRF.
!>          Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k) ont été
!>          échangées et D(k,k) est un bloc diagonal 1x1.
!>          Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0, alors les lignes et
!>          colonnes k-1 et -IPIV(k) ont été échangées et D(k-1:k,k-1:k)
!>          est un bloc diagonal 2x2. Si UPLO = 'L' et IPIV(k) =
!>          IPIV(k+1) < 0, alors les lignes et colonnes k+1 et -IPIV(k) ont été
!>          échangées et D(k:k+1,k:k+1) est un bloc diagonal 2x2.
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et contient en sortie
!>          les détails des échanges et la structure par blocs
!>          de D, tels que déterminés par ZSPTRF.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>          La matrice B du côté droit, de taille N par NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, de dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X, de taille N par NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'estimation du réciproque du nombre de condition de la matrice
!>          A. Si RCOND est inférieur à la précision machine (en
!>          particulier, si RCOND = 0), la matrice est singulière à la précision de travail.
!>          Cette condition est indiquée par un code de retour de
!>          INFO > 0.
!>

FERR

!>          FERR est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>          La borne d'erreur directe estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude de l'élément le plus grand
!>          dans (X(j) - XTRUE) divisé par la magnitude de l'élément le plus grand
!>          dans X(j). L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          majoration de l'erreur réelle.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>          L'erreur résiduelle relative composante par composante de chaque vecteur
!>          solution X(j) (c'est-à-dire le plus petit changement relatif dans
!>          tout élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i,

Function/Subroutine Documentation

zspsvx solves a system of equations using an LU factorization with limited memory, of a complex general band matrix A.

A pair of routines, zspsvx and zspcon, and zspEquilib, are provided to solve the system A*X = B, which is A(lev*NB)*X = B, using the UHFCTR routine zspfa.

zspsvx computes the solution to a system of linear equations A*X = B where A is an N-by-N complex band matrix, and X and B are N-by-NRHS matrices.

zspsvx uses the partial LU factorization of A with limited memory storage, and then uses the factors to compute the solution X.

zspsvx also computes an estimate of the reciprocal condition number of A. The routine returns the solution X and an estimate of the reciprocal condition number of A.

The band matrix A is represented in a one-dimensional array D.
