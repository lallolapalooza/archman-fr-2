Documentation de fonction/sous-programme

sous-routine zsteqr (caractere compz, entier n, double precision, dimension( * ) d, double precision, dimension( * ) e, complexe*16, dimension( ldz, * ) z, entier ldz, double precision, dimension( * ) work, entier info)

ZSTEQR

Objectif :

!>
!> ZSTEQR calcule toutes les valeurs propres et, éventuellement, les vecteurs propres d'une
!> matrice tridiagonale symétrique en utilisant la méthode implicite QL ou QR.
!> Les vecteurs propres d'une matrice hermitienne complète ou bande complexe peuvent également
!> être trouvés si ZHETRD ou ZHPTRD ou ZHBTRD a été utilisé pour réduire cette
!> matrice à la forme tridiagonale.
!>

Paramètres

COMPZ 
!>          COMPZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs propres.
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres de la
!>                  matrice hermitienne d'origine. À l'entrée, Z doit contenir la
!>                  matrice unitaire utilisée pour réduire la matrice d'origine
!>                  à la forme tridiagonale.
!>          = 'I' : Calculer les valeurs propres et les vecteurs propres de la
!>                  matrice tridiagonale. Z est initialisée à la matrice identité.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice. N >= 0.
!>

D

!>          D est un tableau de DOUBLE PRECISION, dimension (N)
!>          À l'entrée, les éléments diagonaux de la matrice tridiagonale.
!>          À la sortie, si INFO = 0, les valeurs propres dans l'ordre croissant.
!>

E

!>          E est un tableau de DOUBLE PRECISION, dimension (N-1)
!>          À l'entrée, les (n-1) éléments sous-diagonaux de la matrice
!>          tridiagonale.
!>          À la sortie, E est détruit.
!>

Z

!>          Z est un tableau de COMPLEX*16, dimension (LDZ, N)
!>          À l'entrée, si COMPZ = 'V', alors Z contient la matrice
!>          unitaire utilisée pour la réduction à la forme tridiagonale.
!>          À la sortie, si INFO = 0, alors si COMPZ = 'V', Z contient les
!>          vecteurs propres orthonormés de la matrice hermitienne d'origine,
!>          et si COMPZ = 'I', Z contient les vecteurs propres orthonormés
!>          de la matrice tridiagonale symétrique.
!>          Si COMPZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          des vecteurs propres sont désirés, alors LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION, dimension (max(1,2*N-2))
!>          Si COMPZ = 'N', alors WORK n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : l'algorithme n'a pas réussi à trouver toutes les valeurs propres en
!>                un total de 30*N itérations ; si INFO = i, alors i
!>                éléments de E n'ont pas convergé vers zéro ; à la sortie, D
!>                et E contiennent les éléments d'une matrice tridiagonale symétrique
!>                qui est unitairement similaire à la matrice d'origine.
!>
