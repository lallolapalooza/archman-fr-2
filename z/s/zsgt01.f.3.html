sous-programme zsgt01 (entier itype, caractère uplo, entier n, entier m, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldz, * ) z, entier ldz, double précision, dimension( * ) d, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, double précision, dimension( * ) result)

ZSGT01

But:

!>
!> CDGT01 vérifie une décomposition de la forme
!>
!>    A Z   =  B Z D ou
!>    A B Z =  Z D ou
!>    B A Z =  Z D
!>
!> où A est une matrice hermitienne, B est hermitienne définie positive,
!> Z est unitaire, et D est diagonale.
!>
!> L'un des rapports de test suivants est calculé:
!>
!> ITYPE = 1:  RESULT(1) = | A Z - B Z D | / ( |A| |Z| n ulp )
!>
!> ITYPE = 2:  RESULT(1) = | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!> ITYPE = 3:  RESULT(1) = | B A Z - Z D | / ( |A| |Z| n ulp )
!>

Paramètres

ITYPE 
!>          ITYPE est ENTIER
!>          La forme du problème aux valeurs propres généralisé hermitien.
!>          = 1:  A*z = (lambda)*B*z
!>          = 2:  A*B*z = (lambda)*z
!>          = 3:  B*A*z = (lambda)*z
!>

UPLO

!>          UPLO est CARACTERE*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure des
!>          matrices hermitiennes A et B est stockée.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

M

!>          M est ENTIER
!>          Le nombre de valeurs propres trouvées.  M >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>          La matrice hermitienne originale A.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB, N)
!>          La matrice hermitienne définie positive originale B.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ, M)
!>          Les vecteurs propres calculés du problème aux valeurs propres généralisé.
!>

LDZ

!>          LDZ est ENTIER
!>          La dimension principale du tableau Z.  LDZ >= max(1,N).
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (M)
!>          Les valeurs propres calculées du problème aux valeurs propres généralisé.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, dimension (1)
!>          Le rapport de test tel que décrit ci-dessus.
!>
