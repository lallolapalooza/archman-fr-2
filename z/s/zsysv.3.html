sous-routine zsysv (uplo, n, nrhs, a, lda, ipiv, b, ldb, work, lwork, info)
ZSYSV calcule la solution du système d'équations linéaires A * X = B pour les matrices SY

Documentation de fonction/sous-routine

sous-routine zsysv (caractere uplo, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( * ) work, entier lwork, entier info)

ZSYSV calcule la solution d'un système d'équations linéaires complexes A * X = B,

Objectif :

!>
!> ZSYSV calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice N par N symétrique et X et B sont des matrices N par NRHS.
!>
!> La méthode de pivotement diagonal est utilisée pour factoriser A en
!>    A = U * D * U**T,  si UPLO = 'U', ou
!>    A = L * D * L**T,  si UPLO = 'L',
!> où U (ou L) est un produit de matrices de permutation et triangulaires unitaires
!> supérieures (inférieures), et D est symétrique et diagonale par blocs avec
!> des blocs diagonaux de 1x1 et 2x2. La forme factorisée de A est ensuite
!> utilisée pour résoudre le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  La partie triangulaire supérieure de A est stockée ;
!>          = 'L':  La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          En entrée, la matrice symétrique A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire de A de taille N par N contient la partie
!>          supérieure triangulaire de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée.  Si UPLO = 'L', la
!>          partie inférieure triangulaire de A de taille N par N contient la partie
!>          inférieure triangulaire de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>
!>          En sortie, si INFO = 0, la matrice diagonale par blocs D et les
!>          multiplicateurs utilisés pour obtenir le facteur U ou L à partir de
!>          la factorisation A = U*D*U**T ou A = L*D*L**T calculée par
!>          ZSYTRF.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure des blocs de D, tels que
!>          déterminés par ZSYTRF.  Si IPIV(k) > 0, alors les lignes et colonnes
!>          k et IPIV(k) ont été échangées, et D(k,k) est un bloc diagonal 1x1.
!>          Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0,
!>          alors les lignes et colonnes k-1 et -IPIV(k) ont été échangées et
!>          D(k-1:k,k-1:k) est un bloc diagonal 2x2.  Si UPLO = 'L' et
!>          IPIV(k) = IPIV(k+1) < 0, alors les lignes et colonnes k+1 et
!>          -IPIV(k) ont été échangées et D(k:k+1,k:k+1) est un bloc diagonal 2x2.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          En entrée, la matrice B de taille N par NRHS du côté droit.
!>          En sortie, si INFO = 0, la matrice solution X de taille N par NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur de WORK.  LWORK >= 1, et pour de meilleures performances
!>          LWORK >= max(1,N*NB), où NB est la taille de bloc optimale pour
!>          ZSYTRF.
!>          pour LWORK < N, TRS sera effectué avec le niveau BLAS 2
!>          pour LWORK >= N, TRS sera effectué avec le niveau BLAS 3
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0: fin réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0: si INFO = i, D(i,i) est exactement zéro.  La factorisation
!>               a été complétée, mais la matrice diagonale par blocs D est
!>               exactement singulière, donc la solution n'a pas pu être calculée.
!>
