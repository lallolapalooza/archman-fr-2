Documentation de la fonction/sous-routine

subroutine zsytrs_aa (character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) work, integer lwork, integer info)

ZSYTRS_AA

Objectif :

!>
!> ZSYTRS_AA résout un système d'équations linéaires A*X = B avec une matrice
!> symétrique complexe A en utilisant la factorisation A = U**T*T*U ou
!> A = L*T*L**T calculée par ZSYTRF_AA.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure, forme A = U**T*T*U ;
!>          = 'L':  Triangulaire inférieure, forme A = L*T*L**T.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          Détails des facteurs calculés par ZSYTRF_AA.
!>

LDA

!>          LDA est INTEGER
!>          Dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          Détails des échanges calculés par ZSYTRF_AA.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>          En entrée, le membre de droite B.
!>          En sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          Dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>

LWORK

!>          LWORK est INTEGER
!>          Dimension du tableau WORK. LWORK >= max(1,3*N-2).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  finition réussie
!>          < 0:  si INFO = -i, le i-ème argument était illégal
!>
