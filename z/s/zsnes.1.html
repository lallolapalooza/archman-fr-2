ZSNES 2.0.12(1) Manuel des commandes générales ZSNES 2.0.12(1)

NOM

ZSNES - émulateur de console Super Nintendo

SYNOPIS

ZSNES [-?] [-1 #] [-2 #] [-dd] [-dh] [-f #] [-g #] [-h | -l] [-j] [-js #] [-k #] [-m] [-mc] [-md] [-ml #] [-n #] [-o] [-p #] [-r #] [-s] [-sa] [-t | -u] [-v #] [-y] [-z] [-zm #] [-zs #] [nom_rom]

DESCRIPTION

ZSNES est un émulateur pour la console de jeux vidéo Super Nintendo. Il est écrit en combinaison d'assembleur x86, C, C++ et PSR. Il est actuellement disponible sur Windows, DOS, Linux x86, Mac OS X x86 et BSD x86.

Visitez http://www.zsnes.com/ pour les dernières mises à jour.

OPTIONS

Note : Beaucoup de ces options peuvent également être définies dans l'interface graphique.

-?
Afficher l'aide en ligne de commande
-1 # / -2 #
Définir les contrôles pour le Joueur 1/2 
0 = Aucun       1 = Clavier/Manette
-dd
Désactiver l'émulation du DSP sonore
-dh
Désactiver les hacks de jeux
-f #
Activer le saut d'image, où # est une valeur numérique de 0-9
-g #
Spécifier la valeur de correction gamma, où # est une valeur numérique de 0-15
-h
Forcer le mode HiROM. Ne peut pas être utilisé avec -l
-j
Désactiver la souris (Désactive automatiquement le clic droit de la souris)
-js #
Ajuster la sensibilité du joystick, où # est une valeur numérique de 0-32767
-k #
Définir le niveau de volume, où # est une valeur numérique de 1-100
-l
Forcer le mode LoROM. Ne peut pas être utilisé avec -h
-m
Désactiver l'interface graphique (Doit spécifier le nom du fichier ROM)
-mc
Quitter ZSNES à la fermeture d'un film (à utiliser avec -zm)
-md
Exporter la vidéo brute (à utiliser avec -zm)
-ml
Définir la longueur de l'exportation du film en nombre d'images (à utiliser avec -md)
-n #
Activer les lignes de balayage (quand disponibles), où # est l'une des options suivantes : 
0 = aucune       1 = plein            2 = 25%
3 = 50%
-o
Désactiver le support MMX
-p #
Changer la vitesse d'horloge du CPU principal, où # est une valeur numérique de 50-150. 100 est la vitesse normale. Changer cette valeur peut avoir des effets indésirables.
-r #
Définir le taux d'échantillonnage audio, où # est l'une des options suivantes : 
0 = 8 KHz      1 = 11.025 KHz     2 = 22.05 KHz
3 = 44.1 KHz   4 = 16 KHz         5 = 32 KHz
6 = 48 KHz
-s
Activer l'émulation SPC700/DSP (Son)
-sa
Afficher tous les fichiers avec toutes les extensions (*.*) dans l'interface graphique. Par défaut, seuls les fichiers avec une des extensions listées dans nom_rom sont affichés.
-t
Forcer le timing NTSC (60 Hz). Ne peut pas être utilisé avec -u
-u
Forcer le timing PAL (50 Hz). Ne peut pas être utilisé avec -t
-v #
Sélectionner le mode vidéo, où # est l'une des options suivantes : 
 0 = 256x224 R W      1 = 256x224 R F      2 = 512x448 DR W
 3 = 512x448 DR F     4 = 640x480 DR F     5 = 256x224 OR W
 6 = 512x448 ODR      7 = 640x480 ODS F    8 = 640x480 ODS W
 9 = 640x560 ODR W   10 = 768x672 ODR W   11 = 800x600 ODS F
12 = 800x600 ODS W   13 = 896x784 ODR W   14 = 1024x768 ODS F
15 = 1024x768 ODS W  16 = 1024x896 ODR W  17 = 1280x960 ODS F
18 = 1280x1024 ODS F 19 = 1600x1200 ODS F 20 = VARIABLE ODR W
21 = VARIABLE ODS W  22 = CUSTOM OD F
-y
Activer l'interpolation
-z
Désactiver le son stéréo. Le son stéréo est activé par défaut.
-zm #
Charger automatiquement un film spécifié au démarrage, où # est une valeur numérique de 0-9
-zs #
Charger automatiquement une sauvegarde d'état spécifiée au démarrage, où # est une valeur numérique de 0-99
nom_rom
Nom de la ROM à charger automatiquement. nom_rom est du format nomfichier.ext, où .ext est l'une des extensions SMC, SFC, SWC, FIG, MGD, MGH, UFO, BIN, GD3, GD7, USA, EUR, JAP, AUS, ST, BS, DX2, 048, 058, 078, 1 ou A. Vous pouvez également charger des ROMs qui ont été compressées avec GZip, Zip ou JMA.

FICHIERS ET RÉPERTOIRES

ZSNES
Le programme principal.
~/.zsnes
C'est le répertoire où sont stockés les fichiers de configuration de ZSNES. Par défaut, c'est aussi le répertoire où sont stockés les états de sauvegarde, les captures d'écran, les exportations SPC et les fichiers de films ZMV, mais vous pouvez changer ce comportement en éditant zsnesl.cfg. Ce répertoire est créé par ZSNES.
~/.zsnes/zsnesl.cfg
Ce fichier contient les paramètres de configuration de ZSNES. Il est dans un format lisible par l'homme et peut être édité manuellement. Il est créé par ZSNES.
~/.zsnes/zmovie.cfg
Ce fichier stocke les paramètres spécifiques à l'exportation AVI. Il est créé par ZSNES.
~/.zsnes/zfont.txt
Ce fichier vous permet de personnaliser les polices de caractères dans l'interface graphique. Activez "Utiliser une police personnalisée" dans le menu Options de l'interface graphique. Il est créé par ZSNES.
~/.zsnes/zinput.cfg
Ce fichier contient les paramètres de configuration des entrées pour ZSNES.

Si pour une raison quelconque vous mettez à jour votre version de ZSNES et qu'elle plante avant que vous ne puissiez faire quoi que ce soit, vous devriez essayer de supprimer les fichiers .cfg ci-dessus et laisser ZSNES en créer de nouveaux.

JEUX À PUCES SPÉCIALES

Beaucoup de jeux sur Super Nintendo utilisaient des CPU personnalisés en plus du CPU principal de la SNES. Certains de ces CPU n'ont pas été entièrement rétro-conçus, et les jeux qui les utilisent peuvent ne pas fonctionner ou présenter des bugs étranges.

Vous pouvez trouver plus d'informations sur ces CPU spéciaux à l'adresse :

http://users.tpg.com.au/advlink/dsp/

http://nsrt.edgeemu.com/INFO/chipinfo.htm

PACKS GRAPHIQUES

Certains jeux basés sur la puce SPC7110, comme Far East of Eden Zero, peuvent utiliser des packs graphiques spéciaux pour contourner les parties non émulées de leur CPU personnalisé. Ces packs graphiques doivent être stockés dans des répertoires individuels au sein du répertoire de sauvegarde, qui est spécifié dans zsnesl.cfg. Par défaut, c'est ~/.zsnes. Le nom du répertoire de chaque pack graphique doit être en majuscules et tous les fichiers à l'intérieur de ce répertoire doivent être en minuscules.

Le nom de répertoire correct pour un pack graphique donné se trouve dans le fichier readme inclus avec ce pack.

NOTE : À partir de la version 1.40, les jeux qui utilisent la puce S-DD1 (Star Ocean et Street Fighter Alpha 2) ne nécessitent plus de packs graphiques.
