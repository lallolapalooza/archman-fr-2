sous-programme zsyt01_rook (caractere uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldafac, * ) afac, entier ldafac, entier, dimension( * ) ipiv, complexe*16, dimension( ldc, * ) c, entier ldc, double precision, dimension( * ) rwork, double precision resid)

ZSYT01_ROOK

Objectif :

!>
!> ZSYT01_ROOK reconstruit une matrice complexe symétrique indéfinie A à partir de sa
!> factorisation par blocs L*D*L' ou U*D*U' et calcule le résidu
!>    norme( C - A ) / ( N * norme(A) * EPS ),
!> où C est la matrice reconstruite, EPS est la virgule flottante de la machine,
!> L' est la transposée de L, et U' est la transposée de U.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice complexe symétrique A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice complexe symétrique originale A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N)
!>

AFAC

!>          AFAC est un tableau COMPLEX*16, dimension (LDAFAC,N)
!>          La forme factorisée de la matrice A. AFAC contient la matrice
!>          diagonale par blocs D et les multiplicateurs utilisés pour obtenir
!>          le facteur L ou U de la factorisation par blocs L*D*L' ou U*D*U'
!>          telle que calculée par ZSYTRF_ROOK.
!>

LDAFAC

!>          LDAFAC est INTEGER
!>          La dimension principale du tableau AFAC. LDAFAC >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot de ZSYTRF_ROOK.
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC,N)
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          Si UPLO = 'L', norme(L*D*L' - A) / ( N * norme(A) * EPS )
!>          Si UPLO = 'U', norme(U*D*U' - A) / ( N * norme(A) * EPS )
!>
