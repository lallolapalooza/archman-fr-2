Documentation de la fonction/sous-routine

sous-routine zsyt01_aa (caractere uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldafac, * ) afac, entier ldafac, entier, dimension( * ) ipiv, complexe*16, dimension( ldc, * ) c, entier ldc, double precision, dimension( * ) rwork, double precision resid)

ZSYT01

But :

!>
!> ZSYT01 reconstruit une matrice hermitienne indéfinie A à partir de sa
!> factorisation par blocs L*D*L' ou U*D*U' et calcule la résiduelle
!>    norme( C - A ) / ( N * norm(A) * EPS ),
!> où C est la matrice reconstruite et EPS est la partie fractionnaire de la machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice hermitienne A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice hermitienne originale A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N)
!>

AFAC

!>          AFAC est un tableau COMPLEX*16, dimension (LDAFAC,N)
!>          La forme factorisée de la matrice A. AFAC contient la matrice
!>          diagonale par blocs D et les multiplicateurs utilisés pour obtenir L
!>          ou U à partir de la factorisation par blocs L*D*L' ou U*D*U'
!>          telle que calculée par ZSYTRF.
!>

LDAFAC

!>          LDAFAC est INTEGER
!>          La dimension principale du tableau AFAC.  LDAFAC >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot de ZSYTRF.
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC,N)
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C.  LDC >= max(1,N).
!>

RWORK

!>          RWORK est un tableau COMPLEX*16, dimension (N)
!>

RESID

!>          RESID est COMPLEX*16
!>          Si UPLO = 'L', norme(L*D*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norme(U*D*U' - A) / ( N * norm(A) * EPS )
!>
