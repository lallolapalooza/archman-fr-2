Documentation de la fonction/sous-routine

sous-routine zsytrs_aa (caractere uplo, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( * ) work, entier lwork, entier info)

ZSYTRS_AA

But :

!>
!> ZSYTRS_AA résout un système d'équations linéaires A*X = B avec une matrice
!> complexe symétrique A en utilisant la factorisation A = U**T*T*U ou
!> A = L*T*L**T calculée par ZSYTRF_AA.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure, forme A = U**T*T*U;
!>          = 'L':  Triangulaire inférieure, forme A = L*T*L**T.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          Détails des facteurs calculés par ZSYTRF_AA.
!>

LDA

!>          LDA est INTEGER
!>          Dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges calculés par ZSYTRF_AA.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          À l'entrée, le membre de droite de la matrice B.
!>          À la sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          Dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>

LWORK

!>          LWORK est INTEGER
!>          Dimension du tableau WORK. LWORK >= max(1,3*N-2).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  Sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument était invalide
!>
