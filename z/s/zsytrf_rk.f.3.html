Documentation de la fonction/sous-routine

sous-routine zsytrf_rk (caractère uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) e, entier, dimension( * ) ipiv, complexe*16, dimension( * ) work, entier lwork, entier info)

ZSYTRF_RK calcule la factorisation d'une matrice complexe symétrique indéfinie en utilisant la méthode de pivotement diagonal de Bunch-Kaufman bornée (rook) (algorithme bloqué BLAS3).

Objectif :

!> ZSYTRF_RK calcule la factorisation d'une matrice complexe symétrique A
!> en utilisant la méthode de pivotement diagonal bornée de Bunch-Kaufman (rook) :
!>
!>    A = P*U*D*(U**T)*(P**T) ou A = P*L*D*(L**T)*(P**T),
!>
!> où U (ou L) est une matrice triangulaire supérieure (ou inférieure) unitaire,
!> U**T (ou L**T) est la transposée de U (ou L), P est une matrice de permutation,
!> P**T est la transposée de P, et D est symétrique et bloc-diagonale avec des
!> blocs diagonaux de taille 1x1 et 2x2.
!>
!> C'est la version bloquée de l'algorithme, appelant le niveau 3 de BLAS.
!> Pour plus d'informations, voir la section Détails supplémentaires.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de
!>          la matrice symétrique A est stockée :
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          En entrée, la matrice symétrique A.
!>            Si UPLO = 'U' : la partie supérieure triangulaire principale de N x N
!>            de A contient la partie supérieure triangulaire de la matrice A,
!>            et la partie strictement inférieure triangulaire de A n'est pas
!>            référencée.
!>
!>            Si UPLO = 'L' : la partie inférieure triangulaire principale de N x N
!>            de A contient la partie inférieure triangulaire de la matrice A,
!>            et la partie strictement supérieure triangulaire de A n'est pas
!>            référencée.
!>
!>          En sortie, contient :
!>            a) UNIQUEMENT les éléments diagonaux de la matrice symétrique bloc-diagonale
!>               D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k) ;
!>               (les éléments superdiagonaux (ou sous-diagonaux) de D
!>                sont stockés en sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : facteur U dans la partie superdiagonale de A.
!>               Si UPLO = 'L' : facteur L dans la partie sous-diagonale de A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau COMPLEX*16, de dimension (N)
!>          En sortie, contient les éléments superdiagonaux (ou sous-diagonaux)
!>          de la matrice symétrique bloc-diagonale D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i), i=2:N, E(1) est mis à 0 ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          NOTE : Pour un bloc diagonal de taille 1x1 D(k), où
!>          1 <= k <= N, l'élément E(k) est mis à 0 dans les deux
!>          cas UPLO = 'U' ou UPLO = 'L'.
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          IPIV décrit la matrice de permutation P dans la factorisation
!>          de la matrice A comme suit. La valeur absolue de IPIV(k)
!>          représente l'indice de la ligne et de la colonne qui ont été
!>          échangées avec la k-ième ligne et colonne. La valeur de UPLO
!>          décrit l'ordre dans lequel les échanges ont été appliqués.
!>          De plus, le signe de IPIV représente la structure en blocs
!>          de la matrice symétrique bloc-diagonale D avec des blocs
!>          diagonaux de 1x1 ou 2x2 qui correspondent à 1 ou 2 échanges
!>          à chaque étape de factorisation. Pour plus d'informations, voir
!>          la section Détails supplémentaires.
!>
!>          Si UPLO = 'U',
!>          ( dans l'ordre de factorisation, k décroît de N à 1) :
!>            a) Une seule entrée positive IPIV(k) > 0 signifie :
!>               D(k,k) est un bloc diagonal de 1x1.
!>               Si IPIV(k) != k, les lignes et colonnes k et IPIV(k) ont été
!>               échangées dans la matrice A(1:N,1:N) ;
!>               Si IPIV(k) = k, aucun échange n'a eu lieu.
!>
!>            b) Une paire d'entrées négatives consécutives
!>               IPIV(k) < 0 et IPIV(k-1) < 0 signifie :
!>               D(k-1:k,k-1:k) est un bloc diagonal de 2x2.
!>               (NOTE : les entrées négatives dans IPIV apparaissent UNIQUEMENT par paires).
!>               1) Si -IPIV(k) != k, les lignes et colonnes
!>                  k et -IPIV(k) ont été échangées
!>                  dans la matrice A(1:N,1:N).
!>                  Si -IPIV(k) = k, aucun échange n'a eu lieu.
!>               2) Si -IPIV(k-1) != k-1, les lignes et colonnes
!>                  k-1 et -IPIV(k-1) ont été échangées
!>                  dans la matrice A(1:N,1:N).
!>                  Si -IPIV(k-1) = k-1, aucun échange n'a eu lieu.
!>
!>            c) Dans les deux cas a) et b), toujours ABS( IPIV(k) ) <= k.
!>
!>            d) NOTE : Toute entrée IPIV(k) est toujours NON NULLE en sortie.
!>
!>          Si UPLO = 'L',
!>          ( dans l'ordre de factorisation, k augmente de 1 à N) :
!>            a) Une seule entrée positive IPIV(k) > 0 signifie :
!>               D(k,k) est un bloc diagonal de 1x1.
!>               Si IPIV(k) != k, les lignes et colonnes k et IPIV(k) ont été
!>               échangées dans la matrice A(1:N,1:N).
!>               Si IPIV(k) = k, aucun échange n'a eu lieu.
!>
!>            b) Une paire d'entrées négatives consécutives
!>               IPIV(k) < 0 et IPIV(k+1) < 0 signifie :
!>               D(k:k+1,k:k+1) est un bloc diagonal de 2x2.
!>               (NOTE : les entrées négatives dans IPIV apparaissent UNIQUEMENT par paires).
!>               1) Si -IPIV(k) != k, les lignes et colonnes
!>                  k et -IPIV(k) ont été échangées
!>                  dans la matrice A(1:N,1:N).
!>                  Si -IPIV(k) = k, aucun échange n'a eu lieu.
!>               2) Si -IPIV(k+1) != k+1, les lignes et colonnes
!>                  k-1 et -IPIV(k-1) ont été échangées
!>                  dans la matrice A(1:N,1:N).
!>                  Si -IPIV(k+1) = k+1, aucun échange n'a eu lieu.
!>
!>            c) Dans les deux cas a) et b), toujours ABS( IPIV(k) ) >= k.
!>
!>            d) NOTE : Toute entrée IPIV(k) est toujours NON NULLE en sortie.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension ( MAX(1,LWORK) ).
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur de WORK.  LWORK >=1.  Pour des performances optimales,
!>          LWORK >= N*NB, où NB est la taille du bloc retournée
!>          par ILAENV.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule uniquement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK,
!>          et aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>
!>          < 0 : Si INFO = -k, le k-ième argument avait une valeur illégale
!>
!>          > 0 : Si INFO = k, la matrice A est singulière, car :
!>                 Si UPLO = 'U' : la colonne k dans la partie
!>                 triangulaire supérieure de A contient uniquement des zéros.
!>                 Si UPLO = 'L' : la colonne k dans la partie
!>                 triangulaire inférieure de A contient uniquement des zéros.
!>
!>               Par conséquent, D(k,k) est exactement zéro, et les éléments
!>               superdiagonaux de la colonne k de U (ou les éléments
!>               sous-diagonaux de la colonne k de L) sont tous des zéros. La factorisation a
!>               été complétée, mais la matrice bloc-diagonale D
!>               est exactement singulière, ce qui signifie qu'elle est
!>               inversible.
!>

NAME

zsytrf_rk — computes the Bunch-Kaufman split-update factorization of a complex symmetric matrix.

SYNOPSIS

SUBROUTINE ZSYTRF_RK( UPLO, N, A, LDA, NB, IPIV, WORK, LWORK, INFO )
  CHARACTER UPLO
  INTEGER N
  COMPLEX*16 A( LDA, * )
  INTEGER LDA
  INTEGER NB
  INTEGER IPIV( * )
  COMPLEX*16 WORK( * )
  INTEGER LWORK
  INTEGER INFO

Function/Subroutine Documentation

Purpose:

  This routine is deprecated and will be removed in a future release.
  It is replaced by ZSYTRF.
  ZSYTRF_RK computes the factorization of a complex symmetric matrix
  A = U * T * U^H or A = L * T * L^H, where T is block diagonal with
  1-by-1 and 2-by-2 blocks. T is further decomposed with one rank-k update.
  This routine uses block recombination.

  If UPLO = 'U', A = U * T * U^H.
  If UPLO = 'L', A = L * T * L^H.

  T consists of:
    - T = T_1
    - T = [ T_11 T_12 ]
          [ T_21 T_22 ]
  where T_11, T_22 are block diagonal matrices.
  A is factorized as:
  if UPLO = 'U':
  A = [ A_11 A_12 ] * [ T_11  0  ] * [ A_11* A_12* ]   if A_22 is singular
      [ A_21 A_22 ]   [  0   T_2 ]   [  0    I   ]
      or
  A = [ A_11 A_12 ] * [ T_11 T_12 ] * [ A_11*  0  ]   if A_22 is nonsingular
      [ A_21 A_22 ]   [ T_21 T_22 ]   [ A_12*  I  ]

  if UPLO = 'L':
  A = [ A_11  0  ] * [ T_1  0 ] * [ A_11^H A_21^H ]   if A_22 is singular
      [ A_12 A_22 ]   [  0  T_2 ]   [  0     I    ]
      or
  A = [ A_11 A_12 ] * [ T_11 T_12 ] * [ A_11^H  0  ]   if A_22 is nonsingular
      [ A_21 A_22 ]   [ T_21 T_22 ]   [ A_12^H  I  ]

  where U or L is a block upper or lower triangular matrix.

  The factorization is in the form
  A = P * U * T * U^H * P^T   if UPLO = 'U', or
  A = P * L * T * L^H * P^T   if UPLO = 'L',
  where P is a permutation matrix. T is a block diagonal matrix and U
  is a block unit upper triangular matrix. L is a block unit lower
  triangular matrix.

  Arguments:
    UPLO    (input) CHARACTER*1
            Specifies whether the matrix A is upper or lower triangular.
            = 'U': Upper triangle of A is stored and taken into account.
            = 'L': Lower triangle of A is stored and taken into account.

    N       (input) INTEGER
            The order of the matrix A. N >= 0.

    A       (input/output) COMPLEX*16 array, dimension (LDA, N)
            On entry, the symmetric matrix A.
            On exit, the block diagonal matrix T and the multipliers below
            or above the diagonal.

    LDA     (input) INTEGER
            The leading dimension of the array A. LDA >= max(1, N).

    NB      (input) INTEGER
            The block size used for the recombination.

    IPIV    (output) INTEGER array, dimension (N)
            Details of the factorization, i.e., the block permutation for T.
            A symmetric permutation is applied to A, and A is factorized
            as L*T*L^H or U*T*U^H.
            If IPIV(i) > 0, it means block i is a 1-by-1 block.
            If IPIV(i) = 0, it means block i is a 2-by-2 block.
            If IPIV(i) < 0, it means block i is a 2-by-2 block and i is
            the row index of the leading element of the 2-by-2 block.

    WORK    (workspace) COMPLEX*16 array, dimension (LWORK)

    LWORK   (input) INTEGER
            The size of the array WORK. LWORK >= max(1, N).
            For optimal performance, LWORK must be at least N * NB.

    INFO    (output) INTEGER
            = 0: Successful exit
            > 0: If INFO = i, it means the rank of the block containing A(i,i)
                 is zero. T(i,i) is not invertible. Division by zero will
                 occur if it is used to solve a system of equations.
            NOTE: INFO only stores the first occurrence of
                  a singularity, any subsequent occurrence of singularity
                  is not stored in INFO even though the factorization
                  always completes.
