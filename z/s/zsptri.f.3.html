Documentation de la fonction/sous-programme

sous-routine zsptri (caractere uplo, entier n, complexe*16, dimension( * ) ap, entier, dimension( * ) ipiv, complexe*16, dimension( * ) work, entier info)

ZSPTRI

Objectif :

!>
!> ZSPTRI calcule l'inverse d'une matrice symétrique indéfinie complexe
!> A en stockage compacté en utilisant la factorisation A = U*D*U**T ou
!> A = L*D*L**T calculée par ZSPTRF.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U' : Triangulaire supérieure, la forme est A = U*D*U**T;
!>          = 'L' : Triangulaire inférieure, la forme est A = L*D*L**T.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          À l'entrée, la matrice diagonale par blocs D et les multiplicateurs
!>          utilisés pour obtenir le facteur U ou L calculés par ZSPTRF,
!>          stockés sous forme de matrice triangulaire compactée.
!>
!>          À la sortie, si INFO = 0, l'inverse (symétrique) de la matrice
!>          d'origine, stocké sous forme de matrice triangulaire compactée. La j-ième colonne
!>          de inv(A) est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = inv(A)(i,j) pour 1<=i<=j;
!>          si UPLO = 'L',
!>             AP(i + (j-1)*(2n-j)/2) = inv(A)(i,j) pour j<=i<=n.
!>

IPIV

!>          IPIV est un tableau ENTIER, de dimension (N)
!>          Détails des échanges et de la structure par blocs de D
!>          tels que déterminés par ZSPTRF.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) = 0 ; la matrice est singulière et son
!>               inverse n'a pas pu être calculé.
!>
