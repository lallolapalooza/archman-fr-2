Documentation de la fonction/sous-routine

sous-routine zspt02 (character uplo, integer n, integer nrhs, complex*16, dimension( * ) a, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) rwork, double precision resid)

ZSPT02

But :

!>
!> ZSPT02 calcule le résidu dans la solution d'un système d'équations linéaires
!> complexes symétriques A*x = b lorsque le stockage compact est utilisé pour la
!> matrice de coefficients. Le ratio calculé est
!>
!>    RESID = norm( B - A*X ) / ( norm(A) * norm(X) * EPS).
!>
!> où EPS est la précision machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique complexe A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de colonnes de B, la matrice des seconds membres.
!>          NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          La matrice symétrique complexe originale A, stockée sous forme de
!>          matrice triangulaire compactée.
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Les vecteurs solutions calculés pour le système d'équations linéaires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.   LDX >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          En entrée, les vecteurs seconds membres pour le système d'équations
!>          linéaires.
!>          En sortie, B est écrasé par la différence B - A*X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

RWORK

!>          RWORK est DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          Le maximum sur le nombre de seconds membres de
!>          norm(B - A*X) / ( norm(A) * norm(X) * EPS ).
!>
