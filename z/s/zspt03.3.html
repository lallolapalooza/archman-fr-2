sous-programme zspt03 (caractere uplo, entier n, complexe*16, dimension( * ) a, complexe*16, dimension( * ) ainv, complexe*16, dimension( ldw, * ) work, entier ldw, double precision, dimension( * ) rwork, double precision rcond, double precision resid)

ZSPT03

But:

!>
!> ZSPT03 calcule le résidu d'une matrice symétrique complexe fois son inverse :
!>    norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique complexe A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          La matrice symétrique complexe originale A, stockée sous forme de
!>          matrice triangulaire packed.
!>

AINV

!>          AINV est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          L'inverse (symétrique) de la matrice A, stockée sous forme de
!>          matrice triangulaire packed.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LDW,N)
!>

LDW

!>          LDW est INTEGER
!>          La dimension principale du tableau WORK.  LDW >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'inverse du nombre de condition de A, calculé comme
!>          ( 1/norm(A) ) / norm(AINV).
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          norm(I - A*AINV) / ( N * norm(A) * norm(AINV) * EPS )
!>
