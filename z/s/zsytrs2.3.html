Documentation de la fonction/sous-routine

subroutine zsytrs2 (character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) work, integer info)

ZSYTRS2

Objectif :

!>
!> ZSYTRS2 résout un système d'équations linéaires A*X = B avec une matrice
!> complexe symétrique A en utilisant la factorisation A = U*D*U**T ou
!> A = L*D*L**T calculée par ZSYTRF et convertie par ZSYCONV.
!>

Paramètres :

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure, forme A = U*D*U**T ;
!>          = 'L':  Triangulaire inférieure, forme A = L*D*L**T .
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>          obtenir le facteur U ou L calculés par ZSYTRF.
!>          Notez que A est une entrée/sortie. Cela peut être contre-intuitif,
!>          et on pourrait penser que A n'est qu'une entrée. A est une entrée/sortie.
!>          Ceci est dû au fait qu'au début de la sous-routine, nous permutons A
!>          dans une certaine forme, puis nous la permutons à nouveau dans sa
!>          forme d'origine à la fin.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure en blocs de D
!>          tels que déterminés par ZSYTRF.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          En entrée, la matrice de second membre B.
!>          En sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument était invalide
!>
