sous-routine zstein (integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, integer m, double precision, dimension( * ) w, integer, dimension( * ) iblock, integer, dimension( * ) isplit, complex*16, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

ZSTEIN

But:

!>
!> ZSTEIN calcule les vecteurs propres d'une matrice symétrique
!> tridiagonale T correspondant à des valeurs propres spécifiées, en
!> utilisant l'itération inverse.
!>
!> Le nombre maximum d'itérations autorisées pour chaque vecteur propre
!> est spécifié par un paramètre interne MAXITS (actuellement réglé sur 5).
!>
!> Bien que les vecteurs propres soient réels, ils sont stockés dans un
!> tableau complexe, qui peut être passé à ZUNMTR ou ZUPMTR pour
!> une rétro-transformation vers les vecteurs propres d'une matrice
!> hermitienne complexe qui a été réduite à forme tridiagonale.
!>
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice.  N >= 0.
!>

D

!>          D est un tableau de double précision (DOUBLE PRECISION),
!>          de dimension (N)
!>          Les N éléments diagonaux de la matrice tridiagonale T.
!>

E

!>          E est un tableau de double précision (DOUBLE PRECISION),
!>          de dimension (N-1)
!>          Les N-1 éléments sous-diagonaux de la matrice tridiagonale
!>          T, stockés dans les éléments 1 à N-1.
!>

M

!>          M est un entier (INTEGER)
!>          Le nombre de vecteurs propres à calculer.  0 <= M <= N.
!>

W

!>          W est un tableau de double précision (DOUBLE PRECISION),
!>          de dimension (N)
!>          Les M premiers éléments de W contiennent les valeurs propres
!>          pour lesquelles les vecteurs propres doivent être calculés.
!>          Les valeurs propres doivent être regroupées par bloc de
!>          séparation et ordonnées de la plus petite à la plus grande
!>          au sein du bloc.  ( Le tableau de sortie W de DSTEBZ avec
!>          ORDER = 'B' est attendu ici. )
!>

IBLOCK

!>          IBLOCK est un tableau d'entiers (INTEGER), de dimension (N)
!>          Les indices des sous-matrices associés aux valeurs propres
!>          correspondantes dans W ; IBLOCK(i)=1 si la valeur propre W(i)
!>          appartient à la première sous-matrice supérieure, =2 si W(i)
!>          appartient à la deuxième sous-matrice, etc.  ( Le tableau de
!>          sortie IBLOCK de DSTEBZ est attendu ici. )
!>

ISPLIT

!>          ISPLIT est un tableau d'entiers (INTEGER), de dimension (N)
!>          Les points de séparation, où T se divise en sous-matrices.
!>          La première sous-matrice comprend les lignes/colonnes 1 à
!>          ISPLIT( 1 ), la seconde les lignes/colonnes ISPLIT( 1 )+1
!>          jusqu'à ISPLIT( 2 ), etc.
!>          ( Le tableau de sortie ISPLIT de DSTEBZ est attendu ici. )
!>

Z

!>          Z est un tableau COMPLEX*16, de dimension (LDZ, M)
!>          Les vecteurs propres calculés.  Le vecteur propre associé
!>          à la valeur propre W(i) est stocké dans la i-ème colonne de
!>          Z.  Tout vecteur qui échoue à converger est mis à sa valeur
!>          itérative courante après MAXITS itérations.
!>          Les parties imaginaires des vecteurs propres sont mises à zéro.
!>

LDZ

!>          LDZ est un entier (INTEGER)
!>          La dimension principale du tableau Z.  LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau de double précision (DOUBLE PRECISION),
!>          de dimension (5*N)
!>

IWORK

!>          IWORK est un tableau d'entiers (INTEGER), de dimension (N)
!>

IFAIL

!>          IFAIL est un tableau d'entiers (INTEGER), de dimension (M)
!>          En cas de sortie normale, tous les éléments de IFAIL sont zéro.
!>          Si un ou plusieurs vecteurs propres n'arrivent pas à converger
!>          après MAXITS itérations, leurs indices sont stockés dans
!>          le tableau IFAIL.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0: si INFO = i, alors i vecteurs propres n'ont pas convergé
!>               en MAXITS itérations. Leurs indices sont stockés dans
!>               le tableau IFAIL.
!>

Paramètres internes:

!>  MAXITS  INTEGER, par défaut = 5
!>          Le nombre maximum d'itérations effectuées.
!>
!>  EXTRA   INTEGER, par défaut = 2
!>          Le nombre d'itérations effectuées après que le critère de
!>          croissance de la norme est satisfait, doit être au moins 1.
!>
