Documentation de fonction/sous-routine

sous-routine zsyl01 (double precision thresh, integer, dimension( 3 ) nfail, double precision, dimension( 2 ) rmax, integer, dimension( 2 ) ninfo, integer knt)

ZSYL01

Objectif :

!>
!> ZSYL01 teste ZTRSYL et ZTRSYL3, routines pour résoudre l'équation matricielle de Sylvester
!>
!>    op(A)*X + ISGN*X*op(B) = scale*C,
!>
!> où op(A) et op(B) sont tous deux sous forme triangulaire supérieure, op() représente une
!> transposée conjuguée optionnelle, et ISGN peut être -1 ou +1. Scale est une sortie
!> inférieure ou égale à 1, choisie pour éviter le débordement dans X.
!>
!> Le code de test vérifie que le résidu suivant ne dépasse pas
!> le seuil fourni :
!>
!>    norm(op(A)*X + ISGN*X*op(B) - scale*C) /
!>        (EPS*max(norm(A),norm(B))*norm(X))
!>
!> Cette routine complète ZGET35 en testant avec des matrices aléatoires plus grandes,
!> dont certaines nécessitent une mise à l'échelle de X pour éviter le débordement.
!>
!>

Paramètres

THRESH 
!>          THRESH est DOUBLE PRECISION
!>          Un test sera compté comme  si le résidu, calculé comme
!>          décrit ci-dessus, dépasse THRESH.
!>

NFAIL

!>          NFAIL est un tableau INTEGER, dimension (3)
!>          NFAIL(1) = Nombre de fois où le résidu ZTRSYL dépasse le seuil THRESH
!>          NFAIL(2) = Nombre de fois où le résidu ZTRSYL3 dépasse le seuil THRESH
!>          NFAIL(3) = Nombre de fois où ZTRSYL3 et ZTRSYL divergent
!>

RMAX

!>          RMAX est un tableau DOUBLE PRECISION, dimension (2)
!>          RMAX(1) = Valeur du plus grand ratio de test de ZTRSYL
!>          RMAX(2) = Valeur du plus grand ratio de test de ZTRSYL3
!>

NINFO

!>          NINFO est un tableau INTEGER, dimension (2)
!>          NINFO(1) = Nombre de fois où ZTRSYL retourne un INFO attendu
!>          NINFO(2) = Nombre de fois où ZTRSYL3 retourne un INFO attendu
!>

KNT

!>          KNT est INTEGER
!>          Nombre total d'exemples testés.
!>

Définition à la ligne 88 du fichier zsyl01.f.
