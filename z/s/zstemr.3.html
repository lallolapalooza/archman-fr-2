But :

!>
!> ZSTEMR calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'une matrice tridiagonale symétrique réelle T. Toute matrice non réduite de ce type possède
!> un ensemble bien défini de valeurs propres réelles distinctes deux à deux, les vecteurs propres
!> réels correspondants sont deux à deux orthogonaux.
!>
!> Le spectre peut être calculé soit complètement, soit partiellement en spécifiant
!> soit un intervalle (VL,VU] soit une plage d'indices IL:IU pour les valeurs propres souhaitées.
!>
!> Selon le nombre de valeurs propres souhaitées, celles-ci sont calculées soit
!> par bissection, soit par l'algorithme dqds. Des vecteurs propres numériquement orthogonaux sont
!> calculés en utilisant diverses factorisations L D L^T appropriées près des clusters
!> de valeurs propres proches (appelées RRR, Représentations Relativement Robustes). Un aperçu informel de l'algorithme suit.
!>
!> Pour chaque bloc non réduit (sous-matrice) de T,
!>    (a) Calculer T - sigma I  = L D L^T, de sorte que L et D
!>        définissent toutes les valeurs propres recherchées avec une haute précision relative.
!>        Cela signifie que de petites modifications relatives des entrées de D et L
!>        entraînent de petites modifications relatives des valeurs propres et
!>        des vecteurs propres. La représentation standard (non factorisée) de la
!>        matrice tridiagonale T n'a pas cette propriété en général.
!>    (b) Calculer les valeurs propres avec une précision appropriée.
!>        Si les vecteurs propres sont désirés, l'algorithme atteint la pleine
!>        précision des valeurs propres calculées juste avant
!>        que les vecteurs correspondants ne doivent être calculés, voir étapes c) et d).
!>    (c) Pour chaque cluster de valeurs propres proches, sélectionner un nouveau
!>        décalage proche du cluster, trouver une nouvelle factorisation, et affiner
!>        les valeurs propres décalées avec une précision appropriée.
!>    (d) Pour chaque valeur propre avec une séparation relative suffisamment grande, calculer
!>        le vecteur propre correspondant en formant une factorisation torsadée révélant le rang.
!>        Revenir à (c) pour les clusters restants.
!>
!> Pour plus de détails, voir :
!> - Inderjit S. Dhillon et Beresford N. Parlett :
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, août 2004.
!> - Inderjit Dhillon et Beresford Parlett :  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004.  Aussi LAPACK Working Note 154.
!> - Inderjit Dhillon : ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, mai 1997.
!>
!> Détails supplémentaires
!> 1. ZSTEMR fonctionne uniquement sur les machines qui suivent la norme de
!> flottants IEEE-754 dans leur gestion des infinis et des NaNs.
!> Cela permet d'utiliser des boucles internes efficaces évitant la vérification des
!> diviseurs nuls.
!>
!> 2. Les routines LAPACK peuvent être utilisées pour réduire une matrice hermitienne complexe en
!> forme tridiagonale symétrique réelle.
!>
!> (Toute matrice tridiagonale hermitienne complexe a des valeurs réelles sur sa diagonale
!> et potentiellement des nombres complexes sur ses sous-diagonales. En appliquant une
!> transformation de similarité avec une matrice diagonale appropriée
!> diag(1,e^{i \phy_1}, ... , e^{i \phy_{n-1}}), la matrice hermitienne complexe
!> peut être transformée en une matrice symétrique réelle et l'arithmétique complexe
!> peut être entièrement évitée.)
!>
!> Bien que les vecteurs propres de la matrice symétrique réelle soient réels,
!> les vecteurs propres de la matrice hermitienne complexe originale ont des entrées complexes
!> en général.
!> Étant donné que les drivers LAPACK écrasent les données de la matrice avec les vecteurs propres,
!> ZSTEMR accepte un espace de travail complexe pour faciliter l'interopérabilité
!> avec ZUNMTR ou ZUPMTR.
!>

!>

!>

W

!>          ordre croissant.
!>

ZSTEMR(3) — LAPACK — Manuel Archlinux

NAME

zstemr — computes the eigenvalues and eigenvectors of a complex Hermitian or real symmetric matrix.

SYNOPSIS

  SUBROUTINE ZSTEMR(
        JOBZ, RANGE, UPLO, N, D, E, VL, VU, IL, IU,
        RTOL, M, NZC, Z, LDZ, ZWORK, WORK, LWORK, IWORK, LIWORK,
        INFO
  )

  CHARACTER          JOBZ, RANGE, UPLO
  INTEGER            IL, IU, INFO, LDZ, LIWORK, LWORK, M, N, NZC
  INTEGER            IWORK( * )
  REAL( KIND=8 )     D( * ), E( * ), RTOL, VL, VU
  COMPLEX( KIND=16 ) Z( LDA, * ), ZWORK( * )
  DOUBLE PRECISION   WORK( * )

Function/Subroutine Documentation

ZSTEMR computes the eigenvalues and eigenvectors of a complex Hermitian or real symmetric matrix.

This subroutine is a wrapper for the computational routine `zstemr`.

This subroutine calls ZTSTEMR.

Arguments:

JOBZ

!>          JOBZ is CHARACTER*1
!>          = 'N':  Compute only the eigenvalues of A.
!>          = 'V':  Compute the eigenvalues and eigenvectors of A.
!>

RANGE

!>          RANGE is CHARACTER*1
!>          = 'A': all eigenvalues will be found.
!>          = 'V': all eigenvalues in the half-open interval (VL, VU]
!>                 will be found.
!>          = 'I': all eigenvalues in the open interval (IL, IU]
!>                 will be found.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored and will be used.
!>          = 'L':  Lower triangle of A is stored and will be used.
!>

N

!>          N is INTEGER
!>          The order of the matrix A. N >= 0.
!>

D

!>          D is REAL( KIND=8 ) array, dimension (N)
!>          On entry, the N diagonal elements of the tridiagonal matrix T.
!>          On exit, if INFO = 0, the eigenvalues, sorted in
!>          increasing order.
!>

E

!>          E is REAL( KIND=8 ) array, dimension (N)
!>          On entry, the (N-1) subdiagonal elements of the tridiagonal
!>          matrix T.
!>          On exit, E is overwritten by zero.
!>

VL

!>          VL is REAL( KIND=8 )
!>

VU

!>          VU is REAL( KIND=8 )
!>          If RANGE='V', the lower and upper bounds for the eigenvalues.
!>          For expected scaling behavior, espll be 1.0D+0 and vu be
!>          1.0D+0.
!>

IL

!>          IL is INTEGER
!>

IU

!>          IU is INTEGER
!>          If RANGE='I', the indices of the eigenvalues in the selected
!>          range (il, iu) . For expected scaling behavior, il will be 1
!>          and iu will be N.
!>

RTOL

!>          RTOL is REAL( KIND=8 )
!>          Relative accuracy for the eigenvalue range.
!>

M

!>          M is INTEGER
!>          The total number of eigenvalues found.
!>          If RANGE = 'A', M = N.
!>          If RANGE = 'I' or 'V', M = the number of eigenvalues in the
!>          specified range.
!>

NZC

!>          NZC is INTEGER
!>          The number of columns in Z. NZC >= max(1,N).
!>          If RANGE = 'A', then NZC >= max(1,N).
!>          If RANGE = 'V', then NZC >= the number of eigenvalues in (VL, VU].
!>          If RANGE = 'I', then NZC >= IU-IL+1.
!>          If NZC = -1, then a workspace query is assumed; the
!>          routine calculates the number of columns of the array Z that
!>          are needed to hold the eigenvectors.
!>          This value is returned as the first entry of the Z array, and
!>          no error message related to NZC is issued by XERBLA.
!>

Z

!>          Z is COMPLEX( KIND=16 ) array, dimension (LDZ, NZC)
!>          If JOBZ = 'V', Z contains the computed eigenvectors.
!>          If JOBZ = 'N', Z is unused.
!>          The eigenvectors are stored in the columns of Z.
!>

LDZ

!>          LDZ is INTEGER
!>          The leading dimension of the array Z. NZC.
!>

ZWORK

!>          ZWORK is COMPLEX( KIND=16 ) array, dimension (max(1,N))
!>          Work array for Z.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (LWORK)
!>          On exit, if INFO = 0, WORK(1) returns the optimal
!>          (and minimal) LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,18*N)
!>          if JOBZ = 'V', and LWORK >= max(1,12*N) if JOBZ = 'N'.
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (LIWORK)
!>          Work array for eigenvalues.
!>

LIWORK

!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.  LIWORK >= max(1,10*N)
!>          if the eigenvectors are desired, and LIWORK >= max(1,8*N)
!>          if only the eigenvalues are to be computed.
!>          If LIWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal size of the IWORK array,
!>          returns this value as the first entry of the IWORK array, and
!>          no error message related to LIWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          On exit, INFO
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = 1X, internal error in DLARRE,
!>                if INFO = 2X, internal error in ZLARRV.
!>                Here, the digit X = ABS( IINFO ) < 10, where IINFO is
!>                the nonzero error code returned by DLARRE or
!>                ZLARRV, respectively.
!>
