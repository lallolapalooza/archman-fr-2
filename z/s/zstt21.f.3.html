Documentation de la fonction/sous-programme

subroutine zstt21 (integer n, integer kband, double precision, dimension( * ) ad, double precision, dimension( * ) ae, double precision, dimension( * ) sd, double precision, dimension( * ) se, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, double precision, dimension( 2 ) result)

ZSTT21

But :

!>
!> ZSTT21  vérifie une décomposition de la forme
!>
!>    A = U S U**H
!>
!> où **H signifie transposée conjuguée, A est symétrique tridiagonale réelle,
!> U est unitaire, et S est diagonale réelle (si KBAND=0) ou symétrique
!> tridiagonale (si KBAND=1).  Deux tests sont effectués :
!>
!>    RESULT(1) = | A - U S U**H | / ( |A| n ulp )
!>
!>    RESULT(2) = | I - U U**H | / ( n ulp )
!>

Paramètres

N 
!>          N est un ENTIER
!>          La taille de la matrice. Si elle est nulle, ZSTT21 ne fait rien.
!>          Elle doit être supérieure ou égale à zéro.
!>

KBAND

!>          KBAND est un ENTIER
!>          La largeur de bande de la matrice S. Elle ne peut être que zéro ou un.
!>          Si elle est nulle, alors S est diagonale et SE n'est pas référencé. Si
!>          elle est égale à un, alors S est symétrique tridiagonale.
!>

AD

!>          AD est un tableau DOUBLE PRECISION, de dimension (N)
!>          La diagonale de la matrice A originale (non factorisée). On suppose
!>          que A est symétrique tridiagonale réelle.
!>

AE

!>          AE est un tableau DOUBLE PRECISION, de dimension (N-1)
!>          La partie décalée de la diagonale de la matrice A originale. On suppose
!>          que A est symétrique tridiagonale. AE(1) est l'élément (1,2)
!>          et (2,1), AE(2) est l'élément (2,3) et (3,2), etc.
!>

SD

!>          SD est un tableau DOUBLE PRECISION, de dimension (N)
!>          La diagonale de la matrice S réelle (tri-)diagonale symétrique.
!>

SE

!>          SE est un tableau DOUBLE PRECISION, de dimension (N-1)
!>          La partie décalée de la diagonale de la matrice S réelle (tri-)diagonale
!>          symétrique.
!>          Non référencé si KBSND=0. Si KBAND=1, alors AE(1) est l'élément
!>          (1,2) et (2,1), SE(2) est l'élément (2,3) et (3,2), etc.
!>

U

!>          U est un tableau COMPLEX*16, de dimension (LDU, N)
!>          La matrice unitaire dans la décomposition.
!>

LDU

!>          LDU est un ENTIER
!>          La dimension principale de U. LDU doit être supérieur ou égal à N.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (N**2)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (N)
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, de dimension (2)
!>          Les valeurs calculées par les deux tests décrits ci-dessus. Les
!>          valeurs sont actuellement limitées à 1/ulp, pour éviter le débordement.
!>          RESULT(1) est toujours modifié.
!>
