sous-programme zsytrs (caractère uplo, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, complexe*16, dimension( ldb, * ) b, entier ldb, entier info)

ZSYTRS

Objectif :

!>
!> ZSYTRS résout un système d'équations linéaires A*X = B avec une matrice
!> complexe symétrique A en utilisant la factorisation A = U*D*U**T ou
!> A = L*D*L**T calculée par ZSYTRF.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U' : Triangulaire supérieure, forme A = U*D*U**T ;
!>          = 'L' : Triangulaire inférieure, forme A = L*D*L**T.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>          obtenir le facteur U ou L calculé par ZSYTRF.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure par blocs de D
!>          tels que déterminés par ZSYTRF.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          À l'entrée, la matrice des seconds membres B.
!>          À la sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
