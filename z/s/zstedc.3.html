Documentation de fonction/sous-programme

sous-programme zstedc (caractère compz, entier n, double précision, dimension( * ) d, double précision, dimension( * ) e, complexe*16, dimension( ldz, * ) z, entier ldz, complexe*16, dimension( * ) work, entier lwork, double précision, dimension( * ) rwork, entier lrwork, entier, dimension( * ) iwork, entier liwork, entier info)

ZSTEDC

Objectif :

!>
!> ZSTEDC calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice tridiagonale symétrique en utilisant la méthode de « diviser pour régner ».
!> Les vecteurs propres d'une matrice hermitienne complète ou bande complexe peuvent également
!> être trouvés si ZHETRD ou ZHPTRD ou ZHBTRD a été utilisé pour réduire cette
!> matrice à une forme tridiagonale.
!>
!>

Paramètres

COMPZ 
!>          COMPZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres.
!>          = 'I':  Calculer également les vecteurs propres de la matrice tridiagonale.
!>          = 'V':  Calculer également les vecteurs propres de la matrice hermitienne d'origine
!>                  . À l'entrée, Z contient la matrice unitaire utilisée
!>                  pour réduire la matrice d'origine à une forme tridiagonale.
!>

N

!>          N est INTEGER
!>          La dimension de la matrice tridiagonale symétrique. N >= 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, les éléments diagonaux de la matrice tridiagonale.
!>          À la sortie, si INFO = 0, les valeurs propres dans l'ordre croissant.
!>

E

!>          E est un tableau DOUBLE PRECISION, dimension (N-1)
!>          À l'entrée, les éléments sous-diagonaux de la matrice tridiagonale.
!>          À la sortie, E a été détruit.
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ,N)
!>          À l'entrée, si COMPZ = 'V', alors Z contient la matrice
!>          unitaire utilisée dans la réduction à la forme tridiagonale.
!>          À la sortie, si INFO = 0, alors si COMPZ = 'V', Z contient les
!>          vecteurs propres orthonormés de la matrice hermitienne d'origine,
!>          et si COMPZ = 'I', Z contient les vecteurs propres
!>          orthonormés de la matrice tridiagonale symétrique.
!>          Si COMPZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1.
!>          Si des vecteurs propres sont souhaités, alors LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si COMPZ = 'N' ou 'I', ou N <= 1, LWORK doit être au moins 1.
!>          Si COMPZ = 'V' et N > 1, LWORK doit être au moins N*N.
!>          Notez que pour COMPZ = 'V', alors si N est inférieur ou
!>          égal à la taille minimale de division, généralement 25, alors LWORK n'a besoin
!>          d'être que 1.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LRWORK))
!>          À la sortie, si INFO = 0, RWORK(1) contient le LRWORK optimal.
!>

LRWORK

!>          LRWORK est INTEGER
!>          La dimension du tableau RWORK.
!>          Si COMPZ = 'N' ou N <= 1, LRWORK doit être au moins 1.
!>          Si COMPZ = 'V' et N > 1, LRWORK doit être au moins
!>                         1 + 3*N + 2*N*lg N + 4*N**2 ,
!>                         où lg( N ) = le plus petit entier k tel que
!>                         2**k >= N.
!>          Si COMPZ = 'I' et N > 1, LRWORK doit être au moins
!>                         1 + 4*N + 2*N**2 .
!>          Notez que pour COMPZ = 'I' ou 'V', alors si N est inférieur ou
!>          égal à la taille minimale de division, généralement 25, alors LRWORK
!>          n'a besoin d'être que max(1,2*(N-1)).
!>
!>          Si LRWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des tableaux WORK,
!>          RWORK et IWORK, et aucun message d'erreur lié à LWORK ou LRWORK ou LIWORK
!>          n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) contient le LIWORK optimal.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si COMPZ = 'N' ou N <= 1, LIWORK doit être au moins 1.
!>          Si COMPZ = 'V' ou N > 1, LIWORK doit être au moins
!>                                     6 + 6*N + 5*N*lg N.
!>          Si COMPZ = 'I' ou N > 1, LIWORK doit être au moins
!>                                     3 + 5*N .
!>          Notez que pour COMPZ = 'I' ou 'V', alors si N est inférieur ou
!>          égal à la taille minimale de division, généralement 25, alors LIWORK
!>          n'a besoin d'être que 1.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des tableaux WORK,
!>          RWORK et IWORK, et aucun message d'erreur lié à LWORK ou LRWORK ou LIWORK
!>          n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : L'algorithme n'a pas réussi à calculer une valeur propre lors
!>                du traitement de la sous-matrice située dans les lignes et colonnes
!>                INFO/(N+1) à mod(INFO,N+1).
!>

NOM

zstedc — est un cadre de matrice de chaînes d'opérateurs.

SYNTAXE

SUBROUTINE ZSTEDC(JOBL, N, AP, VL, LDVL, VR, LDVR, WORK, LWORK, RWORK, LRWORK, IWORK, LIWORK, INFO)

Documentation des fonctions/sous-routines

ZSTEDC est une sous-routine de LAPACK pour calculer tous les valeurs propres et vecteurs propres des matrices symétriques tridiagonales représentées sous forme condensée.

Paramètres

  • JOBL : Caractère. Spécifie si les vecteurs propres de gauche et/ou de droite sont calculés.
  • N : Entier. La taille de la matrice.
  • AP : Tableau complexe à deux dimensions. Contient la matrice tridiagonale condensée.
  • VL : Tableau complexe à deux dimensions. Stocke les vecteurs propres de gauche.
  • LDVL : Entier. Le pas de ligne de VL.
  • VR : Tableau complexe à deux dimensions. Stocke les vecteurs propres de droite.
  • LDVR : Entier. Le pas de ligne de VR.
  • WORK : Tableau complexe à deux dimensions. Stocke la mémoire de travail.
  • LWORK : Entier. La taille du tableau WORK.
  • RWORK : Tableau réel à deux dimensions. Stocke la mémoire de travail réelle.
  • LRWORK : Entier. La taille du tableau RWORK.
  • IWORK : Tableau entier à deux dimensions. Stocke la mémoire de travail entière.
  • LIWORK : Entier. La taille du tableau IWORK.
  • INFO : Entier. Indicateur d'erreur.
