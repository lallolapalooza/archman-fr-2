zsync(1) Transfert de fichiers zsync(1)

NOM

zsync - Client de téléchargement partiel/différentiel de fichiers via HTTP

SYNTAXE

zsync [ -u url ] [ -i fichier_entree ] [ -o fichier_sortie ] [ { -s | -q } ] [ -k fichier.zsync ] [ -A nom_hote=nom_utilisateur:mot_de_passe ] { nom_fichier | url }

zsync -V

DESCRIPTION

Télécharge un fichier via HTTP. zsync utilise un fichier de contrôle pour déterminer si des blocs du fichier sont déjà connus du téléchargeur, et ne télécharge que les nouveaux blocs.

Un nom de fichier ou une URL peut être donné sur la ligne de commande - c'est le chemin du fichier de contrôle pour le téléchargement, qui a normalement le nom du fichier réel à télécharger avec .zsync ajouté. (Pour créer ce fichier .zsync, il faut avoir une copie du fichier cible, donc ce fichier devrait être généré par la personne qui fournit le téléchargement).

zsync télécharge dans votre répertoire courant. Il recherche dans le répertoire un fichier portant le même nom que le fichier à télécharger. S'il en trouve un, il suppose que c'est une version précédente ou incomplète du nouveau fichier à télécharger, et analyse ce fichier à la recherche de blocs qui peuvent être utilisés pour construire le fichier cible. (Il recherche aussi un fichier portant le même nom avec .part ajouté, il trouvera donc automatiquement les téléchargements zsync précédemment interrompus et réutilisera les données déjà téléchargées. Si vous savez que le fichier local à utiliser comme entrée a un nom différent, vous devez utiliser -i)

zsync récupère le reste du fichier cible via HTTP. Une fois le téléchargement terminé, l'ancienne version (si le nouveau fichier doit porter le même nom) est mise de côté (une extension .zs-old est ajoutée). L'heure de modification du fichier est réglée pour être la même que celle du fichier source distant (si spécifiée dans le .zsync).

OPTIONS

-A nom_hote=nom_utilisateur:mot_de_passe
Spécifie un nom d'utilisateur et un mot de passe à utiliser avec le nom d'hôte donné. -A peut être utilisé plusieurs fois (avec des noms d'hôtes différents), dans les cas où par exemple le
fichier .zsync se trouve sur un serveur différent de celui du téléchargement, ou s'il y a plusieurs serveurs de téléchargement (il peut y avoir des identifiants d'authentification différents pour différents serveurs - et zsync ne suppose jamais que votre mot de passe doit être envoyé à un serveur autre que celui nommé - sinon les redirections seraient dangereuses !).
-i fichier_entree
Spécifie des fichiers d'entrée (supplémentaires). fichier_entree est analysé pour identifier les blocs communs avec le fichier cible et zsync utilise les blocs trouvés. Peut être utilisé plusieurs fois.
-k fichier.zsync
Indique que zsync doit sauvegarder le fichier zsync qu'il télécharge, avec le nom de fichier donné. Si ce fichier existe déjà, alors zsync effectuera une requête conditionnelle au serveur web, de telle sorte qu'il ne le téléchargera à nouveau que si la copie du serveur est plus récente. zsync ajoutera .part au nom de fichier pour le stocker pendant le téléchargement, et ne remplacera le fichier principal qu'une fois le téléchargement terminé - et si le téléchargement est interrompu, il reprendra en utilisant les données du fichier .part.
-o fichier_sortie
Remplace le nom de fichier de sortie par défaut.
-q
Supprime la barre de progression, le taux de téléchargement et l'affichage de l'ETA.
-s
Synonyme obsolète de -q.
-u url
Ceci spécifie l'URL de référence. Si vous avez un fichier .zsync localement (si vous l'avez téléchargé séparément, avec wget par exemple) et que le fichier .zsync contient une URL relative, vous devez spécifier d'où vous avez obtenu le fichier .zsync afin que zsync sache quel serveur et quel chemin utiliser pour le reste du téléchargement (c'est analogue à ajouter une <base href="..."> à une page web téléchargée pour que les liens fonctionnent).
-V
Affiche la version de zsync.

FICHIERS

VARIABLES D'ENVIRONNEMENT

http_proxy
Doit être l'adresse [http://]nom_hote:port de votre proxy web, si celui-ci est requis pour accéder aux serveurs web cibles.

EXEMPLES

zsync -i /var/lib/apt/lists/server.debian.org_debian_dists_etch_main_binary-i386_Packages http://zsync.moria.org.uk/s/etch/Packages.zsync
