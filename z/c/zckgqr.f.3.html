ZCKGQR

Objectif :

!>
!> ZCKGQR teste
!> ZGGQRF: factorisation GQR pour la matrice A de N par M et la matrice B de N par P,
!> ZGGRQF: factorisation GRQ pour la matrice A de M par N et la matrice B de P par N.
!>

Paramètres

NM 
!>          NM est ENTIER
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau ENTIER, de dimension (NM)
!>          Les valeurs de la dimension ligne(colonne) de la matrice M.
!>

NP

!>          NP est ENTIER
!>          Le nombre de valeurs de P contenues dans le vecteur PVAL.
!>

PVAL

!>          PVAL est un tableau ENTIER, de dimension (NP)
!>          Les valeurs de la dimension ligne(colonne) de la matrice P.
!>

NN

!>          NN est ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau ENTIER, de dimension (NN)
!>          Les valeurs de la dimension colonne(ligne) de la matrice N.
!>

NMATS

!>          NMATS est ENTIER
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions matricielles. Si NMATS >= NTYPES (le nombre
!>          maximum de types de matrices), alors tous les différents types sont
!>          générés pour le test. Si NMATS < NTYPES, une autre ligne d'entrée
!>          est lue pour obtenir les numéros des types de matrices à utiliser.
!>

ISEED

!>          ISEED est un tableau ENTIER, de dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires. Les éléments
!>          du tableau doivent être compris entre 0 et 4095, sinon ils seront
!>          réduits modulo 4096, et ISEED(4) doit être impair.
!>          À la sortie, la prochaine graine dans la séquence de nombres aléatoires
!>          après que toutes les matrices de test aient été générées.
!>

THRESH

!>          THRESH est DOUBLE PRÉCISION
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque ratio de test soit imprimé, utilisez THRESH = 0.
!>

NMAX

!>          NMAX est ENTIER
!>          La valeur maximale permise pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

AQ

!>          AQ est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

AR

!>          AR est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

TAUA

!>          TAUA est un tableau COMPLEX*16, de dimension (NMAX)
!>

B

!>          B est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

BF

!>          BF est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

BZ

!>          BZ est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

BT

!>          BT est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

BWK

!>          BWK est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

TAUB

!>          TAUB est un tableau COMPLEX*16, de dimension (NMAX)
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, de dimension (NMAX)
!>

NIN

!>          NIN est ENTIER
!>          Le numéro d'unité pour l'entrée.
!>

NOUT

!>          NOUT est ENTIER
!>          Le numéro d'unité pour la sortie.
!>

INFO

!>          INFO est ENTIER
!>          = 0 :  sortie réussie
!>          > 0 :  Si ZLATMS renvoie un code d'erreur, sa valeur absolue
!>                 est retournée.
!>
