Documentation de la fonction/sous-programme

sous-routine zchkec (double précision thresh, logique tsterr, entier nin, entier nout)

ZCHKEC

Objectif :

!>
!> ZCHKEC teste les routines d'estimation de condition des valeurs propres
!>        ZTRSYL, CTREXC, CTRSNA, CTRSEN
!>
!> Dans tous les cas, la routine exécute un ensemble fixe d'exemples numériques,
!> les soumet à divers tests et compare les résultats des tests à un seuil THRESH.
!> De plus, ZTRSNA et CTRSEN sont testés en lisant des exemples précalculés à partir d'un fichier (sur l'unité d'entrée NIN).
!> La sortie est écrite sur l'unité de sortie NOUT.
!>

Paramètres

THRESH 
!>          THRESH est DOUBLE PRECISION
!>          Seuil pour les tests de résidus. Un ratio de test calculé passe
!>          le seuil s'il est inférieur à THRESH.
!>

TSTERR

!>          TSTERR est LOGICAL
!>          Indicateur qui détermine si les sorties d'erreur doivent être testées.
!>

NIN

!>          NIN est INTEGER
!>          Le numéro d'unité logique pour l'entrée.
!>

NOUT

!>          NOUT est INTEGER
!>          Le numéro d'unité logique pour la sortie.
!>
