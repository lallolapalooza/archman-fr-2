Documentation Fonction/Sous-programme

sous-programme zchkq3 (logique, dimension( * ) dotype, entier nm, entier, dimension( * ) mval, entier nn, entier, dimension( * ) nval, entier nnb, entier, dimension( * ) nbval, entier, dimension( * ) nxval, précision double thresh, complexe*16, dimension( * ) a, complexe*16, dimension( * ) copya, précision double, dimension( * ) s, complexe*16, dimension( * ) tau, complexe*16, dimension( * ) work, précision double, dimension( * ) rwork, entier, dimension( * ) iwork, entier nout)

ZCHKQ3

Objectif

!>
!> ZCHKQ3 teste ZGEQP3.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .VRAI.; si DOTYPE(j) = .FAUX., alors le type j n'est pas utilisé.
!>

NM

!>          NM est un ENTIER
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau d'ENTIERS, dimension (NM)
!>          Les valeurs de la dimension des lignes de la matrice M.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, dimension (NN)
!>          Les valeurs de la dimension des colonnes de la matrice N.
!>

NNB

!>          NNB est un ENTIER
!>          Le nombre de valeurs de NB et NX contenues dans
!>          les vecteurs NBVAL et NXVAL. Les paramètres de bloc sont utilisés
!>          par paires (NB,NX).
!>

NBVAL

!>          NBVAL est un tableau d'ENTIERS, dimension (NNB)
!>          Les valeurs de la taille de bloc NB.
!>

NXVAL

!>          NXVAL est un tableau d'ENTIERS, dimension (NNB)
!>          Les valeurs du point de croisement NX.
!>

THRESH

!>          THRESH est de PRÉCISION DOUBLE
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour avoir
!>          chaque rapport de test imprimé, utilisez THRESH = 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (MMAX*NMAX)
!>          où MMAX est la valeur maximale de M dans MVAL et NMAX est la
!>          valeur maximale de N dans NVAL.
!>

COPYA

!>          COPYA est un tableau COMPLEX*16, dimension (MMAX*NMAX)
!>

S

!>          S est un tableau de PRÉCISION DOUBLE, dimension
!>                      (min(MMAX,NMAX))
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (MMAX)
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension
!>                      (max(M*max(M,N) + 4*min(M,N) + max(M,N)))
!>

RWORK

!>          RWORK est un tableau de PRÉCISION DOUBLE, dimension (4*NMAX)
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, dimension (2*NMAX)
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro d'unité pour la sortie.
!>
