ZCK(1) Manuel des commandes générales ZCK(1)

NOM

zck — compresse un fichier en utilisant le format zchunk

SYNTAXE

zck [-D fichier | --dict=fichier] [-m morceau | --manual=morceau] [-o fichier | --output=fichier] [-s chaîne | --split=chaîne] [-v | --verbose] fichier

zck -? | --help | --usage | --version

DESCRIPTION

L'utilitaire zck crée un nouveau fichier zchunk à partir des données du fichier d'entrée spécifié.

NOTE: Si aucun fichier de sortie n'est spécifié à l'aide de l'option -o, l'utilitaire zck placera le nouveau fichier avec l'extension .zck dans le répertoire de travail actuel, et non dans le répertoire où se trouve le fichier d'origine.

L'utilitaire zck accepte les arguments optionnels suivants :

-D, --dict
Définit le dictionnaire de compression zstd sur le fichier spécifié.
-m, --manual
Ne fait aucun découpage automatique (implique -s).
-o, --output
Sortie vers le fichier spécifié.
-s, --split
Divise les morceaux au début de la chaîne spécifiée.
-v, --verbose
Opération verbeuse ; affiche des informations diagnostiques.
-?, --help
Affiche les informations d'utilisation du programme et quitte.
--usage
Affiche les informations d'utilisation brèves du programme et quitte.
--version
Affiche les informations de version du programme et quitte.

CODE DE SORTIE

L'utilitaire zck se termine avec le code d'état 0 en cas de succès, et >0 si une erreur se produit.

EXEMPLES

Créez (dans le répertoire courant) un fichier words.zck compressé en zchunk à partir d'un dictionnaire :

zck /usr/share/dict/words

Idem, mais spécifiez un fichier de sortie :

zck -o /tmp/words.txt.zck /usr/share/dict/words

Générez un fichier zchunk avec des morceaux séparés sur les sections HTML :

zck -s '<h2>' doc.html
