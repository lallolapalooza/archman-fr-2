ZCHKAB

Objectif :

!>
!> ZCHKAB est le programme de test pour la routine LAPACK COMPLEX*16
!> ZCGESV/ZCPOSV
!>
!> Le programme doit être piloté par un court fichier de données. Les 5 premières
!> enregistrements spécifient les dimensions du problème et les options du
!> programme en utilisant une entrée dirigée par liste. Les lignes restantes
!> spécifient les chemins de test LAPACK et le nombre de types de matrices à
!> utiliser dans les tests. Un exemple annoté d'un fichier de données peut être
!> obtenu en supprimant les 3 premiers caractères des 9 lignes suivantes :
!> Fichier de données pour tester LAPACK COMPLEX*16 ZCGESV
!> 7                      Nombre de valeurs de M
!> 0 1 2 3 5 10 16        Valeurs de M (dimension de ligne)
!> 1                      Nombre de valeurs de NRHS
!> 2                      Valeurs de NRHS (nombre de côtés droits)
!> 20.0                   Valeur seuil du ratio de test
!> T                      Mettre T pour tester la routine LAPACK
!> T                      Mettre T pour tester les sorties d'erreur
!> DGE    11              Lister les types sur la ligne suivante si 0 < NTYPES < 11
!> DPO    9               Lister les types sur la ligne suivante si 0 < NTYPES < 9
!> 
!>  NMAX    ENTIER
!>          La valeur maximale autorisée pour N
!>
!>  MAXIN   ENTIER
!>          Le nombre de valeurs différentes pouvant être utilisées pour chacune
!>          de M, N, NRHS, NB, et NX
!>
!>  MAXRHS  ENTIER
!>          Le nombre maximal de côtés droits
!>
!>  NIN     ENTIER
!>          Le numéro d'unité pour l'entrée
!>
!>  NOUT    ENTIER
!>          Le numéro d'unité pour la sortie
!>
