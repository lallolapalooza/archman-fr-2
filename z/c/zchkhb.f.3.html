!>
!> ZCHKHB teste la réduction d'une matrice bande hermitienne à sa forme tridiagonale,
!> utilisée avec le problème de valeurs propres hermitiennes.
!>
!> ZHBTRD factorise une matrice bande hermitienne A en  U S U* , où * signifie
!> transposée conjuguée, S est tridiagonale symétrique et U est unitaire.
!> ZHBTRD peut utiliser seulement le triangle inférieur ou seulement le triangle supérieur
!> de A ; ZCHKHB vérifie les deux cas.
!>
!> Lorsque ZCHKHB est appelée, un nombre de tailles de matrices (), un nombre
!> de largeurs de bande () et un nombre de types de matrices sont
!> spécifiés. Pour chaque taille (), chaque largeur de bande () inférieure ou égale à
!>, et chaque type de matrice, une matrice sera générée
!> et utilisée pour tester la routine de réduction hermitienne bande. Pour chaque
!> matrice, un certain nombre de tests sera effectué :
!>
!> (1)     | A - V S V* | / ( |A| n ulp )  calculé par ZHBTRD avec
!>                                         UPLO='U'
!>
!> (2)     | I - UU* | / ( n ulp )
!>
!> (3)     | A - V S V* | / ( |A| n ulp )  calculé par ZHBTRD avec
!>                                         UPLO='L'
!>
!> (4)     | I - UU* | / ( n ulp )
!>
!> Les  sont spécifiées par un tableau NN(1:NSIZES) ; la valeur de
!> chaque élément NN(j) spécifie une taille.
!> Les  sont spécifiées par un tableau logique DOTYPE( 1:NTYPES ) ;
!> si DOTYPE(j) est .VRAI., alors la matrice de type  sera générée.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!>
!> (3)  Une matrice diagonale avec des entrées régulièrement espacées
!>      1, ..., ULP  et des signes aléatoires.
!>      (ULP = (premier nombre supérieur à 1) - 1 )
!> (4)  Une matrice diagonale avec des entrées géométriquement espacées
!>      1, ..., ULP  et des signes aléatoires.
!> (5)  Une matrice diagonale avec des entrées  1, ULP, ..., ULP
!>      et des signes aléatoires.
!>
!> (6)  Identique à (4), mais multipliée par SQRT( seuil de dépassement de capacité )
!> (7)  Identique à (4), mais multipliée par SQRT( seuil de sous-dépassement de capacité )
!>
!> (8)  Une matrice de la forme  U* D U, où U est unitaire et
!>      D a des entrées régulièrement espacées 1, ..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (9)  Une matrice de la forme  U* D U, où U est unitaire et
!>      D a des entrées géométriquement espacées 1, ..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (10) Une matrice de la forme  U* D U, où U est unitaire et
!>      D a des entrées  1, ULP,..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (11) Identique à (8), mais multipliée par SQRT( seuil de dépassement de capacité )
!> (12) Identique à (8), mais multipliée par SQRT( seuil de sous-dépassement de capacité )
!>
!> (13) Matrice hermitienne avec des entrées aléatoires choisies dans (-1,1).
!> (14) Identique à (13), mais multipliée par SQRT( seuil de dépassement de capacité )
!> (15) Identique à (13), mais multipliée par SQRT( seuil de sous-dépassement de capacité )
!>

Paramètres

NSIZES 
!>          NSIZES est de type INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il est zéro,
!>          ZCHKHB ne fait rien. Il doit être supérieur ou égal à zéro.
!>

NN

!>          NN est un tableau de type INTEGER, dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs zéro seront ignorées. Les valeurs doivent être supérieures ou égales à
!>          zéro.
!>

NWDTHS

!>          NWDTHS est de type INTEGER
!>          Le nombre de largeurs de bande à utiliser. S'il est zéro,
!>          ZCHKHB ne fait rien. Il doit être supérieur ou égal à zéro.
!>

KK

!>          KK est un tableau de type INTEGER, dimension (NWDTHS)
!>          Un tableau contenant les largeurs de bande à utiliser pour les matrices bande.
!>          Les valeurs doivent être supérieures ou égales à zéro.
!>

NTYPES

!>          NTYPES est de type INTEGER
!>          Le nombre d'éléments dans DOTYPE. S'il est zéro, ZCHKHB
!>          ne fait rien. Il doit être supérieur ou égal à zéro. S'il est MAXTYP+1
!>          et que NSIZES est 1, alors un type supplémentaire, MAXTYP+1, est
!>          défini, qui consiste à utiliser la matrice présente dans A. Ceci
!>          n'est utile que si DOTYPE(1:MAXTYP) est .FAUX. et
!>          DOTYPE(MAXTYP+1) est .VRAI. .
!>

DOTYPE

!>          DOTYPE est un tableau de type LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) est .VRAI., alors pour chaque taille dans NN, une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximum de types
!>          définis (PARAMÈTRE MAXTYP), alors les types NTYPES+1 à
!>          MAXTYP ne seront pas générés. Si NTYPES est supérieur
!>          à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!>

ISEED

!>          ISEED est un tableau de type INTEGER, dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une séquence
!>          linéaire congruente limitée à de petits entiers, et devrait donc
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie et peuvent être utilisées
!>          dans l'appel suivant à ZCHKHB pour continuer la même séquence de nombres
!>          aléatoires.
!>

THRESH

!>          THRESH est de type DOUBLE PRECISION
!>          Un test sera compté comme  si le , calculé comme
!>          décrit ci-dessus, dépasse THRESH. Notez que l'erreur
!>          est mise à l'échelle pour être de l'ordre de 1, donc THRESH devrait être un multiple raisonnable
!>          de 1, par exemple 10 ou 100. En particulier,
!>          il ne doit pas dépendre de la précision (simple ou double)
!>          ou de la taille de la matrice. Il doit être supérieur ou égal à zéro.
!>

NOUNIT

!>          NOUNIT est de type INTEGER
!>          Le numéro d'unité FORTRAN pour l'affichage des messages d'erreur
!>          (par exemple, si une routine renvoie IINFO différent de 0.)
!>

A

!>          A est un tableau de type COMPLEX*16, dimension
!>                            (LDA, max(NN))
!>          Utilisé pour contenir la matrice dont les valeurs propres doivent être
!>          calculées.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale de A. Elle doit être au moins 2 (pas 1 !)
!>          et au moins max( KK )+1.
!>

SD

!>          SD est un tableau de type DOUBLE PRECISION, dimension (max(NN))
!>          Utilisé pour contenir la diagonale de la matrice tridiagonale calculée
!>          par ZHBTRD.
!>

SE

!>          SE est un tableau de type DOUBLE PRECISION, dimension (max(NN))
!>          Utilisé pour contenir les éléments hors diagonale de la matrice tridiagonale
!>          calculée par ZHBTRD.
!>

U

!>          U est un tableau de type COMPLEX*16, dimension (LDU, max(NN))
!>          Utilisé pour contenir la matrice unitaire calculée par ZHBTRD.
!>

LDU

!>          LDU est de type INTEGER
!>          La dimension principale de U. Elle doit être au moins max( NN ).
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, dimension (LWORK)
!>          Un tableau de travail utilisé par les routines internes.
!>

LWORK

!>          LWORK est de type INTEGER
!>          La dimension du tableau WORK. Il doit être suffisamment grand pour contenir
!>          les données de travail requises par ZHBTRD.
!>

RWORK

!>          RWORK est un tableau de type DOUBLE PRECISION, dimension (max(NN))
!>          Un tableau de travail utilisé pour les calculs en double précision.
!>

RESULT

!>          RESULT est un tableau de type DOUBLE PRECISION, dimension (4)
!>          Les résultats des quatre tests sont stockés dans ce tableau :
!>          RESULT(1) : Erreur du test (1)
!>          RESULT(2) : Erreur du test (2)
!>          RESULT(3) : Erreur du test (3)
!>          RESULT(4) : Erreur du test (4)
!>

INFO

!>          INFO est de type INTEGER
!>          Info = 0 : succès
!>          Info < 0 : un des paramètres d'entrée est invalide.
!>
