sous-routine zcposv (caractère uplo, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldx, * ) x, entier ldx, complexe*16, dimension( n, * ) work, complexe, dimension( * ) swork, double précision, dimension( * ) rwork, entier iter, entier info)

ZCPOSV calcule la solution du système d'équations linéaires A * X = B pour les matrices PO

Objectif :

!>
!> ZCPOSV calcule la solution d'un système linéaire complexe
!>    A * X = B,
!> où A est une matrice hermitienne et définie positive N par N et X et B
!> sont des matrices N par NRHS.
!>
!> ZCPOSV tente d'abord de factoriser la matrice en COMPLEX et utilise cette
!> factorisation dans une procédure de raffinement itératif pour produire une
!> solution avec une qualité d'erreur rétrograde normée COMPLEX*16 (voir ci-dessous).
!> Si l'approche échoue, la méthode bascule vers une factorisation et une résolution
!> en COMPLEX*16.
!>
!> Le raffinement itératif ne sera pas une stratégie gagnante si
!> le rapport performance COMPLEX sur performance COMPLEX*16 est trop
!> petit. Une stratégie raisonnable devrait tenir compte du nombre de membres
!> de droite et de la taille de la matrice. Cela pourrait être fait
!> avec un appel à ILAENV à l'avenir. Jusqu'à présent, nous essayons toujours
!> le raffinement itératif.
!>
!> Le processus de raffinement itératif est arrêté si
!>     ITER > ITERMAX
!> ou pour tous les RHS :
!>     RNRM < SQRT(N)*XNRM*ANRM*EPS*BWDMAX
!> où
!>     o ITER est le numéro de l'itération actuelle dans le processus de
!>       raffinement itératif
!>     o RNRM est la norme infinie du résidu
!>     o XNRM est la norme infinie de la solution
!>     o ANRM est la norme d'opérateur infinie de la matrice A
!>     o EPS est l'epsilon machine retourné par DLAMCH('Epsilon')
!> Les valeurs ITERMAX et BWDMAX sont fixées à 30 et 1.0D+00 respectivement.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16,
!>          de dimension (LDA,N)
!>          En entrée, la matrice hermitienne A. Si UPLO = 'U', la partie
!>          supérieure triangulaire N par N de A contient la partie
!>          supérieure triangulaire de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la
!>          partie inférieure triangulaire N par N de A contient la partie
!>          inférieure triangulaire de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>
!>          Notez que les parties imaginaires des éléments diagonaux
!>          n'ont pas besoin d'être définies et sont supposées être nulles.
!>
!>          En sortie, si le raffinement itératif a été utilisé avec succès
!>          (INFO = 0 et ITER >= 0, voir la description ci-dessous), alors A est
!>          inchangée, si la factorisation en double précision a été utilisée
!>          (INFO = 0 et ITER < 0, voir la description ci-dessous), alors le
!>          tableau A contient le facteur U ou L de la factorisation de Cholesky
!>          A = U**H*U ou A = L*L**H.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>          La matrice membre de droite B de taille N par NRHS.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, de dimension (LDX,NRHS)
!>          Si INFO = 0, la matrice solution X de taille N par NRHS.
!>

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (N,NRHS)
!>          Ce tableau est utilisé pour contenir les vecteurs résiduels.
!>

SWORK

!>          SWORK est un tableau COMPLEX, de dimension (N*(N+NRHS))
!>          Ce tableau est utilisé pour utiliser la matrice en simple précision et
!>          les membres de droite ou les solutions en simple précision.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, de dimension (N)
!>

ITER

!>          ITER est ENTIER
!>          < 0 : le raffinement itératif a échoué, une factorisation
!>               en COMPLEX*16 a été effectuée.
!>               -1 : la routine a basculé vers la précision complète pour
!>                    des raisons d'implémentation ou spécifiques à la machine.
!>               -2 : la réduction de la précision a provoqué un débordement,
!>                    la routine a basculé vers la précision complète.
!>               -3 : échec de CPOTRF
!>               -31: arrêt du raffinement itératif après la 30ème
!>                    itération.
!>          > 0 : le raffinement itératif a été utilisé avec succès.
!>               Retourne le nombre d'itérations.
!>

INFO

!>          INFO est ENTIER
!>          = 0 :  sortie réussie.
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 :  si INFO = i, le mineur principal de tête d'ordre i
!>                de (COMPLEX*16) A n'est pas positif, donc la factorisation
!>                n'a pas pu être complétée, et la solution n'a pas été
!>                calculée.
!>
