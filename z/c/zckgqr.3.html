ZCKGQR

But:

!>
!> ZCKGQR teste
!> ZGGQRF : Factorisation GQR pour la matrice N-par-M A et la matrice N-par-P B,
!> ZGGRQF : Factorisation GRQ pour la matrice M-par-N A et la matrice P-par-N B.
!>

Paramètres

NM 
!>          NM est un ENTIER
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau d'ENTIERS, dimension (NM)
!>          Les valeurs de la dimension ligne (colonne) de matrice M.
!>

NP

!>          NP est un ENTIER
!>          Le nombre de valeurs de P contenues dans le vecteur PVAL.
!>

PVAL

!>          PVAL est un tableau d'ENTIERS, dimension (NP)
!>          Les valeurs de la dimension ligne (colonne) de matrice P.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, dimension (NN)
!>          Les valeurs de la dimension colonne (ligne) de matrice N.
!>

NMATS

!>          NMATS est un ENTIER
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions de matrices. Si NMATS >= NTYPES (le nombre maximum
!>          de types de matrices), alors tous les types différents sont
!>          générés pour le test. Si NMATS < NTYPES, une autre ligne d'entrée
!>          est lue pour obtenir les numéros des types de matrices à utiliser.
!>

ISEED

!>          ISEED est un tableau d'ENTIERS, dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires. Les éléments
!>          du tableau doivent être compris entre 0 et 4095, sinon ils seront
!>          réduits modulo 4096, et ISEED(4) doit être impair.
!>          À la sortie, la prochaine graine dans la séquence de nombres aléatoires
!>          après la génération de toutes les matrices de test.
!>

THRESH

!>          THRESH est un DOUBLE PRÉCISION
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque ratio de test soit imprimé, utiliser THRESH = 0.
!>

NMAX

!>          NMAX est un ENTIER
!>          La valeur maximale autorisée pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

AQ

!>          AQ est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

AR

!>          AR est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

TAUA

!>          TAUA est un tableau COMPLEX*16, dimension (NMAX)
!>

B

!>          B est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

BF

!>          BF est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

BZ

!>          BZ est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

BT

!>          BT est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

BWK

!>          BWK est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

TAUB

!>          TAUB est un tableau COMPLEX*16, dimension (NMAX)
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (NMAX)
!>

NIN

!>          NIN est un ENTIER
!>          Le numéro d'unité pour l'entrée.
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro d'unité pour la sortie.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 :  fin réussie
!>          > 0 :  Si ZLATMS renvoie un code d'erreur, la valeur absolue
!>                 de celui-ci est retournée.
!>
