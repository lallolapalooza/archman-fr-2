ZCKGSV

Objectif :

!>
!> ZCKGSV teste ZGGSVD :
!>        la GSVD pour la matrice A de dimension M-par-N et la matrice B de dimension P-par-N.
!>

Paramètres

NM 
!>          NM est ENTIER
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau de ENTIER, dimension (NM)
!>          Les valeurs de la dimension des lignes de la matrice M.
!>

PVAL

!>          PVAL est un tableau de ENTIER, dimension (NP)
!>          Les valeurs de la dimension des lignes de la matrice P.
!>

NVAL

!>          NVAL est un tableau de ENTIER, dimension (NN)
!>          Les valeurs de la dimension des colonnes de la matrice N.
!>

NMATS

!>          NMATS est ENTIER
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions de matrices. Si NMATS >= NTYPES (le nombre maximum
!>          de types de matrices), alors tous les types différents sont
!>          générés pour le test. Si NMATS < NTYPES, une autre ligne d'entrée
!>          est lue pour obtenir les numéros des types de matrices à utiliser.
!>

ISEED

!>          ISEED est un tableau de ENTIER, dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires. Les éléments
!>          du tableau doivent être compris entre 0 et 4095, sinon ils seront
!>          réduits modulo 4096, et ISEED(4) doit être impair.
!>          À la sortie, la prochaine graine dans la séquence de nombres aléatoires après
!>          la génération de toutes les matrices de test.
!>

THRESH

!>          THRESH est DOUBLE PRÉCISION
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULTAT >= THRESH. Pour imprimer
!>          chaque ratio de test, utilisez THRESH = 0.
!>

NMAX

!>          NMAX est ENTIER
!>          La valeur maximale autorisée pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau de COMPLEXE*16, dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau de COMPLEXE*16, dimension (NMAX*NMAX)
!>

B

!>          B est un tableau de COMPLEXE*16, dimension (NMAX*NMAX)
!>

BF

!>          BF est un tableau de COMPLEXE*16, dimension (NMAX*NMAX)
!>

U

!>          U est un tableau de COMPLEXE*16, dimension (NMAX*NMAX)
!>

V

!>          V est un tableau de COMPLEXE*16, dimension (NMAX*NMAX)
!>

Q

!>          Q est un tableau de COMPLEXE*16, dimension (NMAX*NMAX)
!>

ALPHA

!>          ALPHA est un tableau de DOUBLE PRÉCISION, dimension (NMAX)
!>

BETA

!>          BETA est un tableau de DOUBLE PRÉCISION, dimension (NMAX)
!>

R

!>          R est un tableau de COMPLEXE*16, dimension (NMAX*NMAX)
!>

IWORK

!>          IWORK est un tableau de ENTIER, dimension (NMAX)
!>

WORK

!>          WORK est un tableau de COMPLEXE*16, dimension (NMAX*NMAX)
!>

RWORK

!>          RWORK est un tableau de DOUBLE PRÉCISION, dimension (NMAX)
!>

NIN

!>          NIN est ENTIER
!>          Le numéro d'unité pour l'entrée.
!>

NOUT

!>          NOUT est ENTIER
!>          Le numéro d'unité pour la sortie.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          > 0 : Si ZLATMS renvoie un code d'erreur, sa valeur absolue est retournée.
!>
