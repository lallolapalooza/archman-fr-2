Objectif :

!>
!> ZCHKBD vérifie les routines de décomposition en valeurs singulières (SVD).
!>
!> ZGEBRD réduit une matrice complexe générale m par n, A, à une forme
!>   bidiagonale réelle supérieure ou inférieure par une transformation orthogonale :
!> Q' * A * P = B (ou A = Q * B * P'). La matrice B est supérieurement bidiagonale
!> si m >= n et inférieurement bidiagonale si m < n.
!>
!> ZUNGBR génère les matrices orthogonales Q et P' à partir de ZGEBRD.
!> Notez que Q et P ne sont pas nécessairement carrées.
!>
!> ZBDSQR calcule la décomposition en valeurs singulières de la matrice
!> bidiagonale B sous la forme B = U S V'. Elle est appelée trois fois pour
!> calculer :
!>    1)  B = U S1 V', où S1 est la matrice diagonale des valeurs singulières
!>        et les colonnes des matrices U et V sont les vecteurs singuliers
!>        gauche et droit, respectivement, de B.
!>    2)  Idem 1), mais les valeurs singulières sont stockées dans S2 et les
!>        vecteurs singuliers ne sont pas calculés.
!>    3)  A = (UQ) S (P'V'), la SVD de la matrice originale A.
!> De plus, ZBDSQR a une option pour appliquer la matrice orthogonale gauche U
!> à une matrice X, utile dans les applications de moindres carrés.
!>
!> Pour chaque paire de dimensions de matrice (M,N) et chaque type de matrice
!> sélectionné, une matrice A de taille M par N et une matrice X de taille
!> M par NRHS sont générées. Les dimensions du problème sont les suivantes :
!>    A:          M x N
!>    Q:          M x min(M,N) (mais M x M si NRHS > 0)
!>    P:          min(M,N) x N
!>    B:          min(M,N) x min(M,N)
!>    U, V:       min(M,N) x min(M,N)
!>    S1, S2      diagonales, d'ordre min(M,N)
!>    X:          M x NRHS
!>
!> Pour chaque matrice générée, 14 tests sont effectués :
!>
!> Tests ZGEBRD et ZUNGBR
!>
!> (1)   | A - Q B PT | / ( |A| max(M,N) ulp ), PT = P'
!>
!> (2)   | I - Q' Q | / ( M ulp )
!>
!> (3)   | I - PT PT' | / ( N ulp )
!>
!> Test ZBDSQR sur la matrice bidiagonale B
!>
!> (4)   | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'
!>
!> (5)   | Y - U Z | / ( |Y| max(min(M,N),k) ulp ), où Y = Q' X
!>                                                  et   Z = U' Y.
!> (6)   | I - U' U | / ( min(M,N) ulp )
!>
!> (7)   | I - VT VT' | / ( min(M,N) ulp )
!>
!> (8)   S1 contient min(M,N) valeurs non négatives dans l'ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (9)   0 si les vraies valeurs singulières de B sont dans THRESH par
!>       rapport à celles de S1.  2*THRESH si ce n'est pas le cas.
!>       (Testé en utilisant DSVDCH)
!>
!> (10)  | S1 - S2 | / ( |S1| ulp ), où S2 est calculé sans calculer U et V.
!>
!> Test ZBDSQR sur la matrice A
!>
!> (11)  | A - (QU) S (VT PT) | / ( |A| max(M,N) ulp )
!>
!> (12)  | X - (QU) Z | / ( |X| max(M,k) ulp )
!>
!> (13)  | I - (QU)'(QU) | / ( M ulp )
!>
!> (14)  | I - (VT PT) (PT'VT') | / ( N ulp )
!>
!> Les types de matrices possibles sont :
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!>
!> (3)  Une matrice diagonale avec des entrées régulièrement espacées
!>      1, ..., ULP et des signes aléatoires.
!>      (ULP = (premier nombre supérieur à 1) - 1 )
!> (4)  Une matrice diagonale avec des entrées géométriquement espacées
!>      1, ..., ULP et des signes aléatoires.
!> (5)  Une matrice diagonale avec des entrées 1, ULP, ..., ULP
!>      et des signes aléatoires.
!>
!> (6)  Identique à (3), mais multiplié par SQRT( seuil de débordement )
!> (7)  Identique à (3), mais multiplié par SQRT( seuil de sous-dépassement )
!>
!> (8)  Une matrice de la forme U D V, où U et V sont orthogonales et
!>      D a des entrées régulièrement espacées 1, ..., ULP avec des signes
!>      aléatoires sur la diagonale.
!>
!> (9)  Une matrice de la forme U D V, où U et V sont orthogonales et
!>      D a des entrées géométriquement espacées 1, ..., ULP avec des signes
!>      aléatoires sur la diagonale.
!>
!> (10) Une matrice de la forme U D V, où U et V sont orthogonales et
!>      D a des entrées 1, ULP,..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (11) Identique à (8), mais multiplié par SQRT( seuil de débordement )
!> (12) Identique à (8), mais multiplié par SQRT( seuil de sous-dépassement )
!>
!> (13) Matrice rectangulaire avec des entrées aléatoires choisies dans (-1,1).
!> (14) Identique à (13), mais multiplié par SQRT( seuil de débordement )
!> (15) Identique à (13), mais multiplié par SQRT( seuil de sous-dépassement )
!>
!> Cas spécial :
!> (16) Une matrice bidiagonale avec des entrées aléatoires choisies selon
!>      une distribution logarithmique sur [ulp^2,ulp^(-2)] (C'est-à-dire que
!>      chaque entrée est e^x, où x est choisi uniformément sur
!>      [ 2 log(ulp), -2 log(ulp) ] .) Pour *ce* type :
!>      (a) ZGEBRD n'est pas appelée pour la réduire à la forme bidiagonale.
!>      (b) la matrice bidiagonale est de taille min(M,N) x min(M,N) ; si M

NSIZES 
NSIZES is INTEGER
The number of pairs (M,N) to be tested.
NN 
NN is INTEGER array, dimension (NSIZES)
The values of the second dimension (number of columns) of the matrices
A to be tested.
MM 
MM is INTEGER array, dimension (NSIZES)
The values of the first dimension (number of rows) of the matrices
A to be tested.
NTYPES 
NTYPES is INTEGER
The number of types of matrices to be generated.  Each type is
defined by a pair of integers (JTYPE, KMODE), where JTYPE is a
number from 1 to MAXTYP, and KMODE is one of 0, 1, 2, 3, 4.
The types to be tested are:
    (JTYPE, KMODE) for JTYPE = 1 to NTYPES,
where JTYPE may be larger than MAXTYP.
The routine DOTYPE(j) is called for j = 1, 2, ..., NTYPES.
If DOTYPE(j) is not in the range 1 to MAXTYP, the call is ignored.
If NTYPES > MAXTYP, then types JTYPE=MAXTYP+1 through NTYPES
will not be generated. If NTYPES is less than the maximum number
of types defined (PARAMETER MAXTYP), then types NTYPES+1 through
MAXTYP will not be generated. If NTYPES is larger than MAXTYP,
DOTYPE(MAXTYP+1) through DOTYPE(NTYPES) will be ignored.
NRHS 
NRHS is INTEGER
The number of columns in the matrices X, Y, and Z, used in testing
ZBDSQR. If NRHS = 0, then the operations on the right-hand side will
not be tested. NRHS must be at least 0.
ISEED 
ISEED is INTEGER array, dimension (4)
On entry ISEED specifies the seed of the random number generator. The
array elements should be between 0 and 4095; if not they will be
reduced mod 4096. Also, ISEED(4) must be odd. The values of ISEED are
changed on exit, and can be used in the next call to ZCHKBD to
continue the same random number sequence.
THRESH 
THRESH is DOUBLE PRECISION
The threshold value for the test ratios. A result is included in the
output file if RESULT >= THRESH. To have every test ratio printed,
use THRESH = 0. Note that the expected value of the test ratios is
O(1), so THRESH should be a reasonably small multiple of 1, e.g.,
10 or 100.
