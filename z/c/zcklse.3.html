sous-programme zcklse (integer nn, integer, dimension( * ) mval, integer, dimension( * ) pval, integer, dimension( * ) nval, integer nmats, integer, dimension( 4 ) iseed, double precision thresh, integer nmax, complex*16, dimension( * ) a, complex*16, dimension( * ) af, complex*16, dimension( * ) b, complex*16, dimension( * ) bf, complex*16, dimension( * ) x, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer nin, integer nout, integer info)

ZCKLSE

Objectif:

!>
!> ZCKLSE teste ZGGLSE - un sous-programme pour résoudre le problème des moindres carrés avec contraintes d'égalité linéaire (LSE).
!>

Paramètres

NN 
!>          NN est un entier
!>          Le nombre de valeurs de (M,P,N) contenues dans les vecteurs
!>          (MVAL, PVAL, NVAL).
!>

MVAL

!>          MVAL est un tableau d'entiers, dimension (NN)
!>          Les valeurs de la dimension M (lignes/colonnes) de la matrice.
!>

PVAL

!>          PVAL est un tableau d'entiers, dimension (NN)
!>          Les valeurs de la dimension P (lignes/colonnes) de la matrice.
!>

NVAL

!>          NVAL est un tableau d'entiers, dimension (NN)
!>          Les valeurs de la dimension N (colonnes/lignes) de la matrice.
!>

NMATS

!>          NMATS est un entier
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions de matrices. Si NMATS >= NTYPES (le nombre maximum
!>          de types de matrices), alors tous les différents types sont
!>          générés pour le test. Si NMATS < NTYPES, une autre ligne d'entrée
!>          est lue pour obtenir les numéros des types de matrices à utiliser.
!>

ISEED

!>          ISEED est un tableau d'entiers, dimension (4)
!>          En entrée, la graine du générateur de nombres aléatoires. Les éléments
!>          du tableau doivent être compris entre 0 et 4095, sinon ils seront
!>          réduits modulo 4096, et ISEED(4) doit être impair.
!>          En sortie, la graine suivante dans la séquence de nombres aléatoires après
!>          la génération de toutes les matrices de test.
!>

THRESH

!>          THRESH est de type DOUBLE PRECISION
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.
!>

NMAX

!>          NMAX est un entier
!>          La valeur maximale autorisée pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau de type COMPLEX*16, dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau de type COMPLEX*16, dimension (NMAX*NMAX)
!>

B

!>          B est un tableau de type COMPLEX*16, dimension (NMAX*NMAX)
!>

BF

!>          BF est un tableau de type COMPLEX*16, dimension (NMAX*NMAX)
!>

X

!>          X est un tableau de type COMPLEX*16, dimension (5*NMAX)
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, dimension (NMAX*NMAX)
!>

RWORK

!>          RWORK est un tableau de type DOUBLE PRECISION, dimension (NMAX)
!>

NIN

!>          NIN est un entier
!>          Le numéro d'unité pour l'entrée.
!>

NOUT

!>          NOUT est un entier
!>          Le numéro d'unité pour la sortie.
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          > 0 : Si ZLATMS renvoie un code d'erreur, sa valeur absolue est retournée.
!>
