programme zblat2

ZBLAT2

Objectif :

!>
!> Programme de test pour les BLAS complexes*16 de niveau 2.
!>
!> Le programme doit être piloté par un fichier de données court. Les 18 premiers enregistrements
!> du fichier sont lus en utilisant l'entrée dirigée par liste, les 17 enregistrements
!> suivants sont lus en utilisant le format ( A6, L2 ). Un exemple annoté de fichier de données
!> peut être obtenu en supprimant les 3 premiers caractères des
!> 35 lignes suivantes :
!> 'zblat2.out'      NOM DU FICHIER DE SORTIE RÉSUMÉ
!> 6                 NUMÉRO D'UNITÉ DU FICHIER RÉSUMÉ
!> 'CBLA2T.SNAP'     NOM DU FICHIER DE SORTIE SNAPSHOT
!> -1                NUMÉRO D'UNITÉ DU FICHIER SNAPSHOT (NON UTILISÉ SI .LT. 0)
!> F        INDICATEUR LOGIQUE, T POUR REMbobiner le FICHIER SNAPSHOT après CHAQUE ENREGISTREMENT.
!> F        INDICATEUR LOGIQUE, T POUR ARRÊTER EN CAS D'ÉCHEC.
!> T        INDICATEUR LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR SEUIL DU RATIO DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 4                 NOMBRE DE VALEURS DE K
!> 0 1 2 4           VALEURS DE K
!> 4                 NOMBRE DE VALEURS DE INCX ET INCY
!> 1 2 -1 -2         VALEURS DE INCX ET INCY
!> 3                 NOMBRE DE VALEURS DE ALPHA
!> (0.0,0.0) (1.0,0.0) (0.7,-0.9)       VALEURS DE ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> (0.0,0.0) (1.0,0.0) (1.3,-1.1)       VALEURS DE BETA
!> ZGEMV  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZGBMV  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZHEMV  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZHBMV  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZHPMV  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZTRMV  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZTBMV  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZTPMV  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZTRSV  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZTBSV  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZTPSV  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZGERC  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZGERU  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZHER   T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZHPR   T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZHER2  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
!> ZHPR2  T Indiquer F pour NE PAS TESTER. Mêmes colonnes.
