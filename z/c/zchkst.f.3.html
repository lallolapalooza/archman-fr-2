Documentation de la fonction/sous-routine

ZCHKST

Objectif :

!>
!> ZCHKST  vérifie les routines du problème de valeurs propres hermitien.
!>
!>    ZHETRD factorise A en  U S U* , où * signifie transconjugué,
!>    S est symétrique tridiagonale réelle, et U est unitaire.
!>    ZHETRD peut utiliser seulement le triangle inférieur ou seulement le triangle
!>    supérieur de A ; ZCHKST vérifie les deux cas.
!>    U est représenté comme un produit de transformations de Householder,
!>    dont les vecteurs sont stockés dans les n-1 premières colonnes de V,
!>    et dont les facteurs d'échelle sont dans TAU.
!>
!>    ZHPTRD fait la même chose que ZHETRD, sauf que A et V sont stockés
!>    en format  .
!>
!>    ZUNGTR construit la matrice U à partir du contenu de V et TAU.
!>
!>    ZUPGTR construit la matrice U à partir du contenu de VP et TAU.
!>
!>    ZSTEQR factorise S en  Z D1 Z* , où Z est la matrice unitaire
!>    des vecteurs propres et D1 est une matrice diagonale avec
!>    les valeurs propres sur la diagonale.  D2 est la matrice des
!>    valeurs propres calculées lorsque Z n'est pas calculé.
!>
!>    DSTERF calcule D3, la matrice des valeurs propres, par la
!>    méthode PWK, qui ne produit pas de vecteurs propres.
!>
!>    ZPTEQR factorise S en  Z4 D4 Z4* , pour une
!>    matrice tridiagonale hermitienne définie positive.
!>    D5 est la matrice des valeurs propres calculées lorsque Z n'est pas
!>    calculé.
!>
!>    DSTEBZ calcule des valeurs propres sélectionnées.  WA1, WA2 et
!>    WA3 désigneront les valeurs propres calculées avec une haute précision
!>    absolue, avec différentes options de plage.
!>    WR désignera les valeurs propres calculées avec une haute précision
!>    relative.
!>
!>    ZSTEIN calcule Y, les vecteurs propres de S, étant données les
!>    valeurs propres.
!>
!>    ZSTEDC factorise S en Z D1 Z* , où Z est la matrice unitaire
!>    des vecteurs propres et D1 est une matrice diagonale avec
!>    les valeurs propres sur la diagonale ('I' option). Elle peut également
!>    mettre à jour une matrice unitaire d'entrée, généralement la sortie
!>    de ZHETRD/ZUNGTR ou ZHPTRD/ZUPGTR ('V' option). Elle peut aussi
!>    simplement calculer des valeurs propres ('N' option).
!>
!>    ZSTEMR factorise S en Z D1 Z* , où Z est la matrice unitaire
!>    des vecteurs propres et D1 est une matrice diagonale avec
!>    les valeurs propres sur la diagonale ('I' option).  ZSTEMR
!>    utilise la Représentation Relativement Robuste lorsque cela est possible.
!>
!> Lorsque ZCHKST est appelé, un certain nombre de tailles de matrice ()
!> et un certain nombre de types de matrices sont spécifiés.  Pour chaque taille ()
!> et chaque type de matrice, une matrice sera générée et utilisée
!> pour tester les routines de valeurs propres hermitiennes. Pour chaque matrice, un certain nombre
!> de tests seront effectués :
!>
!> (1)     | A - V S V* | / ( |A| n ulp ) ZHETRD( UPLO='U', ... )
!>
!> (2)     | I - UV* | / ( n ulp )        ZUNGTR( UPLO='U', ... )
!>
!> (3)     | A - V S V* | / ( |A| n ulp ) ZHETRD( UPLO='L', ... )
!>
!> (4)     | I - UV* | / ( n ulp )        ZUNGTR( UPLO='L', ... )
!>
!> (5-8)   Identique à 1-4, mais pour ZHPTRD et ZUPGTR.
!>
!> (9)     | S - Z D Z* | / ( |S| n ulp ) ZSTEQR('V',...)
!>
!> (10)    | I - ZZ* | / ( n ulp )        ZSTEQR('V',...)
!>
!> (11)    | D1 - D2 | / ( |D1| ulp )        ZSTEQR('N',...)
!>
!> (12)    | D1 - D3 | / ( |D1| ulp )        DSTERF
!>
!> (13)    0 si les vraies valeurs propres (calculées par comptage de Sturm)
!>         de S sont dans THRESH de
!>         celles de D1.  2*THRESH si elles ne le sont pas.  (Testé en utilisant
!>         DSTECH)
!>
!> Pour S définie positive,
!>
!> (14)    | S - Z4 D4 Z4* | / ( |S| n ulp ) ZPTEQR('V',...)
!>
!> (15)    | I - Z4 Z4* | / ( n ulp )        ZPTEQR('V',...)
!>
!> (16)    | D4 - D5 | / ( 100 |D4| ulp )       ZPTEQR('N',...)
!>
!> Lorsque S est également à dominante diagonale par le facteur gamma < 1,
!>
!> (17)    max | D4(i) - WR(i) | / ( |D4(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              DSTEBZ( 'A', 'E', ...)
!>
!> (18)    | WA1 - D3 | / ( |D3| ulp )          DSTEBZ( 'A', 'E', ...)
!>
!> (19)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>                                              DSTEBZ( 'I', 'E', ...)
!>
!> (20)    | S - Y WA1 Y* | / ( |S| n ulp )  DSTEBZ, ZSTEIN
!>
!> (21)    | I - Y Y* | / ( n ulp )          DSTEBZ, ZSTEIN
!>
!> (22)    | S - Z D Z* | / ( |S| n ulp )    ZSTEDC('I')
!>
!> (23)    | I - ZZ* | / ( n ulp )           ZSTEDC('I')
!>
!> (24)    | S - Z D Z* | / ( |S| n ulp )    ZSTEDC('V')
!>
!> (25)    | I - ZZ* | / ( n ulp )           ZSTEDC('V')
!>
!> (26)    | D1 - D2 | / ( |D1| ulp )           ZSTEDC('V') et
!>                                              ZSTEDC('N')
!>
!> Le test 27 est désactivé pour le moment car ZSTEMR ne garantit pas
!> une haute précision relative.
!>
!> (27)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              ZSTEMR('V', 'A')
!>
!> (28)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              ZSTEMR('V', 'I')
!>
!> Les tests 29 à 34 sont désactivés pour le moment car ZSTEMR
!> ne gère pas les requêtes de spectre partiel.
!>
!> (29)    | S - Z D Z* | / ( |S| n ulp )    ZSTEMR('V', 'I')
!>
!> (30)

| I - ZZ* | / ( n ulp ) ZSTEMR('V', 'I') !> !> (31) ( max { min | WA2(i)-WA3(j) | } + !> i j !> max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp ) !> i j !> ZSTEMR('N', 'I') vs. CSTEMR('V', 'I') !> !> (32) | S - Z D Z* | / ( |S| n ulp ) ZSTEMR('V', 'V') !> !> (33) | I - ZZ* | / ( n ulp ) ZSTEMR('V', 'V') !> !> (34) ( max { min | WA2(i)-WA3(j) | } + !> i j !> max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp ) !> i j !> ZSTEMR('N', 'V') vs. CSTEMR('V', 'V') !> !> (35) | S - Z D Z* | / ( |S| n ulp ) ZSTEMR('V', 'A') !> !> (36) | I - ZZ* | / ( n ulp ) ZSTEMR('V', 'A') !> !> (37) ( max { min | WA2(i)-WA3(j) | } + !> i j !> max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp ) !> i j !> ZSTEMR('N', 'A') vs. CSTEMR('V', 'A') !> !> Les sont spécifiés par un tableau NN(1:NSIZES); la valeur de !> chaque élément NN(j) spécifie une taille. !> Les sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ); !> si DOTYPE(j) est .VRAI., alors la matrice de type sera générée. !> Actuellement, la liste des types possibles est : !> !> (1) La matrice nulle. !> (2) La matrice identité. !> !> (3) Une matrice diagonale avec des entrées régulièrement espacées !> 1, ..., ULP et des signes aléatoires. !> (ULP = (premier nombre supérieur à 1) - Paramètres

NSIZES 
!>          NSIZES est un entier
!>          Le nombre de tailles de matrices à utiliser. S'il est zéro,
!>          ZCHKST ne fait rien. Il doit être supérieur ou égal à zéro.
!>

NN

!>          NN est un tableau d'entiers, de dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs zéro seront ignorées. Les valeurs doivent être supérieures ou égales à
!>          zéro.
!>

NTYPES

!>          NTYPES est un entier
!>          Le nombre d'éléments dans DOTYPE. S'il est zéro, ZCHKST
!>          ne fait rien. Il doit être supérieur ou égal à zéro. S'il est égal à MAXTYP+1
!>          et NSIZES est 1, alors un type supplémentaire, MAXTYP+1 est
!>          défini, qui consiste à utiliser quelle que soit la matrice dans A. Ceci
!>          n'est utile que si DOTYPE(1:MAXTYP) est .FAUX. et
!>          DOTYPE(MAXTYP+1) est .VRAI. .
!>

DOTYPE

!>          DOTYPE est un tableau logique, de dimension (NTYPES)
!>          Si DOTYPE(j) est .VRAI., alors pour chaque taille dans NN, une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est plus petit que le nombre maximum de types
!>          définis (PARAMÈTRE MAXTYP), alors les types NTYPES+1 à
!>          MAXTYP ne seront pas générés. Si NTYPES est plus grand
!>          que MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!>

ISEED

!>          ISEED est un tableau d'entiers, de dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une séquence
!>          linéaire congruente limitée à de petits entiers, et devrait donc
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie, et peuvent être utilisées dans
!>          l'appel suivant à ZCHKST pour continuer la même séquence de nombres aléatoires.
!>

THRESH

!>          THRESH est de type DOUBLE PRECISION
!>          Un test sera considéré comme si l'erreur, calculée comme
!>          décrit ci-dessus, dépasse THRESH. Notez que l'erreur
!>          est mise à l'échelle pour être O(1), donc THRESH devrait être un multiple raisonnablement
!>          petit de 1, par exemple, 10 ou 100. En particulier,
!>          il ne doit pas dépendre de la précision (simple ou double)
!>          ou de la taille de la matrice. Il doit être supérieur ou égal à zéro.
!>

NOUNIT

!>          NOUNIT est un entier
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (par exemple, si une routine retourne IINFO différent de 0).
!>

A

!>          A est un tableau COMPLEX*16 de
!>                                  dimension ( LDA , max(NN) )
!>          Utilisé pour contenir la matrice dont les valeurs propres doivent être
!>          calculées. À la sortie, A contient la dernière matrice effectivement
!>          utilisée.
!>

LDA

!>          LDA est un entier
!>          La dimension principale de A. Elle doit être
!>          au moins 1 et au moins max( NN ).
!>

AP

!>          AP est un tableau COMPLEX*16 de
!>                      dimension( max(NN)*max(NN+1)/2 )
!>          La matrice A stockée au format compacté.
!>

SD

!>          SD est un tableau DOUBLE PRECISION de
!>                             dimension( max(NN) )
!>          La diagonale de la matrice tridiagonale calculée par ZHETRD.
!>          À la sortie, SD et SE contiennent la forme tridiagonale de
!>          la matrice dans A.
!>

SE

!>          SE est un tableau DOUBLE PRECISION de
!>                             dimension( max(NN) )
!>          La sous-diagonale de la matrice tridiagonale calculée par
!>          ZHETRD. À la sortie, SD et SE contiennent la forme tridiagonale de
!>          la matrice dans A.
!>

D1

!>          D1 est un tableau DOUBLE PRECISION de
!>                             dimension( max(NN) )
!>          Les valeurs propres de A, calculées par ZSTEQR simultanément
!>          avec Z. À la sortie, les valeurs propres dans D1 correspondent à la
!>          matrice dans A.
!>

D2

!>          D2 est un tableau DOUBLE PRECISION de
!>                             dimension( max(NN) )
!>          Les valeurs propres de A, calculées par ZSTEQR si Z n'est pas
!>          calculé. À la sortie, les valeurs propres dans D2 correspondent à la
!>          matrice dans A.
!>

D3

!>          D3 est un tableau DOUBLE PRECISION de
!>                             dimension( max(NN) )
!>          Les valeurs propres de A, calculées par DSTERF. À la sortie, les
!>          valeurs propres dans D3 correspondent à la matrice dans A.
!>

D4

!>          D4 est un tableau DOUBLE PRECISION de
!>                             dimension( max(NN) )
!>          Les valeurs propres de A, calculées par ZPTEQR(V).
!>          ZPTEQR factorise S en Z4 D4 Z4*
!>          À la sortie, les valeurs propres dans D4 correspondent à la matrice dans A.
!>

D5

!>          D5 est un tableau DOUBLE PRECISION de
!>                             dimension( max(NN) )
!>          Les valeurs propres de A, calculées par ZPTEQR(N)
!>          lorsque Z n'est pas calculé. À la sortie, les
!>          valeurs propres dans D4 correspondent à la matrice dans A.
!>

WA1

!>          WA1 est un tableau DOUBLE PRECISION de
!>                             dimension( max(NN) )
!>          Toutes les valeurs propres de A, calculées avec une grande
!>          précision absolue, avec différentes options de plage.
!>          calculé par DSTEBZ.
!>

WA2

!>          WA2 est un tableau DOUBLE PRECISION de
!>                             dimension( max(NN) )
!>          Valeurs propres sélectionnées de A, calculées avec une grande
!>          précision absolue, avec différentes options de plage.
!>          calculé par DSTEBZ.
!>          Choisir des valeurs aléatoires pour IL et IU, et demander les
!>          valeurs propres de l'indice IL à IU.
!>

WA3

!>          WA3 est un tableau DOUBLE PRECISION de
!>                             dimension( max(NN) )
!>          Valeurs propres sélectionnées de A, calculées avec une grande
!>          précision absolue, avec différentes options de plage.
!>          calculé par DSTEBZ.
!>          Déterminer les valeurs VL et VU des valeurs propres IL-ième et IU-ième
!>          et demander toutes les valeurs propres dans cette plage.
!>

WR

!>          WR est un tableau DOUBLE PRECISION de
!>                             dimension( max(NN) )
!>          Toutes les valeurs propres de A, calculées avec une grande
!>          précision absolue, avec différentes options.
!>          calculé par DSTEBZ.
!>

U

!>          U est un tableau COMPLEX*16 de
!>                             dimension( LDU, max(NN) ).
!>          La matrice unitaire calculée par ZHETRD + ZUNGTR.
!>

LDU

!>          LDU est un entier
!>          La dimension principale de U, Z et V. Elle doit être au moins 1
!>          et au moins max( NN ).
!>

V

!>          V est un tableau COMPLEX*16 de
!>                             dimension( LDU, max(NN) ).
!>          Les vecteurs de Householder calculés par ZHETRD lors de la réduction de A en
!>          forme tridiagonale. Les vecteurs calculés avec UPLO='U' sont
!>          dans le triangle supérieur, et les vecteurs calculés avec UPLO='L'
!>          sont dans le triangle inférieur. (Comme décrit dans ZHETRD, les
!>          sous- et super-diagonales ne sont pas définies à 1, bien que le
!>          véritable vecteur de Householder ait un 1 à cette position. Les
!>          routines qui utilisent V, comme ZUNGTR, définissent ces entrées à
!>          1 avant de les utiliser, puis les restaurent plus tard.)
!>

VP

!>          VP est un tableau COMPLEX*16 de
!>                      dimension( max(NN)*max(NN+1)/2 )
!>          La matrice V stockée au format compacté.
!>

TAU

!>          TAU est un tableau COMPLEX*16 de
!>                             dimension( max(NN) )
!>
;          Les facteurs de Householder calculés par ZHETRD pour réduire A
!>          en forme tridiagonale.
!>

Z

!>          Z est un tableau COMPLEX*16 de
!>                             dimension( LDU, max(NN) ).
!>          La matrice unitaire des vecteurs propres calculée par ZSTEQR,
!>          ZPTEQR et ZSTEIN.
!>

WORK

!>          WORK est un tableau COMPLEX*16 de
!>                      dimension( LWORK )
!>

LWORK

!>          LWORK est un entier.
!>          Le nombre d'entrées dans WORK. Il doit être au moins
!>          1 + 4 * Nmax + 2 * Nmax * lg Nmax + 3 * Nmax**2
!>          où Nmax = max( NN(j), 2 ) et lg = log base 2.
!>

IWORK

!>          IWORK est un tableau d'entiers.
!>          Espace de travail.
!>

LIWORK

!>          LIWORK est un entier.
!>          Le nombre d'entrées dans IWORK. Il doit être au moins
!>                  6 + 6*Nmax + 5 * Nmax * lg Nmax
!>          où Nmax = max( NN(j), 2 ) et lg = log base 2.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION.
!>

LRWORK

!>          LRWORK est un entier.
!>          Le nombre d'entrées dans LRWORK (dimension( ??? )
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, dimension (26).
!>          Les valeurs calculées par les tests décrits ci-dessus.
!>          Les valeurs sont actuellement limitées à 1/ulp, pour éviter
!>          les dépassements de capacité.
!>

INFO

!>          INFO est un entier.
!>          Si 0, alors tout s'est bien passé.
!>           -1: NSIZES < 0
!>           -2: Certains NN(j) < 0
!>           -3: NTYPES < 0
!>           -5: THRESH < 0
!>           -9: LDA < 1 ou LDA < NMAX, où NMAX est max( NN(j) ).
!>          -23: LDU < 1 ou LDU < NMAX.
!>          -29: LWORK trop petit.
!>          Si ZLATMR, CLATMS, ZHETRD, ZUNGTR, ZSTEQR, DSTERF,
!>              ou ZUNMC2 renvoie un code d'erreur, la
!>              valeur absolue de celui-ci est retournée.
!>
