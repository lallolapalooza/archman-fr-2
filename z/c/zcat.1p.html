ZCAT(1P) Manuel du programmeur POSIX ZCAT(1P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

zcat — décompresser et concaténer des données

SYNTAXE

zcat [fichier...]

DESCRIPTION

L'utilitaire zcat doit écrire en sortie standard la forme décompressée des fichiers qui ont été compressés à l'aide de l'utilitaire compress. Il est l'équivalent de uncompress -c. Les fichiers d'entrée ne sont pas affectés.

OPTIONS

Aucune.

OPÉRANDES

L'opérande suivant doit être pris en charge :

fichier
Le chemin d'accès d'un fichier précédemment traité par l'utilitaire compress. Si fichier a déjà le suffixe .Z spécifié, il est utilisé tel quel. Sinon, le suffixe .Z est ajouté au nom de fichier avant le traitement.

ENTRÉE STANDARD

L'entrée standard doit être utilisée uniquement si aucun opérande fichier n'est spécifié, ou si un opérande fichier est '-'.

FICHIERS D'ENTRÉE

Les fichiers d'entrée doivent être des fichiers compressés au format produit par l'utilitaire compress.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes doivent affecter l'exécution de zcat :

LANG
Fournir une valeur par défaut pour les variables d'internationalisation qui sont non définies ou vides. (Voir le volume Définitions de base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation pour la précédence des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de locale.)
LC_ALL
Si elle est définie à une chaîne non vide, remplace les valeurs de toutes les autres variables d'internationalisation.
LC_CTYPE
Détermine la locale pour l'interprétation des séquences d'octets de données textuelles en tant que caractères (par exemple, caractères mono-octet par opposition à multi-octets dans les arguments).
LC_MESSAGES

Détermine la locale qui doit être utilisée pour affecter le format et le contenu des messages diagnostiques écrits sur la sortie d'erreur standard.
NLSPATH
Détermine l'emplacement des catalogues de messages pour le traitement de LC_MESSAGES.

ÉVÉNEMENTS ASYNCHRONES

Par défaut.

SORTIE STANDARD

Les fichiers compressés fournis en entrée doivent être écrits sur la sortie standard sous leur forme décompressée.

SORTIE D'ERREUR STANDARD

La sortie d'erreur standard doit être utilisée uniquement pour les messages diagnostiques.

FICHIERS DE SORTIE

Aucun.

DESCRIPTION ÉTENDUE

Aucune.

STATUT DE SORTIE

Les valeurs de sortie suivantes doivent être retournées :

 0
Achèvement réussi.
>0
Une erreur s'est produite.

CONSÉQUENCES DES ERREURS

Par défaut.
