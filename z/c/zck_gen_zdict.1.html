NOM

zck_gen_zdict — extraire un dictionnaire et éventuellement les morceaux séparés d'un fichier zdict

SYNTAXE

zck_gen_zdict [-d répertoire | --dir=répertoire] [-v | --verbose] fichier

zck_gen_zdict -? | --help | --usage | --version

DESCRIPTION

L'utilitaire zck_gen_zdict lit le fichier zchunk spécifié, extrait le dictionnaire utilisé lors de la compression, et éventuellement décompresse les morceaux individuels dans le répertoire spécifié.

L'utilitaire zck_gen_zdict accepte les arguments optionnels suivants :

-d, --dir
En plus d'extraire le dictionnaire, décompresse les morceaux individuels sous forme de fichiers séquentiels dans le répertoire spécifié.
-v, --verbose
Fonctionnement détaillé ; affiche des informations de diagnostic.
-?, --help
Affiche les informations d'utilisation du programme et quitte.
--usage
Affiche de brèves informations d'utilisation du programme et quitte.
--version
Affiche les informations de version du programme et quitte.

CODE DE RETOUR

L'utilitaire zck_gen_zdict quitte avec le code 0 en cas de succès, et avec un code >0 en cas d'erreur.

EXEMPLES

Extraire le dictionnaire d'un fichier zchunk dans le fichier words.txt.zdict :

zck_gen_zdict words.txt.zck

Extraire le dictionnaire dans words.txt.zdict et également les morceaux dans le répertoire chunks/ :

zck_gen_zdict -d chunks/ words.txt.zck
