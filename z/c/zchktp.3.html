Documentation de la fonction/sous-routine

sous-routine zchktp (logique, dimension( * ) dotype, entier nn, entier, dimension( * ) nval, entier nns, entier, dimension( * ) nsval, double precision thresh, logique tsterr, entier nmax, complexe*16, dimension( * ) ap, complexe*16, dimension( * ) ainvp, complexe*16, dimension( * ) b, complexe*16, dimension( * ) x, complexe*16, dimension( * ) xact, complexe*16, dimension( * ) work, double precision, dimension( * ) rwork, entier nout)

ZCHKTP

Objectif :

!>
!> ZCHKTP teste ZTPTRI, -TRS, -RFS, et -CON, ainsi que ZLATPS
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, dimension (NN)
!>          Les valeurs de la dimension de colonne de matrice N.
!>

NNS

!>          NNS est un ENTIER
!>          Le nombre de valeurs de NRHS contenues dans le vecteur NSVAL.
!>

NSVAL

!>          NSVAL est un tableau d'ENTIERS, dimension (NNS)
!>          Les valeurs du nombre de membres de droite NRHS.
!>

THRESH

!>          THRESH est un DOUBLE PRECISION
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est un LOGIQUE
!>          Indicateur qui spécifie si les sorties d'erreur doivent être testées.
!>

NMAX

!>          NMAX est un ENTIER
!>          La dimension principale des tableaux de travail. NMAX >= la
!>          valeur maximale de N dans NVAL.
!>

AP

!>          AP est un tableau COMPLEX*16, dimension (NMAX*(NMAX+1)/2)
!>

AINVP

!>          AINVP est un tableau COMPLEX*16, dimension (NMAX*(NMAX+1)/2)
!>

B

!>          B est un tableau COMPLEX*16, dimension (NMAX*NSMAX)
!>          où NSMAX est la plus grande entrée dans NSVAL.
!>

X

!>          X est un tableau COMPLEX*16, dimension (NMAX*NSMAX)
!>

XACT

!>          XACT est un tableau COMPLEX*16, dimension (NMAX*NSMAX)
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension
!>                      (NMAX*max(3,NSMAX))
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension
!>                      (max(NMAX,2*NSMAX))
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro d'unité pour la sortie.
!>
