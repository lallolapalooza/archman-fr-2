ZCHKBB

Objectif :

!>
!> ZCHKBB teste la réduction d'une matrice bande rectangulaire complexe générale
!> en une forme bidiagonale réelle.
!>
!> ZGBBRD factorise une matrice bande générale A en Q B P* , où * signifie
!> conjugué transposé, B est upper bidiagonale, et Q et P sont unitaires ;
!> ZGBBRD peut aussi écraser une matrice C donnée avec Q* C .
!>
!> Pour chaque paire de dimensions de matrices (M,N) et chaque type de matrice
!> sélectionné, une matrice A de taille M x N et une matrice C de taille M x NRHS
!> sont générées.
!> Les dimensions du problème sont les suivantes :
!>    A :          M x N
!>    Q :          M x M
!>    P :          N x N
!>    B :          min(M,N) x min(M,N)
!>    C :          M x NRHS
!>
!> Pour chaque matrice générée, 4 tests sont effectués :
!>
!> (1)   | A - Q B PT | / ( |A| max(M,N) ulp ), PT = P'
!>
!> (2)   | I - Q' Q | / ( M ulp )
!>
!> (3)   | I - PT PT' | / ( N ulp )
!>
!> (4)   | Y - Q' C | / ( |Y| max(M,NRHS) ulp ), où Y = Q' C.
!>
!> Les types sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ;
!> si DOTYPE(j) est .VRAI., alors le type de matrice j sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> Les types de matrices possibles sont :
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!>
!> (3)  Une matrice diagonale avec des entrées régulièrement espacées
!>      1, ..., ULP  et des signes aléatoires.
!>      (ULP = (premier nombre supérieur à 1) - 1 )
!> (4)  Une matrice diagonale avec des entrées géométriquement espacées
!>      1, ..., ULP  et des signes aléatoires.
!> (5)  Une matrice diagonale avec des entrées 1, ULP, ..., ULP
!>      et des signes aléatoires.
!>
!> (6)  Identique à (3), mais multipliée par SQRT( seuil de débordement )
!> (7)  Identique à (3), mais multipliée par SQRT( seuil de sous-dépassement )
!>
!> (8)  Une matrice de la forme  U D V, où U et V sont orthogonales et
!>      D a des entrées régulièrement espacées 1, ..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (9)  Une matrice de la forme  U D V, où U et V sont orthogonales et
!>      D a des entrées géométriquement espacées 1, ..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (10) Une matrice de la forme  U D V, où U et V sont orthogonales et
!>      D a des entrées 1, ULP,..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (11) Identique à (8), mais multipliée par SQRT( seuil de débordement )
!> (12) Identique à (8), mais multipliée par SQRT( seuil de sous-dépassement )
!>
!> (13) Matrice rectangulaire avec des entrées aléatoires choisies dans (-1,1).
!> (14) Identique à (13), mais multipliée par SQRT( seuil de débordement )
!> (15) Identique à (13), mais multipliée par SQRT( seuil de sous-dépassement )
!>

Paramètres

NSIZES 
!>          NSIZES est de type INTEGER
!>          Le nombre de valeurs de M et N contenues dans les vecteurs
!>          MVAL et NVAL.  Les tailles de matrices sont utilisées par paires (M,N).
!>          Si NSIZES est zéro, ZCHKBB ne fait rien.  NSIZES doit être
!>          au moins zéro.
!>

MVAL

!>          MVAL est un tableau INTEGER, dimension (NSIZES)
!>          Les valeurs de la dimension des lignes de la matrice M.
!>

NVAL

!>          NVAL est un tableau INTEGER, dimension (NSIZES)
!>          Les valeurs de la dimension des colonnes de la matrice N.
!>

NWDTHS

!>          NWDTHS est un INTEGER
!>          Le nombre de largeurs de bande à utiliser.  Si ce nombre est zéro,
!>          ZCHKBB ne fait rien.  Il doit être au moins zéro.
!>

KK

!>          KK est un tableau INTEGER, dimension (NWDTHS)
!>          Un tableau contenant les largeurs de bande à utiliser pour les matrices
!>          bandes.  Les valeurs doivent être au moins zéro.
!>

NTYPES

!>          NTYPES est un INTEGER
!>          Le nombre d'éléments dans DOTYPE.  Si ce nombre est zéro, ZCHKBB
!>          ne fait rien.  Il doit être au moins zéro.  S'il est égal à MAXTYP+1
!>          et que NSIZES est 1, alors un type supplémentaire, MAXTYP+1, est
!>          défini, qui consiste à utiliser la matrice présente dans A.  Ceci
!>          n'est utile que si DOTYPE(1:MAXTYP) est .FAUX. et
!>          DOTYPE(MAXTYP+1) est .VRAI. .
!>

DOTYPE

!>          DOTYPE est un tableau LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) est .VRAI., alors pour chaque taille dans NN, une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximum de types
!>          définis (PARAMETER MAXTYP), alors les types NTYPES+1 à
!>          MAXTYP ne seront pas générés.  Si NTYPES est supérieur
!>          à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES) seront ignorés.
!>

NRHS

!>          NRHS est un INTEGER
!>          Le nombre de colonnes dans la matrice C.
!>          Si NRHS = 0, alors les opérations sur le membre de droite ne
!>          seront pas testées. NRHS doit être au moins 0.
!>

ISEED

!>          ISEED est un tableau INTEGER, dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une séquence
!>          linéaire congruente limitée à de petits entiers, et devrait donc
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie et peuvent être utilisées
!>          dans l'appel suivant à ZCHKBB pour continuer la même séquence de nombres
!>          aléatoires.
!>

THRESH

!>          THRESH est un DOUBLE PRECISION
!>          Un test sera considéré comme réussi si le résidu, calculé comme
!>          décrit ci-dessus, ne dépasse pas THRESH.  Notez que l'erreur
!>          est mise à l'échelle pour être de l'ordre de 1, donc THRESH devrait être
!>          un multiple raisonnablement petit de 1, par exemple 10 ou 100. En
!>          particulier, il ne doit pas dépendre de la précision (simple ou double)
!>          ou de la taille de la matrice. Il doit être au moins zéro.
!>

NOUNIT

!>          NOUNIT est un INTEGER
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (par exemple, si une routine retourne un IINFO différent de 0).
!>

subroutine ZCHKBB(NN, JTYPE, KMODE, KPARAMS, KVERIF, ULP, THRESH, A, LDA, AB, LDAB, BD, BE, Q, LDQ, P, LDP, C, LDC, CC, WORK, LWORK, RWORK, RESULT, INFO)

This subroutine tests the subroutines ZGBBRD.

Arguments

NN

!>          NN is INTEGER array, dimension (2)
!>          The sizes of the matrices to be tested.
!>          NN(1) = M, the number of rows of A.
!>          NN(2) = N, the number of columns of A.
!>

JTYPE

!>          JTYPE is INTEGER
!>          The type of matrix to be generated. JTYPE = 1, 2, 3, ...
!>

KMODE

!>          KMODE is INTEGER
!>          The mode of generation for the matrix.
!>

KPARAMS

!>          KPARAMS is INTEGER array, dimension (4)
!>          Other parameters for the matrix generator.
!>

KVERIF

!>          KVERIF is INTEGER
!>          If KVERIF = 0, then no verification is performed.
!>

ULP

!>          ULP is DOUBLE PRECISION
!>          The value of the unit in the last place of the machine
!>          (relative error).
!>

THRESH

!>          THRESH is DOUBLE PRECISION
!>          The threshold to use for calling the matrix generators.
!>

A

!>          A is DOUBLE PRECISION array, dimension
!>                            (LDA, max(NN))
!>          Used to hold the matrix A.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of A.  It must be at least 1
!>          and at least max( NN ).
!>

AB

!>          AB is DOUBLE PRECISION array, dimension (LDAB, max(NN))
!>          Used to hold A in band storage format.
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of AB.  It must be at least 2 (not 1!)
!>          and at least max( KK )+1.
!>

BD

!>          BD is DOUBLE PRECISION array, dimension (max(NN))
!>          Used to hold the diagonal of the bidiagonal matrix computed
!>          by ZGBBRD.
!>

BE

!>          BE is DOUBLE PRECISION array, dimension (max(NN))
!>          Used to hold the off-diagonal of the bidiagonal matrix
!>          computed by ZGBBRD.
!>

Q

!>          Q is COMPLEX*16 array, dimension (LDQ, max(NN))
!>          Used to hold the unitary matrix Q computed by ZGBBRD.
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of Q.  It must be at least 1
!>          and at least max( NN ).
!>

P

!>          P is COMPLEX*16 array, dimension (LDP, max(NN))
!>          Used to hold the unitary matrix P computed by ZGBBRD.
!>

LDP

!>          LDP is INTEGER
!>          The leading dimension of P.  It must be at least 1
!>          and at least max( NN ).
!>

C

!>          C is COMPLEX*16 array, dimension (LDC, max(NN))
!>          Used to hold the matrix C updated by ZGBBRD.
!>

LDC

!>          LDC is INTEGER
!>          The leading dimension of U.  It must be at least 1
!>          and at least max( NN ).
!>

CC

!>          CC is COMPLEX*16 array, dimension (LDC, max(NN))
!>          Used to hold a copy of the matrix C.
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>          The number of entries in WORK.  This must be at least
!>          max( LDA+1, max(NN)+1 )*max(NN).
!>

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (max(NN))
!>

RESULT

!>          RESULT is DOUBLE PRECISION array, dimension (4)
!>          The values computed by the tests described above.
!>          The values are currently limited to 1/ulp, to avoid
!>          overflow.
!>

INFO

!>          INFO is INTEGER
!>          If 0, then everything ran OK.
!>
!>-----------------------------------------------------------------------
!>
!>       Some Local Variables and Parameters:
!>       ---- ----- --------- --- ----------
!>       ZERO, ONE       Real 0 and 1.
!>       MAXTYP          The number of types defined.
!>       NTEST           The number of tests performed, or which can
!>                       be performed so far, for the current matrix.
!>       NTESTT          The total number of tests performed so far.
!>       NMAX            Largest value in NN.
!>       NMATS           The number of matrices generated so far.
!>       NERRS           The number of tests which have exceeded THRESH
!>                       so far.
!>       COND, IMODE     Values to be passed to the matrix generators.
!>       ANORM           Norm of A; passed to matrix generators.
!>
!>       OVFL, UNFL      Overflow and underflow thresholds.
!>       ULP, ULPINV     Finest relative precision and its inverse.
!>       RTOVFL, RTUNFL  Square roots of the previous 2 values.
!>               The following four arrays decode JTYPE:
!>       KTYPE(j)        The general type (1-10) for type .
!>       KMODE(j)        The MODE value to be passed to the matrix
!>                       generator for type .
!>       KMAGN(j)        The order of magnitude ( O(1),
!>                       O(overflow^(1/2) ), O(underflow^(1/2) )
!>
