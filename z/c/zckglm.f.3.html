sous-programme zckglm (integer nn, integer, dimension( * ) nval, integer, dimension( * ) mval, integer, dimension( * ) pval, integer nmats, integer, dimension( 4 ) iseed, double precision thresh, integer nmax, complex*16, dimension( * ) a, complex*16, dimension( * ) af, complex*16, dimension( * ) b, complex*16, dimension( * ) bf, complex*16, dimension( * ) x, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer nin, integer nout, integer info)

ZCKGLM

But :

!>
!> ZCKGLM teste ZGGGLM - sous-programme pour résoudre le problème
!>                       du modèle linéaire généralisé.
!>

Paramètres

NN 
!>          NN est un ENTIER
!>          Le nombre de valeurs de N, M et P contenues dans les vecteurs
!>          NVAL, MVAL et PVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, dimension (NN)
!>          Les valeurs de la dimension de ligne de la matrice N.
!>

MVAL

!>          MVAL est un tableau d'ENTIERS, dimension (NN)
!>          Les valeurs de la dimension de colonne de la matrice M.
!>

PVAL

!>          PVAL est un tableau d'ENTIERS, dimension (NN)
!>          Les valeurs de la dimension de colonne de la matrice P.
!>

NMATS

!>          NMATS est un ENTIER
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions de matrices.  Si NMATS >= NTYPES (le nombre maximum
!>          de types de matrices), alors tous les différents types sont
!>          générés pour les tests.  Si NMATS < NTYPES, une ligne d'entrée supplémentaire
!>          est lue pour obtenir les numéros des types de matrices à utiliser.
!>

ISEED

!>          ISEED est un tableau d'ENTIERS, dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires.  Les éléments
!>          du tableau doivent être compris entre 0 et 4095, sinon ils seront
!>          réduits modulo 4096, et ISEED(4) doit être impair.
!>          À la sortie, la prochaine graine dans la séquence de nombres aléatoires après
!>          la génération de toutes les matrices de test.
!>

THRESH

!>          THRESH est un DOUBLE PRÉCISION
!>          La valeur seuil pour les rapports de test.  Un résultat est
!>          inclus dans le fichier de sortie si RESID >= THRESH.  Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.
!>

NMAX

!>          NMAX est un ENTIER
!>          La valeur maximale autorisée pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

B

!>          B est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

BF

!>          BF est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

X

!>          X est un tableau COMPLEX*16, dimension (4*NMAX)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (NMAX)
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

NIN

!>          NIN est un ENTIER
!>          Le numéro d'unité pour l'entrée.
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro d'unité pour la sortie.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 :  sortie réussie
!>          > 0 :  Si ZLATMS renvoie un code d'erreur, la valeur absolue
!>                 de celui-ci est retournée.
!>
