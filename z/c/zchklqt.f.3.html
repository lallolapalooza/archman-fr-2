Documentation de la fonction/sous-programme

sous-programme zchklqt (double precision thresh, logical tsterr, integer nm, integer, dimension( * ) mval, integer nn, integer, dimension( * ) nval, integer nnb, integer, dimension( * ) nbval, integer nout)

ZCHKLQT

But :

!>
!> ZCHKLQT teste ZGELQT et ZUNMLQT.
!>

Paramètres

THRESH 
!>          THRESH est de type DOUBLE PRECISION
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour
!>          imprimer tous les rapports de test, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est de type LOGICAL
!>          Indicateur signalant si les sorties d'erreur doivent être testées.
!>

NM

!>          NM est un INTEGER
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau d'INTEGER, dimension (NM)
!>          Les valeurs de la dimension de ligne de la matrice M.
!>

NN

!>          NN est un INTEGER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'INTEGER, dimension (NN)
!>          Les valeurs de la dimension de colonne de la matrice N.
!>

NNB

!>          NNB est un INTEGER
!>          Le nombre de valeurs de NB contenues dans le vecteur NBVAL.
!>

NBVAL

!>          NBVAL est un tableau d'INTEGER, dimension (NNB)
!>          Les valeurs de la taille de bloc NB.
!>

NOUT

!>          NOUT est un INTEGER
!>          Le numéro de l'unité de sortie.
!>
