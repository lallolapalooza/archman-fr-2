sous-routine zchkgg (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, logical tstdif, double precision thrshn, integer nounit, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( lda, * ) b, complex*16, dimension( lda, * ) h, complex*16, dimension( lda, * ) t, complex*16, dimension( lda, * ) s1, complex*16, dimension( lda, * ) s2, complex*16, dimension( lda, * ) p1, complex*16, dimension( lda, * ) p2, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( ldu, * ) v, complex*16, dimension( ldu, * ) q, complex*16, dimension( ldu, * ) z, complex*16, dimension( * ) alpha1, complex*16, dimension( * ) beta1, complex*16, dimension( * ) alpha3, complex*16, dimension( * ) beta3, complex*16, dimension( ldu, * ) evectl, complex*16, dimension( ldu, * ) evectr, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, logical, dimension( * ) llwork, double precision, dimension( 15 ) result, integer info)

ZCHKGG

Objectif :

!>
!> ZCHKGG  vérifie les routines du problème aux valeurs propres généralisées non symétriques.
!>                                H          H        H
!> ZGGHRD factorise A et B comme U H V  et U T V , où   représente la transposée conjuguée,
!> H est de Hessenberg, T est triangulaire et U et V sont unitaires.
!>
!>                                 H          H
!> ZHGEQZ factorise H et T comme  Q S Z  et Q P Z , où P et S sont triangulaires supérieures
!> et Q et Z sont unitaires. Il calcule également les valeurs propres généralisées
!> (alpha(1),beta(1)),...,(alpha(n),beta(n)), où
!> alpha(j)=S(j,j) et beta(j)=P(j,j) -- ainsi, w(j) = alpha(j)/beta(j)
!> est une racine du problème aux valeurs propres généralisées
!>
!>     det( A - w(j) B ) = 0
!>
!> et m(j) = beta(j)/alpha(j) est une racine du problème essentiellement équivalent
!>
!>     det( m(j) A - B ) = 0
!>
!> ZTGEVC calcule la matrice L des vecteurs propres gauches et la matrice R des vecteurs
!> propres droits pour la paire de matrices ( S, P ). Dans la description ci-dessous,
!> l et r sont les vecteurs propres gauches et droits correspondant aux valeurs propres
!> généralisées (alpha,beta).
!>
!> Lorsque ZCHKGG est appelée, un nombre de tailles de matrices () et un
!> nombre de types de matrices sont spécifiés. Pour chaque taille ()
!> et chaque type de matrice, une matrice sera générée et utilisée
!> pour tester les routines de valeurs propres non symétriques. Pour chaque matrice, 13
!> tests seront effectués. Les douze premiers tests  devraient être
!> petits -- O(1). Ils seront comparés au seuil THRESH :
!>
!>                  H
!> (1)   | A - U H V  | / ( |A| n ulp )
!>
!>                  H
!> (2)   | B - U T V  | / ( |B| n ulp )
!>
!>               H
!> (3)   | I - UU  | / ( n ulp )
!>
!>               H
!> (4)   | I - VV  | / ( n ulp )
!>
!>                  H
!> (5)   | H - Q S Z  | / ( |H| n ulp )
!>
!>                  H
!> (6)   | T - Q P Z  | / ( |T| n ulp )
!>
!>               H
!> (7)   | I - QQ  | / ( n ulp )
!>
!>               H
!> (8)   | I - ZZ  | / ( n ulp )
!>
!> (9)   maximum sur toutes les paires valeur propre/vecteur propre gauche (beta/alpha,l) de
!>                           H
!>       | (beta A - alpha B) l | / ( ulp max( |beta A|, |alpha B| ) )
!>
!> (10)  maximum sur toutes les paires valeur propre/vecteur propre gauche (beta/alpha,l') de
!>                           H
!>       | (beta H - alpha T) l' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       où les vecteurs propres l sont le résultat du passage de Q à
!>       DTGEVC et de la rétro-transformation (JOB='B').
!>
!> (11)  maximum sur toutes les paires valeur propre/vecteur propre droit (beta/alpha,r) de
!>
!>       | (beta A - alpha B) r | / ( ulp max( |beta A|, |alpha B| ) )
!>
!> (12)  maximum sur toutes les paires valeur propre/vecteur propre droit (beta/alpha,r') de
!>
!>       | (beta H - alpha T) r' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       où les vecteurs propres droits r' sont le résultat du passage de Z à
!>       DTGEVC et de la rétro-transformation (JOB='B').
!>
!> Les trois derniers rapports de test seront généralement faibles, mais il n'y a aucune
!> exigence mathématique à ce qu'ils le soient. Ils sont donc
!> comparés au seuil THRESH uniquement si TSTDIF est .TRUE.
!>
!> (13)  | S(Q,Z calculé) - S(Q,Z non calculé) | / ( |S| ulp )
!>
!> (14)  | P(Q,Z calculé) - P(Q,Z non calculé) | / ( |P| ulp )
!>
!> (15)  max( |alpha(Q,Z calculé) - alpha(Q,Z non calculé)|/|S| ,
!>            |beta(Q,Z calculé) - beta(Q,Z non calculé)|/|P| ) / ulp
!>
!> En outre, la normalisation de L et R est vérifiée et comparée
!> au seuil THRSHN.
!>
!> Matrices de test
!> ---- --------
!>
!> Les tailles des matrices de test sont spécifiées par un tableau
!> NN(1:NSIZES) ; la valeur de chaque élément NN(j) spécifie une taille.
!> Les types sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ; si
!> DOTYPE(j) est .TRUE., alors le type de matrice j sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  ( 0, 0 )         (une paire de matrices nulles)
!>
!> (2)  ( I, 0 )         (une matrice identité et une matrice nulle)
!>
!> (3)  ( 0, I )         (une matrice nulle et une matrice identité)
!>
!> (4)  ( I, I )         (une paire de matrices identité)
!>
!>         t   t
!> (5)  ( J , J  )       (une paire de blocs de Jordan transposés)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         où  X = ( J   0  )  et Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       et I est une identité k x k et J un bloc de Jordan (k+1)x(k+1)
!>                       ; k=(N-1)/2
!>
!> (7)  ( D, I )         où D est P*D1, P est une matrice diagonale unitaire aléatoire
!>                       (c'est-à-dire avec des entrées de magnitude 1 aléatoires
!>                       sur la diagonale), et D1=diag( 0, 1,..., N-1 )
!>                       (c'est-à-dire une matrice diagonale avec D1(1,1)=0,
!>                       D1(2,2)=1, ..., D1(N,N)=N-1.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) où  est proche du dépassement de capacité et small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        où D1=P*diag( 0, 0, 1, ..., N-3, 0 ) et
!>                        D2=Q*diag( 0, N-3, N-4,..., 1, 0, 0 ), et
!>                        P et Q sont des matrices diagonales unitaires aléatoires.

!>
!> (17) U ( T1, T2 ) V    où T1 et T2 sont des matrices triangulaires supérieures

!>
!>                                                        N-5
!> (20) U ( T1, T2 ) V    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) U ( T1, T2 ) V    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        où r1,..., r(N-4) sont aléatoires.
!>
!> (22) U ( big*T1, small*T2 ) V   diag(T1) = P*( 0, 0, 1, ..., N-3, 0 )
!>                                 diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) U ( small*T1, big*T2 ) V   diag(T1) = P*( 0, 0, 1, ..., N-3, 0 )
!>                                 diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) U ( small*T1, small*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 )
!>                                 diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) U ( big*T1, big*T2 ) V     diag(T1) = P*( 0, 0, 1, ..., N-3, 0 )
!>                                 diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) U ( T1, T2 ) V     où T1 et T2 sont des matrices triangulaires supérieures aléatoires.
!>

Paramètres

NSIZES 
!>          NSIZES est INTEGER
!>          Le nombre de tailles de matrices à utiliser. Si c'est zéro,
!>          ZCHKGG ne fait rien. Il doit être au moins zéro.
!>

NN

!>          NN est un tableau INTEGER, de dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs zéro seront ignorées. Les valeurs doivent être au moins
!>          zéro.
!>

NTYPES

!>          NTYPES est INTEGER
!>          Le nombre d'éléments dans DOTYPE. Si c'est zéro, ZCHKGG
!>          ne fait rien. Il doit être au moins zéro. S'il est égal à MAXTYP+1
!>          et NSIZES est 1, alors un type supplémentaire, MAXTYP+1, est
!>          défini, qui consiste à utiliser la matrice présente dans A. Ceci
!>          est utile seulement si DOTYPE(1:MAXTYP) est .FALSE. et
!>          DOTYPE(MAXTYP+1) est .TRUE. .
!>

DOTYPE

!>          DOTYPE est un tableau LOGICAL, de dimension (NTYPES)
!>          Si DOTYPE(j) est .TRUE., alors pour chaque taille dans NN une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est plus petit que le nombre maximum de types
!>          définis (PARAMETER MAXTYP), alors les types NTYPES+1 à
!>          MAXTYP ne seront pas générés. Si NTYPES est plus grand
!>          que MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!>

ISEED

!>          ISEED est un tableau INTEGER, de dimension (4)
!>          En entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une séquence
!>          congruentielle linéaire limitée à de petits entiers, et doit donc
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées en sortie, et peuvent être utilisées
!>          dans l'appel suivant à ZCHKGG pour continuer la même séquence de nombres
!>          aléatoires.
!>

THRESH

!>          THRESH est DOUBLE PRECISION
!>          Un test sera comptabilisé comme réussi si le rapport d'erreur,
!>          calculé comme décrit ci-dessus, dépasse THRESH. Notez que l'erreur
!>          est mise à l'échelle pour être O(1), donc THRESH devrait être un
!>          multiple raisonnablement petit de 1, par exemple 10 ou 100. En particulier,
!>          il ne doit pas dépendre de la précision (simple ou double)
!>          ou de la taille de la matrice. Il doit être au moins zéro.
!>

TSTDIF

!>          TSTDIF est LOGICAL
!>          Spécifie si les rapports de test 13-15 seront calculés et
!>          comparés avec THRESH.
!>          = .FALSE.: Seuls les rapports de test 1-12 seront calculés et testés.
!>                     Les rapports 13-15 seront mis à zéro.
!>          = .TRUE.:  Tous les rapports de test 1-15 seront calculés et
!>                     testés.
!>

THRSHN

!>          THRSHN est DOUBLE PRECISION
!>          Seuil pour signaler une erreur de normalisation de vecteur propre.
!>          Si la normalisation d'un vecteur propre diffère de 1 de plus de
!>          THRSHN*ulp, alors un message d'erreur spécial sera
!>          imprimé. (Ceci est géré séparément des autres tests,
!>          car seule une erreur de compilateur ou de programmation devrait provoquer un
!>          message d'erreur, du moins si THRSHN est au moins 5--10.)
!>

NOUNIT

!>          NOUNIT est INTEGER
!>          Le numéro d'unité FORTRAN pour imprimer les messages d'erreur
!>          (par exemple, si une routine retourne IINFO différent de 0).
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA, max(NN))
!>          Utilisé pour contenir la matrice A originale. Utilisé en entrée seulement
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., et
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A, B, H, T, S1, P1, S2, et P2.
!>          Elle doit être au moins 1 et au moins max( NN ).
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDA, max(NN))
!>          Utilisé pour contenir la matrice B originale. Utilisé en entrée seulement
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., et
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

H

!>          H est un tableau COMPLEX*16, de dimension (LDA, max(NN))
!>          La matrice de Hessenberg supérieure calculée à partir de A par ZGGHRD.
!>

T

!>          T est un tableau COMPLEX*16, de dimension (LDA, max(NN))
!>          La matrice triangulaire supérieure calculée à partir de B par ZGGHRD.
!>

S1

!>          S1 est un tableau COMPLEX*16, de dimension (LDA, max(NN))
!>          La matrice triangulaire supérieure de Schur calculée à partir de H par ZHGEQZ
!>          lorsque Q et Z sont également calculés.
!>

S2

!>          S2 est un tableau COMPLEX*16, de dimension (LDA, max(NN))
!>          La matrice triangulaire supérieure de Schur calculée à partir de H par ZHGEQZ
!>          lorsque Q et Z ne sont pas calculés.
!>

P1

!>          P1 est un tableau COMPLEX*16, de dimension (LDA, max(NN))
!>          La matrice triangulaire supérieure calculée à partir de T par ZHGEQZ
!>          lorsque Q et Z sont également calculés.
!>

P2

!>          P2 est un tableau COMPLEX*16, de dimension (LDA, max(NN))
!>          La matrice triangulaire supérieure calculée à partir de T par ZHGEQZ
!>          lorsque Q et Z ne sont pas calculés.
!>

U

!>          U est un tableau COMPLEX*16, de dimension (LDU, max(NN))
!>          La matrice unitaire (gauche) calculée par ZGGHRD.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale de U, V, Q, Z, EVECTL, et EVEZTR. Elle
!>          doit être au moins 1 et au moins max( NN ).
!>

V

!>          V est un tableau COMPLEX*16, de dimension (LDU, max(NN))
!>          La matrice unitaire (droite) calculée par ZGGHRD.
!>

Q

!>          Q est un tableau COMPLEX*16, de dimension (LDU, max(NN))
!>          La matrice unitaire (gauche) calculée par ZHGEQZ.
!>

Z

!>          Z est un tableau COMPLEX*16, de dimension (LDU, max(NN))
!>          La matrice unitaire (droite) calculée par ZHGEQZ.
!>

ALPHA1

!>          ALPHA1 est un tableau COMPLEX*16, de dimension (max(NN))
!>

BETA1

!>          BETA1 est un tableau COMPLEX*16, de dimension (max(NN))
!>          Les valeurs propres généralisées de (A,B) calculées par ZHGEQZ
!>          lorsque Q, Z, et les matrices de Schur complètes sont calculées.
!>

ALPHA3

!>          ALPHA3 est un tableau COMPLEX*16, de dimension (max(NN))
!>

BETA3

!>          BETA3 est un tableau COMPLEX*16, de dimension (max(NN))
!>          Les valeurs propres généralisées de (A,B) calculées par ZHGEQZ
!>          lorsque ni Q, ni Z, ni les matrices de Schur ne sont calculées.
!>

EVECTL

!>          EVECTL est un tableau COMPLEX*16, de dimension (LDU, max(NN))
!>          La matrice de vecteurs propres gauches (triangulaire inférieure) pour les
!>          matrices dans S1 et P1.
!>

EVECTR

!>          EVECTR est un tableau COMPLEX*16, de dimension (LDU, max(NN))
!>          La matrice de vecteurs propres droits (triangulaire supérieure) pour les
!>          matrices dans S1 et P1.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          Le nombre d'entrées dans WORK. Il doit être au moins
!>          max( 4*N, 2 * N**2, 1 ), pour tous les N=NN(j).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (2*max(NN))
!>

LLWORK

!>          LLWORK est un tableau LOGICAL, de dimension (max(NN))
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, de dimension (15)
!>          Les valeurs calculées par les tests décrits ci-dessus.
!>          Les valeurs sont actuellement limitées à 1/ulp, pour éviter
!>          le dépassement.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  Une routine a retourné un code d'erreur. INFO est la valeur
!>                absolue de la valeur INFO retournée.
!>
