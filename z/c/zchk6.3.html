programme zblat2

ZBLAT2

Objectif :

!>
!> Programme de test pour les BLAS de niveau 2 COMPLEX*16.
!>
!> Le programme doit être piloté par un fichier de données court. Les 18 premières
!> lignes du fichier sont lues en utilisant l'entrée dirigée par liste, les 17 dernières
!> lignes sont lues en utilisant le format ( A6, L2 ). Un exemple annoté d'un fichier de données
!> peut être obtenu en supprimant les 3 premiers caractères des
!> 35 lignes suivantes :
!> 'zblat2.out'      NOM DU FICHIER DE SORTIE RÉSUMÉ
!> 6                 NUMÉRO D'UNITÉ DU FICHIER RÉSUMÉ
!> 'CBLA2T.SNAP'     NOM DU FICHIER DE SORTIE INSTANTANÉ
!> -1                NUMÉRO D'UNITÉ DU FICHIER INSTANTANÉ (NON UTILISÉ SI .LT. 0)
!> F        INDICATEUR LOGIQUE, T POUR REMbobiner le FICHIER INSTANTANÉ APRÈS CHAQUE ENREGISTREMENT.
!> F        INDICATEUR LOGIQUE, T POUR ARRÊTER EN CAS D'ÉCHEC.
!> T        INDICATEUR LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR SEUIL DU RAPPORT DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 4                 NOMBRE DE VALEURS DE K
!> 0 1 2 4           VALEURS DE K
!> 4                 NOMBRE DE VALEURS DE INCX ET INCY
!> 1 2 -1 -2         VALEURS DE INCX ET INCY
!> 3                 NOMBRE DE VALEURS DE ALPHA
!> (0.0,0.0) (1.0,0.0) (0.7,-0.9)       VALEURS DE ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> (0.0,0.0) (1.0,0.0) (1.3,-1.1)       VALEURS DE BETA
!> ZGEMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZGBMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZHEMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZHBMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZHPMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZTRMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZTBMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZTPMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZTRSV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZTBSV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZTPSV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZGERC  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZGERU  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZHER   T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZHPR   T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZHER2  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> ZHPR2  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
