Documentation de la fonction/sous-routine

sous-routine zchkhb (integer nsizes, integer, dimension( * ) nn, integer nwdths, integer, dimension( * ) kk, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) sd, double precision, dimension( * ) se, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result, integer info)

ZCHKHB

Objectif :

!>
!> ZCHKHB teste la réduction d'une matrice bande hermitienne en forme tridiagonale,
!> utilisée avec le problème de valeurs propres hermitien.
!>
!> ZHBTRD factorise une matrice bande hermitienne A sous la forme U S U* , où * signifie
!> transposée conjuguée, S est symétrique tridiagonale, et U est unitaire.
!> ZHBTRD peut utiliser soit seulement la partie inférieure, soit seulement la partie
!> supérieure de A ; ZCHKHB vérifie les deux cas.
!>
!> Lorsque ZCHKHB est appelée, un nombre de tailles de matrices (NN), un nombre
!> de largeurs de bande (KK), et un nombre de types de matrices (DOTYPE) sont
!> spécifiés. Pour chaque taille, chaque largeur de bande inférieure ou égale à la
!> taille, et chaque type de matrice, une matrice sera générée et utilisée pour tester
!> la routine de réduction hermitienne par bande. Pour chaque matrice, plusieurs tests
!> seront effectués :
!>
!> (1)     | A - V S V* | / ( |A| n ulp )  calculé par ZHBTRD avec
!>                                         UPLO='U'
!>
!> (2)     | I - UU* | / ( n ulp )
!>
!> (3)     | A - V S V* | / ( |A| n ulp )  calculé par ZHBTRD avec
!>                                         UPLO='L'
!>
!> (4)     | I - UU* | / ( n ulp )
!>
!> Les  tailles sont spécifiées par un tableau NN(1:NSIZES); la valeur de
!> chaque élément NN(j) spécifie une taille.
!> Les  types de matrices sont spécifiés par un tableau logique DOTYPE( 1:NTYPES );
!> si DOTYPE(j) est .VRAI., alors le type de matrice j sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!>
!> (3)  Une matrice diagonale avec des entrées régulièrement espacées
!>      1, ..., ULP et des signes aléatoires.
!>      (ULP = (premier nombre supérieur à 1) - 1 )
!> (4)  Une matrice diagonale avec des entrées géométriquement espacées
!>      1, ..., ULP et des signes aléatoires.
!> (5)  Une matrice diagonale avec des entrées  1, ULP, ..., ULP
!>      et des signes aléatoires.
!>
!> (6)  Identique à (4), mais multiplié par SQRT( seuil de débordement )
!> (7)  Identique à (4), mais multiplié par SQRT( seuil de sous-dépassement )
!>
!> (8)  Une matrice de la forme  U* D U, où U est unitaire et
!>      D a des entrées régulièrement espacées 1, ..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (9)  Une matrice de la forme  U* D U, où U est unitaire et
!>      D a des entrées géométriquement espacées 1, ..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (10) Une matrice de la forme  U* D U, où U est unitaire et
!>      D a des entrées  1, ULP,..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (11) Identique à (8), mais multiplié par SQRT( seuil de débordement )
!> (12) Identique à (8), mais multiplié par SQRT( seuil de sous-dépassement )
!>
!> (13) Matrice hermitienne avec des entrées aléatoires choisies dans (-1,1).
!> (14) Identique à (13), mais multiplié par SQRT( seuil de débordement )
!> (15) Identique à (13), mais multiplié par SQRT( seuil de sous-dépassement )
!>

Paramètres

NSIZES 
!>          NSIZES est de type INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il est égal à zéro,
!>          ZCHKHB ne fait rien. Il doit être supérieur ou égal à zéro.
!>

NN

!>          NN est un tableau de type INTEGER, de dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs nulles seront ignorées. Les valeurs doivent être
!>          supérieures ou égales à zéro.
!>

NWDTHS

!>          NWDTHS est de type INTEGER
!>          Le nombre de largeurs de bande à utiliser. S'il est égal à zéro,
!>          ZCHKHB ne fait rien. Il doit être supérieur ou égal à zéro.
!>

KK

!>          KK est un tableau de type INTEGER, de dimension (NWDTHS)
!>          Un tableau contenant les largeurs de bande à utiliser pour les matrices
!>          bandes. Les valeurs doivent être supérieures ou égales à zéro.
!>

NTYPES

!>          NTYPES est de type INTEGER
!>          Le nombre d'éléments dans DOTYPE. S'il est égal à zéro, ZCHKHB
!>          ne fait rien. Il doit être supérieur ou égal à zéro. S'il est égal à MAXTYP+1
!>          et NSIZES est égal à 1, alors un type supplémentaire, MAXTYP+1, est
!>          défini, qui consiste à utiliser la matrice présente dans A. Ceci
!>          est seulement utile si DOTYPE(1:MAXTYP) est .FAUX. et
!>          DOTYPE(MAXTYP+1) est .VRAI. .
!>

DOTYPE

!>          DOTYPE est un tableau de type LOGICAL, de dimension (NTYPES)
!>          Si DOTYPE(j) est .VRAI., alors pour chaque taille dans NN une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximum de types
!>          définis (PARAMETER MAXTYP), alors les types NTYPES+1 à travers
!>          MAXTYP ne seront pas générés. Si NTYPES est supérieur
!>          à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!>

ISEED

!>          ISEED est un tableau de type INTEGER, de dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une séquence
!>          linéaire congruente limitée à de petits entiers, et doit donc
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie et peuvent être utilisées dans
!>          l'appel suivant à ZCHKHB pour continuer la même séquence de nombres
!>          aléatoires.
!>

THRESH

!>          THRESH est de type DOUBLE PRECISION
!>          Un test sera considéré comme  si l'erreur calculée
!>          comme décrit ci-dessus, dépasse THRESH. Notez que l'erreur
!>          est mise à l'échelle pour être de l'ordre de 1, donc THRESH devrait être un multiple raisonnablement
!>          petit de 1, par exemple 10 ou 100. En particulier,
!>          il ne doit pas dépendre de la précision (simple ou double)
!>          ou de la taille de la matrice. Il doit être supérieur ou égal à zéro.
!>

NOUNIT

!>          NOUNIT est de type INTEGER
!>          Le numéro d'unité FORTRAN pour l'affichage des messages d'erreur
!>          (par exemple, si une routine renvoie un IINFO différent de 0).
!>

A

!>          A est un tableau de type COMPLEX*16, de dimension
!>                            (LDA, max(NN))
!>          Utilisé pour contenir la matrice dont les valeurs propres doivent être
!>          calculées.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale de A. Elle doit être au moins 2 (pas 1 !)
!>          et au moins max( KK )+1.
!>

SD

!>          SD est un tableau de type DOUBLE PRECISION, de dimension (max(NN))
!>          Utilisé pour contenir la diagonale de la matrice tridiagonale calculée
!>          par ZHBTRD.
!>

SE

!>          SE est un tableau de type DOUBLE PRECISION, de dimension (max(NN))
!>          Utilisé pour contenir les éléments hors diagonale de la matrice tridiagonale
!>          calculée par ZHBTRD.
!>

U

!>          U est un tableau de type COMPLEX*16, de dimension (LDU, max(NN))
!>
