NOM

zcmp, zdiff - comparer des fichiers compressés

SYNTAXE

zcmp [ options_cmp ] fichier1 [ fichier2 ]
zdiff [ options_diff ] fichier1 [ fichier2 ]

DESCRIPTION

Les commandes zcmp et zdiff sont utilisées pour invoquer le programme cmp ou diff sur des fichiers compressés via gzip. Toutes les options spécifiées sont directement transmises à cmp ou diff. Si un seul fichier, fichier1, est spécifié, il est comparé au contenu décompressé de fichier1.gz. Si deux fichiers sont spécifiés, leurs contenus (décompressés si nécessaire) sont transmis à cmp ou diff. Les fichiers d'entrée ne sont pas modifiés. Le code de sortie de cmp ou diff est préservé.

VOIR AUSSI

cmp(1), diff(1), zmore(1), zgrep(1), znew(1), zforce(1), gzip(1), gzexe(1)

BOGUES

Les messages des programmes cmp ou diff peuvent faire référence à des noms de fichiers tels que « - » au lieu des noms de fichiers spécifiés.
