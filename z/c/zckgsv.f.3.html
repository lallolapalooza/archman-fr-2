ZCKGSV

But :

!>
!> ZCKGSV teste ZGGSVD :
!>        le GSVD de la matrice A de dimension M par N et de la matrice B de dimension P par N.
!>

Paramètres

NM 
!>          NM est un ENTIER
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau d'ENTIERS, dimension (NM)
!>          Les valeurs de la dimension de ligne M de la matrice.
!>

PVAL

!>          PVAL est un tableau d'ENTIERS, dimension (NP)
!>          Les valeurs de la dimension de ligne P de la matrice.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, dimension (NN)
!>          Les valeurs de la dimension de colonne N de la matrice.
!>

NMATS

!>          NMATS est un ENTIER
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions de matrices. Si NMATS >= NTYPES (le nombre maximum
!>          de types de matrices), alors tous les différents types sont
!>          générés pour le test. Si NMATS < NTYPES, une ligne d'entrée supplémentaire
!>          est lue pour obtenir les numéros des types de matrices à utiliser.
!>

ISEED

!>          ISEED est un tableau d'ENTIERS, dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires. Les éléments
!>          du tableau doivent être compris entre 0 et 4095, sinon ils seront
!>          réduits modulo 4096, et ISEED(4) doit être impair.
!>          À la sortie, la graine suivante de la séquence de nombres aléatoires après
!>          la génération de toutes les matrices de test.
!>

THRESH

!>          THRESH est une DOUBLE PRÉCISION
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque ratio de test soit imprimé, utilisez THRESH = 0.
!>

NMAX

!>          NMAX est un ENTIER
!>          La valeur maximale permise pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

B

!>          B est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

BF

!>          BF est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

U

!>          U est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

V

!>          V est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

Q

!>          Q est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

ALPHA

!>          ALPHA est un tableau de DOUBLE PRÉCISION, dimension (NMAX)
!>

BETA

!>          BETA est un tableau de DOUBLE PRÉCISION, dimension (NMAX)
!>

R

!>          R est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, dimension (NMAX)
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

RWORK

!>          RWORK est un tableau de DOUBLE PRÉCISION, dimension (NMAX)
!>

NIN

!>          NIN est un ENTIER
!>          Le numéro d'unité pour l'entrée.
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro d'unité pour la sortie.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 :  sortie réussie
!>          > 0 :  Si ZLATMS renvoie un code d'erreur, sa valeur absolue
!>                 est retournée.
!>
