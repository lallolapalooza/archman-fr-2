ZCHKHB2STG

But:

!>
!> ZCHKHB2STG teste la réduction d'une matrice de bande hermitienne en une matrice tridiagonale,
!> utilisée pour le problème de valeurs propres hermitiennes.
!>
!> ZHBTRD factorise une matrice de bande hermitienne A en U S U* , où * signifie
!> transposée conjuguée, S est tridiagonale symétrique, et U est unitaire.
!> ZHBTRD peut utiliser seulement le triangle inférieur ou seulement le triangle supérieur
!> de A ; ZCHKHB2STG teste les deux cas.
!>
!> ZHETRD_HB2ST factorise une matrice de bande hermitienne A en U S U* ,
!> où * signifie transposée conjuguée, S est tridiagonale symétrique, et U est
!> unitaire. ZHETRD_HB2ST peut utiliser seulement le triangle inférieur ou seulement
!> le triangle supérieur de A ; ZCHKHB2STG teste les deux cas.
!>
!> DSTEQR factorise S en Z D1 Z'.
!> D1 est la matrice des valeurs propres calculées lorsque Z n'est pas calculé
!> et à partir de S résultant de DSBTRD (utilisée comme référence pour DSYTRD_SB2ST)
!> D2 est la matrice des valeurs propres calculées lorsque Z n'est pas calculé
!> et à partir de S résultant de DSYTRD_SB2ST.
!> D3 est la matrice des valeurs propres calculées lorsque Z n'est pas calculé
!> et à partir de S résultant de DSYTRD_SB2ST.
!>
!> Lorsque ZCHKHB2STG est appelée, un certain nombre de tailles de matrices (),
!> un certain nombre de largeurs de bande (), et un certain nombre de types de matrices
!> sont spécifiés. Pour chaque taille (), chaque largeur de bande () inférieure ou
!> égale à , et chaque type de matrice, une matrice sera générée
!> et utilisée pour tester la routine de réduction hermitienne par bande. Pour chaque
!> matrice, un certain nombre de tests seront effectués :
!>
!> (1)     | A - V S V* | / ( |A| n ulp )  calculé par ZHBTRD avec
!>                                         UPLO='U'
!>
!> (2)     | I - UU* | / ( n ulp )
!>
!> (3)     | A - V S V* | / ( |A| n ulp )  calculé par ZHBTRD avec
!>                                         UPLO='L'
!>
!> (4)     | I - UU* | / ( n ulp )
!>
!> (5)     | D1 - D2 | / ( |D1| ulp )      où D1 est calculé par
!>                                         DSBTRD avec UPLO='U' et
!>                                         D2 est calculé par
!>                                         ZHETRD_HB2ST avec UPLO='U'
!>
!> (6)     | D1 - D3 | / ( |D1| ulp )      où D1 est calculé par
!>                                         DSBTRD avec UPLO='U' et
!>                                         D3 est calculé par
!>                                         ZHETRD_HB2ST avec UPLO='L'
!>
!> Les  sont spécifiés par un tableau NN(1:NSIZES) ; la valeur de
!> chaque élément NN(j) spécifie une taille.
!> Les  sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ;
!> si DOTYPE(j) est .VRAI., alors le type de matrice  sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!>
!> (3)  Une matrice diagonale avec des entrées régulièrement espacées
!>      1, ..., ULP et des signes aléatoires.
!>      (ULP = (premier nombre supérieur à 1) - 1 )
!> (4)  Une matrice diagonale avec des entrées géométriquement espacées
!>      1, ..., ULP et des signes aléatoires.
!> (5)  Une matrice diagonale avec des entrées 1, ULP, ..., ULP
!>      et des signes aléatoires.
!>
!> (6)  Identique à (4), mais multiplié par SQRT( seuil de dépassement de capacité )
!> (7)  Identique à (4), mais multiplié par SQRT( seuil de sous-dépassement de capacité )
!>
!> (8)  Une matrice de la forme U* D U, où U est unitaire et
!>      D a des entrées régulièrement espacées 1, ..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (9)  Une matrice de la forme U* D U, où U est unitaire et
!>      D a des entrées géométriquement espacées 1, ..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (10) Une matrice de la forme U* D U, où U est unitaire et
!>      D a des entrées 1, ULP,..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (11) Identique à (8), mais multiplié par SQRT( seuil de dépassement de capacité )
!> (12) Identique à (8), mais multiplié par SQRT( seuil de sous-dépassement de capacité )
!>
!> (13) Matrice hermitienne avec des entrées aléatoires choisies dans (-1,1).
!> (14) Identique à (13), mais multiplié par SQRT( seuil de dépassement de capacité )
!> (15) Identique à (13), mais multiplié par SQRT( seuil de sous-dépassement de capacité )
!>

Paramètres

NSIZES 
!>          NSIZES est INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il est zéro,
!>          ZCHKHB2STG ne fait rien. Il doit être supérieur ou égal à zéro.
!>

NN

!>          NN est un tableau INTEGER, dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs nulles seront ignorées. Les valeurs doivent être supérieures ou égales à
!>          zéro.
!>

NWDTHS

!>          NWDTHS est INTEGER
!>          Le nombre de largeurs de bande à utiliser. S'il est zéro,
!>          ZCHKHB2STG ne fait rien. Il doit être supérieur ou égal à zéro.
!>

KK

!>          KK est un tableau INTEGER, dimension (NWDTHS)
!>          Un tableau contenant les largeurs de bande à utiliser pour les matrices de bande.
!>          Les valeurs doivent être supérieures ou égales à zéro.
!>

NTYPES

!>          NTYPES est INTEGER
!>          Le nombre d'éléments dans DOTYPE. S'il est zéro, ZCHKHB2STG
!>          ne fait rien. Il doit être supérieur ou égal à zéro. S'il est MAXTYP+1
!>          et NSIZES est 1, alors un type supplémentaire, MAXTYP+1, est
!>          défini, qui consiste à utiliser la matrice présente dans A. Ceci
!>          n'est utile que si DOTYPE(1:MAXTYP) est .FAUX. et
!>          DOTYPE(MAXTYP+1) est .VRAI..
!>

DOTYPE

!>          DOTYPE est un tableau LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) est .VRAI., alors pour chaque taille dans NN, une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximum de types
!>          définis (PARAMETER MAXTYP), alors les types NTYPES+1 à
!>          MAXTYP ne seront pas générés. Si NTYPES est supérieur
!>          à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!>

ISEED

!>          ISEED est un tableau INTEGER, dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une séquence
!>          linéaire congruente limitée à de petits entiers, et devrait donc produire
!>          des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie et peuvent être utilisées dans
!>          l'appel suivant à ZCHKHB2STG pour continuer la même séquence de nombres
!>          aléatoires.
!>

THRESH

!>          THRESH est DOUBLE PRECISION
!>          Seuil pour la précision des tests.
!>

NOUN IT

!>          NOUN IT est INTEGER
!>          Si Nounit est égal à 1, alors U et UU* sont calculés.
!>          Si Nounit est égal à 2, alors U et UU* ne sont pas calculés.
!>

A

!>          A est COMPLEX*16, dimension (LDA, *)
!>          La matrice d'entrée.
!>

LDA

!>          LDA est INTEGER
!>          La longueur de la première dimension de A.
!>

SD

!>          SD est DOUBLE PRECISION, dimension (*)
!>          Tableau de travail.
!>

SE

!>          SE est DOUBLE PRECISION, dimension (*)
!>          Tableau de travail.
!>

D1

!>          D1 est DOUBLE PRECISION, dimension (*)
!>          Tableau pour les valeurs propres.
!>

D2

!>          D2 est DOUBLE PRECISION, dimension (*)
!>          Tableau pour les valeurs propres.
!>

D3

!>          D3 est DOUBLE PRECISION, dimension (*)
!>          Tableau pour les valeurs propres.
!>

U

!>          U est COMPLEX*16, dimension (LDU, *)
!>          La matrice unitaire U.
!>

LDU

!>          LDU est INTEGER
!>          La longueur de la première dimension de U.
!>

WORK

!>          WORK est COMPLEX*16, dimension (*)
!>          Tableau de travail.
!>

LWORK

!>          LWORK est INTEGER
!>          La taille du tableau WORK.
!>

RWORK

!>          RWORK est DOUBLE PRECISION, dimension (*)
!>          Tableau de travail réel.
!>

RESULT

!>          RESULT est DOUBLE PRECISION, dimension (*)
!>          Tableau de résultats des tests.
!>

INFO

!>          INFO est INTEGER
!>          Info > 0: nombre d'erreurs non récupérables détectées.
!>          Info < 0: nombre d'erreurs récupérables détectées.
!>

NAME

zchkhb2stg - Example auxiliary routines for ZHBTRD.

SYNOPSIS

SUBROUTINE ZCHKHB2STG ( NMAX, NN, THRESH, NOUNIT, A, LDA, SD, SE, D1, D2,
                        D3, U, LDU, WORK, LWORK, RWORK, RESULT, INFO )

Function/Subroutine Documentation


*>
THRESH

!>          THRESH est de type DOUBLE PRECISION
!>          Un test réussira si le , calculé comme décrit ci-dessus, dépasse THRESH.
!>          Notez que l'erreur est mise à l'échelle pour être O(1), donc THRESH
!>          devrait être un multiple raisonnablement petit de 1, par exemple 10 ou
!>          100. En particulier, il ne doit pas dépendre de la précision (simple
!>          ou double) ou de la taille de la matrice. Il doit être au moins zéro.
!>

NOUNIT

!>          NOUNIT est de type INTEGER
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (par exemple, si une routine retourne IINFO différent de 0.)
!>

A

!>          A est un tableau de type COMPLEX*16, de dimension
!>                            (LDA, max(NN))
!>          Utilisé pour contenir la matrice dont les valeurs propres doivent être
!>          calculées.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale de A. Elle doit être au moins 2 (pas 1 !)
!>          et au moins max( KK )+1.
!>

SD

!>          SD est un tableau de type DOUBLE PRECISION, de dimension (max(NN))
!>          Utilisé pour contenir la diagonale de la matrice tridiagonale calculée
!>          par ZHBTRD.
!>

SE

!>          SE est un tableau de type DOUBLE PRECISION, de dimension (max(NN))
!>          Utilisé pour contenir les éléments hors diagonale de la matrice
!>          tridiagonale calculée par ZHBTRD.
!>

D1

!>          D1 est un tableau de type DOUBLE PRECISION, de dimension (max(NN))
!>

D2

!>          D2 est un tableau de type DOUBLE PRECISION, de dimension (max(NN))
!>


*>
D3

!>          D3 est un tableau de type DOUBLE PRECISION, de dimension (max(NN))
!>

U

!>          U est un tableau de type COMPLEX*16, de dimension (LDU, max(NN))
!>          Utilisé pour contenir la matrice unitaire calculée par ZHBTRD.
!>

LDU

!>          LDU est de type INTEGER
!>          La dimension principale de U. Elle doit être au moins 1
!>          et au moins max( NN ).
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est de type INTEGER
!>          Le nombre d'entrées dans WORK. Il doit être au moins
!>          max( LDA+1, max(NN)+1 )*max(NN).
!>

RWORK

!>          RWORK est un tableau de type DOUBLE PRECISION
!>

RESULT

!>          RESULT est un tableau de type DOUBLE PRECISION, de dimension (4)
!>          Les valeurs calculées par les tests décrits ci-dessus.
!>          Les valeurs sont actuellement limitées à 1/ulp, pour éviter
!>          le débordement.
!>

INFO

!>          INFO est de type INTEGER
!>          Si 0, alors tout s'est bien passé.

!>                       pour le type .
