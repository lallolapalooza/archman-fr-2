Description

ZCHKGG is a subroutine with the following specification:

SUBROUTINE ZCHKGG( NSIZES, NN, NTYPES, DOTYPE, ISEED, THRESH, TSTDIF,
                    THRSHN, NOUNIT, A, LDA, B, H, T, S1, S2, P1, P2,
                    U, LDU, V, Q, Z, ALPHA1, BETA1, ALPHA3, BETA3,
                    EVECTL, EVECTR, WORK, LWORK, RWORK, LLWORK, RESULT, INFO )

This routine is a driver program for ZGGHRD, ZHGEQZ, and ZGGEV. It calls the following subroutines in order to test them:

1.
ZGGHRD
2.
ZHGEQZ
3.
ZGGEV (indirectly by calling ZHGEQZ with Q and Z computed)

The matrix types are:

  • (1) U( J , J ) V where J is a diagonal matrix. (This is equivalent to (16) and (1) in the ZGGEV driver)

  • (2) U( J , J ) V where J is a diagonal matrix with random complex entries.

  • (3) U( D , D ) V where D is a diagonal matrix.

  • (4) U( D , D ) V where D is a diagonal matrix with random complex entries.

  • (5) U( D , D ) V where D is a diagonal matrix with random real entries.

  • (6) U( T1, T2 ) V where T1 and T2 are upper triangular matrices with random O(1) entries above the diagonal and diagonal entries diag(T1)= (a, ..., a) and diag(T2)=(b, ..., b).

  • (7) U( T1, T2 ) V where T1 and T2 are upper triangular matrices with random O(1) entries above the diagonal and diagonal entries diag(T1)=(a, ..., a) and diag(T2)=(b, ..., b) where a and b are random.

  • (8) U( T1, T2 ) V where T1 and T2 are upper triangular matrices with random O(1) entries above the diagonal and diagonal entries diag(T1)=(1, ..., 1) and diag(T2)=(b, ..., b) where b is random.

  • (9) U( T1, T2 ) V where T1 and T2 are upper triangular matrices with random O(1) entries above the diagonal and diagonal entries diag(T1)=(a, ..., a) and diag(T2)=(1, ..., 1) where a is random.

  • (10) U( T1, T2 ) V where T1 and T2 are upper triangular matrices with random O(1) entries above the diagonal and diagonal entries diag(T1)=(a, ..., a) and diag(T2)=(a, ..., a) where a is random.

  • (11) U( T1, T2 ) V where T1 and T2 are upper triangular matrices with random O(1) entries above the diagonal and diagonal entries diag(T1)=(1, ..., 1) and diag(T2)=(1, ..., 1).

  • (12) U( T1, T2 ) V where T1 and T2 are upper triangular matrices with random O(1) entries above the diagonal and diagonal entries diag(T1)=(a, ..., a) and diag(T2)=(1, ..., 1) where a is random.

  • (13) U( T1, T2 ) V where T1 and T2 are upper triangular matrices with random O(1) entries above the diagonal and diagonal entries diag(T1)=(1, ..., 1) and diag(T2)=(b, ..., b) where b is random.

  • (14) U( T1, T2 ) V where T1 and T2 are upper triangular matrices with random O(1) entries above the diagonal and diagonal entries diag(T1)=(a, ..., a) and diag(T2)=(b, ..., b) where a and b are random, a!=1, b!=1, a!=b.

  • (15) U( T1, T2 ) V where T1 and T2 are upper triangular matrices with random O(1) entries above the diagonal and diagonal entries diag(T1)=(a, ..., a) and diag(T2)=(a, ..., a) where a is random, a!=1.

  • (16) U ( J , J ) V where U and V are random unitary matrices. J is a diagonal matrix with entries 0, 0, 1, ..., N-3, 0.

  • (17) U ( T1, T2 ) V where T1 and T2 are upper triangular matrices with random O(1) entries above the diagonal and diagonal entries diag(T1) = P*( 0, 0, 1, ..., N-3, 0 ) and diag(T2) = Q*( 0, N-3, N-4,..., 1, 0, 0 )

  • (18) U ( T1, T2 ) V diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 ) diag(T2) = ( 0, 1, 0, 1,..., 1, 0 ) s = machine precision.

  • (19) U ( T1, T2 ) V diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 ) diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )

  • (20) U ( T1, T2 ) V diag(T1)=( 0, 0, 1, 1, a, ..., a =s, 0 ) diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )

  • (21) U ( T1, T2 ) V diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 ) diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 ) where r1,..., r(N-4) are random.

  • (22) U ( big*T1, small*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 ) diag(T2) = ( 0, 1, ..., 1, 0, 0 )

  • (23) U ( small*T1, big*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 ) diag(T2) = ( 0, 1, ..., 1, 0, 0 )

  • (24) U ( small*T1, small*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 ) diag(T2) = ( 0, 1, ..., 1, 0, 0 )

  • (25) U ( big*T1, big*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 ) diag(T2) = ( 0, 1, ..., 1, 0, 0 )

  • (26) U ( T1, T2 ) V where T1 and T2 are random upper-triangular matrices.

zchkgg(3)

NOM

zchkgg — vérifie les sous-programmes de test de la paire de matrices triangulaires et d'une matrice de bande.

SYNOPSIS

    subroutine zchkgg(
       k, l, m, n, &
       nz, nl, nr, &
       a, lda, b, ldb, &
       x, ldx, y, ldy, &
       eps, sfmin, &
       c1, c2, c3, &
       resid, result, &
       nounit, iword, ...)

Documentation des fonctions/sous-programmes

zchkgg est une sous-routine qui teste les sous-programmes LAPACK pour la décomposition de matrices triangulaires et la résolution de systèmes linéaires avec des matrices triangulaires ou de bande.

Elle prend les dimensions des matrices, les matrices elles-mêmes, des valeurs de tolérance et des résultats attendus en entrée. Elle calcule les résidus et les compare aux résultats attendus pour évaluer la précision des sous-programmes testés.
