ZCKDL(1) Manuel des commandes générales ZCKDL(1)

NOM

zckdl — télécharger un fichier zchunk

SYNTAXE

zckdl [--fail-no-ranges] [-q | --quiet] [-s fichier | --source=fichier] [-v | --verbose] url

zckdl -? | --help | --usage | --version

DESCRIPTION

L'utilitaire zckdl tente de télécharger un fichier zchunk de manière optimisée, en tenant compte de sa structure en morceaux.

L'utilitaire zckdl accepte les arguments optionnels suivants :

--fail-no-ranges
Si le serveur ne prend pas en charge les plages, échoue au lieu de télécharger le fichier entier.
-q | --quiet
Fonctionnement silencieux ; affiche uniquement les messages d'avertissement et d'erreur. Si spécifié deux fois, n'affiche que les messages d'erreur.
-s | --source
Spécifie le fichier à utiliser comme source, en partant du principe que la plupart des morceaux du fichier téléchargé seront identiques.
-v, --verbose
Fonctionnement verbeux ; affiche des informations diagnostiques.
-?, --help
Affiche les informations d'utilisation du programme et quitte.
--usage
Affiche brièvement les informations d'utilisation du programme et quitte.
--version
Affiche les informations de version du programme et quitte.

STATUT DE SORTIE

L'utilitaire zckdl se termine avec le code 0 en cas de succès, et >0 si une erreur se produit.

EXEMPLES

Télécharge un fichier zchunk qui, on l'espère, n'est pas très différent de la version précédente :

zckdl -s doc1.txt.zck https://example.com/doc2.txt.zck
