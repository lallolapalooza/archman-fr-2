NOM

zypper-log - Lecteur de fichiers journaux de Zypper

SYNTAXE

zypper-log [OPTIONS] [PID]

DESCRIPTION

zypper-log peut lire les fichiers journaux de zypper. Il peut également gérer les fichiers journaux archivés et ouvrira des fichiers plats, compressés en xz, gz ou bz2.

Par défaut, /var/log/zypper.log est lu et une liste de toutes les invocations de zypper est affichée :

$ zypper-log
Reading /var/log/zypper.log ............... DONE
TIME              PID    VER      CMD
2013-10-15 11:01  2195   1.11.14  /usr/bin/zypper se spell
2013-10-15 11:03  2703   1.11.14  /usr/bin/zypper in aspell-en aspell-ispell aspell-de
2013-10-15 15:00  22463  1.11.14  /usr/bin/zypper lr -u
2013-10-15 15:00  22479  1.11.14  /usr/bin/zypper lr -s

Lorsque vous fournissez un PID, vous obtiendrez le journal complet pour l'exécution de zypper correspondante.

OPTIONS

-d AAAA-MM-JJ

Ne visualiser que les exécutions de zypper du jour spécifié.

-l FICHIER

Ne lire que ce fichier journal.

-r NOMBRE

Lire également les NOMBRE derniers fichiers journaux archivés.

--help

Afficher l'aide et quitter.

FICHIERS

/var/log/zypper.log

Fichier journal par défaut de zypper.

/var/log/YaST2/y2log

Comme YAST utilise un format de fichier journal similaire, vous devriez pouvoir analyser également les fichiers journaux de YAST en utilisant l'option -l.
