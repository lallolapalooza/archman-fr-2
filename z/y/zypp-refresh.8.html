NOM

zypp-refresh - Rafraîchit automatiquement les métadonnées de tous les dépôts activés

SYNTAXE

zypp-refresh

DESCRIPTION

zypp-refresh rafraîchit les métadonnées de tous les dépôts activés pour lesquels autorefresh est activé (voir zypper lr). À utiliser par exemple dans les tâches cron ou les scripts.

FICHIERS

/var/log/zypp-refresh.log
