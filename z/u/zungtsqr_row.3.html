Documentation de la fonction/sous-programme

sous-programme zungtsqr_row (integer m, integer n, integer mb, integer nb, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( * ) work, integer lwork, integer info)

ZUNGTSQR_ROW

Objectif :

!>
!> ZUNGTSQR_ROW génère une matrice complexe M par N, Q_out, avec des colonnes
!> orthonormales à partir de la sortie de ZLATSQR. Ces N colonnes orthonormales
!> sont les N premières colonnes d'un produit de matrices unitaires complexes
!> Q(k)_in de taille M, qui sont retournées par ZLATSQR dans un format spécial.
!>
!>      Q_out = premiere_N_colonnes_de( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> Les matrices d'entrée Q(k)_in sont stockées en blocs de lignes et de colonnes dans A.
!> Voir la documentation de ZLATSQR pour plus de détails sur le format de
!> Q(k)_in, où chaque Q(k)_in est représentée par des transformations de Householder
!> par blocs. Cette routine appelle une routine auxiliaire ZLARFB_GETT,
!> où le calcul est effectué sur chaque bloc individuel. L'algorithme balaye d'abord
!> les blocs de colonnes de taille NB de droite à gauche en commençant dans le
!> bloc de ligne inférieur et continue jusqu'au bloc de ligne supérieur (d'où
!> _ROW dans le nom de la routine). Ce balayage est dans l'ordre inverse de l'ordre
!> dans lequel ZLATSQR génère les blocs de sortie.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

MB

!>          MB est un entier (INTEGER)
!>          La taille du bloc de lignes utilisé par ZLATSQR pour retourner
!>          les tableaux A et T. MB > N.
!>          (Notez que si MB > M, alors M est utilisé à la place de MB
!>          comme taille du bloc de lignes).
!>

NB

!>          NB est un entier (INTEGER)
!>          La taille du bloc de colonnes utilisé par ZLATSQR pour retourner
!>          les tableaux A et T. NB >= 1.
!>          (Notez que si NB > N, alors N est utilisé à la place de NB
!>          comme taille du bloc de colonnes).
!>

A

!>          A est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>
!>          À l'entrée :
!>
!>             Les éléments sur et au-dessus de la diagonale ne sont pas utilisés
!>             comme entrée. Les éléments en dessous de la diagonale représentent
!>             la matrice trapézoïdale inférieure bloquée unitaire V calculée par
!>             ZLATSQR qui définit les matrices d'entrée Q_in(k) (les uns sur la
!>             diagonale ne sont pas stockés). Voir ZLATSQR pour plus de détails.
!>
!>          À la sortie :
!>
!>             Le tableau A contient une matrice unitaire M par N, Q_out,
!>             c'est-à-dire que les colonnes de A sont des vecteurs unitaires orthogonaux.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

T

!>          T est un tableau de type COMPLEX*16,
!>          de dimension (LDT, N * NIRB)
!>          où NIRB = Nombre de blocs de lignes d'entrée
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Soit NICB = Nombre de blocs de colonnes d'entrée
!>                   = CEIL(N/NB)
!>
!>          Les réflecteurs de blocs triangulaires supérieurs utilisés pour définir les
!>          matrices d'entrée Q_in(k), k=(1:NIRB*NICB). Les blocs
!>          réflecteurs sont stockés sous forme compacte dans NIRB blocs
!>          de séquences de réflecteurs. Chacune des NIRB séquences de
!>          réflecteurs de blocs est stockée dans un bloc de colonnes plus grand
!>          de T, de taille NB par N, et consiste en NICB plus petits blocs
!>          de colonnes triangulaires supérieurs de taille NB par NB. Voir ZLATSQR
!>          pour plus de détails sur le format de T.
!>

LDT

!>          LDT est un entier (INTEGER)
!>          La dimension principale du tableau T.
!>          LDT >= max(1,min(NB,N)).
!>

WORK

!>          (espace de travail) Tableau de type COMPLEX*16, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La dimension du tableau WORK.
!>          LWORK >= NBLOCAL * MAX(NBLOCAL,(N-NBLOCAL)),
!>          où NBLOCAL=MIN(NB,N).
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée.
!>          La routine calcule uniquement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK, et aucun
!>          message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
