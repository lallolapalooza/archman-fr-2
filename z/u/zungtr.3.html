Documentation de fonction/sous-programme

sous-routine zungtr (caractère uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) tau, complexe*16, dimension( * ) work, entier lwork, entier info)

ZUNGTR

Objectif:

!>
!> ZUNGTR génère une matrice unitaire complexe Q qui est définie comme le
!> produit de n-1 réflecteurs élémentaires d'ordre N, tel que retourné par
!> ZHETRD:
!>
!> si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A contient les réflecteurs
!>                 élémentaires provenant de ZHETRD;
!>          = 'L' : le triangle inférieur de A contient les réflecteurs
!>                 élémentaires provenant de ZHETRD.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice Q. N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          En entrée, les vecteurs qui définissent les réflecteurs
!>          élémentaires, tels que retournés par ZHETRD.
!>          En sortie, la matrice unitaire Q de taille N*N.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= N.
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (N-1)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par ZHETRD.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= N-1.
!>          Pour une performance optimale, LWORK >= (N-1)*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule seulement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK,
!>          et aucun message d'erreur relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale
!>
