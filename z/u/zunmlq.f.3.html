Documentation de la fonction/sous-programme

sous-programme zunmlq (character side, character trans, integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( * ) work, integer lwork, integer info)

ZUNMLQ

But:

!>
!> ZUNMLQ écrase la matrice complexe générale M par N, C, avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> où Q est une matrice unitaire complexe définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(k)**H . . . H(2)**H H(1)**H
!>
!> telle que retournée par ZGELQF. Q est d'ordre M si SIDE = 'L' et d'ordre N
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**H depuis la Gauche ;
!>          = 'R': appliquer Q ou Q**H depuis la Droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': Pas de transposée, appliquer Q ;
!>          = 'C': Transposée conjuguée, appliquer Q**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ème ligne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          ZGELQF dans les k premières lignes de son tableau argument A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension de tête du tableau A. LDA >= max(1,K).
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par ZGELQF.
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC,N)
!>          En entrée, la matrice M par N, C.
!>          En sortie, C est écrasée par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension de tête du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne la taille optimale LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N) ;
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
