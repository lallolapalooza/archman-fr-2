Documentation de la fonction/sous-routine

sous-routine zunhr_col02 (entier m, entier n, entier mb1, entier nb1, entier nb2, double précision, dimension(6) result)

ZUNHR_COL02

Objectif :

!>
!> ZUNHR_COL02 teste ZUNGTSQR_ROW et ZUNHR_COL dans ZGETSQRHRT
!> (qui appelle ZLATSQR, ZUNGTSQR_ROW et ZUNHR_COL) en utilisant ZGEMQRT.
!> Par conséquent, ZLATSQR (partie de ZGEQR), ZGEMQRT (partie de ZGEMQR)
!> doivent être testés avant ce test.
!>
!>

Paramètres

M 
!>          M est ENTIER
!>          Nombre de lignes dans la matrice de test.
!>

N

!>          N est ENTIER
!>          Nombre de colonnes dans la matrice de test.
!>

MB1

!>          MB1 est ENTIER
!>          Nombre de lignes dans le bloc de ligne d'une matrice de test d'entrée.
!>

NB1

!>          NB1 est ENTIER
!>          Nombre de colonnes dans le bloc de colonne d'une matrice de test d'entrée.
!>

NB2

!>          NB2 est ENTIER
!>          Nombre de colonnes dans le bloc de colonne d'une matrice de test de sortie.
!>

RESULT

!>          RESULT est un tableau de DOUBLE PRÉCISION, dimension (6)
!>          Résultats de chacun des six tests ci-dessous.
!>
!>            A est une matrice d'entrée de test m x n à factoriser.
!>            de telle sorte que A = Q_gr * ( R )
!>                                       ( 0 ),
!>
!>            Q_qr est une matrice unitaire implicite m x m, le résultat
!>            de la factorisation en représentation bloquée WY,
!>            stockée au format de sortie ZGEQRT.
!>
!>            R est une matrice triangulaire supérieure n x n,
!>
!>            0 est une matrice nulle (m-n) x n,
!>
!>            Q est une matrice unitaire explicite m x m, Q = Q_gr * I
!>
!>            C est une matrice aléatoire m x n,
!>
!>            D est une matrice aléatoire n x m.
!>
!>          Les six tests sont :
!>
!>          RESULT(1) = |R - (Q**H) * A| / ( eps * m * |A| )
!>            est équivalent au test pour | A - Q * R | / (eps * m * |A|),
!>
!>          RESULT(2) = |I - (Q**H) * Q| / ( eps * m ),
!>
!>          RESULT(3) = | Q_qr * C - Q * C | / (eps * m * |C|),
!>
!>          RESULT(4) = | (Q_gr**H) * C - (Q**H) * C | / (eps * m * |C|)
!>
!>          RESULT(5) = | D * Q_qr - D * Q | / (eps * m * |D|)
!>
!>          RESULT(6) = | D * (Q_qr**H) - D * (Q**H) | / (eps * m * |D|),
!>
!>          où :
!>            Q_qr * C, (Q_gr**H) * C, D * Q_qr, D * (Q_qr**H) sont
!>            calculés à l'aide de ZGEMQRT,
!>
!>            Q * C, (Q**H) * C, D * Q, D * (Q**H) sont
!>            calculés à l'aide de ZGEMM.
!>
