Documentation de la fonction/sous-routine

sous-routine zupmtr (caractère side, caractère uplo, caractère trans, entier m, entier n, complex*16, dimension( * ) ap, complex*16, dimension( * ) tau, complex*16, dimension( ldc, * ) c, entier ldc, complex*16, dimension( * ) work, entier info)

ZUPMTR

But :

!>
!> ZUPMTR remplace la matrice générale complexe M par N de C par
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> où Q est une matrice unitaire complexe d'ordre nq, avec nq = m si
!> SIDE = 'L' et nq = n si SIDE = 'R'. Q est définie comme le produit de
!> nq-1 réflexions élémentaires, telles que retournées par ZHPTRD utilisant le stockage compact :
!>
!> si UPLO = 'U', Q = H(nq-1) . . . H(2) H(1);
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(nq-1).
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**H à gauche ;
!>          = 'R': appliquer Q ou Q**H à droite.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U': stockage triangulaire supérieur compact utilisé dans l'appel
!>                 précédent à ZHPTRD ;
!>          = 'L': stockage triangulaire inférieur compact utilisé dans l'appel
!>                 précédent à ZHPTRD.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N':  Pas de transposition, appliquer Q ;
!>          = 'C':  Transposition conjuguée, appliquer Q**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, dimension
!>                               (M*(M+1)/2) si SIDE = 'L'
!>                               (N*(N+1)/2) si SIDE = 'R'
!>          Les vecteurs qui définissent les réflexions élémentaires, tels que
!>          retournés par ZHPTRD. AP est modifié par la routine mais
!>          restauré à la sortie.
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (M-1) si SIDE = 'L'
!>                                     ou (N-1) si SIDE = 'R'
!>          TAU(i) doit contenir le facteur scalaire de la réflexion élémentaire
!>          H(i), tel que retourné par ZHPTRD.
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC,N)
!>          À l'entrée, la matrice M par N de C.
!>          À la sortie, C est remplacé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension
!>                                   (N) si SIDE = 'L'
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
