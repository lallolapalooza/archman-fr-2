sous-routine zunm2l (character side, character trans, integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( * ) work, integer info)

ZUNM2L multiplie une matrice générale par la matrice unitaire issue d'une factorisation QL déterminée par cgeqlf (algorithme non bloqué).

Objectif :

!>
!> ZUNM2L écrase la matrice complexe générale m par n C avec
!>
!>       Q * C  si SIDE = 'L' et TRANS = 'N', ou
!>
!>       Q**H* C  si SIDE = 'L' et TRANS = 'C', ou
!>
!>       C * Q  si SIDE = 'R' et TRANS = 'N', ou
!>
!>       C * Q**H si SIDE = 'R' et TRANS = 'C',
!>
!> où Q est une matrice unitaire complexe définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(k) . . . H(2) H(1)
!>
!> tels que retournés par ZGEQLF. Q est d'ordre m si SIDE = 'L' et d'ordre n
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**H à gauche
!>          = 'R': appliquer Q ou Q**H à droite
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': appliquer Q  (Pas de transposée)
!>          = 'C': appliquer Q**H (Transposée conjuguée)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          ZGEQLF dans les k dernières colonnes de son argument tableau A.
!>          A est modifié par la routine mais restauré à la sortie.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,M) ;
!>          si SIDE = 'R', LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par ZGEQLF.
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC,N)
!>          À l'entrée, la matrice C de m par n.
!>          À la sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension
!>                                   (N) si SIDE = 'L',
!!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO est INTEGER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
