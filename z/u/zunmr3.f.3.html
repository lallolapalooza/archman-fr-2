sous-routine zunmr3 (caractère side, caractère trans, entier m, entier n, entier k, entier l, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) tau, complexe*16, dimension( ldc, * ) c, entier ldc, complexe*16, dimension( * ) work, entier info)

ZUNMR3 multiplie une matrice générale par la matrice unitaire issue d'une factorisation RZ déterminée par ctzrzf (algorithme non bloqué).

Objectif :

!>
!> ZUNMR3 écrase la matrice générale complexe m par n C avec
!>
!>       Q * C  si SIDE = 'L' et TRANS = 'N', ou
!>
!>       Q**H* C  si SIDE = 'L' et TRANS = 'C', ou
!>
!>       C * Q  si SIDE = 'R' et TRANS = 'N', ou
!>
!>       C * Q**H si SIDE = 'R' et TRANS = 'C',
!>
!> où Q est une matrice unitaire complexe définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> tel que retourné par ZTZRZF. Q est d'ordre m si SIDE = 'L' et d'ordre n
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CARACTERE*1
!>          = 'L': appliquer Q ou Q**H depuis la Gauche
!>          = 'R': appliquer Q ou Q**H depuis la Droite
!>

TRANS

!>          TRANS est CARACTERE*1
!>          = 'N': appliquer Q  (Pas de transposée)
!>          = 'C': appliquer Q**H (Transposée conjuguée)
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

L

!>          L est ENTIER
!>          Le nombre de colonnes de la matrice A contenant
!>          la partie significative des réflecteurs de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

A

!>          A est tableau COMPLEX*16, dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ème ligne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          ZTZRZF dans les k dernières lignes de son argument tableau A.
!>          A est modifié par la routine mais restauré à la sortie.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

TAU

!>          TAU est tableau COMPLEX*16, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par ZTZRZF.
!>

C

!>          C est tableau COMPLEX*16, dimension (LDC,N)
!>          À l'entrée, la matrice C de taille m par n.
!>          À la sortie, C est écrasée par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est ENTIER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est tableau COMPLEX*16, dimension
!>                                   (N) si SIDE = 'L',
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO est ENTIER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
