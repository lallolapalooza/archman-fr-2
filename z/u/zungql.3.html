ZUNGQL

Documentation de la fonction/sous-programme

sous-programme zungql (integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, integer info)

ZUNGQL

Objectif :

!>
!> ZUNGQL génère une matrice complexe Q de taille M par N avec des colonnes
!> orthonormales, définie comme les N dernières colonnes d'un produit de K
!> réflecteurs élémentaires d'ordre M
!>
!>       Q  =  H(k) . . . H(2) H(1)
!>
!> tels que retournés par ZGEQLF.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice Q. M >= N >= 0.
!>

K

!>          K est un entier (INTEGER)
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. N >= K >= 0.
!>

A

!>          A est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, la (n-k+i)-ème colonne doit contenir le vecteur qui
!>          définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel
!>          que retourné par ZGEQLF dans les k dernières colonnes de son tableau
!>          argument A.
!>          À la sortie, la matrice Q de taille M par N.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau de type COMPLEX*16, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par ZGEQLF.
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>          Pour des performances optimales, LWORK >= N*NB, où NB est la
!>          taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule uniquement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK, et aucun
!>          message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument a une valeur illégale
!>
