Documentation de la fonction de sous routine

sous routine zunbdb3 (integer m, integer p, integer q, complex*16, dimension(ldx11,*) x11, integer ldx11, complex*16, dimension(ldx21,*) x21, integer ldx21, double precision, dimension(*) theta, double precision, dimension(*) phi, complex*16, dimension(*) taup1, complex*16, dimension(*) taup2, complex*16, dimension(*) tauq1, complex*16, dimension(*) work, integer lwork, integer info)

ZUNBDB3

Objectif :

!>
!> ZUNBDB3 bidiagonalise simultanément les blocs d'une matrice X mince et haute
!> avec des colonnes orthonormales :
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 est PxQ, et X21 est (M-P)xQ. M-P doit être inférieur ou égal à P,
!> Q, ou M-Q. Les routines ZUNBDB1, ZUNBDB2 et ZUNBDB4 gèrent les cas
!> où M-P n'est pas la dimension minimale.
!>
!> Les matrices unitaires P1, P2 et Q1 sont respectivement PxP, (M-P)x(M-P)
!> et (M-Q)x(M-Q). Elles sont représentées implicitement par des
!> vecteurs de Householder.
!>
!> B11 et B12 sont des matrices bidiagonales (M-P)x(M-P) représentées
!> implicitement par les angles THETA, PHI.
!>
!>

Paramètres

M 
!>          M est un entier
!>           Le nombre de lignes de X11 plus le nombre de lignes de X21.
!>

P

!>          P est un entier
!>           Le nombre de lignes de X11. 0 <= P <= M. M-P <= min(P,Q,M-Q).
!>

Q

!>          Q est un entier
!>           Le nombre de colonnes de X11 et X21. 0 <= Q <= M.
!>

X11

!>          X11 est un tableau COMPLEX*16, de dimension (LDX11,Q)
!>           À l'entrée, le bloc supérieur de la matrice X à réduire. À
!>           la sortie, les colonnes de tril(X11) spécifient les réflecteurs pour P1 et
!>           les lignes de triu(X11,1) spécifient les réflecteurs pour Q1.
!>

LDX11

!>          LDX11 est un entier
!>           La dimension principale de X11. LDX11 >= P.
!>

X21

!>          X21 est un tableau COMPLEX*16, de dimension (LDX21,Q)
!>           À l'entrée, le bloc inférieur de la matrice X à réduire. À
!>           la sortie, les colonnes de tril(X21) spécifient les réflecteurs pour P2.
!>

LDX21

!>          LDX21 est un entier
!>           La dimension principale de X21. LDX21 >= M-P.
!>

THETA

!>          THETA est un tableau DOUBLE PRECISION, de dimension (Q)
!>           Les entrées des blocs bidiagonaux B11, B21 sont définies par
!>           THETA et PHI. Voir Détails supplémentaires.
!>

PHI

!>          PHI est un tableau DOUBLE PRECISION, de dimension (Q-1)
!>           Les entrées des blocs bidiagonaux B11, B21 sont définies par
!>           THETA et PHI. Voir Détails supplémentaires.
!>

TAUP1

!>          TAUP1 est un tableau COMPLEX*16, de dimension (P)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           P1.
!>

TAUP2

!>          TAUP2 est un tableau COMPLEX*16, de dimension (M-P)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           P2.
!>

TAUQ1

!>          TAUQ1 est un tableau COMPLEX*16, de dimension (Q)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           Q1.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>           La dimension du tableau WORK. LWORK >= M-Q.
!>
!>           Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>           calcule uniquement la taille optimale du tableau WORK, renvoie
!>           cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>           relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un entier
!>           = 0 : sortie réussie.
!>           < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires :

!>
!>  Les blocs supérieurs bidiagonaux B11, B21 sont représentés implicitement par
!>  les angles THETA(1), ..., THETA(Q) et PHI(1), ..., PHI(Q-1). Chaque entrée
!>  de chaque bande bidiagonale est un produit d'un sinus ou d'un cosinus d'un THETA
!>  avec un sinus ou un cosinus d'un PHI. Voir [1] ou ZUNCSD pour les détails.
!>
!>  P1, P2 et Q1 sont représentés comme des produits de réflecteurs élémentaires.
!>  Voir ZUNCSD2BY1 pour les détails sur la génération de P1, P2 et Q1 en utilisant ZUNGQR
!>  et ZUNGLQ.
!>

Références :

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
