Documentation de la fonction/sous-routine

sous-routine zunhr_col (integer m, integer n, integer nb, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( * ) d, integer info)

ZUNHR_COL

Purpose:

!>
!>  ZUNHR_COL prend en entrée une matrice complexe M par N, Q_in, avec des colonnes
!>  orthonormales, stockée dans A, et effectue une Reconstruction de Householder (HR),
!>  c'est-à-dire qu'elle reconstruit des vecteurs de Householder V(i) représentant implicitement
!>  une autre matrice M par N, Q_out, telle que Q_in = Q_out*S, où S est une matrice diagonale
!>  N par N avec des entrées diagonales égales à +1 ou -1. Les vecteurs de Householder
!>  (colonnes V(i) de V) sont stockés dans A en sortie, et les entrées diagonales de S sont stockées dans D.
!>  Les réflecteurs de bloc sont également retournés dans T
!>  (même format de sortie que ZGEQRT).
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

NB

!>          NB est un entier (INTEGER)
!>          La taille de bloc de colonnes à utiliser dans la reconstruction
!>          des blocs de vecteurs de colonnes de Householder dans le tableau A
!>          et des réflecteurs de bloc correspondants dans le tableau T. NB >= 1.
!>          (Notez que si NB > N, alors N est utilisé à la place de NB
!>          comme taille de bloc de colonnes.)
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>
!>          En entrée :
!>
!>             Le tableau A contient une matrice orthonormée Q_in de taille M par N,
!>             c'est-à-dire que les colonnes de A sont des vecteurs unitaires orthogonaux.
!>
!>          En sortie :
!>
!>             Les éléments sous la diagonale de A représentent la matrice
!>             unit lower-trapezoidal V des vecteurs de colonnes de Householder
!>             V(i). Les entrées unitaires diagonales de V ne sont pas stockées
!>             (même format que la sortie sous la diagonale dans A de ZGEQRT).
!>             La matrice T et la matrice V stockées en sortie dans A définissent implicitement Q_out.
!>
!>             Les éléments au-dessus de la diagonale contiennent le facteur U
!>             de la décomposition LU :
!>                Q_in - ( S ) = V * U
!>                       ( 0 )
!>             où 0 est une matrice nulle (M-N) par (M-N).
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

T

!>          T est un tableau COMPLEX*16,
!>          dimension (LDT, N)
!>
!>          Soit NOCB = Nombre_de_blocs_de_colonnes_en_sortie
!>                   = CEIL(N/NB)
!>
!>          En sortie, T(1:NB, 1:N) contient NOCB réflecteurs de bloc triangulaires supérieurs
!>          utilisés pour définir Q_out, stockés sous forme compacte comme une séquence
!>          de blocs de colonnes NBxNB triangulaires supérieurs (même format que la sortie T dans ZGEQRT).
!>          La matrice T et la matrice V stockées en sortie dans A définissent implicitement Q_out.
!>          NOTE : Les triangles inférieurs sous les blocs triangulaires supérieurs seront remplis de zéros. Voir Détails supplémentaires.
!>

LDT

!>          LDT est un entier (INTEGER)
!>          La dimension principale du tableau T.
!>          LDT >= max(1,min(NB,N)).
!>

D

!>          D est un tableau COMPLEX*16, dimension min(M,N).
!>          Les éléments peuvent être seulement plus ou moins un.
!>
!>          D(i) est construit comme D(i) = -SIGN(Q_in_i(i,i)), où
!>          1 <= i <= min(M,N), et Q_in_i est Q_in après avoir effectué
!>          i-1 étapes d'élimination gaussienne "modifiée".
!>          Voir Détails supplémentaires.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires:

!>
!> Le facteur unitaire M par M calculé Q_out est défini implicitement comme
!> un produit de matrices unitaires Q_out(i). Chaque Q_out(i) est stockée
!> dans le format de représentation WY compact dans les blocs correspondants des
!> matrices V (stockée dans A) et T.
!>
!> La matrice unit lower-trapezoidal V de taille M par N stockée dans la
!> matrice A de taille M par N contient les vecteurs colonnes V(i) en blocs
!> de taille NB, notés VB(j). Par exemple, VB(1) contient les colonnes
!> V(1), V(2), ... V(NB). NOTE : Les entrées unitaires sur la diagonale de V
!> ne sont pas stockées dans A.
!>
!> Le nombre de blocs de colonnes est
!>
!>     NOCB = Nombre_de_blocs_de_colonnes_en_sortie = CEIL(N/NB)
!>
!> où chaque bloc est de taille NB sauf le dernier, dont la taille est
!> LAST_NB = N - (NOCB-1)*NB.
!>
!> Par exemple, si M=6, N=5 et NB=2, la matrice V est
!>
!>
!>     V = (    VB(1),   VB(2), VB(3) ) =
!>
!>       = (   1                      )
!>         ( v21    1                 )
!>         ( v31  v32    1            )
!>         ( v41  v42  v43   1        )
!>         ( v51  v52  v53  v54    1  )
!>         ( v61  v62  v63  v54   v65 )
!>
!>
!> Pour chacun des blocs de colonnes VB(i), un réflecteur de bloc triangulaire
!> supérieur TB(i) est calculé. Ces blocs sont stockés comme
!> une séquence de blocs de colonnes triangulaires supérieurs dans la matrice T
!> de taille NB par N. La taille de chaque bloc TB(i) est NB par NB, sauf
!> pour le dernier bloc, dont la taille est LAST_NB par LAST_NB.
!>
!> Par exemple, si M=6, N=5 et NB=2, la matrice T est
!>
!>     T  = (    TB(1),    TB(2), TB(3) ) =
!>
!>        = ( t11  t12  t13  t14   t15  )
!>          (      t22       t24        )
!>
!>
!> Le facteur M par M Q_out est donné comme un produit de NOCB
!> matrices unitaires M par M, Q_out(i).
!>
!>     Q_out = Q_out(1) * Q_out(2) * ... * Q_out(NOCB),
!>
!> où chaque matrice Q_out(i) est donnée par la représentation WY
!> en utilisant les blocs correspondants des matrices V et T :
!>
!>     Q_out(i) = I - VB(i) * TB(i) * (VB(i))**T,
!>
!> où I est la matrice identité. Voici la formule avec les dimensions des matrices :
!>
!>  Q(i){M-par-M} = I{M-par-M} -
!>    VB(i){M-par-INB} * TB(i){INB-par-INB} * (VB(i))**T {INB-par-M},
!>
!> où INB = NB, sauf pour le dernier bloc NOCB
!> pour lequel INB=LAST_NB.
!>
!> =====
!> NOTE :
!> =====
!>
!> Si Q_in est le résultat d'une factorisation QR
!> B = Q_in * R_in, alors :
!>
!> B = (Q_out*S) * R_in = Q_out * (S * R_in) = Q_out * R_out.
!>
!> Donc, si l'on souhaite interpréter Q_out comme le résultat
!> de la factorisation QR de B, alors le R_out correspondant
!> doit être égal à R_out = S * R_in, c'est-à-dire que certaines lignes de R_in
!> doivent être multipliées par -1.
!>
!> Pour les détails de l'algorithme, voir [1].
!>
!> [1] ,
!>     G. Ballard, J. Demmel, L. Grigori, M. Jacquelin, H.D. Nguyen,
!>     E. Solomonik, J. Parallel Distrib. Comput.,
!>     vol. 85, pp. 3-31, 2015.
!>

SYNTAXE

SUBROUTINE ZUNHR_COL( K1, K2, A, LDA, TAU, C, LDC )

Documentation de la fonction/sous-routine

ZUNHR_COL effectue l'opération suivante : 

A = SUB( Q ) * C

où Q est une matrice unitaire définie par les appels aux routines de réduction de Householder produits par ZGEHRD, ZHEHRD ou ZHPTRD sur les sous-matrices de A .

Arguments :

K1
(input) INTEGER

Indique les colonnes des sous-matrices de la transformation de Householder qui sont appliquées à C. K1 et K2 sont utilisés pour spécifier un bloc de colonnes de A. K1 et K2 sont les indices des premières et dernières colonnes de A respectivement, à l'intérieur desquelles les transformations sont appliquées. K1 et K2 sont à spécifier de manière à ce que 1 <= K1 <= K2 <= N.

K2
(input) INTEGER

Idem que K1.

A
(input) COMPLEX*16 array, dimension (LDA, N)

Sur l'entrée, A contient les facteurs de transformation de Householder définis par les routines de réduction de la bande. Sur la sortie, le bloc de colonnes spécifié par K1 et K2 est écrasé par le produit SUB( Q ) * C.

LDA
(input) INTEGER

Le premier indice de A. LDA est au moins MAX( 1, K ).

TAU
(input) COMPLEX*16 array, dimension (N-1)

La constante du scalaire des transformations de Householder. Chaque élément de TAU est un scalaire de Householder. TAU est calculé par les routines de réduction de la bande.

C
(input) COMPLEX*16 array, dimension (LDC, N)

Sur l'entrée, C contient la matrice à transformer. Sur la sortie, le bloc de colonnes spécifié par K1 et K2 est écrasé par le produit SUB( Q ) * C.

LDC
(input) INTEGER

Le premier indice de C. LDC est au moins MAX( 1, N ).

Paramètres : K1, K2, A, LDA, TAU, C, LDC

A est un tableau COMPLEX*16 de dimension (LDA, N). Sur l'entrée, A contient les facteurs de transformation de Householder définis par les routines de réduction de la bande. Sur la sortie, le bloc de colonnes spécifié par K1 et K2 est écrasé par le produit SUB( Q ) * C.

LDA est un entier. Le premier indice de A. LDA est au moins MAX( 1, K ).

TAU est un tableau COMPLEX*16 de dimension (N-1). La constante du scalaire des transformations de Householder. Chaque élément de TAU est un scalaire de Householder. TAU est calculé par les routines de réduction de la bande.

C est un tableau COMPLEX*16 de dimension (LDC, N). Sur l'entrée, C contient la matrice à transformer. Sur la sortie, le bloc de colonnes spécifié par K1 et K2 est écrasé par le produit SUB( Q ) * C.

LDC est un entier. Le premier indice de C. LDC est au moins MAX( 1, N ).
