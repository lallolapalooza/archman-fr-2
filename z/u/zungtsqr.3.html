Documentation de la fonction/sous-programme

sous-routine zungtsqr (integer m, integer n, integer mb, integer nb, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( * ) work, integer lwork, integer info)

ZUNGTSQR

But:

!>
!> ZUNGTSQR génère une matrice complexe M par N, Q_out, avec des colonnes
!> orthonormales, qui sont les N premières colonnes d'un produit de matrices
!> unitaires complexes d'ordre M renvoyées par ZLATSQR.
!>
!>      Q_out = premières_N_colonnes( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> Voir la documentation de ZLATSQR.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

MB

!>          MB est un entier (INTEGER)
!>          La taille du bloc de lignes utilisé par ZLATSQR pour renvoyer
!>          les tableaux A et T. MB > N.
!>          (Notez que si MB > M, alors M est utilisé à la place de MB
!>          comme taille du bloc de lignes).
!>

NB

!>          NB est un entier (INTEGER)
!>          La taille du bloc de colonnes utilisé par ZLATSQR pour renvoyer
!>          les tableaux A et T. NB >= 1.
!>          (Notez que si NB > N, alors N est utilisé à la place de NB
!>          comme taille du bloc de colonnes).
!>

A

!>          A est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>
!>          En entrée :
!>
!>             Les éléments sur et au-dessus de la diagonale ne sont pas accédés.
!>             Les éléments en dessous de la diagonale représentent la matrice
!>             en trapèze inférieure bloquée unitaire V calculée par ZLATSQR
!>             qui définit les matrices d'entrée Q_in(k) (les uns sur la
!>             diagonale ne sont pas stockés) (même format que la sortie A
!>             en dessous de la diagonale dans ZLATSQR).
!>
!>          En sortie :
!>
!>             Le tableau A contient une matrice orthonormée M par N, Q_out,
!>             c'est-à-dire que les colonnes de A sont des vecteurs unitaires orthogonaux.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

T

!>          T est un tableau de type COMPLEX*16,
!>          de dimension (LDT, N * NIRB)
!>          où NIRB = Nombre_de_blocs_de_lignes_en_entrée
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Soit NICB = Nombre_de_blocs_de_colonnes_en_entrée
!>                   = CEIL(N/NB)
!>
!>          Les réflecteurs de blocs triangulaires supérieurs utilisés pour définir les
!>          matrices d'entrée Q_in(k), k=(1:NIRB*NICB). Les réflecteurs de blocs
!>          sont stockés sous forme compacte dans NIRB séquences de réflecteurs de blocs.
!>          Chacune des NIRB séquences de réflecteurs de blocs est stockée dans un bloc
!>          de colonne T de taille NB par N et consiste en NICB plus petits blocs de
!>          taille NB par NB triangulaires supérieurs.
!>          (même format que la sortie T dans ZLATSQR).
!>

LDT

!>          LDT est un entier (INTEGER)
!>          La dimension principale du tableau T.
!>          LDT >= max(1,min(NB1,N)).
!>

WORK

!>          (espace de travail) Tableau de type COMPLEX*16, de dimension (MAX(2,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie la valeur LWORK optimale.
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La dimension du tableau WORK. LWORK >= (M+NB)*N.
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée.
!>          La routine calcule uniquement la taille optimale du tableau WORK,
!>          renvoie cette valeur dans la première entrée du tableau WORK,
!>          et aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale
!>
