sous-programme zunbdb3 (entier m, entier p, entier q, complexe*16, dimension(ldx11,*) x11, entier ldx11, complexe*16, dimension(ldx21,*) x21, entier ldx21, double précision, dimension(*) theta, double précision, dimension(*) phi, complexe*16, dimension(*) taup1, complexe*16, dimension(*) taup2, complexe*16, dimension(*) tauq1, complexe*16, dimension(*) work, entier lwork, entier info)

ZUNBDB3

But:

!>
!> ZUNBDB3 bidiagonalise simultanément les blocs d'une matrice X haute et mince
!> avec des colonnes orthonormées :
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 est de taille P par Q, et X21 est de taille (M-P) par Q. M-P doit être
!> inférieur ou égal à P, Q, ou M-Q. Les routines ZUNBDB1, ZUNBDB2 et ZUNBDB4
!> gèrent les cas où M-P n'est pas la dimension minimale.
!>
!> Les matrices unitaires P1, P2 et Q1 sont respectivement de taille P par P,
!> (M-P) par (M-P) et (M-Q) par (M-Q). Elles sont représentées implicitement par
!> des vecteurs de Householder.
!>
!> B11 et B21 sont des matrices bidiagonales (M-P) par (M-P) représentées
!> implicitement par les angles THETA, PHI.
!>
!>

Paramètres

M 
!>          M est ENTIER
!>           Le nombre de lignes de X11 plus le nombre de lignes de X21.
!>

P

!>          P est ENTIER
!>           Le nombre de lignes de X11. 0 <= P <= M. M-P <= min(P,Q,M-Q).
!>

Q

!>          Q est ENTIER
!>           Le nombre de colonnes de X11 et X21. 0 <= Q <= M.
!>

X11

!>          X11 est un tableau COMPLEX*16, dimension (LDX11,Q)
!>           En entrée, le bloc supérieur de la matrice X à réduire. En
!>           sortie, les colonnes de tril(X11) spécifient les réflecteurs
!>           pour P1 et les lignes de triu(X11,1) spécifient les réflecteurs
!>           pour Q1.
!>

LDX11

!>          LDX11 est ENTIER
!>           La dimension principale de X11. LDX11 >= P.
!>

X21

!>          X21 est un tableau COMPLEX*16, dimension (LDX21,Q)
!>           En entrée, le bloc inférieur de la matrice X à réduire. En
!>           sortie, les colonnes de tril(X21) spécifient les réflecteurs
!>           pour P2.
!>

LDX21

!>          LDX21 est ENTIER
!>           La dimension principale de X21. LDX21 >= M-P.
!>

THETA

!>          THETA est un tableau DOUBLE PRÉCISION, dimension (Q)
!>           Les entrées des blocs bidiagonaux B11, B21 sont définies par
!>           THETA et PHI. Voir Détails supplémentaires.
!>

PHI

!>          PHI est un tableau DOUBLE PRÉCISION, dimension (Q-1)
!>           Les entrées des blocs bidiagonaux B11, B21 sont définies par
!>           THETA et PHI. Voir Détails supplémentaires.
!>

TAUP1

!>          TAUP1 est un tableau COMPLEX*16, dimension (P)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           P1.
!>

TAUP2

!>          TAUP2 est un tableau COMPLEX*16, dimension (M-P)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           P2.
!>

TAUQ1

!>          TAUQ1 est un tableau COMPLEX*16, dimension (Q)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           Q1.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est ENTIER
!>           La dimension du tableau WORK. LWORK >= M-Q.
!>
!>           Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>           la routine calcule uniquement la taille optimale du tableau WORK,
!>           retourne cette valeur comme première entrée du tableau WORK, et
!>           aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>           = 0:  réussite.
!>           < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires:

!>
!> Les blocs supérieurs bidiagonaux B11, B21 sont représentés implicitement par
!> les angles THETA(1), ..., THETA(Q) et PHI(1), ..., PHI(Q-1). Chaque entrée
!> de chaque bande bidiagonale est un produit d'un sinus ou cosinus d'un THETA
!> avec un sinus ou cosinus d'un PHI. Voir [1] ou ZUNCSD pour les détails.
!>
!> P1, P2 et Q1 sont représentés comme des produits de réflecteurs élémentaires.
!> Voir ZUNCSD2BY1 pour les détails sur la génération de P1, P2 et Q1 en utilisant
!> ZUNGQR et ZUNGLQ.
!>

Références:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
