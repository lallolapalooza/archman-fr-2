Documentation de la fonction/sous-programme

sous-programme zunmhr (caractère side, caractère trans, entier m, entier n, entier ilo, entier ihi, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) tau, complexe*16, dimension( ldc, * ) c, entier ldc, complexe*16, dimension( * ) work, entier lwork, entier info)

ZUNMHR

Purpose:

!>
!> ZUNMHR écrase la matrice complexe générale M par N, C, avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> où Q est une matrice unitaire complexe d'ordre nq, avec nq = m si
!> SIDE = 'L' et nq = n si SIDE = 'R'. Q est définie comme le produit de
!> IHI-ILO réflexions élémentaires, tel que retourné par ZGEHRD :
!>
!> Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**H à gauche ;
!>          = 'R': appliquer Q ou Q**H à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': appliquer Q (Pas de transposée)
!>          = 'C': appliquer Q**H (Conjuguée transposée)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

ILO

!>          ILO est INTEGER
!>

IHI

!>          IHI est INTEGER
!>
!>          ILO et IHI doivent avoir les mêmes valeurs que lors de l'appel
!>          précédent à ZGEHRD. Q est égale à la matrice unité sauf dans la
!>          sous-matrice Q(ilo+1:ihi,ilo+1:ihi).
!>          Si SIDE = 'L', alors 1 <= ILO <= IHI <= M, si M > 0, et
!>          ILO = 1 et IHI = 0, si M = 0 ;
!>          si SIDE = 'R', alors 1 <= ILO <= IHI <= N, si N > 0, et
!>          ILO = 1 et IHI = 0, si N = 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension
!>                               (LDA,M) si SIDE = 'L'
!>                               (LDA,N) si SIDE = 'R'
!>          Les vecteurs qui définissent les réflexions élémentaires, tels que
!>          retournés par ZGEHRD.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          LDA >= max(1,M) si SIDE = 'L' ; LDA >= max(1,N) si SIDE = 'R'.
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension
!>                               (M-1) si SIDE = 'L'
!>                               (N-1) si SIDE = 'R'
!>          TAU(i) doit contenir le facteur scalaire de la réflexion
!>          élémentaire H(i), tel que retourné par ZGEHRD.
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC,N)
!>          À l'entrée, la matrice C de taille M par N.
!>          À la sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur LWORK
!>          optimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N) ;
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Pour une performance optimale, LWORK >= N*NB si SIDE = 'L', et
!>          LWORK >= M*NB si SIDE = 'R', où NB est la taille de bloc
!>          optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule seulement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK, et
!>          aucun message d'erreur relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
