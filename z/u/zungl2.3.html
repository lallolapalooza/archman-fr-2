Documentation de la fonction/sous-routine

sous-routine zungl2 (integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer info)

ZUNGL2 génère tout ou partie de la matrice unitaire Q à partir d'une factorisation LQ déterminée par cgelqf (algorithme non bloqué).

Objectif:

!>
!> ZUNGL2 génère une matrice complexe m-par-n Q avec des lignes orthonormées,
!> qui est définie comme les m premières lignes d'un produit de k réflecteurs
!> élémentaires d'ordre n
!>
!>       Q  =  H(k)**H . . . H(2)**H H(1)**H
!>
!> comme retourné par ZGELQF.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q. N >= M.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. M >= K >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la i-ème ligne doit contenir le vecteur qui définit
!>          le réflecteur élémentaire H(i), pour i = 1,2,...,k, comme retourné
!>          par ZGELQF dans les k premières lignes de son tableau argument A.
!>          À la sortie, la matrice m par n Q.
!>

LDA

!>          LDA est un ENTIER
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), comme retourné par ZGELQF.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (M)
!>

INFO

!>          INFO est un ENTIER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument a une valeur illégale
!>
