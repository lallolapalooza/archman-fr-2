sous-programme zungbr (caractère vect, entier m, entier n, entier k, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) tau, complexe*16, dimension( * ) work, entier lwork, entier info)

ZUNGBR

But :

!>
!> ZUNGBR génère l'une des matrices unitaires complexes Q ou P**H
!> déterminées par ZGEBRD lors de la réduction d'une matrice complexe A
!> en forme bidiagonale : A = Q * B * P**H. Q et P**H sont définies comme
!> des produits de réflecteurs élémentaires H(i) ou G(i) respectivement.
!>
!> Si VECT = 'Q', A est supposée avoir été une matrice M x K, et Q
!> est d'ordre M :
!> si m >= k, Q = H(1) H(2) . . . H(k) et ZUNGBR retourne les n premières
!> colonnes de Q, où m >= n >= k ;
!> si m < k, Q = H(1) H(2) . . . H(m-1) et ZUNGBR retourne Q comme une
!> matrice M x M.
!>
!> Si VECT = 'P', A est supposée avoir été une matrice K x N, et P**H
!> est d'ordre N :
!> si k < n, P**H = G(k) . . . G(2) G(1) et ZUNGBR retourne les m premières
!> lignes de P**H, où n >= m >= k ;
!> si k >= n, P**H = G(n-1) . . . G(2) G(1) et ZUNGBR retourne P**H comme
!> une matrice N x N.
!>

Paramètres

VECT 
!>          VECT est CHARACTER*1
!>          Spécifie si la matrice Q ou la matrice P**H est
!>          requise, telle que définie dans la transformation appliquée par ZGEBRD :
!>          = 'Q' : générer Q ;
!>          = 'P' : générer P**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice Q ou P**H à retourner.
!>          M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice Q ou P**H à retourner.
!>          N >= 0.
!>          Si VECT = 'Q', M >= N >= min(M,K) ;
!>          si VECT = 'P', N >= M >= min(N,K).
!>

K

!>          K est INTEGER
!>          Si VECT = 'Q', le nombre de colonnes dans la matrice originale M x K
!>          réduite par ZGEBRD.
!>          Si VECT = 'P', le nombre de lignes dans la matrice originale K x N
!>          réduite par ZGEBRD.
!>          K >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, les vecteurs qui définissent les réflecteurs élémentaires,
!>          tels que retournés par ZGEBRD.
!>          À la sortie, la matrice M x N, Q ou P**H.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= M.
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension
!>                                (min(M,K)) si VECT = 'Q'
!>                                (min(N,K)) si VECT = 'P'
!>          TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire
!>          H(i) ou G(i), qui détermine Q ou P**H, tel que
!>          retourné par ZGEBRD dans son tableau argument TAUQ ou TAUP.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,min(M,N)).
!>          Pour des performances optimales, LWORK >= min(M,N)*NB, où NB
!>          est la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
