Documentation Fonction/Sous routine

sous_routine zunghr (entier n, entier ilo, entier ihi, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) tau, complexe*16, dimension( * ) work, entier lwork, entier info)

ZUNGHR

Objectif :

!>
!> ZUNGHR génère une matrice unitaire complexe Q qui est définie comme le
!> produit de IHI-ILO réflecteurs élémentaires d'ordre N, tels que retournés par
!> ZGEHRD :
!>
!> Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice Q. N >= 0.
!>

ILO

!>          ILO est ENTIER
!>

IHI

!>          IHI est ENTIER
!>
!>          ILO et IHI doivent avoir les mêmes valeurs que lors de l'appel
!>          précédent de ZGEHRD. Q est égale à la matrice unité sauf dans la
!>          sous-matrice Q(ilo+1:ihi,ilo+1:ihi).
!>          1 <= ILO <= IHI <= N, si N > 0 ; ILO=1 et IHI=0, si N=0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, les vecteurs qui définissent les réflecteurs élémentaires,
!>          tels que retournés par ZGEHRD.
!>          À la sortie, la matrice unitaire N-par-N Q.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau COMPLEX*16, de dimension (N-1)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire
!>          H(i), tel que retourné par ZGEHRD.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK. LWORK >= IHI-ILO.
!>          Pour des performances optimales, LWORK >= (IHI-ILO)*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
