!> !> ZUNHR_COL prend en entrée une matrice complexe Q_in de taille M par N !> à colonnes orthonormées, stockée dans A, et effectue une reconstruction !> de Householder (HR), c'est-à-dire reconstruit les vecteurs de !> Householder V(i) représentant implicitement une autre matrice Q_out !> de taille M par N, avec la propriété que Q_in = Q_out*S, !> où S est une matrice diagonale de taille N par N dont les éléments !> diagonaux sont égaux à +1 ou -1. Les vecteurs de Householder !> (les colonnes V(i) de V) sont stockés dans A en sortie, et les !> éléments diagonaux de S sont stockés dans D. !> Les réflecteurs de

blocs sont également renvoyés dans T !> (même format de sortie que ZGEQRT). !>

de colonnes de la matrice A. M >= N >= 0.
!>

!>          NB est INTEGER
!>          La taille de bloc de colonnes à utiliser dans la
!>          reconstruction des blocs de vecteurs de colonnes de
!>          Householder dans le tableau A et les réflecteurs de blocs
!>          correspondants dans le tableau T.
 NB >= 1.
!>          (Remarquez que si NB > N, alors N est utilisé à la place
!>          de NB comme taille de bloc de colonnes.)
!>

!>
!>          À l'entrée :
!>
!>             Le tableau A contient une matrice orthonormée Q_in de
!>             taille M par N, c'est-à-dire que les colonnes de A sont
!>             des vecteurs unitaires orthogonaux.
!>
!>          À la sortie :
!>
!>             Les éléments sous la diagonale de A représentent la
!>             matrice trapézoïdale inférieure unitaire V des vecteurs
!>             de colonnes de Householder V(i). Les éléments 
diagonaux
!>             unitaires de V ne sont pas stockés (même format que la
!>             sortie sous la diagonale dans A de ZGEQRT). La matrice T
!>             et la matrice V stockées en sortie dans A définissent
!>             implicitement Q_out.
!>
!>             Les éléments au-dessus de la diagonale contiennent le
!>             facteur U de la décomposition LU :
!>                Q_in - ( S ) = V * U
!>                       ( 0 )
!>             où 0 est une matrice nulle de taille (M-N) par (M-N).
!>

Détails 
supplémen
taires :

!>
!> Le facteur unitaire Q_out de taille M par M calculé est défini
!> implicitement comme un produit de matrices unitaires Q_out(i).
!> Chaque Q_out(i) est stockée dans le format de représentation WY
!> compacte dans les blocs correspondants des matrices V (stockée dans
!> A) et T.
!>
!> La matrice trapézoïdale inférieure unitaire V de taille M par N
!> stockée dans la matrice A de taille M par N contient les vecteurs
!> de colonnes V(i) en blocs de colonnes de taille NB nommés VB(j).
!> Par exemple, VB(1) contient les colonnes V(1), V(2), ... V(NB).
!> NOTE : Les éléments unitaires sur la diagonale de Y ne sont pas
!> stockés dans A.
!>
!> Le nombre de blocs de colonnes est
!>
!>     NOCB = Nombre_de_blocs_de_colonnes_en_sortie = CEIL(N/NB)
!>
!> où chaque bloc est d'ordre NB sauf le dernier bloc, qui est
!> d'ordre LAST_NB = N - (NOCB-1)*NB.
!>
!> Par exemple, si M=6,  N=5 et NB=2, la matrice V est
!>
!>
!>     V = (    VB(1),   VB(2), VB(3) ) =
!>
!>       = (   1                      )
!>         ( v21    1                 )
!>         ( v31  v32    1            )
!>         ( v41  v42  v43   1        )
!>         ( v51  v52  v53  v54    1  )
!>         ( v61  v62  v63  v54   v65 )
!>
!>
!> Pour chacun des blocs de colonnes VB(i), un réflecteur de bloc
!> triangulaire supérieur TB(i) est calculé. Ces blocs sont stockés
!> comme une séquence de blocs de colonnes triangulaires supérieurs
!> dans la matrice T de taille NB par N. La taille de chaque bloc
!> TB(i) est NB par NB, sauf pour le dernier bloc, dont la taille est
!> LAST_NB par LAST_NB.
!>
!> Par exemple, si M=6,  N=5 et NB=2, la matrice T est
!>
!>     T  = (    TB(1),    TB(2), TB(3) ) =
!>
!>        = ( t11  t12  t13  t14   t15  )
!>          (      t22       t24        )
!>
!>
!> Le facteur Q_out de taille M par M est donné comme un produit de
!> NOCB matrices unitaires Q_out(i) de taille M par M.
!>
!>     Q_out = Q_out(1) * Q_out(2) * ... * Q_out(NOCB),
!>
!> où chaque matrice Q_out(i) est donnée par la représentation WY
!> utilisant les blocs correspondants des matrices V et T :
!>
!>     Q_out(i) = I - VB(i) * TB(i) * (VB(i))**T,
!>
!> où I est la matrice identité. Voici la formule avec les dimensions
!> de la matrice :
!>
!>  Q(i){M par M} = I{M par M} -
!>    VB(i){M par INB} * TB(i){INB par INB} * (VB(i))**T {INB par M},
!>
!> où INB = NB, sauf pour le dernier bloc NOCB
!> pour lequel INB=LAST_NB.
!>
!> =====
!> NOTE :
!> =====
!>
!> Si Q_in est le résultat d'une factorisation QR
!> B = Q_in * R_in, alors :
!>
!> B = (Q_out*S) * R_in = Q_out * (S * R_in) = Q_out * R_out.
!>
!> Ainsi, si l'on souhaite interpréter Q_out comme le résultat de la
!> factorisation QR de B, alors le R_out correspondant devrait être
!> égal à R_out = S * R_in, c'est-à-dire que certaines lignes de R_in
!> devraient être multipliées par -1.
!>
!> Pour les détails de l'algorithme,
 voir [1].
!>
!> [1] ,
!>     G. Ballard, J. Demmel, L. Grigori, M. Jacquelin, H.D. Nguyen,
!>     E. Solomonik, J. Parallel Distrib. Comput.,
!>     vol. 85, pp. 3-31, 2015.
!>
