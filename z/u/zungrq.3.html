Documentation de la fonction/sous-programme

sous-programme zungrq (integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, integer info)

ZUNGRQ

Objectif :

!>
!> ZUNGRQ génère une matrice complexe M par N, Q, avec des lignes orthonormées,
!> qui est définie comme les M dernières lignes d'un produit de K réflecteurs
!> élémentaires d'ordre N
!>
!>       Q  =  H(1)**H H(2)**H . . . H(k)**H
!>
!> tel que retourné par ZGERQF.
!>

Paramètres :

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice Q. N >= M.
!>

K

!>          K est un entier
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. M >= K >= 0.
!>

A

!>          A est un tableau de nombres complexes*16, de dimension (LDA,N)
!>          À l'entrée, la (m-k+i)-ème ligne doit contenir le vecteur qui
!>          définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel
!>          que retourné par ZGERQF dans les k dernières lignes de son argument
!>          de tableau A.
!>          À la sortie, la matrice Q de taille M par N.
!>

LDA

!>          LDA est un entier
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau de nombres complexes*16, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par ZGERQF.
!>

WORK

!>          WORK est un tableau de nombres complexes*16, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un entier
!>          La dimension du tableau WORK. LWORK >= max(1,M).
!>          Pour des performances optimales, LWORK >= M*NB, où NB est la
!>          taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, alors le i-ème argument a une valeur illégale
!>
