Documentation de fonction/sous-routine

sous-routine zungtsqr (integer m, integer n, integer mb, integer nb, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( * ) work, integer lwork, integer info)

ZUNGTSQR

But:

!>
!> ZUNGTSQR génère une matrice complexe M par N, Q_out, avec des colonnes
!> orthonormées, qui sont les N premières colonnes d'un produit de matrices
!> unitaires complexes d'ordre M retournées par ZLATSQR
!>
!>      Q_out = premieres_N_colonnes_de( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> Voir la documentation de ZLATSQR.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

MB

!>          MB est un entier
!>          La taille du bloc de ligne utilisé par ZLATSQR pour retourner
!>          les tableaux A et T. MB > N.
!>          (Notez que si MB > M, alors M est utilisé à la place de MB
!>          comme taille du bloc de ligne).
!>

NB

!>          NB est un entier
!>          La taille du bloc de colonne utilisé par ZLATSQR pour retourner
!>          les tableaux A et T. NB >= 1.
!>          (Notez que si NB > N, alors N est utilisé à la place de NB
!>          comme taille du bloc de colonne).
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>
!>          À l'entrée :
!>
!>             Les éléments sur et au-dessus de la diagonale ne sont pas accédés.
!>             Les éléments en dessous de la diagonale représentent la matrice
!>             triangulaire inférieure bloquée V, calculée par ZLATSQR,
!>             qui définit les matrices d'entrée Q_in(k) (les uns sur la
!>             diagonale ne sont pas stockés) (même format que la sortie A
!>             en dessous de la diagonale dans ZLATSQR).
!>
!>          À la sortie :
!>
!>             Le tableau A contient une matrice orthonormée Q_out de taille M par N,
!>             c'est-à-dire que les colonnes de A sont des vecteurs unitaires orthogonaux.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

T

!>          T est un tableau COMPLEX*16,
!>          dimension (LDT, N * NIRB)
!>          où NIRB = Nombre_de_blocs_de_lignes_d_entrée
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Soit NICB = Nombre_de_blocs_de_colonnes_d_entrée
!>                   = CEIL(N/NB)
!>
!>          Les réflecteurs de blocs triangulaires supérieurs utilisés pour définir les
!>          matrices d'entrée Q_in(k), k=(1:NIRB*NICB). Les blocs
!>          réflecteurs sont stockés sous forme compacte dans NIRB séquences de blocs
!>          réflecteurs. Chacune des NIRB séquences de blocs réflecteurs
!>          est stockée dans un bloc de colonne T plus grand de taille NB par N et
!>          consiste en NICB petits blocs de colonne de taille NB par NB, triangulaires supérieurs.
!>          (même format que la sortie T dans ZLATSQR).
!>

LDT

!>          LDT est un entier
!>          La dimension principale du tableau T.
!>          LDT >= max(1,min(NB1,N)).
!>

WORK

!>          (espace de travail) tableau COMPLEX*16, dimension (MAX(2,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne LWORK optimal.
!>

LWORK

!>          LWORK est un entier
!>          La dimension du tableau WORK. LWORK >= (M+NB)*N.
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée.
!>          La routine calcule uniquement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK,
!>          et aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un entier
!>          = 0: succès de l'exécution
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
