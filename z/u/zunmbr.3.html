Documentation de la fonction/sous-programme

sous-programme zunmbr (character vect, character side, character trans, integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( * ) work, integer lwork, integer info)

ZUNMBR

But :

!>
!> Si VECT = 'Q', ZUNMBR écrase la matrice complexe générale M-par-N C par
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> Si VECT = 'P', ZUNMBR écrase la matrice complexe générale M-par-N C par
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      P * C          C * P
!> TRANS = 'C':      P**H * C       C * P**H
!>
!> Ici, Q et P**H sont les matrices unitaires déterminées par ZGEBRD lors de la
!> réduction d'une matrice complexe A en forme bidiagonale : A = Q * B * P**H.
!> Q et P**H sont définies comme des produits de réflecteurs élémentaires H(i) et
!> G(i) respectivement.
!>
!> Soit nq = m si SIDE = 'L' et nq = n si SIDE = 'R'. Ainsi, nq est l'ordre
!> de la matrice unitaire Q ou P**H qui est appliquée.
!>
!> Si VECT = 'Q', A est supposée avoir été une matrice NQ-par-K :
!> si nq >= k, Q = H(1) H(2) . . . H(k) ;
!> si nq < k, Q = H(1) H(2) . . . H(nq-1).
!>
!> Si VECT = 'P', A est supposée avoir été une matrice K-par-NQ :
!> si k < nq, P = G(1) G(2) . . . G(k) ;
!> si k >= nq, P = G(1) G(2) . . . G(nq-1).
!>

Paramètres

VECT 
!>          VECT est CHARACTER*1
!>          = 'Q' : appliquer Q ou Q**H ;
!>          = 'P' : appliquer P ou P**H.
!>

SIDE

!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer Q, Q**H, P ou P**H par la Gauche ;
!>          = 'R' : appliquer Q, Q**H, P ou P**H par la Droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : Pas de transposée, appliquer Q ou P ;
!>          = 'C' : Transposée conjuguée, appliquer Q**H ou P**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Si VECT = 'Q', le nombre de colonnes de la matrice
!>          originale réduite par ZGEBRD.
!>          Si VECT = 'P', le nombre de lignes de la matrice
!>          originale réduite par ZGEBRD.
!>          K >= 0.
!>

A

!>          A est tableau COMPLEX*16, dimension
!>                                (LDA,min(nq,K)) si VECT = 'Q'
!>                                (LDA,nq)        si VECT = 'P'
!>          Les vecteurs qui définissent les réflecteurs élémentaires H(i) et
!>          G(i), dont les produits déterminent les matrices Q et P, tels que
!>          retournés par ZGEBRD.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si VECT = 'Q', LDA >= max(1,nq) ;
!>          si VECT = 'P', LDA >= max(1,min(nq,K)).
!>

TAU

!>          TAU est tableau COMPLEX*16, dimension (min(nq,K))
!>          TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire
!>          H(i) ou G(i) qui détermine Q ou P, tel que retourné
!>          par ZGEBRD dans le paramètre tableau TAUQ ou TAUP.
!>

C

!>          C est tableau COMPLEX*16, dimension (LDC,N)
!>          En entrée, la matrice M-par-N C.
!>          En sortie, C est écrasée par Q*C ou Q**H*C ou C*Q**H ou C*Q
!>          ou P*C ou P**H*C ou C*P ou C*P**H.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N) ;
!>          si SIDE = 'R', LWORK >= max(1,M) ;
!>          si N = 0 ou M = 0, LWORK >= 1.
!>          Pour des performances optimales, LWORK >= max(1,N*NB) si SIDE = 'L',
!>          et LWORK >= max(1,M*NB) si SIDE = 'R', où NB est la
!>          taille de bloc optimale. (NB = 0 si M = 0 ou N = 0.)
!>
!>          Si LWORK = -1, alors une requête d'espace est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
