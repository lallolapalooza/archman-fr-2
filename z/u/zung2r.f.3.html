Documentation de la fonction/sous-routine

sous-routine zung2r (entier m, entier n, entier k, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) tau, complexe*16, dimension( * ) work, entier info)

ZUNG2R

But :

!>
!> ZUNG2R génère une matrice complexe m par n, Q, avec des colonnes orthonormées,
!> qui est définie comme les n premières colonnes d'un produit de k
!> réflecteurs élémentaires d'ordre m
!>
!>       Q  =  H(1) H(2) . . . H(k)
!>
!> tel que retourné par ZGEQRF.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q. M >= N >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires définissant la
!>          matrice Q. N >= K >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la i-ème colonne doit contenir le vecteur qui
!>          définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que
!>          retourné par ZGEQRF dans les k premières colonnes de son argument
!>          tableau A.
!>          À la sortie, la matrice Q de dimension m par n.
!>

LDA

!>          LDA est un ENTIER
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par ZGEQRF.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument a une valeur illégale
!>
