Documentation de la fonction/sous-programme

sous-programme zungrq (entier m, entier n, entier k, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) tau, complexe*16, dimension( * ) work, entier lwork, entier info)

ZUNGRQ

But :

!>
!> ZUNGRQ génère une matrice complexe M par N, Q, avec des lignes orthonormées,
!> qui est définie comme les M dernières lignes d'un produit de K réflecteurs élémentaires
!> d'ordre N
!>
!>       Q  =  H(1)**H H(2)**H . . . H(k)**H
!>
!> comme retourné par ZGERQF.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice Q. N >= M.
!>

K

!>          K est ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. M >= K >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, la (m-k+i)-ème ligne doit contenir le vecteur qui
!>          définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, comme
!>          retourné par ZGERQF dans les k dernières lignes de son argument
!>          tableau A.
!>          À la sortie, la matrice M par N, Q.
!>

LDA

!>          LDA est ENTIER
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEX*16, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), comme retourné par ZGERQF.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,M).
!>          Pour une performance optimale, LWORK >= M*NB, où NB est la
!>          taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument a une valeur illégale
!>
