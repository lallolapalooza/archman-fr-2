sous-programme zunmr2 (caractère side, caractère trans, entier m, entier n, entier k, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) tau, complexe*16, dimension( ldc, * ) c, entier ldc, complexe*16, dimension( * ) work, entier info)

ZUNMR2 multiplie une matrice générale par la matrice unitaire issue d'une factorisation RQ déterminée par cgerqf (algorithme non bloqué).

Objectif :

!>
!> ZUNMR2 écrase la matrice complexe générale m par n, C, avec
!>
!>       Q * C  si SIDE = 'L' et TRANS = 'N', ou
!>
!>       Q**H* C  si SIDE = 'L' et TRANS = 'C', ou
!>
!>       C * Q  si SIDE = 'R' et TRANS = 'N', ou
!>
!>       C * Q**H si SIDE = 'R' et TRANS = 'C',
!>
!> où Q est une matrice unitaire complexe définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(1)**H H(2)**H . . . H(k)**H
!>
!> tels que renvoyés par ZGERQF. Q est d'ordre m si SIDE = 'L' et d'ordre n
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': applique Q ou Q**H à Gauche
!>          = 'R': applique Q ou Q**H à Droite
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': applique Q  (Pas de trans.');
!>          = 'C': applique Q**H (Transconjuguée)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ème ligne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que renvoyé par
!>          ZGERQF dans les k dernières lignes de son tableau argument A.
!>          A est modifié par la routine mais restauré à la sortie.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

TAU

!>          TAU est un tableau COMPLEX*16, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que renvoyé par ZGERQF.
!>

C

!>          C est un tableau COMPLEX*16, de dimension (LDC,N)
!>          À l'entrée, la matrice C de taille m par n.
!>          À la sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension
!>                                   (N) si SIDE = 'L',
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
