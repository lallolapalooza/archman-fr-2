Documentation de la fonction/sous-programme

sous-programme zunbdb (caractère trans, caractère signs, entier m, entier p, entier q, complexe*16, dimension( ldx11, * ) x11, entier ldx11, complexe*16, dimension( ldx12, * ) x12, entier ldx12, complexe*16, dimension( ldx21, * ) x21, entier ldx21, complexe*16, dimension( ldx22, * ) x22, entier ldx22, double précision, dimension( * ) theta, double précision, dimension( * ) phi, complexe*16, dimension( * ) taup1, complexe*16, dimension( * ) taup2, complexe*16, dimension( * ) tauq1, complexe*16, dimension( * ) tauq2, complexe*16, dimension( * ) work, entier lwork, entier info)

ZUNBDB

But:

!>
!> ZUNBDB bidiagonalise simultanément les blocs d'une matrice unitaire M-par-M
!> X :
!>
!>                                 [ B11 | B12 0  0 ]
!>     [ X11 | X12 ]   [ P1 |    ] [  0  |  0 -I  0 ] [ Q1 |    ]**H
!> X = [-----------] = [---------] [----------------] [---------]   .
!>     [ X21 | X22 ]   [    | P2 ] [ B21 | B22 0  0 ] [    | Q2 ]
!>                                 [  0  |  0  0  I ]
!>
!> X11 est P-par-Q. Q ne doit pas être plus grand que P, M-P, ou M-Q. (Si ce
!> n'est pas le cas, alors X doit être transposé et/ou permuté. Cela peut être
!> fait en temps constant en utilisant les options TRANS et SIGNS. Voir ZUNCSD
!> pour les détails.)
!>
!> Les matrices unitaires P1, P2, Q1 et Q2 sont respectivement P-par-P,
!> (M-P)-par-(M-P), Q-par-Q et (M-Q)-par-(M-Q). Elles sont
!> représentées implicitement par des vecteurs de Householder.
!>
!> B11, B12, B21 et B22 sont des matrices bidiagonales Q-par-Q représentées
!> implicitement par les angles THETA, PHI.
!>

Paramètres

TRANS 
!>          TRANS est CARACTÈRE
!>          = 'T' :      X, U1, U2, V1T et V2T sont stockés en ordre ligne majeur;
!>          sinon :     X, U1, U2, V1T et V2T sont stockés en ordre colonne majeur.
!>

SIGNS

!>          SIGNS est CARACTÈRE
!>          = 'O' :      Le bloc inférieur gauche est rendu non positif (la
!>                       convention);
!>          sinon :     Le bloc supérieur droit est rendu non positif (la
!>                       convention).
!>

M

!>          M est ENTIER
!>          Le nombre de lignes et de colonnes de X.
!>

P

!>          P est ENTIER
!>          Le nombre de lignes de X11 et X12. 0 <= P <= M.
!>

Q

!>          Q est ENTIER
!>          Le nombre de colonnes de X11 et X21. 0 <= Q <=
!>          MIN(P,M-P,M-Q).
!>

X11

!>          X11 est tableau COMPLEX*16, dimension (LDX11,Q)
!>          À l'entrée, le bloc supérieur gauche de la matrice unitaire à réduire.
!>          À la sortie, la forme dépend de TRANS:
!>          Si TRANS = 'N', alors
!>             les colonnes de tril(X11) spécifient les réflecteurs pour P1,
!>             les lignes de triu(X11,1) spécifient les réflecteurs pour Q1;
!>          sinon TRANS = 'T', et
!>             les lignes de triu(X11) spécifient les réflecteurs pour P1,
!>             les colonnes de tril(X11,-1) spécifient les réflecteurs pour Q1.
!>

LDX11

!>          LDX11 est ENTIER
!>          La dimension principale de X11. Si TRANS = 'N', alors LDX11 >=
!>          P; sinon LDX11 >= Q.
!>

X12

!>          X12 est tableau COMPLEX*16, dimension (LDX12,M-Q)
!>          À l'entrée, le bloc supérieur droit de la matrice unitaire à
!>          réduire. À la sortie, la forme dépend de TRANS:
!>          Si TRANS = 'N', alors
!>             les lignes de triu(X12) spécifient les P premiers réflecteurs pour
!>             Q2;
!>          sinon TRANS = 'T', et
!>             les colonnes de tril(X12) spécifient les P premiers réflecteurs
!>             pour Q2.
!>

LDX12

!>          LDX12 est ENTIER
!>          La dimension principale de X12. Si TRANS = 'N', alors LDX12 >=
!>          P; sinon LDX11 >= M-Q.
!>

X21

!>          X21 est tableau COMPLEX*16, dimension (LDX21,Q)
!>          À l'entrée, le bloc inférieur gauche de la matrice unitaire à
!>          réduire. À la sortie, la forme dépend de TRANS:
!>          Si TRANS = 'N', alors
!>             les colonnes de tril(X21) spécifient les réflecteurs pour P2;
!>          sinon TRANS = 'T', et
!>             les lignes de triu(X21) spécifient les réflecteurs pour P2.
!>

LDX21

!>          LDX21 est ENTIER
!>          La dimension principale de X21. Si TRANS = 'N', alors LDX21 >=
!>          M-P; sinon LDX21 >= Q.
!>

X22

!>          X22 est tableau COMPLEX*16, dimension (LDX22,M-Q)
!>          À l'entrée, le bloc inférieur droit de la matrice unitaire à
!>          réduire. À la sortie, la forme dépend de TRANS:
!>          Si TRANS = 'N', alors
!>             les lignes de triu(X22(Q+1:M-P,P+1:M-Q)) spécifient les derniers
!>             M-P-Q réflecteurs pour Q2,
!>          sinon TRANS = 'T', et
!>             les colonnes de tril(X22(P+1:M-Q,Q+1:M-P)) spécifient les derniers
!>             M-P-Q réflecteurs pour P2.
!>

LDX22

!>          LDX22 est ENTIER
!>          La dimension principale de X22. Si TRANS = 'N', alors LDX22 >=
!>          M-P; sinon LDX22 >= M-Q.
!>

THETA

!>          THETA est tableau DOUBLE PRÉCISION, dimension (Q)
!>          Les éléments des blocs bidiagonaux B11, B12, B21, B22 peuvent
!>          être calculés à partir des angles THETA et PHI. Voir Détails supplémentaires.
!>

PHI

!>          PHI est tableau DOUBLE PRÉCISION, dimension (Q-1)
!>          Les éléments des blocs bidiagonaux B11, B12, B21, B22 peuvent
!>          être calculés à partir des angles THETA et PHI. Voir Détails supplémentaires.
!>

TAUP1

!>          TAUP1 est tableau COMPLEX*16, dimension (P)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          P1.
!>

TAUP2

!>          TAUP2 est tableau COMPLEX*16, dimension (M-P)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          P2.
!>

TAUQ1

!>          TAUQ1 est tableau COMPLEX*16, dimension (Q)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          Q1.
!>

TAUQ2

!>          TAUQ2 est tableau COMPLEX*16, dimension (M-Q)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          Q2.
!>

WORK

!>          WORK est tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK. LWORK >= M-Q.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 :  sortie réussie.
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires :

!>
!>  Les blocs bidiagonaux B11, B12, B21 et B22 sont représentés
!>  implicitement par les angles THETA(1), ..., THETA(Q) et PHI(1), ...,
!>  PHI(Q-1). B11 et B21 sont bidiagonaux supérieurs, tandis que B21 et B22 sont
!>  bidiagonaux inférieurs. Chaque entrée dans chaque bande bidiagonale est un produit
!>  d'un sinus ou d'un cosinus d'un THETA avec un sinus ou un cosinus d'un PHI. Voir
!>  [1] ou ZUNCSD pour plus de détails.
!>
!>  P1, P2, Q1 et Q2 sont représentés comme des produits de réflecteurs élémentaires.
!>  Voir ZUNCSD pour plus de détails sur la génération de P1, P2, Q1 et Q2
!>  à l'aide de ZUNGQR et ZUNGLQ.
!>
