null(4) Manuel des pilotes de périphériques null(4)

NOM

null, zero - puits de données

DESCRIPTION

Les données écrites dans les fichiers spéciaux /dev/null et /dev/zero sont ignorées.

Les lectures depuis /dev/null renvoient toujours la fin du fichier (c'est-à-dire que read(2) renvoie 0), tandis que les lectures depuis /dev/zero renvoient toujours des octets contenant des zéros (caractères '\0').

Ces périphériques sont généralement créés par :


mknod -m 666 /dev/null c 1 3
mknod -m 666 /dev/zero c 1 5
chown root:root /dev/null /dev/zero

FICHIERS

/dev/null
/dev/zero

NOTES

Si ces périphériques ne sont pas inscriptibles et lisibles par tous les utilisateurs, de nombreux programmes agiront de manière étrange.

Depuis Linux 2.6.31, les lectures depuis /dev/zero sont interrompues par les signaux. (Ce changement a été effectué pour aider à résoudre les latences importantes lors de longues lectures depuis /dev/zero.)

VOIR AUSSI

chown(1), mknod(1), full(4)
