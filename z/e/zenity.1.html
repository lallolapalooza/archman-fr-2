NOM

zenity - page de manuel pour zenity 4.2.1

DESCRIPTION

zenity est un programme qui affiche des boîtes de dialogue GTK+ et renvoie (soit dans le code de retour, soit sur la sortie standard) l'entrée de l'utilisateur. Cela permet de présenter des informations et de demander des informations à l'utilisateur, à partir de toutes sortes de scripts shell.

Par exemple, zenity --question renverra 0, 1 ou 5, selon que l'utilisateur a appuyé sur OK, Annuler ou que le délai d'attente a été atteint. zenity --entry affichera sur la sortie standard ce que l'utilisateur a tapé dans le champ de saisie.

Une documentation complète est également disponible dans le Navigateur d'aide GNOME.

NOM

zenity - Affiche des boîtes de dialogue GTK+

SYNOPIS

zenity [OPTIONS]...

DESCRIPTION

Zenity permet d'afficher des boîtes de dialogue GTK+ depuis des scripts shell.

La commande renvoie le code de sortie 0 si l'utilisateur clique sur OK, 1 si l'utilisateur clique sur Annuler, 5 si l'utilisateur clique sur Non, ou 6 si l'utilisateur clique sur Ignorer. Les autres codes d'erreur sont supérieurs à 10.

EXEMPLES

Affiche un sélecteur de fichiers avec le titre Sélectionner un fichier à supprimer. Le fichier sélectionné est renvoyé sur la sortie standard.

zenity --title="Sélectionner un fichier à supprimer" --file-selection

Affiche une boîte de dialogue de saisie de texte avec le titre Sélectionner l'hôte et le texte Sélectionnez l'hôte que vous souhaitez pinger en masse. Le texte saisi est renvoyé sur la sortie standard.

zenity --title "Sélectionner l'hôte" --entry --text "Sélectionnez l'hôte que vous souhaitez pinger en masse"

Affiche une boîte de dialogue, demandant Windows a été trouvé ! Voulez-vous le supprimer ?. Le code de retour sera 0 (vrai dans le shell) si OK est sélectionné, et 1 (faux) si Annuler est sélectionné.

zenity --question --title "Alerte" --text "Windows a été trouvé ! Voulez-vous le supprimer ?"

Affiche les résultats de recherche dans une boîte de dialogue Liste avec le titre Résultats de la recherche et le texte Recherche de tous les fichiers d'en-tête....

find . -name '*.h' | zenity --list --title "Résultats de la recherche" --text "Recherche de tous les fichiers d'en-tête..." --column "Fichiers"

Affiche une notification passive

zenity --notification --icon=software-update-available --text "Mise à jour du système nécessaire !"

Affiche une liste de courses hebdomadaire dans une boîte de dialogue liste à cocher avec Pommes et Oranges présélectionnées

zenity --list --checklist --column "Acheter" --column "Article" TRUE Pommes TRUE Oranges FALSE Poires FALSE Dentifrice

Affiche une boîte de dialogue de progression lors de la recherche de tous les fichiers postscript dans votre répertoire personnel

find $HOME -name '*.ps' | zenity --progress --pulsate
