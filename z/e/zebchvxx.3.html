subroutine zebchvxx (double precision thresh, character*3 path)

ZEBCHVXX But:

!>
!>  ZEBCHVXX exécutera Z**SVXX sur une série de matrices de Hilbert, puis
!>  comparera les bornes d'erreur retournées par Z**SVXX pour voir si la réponse retournée
!>  tombe effectivement dans ces bornes.
!>
!>  Huit rapports de test seront calculés. Les tests passeront s'ils sont .LT.
!>  THRESH. Il y a deux cas déterminés par 1 / (SQRT( N ) * EPS).
!>  Si cette valeur est .LE. au nombre de condition réciproque composante par composante,
!>  il utilise le cas garanti, sinon il utilise le cas non garanti.
!>
!>  Rapports de test :
!>     Soit Xc X_calculé et Xt X_vérité.
!>     La norme utilisée est la norme de l'infini.
!>
!>     Soit A le cas garanti et B le cas non garanti.
!>
!>       1. Borne d'erreur directe garantie sur la norme.
!>       A: norm ( abs( Xc - Xt ) / norm ( Xt ) .LE. ERRBND( *, nwise_i, bnd_i ) et
!>          ERRBND( *, nwise_i, bnd_i ) .LE. MAX(SQRT(N),10) * EPS.
!>          Si ces conditions sont remplies, le rapport de test est défini comme
!>          ERRBND( *, nwise_i, bnd_i ) / MAX(SQRT(N), 10). Sinon, il est 1/EPS.
!>       B: Pour ce cas, CGESVXX devrait simplement retourner 1. S'il est inférieur à
!>          un, traitez-le de la même manière qu'en 1A. Sinon, il échoue. (Définir le rapport de
!>          test à ERRBND( *, nwise_i, bnd_i ) * THRESH ?)
!>
!>       2. Borne d'erreur directe composante par composante garantie.
!>       A: norm ( abs( Xc(j) - Xt(j) ) ) / norm (Xt(j)) .LE. ERRBND( *, cwise_i, bnd_i )
!>          pour tout j ET ERRBND( *, cwise_i, bnd_i ) .LE. MAX(SQRT(N), 10) * EPS.
!>          Si ces conditions sont remplies, le rapport de test est défini comme
!>          ERRBND( *, cwise_i, bnd_i ) / MAX(SQRT(N), 10). Sinon, il est 1/EPS.
!>       B: Identique au rapport de test normwise.
!>
!>       3. Erreur à rebours.
!>       A: Le rapport de test est défini comme BERR/EPS.
!>       B: Identique rapport de test.
!>
!>       4. Nombre de condition réciproque.
!>       A: Un nombre de condition est calculé avec Xt et comparé à celui
!>          retourné par CGESVXX. Soit RCONDc le RCOND retourné par CGESVXX
!>          et RCONDt le RCOND de la valeur de vérité. Le rapport de test est défini comme
!>          MAX(RCONDc/RCONDt, RCONDt/RCONDc).
!>       B: Le rapport de test est défini comme 1 / (EPS * RCONDc).
!>
!>       5. Nombre de condition normwise réciproque.
!>       A: Le rapport de test est défini comme
!>          MAX(ERRBND( *, nwise_i, cond_i ) / NCOND, NCOND / ERRBND( *, nwise_i, cond_i )).
!>       B: Le rapport de test est défini comme 1 / (EPS * ERRBND( *, nwise_i, cond_i )).
!>
!>       6. Nombre de condition composante par composante réciproque.
!>       A: Le rapport de test est défini comme
!>          MAX(ERRBND( *, cwise_i, cond_i ) / CCOND, CCOND / ERRBND( *, cwise_i, cond_i )).
!>       B: Le rapport de test est défini comme 1 / (EPS * ERRBND( *, cwise_i, cond_i )).
!>
!>     .. Paramètres ..
!>     NMAX est déterminé par le plus grand nombre dans l'inverse de la matrice de Hilbert
!>     La précision est épuisée lorsque la plus grande entrée est supérieure
!>     à 2 à la puissance du nombre de bits dans la fraction du type de données
!>     utilisé plus un, soit 24 pour la simple précision.
!>     NMAX devrait être 6 pour la simple précision et 11 pour la double précision.
!>
