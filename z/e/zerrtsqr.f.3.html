sous-programme zerrtsqr (caractère*3 path, entier nunit)

ZERRTSQR

Objectif :

!>
!> ZERRTSQR teste les sorties d'erreur des routines de précision ZOUBLE
!> qui utilisent la décomposition TSQR d'une matrice générale.
!>

Paramètres

PATH 
!>          PATH est un CARACTERE*3
!>          Le nom du chemin LAPACK pour les routines à tester.
!>

NUNIT

!>          NUNIT est un ENTIER
!>          Le numéro de l'unité de sortie.
!>
