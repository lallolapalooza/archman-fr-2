NOM

zellij - exécuter zellij

DESCRIPTION

Zellij est un espace de travail destiné aux développeurs, aux professionnels de l'ops et à toute personne qui aime le terminal. À la base, c'est un multiplexeur de terminal (similaire à tmux et screen), mais ce n'est que sa couche d'infrastructure.

Zellij inclut un système de mise en page et un système de plugins permettant de créer des plugins dans n'importe quel langage qui compile en WebAssembly.

Pour lister les sessions en cours, exécutez : `zellij list-sessions` Pour vous attacher à une session en cours, exécutez : `zellij attach [nom-session]`

OPTIONS

Exécutez `zellij --help` pour voir les options et sous-commandes disponibles.

CONFIGURATION

Zellij recherche le fichier de configuration dans l'ordre suivant :

1.
le fichier fourni avec --config
2.
dans le chemin fourni par la variable d'environnement ZELLIJ_CONFIG_FILE
3.
l'emplacement par défaut (voir la section FICHIERS)
4.
l'emplacement système

Exécutez `zellij setup --check` pour voir les éventuels problèmes de configuration.

MISES EN PAGE

Les mises en page sont des fichiers yaml que Zellij peut charger au démarrage lorsque l'indicateur --layout est fourni. Par défaut, Zellij chargera une mise en page appelée `default.yaml`, mais cela peut être modifié en utilisant l'option de configuration `default_layout: [NOM_MISE_EN_PAGE]`.

Par exemple, un fichier comme celui-ci :

---
direction: Vertical
parts:
    - direction: Horizontal
      split_size:
        Percent: 50
      parts:
        - direction: Vertical
          split_size:
            Percent: 50
        - direction: Vertical
          split_size:
            Percent: 50
    - direction: Horizontal
      split_size:
        Percent: 50

indiquera à Zellij de créer cette mise en page :

+-----+-----+|     |     |+-----+     ||     |     |+-----+-----+

CRÉATION DE MISES EN PAGE

Un fichier de mise en page est une structure arborescente imbriquée. Chaque nœud décrit soit un panneau (feuille), soit un espace dans lequel ses parties (enfants) seront créées.

Chaque nœud possède les champs suivants :

  • direction: <Horizontal / Vertical> - les enfants du nœud seront créés par une division dans la direction donnée.
  • split_size: - indique soit un pourcentage de l'espace du parent du nœud, soit une taille fixe de colonnes/lignes de l'espace de son parent.
  • Percent: <1-100>
  • Fixed: <nombre_lignes/nombre_colonnes>
•
plugin: /chemin/vers/plugin.wasm - chemin optionnel vers un plugin Zellij compilé. S'il est indiqué, charge un plugin dans l'espace créé. Pour plus d'informations, voir la section PLUGINS.

RACCOURCIS CLAVIER

Zellij est livré avec un ensemble par défaut de raccourcis clavier qui vise à convenir au plus grand nombre d'utilisateurs, mais ce comportement peut être outrepassé ou modifié dans les fichiers de configuration de l'utilisateur. Les informations sur les liaisons sont disponibles dans la section keybinds de la configuration. Par exemple, pour introduire un raccourci clavier qui créera un nouvel onglet et ira à l'onglet 1 après avoir appuyé sur 'c', on peut écrire :

keybinds:
    normal:
        - action: [ NewTab, GoToTab: 1,]
          key: [ Char: 'c',]

où "normal" représente un nom de mode (voir la section MODES), la partie "action" spécifie les actions à exécuter par Zellij (voir la section ACTIONS) et "key" est utilisé pour lister les touches ou combinaisons de touches liées aux actions données (voir la section CLÉS).

Les raccourcis par défaut peuvent être déliés soit pour un mode spécifique, soit pour tous les modes. Il prend en charge soit une liste de `keybinds`, soit un booléen indiquant que tous les raccourcis doivent être déliés :

keybinds:
    unbind: true

Déliera tous les raccourcis par défaut.

keybinds:
    unbind: [ Ctrl: 'p']

Déliera tous les raccourcis par défaut de `^P` pour chaque mode.

keybinds:
    normal:
        - unbind: true

Déliera tous les raccourcis par défaut pour le mode `normal`.

keybinds:
    normal:
        - unbind: [ Alt: 'n', Ctrl: 'g']

Déliera tous les raccourcis par défaut pour `n` et `^g` pour le mode `normal`.

ACTIONS

  • Quit - quitte Zellij
  • SwitchToMode: <InputMode> - passe au mode d'entrée spécifié. Voir la section MODES pour les valeurs possibles.
  • Resize: <Direction> - redimensionne le panneau focalisé dans la direction spécifiée (une parmi : Left, Right, Up, Down).
  • FocusNextPane - déplace le focus vers le panneau suivant à droite ou en bas s'il est sur le bord de l'écran.
  • FocusPreviousPane - déplace le focus vers le panneau suivant à gauche ou en haut s'il est sur le bord de l'écran.
  • SwitchFocus - reste pour le support hérité. Déplace le focus vers un panneau avec l'ID suivant.
  • MoveFocus: <Direction> - déplace le focus dans la direction spécifiée (Left, Right, Up, Down).
  • Clear - efface l'écran actuel.
  • DumpScreen: <File> - enregistre l'écran dans le fichier spécifié.
  • DumpLayout: <File> - enregistre l'écran dans le fichier spécifié ou par défaut.
  • EditScrollback - remplace le panneau actuel par le tampon de défilement.
  • ScrollUp - défile vers le haut d'une ligne dans le panneau focalisé.
  • ScrollDown - défile vers le bas d'une ligne dans le panneau focalisé.
  • PageScrollUp - défile d'une page vers le haut dans le panneau focalisé.
  • PageScrollDown - défile d'une page vers le bas dans le panneau focalisé.
  • ToggleFocusFullscreen - bascule entre le panneau focalisé en plein écran et la mise en page normale.
  • NewPane: <Direction> - ouvre un nouveau panneau dans la direction spécifiée (Left, Right, Up, Down) par rapport au focus.
  • CloseFocus - ferme le panneau focalisé.
  • NewTab - crée un nouvel onglet.
  • GoToNextTab - va à l'onglet suivant.
  • GoToPreviousTab - va à l'onglet précédent.
  • CloseTab - ferme l'onglet actuel.
  • GoToTab: <Index> - va à l'onglet avec le numéro d'index spécifié.
  • Detach - détache la session et quitte.
  • ToggleActiveSyncTab - bascule entre l'envoi de commandes texte à tous les panneaux de l'onglet actuel et le mode normal.
  • UndoRenameTab - annule le changement de nom de l'onglet et revient au nom précédent.
  • UndoRenamePane - annule le changement de nom du panneau et revient au nom précédent.

CLÉS

  • Char: <caractère> - un seul caractère sans modificateur.
  • Alt: <caractère> - un seul caractère avec la touche `Alt` comme modificateur.
  • Ctrl: <caractère> - un seul caractère avec la touche `Ctrl` comme modificateur.
  • F: <1-12> - une des touches `F` (généralement en haut du clavier).
  • Backspace
  • Left / Right / Up / Down - touches fléchées du clavier.
  • Home
  • End
  • PageUp / PageDown
  • BackTab - une touche Tab inversée.
  • Delete
  • Insert
  • Esc

MODES

  • normal - le mode de démarrage par défaut de Zellij. Offre la capacité de passer à différents modes, ainsi que quelques raccourcis de navigation rapides.
  • locked - désactive tous les raccourcis clavier sauf celui qui permettrait de passer en mode normal (ctrl-g par défaut). Utile lorsque les raccourcis clavier de Zellij entrent en conflit avec ceux e d'une application de terminal choisie.
  • tmux - fournit des raccourcis clavier pratiques imitant un comportement tmux simple
  • pane - inclut des instructions qui manipulent les panneaux (ajout de nouveaux panneaux, déplacement, fermeture).
  • tab - inclut des instructions qui manipulent les onglets (ajout de nouveaux onglets, déplacement, fermeture).
  • resize - permet le redimensionnement du panneau actif.
  • scroll - permet le défilement dans le panneau actif.
  • renametab - est un mode "caché" qui peut être passé à l'action SwitchToMode. Il déclenchera le renommage d'un onglet.
  • renamepane - est un mode "caché" qui peut être passé à l'action SwitchToMode. Il déclenchera le renommage d'un panneau.
  • session - permet de se détacher d'une session.

Thème

Un thème de couleur peut être défini au format truecolor, 256 ou couleur hexadécimale. Truecolor :

fg: [0, 0, 0]

256 :

fg: 0

Couleur hexadécimale :

fg: "#000000"
bg: "#000"

Le thème de couleur peut être spécifié de la manière suivante :

themes:
  default:
    fg: [0,0,0]
    bg: [0,0,0]
    black: [0,0,0]
    red: [0,0,0]
    green: [0,0,0]
    yellow: [0,0,0]
    blue: [0,0,0]
    magenta: [0,0,0]
    cyan: [0,0,0]
    white: [0,0,0]
    orange: [0,0,0]

Si le thème est appelé `default`, alors zellij le choisira au démarrage. Pour spécifier un thème différent, exécutez zellij avec :

zellij options --theme [NAME]

ou mettez le nom dans le fichier de configuration avec `theme: [NAME]`.

PLUGINS

Zellij dispose d'un système de plugins basé sur WebAssembly. Tout langage exécutable sur WASI peut être utilisé pour développer un plugin. Pour charger un plugin, incluez-le dans un fichier de disposition. Zellij est livré avec des plugins par défaut inclus : status-bar, strider, tab-bar.

FICHIERS

Emplacement par défaut du répertoire de configuration utilisateur :

  • Linux : $XDG_HOME/zellij /home/alice/.config/zellij
  • macOS : /Users/Alice/Library/Application Support/com.Zellij-Contributors.zellij

Emplacement par défaut du répertoire de disposition utilisateur :

  • Sous-répertoire nommé `layouts` à l'intérieur du répertoire de configuration.
  • Linux : _$XDG_HOME/zellij/layouts /home/alice/.config/zellij/layouts
  • macOS : /Users/Alice/Library/Application/layouts Support/com.Zellij-Contributors.zellij/layouts

Emplacement par défaut du répertoire des plugins :

•
Linux : _$XDG_DATA_HOME/zellij/plugins /home/alice/.local/share/plugins

ENVIRONNEMENT

ZELLIJ_CONFIG_FILE Chemin du fichier de configuration Zellij à charger. ZELLIJ_CONFIG_DIR Chemin du répertoire de configuration Zellij.
