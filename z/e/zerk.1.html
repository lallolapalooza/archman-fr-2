NOM

zerk - Ajustement tout usage GREIS

OPTIONS

zerk [OPTIONS] [serveur[:port[:appareil]]]

zerk -h

zerk -V

DESCRIPTION

zerk est un ajustement tout usage GREIS (GNSS Receiver External Interface Specification). Si vous n'avez pas de GPS Javad qui parle le protocole GREIS, vous pouvez arrêter de lire maintenant.

Cet outil fonctionne avec votre GPS Javad à un niveau très bas. Pour comprendre zerk, vous devez d'abord être familier avec votre GPS Javad et la documentation du protocole GREIS. GREIS Guide https://www.javad.com/downloads/javadgnss/manuals/GREIS/GREIS_Reference_Guide.pdf.

zerk peut décoder les messages GREIS courants, interroger l'état du GPS, activer et désactiver les fonctionnalités GPS, et envoyer des commandes générées par l'utilisateur au GPS. Il peut lire les messages GREIS d'un fichier. Il peut lire et écrire directement via un port série, ou via une instance gpsd en cours d'exécution.

zerk ne nécessite pas de privilèges root, sauf peut-être pour accéder au port série en mode direct. Il fonctionnera bien en tant que root. L'exécution sous sudo entraînera une perte de fonctionnalités.

OPTIONS

Le programme accepte les options suivantes :

-?, -h

Affiche un message d'utilisation et quitte.

-c COMMANDE

Envoie une chaîne de caractères au GPS. Accepte un paramètre, COMMANDE, la chaîne de commande à envoyer au GPS. La chaîne est envoyée telle quelle, sauf qu'un retour à la ligne est ajouté.

-d OPTION

Désactive une option dans le GPS. Accepte un paramètre, OPTION, l'option à désactiver. zerk quittera après que le GPS ait accusé réception de la commande, sauf si -W est donné.

4HZ

Désactive les messages GREIS de base à 4Hz. Les messages sont : [RT], [UO], [GT], [PV], [SG], [DP], [SI], [EL], [AZ], [EC], [SS], et [ET]

COMPASS

Désactive l'utilisation de la constellation COMPASS (BeiDou).

CONS

Désactive l'utilisation de toutes les constellations.

DEFMSG

Désactive l'ensemble de messages par défaut (/dev/msg) à 1Hz.

GALILEO

Désactive l'utilisation de la constellation GALILEO.

GLONASS

Désactive l'utilisation de la constellation GLONASS.

GPS

Désactive l'utilisation de la constellation GPS.

IPR

Désactive tous les messages de pseudo-rangée entière. Ce sont [rx], [rc], [r1], [r2], [r3], [r5], [rl].

IRNSS

Désactive l'utilisation de la constellation IRNSS.

NMEA

Désactive les messages NMEA 4.1e de base à 4Hz. Les messages sont GBS, GGA, GSA, GST, GSV, RMC, VTG, et ZDA.

QZSS

Désactive l'utilisation de la constellation QZSS.

SBAS

Désactive l'utilisation de la constellation SBAS.

SNR

Désactive tous les messages SNR, sauf [EC]. Les messages désactivés sont : [E1], [E2], [E3], [E5], [El].

-e OPTION

Active une option dans le GPS. Accepte un paramètre, OPTION, l'option à activer. zerk quittera après que le GPS ait accusé réception de la commande, sauf si -W est donné. -e accepte les mêmes OPTIONs que -d, sauf que l'action est d'activer l'option.

-f FICHIER

Se connecte à un fichier ou un appareil. Accepte un paramètre, FICHIER, le fichier ou l'appareil à ouvrir. Les fichiers sont ouverts en lecture seule. Les périphériques caractères sont ouverts en lecture/écriture, sauf si le paramètre -r est donné. Nécessite le module pyserial.

-O OAF

Charge un fichier d'autorisation d'option (OAF) dans le GPS. Accepte un paramètre, OAF, le fichier de commande à lire. L'OAF est juste un cas particulier d'un fichier de commande '.jpo' (GREIS). -O enverra tout fichier .jpo valide au GPS.

-p PRESET

Envoie une commande prédéfinie au GPS. Accepte un paramètre, PRESET, le nom de la commande à envoyer. zerk quittera après que le GPS ait accusé réception de la commande, sauf si -W est donné.

COLDBOOT

Redémarrage à froid du GPS.

CONS

Interroge les constellations activées.

DM

Désactive tous les messages GREIS périodiques.

ID

Interroge l'identifiant du récepteur.

IPR

Interroge tous les messages de pseudo-rangée entière. Ce sont [rx], [rc], [r1], [r2], [r3], [r5], [rl].

OAF

Interroge toutes les options OAF.

RESET

Réinitialise (redémarre) le GPS.

SERIAL

Interroge le numéro de série du récepteur.

SNR

Interroge tous les messages de rapport signal sur bruit (SNR). [EC], [E1], [E2], [E3], [E5], [El].

VENDOR

Interroge le vendeur du GPS.

VER

Interroge la version du GPS.

-r

Lecture seule. N'envoie rien au GPS.

-R BRUT

Enregistre toutes les données brutes du GPS dans le fichier BRUT.

-S VITESSE

Configure la vitesse série du GPS à VITESSE bps.

-s VITESSE

Définit la vitesse du port série local à VITESSE bps. Par défaut 115 200 bps.

-V

Affiche la version de zerk et quitte.

-v VERBOSITE

Définit le niveau de verbosité à VERBOSITE. La verbosité peut aller de 0 (très silencieux) à 4 (très bruyant). Par défaut 2.

-W

Force l'attente pendant toute la durée. Pas de sortie anticipée pour l'achèvement des commandes -d, -e ou -p.

-w ATTENTE

Attend ATTENTE secondes avant de quitter. Quittera tôt à l'achèvement des commandes -d, -e ou -p, sauf si -W est donné. Par défaut 2.0 secondes.

ARGUMENTS

Par défaut, les clients collectent des données du démon gpsd local en cours d'exécution sur localhost, en utilisant le port GPSD par défaut 2947. L'argument optionnel à tout client peut modifier ce comportement : [serveur[:port[:appareil]]]

Pour plus d'explications et d'exemples, consultez la section ARGUMENTS de la page de manuel gps(1)

ENVIRONNEMENT

Les options peuvent être placées dans la variable d'environnement ZERKOPTS. ZERKOPTS est traité avant les options de la ligne de commande.

EXEMPLES

Afficher le port série Javad actuel du GPS connecté à gpsd en cours d'exécution localement :

 zerk -c "print,/cur/term"

Décoder un fichier journal brut :

zerk -r -f greis-binary.log -v 2

Changer la vitesse du port GPS de l'appareil sur /dev/ttyAMA0 à 230 400 bps :

zerk -S 230400 -f /dev/ttyAMA0

Observer le cycle de réinitialisation complet du GPS :

zerk -p RESET -v 2 -w 20 -W

Interroger l'état des SV :

zerk -W -w 2 -v 2 -c "out,,jps/{CS,ES,GS,Is,WS,QS}"

Dumps des données gpsd depuis un serveur distant :

zerk -v 2 -w 5 serveur

VALEURS DE RETOUR

0

en cas de succès.

1

en cas d'échec

VOIR AUSSI

zerk est écrit pour se conformer à la documentation Javad officielle pour le protocole GREIS. GREIS Guide https://www.javad.com/downloads/javadgnss/manuals/GREIS/GREIS_Reference_Guide.pdf.
