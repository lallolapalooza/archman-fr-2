ZEITGEIST-DAEMON(1) Manuel des commandes générales ZEITGEIST-DAEMON(1)

NOM

zeitgeist-daemon - Interface D-Bus fournissant un journal des activités

SYNTAXE

zeitgeist-daemon [OPTION]

DESCRIPTION

zeitgeist-daemon est un démon fournissant un journal d'activités. Il comprend une base de données centrale pour les événements tels que l'utilisation de fichiers, l'historique du navigateur, les entrées de calendrier, etc.

Toutes ces informations sont mises à disposition des applications externes qui communiquent avec zeitgeist-daemon via D-Bus. Les applications intéressées peuvent demander des informations, insérer de nouveaux événements ou supprimer des événements existants.

Zeitgeist est également capable d'établir des relations entre les activités. Son objectif est de permettre un bureau conscient des activités avec des interfaces utilisateur adaptatives.

Par défaut, zeitgeist-daemon lancera également l'application de journalisation groupée zeitgeist-datahub.

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options commençant par deux tirets (`--'). Un résumé des options est inclus ci-dessous.

--no-datahub
Ne pas démarrer zeitgeist-datahub avec ce démon.
-r, --replace
Remplace toute instance Zeitgeist existante s'il y en a déjà une en cours d'exécution. Si cette option n'est pas utilisée, zeitgeist-daemon refusera de démarrer si une autre instance en cours d'exécution est trouvée.
--niveau-log=NIVEAU_LOG
Spécifie la quantité d'informations à afficher sur la sortie standard. Les valeurs possibles sont : DEBUG, INFO, WARNING, ERROR, CRITICAL.
--fichier-log=FICHIER_LOG
Spécifie un fichier dans lequel la sortie du journal sera ajoutée.
-q, --quit
Arrête une instance Zeitgeist en cours d'exécution et quitte. Cela permet à Zeitgeist de terminer toute opération qu'il pourrait être en train d'effectuer.
-v, --version
Affiche la version de Zeitgeist en cours d'exécution.
-h, --help
Affiche un court message d'aide listant toutes les options prises en charge.

VARIABLES ENVIRONNEMENT

ZEITGEIST_DATA_PATH
Remplace le répertoire où sont placés les fichiers de données utilisateur. La valeur par défaut est celle du répertoire de données XDG (généralement ~/.local/share/zeitgeist).
ZEITGEIST_DATABASE_PATH
Cette variable vous permet de spécifier un remplacement pour le nom de fichier de la base de données principale. La valeur par défaut est $ZEITGEIST_DATA_PATH/activity.sqlite.
ZEITGEIST_DATABASE_BACKUP_PATH
Cette variable vous permet de spécifier un remplacement pour le nom de fichier d'une éventuelle sauvegarde de la base de données. La valeur par défaut est $ZEITGEIST_DATA_PATH/activity.sqlite.bck.
ZEITGEIST_DISABLED_EXTENSIONS
Cette variable vous permet de spécifier une liste d'extensions séparées par des virgules qui ne devraient pas être chargées. Les noms sont extraits des noms de type des extensions, donc pour désactiver l'extension dont le nom de type est ZeitgeistDataSourceRegistry, la valeur de la variable devrait être DataSourceRegistry.

SIGNALS

SIGHUP : zeitgeist-daemon s'arrêtera proprement.

Il est recommandé que les mises à jour système de Zeitgeist envoient ce signal à toutes les instances en cours d'exécution de zeitgeist-daemon. L'activation D-Bus garantira que le logiciel mis à jour sera automatiquement redémarré si nécessaire.

CODES SORTIE

0
Zeitgeist s'est terminé normalement.
1
Une erreur non spécifiée s'est produite.
10
Il y a déjà une instance Zeitgeist en cours d'exécution.
21
Impossible d'accéder au fichier de la base de données.
22
Le fichier de la base de données est verrouillé.
