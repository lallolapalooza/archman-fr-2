NOM

zeppelin - Démon client d'émulation LAN ATM (LED) Zeppelin

SYNTAXE

zeppelin [-b ] [-c adresse_LECS | -s adresse_LES] [-e esi] [-n nom_VLAN] [-m masque_msg] [-l adresse_ecoute | selecteur] [-i num_interface] [-I num_interface_physique] [-t 1516|1580|4544|9234|18190] [-1 ] [-2 ] [-p ] [-F fichier_log] [-f nom_specifique_Fore]

DESCRIPTION

Un client d'émulation LAN (LEC) est une entité dans une station de connexion ATM qui effectue le transfert de données, la résolution d'adresses et d'autres fonctions de contrôle. Il utilise l'interface LUNI lors de la communication avec d'autres composants dans les LAN émulés. Il fournit aux couches protocolaires supérieures une interface de type MAC similaire à celle des LAN IEEE 802.3/Ethernet ou IEEE 802.5/Token Ring.

Le code du client d'émulation LAN est divisé en deux parties : une application en espace utilisateur, le démon d'émulation LAN (LED) appelé zeppelin(8), et le composant noyau. Zeppelin est responsable des opérations de contrôle nécessaires à la fonction de client d'émulation LAN. Il forme les VCC nécessaires, reçoit toutes les trames de contrôle LE et agit en conséquence. Il contrôle également le fonctionnement du composant noyau LEC.

Le LEC Linux ne prend en charge que le type Ethernet des LAN émulés.

SIGHUP provoque le redémarrage du LEC. Toutes les ressources sont libérées et zeppelin est lancé.

OPTIONS

-b
Exécute en arrière-plan (c'est-à-dire dans un processus enfant issu d'un fork) après initialisation de l'interface noyau.
-c adresse_LECS
Adresse ATM du lecs(8) (Serveur de Configuration d'Émulation LAN), si elle n'est pas définie, l'adresse du serveur connue est utilisée.
-s adresse_LES
Adresse ATM du les(8) (Serveur d'Émulation LAN), peut être utilisé pour contourner la phase de configuration lors de la jointure d'un LAN émulé, c'est-à-dire que l'adresse lecs n'est pas utilisée.
-e esi
Adresse MAC à utiliser lors de la communication dans le LAN Émulé. Par exemple, 00:20:22:23:04:05.
-n nom_VLAN
Nom du réseau local virtuel (VLAN) auquel on demande de se joindre. Ceci est utilisé dans LE_CONFIGURE_REQUEST à LECS ou LE_JOIN_RESPONSE à LES, si la phase de configuration est contournée.
-m masque_msg
Parfois, on veut en savoir plus sur ce qui se passe dans le démon LE, par exemple quand rien ne fonctionne. Il s'agit d'une valeur hexadécimale longue qui définit le masque de message global. 0 = Pas de messages, ffff = Tous les messages.
-l adresse_ecoute | selecteur
Adresse ATM locale que zeppelin utilise comme point de liaison local dans la signalisation. Utilisez ceci si vous exécutez plus d'un client ou un ensemble de serveurs LE. L'adresse ATM locale peut être spécifiée soit en donnant l'adresse ATM complète, soit le byte sélecteur souhaité.
-i num_interface
Le LEC Linux prend en charge jusqu'à 40+8 interfaces réseau. Le num_interface indique à zeppelin à laquelle d'entre elles se connecter. Les interfaces réseau de type Ethernet sont numérotées de "lec0" à "lec39" et les interfaces Token Ring de "lec40" à "lec47". Ces paramètres sont ajustables lors de la compilation du noyau, voir <linux/atmlec.h>.
-I num_interface_physique
L'interface physique à laquelle ce client LANE doit se lier. Si votre hôte possède plusieurs cartes réseau ATM, vous pouvez utiliser cette option pour choisir quelle carte ce zeppelin utilisera.
-t MTU
La MTU de l'ELAN à rejoindre. Vous devez également utiliser ifconfig(8) pour définir la MTU de l'interface LANE.
-1
Exécute en tant que client LANEv1. C'est le comportement par défaut.
-2
Exécute en tant que client LANEv2. Ceci est requis par MPOA.
-p
Active le proxy. Lorsqu'il est lancé avec cette option, il est possible de pontuer des paquets entre ATM et Ethernet. C'est-à-dire, vous pouvez utiliser les interfaces LANE avec le pontage normal. Voir le mini-guide de pontage pour plus d'informations.
-F fichier_log
Au lieu d'écrire les messages de débogage sur stderr, écrivez les messages dans le fichier fichier_log. Utilisez syslog comme nom de fichier pour utiliser la fonctionnalité syslog(3).
-f nom_specifique_Fore
Les serveurs LANE sur les commutateurs Fore ATM peuvent afficher un nom spécial si un client peut en fournir un. Ce nom apparaît avec la commande ´conf lane les show advanced´.

CONSIDÉRATIONS TOKEN RING

Un certain nombre d'interfaces lec sont réservées pour les ELANs Token Ring lorsque le noyau est compilé avec le support Token Ring (CONFIG_TR). Voir la discussion sur l'option de ligne de commande num_interface ci-dessus. Le client LANE Token Ring Linux ne prend pas en charge le pontage entre le Token Ring hérité et les parties ATM de l'ELAN, donc l'utilisation de l'option -p n'est pas recommandée. Le support Token Ring a reçu moins de tests que son homologue Ethernet.

FICHIERS

/var/run/lec[numéro_interface].pid Le fichier contenant l'identifiant du processus de zeppelin.
