sous-routine zerrgg (character*3 path, integer nunit)

ZERRGG

Objectif :

!>
!> ZERRGG teste les sorties d'erreur pour ZGGES, ZGGESX, ZGGEV, ZGGEVX,
!> ZGGES3, ZGGEV3, ZGGGLM, ZGGHRD, ZGGLSE, ZGGQRF, ZGGRQF,
!> ZGGSVD3, ZGGSVP3, ZHGEQZ, ZTGEVC, ZTGEXC, ZTGSEN, ZTGSJA,
!> ZTGSNA, ZTGSYL, et ZUNCSD.
!>

Paramètres

PATH 
!>          PATH est CHARACTER*3
!>          Le nom du chemin LAPACK pour les routines à tester.
!>

NUNIT

!>          NUNIT est INTEGER
!>          Le numéro d'unité pour la sortie.
!>
