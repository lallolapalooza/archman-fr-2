ZEITGEIST-DATAHUB(1) Manuel des commandes générales ZEITGEIST-DATAHUB(1)

NOM

zeitgeist-datahub - enregistreurs passifs pour Zeitgeist

SYNTAXE

zeitgeist-datahub [OPTION]

DESCRIPTION

zeitgeist-datahub est un démon qui centralise toutes les sources de données passives en un seul processus, et assure l'interface entre lesdites sources de données (également appelées enregistreurs) et zeitgeist-daemon (avec lequel il communique via D-Bus).

Les sources de données passives sont celles qui fonctionnent en arrière-plan et recherchent les activités indépendamment des programmes qu'elles surveillent, tandis que Zeitgeist peut également fonctionner avec des sources de données actives qui sont celles intégrées dans d'autres applications (soit nativement, soit via des extensions).

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options commençant par deux traits d'union (`--'). Un résumé des options est inclus ci-dessous.

Actuellement, aucune option n'est disponible.
