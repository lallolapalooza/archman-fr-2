zvbi-atsc-cc(1) Manuel des commandes générales zvbi-atsc-cc(1)

NOM

zvbi-atsc-cc - Décodeur de sous-titres codés ATSC

SYNTAXE

zvbi-atsc-cc [ options ] [-n] nom_station

DESCRIPTION

zvbi-atsc-cc capture les transmissions TV ATSC à l'aide d'un périphérique DVB sous Linux et décode les données de sous-titrage codé intégrées. Il peut enregistrer les sous-titres NTSC (EIA 608-B) et les sous-titres DTVCC (CEA 708-C).

OPTIONS

-? -h --help --usage
Affiche un court message d'utilisation.
-q --quiet
Supprime tous les messages de progression et d'erreur.
-v --verbose
Augmente la verbosité.

Options de périphérique

-a numéro
--adapter-num numéro
Sélectionne un périphérique DVB différent pour capturer le signal (/dev/dvb/adapterN). Le périphérique par défaut est l'adaptateur 0.
-i numéro
--frontend-id numéro
Sélectionne une interface frontale différente sur le périphérique DVB (/dev/dvb/adapterN/frontendM). La plupart des périphériques n'ont qu'une seule interface frontale. L'interface frontale par défaut est la 0.
-d numéro
--demux-id numéro
Sélectionne un multiplexeur différent sur le périphérique DVB (/dev/dvb/adapterN/demuxM). La plupart des périphériques n'ont qu'un seul multiplexeur. Le multiplexeur par défaut est le 0.
-r numéro
--dvr-id numéro
Sélectionne une interface DVR différente sur le périphérique DVB (/dev/dvb/adapterN/dvrM). La plupart des périphériques n'ont qu'une seule interface DVR. L'interface DVR par défaut est la 0.
-T
--ts
Décode un flux de transport MPEG-2 sur l'entrée standard au lieu d'ouvrir un périphérique DVB. Cette option est principalement destinée au débogage.
Étant donné que les flux de transport peuvent contenir plusieurs programmes, vous devez toujours spécifier un ou plusieurs noms de station, que zvbi-atsc-cc recherchera dans un fichier de configuration de canaux pour déterminer l'ID du programme du flux élémentaire vidéo à extraire. Vous devez également ajouter l'option --atsc pour clarifier qu'il s'agit d'un flux ATSC et que le programme s'attendra à un fichier de configuration de canaux azap, qui est par ailleurs déduit des capacités du périphérique DVB.

Options de réglage

-e nom_fichier
--channel-conf nom_fichier
Pour syntoniser une station de télévision, zvbi-atsc-cc a besoin d'un fichier de configuration de canaux. Nous utilisons le fichier de configuration de l'outil de syntonisation azap du paquet linuxtv-dvb-apps. Vous pouvez le créer avec l'outil scan du même paquet.
Le fichier de configuration de canaux azap est un fichier texte qui liste une station par ligne. Chaque ligne contient six champs séparés par des deux-points : le nom de la station, la fréquence du transpondeur en Hz, la modulation utilisée (8VSB, 16VSB, QAM_64, QAM_256), le PID du flux vidéo, le PID du flux audio et l'ID du service. Les lignes vides et les lignes commençant par un signe dièse seront ignorées.
Cette option sélectionne un fichier de configuration de canaux différent. Le fichier par défaut est 
$HOME/.azap/channels.conf
-L --list
Liste toutes les stations dans le fichier de configuration de canaux et leur fréquence de transpondeur.
-n nom_station
--station nom station
La station à syntoniser. Habituellement, le -n peut être omis.
zvbi-atsc-cc peut enregistrer les sous-titres de plusieurs stations à la fois si elles partagent une fréquence de transpondeur. Il suffit de spécifier plusieurs noms de station sur la ligne de commande pour activer cette fonction.

Options de sous-titrage codé

Avec les options de sous-titrage codé et XDS, vous spécifiez quelles données zvbi-atsc-cc doit extraire. Si plusieurs noms de station sont donnés, ces options s'appliquent au nom de station suivant. Vous devez spécifier au moins une de ces options pour chaque station.

-c --cc
Affiche tout sous-titrage reçu sur la sortie standard.
-C nom_fichier
--cc-file nom_fichier
Ajoute tout sous-titrage reçu au fichier spécifié.
-l numéro
--channel numéro
Affiche le canal 1, 2, 3 ou 4 de sous-titrage codé NTSC sur la sortie standard.
-1 ... -4 nom_fichier
--cc1-file ... --cc4-file nom_fichier
Filtre les canaux de sous-titrage codé NTSC CC1 ... CC4 et ajoute le texte au fichier spécifié. CC1 est le service de sous-titrage principal, CC3 le secondaire. Si les deux services sont transmis, CC1 contient généralement les sous-titres en anglais, CC3 en espagnol.
-5 ... -8 nom_fichier
--t1-file ... --t4-file nom_fichier
Filtre les services de texte NTSC T1 ... T4 et ajoute le texte au fichier spécifié.
-9 ... -0 nom_fichier
--s1-file ... --s2-file nom_fichier
Filtre les services DTVCC 1 ou 2 et ajoute le texte au fichier spécifié. Le service 1 est le service de sous-titrage principal, le service 2 le secondaire. Si les deux services sont transmis, le service 1 contient généralement les sous-titres en anglais, le service 2 en espagnol.
Les stations de télévision numérique sont censées transmettre des codes de langue et d'autres informations sur les services de sous-titrage disponibles, mais ceux-ci ne sont pas actuellement évalués. zvbi-atsc-cc filtre le texte qui ne semble pas être du sous-titrage, comme les tickers ou le texte imprimé verticalement.
-b --no-webtv
N'affiche pas les liens WebTV.
-m --timestamps
Précède les lignes de sous-titrage de timestamps YYYYMMDDHHMMSS. Il s'agit de l'heure système dans le fuseau horaire UTC au moment où le texte a été capturé, spécifiquement le code Carriage Return ou Pop-On responsable de l'affichage de la ligne.
-S --stream-time
-Sdate --stream-time=date
Précède les lignes de sous-titrage de timestamps YYYYMMDDHHMMSS générées à partir des timestamps transmis dans le flux vidéo. Si une date est donnée, également au format YYYYMMDDHHMMSS, elle sera ajoutée aux timestamps, sinon le compteur commence à 0001-01-01 00:00:00.
-s --sentences
Affiche le sous-titrage une phrase à la fois.
-j type
--format type
Lorsque le type est "plain", zvbi-atsc-cc affiche le texte du sous-titrage et XDS sans aucune balise. Lorsque le type est "vt100", il reproduit fidèlement les couleurs de premier plan et d'arrière-plan du sous-titrage, ainsi que les attributs italique et souligné en insérant des codes de contrôle de terminal VT.100. Avec le type "ntsc-cc", il imite la sortie des outils ntsc-cc et zvbi-ntsc-cc. Le type par défaut est "ntsc-cc".
zvbi-atsc-cc prend en charge tous les jeux de caractères de sous-titrage codé et convertit vers l'encodage de la locale actuelle, généralement UTF-8.
-p --plain
Identique à -j plain

Options XDS

-x --xds
Affiche toute donnée XDS reçue sur la sortie standard.
-X nom_fichier
--xds-file nom_fichier
Ajoute toute donnée XDS reçue au fichier spécifié.
-w --noweb
Ne pas afficher de données XDS pour les liens WebTV.

EXEMPLE

Pour enregistrer les sous-titres du canal 3 de la station KABC sur la sortie standard:

zvbi-atsc-cc -l 3 KABC

Pour enregistrer le sous-titrage principal (anglais) du canal 1 de la station KABC et le sous-titrage secondaire (espagnol) du canal 2 de la même station dans des fichiers séparés:

zvbi-atsc-cc --s1-file kabc-en.txt --s2-file kabc-es.txt KABC

Pour enregistrer tous les sous-titres de la station KABC en utilisant le format VT100 avec timestamps:

zvbi-atsc-cc -j vt100 -m KABC

Pour décoder un flux de transport sur l'entrée standard et afficher les sous-titres du canal 3 de la station KABC:

cat my_atsc_stream.ts | zvbi-atsc-cc -j plain -c -n KABC -e ~/.azap/channels.conf --atsc

ATTENTION

Ce programme est une application de ligne de commande et ne fournira aucun retour visuel. L'utilisation avec un périphérique DVB nécessite que le noyau dispose des pilotes appropriés et que l'application dvb-apps soit installée.

f='#XDS_options'>Options XDS
-x --xds
Affiche toutes les données XDS reçues sur la sortie standard.
-X nom de fichier
--xds-file nom de fichier
Filtre les données eXtended Data Service (nom de la station, nom du programme, notation du programme, etc.) et les ajoute sous forme de texte au fichier spécifié.
-f type[,type]*
--filter type[,type]*
Filtre les informations XDS spécifiques : all (toutes), call (indicatif de station), desc (synopsis du programme), length (durée), network (réseau), rating (notation), time (heure), timecode (code temporel), timezone (fuseau horaire), title (titre). Les options -f multiples s'ajoutent. La valeur par défaut est "all".

EXEMPLES

zvbi-atsc-cc -c NJN-HD
zvbi-atsc-cc --cc1-file wnyw.txt WNYW-DT --cc1-file wwor.txt WWOR-DT
(NJN-HD, WNYW-DT et WWOR-DT sont des chaînes de télévision à New York. WNYW-DT
et WWOR-DT peuvent être capturés simultanément car ils partagent une
fréquence de transpondeur.)
zvbi-atsc-cc --atsc --ts -c CNN < recorded-from-cnn.ts
