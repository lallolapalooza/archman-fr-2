NOM

zvbi-chains - Wrapper proxy VBI

SYNOPSIS

zvbi-chains [ options ]

DESCRIPTION

zvbi-chains est un petit wrapper qui exécute l'application VBI donnée en ligne de commande tout en surchargeant plusieurs appels de la bibliothèque C (tels que open(2) et read(2)) afin que l'application puisse être forcée d'accéder aux périphériques VBI via le proxy VBI au lieu des fichiers de périphériques directement.

LD_PRELOAD est utilisé pour intercepter les appels de la bibliothèque C et appeler à la place des fonctions de la bibliothèque partagée libzvbi-chain. Les paramètres donnés en ligne de commande (par exemple, le chemin du périphérique) sont transmis à la bibliothèque au moyen de variables d'environnement.

OPTIONS

-dev chemin
Chemin d'un périphérique VBI à partir duquel lire les données.
-debug niveau
Active la sortie de débogage : 0 = désactivé (par défaut) ; 1 = avertissements, 2 = tous les messages.
-help
Affiche une courte description de toutes les options de ligne de commande.
