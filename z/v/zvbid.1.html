NOM

zvbid - Démon mandataire VBI

SYNTAXE

zvbid [ options ]

DESCRIPTION

zvbid est un mandataire pour les périphériques VBI, c'est-à-dire qu'il transmet un ou plusieurs flux de données VBI à un ou plusieurs clients connectés et gère les requêtes de changement de chaîne.

OPTIONS

-dev chemin
Chemin d'un périphérique à partir duquel lire les données. Cet argument peut être spécifié plusieurs fois avec des périphériques différents.
-buffers nombre
Nombre de tampons à allouer pour la capture des données brutes VBI à partir des périphériques qui prennent en charge le streaming (actuellement seulement video4linux, rev. 2). Un plus grand nombre de tampons peut éviter la perte de données en cas de latence élevée. L'inconvénient est une consommation de mémoire plus élevée (typiquement 65 Ko par tampon). Le nombre par défaut est 8, le maximum est 32.
-nodetach
Le processus démon reste connecté au terminal à partir duquel il a été démarré (par exemple, pour pouvoir l'arrêter en appuyant sur les touches Control-C). Intentionné pour le dépannage uniquement.
-kill
Termine un démon mandataire en cours d'exécution pour le périphérique donné.
-debug niveau
Active la sortie de débogage : 0= désactivé (par défaut) ; 1= messages généraux ; En outre, 2, 4, 8, ... peuvent être ajoutés pour activer la sortie de débogage pour diverses catégories.
-syslog niveau
Active la sortie syslog.
-loglevel niveau
Niveau du fichier journal.
-logfile chemin
Chemin vers le fichier journal.
-maxclients nombre
Nombre maximum de clients autorisés à se connecter simultanément.
-help
Affiche une brève description de toutes les options de la ligne de commande.
