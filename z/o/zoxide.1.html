NOM

zoxide - une commande cd plus intelligente

SYNTAXE

zoxide SOUS-COMMANDE [OPTIONS]

DESCRIPTION

zoxide est une commande cd plus intelligente pour votre terminal. Elle garde une trace des répertoires que vous utilisez le plus fréquemment et utilise un algorithme de classement pour naviguer vers la meilleure correspondance.

UTILISATION

z foo              # cd dans le répertoire correspondant à foo avec le classement le plus élevé
z foo bar          # cd dans le répertoire correspondant à foo et bar avec le classement le plus élevé
z foo /            # cd dans un sous-répertoire commençant par foo

z ~/foo            # z fonctionne également comme une commande cd normale
z foo/             # cd dans un chemin relatif
z ..               # cd d'un niveau vers le haut
z -               # cd dans le répertoire précédent

zi foo             # cd avec sélection interactive (en utilisant fzf)

z foo<ESPACE><TAB>  # affiche les complétions interactives (bash 4.4+/fish/zsh uniquement)

SOUS-COMMANDES

zoxide-add(1)
Ajoute un nouveau répertoire à la base de données, ou incrémente son classement.
zoxide-import(1)
Importe des entrées d'une autre application.
zoxide-init(1)
Génère la configuration du shell.
zoxide-query(1)
Recherche un répertoire dans la base de données.
zoxide-remove(1)
Retire un répertoire de la base de données.

OPTIONS

-h, --help
Affiche les informations d'aide.
-V, --version
Affiche les informations de version.

VARIABLES ENVIRONNEMENT

Les variables d'environnement peuvent être utilisées pour la configuration. Elles doivent être définies avant que zoxide-init(1) ne soit appelé.

_ZO_DATA_DIR
Spécifie le répertoire dans lequel la base de données est stockée. La valeur par défaut varie selon les systèmes d'exploitation :
OS Chemin
Linux/BSD $XDG_DATA_HOME ou $HOME/.local/share, ex : /home/alice/.local/share
macOS $HOME/Library/Application Support, ex : /Users/Alice/Library/Application Support
Windows %LOCALAPPDATA%, ex : C:\Users\Alice\AppData\Local
_ZO_ECHO
Lorsqu'il est défini sur 1, z affichera le répertoire correspondant avant de s'y déplacer.
_ZO_EXCLUDE_DIRS
Empêche l'ajout des répertoires spécifiés à la base de données. Ceci est fourni sous forme d'une liste de globes, séparés par des caractères spécifiques au système d'exploitation :
OS Séparateur
Linux/macOS/BSD :, ex : $HOME:$HOME/private/*
Windows ;, ex : $HOME;$HOME/private/*

Par défaut, ceci est défini sur $HOME. Après avoir configuré ceci, vous pourriez avoir besoin d'utiliser zoxide-remove(1) pour supprimer les entrées existantes de la base de données.

_ZO_FZF_OPTS
Options personnalisées à passer à fzf(1) lors de la sélection interactive. Voir la page de manuel pour la liste complète des options.
_ZO_MAXAGE
Configure l'algorithme d'expiration, qui limite le nombre maximum d'entrées dans la base de données. Par défaut, ceci est défini sur 10000.
_ZO_RESOLVE_SYMLINKS
Lorsqu'il est défini sur 1, z résoudra les liens symboliques avant d'ajouter des répertoires à la base de données.

ALGORITHME

EXPIRATION
zoxide utilise un paramètre appelé _ZO_MAXAGE pour limiter le nombre d'entrées dans la base de données en fonction des modèles d'utilisation. Si la FREQUENCE totale des répertoires dans la base de données dépasse cette valeur, nous divisons le score de chaque répertoire par un facteur k - de telle sorte que le nouveau total devienne environ 90% de _ZO_MAXAGE. Par la suite, si le nouveau score d'un répertoire tombe en dessous de 1, il est retiré de la base de données.

Théoriquement, le nombre maximum de répertoires dans la base de données est de 4 * _ZO_MAXAGE, bien qu'il soit plus faible en pratique.

FREQUENCE
Chaque répertoire dans zoxide reçoit un score, commençant par 1 la première fois qu'il est accédé. Chaque accès ultérieur augmente le score de 1. Lorsqu'une requête est effectuée, nous calculons la fréquence en fonction de la dernière fois que le répertoire a été accédé :
Dernier temps d'accès Fréquence
Dans la dernière heure score * 4
Dans le dernier jour score * 2
Dans la dernière semaine score / 2
Sinon score / 4
