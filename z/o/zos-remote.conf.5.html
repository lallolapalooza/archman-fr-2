NOM

zos-remote.conf - fichier de configuration du plugin audisp-racf

DESCRIPTION

zos-remote.conf contrôle la configuration du plugin de distribution d'audit audispd-zos-remote(8). L'emplacement par défaut de ce fichier est /etc/audit/zos-remote.conf, cependant, un autre fichier peut être spécifié comme premier argument du plugin audispd-zos-remote. Voir audispd-zos-remote(8) et auditd(8). Les options disponibles sont les suivantes :

serveur
Ceci est le nom d'hôte ou l'adresse IP du serveur IBM z/OS ITDS
port
Le numéro de port sur lequel ITDS est en cours d'exécution sur le serveur z/OS. Le port par défaut est le 389 (port ldap).
utilisateur
L'ID utilisateur z/OS RACF que le plugin audispd-zos-remote utilisera pour effectuer les requêtes d'audit à distance. Cet utilisateur a besoin d'un accès en LECTURE à la ressource de classe FACILITY IRR.LDAP.REMOTE.AUDIT (voir audispd-zos-remote(8)).
mot_de_passe
Le mot de passe associé à l'ID utilisateur z/OS configuré ci-dessus.
timeout
Le nombre de secondes pendant lesquelles le plugin audispd-zos-remote attendra avant d'abandonner les tentatives de connexion et de soumission d'événements. La valeur par défaut est 15.
q_depth
Le plugin audispd-zos-remote mettra en file d'attente les événements entrants jusqu'à un maximum de q_depth événements lors de la tentative de soumission à distance. Cela peut gérer des rafales d'événements ou un cas de connexion réseau lente. Cependant, le plugin audispd-zos-remote supprimera des événements si la file d'attente est pleine. La profondeur de file d'attente par défaut est de 64 - Augmentez cette valeur si vous constatez une suppression d'événements due à une file d'attente pleine (audispd-zos-remote l'enregistrera dans syslog).
