NOM

zoxide-add - ajouter un nouveau répertoire ou incrémenter son rang

SYNTAXE

zoxide add [CHEMINS]

DESCRIPTION

Si le répertoire n'est pas déjà dans la base de données, cette commande crée une nouvelle entrée pour celui-ci avec un score par défaut de 1, sinon, elle incrémente le score existant de 1. Elle met ensuite à jour le champ « dernière mise à jour » de l'entrée à l'heure actuelle. Après cela, elle exécute l'algorithme VIEILLISSEMENT sur la base de données. Voir zoxide(1) pour plus d'informations sur l'algorithme.

Si vous souhaitez empêcher qu'un répertoire ne soit ajouté à la base de données, consultez la variable d'environnement _ZO_EXCLUDE_DIRS dans zoxide(1).

OPTIONS

-h, --help
Affiche les informations d'aide.
