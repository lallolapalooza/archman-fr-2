NOM

zone2json - Convertit les zones BIND en JSON

SYNTAXE

zone2json {--named-conf=CHEMIN, --zone-file=CHEMIN [--zone-name=NOM]} [OPTION]

DESCRIPTION

zone2json analyse les fichiers de configuration named.conf et les fichiers de zone BIND et génère une sortie JSON sur la sortie standard, qui peut ensuite être fournie à l'API PowerDNS.

zone2json comprend l'extension de fichier maître BIND $GENERATE et respectera également $ORIGIN et $TTL.

OPTIONS

OPTIONS D'ENTRÉE

--named-conf=<CHEMIN>
Lit CHEMIN pour obtenir la configuration BIND.
--zone=<CHEMIN>
Analyse uniquement le fichier de zone à CHEMIN. Conflit avec le paramètre --named-conf.
--zone-name=<NOM>
Lors de l'analyse d'une seule zone sans instruction $ORIGIN, définit ZONE comme nom de zone.

AUTRES OPTIONS

--help
Liste toutes les options.
--on-error-resume-next
Ignore les fichiers de zone manquants pendant l'analyse. Dangereux.
--verbose
Soyez verbeux pendant la conversion.
