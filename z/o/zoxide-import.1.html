NOM

zoxide-import - importer des données d'autres outils

SYNTAXE

zoxide import CHEMIN --from FORMAT [OPTIONS]

OPTIONS

--from FORMAT
Le format de la base de données en cours d'importation :
autojump
z (pour fasd, z, z.lua, ou zsh-z)

Note : zoxide n'importe que les chemins d'autojump, car son algorithme de correspondance est trop différent pour importer les scores.

-h, --help
Affiche les informations d'aide.
--merge
Par défaut, l'importation échoue si la base de données actuelle n'est pas déjà vide. Cette option fusionne les données importées dans la base de données existante.
