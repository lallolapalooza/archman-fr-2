NOM

zoxide-init - génère la configuration du shell pour zoxide

SYNOPSIS

zoxide init SHELL [OPTIONS]

DESCRIPTION

Pour initialiser zoxide sur votre shell :

bash
Ajoutez ceci à la fin de votre fichier de configuration (généralement ~/.bashrc) : 
    eval "$(zoxide init bash)"
elvish
Ajoutez ceci à la fin de votre fichier de configuration (généralement ~/.elvish/rc.elv) : 
    eval $(zoxide init elvish | slurp)

Note : zoxide ne prend en charge qu'elvish v0.18.0 et supérieur.

fish
Ajoutez ceci à la fin de votre fichier de configuration (généralement ~/.config/fish/config.fish) : 
    zoxide init fish | source
nushell
Ajoutez ceci à la fin de votre fichier d'environnement (trouvez-le en exécutant $nu.env-path dans Nushell) : 
    zoxide init nushell | save -f ~/.zoxide.nu

Maintenant, ajoutez ceci à la fin de votre fichier de configuration (trouvez-le en exécutant $nu.config-path dans Nushell) :

    source ~/.zoxide.nu

Note : zoxide ne prend en charge que Nushell v0.89.0+.

powershell
Ajoutez ceci à la fin de votre fichier de configuration (trouvez-le en exécutant echo $profile dans PowerShell) : 
    Invoke-Expression (& { (zoxide init powershell | Out-String) })
tcsh
Ajoutez ceci à la fin de votre fichier de configuration (généralement ~/.tcshrc) : 
    zoxide init tcsh > ~/.zoxide.tcsh
    source ~/.zoxide.tcsh
xonsh
Ajoutez ceci à la fin de votre fichier de configuration (généralement ~/.xonshrc) : 
    execx($(zoxide init xonsh), 'exec', __xonsh__.ctx, filename='zoxide')
zsh
Ajoutez ceci à la fin de votre fichier de configuration (généralement ~/.zshrc) : 
    eval "$(zoxide init zsh)"
tout shell POSIX

Ajoutez ceci à la fin de votre fichier de configuration :

    eval "$(zoxide init posix --hook prompt)"

OPTIONS

--cmd
Change le préfixe des commandes z et zi.
--cmd j changerait les commandes en (j, ji).
--cmd cd remplacerait la commande cd (ne fonctionne pas sur Nushell / shells POSIX).
-h, --help
Affiche les informations d'aide.
--hook HOOK
Change la fréquence à laquelle zoxide incrémente le score d'un répertoire :
none Jamais
prompt À chaque invite de commande
pwd Chaque fois que le répertoire est changé
--no-cmd
Empêche zoxide de définir les commandes z et zi. Ces fonctions seront toujours disponibles dans votre shell sous les noms __zoxide_z et __zoxide_zi, si vous choisissez de les redéfinir.
