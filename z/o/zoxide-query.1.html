NOM

zoxide-query - rechercher un répertoire dans la base de données

SYNTAXE

zoxide query [MOTS-CLÉS] [OPTIONS]

DESCRIPTION

Interroger la base de données pour trouver des chemins correspondant aux mots-clés. L'algorithme exact de CORRESPONDANCE est décrit dans zoxide(1).

OPTIONS

--all
Afficher les répertoires supprimés.
--exclude CHEMIN
Exclure un chemin des résultats de la recherche.
-h, --help
Afficher l'aide.
-i, --interactive
Utiliser la sélection interactive. Cette option nécessite fzf(1).
-l, --list
Lister tous les résultats, plutôt que seulement celui avec la fréquence la plus élevée.
-s, --score
Afficher le score calculé ainsi que le chemin correspondant.
