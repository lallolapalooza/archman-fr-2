NOM

zoom - se promener sur le bureau agrandi

SYNTAXE

zoom [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--mono] [--install] [--visual visuel] [--delay microsecondes] [--duration secondes] [--lenses] [--pixwidth pixels] [--pixheight pixels] [--pixspacex pixels] [--pixspacey pixels] [--lensoffsetx pixels] [--lensoffsety pixels] [--fps]

DESCRIPTION

Le programme zoom prend une image, l'agrandit et se déplace autour d'elle, style fatbits.

L'image qu'il manipule sera capturée à partir de la partie de l'écran sous la fenêtre, ou de l'entrée vidéo du système, ou d'un fichier aléatoire sur disque, comme indiqué par les options grabDesktopImages, grabVideoFrames, et chooseRandomImages dans le fichier ~/.xscreensaver ; voir xscreensaver-settings(1) pour plus de détails.

OPTIONS

zoom accepte les options suivantes :

--window
Dessine dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id numéro
Dessine sur la fenêtre spécifiée.
--mono
Si sur un écran couleur, fait comme si on était sur un écran monochrome.
--install
Installe une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifie quel visuel utiliser. Les valeurs légales sont le nom d'une classe de visuel, ou le numéro d'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--delay microsecondes
Ralentit le mouvement.
--duration secondes
Durée avant de charger une nouvelle image. Par défaut 120 secondes.
--lenses
Au lieu d'agrandir, on copie simplement une région décalée de l'image originale. Si lensoffsetx < pixwidth (et de même pour Y), alors les régions consécutives se chevaucheront, donnant l'effet de regarder à travers un tableau de lentilles.
--pixwidth pixels
Largeur des pixels agrandis.
--pixheight pixels
Hauteur des pixels agrandis.
--pixspacex pixels
Quantité d'espace noir entre les pixels agrandis (direction X).
--pixspacey pixels
Quantité d'espace noir entre les pixels agrandis (direction Y).
--lensoffsetx pixels
Distance en direction X entre les régions copiées consécutives (uniquement efficace lorsque -lenses est utilisé).
--lensoffsety pixels
Distance en direction Y entre les régions copiées consécutives (uniquement efficace lorsque -lenses est utilisé).

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de la fenêtre à utiliser avec --root.
