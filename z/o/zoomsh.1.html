NOM

zoomsh - Shell ZOOM

SYNTAXE

zoomsh [-a fichier_apdu] [-e] [-v niveau_log] [commandes...]

DESCRIPTION

zoomsh est un client ZOOM avec une interface en ligne de commande simple. Le client démontre l'API ZOOM et est utile pour tester des cibles.

Vous pouvez passer une ou plusieurs commandes à zoomsh. Ces commandes sont invoquées en premier.

OPTIONS

-a fichier_apdu

Enregistre les paquets de protocole dans fichier_apdu (journal APDU).

-e

Fait cesser le traitement des commandes par zoomsh dès qu'une erreur survient. Le code de sortie de zoomsh est 1 en cas d'erreur ; 0 sinon.

-v niveau_log

Définit le niveau de journalisation YAZ à niveau_log.

EXEMPLES

Si vous démarrez yaz-ztest dans une console, vous pouvez utiliser le shell ZOOM comme suit :

$ zoomsh
ZOOM>connect localhost:9999
ZOOM>search computer
localhost:9999: 7 hits
ZOOM>show 0 1
1 Default USmarc
001    11224466
003 DLC
005 00000000000000.0
008 910710c19910701nju           00010 eng
010    $a    11224466
040    $a DLC $c DLC
050 00 $a 123-xyz
100 10 $a Jack Collins
245 10 $a How to program a computer
260 1  $a Penguin
263    $a 8710
300    $a p. cm.
ZOOM>quit

Vous pouvez également obtenir le même résultat en passant les commandes comme arguments sur une seule ligne de commande :

$ zoomsh "connect localhost:9999" "search computer" "show 0 1" quit

COMMANDES

connect zurl

Se connecte à la cible donnée par zurl.

close [zurl]

Ferme la connexion à la cible donnée par zurl ou à toutes les cibles si zurl a été omis.

show [début [nombre]]

Affiche nombre enregistrements en commençant à l'offset donné par début. Le premier enregistrement a l'offset 0 (contrairement au protocole Z39.50).

quit

Quitte zoomsh.

set nom [valeur]

Définit l'option nom à valeur.

get nom

Affiche la valeur de l'option nom.

help

Affiche la liste des commandes disponibles.
