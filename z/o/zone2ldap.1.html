NOM

zone2ldap - convertir des fichiers de zone en ldif

SYNTAXE

zone2ldap {--named-conf=CHEMIN,--zone-file=CHEMIN --zone-name=NOM} [OPTION]...

DESCRIPTION

zone2ldap est un programme qui convertit les fichiers de zone BIND en format ldif qui peut être inséré dans un serveur LDAP.

OPTIONS

--help
Afficher un résumé des options.
--basedn=<DN>
DN de base sous lequel stocker les objets
--dnsttl
Ajouter l'attribut dnsttl à chaque entrée
--layout=<layout>
Comment organiser les entrées dans le répertoire ("simple" ou "tree")
--named-conf=<CHEMIN>
Chemin vers un fichier named.conf de BIND à analyser
--resume
Continuer après les erreurs
--verbose
Commentaires détaillés sur le fonctionnement
--zone-file=<CHEMIN>
Fichier de zone à analyser
--zone-name=<NOM>
Spécifier un nom de zone si zone est défini
