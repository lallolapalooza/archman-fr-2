sous-routine zpptrs (caractère uplo, entier n, entier nrhs, complexe*16, dimension( * ) ap, complexe*16, dimension( ldb, * ) b, entier ldb, entier info)

ZPPTRS

But:

!>
!> ZPPTRS résout un système d'équations linéaires A*X = B avec une matrice
!> hermitienne positive définie A en stockage condensé, en utilisant la
!> factorisation de Cholesky A = U**H * U ou A = L * L**H calculée par ZPPTRF.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U': le triangle supérieur de A est stocké ;
!>          = 'L': le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B. NRHS >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H * U ou A = L * L**H, condensé par colonnes dans un
!>          tableau linéaire. La j-ème colonne de U ou L est stockée dans
!>          le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = U(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = L(i,j) pour j<=i<=n.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          En entrée, la matrice du côté droit B.
!>          En sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
