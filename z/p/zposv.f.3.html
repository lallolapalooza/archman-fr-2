Documentation de la fonction/sous-programme

sous-programme zposv (caractère uplo, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, entier info)

ZPOSV calcule la solution du système d'équations linéaires A * X = B pour les matrices PO

Objectif :

!>
!> ZPOSV calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice hermitienne définie positive N par N et X et B sont
!> des matrices N par NRHS.
!>
!> La décomposition de Cholesky est utilisée pour factoriser A en
!>    A = U**H * U,  si UPLO = 'U', ou
!>    A = L * L**H,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est une matrice triangulaire
!> inférieure. La forme factorisée de A est ensuite utilisée pour résoudre le
!> système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la matrice hermitienne A.  Si UPLO = 'U', la partie
!>          triangulaire supérieure principale N par N de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          triangulaire inférieure de A n'est pas référencée. Si UPLO = 'L',
!>          la partie triangulaire inférieure principale N par N de A contient
!>          la partie triangulaire inférieure de la matrice A, et la partie
!>          strictement triangulaire supérieure de A n'est pas référencée.
!>
!>          À la sortie, si INFO = 0, le facteur U ou L de la décomposition de
!>          Cholesky A = U**H *U ou A = L*L**H.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          À l'entrée, la matrice membre de droite B N par NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X N par NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : Sortie réussie.
!>          < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : Si INFO = i, le mineur principal de tête d'ordre i
!>                de A n'est pas positif, donc la factorisation n'a pas pu
!>                être terminée et la solution n'a pas été calculée.
!>
