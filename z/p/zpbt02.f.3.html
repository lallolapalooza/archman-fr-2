sous-programme zpbt02 (caractere uplo, entier n, entier kd, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldx, * ) x, entier ldx, complexe*16, dimension( ldb, * ) b, entier ldb, reel double precision, dimension( * ) rwork, reel double precision resid)

ZPBT02

But :

!>
!> ZPBT02 calcule le residu pour une solution d'un systeme d'equations
!> d'Hermitian bande A*x = b:
!>    RESID = norm( B - A*X ) / ( norm(A) * norm(X) * EPS)
!> ou EPS est la precision machine.
!>

Parametres

UPLO 
!>          UPLO est CHARACTER*1
!>          Specifie si la partie triangulaire superieure ou inferieure
!>          de la matrice A est stockee:
!>          = 'U': partie triangulaire superieure
!>          = 'L': partie triangulaire inferieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A. N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KD >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres. NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice bande originale d'Hermitian A. Si UPLO = 'U',
!>          la partie triangulaire superieure de A est stockee en tant que
!>          matrice bande; si UPLO = 'L', la partie triangulaire inferieure
!>          de A est stockee. Les colonnes de la partie appropriée du triangle
!>          sont stockees dans les colonnes de A et les diagonales du triangle
!>          sont stockees dans les lignes de A. Voir ZPBTRF pour plus de details.
!>

LDA

!>          LDA est INTEGER.
!>          La dimension principale du tableau A. LDA >= max(1,KD+1).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Les vecteurs solution calcules pour le systeme d'equations
!>          lineaires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          En entree, les vecteurs seconds membres pour le systeme d'equations
!>          lineaires.
!>          En sortie, B est ecrasé par la difference B - A*X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          Le maximum sur le nombre de seconds membres de
!>          norm(B - A*X) / ( norm(A) * norm(X) * EPS ).
!>
