Documentation de la fonction/sous-programme

sous-programme zppsvx (character fact, character uplo, integer n, integer nrhs, complex*16, dimension( * ) ap, complex*16, dimension( * ) afp, character equed, double precision, dimension( * ) s, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPPSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices AUTRES

But :

!>
!> ZPPSVX utilise la factorisation de Cholesky A = U**H * U ou A = L * L**H pour
!> calculer la solution d'un système complexe d'équations linéaires
!>    A * X = B,
!> où A est une matrice N-par-N hermitienne et positive définie stockée en
!> format compacté, et X et B sont des matrices N-par-NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de la condition
!> sont également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Le système sera équilibré ou non en fonction de l'échelle de la
!>    matrice A, mais si l'équilibrage est utilisé, A est écrasée par
!>    diag(S)*A*diag(S) et B par diag(S)*B.
!>
!> 2. Si FACT = 'N' ou 'E', la décomposition de Cholesky est utilisée pour
!>    factoriser la matrice A (après équilibrage si FACT = 'E') comme suit :
!>       A = U**H * U ,  si UPLO = 'U', ou
!>       A = L * L**H,  si UPLO = 'L',
!>    où U est une matrice triangulaire supérieure, L est une matrice
!>    triangulaire inférieure, et **H indique la transposée conjuguée.
!>
!> 3. Si le mineur principal principal d'ordre i n'est pas positif,
!>    la routine retourne avec INFO = i. Sinon, la forme factorisée de A
!>    est utilisée pour estimer le nombre de condition de la matrice
!>    A. Si l'inverse du nombre de condition est inférieur à la précision
!>    de la machine, INFO = N+1 est retourné comme avertissement, mais la
!>    routine continue pour résoudre X et calculer les bornes d'erreur comme
!>    décrit ci-dessous.
!>
!> 4. Le système d'équations est résolu pour X en utilisant la forme
!>    factorisée de A.
!>
!> 5. Un raffinement itératif est appliqué pour améliorer la solution
!>    calculée et obtenir des bornes d'erreur et des estimations d'erreur
!>    rétrograde pour celle-ci.
!>
!> 6. Si l'équilibrage a été utilisé, la matrice X est pré-multipliée par
!>    diag(S) afin qu'elle résolve le système original avant
!>    l'équilibrage.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est fournie
!>          en entrée, et si ce n'est pas le cas, si la matrice A doit être
!>          équilibrée avant d'être factorisée.
!>          = 'F' : En entrée, AFP contient la forme factorisée de A.
!>                  Si EQUED = 'Y', la matrice A a été équilibrée
!>                  avec les facteurs d'échelle donnés par S.
!>                  AP et AFP ne seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans AFP et factorisée.
!>          = 'E' : La matrice A sera équilibrée si nécessaire, puis
!>                  copiée dans AFP et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice
!>          hermitienne A, compacté par colonne dans un tableau linéaire,
!>          sauf si FACT = 'F' et EQUED = 'Y', auquel cas A doit contenir
!>          la matrice équilibrée diag(S)*A*diag(S). La j-ième colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.  A n'est pas modifié si
!>          FACT = 'F' ou 'N', ou si FACT = 'E' et EQUED = 'N' à la sortie.
!>
!>          À la sortie, si FACT = 'E' et EQUED = 'Y', A est écrasé par
!>          diag(S)*A*diag(S).
!>

AFP

!>          AFP est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          Si FACT = 'F', alors AFP est un argument d'entrée et contient
!>          à l'entrée le facteur triangulaire U ou L de la décomposition
!>          de Cholesky A = U**H*U ou A = L*L**H, dans le même format de
!>          stockage que A. Si EQUED .ne. 'N', alors AFP est la forme factorisée
!>          de la matrice équilibrée A.
!>
!>          Si FACT = 'N', alors AFP est un argument de sortie et retourne
!>          à la sortie le facteur triangulaire U ou L de la décomposition
!>          de Cholesky A = U**H * U ou A = L * L**H de la matrice originale
!>          A.
!>
!>          Si FACT = 'E', alors AFP est un argument de sortie et retourne
!>          à la sortie le facteur triangulaire U ou L de la décomposition
!>          de Cholesky A = U**H * U ou A = L * L**H de la matrice équilibrée
!>          A (voir la description de AP pour la forme de la matrice
!>          équilibrée).
!>

EQUED

!>          EQUED est CHARACTER*1
!>          Spécifie la forme d'équilibrage qui a été effectuée.
!>          = 'N' : Aucun équilibrage (toujours vrai si FACT = 'N').
!>          = 'Y' : L'équilibrage a été effectué, c'est-à-dire que A a été
!>                  remplacée par diag(S) * A * diag(S).
!>          EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un
!>          argument de sortie.
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (N)
!>          Les facteurs d'échelle pour A ; non accédé si EQUED = 'N'. S
!>          est un argument d'entrée si FACT = 'F' ; sinon, S est un argument
!>          de sortie. Si FACT = 'F' et EQUED = 'Y', chaque élément de S
!>          doit être positif.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          En entrée, la matrice du côté droit B, N-par-NRHS.
!>          À la sortie, si EQUED = 'N', B n'est pas modifié ; si EQUED = 'Y',
!>          B est écrasé par diag(S) * B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X, N-par-NRHS,
!>          du système original d'équations. Notez que si EQUED = 'Y',
!>          A et B sont modifiés à la sortie, et la solution du système
!>          équilibré est inv(diag(S))*X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'estimation du r

FERR

!>          FERR est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ième colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j). L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          majoration de l'erreur réelle.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire le plus petit changement relatif dans
!>          n'importe quel élément de A ou B qui fait de X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (N)
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= N : le mineur principal de tête d'ordre i de A
!>                       n'est pas positif, donc la factorisation n'a pas pu
!>                       être complétée, et la solution n'a pas été
!>                       calculée. RCOND = 0 est retourné.
!>                = N+1 : U est non singulier, mais RCOND est inférieur à la précision
!>                       machine, ce qui signifie que la matrice est singulière
!>                       à la précision de travail. Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car
!>                       il existe un certain nombre de situations où la
!>                       solution calculée peut être plus précise que ce que
!>                       la valeur de RCOND suggérerait.
!>
