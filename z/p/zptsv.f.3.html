subroutine zptsv (integer n, integer nrhs, double precision, dimension( * ) d, complex*16, dimension( * ) e, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZPTSV calcule la solution du système d'équations linéaires A * X = B pour les matrices PT

Objectif :

!>
!> ZPTSV calcule la solution d'un système d'équations linéaires complexes
!> A*X = B, où A est une matrice hermitienne positive définie tridiagonale N×N
!> et X et B sont des matrices N×NRHS.
!>
!> A est factorisée comme A = L*D*L**H, et la forme factorisée de A est ensuite
!> utilisée pour résoudre le système d'équations.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B. NRHS >= 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, de dimension (N)
!>          À l'entrée, les N éléments diagonaux de la matrice tridiagonale
!>          A. À la sortie, les N éléments diagonaux de la matrice diagonale
!>          D de la factorisation A = L*D*L**H.
!>

E

!>          E est un tableau COMPLEX*16, de dimension (N-1)
!>          À l'entrée, les N-1 éléments sous-diagonaux de la matrice
!>          tridiagonale A. À la sortie, les N-1 éléments sous-diagonaux du
!>          facteur bidiagonal unitaire L de la factorisation L*D*L**H de
!>          A. E peut également être considéré comme la superdiagonale du
!>          facteur bidiagonal unitaire U de la factorisation U**H*D*U de A.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice second membre B de taille N×NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N×NRHS.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le mineur principal de tête d'ordre i
!>                n'est pas positif, et la solution n'a pas été calculée.
!>                La factorisation n'est pas terminée, sauf si i = N.
!>
