sous-programme zposvx (character fact, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, character equed, double precision, dimension( * ) s, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPOSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices PO

Objectif :

!>
!> ZPOSVX utilise la factorisation de Cholesky A = U**H*U ou A = L*L**H pour
!> calculer la solution d'un système linéaire complexe
!>    A * X = B,
!> où A est une matrice hermitienne définie positive de taille N x N et X et B
!> sont des matrices de taille N x NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de la condition sont également
!> fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    L'équilibrage du système dépendra de la mise à l'échelle de la matrice A,
!>    mais s'il est utilisé, A est écrasée par diag(S)*A*diag(S) et B par diag(S)*B.
!>
!> 2. Si FACT = 'N' ou 'E', la décomposition de Cholesky est utilisée pour
!>    factoriser la matrice A (après équilibrage si FACT = 'E') en
!>       A = U**H* U,  si UPLO = 'U', ou
!>       A = L * L**H,  si UPLO = 'L',
!>    où U est une matrice triangulaire supérieure et L est une matrice triangulaire
!>    inférieure.
!>
!> 3. Si le mineur principal principal d'ordre i n'est pas positif,
!>    alors la routine renvoie INFO = i. Sinon, la forme factorisée de A est utilisée
!>    pour estimer le nombre de condition de la matrice A. Si l'inverse du nombre de
!>    condition est inférieur à la précision machine, INFO = N+1 est renvoyé
!>    à titre d'avertissement, mais la routine continue à résoudre pour X et à calculer
!>    les bornes d'erreur comme décrit ci-dessous.
!>
!> 4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 5. Un raffinement itératif est appliqué pour améliorer la matrice solution calculée
!>    et calculer les bornes d'erreur et les estimations d'erreur arrière pour celle-ci.
!>
!> 6. Si l'équilibrage a été utilisé, la matrice X est pré-multipliée par
!>    diag(S) afin de résoudre le système original avant
!>    l'équilibrage.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est fournie en entrée,
!>          et si ce n'est pas le cas, si la matrice A doit être équilibrée avant d'être factorisée.
!>          = 'F' : En entrée, AF contient la forme factorisée de A.
!>                  Si EQUED = 'Y', la matrice A a été équilibrée
!>                  avec des facteurs d'échelle donnés par S.
!>                  A et AF ne seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans AF et factorisée.
!>          = 'E' : La matrice A sera équilibrée si nécessaire, puis
!>                  copiée dans AF et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

A

!>          A est COMPLEX*16 array, dimension (LDA,N)
!>          En entrée, la matrice hermitienne A, sauf si FACT = 'F' et
!>          EQUED = 'Y', alors A doit contenir la matrice équilibrée
!>          diag(S)*A*diag(S).  Si UPLO = 'U', la partie
!>          supérieure triangulaire de A de taille N x N contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la partie
!>          inférieure triangulaire de A de taille N x N contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>          A n'est pas modifié si FACT = 'F' ou 'N', ou si FACT = 'E' et EQUED = 'N' à la sortie.
!>
!>          À la sortie, si FACT = 'E' et EQUED = 'Y', A est écrasé par
!>          diag(S)*A*diag(S).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est COMPLEX*16 array, dimension (LDAF,N)
!>          Si FACT = 'F', alors AF est un argument d'entrée et contient à l'entrée
!>          le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H *U ou A = L*L**H, dans le même format de stockage que A.
!>          Si EQUED .ne. 'N', alors AF est la forme factorisée
!>          de la matrice équilibrée diag(S)*A*diag(S).
!>
!>          Si FACT = 'N', alors AF est un argument de sortie et à la sortie
!>          renvoie le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H *U ou A = L*L**H de la matrice originale A.
!>
!>          Si FACT = 'E', alors AF est un argument de sortie et à la sortie
!>          renvoie le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H *U ou A = L*L**H de la matrice équilibrée A (voir la description de A
!>          pour la forme de la matrice équilibrée).
!>

LDAF

!>          LDAF est INTEGER
!>          La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

EQUED

!>          EQUED est CHARACTER*1
!>          Spécifie la forme d'équilibrage qui a été effectuée.
!>          = 'N' : Pas d'équilibrage (toujours vrai si FACT = 'N').
!>          = 'Y' : L'équilibrage a été effectué, c'est-à-dire que A a été remplacé par
!>                  diag(S) * A * diag(S).
!>          EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un
!>          argument de sortie.
!>

S

!>          S est DOUBLE PRECISION array, dimension (N)
!>          Les facteurs d'échelle pour A ; non accédé si EQUED = 'N'. S est
!>          un argument d'entrée si FACT = 'F' ; sinon, S est un argument de sortie.
!>          Si FACT = 'F' et EQUED = 'Y', chaque élément de S doit être positif.
!>

B

!>          B est COMPLEX*16 array, dimension (LDB,NRHS)
!>          En entrée, la matrice du côté droit B de taille N x NRHS.
!>          À la sortie, si EQUED = 'N', B n'est pas modifié ; si EQUED = 'Y',
!>          B est écrasé par diag(S) * B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est COMPLEX*16 array, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N x NRHS
!>          du système d'équations original. Notez que

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'estimation du nombre de conditionnement réciproque de la matrice
!>          A après équilibrage (si effectué). Si RCOND est inférieur à la
!>          précision machine (en particulier, si RCOND = 0), la matrice
!>          est singulière à la précision de travail. Cette condition
!>          est indiquée par un code de retour INFO > 0.
!>

FERR

!>          FERR est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>          La borne d'erreur directe estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisé par la magnitude du plus grand
!>          élément de X(j). L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          majoration de l'erreur réelle.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire, le plus petit changement relatif dans
!>          n'importe quel élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= N : le mineur principal de tête d'ordre i de A
!>                       n'est pas positif, donc la factorisation n'a pas pu
!>                       être complétée, et la solution n'a pas été
!>                       calculée. RCOND = 0 est retourné.

!>                       précision machine, ce qui signifie que la matrice est singulière

!>                       solution et les bornes d'erreur sont calculées car
!>                       il y a un certain nombre de situations où la
!>                       solution calculée peut être plus précise que la
