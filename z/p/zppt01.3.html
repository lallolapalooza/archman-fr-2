Documentation de la fonction/sous-routine

sous-routine zppt01 (caractère uplo, entier n, complexe*16, dimension( * ) a, complexe*16, dimension( * ) afac, double précision, dimension( * ) rwork, double précision resid)

ZPPT01

But :

!>
!> ZPPT01 reconstruit une matrice hermitienne définie positive empaquetée A
!> à partir de sa factorisation L*L' ou U'*U et calcule le résidu
!>    norm( L*L' - A ) / ( N * norm(A) * EPS ) ou
!>    norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> où EPS est l'epsilon machine, L' est la transposée conjuguée de
!> L, et U' est la transposée conjuguée de U.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice hermitienne A est stockée :
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          La matrice hermitienne originale A, stockée comme une matrice
!>          triangulaire empaquetée.
!>

AFAC

!>          AFAC est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          En entrée, le facteur L ou U de la factorisation L*L' ou U'*U
!>          de A, stocké comme une matrice triangulaire empaquetée.
!>          Est écrasé par la matrice reconstruite, puis par la
!>          différence L*L' - A (ou U'*U - A).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          Si UPLO = 'L', norm(L*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U'*U - A) / ( N * norm(A) * EPS )
!>
