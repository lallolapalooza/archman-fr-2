Documentation de la fonction/sous-routine

sous-routine zpbcon (caractère uplo, entier n, entier kd, complexe*16, dimension( ldab, * ) ab, entier ldab, réel double précision anorm, réel double précision rcond, complexe*16, dimension( * ) work, réel double précision, dimension( * ) rwork, entier info)

ZPBCON

But :

!>
!> ZPBCON estime la réciproque du nombre de conditionnement (en norme
!> 1) d'une matrice bande complexe hermitienne définie positive, utilisant
!> la factorisation de Cholesky A = U**H*U ou A = L*L**H calculée par
!> ZPBTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et la réciproque du
!> nombre de conditionnement est calculée comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  facteur triangulaire supérieur stocké dans AB;
!>          = 'L':  facteur triangulaire inférieur stocké dans AB.
!>

N

!>          N est ENTIER
!>          Ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est ENTIER
!>          Nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, dimension (LDAB,N)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H*U ou A = L*L**H de la matrice bande A, stocké dans les
!>          KD+1 premières lignes du tableau. La j-ème colonne de U ou L
!>          est stockée dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO ='U', AB(kd+1+i-j,j) = U(i,j) pour max(1,j-kd)<=i<=j;
!>          si UPLO ='L', AB(1+i-j,j)    = L(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est ENTIER
!>          Dimension principale du tableau AB.  LDAB >= KD+1.
!>

ANORM

!>          ANORM est REEL DOUBLE PRÉCISION
!>          La norme 1 (ou norme infinie) de la matrice bande hermitienne A.
!>

RCOND

!>          RCOND est REEL DOUBLE PRÉCISION
!>          La réciproque du nombre de conditionnement de la matrice A,
!>          calculée comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau REEL DOUBLE PRÉCISION, dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
