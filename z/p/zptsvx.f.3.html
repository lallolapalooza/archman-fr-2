sous-routine zptsvx (character fact, integer n, integer nrhs, double precision, dimension( * ) d, complex*16, dimension( * ) e, double precision, dimension( * ) df, complex*16, dimension( * ) ef, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPTSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices PT

Objectif :

!>
!> ZPTSVX utilise la factorisation A = L*D*L**H pour calculer la solution
!> d'un système linéaire complexe A*X = B, où A est une matrice
!> tridiagonale hermitienne et définie positive de taille N x N, et X et B
!> sont des matrices de taille N x NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de la condition
!> sont également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la matrice A est factorisée sous la forme A = L*D*L**H,
!>    où L est une matrice bidiagonale inférieure unitaire et D est diagonale.
!>    La forme factorisée peut également être considérée comme A = U**H*D*U.
!>
!> 2. Si le mineur principal principal d'ordre i n'est pas positif,
!>    alors la routine renvoie INFO = i. Sinon, la forme factorisée de A
!>    est utilisée pour estimer le nombre de conditionnement de la matrice
!>    A. Si l'inverse du nombre de conditionnement est inférieur à la
!>    précision machine, INFO = N+1 est renvoyé à titre d'avertissement,
!>    mais la routine continue à calculer X et les bornes d'erreur comme
!>    décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme
!>    factorisée de A.
!>
!> 4. Un raffinement itératif est appliqué pour améliorer la solution
!>    calculée et obtenir des bornes d'erreur et des estimations d'erreur
!>    arrière pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est fournie
!>          en entrée.
!>          = 'F' : En entrée, DF et EF contiennent la forme factorisée de A.
!>                  D, E, DF et EF ne seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans DF et EF et
!>                  factorisée.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

D

!>          D est un tableau de type DOUBLE PRECISION, dimension (N)
!>          Les N éléments diagonaux de la matrice tridiagonale A.
!>

E

!>          E est un tableau de type COMPLEX*16, dimension (N-1)
!>          Les N-1 éléments sous-diagonaux de la matrice tridiagonale A.
!>

DF

!>          DF est un tableau de type DOUBLE PRECISION, dimension (N)
!>          Si FACT = 'F', alors DF est un argument d'entrée et contient en
!>          entrée les N éléments diagonaux de la matrice diagonale D
!>          de la factorisation L*D*L**H de A.
!>          Si FACT = 'N', alors DF est un argument de sortie et contient en
!>          sortie les N éléments diagonaux de la matrice diagonale D
!>          de la factorisation L*D*L**H de A.
!>

EF

!>          EF est un tableau de type COMPLEX*16, dimension (N-1)
!>          Si FACT = 'F', alors EF est un argument d'entrée et contient en
!>          entrée les N-1 éléments sous-diagonaux du facteur bidiagonal
!>          unitaire L de la factorisation L*D*L**H de A.
!>          Si FACT = 'N', alors EF est un argument de sortie et contient en
!>          sortie les N-1 éléments sous-diagonaux du facteur bidiagonal
!>          unitaire L de la factorisation L*D*L**H de A.
!>

B

!>          B est un tableau de type COMPLEX*16, dimension (LDB,NRHS)
!>          La matrice B de taille N x NRHS des membres de droite.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau de type COMPLEX*16, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N x NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'inverse du nombre de conditionnement de la matrice A. Si RCOND
!>          est inférieur à la précision machine (en particulier, si
!>          RCOND = 0), la matrice est singulière à la précision de travail.
!>          Cette condition est indiquée par un code de retour INFO > 0.
!>

FERR

!>          FERR est un tableau de type DOUBLE PRECISION, dimension (NRHS)
!>          La borne d'erreur avant pour chaque vecteur solution
!>          X(j) (la j-ième colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j).
!>

BERR

!>          BERR est un tableau de type DOUBLE PRECISION, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque
!>          vecteur solution X(j) (c'est-à-dire la plus petite modification
!>          relative de tout élément de A ou B qui fait de X(j) une solution
!>          exacte).
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, dimension (N)
!>

RWORK

!>          RWORK est un tableau de type DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= N : le mineur principal principal d'ordre i de A
!>                       n'est pas positif, donc la factorisation n'a pas pu
!>                       être complétée, et la solution n'a pas été
!>                       calculée. RCOND = 0 est renvoyé.
!>                = N+1 : U est non singulière, mais RCOND est inférieur à la
!>                       précision machine, ce qui signifie que la matrice est
!>                       singulière à la précision de travail.
!>                       Néanmoins, la solution et les bornes d'erreur sont
!>                       calculées car il existe un certain nombre de
!>                       situations où la solution calculée peut être plus
!>                       précise que ce que suggère la valeur de RCOND.
!>
