Documentation de fonction/sous-routine

sous-routine zpst01 (caractere uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldafac, * ) afac, entier ldafac, complexe*16, dimension( ldperm, * ) perm, entier ldperm, entier, dimension( * ) piv, double precision, dimension( * ) rwork, double precision resid, entier rank)

ZPST01

Objectif :

!>
!> ZPST01 reconstruit une matrice hermitienne semi-définie positive A
!> à partir de ses facteurs L ou U et de la matrice de permutation P, et calcule
!> le résidu
!>    norm( P*L*L'*P' - A ) / ( N * norm(A) * EPS ) ou
!>    norm( P*U'*U*P' - A ) / ( N * norm(A) * EPS ),
!> où EPS est l'epsilon machine, L' est la transposée conjuguée de L,
!> et U' est la transposée conjuguée de U.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice hermitienne A est stockée :
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice hermitienne originale A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N)
!>

AFAC

!>          AFAC est un tableau COMPLEX*16, dimension (LDAFAC,N)
!>          Le facteur L ou U de la factorisation L*L' ou U'*U de A.
!>

LDAFAC

!>          LDAFAC est INTEGER
!>          La dimension principale du tableau AFAC. LDAFAC >= max(1,N).
!>

PERM

!>          PERM est un tableau COMPLEX*16, dimension (LDPERM,N)
!>          La matrice est écrasée avec la matrice reconstruite, puis avec la
!>          différence P*L*L'*P' - A (ou P*U'*U*P' - A)
!>

LDPERM

!>          LDPERM est INTEGER
!>          La dimension principale du tableau PERM.
!>          LDAPERM >= max(1,N).
!>

PIV

!>          PIV est un tableau INTEGER, dimension (N)
!>          PIV est tel que les entrées non nulles sont
!>          P( PIV( K ), K ) = 1.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          Si UPLO = 'L', norm(L*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U'*U - A) / ( N * norm(A) * EPS )
!>

RANK

!>          RANK est INTEGER
!>          nombre de valeurs singulières non nulles de A.
!>
