NOM

zps - lister/récupérer les processus zombies

SYNTAXE

zps [options]

DESCRIPTION

zps liste les processus en cours d'exécution avec leurs statistiques et indique/récupère les processus zombies.

OPTIONS

-v, --version
Afficher les informations de version.
-h, --help
Afficher le texte d'aide.
-a, --all
Lister tous les processus de l'espace utilisateur (pas seulement les zombies).
-r, --reap
Récupérer les processus zombies.
-s sig, --signal=sig, --signal sig
Utiliser le signal sig sur les parents zombies (par défaut : SIGTERM).
-p, --prompt
Afficher une invite pour sélectionner les processus.
-q, --quiet
Récupérer en mode silencieux.
-n, --no-color
Désactiver la sortie couleur.

BOGUES

Aucun bogue connu. Utilisez la page « Issues » pour signaler les bogues : https://github.com/orhun/zps/issues/
