sous-routine zptsvx (character fact, integer n, integer nrhs, double precision, dimension( * ) d, complex*16, dimension( * ) e, double precision, dimension( * ) df, complex*16, dimension( * ) ef, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPTSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices PT

Objectif :

!>
!> ZPTSVX utilise la factorisation A = L*D*L**H pour calculer la solution
!> d'un système complexe d'équations linéaires A*X = B, où A est une matrice
!> tridiagonale hermitienne définie positive de taille N x N et X et B
!> sont des matrices de taille N x NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de condition sont également
!> fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la matrice A est factorisée en A = L*D*L**H, où L
!>    est une matrice bidiagonale inférieure unitaire et D est diagonale. La
!>    factorisation peut également être considérée comme ayant la forme
!>    A = U**H*D*U.
!>
!> 2. Si le mineur principal de tête d'ordre i n'est pas positif,
!>    alors la routine retourne avec INFO = i. Sinon, la forme factorisée
!>    de A est utilisée pour estimer le nombre de conditionnement de la matrice
!>    A. Si l'inverse du nombre de conditionnement est inférieur à la précision machine,
!>    INFO = N+1 est retourné comme avertissement, mais la routine continue
!>    à résoudre pour X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 4. Un raffinement itératif est appliqué pour améliorer la solution calculée
!>    et calculer les bornes d'erreur et les estimations d'erreur arrière
!>    pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice
!>          A est fournie ou non à l'entrée.
!>          = 'F' : À l'entrée, DF et EF contiennent la forme factorisée de A.
!>                  D, E, DF et EF ne seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans DF et EF et
!>                  factorisée.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

D

!>          D est un tableau de type DOUBLE PRECISION, dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale A.
!>

E

!>          E est un tableau de type COMPLEX*16, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de la matrice tridiagonale A.
!>

DF

!>          DF est un tableau de type DOUBLE PRECISION, dimension (N)
!>          Si FACT = 'F', alors DF est un argument d'entrée et contient à l'entrée
!>          les n éléments diagonaux de la matrice diagonale D
!>          issue de la factorisation L*D*L**H de A.
!>          Si FACT = 'N', alors DF est un argument de sortie et contient à la sortie
!>          les n éléments diagonaux de la matrice diagonale D
!>          issue de la factorisation L*D*L**H de A.
!>

EF

!>          EF est un tableau de type COMPLEX*16, dimension (N-1)
!>          Si FACT = 'F', alors EF est un argument d'entrée et contient à l'entrée
!>          les (n-1) éléments sous-diagonaux du facteur bidiagonal unitaire
!>          L issu de la factorisation L*D*L**H de A.
!>          Si FACT = 'N', alors EF est un argument de sortie et contient à la sortie
!>          les (n-1) éléments sous-diagonaux du facteur bidiagonal unitaire
!>          L issu de la factorisation L*D*L**H de A.
!>

B

!>          B est un tableau de type COMPLEX*16, dimension (LDB,NRHS)
!>          La matrice membre de droite B de taille N x NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau de type COMPLEX*16, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N x NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'inverse du nombre de conditionnement de la matrice A.  Si RCOND
!>          est inférieur à la précision machine (en particulier, si
!>          RCOND = 0), la matrice est singulière à la précision de travail.
!>          Cette condition est indiquée par un code de retour INFO > 0.
!>

FERR

!>          FERR est un tableau de type DOUBLE PRECISION, dimension (NRHS)
!>          La borne d'erreur avant pour chaque vecteur solution
!>          X(j) (la j-ième colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j).
!>

BERR

!>          BERR est un tableau de type DOUBLE PRECISION, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire le plus petit changement relatif dans n'importe quel
!>          élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, dimension (N)
!>

RWORK

!>          RWORK est un tableau de type DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ième argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= N : le mineur principal de tête d'ordre i de A
!>                       n'est pas positif, donc la factorisation n'a pas pu
!>                       être terminée, et la solution n'a pas été
!>                       calculée. RCOND = 0 est retourné.
!>                = N+1 : U est non singulière, mais RCOND est inférieur à la précision machine,
!>                       ce qui signifie que la matrice est singulière
!>                       à la précision de travail. Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car
!>                       il existe un certain nombre de situations où la
!>                       solution calculée peut être plus précise que la
!>                       valeur de RCOND ne le suggérerait.
!>

    INTEGER :: N, NRHS, LDB, LDX, INFO
    INTEGER, DIMENSION(N) :: FER
    DOUBLE PRECISION, DIMENSION(N) :: D, DF, FER
    DOUBLE PRECISION, DIMENSION(N-1) :: E, EF

Function/Subroutine Documentation

ZPTSVX uses the Left-Looking Block method to solve the system of linear equations $A \cdot X = B$, where $A$ is a symmetric positive definite tridiagonal matrix.

It is used to compute the solution $X$ of the tridiagonal system of linear equations $A \cdot X = B$. This routine is a driver for computation of the solution $X$, and also computes an error bound for the solution.

The matrix $A$ is symmetric and positive definite tridiagonal.

Arguments:

  • FACT: (input) CHARACTER*1. Specifies whether or not the factorization of the matrix A is supplied. FACT = 'N': the factorization is not supplied. FACT = 'F': the factorization is supplied.
  • UPLO: (input) CHARACTER*1. Specifies whether the upper or lower triangular part of the matrix A is supplied. UPLO = 'U': Upper triangular. UPLO = 'L': Lower triangular.
  • N: (input) INTEGER. The order of the matrix A. N ≥ 0.
  • NRHS: (input) INTEGER. The number of right hand sides, i.e., the number of columns of the matrices B and X. NRHS ≥ 1.
  • D: (input) DOUBLE PRECISION array, dimension (N). If FACT = 'F', D must contain the diagonal elements of the tridiagonal matrix $A$.
  • E: (input) DOUBLE PRECISION array, dimension (N-1). If FACT = 'F', E must contain the off-diagonal elements of the tridiagonal matrix $A$.
  • DF: (output) DOUBLE PRECISION array, dimension (N). If FACT = 'N', DF contains the diagonal elements of the tridiagonal matrix $A$ and its factors. If FACT = 'F', DF is not used.
  • EF: (output) DOUBLE PRECISION array, dimension (N-1). If FACT = 'N', EF contains the off-diagonal elements of the tridiagonal matrix $A$ and its factors. If FACT = 'F', EF is not used.
  • FER: (output) INTEGER array, dimension (N). If FACT = 'N', FER(i) contains the pivot row for row i of the factorization. If FACT = 'F', FER is not used.
  • AF: (input/output) COMPLEX*16 array, dimension (LDB,*). If FACT = 'F', AF contains the factored matrix $A$. If FACT = 'N', AF is used to store the factored matrix $A$.
  • B: (input) COMPLEX*16 array, dimension (LDB, NRHS). The right-hand side matrix.
  • LDB: (input) INTEGER. The leading dimension of the array $B$. LDB ≥ max(1, N).
  • X: (output) COMPLEX*16 array, dimension (LDX, NRHS). The solution matrix.
  • LDX: (input) INTEGER. The leading dimension of the array $X$. LDX ≥ max(1, N).
  • RCOND: (output) DOUBLE PRECISION. The reciprocal of the condition number of A. The system may be ill-conditioned if RCOND is small.
  • SRVCND: (output) DOUBLE PRECISION. The condition number of the matrix.
  • BERR: (output) DOUBLE PRECISION array, dimension (NRHS). The componentwise error bounds for each column of $X$.
  • INFO: (output) INTEGER. = 0: successful exit. < 0: if INFO = -i, the i-th argument had an illegal value. > 0: if INFO = i, and i ≤ N, the factorization of $A$ could not be completed, and the solution could not be computed. i is the number of diagonal entries which are not positive. > 0: if INFO = i, and i > N, the number of entries which are not positive is i-N.
