ZPBSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices OTHER

Objectif :

!>
!> ZPBSVX utilise la factorisation de Cholesky A = U**H*U ou A = L*L**H pour
!> calculer la solution d'un système complexe d'équations linéaires
!>    A * X = B,
!> où A est une matrice bande hermitienne définie positive de taille N x N, et X
!> et B sont des matrices de taille N x NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de la condition sont également
!> fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    L'équilibrage du système dépendra de la mise à l'échelle de la matrice A,
!>    mais si l'équilibrage est utilisé, A est écrasée par diag(S)*A*diag(S) et B par diag(S)*B.
!>
!> 2. Si FACT = 'N' ou 'E', la décomposition de Cholesky est utilisée pour
!>    factoriser la matrice A (après équilibrage si FACT = 'E') comme suit :
!>       A = U**H * U,  si UPLO = 'U', ou
!>       A = L * L**H,  si UPLO = 'L',
!>    où U est une matrice bande triangulaire supérieure, et L est une matrice bande triangulaire inférieure.
!>
!> 3. Si le mineur principal de tête d'ordre i n'est pas positif,
!>    la routine se termine avec INFO = i. Sinon, la forme factorisée de A est
!>    utilisée pour estimer le nombre de condition de la matrice A. Si l'inverse
!>    du nombre de condition est inférieur à la précision machine, INFO = N+1
!>    est retourné comme avertissement, mais la routine continue à résoudre pour X
!>    et calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 5. Un raffinement itératif est appliqué pour améliorer la solution calculée
!>    et calculer les bornes d'erreur et les estimations d'erreur arrière pour celle-ci.
!>
!> 6. Si l'équilibrage a été utilisé, la matrice X est pré-multipliée par
!>    diag(S) de sorte qu'elle résolve le système original avant
!>    l'équilibrage.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est fournie en entrée,
!>          et sinon, si la matrice A doit être équilibrée avant d'être factorisée.
!>          = 'F' : En entrée, AFB contient la forme factorisée de A.
!>                  Si EQUED = 'Y', la matrice A a été équilibrée
!>                  avec des facteurs d'échelle donnés par S. AB et AFB ne seront
!>                  pas modifiés.
!>          = 'N' : La matrice A sera copiée dans AFB et factorisée.
!>          = 'E' : La matrice A sera équilibrée si nécessaire, puis
!>                  copiée dans AFB et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est tableau COMPLEX*16, dimension (LDAB,N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande hermitienne
!>          A, stocké dans les KD+1 premières lignes du tableau, sauf si
!>          FACT = 'F' et EQUED = 'Y', alors A doit contenir
!>          la matrice équilibrée diag(S)*A*diag(S). La j-ème colonne de A
!>          est stockée dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) pour max(1,j-KD)<=i<=j ;

NAME

zpbsvx - computes the solution to a complex Hermitian-positive definite band system of linear equations

SYNOPSIS

SUBROUTINE ZPBSVX( FACT, UPLO, N, KD, NRHS, AB, LDAB, AFB, LDAFB, DIP,
                     RCOND, EQUED, B, LDB, X, LDX, RWORK, WORK, INFO )
        

CHARACTER * 1       FACT, UPLO, EQUED
INTEGER           N, KD, NRHS, LDAB, LDAFB, LDB, LDX, INFO
COMPLEX*16        AB( LDAB, * ), AFB( LDAFB, * ), DIP( * ), WORK( * )
DOUBLE PRECISION  RCOND, RWORK( * )
COMPLEX*16        B( LDB, * ), X( LDX, * )

Function/Subroutine Documentation

ZPBSVX is a subroutine in LAPACK for solving a system of linear equations of the form A*X = B, where A is a complex Hermitian- positive definite band matrix.

The routine uses a band variant of the Cholesky factorization. It also computes an estimate of the reciprocal condition number of the matrix A and uses this to estimate forward and backward error bounds for the computed solution X.

Input Parameters:

FACT
CHARACTER*1. Specifies whether or not the factorization of the matrix A is supplied on exit.
FACT = 'F': On entry, the upper or lower triangular band matrix `AFB` contains the Cholesky factor `U` or `L` of `A` such that `A = U**H * U` or `A = L * L**H`. `AB`, `LDAB`, `AFB`, and `LDAFB` may be modified on exit.
FACT = 'N': On entry, the upper or lower triangular band matrix `AFB` must contain the upper or lower triangular part of the band matrix `A`. The routine returns the Cholesky factor `U` or `L` of `A` in `AFB`.
UPLO
CHARACTER*1. Specifies whether the upper or lower triangular band matrix is stored in the array `AB`.
UPLO = 'U': Upper triangle of `A` is stored.
UPLO = 'L': Lower triangle of `A` is stored.
N
INTEGER. The order of the matrix `A`. 0 <= N.
KD
INTEGER. The number of super-diagonals of the band matrix `A` if `UPLO = 'U'`, or the number of sub-diagonals if `UPLO = 'L'`. 0 <= KD < N.
NRHS
INTEGER. The number of right-hand sides, i.e., the number of columns of the matrices `B` and `X`. 0 <= NRHS.
AB
COMPLEX*16 array, dimension (LDAB, K+1).
On entry, the upper or lower triangular band matrix `A` in band storage format. The relevant elements of the upper triangle are stored in the columns `KD` to 0 of `AB` and the elements of the lower triangle are stored in the columns 0 to `KD` of `AB`. See "Further Details" for more information.
On exit, if `FACT = 'N'`, the elements of A are overwritten by elements of the array `DIP`.
LDAB
INTEGER. The leading dimension of the array `AB`. LDAB >= KD + 1.
AFB
COMPLEX*16 array, dimension (LDAFB, K+1) if K = KD. On entry, if `FACT = 'F'`, `AFB` contains the Cholesky factor `U` or `L` of `A`. On exit, if `FACT = 'N'`, `AFB` contains the Cholesky factor `U` or `L` of `A`.
LDAFB
INTEGER. The leading dimension of the array `AFB`. LDAFB >= KD + 1.
DIP
COMPLEX*16 array, dimension (N). On exit, if `FACT = 'N'`, the diagonal elements of the factor `U` or `L`.
RCOND
DOUBLE PRECISION. On exit, an estimate of the reciprocal condition number of the matrix `A` after equilibration (if done).
EQUED
CHARACTER*1. On exit, `EQUED` is 'Y' if the matrix `A` was scaled, i.e. `A` = diag(S)*A*diag(S); otherwise, `EQUED` is 'N'.
B
COMPLEX*16 array, dimension (LDB, NRHS). On entry, the N-by-NRHS matrix of right-hand sides.
LDB
INTEGER. The leading dimension of the array `B`. LDB >= max(1,N).
X
COMPLEX*16 array, dimension (LDX, NRHS). On exit, if INFO = 0 or INFO = N+1, the N-by-NRHS solution matrix X to the original system of equations. Note that if EQUED = 'Y', A and B are modified on exit, and the solution to the equilibrated system is inv(diag(S))*X.
LDX
INTEGER. The leading dimension of the array X. LDX >= max(1,N).
RCOND
DOUBLE PRECISION. The estimate of the reciprocal condition number of the matrix A after equilibration (if done). If RCOND is less than the machine precision (in particular, if RCOND = 0), the matrix is singular to working precision. This condition is indicated by a return code of INFO > 0.
FERR
DOUBLE PRECISION array, dimension (NRHS). The estimated forward error bound for each solution vector X(j) (the j-th column of the solution matrix X). If XTRUE is the true solution corresponding to X(j), FERR(j) is an estimated upper bound for the magnitude of the largest element in (X(j) - XTRUE) divided by the magnitude of the largest element in X(j). The estimate is as reliable as the estimate for RCOND, and is almost always a slight overestimate of the true error.
BERR
DOUBLE PRECISION array, dimension (NRHS). The componentwise relative backward error of each solution vector X(j) (i.e., the smallest relative change in any element of A or B that makes X(j) an exact solution).
WORK
COMPLEX*16 array, dimension (2*N).
RWORK
DOUBLE PRECISION array, dimension (N).
INFO
INTEGER.
  • 0: successful exit
  • < 0: if INFO = -i, the i-th argument had an illegal value
  • > 0: if INFO = i, and i is
  • <= N: the leading principal minor of order i of A is not positive, so the factorization could not be completed, and the solution has not been computed. RCOND = 0 is returned.
  • = N+1: U is nonsingular, but RCOND is less than machine precision, meaning that the matrix is singular to working precision. Nevertheless, the solution and error bounds are computed because there are a number of situations where the computed solution can be more accurate than the value of RCOND would suggest.
