sous-programme zppequ (caractere uplo, entier n, complexe*16, dimension( * ) ap, double precision, dimension( * ) s, double precision scond, double precision amax, entier info)

ZPPEQU

Objectif :

!>
!> ZPPEQU calcule les mises à l'échelle des lignes et des colonnes destinées à équilibrer une
!> matrice hermitienne définie positive A en stockage condensé et à réduire
!> son nombre de conditionnement (par rapport à la norme deux). S contient les
!> facteurs d'échelle, S(i)=1/sqrt(A(i,i)), choisis de telle sorte que la matrice mise à l'échelle
!> B dont les éléments B(i,j)=S(i)*A(i,j)*S(j) ait des uns sur la diagonale.
!> Ce choix de S place le nombre de conditionnement de B dans un facteur N du
!> plus petit nombre de conditionnement possible sur toutes les mises à l'échelle diagonales possibles.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          Le triangle supérieur ou inférieur de la matrice hermitienne A, condensé
!>          par colonnes dans un tableau linéaire. La j-ème colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>

S

!>          S est un tableau DOUBLE PRECISION, de dimension (N)
!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!>

SCOND

!>          SCOND est DOUBLE PRECISION
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i). Si SCOND >= 0.1 et AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas nécessaire de mettre à l'échelle avec S.
!>

AMAX

!>          AMAX est DOUBLE PRECISION
!>          Valeur absolue de l'élément de matrice le plus grand. Si AMAX est très
!>          proche du dépassement de capacité ou de la sous-dépassement, la matrice
!>          devrait être mise à l'échelle.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>          > 0 : si INFO = i, le i-ème élément diagonal est non positif.
!>
