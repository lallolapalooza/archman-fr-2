Documentation de la fonction/sous-programme

sous-programme zpoequb (integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, double precision scond, double precision amax, integer info)

ZPOEQUB

But :

!>
!> ZPOEQUB calcule des échelles de lignes et de colonnes destinées à équilibrer
!> une matrice A hermitienne définie positive et à réduire son conditionnement
!> (par rapport à la norme deux). S contient les facteurs d'échelle,
!> S(i) = 1/sqrt(A(i,i)), choisis de telle sorte que la matrice mise à l'échelle B
!> avec les éléments B(i,j) = S(i)*A(i,j)*S(j) ait des uns sur la diagonale.
!> Ce choix de S place le conditionnement de B dans un facteur N du
!> conditionnement le plus petit possible sur toutes les mises à l'échelle diagonales possibles.
!>
!> Cette routine diffère de ZPOEQU en limitant les facteurs d'échelle à une puissance
!> du radix. À l'exception des dépassements (overflow et underflow), la mise à l'échelle
!> par ces facteurs n'introduit pas d'erreurs d'arrondi supplémentaires. Cependant,
!> les éléments diagonaux mis à l'échelle ne sont plus approximativement 1 mais se situent
!> entre sqrt(radix) et 1/sqrt(radix).
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice hermitienne définie positive N x N dont les facteurs
!>          d'échelle doivent être calculés. Seuls les éléments diagonaux de A
!>          sont référencés.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (N)
!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!>

SCOND

!>          SCOND est un DOUBLE PRECISION
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i).  Si SCOND >= 0.1 et que AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas utile de mettre à l'échelle par S.
!>

AMAX

!>          AMAX est un DOUBLE PRECISION
!>          Valeur absolue de l'élément matriciel le plus grand. Si AMAX est très
!>          proche du dépassement (overflow) ou très proche du sous-dépassement (underflow),
!>          la matrice doit être mise à l'échelle.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 :  réussite
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  si INFO = i, le i-ème élément diagonal est non positif.
!>
