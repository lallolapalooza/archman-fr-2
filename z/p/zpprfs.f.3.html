sous-programme zpprfs (caractère uplo, entier n, entier nrhs, complexe*16, dimension( * ) ap, complexe*16, dimension( * ) afp, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldx, * ) x, entier ldx, précision double, dimension( * ) ferr, précision double, dimension( * ) berr, complexe*16, dimension( * ) work, précision double, dimension( * ) rwork, entier info)

ZPPRFS

Objectif :

!>
!> ZPPRFS améliore la solution calculée d'un système d'équations linéaires
!> lorsque la matrice de coefficients est hermitienne définie positive
!> et empaquetée, et fournit des bornes d'erreur et des estimations d'erreur arrière
!> pour la solution.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          Le triangle supérieur ou inférieur de la matrice hermitienne A, empaqueté
!>          par colonne dans un tableau linéaire. La j-ème colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>

AFP

!>          AFP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          Le facteur triangulaire U ou L issu de la factorisation de Cholesky
!>          A = U**H*U ou A = L*L**H, tel que calculé par DPPTRF/ZPPTRF,
!>          empaqueté par colonne dans un tableau linéaire du même format que A
!>          (voir AP).
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice des membres de droite B.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, de dimension (LDX,NRHS)
!>          À l'entrée, la matrice solution X, telle que calculée par ZPPTRS.
!>          À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est un ENTIER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

FERR

!>          FERR est un tableau de PRÉCISION DOUBLE, de dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j). L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          sous-estimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau de PRÉCISION DOUBLE, de dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire le plus petit changement relatif dans
!>          n'importe quel élément de A ou B qui fait de X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau de PRÉCISION DOUBLE, de dimension (N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale
!>

Paramètres internes :

!>  ITMAX est le nombre maximum d'étapes de raffinement itératif.
!>
