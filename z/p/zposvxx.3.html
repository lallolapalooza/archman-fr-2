Fonctions/Sous-routines


sous-routine zposvxx (fact, uplo, n, nrhs, a, lda, af, ldaf, equed, s, b, ldb, x, ldx, rcond, rpvgrw, berr, n_err_bnds, err_bnds_norm, err_bnds_comp, nparams, params, work, rwork, info)
ZPOSVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices PO

Documentation de la fonction/sous-routine

sous-routine zposvxx (character fact, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, character equed, double precision, dimension( * ) s, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision rpvgrw, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPOSVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices PO (Hermitiennes positives définies)

But :

!>
!>    ZPOSVXX utilise la factorisation de Cholesky A = U**T*U ou A = L*L**T
!>    pour calculer la solution d'un système d'équations linéaires complexe*16
!>    A * X = B, où A est une matrice Hermitienne positive définie de taille N*N
!>    et X et B sont des matrices de taille N*NRHS.
!>
!>    Si demandé, des bornes d'erreur normées et des bornes d'erreur
!>    composantes maximales sont retournées. ZPOSVXX retournera une solution
!>    avec une erreur garantie minuscule (O(eps) où eps est la précision
!>    de la machine de travail) à moins que la matrice ne soit très mal
!>    conditionnée, auquel cas un avertissement est retourné. Les nombres de
!>    condition pertinents sont également calculés et retournés.
!>
!>    ZPOSVXX accepte des factorisations et des facteurs d'équilibration
!>    fournis par l'utilisateur ; voir les définitions des options FACT et EQUED.
!>    La résolution avec raffinement et l'utilisation d'une factorisation
!>    d'un appel précédent à ZPOSVXX produiront également une solution avec
!>    des erreurs O(eps) ou des avertissements, mais nous ne pouvons pas
!>    prétendre cela pour des factorisations et des facteurs d'équilibration
!>    généraux fournis par l'utilisateur s'ils diffèrent de ce que ZPOSVXX
!>    produirait lui-même.
!>

Description :

!>
!>    Les étapes suivantes sont effectuées :
!>
!>    1. Si FACT = 'E', des facteurs d'échelle en double précision sont calculés
!>    pour équilibrer le système :
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Le système sera équilibré ou non en fonction de la mise à l'échelle
!>    de la matrice A, mais si l'équilibration est utilisée, A est
!>    remplacée par diag(S)*A*diag(S) et B par diag(S)*B.
!>
!>    2. Si FACT = 'N' ou 'E', la décomposition de Cholesky est utilisée pour
!>    factoriser la matrice A (après équilibration si FACT = 'E') comme suit :
!>       A = U**T* U,  si UPLO = 'U', ou
!>       A = L * L**T,  si UPLO = 'L',
!>    où U est une matrice triangulaire supérieure et L est une matrice
!>    triangulaire inférieure.
!>
!>    3. Si le mineur principal principal d'ordre i n'est pas positif,
!>    alors la routine retourne avec INFO = i. Sinon, la forme factorisée
!>    de A est utilisée pour estimer le nombre de condition de la matrice
!>    A (voir l'argument RCOND). Si l'inverse du nombre de condition est
!>    inférieur à la précision de la machine, la routine continue à résoudre
!>    pour X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!>    4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!>    5. Par défaut (sauf si PARAMS(LA_LINRX_ITREF_I) est défini sur zéro),
!>    la routine utilisera le raffinement itératif pour tenter d'obtenir une
!>    petite erreur et des bornes d'erreur. Le raffinement calcule le résidu
!>    à au moins deux fois la précision de travail.
!>
!>    6. Si l'équilibration a été utilisée, la matrice X est pré-multipliée par
!>    diag(S) de sorte qu'elle résolve le système original avant
!>    l'équilibration.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent la façon dont le raffinement est effectué, mais
!>     les valeurs par défaut sont souvent acceptables. Si les valeurs par défaut
!>     sont acceptables, les utilisateurs peuvent passer NPARAMS = 0, ce qui
!>     empêche le code source d'accéder à l'argument PARAMS.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>     Spécifie si la forme factorisée de la matrice A est fournie ou non
!>     à l'entrée, et si ce n'est pas le cas, si la matrice A doit être
!>     équilibrée avant d'être factorisée.
!>       = 'F':  À l'entrée, AF contient la forme factorisée de A.
!>               Si EQUED n'est pas 'N', la matrice A a été
!>               équilibrée avec des facteurs d'échelle donnés par S.
!>               A et AF ne sont pas modifiés.
!>       = 'N':  La matrice A sera copiée dans AF et factorisée.
!>       = 'E':  La matrice A sera équilibrée si nécessaire, puis
!>               copiée dans AF et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>       = 'U':  Le triangle supérieur de A est stocké ;
!>       = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

A

!>          A est COMPLEX*16 array, dimension (LDA,N)
!>     À l'entrée, la matrice Hermitienne A, sauf si FACT = 'F' et EQUED =
!>     'Y', auquel cas A doit contenir la matrice équilibrée
!>     diag(S)*A*diag(S).  Si UPLO = 'U', la partie triangulaire supérieure
!>     N*N de A contient la partie triangulaire supérieure de la matrice A,
!>     et la partie strictement triangulaire inférieure de A n'est pas
!>     référencée. Si UPLO = 'L', la partie triangulaire inférieure
!>     N*N de A contient la partie triangulaire inférieure de la matrice A,
!>     et la partie strictement triangulaire supérieure de A n'est pas
!>     référencée. A n'est pas modifié si FACT = 'F' ou 'N', ou si FACT = 'E'
!>     et EQUED = 'N' à la sortie.
!>
!>     À la sortie, si FACT = 'E' et EQUED = 'Y', A est remplacé par
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est COMPLEX*16 array, dimension (LDAF,N)
!>     Si FACT = 'F', alors AF est un argument d'entrée et contient à
!>     l'entrée la factorisation triangulaire U ou L de la décomposition
!>     de Cholesky A = U**T*U ou A = L*L**T, dans le même format de stockage
!>     que A. Si EQUED .ne. 'N', alors AF est la forme factorisée
!>     de la matrice équilibrée diag(S)*A*diag(S).
!>
!>     Si FACT = 'N', alors AF est un argument de sortie et contient à
!>     la sortie la factorisation triangulaire U ou L de la décomposition
!>     de Cholesky A = U**T*U ou A = L*L**T de la matrice originale
!>     A.
!>
!>     Si FACT = 'E', alors AF est un argument de sortie et contient à
!>     la sortie la factorisation triangulaire U ou L de la décomposition
!>     de Cholesky A = U**T*U ou A = L*L**T de la matrice équilibrée
!>     A (voir la description de A pour la forme de la matrice équilibrée).
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF. LDAF >= max(1,N).
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie si le système a été équilibré.
!>       = 'N': Aucun équilibrage n'a été effectué.
!>       = 'Y': L'équilibrage a été effectué avec les facteurs de mise à l'échelle
!>              donnés dans S.
!>       = 'U': Seules les lignes ont été équilibrées. Ne se produit que si
!>              le système ne peut pas être équilibré pour des raisons numériques.
!>       = 'R': Seules les colonnes ont été équilibrées. Ne se produit que si
!>              le système ne peut pas être équilibré pour des raisons numériques.
!>
!>     Si FACT = 'F', EQUED est une entrée et doit contenir le bon indicateur
!>     d'équilibrage.
!>
!>     Si FACT = 'N' ou 'E', EQUED est une sortie et indique si un
!>     équilibrage a été effectué et avec quelle méthode.
!>

S

!>          S est DOUBLE PRECISION array, dimension (N)
!>     Ce tableau est utilisé pour stocker les facteurs d'échelle calculés par
!>     la routine. Si EQUED = 'Y', A et B sont remplacés par diag(S)*A*diag(S)
!>     et diag(S)*B. Si EQUED = 'U', S(i) contient les facteurs de mise à l'échelle
!>     pour la ligne i. Si EQUED = 'R', S(j) contient les facteurs de mise à l'échelle
!>     pour la colonne j.
!>
!>     Si FACT = 'F', S est un argument d'entrée et contient les facteurs
!>     d'échelle utilisés pour équilibrer A. Si EQUED = 'N', S n'est pas
!>     référencé.
!>
!>     Si FACT = 'N' ou 'E', S est un argument de sortie.
!>

B

!>          B est COMPLEX*16 array, dimension (LDB,NRHS)
!>     Sur l'entrée, le second membre N-by-NRHS de la résolution
!>     A*X = B.
!>
!>     Sur la sortie, si FACT = 'E' et EQUED = 'Y', B est remplacé par
!>     diag(S)*B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est COMPLEX*16 array, dimension (LDX,NRHS)
!>     Sur la sortie, la solution N-by-NRHS de la résolution A*X = B.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     Sur la sortie, une estimation du nombre de condition inverse de A.
!>     Les calculs d'erreur sont seulement effectués lorsque RCOND est
!>     significativement supérieur à la précision de la machine.
!>

RPVGRW

!>          RPVGRW est DOUBLE PRECISION
!>     Sur la sortie, la plus grande valeur de norm(A(i,:)) * norm(A(:,i)) / norm(A(i,i))**2
!>     où A(i,:) est la i-eme ligne de A, A(:,i) est la i-eme colonne de A,
!>     et A(i,i) est l'élément diagonal de A.
!>

BERR

!>          BERR est DOUBLE PRECISION array, dimension (NRHS)
!>     Sur la sortie, BERR(j) contient une borne d'erreur relative sur
!>     la composante j-eme de la solution X.
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Le nombre de bornes d'erreur à calculer. Les bornes d'erreur
!>     disponibles sont 1 (norme de la différence), 2 (composante max de
!>     la différence) et 3 (norme de la différence des résidus).
!>     N_ERR_BNDS = 1 : ERR_BNDS_NORM est calculé.
!>     N_ERR_BNDS = 2 : ERR_BNDS_NORM et ERR_BNDS_COMP sont calculés.
!>     N_ERR_BNDS = 3 : ERR_BNDS_NORM et un calcul de la norme de la
!>                     différence des résidus sont calculés.
!>
!>     La routine calcule seulement une borne d'erreur relative sur la solution.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est DOUBLE PRECISION array, dimension (NRHS)
!>     Sur la sortie, ERR_BNDS_NORM(j) contient une estimation de la borne
!>     d'erreur relative norm(Xj - Xtrue) / norm(Xtrue) pour la j-eme
!>     solution Xj.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est DOUBLE PRECISION array, dimension (NRHS)
!>     Sur la sortie, ERR_BNDS_COMP(j) contient une estimation de la borne
!>     d'erreur relative composante max |Xj - Xtrue| / |Xtrue| pour la j-eme
!>     solution Xj.
!>

NPARAMS

!>          NPARAMS est INTEGER
!>     Le nombre de paramètres optionnels définis dans le tableau PARAMS.
!>     Si NPARAMS = 0, les valeurs par défaut sont utilisées.
!>

PARAMS

!>          PARAMS est DOUBLE PRECISION array, dimension (NPARAMS)
!>     Tableau contenant les paramètres optionnels. Les paramètres disponibles
!>     sont :
!>     PARAMS(1) = LA_LINRX_ITREF_I : nombre d'itérations de raffinement.
!>                 Si 0, le raffinement est désactivé. Par défaut, c'est 4.
!>     PARAMS(2) = LA_LINRX_IRN_I : nombre de calculs de résidus dans le
!>                 raffinement. Par défaut, c'est 30.
!>     PARAMS(3) = LA_LINRX_RPCG_I : nombre de pas de conjugaison
!>                 gradient dans le calcul du résidu. Par défaut, c'est 30.
!>     PARAMS(4) = LA_LINRX_TOL_D : tolérance pour le calcul des bornes d'erreur
!>                 normées. Par défaut, c'est 0.1.
!>     PARAMS(5) = LA_LINRX_TOL_C : tolérance pour le calcul des bornes d'erreur
!>                 composantes. Par défaut, c'est 0.1.
!>     PARAMS(6) = LA_LINRX_FAIL_I : indicateur d'échec du calcul des bornes
!>                 d'erreur. Par défaut, c'est 0.
!>     PARAMS(7) = LA_LINRX_NORM_I : norme à utiliser pour les calculs de borne.
!>                 1 = norme L1, 2 = norme L-infini, 3 = norme L2. Par défaut,
!>                 c'est 2.
!>

WORK

!>          WORK est COMPLEX*16 array, dimension (max(1,LWORK))
!>     Espace de travail.
!>

LWORK

!>     LWORK est INTEGER
!>     La dimension de l'espace de travail WORK.
!>     Si LWORK = -1, alors LWORK est calculé et le résultat est stocké dans WORK(1).
!>

RWORK

!>          RWORK est DOUBLE PRECISION array, dimension (max(1,LRWORK))
!>     Espace de travail en double précision.
!>

LRWORK

!>     LRWORK est INTEGER
!>     La dimension de l'espace de travail RWORK.
!>     Si LRWORK = -1, alors LRWORK est calculé et le résultat est stocké dans RWORK(1).
!>

INFO

!>          INFO est INTEGER
!>     = 0:  Succès.
!>     > 0:  Si INFO <= N, la décomposition de Cholesky a échoué et le
!>          mineur principal de rang INFO n'est pas positif défini.
!>          Si INFO = N + 1, l'équilibrage a échoué.
!>          Si INFO = N + 2, le système est trop mal conditionné pour que
!>          les bornes d'erreur puissent être calculées de manière fiable.
!>          Si INFO = N + 3, le calcul des bornes d'erreur a échoué.
!>
/pre>

LDAF

!>          LDAF est un entier
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

EQUED

!>          EQUED est une chaîne de caractères de longueur 1
!>     Spécifie la forme de l'équilibration qui a été effectuée.
!>       = 'N':  Aucune équilibration (toujours vrai si FACT = 'N').
!>       = 'Y':  Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(S) * A * diag(S).
!>     EQUED est un argument d'entrée si FACT = 'F'; sinon, c'est un
!>     argument de sortie.
!>

S

!>          S est un tableau de DOUBLE PRECISION, de dimension (N)
!>     Les facteurs d'échelle des lignes de A.  Si EQUED = 'Y', A est multiplié à
!>     gauche et à droite par diag(S).  S est un argument d'entrée si FACT =
!>     'F'; sinon, S est un argument de sortie.  Si FACT = 'F' et EQUED
!>     = 'Y', chaque élément de S doit être positif.  Si S est en sortie, chaque
!>     élément de S est une puissance de la base. Si S est en entrée, chaque
!>     élément de S doit être une puissance de la base pour garantir une solution fiable
!>     et des estimations d'erreur. La mise à l'échelle par des puissances de la base ne provoque pas
!>     d'erreurs d'arrondi à moins que le résultat ne sousflue ou ne déborde.
!>     Les erreurs d'arrondi lors de la mise à l'échelle conduisent à un raffinement avec une matrice qui
!>     n'est pas équivalente à la matrice d'entrée, produisant des estimations d'erreur
!>     qui peuvent ne pas être fiables.
!>

B

!>          B est un tableau de COMPLEX*16, de dimension (LDB,NRHS)
!>     À l'entrée, la matrice B des seconds membres de dimension N x NRHS.
!>     À la sortie,
!>     si EQUED = 'N', B n'est pas modifié;
!>     si EQUED = 'Y', B est écrasé par diag(S)*B;
!>

LDB

!>          LDB est un entier
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau de COMPLEX*16, de dimension (LDX,NRHS)
!>     Si INFO = 0, la matrice solution X de dimension N x NRHS du système
!>     d'équations original.  Notez que A et B sont modifiés à la sortie si
!>     EQUED .ne. 'N', et la solution du système équilibré est
!>     inv(diag(S))*X.
!>

LDX

!>          LDX est un entier
!>     La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est un DOUBLE PRECISION
!>     Nombre de conditionnement échelonné réciproque.  Ceci est une estimation du
!>     nombre de conditionnement de Skeel réciproque de la matrice A après
!>     équilibration (si effectuée).  Si ceci est inférieur à la précision machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail.  Notez que l'erreur peut encore être petite même
!>     si ce nombre est très petit et que la matrice semble mal conditionnée.
!>

RPVGRW

!>          RPVGRW est un DOUBLE PRECISION
!>     Croissance pivot réciproque.  À la sortie, ceci contient le facteur de
!>     croissance pivot réciproque norm(A)/norm(U). La
!>     norme est utilisée.  Si ceci est beaucoup inférieur à 1, alors la stabilité de
!>     la factorisation LU de la matrice A (équilibrée) pourrait être médiocre.
!>     Cela signifie également que la solution X, les nombres de conditionnement estimés
!>     et les bornes d'erreur pourraient ne pas être fiables. Si la factorisation échoue avec
!>     0<INFO<=N, alors ceci contient le facteur de croissance pivot réciproque
!>     pour les colonnes INFO principales de A.
!>

BERR

!>          BERR est un tableau de DOUBLE PRECISION, de dimension (NRHS)
!>     Erreur résiduelle relative composante par composante. Ceci est l'
!>     erreur résiduelle relative composante par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire la plus petite modification relative de tout élément de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est un entier
!>     Nombre de bornes d'erreur à retourner pour chaque second membre
!>     et chaque type (global ou composante par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau de DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de conditionnement correspondant à
!>     l'erreur relative globale, qui est définie comme suit :
!>
!>     Erreur relative globale dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois champs
!>     suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              nombre de conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que la prochaine entrée est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne doit être
!>              utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de conditionnement réciproque : Global estimé
!>              nombre de conditionnement réciproque. Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces nombres de conditionnement réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une certaine
!>              matrice Z appropriée et échelonnée.
!>              Soit Z = S*A, où S échelonne chaque ligne par une puissance de la
!>              base de sorte que toutes les sommes de lignes absolues de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des précautions supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau de DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de conditionnement correspondant à
!>     l'erreur relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (dont dépend l'erreur
!>     relative composante par composante), et le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations retournées pour chaque second membre. Si
!>     la précision composante par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>     ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
