Documentation de la fonction/sous-programme

sous-programme zpbequ (caractere uplo, entier n, entier kd, complexe*16, dimension( ldab, * ) ab, entier ldab, double precision, dimension( * ) s, double precision scond, double precision amax, entier info)

ZPBEQU

Objectif :

!>
!> ZPBEQU calcule les mises à l'échelle des lignes et des colonnes destinées à équilibrer une
!> matrice bande hermitienne définie positive A et à réduire son nombre de conditionnement
!> (par rapport à la norme deux). S contient les facteurs d'échelle,
!> S(i) = 1/sqrt(A(i,i)), choisis de sorte que la matrice mise à l'échelle B avec
!> les éléments B(i,j) = S(i)*A(i,j)*S(j) ait des uns sur la diagonale. Ce
!> choix de S place le nombre de conditionnement de B à un facteur N du
!> plus petit nombre de conditionnement possible sur toutes les mises à l'échelle diagonales possibles.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  La partie triangulaire supérieure de A est stockée ;
!>          = 'L':  La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, dimension (LDAB,N)
!>          La partie triangulaire supérieure ou inférieure de la matrice bande hermitienne A,
!>          stockée dans les KD+1 premières lignes du tableau. La j-ème colonne
!>          de A est stockée dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau A.  LDAB >= KD+1.
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (N)
!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!>

SCOND

!>          SCOND est DOUBLE PRECISION
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i).  Si SCOND >= 0.1 et AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas utile de mettre à l'échelle par S.
!>

AMAX

!>          AMAX est DOUBLE PRECISION
!>          Valeur absolue de l'élément matriciel le plus grand. Si AMAX est très
!>          proche du débordement ou très proche du sous-dépassement, la matrice
!>          devrait être mise à l'échelle.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  si INFO = i, le i-ème élément diagonal est non positif.
!>
