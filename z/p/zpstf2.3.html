sous-routine zpstf2 (uplo, n, a, lda, piv, rank, tol, work, info)
ZPSTF2 calcule la factorisation de Cholesky avec pivotement complet d'une matrice complexe hermitienne semi-définie positive.

Documentation de la fonction/sous-routine

sous-routine zpstf2 (caractère uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, entier, dimension( n ) piv, entier rank, double précision tol, double précision, dimension( 2*n ) work, entier info)

ZPSTF2 calcule la factorisation de Cholesky avec pivotement complet d'une matrice complexe hermitienne semi-définie positive A.

Objectif :

!>
!> ZPSTF2 calcule la factorisation de Cholesky avec pivotement
!> complet d'une matrice hermitienne complexe semi-définie positive A.
!>
!> La factorisation a la forme
!>    P**T * A * P = U**H * U ,  si UPLO = 'U',
!>    P**T * A * P = L  * L**H,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est une matrice triangulaire inférieure, et
!> P est stocké comme vecteur PIV.
!>
!> Cet algorithme ne tente pas de vérifier que A est semi-définie positive.
!> Cette version de l'algorithme appelle BLAS de niveau 2.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire de taille n x n de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la
!>          partie inférieure triangulaire de taille n x n de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>
!>          À la sortie, si INFO = 0, le facteur U ou L de la factorisation de
!>          Cholesky comme ci-dessus.
!>

PIV

!>          PIV est un tableau INTEGER, dimension (N)
!>          PIV est tel que les entrées non nulles sont P( PIV(K), K ) = 1.
!>

RANK

!>          RANK est INTEGER
!>          Le rang de A donné par le nombre d'étapes que l'algorithme
!>          a complétées.
!>

TOL

!>          TOL est DOUBLE PRECISION
!>          Tolérance définie par l'utilisateur. Si TOL < 0, alors N*U*MAX( A( K,K ) )
!>          sera utilisé. L'algorithme se termine à la (K-1)ème étape
!>          si le pivot <= TOL.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (2*N)
!>          Espace de travail.
!>

INFO

!>          INFO est INTEGER
!>          < 0 : Si INFO = -K, le K-ème argument avait une valeur illégale,
!>          = 0 : algorithme terminé avec succès, et
!>          > 0 : la matrice A est soit de rang déficient avec un rang calculé
!>               tel que retourné dans RANK, soit n'est pas semi-définie positive. Voir
!>               la section 7 de la note de travail LAPACK #161 pour plus
!>               d'informations.
!>
