Documentation de la fonction/sous-programme

subroutine zpocon (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision anorm, double precision rcond, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPOCON

But:

!>
!> ZPOCON estime la réciproque du nombre de conditionnement (en norme
!> 1) d'une matrice complexe hermitienne définie positive, calculée par
!> la factorisation de Cholesky A = U**H*U ou A = L*L**H.
!>
!> Une estimation de norm(inv(A)) est obtenue, et la réciproque du
!> nombre de conditionnement est calculée comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U': Le triangle supérieur de A est stocké ;
!>          = 'L': Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H*U ou A = L*L**H, tel que calculé par ZPOTRF.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

ANORM

!>          ANORM est DOUBLE PRECISION
!>          La norme 1 (ou norme infinie) de la matrice hermitienne A.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          La réciproque du nombre de conditionnement de la matrice A,
!>          calculée comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, alors le i-ème argument avait une valeur illégale
!>
