Documentation de la fonction/sous-programme

sous-programme zppsv (caractère uplo, entier n, entier nrhs, complexe*16, dimension( * ) ap, complexe*16, dimension( ldb, * ) b, entier ldb, entier info)

ZPPSV calcule la solution du système d'équations linéaires A * X = B pour les matrices AUTRES

Objectif :

!>
!> ZPPSV calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice hermitienne positive définie de taille N-par-N stockée
!> au format compacté et où X et B sont des matrices de taille N-par-NRHS.
!>
!> La décomposition de Cholesky est utilisée pour factoriser A comme suit :
!>    A = U**H * U,  si UPLO = 'U', ou
!>    A = L * L**H,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est une matrice triangulaire
!> inférieure. La forme factorisée de A est ensuite utilisée pour résoudre le
!> système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice hermitienne
!>          A, compacté par colonne dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>
!>          À la sortie, si INFO = 0, le facteur U ou L de la décomposition de
!>          Cholesky A = U**H*U ou A = L*L**H, dans le même format de stockage
!>          que A.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B de membres de droite de taille N-par-NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N-par-NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>          > 0 : si INFO = i, le mineur principal de tête d'ordre i
!>                de A n'est pas positif, donc la décomposition n'a pas pu
!>                être achevée, et la solution n'a pas été calculée.
!>

Détails supplémentaires :

!>
!> Le schéma de stockage compacté est illustré par l'exemple suivant
!> lorsque N = 4, UPLO = 'U' :
!>
!> Stockage bidimensionnel de la matrice hermitienne A :
!>
!>     a11 a12 a13 a14
!>         a22 a23 a24
!>             a33 a34     (aij = conjg(aji))
!>                 a44
!>
!> Stockage compacté du triangle supérieur de A :
!>
!>  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
!>
