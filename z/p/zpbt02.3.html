Documentation de la fonction/sous-routine

sous-routine zpbt02 (character uplo, integer n, integer kd, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) rwork, double precision resid)

ZPBT02

But:

!>
!> ZPBT02 calcule le résidu d'une solution d'un système d'équations hermitien à bande
!> A*x = b:
!>    RESID = norm( B - A*X ) / ( norm(A) * norm(X) * EPS)
!> où EPS est la précision machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice hermitienne A est stockée:
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits. NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice bande hermitienne originale A.  Si UPLO = 'U', la
!>          partie triangulaire supérieure de A est stockée sous forme de matrice bande; si
!>          UPLO = 'L', la partie triangulaire inférieure de A est stockée. Les
!>          colonnes de la diagonale appropriée sont stockées dans les colonnes
!>          de A et les diagonales de la diagonale sont stockées dans les lignes
!>          de A.  Voir ZPBTRF pour plus de détails.
!>

LDA

!>          LDA est INTEGER.
!>          La dimension principale du tableau A.  LDA >= max(1,KD+1).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Les vecteurs de solution calculés pour le système d'équations linéaires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.   LDX >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          À l'entrée, les vecteurs du côté droit pour le système d'équations linéaires.
!>          À la sortie, B est écrasé par la différence B - A*X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          Le maximum sur le nombre de côtés droits de
!>          norm(B - A*X) / ( norm(A) * norm(X) * EPS ).
!>
