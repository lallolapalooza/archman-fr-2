Documentation de la fonction/sous-programme

sous-programme zpocon (caractere uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, double precision anorm, double precision rcond, complexe*16, dimension( * ) work, double precision, dimension( * ) rwork, entier info)

ZPOCON

Objectif :

!>
!> ZPOCON estime l'inverse du nombre de conditionnement (en norme
!> 1) d'une matrice complexe hermitienne définie positive, calculée par
!> la factorisation de Cholesky A = U**H*U ou A = L*L**H calculée par ZPOTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et l'inverse du nombre de
!> conditionnement est calculé comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H*U ou A = L*L**H, tel que calculé par ZPOTRF.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

ANORM

!>          ANORM est DOUBLE PRECISION
!>          La norme 1 (ou norme infinie) de la matrice hermitienne A.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'inverse du nombre de conditionnement de la matrice A,
!>          calculé comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : exécution réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
