Documentation de la fonction/sous-programme

sous-programme zppcon (caractère uplo, entier n, complexe*16, dimensions( * ) ap, double précision anorm, double précision rcond, complexe*16, dimensions( * ) work, double précision, dimensions( * ) rwork, entier info)

ZPPCON

But :

!>
!> ZPPCON estime l'inverse du nombre de conditionnement (en norme 1)
!> d'une matrice complexe hermitienne définie positive mise en packed,
!> en utilisant la factorisation de Cholesky A = U**H*U ou A = L*L**H
!> calculée par ZPPTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et l'inverse du nombre
!> de conditionnement est calculé comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U': le triangle supérieur de A est stocké ;
!>          = 'L': le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H*U ou A = L*L**H, stocké en packed par colonne dans un
!>          tableau linéaire. La j-ième colonne de U ou L est stockée dans le
!>          tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = U(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = L(i,j) pour j<=i<=n.
!>

ANORM

!>          ANORM est DOUBLE PRECISION
!>          La norme 1 (ou norme infinie) de la matrice hermitienne A.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'inverse du nombre de conditionnement de la matrice A,
!>          calculé comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
