sous-programme zpbsvx (caractere fact, caractere uplo, entier n, entier kd, entier nrhs, complexe*16, dimension( ldab, * ) ab, entier ldab, complexe*16, dimension( ldafb, * ) afb, entier ldafb, caractere equed, reel double, dimension( * ) s, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldx, * ) x, entier ldx, reel double rcond, reel double, dimension( * ) ferr, reel double, dimension( * ) berr, complexe*16, dimension( * ) work, reel double, dimension( * ) rwork, entier info)

ZPBSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices AUTRES

Objectif :

!>
!> ZPBSVX utilise la factorisation de Cholesky A = U**H*U ou A = L*L**H pour
!> calculer la solution d'un système complexe d'équations linéaires
!>    A * X = B,
!> où A est une matrice bande hermitienne positive définie de taille N x N et X
!> et B sont des matrices de taille N x NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de la condition sont
!> également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    L'équilibrage du système dépendra de l'échelle de la matrice A, mais si
!>    l'équilibrage est utilisé, A est écrasée par diag(S)*A*diag(S) et B par
!>    diag(S)*B.
!>
!> 2. Si FACT = 'N' ou 'E', la décomposition de Cholesky est utilisée pour
!>    factoriser la matrice A (après équilibrage si FACT = 'E') comme suit :
!>       A = U**H * U,  si UPLO = 'U', ou
!>       A = L * L**H,  si UPLO = 'L',
!>    où U est une matrice bande triangulaire supérieure, et L est une matrice
!>    bande triangulaire inférieure.
!>
!> 3. Si le mineur principal de tête d'ordre i n'est pas positif,
!>    alors la routine retourne avec INFO = i. Sinon, la forme factorisée de A
!>    est utilisée pour estimer le nombre de condition de la matrice
!>    A. Si l'inverse du nombre de condition est inférieur à la précision machine,
!>    INFO = N+1 est retourné comme avertissement, mais la routine continue
!>    quand même à résoudre pour X et à calculer les bornes d'erreur comme
!>    décrit ci-dessous.
!>
!> 4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 5. Un raffinement itératif est appliqué pour améliorer la matrice solution
!>    calculée et en calculer les bornes d'erreur et les estimations d'erreur
!>    rétrogrades.
!>
!> 6. Si l'équilibrage a été utilisé, la matrice X est pré-multipliée par
!>    diag(S) de sorte qu'elle résolve le système original avant
!>    l'équilibrage.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est fournie en
!>          entrée, et si ce n'est pas le cas, si la matrice A doit être
!>          équilibrée avant d'être factorisée.
!>          = 'F' : En entrée, AFB contient la forme factorisée de A.
!>                  Si EQUED = 'Y', la matrice A a été équilibrée
!>                  avec des facteurs d'échelle donnés par S.  AB et AFB ne
!>                  seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans AFB et factorisée.
!>          = 'E' : La matrice A sera équilibrée si nécessaire, puis
!>                  copiée dans AFB et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : La partie triangulaire supérieure de A est stockée ;
!>          = 'L' : La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, dimension (LDAB,N)
!>          En entrée, la partie triangulaire supérieure ou inférieure de la
!>          matrice bande hermitienne A, stockée dans les KD+1 premières
!>          lignes du tableau, sauf si FACT = 'F' et EQUED = 'Y', où A doit
!>          contenir la matrice équilibrée diag(S)*A*diag(S). La j-ième colonne de A
!>          est stockée dans la j-ième colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) pour max(1,j-KD)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(N,j+KD).
!>          Voir ci-dessous pour plus de détails.
!>
!>          En sortie, si FACT = 'E' et EQUED = 'Y', A est écrasée par
!>          diag(S)*A*diag(S).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau A.  LDAB >= KD+1.
!>

AFB

!>          AFB est un tableau COMPLEX*16, dimension (LDAFB,N)
!>          Si FACT = 'F', alors AFB est un argument d'entrée et contient en
!>          entrée le facteur triangulaire U ou L de la factorisation de
!>          Cholesky A = U**H *U ou A = L*L**H de la matrice bande
!>          A, dans le même format de stockage que A (voir AB). Si EQUED = 'Y',
!>          alors AFB est la forme factorisée de la matrice A équilibrée.
!>
!>          Si FACT = 'N', alors AFB est un argument de sortie et retourne en
!>          sortie le facteur triangulaire U ou L de la factorisation de
!>          Cholesky A = U**H *U ou A = L*L**H.
!>
!>          Si FACT = 'E', alors AFB est un argument de sortie et retourne en
!>          sortie le facteur triangulaire U ou L de la factorisation de
!>          Cholesky A = U**H *U ou A = L*L**H de la matrice A équilibrée
!>          (voir la description de A pour la forme de la matrice équilibrée).
!>

LDAFB

!>          LDAFB est INTEGER
!>          La dimension principale du tableau AFB.  LDAFB >= KD+1.
!>

EQUED

!>          EQUED est CHARACTER*1
!>          Spécifie la forme d'équilibrage qui a été effectuée.
!>          = 'N' : Pas d'équilibrage (toujours vrai si FACT = 'N').
!>          = 'Y' : L'équilibrage a été effectué, c'est-à-dire que A a été
!>                  remplacée par diag(S) * A * diag(S).
!>          EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un
!>          argument de sortie.
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (N)
!>          Les facteurs d'échelle pour A ; non accédé si EQUED = 'N'. S est
!>          un argument d'entrée si FACT = 'F' ; sinon, S est un argument
!>          de sortie. Si FACT = 'F' et EQUED = 'Y', chaque élément de S
!>          doit être positif.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          En entrée, la matrice du côté droit B de taille N x NRHS.
!>          En sortie, si EQUED = 'N', B n'est pas modifié ; si EQUED = 'Y',
!>          B est écrasée par diag(S) * B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16,

LDX

!>          LDX est un entier
!>          La dimension de tête du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est un réel double précision
!>          L'estimation de l'inverse du nombre de condition de la matrice
!>          A après équilibrage (si effectué). Si RCOND est inférieur à la
!>          précision machine (en particulier, si RCOND = 0), la matrice
!>          est singulière à la précision de travail. Cette condition est
!>          indiquée par un code de retour INFO > 0.
!>

FERR

!>          FERR est un tableau de réels double précision, de dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude du plus grand
!>          élément dans (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément dans X(j). L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          sur-estimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau de réels double précision, de dimension (NRHS)
!>          L'erreur relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire, le plus petit changement relatif dans
!>          tout élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau de réels double précision, de dimension (N)
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= N : le mineur principal de tête d'ordre i de A
!>                       n'est pas positif, donc la factorisation n'a pas pu
!>                       être complétée, et la solution n'a pas été
!>                       calculée. RCOND = 0 est retourné.
!>                = N+1 : U est non singulier, mais RCOND est inférieur à la
!>                       précision machine, ce qui signifie que la matrice est
!>                       singulière à la précision de travail. Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car
!>                       il existe un certain nombre de situations où la
!>                       solution calculée peut être plus précise que la
!>                       valeur de RCOND ne le suggérerait.
!>
