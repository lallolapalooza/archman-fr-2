ZPOSVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices PO

Documentation de la fonction/sous-programme

sous-programme zposvxx (character fact, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, character equed, double precision, dimension( * ) s, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision rpvgrw, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPOSVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices PO

But :

!>
!>    ZPOSVXX utilise la décomposition de Cholesky A = U**T*U ou A = L*L**T
!>    pour calculer la solution d'un système d'équations linéaires complexe*16
!>    A * X = B, où A est une matrice hermitienne N-par-N définie positive
!>    et X et B sont des matrices N-par-NRHS.
!>
!>    Si demandé, des bornes d'erreur normées et maximales par composante
!>    sont retournées. ZPOSVXX retournera une solution avec une petite
!>    erreur garantie (O(eps) où eps est la précision de machine courante)
!>    sauf si la matrice est très mal conditionnée, auquel cas un avertissement
!>    est retourné. Les nombres de condition pertinents sont également
!>    calculés et retournés.
!>
!>    ZPOSVXX accepte des factorisations et des facteurs d'équilibrage
!>    fournis par l'utilisateur ; voir les définitions des options FACT
!>    et EQUED. La résolution avec raffinement et l'utilisation d'une
!>    factorisation d'un appel précédent à ZPOSVXX produiront également
!>    une solution avec des erreurs O(eps) ou des avertissements, mais
!>    nous ne pouvons pas affirmer cela pour des factorisations et des
!>    facteurs d'équilibrage fournis par l'utilisateur si ceux-ci
!>    diffèrent de ce que ZPOSVXX produirait lui-même.
!>

Description :

!>
!>    Les étapes suivantes sont effectuées :
!>
!>    1. Si FACT = 'E', des facteurs de mise à l'échelle en double précision sont calculés pour équilibrer
!>    le système :
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Le système sera équilibré ou non en fonction de la mise à l'échelle
!>    de la matrice A, mais si l'équilibrage est utilisé, A est
!>    remplacée par diag(S)*A*diag(S) et B par diag(S)*B.
!>
!>    2. Si FACT = 'N' ou 'E', la décomposition de Cholesky est utilisée pour
!>    factoriser la matrice A (après équilibrage si FACT = 'E') comme suit :
!>       A = U**T* U,  si UPLO = 'U', ou
!>       A = L * L**T,  si UPLO = 'L',
!>    où U est une matrice triangulaire supérieure et L est une matrice triangulaire
!>    inférieure.
!>
!>    3. Si le mineur principal principal d'ordre i n'est pas positif,
!>    alors la routine retourne avec INFO = i. Sinon, la forme factorisée
!>    de A est utilisée pour estimer le nombre de condition de la matrice
!>    A (voir l'argument RCOND).  Si l'inverse du nombre de condition
!>    est inférieur à la précision de la machine, la routine continue
!>    quand même pour résoudre X et calculer les bornes d'erreur comme décrit ci-dessous.
!>
!>    4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!>    5. Par défaut (sauf si PARAMS(LA_LINRX_ITREF_I) est mis à zéro),
!>    la routine utilisera le raffinement itératif pour tenter d'obtenir une
!>    erreur et des bornes d'erreur faibles.  Le raffinement calcule le résidu
!>    avec une précision au moins double de celle de travail.
!>
!>    6. Si l'équilibrage a été utilisé, la matrice X est pré-multipliée par
!>    diag(S) afin de résoudre le système original avant
!>    l'équilibrage.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent la façon dont le raffinement est effectué, mais
!>     souvent les valeurs par défaut sont acceptables. Si les valeurs par défaut
!>     sont acceptables, les utilisateurs peuvent passer NPARAMS = 0, ce qui empêche
!>     le code source d'accéder à l'argument PARAMS.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>     Spécifie si la forme factorisée de la matrice A est fournie à l'entrée, et si ce n'est pas le cas, si la matrice A doit être équilibrée avant d'être factorisée.
!>       = 'F':  À l'entrée, AF contient la forme factorisée de A.
!>               Si EQUED n'est pas 'N', la matrice A a été
!>               équilibrée avec des facteurs d'échelle donnés par S.
!>               A et AF ne sont pas modifiés.
!>       = 'N':  La matrice A sera copiée dans AF et factorisée.
!>       = 'E':  La matrice A sera équilibrée si nécessaire, puis
!>               copiée dans AF et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>       = 'U':  Le triangle supérieur de A est stocké ;
!>       = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>     À l'entrée, la matrice hermitienne A, sauf si FACT = 'F' et EQUED =
!>     'Y', alors A doit contenir la matrice équilibrée
!>     diag(S)*A*diag(S).  Si UPLO = 'U', la partie triangulaire supérieure
!>     N-par-N de A contient la partie triangulaire supérieure de la
!>     matrice A, et la partie strictement triangulaire inférieure de A n'est
!>     pas référencée.  Si UPLO = 'L', la partie triangulaire inférieure
!>     N-par-N de A contient la partie triangulaire inférieure de la matrice A, et
!>     la partie strictement triangulaire supérieure de A n'est pas
!>     référencée.  A n'est pas modifié si FACT = 'F' ou 'N', ou si FACT = 'E' et EQUED =
!>     'N' à la sortie.
!>
!>     À la sortie, si FACT = 'E' et EQUED = 'Y', A est remplacé par
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, de dimension (LDAF,N)
!>     Si FACT = 'F', alors AF est un argument d'entrée et à l'entrée
!>     contient le facteur triangulaire U ou L de la décomposition de Cholesky
!>     A = U**T*U ou A = L*L**T, dans le même format de stockage
!>     que A.  Si EQUED .ne. 'N', alors AF est la forme factorisée
!>     de la matrice équilibrée diag(S)*A*diag(S).
!>
!>     Si FACT = 'N', alors AF est un argument de sortie et à la sortie
!>     retourne le facteur triangulaire U ou L de la décomposition de Cholesky
!>     de la matrice originale A.
!>
!>     Si FACT = 'E', alors AF est un argument de sortie et à la sortie
!>     retourne le facteur triangulaire U ou L de la décomposition de Cholesky
!>     de la matrice équilibrée A (voir la description de A pour la forme de la
!>     matrice équilibrée).
!>



LDAF


!>          LDAF est un entier
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!> 


EQUED


!>          EQUED est un caractère*1
!>     Spécifie la forme d'équilibration qui a été effectuée.
!>       = 'N' : Pas d'équilibration (toujours vrai si FACT = 'N').
!>       = 'Y' : Équilibrations des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(S) * A * diag(S).
!>     EQUED est un argument d'entrée si FACT = 'F'; sinon, c'est un
!>     argument de sortie.
!> 


S


!>          S est un tableau de PRECISION DOUBLE, dimension (N)
!>     Les facteurs d'échelle des lignes de A.  Si EQUED = 'Y', A est multiplié à
!>     gauche et à droite par diag(S).  S est un argument d'entrée si FACT =
!>     'F'; sinon, S est un argument de sortie.  Si FACT = 'F' et EQUED
!>     = 'Y', chaque élément de S doit être positif.  Si S est en sortie, chaque
!>     élément de S est une puissance de la base. Si S est en entrée, chaque
!>     élément de S devrait être une puissance de la base pour assurer une solution fiable
!>     et des estimations d'erreur. La mise à l'échelle par des puissances de la base ne provoque pas
!>     d'erreurs d'arrondi, sauf si le résultat sous-flue ou surflue.
!>     Les erreurs d'arrondi lors de la mise à l'échelle entraînent un raffinement avec une matrice qui
!>     n'est pas équivalente à la matrice d'entrée, produisant des estimations d'erreur
!>     qui peuvent ne pas être fiables.
!> 


B


!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>     À l'entrée, la matrice B du second membre de dimension N x NRHS.
!>     À la sortie,
!>     si EQUED = 'N', B n'est pas modifié ;
!>     si EQUED = 'Y', B est écrasé par diag(S)*B ;
!> 


LDB


!>          LDB est un entier
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!> 


X


!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>     Si INFO = 0, la matrice solution X de dimension N x NRHS du système
!>     d'équations original.  Notez que A et B sont modifiés en sortie si
!>     EQUED .ne. 'N', et la solution du système équilibré est
!>     inv(diag(S))*X.
!> 


LDX


!>          LDX est un entier
!>     La dimension principale du tableau X.  LDX >= max(1,N).
!> 


RCOND


!>          RCOND est de PRÉCISION DOUBLE
!>     Conditionnement réciproque à l'échelle. C'est une estimation du
!>     conditionnement de Skeel réciproque de la matrice A après
!>     équilibration (si effectuée).  Si celui-ci est inférieur à la précision machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail.  Notez que l'erreur peut encore être petite même
!>     si ce nombre est très petit et que la matrice semble mal
!>     conditionnée.
!> 


RPVGRW


!>          RPVGRW est de PRÉCISION DOUBLE
!>     Croissance pivot réciproque. En sortie, contient le facteur de
!>     croissance pivot réciproque norm(A)/norm(U). La norme est utilisée.
!>     Si celui-ci est bien inférieur à 1, alors la stabilité de
!>     la factorisation LU de la matrice A (équilibrée) pourrait être faible.
!>     Cela signifie également que la solution X, les conditionnements estimés,
!>     et les bornes d'erreur pourraient ne pas être fiables. Si la factorisation échoue avec
!>     0<INFO<=N, alors RPVGRW contient le facteur de croissance pivot réciproque
!>     pour les INFO premières colonnes de A.
!> 


BERR


!>          BERR est un tableau de PRÉCISION DOUBLE, dimension (NRHS)
!>     Erreur relative par composante à rebours. C'est l'
!>     erreur relative par composante à rebours de chaque vecteur solution X(j)
!>     (c'est-à-dire le plus petit changement relatif dans un élément de A ou B qui
!>     rend X(j) une solution exacte).
!> 


N_ERR_BNDS


!>          N_ERR_BNDS est un entier
!>     Nombre de bornes d'erreur à renvoyer pour chaque second membre
!>     et chaque type (par norme ou par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!> 


ERR_BNDS_NORM


!>          ERR_BNDS_NORM est un tableau de PRÉCISION DOUBLE, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et conditionnements correspondant à
!>     l'erreur relative par norme, qui est définie comme suit :
!>
!>     Erreur relative par norme dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'informations d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     renvoyées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le second indice dans ERR_BNDS_NORM(:,err) contient les trois champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Conditionnement réciproque : Conditionnement
!>              réciproque par norme estimé. Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation d'erreur
!>              est . Ces conditionnements réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une matrice Z
!>              appropriée et mise à l'échelle.
!>              Soit Z = S*A, où S met à l'échelle chaque ligne par une puissance de la
!>              base de sorte que toutes les sommes de lignes absolues de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des mises en garde supplémentaires.
!> 


ERR_BNDS_COMP


!>          ERR_BNDS_COMP est un tableau de PRÉCISION DOUBLE, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et conditionnements correspondant à
!>     l'erreur relative par composante, qui est définie comme suit :
!>
!>     Erreur relative par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (dont dépend l'erreur relative par composante),
!>     et le type d'information d'erreur tel que décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations renvoyées pour chaque second membre. Si
!>     une précision par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>     ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont renvoyées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le second indice dans ERR_BNDS_COMP(:,err) contient les trois champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Conditionnement réciproque : Conditionnement
!>              réciproque par composante estimé. Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation d'erreur
!>              est . Ces conditionnements réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une matrice Z
!>              appropriée et mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour
!>              le second membre courant et S met à l'échelle chaque ligne de
!>              A*diag(x) par une puissance de la base de sorte que toutes les sommes de lignes absolues
!>              de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des mises en garde supplémentaires.
!> 


NPARAMS


!>          NPARAMS est un entier
!>     Spécifie le nombre de paramètres définis dans PARAMS. Si <= 0, le
!>     tableau PARAMS n'est jamais référencé et les valeurs par défaut sont utilisées.
!> 


PARAMS


!>          PARAMS est un tableau de PRÉCISION DOUBLE, dimension NPARAMS
!>     Spécifie les paramètres de l'algorithme. Si une entrée est < 0.0, alors
!>     cette entrée sera remplie avec la valeur par défaut utilisée pour ce
!>     paramètre. Seules les positions jusqu'à NPARAMS sont accédées ; les défauts
!>     sont utilisés pour les paramètres de rang supérieur.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Indique s'il faut effectuer un raffinement itératif
!>            ou non.
!>         Défaut : 1.0D+0
!>            = 0.0 : Aucun raffinement n'est effectué et aucune borne d'erreur n'est
!>                    calculée.
!>            = 1.0 : Utilise l'algorithme de raffinement extra-précis.
!>              (d'autres valeurs sont réservées pour une utilisation future)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Nombre maximum de résidus
!>            calculés autorisés pour le raffinement.
!>         Défaut : 10
!>         Agressif : Fixé à 100 pour permettre la convergence en utilisant des factorisations approximatives
!>                     ou des factorisations autres que LU. Si
!>                     la factorisation utilise une technique autre que
!>                     l'élimination gaussienne, les garanties dans
!>                     err_bnds_norm et err_bnds_comp peuvent ne plus être
!>                     fiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Indicateur déterminant si le code
!>            tentera de trouver une solution avec une petite erreur relative par composante
!>            dans l'algorithme de double précision. Positif
!>            est vrai, 0.0 est faux.
!>         Défaut : 1.0 (tenter la convergence par composante)
!> 


WORK


!>          WORK est un tableau COMPLEX*16, dimension (2*N)
!> 


RWORK


!>          RWORK est un tableau de PRÉCISION DOUBLE, dimension (2*N)
!> 


INFO


!>          INFO est un entier
!>       = 0 : Sortie réussie. La solution de chaque second membre est
!>         garantie.
!>       < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>       > 0 et <= N : U(INFO,INFO) est exactement zéro. La factorisation
!>         a été complétée, mais le facteur U est exactement singulier, donc
!>         la solution et les bornes d'erreur n'ont pas pu être calculées. RCOND = 0
!>         est renvoyé.
!>       = N+J : La solution correspondant au J-ième second membre n'est
!>         pas garantie. Les solutions correspondant aux autres seconds membres
!>         K tels que K > J peuvent également ne pas être garanties,
!>         mais seul le premier second membre de ce type est signalé. Si une petite
!>         erreur par composante n'est pas demandée (PARAMS(3) = 0.0) alors
!>         le J-ième second membre est le premier avec une borne d'erreur par norme
!>         qui n'est pas garantie.
!>

NAME


zposvxx - posvxx






SYNOPSIS


Subroutine zposvxx(UPLO, N, NRHS, A, LDA, AF, LDAF, B, LDB, RCOND,
                 FERR, BERR, X, LDX, INFO)



Input Parameters


CHARACTER * 1 UPLO
INTEGER N
INTEGER NRHS
COMPLEX*16 A(LDA,*)
INTEGER LDA
COMPLEX*16 AF(LDAF,*)
INTEGER LDAF
COMPLEX*16 B(LDB,*)
INTEGER LDB
INTEGER LDX



Output Parameters


REAL*8 RCOND
REAL*8 FERR(NRHS)
REAL*8 BERR(NRHS)
COMPLEX*16 X(LDX,*)
INTEGER INFO







Function/Subroutine Documentation




!> \brief \ாளர் zposvxx computes the solution to a complex system of linear
!> equations Ax = B, A is positive definite, and optionally computes
!> error bounds and condition estimates.
!>
!> Version: 1.0.0
!> Date:    2024-03-20
!>
!> \details
!> See also:
!>   zposvxx - high level overview:
!>       zposvxx is a complex routine that computes the solution to a
!>       complex system of linear equations Ax = B, where A is a general
!>       complex Hermitian positive definite matrix. The routine also
!>       computes an estimate for the reciprocal condition number of A,
!>       and estimates of the forward and backward error bounds for each
!>       solution vector X(j).
!>
!> Arguments:
!> * UPLO Character*1. Specifies whether the matrix A is upper or lower
!>           Hermitian positive definite.
!>           UPLO ='U': A is upper Hermitian positive definite.
!>           UPLO ='L': A is lower Hermitian positive definite.
!>
!> * N Integer. The order of the matrix A. N >= 0.
!>
!> * NRHS Integer. The number of right hand sides, i.e., the number of
!>            columns in the arrays B and X. NRHS >= 0.
!>
!> * A Complex*16 array, dimension (LDA, N).
!>           On entry, the Hermitian positive definite matrix A. The other
!>           part of the array A may hold unrelated information.
!>
!> * LDA Integer. The leading dimension of the array A. LDA >= max(1, N).
!>
!> * AF Complex*16 array, dimension (LDAF, N).
!>           On entry, the Cholesky factor of A, computed by ZPOTRF. On
!>           exit, AF is overwritten by the Cholesky factor of A.
!>
!> * LDAF Integer. The leading dimension of the array AF. LDAF >= max(1, N).
!>
!> * B Complex*16 array, dimension (LDB, NRHS).
!>           On entry, the right hand side matrix B.
!>
!> * LDB Integer. The leading dimension of the array B. LDB >= max(1, N).
!>
!> * RCOND Real*8. The estimate of the reciprocal condition number of A.
!>            RCOND is always positive for Herimitian positive definite
!>            matrices.
!>
!> * FERR Real*8 array, dimension (NRHS).
!>            FERR(j) is an estimate of the relative forward error in the
!>            j-th solution vector, which is of the form FERR(j) =
!>            norm(X(j) - Xtruth(j)) / norm(X(j)).
!>
!> * BERR Real*8 array, dimension (NRHS).
!>            BERR(j) is an estimate of the relative backward error, which
