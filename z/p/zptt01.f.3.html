sous-routine zptt01 (n, d, e, df, ef, work, resid)
ZPTT01

Documentation de la fonction/sous-routine

sous-routine zptt01 (entier n, double précision, dimension( * ) d, complexe*16, dimension( * ) e, double précision, dimension( * ) df, complexe*16, dimension( * ) ef, complexe*16, dimension( * ) work, double précision resid)

ZPTT01

Objectif :

!>
!> ZPTT01 reconstruit une matrice tridiagonale A à partir de sa factorisation L*D*L'
!> et calcule le résidu
!>    norme(L*D*L' - A) / ( n * norme(A) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A.
!>

D

!>          D est un tableau de DOUBLE PRÉCISION, dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale A.
!>

E

!>          E est un tableau de COMPLEX*16, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de la matrice tridiagonale A.
!>

DF

!>          DF est un tableau de DOUBLE PRÉCISION, dimension (N)
!>          Les n éléments diagonaux du facteur L de la factorisation L*D*L'
!>          de A.
!>

EF

!>          EF est un tableau de COMPLEX*16, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux du facteur L de la
!>          factorisation L*D*L' de A.
!>

WORK

!>          WORK est un tableau de COMPLEX*16, dimension (2*N)
!>

RESID

!>          RESID est un DOUBLE PRÉCISION
!>          norme(L*D*L' - A) / (n * norme(A) * EPS)
!>
