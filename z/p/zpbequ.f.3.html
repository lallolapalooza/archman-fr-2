Documentation de la fonction/sous-programme

sous-programme zpbequ (caractère uplo, entier n, entier kd, complexe*16, dimension( ldab, * ) ab, entier ldab, double précision, dimension( * ) s, double précision scond, double précision amax, entier info)

ZPBEQU

Objectif:

!>
!> ZPBEQU calcule des mises à l'échelle des lignes et des colonnes destinées à
!> équilibrer une matrice bande hermitienne définie positive A et à réduire son
!> nombre de conditionnement (par rapport à la norme deux). S contient les
!> facteurs d'échelle, S(i) = 1/sqrt(A(i,i)), choisis de telle sorte que la
!> matrice mise à l'échelle B avec les éléments B(i,j) = S(i)*A(i,j)*S(j)
!> ait des uns sur la diagonale. Ce choix de S place le nombre de
!> conditionnement de B à un facteur N du plus petit nombre de
!> conditionnement possible sur toutes les mises à l'échelle diagonales
!> possibles.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U': le triangle supérieur de A est stocké ;
!>          = 'L': le triangle inférieur de A est stocké.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

KD

!>          KD est un ENTIER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KD >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, dimension (LDAB,N)
!>          Le triangle supérieur ou inférieur de la matrice bande hermitienne A,
!>          stocké dans les KD+1 premières lignes du tableau. La j-ème colonne
!>          de A est stockée dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est un ENTIER
!>          La dimension principale du tableau A. LDAB >= KD+1.
!>

S

!>          S est un tableau DOUBLE PRÉCISION, dimension (N)
!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!>

SCOND

!>          SCOND est DOUBLE PRÉCISION
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i). Si SCOND >= 0.1 et AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas utile de mettre à l'échelle par S.
!>

AMAX

!>          AMAX est DOUBLE PRÉCISION
!>          Valeur absolue de l'élément de matrice le plus grand. Si AMAX est très
!>          proche du débordement ou très proche du sous-débordement, la matrice
!>          doit être mise à l'échelle.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = i, le i-ème élément diagonal est non positif.
!>
