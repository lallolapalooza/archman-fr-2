Documentation de la fonction/sous-routine

sous-routine zptrfs (character uplo, integer n, integer nrhs, double precision, dimension( * ) d, complex*16, dimension( * ) e, double precision, dimension( * ) df, complex*16, dimension( * ) ef, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPTRFS

But:

!>
!> ZPTRFS améliore la solution calculée d'un système d'équations linéaires
!> lorsque la matrice des coefficients est hermitienne positive définie
!> et tridiagonale, et fournit des bornes d'erreur et des estimations d'erreur directe
!> pour la solution.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la superdiagonale ou la sous-diagonale de la
!>          matrice tridiagonale A est stockée et la forme de la
!>          factorisation :
!>          = 'U':  E est la superdiagonale de A, et A = U**H*D*U ;
!>          = 'L':  E est la sous-diagonale de A, et A = L*D*L**H.
!>          (Les deux formes sont équivalentes si A est réelle.)
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          Les n éléments diagonaux réels de la matrice tridiagonale A.
!>

E

!>          E est un tableau COMPLEX*16, dimension (N-1)
!>          Les (n-1) éléments hors diagonale de la matrice tridiagonale A
!>          (voir UPLO).
!>

DF

!>          DF est un tableau DOUBLE PRECISION, dimension (N)
!>          Les n éléments diagonaux de la matrice diagonale D issue de la
!>          factorisation calculée par ZPTTRF.
!>

EF

!>          EF est un tableau COMPLEX*16, dimension (N-1)
!>          Les (n-1) éléments hors diagonale du facteur unitaire bidiagonal
!>          U ou L issu de la factorisation calculée par ZPTTRF
!>          (voir UPLO).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          Le tableau des membres de droite B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          En entrée, la matrice solution X, telle que calculée par ZPTTRS.
!>          En sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

FERR

!>          FERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          La borne d'erreur directe pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j).
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          L'erreur directe composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire le plus petit changement relatif dans
!>          n'importe quel élément de A ou B qui fait de X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Paramètres internes:

!>  ITMAX est le nombre maximum d'étapes d'affinage itératif.
!>
