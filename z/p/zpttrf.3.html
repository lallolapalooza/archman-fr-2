Documentation de la fonction/sous-routine

sous-routine zpttrf (integer n, double precision, dimension( * ) d, complex*16, dimension( * ) e, integer info)

ZPTTRF

But :

!>
!> ZPTTRF calcule la factorisation L*D*L**H d'une matrice tridiagonale hermitienne
!> complexe définie positive A. La factorisation peut également
!> être considérée comme ayant la forme A = U**H *D*U.
!>

Paramètres :

N 
!>          N est un entier
!>          L'ordre de la matrice A.  N >= 0.
!>

D

!>          D est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          À l'entrée, les n éléments diagonaux de la matrice tridiagonale
!>          A.  À la sortie, les n éléments diagonaux de la matrice diagonale
!>          D issue de la factorisation L*D*L**H de A.
!>

E

!>          E est un tableau de type COMPLEX*16, de dimension (N-1)
!>          À l'entrée, les (n-1) éléments sous-diagonaux de la matrice
!>          tridiagonale A.  À la sortie, les (n-1) éléments sous-diagonaux du
!>          facteur bidiagonal unitaire L issu de la factorisation L*D*L**H de A.
!>          E peut également être considéré comme la superdiagonale du facteur
!>          bidiagonal unitaire U issu de la factorisation U**H *D*U de A.
!>

INFO

!>          INFO est un entier
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -k, le k-ième argument avait une valeur illégale
!>          > 0 : si INFO = k, le mineur principal principal d'ordre k
!>               n'est pas positif ; si k < N, la factorisation n'a pas pu
!>               être achevée, tandis que si k = N, la factorisation a été
!>               achevée, mais D(N) <= 0.
!>
