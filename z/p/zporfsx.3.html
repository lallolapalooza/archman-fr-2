ZPORFSX

But :

!>
!>    ZPORFSX améliore la solution calculée d'un système d'équations linéaires
!>    lorsque la matrice des coefficients est hermitienne définie positive, et fournit des bornes d'erreur et des estimations d'erreur à posteriori pour la solution. En plus de la borne d'erreur par norme, le code fournit une borne d'erreur composante par composante maximale si possible. Voir
!>    les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des
!>    bornes d'erreur.
!>
!>    Le système d'équations linéaires d'origine peut avoir été équilibré
!>    avant d'appeler cette routine, comme décrit par les arguments EQUED et S
!>    ci-dessous. Dans ce cas, la solution et les bornes d'erreur retournées
!>    sont pour le système déséquilibré d'origine.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment le raffinement est effectué, mais souvent les
!>     valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U': le triangle supérieur de A est stocké ;
!>       = 'L': le triangle inférieur de A est stocké.
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibration qui a été effectuée sur A
!>     avant d'appeler cette routine. Ceci est nécessaire pour calculer
!>     la solution et les bornes d'erreur correctement.
!>       = 'N': Pas d'équilibration
!>       = 'Y': Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(S) * A * diag(S).
!>               Le côté droit B a été modifié en conséquence.
!>

N

!>          N est INTEGER
!>     L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>     des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>     La matrice hermitienne A. Si UPLO = 'U', la partie supérieure N par N
!>     de A contient la partie triangulaire supérieure de la matrice A,
!>     et la partie strictement inférieure de A n'est pas référencée. Si UPLO = 'L', la partie inférieure N par N
!>     de A contient la partie triangulaire inférieure de la matrice A,
!>     et la partie strictement supérieure de A n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A. LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>     Le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**H*U ou A = L*L**H, tel que calculé par ZPOTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF. LDAF >= max(1,N).
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle pour A. Si EQUED = 'Y', A est multiplié à
!>     gauche et à droite par diag(S). S est un argument d'entrée si FACT =
!>     'F' ; sinon, S est un argument de sortie. Si FACT = 'F' et EQUED
!>     = 'Y', chaque élément de S doit être positif. Si S est en sortie, chaque
!>     élément de S est une puissance de la base de calcul. Si S est en entrée, chaque
!>     élément de S devrait être une puissance de la base de calcul pour assurer une solution fiable
!>     et des estimations d'erreur. La mise à l'échelle par des puissances de la base de calcul ne provoque pas
!>     d'erreurs d'arrondi, sauf si le résultat déborde (underflow ou overflow).
!>     Les erreurs d'arrondi lors de la mise à l'échelle conduisent à un raffinement avec une matrice qui
!>     n'est pas équivalente à la matrice d'entrée, produisant des estimations d'erreur
!>     qui peuvent ne pas être fiables.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>     La matrice du côté droit B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par ZGETRS.
!>     À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     Conditionnement inverse mis à l'échelle. C'est une estimation du
!>     conditionnement inverse de Skeel de la matrice A après
!>     équilibration (si effectuée). S'il est inférieur à la précision machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut encore être faible même
!>     si ce nombre est très petit et que la matrice semble mal conditionnée.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>     Erreur à posteriori relative composante par composante. C'est l'erreur
!>     à posteriori relative composante par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire la plus petite modification relative de n'importe quel élément de A ou B qui
!>     fait de X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à retourner pour chaque côté droit
!>     et chaque type (par norme ou composante par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque côté droit, ce tableau contient des informations sur
!>     diverses bornes d'erreur et conditionnements correspondant à l'erreur
!>     relative par norme, qui est définie comme suit :
!>
!>     Erreur relative par norme dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur comme décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     côté droit.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si

NAME

zporfsx — zporfsx

SYNOPSIS

Subroutine zporfsx(
    UPLO, N, NRHS, A, LDA, AF, LDAF, B, LDB, X, LDX, FERR, BERR,           &
    ERR_BNDS_NORM, ERR_BNDS_COMP, NPARAMS, PARAMS, WORK, RWORK,          &
    INFO
    )




CHARACTER          UPLO


INTEGER            N, NRHS, LDA, LDAF, LDB, LDX, NPARAMS, INFO


COMPLEX*16         A( LDA, * ), AF( LDAF, * ), B( LDB, * ), X( LDX, * )


COMPLEX*16         WORK( * )


DOUBLE PRECISION   FERR( * ), BERR( * ), ERR_BNDS_NORM( * ),              &
                   ERR_BNDS_COMP( * ), PARAMS( * )


DOUBLE PRECISION   RWORK( * )

Function/Subroutine Documentation

Purpose

  zporfsx computes the error bounds for the solution of a complex hermitian
  positive definite system of linear equations Ax = B.

  This subroutine is called by ZPORFS to compute the error bounds for the
  solution computed by ZPORTRS.

  Fortran interface:
  SUBROUTINE ZPORFSX( UPLO, N, NRHS, A, LDA, AF, LDAF, B, LDB, X, LDX,
                     FERR, BERR, ERR_BNDS_NORM, ERR_BNDS_COMP, NPARAMS,
                     PARAMS, WORK, RWORK, INFO )
     CHARACTER          UPLO
     INTEGER            N, NRHS, LDA, LDAF, LDB, LDX, NPARAMS, INFO
     COMPLEX*16         A( LDA, * ), AF( LDAF, * ), B( LDB, * ), X( LDX, * )
     COMPLEX*16         WORK( * )
     DOUBLE PRECISION   FERR( * ), BERR( * ), ERR_BNDS_NORM( * ),
                        ERR_BNDS_COMP( * ), PARAMS( * )
     DOUBLE PRECISION   RWORK( * )

Parameters

UPLO

  UPLO is CHARACTER*1
          = 'U': Upper triangle of A is stored;
          = 'L': Lower triangle of A is stored.

N

  N is INTEGER
          The number of linear equations, i.e., the order of the matrix A.
          N >= 0.

NRHS

  NRHS is INTEGER
          The number of right hand sides, i.e., the number of columns of
          matrices B, X, FERR, and BERR. NRHS >= 0.

A

  A is COMPLEX*16 array, dimension (LDA,N)
          Original coefficient matrix A.

LDA

  LDA is INTEGER
          The leading dimension of the array A. LDA >= max(1,N).

AF

  AF is COMPLEX*16 array, dimension (LDAF,N)
          The factored form of the matrix A. This is the factored form of
          the LU factorization that is computed by ZPOFA.

LDAF

  LDAF is INTEGER
          The leading dimension of the array AF. LDAF >= max(1,N).

B

  B is COMPLEX*16 array, dimension (LDB,NRHS)
          The right-hand side matrix of the system Ax = B.

LDB

  LDB is INTEGER
          The leading dimension of the array B. LDB >= max(1,N).

X

  X is COMPLEX*16 array, dimension (LDX,NRHS)
          On entry, the solution matrix X to the system of equations
          Ax = B.
          On exit, the solution matrix X may be refined.

LDX

  LDX is INTEGER
          The leading dimension of the array X. LDX >= max(1,N).

FERR

  FERR is DOUBLE PRECISION array, dimension (NRHS)
          On exit, FERR(i) is an estimate of the forward error, that is,
          the relative error in the solutions X(i) of the systems
          Ax = B.  It is computed as follows:
             FERR(i) = ( norm(X(i)) * F1 ) / ( norm(X(i)) - F2 )
          where F1 and F2 are computed in the body of the algorithm, and
          norm(X(i)) is the infinity norm of the solution X(i).

BERR

  BERR is DOUBLE PRECISION array, dimension (NRHS)
          On exit, BERR(i) is the componentwise error estimate in the
          solution X(i) of the system Ax = B.
          It is computed as:
             BERR(i) = max | X(i) - x(i) | / | x(i) |,
          where x(i) is the true solution.

ERR_BNDS_NORM

     ERR_BNDS_NORM is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
     For each right-hand side, this array contains information about
     various error bounds and condition numbers corresponding to the
     normwise relative error, which is defined as follows:
                    norm(XTRUE - X)
             norm(X) -------------
                       norm(XTRUE)
     The array is indexed by the right-hand side i (on which the
     normwise relative error depends), and the type of error
     information as described below. There currently are up to three
     pieces of information returned for each right-hand side. If
     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
     ERR_BNDS_NORM is not accessed. If N_ERR_BNDS < 3, then at most
     the first (:,N_ERR_BNDS) entries are returned.

     The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
     right-hand side.

     The second index in ERR_BNDS_NORM(:,err) contains the following
     three fields:
     err = 1  boolean. Trust the answer if the
              reciprocal condition number is less than the threshold
              sqrt(n) * dlamch('Epsilon').

     err = 2  error bound: The estimated forward error,
              almost certainly within a factor of 10 of the true error
              so long as the next entry is greater than the threshold
              sqrt(n) * dlamch('Epsilon'). This error bound should only
              be trusted if the previous boolean is true.

     err = 3  Reciprocal condition number: Estimated normwise
              reciprocal condition number.  Compared with the threshold
              sqrt(n) * dlamch('Epsilon') to determine if the error
              estimate is . These reciprocal condition
              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
              appropriately scaled matrix Z.
              Let Z = S*A, where S scales each row by a power of the
              radix so all absolute row sums of Z are approximately 1.

     See Lapack Working Note 165 for further details and extra
     cautions.

ERR_BNDS_COMP

     ERR_BNDS_COMP is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
     For each right-hand side, this array contains information about
     various error bounds and condition numbers corresponding to the
     componentwise relative error, which is defined as follows:

     Componentwise relative error in the ith solution vector:
                    abs(XTRUE(j,i) - X(j,i))
             max_j ----------------------
                         abs(X(j,i))

     The array is indexed by the right-hand side i (on which the
     componentwise relative error depends), and the type of error
     information as described below. There currently are up to three
     pieces of information returned for each right-hand side. If
     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
     ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
     the first (:,N_ERR_BNDS) entries are returned.

     The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
     right-hand side.

     The second index in ERR_BNDS_COMP(:,err) contains the following
     three fields:
     err = 1  boolean. Trust the answer if the
              reciprocal condition number is less than the threshold
              sqrt(n) * dlamch('Epsilon').

     err = 2  error bound: The estimated forward error,
              almost certainly within a factor of 10 of the true error
              so long as the next entry is greater than the threshold
              sqrt(n) * dlamch('Epsilon'). This error bound should only
              be trusted if the previous boolean is true.

     err = 3  Reciprocal condition number: Estimated componentwise
              reciprocal condition number.  Compared with the threshold
              sqrt(n) * dlamch('Epsilon') to determine if the error
              estimate is . These reciprocal condition
              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
              appropriately scaled matrix Z.
              Let Z = S*(A*diag(x)), where x is the solution for the
              current right-hand side and S scales each row of
              A*diag(x) by a power of the radix so all absolute row
              sums of Z are approximately 1.

     See Lapack Working Note 165 for further details and extra
     cautions.

NPARAMS

     NPARAMS is INTEGER
     Specifies the number of parameters set in PARAMS.  If <= 0, the
     PARAMS array is never referenced and default values are used.

PARAMS

     PARAMS is DOUBLE PRECISION array, dimension NPARAMS
     Specifies algorithm parameters.  If an entry is < 0.0, then
     that entry will be filled with default value used for that
     parameter.  Only positions up to NPARAMS are accessed; defaults
     are used for higher-numbered parameters.

       PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
            refinement or not.
         Default: 1.0D+0
            = 0.0:  No refinement is performed, and no error bounds are
                    computed.
            = 1.0:  Use the double-precision refinement algorithm,
                    possibly with doubled-single computations if the
                    compilation environment does not support DOUBLE
                    PRECISION.
              (other values are reserved for future use)

       PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual
            computations allowed for refinement.
         Default: 10
         Aggressive: Set to 100 to permit convergence using approximate
                     factorizations or factorizations other than LU. If
                     the factorization uses a technique other than
                     Gaussian elimination, the guarantees in
                     err_bnds_norm and err_bnds_comp may no longer be
                     trustworthy.

       PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code
            will attempt to find a solution with small componentwise
            relative error in the double-precision algorithm.  Positive
            is true, 0.0 is false.
         Default: 1.0 (attempt componentwise convergence)

WORK

     WORK is COMPLEX*16 array, dimension (2*N)

RWORK

     RWORK is DOUBLE PRECISION array, dimension (2*N)

INFO

     INFO is INTEGER
      = 0:  Successful exit. The solution to every right-hand side is
        guaranteed.
      < 0:  If INFO = -i, the i-th argument had an illegal value
      > 0 and <= N:  U(INFO,INFO) is exactly zero.  The factorization
        has been completed, but the factor U is exactly singular, so
        the solution and error bounds could not be computed. RCOND = 0
        is returned.
      = N+J: The solution corresponding to the Jth right-hand side is
        not guaranteed. The solutions corresponding to other right-
        hand sides K with K > J may not be guaranteed as well, but
        only the first such right-hand side is reported. If a small
        componentwise error is not requested (PARAMS(3) = 0.0) then
        the Jth right-hand side is the first with a normwise error
        bound that is not guaranteed (the smallest J such
        that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
        the Jth right-hand side is the first with either a normwise or
        componentwise error bound that is not guaranteed (the smallest
        J such that either ERR_BNDS_NORM(J,1) = 0.0 or
        ERR_BNDS_COMP(J,1) = 0.0). See the definition of
        ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
        about all of the right-hand sides check ERR_BNDS_NORM or
        ERR_BNDS_COMP.
