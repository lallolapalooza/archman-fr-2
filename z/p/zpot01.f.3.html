Documentation de la fonction/sous-routine

subroutine zpot01 (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldafac, * ) afac, integer ldafac, double precision, dimension( * ) rwork, double precision resid)

ZPOT01

But:

!>
!> ZPOT01 reconstruit une matrice hermitienne définie positive A à partir
!> de sa factorisation L*L' ou U'*U et calcule la norme résiduelle
!>    norm( L*L' - A ) / ( N * norm(A) * EPS ) ou
!>    norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> où EPS est l'epsilon machine, L' est la transposée conjuguée de L,
!> et U' est la transposée conjuguée de U.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice hermitienne A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice hermitienne originale A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N)
!>

AFAC

!>          AFAC est un tableau COMPLEX*16, dimension (LDAFAC,N)
!>          En entrée, le facteur L ou U de la factorisation L * L**H ou U**H * U
!>          de A.
!>          Surécrit avec la matrice reconstruite, puis avec
!>          la différence L * L**H - A (ou U**H * U - A).
!>

LDAFAC

!>          LDAFAC est INTEGER
!>          La dimension principale du tableau AFAC.  LDAFAC >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          Si UPLO = 'L', norm(L * L**H - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U**H * U - A) / ( N * norm(A) * EPS )
!>
