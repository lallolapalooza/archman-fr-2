Documentation de la fonction/sous-routine

sous-routine zppt03 (caractere uplo, entier n, complexe*16, dimension( * ) a, complexe*16, dimension( * ) ainv, complexe*16, dimension( ldwork, * ) work, entier ldwork, double precision, dimension( * ) rwork, double precision rcond, double precision resid)

ZPPT03

Objectif :

!>
!> ZPPT03 calcule le résidu pour une matrice hermitienne empaquetée multipliée par son
!> inverse :
!>    norme( I - A*AINV ) / ( N * norme(A) * norme(AINV) * EPS ),
!> où EPS est le epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice hermitienne A est stockée :
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

N

!>          N est ENTIER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          La matrice hermitienne originale A, stockée sous forme de matrice
!>          triangulaire empaquetée.
!>

AINV

!>          AINV est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          L'inverse (hermitienne) de la matrice A, stockée sous forme de matrice
!>          triangulaire empaquetée.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LDWORK,N)
!>

LDWORK

!>          LDWORK est ENTIER
!>          La dimension principale du tableau WORK.  LDWORK >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'inverse du nombre de condition de A, calculé comme
!>          ( 1/norme(A) ) / norme(AINV).
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          norme(I - A*AINV) / ( N * norme(A) * norme(AINV) * EPS )
!>
