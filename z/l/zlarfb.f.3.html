subroutine zlarfb (side, trans, direct, storev, m, n, k, v, ldv, t, ldt, c, ldc, work, ldwork)
ZLARFB applique un bloc réflecteur ou sa transposée conjuguée à une matrice rectangulaire générale.

Documentation de la fonction/sous-routine

sous-routine zlarfb (caractère side, caractère trans, caractère direct, caractère storev, entier m, entier n, entier k, complexe*16, dimension( ldv, * ) v, entier ldv, complexe*16, dimension( ldt, * ) t, entier ldt, complexe*16, dimension( ldc, * ) c, entier ldc, complexe*16, dimension( ldwork, * ) work, entier ldwork)

ZLARFB applique un bloc réflecteur H ou sa transposée conjuguée H**H à une matrice rectangulaire générale C, soit à gauche, soit à droite.

But :

!>
!> ZLARFB applique un bloc réflecteur complexe H ou sa transposée H**H à une
!> matrice C complexe M-par-N, soit depuis la gauche, soit depuis la droite.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer H ou H**H depuis la gauche
!>          = 'R': appliquer H ou H**H depuis la droite
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': appliquer H (Pas de transposée)
!>          = 'C': appliquer H**H (Transposée conjuguée)
!>

DIRECT

!>          DIRECT est CHARACTER*1
!>          Indique comment H est formé à partir d'un produit de
!>          réflecteurs élémentaires
!>          = 'F': H = H(1) H(2) . . . H(k) (Avant)
!>          = 'B': H = H(k) . . . H(2) H(1) (Arrière)
!>

STOREV

!>          STOREV est CHARACTER*1
!>          Indique comment les vecteurs qui définissent les réflecteurs
!>          élémentaires sont stockés :
!>          = 'C': Par colonne
!>          = 'R': Par ligne
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

K

!>          K est INTEGER
!>          L'ordre de la matrice T (= le nombre de réflecteurs
!>          élémentaires dont le produit définit le bloc réflecteur).
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

V

!>          V est un tableau COMPLEX*16, dimension
!>                                (LDV,K) si STOREV = 'C'
!>                                (LDV,M) si STOREV = 'R' et SIDE = 'L'
!>                                (LDV,N) si STOREV = 'R' et SIDE = 'R'
!>          Voir Détails supplémentaires.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V.
!>          Si STOREV = 'C' et SIDE = 'L', LDV >= max(1,M);
!>          si STOREV = 'C' et SIDE = 'R', LDV >= max(1,N);
!>          si STOREV = 'R', LDV >= K.
!>

T

!>          T est un tableau COMPLEX*16, dimension (LDT,K)
!>          La matrice triangulaire K-par-K T dans la représentation du
!>          bloc réflecteur.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= K.
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC,N)
!>          En entrée, la matrice C de taille M-par-N.
!>          En sortie, C est écrasée par H*C ou H**H*C ou C*H ou C*H**H.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LDWORK,K)
!>

LDWORK

!>          LDWORK est INTEGER
!>          La dimension principale du tableau WORK.
!>          Si SIDE = 'L', LDWORK >= max(1,N);
!>          si SIDE = 'R', LDWORK >= max(1,M).
!>

Détails supplémentaires :

!>
!>  La forme de la matrice V et le stockage des vecteurs qui définissent
!>  les H(i) sont mieux illustrés par l'exemple suivant avec n = 5 et
!>  k = 3. La partie triangulaire de V (y compris sa diagonale) n'est pas
!>  référencée.
!>
!>  DIRECT = 'F' et STOREV = 'C':         DIRECT = 'F' et STOREV = 'R':
!>
!>               V = (  1       )                 V = (  1 v1 v1 v1 v1 )
!>                   ( v1  1    )                     (     1 v2 v2 v2 )
!>                   ( v1 v2  1 )                     (        1 v3 v3 )
!>                   ( v1 v2 v3 )
!>                   ( v1 v2 v3 )
!>
!>  DIRECT = 'B' et STOREV = 'C':         DIRECT = 'B' et STOREV = 'R':
!>
!>               V = ( v1 v2 v3 )                 V = ( v1 v1  1       )
!>                   ( v1 v2 v3 )                     ( v2 v2 v2  1    )
!>                   (  1 v2 v3 )                     ( v3 v3 v3 v3  1 )
!>                   (     1 v3 )
!>                   (        1 )
!>
