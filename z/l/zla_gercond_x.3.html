double precision function zla_gercond_x (character trans, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, complex*16, dimension( * ) x, integer info, complex*16, dimension( * ) work, double precision, dimension( * ) rwork)

ZLA_GERCOND_X calcule le nombre de conditionnement en norme infinie de op(A)*diag(x) pour les matrices générales.

Objectif :

!>
!>    ZLA_GERCOND_X calcule le nombre de conditionnement en norme infinie de
!>    op(A) * diag(X) où X est un vecteur COMPLEX*16.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N' :  A * X = B     (Pas de transposée)
!>       = 'T' :  A**T * X = B  (Transposée)
!>       = 'C' :  A**H * X = B  (Transposée conjuguée = Transposée)
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N-par-N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>     Les facteurs L et U de la factorisation
!>     A = P*L*U calculée par ZGETRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Les indices de pivot de la factorisation A = P*L*U
!>     calculée par ZGETRF ; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>

X

!>          X est un tableau COMPLEX*16, dimension (N)
!>     Le vecteur X dans la formule op(A) * diag(X).
!>

INFO

!>          INFO est INTEGER
!>       = 0 : Sortie réussie.
!>     i > 0 : Le i-ème argument est invalide.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N).
!>     Espace de travail.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N).
!>     Espace de travail.
!>
