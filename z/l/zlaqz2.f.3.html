ZLAQZ2

Objectif:

!>
!> ZLAQZ2 effectue AED
!>

Paramètres

ILSCHUR 
!>          ILSCHUR est LOGIQUE
!>              Détermine si la forme de Schur complète doit être mise à jour ou non
!>

ILQ

!>          ILQ est LOGIQUE
!>              Détermine si la matrice Q doit être mise à jour ou non
!>

ILZ

!>          ILZ est LOGIQUE
!>              Détermine si la matrice Z doit être mise à jour ou non
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A, B, Q et Z. N >= 0.
!>

ILO

!>          ILO est ENTIER
!>

IHI

!>          IHI est ENTIER
!>          ILO et IHI marquent les lignes et colonnes de (A,B) qui
!>          doivent être normalisées
!>

NW

!>          NW est ENTIER
!>          La taille souhaitée de la fenêtre de déflation.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max( 1, N ).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB, N)
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= max( 1, N ).
!>

Q

!>          Q est un tableau COMPLEX*16, dimension (LDQ, N)
!>

LDQ

!>          LDQ est ENTIER
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ, N)
!>

LDZ

!>          LDZ est ENTIER
!>

NS

!>          NS est ENTIER
!>          Le nombre de valeurs propres non convergées disponibles pour
!>          être utilisées comme décalages.
!>

ND

!>          ND est ENTIER
!>          Le nombre de valeurs propres convergées trouvées.
!>

ALPHA

!>          ALPHA est un tableau COMPLEX*16, dimension (N)
!>          Chaque scalaire alpha définissant une valeur propre
!>          de GNEP.
!>

BETA

!>          BETA est un tableau COMPLEX*16, dimension (N)
!>          Les scalaires beta qui définissent les valeurs propres de GNEP.
!>          Ensemble, les quantités alpha = ALPHA(j) et
!>          beta = BETA(j) représentent la j-ème valeur propre de la paire
!>          de matrices (A,B), sous l'une des formes lambda = alpha/beta ou
!>          mu = beta/alpha. Puisque lambda ou mu peut déborder,
!>          ils ne devraient, en général, pas être calculés.
!>

QC

!>          QC est un tableau COMPLEX*16, dimension (LDQC, NW)
!>

LDQC

!>          LDQC est ENTIER
!>

ZC

!>          ZC est un tableau COMPLEX*16, dimension (LDZC, NW)
!>

LDZC

!>          LDZ est ENTIER
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO >= 0, WORK(1) contient le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (N)
!>

REC

!>          REC est ENTIER
!>             REC indique le niveau de récursion courant. Devrait être mis
!>             à 0 lors du premier appel.
!>

INFO

!>          INFO est ENTIER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
