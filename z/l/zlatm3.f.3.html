complex *16 function zlatm3 (m, n, i, j, isub, jsub, kl, ku, idist, iseed, d, igrade, dl, dr, ipvtng, iwork, sparse)
ZLATM3

Documentation de la fonction/sous-programme

complex*16 function zlatm3 (integer m, integer n, integer i, integer j, integer isub, integer jsub, integer kl, integer ku, integer idist, integer, dimension( 4 ) iseed, complex*16, dimension( * ) d, integer igrade, complex*16, dimension( * ) dl, complex*16, dimension( * ) dr, integer ipvtng, integer, dimension( * ) iwork, double precision sparse)

ZLATM3

Objectif :

!>
!>    ZLATM3 renvoie l'entrée (ISUB,JSUB) d'une matrice aléatoire de
!>    dimension (M, N) décrite par les autres paramètres. (ISUB,JSUB)
!>    est la position finale de l'entrée (I,J) après le pivotement
!>    selon IPVTNG et IWORK. ZLATM3 est appelée par la
!>    routine ZLATMR afin de construire des matrices de test aléatoires. Aucune vérification d'erreur
!>    sur les paramètres n'est effectuée, car cette routine est appelée dans une
!>    boucle serrée par ZLATMR qui a déjà vérifié les paramètres.
!>
!>    L'utilisation de ZLATM3 diffère de CLATM2 dans l'ordre dans lequel le générateur de nombres aléatoires
!>    est appelé pour remplir les entrées de la matrice aléatoire.
!>    Avec ZLATM2, le générateur est appelé pour remplir la matrice pivotée
!>    par colonnes. Avec ZLATM3, le générateur est appelé pour remplir la
!>    matrice par colonnes, après quoi elle est pivotée. Ainsi, ZLATM3 peut
!>    être utilisé pour construire des matrices aléatoires qui ne diffèrent que par leur
!>    ordre de lignes et/ou de colonnes. ZLATM2 est utilisé pour construire des matrices bandes
!>    tout en évitant d'appeler le générateur de nombres aléatoires pour
!>    les entrées hors bande (et donc en générant des nombres aléatoires
!>    dans des ordres différents pour des ordres de pivotement différents).
!>
!>    La matrice dont l'entrée (ISUB,JSUB) est renvoyée est construite comme
!>    suit (cette routine ne calcule qu'une seule entrée) :
!>
!>      Si ISUB est en dehors de (1..M) ou JSUB est en dehors de (1..N), renvoyer zéro
!>         (ceci est pratique pour générer des matrices au format bande).
!>
!>      Générer une matrice A avec des entrées aléatoires de distribution IDIST.
!>
!>      Définir la diagonale à D.
!>
!>      Graduer la matrice, si désiré, à gauche (par DL) et/ou
!>         à droite (par DR ou DL) comme spécifié par IGRADE.
!>
!>      Permuter, si désiré, les lignes et/ou les colonnes comme spécifié par
!>         IPVTNG et IWORK.
!>
!>      Mettre la matrice en forme de bande avec une bande inférieure KL et une bande supérieure
!>         KU.
!>
!>      Mettre des entrées aléatoires à zéro comme spécifié par SPARSE.
!>

Paramètres

M 
!>          M est INTEGER
!>           Nombre de lignes de la matrice. Non modifié.
!>

N

!>          N est INTEGER
!>           Nombre de colonnes de la matrice. Non modifié.
!>

I

!>          I est INTEGER
!>           Ligne de l'entrée non pivotée à renvoyer. Non modifié.
!>

J

!>          J est INTEGER
!>           Colonne de l'entrée non pivotée à renvoyer. Non modifié.
!>

ISUB

!>          ISUB est INTEGER
!>           Ligne de l'entrée pivotée à renvoyer. Modifié en sortie.
!>

JSUB

!>          JSUB est INTEGER
!>           Colonne de l'entrée pivotée à renvoyer. Modifié en sortie.
!>

KL

!>          KL est INTEGER
!>           Bande inférieure. Non modifié.
!>

KU

!>          KU est INTEGER
!>           Bande supérieure. Non modifié.
!>

IDIST

!>          IDIST est INTEGER
!>           En entrée, IDIST spécifie le type de distribution à utiliser
!>           pour générer une matrice aléatoire.
!>           1 => parties réelle et imaginaire chacune UNIFORME( 0, 1 )
!>           2 => parties réelle et imaginaire chacune UNIFORME( -1, 1 )
!>           3 => parties réelle et imaginaire chacune NORMALE( 0, 1 )
!>           4 => nombre complexe uniforme dans DISQUE( 0 , 1 )
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau INTEGER de dimension ( 4 )
!>           Graine pour le générateur de nombres aléatoires.
!>           Modifié en sortie.
!>

D

!>          D est un tableau COMPLEX*16 de dimension ( MIN( I , J ) )
!>           Entrées diagonales de la matrice. Non modifié.
!>

IGRADE

!>          IGRADE est INTEGER
!>           Spécifie la graduation de la matrice comme suit :
!>           0  => pas de graduation
!>           1  => matrice prémultipliée par diag( DL )
!>           2  => matrice postmultipliée par diag( DR )
!>           3  => matrice prémultipliée par diag( DL ) et
!>                         postmultipliée par diag( DR )
!>           4  => matrice prémultipliée par diag( DL ) et
!>                         postmultipliée par inv( diag( DL ) )
!>           5  => matrice prémultipliée par diag( DL ) et
!>                         postmultipliée par diag( CONJG(DL) )
!>           6  => matrice prémultipliée par diag( DL ) et
!>                         postmultipliée par diag( DL )
!>           Non modifié.
!>

DL

!>          DL est un tableau COMPLEX*16 ( I ou J, selon le cas )
!>           Facteurs d'échelle gauche pour la graduation de la matrice. Non modifié.
!>

DR

!>          DR est un tableau COMPLEX*16 ( I ou J, selon le cas )
!>           Facteurs d'échelle droite pour la graduation de la matrice. Non modifié.
!>

IPVTNG

!>          IPVTNG est INTEGER
!>           En entrée, spécifie les permutations de pivotement comme suit :
!>           0 => aucune.
!>           1 => pivotement de ligne.
!>           2 => pivotement de colonne.
!>           3 => pivotement complet, c'est-à-dire des deux côtés.
!>           Non modifié.
!>

IWORK

!>          IWORK est un tableau INTEGER ( I ou J, selon le cas )
!>           Ce tableau spécifie la permutation utilisée. La
!>           ligne (ou colonne) initialement en position K est en
!>           position IWORK( K ) après pivotement.
!>           Ceci diffère de IWORK pour ZLATM2. Non modifié.
!>

SPARSE

!>          SPARSE est DOUBLE PRECISION entre 0. et 1.
!>           En entrée, spécifie la sparsité de la matrice
!>           si une matrice creuse doit être générée.
!>           SPARSE doit être compris entre 0 et 1.
!>           Un nombre aléatoire uniforme ( 0, 1 ) x est généré et
!>           comparé à SPARSE ; si x est plus grand, l'entrée de la matrice
!>           n'est pas modifiée et si x est plus petit, l'entrée est mise
!>           à zéro. Ainsi, en moyenne, une fraction SPARSE des
!>           entrées sera mise à zéro.
!>           Non modifié.
!>
