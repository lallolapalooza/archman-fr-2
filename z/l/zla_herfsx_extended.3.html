sous-programme zla_herfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, logical colequ, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, complex*16, dimension( * ) res, double precision, dimension( * ) ayb, complex*16, dimension( * ) dy, complex*16, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

ZLA_HERFSX_EXTENDED améliore la solution calculée d'un système d'équations linéaires pour les matrices hermitiennes indéfinies en effectuant un raffinement itératif à précision étendue et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.

Objectif :

!>
!> ZLA_HERFSX_EXTENDED améliore la solution calculée d'un système d'équations
!> linéaires en effectuant un raffinement itératif à précision étendue
!> et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.
!> Ce sous-programme est appelé par ZHERFSX pour effectuer le raffinement itératif.
!> En plus de la borne d'erreur normwise, le code fournit la borne d'erreur
!> composante par composante maximale si possible. Voir les commentaires pour
!> ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des bornes d'erreur. Notez que ce
!> sous-programme est uniquement responsable de la définition des seconds champs de
!> ERR_BNDS_NORM et ERR_BNDS_COMP.
!>

Paramètres

PREC_TYPE 
!>          PREC_TYPE est INTEGER
!>     Spécifie la précision intermédiaire à utiliser pour le raffinement.
!>     La valeur est définie par ILAPREC(P) où P est un CARACTÈRE et P
!>          = 'S': Simple précision
!>          = 'D': Double précision
!>          = 'I': Indigène
!>          = 'X' or 'E': Extra
!>

UPLO

!>          UPLO est CHARACTER*1
!>       = 'U': Le triangle supérieur de A est stocké ;
!>       = 'L': Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de côtés droits, c'est-à-dire le nombre de colonnes de la
!>     matrice B.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>     En entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>     La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>     obtenir le facteur U ou L calculé par ZHETRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Détails des échanges et de la structure par blocs de D
!>     tels que déterminés par ZHETRF.
!>

COLEQU

!>          COLEQU est LOGICAL
!>     Si .VRAI. alors l'équilibration des colonnes a été effectuée sur A avant d'appeler
!>     ce sous-programme. Ceci est nécessaire pour calculer correctement la solution et les bornes d'erreur.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle des colonnes pour A. Si COLEQU = .FAUX., C
!>     n'est pas accédé. Si C est entré, chaque élément de C doit être une puissance
!>     de la base pour garantir une solution et des estimations d'erreur fiables.
!>     La mise à l'échelle par des puissances de la base ne provoque pas d'erreurs d'arrondi, sauf si
!>     le résultat sousflue ou sue. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui pourraient ne pas être
!>     fiables.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>     La matrice du côté droit B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

Y

!>          Y est un tableau COMPLEX*16, dimension (LDY,NRHS)
!>     En entrée, la matrice solution X, telle que calculée par ZHETRS.
!>     En sortie, la matrice solution améliorée Y.
!>

LDY

!>          LDY est INTEGER
!>     La dimension principale du tableau Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT est un tableau DOUBLE PRECISION, dimension (NRHS)
!>     En sortie, BERR_OUT(j) contient l'erreur arrière relative composante par composante
!>     pour le j-ième côté droit, selon la formule :
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     où abs(Z) est la valeur absolue composante par composante de la matrice
!>     ou du vecteur Z. Ceci est calculé par ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS est INTEGER
!>     Détermine quelles bornes d'erreur retourner (voir ERR_BNDS_NORM
!>     et ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 retourner les bornes d'erreur normwise.
!>     Si N_NORMS >= 2 retourner les bornes d'erreur composante par composante.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque côté droit, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de conditionnement correspondant à
!>     l'erreur relative normwise, qui est définie comme suit :
!>
!>     Erreur relative normwise dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois éléments d'information
!>     retournés.
!>
!>     Le premier index dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     côté droit.
!>
!>     Le second index dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              nombre de conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * slam

NAME

zla_herfsx_extended - Performs extended iterative refinement for a general complex Hermitian system of linear equations.

SYNOPSIS

Function/Subroutine Documentation

UPLO

 CHARACTER*1

Specifies whether the matrix A is upper or lower triangular. = 'U': Upper triangular

= 'L': Lower triangular.

N

 INTEGER

The order of the matrix A. N >= 0.

NRHS

 INTEGER

The number of right hand sides, i.e., the number of columns of the matrix B. NRHS >= 0.

A

 COMPLEX*16 array, dimension (LDA, N)

The coefficient matrix A in the linear system.

LDA

 INTEGER

The leading dimension of the array A. LDA >= max(1, N).

AF

 COMPLEX*16 array, dimension (LDAF, N)

The factors of A, as returned by ZSYTRF.

LDAF

 INTEGER

The leading dimension of the array AF. LDAF >= max(1, N).

IPIV

 INTEGER array, dimension (N)

The pivot indices, as returned by ZSYTRF.

B

 COMPLEX*16 array, dimension (LDB, NRHS)

The right hand side matrix B.

LDB

 INTEGER

The leading dimension of the array B. LDB >= max(1, N).

X

 COMPLEX*16 array, dimension (LDX, NRHS)

On entry, the solution matrix X, as returned by ZSYTRS.

On exit, the improved solution matrix X.

LDX

 INTEGER

The leading dimension of the array X. LDX >= max(1, N).

ERR_BNDS_NORM

 DOUBLE PRECISION array, dimension (NRHS, 3)

For each right hand side, this array contains information about normwise error bounds and condition numbers. The array is indexed by the right hand side i (on which the normwise error depends), and the type of error information as described below. There currently are up to three pieces of information returned for each right hand side.

The first index in ERR_BNDS_NORM(i,:) corresponds to the ith right hand side.

The second index in ERR_BNDS_NORM(:,err) contains the following three fields:

err = 1
Boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').
err = 2
Error bound. The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.
err = 3
Reciprocal condition number. Estimated normwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is trustworthy. These reciprocal condition numbers are 1/(norm(A_inv,inf)*norm(A,inf)) for some appropriately scaled matrix A. Let Z = S*A, where S scales each row by a power of the radix so all absolute row sums of Z are approximately 1.

This subroutine is only responsible for setting the second field above.

See Lapack Working Note 165 for further details and extra cautions.

ERR_BNDS_COMP

DOUBLE PRECISION array, dimension (NRHS, 3)

For each right hand side, this array contains information about various error bounds and condition numbers corresponding to the componentwise relative error, which is defined as follows:

Componentwise relative error in the ith solution vector:

max_j abs(XTRUE(j,i) - X(j,i)) / abs(X(j,i))

The array is indexed by the right-hand side i (on which the componentwise relative error depends), and the type of error information as described below. There currently are up to three pieces of information returned for each right-hand side. If componentwise accuracy is not requested (PARAMS(3) = 0.0), then ERR_BNDS_COMP is not accessed. If N_ERR_BNDS < 3, then at most the first (:,N_ERR_BNDS) entries are returned.

The first index in ERR_BNDS_COMP(i,:) corresponds to the ith right-hand side.

The second index in ERR_BNDS_COMP(:,err) contains the following three fields:

err = 1
Boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').
err = 2
Error bound. The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.
err = 3
Reciprocal condition number. Estimated componentwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is trustworthy. These reciprocal condition numbers are 1/(norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately scaled matrix Z. Let Z = S*(A*diag(x)), where x is the solution for the current right-hand side and S scales each row of A*diag(x) by a power of the radix so all absolute row sums of Z are approximately 1.

This subroutine is only responsible for setting the second field above.

See Lapack Working Note 165 for further details and extra cautions.

PARAMS

DOUBLE PRECISION array, dimension (NRHS, 6)

On entry, parameters for condition estimation. PARAMS(i, 1) = Threshold for Condition Number calculation. PARAMS(i, 2) = Threshold for determining whether the matrix is singular to working precision. PARAMS(i, 3) = Tolerance for stopping refinement. PARAMS(i, 4) = Threshold for componentwise convergence. PARAMS(i, 5) = Unused. PARAMS(i, 6) = Unused. On exit, parameters for condition estimation. PARAMS(i, 1) = Threshold for Condition Number calculation. PARAMS(i, 2) = Threshold for determining whether the matrix is singular to working precision. PARAMS(i, 3) = Tolerance for stopping refinement. PARAMS(i, 4) = Threshold for componentwise convergence. PARAMS(i, 5) = Reciprocal condition number estimate for normwise error. PARAMS(i, 6) = Reciprocal condition number estimate for componentwise error.

WORK

COMPLEX*16 array, dimension (LWORK)

Workspace array. Size depends on the value of LWORK.

LWORK

INTEGER

The dimension of the array WORK. LWORK >= max(1, 2*N).

INFO

INTEGER

= 0: Successful exit.

< 0: If INFO = -i, the i-th argument to the subroutine had an illegal value.

RES

COMPLEX*16 array, dimension (N)

Workspace to hold the intermediate residual.

AYB

DOUBLE PRECISION array, dimension (N)

Workspace.

DY

COMPLEX*16 array, dimension (N)

Workspace to hold the intermediate solution.

Y_TAIL

COMPLEX*16 array, dimension (N)

Workspace to hold the trailing bits of the intermediate solution.

RCOND

DOUBLE PRECISION

Reciprocal scaled condition number. This is an estimate of the reciprocal Skeel condition number of the matrix A after equilibration (if done). If this is less than the machine precision (in particular, if it is zero), the matrix is singular to working precision. Note that the error may still be small even if this number is very small and the matrix appears ill-conditioned.

ITHRESH

INTEGER

The maximum number of residual computations allowed for refinement. The default is 10. For 'aggressive' set to 100 to permit convergence using approximate factorizations or factorizations other than LU. If the factorization uses a technique other than Gaussian elimination, the guarantees in ERR_BNDS_NORM and ERR_BNDS_COMP may no longer be trustworthy.

RTHRESH

DOUBLE PRECISION

Determines when to stop refinement if the error estimate stops decreasing. Refinement will stop when the next solution no longer satisfies norm(dx_{i+1}) < RTHRESH * norm(dx_i) where norm(Z) is the infinity norm of Z. RTHRESH satisfies 0 < RTHRESH <= 1. The default value is 0.5. For 'aggressive' set to 0.9 to permit convergence on extremely ill-conditioned matrices. See LAWN 165 for more details.

DZ_UB

DOUBLE PRECISION

Determines when to start considering componentwise convergence. Componentwise convergence is only considered after each component of the solution Y is stable, which we define as the relative change in each component being less than DZ_UB. The default value is 0.25, requiring the first bit to be stable. See LAWN 165 for more details.

IGNORE_CWISE

LOGICAL

If .TRUE. then ignore componentwise convergence. Default value is .FALSE..

INFO

INTEGER

= 0: Successful exit.

< 0: if INFO = -i, the ith argument to ZLA_HERFSX_EXTENDED had an illegal value.
