sous-routine zlaqp3rk (integer m, integer n, integer nrhs, integer ioffset, integer nb, double precision abstol, double precision reltol, integer kp1, double precision maxc2nrm, complex*16, dimension( lda, * ) a, integer lda, logical done, integer kb, double precision maxc2nrmk, double precision relmaxc2nrmk, integer, dimension( * ) jpiv, complex*16, dimension( * ) tau, double precision, dimension( * ) vn1, double precision, dimension( * ) vn2, complex*16, dimension( * ) auxv, complex*16, dimension( ldf, * ) f, integer ldf, integer, dimension( * ) iwork, integer info)

ZLAQP3RK calcule une étape de factorisation QR tronquée avec pivotement de colonne d'une matrice complexe m-par-n A en utilisant BLAS de niveau 3 et écrase une matrice complexe m-par-nrhs B avec Q**H * B.

Objectif :

!>
!> ZLAQP3RK calcule une étape de factorisation QR tronquée avec pivotement de colonne
!> de la matrice complexe M-par-N A bloc A(IOFFSET+1:M,1:N)
!> en utilisant BLAS de niveau 3 comme
!>
!>   A * P(KB) = Q(KB) * R(KB).
!>
!> La routine tente de factoriser NB colonnes de A à partir de
!> la ligne IOFFSET+1 et met à jour la matrice résiduelle avec BLAS 3
!> xGEMM. Le nombre de colonnes effectivement factorisées est retourné
!> est plus petit que NB.
!>
!> Le bloc A(1:IOFFSET,1:N) est pivoté en conséquence, mais pas factorisé.
!>
!> La routine écrase également la matrice des seconds membres B stockée
!> dans A(IOFFSET+1:M,1:N+1:N+NRHS) avec Q(KB)**H * B.
!>
!> Cas où le nombre de colonnes factorisées KB < NB :
!>
!> (1) Dans certains cas, en raison d'annulations catastrophiques, elle ne
!> peut pas factoriser les NB colonnes et doit mettre à jour la matrice résiduelle.
!> Par conséquent, le nombre réel de colonnes factorisées dans le bloc retourné
!> dans KB est inférieur à NB. La valeur logique DONE est retournée comme FAUX.
!> La factorisation de la matrice originale entière A_orig doit se poursuivre
!> avec le bloc suivant.
!>
!> (2) Chaque fois que le critère d'arrêt ABSTOL ou RELTOL est satisfait,
!> la factorisation de la matrice originale entière A_orig s'arrête,
!> la valeur logique DONE est retournée comme VRAI. Le nombre de colonnes factorisées
!> qui est inférieur à NB est retourné dans KB.
!>
!> (3) Si les deux critères d'arrêt ABSTOL ou RELTOL ne sont pas utilisés,
!> et lorsque la matrice résiduelle est une matrice nulle à une étape de factorisation
!> KB, la factorisation de la matrice originale entière A_orig s'arrête,
!> la valeur logique DONE est retournée comme VRAI. Le nombre de colonnes factorisées
!> qui est inférieur à NB est retourné dans KB.
!>
!> (4) Chaque fois que NaN est détecté dans la matrice A ou dans le tableau TAU,
!> la factorisation de la matrice originale entière A_orig s'arrête,
!> la valeur logique DONE est retournée comme VRAI. Le nombre de colonnes factorisées
!> qui est inférieur à NB est retourné dans KB. Le paramètre INFO est défini
!> à l'indice de colonne de la première occurrence de NaN.
!>
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes de la matrice B. NRHS >= 0.
!>

IOFFSET

!>          IOFFSET est INTEGER
!>          Le nombre de lignes de la matrice A qui doivent être pivotées
!>          mais pas factorisées. IOFFSET >= 0.
!>
!>          IOFFSET représente également le nombre de colonnes de la matrice
!>          originale entière A_orig qui ont été factorisées
!>          dans les étapes précédentes.
!>

NB

!>          NB est INTEGER
!>          Taille du bloc de factorisation, c'est-à-dire le nombre de colonnes
!>          à factoriser dans la matrice A. 0 <= NB
!>
!>          Si NB = 0, la routine se termine immédiatement.
!>             Cela signifie que la factorisation n'est pas effectuée,
!>             les matrices A et B et les tableaux TAU, IPIV
!>             ne sont pas modifiés.
!>

ABSTOL

!>          ABSTOL est DOUBLE PRECISION, ne peut pas être NaN.
!>
!>          La tolérance absolue (seuil d'arrêt) pour
!>          la norme 2 maximale des colonnes de la matrice résiduelle.
!>          L'algorithme converge (arrête la factorisation) lorsque
!>          la norme 2 maximale des colonnes de la matrice résiduelle
!>          est inférieure ou égale à ABSTOL.
!>
!>          a) Si ABSTOL < 0.0, alors ce critère d'arrêt n'est pas
!>                utilisé, la routine factorise des colonnes en fonction
!>                de NB et RELTOL.
!>                Cela inclut le cas ABSTOL = -Inf.
!>
!>          b) Si 0.0 <= ABSTOL alors la valeur d'entrée
!>                de ABSTOL est utilisée.
!>

RELTOL

!>          RELTOL est DOUBLE PRECISION, ne peut pas être NaN.
!>
!>          La tolérance (seuil d'arrêt) pour le rapport de la
!>          norme 2 maximale des colonnes de la matrice résiduelle à la
!>          norme 2 maximale des colonnes de la matrice originale A_orig. L'algorithme
!>          converge (arrête la factorisation) lorsque ce rapport est
!>          inférieur ou égal à RELTOL.
!>
!>          a) Si RELTOL < 0.0, alors ce critère d'arrêt n'est pas
!>                utilisé, la routine factorise des colonnes en fonction
!>                de NB et ABSTOL.
!>                Cela inclut le cas RELTOL = -Inf.
!>
!>          d) Si 0.0 <= RELTOL alors la valeur d'entrée de RELTOL
!>                est utilisée.
!>

KP1

!>          KP1 est INTEGER
!>          L'indice de la colonne avec la norme 2 maximale dans
!>          la matrice originale entière A_orig déterminée dans
!>          la routine principale ZGEQP3RK. 1 <= KP1 <= N_orig.
!>

MAXC2NRM

!>          MAXC2NRM est DOUBLE PRECISION
!>          La norme 2 maximale des colonnes de la matrice originale
!>          entière A_orig calculée dans la routine principale ZGEQP3RK.
!>          MAXC2NRM >= 0.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1,M).

DONE

!>          DONE est un booléen (LOGICAL)
!>          VRAI : a) si la factorisation s'est terminée avant le traitement
!>                   de toutes les colonnes min(M-IOFFSET,NB,N) en raison
!>                   du critère ABSTOL ou RELTOL,
!>                b) si la factorisation s'est terminée avant le traitement
!>                   de toutes les colonnes min(M-IOFFSET,NB,N) en raison

!>                c) lorsqu'un NaN a été détecté dans la matrice A
!>                   ou dans le tableau TAU.
!>          FAUX : sinon.
!>

KB

!>          KB est un entier (INTEGER)
!>          Rang de factorisation de la matrice A, c'est-à-dire le rang
!>          du facteur R, qui est égal au nombre de lignes non nulles
!>          du facteur R. 0 <= KB <= min(M-IOFFSET,NB,N).
!>
!>          KB représente également le nombre de vecteurs de Householder non nuls.
!>

MAXC2NRMK

!>          MAXC2NRMK est un nombre à virgule flottante double précision (DOUBLE PRECISION)
!>          La norme euclidienne de colonne maximale de la matrice résiduelle,
!>          lorsque la factorisation s'est arrêtée au rang KB. MAXC2NRMK >= 0.
!>

RELMAXC2NRMK

!>          RELMAXC2NRMK est un nombre à virgule flottante double précision (DOUBLE PRECISION)
!>          Le rapport MAXC2NRMK / MAXC2NRM de la norme euclidienne de colonne maximale
!>          de la matrice résiduelle (lorsque la factorisation s'est arrêtée au rang KB)
!>          à la norme euclidienne de colonne maximale de la matrice originale A_orig.
!>          RELMAXC2NRMK >= 0.
!>

JPIV

!>          JPIV est un tableau d'entiers (INTEGER), de dimension (N)
!>          Indices de pivot de colonne, pour 1 <= j <= N, la colonne j
!>          de la matrice A a été échangée avec la colonne JPIV(j).
!>

TAU

!>          TAU est un tableau complexe double précision (COMPLEX*16), de dimension (min(M-IOFFSET,N))
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

VN1

!>          VN1 est un tableau à virgule flottante double précision (DOUBLE PRECISION), de dimension (N)
!>          Le vecteur avec les normes de colonnes partielles.
!>

VN2

!>          VN2 est un tableau à virgule flottante double précision (DOUBLE PRECISION), de dimension (N)
!>          Le vecteur avec les normes de colonnes exactes.
!>

AUXV

!>          AUXV est un tableau complexe double précision (COMPLEX*16), de dimension (NB)
!>          Vecteur auxiliaire.
!>

F

!>          F est un tableau complexe double précision (COMPLEX*16), de dimension (LDF,NB)
!>          Matrice F**H = L*(Y**H)*A.
!>

LDF

!>          LDF est un entier (INTEGER)
!>          La dimension principale du tableau F. LDF >= max(1,N+NRHS).
!>

IWORK

!>          IWORK est un tableau d'entiers (INTEGER), de dimension (N-1).
!>          Est un tableau de travail. (IWORK est utilisé pour stocker les indices
!>          des colonnes pour la mise à jour descendante des normes dans la matrice
!>          résiduelle).
!>

INFO

!>          INFO est un entier (INTEGER)
!>          1) INFO = 0 : sortie réussie.
!>          2) Si INFO = j_1, où 1 <= j_1 <= N, alors un NaN a été
!>             détecté et la routine arrête le calcul.
!>             La j_1-ième colonne de la matrice A ou le j_1-ième
!>             élément du tableau TAU contient la première occurrence
!>             de NaN à l'étape de factorisation KB+1 (quand KB colonnes
!>             ont été factorisées).
!>
!>             À la sortie :
!>             KB                  est défini comme le nombre de
!>                                    colonnes factorisées sans
!>                                    exception.
!>             MAXC2NRMK           est défini comme NaN.
!>             RELMAXC2NRMK        est défini comme NaN.
!>             TAU(KB+1:min(M,N))     n'est pas défini et contient des
!>                                    éléments indéfinis. Si j_1=KB+1, TAU(KB+1)
!>                                    peut contenir NaN.
!>          3) Si INFO = j_2, où N+1 <= j_2 <= 2*N, alors aucun NaN
!>             n'a été détecté, mais +Inf (ou -Inf) a été détecté et
!>             la routine continue le calcul jusqu'à son achèvement.
!>             La (j_2-N)-ième colonne de la matrice A contient la première
!>             occurrence de +Inf (ou -Inf) à l'étape de factorisation
!>             KB+1 (quand KB colonnes ont été factorisées).
!>
