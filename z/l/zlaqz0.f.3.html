Objectif :

!>
!> ZLAQZ0 calcule les valeurs propres d'une paire de matrices réelles (H,T),
!> où H est une matrice de Hessenberg supérieure et T est une matrice triangulaire supérieure,
!> en utilisant la méthode QZ à double décalage.
!> Les paires de matrices de ce type sont produites par la réduction à
!> la forme de Hessenberg généralisée d'une paire de matrices réelles (A,B) :
!>
!>    A = Q1*H*Z1**H,  B = Q1*T*Z1**H,
!>
!> comme calculé par ZGGHRD.
!>
!> Si JOB='S', alors la paire de Hessenberg-triangulaire (H,T) est
!> également réduite à la forme de Schur généralisée,
!>
!>    H = Q*S*Z**H,  T = Q*P*Z**H,
!>
!> où Q et Z sont des matrices unitaires, P et S sont des matrices triangulaires
!> supérieures.
!>
!> Optionnellement, la matrice unitaire Q de la factorisation de Schur
!> généralisée peut être post-multipliée dans une matrice d'entrée Q1, et la
!> matrice unitaire Z peut être post-multipliée dans une matrice d'entrée Z1.
!> Si Q1 et Z1 sont les matrices unitaires de ZGGHRD qui ont réduit
!> la paire de matrices (A,B) à la forme de Hessenberg généralisée, alors les
!> matrices de sortie Q1*Q et Z1*Z sont les facteurs unitaires de la
!> factorisation de Schur généralisée de (A,B) :
!>
!>    A = (Q1*Q)*S*(Z1*Z)**H,  B = (Q1*Q)*P*(Z1*Z)**H.
!>
!> Pour éviter le débordement, les valeurs propres de la paire de matrices (H,T) (équivalemment,
!> de (A,B)) sont calculées sous forme d'une paire de valeurs (alpha,beta), où alpha est
!> complexe et beta réelle.
!> Si beta est non nul, lambda = alpha / beta est une valeur propre du
!> problème aux valeurs propres généralisé non symétrique (GNEP)
!>    A*x = lambda*B*x
!> et si alpha est non nul, mu = beta / alpha est une valeur propre de la
!> forme alternative du GNEP
!>    mu*A*y = B*y.
!> Les valeurs propres peuvent être lues directement de la forme de Schur
!> généralisée :
!>   alpha = S(i,i), beta = P(i,i).
!>
!> Réf : C.B. Moler & G.W. Stewart, , SIAM J. Numer. Anal., 10(1973),
!>      pp. 241--256.
!>
!> Réf : B. Kagstrom, D. Kressner, , SIAM J. Numer.
!>      Anal., 29(2006), pp. 199--227.
!>
!> Réf : T. Steel, D. Camps, K. Meerbergen, R. Vandebril
!>

NAME

zlaqz0 - Sépare les matrices (A, B) sous forme quasi triangulaire supérieure pour le problème généralisé de valeurs propres d'une paire triangulaire supérieure.

COMPLEX*16 A(LDA, *), B(LDB, *), Q(LDQ, *), Z(LDZ, *)
DOUBLE PRECISION ALPHA(*), BETA(*)
COMPLEX*16 WORK(LWORK)

Function/Subroutine Documentation

ZLAQZ0 effectue la décomposition Schur généralisée de la paire de matrices triangulaires supérieures (A, B) afin de calculer les valeurs propres généralisées associées.

Arguments :

A

A is COMPLEX*16 array, dimension (LDA, N)

LDA

LDA is INTEGER
The leading dimension of the array A. LDA >= max(1,N).

B

B is COMPLEX*16 array, dimension (LDB, N)

LDB

LDB is INTEGER
The leading dimension of the array B. LDB >= max(1,N).

ALPHA

ALPHA is DOUBLE PRECISION array, dimension (N)

BETA

BETA is DOUBLE PRECISION array, dimension (N)

Each pair of elements (ALPHA(i), BETA(i)) corresponds to the generalized eigenvalue lambda=ALPHA(i)/BETA(i).

Q

Q is COMPLEX*16 array, dimension (LDQ, N)

LDQ

LDQ is INTEGER
The leading dimension of the array Q. LDQ >= 1.

Z

Z is COMPLEX*16 array, dimension (LDZ, N)

LDZ

LDZ is INTEGER
The leading dimension of the array Z. LDZ >= 1.

WORK

WORK is COMPLEX*16 array, dimension (MAX(1,LWORK))

LWORK

LWORK is INTEGER
The dimension of the array WORK. LWORK >= max(1,N).

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

REC

REC is INTEGER
REC indicates the current recursion level. Should be set
to 0 on first call.

INFO

INFO is INTEGER
= 0: successful exit
< 0: if INFO = -i, the i-th argument had an illegal value
= 1,...,N: the QZ iteration did not converge.  (A,B) is not
in Schur form, but ALPHA(i) and
BETA(i), i=INFO+1,...,N should be correct.
