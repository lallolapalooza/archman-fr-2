sous-routine zlalsa (entier icompq, entier smlsiz, entier n, entier nrhs, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldbx, * ) bx, entier ldbx, double précision, dimension( ldu, * ) u, entier ldu, double précision, dimension( ldu, * ) vt, entier, dimension( * ) k, double précision, dimension( ldu, * ) difl, double précision, dimension( ldu, * ) difr, double précision, dimension( ldu, * ) z, double précision, dimension( ldu, * ) poles, entier, dimension( * ) givptr, entier, dimension( ldgcol, * ) givcol, entier ldgcol, entier, dimension( ldgcol, * ) perm, double précision, dimension( ldu, * ) givnum, double précision, dimension( * ) c, double précision, dimension( * ) s, double précision, dimension( * ) rwork, entier, dimension( * ) iwork, entier info)

ZLALSA calcule la SVD de la matrice des coefficients sous forme compacte. Utilisé par sgelsd.

Objectif :

!>
!> ZLALSA est une étape intermédiaire dans la résolution du problème des moindres carrés
!> en calculant la SVD de la matrice des coefficients sous forme compacte (Les
!> vecteurs singuliers sont calculés comme produits de matrices orthogonales simples.).
!>
!> Si ICOMPQ = 0, ZLALSA applique l'inverse de la matrice des vecteurs singuliers gauches
!> d'une matrice bidiagonale supérieure au membre de droite ; et si
!> ICOMPQ = 1, ZLALSA applique la matrice des vecteurs singuliers droits au
!> membre de droite. Les matrices de vecteurs singuliers ont été générées sous
!> forme compacte par ZLALSA.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est un ENTIER
!>         Spécifie si la matrice des vecteurs singuliers gauches ou droits
!>         est impliquée.
!>         = 0 : Matrice des vecteurs singuliers gauches
!>         = 1 : Matrice des vecteurs singuliers droits
!>

SMLSIZ

!>          SMLSIZ est un ENTIER
!>         La taille maximale des sous-problèmes au bas de l'arbre de calcul.
!>

N

!>          N est un ENTIER
!>         Les dimensions de ligne et de colonne de la matrice bidiagonale supérieure.
!>

NRHS

!>          NRHS est un ENTIER
!>         Le nombre de colonnes de B et BX. NRHS doit être au moins 1.
!>

B

!>          B est un tableau COMPLEX*16, dimension ( LDB, NRHS )
!>         En entrée, B contient les membres de droite des problèmes des moindres carrés
!>         dans les lignes 1 à M.
!>         En sortie, B contient la solution X dans les lignes 1 à N.
!>

LDB

!>          LDB est un ENTIER
!>         La dimension principale de B dans la sous-routine appelante.
!>         LDB doit être au moins max(1, MAX( M, N ) ).
!>

BX

!>          BX est un tableau COMPLEX*16, dimension ( LDBX, NRHS )
!>         En sortie, le résultat de l'application de la matrice des vecteurs singuliers
!>         gauches ou droits à B.
!>

LDBX

!>          LDBX est un ENTIER
!>         La dimension principale de BX.
!>

U

!>          U est un tableau DOUBLE PRÉCISION, dimension ( LDU, SMLSIZ ).
!>         En entrée, U contient les matrices des vecteurs singuliers gauches de tous
!>         les sous-problèmes au niveau inférieur.
!>

LDU

!>          LDU est un ENTIER, LDU = > N.
!>         La dimension principale des tableaux U, VT, DIFL, DIFR,
!>         POLES, GIVNUM, et Z.
!>

VT

!>          VT est un tableau DOUBLE PRÉCISION, dimension ( LDU, SMLSIZ+1 ).
!>         En entrée, VT**H contient les matrices des vecteurs singuliers droits de
!>         tous les sous-problèmes au niveau inférieur.
!>

K

!>          K est un tableau ENTIER, dimension ( N ).
!>

DIFL

!>          DIFL est un tableau DOUBLE PRÉCISION, dimension ( LDU, NLVL ).
!>         où NLVL = INT(log_2 (N/(SMLSIZ+1))) + 1.
!>

DIFR

!>          DIFR est un tableau DOUBLE PRÉCISION, dimension ( LDU, 2 * NLVL ).
!>         En entrée, DIFL(*, I) et DIFR(*, 2 * I -1) enregistrent
!>         les distances entre les valeurs singulières au niveau I et
!>         les valeurs singulières au niveau (I -1), et DIFR(*, 2 * I)
!>         enregistre les facteurs de normalisation des matrices de vecteurs singuliers
!>         droits des sous-problèmes au niveau I.
!>

Z

!>          Z est un tableau DOUBLE PRÉCISION, dimension ( LDU, NLVL ).
!>         En entrée, Z(1, I) contient les composantes du vecteur de mise à jour ajusté
!>         par déflation pour les sous-problèmes au niveau I.
!>

POLES

!>          POLES est un tableau DOUBLE PRÉCISION, dimension ( LDU, 2 * NLVL ).
!>         En entrée, POLES(*, 2 * I -1: 2 * I) contient les nouvelles et anciennes
!>         valeurs singulières impliquées dans les équations séculaires au niveau I.
!>

GIVPTR

!>          GIVPTR est un tableau ENTIER, dimension ( N ).
!>         En entrée, GIVPTR( I ) enregistre le nombre de rotations de Givens
!>         effectuées sur le problème I dans l'arbre de calcul.
!>

GIVCOL

!>          GIVCOL est un tableau ENTIER, dimension ( LDGCOL, 2 * NLVL ).
!>         En entrée, pour chaque I, GIVCOL(*, 2 * I - 1: 2 * I) enregistre les
!>         emplacements des rotations de Givens effectuées au niveau I dans
!>         l'arbre de calcul.
!>

LDGCOL

!>          LDGCOL est un ENTIER, LDGCOL = > N.
!>         La dimension principale des tableaux GIVCOL et PERM.
!>

PERM

!>          PERM est un tableau ENTIER, dimension ( LDGCOL, NLVL ).
!>         En entrée, PERM(*, I) enregistre les permutations effectuées au niveau I
!>         de l'arbre de calcul.
!>

GIVNUM

!>          GIVNUM est un tableau DOUBLE PRÉCISION, dimension ( LDU, 2 * NLVL ).
!>         En entrée, GIVNUM(*, 2 *I -1 : 2 * I) enregistre les valeurs C et S
!>         des rotations de Givens effectuées au niveau I dans l'arbre de calcul.
!>

C

!>          C est un tableau DOUBLE PRÉCISION, dimension ( N ).
!>         En entrée, si le sous-problème I n'est pas carré,
!>         C( I ) contient la valeur C d'une rotation de Givens liée à
!>         l'espace nul droit du sous-problème I.
!>

S

!>          S est un tableau DOUBLE PRÉCISION, dimension ( N ).
!>         En entrée, si le sous-problème I n'est pas carré,
!>         S( I ) contient la valeur S d'une rotation de Givens liée à
!>         l'espace nul droit du sous-problème I.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, de dimension au moins
!>         MAX( (SMLSZ+1)*NRHS*3, N*(1+NRHS) + 2*NRHS ).
!>

NAME

zlalsa - z... routines

SYNOPSIS

call zlalsa(
           z, iwork, rwork,
           ncmp, nw, nl, nr,
           a, lda, v, ldv,
           u, ldu, q, ldq,
           x, n,
           iwork, info )

Function/Subroutine Documentation

zlalsa

Purpose

zlalsa is a subroutine that reduces a bidiagonal matrix to diagonal form, which completes the singular value decomposition of a general matrix.

Arguments

Z

          Z is COMPLEX*16 array, dimension (3*N)

IWORK

          IWORK is INTEGER array, dimension (3*N)

RWORK

          RWORK is DOUBLE PRECISION array, dimension (3*N)

NCMP

          NCMP is INTEGER

The number of columns in the matrix U.

NW

          NW is INTEGER

The number of columns in the matrix V.

NL

          NL is INTEGER

The number of rows in the matrix U.

NR

          NR is INTEGER

The number of rows in the matrix V.

A

          A is COMPLEX*16 array, dimension (LDA, K)

The bidiagonal matrix to be reduced.

LDA

          LDA is INTEGER

The leading dimension of the array A.

V

          V is COMPLEX*16 array, dimension (LDV, NW)

The matrix V.

LDV

          LDV is INTEGER

The leading dimension of the array V.

U

          U is COMPLEX*16 array, dimension (LDU, NCMP)

The matrix U.

LDU

          LDU is INTEGER

The leading dimension of the array U.

Q

          Q is COMPLEX*16 array, dimension (LDQ, NR)

The matrix Q.

LDQ

          LDQ is INTEGER

The leading dimension of the array Q.

X

          X is COMPLEX*16 array, dimension (N)

The vector X.

N

          N is INTEGER

The order of the bidiagonal matrix.

IWORK

          IWORK is INTEGER array, dimension (3*N)

INFO

          INFO is INTEGER

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.
