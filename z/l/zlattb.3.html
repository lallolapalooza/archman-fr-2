But :

!>
!> ZLATTB génère une matrice de test triangulaire en stockage 2-dimensionnel.
!> IMAT et UPLO spécifient de manière unique les propriétés de la matrice de test,
!> qui est retournée dans le tableau A.
!>

Paramètres

IMAT 
!>          IMAT est INTEGER
!>          Une clé entière décrivant quelle matrice générer pour ce
!>          chemin.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A sera triangulaire supérieure ou
!>          inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie si la matrice ou sa transposée sera utilisée.
!>          = 'N':  Pas de transposée
!>          = 'T':  Transposée
!>          = 'C':  Transposée conjuguée (= transposée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

ISEED

!>          ISEED est un tableau de type INTEGER, dimension (4)
!>          Le vecteur de germe pour le générateur de nombres aléatoires (utilisé
!>          dans ZLATMS). Modifié à la sortie.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice à générer.
!>

KD

!>          KD est INTEGER
!>          Le nombre de superdiagonales ou de sous-diagonales de la matrice
!>          triangulaire bande A. KD >= 0.
!>

AB

!>          AB est un tableau de type COMPLEX*16, dimension (LDAB,N)
!>          La matrice triangulaire bande supérieure ou inférieure A, stockée
!>          dans les KD+1 premières lignes de AB. Soit j une colonne de A,
!>          1<=j<=n.
!>          Si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j.
!>          Si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB. LDAB >= KD+1.
!>

B

!>          B est un tableau de type COMPLEX*16, dimension (N)
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau de type DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
