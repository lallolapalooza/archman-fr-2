Documentation de la fonction/sous-programme

double precision function zla_gerpvgrw (integer n, integer ncols, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf)

ZLA_GERPVGRW multiplie une matrice réelle carrée par une matrice complexe.

Objectif :

!>
!>
!> ZLA_GERPVGRW calcule le facteur de croissance du pivot réciproque
!> norm(A)/norm(U). La norme est utilisée. Si ceci est
!> beaucoup moins que 1, la stabilité de la factorisation LU de la
!> matrice (équilibrée) A pourrait être médiocre. Cela signifie également que la
!> solution X, les nombres de condition estimés et les bornes d'erreur pourraient être
!> peu fiables.
!>

Paramètres

N 
!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

NCOLS

!>          NCOLS est INTEGER
!>     Le nombre de colonnes de la matrice A. NCOLS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>     À l'entrée, la matrice N*N A.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>     Les facteurs L et U de la factorisation
!>     A = P*L*U calculés par ZGETRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>
