sous-programme zlattp (integer imat, character uplo, character trans, character diag, integer, dimension( 4 ) iseed, integer n, complex*16, dimension( * ) ap, complex*16, dimension( * ) b, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZLATTP

But :

!>
!> ZLATTP génère une matrice de test triangulaire en stockage compressé.
!> IMAT et UPLO spécifient de manière unique les propriétés de la matrice de test,
!> qui est retournée dans le tableau AP.
!>

Paramètres

IMAT 
!>          IMAT est un entier (INTEGER)
!>          Une clé entière décrivant quelle matrice générer pour ce
!>          chemin.
!>

UPLO

!>          UPLO est un caractère (CHARACTER*1)
!>          Spécifie si la matrice A sera triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est un caractère (CHARACTER*1)
!>          Spécifie si la matrice ou sa transposée sera utilisée.
!>          = 'N':  Pas de transposée
!>          = 'T':  Transposée
!>          = 'C':  Conjuguée transposée
!>

DIAG

!>          DIAG est un caractère (CHARACTER*1)
!>          Spécifie si la matrice A est unitaire triangulaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

ISEED

!>          ISEED est un tableau d'entiers (INTEGER), dimension (4)
!>          Le vecteur de semence pour le générateur de nombres aléatoires (utilisé dans
!>          ZLATMS). Modifié à la sortie.
!>

N

!>          N est un entier (INTEGER)
!>          L'ordre de la matrice à générer.
!>

AP

!>          AP est un tableau complexe*16 (COMPLEX*16), dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, compressée par colonne dans
!>          un tableau linéaire. La j-ème colonne de A est stockée dans le tableau
!>          AP comme suit :
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) pour j<=i<=n.
!>

B

!>          B est un tableau complexe*16 (COMPLEX*16), dimension (N)
!>          Le vecteur du second membre, si IMAT > 10.
!>

WORK

!>          WORK est un tableau complexe*16 (COMPLEX*16), dimension (2*N)
!>

RWORK

!>          RWORK est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
