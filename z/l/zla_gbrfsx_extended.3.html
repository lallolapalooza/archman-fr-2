sous-routine zla_gbrfsx_extended (integer prec_type, integer trans_type, integer n, integer kl, integer ku, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, logical colequ, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, complex*16, dimension( * ) res, double precision, dimension(*) ayb, complex*16, dimension( * ) dy, complex*16, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

ZLA_GBRFSX_EXTENDED améliore la solution calculée d'un système d'équations linéaires pour les matrices bande générales en effectuant un raffinement itératif à précision étendue et fournit des bornes d'erreur et des estimations d'erreur à posteriori pour la solution.

Objectif :

!>
!> ZLA_GBRFSX_EXTENDED améliore la solution calculée d'un système d'équations
!> linéaires en effectuant un raffinement itératif à précision étendue
!> et fournit des bornes d'erreur et des estimations d'erreur à posteriori pour la solution.
!> Cette sous-routine est appelée par ZGBRFSX pour effectuer le raffinement itératif.
!> En plus de la borne d'erreur norma, le code fournit la borne d'erreur maximale par composante
!> si possible. Voir les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des bornes d'erreur.
!> Il est à noter que cette sous-routine est uniquement responsable de la définition des seconds champs de
!> ERR_BNDS_NORM et ERR_BNDS_COMP.
!>

Paramètres

PREC_TYPE 
!>          PREC_TYPE est INTEGER
!>     Spécifie la précision intermédiaire à utiliser pour le raffinement.
!>     La valeur est définie par ILAPREC(P) où P est un CARACTÈRE et P
!>          = 'S' : Simple précision
!>          = 'D' : Double précision
!>          = 'I' : Précision Indigène
!>          = 'X' ou 'E' : Précision Étendue
!>

TRANS_TYPE

!>          TRANS_TYPE est INTEGER
!>     Spécifie l'opération de transposition sur A.
!>     La valeur est définie par ILATRANS(T) où T est un CARACTÈRE et T
!>          = 'N' : Pas de transposition
!>          = 'T' : Transposition
!>          = 'C' : Transposition conjuguée
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes de la
!>     matrice B.
!>

AB

!>          AB est tableau COMPLEX*16, dimension (LDAB,N)
!>     En entrée, la matrice A de taille N x N.
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale du tableau A.  LDAB >= max(1,N).
!>

AFB

!>          AFB est tableau COMPLEX*16, dimension (LDAF,N)
!>     Les facteurs L et U issus de la factorisation
!>     A = P*L*U calculée par ZGBTRF.
!>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est tableau INTEGER, dimension (N)
!>     Les indices de pivot issus de la factorisation A = P*L*U
!>     calculée par ZGBTRF ; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>

COLEQU

!>          COLEQU est LOGICAL
!>     Si .VRAI. alors l'équilibration des colonnes a été effectuée sur A avant d'appeler
!>     cette routine. Ceci est nécessaire pour calculer correctement la solution et les bornes d'erreur.
!>

C

!>          C est tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle des colonnes pour A. Si COLEQU = .FAUX., C
!>     n'est pas accédé. Si C est en entrée, chaque élément de C devrait être une puissance
!>     de la base pour garantir une solution et des estimations d'erreur fiables.
!>     La mise à l'échelle par des puissances de la base ne cause pas d'erreurs d'arrondi sauf
!>     si le résultat déborde (sous-dépassement ou sur-dépassement). Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est tableau COMPLEX*16, dimension (LDB,NRHS)
!>     La matrice des membres de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

Y

!>          Y est tableau COMPLEX*16, dimension (LDY,NRHS)
!>     En entrée, la matrice solution X, calculée par ZGBTRS.
!>     En sortie, la matrice solution améliorée Y.
!>

LDY

!>          LDY est INTEGER
!>     La dimension principale du tableau Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT est tableau DOUBLE PRECISION, dimension (NRHS)
!>     En sortie, BERR_OUT(j) contient l'erreur relative à posteriori par composante
!>     pour le membre de droite j selon la formule
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     où abs(Z) est la valeur absolue par composante de la matrice
!>     ou du vecteur Z. Ceci est calculé par ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS est INTEGER
!>     Détermine quelles bornes d'erreur retourner (voir ERR_BNDS_NORM
!>     et ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 retourner les bornes d'erreur norma.
!>     Si N_NORMS >= 2 retourner les bornes d'erreur par composante.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative norma, qui est définie comme suit :
!>
!>     Erreur relative norma dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------

zla_gbrfsx_extended(3) - LAPACK

NAME

zla_gbrfsx_extended — This subroutine sets up the constants needed to compute the error bounds

SYNOPSIS

SUBROUTINE ZLA_GBFSX_EXTENDED(
     MatrixType, TRANS, N, KBLAS, KUBLAS,
     NB, NRHS, AFAC, LDAFAC, IPIV, B, LDB,
     X, LDX, XTRUE, LDXTRUE, FERR, BERR,
     ERR_BNDS_NORM, ERR_BNDS_COMP, RES, AYB, DY,
     Y_TAIL, RCOND, ITHRESH, RTHRESH, DZ_UB,
     IGNORE_CWISE, INFO
)
!> MatrixType
!>          CHARACTER*1. Specifies the form of the matrix A:
!>          ='G': General Matrix
!>          ='L': Lower triangular matrix
!>          ='U': Upper triangular matrix
!>
!>          TRANS: CHARACTER*1. Specifies whether to compute the error
!>          bounds for the original matrix or its transpose:
!>          ='N': No transpose, solve A*X = B.
!>          ='T': Transpose, solve A**T * X = B.
!>          ='C': Conjugate transpose, solve A**H * X = B.
!>
!>          N: INTEGER. The order of the matrix A. N >= 0.
!>
!>          KBLAS: INTEGER. The number of subdiagonals plus 1.
!>          KUBLAS: INTEGER. The number of superdiagonals plus 1.
!>          NB: INTEGER. The block size of the matrix.
!>          NRHS: INTEGER. The number of right hand sides.
!>
!>          AFAC: COMPLEX*16 array, dimension (LDAFAC, N).
!>          LDAFAC: INTEGER. The leading dimension of AFAC.
!>          IPIV: INTEGER array, dimension (min(N,KBLAS+KUBLAS+1)).
!>          The pivoting information for the factored matrix AFAC.
!>
!>          B: COMPLEX*16 array, dimension (LDB, NRHS).
!>          The right hand side matrix with B(j,i)
!>
!>          LDB: INTEGER. The leading dimension of B.
!>
!>          X: COMPLEX*16 array, dimension (LDX, NRHS).
!>          The solution matrix with X(j,i)
!>
!>          LDX: INTEGER. The leading dimension of X.
!>
!>          XTRUE: COMPLEX*16 array, dimension (LDXTRUE, NRHS).
!>          The true solution matrix.
!>
!>          LDXTRUE: INTEGER. The leading dimension of XTRUE.
!>
!>          FERR: DOUBLE PRECISION array, dimension (NRHS).
!>          For each right hand side i, the estimated forward error bounds
!>          for the componentwise relative error in the solution X.
!>
!>          BERR: DOUBLE PRECISION array, dimension (NRHS).
!>          For each right hand side i, the componentwise relative error
!>          in the solution X.
!>
!>          ERR_BNDS_NORM: DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS).
!>          For each right hand side, this array contains information about
!>          various error bounds and condition numbers corresponding to the
!>          normwise relative error, which is defined as follows:
!>
!>          Normwise relative error in the ith solution vector:
!>                         abs(XTRUE(j,i) - X(j,i))
!>                  max_j ----------------------
!>                              abs(X(j,i))
!>
!>          The array is indexed by the type of error information as described
!>          below. There currently are up to three pieces of information
!>          returned.
!>
!>          The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
!>          right-hand side.
!>
!>          The second index in ERR_BNDS_NORM(:,err) contains the following
!>          three fields:
!>          err = 1  boolean. Trust the answer if the
!>                   reciprocal condition number is less than the threshold
!>                   sqrt(n) * slamch('Epsilon').
!>
!>          err = 2  error bound: The estimated forward error,
!>                   almost certainly within a factor of 10 of the true error
!>                   so long as the next entry is greater than the threshold
!>                   sqrt(n) * slamch('Epsilon'). This error bound should only
!>                   be trusted if the previous boolean is true.
!>
!>          err = 3  Reciprocal condition number: Estimated normwise
!>                   reciprocal condition number.  Compared with the threshold
!>                   sqrt(n) * slamch('Epsilon') to determine if the error
!>                   estimate is . These reciprocal condition
!>                   numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>                   appropriately scaled matrix Z.
!>                   Let Z = S*A, where S scales each row by a power of the
!>                   radix so all absolute row sums of Z are approximately 1.
!>
!>          This subroutine is only responsible for setting the second field
!>          above.
!>          See Lapack Working Note 165 for further details and extra
!>          cautions.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     componentwise relative error, which is defined as follows:
!>
!>     Componentwise relative error in the ith solution vector:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     The array is indexed by the right-hand side i (on which the
!>     componentwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_COMP(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated componentwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*(A*diag(x)), where x is the solution for the
!>              current right-hand side and S scales each row of
!>              A*diag(x) by a power of the radix so all absolute row
!>              sums of Z are approximately 1.
!>
!>     This subroutine is only responsible for setting the second field
!>     above.
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

RES

!>          RES is COMPLEX*16 array, dimension (N)
!>     Workspace to hold the intermediate residual.
!>

AYB

!>          AYB is DOUBLE PRECISION array, dimension (N)
!>     Workspace.
!>

DY

!>          DY is COMPLEX*16 array, dimension (N)
!>     Workspace to hold the intermediate solution.
!>

Y_TAIL

!>          Y_TAIL is COMPLEX*16 array, dimension (N)
!>     Workspace to hold the trailing bits of the intermediate solution.
!>

RCOND

!>          RCOND is DOUBLE PRECISION
!>     Reciprocal scaled condition number.  This is an estimate of the
!>     reciprocal Skeel condition number of the matrix A after
!>     equilibration (if done).  If this is less than the machine
!>     precision (in particular, if it is zero), the matrix is singular
!>     to working precision.  Note that the error may still be small even
!>     if this number is very small and the matrix appears ill-
!>     conditioned.
!>

ITHRESH

!>          ITHRESH is INTEGER
!>     The maximum number of residual computations allowed for
!>     refinement. The default is 10. For 'aggressive' set to 100 to
!>     permit convergence using approximate factorizations or
!>     factorizations other than LU. If the factorization uses a
!>     technique other than Gaussian elimination, the guarantees in
!>     ERR_BNDS_NORM and ERR_BNDS_COMP may no longer be trustworthy.
!>

RTHRESH

!>          RTHRESH is DOUBLE PRECISION
!>     Determines when to stop refinement if the error estimate stops
!>     decreasing. Refinement will stop when the next solution no longer
!>     satisfies norm(dx_{i+1}) < RTHRESH * norm(dx_i) where norm(Z) is
!>     the infinity norm of Z. RTHRESH satisfies 0 < RTHRESH <= 1. The
!>     default value is 0.5. For 'aggressive' set to 0.9 to permit
!>     convergence on extremely ill-conditioned matrices. See LAWN 165
!!>     for more details.
!>

DZ_UB

!>          DZ_UB is DOUBLE PRECISION
!>     Determines when to start considering componentwise convergence.
!>     Componentwise convergence is only considered after each component
!>     of the solution Y is stable, which we define as the relative
!>     change in each component being less than DZ_UB. The default value
!>     is 0.25, requiring the first bit to be stable. See LAWN 165 for
!>     more details.
!>

IGNORE_CWISE

!>          IGNORE_CWISE is LOGICAL
!>     If .TRUE. then ignore componentwise convergence. Default value
!>     is .FALSE..
!>

INFO

!>          INFO is INTEGER
!>       = 0:  Successful exit.
!>       < 0:  if INFO = -i, the ith argument to ZGBTRS had an illegal
!>             value
!>
