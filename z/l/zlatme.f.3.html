sous-programme zlatme (integer n, character dist, integer, dimension( 4 ) iseed, complex*16, dimension( * ) d, integer mode, double precision cond, complex*16 dmax, character rsign, character upper, character sim, double precision, dimension( * ) ds, integer modes, double precision conds, integer kl, integer ku, double precision anorm, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) work, integer info)

ZLATME

But :

!>
!>    ZLATME génère des matrices carrées aléatoires non symétriques avec
!>    des valeurs propres spécifiées pour tester les programmes LAPACK.
!>
!>    ZLATME opère en appliquant la séquence suivante d'opérations :
!>
!>    1. Définit la diagonale à D, où D peut être entrée ou
!>         calculée selon MODE, COND, DMAX et RSIGN comme décrit ci-dessous.
!>
!>    2. Si UPPER='T', le triangle supérieur de A est défini avec des valeurs aléatoires
!>         provenant de la distribution DIST.
!>
!>    3. Si SIM='T', A est multipliée à gauche par une matrice aléatoire
!>         X, dont les valeurs singulières sont spécifiées par DS, MODES, et
!>         CONDS, et à droite par X inverse.
!>
!>    4. Si KL < N-1, la bande inférieure est réduite à KL en utilisant
!>         des transformations de Householder. Si KU < N-1, la bande supérieure
!>         est réduite à KU.
!>
!>    5. Si ANORM n'est pas négatif, la matrice est mise à l'échelle pour avoir
!>         la norme de l'élément maximum ANORM.
!>
!>    (Note : puisque la matrice ne peut pas être réduite au-delà de la forme de Hessenberg,
!>     aucune option d'empaquetage n'est disponible.)
!>

Paramètres

N 
!>          N est un ENTIER
!>           Le nombre de colonnes (ou de lignes) de A. Non modifié.
!>

DIST

!>          DIST est CHARACTER*1
!>           À l'entrée, DIST spécifie le type de distribution à utiliser
!>           pour générer les valeurs propres/singulières aléatoires, et sur le
!>           triangle supérieur (voir UPPER).
!>           'U' => UNIFORME( 0, 1 )  ( 'U' pour uniform )
!>           'S' => UNIFORME( -1, 1 ) ( 'S' pour symétrique )
!>           'N' => NORMALE( 0, 1 )   ( 'N' pour normale )
!>           'D' => uniforme dans le disque complexe |z| < 1.
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau d'ENTIERS, de dimension ( 4 )
!>           À l'entrée, ISEED spécifie la graine du générateur de nombres
!>           aléatoires. Elles doivent être comprises entre 0 et 4095 inclusivement,
!>           et ISEED(4) doit être impair. Le générateur de nombres aléatoires
!>           utilise une séquence congruente linéaire limitée à de petits
!>           entiers, et devrait donc produire des nombres aléatoires indépendants
!>           de la machine. Les valeurs de ISEED sont modifiées à la sortie,
!>           et peuvent être utilisées lors de l'appel suivant à ZLATME
!>           pour continuer la même séquence de nombres aléatoires.
!>           Modifié à la sortie.
!>

D

!>          D est un tableau COMPLEX*16, de dimension ( N )
!>           Ce tableau est utilisé pour spécifier les valeurs propres de A. Si
!>           MODE=0, alors D est supposé contenir les valeurs propres
!>           sinon elles seront calculées selon MODE, COND,
!>           DMAX, et RSIGN et placées dans D.
!>           Modifié si MODE est non nul.
!>

MODE

!>          MODE est un ENTIER
!>           À l'entrée, cela décrit comment les valeurs propres doivent être
!>           spécifiées :
!>           MODE = 0 signifie utiliser D en entrée
!>           MODE = 1 définit D(1)=1 et D(2:N)=1.0/COND
!>           MODE = 2 définit D(1:N-1)=1 et D(N)=1.0/COND
!>           MODE = 3 définit D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 définit D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 définit D à des nombres aléatoires dans l'intervalle
!>                    ( 1/COND , 1 ) tels que leurs logarithmes
!>                    soient uniformément distribués.
!>           MODE = 6 définit D à des nombres aléatoires de la même distribution
!>                    que le reste de la matrice.
!>           MODE < 0 a la même signification que ABS(MODE), sauf que
!>              l'ordre des éléments de D est inversé.
!>           Ainsi, si MODE est entre 1 et 4, D a des entrées allant
!>              de 1 à 1/COND, si entre -1 et -4, D a des entrées
!>              allant de 1/COND à 1,
!>           Non modifié.
!>

COND

!>          COND est un DOUBLE PRÉCISION
!>           À l'entrée, il est utilisé comme décrit sous MODE ci-dessus.
!>           S'il est utilisé, il doit être >= 1. Non modifié.
!>

DMAX

!>          DMAX est COMPLEX*16
!>           Si MODE n'est ni -6, 0 ni 6, le contenu de D, tel que
!>           calculé selon MODE et COND, sera mis à l'échelle par
!>           DMAX / max(abs(D(i))). Notez que DMAX n'a pas besoin d'être
!>           positif ou réel : si DMAX est négatif ou complexe (ou nul),
!>           D sera mis à l'échelle par un nombre négatif ou complexe (ou nul).
!>           Si RSIGN='F', alors la valeur propre de plus grand module sera
!>           égale à DMAX.
!>           Non modifié.
!>

RSIGN

!>          RSIGN est CHARACTER*1
!>           Si MODE n'est pas 0, 6, ou -6, et RSIGN='T', alors les
!>           éléments de D, tels que calculés selon MODE et COND, seront
!>           multipliés par un nombre complexe aléatoire du cercle unité
!>           |z| = 1. Si RSIGN='F', ils ne le seront pas. RSIGN ne peut
!>           avoir que les valeurs 'T' ou 'F'.
!>           Non modifié.
!>

UPPER

!>          UPPER est CHARACTER*1
!>           Si UPPER='T', alors les éléments de A au-dessus de la diagonale
!>           seront définis avec des nombres aléatoires issus de DIST. Si UPPER='F',
!>           ils ne le seront pas. UPPER ne peut avoir que les valeurs 'T' ou 'F'.
!>           Non modifié.
!>

SIM

!>          SIM est CHARACTER*1
!>           Si SIM='T', alors A sera transformée par l'opération A = X*A*X**(-1),
!>           c'est-à-dire multipliée à gauche par une matrice X et
!>           à droite par X inverse. X = U S V, où U et V sont
!>           des matrices unitaires aléatoires et S est une matrice (diagonale)
!>           de valeurs singulières spécifiées par DS, MODES, et CONDS. Si
!>           SIM='F', alors A ne sera pas transformée.
!>           Non modifié.
!>

DS

!>          DS est un tableau DOUBLE PRÉCISION, de dimension ( N )
!>           Ce tableau est utilisé pour spécifier les valeurs singulières de X,
!>           de la même manière que D spécifie les valeurs propres de A.
!>           Si MODE=0, DS contient les valeurs singulières, qui
!>           ne peuvent pas être nulles.
!>           Modifié si MODE est non nul.
!>

MODES

!>          MODES est un ENTIER
!>

CONDS

!>          CONDS est un DOUBLE PRÉCISION
!>           Similaire à MODE et COND, mais pour spécifier la diagonale
!>           de S. MODES=-6 et +6 ne sont pas autorisés (car ils
!>           résulteraient en des valeurs propres aléatoirement mal conditionnées.)
!>

KL

!>          KL est un ENTIER
!>           Ceci spécifie la bande inférieure de la matrice A. KL=1
!>           spécifie une forme de Hessenberg supérieure. Si KL est au moins N-1,
!>           alors A aura une bande inférieure complète.
!>           Non modifié.
!>

KU

!>          KU est un ENTIER
!>           Ceci spécifie la bande supérieure de la matrice A. KU=1
!>           spécifie une forme de Hessenberg inférieure. Si KU est au moins N-1,
!>           alors A aura une bande supérieure complète ; si KU et KL
!>           sont tous deux égaux à

SYNOPSIS

SUBROUTINE ZLATME (
     M, N, DIST, DIAG, MODE, OMEGA, REALPART, IMAGPART, THETA,
     COND, RANK, ANORM, A, LDA, WORK, INFO )

SUBROUTINE ZLATME ( INTEGER M, INTEGER N, CHARACTER*(*) DIST,
     CHARACTER*(*) DIAG, INTEGER MODE, DOUBLE PRECISION OMEGA,
     DOUBLE PRECISION REALPART, DOUBLE PRECISION IMAGPART,
     DOUBLE PRECISION THETA, DOUBLE PRECISION COND, INTEGER RANK,
     DOUBLE PRECISION ANORM, COMPLEX*16 A, INTEGER LDA,
     COMPLEX*16 WORK, INTEGER INFO )

Function/Subroutine Documentation

This subroutine generates a complex matrix A which is either upper or lower triangular, or general, and is scaled to have a specified norm and condition number. A is factored as A = U*S*V', where U and V are unitary and S is the diagonal matrix of singular values.

Arguments:

M

INTEGER

!>          M is INTEGER
!>           The number of rows of A.
!>           Not modified.
N

INTEGER

!>          N is INTEGER
!>           The number of columns of A.
!>           Not modified.
DIST

CHARACTER*(*)

!>          DIST is CHARACTER*(*)
!>           Specifies the form of the singular values.
!>           See DIST of ZLATMS for details.
!>           Not modified.
DIAG

CHARACTER*(*)

!>          DIAG is CHARACTER*(*)
!>           Specifies the form of the matrix A.
!>           See DIAG of ZLATMS for details.
!>           Not modified.
MODE

INTEGER

!>          MODE is INTEGER
!>           Specifies the distribution of the singular values.
!>           See MODE of ZLATMS for details.
!>           Not modified.
OMEGA

DOUBLE PRECISION

!>          OMEGA is DOUBLE PRECISION
!>           Specifies the value of the smallest singular value if MODE = 1
!>           or the value of the largest singular value if MODE = 2, 3, 4.
!>           Not modified.
REALPART

DOUBLE PRECISION

!>          REALPART is DOUBLE PRECISION
!>           The real part of the complex eigenvalues.
!>           Not modified.
IMAGPART

DOUBLE PRECISION

!>          IMAGPART is DOUBLE PRECISION
!>           The imaginary part of the complex eigenvalues.
!>           Not modified.
THETA

DOUBLE PRECISION

!>          THETA is DOUBLE PRECISION
!>           The angle in degrees to rotate the eigenvalues.
!>           Not modified.
COND

DOUBLE PRECISION

!>          COND is DOUBLE PRECISION
!>           The condition number of A.
!>           Not modified.
RANK

INTEGER

!>          RANK is INTEGER
!>           The rank of A.
!>           Not modified.
ANORM

DOUBLE PRECISION

!>          ANORM is DOUBLE PRECISION
!>           If ANORM is not negative, then A will be scaled by a non-
!>           negative real number to make the maximum-element-norm of A
!>           to be ANORM.
!>           Not modified.
A

COMPLEX*16

!>          A is COMPLEX*16 array, dimension ( LDA, N )
!>           On exit A is the desired test matrix.
!>           Modified.
LDA

INTEGER

!>          LDA is INTEGER
!>           LDA specifies the first dimension of A as declared in the
!>           calling program.  LDA must be at least M.
!>           Not modified.
WORK

COMPLEX*16

!>          WORK is COMPLEX*16 array, dimension ( 3*N )
!>           Workspace.
!>           Modified.
INFO

INTEGER

!>          INFO is INTEGER
!>           Error code.  On exit, INFO will be set to one of the
!>           following values:
!>             0 => normal return
!>            -1 => N negative
!>            -2 => DIST illegal string
!>            -5 => MODE not in range -6 to 6
!>            -6 => COND less than 1.0, and MODE neither -6, 0 nor 6
!>            -9 => RSIGN is not 'T' or 'F'
!>           -10 => UPPER is not 'T' or 'F'
!>           -11 => SIM   is not 'T' or 'F'
!>           -12 => MODES=0 and DS has a zero singular value.
!>           -13 => MODES is not in the range -5 to 5.
!>           -14 => MODES is nonzero and CONDS is less than 1.
!>           -15 => KL is less than 1.
!>           -16 => KU is less than 1, or KL and KU are both less than
!>                  N-1.
!>           -19 => LDA is less than M.
!>            1  => Error return from ZLATM1 (computing D)
!>            2  => Cannot scale to DMAX (max. eigenvalue is 0)
!>            3  => Error return from DLATM1 (computing DS)
!>            4  => Error return from ZLARGE
!>            5  => Zero singular value from DLATM1.
!>
