ZLAQZ3

Objectif:

!>
!> ZLAQZ3 Exécute un seul balayage QZ multi-shifts
!>

Paramètres

ILSCHUR 
!>          ILSCHUR est LOGIQUE
!>              Détermine si la forme de Schur complète doit être mise à jour ou non
!>

ILQ

!>          ILQ est LOGIQUE
!>              Détermine si la matrice Q doit être mise à jour ou non
!>

ILZ

!>          ILZ est LOGIQUE
!>              Détermine si la matrice Z doit être mise à jour ou non
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A, B, Q et Z. N >= 0.
!>

ILO

!>          ILO est ENTIER
!>

IHI

!>          IHI est ENTIER
!>

NSHIFTS

!>          NSHIFTS est ENTIER
!>          Le nombre désiré de shifts à utiliser
!>

NBLOCK_DESIRED

!>          NBLOCK_DESIRED est ENTIER
!>          La taille désirée des fenêtres de calcul
!>

ALPHA

!>          ALPHA est un tableau COMPLEX*16. SR contient
!>          les parties alpha des shifts à utiliser.
!>

BETA

!>          BETA est un tableau COMPLEX*16. SS contient
!>          l'échelle des shifts à utiliser.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max( 1, N ).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB, N)
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= max( 1, N ).
!>

Q

!>          Q est un tableau COMPLEX*16, dimension (LDQ, N)
!>

LDQ

!>          LDQ est ENTIER
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ, N)
!>

LDZ

!>          LDZ est ENTIER
!>

QC

!>          QC est un tableau COMPLEX*16, dimension (LDQC, NBLOCK_DESIRED)
!>

LDQC

!>          LDQC est ENTIER
!>

ZC

!>          ZC est un tableau COMPLEX*16, dimension (LDZC, NBLOCK_DESIRED)
!>

LDZC

!>          LDZC est ENTIER
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO >= 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0: succès
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
