ZLANHF retourne la valeur de la norme 1, de la norme de Frobenius, de la norme d'infini, ou de l'élément de plus grande valeur absolue d'une matrice Hermitienne au format RFP.

Documentation de la fonction/sous-programme

double precision function zlanhf (character norm, character transr, character uplo, integer n, complex*16, dimension( 0: * ) a, double precision, dimension( 0: * ) work)

ZLANHF retourne la valeur de la norme 1, de la norme de Frobenius, de la norme d'infini, ou de l'élément de plus grande valeur absolue d'une matrice Hermitienne au format RFP.

Objectif :

!>
!> ZLANHF  retourne la valeur de la norme 1,  ou la norme de Frobenius, ou
!> la norme d'infini,  ou l'élément de plus grande valeur absolue d'une
!> matrice Hermitienne complexe A au format RFP.
!>

Retourne

ZLANHF 
!>
!>    ZLANHF = ( max(abs(A(i,j))), NORM = 'M' ou 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' ou 'o'
!>             (
!>             ( normI(A),         NORM = 'I' ou 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' ou 'e'
!>
!> où  norm1  désigne la norme 1 d'une matrice (somme des valeurs absolues
!> maximale des colonnes), normI  désigne la norme d'infini d'une matrice
!> (somme des valeurs absolues maximale des lignes) et normF  désigne la
!> norme de Frobenius d'une matrice (racine carrée de la somme des carrés).
!> Notez que max(abs(A(i,j))) n'est pas une norme matricielle.
!>

Paramètres

NORM 
!>          NORM est CHARACTER
!>            Spécifie la valeur à retourner dans ZLANHF comme décrit
!>            ci-dessus.
!>

TRANSR

!>          TRANSR est CHARACTER
!>            Spécifie si le format RFP de A est le format normal ou le
!>            format conjugué transposé.
!>            = 'N' :  Le format RFP est Normal
!>            = 'C' :  Le format RFP est Conjugué Transposé
!>

UPLO

!>          UPLO est CHARACTER
!>            En entrée, UPLO spécifie si la matrice RFP A provient d'une
!>            matrice triangulaire supérieure ou inférieure comme suit :
!>
!>            UPLO = 'U' ou 'u' : RFP A provient d'une matrice
!>            triangulaire supérieure
!>
!>            UPLO = 'L' ou 'l' : RFP A provient d'une matrice
!>            triangulaire inférieure
!>

N

!>          N est INTEGER
!>            L'ordre de la matrice A.  N >= 0.  Lorsque N = 0, ZLANHF est
!>            mis à zéro.
!>

A

!>          A est un tableau COMPLEX*16, de dimension ( N*(N+1)/2 );
!>            En entrée, la matrice A au format RFP.
!>            Le format RFP est décrit par TRANSR, UPLO et N comme suit :
!>            Si TRANSR='N' alors RFP A est (0:N,0:K-1) lorsque N est pair ;
!>            K=N/2. RFP A est (0:N-1,0:K) lorsque N est impair ; K=N/2. Si
!>            TRANSR = 'C' alors RFP est la conjuguée transposée de RFP A
!>            telle que définie lorsque TRANSR = 'N'. Le contenu de RFP A
!>            est défini par UPLO comme suit : Si UPLO = 'U', RFP A
!>            contient les ( N*(N+1)/2 ) éléments de A supérieur packé
!>            soit en format normal, soit en format conjugué transposé. Si
!>            UPLO = 'L', RFP A contient les ( N*(N+1)/2 ) éléments
!>            de A inférieur packé, soit en format normal, soit en format
!>            conjugué transposé. Le LDA de RFP A est (N+1)/2 lorsque
!>            TRANSR = 'C'. Lorsque TRANSR est 'N', le LDA est N+1 lorsque
!>            N est pair et est N lorsqu'il est impair. Voir la Note ci-dessous
!>            pour plus de détails.
!>            Inchangé en sortie.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (LWORK),
!>            où LWORK >= N lorsque NORM = 'I' ou '1' ou 'O' ; sinon,
!>            WORK n'est pas référencé.
!>

!>  supérieur.
!>  Pour UPLO = 'L', le trapèze inférieur A(0:4,0:2) contient les trois
!>  premières colonnes de AP inférieur. Le triangle supérieur A(0:1,1:2)

ZLANHF(3) LAPACK ZLANHF(3)

NAME

ZLANHF - La norme 1, L-infini et la norme F d'une matrice hermitienne en format triangulaire condensé.

SYNOPSIS

  SUBROUTINE ZLANHF( NORM, UPLO, SIDE, M, N, A, LDA, WORK, INFO )

      CHARACTER          SIDE, UPLO, NORM
      INTEGER            M, N, LDA, INFO
      COMPLEX*16         A( LDA, * ), WORK( * )

Function/Subroutine Documentation

ZLANHF calcule une norme de matrice 1, L-infini ou F (Hardy). La matrice A est une matrice complexe de taille M x N. Elle est supposée être hermitienne et stockée dans un format triangulaire condensé.

L-infini : la plus grande norme en valeur absolue sur les lignes.

Norme 1 : la plus grande norme en valeur absolue sur les colonnes.

Norme F : la racine carrée de la somme des carrés des éléments.

Parameters

  • NORM (CHARACTER*1) : Spécifie la norme à calculer.
    • 'O' ou '1' : 1-norme (par défaut)
    • 'I' : L-infini-norme
    • 'F' : F-norme
  • UPLO (CHARACTER*1) : Spécifie quelle partie de la matrice est stockée.
    • 'U' : La partie supérieure est stockée.
    • 'L' : La partie inférieure est stockée.
  • SIDE (CHARACTER*1) : Spécifie si A est une matrice de gauche ou de droite.
    • 'L' : La norme est calculée pour A*A**H.
    • 'R' : La norme est calculée pour A**H*A.
  • M (INTEGER) : Le nombre de lignes de la matrice A.
  • N (INTEGER) : Le nombre de colonnes de la matrice A.
  • A (COMPLEX*16) : Le tableau d'entrée de taille LDA x K, où K est N lorsque UPLO = 'L' et K est M lorsque UPLO = 'U'.
  • LDA (INTEGER) : La dimension de référence du tableau A.
  • WORK (COMPLEX*16) : Tableau de travail. La taille dépend de NORM et de la valeur de SIDE.
  • INFO (INTEGER) : Si 0, l'exécution a réussi. Sinon, c'est le code d'erreur.

Exemples

  >>> import numpy as np
  >>> from scipy.linalg import lapack
  >>> a = np.array([[1+1j, 2+2j], [3+3j, 4+4j]])
  >>> # Calcul de la norme 1 de la partie supérieure
  >>> lapack.zlanhf(norm_option='1', uplo='U', side='L', m=2, n=2, a=a)
  (6.0, '')
  >>> # Calcul de la norme infinie de la partie inférieure
  >>> lapack.zlanhf(norm_option='I', uplo='L', side='R', m=2, n=2, a=a)
  (12.0, '')
