sous-routine zla_geamv (trans, m, n, alpha, a, lda, x, incx, beta, y, incy)
ZLA_GEAMV calcule le produit matrice-vecteur d'une matrice générale pour calculer les bornes d'erreur.

Documentation de la fonction/sous-routine

sous-routine zla_geamv (integer trans, integer m, integer n, double precision alpha, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) x, integer incx, double precision beta, double precision, dimension( * ) y, integer incy)

ZLA_GEAMV calcule le produit matrice-vecteur d'une matrice générale pour calculer les bornes d'erreur.

Objectif :

!>
!> ZLA_GEAMV  effectue l'une des opérations matrice-vecteur :
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>    ou   y := alpha*abs(A)**T*abs(x) + beta*abs(y),
!>
!> où alpha et beta sont des scalaires, x et y sont des vecteurs et A est une
!> matrice de m par n.
!>
!> Cette fonction est principalement utilisée pour calculer des bornes d'erreur.
!> Pour se protéger contre le sous-flux lors de l'évaluation, les composantes du
!> vecteur résultant sont perturbées à partir de zéro par (N+1) fois le seuil de
!> sous-flux. Pour éviter des erreurs inutilement grandes pour les structures de blocs
!> intégrées dans des matrices générales, les composantes nulles ne sont pas perturbées.
!> Une entrée nulle est considérée si toutes les multiplications impliquées
!> dans le calcul de cette entrée ont au moins un multiplicande nul.
!>

Paramètres

TRANS 
!>          TRANS est de type INTEGER
!>           À l'entrée, TRANS spécifie l'opération à effectuer comme suit :
!>
!>             BLAS_NO_TRANS      y := alpha*abs(A)*abs(x) + beta*abs(y)
!>             BLAS_TRANS         y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>             BLAS_CONJ_TRANS    y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>
!>           Inchangé à la sortie.
!>

M

!>          M est de type INTEGER
!>           À l'entrée, M spécifie le nombre de lignes de la matrice A.
!>           M doit être supérieur ou égal à zéro.
!>           Inchangé à la sortie.
!>

N

!>          N est de type INTEGER
!>           À l'entrée, N spécifie le nombre de colonnes de la matrice A.
!>           N doit être supérieur ou égal à zéro.
!>           Inchangé à la sortie.
!>

ALPHA

!>          ALPHA est de type DOUBLE PRECISION
!>           À l'entrée, ALPHA spécifie le scalaire alpha.
!>           Inchangé à la sortie.
!>

A

!>          A est un tableau de type COMPLEX*16, de dimension ( LDA, n )
!>           Avant l'entrée, la partie principale de m lignes par n colonnes du tableau A doit
!>           contenir la matrice des coefficients.
!>           Inchangé à la sortie.
!>

LDA

!>          LDA est de type INTEGER
!>           À l'entrée, LDA spécifie la première dimension de A telle que déclarée
!>           dans le programme appelant (sous-programme). LDA doit être supérieur ou égal à
!>           max( 1, m ).
!>           Inchangé à la sortie.
!>

X

!>          X est un tableau de type COMPLEX*16, de dimension au moins
!>           ( 1 + ( n - 1 )*abs( INCX ) ) lorsque TRANS = 'N' ou 'n'
!>           et au moins
!>           ( 1 + ( m - 1 )*abs( INCX ) ) sinon.
!>           Avant l'entrée, le tableau X incrémenté doit contenir le
!>           vecteur x.
!>           Inchangé à la sortie.
!>

INCX

!>          INCX est de type INTEGER
!>           À l'entrée, INCX spécifie l'incrément pour les éléments de
!>           X. INCX ne doit pas être zéro.
!>           Inchangé à la sortie.
!>

BETA

!>          BETA est de type DOUBLE PRECISION
!>           À l'entrée, BETA spécifie le scalaire beta. Lorsque BETA est
!>           fourni comme zéro, Y n'a pas besoin d'être défini à l'entrée.
!>           Inchangé à la sortie.
!>

Y

!>          Y est un tableau de type DOUBLE PRECISION, de dimension
!>           ( 1 + ( m - 1 )*abs( INCY ) ) lorsque TRANS = 'N' ou 'n'
!>           et au moins
!>           ( 1 + ( n - 1 )*abs( INCY ) ) sinon.
!>           Avant l'entrée avec BETA non nul, le tableau Y incrémenté
!>           doit contenir le vecteur y. À la sortie, Y est écrasé par le
!>           vecteur y mis à jour.
!>           Si m ou n est zéro, alors Y n'est pas référencé et la fonction
!>           effectue un retour rapide.
!>

INCY

!>          INCY est de type INTEGER
!>           À l'entrée, INCY spécifie l'incrément pour les éléments de
!>           Y. INCY ne doit pas être zéro.
!>           Inchangé à la sortie.
!>
!>  Routine Blas de niveau 2.
!>
