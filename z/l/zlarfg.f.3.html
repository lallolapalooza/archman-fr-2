subroutine zlarfg (n, alpha, x, incx, tau)
ZLARFG génère un réflecteur élémentaire (matrice de Householder).

Documentation Fonction/Sous-programme

sous-programme zlarfg (integer n, complex*16 alpha, complex*16, dimension( * ) x, integer incx, complex*16 tau)

ZLARFG génère un réflecteur élémentaire complexe H d'ordre n, tel que

But :

!>
!> ZLARFG génère un réflecteur élémentaire complexe H d'ordre n, tel que
!>
!>       H**H * ( alpha ) = ( beta ),   H**H * H = I.
!>              (   x   )   (   0  )
!>
!> où alpha et beta sont des scalaires, avec beta réel, et x est un
!> vecteur complexe à (n-1) éléments. H est représenté sous la forme
!>
!>       H = I - tau * ( 1 ) * ( 1 v**H ) ,
!>                     ( v )
!>
!> où tau est un scalaire complexe et v est un vecteur complexe à (n-1)
!> éléments. Notez que H n'est pas hermitien.
!>
!> Si les éléments de x sont tous nuls et alpha est réel, alors tau = 0
!> et H est prise comme étant la matrice unité.
!>
!> Sinon,  1 <= real(tau) <= 2  et  abs(tau-1) <= 1 .
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre du réflecteur élémentaire.
!>

ALPHA

!>          ALPHA est COMPLEX*16
!>          En entrée, la valeur alpha.
!>          En sortie, elle est écrasée par la valeur beta.
!>

X

!>          X est un tableau COMPLEX*16, de dimension
!>                         (1+(N-2)*abs(INCX))
!>          En entrée, le vecteur x.
!>          En sortie, il est écrasé par le vecteur v.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les éléments de X. INCX > 0.
!>

TAU

!>          TAU est COMPLEX*16
!>          La valeur tau.
!>
