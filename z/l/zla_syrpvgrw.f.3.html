Documentation de la fonction/sous-programme

double precision function zla_syrpvgrw (character*1 uplo, integer n, integer info, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, double precision, dimension( * ) work)

ZLA_SYRPVGRW calcule le facteur de croissance réciproque des pivots norm(A)/norm(U) pour une matrice indéfinie symétrique.

But:

!>
!>
!> ZLA_SYRPVGRW calcule le facteur de croissance réciproque des pivots
!> norm(A)/norm(U). La  norme est utilisée. Si celle-ci est
!> beaucoup plus petite que 1, la stabilité de la factorisation LU de la
!> matrice équilibrée A pourrait être médiocre. Cela signifie également que
!> la solution X, les estimations du nombre de condition et les bornes d'erreur
!> pourraient être peu fiables.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U':  Le triangle supérieur de A est stocké ;
!>       = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

INFO

!>          INFO est INTEGER
!>     La valeur de INFO renvoyée par ZSYTRF, c'est-à-dire le pivot de
!>     colonne INFO est exactement 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>     En entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, de dimension (LDAF,N)
!>     La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>     obtenir le facteur U ou L tels que calculés par ZSYTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>     Détails des échanges et de la structure par blocs de D
!>     tels que déterminés par ZSYTRF.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (2*N)
!>
