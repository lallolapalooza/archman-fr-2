Documentation de fonction/sous-routine

sous-routine zlarhs (character*3 path, character xtype, character uplo, character trans, integer m, integer n, integer kl, integer ku, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldb, * ) b, integer ldb, integer, dimension( 4 ) iseed, integer info)

ZLARHS

Objectif :

!>
!> ZLARHS choisit un ensemble de NRHS vecteurs solutions aléatoires et configure les
!> membres de droite pour le système linéaire
!>    op(A) * X = B,
!> où op(A) = A, A**T, ou A**H, en fonction de TRANS.
!>

Paramètres

PATH 
!>          PATH est CHARACTER*3
!>          Le type de la matrice complexe A. PATH peut être saisi en majuscules
!>          ou minuscules. Les chemins valides incluent :
!>             xGE:  Matrice générale m x n
!>             xGB:  Matrice bande générale
!>             xPO:  Hermitienne définie positive, stockage 2D
!>             xPP:  Hermitienne définie positive, compressée
!>             xPB:  Hermitienne définie positive, bande
!>             xHE:  Hermitienne indéfinie, stockage 2D
!>             xHP:  Hermitienne indéfinie, compressée
!>             xHB:  Hermitienne indéfinie, bande
!>             xSY:  Symétrique indéfinie, stockage 2D
!>             xSP:  Symétrique indéfinie, compressée
!>             xSB:  Symétrique indéfinie, bande
!>             xTR:  Triangulaire
!>             xTP:  Triangulaire, compressée
!>             xTB:  Triangulaire, bande
!>             xQR:  Matrice générale m x n
!>             xLQ:  Matrice générale m x n
!>             xQL:  Matrice générale m x n
!>             xRQ:  Matrice générale m x n
!>          où le premier caractère indique la précision.
!>

XTYPE

!>          XTYPE est CHARACTER*1
!>          Spécifie comment la solution exacte X sera déterminée :
!>          = 'N':  Nouvelle solution ; génère un X aléatoire.
!>          = 'C':  Calculée ; utilise la valeur de X à l'entrée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          Utilisé uniquement si A est symétrique ou triangulaire ; spécifie si
!>          la partie triangulaire supérieure ou inférieure de la matrice A est stockée.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Utilisé uniquement si A est non symétrique ; spécifie l'opération
!>          appliquée à la matrice A.
!>          = 'N':  B := A    * X  (Pas de transposée)
!>          = 'T':  B := A**T * X  (Transposée)
!>          = 'C':  B := A**H * X  (Transposée conjuguée)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

KL

!>          KL est INTEGER
!>          Utilisé uniquement si A est une matrice bande ; spécifie le nombre de
!>          sous-diagonales de A si A est une matrice bande générale ou si A est
!>          symétrique ou triangulaire et UPLO = 'L' ; spécifie le nombre de
!>          super-diagonales de A si A est symétrique ou triangulaire et
!>          UPLO = 'U'. 0 <= KL <= M-1.
!>

KU

!>          KU est INTEGER
!>          Utilisé uniquement si A est une matrice bande générale ou si A est
!>          triangulaire.
!>
!>          Si PATH = xGB, spécifie le nombre de super-diagonales de A,
!>          et 0 <= KU <= N-1.
!>
!>          Si PATH = xTR, xTP, ou xTB, spécifie si la matrice a une diagonale
!>          unitaire ou non :
!>          = 1:  matrice avec diagonale non unitaire (par défaut)
!>          = 2:  matrice avec diagonale unitaire
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de vecteurs de second membre dans le système A*X = B.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          La matrice de test dont le type est donné par PATH.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si PATH = xGB, LDA >= KL+KU+1.
!>          Si PATH = xPB, xSB, xHB, ou xTB, LDA >= KL+1.
!>          Sinon, LDA >= max(1,M).
!>

X

!>          X est un tableau COMPLEX*16 (en entrée ou sortie) de dimension (LDX,NRHS)
!>          À l'entrée, si XTYPE = 'C' (pour 'Calculé'), alors X contient
!>          la solution exacte du système d'équations linéaires.
!>          À la sortie, si XTYPE = 'N' (pour 'Nouveau'), alors X est initialisé
!>          avec des valeurs aléatoires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. Si TRANS = 'N',
!>          LDX >= max(1,N) ; si TRANS = 'T', LDX >= max(1,M).
!>

B

!>          B est un tableau COMPLEX*16 de dimension (LDB,NRHS)
!>          Le ou les vecteurs de second membre pour le système d'équations,
!>          calculé(s) à partir de B = op(A) * X, où op(A) est déterminé par
!>          TRANS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. Si TRANS = 'N',
!>          LDB >= max(1,M) ; si TRANS = 'T', LDB >= max(1,N).
!>

ISEED

!>          ISEED est un tableau INTEGER de dimension (4)
!>          Le vecteur graine pour le générateur de nombres aléatoires (utilisé dans
!>          ZLATMS). Modifié à la sortie.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
