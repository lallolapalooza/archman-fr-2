Documentation de la fonction/sous-programme

double precision function zlanhf (character norm, character transr, character uplo, integer n, complex*16, dimension( 0: * ) a, double precision, dimension( 0: * ) work)

ZLANHF renvoie la valeur de la norme 1, ou la norme de Frobenius, ou la norme infinie, ou l'élément de plus grande valeur absolue d'une matrice hermitienne complexe au format RFP.

Objectif :

!>
!> ZLANHF  renvoie la valeur de la norme 1,  ou la norme de Frobenius, ou
!> la  norme infinie,  ou l'élément de  plus grande valeur absolue  d'une
!> matrice hermitienne complexe A au format RFP.
!>

Retourne

ZLANHF 
!>
!>    ZLANHF = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> où  norm1  désigne la  norme 1 d'une matrice (somme maximale des colonnes),
!> normI  désigne la  norme infinie  d'une matrice  (somme maximale des lignes) et
!> normF  désigne la  norme de Frobenius  d'une matrice (racine carrée de la somme des
!> carrés).  Notez que  max(abs(A(i,j)))  n'est pas  une norme matricielle.
!>

Paramètres

NORM 
!>          NORM est CHARACTER
!>            Spécifie la valeur à retourner dans ZLANHF comme décrit
!>            ci-dessus.
!>

TRANSR

!>          TRANSR est CHARACTER
!>            Spécifie si le format RFP de A est normal ou
!>            transposé conjugué.
!>            = 'N':  Le format RFP est Normal
!>            = 'C':  Le format RFP est Transposé conjugué
!>

UPLO

!>          UPLO est CHARACTER
!>            À l'entrée, UPLO spécifie si la matrice RFP A provient
!>            d'une matrice triangulaire supérieure ou inférieure comme suit :
!>
!>            UPLO = 'U' or 'u' RFP A provient d'une matrice triangulaire
!>            supérieure
!>
!>            UPLO = 'L' or 'l' RFP A provient d'une matrice triangulaire
!>            inférieure
!>

N

!>          N est INTEGER
!>            L'ordre de la matrice A.  N >= 0.  Lorsque N = 0, ZLANHF est
!>            mis à zéro.
!>

A

!>          A est un tableau COMPLEX*16, dimension ( N*(N+1)/2 );
!>            À l'entrée, la matrice A au format RFP.
!>            Le format RFP est décrit par TRANSR, UPLO et N comme suit :
!>            Si TRANSR='N' alors RFP A est (0:N,0:K-1) quand N est pair;
!>            K=N/2. RFP A est (0:N-1,0:K) quand N est impair; K=N/2. Si
!>            TRANSR = 'C' alors RFP est la transposée conjuguée de RFP A
!>            telle que définie quand TRANSR = 'N'. Le contenu de RFP A est
!>            défini par UPLO comme suit : Si UPLO = 'U', RFP A
!>            contient les ( N*(N+1)/2 ) éléments de A supérieur packé
!>            soit en format normal, soit en format transposé conjugué. Si
!>            UPLO = 'L', RFP A contient les ( N*(N+1)/2 ) éléments
!>            de A inférieur packé, soit en format normal, soit en format
!>            transposé conjugué. Le LDA de RFP A est (N+1)/2 quand TRANSR = 'C'. Quand
!>            TRANSR est 'N', le LDA est N+1 quand N est pair et N quand
!>            il est impair. Voir la Note ci-dessous pour plus de détails.
!>            Non modifié à la sortie.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (LWORK),
!>            où LWORK >= N quand NORM = 'I' or '1' or 'O'; sinon,
!>            WORK n'est pas référencé.
!>

NAME

zlanhf — Calculer une norme de Frobenius ou 1-norme d'une matrice hermitienne complexe à bande supérieure

SYNOPSIS

REAL FUNCTION zlanhf(norm, uplo, n, kband, ab, ldab, work) INTEGER :: n INTEGER :: kband COMPLEX*16, DIMENSION(ldab, *) :: ab INTEGER :: ldab REAL*8 :: work CHARACTER(LEN=*) :: norm CHARACTER(LEN=1) :: uplo ``` Pour `norm = 'I'` (norme 1), `zlanhf` calcule le maximum des sommes des valeurs absolues des éléments dans chaque colonne.

Pour `norm = 'F'` (norme de Frobenius), `zlanhf` calcule la racine carrée de la somme des carrés des valeurs absolues de tous les éléments.

Pour `norm = 'O'` (norme infinie), `zlanhf` calcule le maximum des sommes des valeurs absolues des éléments dans chaque ligne.

Pour `norm = 'M'` (norme maximale), `zlanhf` calcule le maximum des valeurs absolues de tous les éléments.

uplo spécifie si la matrice est triangulaire supérieure ('U') ou inférieure ('L').

n est l'ordre de la matrice.

kband est le nombre de bandes au-dessus ou en dessous de la diagonale principale.

ab est le tableau de stockage de la matrice hermitienne complexe à bande supérieure.

ldab est le nombre de lignes de ab.

work est un tableau de travail utilisé par la fonction.

Function/Subroutine Documentation

Le reste de la documentation, y compris les détails sur la façon dont les normes sont calculées pour les différentes options de `norm` et `uplo`, ainsi que les valeurs de retour possibles et les paramètres d'entrée, ne sont pas fournis dans cet extrait.

Cependant, on peut déduire que les normes calculées sont des normes matricielles standard. La fonction est destinée à être utilisée avec des matrices hermitiennes complexes stockées sous forme de bandes.
