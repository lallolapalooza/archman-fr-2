sous-programme zlqt02 (entier m, entier n, entier k, complexe*16, dimension( lda, * ) a, complexe*16, dimension( lda, * ) af, complexe*16, dimension( lda, * ) q, complexe*16, dimension( lda, * ) l, entier lda, complexe*16, dimension( * ) tau, complexe*16, dimension( lwork ) work, entier lwork, double précision, dimension( * ) rwork, double précision, dimension( * ) result)

ZLQT02

Objectif:

!>
!> ZLQT02 teste ZUNGLQ, qui génère une matrice Q de taille m x n avec
!> des lignes orthonormées, définie comme le produit de k réflecteurs élémentaires.
!>
!> Étant donné la factorisation LQ d'une matrice A de taille m x n, ZLQT02 génère
!> la matrice orthogonale Q définie par la factorisation des k premières lignes de A ;
!> il compare L(1:k,1:m) à A(1:k,1:n)*Q(1:m,1:n)', et vérifie que les lignes de Q sont orthonormées.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q à générer.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q à générer.
!>          N >= M >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. M >= K >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          La matrice A de taille m x n factorisée par ZLQT01.
!>

AF

!>          AF est un tableau COMPLEX*16, de dimension (LDA,N)
!>          Détails de la factorisation LQ de A, tels que retournés par ZGELQF.
!>          Voir ZGELQF pour plus de détails.
!>

Q

!>          Q est un tableau COMPLEX*16, de dimension (LDA,N)
!>

L

!>          L est un tableau COMPLEX*16, de dimension (LDA,M)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, Q et L. LDA >= N.
!>

TAU

!>          TAU est un tableau COMPLEX*16, de dimension (M)
!>          Les facteurs scalaires des réflecteurs élémentaires correspondant
!>          à la factorisation LQ dans AF.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, de dimension (M)
!>

RESULT

!>          RESULT est un tableau DOUBLE PRÉCISION, de dimension (2)
!>          Les rapports de test :
!>          RESULT(1) = norm( L - A*Q' ) / ( N * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q*Q' ) / ( N * EPS )
!>
