sous-routine zla_gbrfsx_extended (integer prec_type, integer trans_type, integer n, integer kl, integer ku, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, logical colequ, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, complex*16, dimension( * ) res, double precision, dimension(*) ayb, complex*16, dimension( * ) dy, complex*16, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

ZLA_GBRFSX_EXTENDED améliore la solution calculée d'un système d'équations linéaires pour des matrices bande générales en effectuant un raffinement itératif de précision supplémentaire et fournit des bornes d'erreur et des estimations d'erreur à rebours pour la solution.

Objectif :

!>
!> ZLA_GBRFSX_EXTENDED améliore la solution calculée d'un système
!> d'équations linéaires en effectuant un raffinement itératif de précision
!> supplémentaire et fournit des bornes d'erreur et des estimations
!> d'erreur à rebours pour la solution.
!> Cette sous-routine est appelée par ZGBRFSX pour effectuer le raffinement
!> itératif. En plus de la borne d'erreur normwise, le code fournit une borne
!> d'erreur composante par composante maximale si possible. Voir les commentaires
!> pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des bornes d'erreur.
!> Notez que cette sous-routine est uniquement responsable de la définition des
!> seconds champs de ERR_BNDS_NORM et ERR_BNDS_COMP.
!>

Paramètres

PREC_TYPE 
!>          PREC_TYPE est INTEGER
!>     Spécifie la précision intermédiaire à utiliser pour le raffinement.
!>     La valeur est définie par ILAPREC(P) où P est un CARACTÈRE et P
!>          = 'S':  Simple
!>          = 'D':  Double
!>          = 'I':  Indigène
!>          = 'X' or 'E':  Extra
!>

TRANS_TYPE

!>          TRANS_TYPE est INTEGER
!>     Spécifie l'opération de transposition sur A.
!>     La valeur est définie par ILATRANS(T) où T est un CARACTÈRE et T
!>          = 'N':  Pas de transposition
!>          = 'T':  Transposée
!>          = 'C':  Transposée conjuguée
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes de la
!>     matrice B.
!>

AB

!>          AB est tableau COMPLEX*16, dimension (LDAB,N)
!>     À l'entrée, la matrice A de taille N par N.
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale du tableau A.  LDAB >= max(1,N).
!>

AFB

!>          AFB est tableau COMPLEX*16, dimension (LDAF,N)
!>     Les facteurs L et U de la factorisation
!>     A = P*L*U tels que calculés par ZGBTRF.
!>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est tableau INTEGER, dimension (N)
!>     Les indices de pivot de la factorisation A = P*L*U
!>     tels que calculés par ZGBTRF ; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>

COLEQU

!>          COLEQU est LOGICAL
!>     Si .TRUE. alors l'équilibration des colonnes a été effectuée sur A avant
!>     d'appeler cette routine. Ceci est nécessaire pour calculer la solution et
!>     les bornes d'erreur correctement.
!>

C

!>          C est tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle des colonnes pour A. Si COLEQU = .FALSE., C
!>     n'est pas accédé. Si C est en entrée, chaque élément de C doit être une
!>     puissance du radix pour assurer une solution et des estimations d'erreur
!>     fiables. La mise à l'échelle par des puissances du radix ne cause pas
!>     d'erreurs d'arrondi sauf si le résultat sousflue ou déborde. Les erreurs
!>     d'arrondi lors de la mise à l'échelle conduisent à un raffinement avec une
!>     matrice qui n'est pas équivalente à la matrice d'entrée, produisant des
!>     estimations d'erreur qui peuvent ne pas être fiables.
!>

B

!>          B est tableau COMPLEX*16, dimension (LDB,NRHS)
!>     La matrice des membres de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

Y

!>          Y est tableau COMPLEX*16, dimension (LDY,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par ZGBTRS.
!>     À la sortie, la matrice solution améliorée Y.
!>

LDY

!>          LDY est INTEGER
!>     La dimension principale du tableau Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT est tableau DOUBLE PRECISION, dimension (NRHS)
!>     À la sortie, BERR_OUT(j) contient l'erreur composante par composante
!>     relative à rebours pour le membre de droite j selon la formule
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     où abs(Z) est la valeur absolue composante par composante de la matrice
!>     ou du vecteur Z. Ceci est calculé par ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS est INTEGER
!>     Détermine quelles bornes d'erreur retourner (voir ERR_BNDS_NORM
!>     et ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 retourne les bornes d'erreur normwise.
!>     Si N_NORMS >= 2 retourne les bornes d'erreur composante par composante.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative normwise, qui est définie comme suit :
!>
!>     Erreur relative normwise dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ----------------------------
-- !> max_j abs(X(j,i)) !> !> Le tableau est indexé par le type d'informations d'erreur tel que décrit !> ci-dessous. Il y a actuellement jusqu'à trois informations !> retournées. !> !> Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème !> second membre. !> !> Le second indice dans ERR_BNDS_NORM(:,err) contient les trois !> champs suivants : !> err = 1 booléen. Faites confiance à la réponse si le !> nombre de condition réciproque est inférieur au seuil !> sqrt(n) * slamch('Epsilon'). !> !> err = 2 borne d'erreur : L'erreur avant estimée, !> presque certainement dans un facteur de 10 de l'erreur !> vraie tant que l'entrée suivante est supérieure au seuil !> sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne doit !> être utilisée que si le booléen précédent est vrai. !> !> err = 3 Nombre de condition réciproque : Norme estimée de la !> norme du nombre de condition réciproque. Comparé au seuil !> sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation !> de l'erreur est . Ces nombres de condition !> réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour !> une matrice Z convenablement mise à l'échelle. !> Soit Z = S*A, où S met à l'échelle chaque ligne par une !> puissance de la base de sorte que toutes les sommes de lignes !> absolues de Z soient approximativement 1. !> !> Cette sous-routine est uniquement responsable de la définition du !> second champ ci-dessus. !> Voir Lapack Working Note 165 pour plus de détails et des précautions !> supplémentaires. !>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative par composante, qui est définie comme suit :
!>
!>     Erreur relative par composante du i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le i-ème second membre (sur lequel
!>     l'erreur relative par composante dépend) et le type d'informations
!>     d'erreur tel que décrit ci-dessous. Il y a actuellement jusqu'à
!>     trois informations retournées pour chaque second membre. Si la
!>     précision par composante n'est pas demandée (PARAMS(3) = 0.0),
!>     alors ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors
!>     au plus les premières (:,N_ERR_BNDS) entrées sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le second indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur
!>              vraie tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne doit
!>              être utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Nombre de condition
!>              réciproque par composante estimé. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation
!>              de l'erreur est . Ces nombres de condition
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour
!>              une matrice Z convenablement mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre courant et S met à l'échelle chaque ligne
!>              de A*diag(x) par une puissance de la base de sorte que
!>              toutes les sommes de lignes absolues de Z soient
!>              approximativement 1.
!>
!>     Cette sous-routine est uniquement responsable de la définition du
!>     second champ ci-dessus.
!>     Voir Lapack Working Note 165 pour plus de détails et des précautions
!>     supplémentaires.
!>

RES

!>          RES est un tableau COMPLEX*16, de dimension (N)
!>     Espace de travail pour contenir le résidu intermédiaire.
!>

AYB

!>          AYB est un tableau DOUBLE PRECISION, de dimension (N)
!>     Espace de travail.
!>

DY

!>          DY est un tableau COMPLEX*16, de dimension (N)
!>     Espace de travail pour contenir la solution intermédiaire.
!>

Y_TAIL

!>          Y_TAIL est un tableau COMPLEX*16, de dimension (N)
!>     Espace de travail pour contenir les bits finaux de la solution
!>     intermédiaire.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     Nombre de condition réciproque mis à l'échelle. C'est une
!>     estimation du nombre de condition réciproque de Skeel de la
!>     matrice A après équilibrage (si effectué). S'il est inférieur
!>     à la précision machine (en particulier, s'il est zéro), la
!>     matrice est singulière à la précision de travail. Notez que
!>     l'erreur peut toujours être petite même si ce nombre est très
!>     petit et que la matrice semble mal conditionnée.
!>

ITHRESH

!>          ITHRESH est INTEGER
!>     Le nombre maximum de calculs de résidu autorisés pour le
!>     raffinement. La valeur par défaut est 10. Pour 'agressif',
!>     définir à 100 pour permettre la convergence en utilisant des
!>     factorisations approchées ou des factorisations autres que LU.
!>     Si la factorisation utilise une technique autre que l'élimination
!>     gaussienne, les garanties dans ERR_BNDS_NORM et ERR_BNDS_COMP
!>     peuvent ne plus être fiables.
!>

RTHRESH

!>          RTHRESH est DOUBLE PRECISION
!>     Détermine quand arrêter le raffinement si l'estimation de
!>     l'erreur cesse de diminuer. Le raffinement s'arrêtera lorsque
!>     la solution suivante ne satisfera plus norm(dx_{i+1}) <
!>     RTHRESH * norm(dx_i) où norm(Z) est la norme infinie de Z.
!>     RTHRESH satisfait 0 < RTHRESH <= 1. La valeur par défaut est 0.5.
!>     Pour 'agressif', définir à 0.9 pour permettre la convergence
!>     sur des matrices extrêmement mal conditionnées. Voir LAWN 165
!>     pour plus de détails.
!>

DZ_UB

!>          DZ_UB est DOUBLE PRECISION
!>     Détermine quand commencer à considérer la convergence par
!>     composante. La convergence par composante n'est considérée
!>     qu'après que chaque composante de la solution Y soit stable,
!>     ce que nous définissons comme le changement relatif de chaque
!>     composante étant inférieur à DZ_UB. La valeur par défaut est
!>     0.25, nécessitant que le premier bit soit stable. Voir LAWN 165
!>     pour plus de détails.
!>

IGNORE_CWISE

!>          IGNORE_CWISE est LOGICAL
!>     Si .VRAI. alors ignorer la convergence par composante. Valeur
!>     par défaut : .FAUX..
!>

INFO

!>          INFO est INTEGER
!>       = 0 : Sortie réussie.
!>       < 0 : Si INFO = -i, le i-ème argument de ZGBTRS avait une
!>             valeur illégale.
!>
