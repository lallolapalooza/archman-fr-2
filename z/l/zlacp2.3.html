subroutine zlacp2 (uplo, m, n, a, lda, b, ldb)
ZLACP2 copie tout ou partie d'un tableau bidimensionnel réel vers un tableau complexe.

Documentation de la fonction/sous-programme

sous-programme zlacp2 (caractere uplo, entier m, entier n, double precision, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb)

ZLACP2 copie tout ou partie d'une matrice bidimensionnelle réelle A vers une matrice complexe B.

Objectif:

!>
!> ZLACP2 copie tout ou partie d'une matrice bidimensionnelle réelle A vers une
!> matrice complexe B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie la partie de la matrice A à copier dans B.
!>          = 'U':      Partie triangulaire supérieure
!>          = 'L':      Partie triangulaire inférieure
!>          Sinon:      Toute la matrice A
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,N)
!>          La matrice m par n, A.  Si UPLO = 'U', seul le trapèze supérieur
!>          est accédé ; si UPLO = 'L', seul le trapèze inférieur est
!>          accédé.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,N)
!>          En sortie, B = A dans les emplacements spécifiés par UPLO.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,M).
!>
