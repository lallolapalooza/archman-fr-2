sous-routine zlartg (complex(wp) f, complex(wp) g, real(wp) c, complex(wp) s, complex(wp) r)

ZLARTG génère une rotation plane avec cosinus réel et sinus complexe.

Objectif :

!>
!> ZLARTG génère une rotation plane telle que
!>
!>    [  C         S  ] . [ F ]  =  [ R ]
!>    [ -conjg(S)  C  ]   [ G ]     [ 0 ]
!>
!> où C est réel et C**2 + |S|**2 = 1.
!>
!> Les formules mathématiques utilisées pour C et S sont
!>
!>    sgn(x) = {  x / |x|,   x != 0
!>             {  1,         x  = 0
!>
!>    R = sgn(F) * sqrt(|F|**2 + |G|**2)
!>
!>    C = |F| / sqrt(|F|**2 + |G|**2)
!>
!>    S = sgn(F) * conjg(G) / sqrt(|F|**2 + |G|**2)
!>
!> Conditions spéciales :
!>    Si G=0, alors C=1 et S=0.
!>    Si F=0, alors C=0 et S est choisi tel que R soit réel.
!>
!> Lorsque F et G sont réels, les formules se simplifient en C = F/R et
!> S = G/R, et les valeurs retournées de C, S et R devraient être
!> identiques à celles retournées par DLARTG.
!>
!> L'algorithme utilisé pour calculer ces quantités intègre une mise à l'échelle
!> pour éviter le débordement ou le sous-dépassement lors du calcul de la racine
!> carrée de la somme des carrés.
!>
!> C'est la même routine que ZROTG de BLAS1, sauf que
!> F et G ne sont pas modifiés au retour.
!>
!> Ci-dessous, wp=>dp fait référence à la double précision du module LA_CONSTANTS.
!>

Paramètres

F 
!>          F est COMPLEX(wp)
!>          Le premier composant du vecteur à faire pivoter.
!>

G

!>          G est COMPLEX(wp)
!>          Le deuxième composant du vecteur à faire pivoter.
!>

C

!>          C est REAL(wp)
!>          Le cosinus de la rotation.
!>

S

!>          S est COMPLEX(wp)
!>          Le sinus de la rotation.
!>

R

!>          R est COMPLEX(wp)
!>          Le composant non nul du vecteur pivoté.
!>
