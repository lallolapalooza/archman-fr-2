sous-routine zlatb5 (caractère*3 path, entier imat, entier n, caractère type, entier kl, entier ku, double précision anorm, entier mode, double précision cndnum, caractère dist)

ZLATB5

Objectif :

!>
!> ZLATB5 définit les paramètres du générateur de matrice en fonction du type
!> de matrice à générer.
!>

Paramètres

PATH 
!>          PATH est CARACTÈRE*3
!>          Le nom du chemin LAPACK.
!>

IMAT

!>          IMAT est ENTIER
!>          Une clé entière décrivant quelle matrice générer pour ce
!>          chemin.
!>

N

!>          N est ENTIER
!>          Le nombre de lignes et de colonnes de la matrice à générer.
!>

TYPE

!>          TYPE est CARACTÈRE*1
!>          Le type de la matrice à générer :
!>          = 'S' :  matrice symétrique
!>          = 'P' :  matrice symétrique définie (positivement)
!>          = 'N' :  matrice non symétrique
!>

KL

!>          KL est ENTIER
!>          La largeur de bande inférieure de la matrice à générer.
!>

KU

!>          KU est ENTIER
!>          La largeur de bande supérieure de la matrice à générer.
!>

ANORM

!>          ANORM est DOUBLE PRÉCISION
!>          La norme souhaitée de la matrice à générer. La matrice diagonale
!>          des valeurs singulières ou propres est mise à l'échelle par cette
!>          valeur.
!>

MODE

!>          MODE est ENTIER
!>          Une clé indiquant comment choisir le vecteur des valeurs propres.
!>

CNDNUM

!>          CNDNUM est DOUBLE PRÉCISION
!>          Le nombre de conditionnement souhaité.
!>

DIST

!>          DIST est CARACTÈRE*1
!>          Le type de distribution à utiliser par le générateur de nombres
!>          aléatoires.
!>
