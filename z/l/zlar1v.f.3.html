sous-routine zlar1v (integer n, integer b1, integer bn, double precision lambda, double precision, dimension( * ) d, double precision, dimension( * ) l, double precision, dimension( * ) ld, double precision, dimension( * ) lld, double precision pivmin, double precision gaptol, complex*16, dimension( * ) z, logical wantnc, integer negcnt, double precision ztz, double precision mingma, integer r, integer, dimension( * ) isuppz, double precision nrminv, double precision resid, double precision rqcorr, double precision, dimension( * ) work)

ZLAR1V calcule la colonne r (mise à l'échelle) de l'inverse de la sous-matrice des lignes b1 à bn de la matrice tridiagonale LDLT - λI.

Objectif :

!>
!> ZLAR1V calcule la colonne r (mise à l'échelle) de l'inverse de
!> la sous-matrice des lignes B1 à BN de la matrice tridiagonale
!> L D L**T - sigma I. Lorsque sigma est proche d'une valeur propre,
!> le vecteur calculé est un vecteur propre précis. Généralement, r correspond
!> à l'indice où le vecteur propre est le plus grand en magnitude.
!> Les étapes suivantes accomplissent ce calcul :
!> (a) Transformation qd stationnaire, L D L**T - sigma I = L(+) D(+) L(+)**T,
!> (b) Transformation qd progressive, L D L**T - sigma I = U(-) D(-) U(-)**T,
!> (c) Calcul des éléments diagonaux de l'inverse de
!>     L D L**T - sigma I en combinant les transformations ci-dessus, et en choisissant
!>     r comme l'indice où la diagonale de l'inverse est (l'un des)
!>     plus grands en magnitude.
!> (d) Calcul de la colonne r (mise à l'échelle) de l'inverse en utilisant la
!>     factorisation torsadée obtenue en combinant la partie supérieure de la
!>     transformation stationnaire et la partie inférieure de la transformation progressive.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>           L'ordre de la matrice L D L**T.
!>

B1

!>          B1 est un entier (INTEGER)
!>           Premier indice de la sous-matrice de L D L**T.
!>

BN

!>          BN est un entier (INTEGER)
!>           Dernier indice de la sous-matrice de L D L**T.
!>

LAMBDA

!>          LAMBDA est un double précision (DOUBLE PRECISION)
!>           Le décalage. Afin de calculer un vecteur propre précis,
!>           LAMBDA doit être une bonne approximation d'une valeur propre
!>           de L D L**T.
!>

L

!>          L est un tableau de double précision (DOUBLE PRECISION), dimension (N-1)
!>           Les (n-1) éléments sous-diagonaux de la matrice unitaire bidiagonale
!>           L, dans les éléments 1 à N-1.
!>

D

!>          D est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>           Les n éléments diagonaux de la matrice diagonale D.
!>

LD

!>          LD est un tableau de double précision (DOUBLE PRECISION), dimension (N-1)
!>           Les n-1 éléments L(i)*D(i).
!>

LLD

!>          LLD est un tableau de double précision (DOUBLE PRECISION), dimension (N-1)
!>           Les n-1 éléments L(i)*L(i)*D(i).
!>

PIVMIN

!>          PIVMIN est un double précision (DOUBLE PRECISION)
!>           Le pivot minimum dans la séquence de Sturm.
!>

GAPTOL

!>          GAPTOL est un double précision (DOUBLE PRECISION)
!>           Tolérance indiquant quand les entrées du vecteur propre sont négligeables
!>           par rapport à leur contribution au résidu.
!>

Z

!>          Z est un tableau complexe*16 (COMPLEX*16), dimension (N)
!>           En entrée, toutes les entrées de Z doivent être mises à 0.
!>           En sortie, Z contient la colonne r (mise à l'échelle) de l'inverse.
!>           La mise à l'échelle est telle que Z(R) est égal à 1.
!>

WANTNC

!>          WANTNC est une valeur logique (LOGICAL)
!>           Spécifie si NEGCNT doit être calculé.
!>

NEGCNT

!>          NEGCNT est un entier (INTEGER)
!>           Si WANTNC est .VRAI. alors NEGCNT = le nombre de pivots < pivmin
!>           dans la factorisation de la matrice L D L**T, et NEGCNT = -1 sinon.
!>

ZTZ

!>          ZTZ est un double précision (DOUBLE PRECISION)
!>           Le carré de la norme 2 de Z.
!>

MINGMA

!>          MINGMA est un double précision (DOUBLE PRECISION)
!>           L'inverse du plus grand élément diagonal (en magnitude) de
!>           l'inverse de L D L**T - sigma I.
!>

R

!>          R est un entier (INTEGER)
!>           L'indice de torsion pour la factorisation torsadée utilisée pour
!>           calculer Z.
!>           En entrée, 0 <= R <= N. Si R est entré comme 0, R est mis à
!>           l'indice où (L D L**T - sigma I)^{-1} est le plus grand
!>           en magnitude. Si 1 <= R <= N, R n'est pas modifié.
!>           En sortie, R contient l'indice de torsion utilisé pour calculer Z.
!>           Idéalement, R désigne la position de l'élément maximum dans le
!>           vecteur propre.
!>

ISUPPZ

!>          ISUPPZ est un tableau d'entiers (INTEGER), dimension (2)
!>           Le support du vecteur Z, c'est-à-dire que le vecteur Z est
!>           non nul uniquement dans les éléments ISUPPZ(1) à ISUPPZ( 2 ).
!>

NRMINV

!>          NRMINV est un double précision (DOUBLE PRECISION)
!>           NRMINV = 1/SQRT( ZTZ )
!>

RESID

!>          RESID est un double précision (DOUBLE PRECISION)
!>           Le résidu du vecteur FP (virgule flottante).
!>           RESID = ABS( MINGMA )/SQRT( ZTZ )
!>

RQCORR

!>          RQCORR est un double précision (DOUBLE PRECISION)
!>           La correction du quotient de Rayleigh à LAMBDA.
!>           RQCORR = MINGMA*TMP
!>

WORK

!>          WORK est un tableau de double précision (DOUBLE PRECISION), dimension (4*N)
!>
