Documentation de la fonction/sous-programme

sous-programme zlagsy (entier n, entier k, double précision, dimension( * ) d, complexe*16, dimension( lda, * ) a, entier lda, entier, dimension( 4 ) iseed, complexe*16, dimension( * ) work, entier info)

ZLAGSY

But:

!>
!> ZLAGSY génère une matrice symétrique complexe A, en pré- et post-
!> multipliant une matrice diagonale réelle D par une matrice unitaire aléatoire:
!> A = U*D*U**T. La bande semi-bande peut alors être réduite à k par
!> des transformations unitaires supplémentaires.
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

K

!>          K est ENTIER
!>          Le nombre de sous-diagonales non nulles dans la bande de A.
!>          0 <= K <= N-1.
!>

D

!>          D est un tableau de DOUBLE PRÉCISION, de dimension (N)
!>          Les éléments diagonaux de la matrice diagonale D.
!>

A

!>          A est un tableau de COMPLEX*16, de dimension (LDA,N)
!>          La matrice symétrique A générée de taille n par n (la matrice complète est
!>          stockée).
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= N.
!>

ISEED

!>          ISEED est un tableau ENTIER, de dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires; les éléments du tableau
!>          doivent être compris entre 0 et 4095, et ISEED(4) doit être
!>          impair.
!>          À la sortie, la graine est mise à jour.
!>

WORK

!>          WORK est un tableau de COMPLEX*16, de dimension (2*N)
!>

INFO

!>          INFO est ENTIER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument était illégal
!>
