sous-routine zla_herfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, logical colequ, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, complex*16, dimension( * ) res, double precision, dimension( * ) ayb, complex*16, dimension( * ) dy, complex*16, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

ZLA_HERFSX_EXTENDED améliore la solution calculée d'un système d'équations linéaires pour les matrices hermitiennes indéfinies en effectuant un raffinage itératif extra-précis et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.

Objectif :

!>
!> ZLA_HERFSX_EXTENDED améliore la solution calculée d'un système d'équations
!> linéaires en effectuant un raffinage itératif extra-précis
!> et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.
!> Cette sous-routine est appelée par ZHERFSX pour effectuer le raffinage itératif.
!> En plus de la borne d'erreur globale, le code fournit une borne d'erreur
!> composante par composante maximale si possible. Voir les commentaires pour ERR_BNDS_NORM
!> et ERR_BNDS_COMP pour les détails des bornes d'erreur. Notez que cette
!> sous-routine est uniquement responsable de la définition des seconds champs de
!> ERR_BNDS_NORM et ERR_BNDS_COMP.
!>

Paramètres

PREC_TYPE 
!>          PREC_TYPE est un entier
!>     Spécifie la précision intermédiaire à utiliser pour le raffinement.
!>     La valeur est définie par ILAPREC(P) où P est un caractère et P
!>          = 'S':  Simple
!>          = 'D':  Double
!>          = 'I':  Indigène
!>          = 'X' ou 'E':  Extra
!>

UPLO

!>          UPLO est un caractère de longueur 1
!>       = 'U':  Le triangle supérieur de A est stocké ;
!>       = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est un entier
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un entier
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes de la
!>     matrice B.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est un entier
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, de dimension (LDAF,N)
!>     La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>     obtenir le facteur U ou L calculé par ZHETRF.
!>

LDAF

!>          LDAF est un entier
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau d'entiers, de dimension (N)
!>     Détails des échanges et de la structure par blocs de D
!>     tels que déterminés par ZHETRF.
!>

COLEQU

!>          COLEQU est un logique
!>     Si .VRAI. alors l'équilibration des colonnes a été effectuée sur A avant d'appeler
!>     cette routine. Ceci est nécessaire pour calculer correctement la solution et les bornes d'erreur.
!>

C

!>          C est un tableau DOUBLE PRECISION, de dimension (N)
!>     Les facteurs d'échelle des colonnes pour A. Si COLEQU = .FAUX., C
!>     n'est pas accédé. Si C est en entrée, chaque élément de C doit être une puissance
!>     de la base pour assurer une solution et des estimations d'erreur fiables.
!>     La mise à l'échelle par des puissances de la base ne provoque pas d'erreurs d'arrondi, sauf si
!>     le résultat déborde ou sous-dépasse. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent au raffinement d'une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>     La matrice des membres de droite B.
!>

LDB

!>          LDB est un entier
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

Y

!>          Y est un tableau COMPLEX*16, de dimension (LDY,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par ZHETRS.
!>     À la sortie, la matrice solution améliorée Y.
!>

LDY

!>          LDY est un entier
!>     La dimension principale du tableau Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>     À la sortie, BERR_OUT(j) contient l'erreur arrière relative composante par composante
!>     pour le membre de droite j selon la formule
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     où abs(Z) est la valeur absolue composante par composante de la matrice
!>     ou du vecteur Z. Ceci est calculé par ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS est un entier
!>     Détermine quelles bornes d'erreur retourner (voir ERR_BNDS_NORM
!>     et ERR_BNDS_COMP).
!>     Si N_NORMS >= 1, retourner les bornes d'erreur globales.
!>     Si N_NORMS >= 2, retourner les bornes d'erreur composantes par composantes.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative globale, qui est définie comme suit :
!>
!>     Erreur relative globale dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le second indice dans ERR_BNDS_NORM(:,err) contient les trois champs
!>     suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * sl

NAME

zla_herfsx_extended - Provides error bounds and condition numbers for complex Hermitian systems of linear equations.

SYNOPSIS

In the following routines, all matrices are assumed to be complex and all vectors are assumed to be complex.

    SUBROUTINE ZLA_HERFSX_EXTENDED( UPLO, N, NRHS, A, LDA, AF, LDAF, IPIV,
                                    B, LDB, X, LDX, FERR, BERR, CND, RINFO,
                                    PARAMS, WORK, LWORK, INFO )
    CHARACTER *1               UPLO
    INTEGER                   N, NRHS, LDA, LDAF, LDB, LDX, LWORK, INFO
    INTEGER                   IPIV( * )
    COMPLEX*16                A( LDA, * ), AF( LDAF, * ), B( LDB, * ),
                                X( LDX, * )
    DOUBLE PRECISION          FERR( * ), BERR( * ), CND( * ), RINFO( * ),
                                PARAMS( * )
    COMPLEX*16                WORK( * )

Function/Subroutine Documentation

UPLO

          CHARACTER*1 UPLO
          Specifies whether the matrix A is upper or lower triangular.
          UPLO = 'U' or 'u': Upper triangular.
          UPLO = 'L' or 'l': Lower triangular.

N

          INTEGER N
          The number of linear equations, i.e., the dimension of the
          matrix A. N >= 0.

NRHS

          INTEGER NRHS
          The number of right hand sides, i.e., the number of vectors in
          B and X. NRHS >= 0.

A

          COMPLEX*16 A(LDA, N)
          The original upper or lower triangular matrix A, of dimension N x N.

LDA

          INTEGER LDA
          The leading dimension of the array A. LDA >= max(1, N).

AF

          COMPLEX*16 AF(LDAF, N)
          The LU factorization of A, computed by ZGETRF.

LDAF

          INTEGER LDAF
          The leading dimension of the array AF. LDAF >= max(1, N).

IPIV

          INTEGER IPIV(N)
          The pivot indices of the factorization A = P*A, computed by ZGETRF.
          Column k of the factorization is exchanged with column IPIV(k).

B

          COMPLEX*16 B(LDB, NRHS)
          On entry, the right hand side matrix of dimension N x NRHS.
          On exit, B is overwritten by the solution vectors X.

LDB

          INTEGER LDB
          The leading dimension of the array B. LDB >= max(1, N).

X

          COMPLEX*16 X(LDX, NRHS)
          On exit, the solution matrix to the system of equations Ax = b.
          X has dimension N x NRHS.

LDX

          INTEGER LDX
          The leading dimension of the array X. LDX >= max(1, N).

FERR

          DOUBLE PRECISION FERR(NRHS)
          On exit, FERR(j) is an estimate of the forward error in the
          j-th solution vector X(:,j), that is, the relative error
          ||X(:,j) - XTRUE(:,j)|| / ||XTRUE(:,j)||.

BERR

          DOUBLE PRECISION BERR(NRHS)
          On exit, BERR(j) is the componentwise error bound for the
          j-th solution vector X(:,j). This is the solution computed by
          the subroutine ZLA_HERFSX_EXTENDED.

CND

          DOUBLE PRECISION CND(NRHS)
          On exit, CND(j) is the condition number of the leading submatrix
          of A, computed by ZLA_HERFSX_EXTENDED.

RINFO

          DOUBLE PRECISION RINFO(NRHS)
          On exit, RINFO(j) contains information about the accuracy of
          the solution X(:,j). It is defined as follows:
          RINFO(j) = FERR(j) / BERR(j).
          If RINFO(j) is large, it means that the matrix A is singular
          or badly scaled.

PARAMS

          DOUBLE PRECISION PARAMS(3)
          On entry, PARAMS specifies the parameters that control the
          accuracy of the solution.
          PARAMS(1) = threshold for singularity detection.
          PARAMS(2) = threshold for iterative refinement.
          PARAMS(3) = threshold for componentwise error estimation.
          On exit, PARAMS(1) contains the reciprocal condition number
          of the matrix A.

WORK

          COMPLEX*16 WORK(LWORK)
          Workspace array.

LWORK

          INTEGER LWORK
          The dimension of the array WORK. LWORK >= max(1, 2*N).
          If LWORK is too small, the routine will exit with INFO = -14.

INFO

          INTEGER INFO
          = 0: Successful exit.
          < 0: if INFO = -i, the i-th argument had an illegal value.
          > 0: if INFO = i, the algorithm failed to converge. i is the
               number of iterations.

ERR_BNDS_NORM

!>          ERR_BNDS_NORM is DOUBLE PRECISION array, dimension (NRHS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     normwise relative error, which is defined as follows:
!>
!>     Normwise relative error in the ith solution vector:
!>                    ||XTRUE(:,i) - X(:,i)||
!>             ---------------------------
!>                    ||XTRUE(:,i)||
!>
!>     The array is indexed by the right-hand side i (on which the
!>     normwise relative error depends). There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     normwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_NORM is not accessed.
!>
!>     The first index in ERR_BNDS_NORM(i) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_NORM(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated normwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*A, where S scales each row by a power of the
!>              radix so all absolute row sums of Z are approximately 1.
!>
!>     This subroutine is only responsible for setting the second field
!>     above.
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     componentwise relative error, which is defined as follows:
!>
!>     Componentwise relative error in the ith solution vector:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     The array is indexed by the right-hand side i (on which the
!>     componentwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_COMP(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated componentwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*(A*diag(x)), where x is the solution for the
!>              current right-hand side and S scales each row of
!>              A*diag(x) by a power of the radix so all absolute row
!>              sums of Z are approximately 1.
!>
!>     This subroutine is only responsible for setting the second field
!>     above.
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

RES

!>          RES is COMPLEX*16 array, dimension (N)
!>     Workspace to hold the intermediate residual.
!>

AYB

!>          AYB is DOUBLE PRECISION array, dimension (N)
!>     Workspace.
!>

DY

!>          DY is COMPLEX*16 array, dimension (N)
!>     Workspace to hold the intermediate solution.
!>

Y_TAIL

!>          Y_TAIL is COMPLEX*16 array, dimension (N)
!>     Workspace to hold the trailing bits of the intermediate solution.
!>

RCOND

!>          RCOND is DOUBLE PRECISION
!>     Reciprocal scaled condition number.  This is an estimate of the
!>     reciprocal Skeel condition number of the matrix A after
!>     equilibration (if done).  If this is less than the machine
!>     precision (in particular, if it is zero), the matrix is singular
!>     to working precision.  Note that the error may still be small even
!>     if this number is very small and the matrix appears ill-
!>     conditioned.
!>

ITHRESH

!>          ITHRESH is INTEGER
!>     The maximum number of residual computations allowed for
!>     refinement. The default is 10. For 'aggressive' set to 100 to
!>     permit convergence using approximate factorizations or
!>     factorizations other than LU. If the factorization uses a
!>     technique other than Gaussian elimination, the guarantees in
!>     ERR_BNDS_NORM and ERR_BNDS_COMP may no longer be trustworthy.
!>

RTHRESH

!>          RTHRESH is DOUBLE PRECISION
!>     Determines when to stop refinement if the error estimate stops
!>     decreasing. Refinement will stop when the next solution no longer
!>     satisfies norm(dx_{i+1}) < RTHRESH * norm(dx_i) where norm(Z) is
!>     the infinity norm of Z. RTHRESH satisfies 0 < RTHRESH <= 1. The
!>     default value is 0.5. For 'aggressive' set to 0.9 to permit
!>     convergence on extremely ill-conditioned matrices. See LAWN 165
!>     for more details.
!>

DZ_UB

!>          DZ_UB is DOUBLE PRECISION
!>     Determines when to start considering componentwise convergence.
!>     Componentwise convergence is only considered after each component
!>     of the solution Y is stable, which we define as the relative
!>     change in each component being less than DZ_UB. The default value
!>     is 0.25, requiring the first bit to be stable. See LAWN 165 for
!>     more details.
!>

IGNORE_CWISE

!>          IGNORE_CWISE is LOGICAL
!>     If .TRUE. then ignore componentwise convergence. Default value
!>     is .FALSE..
!>

INFO

!>          INFO is INTEGER
!>       = 0:  Successful exit.
!>       < 0:  if INFO = -i, the ith argument to ZLA_HERFSX_EXTENDED had an illegal
!>             value
!>
