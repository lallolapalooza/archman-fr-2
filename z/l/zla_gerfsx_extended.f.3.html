sous-programme zla_gerfsx_extended (integer prec_type, integer trans_type, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, logical colequ, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) errs_n, double precision, dimension( nrhs, * ) errs_c, complex*16, dimension( * ) res, double precision, dimension( * ) ayb, complex*16, dimension( * ) dy, complex*16, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

ZLA_GERFSX_EXTENDED

But :

!>
!> ZLA_GERFSX_EXTENDED améliore la solution calculée d'un système d'équations
!> linéaires en effectuant un raffinement itératif de précision supplémentaire
!> et fournit des bornes d'erreur ainsi que des estimations d'erreurs arrière pour la solution.
!> Ce sous-programme est appelé par ZGERFSX pour effectuer le raffinement itératif.
!> En plus de la borne d'erreur normwise, le code fournit une borne d'erreur composante par composante
!> si possible. Voir les commentaires pour ERRS_N et ERRS_C pour les détails des bornes d'erreur.
!> Notez que ce sous-programme est uniquement responsable de la définition des seconds champs de
!> ERRS_N et ERRS_C.
!>

Paramètres

PREC_TYPE 
!>          PREC_TYPE est un entier
!>     Spécifie la précision intermédiaire à utiliser pour le raffinement.
!>     La valeur est définie par ILAPREC(P) où P est un caractère et P
!>          = 'S':  Simple
!>          = 'D':  Double
!>          = 'I':  Indigène
!>          = 'X' ou 'E':  Extra
!>

TRANS_TYPE

!>          TRANS_TYPE est un entier
!>     Spécifie l'opération de transposition sur A.
!>     La valeur est définie par ILATRANS(T) où T est un caractère et T
!>          = 'N':  Pas de transposition
!>          = 'T':  Transposition
!>          = 'C':  Transposition conjuguée
!>

N

!>          N est un entier
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A. N >= 0.
!>

NRHS

!>          NRHS est un entier
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes de la
!>     matrice B.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>     À l'entrée, la matrice N par N, A.
!>

LDA

!>          LDA est un entier
!>     La dimension principale du tableau A. LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, de dimension (LDAF,N)
!>     Les facteurs L et U de la factorisation
!>     A = P*L*U calculée par ZGETRF.
!>

LDAF

!>          LDAF est un entier
!>     La dimension principale du tableau AF. LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau d'entiers, de dimension (N)
!>     Les indices de pivot de la factorisation A = P*L*U
!>     calculée par ZGETRF ; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>

COLEQU

!>          COLEQU est un logique
!>     Si .VRAI. alors l'équilibration des colonnes a été effectuée sur A avant d'appeler
!>     ce sous-programme. Ceci est nécessaire pour calculer correctement la solution et les bornes d'erreur.
!>

C

!>          C est un tableau de DOUBLE PRÉCISION, de dimension (N)
!>     Les facteurs d'échelle des colonnes pour A. Si COLEQU = .FAUX., C
!>     n'est pas accédé. Si C est en entrée, chaque élément de C devrait être une puissance
!>     du radix pour assurer une solution et des estimations d'erreur fiables.
!>     La mise à l'échelle par des puissances du radix ne provoque pas d'erreurs d'arrondi à moins
!>     que le résultat ne sous-flotte ou ne sur-flotte. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>     La matrice des membres de droite B.
!>

LDB

!>          LDB est un entier
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

Y

!>          Y est un tableau COMPLEX*16, de dimension (LDY,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par ZGETRS.
!>     À la sortie, la matrice solution améliorée Y.
!>

LDY

!>          LDY est un entier
!>     La dimension principale du tableau Y. LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT est un tableau de DOUBLE PRÉCISION, de dimension (NRHS)
!>     À la sortie, BERR_OUT(j) contient l'erreur arrière relative composante par composante
!>     provenant de la formule
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     où abs(Z) est la valeur absolue composante par composante de la matrice
!>     ou du vecteur Z. Ceci est calculé par ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS est un entier
!>     Détermine quelles bornes d'erreur retourner (voir ERRS_N
!>     et ERRS_C).
!>     Si N_NORMS >= 1, retourner les bornes d'erreur normwise.
!>     Si N_NORMS >= 2, retourner les bornes d'erreur composante par composante.
!>

ERRS_N

!>          ERRS_N est un tableau de DOUBLE PRÉCISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative normwise, qui est définie comme suit :
!>
!>     Erreur relative normwise dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice de ERRS_N(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le second indice de ERRS_N(:,err) contient les trois champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur
!>              vraie tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne doit être
!>              fait confiance que si le booléen précédent est vrai.
!>
!>

ERRS_C

!>          ERRS_C est un tableau de DOUBLE PRÉCISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>             max_j (abs(X(j,i)))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice de ERRS_C(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le second indice de ERRS_C(:,err) contient les trois champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur
!>              vraie tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne doit être
!>              fait confiance que si le booléen précédent est vrai.
!>
!>

RES

!>          RES est un tableau COMPLEX*16, de dimension (N)
!>     Le résidu R = B - op(A)*Y.
!>

AYB

!>          AYB est un tableau de DOUBLE PRÉCISION, de dimension (N)
!>     Si COLEQU = .TRUE., AYB contient abs(op(A))*abs(Y) + abs(B).
!>     Sinon, AYB contient abs(op(A)*Y - B).
!>

DY

!>          DY est un tableau COMPLEX*16, de dimension (N)
!>     Le vecteur utilisé dans la première étape de raffinemment itératif
!>     pour le calcul de l'erreur composante par composante.
!>

Y_TAIL

!>          Y_TAIL est un tableau COMPLEX*16, de dimension (N)
!>     Contient les N premiers éléments de Y. Les éléments restants de Y
!>     sont utilisés pour le calcul de l'erreur du membre de droite.
!>

RCOND

!>          RCOND est un DOUBLE PRÉCISION
!>     Le nombre de condition réciproque de la matrice A.
!>

ITHRESH

!>          ITHRESH est un entier
!>     Le seuil appliqué aux normes des résidus et des matrices lors
!>     de la sélection du type d'erreurs à retourner.
!>

RTHRESH

!>          RTHRESH est un DOUBLE PRÉCISION
!>     Le seuil appliqué aux nombres de condition réciproques lors
!>     de la sélection du type d'erreurs à retourner.
!>

DZ_UB

!>          DZ_UB est un DOUBLE PRÉCISION
!>     La borne supérieure de l'erreur pour le calcul de l'erreur
!>     composante par composante.
!>

IGNORE_CWISE

!>          IGNORE_CWISE est un logique
!>     Si .VRAI., alors le calcul de l'erreur composante par composante
!>     est ignoré.
!>

INFO

!>          INFO est un entier
!>     = 0 : succès de l'exécution.
!>     < 0 : si INFO = -i, alors le i-ème argument était invalide.
!>

err = 3 Numéro conditionnel réciproque : Norme estimée !> numéro conditionnel réciproque. Comparé au seuil !> sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation !> de l'erreur est . Ces numéros conditionnels réciproques !> sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une matrice Z !> appropriément mise à l'échelle. !> Soit Z = S*A, où S met à l'échelle chaque ligne par une puissance !> de la base afin que toutes les sommes de lignes absolues de Z !> soient approximativement égales à 1. !> !> Cette sous-routine est uniquement responsable de la définition du deuxième champ !> ci-dessus. !> Voir Lapack Working Note 165 pour plus de détails et des mises en garde !> supplémentaires. !>

ERRS_C

!>          ERRS_C est un tableau DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     divers bornes d'erreur et numéros conditionnels correspondant à
!>     l'erreur relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante du i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (dont dépend l'erreur
!>     relative composante par composante), et le type d'information d'erreur
!>     tel que décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations retournées pour chaque second membre. Si la précision
!>     composante par composante n'est pas demandée (PARAMS(3) = 0.0),
!>     alors ERRS_C n'est pas accédé. Si N_ERR_BNDS < 3, alors au maximum
!>     les premières (:,N_ERR_BNDS) entrées sont retournées.
!>
!>     Le premier indice dans ERRS_C(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERRS_C(:,err) contient les trois champs
!>     suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              numéro conditionnel réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : La borne d'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur
!>              vraie tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Numéro conditionnel réciproque : Numéro conditionnel réciproque
!>              composante par composante estimé. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation
!>              de l'erreur est . Ces numéros conditionnels réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une matrice Z
!>              appropriément mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre courant et S met à l'échelle chaque ligne de
!>              A*diag(x) par une puissance de la base afin que toutes les sommes
!>              de lignes absolues de Z soient approximativement égales à 1.
!>
!>     Cette sous-routine est uniquement responsable de la définition du deuxième champ
!>     ci-dessus.
!>     Voir Lapack Working Note 165 pour plus de détails et des mises en garde
!>     supplémentaires.
!>

RES

!>          RES est un tableau COMPLEX*16, de dimension (N)
!>     Espace de travail pour contenir le résidu intermédiaire.
!>

AYB

!>          AYB est un tableau DOUBLE PRECISION, de dimension (N)
!>     Espace de travail.
!>

DY

!>          DY est un tableau COMPLEX*16, de dimension (N)
!>     Espace de travail pour contenir la solution intermédiaire.
!>

Y_TAIL

!>          Y_TAIL est un tableau COMPLEX*16, de dimension (N)
!>     Espace de travail pour contenir les bits finaux de la solution intermédiaire.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     Numéro conditionnel réduit réciproque. C'est une estimation du
!>     numéro conditionnel de Skeel réciproque de la matrice A après
!>     équilibration (si elle a été effectuée). S'il est inférieur à la précision
!>     de la machine (en particulier, s'il est zéro), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut toujours être petite même
!>     si ce nombre est très petit et que la matrice apparaît mal conditionnée.
!>

ITHRESH

!>          ITHRESH est INTEGER
!>     Le nombre maximum de calculs de résidus autorisés pour le
!>     raffinage. La valeur par défaut est 10. Pour 'agressif', réglé à 100 pour
!>     permettre la convergence en utilisant des factorisations approximatives ou
!>     des factorisations autres que LU. Si la factorisation utilise une
!>     technique autre que l'élimination de Gauss, les garanties dans
!>     ERRS_N et ERRS_C peuvent ne plus être fiables.
!>

RTHRESH

!>          RTHRESH est DOUBLE PRECISION
!>     Détermine quand arrêter le raffinement si l'estimation de l'erreur cesse
!>     de diminuer. Le raffinement s'arrêtera lorsque la solution suivante ne
!>     satisfera plus norm(dx_{i+1}) < RTHRESH * norm(dx_i) où norm(Z) est
!>     la norme infinie de Z. RTHRESH satisfait 0 < RTHRESH <= 1. La
!>     valeur par défaut est 0.5. Pour 'agressif', réglé à 0.9 pour permettre
!>     la convergence sur des matrices extrêmement mal conditionnées. Voir LAWN 165
!>     pour plus de détails.
!>

DZ_UB

!>          DZ_UB est DOUBLE PRECISION
!>     Détermine quand commencer à considérer la convergence composante par composante.
!>     La convergence composante par composante n'est considérée qu'après que chaque composante
!>     de la solution Y soit stable, ce que nous définissons comme le changement relatif
!>     de chaque composante étant inférieur à DZ_UB. La valeur par défaut
!>     est 0.25, nécessitant que le premier bit soit stable. Voir LAWN 165 pour
!>     plus de détails.
!>

IGNORE_CWISE

!>          IGNORE_CWISE est LOGICAL
!>     Si .TRUE. alors ignorer la convergence composante par composante. Valeur par défaut
!>     est .FALSE..
!>

INFO

!>          INFO est INTEGER
!>       = 0 : Sortie réussie.
!>       < 0 : Si INFO = -i, le i-ème argument de ZGETRS avait une valeur illégale
!>             .
!>
