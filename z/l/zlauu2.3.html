Documentation de la fonction/sous-routine

sous-routine zlauu2 (caractère uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, entier info)

ZLAUU2 calcule le produit UUH ou LHL, où U et L sont des matrices triangulaires (algorithme non bloqué).

Objectif :

!>
!> ZLAUU2 calcule le produit U * U**H ou L**H * L, où le facteur triangulaire
!> U ou L est stocké dans la partie triangulaire supérieure ou inférieure
!> du tableau A.
!>
!> Si UPLO = 'U' ou 'u' alors le triangle supérieur du résultat est stocké,
!> écrasant le facteur U dans A.
!> Si UPLO = 'L' ou 'l' alors le triangle inférieur du résultat est stocké,
!> écrasant le facteur L dans A.
!>
!> C'est la forme non bloquée de l'algorithme, appelant le BLAS de niveau 2.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si le facteur triangulaire stocké dans le tableau A
!>          est triangulaire supérieur ou inférieur :
!>          = 'U' : Triangulaire supérieur
!>          = 'L' : Triangulaire inférieur
!>

N

!>          N est INTEGER
!>          L'ordre du facteur triangulaire U ou L.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, le facteur triangulaire U ou L.
!>          À la sortie, si UPLO = 'U', le triangle supérieur de A est
!>          écrasé par le triangle supérieur du produit U * U**H ;
!>          si UPLO = 'L', le triangle inférieur de A est écrasé par
!>          le triangle inférieur du produit L**H * L.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -k, le k-ième argument était illégal
!>
