subroutine zlaed8 (integer k, integer n, integer qsiz, complex*16, dimension( ldq, * ) q, integer ldq, double precision, dimension( * ) d, double precision rho, integer cutpnt, double precision, dimension( * ) z, double precision, dimension( * ) dlambda, complex*16, dimension( ldq2, * ) q2, integer ldq2, double precision, dimension( * ) w, integer, dimension( * ) indxp, integer, dimension( * ) indx, integer, dimension( * ) indxq, integer, dimension( * ) perm, integer givptr, integer, dimension( 2, * ) givcol, double precision, dimension( 2, * ) givnum, integer info)

ZLAED8 utilisé par ZSTEDC. Fusionne les valeurs propres et déflate l'équation séculaire. Utilisé lorsque la matrice originale est dense.

Objectif :

!>
!> ZLAED8 fusionne les deux ensembles de valeurs propres en un seul
!> ensemble trié.  Ensuite, il tente de déflater la taille du problème.
!> Il existe deux manières dont la déflation peut se produire : lorsque deux valeurs propres ou plus
!> sont proches les unes des autres ou s'il y a un élément minuscule dans le
!> vecteur Z.  Pour chaque occurrence, l'ordre du problème d'équation séculaire
!> associé est réduit de un.
!>

Paramètres

K 
!>          K est INTEGER
!>         Contient le nombre de valeurs propres non déflatées.
!>         C'est l'ordre du problème d'équation séculaire associé.
!>

N

!>          N est INTEGER
!>         La dimension de la matrice tridiagonale symétrique.  N >= 0.
!>

QSIZ

!>          QSIZ est INTEGER
!>         La dimension de la matrice unitaire utilisée pour réduire
!>         la matrice dense ou bande à sa forme tridiagonale.
!>         QSIZ >= N si ICOMPQ = 1.
!>

Q

!>          Q est un tableau COMPLEX*16, dimension (LDQ,N)
!>         À l'entrée, Q contient les vecteurs propres du système partiellement résolu
!>         qui a été précédemment mis à jour dans des multiplications matricielles
!>         avec d'autres systèmes propres partiellement résolus.
!>         À la sortie, Q contient les derniers (N-K) vecteurs propres mis à jour
!>         (ceux qui ont été déflatés) dans ses dernières N-K colonnes.
!>

LDQ

!>          LDQ est INTEGER
!>         La dimension principale du tableau Q.  LDQ >= max( 1, N ).
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>         À l'entrée, D contient les valeurs propres des deux sous-matrices à
!>         combiner.  À la sortie, D contient les derniers (N-K) valeurs propres mises à jour
!>         (celles qui ont été déflatées) triées par ordre croissant.
!>

RHO

!>          RHO est DOUBLE PRECISION
!>         Contient l'élément hors diagonale associé à la coupure de rang 1
!>         qui a initialement divisé les deux sous-matrices qui sont maintenant
!>         recombinées. RHO est modifié pendant le calcul pour
!>         prendre la valeur requise par DLAED3.
!>

CUTPNT

!>          CUTPNT est INTEGER
!>         Contient l'emplacement de la dernière valeur propre dans la sous-matrice
!>         principale.  MIN(1,N) <= CUTPNT <= N.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, dimension (N)
!>         À l'entrée, ce vecteur contient le vecteur de mise à jour (la dernière
!>         ligne du premier vecteur propre de sous-matrice et la première ligne de
!>         la deuxième matrice de vecteurs propres) . Le contenu de Z est
!>         détruit pendant le processus de mise à jour.
!>

DLAMBDA

!>          DLAMBDA est un tableau DOUBLE PRECISION, dimension (N)
!>         Contient une copie des K premières valeurs propres qui seront utilisées
!>         par DLAED3 pour former l'équation séculaire.
!>

Q2

!>          Q2 est un tableau COMPLEX*16, dimension (LDQ2,N)
!>         Si ICOMPQ = 0, Q2 n'est pas référencé. Sinon,
!>         contient une copie des K premiers vecteurs propres qui seront utilisés
!>         par DLAED7 dans une multiplication matricielle (DGEMM) pour mettre à jour les nouveaux
!>         vecteurs propres.
!>

LDQ2

!>          LDQ2 est INTEGER
!>         La dimension principale du tableau Q2.  LDQ2 >= max( 1, N ).
!>

W

!>          W est un tableau DOUBLE PRECISION, dimension (N)
!>         Ce tableau contiendra les K premières valeurs du vecteur
!>         z final modifié par déflation et sera passé à DLAED3.
!>

INDXP

!>          INDXP est un tableau INTEGER, dimension (N)
!>         Il contiendra la permutation utilisée pour placer les valeurs
!>         déflatées de D à la fin du tableau. À la sortie, INDXP(1:K)
!>         pointe vers les valeurs D non déflatées et INDXP(K+1:N)
!>         pointe vers les valeurs propres déflatées.
!>

INDX

!>          INDX est un tableau INTEGER, dimension (N)
!>         Il contiendra la permutation utilisée pour trier le contenu de
!>         D par ordre croissant.
!>

INDXQ

!>          INDXQ est un tableau INTEGER, dimension (N)
!>         Il contient la permutation qui trie séparément les deux
!>         sous-problèmes de D par ordre croissant.  Notez que les éléments de
!>         la seconde moitié de cette permutation doivent d'abord avoir CUTPNT
!>         ajouté à leurs valeurs pour être précis.
!>

PERM

!>          PERM est un tableau INTEGER, dimension (N)
!>         Contient les permutations (provenant de la déflation et du tri) à
!>         appliquer à chaque bloc propre.
!>

GIVPTR

!>          GIVPTR est INTEGER
!>         Contient le nombre de rotations de Givens qui ont eu lieu dans
!>         ce sous-problème.
!>

GIVCOL

!>          GIVCOL est un tableau INTEGER, dimension (2, N)
!>         Chaque paire de nombres indique une paire de colonnes pour effectuer
!>         une rotation de Givens.
!>

GIVNUM

!>          GIVNUM est un tableau DOUBLE PRECISION, dimension (2, N)
!>         Chaque nombre indique la valeur S à utiliser dans la
!>         rotation de Givens correspondante.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>
