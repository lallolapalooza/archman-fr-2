sous-routine zlaqz1 (logical, intent(in) ilq, logical, intent(in) ilz, integer, intent(in) k, integer, intent(in) istartm, integer, intent(in) istopm, integer, intent(in) ihi, complex*16, dimension( lda, * ) a, integer, intent(in) lda, complex*16, dimension( ldb, * ) b, integer, intent(in) ldb, integer, intent(in) nq, integer, intent(in) qstart, complex*16, dimension( ldq, * ) q, integer, intent(in) ldq, integer, intent(in) nz, integer, intent(in) zstart, complex*16, dimension( ldz, * ) z, integer, intent(in) ldz)

ZLAQZ1

But :

!>
!>      ZLAQZ1 poursuit une déformation de décalage 1x1 dans un crayon de matrices
!>      vers le bas d'une seule position.
!>

Paramètres

ILQ 
!>          ILQ est LOGIQUE
!>              Détermine si la matrice Q doit être mise à jour ou non.
!>

ILZ

!>          ILZ est LOGIQUE
!>              Détermine si la matrice Z doit être mise à jour ou non.
!>

K

!>          K est ENTIER
!>              Indice indiquant la position de la déformation.
!>              À l'entrée, la déformation est située dans
!>              (A(k+1,k),B(k+1,k)).
!>              À la sortie, la déformation est située dans
!>              (A(k+2,k+1),B(k+2,k+1)).
!>

ISTARTM

!>          ISTARTM est ENTIER
!>

ISTOPM

!>          ISTOPM est ENTIER
!>              Les mises à jour de (A,B) sont restreintes à
!>              (istartm:k+2,k:istopm). Il est supposé
!>              sans vérification que istartm <= k+1 et
!>              k+2 <= istopm.
!>

IHI

!>          IHI est ENTIER
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>

LDA

!>          LDA est ENTIER
!>              La dimension principale de A telle que déclarée dans
!>              la procédure appelante.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,N)
!>

LDB

!>          LDB est ENTIER
!>              La dimension principale de B telle que déclarée dans
!>              la procédure appelante.
!>

NQ

!>          NQ est ENTIER
!>              L'ordre de la matrice Q.
!>

QSTART

!>          QSTART est ENTIER
!>              Indice de début de la matrice Q. Les rotations sont appliquées
!>              aux colonnes k+2-qStart:k+3-qStart de Q.
!>

Q

!>          Q est un tableau COMPLEX*16, de dimension (LDQ,NQ)
!>

LDQ

!>          LDQ est ENTIER
!>              La dimension principale de Q telle que déclarée dans
!>              la procédure appelante.
!>

NZ

!>          NZ est ENTIER
!>              L'ordre de la matrice Z.
!>

ZSTART

!>          ZSTART est ENTIER
!>              Indice de début de la matrice Z. Les rotations sont appliquées
!>              aux colonnes k+1-qStart:k+2-qStart de Z.
!>

Z

!>          Z est un tableau COMPLEX*16, de dimension (LDZ,NZ)
!>

LDZ

!>          LDZ est ENTIER
!>              La dimension principale de Q telle que déclarée dans
!>              la procédure appelante.
!>
