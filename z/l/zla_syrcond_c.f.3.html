Documentation de la fonction/sous-programme

double precision function zla_syrcond_c (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, double precision, dimension( * ) c, logical capply, integer info, complex*16, dimension( * ) work, double precision, dimension( * ) rwork)

ZLA_SYRCOND_C calcule le nombre de conditionnement de la norme infinie de op(A)*inv(diag(c)) pour les matrices symétriques indéfinies.

Objectif :

!>
!>    ZLA_SYRCOND_C Calcule le nombre de conditionnement de la norme infinie
!>    de op(A) * inv(diag(C)) où C est un vecteur DOUBLE PRECISION.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U' :  Le triangle supérieur de A est stocké ;
!>       = 'L' :  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>     En entrée, la matrice A de taille N x N
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, de dimension (LDAF,N)
!>     La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>     obtenir le facteur U ou L tels que calculés par ZSYTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>     Détails des échanges et de la structure par blocs de D
!>     tels que déterminés par ZSYTRF.
!>

C

!>          C est un tableau DOUBLE PRECISION, de dimension (N)
!>     Le vecteur C dans la formule op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY est LOGICAL
!>     Si .TRUE. alors accéder au vecteur C dans la formule ci-dessus.
!>

INFO

!>          INFO est INTEGER
!>       = 0:  Sortie réussie.
!>     i > 0:  Le i-ème argument est invalide.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N).
!>     Espace de travail.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (N).
!>     Espace de travail.
!>
