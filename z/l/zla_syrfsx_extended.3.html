sous-routine zla_syrfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, logical colequ, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, complex*16, dimension( * ) res, double precision, dimension( * ) ayb, complex*16, dimension( * ) dy, complex*16, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

ZLA_SYRFSX_EXTENDED améliore la solution calculée pour un système d'équations linéaires pour les matrices symétriques indéfinies en effectuant un raffinement itératif de précision étendue et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.

Objectif :

!>
!> ZLA_SYRFSX_EXTENDED améliore la solution calculée d'un système d'équations
!> linéaires en effectuant un raffinement itératif de précision étendue
!> et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.
!> Cette sous-routine est appelée par ZSYRFSX pour effectuer le raffinement itératif.
!> En plus de la borne d'erreur normwise, le code fournit une borne d'erreur
!> composante par composante maximale si possible. Voir les commentaires pour
!> ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des bornes d'erreur. Il est à
!> noter que cette sous-routine est uniquement responsable de la définition des
!> seconds champs de ERR_BNDS_NORM et ERR_BNDS_COMP.
!>

Paramètres

PREC_TYPE 
!>          PREC_TYPE est INTEGER
!>     Spécifie la précision intermédiaire à utiliser pour le raffinement.
!>     La valeur est définie par ILAPREC(P) où P est un CARACTÈRE et P
!>          = 'S':  Simple
!>          = 'D':  Double
!>          = 'I':  Indigène
!>          = 'X' ou 'E':  Extra
!>

UPLO

!>          UPLO est CHARACTER*1
!>       = 'U':  Le triangle supérieur de A est stocké ;
!>       = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes de la
!>     matrice B.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>     La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>     obtenir le facteur U ou L tels que calculés par ZSYTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Détails des échanges et de la structure par blocs de D
!>     tels que déterminés par ZSYTRF.
!>

COLEQU

!>          COLEQU est LOGICAL
!>     Si .TRUE. alors l'équilibration des colonnes a été effectuée sur A avant l'appel
!>     de cette sous-routine. Ceci est nécessaire pour calculer la solution et les bornes
!>     d'erreur correctement.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle des colonnes pour A. Si COLEQU = .FALSE., C
!>     n'est pas accédé. Si C est en entrée, chaque élément de C doit être une puissance
!>     de la base pour garantir une solution et des estimations d'erreur fiables.
!>     La mise à l'échelle par des puissances de la base ne provoque pas d'erreurs d'arrondi, sauf si
!>     le résultat déborde ou sous-déborde. Les erreurs d'arrondi pendant la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui pourraient ne pas être
!>     fiables.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>     La matrice des membres de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

Y

!>          Y est un tableau COMPLEX*16, dimension (LDY,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par ZSYTRS.
!>     À la sortie, la matrice solution améliorée Y.
!>

LDY

!>          LDY est INTEGER
!>     La dimension principale du tableau Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT est un tableau DOUBLE PRECISION, dimension (NRHS)
!>     À la sortie, BERR_OUT(j) contient l'erreur relative arrière composante par composante
!>     pour le j-ème membre de droite selon la formule
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     où abs(Z) est la valeur absolue composante par composante de la matrice
!>     ou du vecteur Z. Ceci est calculé par ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS est INTEGER
!>     Détermine quelles bornes d'erreur doivent être retournées (voir
!>     ERR_BNDS_NORM et ERR_BNDS_COMP).
!>     Si N_NORMS >= 1, retourne les bornes d'erreur normwise.
!>     Si N_NORMS >= 2, retourne les bornes d'erreur composante par composante.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative normwise, qui est définie comme suit :
!>
!>     Erreur relative normwise dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     renvoyées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le second indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('S') * SLAMCH('N')
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante dans le i-ème vecteur solution :
!>             max_i (abs(XTRUE(i)) - abs(X(i)))
!>            -------------------------------------
!>                   max_i abs(X(i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     renvoyées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le second indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('S') * SLAMCH('N')
!>

RES

!>          RES est un tableau COMPLEX*16, dimension (N)
!>     Le résidu A*Y - B.
!>

AYB

!>          AYB est un tableau DOUBLE PRECISION, dimension (N)
!>     La valeur absolue composante par composante de A*Y.
!>

DY

!>          DY est un tableau COMPLEX*16, dimension (N)
!>     Le changement dans Y.
!>

Y_TAIL

!>          Y_TAIL est un tableau COMPLEX*16, dimension (N)
!>     Les derniers éléments de Y qui ne sont pas inclus dans le calcul de
!>     BERR_OUT.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     La réciproque du nombre de condition de A.
!>

ITHRESH

!>          ITHRESH est INTEGER
!>     Seuil pour ignorer les erreurs composante par composante.
!>

RTHRESH

!>          RTHRESH est DOUBLE PRECISION
!>     Seuil pour ignorer les erreurs composante par composante.
!>

DZ_UB

!>          DZ_UB est DOUBLE PRECISION
!>     Limite supérieure pour les erreurs composante par composante.
!>

IGNORE_CWISE

!>          IGNORE_CWISE est LOGICAL
!>     Si .TRUE., ne pas calculer les erreurs composante par composante.
!>

INFO

!>          INFO est INTEGER
!>     = 0: succès.
!>     < 0: si INFO = -i, alors le i-ème argument était illégal.
!>     > 0: si INFO = i, alors le raffinement itératif n'a pas convergé.
!>          Le vecteur résultat Y contient la dernière itération.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres conditionnels correspondant à
!>     l'erreur relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le membre de droite i (dont dépend l'erreur
!>     relative composante par composante), et le type d'information d'erreur
!>     comme décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations retournées pour chaque membre de droite. Si
!>     la précision composante par composante n'est pas demandée (PARAMS(3) = 0.0),
!>     alors ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              nombre conditionnel réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur directe estimée,
!>              presque certainement dans un facteur de 10 de l'erreur vraie
!>              tant que la prochaine entrée est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre conditionnel réciproque : Nombre conditionnel réciproque
!>              composante par composante estimé. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation de l'erreur
!>              est . Ces nombres conditionnels réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une certaine
!>              matrice Z correctement mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              membre de droite actuel et S met à l'échelle chaque ligne de
!>              A*diag(x) par une puissance de la base afin que toutes les sommes de lignes absolues
!>              de Z soient approximativement 1.
!>
!>     Cette sous-routine est uniquement responsable de la définition du deuxième champ
!>     ci-dessus.
!>     Voir Lapack Working Note 165 pour plus de détails et des
!>     précautions supplémentaires.
!>

RES

!>          RES est un tableau COMPLEX*16, de dimension (N)
!>     Espace de travail pour contenir le résidu intermédiaire.
!>

AYB

!>          AYB est un tableau DOUBLE PRECISION, de dimension (N)
!>     Espace de travail.
!>

DY

!>          DY est un tableau COMPLEX*16, de dimension (N)
!>     Espace de travail pour contenir la solution intermédiaire.
!>

Y_TAIL

!>          Y_TAIL est un tableau COMPLEX*16, de dimension (N)
!>     Espace de travail pour contenir les bits finaux de la solution intermédiaire.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     Nombre conditionnel réciproque mis à l'échelle. C'est une estimation du
!>     nombre conditionnel Skeel réciproque de la matrice A après
!>     équilibration (si effectuée). S'il est inférieur à la précision machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut toujours être petite même
!>     si ce nombre est très petit et que la matrice semble mal
!>     conditionnée.
!>

ITHRESH

!>          ITHRESH est INTEGER
!>     Le nombre maximal de calculs de résidus autorisés pour
!>     l'affinage. La valeur par défaut est 10. Pour 'agressif', définie à 100 pour
!>     permettre la convergence en utilisant des factorisations approximatives ou
!>     des factorisations autres que LU. Si la factorisation utilise une
!>     technique autre que l'élimination gaussienne, les garanties dans
!>     ERR_BNDS_NORM et ERR_BNDS_COMP peuvent ne plus être fiables.
!>

RTHRESH

!>          RTHRESH est DOUBLE PRECISION
!>     Détermine quand arrêter l'affinage si l'estimation de l'erreur cesse de
!>     diminuer. L'affinage s'arrêtera lorsque la solution suivante ne
!>     satisfait plus norm(dx_{i+1}) < RTHRESH * norm(dx_i) où norm(Z) est
!>     la norme infinie de Z. RTHRESH satisfait 0 < RTHRESH <= 1. La
!>     valeur par défaut est 0.5. Pour 'agressif', définie à 0.9 pour permettre
!>     la convergence sur des matrices extrêmement mal conditionnées. Voir LAWN 165
!>     pour plus de détails.
!>

DZ_UB

!>          DZ_UB est DOUBLE PRECISION
!>     Détermine quand commencer à considérer la convergence composante par composante.
!>     La convergence composante par composante n'est considérée qu'après que chaque composante
!>     de la solution Y est stable, ce que nous définissons comme le changement relatif
!>     de chaque composante étant inférieur à DZ_UB. La valeur par défaut
!>     est 0.25, exigeant que le premier bit soit stable. Voir LAWN 165 pour
!>     plus de détails.
!>

IGNORE_CWISE

!>          IGNORE_CWISE est LOGICAL
!>     Si .TRUE. alors ignorer la convergence composante par composante. Valeur par défaut
!>     est .FALSE..
!>

INFO

!>          INFO est INTEGER
!>       = 0 : Sortie réussie.
!>       < 0 : si INFO = -i, le i-ème argument de ZLA_HERFSX_EXTENDED avait une valeur illégale
!>             .
!>
