sous-programme zlaqr5 (logical wantt, logical wantz, integer kacc22, integer n, integer ktop, integer kbot, integer nshfts, complex*16, dimension( * ) s, complex*16, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( ldu, * ) u, integer ldu, integer nv, complex*16, dimension( ldwv, * ) wv, integer ldwv, integer nh, complex*16, dimension( ldwh, * ) wh, integer ldwh)

ZLAQR5 effectue un balayage QR à décalages multiples avec un petit bourrelet.

Objectif :

!>
!>    ZLAQR5, appelé par ZLAQR0, effectue un
!>    balayage QR à décalages multiples avec un petit bourrelet.
!>

Paramètres

WANTT 
!>          WANTT est LOGICAL
!>             WANTT = .true. si le facteur Schur triangulaire
!>             est en cours de calcul. WANTT est mis à .false. sinon.
!>

WANTZ

!>          WANTZ est LOGICAL
!>             WANTZ = .true. si le facteur Schur unitaire est en cours de
!>             calcul. WANTZ est mis à .false. sinon.
!>

KACC22

!>          KACC22 est INTEGER avec la valeur 0, 1, ou 2.
!>             Spécifie le mode de calcul des mises à jour orthogonales
!>             loignées de la diagonale.
!>        = 0 : ZLAQR5 n'accumule pas les réflexions et n'utilise pas
!>             la multiplication matrice-matrice pour mettre à jour les
!>             entrées de matrice éloignées de la diagonale.
!>        = 1 : ZLAQR5 accumule les réflexions et utilise la multiplication
!>             matrice-matrice pour mettre à jour les entrées de matrice
!>             éloignées de la diagonale.
!>        = 2 : Identique à KACC22 = 1. Cette option était utilisée pour
!>             exploiter la structure 2x2 pendant les multiplications
!>             matricielles, mais ce n'est plus supporté.
!>

N

!>          N est INTEGER
!>             N est l'ordre de la matrice de Hessenberg H sur laquelle
!>             ce sous-programme opère.
!>

KTOP

!>          KTOP est INTEGER
!>

KBOT

!>          KBOT est INTEGER
!>             Ce sont les indices de la première et de la dernière ligne et
!>             colonne d'un bloc diagonal isolé sur lequel le balayage QR
!>             doit être appliqué. Il est supposé sans vérification que
!>                       soit KTOP = 1  soit   H(KTOP,KTOP-1) = 0
!>             et
!>                       soit KBOT = N  soit   H(KBOT+1,KBOT) = 0.
!>

NSHFTS

!>          NSHFTS est INTEGER
!>             NSHFTS donne le nombre de décalages simultanés. NSHFTS
!>             doit être positif et pair.
!>

S

!>          S est un tableau COMPLEX*16, dimension (NSHFTS)
!>             S contient les décalages d'origine qui définissent le balayage
!>             QR à décalages multiples. En sortie, S peut être réordonné.
!>

H

!>          H est un tableau COMPLEX*16, dimension (LDH,N)
!>             En entrée, H contient une matrice de Hessenberg. En sortie, un
!>             balayage QR à décalages multiples avec les décalages SR(J)+i*SI(J)
!>             est appliqué au bloc diagonal isolé dans les lignes et colonnes
!>             de KTOP à KBOT.
!>

LDH

!>          LDH est INTEGER
!>             LDH est la dimension principale de H, telle que déclarée dans
!>             la procédure appelante. LDH >= MAX(1,N).
!>

ILOZ

!>          ILOZ est INTEGER
!>

IHIZ

!>          IHIZ est INTEGER
!>             Spécifient les lignes de Z auxquelles les transformations doivent
!>             être appliquées si WANTZ est .TRUE.. 1 <= ILOZ <= IHIZ <= N
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ,IHIZ)
!>             Si WANTZ = .TRUE., alors la transformation de similarité unitaire
!>             du balayage QR est accumulée dans
!>             Z(ILOZ:IHIZ,ILOZ:IHIZ) par la droite.
!>             Si WANTZ = .FALSE., alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>             LDZ est la dimension principale de Z, telle que déclarée dans
!>             la procédure appelante. LDZ >= N.
!>

V

!>          V est un tableau COMPLEX*16, dimension (LDV,NSHFTS/2)
!>

LDV

!>          LDV est INTEGER
!>             LDV est la dimension principale de V telle que déclarée dans
!>             la procédure appelante. LDV >= 3.
!>

U

!>          U est un tableau COMPLEX*16, dimension (LDU,2*NSHFTS)
!>

LDU

!>          LDU est INTEGER
!>             LDU est la dimension principale de U, telle que déclarée dans
!>             la procédure appelante. LDU >= 2*NSHFTS.
!>

NV

!>          NV est INTEGER
!>             NV est le nombre de lignes dans WV disponibles pour l'espace de travail.
!>             NV >= 1.
!>

WV

!>          WV est un tableau COMPLEX*16, dimension (LDWV,2*NSHFTS)
!>

LDWV

!>          LDWV est INTEGER
!>             LDWV est la dimension principale de WV, telle que déclarée dans
!>             la procédure appelante. LDWV >= NV.
!>

NH

!>          NH est INTEGER
!>             NH est le nombre de colonnes dans le tableau WH disponibles
!>             pour l'espace de travail. NH >= 1.
!>

WH

!>          WH est un tableau COMPLEX*16, dimension (LDWH,NH)
!>

LDWH

!>          LDWH est INTEGER
!>             Dimension principale de WH telle que déclarée dans
!>             la procédure appelante. LDWH >= 2*NSHFTS.
!>
