Documentation de la fonction/sous-programme

sous-programme zlqt04 (integer m, integer n, integer nb, double precision, dimension(6) result)

DLQT04

But :

!>
!> ZLQT04 teste ZGELQT et ZUNMLQT.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Nombre de lignes dans la matrice de test.
!>

N

!>          N est un ENTIER
!>          Nombre de colonnes dans la matrice de test.
!>

NB

!>          NB est un ENTIER
!>          Taille du bloc de la matrice de test.  NB <= Min(M,N).
!>

RESULT

!>          RESULT est un tableau DOUBLE PRÉCISION, de dimension (6)
!>          Résultats de chacun des six tests ci-dessous.
!>
!>          RESULT(1) = | A - L Q |
!>          RESULT(2) = | I - Q Q^H |
!>          RESULT(3) = | Q C - Q C |
!>          RESULT(4) = | Q^H C - Q^H C |
!>          RESULT(5) = | C Q - C Q |
!>          RESULT(6) = | C Q^H - C Q^H |
!>
