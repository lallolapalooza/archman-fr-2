sousroutine zlaqr2 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, complex*16, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, complex*16, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, complex*16, dimension( * ) sh, complex*16, dimension( ldv, * ) v, integer ldv, integer nh, complex*16, dimension( ldt, * ) t, integer ldt, integer nv, complex*16, dimension( ldwv, * ) wv, integer ldwv, complex*16, dimension( * ) work, integer lwork)

ZLAQR2 effectue la transformation de similarité unitaire d'une matrice de Hessenberg pour détecter et déflater les valeurs propres complètement convergentes d'une sous-matrice principale terminale (déflation précoce agressive).

But :

!>
!>    ZLAQR2 est identique à ZLAQR3 sauf qu'il évite
!>    la récursion en appelant ZLAHQR au lieu de ZLAQR4.
!>
!>    Déflation précoce agressive :
!>
!>    ZLAQR2 accepte en entrée une matrice de Hessenberg supérieure
!>    H et effectue une transformation de similarité unitaire
!>    conçue pour détecter et déflater les valeurs propres complètement
!>    convergentes d'une sous-matrice principale terminale. En sortie, H a été
!>    écrasé par une nouvelle matrice de Hessenberg qui est une perturbation de
!>    une transformation de similarité unitaire de H. On espère que
!>    la version finale de H aura de nombreuses entrées sous-diagonales nulles.
!>
!>

Paramètres

WANTT 
!>          WANTT est LOGICAL
!>          Si .TRUE., alors la matrice de Hessenberg H est entièrement mise à jour
!>          afin que le facteur triangulaire de Schur puisse être
!>          calculé (en coopération avec la sous-routine appelante).
!>          Si .FALSE., alors seule une partie suffisante de H est mise à jour pour préserver
!>          les valeurs propres.
!>

WANTZ

!>          WANTZ est LOGICAL
!>          Si .TRUE., alors la matrice unitaire Z est mise à jour
!>          de sorte que le facteur de Schur unitaire puisse être calculé
!>          (en coopération avec la sous-routine appelante).
!>          Si .FALSE., alors Z n'est pas référencé.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice H et (si WANTZ est .TRUE.) l'ordre
!>          de la matrice unitaire Z.
!>

KTOP

!>          KTOP est INTEGER
!>          On suppose que KTOP = 1 ou que H(KTOP,KTOP-1)=0.
!>          KBOT et KTOP ensemble déterminent un bloc isolé
!>          le long de la diagonale de la matrice de Hessenberg.
!>

KBOT

!>          KBOT est INTEGER
!>          On suppose sans vérification que soit
!>          KBOT = N ou H(KBOT+1,KBOT)=0. KBOT et KTOP ensemble
!>          déterminent un bloc isolé le long de la diagonale de la
!>          matrice de Hessenberg.
!>

NW

!>          NW est INTEGER
!>          Taille de la fenêtre de déflation.  1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H est un tableau COMPLEX*16, dimension (LDH,N)
!>          En entrée, la section N-par-N initiale de H stocke la
!>          matrice de Hessenberg subissant une déflation précoce agressive.
!>          En sortie, H a été transformé par une transformation de similarité
!>          unitaire, perturbé, et ramené à une forme de Hessenberg qui, on l'espère,
!>          a des entrées sous-diagonales nulles.
!>

LDH

!>          LDH est INTEGER
!>          Dimension principale de H, telle que déclarée dans la sous-routine appelante.
!>          N <= LDH
!>

ILOZ

!>          ILOZ est INTEGER
!>

IHIZ

!>          IHIZ est INTEGER
!>          Spécifiez les lignes de Z auxquelles les transformations doivent être
!>          appliquées si WANTZ est .TRUE.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ,N)
!>          SI WANTZ est .TRUE., alors en sortie, la transformation de similarité
!>          unitaire mentionnée ci-dessus a été accumulée dans Z(ILOZ:IHIZ,ILOZ:IHIZ)
!>          par la droite.
!>          Si WANTZ est .FALSE., alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale de Z, telle que déclarée dans la
!>          sous-routine appelante.  1 <= LDZ.
!>

NS

!>          NS est INTEGER
!>          Le nombre de valeurs propres non convergentes (c'est-à-dire approximatives)
!>          renvoyées dans SR et SI qui peuvent être utilisées comme décalages par
!>          la sous-routine appelante.
!>

ND

!>          ND est INTEGER
!>          Le nombre de valeurs propres convergentes découvertes par cette
!>          sous-routine.
!>

SH

!>          SH est un tableau COMPLEX*16, dimension (KBOT)
!>          En sortie, les valeurs propres approximatives qui peuvent
!>          être utilisées pour les décalages sont stockées dans SH(KBOT-ND-NS+1)
!>          jusqu'à SR(KBOT-ND). Les valeurs propres convergentes sont
!>          stockées dans SH(KBOT-ND+1) jusqu'à SH(KBOT).
!>

V

!>          V est un tableau COMPLEX*16, dimension (LDV,NW)
!>          Un tableau de travail NW-par-NW.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale de V, telle que déclarée dans la
!>          sous-routine appelante.  NW <= LDV
!>

NH

!>          NH est INTEGER
!>          Le nombre de colonnes de T.  NH >= NW.
!>

T

!>          T est un tableau COMPLEX*16, dimension (LDT,NW)
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale de T, telle que déclarée dans la
!>          sous-routine appelante.  NW <= LDT
!>

NV

!>          NV est INTEGER
!>          Le nombre de lignes du tableau de travail WV disponibles pour
!>          l'espace de travail.  NV >= NW.
!>

WV

!>          WV est un tableau COMPLEX*16, dimension (LDWV,NW)
!>

LDWV

!>          LDWV est INTEGER
!>          La dimension principale de W, telle que déclarée dans la
!>          sous-routine appelante.  NW <= LDV
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>          En sortie, WORK(1) est défini comme une estimation de la valeur optimale
!>          de LWORK pour les valeurs données de N, NW, KTOP et KBOT.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau de travail WORK.  LWORK = 2*NW
!>          suffit, mais une plus grande efficacité peut résulter de valeurs
!>          plus grandes de LWORK.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée; ZLAQR2
!>          estime uniquement la taille optimale de l'espace de travail pour les
!>          valeurs données de N, NW, KTOP et KBOT. L'estimation est renvoyée
!>          dans WORK(1). Aucun message d'erreur lié à LWORK n'est émis
!>          par XERBLA. Ni H ni Z ne sont accédés.
!>
