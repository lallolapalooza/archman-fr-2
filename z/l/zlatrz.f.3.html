Documentation de la fonction/sous-programme

sous-programme zlatrz (entier m, entier n, entier l, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) tau, complexe*16, dimension( * ) work)

ZLATRZ factorise une matrice trapézoïdale supérieure au moyen de transformations unitaires.

Objectif :

!>
!> ZLATRZ factorise la matrice complexe supérieure trapézoïdale M-par-(M+L)
!> [ A1 A2 ] = [ A(1:M,1:M) A(1:M,N-L+1:N) ] en ( R  0 ) * Z au moyen
!> de transformations unitaires, où Z est une matrice unitaire (M+L)-par-(M+L)
!> et R et A1 sont des matrices triangulaires supérieures M-par-M.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

L

!>          L est ENTIER
!>          Le nombre de colonnes de la matrice A contenant la
!>          partie significative des vecteurs de Householder. N-M >= L >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, la partie supérieure trapézoïdale M-par-N de
!>          la matrice A doit contenir la matrice à factoriser.
!>          À la sortie, la partie supérieure triangulaire M-par-M de A
!>          contient la matrice triangulaire supérieure R, et les éléments N-L+1 à
!>          N des M premières lignes de A, avec le tableau TAU, représentent la
!>          matrice unitaire Z comme produit de M réflecteurs élémentaires.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEX*16, de dimension (M)
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (M)
!>

Détails supplémentaires :

!>
!>  La factorisation est obtenue par la méthode de Householder. La k-ième
!>  matrice de transformation, Z( k ), qui est utilisée pour introduire des zéros dans
!>  la ( m - k + 1 )-ième ligne de A, est donnée sous la forme
!>
!>     Z( k ) = ( I     0   ),
!>              ( 0  T( k ) )
!>
!>  où
!>
!>     T( k ) = I - tau*u( k )*u( k )**H,   u( k ) = (   1    ),
!>                                                 (   0    )
!>                                                 ( z( k ) )
!>
!>  tau est un scalaire et z( k ) est un vecteur de longueur l. tau et z( k )
!>  sont choisis pour annuler les éléments de la k-ième ligne de A2.
!>
!>  Le scalaire tau est retourné dans le k-ième élément de TAU et le vecteur
!>  u( k ) dans la k-ième ligne de A2, de telle sorte que les éléments de z( k )
!>  sont dans  a( k, l + 1 ), ..., a( k, n ). Les éléments de R sont retournés dans
!>  la partie triangulaire supérieure de A1.
!>
!>  Z est donné par
!>
!>     Z =  Z( 1 ) * Z( 2 ) * ... * Z( m ).
!>
