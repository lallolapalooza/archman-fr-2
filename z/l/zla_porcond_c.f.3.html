fonction double précision zla_porcond_c (caractère uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldaf, * ) af, entier ldaf, double précision, dimension( * ) c, logique capply, entier info, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork)

ZLA_PORCOND_C calcule le nombre de condition en norme infinie de op(A)*inv(diag(c)) pour les matrices hermitiennes définies positives.

Objectif :

!>
!>    ZLA_PORCOND_C Calcule le nombre de condition en norme infinie de
!>    op(A) * inv(diag(C)) où C est un vecteur DOUBLE PRECISION
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U' : Le triangle supérieur de A est stocké ;
!>       = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N x N
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>     Le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**H*U ou A = L*L**H, tel que calculé par ZPOTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (N)
!>     Le vecteur C dans la formule op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY est LOGICAL
!>     Si .VRAI. alors accéder au vecteur C dans la formule ci-dessus.
!>

INFO

!>          INFO est INTEGER
!>       = 0 : Sortie réussie.
!>     i > 0 : Le i-ème argument est invalide.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N).
!>     Espace de travail.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N).
!>     Espace de travail.
!>
