Documentation de la fonction/sous-routine

double precision function zla_porpvgrw (character*1 uplo, integer ncols, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, double precision, dimension( * ) work)

ZLA_PORPVGRW calcule le facteur de croissance réciproque des pivots norm(A)/norm(U) pour une matrice symétrique ou hermitienne définie positive.

But :

!>
!>
!> ZLA_PORPVGRW calcule le facteur de croissance réciproque des pivots
!> norm(A)/norm(U). La norme est utilisée. Si c'est
!> beaucoup moins que 1, la stabilité de la factorisation LU de la
!> matrice (équilibrée) A pourrait être mauvaise. Cela signifie également que la
!> solution X, les estimations du nombre de conditionnement et les bornes d'erreur pourraient être
!> peu fiables.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U' : Le triangle supérieur de A est stocké ;
!>       = 'L' : Le triangle inférieur de A est stocké.
!>

NCOLS

!>          NCOLS est INTEGER
!>     Le nombre de colonnes de la matrice A. NCOLS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A. LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>     Le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T, tel que calculé par ZPOTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF. LDAF >= max(1,N).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (2*N)
!>
