Documentation de la fonction/sous-programme

double precision function zlantp (character norm, character uplo, character diag, integer n, complex*16, dimension( * ) ap, double precision, dimension( * ) work)

ZLANTP renvoie la valeur de la norme 1, ou la norme de Frobenius, ou la norme infini, ou l'élément de plus grande valeur absolue d'une matrice triangulaire fournie sous forme compacte.

Objectif :

!>
!> ZLANTP  renvoie la valeur de la norme un,  ou la norme de Frobenius, ou
!> la norme  infini,  ou l'élément de  plus grande valeur absolue  d'une
!> matrice triangulaire A, fournie sous forme compacte.
!>

Renvoie

ZLANTP 
!>
!>    ZLANTP = ( max(abs(A(i,j))), NORM = 'M' ou 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' ou 'o'
!>             (
!>             ( normI(A),         NORM = 'I' ou 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' ou 'e'
!>
!> où  norm1  désigne la  norme un d'une matrice (somme maximale des colonnes),
!> normI  désigne la  norme infini  d'une matrice  (somme maximale des lignes) et
!> normF  désigne la  norme de Frobenius  d'une matrice (racine carrée de la somme des
!> carrés).  Notez que  max(abs(A(i,j)))  n'est pas une norme matricielle cohérente.
!>

Paramètres

NORM 
!>          NORM est CHARACTER*1
!>          Spécifie la valeur à retourner dans ZLANTP comme décrit
!>          ci-dessus.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.  Lorsque N = 0, ZLANTP est
!>          mis à zéro.
!>

AP

!>          AP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, compactée par colonne dans
!>          un tableau linéaire.  La j-ème colonne de A est stockée dans le tableau
!>          AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Notez que lorsque DIAG = 'U', les éléments du tableau AP
!>          correspondant aux éléments diagonaux de la matrice A
!>          ne sont pas référencés, mais sont supposés être un.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (MAX(1,LWORK)),
!>          où LWORK >= N lorsque NORM = 'I' ; sinon, WORK n'est pas
!>          référencé.
!>
