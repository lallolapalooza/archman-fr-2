subroutine zlacrt (n, cx, incx, cy, incy, c, s)
ZLACRT effectue une transformation linéaire d'une paire de vecteurs complexes.

Documentation de la fonction/sous-programme

sous-programme zlacrt (entier n, complexe*16, dimension( * ) cx, entier incx, complexe*16, dimension( * ) cy, entier incy, complexe*16 c, complexe*16 s)

ZLACRT effectue une transformation linéaire d'une paire de vecteurs complexes.

Objectif :

!>
!> ZLACRT effectue l'opération
!>
!>    (  c  s )( x )  ==> ( x )
!>    ( -s  c )( y )      ( y )
!>
!> où c et s sont complexes et les vecteurs x et y sont complexes.
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre d'éléments dans les vecteurs CX et CY.
!>

CX

!>          CX est un tableau COMPLEX*16, de dimension (N)
!>          En entrée, le vecteur x.
!>          En sortie, CX est écrasé par c*x + s*y.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les valeurs successives de CX. INCX <> 0.
!>

CY

!>          CY est un tableau COMPLEX*16, de dimension (N)
!>          En entrée, le vecteur y.
!>          En sortie, CY est écrasé par -s*x + c*y.
!>

INCY

!>          INCY est un ENTIER
!>          L'incrément entre les valeurs successives de CY. INCY <> 0.
!>

C

!>          C est COMPLEX*16
!>

S

!>          S est COMPLEX*16
!>          C et S définissent la matrice
!>             [  C   S  ].
!>             [ -S   C  ]
!>
