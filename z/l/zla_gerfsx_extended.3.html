sous-routine zla_gerfsx_extended (integer prec_type, integer trans_type, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, logical colequ, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) errs_n, double precision, dimension( nrhs, * ) errs_c, complex*16, dimension( * ) res, double precision, dimension( * ) ayb, complex*16, dimension( * ) dy, complex*16, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

ZLA_GERFSX_EXTENDED

Objectif :

!>
!> ZLA_GERFSX_EXTENDED améliore la solution calculée d'un système
!> d'équations linéaires en effectuant un raffinement itératif de précision supplémentaire
!> et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.
!> Cette sous-routine est appelée par ZGERFSX pour effectuer le raffinement itératif.
!> En plus de la borne d'erreur sur la norme, le code fournit une borne d'erreur composante par composante
!> maximale lorsque cela est possible. Voir les commentaires pour ERRS_N
!> et ERRS_C pour les détails des bornes d'erreur. Notez que cette
!> sous-routine est uniquement responsable de la définition des seconds champs
!> de ERRS_N et ERRS_C.
!>

Paramètres

PREC_TYPE 
!>          PREC_TYPE est INTEGER
!>     Spécifie la précision intermédiaire à utiliser pour le raffinement.
!>     La valeur est définie par ILAPREC(P) où P est un CARACTÈRE et P
!>          = 'S':  Simple
!>          = 'D':  Double
!>          = 'I':  Indigène
!>          = 'X' ou 'E':  Extra
!>

TRANS_TYPE

!>          TRANS_TYPE est INTEGER
!>     Spécifie l'opération de transposition sur A.
!>     La valeur est définie par ILATRANS(T) où T est un CARACTÈRE et T
!>          = 'N':  Pas de transposition
!>          = 'T':  Transposition
!>          = 'C':  Transposition conjuguée
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes de la
!>     matrice B.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>     Les facteurs L et U de la factorisation
!>     A = P*L*U calculée par ZGETRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Les indices de pivot de la factorisation A = P*L*U
!>     calculée par ZGETRF ; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>

COLEQU

!>          COLEQU est LOGICAL
!>     Si .TRUE., l'équilibrage des colonnes a été effectué sur A avant d'appeler
!>     cette routine. Ceci est nécessaire pour calculer correctement la solution et les bornes d'erreur.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle des colonnes pour A. Si COLEQU = .FALSE., C
!>     n'est pas accédé. Si C est entré, chaque élément de C devrait être une puissance
!>     de la base pour garantir une solution et des estimations d'erreur fiables.
!>     La mise à l'échelle par des puissances de la base ne provoque pas d'erreurs d'arrondi, sauf
!>     si le résultat sous-flue ou surflue. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>     La matrice des membres de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

Y

!>          Y est un tableau COMPLEX*16, dimension (LDY,NRHS)
!>     À l'entrée, la matrice solution X, calculée par ZGETRS.
!>     À la sortie, la matrice solution améliorée Y.
!>

LDY

!>          LDY est INTEGER
!>     La dimension principale du tableau Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT est un tableau DOUBLE PRECISION, dimension (NRHS)
!>     À la sortie, BERR_OUT(j) contient l'erreur arrière relative composante par composante
!>     selon la formule
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     où abs(Z) est la valeur absolue composante par composante de la matrice
!>     ou du vecteur Z. Ceci est calculé par ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS est INTEGER
!>     Détermine quelles bornes d'erreur retourner (voir ERRS_N
!>     et ERRS_C).
!>     Si N_NORMS >= 1, retourne les bornes d'erreur sur la norme.
!>     Si N_NORMS >= 2, retourne les bornes d'erreur composante par composante.
!>

ERRS_N

!>          ERRS_N est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative sur la norme, qui est définie comme suit :
!>
!>     Erreur relative sur la norme dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     renvoyées.
!>
!>     Le premier indice dans ERRS_N(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le second indice dans ERRS_N(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur
!>              vraie tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              utilisée que si le booléen précédent est vrai.
!>
!>
err = 3 Numéro de condition réciproque : Norme estimée des !> la norme du numéro de condition réciproque. Comparé au seuil !> sqrt(n) * slamch('Epsilon') pour déterminer si l'erreur !> l'estimation est . Ces numéros de condition réciproques !> sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une certaine !> matrice Z appropriée. !> Soit Z = S*A, où S met à l'échelle chaque ligne par une puissance de la !> base de sorte que toutes les sommes absolues des lignes de Z soient approximativement 1. !> !> Cette sous-routine est uniquement responsable de la définition du deuxième champ !> ci-dessus. !> Voir Lapack Working Note 165 pour plus de détails et des !> précautions supplémentaires. !>

ERRS_C

!>          ERRS_C est un tableau DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     divers bornes d'erreur et numéros de condition correspondant à
!>     l'erreur relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (sur lequel l'erreur
!>     relative composante par composante dépend), et le type d'information
!>     d'erreur comme décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations retournées pour chaque second membre. Si
!>     la précision composante par composante n'est pas demandée (PARAMS(3) = 0.0),
!>     alors ERRS_C n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERRS_C(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERRS_C(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              numéro de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Numéro de condition réciproque : Numéro de condition
!>              réciproque composante par composante estimé. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces numéros de condition
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              certaine matrice Z appropriée.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre courant et S met à l'échelle chaque ligne de
!>              A*diag(x) par une puissance de la base de sorte que toutes les sommes
!>              absolues des lignes de Z soient approximativement 1.
!>
!>     Cette sous-routine est uniquement responsable de la définition du deuxième champ
!>     ci-dessus.
!>     Voir Lapack Working Note 165 pour plus de détails et des
!>     précautions supplémentaires.
!>

RES

!>          RES est un tableau COMPLEX*16, de dimension (N)
!>     Espace de travail pour contenir le résidu intermédiaire.
!>

AYB

!>          AYB est un tableau DOUBLE PRECISION, de dimension (N)
!>     Espace de travail.
!>

DY

!>          DY est un tableau COMPLEX*16, de dimension (N)
!>     Espace de travail pour contenir la solution intermédiaire.
!>

Y_TAIL

!>          Y_TAIL est un tableau COMPLEX*16, de dimension (N)
!>     Espace de travail pour contenir les bits finaux de la solution intermédiaire.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     Numéro de condition réciproque mis à l'échelle. Ceci est une estimation du
!>     numéro de condition de Skeel réciproque de la matrice A après
!>     équilibration (si effectuée). S'il est inférieur à la précision de la machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut toujours être petite même
!>     si ce nombre est très petit et que la matrice semble mal conditionnée.
!>

ITHRESH

!>          ITHRESH est INTEGER
!>     Le nombre maximum de calculs de résidus autorisés pour
!>     le raffinement. La valeur par défaut est 10. Pour 'agressif', réglez sur 100 pour
!>     permettre la convergence en utilisant des factorisations approchées ou
!>     des factorisations autres que LU. Si la factorisation utilise une
!>     technique autre que l'élimination gaussienne, les garanties dans
!>     ERRS_N et ERRS_C peuvent ne plus être fiables.
!>

RTHRESH

!>          RTHRESH est DOUBLE PRECISION
!>     Détermine quand arrêter le raffinement si l'estimation de l'erreur cesse de
!>     diminuer. Le raffinement s'arrêtera lorsque la solution suivante ne satisfera plus
!>     norm(dx_{i+1}) < RTHRESH * norm(dx_i) où norm(Z) est
!>     la norme infinie de Z. RTHRESH satisfait 0 < RTHRESH <= 1. La
!>     valeur par défaut est 0.5. Pour 'agressif', réglez sur 0.9 pour permettre la
!>     convergence sur des matrices extrêmement mal conditionnées. Voir LAWN 165
!>     pour plus de détails.
!>

DZ_UB

!>          DZ_UB est DOUBLE PRECISION
!>     Détermine quand commencer à considérer la convergence composante par composante.
!>     La convergence composante par composante n'est considérée qu'après que chaque composante
!>     de la solution Y soit stable, ce que nous définissons comme le changement relatif
!>     dans chaque composante étant inférieur à DZ_UB. La valeur par défaut
!>     est 0.25, nécessitant que le premier bit soit stable. Voir LAWN 165
!>     pour plus de détails.
!>

IGNORE_CWISE

!>          IGNORE_CWISE est LOGICAL
!>     Si .TRUE. alors ignorer la convergence composante par composante. Valeur par défaut
!>     est .FALSE..
!>

INFO

!>          INFO est INTEGER
!>       = 0 : Sortie réussie.
!>       < 0 : Si INFO = -i, le i-ème argument de ZGETRS avait une valeur illégale.
!>
