sous-routine zlaein (logique rightv, logique noinit, entier n, complexe*16, dimension( ldh, * ) h, entier ldh, complexe*16 w, complexe*16, dimension( * ) v, complexe*16, dimension( ldb, * ) b, entier ldb, double précision, dimension( * ) rwork, double précision eps3, double précision smlnum, entier info)

ZLAEIN calcule un vecteur propre droit ou gauche spécifié d'une matrice de Hessenberg supérieure par itération inverse.

Objectif :

!>
!> ZLAEIN utilise l'itération inverse pour trouver un vecteur propre droit ou
!> gauche correspondant à la valeur propre W d'une matrice de Hessenberg
!> supérieure H.
!>

Paramètres

RIGHTV 
!>          RIGHTV est LOGIQUE
!>          = .VRAI. : calculer le vecteur propre droit ;
!>          = .FAUX. : calculer le vecteur propre gauche.
!>

NOINIT

!>          NOINIT est LOGIQUE
!>          = .VRAI. : aucun vecteur initial fourni dans V
!>          = .FAUX. : vecteur initial fourni dans V.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice H.  N >= 0.
!>

H

!>          H est un tableau COMPLEX*16, dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H.
!>

LDH

!>          LDH est ENTIER
!>          La dimension principale du tableau H.  LDH >= max(1,N).
!>

W

!>          W est COMPLEX*16
!>          La valeur propre de H dont le vecteur propre droit ou gauche
!>          correspondant doit être calculé.
!>

V

!>          V est un tableau COMPLEX*16, dimension (N)
!>          À l'entrée, si NOINIT = .FAUX., V doit contenir un vecteur de
!>          démarrage pour l'itération inverse ; sinon, V n'a pas besoin d'être
!>          initialisé.
!>          À la sortie, V contient le vecteur propre calculé, normalisé de
!>          telle sorte que la composante de magnitude maximale ait une
!>          magnitude de 1 ; ici, la magnitude d'un nombre complexe (x,y) est
!>          considérée comme |x| + |y|.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,N)
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (N)
!>

EPS3

!>          EPS3 est DOUBLE PRÉCISION
!>          Une petite valeur dépendante de la machine qui est utilisée pour
!>          perturber les valeurs propres proches, et pour remplacer les pivots
!>          nuls.
!>

SMLNUM

!>          SMLNUM est DOUBLE PRÉCISION
!>          Une valeur dépendante de la machine proche du seuil de
!>          sous-dépassement.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          = 1 : l'itération inverse n'a pas convergé ; V est défini sur le
!>                dernier itéré.
!>
