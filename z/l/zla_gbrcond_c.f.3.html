double precision function zla_gbrcond_c (character trans, integer n, integer kl, integer ku, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, double precision, dimension( * ) c, logical capply, integer info, complex*16, dimension( * ) work, double precision, dimension( * ) rwork)

ZLA_GBRCOND_C calcule le nombre de conditionnement en norme infinie de op(A)*inv(diag(c)) pour les matrices bande générales.

Objectif :

!>
!>    ZLA_GBRCOND_C Calcule le nombre de conditionnement en norme infinie de
!>    op(A) * inv(diag(C)) où C est un vecteur DOUBLE PRECISION.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N' :  A * X = B     (Pas de transposée)
!>       = 'T' :  A**T * X = B  (Transposée)
!>       = 'C' :  A**H * X = B  (Conjuguée Transposée = Transposée)
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, dimension (LDAB,N)
!>     En entrée, la matrice A en stockage bande, dans les lignes 1 à KL+KU+1.
!>     La j-ième colonne de A est stockée dans la j-ième colonne du
!>     tableau AB comme suit :
!>     AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU)<=i<=min(N,j+kl)
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est un tableau COMPLEX*16, dimension (LDAFB,N)
!>     Détails de la factorisation LU de la matrice bande A, comme
!>     calculée par ZGBTRF.  U est stockée comme une matrice bande
!>     triangulaire supérieure avec KL+KU super-diagonales dans les
!>     lignes 1 à KL+KU+1, et les multiplicateurs utilisés lors de la
!>     factorisation sont stockés dans les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale du tableau AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Les indices de pivot de la factorisation A = P*L*U
!>     comme calculée par ZGBTRF ; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (N)
!>     Le vecteur C dans la formule op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY est LOGICAL
!>     Si .TRUE. alors accède au vecteur C dans la formule ci-dessus.
!>

INFO

!>          INFO est INTEGER
!>       = 0 : Sortie réussie.
!>     i > 0 : Le i-ème argument est invalide.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N).
!>     Espace de travail.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N).
!>     Espace de travail.
!>
