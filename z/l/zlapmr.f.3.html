sous-programme zlapmr (logical forwrd, integer m, integer n, complex*16, dimension( ldx, * ) x, integer ldx, integer, dimension( * ) k)

ZLAPMR réorganise les lignes d'une matrice selon un vecteur de permutation.

Objectif :

!>
!> ZLAPMR réorganise les lignes de la matrice M par N, X, comme spécifié
!> par la permutation K(1),K(2),...,K(M) des entiers 1,...,M.
!> Si FORWRD = .VRAI., permutation avant :
!>
!>      X(K(I),*) est déplacé vers X(I,*) pour I = 1,2,...,M.
!>
!> Si FORWRD = .FAUX., permutation arrière :
!>
!>      X(I,*) est déplacé vers X(K(I),*) pour I = 1,2,...,M.
!>

Paramètres

FORWWRD 
!>          FORWRD est LOGIQUE
!>          = .VRAI., permutation avant
!>          = .FAUX., permutation arrière
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice X. M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice X. N >= 0.
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,N)
!>          À l'entrée, la matrice M par N X.
!>          À la sortie, X contient la matrice X permutée.
!>

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X, LDX >= MAX(1,M).
!>

K

!>          K est un tableau ENTIER, dimension (M)
!>          À l'entrée, K contient le vecteur de permutation. K est utilisé
!>          comme espace de travail interne, mais est réinitialisé à sa
!>          valeur d'origine à la sortie.
!>
