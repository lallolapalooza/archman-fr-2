subroutine zlar1v (integer n, integer b1, integer bn, double precision lambda, double precision, dimension( * ) d, double precision, dimension( * ) l, double precision, dimension( * ) ld, double precision, dimension( * ) lld, double precision pivmin, double precision gaptol, complex*16, dimension( * ) z, logical wantnc, integer negcnt, double precision ztz, double precision mingma, integer r, integer, dimension( * ) isuppz, double precision nrminv, double precision resid, double precision rqcorr, double precision, dimension( * ) work)

ZLAR1V calcule la colonne r (mise à l'échelle) de l'inverse de la sous-matrice dans les lignes b1 à bn de la matrice tridiagonale LDLT - λI.

Objectif :

!>
!> ZLAR1V calcule la colonne r (mise à l'échelle) de l'inverse de
!> la sous-matrice dans les lignes B1 à BN de la matrice tridiagonale
!> L D L**T - sigma I. Lorsque sigma est proche d'une valeur propre,
!> le vecteur calculé est un vecteur propre précis. Habituellement, r correspond
!> à l'indice où le vecteur propre a la plus grande magnitude.
!> Les étapes suivantes accomplissent ce calcul :
!> (a) Transformation qd stationnaire, L D L**T - sigma I = L(+) D(+) L(+)**T,
!> (b) Transformation qd progressive, L D L**T - sigma I = U(-) D(-) U(-)**T,
!> (c) Calcul des éléments diagonaux de l'inverse de
!>     L D L**T - sigma I en combinant les transformations ci-dessus, et en choisissant
!>     r comme l'indice où la diagonale de l'inverse est (un des)
!>     éléments de plus grande magnitude.
!> (d) Calcul de la colonne r (mise à l'échelle) de l'inverse en utilisant la
!>     factorisation torsadée obtenue en combinant la partie supérieure de
!>     la transformation stationnaire et la partie inférieure de la transformation progressive.
!>

Paramètres

N 
!>          N est INTEGER
!>           L'ordre de la matrice L D L**T.
!>

B1

!>          B1 est INTEGER
!>           Premier indice de la sous-matrice de L D L**T.
!>

BN

!>          BN est INTEGER
!>           Dernier indice de la sous-matrice de L D L**T.
!>

LAMBDA

!>          LAMBDA est DOUBLE PRECISION
!>           Le décalage. Afin de calculer un vecteur propre précis,
!>           LAMBDA doit être une bonne approximation d'une valeur propre
!>           de L D L**T.
!>

L

!>          L est un tableau DOUBLE PRECISION, dimension (N-1)
!>           Les (n-1) éléments sous-diagonaux de la matrice unit-bidiagonale
!>           L, dans les éléments 1 à N-1.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>           Les n éléments diagonaux de la matrice diagonale D.
!>

LD

!>          LD est un tableau DOUBLE PRECISION, dimension (N-1)
!>           Les n-1 éléments L(i)*D(i).
!>

LLD

!>          LLD est un tableau DOUBLE PRECISION, dimension (N-1)
!>           Les n-1 éléments L(i)*L(i)*D(i).
!>

PIVMIN

!>          PIVMIN est DOUBLE PRECISION
!>           Le pivot minimum dans la séquence de Sturm.
!>

GAPTOL

!>          GAPTOL est DOUBLE PRECISION
!>           Tolérance indiquant quand les entrées du vecteur propre sont négligeables
!>           par rapport à leur contribution au résidu.
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (N)
!>           À l'entrée, toutes les entrées de Z doivent être mises à 0.
!>           À la sortie, Z contient la colonne r (mise à l'échelle) de l'inverse.
!>           La mise à l'échelle est telle que Z(R) égale 1.
!>

WANTNC

!>          WANTNC est LOGICAL
!>           Spécifie si NEGCNT doit être calculé.
!>

NEGCNT

!>          NEGCNT est INTEGER
!>           Si WANTNC est .TRUE. alors NEGCNT = le nombre de pivots < pivmin
!>           dans la factorisation de la matrice L D L**T, et NEGCNT = -1 sinon.
!>

ZTZ

!>          ZTZ est DOUBLE PRECISION
!>           Le carré de la norme 2 de Z.
!>

MINGMA

!>          MINGMA est DOUBLE PRECISION
!>           L'inverse du plus grand élément diagonal (en magnitude)
!>           de l'inverse de L D L**T - sigma I.
!>

R

!>          R est INTEGER
!>           L'indice de torsion pour la factorisation torsadée utilisée pour
!>           calculer Z.
!>           À l'entrée, 0 <= R <= N. Si R est entré comme 0, R est mis à
!>           l'indice où (L D L**T - sigma I)^{-1} est le plus grand en magnitude.
!>           Si 1 <= R <= N, R n'est pas modifié.
!>           À la sortie, R contient l'indice de torsion utilisé pour calculer Z.
!>           Idéalement, R désigne la position de l'élément maximum du vecteur propre.
!>

ISUPPZ

!>          ISUPPZ est un tableau INTEGER, dimension (2)
!>           Le support du vecteur Z, c'est-à-dire que le vecteur Z est
!>           non nul uniquement dans les éléments ISUPPZ(1) à ISUPPZ( 2 ).
!>

NRMINV

!>          NRMINV est DOUBLE PRECISION
!>           NRMINV = 1/SQRT( ZTZ )
!>

RESID

!>          RESID est DOUBLE PRECISION
!>           Le résidu du vecteur FP.
!>           RESID = ABS( MINGMA )/SQRT( ZTZ )
!>

RQCORR

!>          RQCORR est DOUBLE PRECISION
!>           La correction du quotient de Rayleigh à LAMBDA.
!>           RQCORR = MINGMA*TMP
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (4*N)
!>

zlar1v

zlar1v est un sous-programme de calcul de valeurs propres pour les matrices de bandes complexes.

NOM

zlar1v — sous-programme de calcul de valeurs propres pour les matrices de bandes complexes

SYNTAXE

CALL zlar1v(N, VL, VU, IL, IU, AMAT, DESC, NB, WORK, INFO)

Documentation de la fonction/sous-routine

Ce sous-programme est une partie de la bibliothèque LAPACK (Linear Algebra PACKage). Il calcule les valeurs propres d'une matrice de bandes complexe. Les arguments sont :

  • N : Ordre de la matrice.
  • VL : Borne inférieure des valeurs propres recherchées.
  • VU : Borne supérieure des valeurs propres recherchées.
  • IL : Indice de la plus petite valeur propre recherchée.
  • IU : Indice de la plus grande valeur propre recherchée.
  • AMAT : Matrice d'entrée.
  • DESC : Descripteur de la matrice.
  • NB : Taille des blocs pour les algorithmes de blocage.
  • WORK : Tableau de travail.
  • INFO : Indicateur d'état.

Pour une documentation plus détaillée, veuillez consulter la documentation officielle de LAPACK.
