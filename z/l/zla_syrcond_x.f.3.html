double précision fonction zla_syrcond_x (caractère uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldaf, * ) af, entier ldaf, entier, dimension( * ) ipiv, complexe*16, dimension( * ) x, entier info, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork)

ZLA_SYRCOND_X calcule le nombre de conditionnement en norme infinie de op(A)*diag(x) pour les matrices indéfinies symétriques.

Objectif :

!>
!>    ZLA_SYRCOND_X Calcule le nombre de conditionnement en norme infinie de
!>    op(A) * diag(X) où X est un vecteur COMPLEX*16.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U' : Le triangle supérieur de A est stocké ;
!>       = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>     En entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>     La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>     obtenir le facteur U ou L tels que calculés par ZSYTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Détails des échanges et de la structure de blocs de D
!>     tels que déterminés par ZSYTRF.
!>

X

!>          X est un tableau COMPLEX*16, dimension (N)
!>     Le vecteur X dans la formule op(A) * diag(X).
!>

INFO

!>          INFO est INTEGER
!>       = 0 : Sortie réussie.
!>     i > 0 : Le i-ème argument est invalide.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N).
!>     Espace de travail.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N).
!>     Espace de travail.
!>
