Documentation de la fonction/sous-programme

sous-programme zlatrs3 (character uplo, character trans, character diag, character normin, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldx, * ) x, integer ldx, double precision, dimension( * ) scale, double precision, dimension( * ) cnorm, double precision, dimension( * ) work, integer lwork, integer info)

ZLATRS3 résout un système d'équations triangulaire avec les facteurs d'échelle définis pour éviter le dépassement de capacité.

Objectif:

!>
!> ZLATRS3 résout l'un des systèmes triangulaires
!>
!>    A * X = B * diag(scale),  A**T * X = B * diag(scale), ou
!>    A**H * X = B * diag(scale)
!>
!> avec mise à l'échelle pour éviter le dépassement de capacité. Ici A est une matrice
!> triangulaire supérieure ou inférieure, A**T désigne la transposée de A, A**H
!> désigne la transposée conjuguée de A. X et B sont des matrices n-par-nrhs
!> et scale est un vecteur de nrhs facteurs d'échelle. Un facteur d'échelle scale(j)
!> est généralement inférieur ou égal à 1, choisi de telle sorte que X(:,j) soit
!> inférieur au seuil de dépassement de capacité. Si la matrice A est singulière (A(j,j) = 0
!> pour un certain j), alors une solution non triviale à A*X = 0 est retournée. Si
!> le système est si mal mis à l'échelle que la solution ne peut pas être représentée
!> comme (1/scale(k))*X(:,k), alors x(:,k) = 0 et scale(k) est retourné.
!>
!> Il s'agit d'une version BLAS-3 de LATRS pour résoudre plusieurs seconds membres
!> simultanément.
!>
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  Résoudre A * x = s*b  (Pas de transposée)
!>          = 'T':  Résoudre A**T* x = s*b  (Transposée)
!>          = 'C':  Résoudre A**T* x = s*b  (Transposée conjuguée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

NORMIN

!>          NORMIN est CHARACTER*1
!>          Spécifie si CNORM a été défini ou non.
!>          = 'Y':  CNORM contient les normes des colonnes à l'entrée
!>          = 'N':  CNORM n'est pas défini à l'entrée. En sortie, les normes
!>                  seront calculées et stockées dans CNORM.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de colonnes de X.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie supérieure
!>          triangulaire principale n par n du tableau A contient la matrice
!>          triangulaire supérieure, et la partie strictement triangulaire
!>          inférieure de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          inférieure triangulaire principale n par n du tableau A contient la
!>          matrice triangulaire inférieure, et la partie strictement triangulaire
!>          supérieure de A n'est pas référencée.  Si DIAG = 'U', les éléments
!>          diagonaux de A ne sont pas non plus référencés et sont supposés être 1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max (1,N).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          À l'entrée, le second membre B du système triangulaire.
!>          En sortie, X est écrasé par la matrice solution X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max (1,N).
!>

SCALE

!>          SCALE est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          Le facteur d'échelle s(k) est pour le système triangulaire
!>          A * x(:,k) = s(k)*b(:,k)  ou  A**T* x(:,k) = s(k)*b(:,k).
!>          Si SCALE = 0, la matrice A est singulière ou mal mise à l'échelle.
!>          Si A(j,j) = 0 est rencontré, un vecteur non trivial x(:,k)
!>          qui est une solution exacte ou approximative à A*x(:,k) = 0
!>          est retourné. Si le système est si mal mis à l'échelle que la solution
!>          ne peut pas être présentée comme x(:,k) * 1/s(k), alors x(:,k) = 0
!>          est retourné.
!>

CNORM

!>          CNORM est un tableau DOUBLE PRECISION, dimension (N)
!>
!>          Si NORMIN = 'Y', CNORM est un argument d'entrée et CNORM(j)
!>          contient la norme de la partie non diagonale de la j-ème colonne
!>          de A.  Si TRANS = 'N', CNORM(j) doit être supérieur ou égal
!>          à la norme infinie, et si TRANS = 'T' ou 'C', CNORM(j)
!>          doit être supérieur ou égal à la norme 1.
!>
!>          Si NORMIN = 'N', CNORM est un argument de sortie et CNORM(j)
!>          retourne la norme 1 de la partie non diagonale de la j-ème colonne
!>          de A.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (LWORK).
!>          En sortie, si INFO = 0, WORK(1) retourne la taille optimale de
!>          WORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>
!>          Si MIN(N,NRHS) = 0, LWORK >= 1, sinon
!>          LWORK >= MAX(1, 2*NBA * MAX(NBA, MIN(NRHS, 32)), où
!>          NBA = (N + NB - 1)/NB et NB est la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les dimensions optimales du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  succès de l'exécution
!>          < 0:  si INFO = -k, le k-ème argument avait une valeur illégale
!>
