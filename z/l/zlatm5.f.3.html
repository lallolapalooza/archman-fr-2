sous-programme zlatm5 (entier prtype, entier m, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldc, * ) c, entier ldc, complexe*16, dimension( ldd, * ) d, entier ldd, complexe*16, dimension( lde, * ) e, entier lde, complexe*16, dimension( ldf, * ) f, entier ldf, complexe*16, dimension( ldr, * ) r, entier ldr, complexe*16, dimension( ldl, * ) l, entier ldl, double précision alpha, entier qblcka, entier qblckb)

ZLATM5

Objectif :

!>
!> ZLATM5 génère les matrices impliquées dans l'équation de Sylvester Généralisée:
!>
!>     A * R - L * B = C
!>     D * R - L * E = F
!>
!> Elles satisfont également (la condition de diagonalisation)
!>
!>  [ I -L ] ( [ A  -C ], [ D -F ] ) [ I  R ] = ( [ A    ], [ D    ] )
!>  [    I ] ( [     B ]  [    E ] ) [    I ]   ( [    B ]  [    E ] )
!>
!>

Paramètres

PRTYPE 
!>          PRTYPE est ENTIER
!>           vers un certain type de matrices à générer
!>          (voir plus de détails).
!>

M

!>          M est ENTIER
!>          Spécifie l'ordre de A et D et le nombre de lignes dans
!>          C, F,  R et L.
!>

N

!>          N est ENTIER
!>          Spécifie l'ordre de B et E et le nombre de colonnes dans
!>          C, F, R et L.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, M).
!>          À la sortie, A de taille M par M est initialisé selon PRTYPE.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale de A.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB, N).
!>          À la sortie, B de taille N par N est initialisé selon PRTYPE.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale de B.
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC, N).
!>          À la sortie, C de taille M par N est initialisé selon PRTYPE.
!>

LDC

!>          LDC est ENTIER
!>          La dimension principale de C.
!>

D

!>          D est un tableau COMPLEX*16, dimension (LDD, M).
!>          À la sortie, D de taille M par M est initialisé selon PRTYPE.
!>

LDD

!>          LDD est ENTIER
!>          La dimension principale de D.
!>

E

!>          E est un tableau COMPLEX*16, dimension (LDE, N).
!>          À la sortie, E de taille N par N est initialisé selon PRTYPE.
!>

LDE

!>          LDE est ENTIER
!>          La dimension principale de E.
!>

F

!>          F est un tableau COMPLEX*16, dimension (LDF, N).
!>          À la sortie, F de taille M par N est initialisé selon PRTYPE.
!>

LDF

!>          LDF est ENTIER
!>          La dimension principale de F.
!>

R

!>          R est un tableau COMPLEX*16, dimension (LDR, N).
!>          À la sortie, R de taille M par N est initialisé selon PRTYPE.
!>

LDR

!>          LDR est ENTIER
!>          La dimension principale de R.
!>

L

!>          L est un tableau COMPLEX*16, dimension (LDL, N).
!>          À la sortie, L de taille M par N est initialisé selon PRTYPE.
!>

LDL

!>          LDL est ENTIER
!>          La dimension principale de L.
!>

ALPHA

!>          ALPHA est DOUBLE PRÉCISION
!>          Paramètre utilisé pour générer les matrices PRTYPE = 1 et 5.
!>

QBLCKA

!>          QBLCKA est ENTIER
!>          Lorsque PRTYPE = 3, spécifie la distance entre les blocs de 2x2
!>          sur la diagonale de A. Sinon, QBLCKA n'est pas référencé. QBLCKA > 1.
!>

QBLCKB

!>          QBLCKB est ENTIER
!>          Lorsque PRTYPE = 3, spécifie la distance entre les blocs de 2x2
!>          sur la diagonale de B. Sinon, QBLCKB n'est pas référencé. QBLCKB > 1.
!>

Détails supplémentaires :

!>
!>  PRTYPE = 1 : A et B sont des blocs de Jordan, D et E sont des matrices identité
!>
!>             A : si (i == j) alors A(i, j) = 1.0
!>                 si (j == i + 1) alors A(i, j) = -1.0
!>                 sinon A(i, j) = 0.0,            i, j = 1...M
!>
!>             B : si (i == j) alors B(i, j) = 1.0 - ALPHA
!>                 si (j == i + 1) alors B(i, j) = 1.0
!>                 sinon B(i, j) = 0.0,            i, j = 1...N
!>
!>             D : si (i == j) alors D(i, j) = 1.0
!>                 sinon D(i, j) = 0.0,            i, j = 1...M
!>
!>             E : si (i == j) alors E(i, j) = 1.0
!>                 sinon E(i, j) = 0.0,            i, j = 1...N
!>
!>             L =  R sont choisis dans [-10...10],
!>                  ce qui spécifie les membres de droite (C, F).
!>
!>  PRTYPE = 2 ou 3 : Triangulaire et/ou quasi-triangulaire.
!>
!>             A : si (i <= j) alors A(i, j) = [-1...1]
!>                 sinon A(i, j) = 0.0,             i, j = 1...M
!>
!>                 si (PRTYPE = 3) alors
!>                    A(k + 1, k + 1) = A(k, k)
!>                    A(k + 1, k) = [-1...1]
!>                    sign(A(k, k + 1) = -(sin(A(k + 1, k))
!>                        k = 1, M - 1, QBLCKA
!>
!>             B : si (i <= j) alors B(i, j) = [-1...1]
!>                 sinon B(i, j) = 0.0,            i, j = 1...N
!>
!>                 si (PRTYPE = 3) alors
!>                    B(k + 1, k + 1) = B(k, k)
!>                    B(k + 1, k) = [-1...1]
!>                    sign(B(k, k + 1) = -(sign(B(k + 1, k))
!>                        k = 1, N - 1, QBLCKB
!>
!>             D : si (i <= j) alors D(i, j) = [-1...1].
!>                 sinon D(i, j) = 0.0,            i, j = 1...M
!>
!>
!>             E : si (i <= j) alors D(i, j) = [-1...1]
!>                 sinon E(i, j) = 0.0,            i, j = 1...N
!>
!>                 L, R sont choisis dans [-10...10],
!>                 ce qui spécifie les membres de droite (C, F).
!>
!>  PRTYPE = 4 Plein
!>             A(i, j) = [-10...10]
!>             D(i, j) = [-1...1]    i,j = 1...M
!>             B(i, j) = [-10...10]
!>             E(i, j) = [-1...1]    i,j = 1...N
!>             R(i, j) = [-10...10]
!>             L(i, j) = [-1...1]    i = 1..M ,j = 1...N
!>
!>             L, R spécifient les membres de droite (C, F).
!>
!>  PRTYPE = 5 cas spécial valeurs propres communes et/ou proches
!>
