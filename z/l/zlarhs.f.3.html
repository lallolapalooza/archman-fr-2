Documentation de la fonction/sous-programme

sous-programme zlarhs (character*3 path, character xtype, character uplo, character trans, integer m, integer n, integer kl, integer ku, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldb, * ) b, integer ldb, integer, dimension( 4 ) iseed, integer info)

ZLARHS

Objectif :

!>
!> ZLARHS choisit un ensemble de NRHS vecteurs solutions aléatoires et configure
!> les membres de droite pour le système linéaire
!>    op(A) * X = B,
!> où op(A) = A, A**T, ou A**H, selon TRANS.
!>

Paramètres

PATH 
!>          PATH est CHARACTER*3
!>          Le type de la matrice complexe A.  PATH peut être indiqué dans
!>          n'importe quelle combinaison de casse supérieure et inférieure.  Les chemins valides comprennent
!>             xGE : Matrice générale m x n
!>             xGB : Matrice bande générale
!>             xPO : Hermitienne définie positive, stockage 2D
!>             xPP : Hermitienne définie positive packée
!>             xPB : Hermitienne définie positive bande
!>             xHE : Hermitienne indéfinie, stockage 2D
!>             xHP : Hermitienne indéfinie packée
!>             xHB : Hermitienne indéfinie bande
!>             xSY : Symétrique indéfinie, stockage 2D
!>             xSP : Symétrique indéfinie packée
!>             xSB : Symétrique indéfinie bande
!>             xTR : Triangulaire
!>             xTP : Triangulaire packée
!>             xTB : Triangulaire bande
!>             xQR : Matrice générale m x n
!>             xLQ : Matrice générale m x n
!>             xQL : Matrice générale m x n
!>             xRQ : Matrice générale m x n
!>          où le caractère de tête indique la précision.
!>

XTYPE

!>          XTYPE est CHARACTER*1
!>          Spécifie comment la solution exacte X sera déterminée :
!>          = 'N' : Nouvelle solution ; générer une solution X aléatoire.
!>          = 'C' : Calculée ; utiliser la valeur de X à l'entrée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          Utilisé uniquement si A est symétrique ou triangulaire ; spécifie si
!>          la partie triangulaire supérieure ou inférieure de la matrice A est stockée.
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Utilisé uniquement si A est non symétrique ; spécifie l'opération
!>          appliquée à la matrice A.
!>          = 'N' : B := A    * X  (Pas de transposée)
!>          = 'T' : B := A**T * X  (Transposée)
!>          = 'C' : B := A**H * X  (Conjuguée transposée)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>          Utilisé uniquement si A est une matrice bande ; spécifie le nombre de
!>          sous-diagonales de A si A est une matrice bande générale ou si A est
!>          symétrique ou triangulaire et UPLO = 'L' ; spécifie le nombre de
!>          super-diagonales de A si A est symétrique ou triangulaire et
!>          UPLO = 'U'.  0 <= KL <= M-1.
!>

KU

!>          KU est INTEGER
!>          Utilisé uniquement si A est une matrice bande générale ou si A est
!>          triangulaire.
!>
!>          Si PATH = xGB, spécifie le nombre de super-diagonales de A,
!>          et 0 <= KU <= N-1.
!>
!>          Si PATH = xTR, xTP, ou xTB, spécifie si la matrice a
!>          une diagonale unitaire ou non :
!>          = 1 : matrice avec diagonale non unitaire (par défaut)
!>          = 2 : matrice avec diagonale unitaire
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de vecteurs de second membre dans le système A*X = B.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice de test dont le type est donné par PATH.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si PATH = xGB, LDA >= KL+KU+1.
!>          Si PATH = xPB, xSB, xHB, ou xTB, LDA >= KL+1.
!>          Sinon, LDA >= max(1,M).
!>

X

!>          X est un tableau COMPLEX*16 (entrée ou sortie) dimension (LDX,NRHS)
!>          À l'entrée, si XTYPE = 'C' (pour 'Calculée'), alors X contient
!>          la solution exacte du système d'équations linéaires.
!>          À la sortie, si XTYPE = 'N' (pour 'Nouvelle'), alors X est initialisé
!>          avec des valeurs aléatoires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  Si TRANS = 'N',
!>          LDX >= max(1,N) ; si TRANS = 'T', LDX >= max(1,M).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          Le vecteur (ou les vecteurs) de second membre pour le système d'équations,
!>          calculé à partir de B = op(A) * X, où op(A) est déterminé par
!>          TRANS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  Si TRANS = 'N',
!>          LDB >= max(1,M) ; si TRANS = 'T', LDB >= max(1,N).
!>

ISEED

!>          ISEED est un tableau INTEGER, dimension (4)
!>          La graine pour le générateur de nombres aléatoires (utilisé dans
!>          ZLATMS).  Modifié à la sortie.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
