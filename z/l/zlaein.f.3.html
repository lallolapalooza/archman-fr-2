sous-programme zlaein (logical rightv, logical noinit, integer n, complex*16, dimension( ldh, * ) h, integer ldh, complex*16 w, complex*16, dimension( * ) v, complex*16, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) rwork, double precision eps3, double precision smlnum, integer info)

ZLAEIN calcule un vecteur propre droit ou gauche spécifié d'une matrice de Hessenberg supérieure par itération inverse.

Objectif :

!>
!> ZLAEIN utilise l'itération inverse pour trouver un vecteur propre droit ou
!> gauche correspondant à la valeur propre W d'une matrice de Hessenberg
!> supérieure complexe H.
!>

Paramètres

RIGHTV 
!>          RIGHTV est LOGICAL
!>          = .TRUE. : calculer le vecteur propre droit ;
!>          = .FALSE.: calculer le vecteur propre gauche.
!>

NOINIT

!>          NOINIT est LOGICAL
!>          = .TRUE. : aucun vecteur initial fourni dans V
!>          = .FALSE.: vecteur initial fourni dans V.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice H.  N >= 0.
!>

H

!>          H est un tableau COMPLEX*16, dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H.
!>

LDH

!>          LDH est INTEGER
!>          Dimension principale du tableau H.  LDH >= max(1,N).
!>

W

!>          W est COMPLEX*16
!>          La valeur propre de H dont le vecteur propre droit ou gauche
!>          correspondant doit être calculé.
!>

V

!>          V est un tableau COMPLEX*16, dimension (N)
!>          À l'entrée, si NOINIT = .FALSE., V doit contenir un vecteur de
!>          démarrage pour l'itération inverse ; sinon, V n'a pas besoin d'être
!>          initialisé.
!>          À la sortie, V contient le vecteur propre calculé, normalisé de
!>          manière à ce que le composant de magnitude la plus grande ait une
!>          magnitude de 1 ; ici, la magnitude d'un nombre complexe (x,y) est
!>          prise comme |x| + |y|.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,N)
!>

LDB

!>          LDB est INTEGER
!>          Dimension principale du tableau B.  LDB >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

EPS3

!>          EPS3 est DOUBLE PRECISION
!>          Une petite valeur dépendant de la machine qui est utilisée pour
!>          perturber les valeurs propres proches et pour remplacer les pivots
!>          nuls.
!>

SMLNUM

!>          SMLNUM est DOUBLE PRECISION
!>          Une valeur dépendant de la machine proche du seuil de sous-dépassement.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          = 1:  l'itération inverse n'a pas convergé ; V est défini comme
!>                la dernière itération.
!>
