ZLAED7 utilisé par ZSTEDC. Calcule le système propre mis à jour d'une matrice diagonale après modification par une matrice symétrique de rang un. Utilisé lorsque la matrice d'origine est dense.

Objectif :

!>
!> ZLAED7 calcule le système propre mis à jour d'une matrice
!> diagonale après modification par une matrice symétrique de rang un.
!> Cette sous-routine est utilisée uniquement pour le problème propre qui nécessite toutes
!> les valeurs propres et éventuellement les vecteurs propres d'une matrice
!> hermitienne dense ou par bandes qui a été réduite à une forme tridiagonale.
!>
!>   T = Q(in) ( D(in) + RHO * Z*Z**H ) Q**H(in) = Q(out) * D(out) * Q**H(out)
!>
!>   où Z = Q**Hu, u est un vecteur de longueur N avec des uns dans les
!>   éléments CUTPNT et CUTPNT + 1 et des zéros ailleurs.
!>
!>    Les vecteurs propres de la matrice d'origine sont stockés dans Q, et les
!>    valeurs propres sont dans D. L'algorithme comprend trois étapes :
!>
!>       La première étape consiste à dégonfler la taille du problème
!>       lorsqu'il y a des valeurs propres multiples ou s'il y a un zéro dans
!>       le vecteur Z. Pour chaque occurrence, la dimension du
!>       problème d'équation séculaire est réduite de un. Cette étape
!>       est réalisée par la sous-routine DLAED2.
!>
!>       La deuxième étape consiste à calculer les valeurs propres
!>       mises à jour. Ceci est fait en trouvant les racines de l'équation séculaire
!>       via la sous-routine DLAED4 (appelée par SLAED3).
!>       Cette sous-routine calcule également les vecteurs propres du
!>       problème courant.
!>
!>       La dernière étape consiste à calculer directement les vecteurs propres
!>       mis à jour en utilisant les valeurs propres mises à jour. Les vecteurs propres
!>       du problème courant sont multipliés par les vecteurs propres du
!>       problème global.
!>

Paramètres

N 
!>          N est INTEGER
!>         La dimension de la matrice tridiagonale symétrique. N >= 0.
!>

CUTPNT

!>          CUTPNT est INTEGER
!>         Contient la position de la dernière valeur propre dans la sous-matrice
!>         principale. min(1,N) <= CUTPNT <= N.
!>

QSIZ

!>          QSIZ est INTEGER
!>         La dimension de la matrice unitaire utilisée pour réduire
!>         la matrice complète à une forme tridiagonale. QSIZ >= N.
!>

TLVLS

!>          TLVLS est INTEGER
!>         Le nombre total de niveaux de fusion dans l'arbre de diviser-pour-régner global.
!>

CURLVL

!>          CURLVL est INTEGER
!>         Le niveau courant dans la routine de fusion globale,
!>         0 <= curlvl <= tlvls.
!>

CURPBM

!>          CURPBM est INTEGER
!>         Le problème courant au niveau courant de la routine de fusion globale
!>         (en comptant de la gauche supérieure vers la droite inférieure).
!>

D

!>          D est tableau de DOUBLE PRECISION, dimension (N)
!>         À l'entrée, les valeurs propres de la matrice perturbée de rang 1.
!>         À la sortie, les valeurs propres de la matrice réparée.
!>

Q

!>          Q est tableau de COMPLEX*16, dimension (LDQ,N)
!>         À l'entrée, les vecteurs propres de la matrice perturbée de rang 1.
!>         À la sortie, les vecteurs propres de la matrice tridiagonale réparée.
!>

LDQ

!>          LDQ est INTEGER
!>         La dimension principale du tableau Q. LDQ >= max(1,N).
!>

RHO

!>          RHO est DOUBLE PRECISION
!>         Contient l'élément sous-diagonal utilisé pour créer la modification de rang 1.
!>

INDXQ

!>          INDXQ est tableau de INTEGER, dimension (N)
!>         Ceci contient la permutation qui réintégrera le sous-problème
!>         qui vient d'être résolu dans l'ordre trié,
!>         c'est-à-dire que D( INDXQ( I = 1, N ) ) sera dans l'ordre croissant.
!>

IWORK

!>          IWORK est tableau de INTEGER, dimension (4*N)
!>

RWORK

!>          RWORK est tableau de DOUBLE PRECISION,
!>                                 dimension (3*N+2*QSIZ*N)
!>

WORK

!>          WORK est tableau de COMPLEX*16, dimension (QSIZ*N)
!>

QSTORE

!>          QSTORE est tableau de DOUBLE PRECISION, dimension (N**2+1)
!>         Stocke les vecteurs propres des sous-matrices rencontrées pendant
!>         la division et la conquête, regroupés. QPTR pointe vers
!>         le début des sous-matrices.
!>

QPTR

!>          QPTR est tableau de INTEGER, dimension (N+2)
!>         Liste des indices pointant vers le début des sous-matrices stockées
!>         dans QSTORE. Les sous-matrices sont numérotées en commençant par
!>         le coin inférieur gauche de l'arbre de diviser-pour-régner, de gauche à
!>         droite et de bas en haut.
!>

PRMPTR

!>          PRMPTR est tableau de INTEGER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où, dans PERM, la
!>         permutation d'un niveau est stockée. PRMPTR(i+1) - PRMPTR(i)
!>         indique la taille de la permutation et aussi la taille du
!>         problème complet, non dégonflé.
!>

PERM

!>          PERM est tableau de INTEGER, dimension (N lg N)
!>         Contient les permutations (issues du dégonflement et du tri) à
!>         appliquer à chaque bloc propre.
!>

GIVPTR

!>          GIVPTR est tableau de INTEGER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où, dans GIVCOL, les
!>         rotations de Givens d'un niveau sont stockées. GIVPTR(i+1) - GIVPTR(i)
!>         indique le nombre de rotations de Givens.
!>

GIVCOL

!>          GIVCOL est tableau de INTEGER, dimension (2, N lg N)
!>         Chaque paire de nombres indique une paire de colonnes pour effectuer
!>         une rotation de Givens.
!>

GIVNUM

!>          GIVNUM est tableau de DOUBLE PRECISION, dimension (2, N lg N)
!>         Chaque nombre indique la valeur S à utiliser dans la
!>         rotation de Givens correspondante.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument était invalide.
!>          > 0 : si INFO = 1, une valeur propre n'a pas convergé.
!>
