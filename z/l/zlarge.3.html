Documentation de la fonction/sous-routine

sous-routine zlarge (entier n, complexe*16, dimension( lda, * ) a, entier lda, entier, dimension( 4 ) iseed, complexe*16, dimension( * ) work, entier info)

ZLARGE

Objectif:

!>
!> ZLARGE pré- et post-multiplie une matrice complexe générale n par n, A,
!> par une matrice unitaire aléatoire : A = U*D*U'.
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la matrice originale n par n A.
!>          À la sortie, A est écrasé par U*A*U' pour une matrice unitaire
!>          aléatoire U.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= N.
!>

ISEED

!>          ISEED est un tableau ENTIER, dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires ; les
!>          éléments du tableau doivent être compris entre 0 et 4095, et
!>          ISEED(4) doit être impair.
!>          À la sortie, la graine est mise à jour.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N)
!>

INFO

!>          INFO est ENTIER
!>          = 0: succès
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
