double precision function zlangb (norm, n, kl, ku, ab, ldab, work)
ZLANGB renvoie la valeur de la norme 1, la norme de Frobenius, la norme infini, ou la plus grande valeur absolue de tout élément d'une matrice bande générale.

Documentation de la fonction/sous-programme

double precision function zlangb (character norm, integer n, integer kl, integer ku, complex*16, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) work)

ZLANGB renvoie la valeur de la norme 1, la norme de Frobenius, la norme infinie, ou la plus grande valeur absolue de tout élément d'une matrice bande générale.

Objectif :

!>
!> ZLANGB  renvoie la valeur de la norme 1,  ou la norme de Frobenius,  ou
!> la  norme infinie,  ou l'élément de plus grande valeur absolue  d'une
!> matrice bande A de taille n x n,  avec kl sous-diagonales et ku
!> super-diagonales.
!>

Retourne

ZLANGB 
!>
!>    ZLANGB = ( max(abs(A(i,j))), NORM = 'M' ou 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' ou 'o'
!>             (
!>             ( normI(A),         NORM = 'I' ou 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' ou 'e'
!>
!> où  norm1  désigne la  norme 1 d'une matrice (somme maximale de colonne),
!> normI  désigne la  norme infinie  d'une matrice  (somme maximale de ligne)
!> et normF  désigne la  norme de Frobenius  d'une matrice (racine carrée de
!> la somme des carrés).  Notez que  max(abs(A(i,j)))  n'est pas une norme
!> matricielle cohérente.
!>

Paramètres

NORM 
!>          NORM est CHARACTER*1
!>          Spécifie la valeur à renvoyer dans ZLANGB comme décrit
!>          ci-dessus.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.  Lorsque N = 0, ZLANGB est
!>          mis à zéro.
!>

KL

!>          KL est INTEGER
!>          Nombre de sous-diagonales de la matrice A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>          Nombre de super-diagonales de la matrice A.  KU >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, de dimension (LDAB,N)
!>          La matrice bande A, stockée dans les lignes 1 à KL+KU+1. La j-ème
!>          colonne de A est stockée dans la j-ème colonne du tableau AB comme
!>          suit :
!>          AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku)<=i<=min(n,j+kl).
!>

LDAB

!>          LDAB est INTEGER
!>          Dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (MAX(1,LWORK)),
!>          où LWORK >= N lorsque NORM = 'I' ; sinon, WORK n'est pas
!>          référencé.
!>
