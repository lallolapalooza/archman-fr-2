double precision function zla_gbrcond_x (character trans, integer n, integer kl, integer ku, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, complex*16, dimension( * ) x, integer info, complex*16, dimension( * ) work, double precision, dimension( * ) rwork)

ZLA_GBRCOND_X calcule le nombre de conditionnement de la norme infinie de op(A)*diag(x) pour les matrices à bande générale.

Objectif:

!>
!>    ZLA_GBRCOND_X Calcule le nombre de conditionnement de la norme infinie de
!>    op(A) * diag(X) où X est un vecteur COMPLEX*16.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations:
!>       = 'N':  A * X = B     (Pas de transposée)
!>       = 'T':  A**T * X = B  (Transposée)
!>       = 'C':  A**H * X = B  (Conjuguée Transposée = Transposée)
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire, l'ordre de
!>     la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

AB

!>          AB est COMPLEX*16 array, dimension (LDAB,N)
!>     En entrée, la matrice A en stockage bande, dans les lignes 1 à KL+KU+1.
!>     La j-ième colonne de A est stockée dans la j-ième colonne de
!>     l'array AB comme suit:
!>     AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU)<=i<=min(N,j+kl)
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale de l'array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est COMPLEX*16 array, dimension (LDAFB,N)
!>     Détails de la factorisation LU de la matrice bande A, tels que
!>     calculés par ZGBTRF.  U est stocké comme une matrice triangulaire
!>     supérieure bande avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1,
!>     et les multiplicateurs utilisés pendant la factorisation sont stockés
!>     dans les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale de l'array AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est INTEGER array, dimension (N)
!>     Les indices de pivot de la factorisation A = P*L*U
!>     tels que calculés par ZGBTRF; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>

X

!>          X est COMPLEX*16 array, dimension (N)
!>     Le vecteur X dans la formule op(A) * diag(X).
!>

INFO

!>          INFO est INTEGER
!>       = 0:  Sortie réussie.
!>     i > 0:  Le i-ème argument est invalide.
!>

WORK

!>          WORK est COMPLEX*16 array, dimension (2*N).
!>     Espace de travail.
!>

RWORK

!>          RWORK est DOUBLE PRECISION array, dimension (N).
!>     Espace de travail.
!>
