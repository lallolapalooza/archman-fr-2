sous-routine zlascl2 (integer m, integer n, double precision, dimension( * ) d, complex*16, dimension( ldx, * ) x, integer ldx)

ZLASCL2 effectue une mise à l'échelle diagonale d'une matrice.

Objectif :

!>
!> ZLASCL2 effectue une mise à l'échelle diagonale d'une matrice :
!>   x <-- D * x
!> où la matrice diagonale DOUBLE PRECISION D est stockée sous forme de vecteur.
!>
!> Finalement, sera remplacée par BLAS_zge_diag_scale dans le nouveau
!> standard BLAS.
!>

Paramètres

M 
!>          M est INTEGER
!>     Le nombre de lignes de D et X. M >= 0.
!>

N

!>          N est INTEGER
!>     Le nombre de colonnes de X. N >= 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, longueur M
!>     Matrice diagonale D, stockée sous forme de vecteur de longueur M.
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,N)
!>     À l'entrée, la matrice X à mettre à l'échelle par D.
!>     À la sortie, la matrice mise à l'échelle.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale de la matrice X. LDX >= M.
!>
