sous-programme zla_porfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, logical colequ, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, complex*16, dimension( * ) res, double precision, dimension( * ) ayb, complex*16, dimension( * ) dy, complex*16, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

ZLA_PORFSX_EXTENDED améliore la solution calculée d'un système d'équations linéaires pour des matrices symétriques ou hermitiennes définies positives en effectuant un raffinement itératif de précision supplémentaire et fournit des bornes d'erreur ainsi que des estimations d'erreur rétrogrades pour la solution.

Objectif :

!>
!> ZLA_PORFSX_EXTENDED améliore la solution calculée d'un système d'équations
!> linéaires en effectuant un raffinement itératif de précision supplémentaire
!> et fournit des bornes d'erreur ainsi que des estimations d'erreur rétrogrades pour la solution.
!> Ce sous-programme est appelé par ZPORFSX pour effectuer le raffinement itératif.
!> En plus de la borne d'erreur normwise, le code fournit une borne d'erreur composante par composante
!> maximale si possible. Voir les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des bornes d'erreur.
!> Notez que ce sous-programme est uniquement responsable de la définition des seconds champs
!> de ERR_BNDS_NORM et ERR_BNDS_COMP.
!>

Paramètres

PREC_TYPE 
!>          PREC_TYPE est INTEGER
!>     Spécifie la précision intermédiaire à utiliser lors du raffinement.
!>     La valeur est définie par ILAPREC(P) où P est un CARACTÈRE et P
!>          = 'S':  Simple précision
!>          = 'D':  Double précision
!>          = 'I':  Indigène
!>          = 'X' ou 'E':  Extra précision
!>

UPLO

!>          UPLO est CARACTÈRE*1
!>       = 'U':  Le triangle supérieur de A est stocké ;
!>       = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes de la
!>     matrice B.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N par N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>     Le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T, tel que calculé par ZPOTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

COLEQU

!>          COLEQU est LOGICAL
!>     Si .VRAI. alors l'équilibrage des colonnes a été effectué sur A avant d'appeler
!>     ce sous-programme. Ceci est nécessaire pour calculer correctement la solution et les bornes d'erreur.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle des colonnes pour A. Si COLEQU = .FAUX., C
!>     n'est pas accédé. Si C est en entrée, chaque élément de C doit être une puissance
!>     du radix pour assurer une solution et des estimations d'erreur fiables.
!>     La mise à l'échelle par des puissances du radix n'entraîne pas d'erreurs d'arrondi, sauf si
!>     le résultat est un sous-dépassement ou un dépassement de capacité. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent au raffinement d'une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>     La matrice des membres de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

Y

!>          Y est un tableau COMPLEX*16, dimension (LDY,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par ZPOTRS.
!>     À la sortie, la matrice solution améliorée Y.
!>

LDY

!>          LDY est INTEGER
!>     La dimension principale du tableau Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT est un tableau DOUBLE PRECISION, dimension (NRHS)
!>     À la sortie, BERR_OUT(j) contient l'erreur rétrograde relative composante par composante
!>     pour le membre de droite j selon la formule
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     où abs(Z) est la valeur absolue composante par composante de la matrice
!>     ou du vecteur Z. Ceci est calculé par ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS est INTEGER
!>     Détermine quelles bornes d'erreur renvoyer (voir ERR_BNDS_NORM
!>     et ERR_BNDS_COMP).
!>     Si N_NORMS >= 1, renvoyer des bornes d'erreur normwise.
!>     Si N_NORMS >= 2, renvoyer des bornes d'erreur composantes par composantes.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et numéros de condition correspondant à
!>     l'erreur relative normwise, qui est définie comme suit :
!>
!>     Erreur relative normwise dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     renvoyées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le second indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              numéro de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur vraie
!>              tant que la prochaine entrée est supérieure au seuil
!>

NAME

zla_porfsx_extended - This subroutine is used by zporfsx(3) to compute error bounds and condition numbers for the solution of a complex system of linear equations.

SYNOPSIS

    SUBROUTINE ZLA_PORFSX_EXTENDED( UPLO, N, NRHS, A, LDA, AF, LDAF, Q, LDQ,
                                    B, LDB, X, LDX, CX, LDCX, ERR_BNDS_NORM,
                                    ERR_BNDS_COMP, RES, AYB, DY, Y_TAIL, RCOND,
                                    ITHRESH, RTHRESH, DZ_UB, IGNORE_CWISE, INFO )


        CHARACTER          UPLO
        INTEGER            N, NRHS, LDA, LDAF, LDB, LDX, LDCX, INFO
        INTEGER            LDA
        INTEGER            LDAF
        INTEGER            LDB
        INTEGER            LDX
        INTEGER            LDCX
        COMPLEX*16         A( LDA, * ), AF( LDAF, * ), Q( LDQ, * ), B( LDB, * ),
        COMPLEX*16         X( LDX, * ), CX( LDCX, * ), RES( * ), DY( * ),
        COMPLEX*16         Y_TAIL( * )
        INTEGER            LDQ
        DOUBLE PRECISION   ERR_BNDS_NORM( * ), ERR_BNDS_COMP( * ), AYB( * ),
        DOUBLE PRECISION   RCOND, RTHRESH, DZ_UB
        LOGICAL            IGNORE_CWISE
        INTEGER            ITHRESH

Function/Subroutine Documentation

UPLO

!>          UPLO is CHARACTER*1
!>     Specifies whether the matrix A is upper or lower triangular.
!>     = 'U': Upper triangular
!>     = 'L': Lower triangular

N

!>          N is INTEGER
!>     The order of the matrix A.  N >= 0.

NRHS

!>          NRHS is INTEGER
!>     The number of right hand sides, i.e., the number of systems to be solved.
!>     NRHS >= 0.

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>     On entry, the coefficient matrix A.

LDA

!>          LDA is INTEGER
!>     The leading dimension of the array A. LDA >= max(1,N).

AF

!>          AF is COMPLEX*16 array, dimension (LDAF,N)
!>     On entry, the factors of A computed by ZPOTRF.

LDAF

!>          LDAF is INTEGER
!>     The leading dimension of the array AF. LDAF >= max(1,N).

Q

!>          Q is COMPLEX*16 array, dimension (LDQ,N)
!>     On entry, the orthogonal matrix Q computed by ZGEQRF.

LDQ

!>          LDQ is INTEGER
!>     The leading dimension of the array Q. LDQ >= max(1,N).

B

!>          B is COMPLEX*16 array, dimension (LDB,NRHS)
!>     On entry, the right hand side matrix.

LDB

!>          LDB is INTEGER
!>     The leading dimension of the array B. LDB >= max(1,N).

X

!>          X is COMPLEX*16 array, dimension (LDX,NRHS)
!>     On entry, the solution matrix X.
!>     On exit, the improved solution matrix X.

LDX

!>          LDX is INTEGER
!>     The leading dimension of the array X. LDX >= max(1,N).

CX

!>          CX is COMPLEX*16 array, dimension (LDCX,NRHS)
!>     On entry, the solution matrix X.
!>     On exit, the improved solution matrix X.

LDCX

!>          LDCX is INTEGER
!>     The leading dimension of the array CX. LDCX >= max(1,N).

ERR_BNDS_NORM

!>          ERR_BNDS_NORM is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     normwise relative error, which is defined as follows:
!>
!>     Normwise relative error in the ith solution vector:
!>                    norm(XTRUE(i) - X(i)) / norm(X(i))
!>
!>     The array is indexed by the right-hand side i (on which the
!>     normwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     normwise accuracy is not requested (PARAMS(2) = 0.0), then
!>     ERR_BNDS_NORM is not accessed. If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_NORM(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated normwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*A, where S scales each row by a power of the
!>              radix so all absolute row sums of Z are approximately 1.
!>
!>     This subroutine is only responsible for setting the second field
!>     above.
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     componentwise relative error, which is defined as follows:
!>
!>     Componentwise relative error in the ith solution vector:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     The array is indexed by the right-hand side i (on which the
!>     componentwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_COMP(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated componentwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*(A*diag(x)), where x is the solution for the
!>              current right-hand side and S scales each row of
!>              A*diag(x) by a power of the radix so all absolute row
!>              sums of Z are approximately 1.
!>
!>     This subroutine is only responsible for setting the second field
!>     above.
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

RES

!>          RES is COMPLEX*16 array, dimension (N)
!>     Workspace to hold the intermediate residual.
!>

AYB

!>          AYB is DOUBLE PRECISION array, dimension (N)
!>     Workspace.
!>

DY

!>          DY is COMPLEX*16 PRECISION array, dimension (N)
!>     Workspace to hold the intermediate solution.
!>

Y_TAIL

!>          Y_TAIL is COMPLEX*16 array, dimension (N)
!>     Workspace to hold the trailing bits of the intermediate solution.
!>

RCOND

!>          RCOND is DOUBLE PRECISION
!>     Reciprocal scaled condition number.  This is an estimate of the
!>     reciprocal Skeel condition number of the matrix A after
!>     equilibration (if done).  If this is less than the machine
!>     precision (in particular, if it is zero), the matrix is singular
!>     to working precision.  Note that the error may still be small even
!>     if this number is very small and the matrix appears ill-
!>     conditioned.
!>

ITHRESH

!>          ITHRESH is INTEGER
!>     The maximum number of residual computations allowed for
!>     refinement. The default is 10. For 'aggressive' set to 100 to
!>     permit convergence using approximate factorizations or
!>     factorizations other than LU. If the factorization uses a
!>     technique other than Gaussian elimination, the guarantees in
!>     ERR_BNDS_NORM and ERR_BNDS_COMP may no longer be trustworthy.
!>

RTHRESH

!>          RTHRESH is DOUBLE PRECISION
!>     Determines when to stop refinement if the error estimate stops
!>     decreasing. Refinement will stop when the next solution no longer
!>     satisfies norm(dx_{i+1}) < RTHRESH * norm(dx_i) where norm(Z) is
!>     the infinity norm of Z. RTHRESH satisfies 0 < RTHRESH <= 1. The
!>     default value is 0.5. For 'aggressive' set to 0.9 to permit
!>     convergence on extremely ill-conditioned matrices. See LAWN 165
!>     for more details.
!>

DZ_UB

!>          DZ_UB is DOUBLE PRECISION
!>     Determines when to start considering componentwise convergence.
!>     Componentwise convergence is only considered after each component
!>     of the solution Y is stable, which we define as the relative
!>     change in each component being less than DZ_UB. The default value
!>     is 0.25, requiring the first bit to be stable. See LAWN 165 for
!>     more details.
!>

IGNORE_CWISE

!>          IGNORE_CWISE is LOGICAL
!>     If .TRUE. then ignore componentwise convergence. Default value
!>     is .FALSE..
!>

INFO

!>          INFO is INTEGER
!>       = 0:  Successful exit.
!>       < 0:  if INFO = -i, the ith argument to ZPOTRS had an illegal
!>             value
!>
