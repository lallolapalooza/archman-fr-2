Documentation de la fonction/sous-programme

sous-programme zlaqr4 (logical wantt, logical wantz, integer n, integer ilo, integer ihi, complex*16, dimension( ldh, * ) h, integer ldh, complex*16, dimension( * ) w, integer iloz, integer ihiz, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, integer info)

ZLAQR4 calcule les valeurs propres d'une matrice de Hessenberg, et optionnellement les matrices de la décomposition de Schur.

Objectif :

!>
!>    ZLAQR4 implémente un niveau de récursion pour ZLAQR0.
!>    C'est une implémentation complète de l'algorithme QR multi-multiplicateur à petites extensions. Il peut être appelé par ZLAQR0 et, pour une taille de fenêtre de déflation suffisamment grande, il peut être appelé par ZLAQR3. Ce sous-programme est identique à ZLAQR0 sauf qu'il appelle ZLAQR2 au lieu de ZLAQR3.
!>
!>    ZLAQR4 calcule les valeurs propres d'une matrice de Hessenberg H
!>    et, optionnellement, les matrices T et Z de la décomposition de Schur
!>    H = Z T Z**H, où T est une matrice triangulaire supérieure (la
!>    forme de Schur), et Z est la matrice unitaire des vecteurs de Schur.
!>
!>    Optionnellement Z peut être post-multiplié dans une matrice unitaire d'entrée
!>    Q de sorte que cette routine puisse donner la factorisation de Schur
!>    d'une matrice A qui a été réduite à la forme de Hessenberg H
!>    par la matrice unitaire Q :  A = Q*H*Q**H = (QZ)*H*(QZ)**H.
!>

Paramètres

WANTT 
!>          WANTT est LOGICAL
!>          = .VRAI. : la forme complète de Schur T est requise ;
!>          = .FAUX. : seules les valeurs propres sont requises.
!>

WANTZ

!>          WANTZ est LOGICAL
!>          = .VRAI. : la matrice des vecteurs de Schur Z est requise ;
!>          = .FAUX. : les vecteurs de Schur ne sont pas requis.
!>

N

!>          N est INTEGER
!>           L'ordre de la matrice H.  N >= 0.
!>

ILO

!>          ILO est INTEGER
!>

IHI

!>          IHI est INTEGER
!>           On suppose que H est déjà triangulaire supérieure dans les lignes
!>           et colonnes 1:ILO-1 et IHI+1:N et, si ILO > 1,
!>           H(ILO,ILO-1) est zéro. ILO et IHI sont normalement définis par un
!>           appel précédent à ZGEBAL, puis passés à ZGEHRD lorsque la
!>           matrice générée par ZGEBAL est réduite à la forme de Hessenberg.
!>           Sinon, ILO et IHI devraient être définis à 1 et N,
!>           respectivement.  Si N > 0, alors 1 <= ILO <= IHI <= N.
!>           Si N = 0, alors ILO = 1 et IHI = 0.
!>

H

!>          H est un tableau COMPLEX*16, dimension (LDH,N)
!>           À l'entrée, la matrice de Hessenberg supérieure H.
!>           À la sortie, si INFO = 0 et WANTT est .VRAI., alors H
!>           contient la matrice triangulaire supérieure T de la
!>           décomposition de Schur (la forme de Schur). Si INFO = 0 et WANT est
!>           .FAUX., alors le contenu de H n'est pas spécifié à la sortie.
!>           (La valeur de sortie de H lorsque INFO > 0 est donnée sous la
!>           description de INFO ci-dessous.)
!>
!>           Ce sous-programme peut explicitement définir H(i,j) = 0 pour i > j et
!>           j = 1, 2, ... ILO-1 ou j = IHI+1, IHI+2, ... N.
!>

LDH

!>          LDH est INTEGER
!>           La dimension de tête du tableau H. LDH >= max(1,N).
!>

W

!>          W est un tableau COMPLEX*16, dimension (N)
!>           Les valeurs propres calculées de H(ILO:IHI,ILO:IHI) sont stockées
!>           dans W(ILO:IHI). Si WANTT est .VRAI., alors les valeurs propres sont
!>           stockées dans le même ordre que sur la diagonale de la forme
!>           de Schur retournée dans H, avec W(i) = H(i,i).
!>

ILOZ

!>          ILOZ est INTEGER
!>

IHIZ

!>          IHIZ est INTEGER
!>           Spécifie les lignes de Z auxquelles les transformations doivent être
!>           appliquées si WANTZ est .VRAI..
!>           1 <= ILOZ <= ILO; IHI <= IHIZ <= N.
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ,IHI)
!>           Si WANTZ est .FAUX., alors Z n'est pas référencé.
!>           Si WANTZ est .VRAI., alors Z(ILO:IHI,ILOZ:IHIZ) est
!>           remplacé par Z(ILO:IHI,ILOZ:IHIZ)*U où U est le
!>           facteur de Schur orthogonal de H(ILO:IHI,ILO:IHI).
!>           (La valeur de sortie de Z lorsque INFO > 0 est donnée sous
!>           la description de INFO ci-dessous.)
!>

LDZ

!>          LDZ est INTEGER
!>           La dimension de tête du tableau Z.  Si WANTZ est .VRAI.
!>           alors LDZ >= MAX(1,IHIZ).  Sinon, LDZ >= 1.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension LWORK
!>           À la sortie, si LWORK = -1, WORK(1) retourne une estimation de
!>           la valeur optimale pour LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>           La dimension du tableau WORK.  LWORK >= max(1,N)
!>           est suffisant, mais LWORK typiquement aussi grand que 6*N peut
!>           être requis pour une performance optimale.  Une requête d'espace
!>           de travail pour déterminer la taille optimale de l'espace de travail est recommandée.
!>
!>           Si LWORK = -1, alors ZLAQR4 effectue une requête d'espace de travail.
!>           Dans ce cas, ZLAQR4 vérifie les paramètres d'entrée et
!>           estime la taille optimale de l'espace de travail pour les
!>           valeurs données de N, ILO et IHI. L'estimation est retournée
!>           dans WORK(1). Aucun message d'erreur lié à LWORK n'est
!>           émis par XERBLA. Ni H ni Z ne sont accédés.
!>

INFO

!>          INFO est INTEGER
!>             =  0 :  fin réussie
!>             > 0 :  si INFO = i, ZLAQR4 n'a pas réussi à calculer toutes les
!>                valeurs propres. Les éléments 1:ilo-1 et i+1:n de WR
!>                et WI contiennent les valeurs propres qui ont été
!>                calculées avec succès.  (Les échecs sont rares.)
!>
!>                Si INFO > 0 et WANT est .FAUX., alors à la sortie,
!>                les valeurs propres non convergées restantes sont les valeurs propres
!>                de la matrice de Hessenberg supérieure des lignes
!>                et colonnes ILO à INFO de la valeur finale, de sortie
!>                de H.
!>
!>                Si INFO > 0 et WANTT est .VRAI., alors à la sortie
!>
!>           (*)  (valeur initiale de H)*U  = U*(valeur finale de H)
!>
!>                où U est une matrice unitaire. La valeur finale
!>                de H est de Hessenberg supérieure et triangulaire dans
!>                les lignes et colonnes INFO+1 à IHI.
!>
!>                Si INFO > 0 et WANTZ est .VRAI., alors à la sortie
!>
!>                  (valeur finale de Z(ILO:IHI,ILOZ:IHIZ)
!>                   =  (valeur initiale de Z(ILO:IHI,ILOZ:IHIZ)*U
!>
!>                où U est la matrice unitaire dans (*) (indépendamment
!>                de la valeur de WANTT.)
!>
!>                Si INFO > 0 et WANTZ est .FAUX., alors Z n'est pas
!>                accédé.
!>

NAME

zlaqr4 — Routine de transformation de Schur

SYNOPSIS

    SUBROUTINE ZLAQR4( WANTT, WANTZ, N, ILO, IHI, A, LDA, B, LDB, WR, WI, Z,
                   LDZ, WORK, INFO )

C POINTERS

    complex *16 A( * ), B( * ), Z( * )
    real *8 WR( * ), WI( * )
    complex *16 WORK( * )

Function/Subroutine Documentation

This routine is part of the LAPACK routine ZLAQR0. It is used by ZLAQR0 to compute the eigenvalues and Schur decomposition of an upper Hessenberg matrix.

This routine is an interface to the Schur decomposition routine of the QR algorithm. It is a modified version of the LAPACK routine ZLAQR4.

The routine is called by ZLAQR0 to compute the eigenvalues and Schur vectors of an upper Hessenberg matrix.

For more details, see the original LAPACK documentation.

The original routine is described in:

D. Griffiths and R. J. N. Jones, "A Library for Computer-Aided Design", ACM Trans. Math. Software, 6(3):381-390, 1980.

The implementation is based on:

B. Kagstrom and P. Van Dooren, "A direct method for the computation of the Kronecker structure of a pencil of matrices", SIAM Journal on Matrix Analysis and Applications, volume 23, pages 948--973, 2002.
