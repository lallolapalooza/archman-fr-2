Documentation de la fonction/sous-programme

sous-routine zlatms (entier m, entier n, caractere dist, entier, dimension( 4 ) iseed, caractere sym, double precision, dimension( * ) d, entier mode, double precision cond, double precision dmax, entier kl, entier ku, caractere pack, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) work, entier info)

ZLATMS

Objectif :

!>
!>    ZLATMS génère des matrices aléatoires avec des valeurs singulières
!>    spécifiées (ou hermitiennes avec des valeurs propres spécifiées)
!>    pour tester les programmes LAPACK.
!>
!>    ZLATMS opère en appliquant la séquence suivante d'opérations :
!>
!>      Définir la diagonale à D, où D peut être entrée ou
!>         calculée selon MODE, COND, DMAX et SYM décrits ci-dessous.
!>
!>      Générer une matrice avec la structure de bande appropriée, par une
!>         des deux méthodes :
!>
!>      Méthode A :
!>          Générer une matrice dense M x N en multipliant D à gauche
!>              et à droite par des matrices unitaires aléatoires, puis :
!>
!>          Réduire la bande selon KL et KU, en utilisant
!>              des transformations de Householder.
!>
!>      Méthode B :
!>          Convertir la matrice de bande 0 (c'est-à-dire diagonale) en une
!>              matrice de bande 1 en utilisant des rotations de Givens, 
!>              les éléments hors bande retournent, un peu comme en QR ; puis convertir
!>              la bande 1 en une matrice de bande 2, etc. Notez
!>              que pour des bandes raisonnablement petites (par rapport à M et
!>              N), cela nécessite moins de stockage, car une matrice dense n'est pas
!>              générée. De plus, pour les matrices hermitiennes ou symétriques,
!>              seul un triangle est généré.
!>
!>      La méthode A est choisie si la bande est une grande fraction de
!>          l'ordre de la matrice, et que LDA est au moins M (pour qu'une matrice dense
!>          puisse être stockée). La méthode B est choisie si la bande
!>          est petite (< 1/2 N pour hermitienne ou symétrique, < .3 N+M pour
!>          non-symétrique), ou si LDA est inférieur à M et pas inférieur à la
!>          bande.
!>
!>      Empaqueter la matrice si désiré. Les options spécifiées par PACK sont :
!>         pas d'empaquetage
!>         remettre à zéro la moitié supérieure (si hermitienne)
!>         remettre à zéro la moitié inférieure (si hermitienne)
!>         stocker la moitié supérieure colonne par colonne (si hermitienne ou
!>               triangulaire supérieure)
!>         stocker la moitié inférieure colonne par colonne (si hermitienne ou
!>               triangulaire inférieure)
!>         stocker le triangle inférieur au format bande (si hermitienne ou
!>               triangulaire inférieure)
!>         stocker le triangle supérieur au format bande (si hermitienne ou
!>               triangulaire supérieure)
!>         stocker toute la matrice au format bande
!>      Si la méthode B est choisie, et que le format bande est spécifié, alors la
!>         matrice sera générée au format bande, donc aucun ré-empaquetage
!>         ne sera nécessaire.
!>

Paramètres

M 
!>          M est ENTIER
!>           Le nombre de lignes de A. Non modifié.
!>

N

!>          N est ENTIER
!>           Le nombre de colonnes de A. N doit être égal à M si la matrice
!>           est symétrique ou hermitienne (c'est-à-dire si SYM n'est pas 'N')
!>           Non modifié.
!>

DIST

!>          DIST est CARACTERE*1
!>           En entrée, DIST spécifie le type de distribution à utiliser
!>           pour générer les valeurs propres/singulières aléatoires.
!>           'U' => UNIFORME( 0, 1 )  ('U' pour uniforme)
!>           'S' => UNIFORME( -1, 1 ) ('S' pour symétrique)
!>           'N' => NORMAL( 0, 1 )   ('N' pour normale)
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau ENTIER, dimension ( 4 )
!>           En entrée, ISEED spécifie la graine du générateur de nombres
!>           aléatoires. Elles doivent être comprises entre 0 et 4095 inclus,
!>           et ISEED(4) doit être impair. Le générateur de nombres
!>           aléatoires utilise une séquence congruente linéaire limitée à de petits
!>           entiers, et devrait donc produire des nombres aléatoires indépendants de la machine.
!>           Les valeurs de ISEED sont modifiées à la sortie, et peuvent être utilisées
!>           dans le prochain appel à ZLATMS pour continuer la même séquence de nombres aléatoires.
!>           Modifié à la sortie.
!>

SYM

!>          SYM est CARACTERE*1
!>           Si SYM='H', la matrice générée est hermitienne, avec
!>             des valeurs propres spécifiées par D, COND, MODE, et DMAX ; elles
!>             peuvent être positives, négatives ou nulles.
!>           Si SYM='P', la matrice générée est hermitienne, avec
!>             des valeurs propres (= valeurs singulières) spécifiées par D, COND,
!>             MODE, et DMAX ; elles ne seront pas négatives.
!>           Si SYM='N', la matrice générée est non-symétrique, avec
!>             des valeurs singulières spécifiées par D, COND, MODE, et DMAX ;
!>             elles ne seront pas négatives.
!>           Si SYM='S', la matrice générée est symétrique (complexe),
!>             avec des valeurs singulières spécifiées par D, COND, MODE, et
!>             DMAX ; elles ne seront pas négatives.
!>           Non modifié.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension ( MIN( M, N ) )
!>           Ce tableau est utilisé pour spécifier les valeurs singulières ou
!>           les valeurs propres de A (voir SYM, ci-dessus). Si MODE=0, alors D est
!>           supposé contenir les valeurs propres/singulières, sinon
!>           elles seront calculées selon MODE, COND, et DMAX,
!>           et placées dans D.
!>           Modifié si MODE est non nul.
!>

MODE

!>          MODE est ENTIER
!>           En entrée, ceci décrit comment les valeurs propres/singulières sont à
!>           spécifier :
!>           MODE = 0 signifie utiliser D en entrée
!>           MODE = 1 définit D(1)=1 et D(2:N)=1.0/COND
!>           MODE = 2 définit D(1:N-1)=1 et D(N)=1.0/COND
!>           MODE = 3 définit D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 définit D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 définit D à des nombres aléatoires dans l'intervalle
!>                    ( 1/COND , 1 ) tels que leurs logarithmes
!>                    soient uniformément distribués.
!>           MODE = 6 définit D à des nombres aléatoires de la même distribution
!>                    que le reste de la matrice.
!>           MODE < 0 a la même signification que ABS(MODE), sauf que
!>              l'ordre des éléments de D est inversé.
!>           Ainsi, si MODE est positif, D a des éléments allant de
!>              1 à 1/COND, si négatif, de 1/COND à 1,
!>           Si SYM='H', et que MODE n'est ni 0, ni 6, ni -6, alors
!>              les éléments de D seront également multipliés par un signe aléatoire
!>              (c'est-à-dire +1 ou -1.)
!>           Non modifié.
!>

COND

!>          COND est DOUBLE PRECISION
!>           En entrée, ceci est utilisé comme décrit sous MODE ci-dessus.
!>           Si utilisé, il doit être >= 1. Non modifié.
!>

DMAX

!>          DMAX est DOUBLE PRECISION
!>           Si MODE n'est ni -6, ni 0, ni 6, le contenu de D, comme
!>           calculé selon MODE et COND, sera mis à l'échelle par
!>           DMAX / max(abs(D(i))) ; ainsi, la valeur propre ou singulière absolue maximale
!>           (qui est la norme) sera abs(DMAX).
!>           Notez que DMAX n'est pas nécessairement positif : si DMAX est négatif
!>           (ou nul), D sera mis à l'échelle par un nombre négatif (ou nul).
!>           Non modifié.
!>

KL

!>          KL est ENTIER
!>           Ceci spécifie la bande inférieure de la matrice. Par
!>           exemple, KL=0 implique triangulaire supérieure, KL=1 implique supérieure
!>           Hessenberg, et KL étant au moins M-1 signifie que la matrice

NAME

zlatms - generate test matrices

SYNOPSIS

  CALL ZLATMS( M, N, DIST, DIAG, MODE, COND, DMIN,
                 SEEDS, SUBTYPE, EXTEND, PARAM,
                 KL, KU, PACK, A, LDA, WORK, INFO )

Function/Subroutine Documentation

M

!> M is INTEGER
!> Number of rows of the matrix A.
!> Not modified.

N

!> N is INTEGER
!> Number of columns of the matrix A.
!> Not modified.

DIST

!> DIST is CHARACTER*1
!> Specifies the storage scheme for the matrix A:
!> 'U' => upper triangular matrix
!> 'L' => lower triangular matrix
!> 'L' => lower triangular matrix
!> 'G' => general band matrix
!> 'U' => upper triangular matrix
!> 'L' => lower triangular matrix
!> 'B' => lower triangular band matrix
!> 'Q' => upper triangular band matrix
!> 'Z' => general band matrix
!> Not modified.

DIAG

!> DIAG is CHARACTER*1
!> Specifies the type of diagonal elements:
!> 'N' => no diagonal elements are added
!> 'U' => the matrix has unit diagonal elements
!> 'S' => the matrix has randomly chosen diagonal elements
!> 'D' => the matrix has randomly chosen diagonal elements
!> 'W' => the matrix has randomly chosen diagonal elements
!> Not modified.

MODE

!> MODE is INTEGER
!> Specifies the value of the smallest singular value of A:
!> MODE = 0 => use DMIN
!> MODE = 1 => use 1.0
!> MODE = 2 => use EPS * COND
!> MODE = 3 => use EPS
!> MODE = 4 => use 1.0 / COND
!> MODE = 5 => use 1.0 / EPS
!> MODE = 6 => use DMIN / EPS
!> Not modified.

COND

!> COND is DOUBLE PRECISION
!> The condition number of the matrix.
!> Not modified.

DMIN

!> DMIN is DOUBLE PRECISION
!> The smallest singular value of the matrix.
!> Not modified.

SEEDS

!> SEEDS is INTEGER array, dimension ( 4 )
!> Random number generation seeds.
!> Not modified.

SUBTYPE

!> SUBTYPE is CHARACTER*1
!> Specifies the subtype of the matrix for the given distribution:
!> 'N' => general matrix
!> 'L' => lower triangular matrix
!> 'U' => upper triangular matrix
!> 'S' => symmetric matrix
!> 'H' => Hermitian matrix
!> 'P' => triangular matrix (complex)
!> Not modified.

EXTEND

!> EXTEND is CHARACTER*1
!> Specifies the subtype of the matrix for the given distribution:
!> 'N' => no extension
!> 'Y' => extend the matrix
!> Not modified.

PARAM

!> PARAM is DOUBLE PRECISION
!> Additional parameter for the given subtype.
!> Not modified.

KL

!> KL is INTEGER
!> This specifies the lower bandwidth of the matrix. For example,
!> KL=0 implies upper triangular, KL=1 implies upper Hessenberg,
!> and KL being at least N-1 means that the matrix has full lower
!> bandwidth. KL must equal KU if the matrix is symmetric or
!> hermitian.
!> Not modified.

KU

!> KU is INTEGER
!> This specifies the upper bandwidth of the matrix. For example,
!> KU=0 implies lower triangular, KU=1 implies lower
!> Hessenberg, and KU being at least N-1 means that the matrix
!> has full upper bandwidth. KL must equal KU if the matrix
!> is symmetric or hermitian.
!> Not modified.

PACK

!> PACK is CHARACTER*1
!> This specifies packing of matrix as follows:
!> 'N' => no packing
!> 'U' => zero out all subdiagonal entries (if symmetric
!> or hermitian)
!> 'L' => zero out all superdiagonal entries (if symmetric
!> or hermitian)
!> 'C' => store the upper triangle columnwise (only if the
!> matrix is symmetric, hermitian, or upper triangular)
!> 'R' => store the lower triangle columnwise (only if the
!> matrix is symmetric, hermitian, or lower triangular)
!> 'B' => store the lower triangle in band storage scheme
!> (only if the matrix is symmetric, hermitian, or
!> lower triangular)
!> 'Q' => store the upper triangle in band storage scheme
!> (only if the matrix is symmetric, hermitian, or
!> upper triangular)
!> 'Z' => store the entire matrix in band storage scheme
!> (pivoting can be provided for by using this
!> option to store A in the trailing rows of
!> the allocated storage)
!>
!> Using these options, the various LAPACK packed and banded
!> storage schemes can be obtained:
!> GB                    - use 'Z'
!> PB, SB, HB, or TB     - use 'B' or 'Q'
!> PP, SP, HB, or TP     - use 'C' or 'R'
!>
!> If two calls to ZLATMS differ only in the PACK parameter,
!> they will generate mathematically equivalent matrices.
!> Not modified.

A

!> A is COMPLEX*16 array, dimension ( LDA, N )
!> On exit A is the desired test matrix. A is first generated
!> in full (unpacked) form, and then packed, if so specified
!> by PACK. Thus, the first M elements of the first N
!> columns will always be modified. If PACK specifies a
!> packed or banded storage scheme, all LDA elements of the
!> first N columns will be modified; the elements of the
!> array which do not correspond to elements of the generated
!> matrix are set to zero.
!> Modified.

LDA

!> LDA is INTEGER
!> LDA specifies the first dimension of A as declared in the
!> calling program. If PACK='N', 'U', 'L', 'C', or 'R', then
!> LDA must be at least M. If PACK='B' or 'Q', then LDA must
!> be at least MIN( KL, M-1) (which is equal to MIN(KU,N-1)).
!> If PACK='Z', LDA must be large enough to hold the packed
!> array: MIN( KU, N-1) + MIN( KL, M-1) + 1.
!> Not modified.

WORK

!> WORK is COMPLEX*16 array, dimension ( 3*MAX( N, M ) )
!> Workspace.
!> Modified.

INFO

!> INFO is INTEGER
!> Error code. On exit, INFO will be set to one of the
!> following values:
!> 0 => normal return
!> -1 => M negative or unequal to N and SYM='S', 'H', or 'P'
!> -2 => N negative
!> -3 => DIST illegal string
!> -5 => SYM illegal string
!> -7 => MODE not in range -6 to 6
!> -8 => COND less than 1.0, and MODE neither -6, 0 nor 6
!> -10 => KL negative
!> -11 => KU negative, or SYM is not 'N' and KU is not equal to
!> KL
!> -12 => PACK illegal string, or PACK='U' or 'L', and SYM='N';
!> or PACK='C' or 'Q' and SYM='N' and KL is not zero;
!> or PACK='R' or 'B' and SYM='N' and KU is not zero;
!> or PACK='U', 'L', 'C', 'R', 'B', or 'Q', and M is not
!> N.
!> -14 => LDA is less than M, or PACK='Z' and LDA is less than
!> MIN(KU,N-1) + MIN(KL,M-1) + 1.
!> 1 => Error return from DLATM1
!> 2 => Cannot scale to DMAX (max. sing. value is 0)
!> 3 => Error return from ZLAGGE, CLAGHE or CLAGSY
