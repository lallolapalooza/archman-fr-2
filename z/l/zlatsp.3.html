Documentation de la fonction/sous-programme

sous-programme zlatsp (caractere uplo, entier n, complexe*16, dimension( * ) x, entier, dimension( * ) iseed)

ZLATSP

Objectif :

!>
!> ZLATSP génère une matrice de test spéciale pour la factorisation complexe symétrique
!> (indéfinie) pour les matrices compactées. Les blocs pivots de
!> la matrice générée seront dans l'ordre suivant :
!>    bloc pivot 2x2, non diagonalisable
!>    bloc pivot 1x1
!>    bloc pivot 2x2, diagonalisable
!>    (le cycle se répète)
!> Un échange de ligne est requis pour chaque bloc 2x2 non diagonalisable.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER
!>          Spécifie si la matrice générée doit être triangulaire supérieure ou
!>          inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          La dimension de la matrice à générer.
!>

X

!>          X est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          La matrice générée au format de stockage compacté. La matrice
!>          est composée de blocs diagonaux 3x3 et 2x2 qui résultent en la
!>          séquence de pivots donnée ci-dessus. La matrice en dehors de ces
!>          blocs diagonaux est nulle.
!>

ISEED

!>          ISEED est un tableau INTEGER, dimension (4)
!>          À l'entrée, la graine pour le générateur de nombres aléatoires. Le dernier
!>          des quatre entiers doit être impair. (modifié à la sortie)
!>
