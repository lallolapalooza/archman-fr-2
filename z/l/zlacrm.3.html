ZLACRM multiplie une matrice complexe par une matrice réelle carrée.

Documentation de la fonction/sous-programme

sous-programme zlacrm (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldc, * ) c, integer ldc, double precision, dimension( * ) rwork)

ZLACRM multiplie une matrice complexe par une matrice réelle carrée.

Objectif :

!>
!> ZLACRM effectue une multiplication de matrices très simple :
!>          C := A * B,
!> où A est M par N et complexe ; B est N par N et réelle ;
!> C est M par N et complexe.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A et de la matrice C.
!>          M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes et de lignes de la matrice B et
!>          le nombre de colonnes de la matrice C.
!>          N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>          À l'entrée, A contient la matrice A de taille M par N.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >=max(1,M).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB, N)
!>          À l'entrée, B contient la matrice B de taille N par N.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B. LDB >=max(1,N).
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC, N)
!>          À la sortie, C contient la matrice C de taille M par N.
!>

LDC

!>          LDC est un ENTIER
!>          La dimension principale du tableau C. LDC >=max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (2*M*N)
!>
