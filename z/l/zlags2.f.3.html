Documentation de la fonction/sous-programme

sous-programme zlags2 (logical upper, double precision a1, complex*16 a2, double precision a3, double precision b1, complex*16 b2, double precision b3, double precision csu, complex*16 snu, double precision csv, complex*16 snv, double precision csq, complex*16 snq)

ZLAGS2

Objectif :

!>
!> ZLAGS2 calcule les matrices unitaires U, V et Q de taille 2x2, telles que si ( UPPER ) alors
!>
!>           U**H *A*Q = U**H *( A1 A2 )*Q = ( x  0  )
!>                             ( 0  A3 )     ( x  x  )
!> et
!>           V**H*B*Q = V**H *( B1 B2 )*Q = ( x  0  )
!>                            ( 0  B3 )     ( x  x  )
!>
!> ou si ( .NOT.UPPER ) alors
!>
!>           U**H *A*Q = U**H *( A1 0  )*Q = ( x  x  )
!>                             ( A2 A3 )     ( 0  x  )
!> et
!>           V**H *B*Q = V**H *( B1 0  )*Q = ( x  x  )
!>                             ( B2 B3 )     ( 0  x  )
!> où
!>
!>   U = (   CSU    SNU ), V = (  CSV    SNV ),
!>       ( -SNU**H  CSU )      ( -SNV**H CSV )
!>
!>   Q = (   CSQ    SNQ )
!>       ( -SNQ**H  CSQ )
!>
!> Les lignes des matrices A et B transformées sont parallèles. De plus, si la
!> matrice d'entrée 2x2 A n'est pas nulle, alors l'entrée (1,1) transformée
!> de A n'est pas nulle. Si les matrices d'entrée A et B ne sont pas toutes deux
!> nulles, alors l'élément (2,2) transformé de B n'est pas nul, sauf lorsque
!> les premières lignes de A et B d'entrée sont parallèles et les secondes lignes sont
!> nulles.
!>

Paramètres

UPPER 
!>          UPPER est LOGICAL
!>          = .TRUE. : les matrices d'entrée A et B sont triangulaires supérieures.
!>          = .FALSE. : les matrices d'entrée A et B sont triangulaires inférieures.
!>

A1

!>          A1 est DOUBLE PRECISION
!>

A2

!>          A2 est COMPLEX*16
!>

A3

!>          A3 est DOUBLE PRECISION
!>          À l'entrée, A1, A2 et A3 sont les éléments de la matrice triangulaire
!>          supérieure (inférieure) d'entrée 2x2 A.
!>

B1

!>          B1 est DOUBLE PRECISION
!>

B2

!>          B2 est COMPLEX*16
!>

B3

!>          B3 est DOUBLE PRECISION
!>          À l'entrée, B1, B2 et B3 sont les éléments de la matrice triangulaire
!>          supérieure (inférieure) d'entrée 2x2 B.
!>

CSU

!>          CSU est DOUBLE PRECISION
!>

SNU

!>          SNU est COMPLEX*16
!>          La matrice unitaire désirée U.
!>

CSV

!>          CSV est DOUBLE PRECISION
!>

SNV

!>          SNV est COMPLEX*16
!>          La matrice unitaire désirée V.
!>

CSQ

!>          CSQ est DOUBLE PRECISION
!>

SNQ

!>          SNQ est COMPLEX*16
!>          La matrice unitaire désirée Q.
!>
