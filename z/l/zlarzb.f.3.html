subroutine zlarzb (side, trans, direct, storev, m, n, k, l, v, ldv, t, ldt, c, ldc, work, ldwork)
ZLARZB applique un bloc réflecteur ou sa conjuguée transposée à une matrice générale.

Documentation de la fonction/sous-programme

sous-programme zlarzb (character side, character trans, character direct, character storev, integer m, integer n, integer k, integer l, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( ldwork, * ) work, integer ldwork)

ZLARZB applique un bloc réflecteur complexe H ou sa conjuguée transposée H**H à une matrice générale complexe distribuée M-par-N C, depuis la gauche ou la droite.

Objectif :

!>
!> ZLARZB applique un bloc réflecteur complexe H ou sa transposée H**H
!> à une matrice complexe distribuée C de dimensions M-par-N depuis la
!> gauche ou la droite.
!>
!> Actuellement, seuls STOREV = 'R' et DIRECT = 'B' sont supportés.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer H ou H**H depuis la gauche
!>          = 'R' : appliquer H ou H**H depuis la droite
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : appliquer H (Pas de transposée)
!>          = 'C' : appliquer H**H (Conjuguée transposée)
!>

DIRECT

!>          DIRECT est CHARACTER*1
!>          Indique comment H est formé à partir d'un produit de
!>          réflecteurs élémentaires
!>          = 'F' : H = H(1) H(2) . . . H(k) (Avant, pas encore supporté)
!>          = 'B' : H = H(k) . . . H(2) H(1) (Arrière)
!>

STOREV

!>          STOREV est CHARACTER*1
!>          Indique comment les vecteurs qui définissent les réflecteurs
!>          élémentaires sont stockés :
!>          = 'C' : Par colonnes                        (pas encore supporté)
!>          = 'R' : Par lignes
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

K

!>          K est INTEGER
!>          L'ordre de la matrice T (= le nombre de réflecteurs
!>          élémentaires dont le produit définit le bloc réflecteur).
!>

L

!>          L est INTEGER
!>          Le nombre de colonnes de la matrice V contenant la partie
!>          significative des réflecteurs de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

V

!>          V est un tableau COMPLEX*16, dimension (LDV,NV).
!>          Si STOREV = 'C', NV = K ; si STOREV = 'R', NV = L.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V.
!>          Si STOREV = 'C', LDV >= L ; si STOREV = 'R', LDV >= K.
!>

T

!>          T est un tableau COMPLEX*16, dimension (LDT,K)
!>          La matrice triangulaire K-par-K T dans la représentation du
!>          bloc réflecteur.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= K.
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC,N)
!>          À l'entrée, la matrice C de dimensions M-par-N.
!>          À la sortie, C est écrasé par H*C ou H**H*C ou C*H ou C*H**H.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LDWORK,K)
!>

LDWORK

!>          LDWORK est INTEGER
!>          La dimension principale du tableau WORK.
!>          Si SIDE = 'L', LDWORK >= max(1,N) ;
!>          si SIDE = 'R', LDWORK >= max(1,M).
!>
