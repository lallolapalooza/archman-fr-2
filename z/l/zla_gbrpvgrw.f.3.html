ZLA_GBRPVGRW calcule le facteur de croissance des pivots réciproque norm(A)/norm(U) pour une matrice bande générale.

Documentation de la fonction/sous-routine

double precision function zla_gbrpvgrw (integer n, integer kl, integer ku, integer ncols, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldafb, * ) afb, integer ldafb)

ZLA_GBRPVGRW calcule le facteur de croissance des pivots réciproque norm(A)/norm(U) pour une matrice bande générale.

Objectif :

!>
!> ZLA_GBRPVGRW calcule le facteur de croissance des pivots réciproque
!> norm(A)/norm(U). La norme est utilisée. Si ceci est
!> beaucoup moins que 1, la stabilité de la factorisation LU de la
!> matrice (équilibrée) A pourrait être médiocre. Cela signifie aussi que
!> la solution X, les nombres de condition estimés et les bornes d'erreur pourraient être
!> peu fiables.
!>

Paramètres

N 
!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NCOLS

!>          NCOLS est INTEGER
!>     Le nombre de colonnes de la matrice A.  NCOLS >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, dimension (LDAB,N)
!>     En entrée, la matrice A en stockage bande, dans les lignes 1 à KL+KU+1.
!>     La j-ième colonne de A est stockée dans la j-ième colonne du
!>     tableau AB comme suit :
!>     AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU)<=i<=min(N,j+kl)
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est un tableau COMPLEX*16, dimension (LDAFB,N)
!>     Détails de la factorisation LU de la matrice bande A, tels que
!>     calculés par ZGBTRF.  U est stocké comme une matrice bande triangulaire supérieure
!>     avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1,
!>     et les multiplicateurs utilisés pendant la factorisation sont stockés
!>     dans les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale du tableau AFB.  LDAFB >= 2*KL+KU+1.
!>
