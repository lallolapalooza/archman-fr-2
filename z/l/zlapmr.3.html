sous-routine zlapmr (logical forwrd, integer m, integer n, complex*16, dimension( ldx, * ) x, integer ldx, integer, dimension( * ) k)

ZLAPMR réorganise les lignes d'une matrice selon un vecteur de permutation.

Objectif :

!>
!> ZLAPMR réorganise les lignes de la matrice M par N de X selon la
!> permutation K(1),K(2),...,K(M) des entiers 1,...,M.
!> Si FORWRD = .TRUE., permutation avant :
!>
!>      X(K(I),*) est déplacé vers X(I,*) pour I = 1,2,...,M.
!>
!> Si FORWRD = .FALSE., permutation arrière :
!>
!>      X(I,*) est déplacé vers X(K(I),*) pour I = 1,2,...,M.
!>

Paramètres

FORWRD 
!>          FORWRD est LOGICAL
!>          = .TRUE., permutation avant
!>          = .FALSE., permutation arrière
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice X. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice X. N >= 0.
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,N)
!>          À l'entrée, la matrice M par N X.
!>          À la sortie, X contient la matrice permutée X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X, LDX >= MAX(1,M).
!>

K

!>          K est un tableau INTEGER, dimension (M)
!>          À l'entrée, K contient le vecteur de permutation. K est utilisé comme
!>          espace de travail interne, mais est réinitialisé à sa valeur d'origine
!>          à la sortie.
!>
