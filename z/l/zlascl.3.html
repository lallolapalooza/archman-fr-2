Fonctions/Sous-programmes


sous-programme zlascl (type, kl, ku, cfrom, cto, m, n, a, lda, info)
ZLASCL multiplie une matrice rectangulaire générale par un scalaire réel défini comme cto/cfrom.

Documentation de la fonction/sous-programme

sous-programme zlascl (caractère type, entier kl, entier ku, double précision cfrom, double précision cto, entier m, entier n, complexe*16, dimension( lda, * ) a, entier lda, entier info)

ZLASCL multiplie la matrice complexe M par N, A, par le scalaire réel CTO/CFROM. Ceci est fait sans débordement supérieur/inférieur tant que le résultat final CTO*A(I,J)/CFROM ne déborde pas.

Objectif :

!>
!> ZLASCL multiplie la matrice complexe M par N, A, par le scalaire réel
!> CTO/CFROM.  Ceci est fait sans débordement supérieur/inférieur tant que
!> le résultat final CTO*A(I,J)/CFROM ne déborde pas. TYPE spécifie que
!> A peut être complète, triangulaire supérieure, triangulaire inférieure,
!> supérieure-Hessenberg, ou bande.
!>

Paramètres

TYPE 
!>          TYPE est CHARACTER*1
!>          TYPE indique le type de stockage de la matrice d'entrée.
!>          = 'G':  A est une matrice complète.
!>          = 'L':  A est une matrice triangulaire inférieure.
!>          = 'U':  A est une matrice triangulaire supérieure.
!>          = 'H':  A est une matrice supérieure-Hessenberg.
!>          = 'B':  A est une matrice bande symétrique avec une bande inférieure KL
!>                  et une bande supérieure KU et avec seulement la moitié inférieure stockée.
!>          = 'Q':  A est une matrice bande symétrique avec une bande inférieure KL
!>                  et une bande supérieure KU et avec seulement la moitié supérieure stockée.
!>          = 'Z':  A est une matrice bande avec une bande inférieure KL et une bande supérieure
!>                  KU. Voir ZGBTRF pour les détails de stockage.
!>

KL

!>          KL est INTEGER
!>          La largeur de bande inférieure de A.  Référencée seulement si TYPE = 'B',
!>          'Q' ou 'Z'.
!>

KU

!>          KU est INTEGER
!>          La largeur de bande supérieure de A.  Référencée seulement si TYPE = 'B',
!>          'Q' ou 'Z'.
!>

CFROM

!>          CFROM est DOUBLE PRECISION
!>

CTO

!>          CTO est DOUBLE PRECISION
!>
!>          La matrice A est multipliée par CTO/CFROM. A(I,J) est calculé
!>          sans débordement supérieur/inférieur si le résultat final CTO*A(I,J)/CFROM
!>          peut être représenté sans débordement supérieur/inférieur.  CFROM doit
!>          être non nul.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice à multiplier par CTO/CFROM.  Voir TYPE pour le
!>          type de stockage.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si TYPE = 'G', 'L', 'U', 'H', LDA >= max(1,M);
!>             TYPE = 'B', LDA >= KL+1;
!>             TYPE = 'Q', LDA >= KU+1;
!>             TYPE = 'Z', LDA >= 2*KL+KU+1.
!>

INFO

!>          INFO est INTEGER
!>          0  - sortie réussie
!>          <0 - si INFO = -i, le i-ème argument avait une valeur illégale.
!>
