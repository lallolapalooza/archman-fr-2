ZLATM3

Objectif :

!>
!>    ZLATM3 renvoie l'entrée (ISUB,JSUB) d'une matrice aléatoire de
!>    dimension (M, N) décrite par les autres paramètres. (ISUB,JSUB)
!>    est la position finale de l'entrée (I,J) après pivotement
!>    selon IPVTNG et IWORK. ZLATM3 est appelée par la
!>    routine ZLATMR afin de construire des matrices de test aléatoires. Aucune vérification des paramètres n'est effectuée, car cette routine est appelée dans
!>    une boucle serrée par ZLATMR qui a déjà vérifié les paramètres.
!>
!>    L'utilisation de ZLATM3 diffère de CLATM2 dans l'ordre dans lequel le générateur de nombres aléatoires
!>    est appelé pour remplir les entrées de la matrice aléatoire.
!>    Avec ZLATM2, le générateur est appelé pour remplir la matrice pivotée
!>    colonne par colonne. Avec ZLATM3, le générateur est appelé pour remplir la
!>    matrice colonne par colonne, après quoi elle est pivotée. Ainsi, ZLATM3 peut
!>    être utilisé pour construire des matrices aléatoires qui diffèrent uniquement par leur
!>    ordre de lignes et/ou de colonnes. ZLATM2 est utilisé pour construire des matrices bande
!>    tout en évitant d'appeler le générateur de nombres aléatoires pour
!>    les entrées en dehors de la bande (et donc de générer des nombres aléatoires
!>    dans des ordres différents pour des ordres de pivotement différents).
!>
!>    La matrice dont l'entrée (ISUB,JSUB) est renvoyée est construite comme
!>    suit (cette routine ne calcule qu'une seule entrée) :
!>
!>      Si ISUB est en dehors de (1..M) ou JSUB est en dehors de (1..N), renvoyer zéro
!>         (ceci est pratique pour générer des matrices au format bande).
!>
!>      Générer une matrice A avec des entrées aléatoires de distribution IDIST.
!>
!>      Définir la diagonale à D.
!>
!>      Graduer la matrice, si désiré, par la gauche (par DL) et/ou
!>         par la droite (par DR ou DL) comme spécifié par IGRADE.
!>
!>      Permuter, si désiré, les lignes et/ou les colonnes comme spécifié par
!>         IPVTNG et IWORK.
!>
!>      Mettre la matrice en bande pour avoir une bande inférieure KL et une bande supérieure
!>         KU.
!>
!>      Définir les entrées aléatoires à zéro comme spécifié par SPARSE.
!>

Paramètres

M 
!>          M est un ENTIER
!>           Nombre de lignes de la matrice. Non modifié.
!>

N

!>          N est un ENTIER
!>           Nombre de colonnes de la matrice. Non modifié.
!>

I

!>          I est un ENTIER
!>           Ligne de l'entrée non pivotée à renvoyer. Non modifiée.
!>

J

!>          J est un ENTIER
!>           Colonne de l'entrée non pivotée à renvoyer. Non modifiée.
!>

ISUB

!>          ISUB est un ENTIER
!>           Ligne de l'entrée pivotée à renvoyer. Modifiée à la sortie.
!>

JSUB

!>          JSUB est un ENTIER
!>           Colonne de l'entrée pivotée à renvoyer. Modifiée à la sortie.
!>

KL

!>          KL est un ENTIER
!>           Bande inférieure. Non modifiée.
!>

KU

!>          KU est un ENTIER
!>           Bande supérieure. Non modifiée.
!>

IDIST

!>          IDIST est un ENTIER
!>           À l'entrée, IDIST spécifie le type de distribution à utiliser pour générer une matrice aléatoire.
!>           1 => parties réelle et imaginaire UNIFORMES ( 0, 1 ) chacune
!>           2 => parties réelle et imaginaire UNIFORMES ( -1, 1 ) chacune
!>           3 => parties réelle et imaginaire NORMALES ( 0, 1 ) chacune
!>           4 => nombre complexe dans le DISQUE ( 0 , 1 )
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau d'ENTIERS de dimension ( 4 )
!>           Graine pour le générateur de nombres aléatoires.
!>           Modifié à la sortie.
!>

D

!>          D est un tableau COMPLEX*16 de dimension ( MIN( I , J ) )
!>           Entrées diagonales de la matrice. Non modifié.
!>

IGRADE

!>          IGRADE est un ENTIER
!>           Spécifie la graduation de la matrice comme suit :
!>           0  => pas de graduation
!>           1  => matrice pré-multipliée par diag( DL )
!>           2  => matrice post-multipliée par diag( DR )
!>           3  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( DR )
!>           4  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par inv( diag( DL ) )
!>           5  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( CONJG(DL) )
!>           6  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( DL )
!>           Non modifié.
!>

DL

!>          DL est un tableau COMPLEX*16 ( I ou J, selon le cas )
!>           Facteurs d'échelle gauches pour la graduation de la matrice. Non modifié.
!>

DR

!>          DR est un tableau COMPLEX*16 ( I ou J, selon le cas )
!>           Facteurs d'échelle droits pour la graduation de la matrice. Non modifié.
!>

IPVTNG

!>          IPVTNG est un ENTIER
!>           À l'entrée, spécifie les permutations de pivotement comme suit :
!>           0 => aucune.
!>           1 => pivotement de ligne.
!>           2 => pivotement de colonne.
!>           3 => pivotement complet, c'est-à-dire des deux côtés.
!>           Non modifié.
!>

IWORK

!>          IWORK est un tableau d'ENTIERS ( I ou J, selon le cas )
!>           Ce tableau spécifie la permutation utilisée. La
!>           ligne (ou colonne) initialement en position K se trouve en
!>           position IWORK( K ) après pivotement.
!>           Ceci diffère de IWORK pour ZLATM2. Non modifié.
!>

SPARSE

!>          SPARSE est un DOUBLE PRÉCISION entre 0 et 1.
!>           À l'entrée, spécifie la sparsité de la matrice
!>           si une matrice creuse doit être générée.
!>           SPARSE doit être compris entre 0 et 1.
!>           Un nombre aléatoire x UNIFORME ( 0, 1 ) est généré et
!>           comparé à SPARSE ; si x est plus grand, l'entrée de la matrice
!>           n'est pas modifiée et si x est plus petit, l'entrée est mise à
!>           zéro. Ainsi, en moyenne, une fraction SPARSE des
!>           entrées sera mise à zéro.
!>           Non modifié.
!>

zlatm3(3)

NAME

zlatm3 - form a general matrix $A$ given its singular values, condition number and distribution.

SYNOPSIS

SUBROUTINE ZLATM3( LWORK, A, LDA, X, Y, ..., WORK, INFO )

Function/Subroutine Documentation

This subroutine is part of the LAPACK library, which provides routines for linear algebra computations. zlatm3 is specifically designed to generate a complex general matrix `A` based on its singular values, a specified condition number, and information about the distribution of these singular values.

**Parameters:**

  • LWORK: INTEGER. Length of the array WORK.
  • A: COMPLEX*16 array, dimension (LDA, N). On exit, A contains the generated matrix.
  • LDA: INTEGER. Leading dimension of A.
  • X: DOUBLE PRECISION array, dimension (N). On entry, X contains the singular values of A.
  • Y: DOUBLE PRECISION array, dimension (N). On entry, Y contains the right singular vectors of A.
  • WORK: COMPLEX*16 array, dimension (LWORK). Workspace array.
  • INFO: INTEGER.
    • INFO = 0: successful exit
    • INFO < 0: if INFO = -i, the i-th argument had an illegal value
    • INFO > 0: if INFO = i, the algorithm did not converge after i iterations

**Purpose:**

The purpose of ZLATM3 is to construct a matrix A with a prescribed singular value distribution. The singular values are given in array X. The distribution of the singular values is controlled by the value of the condition number KAPPA. The right singular vectors are given in array Y.

The matrix A is constructed in the form $A = U \Sigma V^H$, where $\Sigma$ is a diagonal matrix with the singular values on the diagonal, and U and V are unitary matrices.

The condition number can be specified by the user. If KAPPA is large, the matrix A will be ill-conditioned.

NOM

zlatm3 - forme une matrice générale $A$ étant données ses valeurs singulières, son nombre de condition et sa distribution.

SYNTAXE

SUBROUTINE ZLATM3( LWORK, A, LDA, X, Y, ..., WORK, INFO )

Documentation de la fonction/sous-routine

Cette sous-routine fait partie de la bibliothèque LAPACK, qui fournit des routines pour les calculs d'algèbre linéaire. zlatm3 est spécifiquement conçue pour générer une matrice complexe générale `A` en fonction de ses valeurs singulières, d'un nombre de condition spécifié et d'informations sur la distribution de ces valeurs singulières.

**Paramètres :**

  • LWORK : ENTIER. Longueur du tableau WORK.
  • A : Tableau COMPLEX*16, de dimension (LDA, N). En sortie, A contient la matrice générée.
  • LDA : ENTIER. Dimension principale de A.
  • X : Tableau DOUBLE PRECISION, de dimension (N). En entrée, X contient les valeurs singulières de A.
  • Y : Tableau DOUBLE PRECISION, de dimension (N). En entrée, Y contient les vecteurs singuliers droits de A.
  • WORK : Tableau COMPLEX*16, de dimension (LWORK). Tableau de travail.
  • INFO : ENTIER.
    • INFO = 0 : sortie réussie
    • INFO < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
    • INFO > 0 : si INFO = i, l'algorithme n'a pas convergé après i itérations

**Objectif :**

L'objectif de ZLATM3 est de construire une matrice A avec une distribution de valeurs singulières prescrite. Les valeurs singulières sont données dans le tableau X. La distribution des valeurs singulières est contrôlée par la valeur du nombre de condition KAPPA. Les vecteurs singuliers droits sont donnés dans le tableau Y.

La matrice A est construite sous la forme $A = U \Sigma V^H$, où $\Sigma$ est une matrice diagonale avec les valeurs singulières sur la diagonale, et U et V sont des matrices unitaires.

Le nombre de condition peut être spécifié par l'utilisateur. Si KAPPA est grand, la matrice A sera mal conditionnée.
