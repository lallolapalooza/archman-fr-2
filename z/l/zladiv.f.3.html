Documentation de la fonction/sous-programme

complex*16 function zladiv (complex*16 x, complex*16 y)

ZLADIV effectue une division complexe en arithmétique réelle, évitant les débordements inutiles.

But :

!>
!> ZLADIV := X / Y, où X et Y sont des nombres complexes. Le calcul de X / Y
!> ne débordera pas lors d'une étape intermédiaire, sauf si le résultat
!> déborde.
!>

Paramètres

X 
!>          X est COMPLEX*16
!>

Y

!>          Y est COMPLEX*16
!>          Les scalaires complexes X et Y.
!>
