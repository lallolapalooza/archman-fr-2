ZLARFB_GETT

But :

!>
!> ZLARFB_GETT applique un bloc réflecteur de Householder complexe H de
!> gauche à une matrice complexe de taille (K+M)-par-N composée de deux
!> matrices blocs : une matrice trapézoïdale supérieure K-par-N stockée dans le
!> tableau A, et une matrice rectangulaire M-par-(N-K), stockée dans le
!> tableau B. Le bloc réflecteur H est stocké dans une représentation
!> compacte de type WY, où les réflecteurs élémentaires sont dans les
!> tableaux A, B et T. Voir la section Détails supplémentaires.
!>

Paramètres

IDENT 
!>          IDENT est CHARACTER*1
!>          Si IDENT = non 'I', ou non 'i', alors V1 est une matrice
!>             triangulaire inférieure unitaire et stockée dans le bloc
!>             supérieur gauche K-par-K de la matrice d'entrée A,
!>          Si IDENT = 'I' ou 'i', alors V1 est une matrice identité et
!>             n'est pas stockée.
!>          Voir la section Détails supplémentaires.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice B.
!>          M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B.
!>          N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de lignes de la matrice A.
!>          K est aussi l'ordre de la matrice T, c'est-à-dire le nombre
!>          de réflecteurs élémentaires dont le produit définit le bloc
!>          réflecteur. 0 <= K <= N.
!>

T

!>          T est un tableau COMPLEX*16, dimension (LDT,K)
!>          La matrice triangulaire supérieure T de taille KxK dans la
!>          représentation du bloc réflecteur.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= K.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>
!>          À l'entrée :
!>           a) Dans la partie trapézoïdale supérieure KxN de A : matrice d'entrée A.
!>           b) Dans les colonnes sous la diagonale : colonnes de V1
!>              (les uns ne sont pas stockés sur la diagonale).
!>
!>          À la sortie :
!>            A est écrasé par le produit matriciel rectangulaire KxN, H*A.
!>
!>          Voir la section Détails supplémentaires.
!>

LDA

!>          LDB est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,N)
!>
!>          À l'entrée :
!>            a) Dans le bloc droit M-par-(N-K) : matrice d'entrée B.
!>            b) Dans le bloc gauche M-par-N : colonnes de V2.
!>
!>          À la sortie :
!>            B est écrasé par le produit matriciel rectangulaire M-par-N, H*B.
!>
!>          Voir la section Détails supplémentaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX*16,
!>          dimension (LDWORK,max(K,N-K))
!>

LDWORK

!>          LDWORK est INTEGER
!>          La dimension principale du tableau WORK. LDWORK>=max(1,K).
!>
!>

Détails supplémentaires :

!>
!>    (1) Description de l'Opération Algébrique.
!>
!>    La matrice A est une matrice K-par-N composée de deux matrices
!>    blocs de colonnes, A1, qui est K-par-K, et A2, qui est K-par-(N-K) :
!>    A = ( A1, A2 ).
!>    La matrice B est une matrice M-par-N composée de deux matrices
!>    blocs de colonnes, B1, qui est M-par-K, et B2, qui est M-par-(N-K) :
!>    B = ( B1, B2 ).
!>
!>    Effectuer l'opération :
!>
!>       ( A_out ) := H * ( A_in ) = ( I - V * T * V**H ) * ( A_in ) =
!>       ( B_out )        ( B_in )                          ( B_in )
!>                  = ( I - ( V1 ) * T * ( V1**H, V2**H ) ) * ( A_in )
!>                          ( V2 )                            ( B_in )
!>     À l'entrée :
!>
!>    a) ( A_in )  contient deux blocs de colonnes :
!>       ( B_in )
!>
!>       ( A_in ) = (( A1_in ) ( A2_in )) = (( A1_in ) ( A2_in ))
!>       ( B_in )   (( B1_in ) ( B2_in ))   ((     0 ) ( B2_in )),
!>
!>       où les blocs de colonnes sont :
!>
!>       (  A1_in )  est une matrice triangulaire supérieure K-par-K stockée
!>                   dans la partie triangulaire supérieure du tableau A(1:K,1:K).
!>       (  B1_in )  est une matrice ZÉRO rectangulaire M-par-K et n'est pas
!>                   stockée.
!>
!>       ( A2_in )  est une matrice rectangulaire K-par-(N-K) stockée
!>                  dans le tableau A(1:K,K+1:N).
!>       ( B2_in )  est une matrice rectangulaire M-par-(N-K) stockée
!>                  dans le tableau B(1:M,K+1:N).
!>
!>    b) V = ( V1 )
!>           ( V2 )
!>
!>       où :
!>       1) si IDENT == 'I', V1 est une matrice identité K-par-K, non stockée ;
!>       2) si IDENT != 'I', V1 est une matrice triangulaire inférieure unitaire K-par-K,
!>          stockée dans la partie triangulaire inférieure du tableau
!>          A(1:K,1:K) (les uns ne sont pas stockés),
!>       et V2 est une matrice rectangulaire M-par-K stockée dans le tableau
!>       B(1:M,1:K), (car à l'entrée B1_in est une matrice nulle rectangulaire
!>       qui n'est pas stockée et l'espace est utilisé pour stocker V2).
!>
!>    c) T est une matrice triangulaire supérieure K-par-K stockée
!>       dans le tableau T(1:K,1:K).
!>
!>    À la sortie :
!>
!>    a) ( A_out ) contient deux blocs de colonnes :
!>       ( B_out )
!>
!>       ( A_out ) = (( A1_out ) ( A2_out ))
!>       ( B_out )   (( B1_out ) ( B2_out )),
!>
!>       où les blocs de colonnes sont :
!>
!>       ( A1_out )  est une matrice carrée K-par-K, ou une matrice
!>                   triangulaire supérieure K-par-K, si V1 est une
!>                   matrice identité. AiOut est stockée dans
!>                   le tableau A(1:K,1:K).
!>       ( B1_out )  est une matrice rectangulaire M-par-K stockée
!>                   dans le tableau B(1:M,K:N).
!>
!>       ( A2_out )  est une matrice rectangulaire K-par-(N-K) stockée
!>                   dans le tableau A(1:K,K+1:N).
!>       ( B2_out )  est une matrice rectangulaire M-par-(N-K) stockée
!>                   dans le tableau B(1:M,K+1:N).
!>
!>
!>    L'opération ci-dessus peut être représentée comme la même opération
!>    sur chaque bloc de colonnes :
!>
!>       ( A1_out ) := H * ( A1_in ) = ( I - V * T * V**H ) * ( A1_in )
!>       ( B1_out )        (     0 )                          (     0 )
!>
!>       ( A2_out ) := H * ( A2_in ) = ( I - V * T * V**H ) * ( A2_in )
!>       ( B2_out )        ( B2_in )                          ( B2_in )
!>
!>    Si IDENT != 'I' :
!>
!>       Le calcul pour le bloc de colonnes 1 :
!>
!>       A1_out: = A1_in - V1*T*(V1**H)*A1_in
!>
!>       B1_out: = - V2*T*(V1**H)*A1_in
!>
!>       Le calcul pour le bloc de colonnes 2, qui existe si N > K :
!>
!>       A2_out: = A2_in - V1*T*( (V1**H)*A2_in + (V2**H)*B2_in )
!>
!>       B2_out: = B2_in - V2*T*( (V1**H)*A2_in + (V2**H)*B2_in )
!>
!>    Si IDENT == 'I' :
!>
!>       L'opération pour le bloc de colonnes 1 :
!>
!>       A1_out: = A1_in - V1*T*A1_in
!>
!>       B1_out: = - V2*T*A1_in
!>
!>       Le calcul pour le bloc de colonnes 2, qui existe si N > K :
!>
!>       A2_out: = A2_in - V1*T*( (V1**H)*A2_in + (V2**H)*B2_in )
!>
!>       B2_out: = B2_in - V2*T*( (V1**H)*A2_in + (V2**H)*B2_in )
!>
!>
!>

!>       B2_out: = B2_in - V2*T*( A2_in + (V2**H)*B2_in )
!>
!>    (2) Description of the Algorithmic Computation.
!>
!>    In the first step, we compute column block 2, i.e. A2 and B2.
!>    Here, we need to use the K-by-(N-K) rectangular workspace
!>    matrix W2 that is of the same size as the matrix A2.
!>    W2 is stored in the array WORK(1:K,1:(N-K)).
!>
!>    In the second step, we compute column block 1, i.e. A1 and B1.
!>    Here, we need to use the K-by-K square workspace matrix W1
!>    that is of the same size as the as the matrix A1.
!>    W1 is stored in the array WORK(1:K,1:K).
!>
!>    NOTE: Hence, in this routine, we need the workspace array WORK
!>    only of size WORK(1:K,1:max(K,N-K)) so it can hold both W2 from
!>    the first step and W1 from the second step.
!>
!>    Case (A), when V1 is unit lower-triangular, i.e. IDENT != 'I',
!>    more computations than in the Case (B).
!>
!>    if( IDENT != 'I' ) then
!>     if ( N > K ) then
!>       (First Step - column block 2)
!>       col2_(1) W2: = A2
!>       col2_(2) W2: = (V1**H) * W2 = (unit_lower_tr_of_(A1)**H) * W2
!>       col2_(3) W2: = W2 + (V2**H) * B2 = W2 + (B1**H) * B2
!>       col2_(4) W2: = T * W2
!>       col2_(5) B2: = B2 - V2 * W2 = B2 - B1 * W2
!>       col2_(6) W2: = V1 * W2 = unit_lower_tr_of_(A1) * W2
!>       col2_(7) A2: = A2 - W2
!>     else
!>       (Second Step - column block 1)
!>       col1_(1) W1: = A1
!>       col1_(2) W1: = (V1**H) * W1 = (unit_lower_tr_of_(A1)**H) * W1
!>       col1_(3) W1: = T * W1
!>       col1_(4) B1: = - V2 * W1 = - B1 * W1
!>       col1_(5) square W1: = V1 * W1 = unit_lower_tr_of_(A1) * W1
!>       col1_(6) square A1: = A1 - W1
!>     end if
!>    end if
!>
!>    Case (B), when V1 is an identity matrix, i.e. IDENT == 'I',
!>    less computations than in the Case (A)
!>
!>    if( IDENT == 'I' ) then
!>     if ( N > K ) then
!>       (First Step - column block 2)
!>       col2_(1) W2: = A2
!>       col2_(3) W2: = W2 + (V2**H) * B2 = W2 + (B1**H) * B2
!>       col2_(4) W2: = T * W2
!>       col2_(5) B2: = B2 - V2 * W2 = B2 - B1 * W2
!>       col2_(7) A2: = A2 - W2
!>     else
!>       (Second Step - column block 1)
!>       col1_(1) W1: = A1
!>       col1_(3) W1: = T * W1
!>       col1_(4) B1: = - V2 * W1 = - B1 * W1
!>       col1_(6) upper-triangular_of_(A1): = A1 - W1
!>     end if
!>    end if
!>
!>    Combine these cases (A) and (B) together, this is the resulting
