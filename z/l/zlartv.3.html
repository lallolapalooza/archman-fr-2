sous-routine zlartv (n, x, incx, y, incy, c, s, incc)
ZLARTV applique un vecteur de rotations planes avec des cosinus réels et des sinus complexes aux éléments d'une paire de vecteurs.

Documentation de la fonction/sous-routine

sous-routine zlartv (integer n, complex*16, dimension( * ) x, integer incx, complex*16, dimension( * ) y, integer incy, double precision, dimension( * ) c, complex*16, dimension( * ) s, integer incc)

ZLARTV applique un vecteur de rotations planes avec des cosinus réels et des sinus complexes aux éléments d'une paire de vecteurs.

Objectif:

!>
!> ZLARTV applique un vecteur de rotations planes complexes avec des cosinus
!> réels aux éléments des vecteurs complexes x et y. Pour i = 1,2,...,n
!>
!>    ( x(i) ) := (        c(i)   s(i) ) ( x(i) )
!>    ( y(i) )    ( -conjg(s(i))  c(i) ) ( y(i) )
!>

Paramètres

N 
!>          N est un entier
!>          Le nombre de rotations planes à appliquer.
!>

X

!>          X est un tableau COMPLEX*16, dimension (1+(N-1)*INCX)
!>          Le vecteur x.
!>

INCX

!>          INCX est un entier
!>          L'incrément entre les éléments de X. INCX > 0.
!>

Y

!>          Y est un tableau COMPLEX*16, dimension (1+(N-1)*INCY)
!>          Le vecteur y.
!>

INCY

!>          INCY est un entier
!>          L'incrément entre les éléments de Y. INCY > 0.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (1+(N-1)*INCC)
!>          Les cosinus des rotations planes.
!>

S

!>          S est un tableau COMPLEX*16, dimension (1+(N-1)*INCC)
!>          Les sinus des rotations planes.
!>

INCC

!>          INCC est un entier
!>          L'incrément entre les éléments de C et S. INCC > 0.
!>
