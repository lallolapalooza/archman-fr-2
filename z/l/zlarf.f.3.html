SRC/zlarf.f

SYNOPSIS

Fonctions/Sous-routines


sous-routine zlarf (side, m, n, v, incv, tau, c, ldc, work)
ZLARF applique un réflecteur élémentaire à une matrice rectangulaire générale.

Documentation de la fonction/sous-routine

sous-routine zlarf (caractère side, entier m, entier n, complexe*16, dimension( * ) v, entier incv, complexe*16 tau, complexe*16, dimension( ldc, * ) c, entier ldc, complexe*16, dimension( * ) work)

ZLARF applique un réflecteur élémentaire complexe H à une matrice complexe M par N, C, soit à gauche, soit à droite. H est représentée sous la forme

       H = I - tau * v * v**H

où tau est un scalaire complexe et v est un vecteur complexe.

Si tau = 0, alors H est considérée comme la matrice identité.

Pour appliquer H**H, fournissez conjg(tau) à la place de tau.

Paramètres

SIDE 
          SIDE est CHARACTER*1
          = 'L': former  H * C
          = 'R': former  C * H

M

          M est INTEGER
          Le nombre de lignes de la matrice C.

N

          N est INTEGER
          Le nombre de colonnes de la matrice C.

V

          V est un tableau COMPLEX*16, de dimension
                     (1 + (M-1)*abs(INCV)) si SIDE = 'L'
                  ou (1 + (N-1)*abs(INCV)) si SIDE = 'R'
          Le vecteur v dans la représentation de H. V n'est pas utilisé si
          TAU = 0.

INCV

          INCV est INTEGER
          L'incrément entre les éléments de v. INCV <> 0.

TAU

          TAU est COMPLEX*16
          La valeur tau dans la représentation de H.

C

          C est un tableau COMPLEX*16, de dimension (LDC,N)
          À l'entrée, la matrice M par N, C.
          À la sortie, C est écrasée par la matrice H * C si SIDE = 'L',
          ou C * H si SIDE = 'R'.

LDC

          LDC est INTEGER
          La dimension principale du tableau C. LDC >= max(1,M).

WORK

          WORK est un tableau COMPLEX*16, de dimension
                         (N) si SIDE = 'L'
                      ou (M) si SIDE = 'R'
