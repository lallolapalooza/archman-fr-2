sous-routine zla_porfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, logical colequ, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, complex*16, dimension( * ) res, double precision, dimension( * ) ayb, complex*16, dimension( * ) dy, complex*16, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

ZLA_PORFSX_EXTENDED améliore la solution calculée d'un système d'équations linéaires pour les matrices symétriques ou hermitiennes définies positives en effectuant un raffinement itératif de précision supplémentaire et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.

Objectif :

!>
!> ZLA_PORFSX_EXTENDED améliore la solution calculée d'un système d'équations linéaires en effectuant un
!> raffinement itératif de précision supplémentaire et fournit des bornes d'erreur et des estimations d'erreur
!> arrière pour la solution.
!> Cette sous-routine est appelée par ZPORFSX pour effectuer le raffinement itératif.
!> En plus de la borne d'erreur normwise, le code fournit une borne d'erreur composante par composante maximale
!> si possible. Voir les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des bornes d'erreur.
!> Notez que cette sous-routine est uniquement responsable de la définition des deuxièmes champs de
!> ERR_BNDS_NORM et ERR_BNDS_COMP.
!>

Paramètres

PREC_TYPE 
!>          PREC_TYPE est INTEGER
!>     Spécifie la précision intermédiaire à utiliser pour le raffinement.
!>     La valeur est définie par ILAPREC(P) où P est un caractère et P
!>          = 'S':  Simple
!>          = 'D':  Double
!>          = 'I':  Indigène
!>          = 'X' ou 'E':  Extra
!>

UPLO

!>          UPLO est CHARACTER*1
!>       = 'U':  Le triangle supérieur de A est stocké ;
!>       = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes de la
!>     matrice B.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>     En entrée, la matrice A de taille N par N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension de tête du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>     Le facteur triangulaire U ou L de la décomposition de Cholesky
!>     A = U**T*U ou A = L*L**T, tel que calculé par ZPOTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension de tête du tableau AF.  LDAF >= max(1,N).
!>

COLEQU

!>          COLEQU est LOGICAL
!>     Si .TRUE. alors l'équilibraison des colonnes a été effectuée sur A avant d'appeler
!>     cette routine. Ceci est nécessaire pour calculer correctement la solution et les bornes d'erreur.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle des colonnes pour A. Si COLEQU = .FALSE., C
!>     n'est pas accédé. Si C est en entrée, chaque élément de C doit être une puissance
!>     du système de représentation pour garantir une solution et des estimations d'erreur fiables.
!>     La mise à l'échelle par des puissances du système de représentation n'entraîne pas d'erreurs
!>     d'arrondi, sauf si le résultat aboutit à un sous-dépassement ou un dépassement. Les erreurs d'arrondi
!>     pendant la mise à l;échelle conduisent à un raffinement avec une matrice qui n'est pas
!>     équivalente à la matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas
!>     être fiables.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>     La matrice des membres de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension de tête du tableau B.  LDB >= max(1,N).
!>

Y

!>          Y est un tableau COMPLEX*16, dimension (LDY,NRHS)
!>     En entrée, la matrice solution X, telle que calculée par ZPOTRS.
!>     En sortie, la matrice solution améliorée Y.
!>

LDY

!>          LDY est INTEGER
!>     La dimension de tête du tableau Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT est un tableau DOUBLE PRECISION, dimension (NRHS)
!>     En sortie, BERR_OUT(j) contient l'erreur arrière relative composante par composante
!>     pour le membre de droite j selon la formule
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     où abs(Z) est la valeur absolue composante par composante de la matrice
!>     ou du vecteur Z. Ceci est calculé par ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS est INTEGER
!>     Détermine quelles bornes d'erreur retourner (voir ERR_BNDS_NORM
!>     et ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 retourner les bornes d'erreur normwise.
!>     Si N_NORMS >= 2 retourner les bornes d'erreur composante par composante.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à l'erreur relative normwise,
!>     qui est définie comme suit :
!>
!>     Erreur relative normwise dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusquà trois informations retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois champs
!>     suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur véritable
!>

NAME

zla_porfsx_extended -

SYNOPSIS

This subroutine is not directly callable by the user.

Module: zla_utilities

Interfaces:

SUBROUTINE ZLA_PORFSX_EXTENDED(
     UPLO, N, NRHS, A, LDA, AFAC, LDAFAC, IPIV, B, LDB, X, LDX,
     ERR_BNDS_NORM, ERR_BNDS_COMP, RES, AYB, DY, Y_TAIL,
     RCOND, ITHRESH, RTHRESH, DZ_UB, IGNORE_CWISE, INFO )

Parameters:

UPLO
CHARACTER*1.

'U' specifies that the upper triangle of A is stored and that A is Hermitian positive definite.

'L' specifies that the lower triangle of A is stored and that A is Hermitian positive definite.

N
INTEGER.

The order of the matrix A. N >= 0.

NRHS
INTEGER.

The number of right hand sides, i.e., the number of columns of the matrices B, X, and Y. NRHS >= 0.

A
COMPLEX*16 array, dimension (LDA,N).

The coefficient matrix A of size N x N.

LDA
INTEGER.

The leading dimension of the array A. LDA >= max(1,N).

AFAC
COMPLEX*16 array, dimension (LDAFAC,N).

The factorization of A, computed by ZPOTRF.

LDAFAC
INTEGER.

The leading dimension of the array AFAC. LDAFAC >= max(1,N).

IPIV
INTEGER array, dimension (N).

The pivot indices of the factorization. Only relevant if the factorization is not a Cholesky factorization.

B
COMPLEX*16 array, dimension (LDB,NRHS).

The right hand side matrix B of size N x NRHS.

LDB
INTEGER.

The leading dimension of the array B. LDB >= max(1,N).

X
COMPLEX*16 array, dimension (LDX,NRHS).

On entry, the solution matrix X of size N x NRHS. On exit, the refined solution matrix X.

LDX
INTEGER.

The leading dimension of the array X. LDX >= max(1,N).

ERR_BNDS_NORM
DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS).

N_ERR_BNDS is a constant in the subroutine, currently 3.

For each right-hand side, this array contains information about various error bounds and condition numbers corresponding to the normwise relative error, which is defined as follows:

Normwise relative error in the ith solution vector: norm(XTRUE - X) / norm(X)

The array is indexed by the right-hand side i (on which the normwise relative error depends), and the type of error information as described below. If componentwise accuracy is not requested (PARAMS(3) = 0.0), then ERR_BNDS_NORM is not accessed. If N_ERR_BNDS < 3, then at most the first (:,N_ERR_BNDS) entries are returned.

The first index in ERR_BNDS_NORM(i,:) corresponds to the ith right-hand side.

The second index in ERR_BNDS_NORM(:,err) contains the following three fields:

err = 1
boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').
err = 2
error bound: Estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.
err = 3
Reciprocal condition number: Estimated normwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is . These reciprocal condition numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately scaled matrix Z. Let Z = S*A, where S scales each row by a power of the radix so all absolute row sums of Z are approximately 1.

This subroutine is only responsible for setting the second field above. See Lapack Working Note 165 for further details and extra cautions.

ERR_BNDS_COMP
DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS).

N_ERR_BNDS is a constant in the subroutine, currently 3.

For each right-hand side, this array contains information about various error bounds and condition numbers corresponding to the componentwise relative error, which is defined as follows:

Componentwise relative error in the ith solution vector: max_j abs(XTRUE(j,i) - X(j,i)) / abs(X(j,i))

The array is indexed by the right-hand side i (on which the componentwise relative error depends), and the type of error information as described below. There currently are up to three pieces of information returned for each right-hand side. If componentwise accuracy is not requested (PARAMS(3) = 0.0), then ERR_BNDS_COMP is not accessed. If N_ERR_BNDS < 3, then at most the first (:,N_ERR_BNDS) entries are returned.

The first index in ERR_BNDS_COMP(i,:) corresponds to the ith right-hand side.

The second index in ERR_BNDS_COMP(:,err) contains the following three fields:

err = 1
boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').
err = 2
error bound: The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.
err = 3
Reciprocal condition number: Estimated componentwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is . These reciprocal condition numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately scaled matrix Z. Let Z = S*(A*diag(x)), where x is the solution for the current right-hand side and S scales each row of A*diag(x) by a power of the radix so all absolute row sums of Z are approximately 1.

This subroutine is only responsible for setting the second field above. See Lapack Working Note 165 for further details and extra cautions.

RES
COMPLEX*16 array, dimension (N).

Workspace to hold the intermediate residual.

AYB
DOUBLE PRECISION array, dimension (N).

Workspace.

DY
COMPLEX*16 array, dimension (N).

Workspace to hold the intermediate solution.

Y_TAIL
COMPLEX*16 array, dimension (N).

Workspace to hold the trailing bits of the intermediate solution.

RCOND
DOUBLE PRECISION.

Reciprocal scaled condition number. This is an estimate of the reciprocal Skeel condition number of the matrix A after equilibration (if done). If this is less than the machine precision (in particular, if it is zero), the matrix is singular to working precision. Note that the error may still be small even if this number is very small and the matrix appears ill- conditioned.

ITHRESH
INTEGER.

The maximum number of residual computations allowed for refinement. The default is 10. For 'aggressive' set to 100 to permit convergence using approximate factorizations or factorizations other than LU. If the factorization uses a technique other than Gaussian elimination, the guarantees in ERR_BNDS_NORM and ERR_BNDS_COMP may no longer be trustworthy.

RTHRESH
DOUBLE PRECISION.

Determines when to stop refinement if the error estimate stops decreasing. Refinement will stop when the next solution no longer satisfies norm(dx_{i+1}) < RTHRESH * norm(dx_i) where norm(Z) is the infinity norm of Z. RTHRESH satisfies 0 < RTHRESH <= 1. The default value is 0.5. For 'aggressive' set to 0.9 to permit convergence on extremely ill-conditioned matrices. See LAWN 165 for more details.

DZ_UB
DOUBLE PRECISION.

Determines when to start considering componentwise convergence. Componentwise convergence is only considered after each component of the solution Y is stable, which we define as the relative change in each component being less than DZ_UB. The default value is 0.25, requiring the first bit to be stable. See LAWN 165 for more details.

IGNORE_CWISE
LOGICAL.

If .TRUE. then ignore componentwise convergence. Default value is .FALSE..

INFO
INTEGER.

= 0: Successful exit.

< 0: if INFO = -i, the ith argument to ZPOTRS had an illegal value
