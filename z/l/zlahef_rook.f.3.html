Documentation de la fonction/sous-routine

subroutine zlahef_rook (character uplo, integer n, integer nb, integer kb, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( ldw, * ) w, integer ldw, integer info)

Purpose:

!>
!> ZLAHEF_ROOK calcule une factorisation partielle d'une matrice hermitienne
!> complexe A en utilisant la méthode de pivotement diagonal bornée de Bunch-Kaufman ().
!> La factorisation partielle a la forme :
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I      0     )  si UPLO = 'U', ou :
!>       ( 0  U22 ) (  0   D  ) ( U12**H U22**H )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**H L21**H )  si UPLO = 'L'
!>       ( L21  I ) (  0  A22 ) (  0      I     )
!>
!> où l'ordre de D est au maximum NB. L'ordre réel est renvoyé dans
!> l'argument KB, et est soit NB soit NB-1, soit N si N <= NB.
!> Notez que U**H dénote la transposée conjuguée de U.
!>
!> ZLAHEF_ROOK est une routine auxiliaire appelée par ZHETRF_ROOK. Elle utilise
!> du code bloqué (appelant BLAS de niveau 3) pour mettre à jour la sous-matrice
!> A11 (si UPLO = 'U') ou A22 (si UPLO = 'L').
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de
!>          la matrice hermitienne A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NB

!>          NB est INTEGER
!>          Le nombre maximum de colonnes de A qui doivent être
!>          factorisées.  NB doit être au moins 2 pour permettre des blocs
!>          de pivots de 2x2.
!>

KB

!>          KB est INTEGER
!>          Le nombre de colonnes de A qui ont été effectivement factorisées.
!>          KB est soit NB-1, soit NB, soit N si N <= NB.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, A contient les détails de la factorisation partielle.
!>          Si UPLO = 'U', la partie supérieure triangulaire n x n de A contient
!>          la partie supérieure triangulaire de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la
!>          partie inférieure triangulaire n x n de A contient la partie
!>          inférieure triangulaire de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>          À la sortie, A contient les détails de la factorisation partielle.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          Détails des échanges et de la structure des blocs de D.
!>
!>          Si UPLO = 'U':
!>             Seuls les KB derniers éléments de IPIV sont définis.
!>
!>             Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k) ont été
!>             échangées et D(k,k) est un bloc diagonal 1x1.
!>
!>             Si IPIV(k) < 0 et IPIV(k-1) < 0, alors les lignes et
!>             colonnes k et -IPIV(k) ont été échangées et les lignes et
!>             colonnes k-1 et -IPIV(k-1) ont été échangées,
!>             D(k-1:k,k-1:k) est un bloc diagonal 2x2.
!>
!>          Si UPLO = 'L':
!>             Seuls les KB premiers éléments de IPIV sont définis.
!>
!>             Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k)
!>             ont été échangées et D(k,k) est un bloc diagonal 1x1.
!>
!>             Si IPIV(k) < 0 et IPIV(k+1) < 0, alors les lignes et
!>             colonnes k et -IPIV(k) ont été échangées et les lignes et
!>             colonnes k+1 et -IPIV(k+1) ont été échangées,
!>             D(k:k+1,k:k+1) est un bloc diagonal 2x2.
!>

W

!>          W est un tableau COMPLEX*16, de dimension (LDW,NB)
!>

LDW

!>          LDW est INTEGER
!>          La dimension principale du tableau W.  LDW >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0: succès de l'exécution
!>          > 0: si INFO = k, D(k,k) est exactement zéro. La factorisation
!>               a été complétée, mais la matrice diagonale par blocs D est
!>               exactement singulière.
!>
