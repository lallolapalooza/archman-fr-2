sous-routine zlarfgp (integer n, complex*16 alpha, complex*16, dimension( * ) x, integer incx, complex*16 tau)

ZLARFGP génère un réflecteur élémentaire complexe H de taille n, tel que

!>
!> ZLARFGP génère un réflecteur élémentaire complexe H de taille n, tel que
!>
!>       H**H * ( alpha ) = ( beta ),   H**H * H = I.
!>              (   x   )   (   0  )
!>
!> où alpha et beta sont des scalaires, beta est réel et non négatif, et
!> x est un vecteur complexe de (n-1) éléments. H est représenté sous la forme
!>
!>       H = I - tau * ( 1 ) * ( 1 v**H ) ,
!>                     ( v )
!>
!> où tau est un scalaire complexe et v est un vecteur complexe de (n-1)
!> éléments. Notez que H n'est pas hermitien.
!>
!> Si tous les éléments de x sont zéro et alpha est réel, alors tau = 0
!> et H est considéré comme la matrice identité.
!>

Paramètres

N 
!>          N est un ENTIER
!>          La taille du réflecteur élémentaire.
!>

ALPHA

!>          ALPHA est COMPLEX*16
!>          En entrée, la valeur alpha.
!>          En sortie, elle est écrasée par la valeur beta.
!>

X

!>          X est un tableau COMPLEX*16, de dimension
!>                         (1+(N-2)*abs(INCX))
!>          En entrée, le vecteur x.
!>          En sortie, il est écrasé par le vecteur v.
!>

INCX

!>          INCX est un ENTIER
!>          Le pas entre les éléments de X. INCX > 0.
!>

TAU

!>          TAU est COMPLEX*16
!>          La valeur tau.
!>
