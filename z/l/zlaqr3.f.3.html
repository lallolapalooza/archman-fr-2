ZLAQR3 effectue la transformation de similarité unitaire d'une matrice de Hessenberg pour détecter et déflater les valeurs propres entièrement convergentes d'une sous-matrice principale en finale (déflation précoce agressive).

But :

!>
!>    Déflation précoce agressive :
!>
!>    ZLAQR3 accepte en entrée une matrice de Hessenberg supérieure
!>    H et effectue une transformation de similarité unitaire
!>    conçue pour détecter et déflater les valeurs propres entièrement convergentes
!>    d'une sous-matrice principale. En sortie, H a été écrasée par une nouvelle matrice de Hessenberg
!>    qui est une perturbation d'une transformation de similarité unitaire de H.
!>    On espère que la version finale de H aura de nombreuses entrées sous-diagonales nulles.
!>
!>

Paramètres

WANTT 
!>          WANTT est LOGIQUE
!>          Si .VRAI., alors la matrice de Hessenberg H est entièrement mise à jour
!>          afin que le facteur triangulaire de Schur puisse être
!>          calculé (en coopération avec le sous-programme appelant).
!>          Si .FAUX., alors seule une partie suffisante de H est mise à jour pour préserver
!>          les valeurs propres.
!>

WANTZ

!>          WANTZ est LOGIQUE
!>          Si .VRAI., alors la matrice unitaire Z est mise à jour
!>          afin que le facteur de Schur unitaire puisse être
!>          calculé (en coopération avec le sous-programme appelant).
!>          Si .FAUX., alors Z n'est pas référencé.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice H et (si WANTZ est .VRAI.) l'ordre
!>          de la matrice unitaire Z.
!>

KTOP

!>          KTOP est ENTIER
!>          On suppose que KTOP = 1 ou que H(KTOP,KTOP-1)=0.
!>          KBOT et KTOP ensemble déterminent un bloc isolé
!>          le long de la diagonale de la matrice de Hessenberg.
!>

KBOT

!>          KBOT est ENTIER
!>          On suppose sans vérification que soit
!>          KBOT = N soit H(KBOT+1,KBOT)=0. KBOT et KTOP ensemble
!>          déterminent un bloc isolé le long de la diagonale de la
!>          matrice de Hessenberg.
!>

NW

!>          NW est ENTIER
!>          Taille de la fenêtre de déflation. 1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H est un tableau COMPLEX*16, dimension (LDH,N)
!>          En entrée, la section N x N initiale de H stocke la
!>          matrice de Hessenberg subissant une déflation précoce agressive.
!>          En sortie, H a été transformée par une transformation de similarité
!>          unitaire, perturbée, et retournée sous forme de Hessenberg
!>          qui, espérons-le, a quelques entrées sous-diagonales nulles.
!>

LDH

!>          LDH est ENTIER
!>          Dimension principale de H telle que déclarée dans le sous-programme appelant.
!>          N <= LDH
!>

ILOZ

!>          ILOZ est ENTIER
!>

IHIZ

!>          IHIZ est ENTIER
!>          Spécifier les lignes de Z auxquelles les transformations doivent
!>          être appliquées si WANTZ est .VRAI.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ,N)
!>          Si WANTZ est .VRAI., alors en sortie, la transformation de similarité
!>          unitaire mentionnée ci-dessus a été accumulée dans Z(ILOZ:IHIZ,ILOZ:IHIZ)
!>          par la droite.
!>          Si WANTZ est .FAUX., alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est ENTIER
!>          La dimension principale de Z telle que déclarée dans le
!>          sous-programme appelant. 1 <= LDZ.
!>

NS

!>          NS est ENTIER
!>          Le nombre de valeurs propres non convergentes (c'est-à-dire approximatives)
!>          renvoyées dans SR et SI qui peuvent être utilisées comme décalages par le
!>          sous-programme appelant.
!>

ND

!>          ND est ENTIER
!>          Le nombre de valeurs propres convergentes découvertes par ce
!>          sous-programme.
!>

SH

!>          SH est un tableau COMPLEX*16, dimension (KBOT)
!>          En sortie, les valeurs propres approximatives qui peuvent
!>          être utilisées pour les décalages sont stockées dans SH(KBOT-ND-NS+1)
!>          jusqu'à SR(KBOT-ND). Les valeurs propres convergentes sont
!>          stockées dans SH(KBOT-ND+1) jusqu'à SH(KBOT).
!>

V

!>          V est un tableau COMPLEX*16, dimension (LDV,NW)
!>          Un tableau de travail NW x NW.
!>

LDV

!>          LDV est ENTIER
!>          La dimension principale de V telle que déclarée dans le
!>          sous-programme appelant. NW <= LDV
!>

NH

!>          NH est ENTIER
!>          Le nombre de colonnes de T. NH >= NW.
!>

T

!>          T est un tableau COMPLEX*16, dimension (LDT,NW)
!>

LDT

!>          LDT est ENTIER
!>          La dimension principale de T telle que déclarée dans le
!>          sous-programme appelant. NW <= LDT
!>

NV

!>          NV est ENTIER
!>          Le nombre de lignes du tableau de travail WV disponibles pour
!>          l'espace de travail. NV >= NW.
!>

WV

!>          WV est un tableau COMPLEX*16, dimension (LDWV,NW)
!>

LDWV

!>          LDWV est ENTIER
!>          La dimension principale de W telle que déclarée dans le
!>          sous-programme appelant. NW <= LDV
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>          À la sortie, WORK(1) est défini avec une estimation de la valeur optimale
!>          de LWORK pour les valeurs données de N, NW, KTOP et KBOT.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau de travail WORK. LWORK = 2*NW
!>          suffit, mais une plus grande efficacité peut résulter de valeurs
!>          plus grandes de LWORK.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; ZLAQR3
!>          estime seulement la taille optimale de l'espace de travail pour les
!>          valeurs données de N, NW, KTOP et KBOT. L'estimation est renvoyée
!>          dans WORK(1). Aucun message d'erreur lié à LWORK n'est émis
!>          par XERBLA. Ni H ni Z ne sont accédés.
!>

  This subroutine is the implementation of the second variation of the
  implicit double shift QR algorithm for the solution of the
  eigenvalue problem Z A Q = T, where A is a general n x n matrix.
  
  The algorithm is described in "Eigenvalue Algorithms" by J. K.
  Fletcher, D. J. Higham and G. A. Heath (1987), and "A new approach
  to the single shift implicit QR algorithm" by J. K. Fletcher and G. A.
  Heath (1988).
  
  The function is called by ZLACPY to compute the Schur decomposition of
  a general matrix A.
  
  The input matrix A is overwritten by the Schur matrix T.
  
  Arguments:
  
  WANTT (input) logical
  = True.  Compute the Schur matrix T.
  = False. Do not compute the form T.
  
  WANTZ (input) logical
  = True.  Compute the Schur vectors Z.
  = False. Do not compute the Schur vectors Z.
  
  N (input) integer
  The order of the matrix A.  N >= 0.
  
  KNT (input) integer
  The number of columns of A to be considered.  0 <= KNT <= N.
  
  NP (input) integer
  The number of columns of A to be factored.  0 <= NP <= KNT.
  
  Q (output) complex*16 array, dimension (LDQ,N)
  If WANTZ = .True., Q contains the orthogonal matrix Z.
  
  LDQ (input) integer
  The leading dimension of the array Q.  LDQ >= max(1,N).
  
  R (output) complex*16 array, dimension (LDR,N)
  R contains the upper triangular matrix T.
  
  LDR (input) integer
  The leading dimension of the array R.  LDR >= max(1,N).
  
  K (output) integer
  The number of blocks of size 2x2 for the eigenvalues.
  
  SL (output) complex*16 array, dimension (N)
  SL contains the real part of the eigenvalues.
  
  SR (output) complex*16 array, dimension (N)
  SR contains the imaginary part of the eigenvalues.

  La fonction est appelée par ZLACPY pour calculer la décomposition de Schur
  d'une matrice générale A.
  
  La matrice d'entrée A est écrasée par la matrice de Schur T.
  
  Arguments :
  
  WANTT (entrée) logique
  = Vrai. Calculer la matrice de Schur T.
  = Faux. Ne pas calculer la forme T.
  
  WANTZ (entrée) logique
  = Vrai. Calculer les vecteurs de Schur Z.
  = Faux. Ne pas calculer les vecteurs de Schur Z.
  
  N (entrée) entier
  L'ordre de la matrice A. N >= 0.
  
  KNT (entrée) entier
  Le nombre de colonnes de A à considérer. 0 <= KNT <= N.
  
  NP (entrée) entier
  Le nombre de colonnes de A à factoriser. 0 <= NP <= KNT.
  
  Q (sortie) tableau complexe*16, dimension (LDQ,N)
  Si WANTZ = Vrai, Q contient la matrice orthogonale Z.
  
  LDQ (entrée) entier
  La dimension principale du tableau Q. LDQ >= max(1,N).
  
  R (sortie) tableau complexe*16, dimension (LDR,N)
  R contient la matrice triangulaire supérieure T.
  
  LDR (entrée) entier
  La dimension principale du tableau R. LDR >= max(1,N).
  
  K (sortie) entier
  Le nombre de blocs de taille 2x2 pour les valeurs propres.
  
  SL (sortie) tableau complexe*16, dimension (N)
  SL contient la partie réelle des valeurs propres.
  
  SR (sortie) tableau complexe*16, dimension (N)
  SR contient la partie imaginaire des valeurs propres.
  
  SS (sortie) tableau complexe*16, dimension (N)
  SS contient la partie réelle des valeurs propres.
  
  L (sortie) tableau complexe*16, dimension (N)
  L contient la partie imaginaire des valeurs propres.
  
  S (sortie) tableau complexe*16, dimension (N)
  S contient les valeurs propres.
  
  LLS (sortie) entier
  Le nombre de blocs de taille 1x1 pour les valeurs propres.
  
  NBS (sortie) entier
  Le nombre de blocs de taille 2x2 pour les valeurs propres.
  
  INFO (sortie) entier
  = 0. Sortie réussie.
  < 0. Si INFO = -i, alors le i-ème argument avait une valeur illégale.
  > 0. Si INFO = i, alors la i-ème itération n'a pas convergé.
  
  La définition des variables suivantes est similaire à celles utilisées dans ZLACPY.
  
  SL, SR : SL(j) = REAL(S(j)), SR(j) = IMAG(S(j)) pour j=1..N
  SL, SR : SL(j) = REAL(S(j)), SR(j) = IMAG(S(j)) pour j=1..N
