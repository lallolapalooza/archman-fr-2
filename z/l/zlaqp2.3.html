ZLAQP2 calcule une factorisation QR avec pivotement de colonnes du bloc matrice.

Documentation de la fonction/sous-programme

sous-programme zlaqp2 (entier m, entier n, entier offset, complexe*16, dimension( lda, * ) a, entier lda, entier, dimension( * ) jpvt, complexe*16, dimension( * ) tau, double précision, dimension( * ) vn1, double précision, dimension( * ) vn2, complexe*16, dimension( * ) work)

ZLAQP2 calcule une factorisation QR avec pivotement de colonnes du bloc matrice.

Objectif :

!>
!> ZLAQP2 calcule une factorisation QR avec pivotement de colonnes du
!> bloc A(OFFSET+1:M,1:N).
!> Le bloc A(1:OFFSET,1:N) est pivoté en conséquence, mais pas factorisé.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

OFFSET

!>          OFFSET est ENTIER
!>          Le nombre de lignes de la matrice A qui doivent être pivotées
!>          mais non factorisées. OFFSET >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimensions M-par-N.
!>          À la sortie, le triangle supérieur du bloc A(OFFSET+1:M,1:N) est
!>          le facteur triangulaire obtenu ; les éléments dans le bloc
!>          A(OFFSET+1:M,1:N) sous la diagonale, ainsi que le tableau TAU,
!>          représentent la matrice orthogonale Q comme un produit de
!>          réflecteurs élémentaires. Le bloc A(1:OFFSET,1:N) a été
!>          pivoté en conséquence, mais pas factorisé.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

JPVT

!>          JPVT est un tableau ENTIER, dimension (N)
!>          À l'entrée, si JPVT(i) .ne. 0, la i-ème colonne de A est permutée
!>          à l'avant de A*P (une colonne principale) ; si JPVT(i) = 0,
!>          la i-ème colonne de A est une colonne libre.
!>          À la sortie, si JPVT(i) = k, alors la i-ème colonne de A*P
!>          était la k-ème colonne de A.
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

VN1

!>          VN1 est un tableau DOUBLE PRÉCISION, dimension (N)
!>          Le vecteur avec les normes partielles des colonnes.
!>

VN2

!>          VN2 est un tableau DOUBLE PRÉCISION, dimension (N)
!>          Le vecteur avec les normes exactes des colonnes.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N)
!>
