sous-programme zlatb4 (character*3 path, integer imat, integer m, integer n, character type, integer kl, integer ku, double precision anorm, integer mode, double precision cndnum, character dist)

ZLATB4

But :

!>
!> ZLATB4 définit les paramètres pour le générateur de matrice en fonction du type
!> de matrice à générer.
!>

Paramètres

PATH 
!>          PATH est CHARACTER*3
!>          Le nom du chemin LAPACK.
!>

IMAT

!>          IMAT est INTEGER
!>          Une clé entière décrivant quelle matrice générer pour ce
!>          chemin.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice à générer.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice à générer.
!>

TYPE

!>          TYPE est CHARACTER*1
!>          Le type de matrice à générer :
!>          = 'S' : matrice symétrique
!>          = 'H' : matrice hermitienne
!>          = 'P' : matrice hermitienne définie (semi)positive
!>          = 'N' : matrice non symétrique
!>

KL

!>          KL est INTEGER
!>          La largeur de bande inférieure de la matrice à générer.
!>

KU

!>          KU est INTEGER
!>          La largeur de bande supérieure de la matrice à générer.
!>

ANORM

!>          ANORM est DOUBLE PRECISION
!>          La norme désirée de la matrice à générer. La matrice diagonale
!>          des valeurs singulières ou des valeurs propres est mise à l'échelle par cette
!>          valeur.
!>

MODE

!>          MODE est INTEGER
!>          Une clé indiquant comment choisir le vecteur des valeurs propres.
!>

CNDNUM

!>          CNDNUM est DOUBLE PRECISION
!>          Le nombre de condition désiré.
!>

DIST

!>          DIST est CHARACTER*1
!>          Le type de distribution à utiliser par le générateur de nombres aléatoires.
!>
