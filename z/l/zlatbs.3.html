sous-programme zlatbs (caractère uplo, caractère trans, caractère diag, caractère normin, entier n, entier kd, complexe*16, dimension( ldab, * ) ab, entier ldab, complexe*16, dimension( * ) x, réel double précision scale, réel double précision, dimension( * ) cnorm, entier info)

ZLATBS résout un système d'équations triangulaire à bande.

But :

!>
!> ZLATBS résout l'un des systèmes triangulaires
!>
!>    A * x = s*b,  A**T * x = s*b,  ou  A**H * x = s*b,
!>
!> avec mise à l'échelle pour éviter le débordement, où A est une matrice
!> triangulaire supérieure ou inférieure à bande. Ici A**T dénote la transposée
!> de A, x et b sont des vecteurs à n éléments, et s est un facteur de
!> mise à l'échelle, généralement inférieur ou égal à 1, choisi de sorte que
!> les composantes de x soient inférieures au seuil de débordement. Si le
!> problème non mis à l'échelle ne provoquera pas de débordement, la routine
!> BLAS de niveau 2 ZTBSV est appelée. Si la matrice A est singulière
!> (A(j,j) = 0 pour un certain j), alors s est mis à 0 et une solution non
!> triviale à A*x = 0 est retournée.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  Résoudre A * x = s*b     (Pas de transposée)
!>          = 'T':  Résoudre A**T * x = s*b  (Transposée)
!>          = 'C':  Résoudre A**H * x = s*b  (Conjuguée transposée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

NORMIN

!>          NORMIN est CHARACTER*1
!>          Spécifie si CNORM a été défini ou non.
!>          = 'Y':  CNORM contient les normes des colonnes à l'entrée
!>          = 'N':  CNORM n'est pas défini à l'entrée. À la sortie, les normes
!>                  seront calculées et stockées dans CNORM.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de sous-diagonales ou super-diagonales dans la
!>          matrice triangulaire A.  KD >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, dimension (LDAB,N)
!>          La matrice triangulaire supérieure ou inférieure à bande A,
!>          stockée dans les KD+1 premières lignes du tableau. La j-ième
!>          colonne de A est stockée dans la j-ième colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

X

!>          X est un tableau COMPLEX*16, dimension (N)
!>          À l'entrée, le côté droit b du système triangulaire.
!>          À la sortie, X est écrasé par le vecteur solution x.
!>

SCALE

!>          SCALE est REAL DOUBLE PRÉCISION
!>          Le facteur de mise à l'échelle s pour le système triangulaire
!>             A * x = s*b,  A**T * x = s*b,  ou  A**H * x = s*b.
!>          Si SCALE = 0, la matrice A est singulière ou mal mise à l'échelle,
!>          et le vecteur x est une solution exacte ou approximative de A*x = 0.
!>

CNORM

!>          CNORM est un tableau REAL DOUBLE PRÉCISION, dimension (N)
!>
!>          Si NORMIN = 'Y', CNORM est un argument d'entrée et CNORM(j)
!>          contient la norme de la partie non diagonale de la j-ième colonne
!>          de A. Si TRANS = 'N', CNORM(j) doit être supérieur ou égal à la
!>          norme infinie, et si TRANS = 'T' ou 'C', CNORM(j) doit être
!>          supérieur ou égal à la norme 1.
!>
!>          Si NORMIN = 'N', CNORM est un argument de sortie et CNORM(j)
!>          retourne la norme 1 de la partie non diagonale de la j-ième colonne
!>          de A.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  Sortie réussie
!>          < 0:  si INFO = -k, le k-ième argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!> Une estimation grossière de x est calculée ; si elle est inférieure au
!> débordement, ZTBSV est appelée, sinon, un code spécifique est utilisé qui
!> vérifie les risques de débordement ou de division par zéro à chaque
!> opération.
!>
!> Un schéma par colonne est utilisé pour résoudre A*x = b. L'algorithme de
!> base si A est triangulaire inférieure est
!>
!>       x[1:n] := b[1:n]
!>       pour j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!> Définissons des bornes pour les composantes de x après j itérations de la
!> boucle :
!>     M(j) = borne sur x[1:j]
!>     G(j) = borne sur x[j+1:n]
!> Initialement, soit M(0) = 0 et G(0) = max{x(i), i=1,...,n}.
!>
!> Alors pour l'itération j+1, nous avons
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> où CNORM(j+1) est supérieur ou égal à la norme infinie de la colonne j+1
!> de A, sans compter la diagonale. Donc
!>
!>     G(j) <= G(0) produit ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> et
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) produit ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> Puisque |x(j)| <= M(j), nous utilisons la routine BLAS de niveau 2 ZTBSV si
!> le réciproque du plus grand M(j), j=1,..,n, est plus grand que
!> max(sous-dépassement, 1/dépassement).
!>
!> La borne sur x(j) est également utilisée pour déterminer quand une étape
!> de la méthode par colonne peut être effectuée sans crainte de débordement.
!> Si la borne calculée est supérieure à une grande constante, x est mise à
!> l'échelle pour éviter le débordement, mais si la borne déborde, x est mise
!> à 0, x(j) à 1, et scale à 0, et une solution non triviale de A*x = 0 est trouvée.
!>
!> De même, un schéma par ligne est utilisé pour résoudre A**T *x = b ou
!> A**H *x = b. L'algorithme de base pour A triangulaire supérieure est
!>
!>       pour j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       fin
!>
!> Nous calculons simultanément deux bornes
!>       G(j) = borne sur ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
!>       M(j) = borne sur x(i), 1<=i<=j
!>
!> Les valeurs initiales sont G(0) = 0, M(0) = max{b(i), i=1,..,n}, et nous
!> ajoutons la contrainte G(j) >= G(j-1) et M(j) >= M(j-1) pour j >= 1.
!> Alors la borne sur x(j) est
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * produit ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> et nous pouvons appeler ZTBSV en toute sécurité si 1/M(n) et 1/G(n) sont
!> tous deux supérieurs à max(sous-dépassement, 1/dépassement).
!>

zlatbs(3)

NOM

zlatbs - Résout un système d'équations linéaires unitaire par blocs.

SYNTAXE

SUBROUTINE ZLATBS(
     UPLO, TRANS, DIAG, NOROWS, EQUED, N, NB, NRHS, KD, AB, LDAB, B, LDB, WORK,
     INFO)

CHARACTER(1) UPLO, TRANS, DIAG, EQUED
INTEGER N, NB, NRHS, KD, LDAB, LDB, INFO
COMPLEX(8) AB(LDAB, *), B(LDB, *), WORK(*)
LOGICAL NOROWS

Documentation des fonctions/sous-routines

ZLATBS résout un ou plusieurs des systèmes d'équations linéaires suivants avec une matrice triangulaire par blocs unitaire :

A * X = B ou A^T * X = B ou A^H * X = B

où A est une matrice triangulaire par blocs unitaire, et X et B sont des matrices.

La matrice A est représentée par ses deux bandes supérieures ou inférieures, contenant les éléments des blocs diagonaux et des blocs de bandes adjacents.

Les arguments de la sous-routine sont les suivants :

  • UPLO : Indique si A est triangulaire supérieure ou inférieure. 'U' pour supérieure, 'L' pour inférieure.
  • TRANS : Indique le type de système à résoudre. 'N' pour A, 'T' pour A^T, 'C' pour A^H.
  • DIAG : Indique si les blocs diagonaux sont unitaires. 'U' pour unitaires, 'N' pour non unitaires.
  • NOROWS : Indique si l'option de mise à l'échelle est activée. Vrai si la mise à l'échelle est appliquée.
  • EQUED : Indique si la matrice a été mise à l'échelle. 'Y' si mise à l'échelle, 'N' si non mise à l'échelle.
  • N : La taille de la matrice A (N x N).
  • NB : La taille des blocs.
  • NRHS : Le nombre de colonnes de B, le vecteur second membre.
  • KD : Le nombre de super/sous-diagonales dans A.
  • AB : Matrice (LDAB, K+1) contenant les blocs de A. K = NB.
  • LDAB : La largeur de la mémoire de AB.
  • B : Matrice (LDB, NRHS) contenant le vecteur second membre B.
  • LDB : La largeur de la mémoire de B.
  • WORK : Tableau de travail. La taille dépend des options.
  • INFO : Entier indiquant le succès ou l'échec de l'opération.
