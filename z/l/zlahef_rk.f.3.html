sous-routine zlahef_rk (character uplo, integer n, integer nb, integer kb, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) e, integer, dimension( * ) ipiv, complex*16, dimension( ldw, * ) w, integer ldw, integer info)

ZLAHEF_RK calcule une factorisation partielle d'une matrice complexe Hermitienne indéfinie en utilisant la méthode de pivotage diagonal de Bunch-Kaufman (rook) bornée.

Objectif :

!> ZLAHEF_RK calcule une factorisation partielle d'une matrice complexe
!> Hermitienne A en utilisant la méthode de pivotage diagonal de
!> Bunch-Kaufman (rook) bornée. La factorisation partielle a la forme :
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  si UPLO = 'U', ou :
!>       ( 0  U22 ) (  0   D  ) ( U12**H U22**H )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**H L21**H )  si UPLO = 'L',
!>       ( L21  I ) (  0  A22 ) (  0       I    )
!>
!> où l'ordre de D est au plus NB. L'ordre réel est retourné dans
!> l'argument KB, et est soit NB, soit NB-1, soit N si N <= NB.
!>
!> ZLAHEF_RK est une routine auxiliaire appelée par ZHETRF_RK. Elle utilise
!> du code bloc (appelant BLAS de niveau 3) pour mettre à jour la sous-matrice
!> A11 (si UPLO = 'U') ou A22 (si UPLO = 'L').
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure
!>          de la matrice Hermitienne A est stockée :
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NB

!>          NB est INTEGER
!>          Le nombre maximum de colonnes de la matrice A qui doivent être
!>          factorisées.  NB doit être au moins 2 pour permettre des blocs
!>          de pivot de taille 2x2.
!>

KB

!>          KB est INTEGER
!>          Le nombre de colonnes de A qui ont été effectivement factorisées.
!>          KB est soit NB-1, soit NB, soit N si N <= NB.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, la matrice Hermitienne A.
!>            Si UPLO = 'U' : la partie supérieure triangulaire N x N
!>            de A contient la partie supérieure triangulaire de la matrice A,
!>            et la partie strictement inférieure triangulaire de A n'est pas
!>            référencée.
!>
!>            Si UPLO = 'L' : la partie inférieure triangulaire N x N
!>            de A contient la partie inférieure triangulaire de la matrice A,
!>            et la partie strictement supérieure triangulaire de A n'est pas
!>            référencée.
!>
!>          En sortie, contient :
!>            a) UNIQUEMENT les éléments diagonaux de la matrice bloc diagonale
!>               Hermitienne D sur la diagonale de A, c.-à-d. D(k,k) = A(k,k) ;
!>               (les éléments superdiagonaux (ou sous-diagonaux) de D
!>                sont stockés en sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : le facteur U dans la partie superdiagonale de A.
!>               Si UPLO = 'L' : le facteur L dans la partie sous-diagonale de A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau COMPLEX*16, de dimension (N)
!>          En sortie, contient les éléments superdiagonaux (ou sous-diagonaux)
!>          de la matrice bloc diagonale Hermitienne D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i), i=2:N, E(1) est mis à 0 ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          NOTE : Pour un bloc diagonal de 1x1 D(k), où
!>          1 <= k <= N, l'élément E(k) est mis à 0 dans les deux
!>          cas UPLO = 'U' ou UPLO = 'L'.
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          IPIV décrit la matrice de permutation P dans la factorisation
!>          de la matrice A comme suit. La valeur absolue de IPIV(k)
!>          représente l'indice de la ligne et de la colonne qui ont été
!>          échangées avec la k-ième ligne et colonne. La valeur de UPLO
!>          décrit l'ordre dans lequel les échanges ont été appliqués.
!>          De plus, le signe de IPIV représente la structure de bloc
!>          de la matrice bloc diagonale Hermitienne D avec des blocs
!>          diagonaux de 1x1 ou 2x2 qui correspondent à 1 ou 2 échanges
!>          à chaque étape de factorisation.
!>
!>          Si UPLO = 'U',
!>          ( dans l'ordre de factorisation, k diminue de N à 1 ) :
!>            a) Une seule entrée positive IPIV(k) > 0 signifie :
!>               D(k,k) est un bloc diagonal de 1x1.
!>               Si IPIV(k) != k, les lignes et colonnes k et IPIV(k) ont été
!>               échangées dans la sous-matrice A(1:N,N-KB+1:N) ;
!>               Si IPIV(k) = k, aucun échange n'a eu lieu.
!>
!>
!>            b) Une paire d'entrées négatives consécutives
!>               IPIV(k) < 0 et IPIV(k-1) < 0 signifie :
!>               D(k-1:k,k-1:k) est un bloc diagonal de 2x2.
!>               (NOTE : les entrées négatives dans IPIV apparaissent UNIQUEMENT par paires).
!>               1) Si -IPIV(k) != k, les lignes et colonnes
!>                  k et -IPIV(k) ont été échangées
!>                  dans la matrice A(1:N,N-KB+1:N).
!>                  Si -IPIV(k) = k, aucun échange n'a eu lieu.
!>               2) Si -IPIV(k-1) != k-1, les lignes et colonnes
!>                  k-1 et -IPIV(k-1) ont été échangées
!>                  dans la sous-matrice A(1:N,N-KB+1:N).
!>                  Si -IPIV(k-1) = k-1, aucun échange n'a eu lieu.
!>
!>            c) Dans les deux cas a) et b), on a toujours ABS( IPIV(k) ) <= k.
!>
!>            d) NOTE : Toute entrée IPIV(k) est toujours NON NULLE en sortie.
!>
!>          Si UPLO = 'L',
!>          ( dans l'ordre de factorisation, k augmente de 1 à N ) :
!>            a) Une seule entrée positive IPIV(k) > 0 signifie :
!>               D(k,k) est un bloc diagonal de 1x1.
!>               Si IPIV(k) != k, les lignes et colonnes k et IPIV(k) ont été
!>               échangées dans la sous-matrice A(1:N,1:KB).
!>               Si IPIV(k) = k, aucun échange n'a eu lieu.
!>
!>            b) Une paire d'entrées négatives consécutives
!>               IPIV(k) < 0 et IPIV(k+1) < 0 signifie :
!>               D(k:k+1,k:k+1) est un bloc diagonal de 2x2.
!>               (NOTE : les entrées négatives dans IPIV apparaissent UNIQUEMENT par paires).
!>               1) Si -IPIV(k) != k, les lignes et colonnes
!>                  k et -IPIV(k) ont été échangées
!>                  dans la sous-matrice A(1:N,1:KB).
!>                  Si -IPIV(k) = k, aucun échange n'a eu lieu.
!>               2) Si -IPIV(k+1) != k+1, les lignes et colonnes
!>                  k+1 et -IPIV(k+1) ont été échangées
!>                  dans la sous-matrice A(1:N,1:KB).
!>                  Si -IPIV(k+1) = k+1, aucun échange n'a eu lieu.
!>
!>            c) Dans les deux cas a) et b), on a toujours ABS( IPIV(k) ) >= k.
!>
!>            d) NOTE : Toute entrée IPIV(k) est toujours NON NULLE en sortie.
!>

W

!>          W est un tableau COMPLEX*16, de dimension (LDW,NB)
!>

LDW

!>          LDW est INTEGER
!>          La dimension principale du tableau W.  LDW >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution
!>
!>          < 0 : Si INFO = -k, le k-ième argument avait une valeur illégale
!>
!>          > 0 : Si INFO = k, la matrice A est singulière, car :
!>                 Si UPLO = 'U' : la colonne k dans la partie
!>                 triangulaire supérieure de A contient que des zéros.
!>                 Si UPLO = 'L' : la colonne k dans la partie
!>                 triangulaire inférieure de A contient que des zéros.
!>
!>               Par conséquent D(k,k) est exactement zéro, et les éléments
!>               superdiagonaux de la colonne k de U (ou sous-diagonaux
!>               de la colonne k de L)

zlahef_rk.f(3)

NAME

zlahef_rk — routines to compute the restricted rank characteristics of a general rectangular matrix.

SYNOPSIS

  Subroutine zlahef_rk( a, lda, n, k, tau, w, info )

Parameters:

a
CHARACTER*1. On entry, the elements of A are:
‘U’: Upper triangular
‘L’: Lower triangular
lda
INTEGER. The leading dimension of the array A.
n
INTEGER. The order of the matrix A. The dimensions of A are N x N.
k
INTEGER. The number of blocks for block diagonal matrix D.
tau
COMPLEX*16. Array of dimension (N). This array stores the scalar products needed.
w
COMPLEX*16. Array of dimension (N). This array stores the elements of D.
info
INTEGER.

Info is an integer output parameter and is used as follows:

info = 0: successful exit

info < 0: if info = -i, the i-th argument had an illegal value.

info > 0: if info = i, then D(i,i) is zero. This means that the factorization has been completed, but D is singular (exactly singular). The factorisation is still valid, but division by zero will occur if D is used to solve a system of equations.

NOTE: info only stores the first occurrence of a singularity, any subsequent occurrence of singularity is not stored in info even though the factorization always completes.

Function/Subroutine Documentation

The routine computes the restricted rank characteristics of a general rectangular matrix A.

The factorization is:

A = P D Q

where P and Q are permutation matrices and D is block diagonal with

1 x 1 or 2 x 2 diagonal blocks.

The factorization is computed by applying k steps of rook-based partial pivoting. Specifically, the algorithm proceeds as follows:

  1. For i = 1 to k, find the desired pivot.
    A[i,i] is used as the pivot element.
    Swap rows and columns to bring the pivot element to A[i,i].
    Store the pivot information in tau.
    Compute the Schur complement.
    Update the remaining submatrix.
  2. The diagonal elements of D are stored in W.

The diagonal elements of D are computed in the following way:

If D(i,i) is 1x1, then D(i,i) is set to A(i,i).
If D(i,i) is 2x2, then D(i,i) is set to the determinant of the 2x2 block
of A(i:i+1, i:i+1).

If at any stage the pivot element A(i,i) is zero, then D(i,i) will be zero, and info is set to i.

The factorization is complete when k is reached. However, if any D(i,i) in the diagonal blocks of D is zero, the matrix D is singular.

The computation of the Schur complement is as follows:
Let A be partitioned as:
A = [ A11 A12 ]
[ A21 A22 ]
where A11 is the pivot block (1x1 or 2x2).
The Schur complement is:
S = A22 - A21 * inv(A11) * A12
The algorithm updates A22 in place.
The elements of tau store the scalar factors needed for the updates.
The elements of W store the diagonal blocks of D.
If the pivot is 1x1, then A11 = A(i,i).
If the pivot is 2x2, then A11 = [ A(i,i) A(i,i+1) ]
[ A(i+1,i) A(i+1,i+1) ]
The diagonal of D is computed as follows:
If the pivot is 1x1, D(i,i) = A(i,i).
If the pivot is 2x2, D(i,i) = det(A11).
The value info is set to the first index i for which D(i,i) is zero.
If info is greater than 0, it means that the diagonal block D(i,i) (in lumn k of L ) are all zeros. The factorization has been completed, but the block diagonal matrix D is exactly singular, and division by zero will occur if it is used to solve a system of equations.

NOTE: INFO only stores the first occurrence of a singularity, any subsequent occurrence of singularity is not stored in INFO even though the factorization always completes.
