ZLAQP2RK calcule une factorisation QR tronquée avec pivotement de colonnes d'un bloc de matrice complexe à l'aide de BLAS de niveau 2 et écrase une matrice complexe B de taille m x nrhs par Q**H * B.

Documentation de la fonction/sous-programme

subroutine zlaqp2rk (integer m, integer n, integer nrhs, integer ioffset, integer kmax, double precision abstol, double precision reltol, integer kp1, double precision maxc2nrm, complex*16, dimension( lda, * ) a, integer lda, integer k, double precision maxc2nrmk, double precision relmaxc2nrmk, integer, dimension( * ) jpiv, complex*16, dimension( * ) tau, double precision, dimension( * ) vn1, double precision, dimension( * ) vn2, complex*16, dimension( * ) work, integer info)

ZLAQP2RK calcule une factorisation QR tronquée (rang K) ou de rang complet avec pivotement de colonnes du bloc de matrice complexe A(IOFFSET+1:M,1:N) comme suit :

Objectif :

!>
!> ZLAQP2RK calcule une factorisation QR tronquée (rang K) ou de rang complet avec pivotement de colonnes de la matrice complexe
!> bloc A(IOFFSET+1:M,1:N) comme
!>
!>   A * P(K) = Q(K) * R(K).
!>
!> La routine utilise BLAS de niveau 2. Le bloc A(1:IOFFSET,1:N)
!> est pivoté en conséquence, mais pas factorisé.
!>
!> La routine écrase également les blocs de droite de la matrice B
!> stockés dans A(IOFFSET+1:M,N+1:N+NRHS) par Q(K)**H * B.
!>

Paramètres

M 
!>          M est un INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est un INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de
!>          colonnes de la matrice B. NRHS >= 0.
!>

IOFFSET

!>          IOFFSET est un INTEGER
!>          Le nombre de lignes de la matrice A qui doivent être pivotées
!>          mais non factorisées. IOFFSET >= 0.
!>
!>          IOFFSET représente également le nombre de colonnes de la
!>          matrice originale A_orig qui ont été factorisées
!>          dans les étapes précédentes.
!>

KMAX

!>          KMAX est un INTEGER
!>
!>          Le premier critère d'arrêt de la factorisation. KMAX >= 0.
!>
!>          Le nombre maximum de colonnes de la matrice A à factoriser,
!>          c'est-à-dire le rang de factorisation maximal.
!>
!>          a) Si KMAX >= min(M-IOFFSET,N), alors ce critère d'arrêt
!>                n'est pas utilisé, la factorisation des colonnes
!>                dépend de ABSTOL et RELTOL.
!>
!>          b) Si KMAX = 0, alors ce critère d'arrêt est
!>             satisfait à l'entrée et la routine se termine immédiatement.
!>             Cela signifie que la factorisation n'est pas effectuée,
!>             les matrices A et B ainsi que les tableaux TAU, IPIV
!>             ne sont pas modifiés.
!>

ABSTOL

!>          ABSTOL est un DOUBLE PRECISION, ne peut pas être NaN.
!>
!>          Le second critère d'arrêt de la factorisation.
!>
!>          La tolérance absolue (seuil d'arrêt) pour la
!>          norme 2 maximale des colonnes de la matrice résiduelle.
!>          L'algorithme converge (arrête la factorisation) lorsque
!>          la norme 2 maximale des colonnes de la matrice résiduelle
!>          est inférieure ou égale à ABSTOL.
!>
!>          a) Si ABSTOL < 0.0, alors ce critère d'arrêt n'est pas
!>                utilisé, la routine factorise les colonnes en fonction
!>                de KMAX et RELTOL.
!>                Cela inclut le cas ABSTOL = -Inf.
!>
!>          b) Si 0.0 <= ABSTOL alors la valeur d'entrée
!>                de ABSTOL est utilisée.
!>

RELTOL

!>          RELTOL est un DOUBLE PRECISION, ne peut pas être NaN.
!>
!>          Le troisième critère d'arrêt de la factorisation.
!>
!>          La tolérance (seuil d'arrêt) pour le rapport de la
!>          norme 2 maximale des colonnes de la matrice résiduelle à la
!>          norme 2 maximale des colonnes de la matrice originale A_orig.
!>          L'algorithme converge (arrête la factorisation), lorsque ce
!>          rapport est inférieur ou égal à RELTOL.
!>
!>          a) Si RELTOL < 0.0, alors ce critère d'arrêt n'est pas
!>                utilisé, la routine factorise les colonnes en fonction
!>                de KMAX et ABSTOL.
!>                Cela inclut le cas RELTOL = -Inf.
!>
!>          d) Si 0.0 <= RELTOL alors la valeur d'entrée de RELTOL
!>                est utilisée.
!>

KP1

!>          KP1 est un INTEGER
!>          L'indice de la colonne avec la norme 2 maximale dans
!>          la matrice originale A_orig complète, déterminé dans
!>          la routine principale ZGEQP3RK. 1 <= KP1 <= N_orig_mat.
!>

MAXC2NRM

!>          MAXC2NRM est un DOUBLE PRECISION
!>          La norme 2 maximale des colonnes de la matrice originale
!>          A_orig complète calculée dans la routine principale ZGEQP3RK.
!>          MAXC2NRM >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N+NRHS)
!>          À l'entrée :
!>              la matrice A de taille M x N et la matrice B de taille M x NRHS, comme dans
!>
!>                                  N     NRHS
!>              tableau_A   =   M  [ mat_A, mat_B ]
!>
!>          À la sortie :
!>          1. Les éléments du bloc A(IOFFSET+1:M,1:K) sous
!>             la diagonale, ainsi que le tableau TAU, représentent
!>             la matrice unitaire Q(K) sous forme de produit de réflecteurs élémentaires.
!>          2. Le bloc triangulaire supérieur de la matrice A stocké
!>             dans A(IOFFSET+1:M,1:K) est le facteur triangulaire obtenu.
!>          3. Le bloc de la matrice A stocké dans A(1:IOFFSET,1:N)
!>             a été pivoté en conséquence, mais non factorisé.
!>          4. Le reste du tableau A, bloc A(IOFFSET+1:M,K+1:N+NRHS).
!>             La partie gauche A(IOFFSET+1:M,K+1:N) de ce bloc
!>             contient le résidu de la matrice A et,
!>             si NRHS > 0, la partie droite du bloc
!>             A(IOFFSET+1:M,N+1:N+NRHS) contient le bloc de
!>             la matrice membre de droite B. Ces deux blocs ont été
!>             mis à jour par multiplication à gauche par Q(K)**H.
!>

LDA

!>          LDA est un INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

K

!>          K est un INTEGER
!>          Rang de factorisation de la matrice A, c'est-à-dire le rang
!>          du facteur R, qui est le même que le nombre de lignes non nulles
!>          du facteur R. 0 <= K <= min(M-IOFFSET,KMAX,N).
!>
!>          K représente également le nombre de vecteurs de Householder non nuls.
!>

MAXC2NRMK

!>          MAXC2NRMK est un DOUBLE PRECISION
!>          La norme 2 maximale des colonnes de la matrice résiduelle,
!>          lorsque la factorisation s'est arrêtée au rang K. MAXC2NRMK >= 0.
!>

RELMAXC2NRMK

!>          RELMAXC2NRMK est un DOUBLE PRECISION
!>          Le rapport MAXC2NRMK / MAXC2NRM de la norme 2 maximale des colonnes
!>          de la matrice résiduelle (lorsque la factorisation
!>          s'est arrêtée au rang K) à la norme 2 maximale des colonnes
!>          de la matrice originale A complète. RELMAXC2NRMK >= 0.
!>

JPIV

!>          JPIV est un tableau INTEGER, de dimension (N)
!>          Indices de pivotement des colonnes, pour 1 <= j <= N, la colonne j
!>

zlaqp2rk(3) - LAPACK

NAME

zlaqp2rk — applies a block of two column transformations to an upper trapezoidal matrix.

SYNOPSIS

SUBROUTINE ZLAQP2RK(
      INTEGER M,
      INTEGER N,
      INTEGER K,
      INTEGER I_OFFSET,
      COMPLEX*16 A( M, N ),
      INTEGER LDA,
      INTEGER JPIV( N ),
      COMPLEX*16 TAU( min(M-I_OFFSET,N) ),
      DOUBLE PRECISION VN1( N ),
      DOUBLE PRECISION VN2( N ),
      COMPLEX*16 WORK( N-1 ),
      INTEGER INFO )

Function/Subroutine Documentation

This subroutine is part of the LAPACK routines that compute the QR factorization of a general matrix A with column pivoting.

The routine is called by ZGEQP3 to compute the QR factorization of a general M-by-N matrix A with column pivoting. It is assumed that:

          A(M,N) is partitioned as ( A11 A2 )
                                 ( 0  A22 )
     where A11 is I_OFFSET-by-K upper trapezoidal,
     and A(M,N) is upper trapezoidal with K+1 columns,
     so A2 is I_OFFSET-by-(N-K)
     and A22 is (M-I_OFFSET)-by-(N-K)

The routine ZLAQP2RK applies the block transformations to A from the left to update the submatrix A2.

The elementary reflectors are of the form:

          H = I - tau*v*v'

where tau is a scalar and v is an I_OFFSET-by-1 vector. The matrix H is applied to the submatrix A2.

Parameters

M

M is INTEGER

The number of rows of the matrix A.

N

N is INTEGER

The number of columns of the matrix A.

K

K is INTEGER

The number of columns of the matrix A11.

I_OFFSET

I_OFFSET is INTEGER

The number of rows in the submatrix A11.

A

A is COMPLEX*16 array, dimension (LDA,N)

On entry, the M-by-N matrix A.

On exit, the submatrix A2 is updated.

LDA

LDA is INTEGER

The leading dimension of the array A.

JPIV

JPIV is INTEGER array, dimension (N)

The pivoting information.

On entry, the pivoting columns of the matrix A.

On exit, the pivoting columns of the updated matrix A.

TAU

TAU is COMPLEX*16 array, dimension (min(M-I_OFFSET,N))

The scalar factors of the elementary reflectors.

VN1

VN1 is DOUBLE PRECISION array, dimension (N)

The vector with the partial column norms.

VN2

VN2 is DOUBLE PRECISION array, dimension (N)

The vector with the exact column norms.

WORK

WORK is COMPLEX*16 array, dimension (N-1)

Used in ZLARF1F subroutine to apply an elementary reflector from the left.

INFO

INFO is INTEGER

1) INFO = 0: successful exit.

2) If INFO = j_1, where 1 <= j_1 <= N, then NaN was detected and the routine stops the computation. The j_1-th column of the matrix A or the j_1-th element of array TAU contains the first occurrence of NaN in the factorization step K+1 ( when K columns have been factorized ).

On exit:

K is set to the number of factorized columns without exception.

MAXC2NRMK is set to NaN.

RELMAXC2NRMK is set to NaN.

TAU(K+1:min(M,N)) is not set and contains undefined elements. If j_1=K+1, TAU(K+1) may contain NaN.

3) If INFO = j_2, where N+1 <= j_2 <= 2*N, then no NaN was detected, but +Inf (or -Inf) was detected and the routine continues the computation until completion. The (j_2-N)-th column of the matrix A contains the first occurrence of +Inf (or -Inf) in the factorization step K+1 ( when K columns have been factorized ).
