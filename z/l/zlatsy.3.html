sous-programme zlatsy (caractère uplo, entier n, complexe*16, dimension( ldx, * ) x, entier ldx, entier, dimension( * ) iseed)

ZLATSY

But :

!>
!> ZLATSY génère une matrice de test spéciale pour la factorisation complexe symétrique
!> (indéfinie). Les blocs de pivot de la matrice générée seront dans l'ordre suivant :
!>    bloc de pivot 2x2, non diagonalisable
!>    bloc de pivot 1x1
!>    bloc de pivot 2x2, diagonalisable
!>    (le cycle se répète)
!> Un échange de ligne est requis pour chaque bloc 2x2 non diagonalisable.
!>

Paramètres

UPLO 
!>          UPLO est CARACTÈRE
!>          Spécifie si la matrice générée doit être triangulaire supérieure ou
!>          inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est ENTIER
!>          La dimension de la matrice à générer.
!>

X

!>          X est un tableau COMPLEXE*16, de dimension (LDX,N)
!>          La matrice générée, composée de blocs diagonaux 3x3 et 2x2 qui résultent
!>          en la séquence de pivot donnée ci-dessus.
!>          La matrice en dehors de ces blocs diagonaux est nulle.
!>

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X.
!>

ISEED

!>          ISEED est un tableau ENTIER, de dimension (4)
!>          En entrée, la graine pour le générateur de nombres aléatoires. Le dernier
!>          des quatre entiers doit être impair. (modifié en sortie)
!>
