subroutine zlarfx (side, m, n, v, tau, c, ldc, work)
ZLARFX applique un réflecteur élémentaire à une matrice rectangulaire générale, avec déroulement de boucle lorsque le réflecteur a un ordre ≤ 10.

Documentation de la fonction/sous-programme

sous-programme zlarfx (caractère side, entier m, entier n, complexe*16, dimension( * ) v, complexe*16 tau, complexe*16, dimension( ldc, * ) c, entier ldc, complexe*16, dimension( * ) work)

ZLARFX applique un réflecteur élémentaire complexe H à une matrice complexe m par n C, par la gauche ou par la droite. H est représentée sous la forme


       H = I - tau * v * v**H

où tau est un scalaire complexe et v est un vecteur complexe.

Si tau = 0, alors H est prise comme étant la matrice unité.

Cette version utilise du code en ligne si H a un ordre < 11.

Objectif :

!>
!> ZLARFX applique un réflecteur élémentaire complexe H à une matrice m par n
!> complexe C, par la gauche ou par la droite. H est représentée sous la forme
!>
!>       H = I - tau * v * v**H
!>
!> où tau est un scalaire complexe et v est un vecteur complexe.
!>
!> Si tau = 0, alors H est prise comme étant la matrice unité.
!>
!> Cette version utilise du code en ligne si H a un ordre < 11.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': forme  H * C
!>          = 'R': forme  C * H
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

V

!>          V est tableau COMPLEX*16, dimension (M) si SIDE = 'L'
!>                                        ou (N) si SIDE = 'R'
!>          Le vecteur v dans la représentation de H.
!>

TAU

!>          TAU est COMPLEX*16
!>          La valeur tau dans la représentation de H.
!>

C

!>          C est tableau COMPLEX*16, dimension (LDC,N)
!>          En entrée, la matrice m par n C.
!>          En sortie, C est écrasée par la matrice H * C si SIDE = 'L',
!>          ou C * H si SIDE = 'R'.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est tableau COMPLEX*16, dimension (N) si SIDE = 'L'
!>                                            ou (M) si SIDE = 'R'
!>          WORK n'est pas référencé si H a un ordre < 11.
!>
