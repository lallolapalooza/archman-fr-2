subroutine zlaqp3rk (integer m, integer n, integer nrhs, integer ioffset, integer nb, double precision abstol, double precision reltol, integer kp1, double precision maxc2nrm, complex*16, dimension( lda, * ) a, integer lda, logical done, integer kb, double precision maxc2nrmk, double precision relmaxc2nrmk, integer, dimension( * ) jpiv, complex*16, dimension( * ) tau, double precision, dimension( * ) vn1, double precision, dimension( * ) vn2, complex*16, dimension( * ) auxv, complex*16, dimension( ldf, * ) f, integer ldf, integer, dimension( * ) iwork, integer info)

ZLAQP3RK calcule une étape de factorisation QR tronquée avec pivotement de colonne d'une matrice complexe m-par-n A, bloc A(IOFFSET+1:M,1:N), en utilisant les BLAS de niveau 3 sous la forme :

A * P(KB) = Q(KB) * R(KB).

La routine tente de factoriser NB colonnes à partir de A en commençant à la ligne IOFFSET+1 et met à jour la matrice résiduelle avec BLAS 3 xGEMM. Le nombre de colonnes effectivement factorisées est inférieur à NB.

Le bloc A(1:IOFFSET,1:N) est pivoté en conséquence, mais pas factorisé.

La routine écrase également les côtés droits de la matrice B stockée dans A(IOFFSET+1:M,1:N+1:N+NRHS) avec Q(KB)**H * B.

Cas où le nombre de colonnes factorisées KB < NB :

(1) Dans certains cas, en raison d'annulations catastrophiques, il ne peut pas factoriser les NB colonnes et doit mettre à jour la matrice résiduelle. Par conséquent, le nombre réel de colonnes factorisées dans le bloc retourné dans KB est inférieur à NB. La variable logique DONE est retournée comme FAUX. La factorisation de la matrice originale A_orig doit se poursuivre avec le bloc suivant.

(2) Chaque fois que le critère d'arrêt ABSTOL ou RELTOL est satisfait, la factorisation de la matrice originale A_orig s'arrête, la variable logique DONE est retournée comme VRAI. Le nombre de colonnes factorisées, qui est inférieur à NB, est retourné dans KB.

(3) Si les deux critères d'arrêt ABSTOL ou RELTOL ne sont pas utilisés, et lorsque la matrice résiduelle est une matrice nulle à une étape de factorisation KB, la factorisation de la matrice originale A_orig s'arrête, la variable logique DONE est retournée comme VRAI. Le nombre de colonnes factorisées, qui est inférieur à NB, est retourné dans KB.

(4) Chaque fois qu'une valeur NaN (Not a Number) est détectée dans la matrice A ou dans le tableau TAU, la factorisation de la matrice originale A_orig s'arrête, la variable logique DONE est retournée comme VRAI. Le nombre de colonnes factorisées, qui est inférieur à NB, est retourné dans KB. Le paramètre INFO est défini à l'indice de la colonne de la première occurrence de NaN.

NOM

ZLAQP3RK - Mises à jour de rang K des blocs de matrices unitaires complexes.

SYNTAXIS

 CALL ZLAQP3RK( M, N, K, NB, A, LDA, B, LDB, C, LDC, X, Y, JPIV, SCALE, V, T, D, SD, SWAP, WORK, IWORK, INFO )

DESCRIPTION

ZLAQP3RK implémente les mises à jour de rang K des blocs de matrices unitaires.

Cette routine est appelée par ZLAQP3.

ZLAQP3RK effectue l'opération suivante:

   [ A ] = [ I   0 ] [ I   0 ] [ A ] [ V ]
   [ B ]   [ 0   I ]   [ 0   V ]   [ B ] [ X ]

où:

  • ( 1, 1 ) bloc de A est de taille ( M, N )
  • ( 2, 1 ) bloc de B est de taille ( N, N )
  • V est une matrice unitaire de taille ( N, K )
  • X est une matrice de taille ( K, N )
  • Y est une matrice de taille ( K, K )
  • D est une matrice de taille ( K, K )
  • T est une matrice de taille ( K, K )

En plus, les matrices B et X sont mises à jour par multiplication par la gauche par Q( KB )**H.

Les matrices B et X sont toutes deux mises à jour par multiplication par la gauche par Q( KB )**H.

PARAMETRES

M

M est INTEGER

Le nombre de lignes de la matrice A.

N

N est INTEGER

Le nombre de colonnes de la matrice A.

K

K est INTEGER

Le rang de mise à jour. 0 <= K <= min( M, N ).

NB

NB est INTEGER

La taille du bloc.

A

A est COMPLEX*16, de dimension ( LDA, N )

Sur l'entrée, la matrice A de taille ( M, N ) qui sera mise à jour.

Sur la sortie, la matrice A est mise à jour par l'application des vecteurs de Householder.

LDA

LDA est INTEGER

La dimension principale du tableau A. LDA >= max( 1, M ).

B

B est COMPLEX*16, de dimension ( LDB, N )

Sur l'entrée, la matrice B de taille ( N, N ) qui sera mise à jour.

Sur la sortie, B est mise à jour par l'application des vecteurs de Householder.

LDB

LDB est INTEGER

La dimension principale du tableau B. LDB >= max( 1, N ).

C

C est COMPLEX*16, de dimension ( LDC, NB )

Sur l'entrée, la matrice C.

Sur la sortie, la matrice C est mise à jour par l'application des vecteurs de Householder.

LDC

LDC est INTEGER

La dimension principale du tableau C. LDC >= max( 1, M ).

X

X est COMPLEX*16, de dimension ( NB, N )

Sur l'entrée, le tableau X.

Sur la sortie, le tableau X est mis à jour par l'application des vecteurs de Householder.

Y

Y est COMPLEX*16, de dimension ( NB, NB )

Sur l'entrée, le tableau Y.

Sur la sortie, le tableau Y est mis à jour par l'application des vecteurs de Householder.

JPIV

JPIV est INTEGER, de dimension ( N )

Sur l'entrée, les indices de pivot de colonne.

Sur la sortie, JPIV est mis à jour par l'application des opérations de pivot.

SCALE

SCALE est DOUBLE PRECISION

Sur l'entrée, le facteur de mise à l'échelle.

Sur la sortie, SCALE est mis à jour.

V

V est COMPLEX*16, de dimension ( NB, NB )

Sur l'entrée, le tableau V.

Sur la sortie, le tableau V est mis à jour.

T

T est COMPLEX*16, de dimension ( NB, NB )

Sur l'entrée, le tableau T.

Sur la sortie, le tableau T est mis à jour.

D

D est COMPLEX*16, de dimension ( NB, NB )

Sur l'entrée, le tableau D.

Sur la sortie, le tableau D est mis à jour.

SD

SD est COMPLEX*16, de dimension ( NB )

Sur l'entrée, le tableau SD.

Sur la sortie, le tableau SD est mis à jour.

SWAP

SWAP est INTEGER, de dimension ( NB )

Sur l'entrée, le tableau SWAP.

Sur la sortie, le tableau SWAP est mis à jour.

WORK

WORK est COMPLEX*16, de dimension ( NB )

Tableau de travail.

IWORK

IWORK est INTEGER, de dimension ( NB )

Tableau de travail.

INFO

INFO est INTEGER

INFO = 0: succès.

INFO < 0: si INFO = -i, le i-ème argument avait une valeur illégale.

INFO > 0: un problème est survenu lors de la factorisation.
