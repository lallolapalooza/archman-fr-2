sous-routine zlacon (integer n, complex*16, dimension( n ) v, complex*16, dimension( n ) x, double precision est, integer kase)

ZLACON estime la norme 1 d'une matrice carrée complexe, en utilisant la communication inverse pour évaluer les produits matrice-vecteur.

Objectif :

!>
!> ZLACON estime la norme 1 d'une matrice carrée complexe A.
!> La communication inverse est utilisée pour évaluer les produits matrice-vecteur.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>         L'ordre de la matrice.  N >= 1.
!>

V

!>          V est un tableau de type COMPLEX*16, de dimension (N)
!>         Lors du retour final, V = A*W,  où  EST = norm(V)/norm(W)
!>         (W n'est pas retourné).
!>

X

!>          X est un tableau de type COMPLEX*16, de dimension (N)
!>         Lors d'un retour intermédiaire, X doit être écrasé par
!>               A * X,   si KASE=1,
!>               A**H * X,  si KASE=2,
!>         où A**H est la transposée conjuguée de A, et ZLACON doit être
!>         rappelé avec tous les autres paramètres inchangés.
!>

EST

!>          EST est de type DOUBLE PRECISION
!>         À l'entrée avec KASE = 1 ou 2 et JUMP = 3, EST doit être
!>         inchangé par rapport à l'appel précédent à ZLACON.
!>         À la sortie, EST est une estimation (une borne inférieure) de norm(A).
!>

KASE

!>          KASE est un entier (INTEGER)
!>         Lors de l'appel initial à ZLACON, KASE doit être 0.
!>         Lors d'un retour intermédiaire, KASE sera 1 ou 2, indiquant
!>         si X doit être écrasé par A * X  ou A**H * X.
!>         Lors du retour final de ZLACON, KASE sera à nouveau 0.
!>
