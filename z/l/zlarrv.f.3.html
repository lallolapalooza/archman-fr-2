subroutine zlarrv (n, vl, vu, d, l, pivmin, isplit, m, dol, dou, minrgp, rtol1, rtol2, w, werr, wgap, iblock, indexw, gers, z, ldz, isuppz, work, iwork, info)
ZLARRV calcule les vecteurs propres de la matrice tridiagonale T = L D LT étant donné L, D et les valeurs propres de L D LT.

Documentation de la fonction/sous-programme

sous-routine zlarrv (integer n, double precision vl, double precision vu, double precision, dimension( * ) d, double precision, dimension( * ) l, double precision pivmin, integer, dimension( * ) isplit, integer m, integer dol, integer dou, double precision minrgp, double precision rtol1, double precision rtol2, double precision, dimension( * ) w, double precision, dimension( * ) werr, double precision, dimension( * ) wgap, integer, dimension( * ) iblock, integer, dimension( * ) indexw, double precision, dimension( * ) gers, complex*16, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

ZLARRV calcule les vecteurs propres de la matrice tridiagonale T = L D LT étant donné L, D et des APPROXIMATIONS des valeurs propres de L D LT. Les valeurs propres d'entrée doivent avoir été calculées par DLARRE.

Objectif :

!>
!> ZLARRV calcule les vecteurs propres de la matrice tridiagonale
!> T = L D L**T étant donné L, D et des APPROXIMATIONS des valeurs propres de L D L**T.
!> Les valeurs propres d'entrée doivent avoir été calculées par DLARRE.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice.  N >= 0.
!>

VL

!>          VL est un DOUBLE PRECISION
!>          Borne inférieure de l'intervalle qui contient les valeurs propres
!>          désirées. VL < VU. Nécessaire pour calculer les écarts à l'extrémité
!>          gauche ou droite des valeurs propres extrêmes dans la PLAGE désirée.
!>

VU

!>          VU est un DOUBLE PRECISION
!>          Borne supérieure de l'intervalle qui contient les valeurs propres
!>          désirées. VL < VU. Nécessaire pour calculer les écarts à l'extrémité
!>          gauche ou droite des valeurs propres extrêmes dans la PLAGE désirée.
!>

D

!>          D est un tableau de DOUBLE PRECISION, dimension (N)
!>          À l'entrée, les N éléments diagonaux de la matrice diagonale D.
!>          À la sortie, D peut être écrasé.
!>

L

!>          L est un tableau de DOUBLE PRECISION, dimension (N)
!>          À l'entrée, les (N-1) éléments sous-diagonaux de la matrice
!>          bidiagonale unitaire L sont dans les éléments 1 à N-1 de L
!>          (si la matrice n'est pas divisée). À la fin de chaque bloc
!>          est stocké le décalage correspondant donné par DLARRE.
!>          À la sortie, L est écrasé.
!>

PIVMIN

!>          PIVMIN est un DOUBLE PRECISION
!>          Le pivot minimum autorisé dans la séquence de Sturm.
!>

ISPLIT

!>          ISPLIT est un tableau de ENTIER, dimension (N)
!>          Les points de division, où T se décompose en blocs.
!>          Le premier bloc comprend les lignes/colonnes 1 à
!>          ISPLIT( 1 ), le second les lignes/colonnes ISPLIT( 1 )+1
!>          jusqu'à ISPLIT( 2 ), etc.
!>

M

!>          M est un ENTIER
!>          Le nombre total de valeurs propres fournies.  0 <= M <= N.
!>

DOL

!>          DOL est un ENTIER
!>

DOU

!>          DOU est un ENTIER
!>          Si l'utilisateur souhaite calculer uniquement des vecteurs propres sélectionnés parmi toutes
!>          les valeurs propres fournies, il peut spécifier une plage d'indices DOL:DOU.
!>          Sinon, le réglage DOL=1, DOU=M doit être appliqué.
!>          Notez que DOL et DOU font référence à l'ordre dans lequel les valeurs propres
!>          sont stockées dans W.
!>          Si l'utilisateur souhaite calculer uniquement des paires propres sélectionnées, alors
!>          les colonnes DOL-1 à DOU+1 de l'espace de vecteurs propres Z contiennent les
!>          vecteurs propres calculés. Toutes les autres colonnes de Z sont mises à zéro.
!>

MINRGP

!>          MINRGP est un DOUBLE PRECISION
!>

RTOL1

!>          RTOL1 est un DOUBLE PRECISION
!>

RTOL2

!>          RTOL2 est un DOUBLE PRECISION
!>           Paramètres pour la méthode de dichotomie.
!>           Un intervalle [GAUCHE,DROITE] a convergé si
!>           DROITE-GAUCHE < MAX( RTOL1*ECART, RTOL2*MAX(|GAUCHE|,|DROITE|) )
!>

W

!>          W est un tableau de DOUBLE PRECISION, dimension (N)
!>          Les M premiers éléments de W contiennent les valeurs propres APPROXIMATIVES
!>          pour lesquelles les vecteurs propres doivent être calculés. Les valeurs propres
!>          doivent être groupées par bloc détaché et ordonnées de la plus petite à la plus grande
!>          au sein du bloc (Le tableau de sortie
!>          W de DLARRE est attendu ici). De plus, elles sont relatives
!>          au décalage de la représentation de racine correspondante
!>          pour leur bloc. À la sortie, W contient les valeurs propres de la
!>          matrice NON DÉCALÉE.
!>

WERR

!>          WERR est un tableau de DOUBLE PRECISION, dimension (N)
!>          Les M premiers éléments contiennent la demi-largeur de l'intervalle d'incertitude
!>          de la valeur propre correspondante dans W.
!>

WGAP

!>          WGAP est un tableau de DOUBLE PRECISION, dimension (N)
!>          La séparation de la valeur propre voisine de droite dans W.
!>

IBLOCK

!>          IBLOCK est un tableau de ENTIER, dimension (N)
!>          Les indices des blocs (sous-matrices) associés aux
!>          valeurs propres correspondantes dans W ; IBLOCK(i)=1 si la valeur propre
!>          W(i) appartient au premier bloc par le haut, =2 si W(i)
!>          appartient au deuxième bloc, etc.
!>

INDEXW

!>          INDEXW est un tableau de ENTIER, dimension (N)
!>          Les indices des valeurs propres au sein de chaque bloc (sous-matrice) ;
!>          par exemple, INDEXW(i)= 10 et IBLOCK(i)=2 impliquent que la
!>          i-ème valeur propre W(i) est la 10-ème valeur propre du deuxième bloc.
!>

GERS

!>          GERS est un tableau de DOUBLE PRECISION, dimension (2*N)
!>          Les N intervalles de Gerschgorin (le i-ème intervalle
!>          de Gerschgorin est (GERS(2*i-1), GERS(2*i)). Les intervalles de Gerschgorin doivent
!>          être calculés à partir de la matrice NON DÉCALÉE d'origine.
!>

Z

!>          Z est un tableau de COMPLEX*16, dimension (LDZ, max(1,M) )
!>          Si INFO = 0, les M premières colonnes de Z contiennent les
!>          vecteurs propres orthonormés de la matrice T
!>          correspondant aux valeurs propres d'entrée, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z.
!>

LDZ

!>          LDZ est un ENTIER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ est un tableau de ENTIER, dimension ( 2*max(1,M) )
!>          Le support des vecteurs propres dans Z, c'est-à-dire les indices
!>          indiquant les éléments non nuls dans Z. Le I-ème vecteur propre
!>          n'est non nul que dans les éléments ISUPPZ( 2*I-1
 ) à travers
!>          ISUPPZ( 2*I ).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (12*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (7*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>
!>          > 0 :  Un problème est survenu dans ZLARRV.
!>          < 0 :  Une des sous-routines appelées a signalé un problème interne.
!>                Nécessite une inspection du paramètre IINFO correspondant
!>                pour plus d'informations.
!>
!>          =-1 :  Problème dans DLARRB lors du raffinement des valeurs propres d'un enfant.
!>          =-2 :  Problème dans DLARRF lors du calcul du RRR d'un enfant.
!>                Lorsqu'un enfant est à l'intérieur d'un cluster serré, il peut être difficile
!>                de trouver un RRR. Un remède partiel du point de vue de l'utilisateur est de rendre le paramètre MINRGP plus petit et de recompiler.
!>                Cependant, comme l'orthogonalité des vecteurs calculés est
!>                proportionnelle à 1/MINRGP, l'utilisateur doit être conscient qu'il pourrait sacrifier la précision en diminuant MINRGP.
!>          =-3 :  Problème dans DLARRB lors du raffinement d'une seule valeur propre
!>                après que la correction de Rayleigh a été rejetée.
!>          = 5 :  L'itération du quotient de Rayleigh n'a pas convergé vers la
!>                pleine précision en MAXITR étapes.
!>
