sous-programme zlattr (entier imat, caractère uplo, caractère trans, caractère diag, entier, dimension( 4 ) iseed, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) b, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier info)

ZLATTR

But :

!>
!> ZLATTR génère une matrice de test triangulaire en stockage bidimensionnel.
!> IMAT et UPLO spécifient de manière unique les propriétés de la matrice de test,
!> qui est renvoyée dans le tableau A.
!>

Paramètres

IMAT 
!>          IMAT est ENTIER
!>          Une clé entière décrivant quelle matrice générer pour ce
!>          chemin.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          Spécifie si la matrice A sera triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CARACTERE*1
!>          Spécifie si la matrice ou sa transposée sera utilisée.
!>          = 'N':  Pas de transposée
!>          = 'T':  Transposée
!>          = 'C':  Transposée conjuguée
!>

DIAG

!>          DIAG est CARACTERE*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

ISEED

!>          ISEED est tableau ENTIER, dimension (4)
!>          Le vecteur de départ pour le générateur de nombres aléatoires (utilisé dans
!>          ZLATMS).  Modifié à la sortie.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice à générer.
!>

A

!>          A est tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie supérieure
!>          triangulaire N x N de tête du tableau A contient la matrice
!>          triangulaire supérieure, et la partie strictement triangulaire
!>          inférieure de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          inférieure triangulaire N x N de tête du tableau A contient la matrice
!>          triangulaire inférieure et la partie strictement triangulaire
!>          supérieure de A n'est pas référencée.
!>

LDA

!>          LDA est ENTIER
!>          La dimension de tête du tableau A.  LDA >= max(1,N).
!>

B

!>          B est tableau COMPLEX*16, dimension (N)
!>          Le vecteur de droite, si IMAT > 10.
!>

WORK

!>          WORK est tableau COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK est tableau DOUBLE PRÉCISION, dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
