sous-programme zlaunhr_col_getrfnp (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) d, integer info)

ZLAUNHR_COL_GETRFNP

But:

!>
!> ZLAUNHR_COL_GETRFNP calcule la factorisation LU modifiée sans
!> pivotement d'une matrice complexe générale M par N, A. La factorisation a la forme:
!>
!>     A - S = L * U,
!>
!> où:
!>    S est une matrice de signe diagonale M par N avec la diagonale D, de sorte que
!>    D(i) = S(i,i), 1 <= i <= min(M,N). La diagonale D est construite
!>    comme D(i)=-SIGN(A(i,i)), où A(i,i) est la valeur après avoir effectué
!>    i-1 étapes d'élimination gaussienne. Cela signifie que l'élément diagonal
!>    à chaque étape d'élimination gaussienne
!>    a une valeur absolue d'au moins un (de sorte que la division par zéro n'est pas
!>    possible pendant la division par l'élément diagonal) ;
!>
!>    L est une matrice triangulaire inférieure M par N avec des éléments diagonaux unitaires
!>    (trapézoïdale inférieure si M > N) ;
!>
!>    et U est une matrice triangulaire supérieure M par N
!>    (trapézoïdale supérieure si M < N).
!>
!> Cette routine est une routine auxiliaire utilisée dans la routine de reconstruction de Householder
!> ZUNHR_COL. Dans ZUNHR_COL, cette routine est
!> appliquée à une matrice A de M par N avec des colonnes orthonormées, où chaque
!> élément est borné par un en valeur absolue. Avec le choix de
!> la matrice S ci-dessus, on peut montrer que l'élément diagonal à chaque
!> étape d'élimination gaussienne est le plus grand (en valeur absolue) dans
!> la colonne sur ou sous la diagonale, de sorte qu'aucun pivotement n'est requis
!> pour la stabilité numérique [1].
!>
!> Pour plus de détails sur l'algorithme de reconstruction de Householder,
!> y compris la factorisation LU modifiée, voir [1].
!>
!> C'est la version bloc de droite (right-looking) de l'algorithme,
!> appelant le BLAS de niveau 3 pour mettre à jour la sous-matrice. Pour factoriser un bloc,
!> cette routine appelle la routine récursive ZLAUNHR_COL_GETRFNP2.
!>
!> [1] ,
!>     G. Ballard, J. Demmel, L. Grigori, M. Jacquelin, H.D. Nguyen,
!>     E. Solomonik, J. Parallel Distrib. Comput.,
!>     vol. 85, pp. 3-31, 2015.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

A

!>          A est tableau COMPLEX*16, dimension (LDA,N)
!>          En entrée, la matrice M par N à factoriser.
!>          En sortie, les facteurs L et U de la factorisation
!>          A-S=L*U ; les éléments diagonaux unitaires de L ne sont pas stockés.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

D

!>          D est tableau COMPLEX*16, dimension min(M,N)
!>          Les éléments diagonaux de la matrice de signe diagonale M par N, S,
!>          D(i) = S(i,i), où 1 <= i <= min(M,N). Les éléments peuvent être
!>          uniquement ( +1.0, 0.0 ) ou (-1.0, 0.0 ).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était une valeur illégale
!>
