sous-programme zlapmt (logical forwrd, integer m, integer n, complex*16, dimension( ldx, * ) x, integer ldx, integer, dimension( * ) k)

ZLAPMT effectue une permutation avant ou arrière des colonnes d'une matrice.

Objectif:

!>
!> ZLAPMT réorganise les colonnes de la matrice M par N de X selon
!> la permutation spécifiée K(1),K(2),...,K(N) des entiers 1,...,N.
!> Si FORWRD = .VRAI., permutation avant :
!>
!>      X(*,K(J)) est déplacé vers X(*,J) pour J = 1,2,...,N.
!>
!> Si FORWRD = .FAUX., permutation arrière :
!>
!>      X(*,J) est déplacé vers X(*,K(J)) pour J = 1,2,...,N.
!>

Paramètres

FORWRD 
!>          FORWRD est LOGICAL
!>          = .VRAI., permutation avant
!>          = .FAUX., permutation arrière
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice X. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice X. N >= 0.
!>

X

!>          X est un tableau COMPLEX*16, de dimension (LDX,N)
!>          À l'entrée, la matrice M par N X.
!>          À la sortie, X contient la matrice permutée X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X, LDX >= MAX(1,M).
!>

K

!>          K est un tableau INTEGER, de dimension (N)
!>          À l'entrée, K contient le vecteur de permutation. K est utilisé
!>          comme espace de travail interne, mais est remis à sa valeur
!>          d'origine à la sortie.
!>
