!>
!>    ZLATM2 retourne l'entrée (I,J) d'une matrice aléatoire de dimension
!>    (M, N) décrite par les autres paramètres. Elle est appelée par la
!>    routine ZLATMR afin de construire des matrices de test aléatoires. Aucune
!>    vérification d'erreur sur les paramètres n'est effectuée, car cette routine est appelée dans
!>    une boucle serrée par ZLATMR qui a déjà vérifié les paramètres.
!>
!>    L'utilisation de ZLATM2 diffère de CLATM3 dans l'ordre dans lequel le générateur
!>    de nombres aléatoires est appelé pour remplir les entrées de la matrice aléatoire.
!>    Avec ZLATM2, le générateur est appelé pour remplir la matrice pivotée
!>    colonne par colonne. Avec ZLATM3, le générateur est appelé pour remplir la
!>    matrice colonne par colonne, après quoi elle est pivotée. Ainsi, ZLATM3 peut
!>    être utilisé pour construire des matrices aléatoires qui ne diffèrent que par leur
!>    ordre de lignes et/ou de colonnes. ZLATM2 est utilisé pour construire des matrices bande
!>    tout en évitant d'appeler le générateur de nombres aléatoires pour les
!>    entrées en dehors de la bande (et donc générant des nombres aléatoires
!>
!>    La matrice dont l'entrée (I,J) est retournée est construite comme suit
!>    (cette routine ne calcule qu'une seule entrée) :
!>
!>      Si I est en dehors de (1..M) ou J est en dehors de (1..N), retourner zéro
!>         (ceci est pratique pour générer des matrices au format bande).
!>
!>      Générer une matrice A avec des entrées aléatoires de distribution IDIST.
!>
!>      Définir la diagonale à D.
!>
!>      Classer la matrice, si désiré, par la gauche (par DL) et/ou
!>         par la droite (par DR ou DL) comme spécifié par IGRADE.
!>
!>      Permuter, si désiré, les lignes et/ou les colonnes comme spécifié par
!>         IPVTNG et IWORK.
!>
!>      Transformer la matrice en bande avec une bande inférieure KL et une bande supérieure
!>         KU.
!>
!>      Mettre à zéro des entrées aléatoires comme spécifié par SPARSE.
!>

Paramètres

M 
!>          M est INTEGER
!>           Nombre de lignes de la matrice. Non modifié.
!>

N

!>          N est INTEGER
!>           Nombre de colonnes de la matrice. Non modifié.
!>

I

!>          I est INTEGER
!>           Ligne de l'entrée à retourner. Non modifiée.
!>

J

!>          J est INTEGER
!>           Colonne de l'entrée à retourner. Non modifiée.
!>

KL

!>          KL est INTEGER
!>           Bande inférieure. Non modifié.
!>

KU

!>          KU est INTEGER
!>           Bande supérieure. Non modifié.
!>

IDIST

!>          IDIST est INTEGER
!>           En entrée, IDIST spécifie le type de distribution à utiliser pour générer une matrice aléatoire.
!>           1 => parties réelle et imaginaire chacune UNIFORME( 0, 1 )
!>           2 => parties réelle et imaginaire chacune UNIFORME( -1, 1 )
!>           3 => parties réelle et imaginaire chacune NORMALE( 0, 1 )
!>           4 => nombre complexe uniforme dans DISQUE( 0 , 1 )
!>           Non modifié.
!>

ISEED

!>          ISEED est tableau INTEGER de dimension ( 4 )
!>           Graine pour le générateur de nombres aléatoires.
!>           Modifié en sortie.
!>

D

!>          D est tableau COMPLEX*16 de dimension ( MIN( I , J ) )
!>           Entrées diagonales de la matrice. Non modifié.
!>

IGRADE

!>          IGRADE est INTEGER
!>           Spécifie le classement de la matrice comme suit :
!>           0  => pas de classement
!>           1  => matrice prémultipliée par diag( DL )
!>           2  => matrice postmultipliée par diag( DR )
!>           3  => matrice prémultipliée par diag( DL ) et
!>                         postmultipliée par diag( DR )
!>           4  => matrice prémultipliée par diag( DL ) et
!>                         postmultipliée par inv( diag( DL ) )
!>           5  => matrice prémultipliée par diag( DL ) et
!>                         postmultipliée par diag( CONJG(DL) )
!>           6  => matrice prémultipliée par diag( DL ) et
!>                         postmultipliée par diag( DL )
!>           Non modifié.
!>

DL

!>          DL est tableau COMPLEX*16 ( I ou J, selon le cas )
!>           Facteurs d'échelle gauche pour le classement de la matrice. Non modifié.
!>

DR

!>          DR est tableau COMPLEX*16 ( I ou J, selon le cas )
!>           Facteurs d'échelle droite pour le classement de la matrice. Non modifié.
!>

IPVTNG

!>          IPVTNG est INTEGER
!>           En entrée spécifie les permutations de pivotement comme suit :
!>           0 => aucune.
!>           1 => pivotement de lignes.
!>           2 => pivotement de colonnes.
!>           3 => pivotement complet, c'est-à-dire des deux côtés.
!>           Non modifié.
!>

IWORK

!>          IWORK est tableau INTEGER ( I ou J, selon le cas )
!>           Ce tableau spécifie la permutation utilisée. La
!>           ligne (ou colonne) en position K était originellement en
!>           position IWORK( K ).
!>           Ceci diffère de IWORK pour ZLATM3. Non modifié.
!>

SPARSE

!>          SPARSE est DOUBLE PRECISION entre 0. et 1.
!>           En entrée spécifie la sparsité de la matrice
!>           si une matrice creuse doit être générée.
!>           SPARSE doit être compris entre 0 et 1.
!>           Un nombre aléatoire uniforme x( 0, 1 ) est généré et
!>           comparé à SPARSE ; si x est plus grand, l'entrée de la matrice
!>           n'est pas modifiée et si x est plus petit, l'entrée est mise
!>           à zéro. Ainsi, en moyenne, une fraction SPARSE des
!>           entrées sera mise à zéro.
!>           Non modifié.
!>

zlatm2.f (3)

NAME

zlatm2 - zlatsm2

SYNOPSIS

SUBROUTINE ZLATM2( CWORK, CMAX, A, LDA, B, LDB, R, LDAR, C, LDAC, WORK )

DESCRIPTION

ZLATM2 generates a complex Schur decomposition matrix.

This routine is a helper routine for ZLASCL.

It generates a complex matrix A of order N with,

1 <= K = < N, such that

A = S * ( U * D * V' )

where

U and V are unitary matrices.

D is a diagonal matrix.

S is a diagonal matrix with elements of magnitude CWORK(1), ..., CWORK(N).

The diagonal elements of D are chosen to be CMAX, CMAX/2, ..., CMAX/2**(N-1).

The diagonal elements of D are complex numbers of magnitude CMAX.

The off-diagonal elements of A are chosen randomly.

The elements of the matrix are in the range [-1, 1].

PARAMETERS

CWORK
COMPLEX*16 array, dimension (N)
The diagonal elements of S.
CMAX
DOUBLE PRECISION
The maximum magnitude of the diagonal elements of D.
A
COMPLEX*16 array, dimension (LDA, N)
The matrix A.
LDA
INTEGER
The leading dimension of A.
B
COMPLEX*16 array, dimension (LDB, N)
The matrix B.
LDB
INTEGER
The leading dimension of B.
R
COMPLEX*16 array, dimension (LDAR, N)
The matrix R.
LDAR
INTEGER
The leading dimension of R.
C
COMPLEX*16 array, dimension (LDAC, N)
The matrix C.
LDAC
INTEGER
The leading dimension of C.

COMPLEX*16 array, dimension (N)
Workspace.
