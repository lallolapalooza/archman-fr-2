sous-programme zlacn2 (entier n, complexe*16, dimension( * ) v, complexe*16, dimension( * ) x, double précision est, entier kase, entier, dimension( 3 ) isave)

ZLACN2 estime la 1-norme d'une matrice carrée complexe, utilisant la communication inverse pour évaluer les produits matrice-vecteur.

Objectif:

!>
!> ZLACN2 estime la 1-norme d'une matrice carrée complexe A.
!> La communication inverse est utilisée pour évaluer les produits matrice-vecteur.
!>

Paramètres

N 
!>          N est ENTIER
!>         L'ordre de la matrice.  N >= 1.
!>

V

!>          V est un tableau COMPLEX*16, de dimension (N)
!>         Lors du retour final, V = A*W,  où  EST = norm(V)/norm(W)
!>         (W n'est pas retourné).
!>

X

!>          X est un tableau COMPLEX*16, de dimension (N)
!>         Lors d'un retour intermédiaire, X doit être écrasé par
!>               A * X,   si KASE=1,
!>               A**H * X,  si KASE=2,
!>         où A**H est la transposée conjuguée de A, et ZLACN2 doit être
!>         rappelé avec tous les autres paramètres inchangés.
!>

EST

!>          EST est DOUBLE PRÉCISION
!>         À l'entrée avec KASE = 1 ou 2 et ISAVE(1) = 3, EST doit être
!>         inchangé par rapport à l'appel précédent à ZLACN2.
!>         À la sortie, EST est une estimation (une borne inférieure) pour norm(A).
!>

KASE

!>          KASE est ENTIER
!>         Lors de l'appel initial à ZLACN2, KASE doit être 0.
!>         Lors d'un retour intermédiaire, KASE sera 1 ou 2, indiquant
!>         si X doit être écrasé par A * X  ou A**H * X.
!>         Lors du retour final de ZLACN2, KASE sera à nouveau 0.
!>

ISAVE

!>          ISAVE est un tableau ENTIER, de dimension (3)
!>         ISAVE est utilisé pour sauvegarder des variables entre les appels à ZLACN2
!>
