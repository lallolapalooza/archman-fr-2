Documentation des fonctions/sous-programmes

sous-programme zlaic1 (integer job, integer j, complex*16, dimension( j ) x, double precision sest, complex*16, dimension( j ) w, complex*16 gamma, double precision sestpr, complex*16 s, complex*16 c)

ZLAIC1 applique une étape d'estimation incrémentale de la condition.

Objectif :

!>
!> ZLAIC1 applique une étape d'estimation incrémentale de la condition
!> dans sa version la plus simple :
!>
!> Soit x, twonorm(x) = 1, un vecteur singulier approximatif d'une matrice triangulaire inférieure j-par-j L, tel que
!>          twonorm(L*x) = sest
!> Alors ZLAIC1 calcule sestpr, s, c tels que
!> le vecteur
!>                 [ s*x ]
!>          xhat = [  c  ]
!> est un vecteur singulier approximatif de
!>                 [ L       0  ]
!>          Lhat = [ w**H gamma ]
!> dans le sens où
!>          twonorm(Lhat*xhat) = sestpr.
!>
!> Selon JOB, une estimation de la plus grande ou de la plus petite valeur singulière est calculée.
!>
!> Notez que [s c]**H et sestpr**2 est une paire propre du système
!>
!>     diag(sest*sest, 0) + [alpha  gamma] * [ conjg(alpha) ]
!>                                           [ conjg(gamma) ]
!>
!> où  alpha =  x**H * w.
!>

Paramètres

JOB 
!>          JOB est INTEGER
!>          = 1 : une estimation de la plus grande valeur singulière est calculée.
!>          = 2 : une estimation de la plus petite valeur singulière est calculée.
!>

J

!>          J est INTEGER
!>          Longueur de X et W
!>

X

!>          X est un tableau COMPLEX*16, de dimension (J)
!>          Le vecteur j x.
!>

SEST

!>          SEST est DOUBLE PRECISION
!>          Valeur singulière estimée de la matrice L de taille j par j
!>

W

!>          W est un tableau COMPLEX*16, de dimension (J)
!>          Le vecteur j w.
!>

GAMMA

!>          GAMMA est COMPLEX*16
!>          L'élément diagonal gamma.
!>

SESTPR

!>          SESTPR est DOUBLE PRECISION
!>          Valeur singulière estimée de la matrice Lhat de taille (j+1) par (j+1).
!>

S

!>          S est COMPLEX*16
!>          Sinus nécessaire pour former xhat.
!>

C

!>          C est COMPLEX*16
!>          Cosinus nécessaire pour former xhat.
!>
