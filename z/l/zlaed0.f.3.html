sous-programme zlaed0 (integer qsiz, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( ldqs, * ) qstore, integer ldqs, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

ZLAED0 utilisé par ZSTEDC. Calcule toutes les valeurs propres et les vecteurs propres correspondants d'une matrice tridiagonale symétrique non réduite à l'aide de la méthode de division et de conquête.

Objectif :

!>
!> En utilisant la méthode de division et de conquête, ZLAED0 calcule toutes les valeurs propres
!> d'une matrice tridiagonale symétrique qui est un bloc diagonal
!> de ceux obtenus en réduisant une matrice hermitienne dense ou bande
!> et les vecteurs propres correspondants de la matrice dense ou bande.
!>

Paramètres

QSIZ 
!>          QSIZ est un entier
!>         La dimension de la matrice unitaire utilisée pour réduire
!>         la matrice complète en forme tridiagonale.  QSIZ >= N si ICOMPQ = 1.
!>

N

!>          N est un entier
!>         La dimension de la matrice tridiagonale symétrique.  N >= 0.
!>

D

!>          D est un tableau de DOUBLE PRECISION, dimension (N)
!>         À l'entrée, les éléments diagonaux de la matrice tridiagonale.
!>         À la sortie, les valeurs propres en ordre croissant.
!>

E

!>          E est un tableau de DOUBLE PRECISION, dimension (N-1)
!>         À l'entrée, les éléments hors diagonale de la matrice tridiagonale.
!>         À la sortie, E a été détruit.
!>

Q

!>          Q est un tableau COMPLEX*16, dimension (LDQ,N)
!>         À l'entrée, Q doit contenir une matrice QSIZ x N dont les colonnes
!>         sont unitaires et orthonormales. Elle fait partie de la matrice unitaire
!>         qui réduit la matrice hermitienne dense complète en une
!>         matrice tridiagonale symétrique (réductible).
!>

LDQ

!>          LDQ est un entier
!>         La dimension principale du tableau Q.  LDQ >= max(1,N).
!>

IWORK

!>          IWORK est un tableau d'entiers,
!>         la dimension de IWORK doit être au moins
!>                      6 + 6*N + 5*N*lg N
!>                      ( lg( N ) = le plus petit entier k
!>                                  tel que 2^k >= N )
!>

RWORK

!>          RWORK est un tableau de DOUBLE PRECISION,
!>                               dimension (1 + 3*N + 2*N*lg N + 3*N**2)
!>                        ( lg( N ) = le plus petit entier k
!>                                    tel que 2^k >= N )
!>

QSTORE

!>          QSTORE est un tableau COMPLEX*16, dimension (LDQS, N)
!>         Utilisé pour stocker des parties de
!>         la matrice des vecteurs propres lorsque les multiplications de matrices
!>         ont lieu.
!>

LDQS

!>          LDQS est un entier
!>         La dimension principale du tableau QSTORE.
!>         LDQS >= max(1,N).
!>

INFO

!>          INFO est un entier
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  L'algorithme n'a pas réussi à calculer une valeur propre lors de
!>                l'exécution sur la sous-matrice située dans les lignes et colonnes
!>                INFO/(N+1) à mod(INFO,N+1).
!>
