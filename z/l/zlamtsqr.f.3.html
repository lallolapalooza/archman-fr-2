Documentation de la fonction/sous-programme

sous-programme zlamtsqr (caractère side, caractère trans, entier m, entier n, entier k, entier mb, entier nb, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldt, * ) t, entier ldt, complexe*16, dimension( ldc, * ) c, entier ldc, complexe*16, dimension( * ) work, entier lwork, entier info)

ZLAMTSQR

Objectif

!>
!>      ZLAMTSQR écrase la matrice complexe générale M par N, C, par
!>
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>      où Q est une matrice complexe unitaire définie comme le produit
!>      de facteurs élémentaires bloqués calculés par la factorisation QR
!>      mince et longue (ZLATSQR).
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**H par la gauche ;
!>          = 'R': appliquer Q ou Q**H par la droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N':  Pas de transposée, appliquer Q ;
!>          = 'C':  Transposée conjuguée, appliquer Q**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >=0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de facteurs élémentaires dont le produit définit
!>          la matrice Q. M >= K >= 0;
!>
!>

MB

!>          MB est INTEGER
!>          La taille de bloc à utiliser dans la QR bloquée.
!>          MB > N. (doit être le même que ZLATSQR)
!>

NB

!>          NB est INTEGER
!>          La taille de bloc de colonnes à utiliser dans la QR bloquée.
!>          N >= NB >= 1.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          facteur élémentaire bloqué H(i), pour i = 1,2,...,k, tel que
!>          retourné par ZLATSQR dans les k premières colonnes de
!>          son tableau argument A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,M) ;
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T est un tableau COMPLEX*16, de dimension
!>          ( N * Nombre de blocs(CEIL(M-K/MB-K)),
!>          Les facteurs de blocs triangulaires supérieurs stockés sous forme compacte
!>          comme une séquence de blocs triangulaires supérieurs. Voir ci-dessous
!>          pour plus de détails.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= NB.
!>

C

!>          C est un tableau COMPLEX*16, de dimension (LDC,N)
!>          À l'entrée, la matrice C de taille M par N.
!>          À la sortie, C est écrasée par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          (espace de travail) tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la LWORK minimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si MIN(M,N,K) = 0, LWORK >= 1.
!>          Si SIDE = 'L', LWORK >= max(1,N*NB).
!>          Si SIDE = 'R', LWORK >= max(1,MB*NB).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille minimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  terminaison réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires

!> La factorisation QR mince et longue (TSQR) effectue la QR par une séquence de transformations unitaires,
!> représentant Q comme un produit d'autres matrices unitaires
!>   Q = Q(1) * Q(2) * . . . * Q(k)
!> où chaque Q(i) annule les entrées sous-diagonales d'un bloc de MB lignes de A :
!>   Q(1) annule les entrées sous-diagonales des lignes 1:MB de A
!>   Q(2) annule les lignes MB-N inférieures des lignes [1:N,MB+1:2*MB-N] de A
!>   Q(3) annule les lignes MB-N inférieures des lignes [1:N,2*MB-N+1:3*MB-2*N] de A
!>   . . .
!>
!> Q(1) est calculé par GEQRT, qui représente Q(1) par des vecteurs de Householder
!> stockés sous la diagonale des lignes 1:MB de A, et par des facteurs triangulaires
!> bloqués, stockés dans le tableau T(1:LDT,1:N).
!> Pour plus d'informations, voir les détails supplémentaires dans GEQRT.
!>
!> Q(i) pour i>1 est calculé par TPQRT, qui représente Q(i) par des vecteurs de Householder
!> stockés dans les lignes [(i-1)*(MB-N)+N+1:i*(MB-N)+N] de A, et par des facteurs triangulaires
!> bloqués, stockés dans le tableau T(1:LDT,(i-1)*N+1:i*N).
!> Le dernier Q(k) peut utiliser moins de lignes.
!> Pour plus d'informations, voir les détails supplémentaires dans TPQRT.
!>
!> Pour plus de détails sur l'algorithme global, voir la description de
!> TSQR séquentielle à la section 2.2 de [1].
!>
!> [1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,”
!>     J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
!>     SIAM J. Sci. Comput, vol. 34, no. 1, 2012
!>
