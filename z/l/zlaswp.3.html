sous-routine zlaswp (integer n, complex*16, dimension( lda, * ) a, integer lda, integer k1, integer k2, integer, dimension( * ) ipiv, integer incx)

ZLASWP effectue une série d'échanges de lignes sur une matrice rectangulaire générale.

Objectif :

!>
!> ZLASWP effectue une série d'échanges de lignes sur la matrice A.
!> Un échange de ligne est initié pour chacune des lignes K1 à K2 de A.
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.
!>

A

!>          A est un tableau COMPLEXE*16, de dimension (LDA,N)
!>          À l'entrée, la matrice de dimension de colonne N sur laquelle les
!>          échanges de lignes seront appliqués.
!>          À la sortie, la matrice permutée.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.
!>

K1

!>          K1 est un ENTIER
!>          Le premier élément de IPIV pour lequel un échange de ligne sera
!>          effectué.
!>

K2

!>          K2 est un ENTIER
!>          (K2-K1+1) est le nombre d'éléments de IPIV pour lesquels un échange de
!>          ligne sera effectué.
!>

IPIV

!>          IPIV est un tableau ENTIER, de dimension (K1+(K2-K1)*abs(INCX))
!>          Le vecteur des indices de pivot. Seuls les éléments aux positions
!>          K1 à K1+(K2-K1)*abs(INCX) de IPIV sont accédés.
!>          IPIV(K1+(K-K1)*abs(INCX)) = L implique que les lignes K et L doivent être
!>          échangées.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les valeurs successives de IPIV. Si INCX
!>          est négatif, les pivots sont appliqués dans l'ordre inverse.
!>
