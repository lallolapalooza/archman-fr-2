!>
!> ZLATTR génère une matrice de test triangulaire en stockage 2D.
!> IMAT et UPLO spécifient de manière unique les propriétés de la matrice de test,
!> qui est retournée dans le tableau A.
!>

Paramètres

IMAT 
!>          IMAT est INTEGER
!>          Une clé entière décrivant quelle matrice générer pour ce
!>          chemin.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A sera triangulaire supérieure ou
!>          inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie si la matrice ou sa transposée sera utilisée.
!>          = 'N':  Pas de transposée
!>          = 'T':  Transposée
!>          = 'C':  Transposée conjuguée
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire triangulaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

ISEED

!>          ISEED est un tableau INTEGER, dimension (4)
!>          Le vecteur graine pour le générateur de nombres aléatoires (utilisé dans
!>          ZLATMS). Modifié à la sortie.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice à générer.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice triangulaire A. Si UPLO = 'U', la partie triangulaire
!>          supérieure N x N du tableau A contient la matrice triangulaire
!>          supérieure, et la partie strictement triangulaire inférieure de
!>          A n'est pas référencée. Si UPLO = 'L', la partie triangulaire
!>          inférieure N x N du tableau A contient la matrice triangulaire
!>          inférieure et la partie strictement triangulaire supérieure de A n'est pas
!>          référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (N)
!>          Le vecteur du second membre, si IMAT > 10.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  Succès de l'exécution
!>          < 0:  si INFO = -i, le i-ème argument était invalide
!>
