Documentation de la fonction/sous-programme

sous-programme zlsets (integer m, integer p, integer n, complex*16, dimension( lda, * ) a, complex*16, dimension( lda, * ) af, integer lda, complex*16, dimension( ldb, * ) b, complex*16, dimension( ldb, * ) bf, integer ldb, complex*16, dimension( * ) c, complex*16, dimension( * ) cf, complex*16, dimension( * ) d, complex*16, dimension( * ) df, complex*16, dimension( * ) x, complex*16, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( 2 ) result)

ZLSETS

Objectif:

!>
!> ZLSETS teste ZGGLSE - un sous-programme pour résoudre le problème des moindres carrés linéaires avec contraintes d'égalité (LSE).
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

P

!>          P est un entier
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice A de dimensions M par N.
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDA,N)
!>

LDA

!>          LDA est un entier
!>          La dimension principale des tableaux A, AF, Q et R.
!>          LDA >= max(M,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,N)
!>          La matrice B de dimensions P par N.
!>

BF

!>          BF est un tableau COMPLEX*16, dimension (LDB,N)
!>

LDB

!>          LDB est un entier
!>          La dimension principale des tableaux B, BF, V et S.
!>          LDB >= max(P,N).
!>

C

!>          C est un tableau COMPLEX*16, dimension( M )
!>          le vecteur C dans le problème LSE.
!>

CF

!>          CF est un tableau COMPLEX*16, dimension( M )
!>

D

!>          D est un tableau COMPLEX*16, dimension( P )
!>          le vecteur D dans le problème LSE.
!>

DF

!>          DF est un tableau COMPLEX*16, dimension( P )
!>

X

!>          X est un tableau COMPLEX*16, dimension( N )
!>          le vecteur solution X dans le problème LSE.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (M)
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, dimension (2)
!>          Les rapports de test:
!>            RESULT(1) = norm( A*x - c )/ norm(A)*norm(X)*EPS
!>            RESULT(2) = norm( B*x - d )/ norm(B)*norm(X)*EPS
!>
