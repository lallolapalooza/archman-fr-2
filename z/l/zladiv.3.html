Documentation Fonction/Sous-routine

complexe*16 fonction zladiv (complexe*16 x, complexe*16 y)

ZLADIV effectue une division complexe en arithmétique réelle, évitant les débordements inutiles.

Objectif :

!>
!> ZLADIV := X / Y, où X et Y sont complexes. Le calcul de X / Y
!> ne débordera pas à une étape intermédiaire sauf si le résultat
!> déborde.
!>

Paramètres

X 
!>          X est COMPLEX*16
!>

Y

!>          Y est COMPLEX*16
!>          Les scalaires complexes X et Y.
!>
