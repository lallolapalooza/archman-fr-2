Documentation de la fonction/sous-programme

sous-programme zlatm1 (integer mode, double precision cond, integer irsign, integer idist, integer, dimension( 4 ) iseed, complex*16, dimension( * ) d, integer n, integer info)

ZLATM1

But :

!>
!>    ZLATM1 calcule les entrées de D(1..N) telles que spécifiées par
!>    MODE, COND et IRSIGN. IDIST et ISEED déterminent la génération
!>    de nombres aléatoires. ZLATM1 est appelé par ZLATMR pour générer
!>    des matrices de test aléatoires pour les programmes LAPACK.
!>

Paramètres

MODE 
!>          MODE est de type INTEGER
!>           En entrée, décrit comment D doit être calculé :
!>           MODE = 0 signifie ne pas changer D.
!>           MODE = 1 définit D(1)=1 et D(2:N)=1.0/COND
!>           MODE = 2 définit D(1:N-1)=1 et D(N)=1.0/COND
!>           MODE = 3 définit D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 définit D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 définit D à des nombres aléatoires dans l'intervalle
!>                    ( 1/COND , 1 ) tels que leurs logarithmes
!>                    sont uniformément distribués.
!>           MODE = 6 définit D à des nombres aléatoires de la même distribution
!>                    que le reste de la matrice.
!>           MODE < 0 a la même signification que ABS(MODE), sauf que
!>              l'ordre des éléments de D est inversé.
!>           Ainsi, si MODE est positif, les entrées de D varient de
!>              1 à 1/COND, si négatif, de 1/COND à 1,
!!>           Non modifié.
!>

COND

!>          COND est de type DOUBLE PRECISION
!>           En entrée, utilisé comme décrit sous MODE ci-dessus.
!>           S'il est utilisé, il doit être >= 1. Non modifié.
!>

IRSIGN

!>          IRSIGN est de type INTEGER
!>           En entrée, si MODE n'est ni -6, 0 ni 6, détermine le signe des
!>           entrées de D
!>           0 => laisse les entrées de D inchangées
!>           1 => multiplie chaque entrée de D par un nombre complexe aléatoire
!>                uniformément distribué avec une valeur absolue de 1
!>

IDIST

!>          IDIST est de type INTEGER
!>           En entrée, IDIST spécifie le type de distribution à utiliser
!>           pour générer une matrice aléatoire.
!>           1 => parties réelle et imaginaire UNIFORM( 0, 1 ) chacune
!>           2 => parties réelle et imaginaire UNIFORM( -1, 1 ) chacune
!>           3 => parties réelle et imaginaire NORMAL( 0, 1 ) chacune
!>           4 => nombre complexe uniforme dans DISK( 0, 1 )
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau de type INTEGER, dimension ( 4 )
!>           En entrée, ISEED spécifie la graine du générateur de nombres
!>           aléatoires. Le générateur de nombres aléatoires utilise une
!>           séquence congruente linéaire limitée à de petits entiers,
!>           et doit donc produire des nombres aléatoires indépendants de la machine.
!>           Les valeurs de ISEED sont modifiées à la sortie, et peuvent être
!>           utilisées dans l'appel suivant à ZLATM1
!>           pour continuer la même séquence de nombres aléatoires.
!>           Modifié en sortie.
!>

D

!>          D est un tableau de type COMPLEX*16, dimension ( N )
!>           Tableau à calculer selon MODE, COND et IRSIGN.
!>           Peut être modifié en sortie si MODE est non nul.
!>

N

!>          N est de type INTEGER
!>           Nombre d'entrées de D. Non modifié.
!>

INFO

!>          INFO est de type INTEGER
!>            0  => terminaison normale
!>           -1  => si MODE n'est pas dans l'intervalle -6 à 6
!>           -2  => si MODE n'est ni -6, 0 ni 6, et
!>                  IRSIGN n'est ni 0 ni 1
!>           -3  => si MODE n'est ni -6, 0 ni 6 et COND inférieur à 1
!>           -4  => si MODE est égal à 6 ou -6 et IDIST n'est pas dans l'intervalle 1 à 4
!>           -7  => si N est négatif
!>
