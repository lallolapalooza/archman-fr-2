Documentation de la fonction/sous-routine

subroutine zlaptm (character uplo, integer n, integer nrhs, double precision alpha, double precision, dimension( * ) d, complex*16, dimension( * ) e, complex*16, dimension( ldx, * ) x, integer ldx, double precision beta, complex*16, dimension( ldb, * ) b, integer ldb)

ZLAPTM

Purpose:

!>
!> ZLAPTM multiplie une matrice N par NRHS X par une matrice tridiagonale
!> hermitienne A et stocke le résultat dans une matrice B. L'opération a la
!> forme
!>
!>    B := alpha * A * X + beta * B
!>
!> où alpha peut être soit 1. soit -1. et beta peut être 0., 1. ou -1.
!>

Paramètres

UPLO 
!>          UPLO est de type CHARACTER
!>          Spécifie si la surdiagonale ou la sous-diagonale de la
!>          matrice tridiagonale A est stockée.
!>          = 'U':  Supérieure, E est la surdiagonale de A.
!>          = 'L':  Inférieure, E est la sous-diagonale de A.
!>

N

!>          N est un entier
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est un entier
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices X et B.
!>

ALPHA

!>          ALPHA est de type DOUBLE PRECISION
!>          Le scalaire alpha. ALPHA doit être 1. ou -1.; sinon,
!>          il est supposé être 0.
!>

D

!>          D est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale A.
!>

E

!>          E est un tableau de type COMPLEX*16, de dimension (N-1)
!>          Les (n-1) éléments de la sous-diagonale ou surdiagonale de A.
!>

X

!>          X est un tableau de type COMPLEX*16, de dimension (LDX,NRHS)
!>          La matrice X de taille N par NRHS.
!>

LDX

!>          LDX est un entier
!>          La dimension principale du tableau X. LDX >= max(N,1).
!>

BETA

!>          BETA est de type DOUBLE PRECISION
!>          Le scalaire beta. BETA doit être 0., 1. ou -1.; sinon,
!>          il est supposé être 1.
!>

B

!>          B est un tableau de type COMPLEX*16, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B de taille N par NRHS.
!>          À la sortie, B est écrasée par l'expression matricielle
!>          B := alpha * A * X + beta * B.
!>

LDB

!>          LDB est un entier
!>          La dimension principale du tableau B. LDB >= max(N,1).
!>
