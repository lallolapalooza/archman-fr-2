Documentation de la fonction/sous-programme

sous-programme zlaesy (complex*16 a, complex*16 b, complex*16 c, complex*16 rt1, complex*16 rt2, complex*16 evscal, complex*16 cs1, complex*16 sn1)

ZLAESY calcule les valeurs propres et les vecteurs propres d'une matrice complexe symétrique de taille 2 par 2.

Objectif:

!>
!> ZLAESY calcule la décomposition en valeurs propres d'une matrice symétrique
!> de taille 2 par 2
!>    ( ( A, B );( B, C ) )
!> à condition que la norme de la matrice des vecteurs propres soit supérieure
!> à un certain seuil.
!>
!> RT1 est la valeur propre de plus grande valeur absolue, et RT2 de
!> plus petite valeur absolue. Si les vecteurs propres sont calculés, alors
!> à la sortie ( CS1, SN1 ) est le vecteur propre unitaire pour RT1, donc
!>
!> [  CS1     SN1   ] . [ A  B ] . [ CS1    -SN1   ] = [ RT1  0  ]
!> [ -SN1     CS1   ]   [ B  C ]   [ SN1     CS1   ]   [  0  RT2 ]
!>

Paramètres

A 
!>          A est COMPLEX*16
!>          L'élément ( 1, 1 ) de la matrice d'entrée.
!>

B

!>          B est COMPLEX*16
!>          L'élément ( 1, 2 ) de la matrice d'entrée. L'élément ( 2, 1 )
!>          est également donné par B, car la matrice de taille 2 par 2 est
!>          symétrique.
!>

C

!>          C est COMPLEX*16
!>          L'élément ( 2, 2 ) de la matrice d'entrée.
!>

RT1

!>          RT1 est COMPLEX*16
!>          La valeur propre de plus grand module.
!>

RT2

!>          RT2 est COMPLEX*16
!>          La valeur propre de plus petit module.
!>

EVSCAL

!>          EVSCAL est COMPLEX*16
!>          La valeur complexe par laquelle la matrice des vecteurs propres a été
!>          mise à l'échelle pour la rendre orthonormée. Si EVSCAL est zéro,
!>          les vecteurs propres n'ont pas été calculés. Cela signifie une des deux
!>          choses suivantes : la matrice de taille 2 par 2 n'a pas pu être
!>          diagonalisée, ou la norme de la matrice des vecteurs propres avant
!>          mise à l'échelle était supérieure à la valeur seuil THRESH (définie ci-dessous).
!>

CS1

!>          CS1 est COMPLEX*16
!>

SN1

!>          SN1 est COMPLEX*16
!>          Si EVSCAL .NE. 0,  ( CS1, SN1 ) est le vecteur propre droit unitaire
!>          pour RT1.
!>
