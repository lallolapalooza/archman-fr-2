sous-routine zlarz (side, m, n, l, v, incv, tau, c, ldc, work)
ZLARZ applique un réflecteur élémentaire (tel que retourné par stzrzf) à une matrice générale.

Documentation de la fonction/sous-routine

sous-routine zlarz (character side, integer m, integer n, integer l, complex*16, dimension( * ) v, integer incv, complex*16 tau, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( * ) work)

ZLARZ applique un réflecteur élémentaire complexe H à une matrice complexe C de taille M par N, soit à gauche, soit à droite. H est représenté sous la forme 

       H = I - tau * v * v**H

où tau est un scalaire complexe et v est un vecteur complexe.

Si tau = 0, alors H est considérée comme la matrice identité.

Pour appliquer H**H (la transposée conjuguée de H), fournissez conjg(tau) à la place de tau.

H est un produit de k réflecteurs élémentaires tel que retourné par ZTZRZF.

Paramètres

SIDE 
          SIDE est CHARACTER*1
          = 'L': forme  H * C
          = 'R': forme  C * H

M

          M est INTEGER
          Le nombre de lignes de la matrice C.

N

          N est INTEGER
          Le nombre de colonnes de la matrice C.

L

          L est INTEGER
          Le nombre d'entrées du vecteur V contenant
          la partie significative des vecteurs de Householder.
          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.

V

          V est un tableau COMPLEX*16, dimension (1+(L-1)*abs(INCV))
          Le vecteur v dans la représentation de H tel que retourné par
          ZTZRZF. V n'est pas utilisé si TAU = 0.

INCV

          INCV est INTEGER
          Le pas entre les éléments de v. INCV <> 0.

TAU

          TAU est COMPLEX*16
          La valeur tau dans la représentation de H.

C

          C est un tableau COMPLEX*16, dimension (LDC,N)
          En entrée, la matrice C de taille M par N.
          En sortie, C est écrasée par la matrice H * C si SIDE = 'L',
          ou C * H si SIDE = 'R'.

LDC

          LDC est INTEGER
          La dimension principale du tableau C. LDC >= max(1,M).

WORK

          WORK est un tableau COMPLEX*16, dimension
                         (N) si SIDE = 'L'
                      ou (M) si SIDE = 'R'
