Documentation de la fonction/sous-programme

sous-programme zlarf1f (caractère side, entier m, entier n, complexe*16, dimension( * ) v, entier incv, complexe*16 tau, complexe*16, dimension( ldc, * ) c, entier ldc, complexe*16, dimension( * ) work)

ZLARF1F applique un réflecteur élémentaire complexe à une matrice réelle m par n

Objectif :

!>
!> ZLARF1F applique un réflecteur élémentaire complexe H à une matrice réelle m par n
!> C, de la gauche ou de la droite. H est représenté sous la forme
!>
!>       H = I - tau * v * v**H
!>
!> où tau est un scalaire complexe et v est un vecteur complexe.
!>
!> Si tau = 0, alors H est considérée comme la matrice unité.
!>
!> Pour appliquer H**H, fournissez conjg(tau) au lieu de
!> tau.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : forme  H * C
!>
!> \param[in] M
!> \verbatim
!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

V

!>          V est un tableau COMPLEX*16, dimension
!>                     (1 + (M-1)*abs(INCV)) si SIDE = 'L'
!>                  ou (1 + (N-1)*abs(INCV)) si SIDE = 'R'
!>          Le vecteur v dans la représentation de H. V n'est pas utilisé si
!>          TAU = 0. V(1) n'est pas référencé ni modifié.
!>

INCV

!>          INCV est INTEGER
!>          L'incrément entre les éléments de v. INCV <> 0.
!>

TAU

!>          TAU est COMPLEX*16
!>          La valeur tau dans la représentation de H.
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC,N)
!>          En entrée, la matrice C de taille m par n.
!>          En sortie, C est écrasé par la matrice H * C si SIDE = 'L',
!>          ou C * H si SIDE = 'R'.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension
!>                         (N) si SIDE = 'L'
!>                      ou (M) si SIDE = 'R'
!>
