ZLAGHE

Documentation de la fonction/sous-routine

sous-routine zlaghe (integer n, integer k, double precision, dimension( * ) d, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( 4 ) iseed, complex*16, dimension( * ) work, integer info)

ZLAGHE

Objectif :

!>
!> ZLAGHE génère une matrice hermitienne complexe A, en pré- et post-
!> multipliant une matrice diagonale réelle D par une matrice unitaire aléatoire :
!> A = U*D*U'. La semi-bande peut alors être réduite à k par des transformations unitaires supplémentaires.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de sous-diagonales non nulles dans la bande de A.
!>          0 <= K <= N-1.
!>

D

!>          D est un tableau DOUBLE PRÉCISION, dimension (N)
!>          Les éléments diagonaux de la matrice diagonale D.
!>

A

!>          A est un tableau COMPLEXE*16, dimension (LDA,N)
!>          La matrice hermitienne n x n générée A (la matrice complète est
!>          stockée).
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= N.
!>

ISEED

!>          ISEED est un tableau ENTIER, dimension (4)
!>          En entrée, la graine du générateur de nombres aléatoires ; les éléments
!>          du tableau doivent être compris entre 0 et 4095, et ISEED(4) doit être
!>          impair.
!>          En sortie, la graine est mise à jour.
!>

WORK

!>          WORK est un tableau COMPLEXE*16, dimension (2*N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>
