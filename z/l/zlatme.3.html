Documentation de la fonction/sous-programme

sous-programme zlatme (integer n, character dist, integer, dimension( 4 ) iseed, complex*16, dimension( * ) d, integer mode, double precision cond, complex*16 dmax, character rsign, character upper, character sim, double precision, dimension( * ) ds, integer modes, double precision conds, integer kl, integer ku, double precision anorm, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) work, integer info)

ZLATME

Objectif :

!>
!>    ZLATME génère des matrices carrées non symétriques aléatoires avec
!>    des valeurs propres spécifiées pour tester les programmes LAPACK.
!>
!>    ZLATME fonctionne en appliquant la séquence d'opérations suivante :
!>
!>    1. Définir la diagonale à D, où D peut être entré ou
!>         calculé selon MODE, COND, DMAX et RSIGN
!>         comme décrit ci-dessous.
!>
!>    2. Si UPPER='T', le triangle supérieur de A est défini avec des valeurs
!>         aléatoires issues de la distribution DIST.
!>
!>    3. Si SIM='T', A est multiplié à gauche par une matrice aléatoire
!>         X, dont les valeurs propres sont spécifiées par DS, MODES et
!>         CONDS, et à droite par X inverse.
!>
!>    4. Si KL < N-1, la bande inférieure est réduite à KL en utilisant
!>         des transformations de Householder. Si KU < N-1, la bande supérieure
!>         est réduite à KU.
!>
!>    5. Si ANORM n'est pas négatif, la matrice est mise à l'échelle pour avoir
!>         une norme d'élément maximum ANORM.
!>
!>    (Note : puisque la matrice ne peut pas être réduite au-delà de la forme de Hessenberg,
!>     aucune option de regroupement n'est disponible.)
!>

Paramètres

N 
!>          N est INTEGER
!>           Le nombre de colonnes (ou de lignes) de A. Non modifié.
!>

DIST

!>          DIST est CHARACTER*1
!>           À l'entrée, DIST spécifie le type de distribution à utiliser
!>           pour générer les valeurs propres/singulières aléatoires, et sur le
!>           triangle supérieur (voir UPPER).
!>           'U' => UNIFORME( 0, 1 )  ( 'U' pour uniforme )
!>           'S' => UNIFORME( -1, 1 ) ( 'S' pour symétrique )
!>           'N' => NORMALE( 0, 1 )   ( 'N' pour normale )
!>           'D' => uniforme sur le disque complexe |z| < 1.
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau INTEGER, dimension ( 4 )
!>           À l'entrée, ISEED spécifie la graine du générateur de nombres
!>           aléatoires. Les valeurs doivent être comprises entre 0 et 4095 inclus,
!>           et ISEED(4) doit être impair. Le générateur de nombres aléatoires
!>           utilise une séquence congruente linéaire limitée à de petits
!>           entiers, et devrait produire des nombres aléatoires indépendants de la machine.
!>           Les valeurs de ISEED sont modifiées à la sortie et peuvent être utilisées
!>           dans le prochain appel à ZLATME pour continuer la même séquence de nombres aléatoires.
!>           Modifié à la sortie.
!>

D

!>          D est un tableau COMPLEX*16, dimension ( N )
!>           Ce tableau est utilisé pour spécifier les valeurs propres de A. Si
!>           MODE=0, alors D est supposé contenir les valeurs propres ;
!>           sinon, elles seront calculées selon MODE, COND,
!>           DMAX et RSIGN et placées dans D.
!>           Modifié si MODE est non nul.
!>

MODE

!>          MODE est INTEGER
!>           À l'entrée, ceci décrit comment les valeurs propres doivent
!>           être spécifiées :
!>           MODE = 0 signifie utiliser D en entrée
!>           MODE = 1 définit D(1)=1 et D(2:N)=1.0/COND
!>           MODE = 2 définit D(1:N-1)=1 et D(N)=1.0/COND
!>           MODE = 3 définit D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 définit D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 définit D avec des nombres aléatoires dans l'intervalle
!>                    ( 1/COND , 1 ) tels que leurs logarithmes
!>                    sont uniformément distribués.
!>           MODE = 6 définit D avec des nombres aléatoires de la même distribution
!>                    que le reste de la matrice.
!>           MODE < 0 a la même signification que ABS(MODE), sauf que
!>              l'ordre des éléments de D est inversé.
!>           Ainsi, si MODE est entre 1 et 4, D a des entrées allant
!>              de 1 à 1/COND ; si entre -1 et -4, D a des entrées
!>              allant de 1/COND à 1.
!>           Non modifié.
!>

COND

!>          COND est DOUBLE PRECISION
!>           À l'entrée, ceci est utilisé comme décrit sous MODE ci-dessus.
!>           S'il est utilisé, il doit être >= 1. Non modifié.
!>

DMAX

!>          DMAX est COMPLEX*16
!>           Si MODE n'est ni -6, ni 0, ni 6, le contenu de D, tel que
!>           calculé selon MODE et COND, sera mis à l'échelle par
!>           DMAX / max(abs(D(i))). Notez que DMAX n'a pas besoin
!>           d'être positif ou réel : si DMAX est négatif ou complexe (ou zéro),
!>           D sera mis à l'échelle par un nombre négatif ou complexe (ou zéro).
!>           Si RSIGN='F', alors la valeur propre (en valeur absolue) la plus grande sera
!>           égale à DMAX.
!>           Non modifié.
!>

RSIGN

!>          RSIGN est CHARACTER*1
!>           Si MODE n'est pas 0, 6 ou -6, et RSIGN='T', alors les
!>           éléments de D, tels que calculés selon MODE et COND, seront
!>           multipliés par un nombre complexe aléatoire du cercle unité
!>           |z| = 1. Si RSIGN='F', ils ne seront pas multipliés. RSIGN ne peut
!>           avoir que les valeurs 'T' ou 'F'.
!>           Non modifié.
!>

UPPER

!>          UPPER est CHARACTER*1
!>           Si UPPER='T', alors les éléments de A au-dessus de la diagonale
!>           seront définis avec des nombres aléatoires issus de DIST. Si UPPER='F',
!>           ils ne le seront pas. UPPER ne peut avoir que les valeurs 'T' ou 'F'.
!>           Non modifié.
!>

SIM

!>          SIM est CHARACTER*1
!>           Si SIM='T', alors A sera transformé par, c'est-à-dire multiplié à gauche par une matrice X et
!>           à droite par X inverse. X = U S V, où U et V sont
!>           des matrices unitaires aléatoires et S est une matrice (diagonale) de
!>           valeurs propres spécifiées par DS, MODES et CONDS. Si
!>           SIM='F', alors A ne sera pas transformé.
!>           Non modifié.
!>

DS

!>          DS est un tableau DOUBLE PRECISION, dimension ( N )
!>           Ce tableau est utilisé pour spécifier les valeurs propres de X,
!>           de la même manière que D spécifie les valeurs propres de A.
!>           Si MODE=0, DS contient les valeurs propres, qui
!>           ne peuvent pas être nulles.
!>           Modifié si MODE est non nul.
!>

MODES

!>          MODES est INTEGER
!>

CONDS

!>          CONDS est DOUBLE PRECISION
!>           Similaire à MODE et COND, mais pour spécifier la diagonale
!>           de S. MODES=-6 et +6 ne sont pas autorisés (car ils résulteraient
!>           en des valeurs propres aléatoirement mal conditionnées).
!>

KL

!>          KL est INTEGER
!>           Ceci spécifie la bande inférieure de la matrice. KL=1
!>           spécifie la forme de Hessenberg supérieure. Si KL est au moins N-1,
!>           alors A aura une bande inférieure complète.
!>           Non modifié.
!>

KU

!>          KU est INTEGER
!>           Ceci spécifie la bande supérieure de la matrice. KU=1
!>           spécifie la forme de Hessenberg inférieure. Si KU est au moins N-1,
!>           alors A aura une bande supérieure complète ; si KU et KL
!>           sont tous deux à

Function/Subroutine Documentation

ZLATME construit une matrice complexe de test A de taille N x N, dont les propriétés sont contrôlées par les paramètres d'entrée.

Arguments:

N

INTEGER L'ordre de la matrice.

DIST

CHARACTER*1 Spécifie la distribution des valeurs des éléments de A.

   DIST = 'U' : Uniforme dans la plage [-1, 1].
   DIST = 'S' : Sinusoïdale. Les valeurs sont générées par sin(theta*k) et cos(theta*k).
   DIST = 'N' : Normale. Les valeurs sont générées à partir d'une distribution normale avec une moyenne de 0 et une variance de 1.
   DIST = 'L' : Log-uniforme. Les valeurs sont uniformément distribuées sur une échelle logarithmique.
   DIST = 'D' : Diagonale dominante. La valeur absolue des éléments diagonaux est supérieure à la somme des valeurs absolues des autres éléments dans la même ligne.
   DIST = 'C' : Conditionnement contrôlé.
   DIST = 'A' : Entièrement aléatoire.
MODE

INTEGER Le mode de génération de la matrice.

   MODE = -6 : La matrice est construite de telle sorte que sa 1-norme et sa
                 norme infinie sont contrôlées par les paramètres d'entrée
                 COND et ANORM. Le paramètre
                 MAX est ignoré.
   MODE = -5 : La matrice est construite de telle sorte que sa norme infinie
                 est contrôlée par ANORM. Le paramètre
                 COND est ignoré.
   MODE = -4 : La matrice est construite de telle sorte que sa 1-norme est
                 contrôlée par ANORM. Le paramètre
                 COND est ignoré.
   MODE = -3 : La matrice est construite de telle sorte que sa norme de Frobenius
                 est contrôlée par ANORM. Le paramètre
                 COND est ignoré.
   MODE = -2 : La matrice est construite de telle sorte que sa norme spectrale
                 est contrôlée par ANORM. Le paramètre
                 COND est ignoré.
   MODE = -1 : La matrice est construite de telle sorte que sa norme spectrale
                 est contrôlée par ANORM. Le paramètre
                 COND est ignoré.  Note: Ceci est identique à MODE = -2.
   MODE = 0 : La matrice est construite avec des éléments aléatoires, et les
               paramètres COND et ANORM sont ignorés.
   MODE = 1 : La matrice est construite de telle sorte que sa plus grande
               valeur singulière est MAX et sa plus petite valeur
               singulière est 1.0. La norme infinie est mise à ANORM.
   MODE = 2 : La matrice est construite de telle sorte que sa plus grande
               valeur singulière est MAX et sa plus petite valeur
               singulière est 1.0. La 1-norme est mise à ANORM.
   MODE = 3 : La matrice est construite de telle sorte que sa plus grande
               valeur singulière est MAX et sa plus petite valeur
               singulière est 1.0. La norme de Frobenius est mise à ANORM.
   MODE = 4 : La matrice est construite de telle sorte que sa plus grande
               valeur singulière est MAX et sa plus petite valeur
               singulière est 1.0. La norme spectrale est mise à ANORM.
   MODE = 5 : La matrice est construite de telle sorte que sa plus grande
               valeur singulière est MAX et sa plus petite valeur
               singulière est 1.0. La norme spectrale est mise à ANORM.
               Note: Ceci est identique à MODE = 4.
   MODE = 6 : La matrice est construite de telle sorte que sa plus grande
               valeur singulière est MAX et sa plus petite valeur
               singulière est 1.0. La norme infinie est mise à ANORM.
               Note: Ceci est identique à MODE = -5.
SEMAINE

DOUBLE PRECISION Le facteur d'échelle pour les valeurs des éléments de la matrice.

COND

DOUBLE PRECISION Le rapport entre la plus grande et la plus petite valeur singulière de la matrice.

MAX

DOUBLE PRECISION Le maximum de la valeur absolue des éléments de la matrice.

MATYPE

CHARACTER*1 Spécifie le type de matrice à générer.

   MATYPE = 'G' : Matrice générale.
   MATYPE = 'S' : Matrice symétrique.
   MATYPE = 'H' : Matrice hermitienne.
   MATYPE = 'T' : Matrice triangulaire supérieure.
   MATYPE = 'L' : Matrice triangulaire inférieure.
   MATYPE = 'B' : Matrice bidiagonale supérieure.
   MATYPE = 'Q' : Matrice bidiagonale inférieure.
   MATYPE = 'U' : Matrice unitaire.
   MATYPE = 'R' : Matrice réelle.
KL

INTEGER Le nombre de sous-diagonales inférieures.

KU

INTEGER Le nombre de super-diagonales supérieures.

ANORM

DOUBLE PRECISION Si ANORM est non négatif, alors A sera mis à l'échelle par un nombre réel non négatif pour que la norme de l'élément maximum de A soit ANORM.

Non modifié.

A

COMPLEX*16 Tableau de dimension ( LDA, N ). En sortie, A est la matrice de test souhaitée.

Modifié.

LDA

INTEGER LDA spécifie la première dimension de A telle que déclarée dans le programme appelant. LDA doit être au moins M.

Non modifié.

WORK

COMPLEX*16 Tableau de dimension ( 3*N ). Espace de travail.

Modifié.

INFO

INTEGER Code d'erreur. En sortie, INFO sera défini à l'une des valeurs suivantes:

             0 => retour normal
            -1 => N négatif
            -2 => DIST chaîne illégale
            -5 => MODE n'est pas dans la plage -6 à 6
            -6 => COND inférieur à 1.0, et MODE ni -6, 0 ni 6
            -9 => RSIGN n'est pas 'T' ou 'F'
           -10 => UPPER n'est pas 'T' ou 'F'
           -11 => SIM n'est pas 'T' ou 'F'
           -12 => MODE=0 et DS a une valeur singulière nulle.
           -13 => MODE n'est pas dans la plage -5 à 5.
           -14 => MODE est non nul et CONDS est inférieur à 1.
           -15 => KL est inférieur à 1.
           -16 => KU est inférieur à 1, ou KL et KU sont tous deux inférieurs à
                  N-1.
           -19 => LDA est inférieur à M.
             1 => Erreur de retour de ZLATM1 (calcul de D)
             2 => Impossible de mettre à l'échelle vers DMAX (la valeur propre maximale est 0)
             3 => Erreur de retour de DLATM1 (calcul de DS)
             4 => Erreur de retour de ZLARGE
             5 => Valeur singulière nulle de DLATM1.
