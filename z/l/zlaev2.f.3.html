sous-programme zlaev2 (complex*16 a, complex*16 b, complex*16 c, double precision rt1, double precision rt2, double precision cs1, complex*16 sn1)

ZLAEV2 calcule les valeurs propres et vecteurs propres d'une matrice hermitienne/symétrique 2x2.

Objectif :

!>
!> ZLAEV2 calcule la décomposition en valeurs propres d'une matrice hermitienne 2x2
!>    [  A         B  ]
!>    [  CONJG(B)  C  ].
!> Au retour, RT1 est la valeur propre de valeur absolue plus grande, RT2 est la
!> valeur propre de valeur absolue plus petite, et (CS1,SN1) est le vecteur propre
!> droit unitaire pour RT1, donnant la décomposition
!>
!> [ CS1  CONJG(SN1) ] [    A     B ] [ CS1 -CONJG(SN1) ] = [ RT1  0  ]
!> [-SN1     CS1     ] [ CONJG(B) C ] [ SN1     CS1     ]   [  0  RT2 ].
!>

Paramètres

A 
!>          A est COMPLEX*16
!>         L'élément (1,1) de la matrice 2x2.
!>

B

!>          B est COMPLEX*16
!>         L'élément (1,2) et le conjugué de l'élément (2,1) de
!>         la matrice 2x2.
!>

C

!>          C est COMPLEX*16
!>         L'élément (2,2) de la matrice 2x2.
!>

RT1

!>          RT1 est DOUBLE PRECISION
!>         La valeur propre de valeur absolue plus grande.
!>

RT2

!>          RT2 est DOUBLE PRECISION
!>         La valeur propre de valeur absolue plus petite.
!>

CS1

!>          CS1 est DOUBLE PRECISION
!>

SN1

!>          SN1 est COMPLEX*16
!>         Le vecteur (CS1, SN1) est un vecteur propre droit unitaire pour RT1.
!>

Détails supplémentaires :

!>
!>  RT1 est précis à quelques ULPs près, à l'exception des débordements/sous-dépassements.
!>
!>  RT2 peut être imprécis en cas d'annulation massive dans le
!>  déterminant A*C-B*B ; une arithmétique à plus haute précision, arrondie correctement ou
!>  tronquée correctement serait nécessaire pour calculer RT2
!>  précisément dans tous les cas.
!>
!>  CS1 et SN1 sont précis à quelques ULPs près, à l'exception des débordements/sous-dépassements.
!>
!>  Le débordement n'est possible que si RT1 est à un facteur 5 du débordement.
!>  Le sous-dépassement est sans danger si les données d'entrée sont 0 ou dépassent
!>     seuil_sous-dépassement / macheps.
!>
