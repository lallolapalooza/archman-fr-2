Documentation de la fonction/sous-routine

sous-routine zlatmr (entier m, entier n, caractère dist, entier, dimension( 4 ) iseed, caractère sym, complexe*16, dimension( * ) d, entier mode, double précision cond, complexe*16 dmax, caractère rsign, caractère grade, complexe*16, dimension( * ) dl, entier model, double précision condl, complexe*16, dimension( * ) dr, entier moder, double précision condr, caractère pivtng, entier, dimension( * ) ipivot, entier kl, entier ku, double précision sparse, double précision anorm, caractère pack, complexe*16, dimension( lda, * ) a, entier lda, entier, dimension( * ) iwork, entier info)

ZLATMR

Objectif :

!>
!>    ZLATMR génère des matrices aléatoires de divers types pour tester
!>    les programmes LAPACK.
!>
!>    ZLATMR opère en appliquant la séquence suivante d'opérations :
!>
!>      Générer une matrice A avec des entrées aléatoires de distribution DIST
!>         qui est symétrique si SYM='S', hermitienne si SYM='H', et
!>         non symétrique si SYM='N'.
!>
!>      Définir la diagonale à D, où D peut être entré ou
!>         calculé selon MODE, COND, DMAX et RSIGN
!>         comme décrit ci-dessous.
!>
!>      Graduer la matrice, si désiré, par la gauche et/ou par la droite
!>         selon GRADE. Les entrées DL, MODEL, CONDL, DR,
!>         MODER et CONDR déterminent également la graduation comme décrit
!>         ci-dessous.
!>
!>      Permuter, si désiré, les lignes et/ou les colonnes selon
!>         PIVTNG et IPIVOT.
!>
!>      Mettre des entrées aléatoires à zéro, si désiré, pour obtenir une matrice
!>         aléatoire creuse selon SPARSE.
!>
!>      Faire de A une matrice bande, si désiré, en mettant à zéro la matrice
!>         en dehors d'une bande de largeur inférieure KL et de largeur supérieure KU.
!>
!>      Échelonner A, si désiré, pour avoir une entrée maximale ANORM.
!>
!>      Empaqueter la matrice si désiré. Les options spécifiées par PACK sont :
!>         pas d'empaquetage
!>         mettre à zéro la moitié supérieure (si symétrique ou hermitienne)
!>         mettre à zéro la moitié inférieure (si symétrique ou hermitienne)
!>         stocker la moitié supérieure par colonne (si symétrique ou hermitienne
!>             ou triangulaire supérieure carrée)
!>         stocker la moitié inférieure par colonne (si symétrique ou hermitienne
!>             ou triangulaire inférieure carrée)
!>             identique à la moitié supérieure par ligne si symétrique
!>             identique à la moitié supérieure conjuguée par ligne si hermitienne
!>         stocker le triangle inférieur en format bande
!>             (si symétrique ou hermitienne)
!>         stocker le triangle supérieur en format bande
!>             (si symétrique ou hermitienne)
!>         stocker toute la matrice en format bande
!>
!>    Note : Si deux appels à ZLATMR diffèrent uniquement par le paramètre PACK,
!>          ils généreront des matrices mathématiquement équivalentes.
!>
!>          Si deux appels à ZLATMR ont tous deux une bande complète (KL = M-1
!>          et KU = N-1), et diffèrent uniquement par les paramètres PIVTNG et PACK,
!>          alors les matrices générées ne différeront que par l'ordre des lignes
!>          et/ou des colonnes, et contiendront sinon les mêmes données. Cette cohérence
!>          ne peut être et n'est pas maintenue avec une bande inférieure à la bande complète.
!>

Paramètres

M 
!>          M est ENTIER
!>           Nombre de lignes de A. Non modifié.
!>

N

!>          N est ENTIER
!>           Nombre de colonnes de A. Non modifié.
!>

DIST

!>          DIST est CARACTERE*1
!>           À l'entrée, DIST spécifie le type de distribution à utiliser
!>           pour générer une matrice aléatoire.
!>           'U' => parties réelle et imaginaire sont indépendantes
!>                  UNIFORME( 0, 1 )  ( 'U' pour uniforme )
!>           'S' => parties réelle et imaginaire sont indépendantes
!>                  UNIFORME( -1, 1 ) ( 'S' pour symétrique )
!>           'N' => parties réelle et imaginaire sont indépendantes
!>                  NORMALE( 0, 1 )   ( 'N' pour normale )
!>           'D' => uniforme sur l'intérieur du disque unité ( 'D' pour disque )
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau ENTIER, dimension (4)
!>           À l'entrée, ISEED spécifie la graine du générateur de nombres
!>           aléatoires. Les valeurs doivent être comprises entre 0 et 4095 inclus,
!>           et ISEED(4) doit être impair. Le générateur de nombres aléatoires
!>           utilise une séquence congruente linéaire limitée à de petits
!>           entiers, et devrait donc produire des nombres aléatoires indépendants
!>           de la machine. Les valeurs de ISEED sont modifiées à la sortie,
!>           et peuvent être utilisées dans l'appel suivant à ZLATMR
!>           pour continuer la même séquence de nombres aléatoires.
!>           Modifié à la sortie.
!>

SYM

!>          SYM est CARACTERE*1
!>           Si SYM='S', la matrice générée est symétrique.
!>           Si SYM='H', la matrice générée est hermitienne.
!>           Si SYM='N', la matrice générée est non symétrique.
!>           Non modifié.
!>

D

!>          D est un tableau COMPLEX*16, dimension (min(M,N))
!>           À l'entrée, ce tableau spécifie les entrées diagonales
!>           de la diagonale de A. D peut être spécifié
!>           à l'entrée, ou défini selon MODE et COND comme décrit
!>           ci-dessous. Si la matrice est hermitienne, la partie réelle de D
!>           sera utilisée. Peut être modifié à la sortie si MODE est non nul.
!>

MODE

!>          MODE est ENTIER
!>           À l'entrée, décrit comment D doit être utilisé :
!>           MODE = 0 signifie utiliser D en entrée
!>           MODE = 1 définit D(1)=1 et D(2:N)=1.0/COND
!>           MODE = 2 définit D(1:N-1)=1 et D(N)=1.0/COND
!>           MODE = 3 définit D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 définit D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 définit D à des nombres aléatoires dans l'intervalle
!>                    ( 1/COND , 1 ) tels que leurs logarithmes
!>                    sont uniformément distribués.
!>           MODE = 6 définit D à des nombres aléatoires provenant de la même distribution
!>                    que le reste de la matrice.
!>           MODE < 0 a la même signification que ABS(MODE), sauf que
!>              l'ordre des éléments de D est inversé.
!>           Ainsi, si MODE est positif, D a des entrées allant de
!>              1 à 1/COND, si négatif, de 1/COND à 1,
!>           Non modifié.
!>

COND

!>          COND est DOUBLE PRÉCISION
!>           À l'entrée, utilisé comme décrit sous MODE ci-dessus.
!>           S'il est utilisé, il doit être >= 1. Non modifié.
!>

DMAX

!>          DMAX est COMPLEX*16
!>           Si MODE n'est ni -6, 0 ni 6, la diagonale est échelonnée par
!>           DMAX / max(abs(D(i))), de sorte que l'entrée maximale absolue
!>           de la diagonale soit abs(DMAX). Si DMAX est complexe (ou zéro),
!>           la diagonale sera échelonnée par un nombre complexe (ou zéro).
!>

RSIGN

!>          RSIGN est CARACTERE*1
!>           Si MODE n'est ni -6, 0 ni 6, spécifie le signe de la diagonale
!>           comme suit :
!>           'T' => les entrées diagonales sont multipliées par un nombre complexe
!>                  aléatoire uniformément distribué avec une valeur absolue de 1
!>           'F' => diagonale inchangée

GRADE

!>          GRADE est CHARACTER*1
!>           Spécifie le classement de la matrice comme suit :
!>           'N'  => pas de classement
!>           'L'  => matrice pré-multipliée par diag( DL )
!>                   (uniquement si la matrice est non symétrique)
!>           'R'  => matrice post-multipliée par diag( DR )
!>                   (uniquement si la matrice est non symétrique)
!>           'B'  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( DR )
!>                   (uniquement si la matrice est non symétrique)
!>           'H'  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( CONJG(DL) )
!>                   (uniquement si la matrice est hermitienne ou non symétrique)
!>           'S'  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( DL )
!>                   (uniquement si la matrice est symétrique ou non symétrique)
!>           'E'  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par inv( diag( DL ) )
!>                         ( 'S' pour similarité )
!>                   (uniquement si la matrice est non symétrique)
!>                   Note : si GRADE='S', alors M doit être égal à N.
!>           Non modifié.
!>

DL

!>          DL est un tableau COMPLEX*16, dimension (M)
!>           Si MODEL=0, alors à l'entrée ce tableau spécifie les entrées diagonales
!>           d'une matrice diagonale utilisée comme décrit ci-dessus pour GRADE. Si MODEL n'est pas zéro, alors DL sera défini
!>           selon MODEL et CONDL, de manière analogue à la façon dont D est défini
!>           selon MODE et COND (sauf qu'il n'y a pas de paramètre DMAX pour DL).
!>           Si GRADE='E', alors DL ne doit pas contenir d'entrées nulles.
!>           Non référencé si GRADE = 'N' ou 'R'. Modifié en sortie.
!>

MODEL

!>          MODEL est INTEGER
!>           Spécifie comment le tableau diagonal DL doit être calculé,
!>           tout comme MODE spécifie comment D doit être calculé.
!>           Non modifié.
!>

CONDL

!>          CONDL est DOUBLE PRECISION
!>           Lorsque MODEL n'est pas zéro, spécifie le conditionnement
!>           du DL calculé. Non modifié.
!>

DR

!>          DR est un tableau COMPLEX*16, dimension (N)
!>           Si MODER=0, alors à l'entrée ce tableau spécifie les entrées diagonales
!>           d'une matrice diagonale utilisée comme décrit ci-dessus pour GRADE. Si MODER n'est pas zéro, alors DR sera défini
!>           selon MODER et CONDR, de manière analogue à la façon dont D est défini
!>           selon MODE et COND (sauf qu'il n'y a pas de paramètre DMAX pour DR).
!>           Non référencé si GRADE = 'N', 'L', 'H' ou 'S'.
!>           Modifié en sortie.
!>

MODER

!>          MODER est INTEGER
!>           Spécifie comment le tableau diagonal DR doit être calculé,
!>           tout comme MODE spécifie comment D doit être calculé.
!>           Non modifié.
!>

CONDR

!>          CONDR est DOUBLE PRECISION
!>           Lorsque MODER n'est pas zéro, spécifie le conditionnement
!>           du DR calculé. Non modifié.
!>

PIVTNG

!>          PIVTNG est CHARACTER*1
!>           À l'entrée spécifie les permutations de pivotement comme suit :
!>           'N' ou ' ' => aucune.
!>           'L' => pivotement gauche ou par lignes (la matrice doit être non symétrique).
!>           'R' => pivotement droit ou par colonnes (la matrice doit être
!>                  non symétrique).
!>           'B' ou 'F' => les deux ou pivotement complet, c'est-à-dire des deux côtés.
!>                         Dans ce cas, M doit être égal à N.
!>
!>           Si deux appels à ZLATMR ont tous deux une bande passante complète (KL = M-1
!>           et KU = N-1), et ne diffèrent que par les paramètres PIVTNG et PACK,
!>           alors les matrices générées ne différeront que par l'ordre des lignes et/ou des colonnes, et
!>           contiendront autrement les mêmes données. Cette cohérence ne peut pas être
!>           maintenue avec une bande passante inférieure à la complète.
!>

IPIVOT

!>          IPIVOT est un tableau INTEGER, dimension (N ou M)
!>           Ce tableau spécifie la permutation utilisée. Après que la
!>           matrice de base est générée, les lignes, les colonnes, ou les deux
!>           sont permutées. Si, par exemple, le pivotement par lignes est sélectionné, ZLATMR
!>           commence par la *dernière* ligne et échange la M-ème ligne et la
!>           ligne IPIVOT(M), puis passe à la ligne avant-dernière,
!>           échangeant la (M-1)-ème ligne et la ligne IPIVOT(M-1),
!>           et ainsi de suite. En termes de , la permutation est
!>           (1 IPIVOT(1)) (2 IPIVOT(2)) ... (M IPIVOT(M))
!>           où le cycle le plus à droite est appliqué en premier. C'est l'*inverse*
!>           de l'effet du pivotement dans LINPACK. L'idée
!>           est que la factorisation (avec pivotement) d'une matrice identité
!>           qui a été pivotée en inverse de cette manière devrait
!>           produire un vecteur de pivot identique à IPIVOT.
!>           Non référencé si PIVTNG = 'N'. Non modifié.
!>

KL

!>          KL est INTEGER
!>           À l'entrée spécifie la bande inférieure de la matrice. Par
!>           exemple, KL=0 implique triangulaire supérieure, KL=1 implique de Hessenberg
!>           supérieure, et KL au moins M-1 implique que la matrice n'est pas
!>           bande. Doit être égal à KU si la matrice est symétrique ou hermitienne.
!>           Non modifié.
!>

KU

!>          KU est INTEGER
!>           À l'entrée spécifie la bande supérieure de la matrice. Par
!>           exemple, KU=0 implique triangulaire inférieure, KU=1 implique de Hessenberg
!>           inférieure, et KU au moins N-1 implique que la matrice n'est pas
!>           bande. Doit être égal à KL si la matrice est symétrique ou hermitienne.
!>           Non modifié.
!>

SPARSE

!>          SPARSE est DOUBLE PRECISION
!>           À l'entrée spécifie la sparsité de la matrice si une matrice creuse
!>           doit être générée. SPARSE doit être compris entre
!>           0 et 1. Pour générer une matrice creuse, pour chaque entrée de matrice
!>           un nombre aléatoire uniforme ( 0, 1 ) x est généré et
!>           comparé à SPARSE ; si x est plus grand, l'entrée de la matrice
!>           n'est pas modifiée et si x est plus petit, l'entrée est mise
!>           à zéro. Ainsi, en moyenne, une fraction SPARSE des
!>           entrées sera mise à zéro.
!>           Non modifié.
!>

ANORM

!>          ANORM est DOUBLE PRECISION
!>           À l'entrée spécifie l'entrée maximale de la matrice de sortie
!>           (la matrice de sortie sera multipliée par une constante de sorte que
!>           sa plus grande valeur absolue soit égale à ANORM)
!>           si ANORM est non négatif. Si ANORM est négatif, aucune mise à l'échelle
!>           n'est effectuée. Non modifié.
!>

PACK

!>          PACK est CHARACTER*1
!>           À l'entrée spécifie le conditionnement de la matrice comme suit :
!>           'N' => pas de conditionnement
!>           'U' => mise à zéro de toutes les entrées sous-diagonales
!>                  (si symétrique ou hermitienne)
!>           'L' => mise à zéro de toutes les entrées sur-diagonales
!>                  (si symétrique ou hermitienne)
!>           'C' => stockage du triangle supérieur par colonnes
!>                  (uniquement si la matrice est carrée symétrique ou hermitienne ou
!>                   triangulaire supérieure)
!>           'R' => stockage du triangle inférieur par colonnes
!>                  (uniquement si la matrice est carrée symétrique ou hermitienne ou
!>                   triangulaire inférieure)
!>                  (identique à la moitié supérieure en lignes si symétrique)
!>                  (identique à la moitié supérieure conjuguée en lignes si hermitienne)
!>           'B' => stockage du triangle inférieur selon le schéma de stockage bande
!>                  (uniquement si la matrice est symétrique ou hermitienne)
!>           'Q' => stockage du triangle supérieur selon le schéma de stockage bande
!>                  (uniquement si la matrice est symétrique ou hermitienne)
!>           'Z' => stockage de la matrice entière selon le schéma de stockage bande
!>                      (le pivotement peut être assuré en utilisant cette
!>                      option pour stocker A dans les lignes finales de
!>                      l'espace alloué)
!>
!>           En utilisant ces options, les différents schémas de stockage LAPACK, conditionnés et en bande,
!>           peuvent être obtenus :
!>           GB               - utiliser 'Z'
!>           PB, HB ou TB     - utiliser 'B' ou 'Q'
!>           PP, HP ou TP     - utiliser 'C' ou 'R'
!>
!>           Si deux appels à ZLATMR diffèrent uniquement par le paramètre PACK,
!>           ils généreront des matrices mathématiquement équivalentes.
!>           Non modifié.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>           En sortie, A est la matrice de test souhaitée. Seules les
!>           entrées de A qui sont significatives en sortie
!>           seront référencées (même si A est au format de stockage conditionné ou bande).
!>           Les 'coins inoccupés' de A en
!>           format bande seront mis à zéro.
!>

LDA

!>          LDA est INTEGER
!>           À l'entrée, LDA spécifie la première dimension de A telle que
!>           déclarée dans le programme appelant.
!>           Si PACK='N', 'U' ou 'L', LDA doit être au moins max ( 1, M ).
!>           Si PACK='C' ou 'R', LDA doit être au moins 1.
!>           Si PACK='B' ou 'Q', LDA doit être MIN ( KU+1, N )
!>           Si PACK='Z', LDA doit être au moins KUU+KLL+1, où
!>           KUU = MIN ( KU, N-1 ) et KLL = MIN ( KL, M-1 )
!>           Non modifié.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (N ou M)
!>           Espace de travail. Non référencé si PIVTNG = 'N'. Modifié en sortie.
!>

INFO

!>          INFO est INTEGER
!>           Paramètre d'erreur en sortie :
!>             0 => retour normal
!>            -1 => M négatif ou inégal à N et SYM='S' ou 'H'
!>            -2 => N négatif
!>            -3 => DIST chaîne illégale
!>            -5 => SYM chaîne illégale
!>            -7 => MODE hors de la plage -6 à 6
!>            -8 => COND inférieur à 1.0, et MODE ni -6, ni 0, ni 6
!>           -10 => MODE ni -6, ni 0, ni 6 et RSIGN chaîne illégale
!>           -11 => GRADE chaîne illégale, ou GRADE='E' et
!>                  M non égal à N, ou GRADE='L', 'R', 'B', 'S' ou 'E'
!>                  et SYM = 'H', ou GRADE='L', 'R', 'B', 'H' ou 'E'
!>                  et SYM = 'S'
!>           -12 => GRADE = 'E' et DL contient zéro
!>           -13 => MODEL hors de la plage -6 à 6 et GRADE= 'L', 'B', 'H',
!>                  'S' ou 'E'
!>           -14 => CONDL inférieur à 1.0, GRADE='L', 'B', 'H', 'S' ou 'E',
!>                  et MODEL ni -6, ni 0, ni 6
!>           -16 => MODER hors de la plage -6 à 6 et GRADE= 'R' ou 'B'
!>           -17 => CONDR inférieur à 1.0, GRADE='R' ou 'B', et
!>                  MODER ni -6, ni 0, ni 6
!>           -18 => PIVTNG chaîne illégale, ou PIVTNG='B' ou 'F' et
!>                  M non égal à N, ou PIVTNG='L' ou 'R' et SYM='S'
!>                  ou 'H'
!>           -19 => IPIVOT contient un nombre hors plage et
!>                  PIVTNG non égal à 'N'
!>           -20 => KL négatif
!>           -21 => KU négatif, ou SYM='S'

NAME


zlatmr — LAPACK routine (version 3.12.0)






SYNOPSIS


 SUBROUTINE ZLATMR( N,      M,      NB,     ISPC,     DIAG,
      JL,      JU,      KL,      KU,      ANORM,
      PACK,     EQUED,    R,       C,       A,
      LDA,     WORK,    INFO )
 


Parameters




CHARACTER N




INTEGER N




Number of rows of the matrix A.




INTEGER M




Number of columns of the matrix A.




INTEGER NB




The number of blocks in the block cyclic decomposition of A.




INTEGER ISPC




The type of sparsity structure of A.




CHARACTER DIAG




Specifies the type of diagonal entries.




INTEGER JL




The row index of the first subdiagonal, if DIAG = 'R' or 'C'.




INTEGER JU




The row index of the first superdiagonal, if DIAG = 'R' or 'C'.




INTEGER KL




The number of subdiagonals of the matrix A.




INTEGER KU




The number of superdiagonals of the matrix A.




REAL ANORM




The desired norm of the matrix A.




CHARACTER PACK




Specifies the storage format of A.




CHARACTER EQUED




Specifies whether or not the equilibration factors R and C are
    used.




REAL R( * )




The array R contains the diagonal entries of the diagonal matrix
    D.




REAL C( * )




The array C contains the diagonal entries of the diagonal matrix
    D.




COMPLEX A( LDA, * )




The matrix A to be generated.




INTEGER LDA




The leading dimension of the array A.




COMPLEX WORK( * )




Workspace array.




INTEGER INFO




INFO = 0:  successful exit
    < 0:  if INFO = -i, the i-th argument had an illegal value.
    > 0:  a problem occurred during generation










Function/Subroutine Documentation






!> \brief \b ZLATMR
!>
!> \par Purpose
!>    ZLATMR generates a complex matrix A that is randomly chosen
!>    from the set of matrices having dimension N, M, non-zero elements
!>    equal to NB, and sparsity structure ISPC, norm equal to ANORM,
!>    and optionally, with a specified diagonal condition number.
!>
!> \par Arguments
!> \verbatim
!>  N      - INTEGER
!>           The number of rows of the matrix A.  N >= 0.
!>
!>  M      - INTEGER
!>           The number of columns of the matrix A.  M >= 0.
!>
!>  NB     - INTEGER
!>           The number of blocks in the block cyclic decomposition of A.
!>           NB > 0.
!>
!>  ISPC   - INTEGER
!>           Specifies the sparsity structure of A.
!>           ISPC = 0: dense matrix.
!>           ISPC = 1: upper triangular matrix.
!>           ISPC = 2: lower triangular matrix.
!>           ISPC = 3: upper bidiagonal matrix.
!>           ISPC = 4: lower bidiagonal matrix.
!>           ISPC = 5: symmetric matrix with lower triangular structure.
!>           ISPC = 6: symmetric matrix with upper triangular structure.
!>           ISPC = 7: general sparse matrix with NB blocks.
!>
!>  DIAG   - CHARACTER*1
!>           Specifies the type of diagonal entries.
!>           DIAG = 'N': none of the diagonal entries are specified.
!>           DIAG = 'A': all of the diagonal entries are specified.
!>           DIAG = 'L': some of the diagonal entries are specified.
!>           DIAG = 'U': some of the diagonal entries are specified.
!>
!>  JL     - INTEGER
!>           The row index of the first subdiagonal, if DIAG = 'R' or 'C'.
!>           1 <= JL <= N.
