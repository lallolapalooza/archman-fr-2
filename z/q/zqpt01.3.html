double precision function zqpt01 (integer m, integer n, integer k, complex*16, dimension( lda, * ) a, complex*16, dimension( lda, * ) af, integer lda, complex*16, dimension( * ) tau, integer, dimension( * ) jpvt, complex*16, dimension( lwork ) work, integer lwork)

ZQPT01

But :

!>
!> ZQPT01 teste la factorisation QR avec pivot de la matrice A. Le
!> tableau AF contient la factorisation QR (éventuellement partielle) de A, où
!> le triangle supérieur de AF(1:k,1:k) est un facteur triangulaire partiel,
!> les entrées sous la diagonale dans les k premières colonnes sont les
!> vecteurs de Householder, et le reste de AF contient une matrice mise à jour partiellement.
!>
!> Cette fonction retourne ||A*P - Q*R|| / ( ||norm(A)||*eps*max(M,N) )
!>

Paramètres

M 
!>          M est de type INTEGER
!>          Le nombre de lignes des matrices A et AF.
!>

N

!>          N est de type INTEGER
!>          Le nombre de colonnes des matrices A et AF.
!>

K

!>          K est de type INTEGER
!>          Le nombre de colonnes de AF qui ont été réduites
!>          en forme triangulaire supérieure.
!>

A

!>          A est un tableau de type COMPLEX*16, de dimension (LDA, N)
!>          La matrice originale A.
!>

AF

!>          AF est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>          La sortie (éventuellement partielle) de ZGEQPF. Le triangle supérieur
!>          de AF(1:k,1:k) est un facteur triangulaire partiel, les entrées
!>          sous la diagonale dans les k premières colonnes sont les vecteurs de
!>          Householder, et le reste de AF contient une matrice mise à jour partiellement.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale des tableaux A et AF.
!>

TAU

!>          TAU est un tableau de type COMPLEX*16, de dimension (K)
!>          Détails des transformations de Householder tels que retournés par
!>          ZGEQPF.
!>

JPVT

!>          JPVT est un tableau de type INTEGER, de dimension (N)
!>          Informations de pivot telles que retournées par ZGEQPF.
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est de type INTEGER
!>          La longueur du tableau WORK. LWORK >= M*N+N.
!>
