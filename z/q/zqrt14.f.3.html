Documentation de la fonction/sous-routine

double precision function zqrt14 (character trans, integer m, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( lwork ) work, integer lwork)

ZQRT14

But :

!>
!> ZQRT14 vérifie si X appartient à l'espace des lignes de A ou de A'. Il le fait
!> en mettant à l'échelle X et A de telle sorte que leurs normes soient dans l'intervalle
!> [sqrt(eps), 1/sqrt(eps)], puis en calculant une factorisation QR de [A,X]
!> (si TRANS = 'C') ou une factorisation LQ de [A',X]' (si TRANS = 'N'),
!> et en renvoyant la norme du triangle de queue, mise à l'échelle par
!> MAX(M,N,NRHS)*eps.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N' : Pas de transposée, vérifie si X appartient à l'espace des lignes de A
!>          = 'C' : Transposée conjuguée, vérifie si X appartient à l'espace des lignes de A'.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de X.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice A de taille M par N.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Si TRANS = 'N', la matrice X de taille N par NRHS.
!>          Si TRANS = 'C', la matrice X de taille M par NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.
!>

WORK

!>          WORK est un tableau COMPLEX*16 de dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          taille du tableau de travail requis
!>          Si TRANS = 'N', LWORK >= (M+NRHS)*(N+2) ;
!>          si TRANS = 'C', LWORK >= (N+NRHS)*(M+2).
!>
