sous-programme zqlt02 (integer m, integer n, integer k, complex*16, dimension( lda, * ) a, complex*16, dimension( lda, * ) af, complex*16, dimension( lda, * ) q, complex*16, dimension( lda, * ) l, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result)

ZQLT02

But :

!>
!> ZQLT02 teste ZUNGQL, qui génère une matrice m x n, Q, avec des colonnes
!> orthonormées, définie comme le produit de k réflecteurs élémentaires.
!>
!> Étant donné la factorisation QL d'une matrice m x n, A, ZQLT02 génère
!> la matrice orthogonale Q définie par la factorisation des k dernières
!> colonnes de A ; il compare L(m-n+1:m,n-k+1:n) avec
!> Q(1:m,m-n+1:m)'*A(1:m,n-k+1:n), et vérifie que les colonnes de Q
!> sont orthonormées.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q à générer. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q à générer.
!>          M >= N >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q. N >= K >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice m x n A qui a été factorisée par ZQLT01.
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDA,N)
!>          Détails de la factorisation QL de A, tels que retournés par ZGEQLF.
!>          Voir ZGEQLF pour plus de détails.
!>

Q

!>          Q est un tableau COMPLEX*16, dimension (LDA,N)
!>

L

!>          L est un tableau COMPLEX*16, dimension (LDA,N)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, Q et L. LDA >= M.
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (N)
!>          Les facteurs scalaires des réflecteurs élémentaires correspondant
!>          à la factorisation QL dans AF.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (M)
!>

RESULT

!>          RESULT est un tableau DOUBLE PRÉCISION, dimension (2)
!>          Les ratios de test :
!>          RESULT(1) = norm( L - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
