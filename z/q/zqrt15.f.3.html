Documentation de la fonction/sous-routine

sous-routine zqrt15 (entier scale, entier rksel, entier m, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, double precision, dimension( * ) s, entier rank, double precision norma, double precision normb, entier, dimension( 4 ) iseed, complexe*16, dimension( lwork ) work, entier lwork)

ZQRT15

But :

!>
!> ZQRT15 génère une matrice de rang plein ou déficient et de différentes
!> normes.
!>

Paramètres

SCALE 
!>          SCALE est ENTIER
!>          SCALE = 1 : matrice normalement mise à l'échelle
!>          SCALE = 2 : matrice mise à l'échelle vers le haut
!>          SCALE = 3 : matrice mise à l'échelle vers le bas
!>

RKSEL

!>          RKSEL est ENTIER
!>          RKSEL = 1 : matrice de rang plein
!>          RKSEL = 2 : matrice de rang déficient
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice A.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de A.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de colonnes de B.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice A de taille M x N.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB, NRHS)
!>          Une matrice qui est dans l'espace image de la matrice A.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension MIN(M,N)
!>          Valeurs singulières de A.
!>

RANK

!>          RANK est ENTIER
!>          nombre de valeurs singulières non nulles de A.
!>

NORMA

!>          NORMA est DOUBLE PRECISION
!>          norme un de A.
!>

NORMB

!>          NORMB est DOUBLE PRECISION
!>          norme un de B.
!>

ISEED

!>          ISEED est un tableau entier, dimension (4)
!>          graine pour le générateur de nombres aléatoires.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est ENTIER
!>          longueur de l'espace de travail requis.
!>          LWORK >= MAX(M+MIN(M,N),NRHS*MIN(M,N),2*N+M)
!>
