ZQRT01

Documentation Fonction/Sous-routine

sous-routine zqrt01 (integer m, integer n, complex*16, dimension( lda, * ) a, complex*16, dimension( lda, * ) af, complex*16, dimension( lda, * ) q, complex*16, dimension( lda, * ) r, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result)

ZQRT01

Objectif :

!>
!> ZQRT01 teste ZGEQRF, qui calcule la factorisation QR d'une matrice m-par-n
!> A, et teste partiellement ZUNGQR qui forme la matrice orthogonale m-par-m
!> Q.
!>
!> ZQRT01 compare R avec Q'*A, et vérifie que Q est orthogonale.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice A m-par-n.
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDA,N)
!>          Détails de la factorisation QR de A, tels que retournés par ZGEQRF.
!>          Voir ZGEQRF pour plus de détails.
!>

Q

!>          Q est un tableau COMPLEX*16, dimension (LDA,M)
!>          La matrice orthogonale Q m-par-m.
!>

R

!>          R est un tableau COMPLEX*16, dimension (LDA,max(M,N))
!>

LDA

!>          LDA est un entier
!>          La dimension principale des tableaux A, AF, Q et R.
!>          LDA >= max(M,N).
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (min(M,N))
!>          Les facteurs scalaires des réflexions élémentaires, tels que retournés
!>          par ZGEQRF.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (M)
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, dimension (2)
!>          Les rapports de test :
!>          RESULT(1) = norm( R - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
