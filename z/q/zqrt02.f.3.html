sous-routine zqrt02 (entier m, entier n, entier k, complexe*16, dimension( lda, * ) a, complexe*16, dimension( lda, * ) af, complexe*16, dimension( lda, * ) q, complexe*16, dimension( lda, * ) r, entier lda, complexe*16, dimension( * ) tau, complexe*16, dimension( lwork ) work, entier lwork, double_precision, dimension( * ) rwork, double_precision, dimension( * ) result)

ZQRT02

But :

!>
!> ZQRT02 teste ZUNGQR, qui génère une matrice Q de taille m x n avec
!> des colonnes orthonormées, définie comme le produit de k réflecteurs élémentaires.
!>
!> Étant donnée la factorisation QR d'une matrice A de taille m x n, ZQRT02 génère
!> la matrice orthogonale Q définie par la factorisation des k premières colonnes
!> de A ; elle compare R(1:n,1:k) avec Q(1:m,1:n)'*A(1:m,1:k),
!> et vérifie que les colonnes de Q sont orthonormées.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q à générer. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q à générer.
!>          M >= N >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. N >= K >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice A de taille m x n factorisée par ZQRT01.
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDA,N)
!>          Détails de la factorisation QR de A, tels que retournés par ZGEQRF.
!>          Voir ZGEQRF pour plus de détails.
!>

Q

!>          Q est un tableau COMPLEX*16, dimension (LDA,N)
!>

R

!>          R est un tableau COMPLEX*16, dimension (LDA,N)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, Q et R. LDA >= M.
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (N)
!>          Les facteurs scalaires des réflecteurs élémentaires correspondant
!>          à la factorisation QR dans AF.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (M)
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, dimension (2)
!>          Les rapports de test :
!>          RESULT(1) = norm( R - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
