Documentation de la fonction/sous-routine

double precision function zqrt11 (integer m, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( lwork ) work, integer lwork)

ZQRT11

Objectif:

!>
!> ZQRT11 calcule le rapport de test
!>
!>       || Q'*Q - I || / (eps * m)
!>
!> où la matrice orthogonale Q est représentée comme un produit de
!> transformations élémentaires. Chaque transformation a la forme
!>
!>    H(k) = I - tau(k) v(k) v(k)'
!>
!> où tau(k) est stocké dans TAU(k) et v(k) est un m-vecteur de la forme
!> [ 0 ... 0 1 x(k) ]', où x(k) est un vecteur de longueur m-k stocké
!> dans A(k+1:m,k).
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice A.
!>

K

!>          K est un entier
!>          Le nombre de colonnes de A dont les entrées sous-diagonales
!>          contiennent des informations sur les transformations orthogonales.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,K)
!>          Le résultat (éventuellement partiel) d'une routine de réduction QR.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A.
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (K)
!>          Les facteurs de mise à l'échelle tau pour les transformations élémentaires, tels que
!>          calculés par la routine de factorisation QR.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>          La longueur du tableau WORK.  LWORK >= M*M + M.
!>
