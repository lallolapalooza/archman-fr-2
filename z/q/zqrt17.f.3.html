double precision function zqrt17 (character trans, integer iresid, integer m, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldb, * ) c, complex*16, dimension( lwork ) work, integer lwork)

ZQRT17

But :

!>
!> ZQRT17 calcule le rapport
!>
!>    norm(R**H * op(A)) / ( norm(A) * alpha * max(M,N,NRHS) * EPS ),
!>
!> où R = B - op(A)*X, op(A) est A ou A**H, selon TRANS, EPS
!> est l'epsilon machine, et
!>
!>    alpha = norm(B) si IRESID = 1 (problème à résidu nul)
!>    alpha = norm(R) si IRESID = 2 (sinon).
!>
!> La norme utilisée est la 1-norme.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie si la transposée de A est utilisée ou non.
!>          = 'N':  Pas de transposée, op(A) = A.
!>          = 'C':  Transposée conjuguée, op(A) = A**H.
!>

IRESID

!>          IRESID est INTEGER
!>          IRESID = 1 indique un problème à résidu nul.
!>          IRESID = 2 indique un résidu non nul.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.
!>          Si TRANS = 'N', le nombre de lignes de la matrice B.
!>          Si TRANS = 'C', le nombre de lignes de la matrice X.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.
!>          Si TRANS = 'N', le nombre de lignes de la matrice X.
!>          Si TRANS = 'C', le nombre de lignes de la matrice B.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de colonnes des matrices X et B.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice A de taille m x n.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= M.
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Si TRANS = 'N', la matrice X de taille n x nrhs.
!>          Si TRANS = 'C', la matrice X de taille m x nrhs.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.
!>          Si TRANS = 'N', LDX >= N.
!>          Si TRANS = 'C', LDX >= M.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          Si TRANS = 'N', la matrice B de taille m x nrhs.
!>          Si TRANS = 'C', la matrice B de taille n x nrhs.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.
!>          Si TRANS = 'N', LDB >= M.
!>          Si TRANS = 'C', LDB >= N.
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK. LWORK >= NRHS*(M+N).
!>
