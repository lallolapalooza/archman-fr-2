ZQRT12

Documentation de la fonction/sous-programme

double precision function zqrt12 (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, complex*16, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork)

ZQRT12

Objectif :

!>
!> ZQRT12 calcule les valeurs singulières `svlues' de la partie trapézoïdale supérieure
!> de A(1:M,1:N) et renvoie le ratio
!>
!>      || svlues - s||/(||s||*eps*max(M,N))
!>

Paramètres

M 
!>          M est un ENTIER (INTEGER)
!>          Le nombre de lignes de la matrice A.
!>

N

!>          N est un ENTIER (INTEGER)
!>          Le nombre de colonnes de la matrice A.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          La matrice A de taille M par N. Seule la partie trapézoïdale supérieure est référencée.
!>

LDA

!>          LDA est un ENTIER (INTEGER)
!>          La dimension principale du tableau A.
!>

S

!>          S est un tableau DOUBLE PRECISION, de dimension (min(M,N))
!>          Les valeurs singulières de la matrice A.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER (INTEGER)
!>          La longueur du tableau WORK. LWORK >= M*N + 2*min(M,N) +
!>          max(M,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (2*min(M,N))
!>
