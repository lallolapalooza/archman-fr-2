Documentation de la fonction/sous-routine

sous-routine zqrt13 (entier scale, entier m, entier n, complexe*16, dimension( lda, * ) a, entier lda, double précision norma, entier, dimension( 4 ) iseed)

ZQRT13

Objectif :

!>
!> ZQRT13 génère une matrice de rang complet qui peut être mise à l'échelle
!> pour avoir une norme grande ou petite.
!>

Paramètres

SCALE 
!>          SCALE est ENTIER
!>          SCALE = 1 : matrice normalement mise à l'échelle
!>          SCALE = 2 : matrice mise à l'échelle vers le haut
!>          SCALE = 3 : matrice mise à l'échelle vers le bas
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice A.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de A.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice M par N, A.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.
!>

NORMA

!>          NORMA est DOUBLE PRÉCISION
!>          La norme un de A.
!>

ISEED

!>          ISEED est un tableau entier, dimension (4)
!>          Graine pour le générateur de nombres aléatoires
!>
