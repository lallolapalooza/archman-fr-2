sous-routine zqlt03 (integer m, integer n, integer k, complex*16, dimension( lda, * ) af, complex*16, dimension( lda, * ) c, complex*16, dimension( lda, * ) cc, complex*16, dimension( lda, * ) q, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result)

ZQLT03

But:

!>
!> ZQLT03 teste ZUNMQL, qui calcule Q*C, Q'*C, C*Q ou C*Q'.
!>
!> ZQLT03 compare les résultats d'un appel à ZUNMQL avec les résultats de
!> la formation explicite de Q par un appel à ZUNGQL, puis de la multiplication matricielle
!> par un appel à ZGEMM.
!>

Paramètres

M 
!>          M est un ENTIER
!>          L'ordre de la matrice orthogonale Q.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de lignes ou de colonnes de la matrice C; C est m-par-n si
!>          Q est appliqué à gauche, ou n-par-m si Q est appliqué à
!>          droite.  N >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice orthogonale Q.  M >= K >= 0.
!>

AF

!>          AF est un tableau COMPLEX*16, de dimension (LDA,N)
!>          Détails de la factorisation QL d'une matrice m-par-n, tel que
!>          retourné par ZGEQLF. Voir CGEQLF pour plus de détails.
!>

C

!>          C est un tableau COMPLEX*16, de dimension (LDA,N)
!>

CC

!>          CC est un tableau COMPLEX*16, de dimension (LDA,N)
!>

Q

!>          Q est un tableau COMPLEX*16, de dimension (LDA,M)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux AF, C, CC et Q.
!>

TAU

!>          TAU est un tableau COMPLEX*16, de dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires correspondant
!>          à la factorisation QL dans AF.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur de WORK.  LWORK doit être au moins M, et doit être
!>          M*NB, où NB est la taille de bloc pour cet environnement.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (M)
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, de dimension (4)
!>          Les rapports de test comparent deux techniques pour multiplier une
!>          matrice aléatoire C par une matrice orthogonale m-par-m Q.
!>          RESULT(1) = norm( Q*C - Q*C )  / ( M * norm(C) * EPS )
!>          RESULT(2) = norm( C*Q - C*Q )  / ( M * norm(C) * EPS )
!>          RESULT(3) = norm( Q'*C - Q'*C )/ ( M * norm(C) * EPS )
!>          RESULT(4) = norm( C*Q' - C*Q' )/ ( M * norm(C) * EPS )
!>
