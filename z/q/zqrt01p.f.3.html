Documentation de la fonction/sous-routine

sous-routine zqrt01p (integer m, integer n, complex*16, dimension( lda, * ) a, complex*16, dimension( lda, * ) af, complex*16, dimension( lda, * ) q, complex*16, dimension( lda, * ) r, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result)

ZQRT01P

Objectif :

!>
!> ZQRT01P teste ZGEQRFP, qui calcule la factorisation QR d'une matrice A de taille m x n,
!> et teste partiellement ZUNGQR qui forme la matrice orthogonale m x m, Q.
!>
!> ZQRT01P compare R avec Q'*A, et vérifie que Q est orthogonale.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

A

!>          A est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>          La matrice A de taille m x n.
!>

AF

!>          AF est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>          Détails de la factorisation QR de A, tels que retournés par ZGEQRFP.
!>          Voir ZGEQRFP pour plus de détails.
!>

Q

!>          Q est un tableau de type COMPLEX*16, de dimension (LDA,M)
!>          La matrice orthogonale m x m, Q.
!>

R

!>          R est un tableau de type COMPLEX*16, de dimension (LDA,max(M,N))
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale des tableaux A, AF, Q et R.
!>          LDA >= max(M,N).
!>

TAU

!>          TAU est un tableau de type COMPLEX*16, de dimension (min(M,N))
!>          Les facteurs scalaires des réflexions élémentaires, tels que retournés
!>          par ZGEQRFP.
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau de type DOUBLE PRECISION, de dimension (M)
!>

RESULT

!>          RESULT est un tableau de type DOUBLE PRECISION, de dimension (2)
!>          Les rapports de test :
!>          RESULT(1) = norm( R - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
