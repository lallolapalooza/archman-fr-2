ZFORCE(1) Manuel des commandes générales ZFORCE(1)

NOM

zforce - Forcer l'extension '.gz' sur tous les fichiers gzip

SYNTAXE

zforce [ nom ... ]

DESCRIPTION

La commande zforce force l'extension .gz sur tous les fichiers gzip afin que gzip ne les compresse pas deux fois. Ceci peut être utile pour les fichiers dont le nom a été tronqué après un transfert. Sur les systèmes avec une limitation de 14 caractères pour les noms de fichiers, le nom original est tronqué pour faire de la place pour le suffixe .gz. Par exemple, 12345678901234 est renommé en 12345678901.gz. Un nom de fichier tel que foo.tgz est laissé intact.

VOIR AUSSI

gzip(1), znew(1), zmore(1), zgrep(1), zdiff(1), gzexe(1)
