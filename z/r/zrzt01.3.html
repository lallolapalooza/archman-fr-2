Documentation de la fonction/sous-routine

double precision function zrzt01 (integer m, integer n, complex*16, dimension( lda, * ) a, complex*16, dimension( lda, * ) af, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( lwork ) work, integer lwork)

ZRZT01

Objectif :

!>
!> ZRZT01 renvoie
!>      || A - R*Q || / ( M * eps * ||A|| )
!> pour une matrice A trapézoïdale supérieure qui a été factorisée avec ZTZRZF.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes des matrices A et AF.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes des matrices A et AF.
!>

A

!>          A est un tableau de nombres complexes complexes*16 (COMPLEX*16),
!>          de dimension (LDA,N).
!>          La matrice A originale, trapézoïdale supérieure, de taille M par N.
!>

AF

!>          AF est un tableau de nombres complexes complexes*16 (COMPLEX*16),
!>          de dimension (LDA,N).
!>          Le résultat de ZTZRZF pour la matrice d'entrée A.
!>          La partie triangulaire inférieure n'est pas référencée.
!>

LDA

!>          LDA est un entier (INTEGER).
!>          La dimension principale des tableaux A et AF.
!>

TAU

!>          TAU est un tableau de nombres complexes complexes*16 (COMPLEX*16),
!>          de dimension (M).
!>          Détails des transformations de Householder renvoyés par ZTZRZF.
!>

WORK

!>          WORK est un tableau de nombres complexes complexes*16 (COMPLEX*16),
!>          de dimension (LWORK).
!>

LWORK

!>          LWORK est un entier (INTEGER).
!>          La longueur du tableau WORK. LWORK >= m*n + m.
!>
