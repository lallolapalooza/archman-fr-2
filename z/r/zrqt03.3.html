Documentation de la fonction/sous-routine

sous-routine zrqt03 (integer m, integer n, integer k, complex*16, dimension( lda, * ) af, complex*16, dimension( lda, * ) c, complex*16, dimension( lda, * ) cc, complex*16, dimension( lda, * ) q, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result)

ZRQT03

Objectif:

!>
!> ZRQT03 teste ZUNMRQ, qui calcule Q*C, Q'*C, C*Q ou C*Q'.
!>
!> ZRQT03 compare les résultats d'un appel à ZUNMRQ avec les résultats de
!> la formation explicite de Q par un appel à ZUNGRQ puis de la multiplication matricielle
!> par un appel à ZGEMM.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes ou de colonnes de la matrice C; C est n-par-m si
!>          Q est appliqué par la gauche, ou m-par-n si Q est appliqué par la
!>          droite.  M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          L'ordre de la matrice orthogonale Q.  N >= 0.
!>

K

!>          K est un entier (INTEGER)
!>          Le nombre de réflexions élémentaires dont le produit définit la
!>          matrice orthogonale Q.  N >= K >= 0.
!>

AF

!>          AF est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>          Détails de la factorisation RQ d'une matrice m-par-n, tel que
!>          retourné par ZGERQF. Voir CGERQF pour plus de détails.
!>

C

!>          C est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>

CC

!>          CC est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>

Q

!>          Q est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale des tableaux AF, C, CC et Q.
!>

TAU

!>          TAU est un tableau de type COMPLEX*16, de dimension (min(M,N))
!>          Les facteurs scalaires des réflexions élémentaires correspondant
!>          à la factorisation RQ dans AF.
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La longueur de WORK.  LWORK doit être au moins M, et devrait être
!>          M*NB, où NB est la taille du bloc pour cet environnement.
!>

RWORK

!>          RWORK est un tableau de type DOUBLE PRECISION, de dimension (M)
!>

RESULT

!>          RESULT est un tableau de type DOUBLE PRECISION, de dimension (4)
!>          Les rapports de test comparent deux techniques de multiplication d'une
!>          matrice aléatoire C par une matrice orthogonale Q de taille n-par-n.
!>          RESULT(1) = norm( Q*C - Q*C )  / ( N * norm(C) * EPS )
!>          RESULT(2) = norm( C*Q - C*Q )  / ( N * norm(C) * EPS )
!>          RESULT(3) = norm( Q'*C - Q'*C )/ ( N * norm(C) * EPS )
!>          RESULT(4) = norm( C*Q' - C*Q' )/ ( N * norm(C) * EPS )
!>
