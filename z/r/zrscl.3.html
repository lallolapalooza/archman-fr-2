subroutine zrscl (integer n, complex*16 a, complex*16, dimension( * ) x, integer incx)

ZDRSCL multiplie un vecteur par l'inverse d'un scalaire réel.

Objectif:

!>
!> ZRSCL multiplie un vecteur complexe x à n composantes par le scalaire complexe
!> 1/a. Ceci est fait sans dépassement de capacité ou sous-dépassement de capacité tant que
!> le résultat final x/a ne dépasse pas la capacité ou ne sous-dépasse pas la capacité.
!>

Paramètres

N 
!>          N est un entier
!>          Le nombre de composantes du vecteur x.
!>

A

!>          A est COMPLEX*16
!>          Le scalaire a utilisé pour diviser chaque composante de x.
!>          A ne doit pas être 0, sinon la subroutine divisera par zéro.
!>

X

!>          X est un tableau COMPLEX*16, dimension
!>                         (1+(N-1)*abs(INCX))
!>          Le vecteur x à n composantes.
!>

INCX

!>          INCX est un entier
!>          L'incrément entre les valeurs successives du vecteur SX.
!>          > 0 :  SX(1) = X(1) et SX(1+(i-1)*INCX) = x(i),     1< i<= n
!>
