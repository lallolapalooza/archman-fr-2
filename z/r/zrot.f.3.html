sous-programme zrot (integer n, complex*16, dimension( * ) cx, integer incx, complex*16, dimension( * ) cy, integer incy, double precision c, complex*16 s)

ZROT applique une rotation de plan avec un cosinus réel et un sinus complexe à une paire de vecteurs complexes.

Objectif :

!>
!> ZROT applique une rotation de plan, où le cosinus (C) est réel et le
!> sinus (S) est complexe, et les vecteurs CX et CY sont complexes.
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre d'éléments dans les vecteurs CX et CY.
!>

CX

!>          CX est un tableau COMPLEX*16, de dimension (N)
!>          En entrée, le vecteur X.
!>          En sortie, CX est écrasé par C*X + S*Y.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les valeurs successives de CX.  INCX <> 0.
!>

CY

!>          CY est un tableau COMPLEX*16, de dimension (N)
!>          En entrée, le vecteur Y.
!>          En sortie, CY est écrasé par -CONJG(S)*X + C*Y.
!>

INCY

!>          INCY est un ENTIER
!>          L'incrément entre les valeurs successives de CY.  INCX <> 0.
!>

C

!>          C est un DOUBLE PRECISION
!>

S

!>          S est un COMPLEX*16
!>          C et S définissent une rotation
!>             [  C          S  ]
!>             [ -conjg(S)   C  ]
!>          où C*C + S*CONJG(S) = 1.0.
!>
