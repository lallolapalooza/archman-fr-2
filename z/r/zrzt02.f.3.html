Documentation de la fonction/sous-routine

double precision function zrzt02 (integer m, integer n, complex*16, dimension( lda, * ) af, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( lwork ) work, integer lwork)

ZRZT02

Objectif :

!>
!> ZRZT02 retourne
!>      || I - Q'*Q || / ( M * eps)
!> où la matrice Q est définie par les transformations de Householder
!> générées par ZTZRZF.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice AF.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice AF.
!>

AF

!>          AF est un tableau COMPLEX*16, de dimension (LDA,N)
!>          La sortie de ZTZRZF.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau AF.
!>

TAU

!>          TAU est un tableau COMPLEX*16, de dimension (M)
!>          Détails des transformations de Householder retournés par
!>          ZTZRZF.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>          Longueur du tableau WORK. LWORK >= N*N+N.
!>
