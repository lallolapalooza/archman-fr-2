ZRAMCTL(8) Administration système ZRAMCTL(8)

NOM

zramctl - configurer et contrôler les périphériques zram

SYNTAXE

Obtenir des informations :

zramctl [options]

Réinitialiser zram :

zramctl -r zramdev...

Afficher le nom du premier périphérique zram inutilisé :

zramctl -f

Configurer un périphérique zram :

zramctl [-f | zramdev] [-s taille] [-t nombre] [-a algorithme]

DESCRIPTION

zramctl est utilisé pour configurer rapidement les paramètres des périphériques zram, pour réinitialiser les périphériques zram et pour interroger l'état des périphériques zram utilisés.

Si aucune option n'est donnée, tous les périphériques zram de taille non nulle sont affichés.

Notez que le nœud zramdev spécifié sur la ligne de commande doit déjà exister. La commande zramctl crée de nouveaux nœuds /dev/zram<N> uniquement lorsque l'option --find est spécifiée. Il est possible (et courant) qu'après le démarrage du système les nœuds /dev/zram<N> ne soient pas encore créés.

OPTIONS

-a, --algorithm lzo|lz4|lz4hc|deflate|842|zstd

Définit l'algorithme de compression à utiliser pour compresser les données dans le périphérique zram.

La liste des algorithmes pris en charge peut être inexacte car elle dépend de la configuration actuelle du noyau. Un aperçu de base peut être obtenu en utilisant la commande "cat /sys/block/zram0/comp_algorithm" ; cependant, veuillez noter que cette liste peut également être incomplète. Ceci est dû au fait que ZRAM utilise l'API cryptographique, et si certains algorithmes ont été compilés en tant que modules, il devient impossible de tous les énumérer.

-f, --find

Trouve le premier périphérique zram inutilisé. Si un argument --size est présent, alors initialise le périphérique.

-n, --noheadings

N'affiche pas de ligne d'en-tête dans la sortie d'état.

-o, --output liste

Définit les colonnes de sortie d'état à utiliser. Si aucun arrangement de sortie n'est spécifié, un ensemble par défaut est utilisé. Utilisez --help pour obtenir une liste de toutes les colonnes prises en charge.

La liste par défaut des colonnes peut être étendue si liste est spécifiée sous la forme +liste (par exemple, zramctl -o+COMP-RATIO).

-p, --algorithm-params

Définit les paramètres de l'algorithme, par exemple, level=9 dict=/etc/dictionary pour définir le niveau de compression et un dictionnaire pré-entraîné. Les paramètres sont spécifiques à l'algorithme.

--output-all

Affiche toutes les colonnes disponibles.

--raw

Utilise le format brut pour la sortie d'état.

-r, --reset

Réinitialise les options du ou des périphériques zram spécifiés. Les paramètres du périphérique zram ne peuvent être modifiés qu'après une réinitialisation.

-s, --size taille

Crée un périphérique zram de la taille spécifiée. Les périphériques zram sont alignés sur les pages mémoire ; lorsque la taille demandée n'est pas un multiple de la taille de page, elle sera arrondie au multiple supérieur. Sauf indication contraire, l'unité du paramètre taille est les octets.

L'argument taille peut être suivi des suffixes multiplicatifs KiB (=1024), MiB (=1024*1024), et ainsi de suite pour GiB, TiB, PiB, EiB, ZiB et YiB (le "iB" est facultatif, par exemple, "K" a la même signification que "KiB") ou les suffixes KB (=1000), MB (=1000*1000), et ainsi de suite pour GB, TB, PB, EB, ZB et YB.

-t, --streams nombre

Définit le nombre maximum de flux de compression qui peuvent être utilisés pour le périphérique. La valeur par défaut est d'utiliser tous les processeurs et un flux pour les noyaux plus anciens que 4.6.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

STATUT DE SORTIE

zramctl retourne 0 en cas de succès, une valeur non nulle en cas d'échec.

FICHIERS

/dev/zram[0..N]

Périphériques blocs zram

EXEMPLE

Les commandes suivantes configurent un périphérique zram avec une taille d'un gigaoctet et l'utilisent comme périphérique d'échange.

 # zramctl --find --size 1024M
 /dev/zram0
 # mkswap /dev/zram0
 # swapon /dev/zram0
 ...
 # swapoff /dev/zram0
 # zramctl --reset /dev/zram0
