!> ZBBCSD calcule la décomposition CS d'une matrice unitaire sous
!> forme de blocs bidiagonaux,
!>
!>
!>     [ B11 | B12 0  0 ]
!>     [  0  |  0 -I  0 ]
!> X = [----------------]
!>     [ B21 | B22 0  0 ]
!>     [  0  |  0  0  I ]
!>
!>                               [  C | -S  0  0 ]
!>                   [ U1 |    ] [  0 |  0 -I  0 ] [ V1 |    ]**H
!>                 = [---------] [---------------] [---------]   .
!>                   [    | U2 ] [  S |  C  0  0 ] [    | V2 ]
!>                               [  0 |  0  0  I ]
!>
!> X est de taille M-par-M, son bloc supérieur gauche est de taille P-par-Q, et Q
!> ne doit pas être plus grand que P, M-P, ou M-Q. (Si Q n'est pas l'indice
!> le plus petit, alors X doit être transposé et/ou permuté. Cela peut être fait
!> en temps constant en utilisant les options TRANS et SIGNS. Voir ZUNCSD pour
!> plus de détails.)
!>
!> Les matrices bidiagonales B11, B12, B21 et B22 sont représentées
!> implicitement par les angles THETA(1:Q) et PHI(1:Q-1).
!>
!> Les matrices unitaires U1, U2, V1T et V2T sont en entrée/sortie.
!> Les matrices d'entrée sont pré- ou post-multipliées par les matrices de
!> vecteurs singuliers appropriées.
!>

JOBV2T

!>          sinon : V2T n'est pas mise à jour.
!>

TRANS

!>          sinon : X, U1, U2, V1T et V2T sont stockés en ordre colonne-majeur.

Function/Subroutine Documentation

ZBBCSD

  Purpose:
  =======
  ZBBCSD computes the CS decomposition of a general matrix.

  The CS decomposition is defined by the equations:
  A = U * R * (C * X**H + S * Y**H) * V**H
  B = U * R * (S * X**H - C * Y**H) * V**H

  where U, V are unitary matrices, R is a diagonal matrix with
  non-negative diagonal entries, and C and S are diagonal matrices
  with non-negative diagonal entries such that C**2 + S**2 = I.
  X and Y are diagonal matrices with diagonal entries of magnitude 1.

  The CS decomposition is computed by the routine ZBBCSD.
  The diagonal matrices C and S have diagonal entries c_i and s_i
  such that c_i = cos(theta_i) and s_i = sin(theta_i) for
  0 <= theta_i <= pi/2.

  The matrices X and Y are diagonal matrices with diagonal entries
  x_i and y_i such that x_i = exp(i * phi_i) and y_i = exp(i * psi_i)
  for 0 <= phi_i < pi and 0 <= psi_i < pi.

  Arguments:
  ==========
  JOBU    (input) CHARACTER*1
          Specifies whether to compute the unitary matrix U.
          = 'Y': U is computed.
          = 'N': U is not computed.

  JOBV    (input) CHARACTER*1
          Specifies whether to compute the unitary matrix V.
          = 'Y': V is computed.
          = 'N': V is not computed.

  M       (input) INTEGER
          The number of rows of the matrices A and B. M >= 0.

  N       (input) INTEGER
          The number of columns of the matrices A and B. N >= 0.

  A       (input/output) COMPLEX*16 array, dimension (LDA, N)
          On entry, the leading M-by-N submatrix of A contains the
          matrix A.
          On exit, A is overwritten.

  LDA     (input) INTEGER
          The leading dimension of the array A. LDA >= max(1, M).

  B       (input/output) COMPLEX*16 array, dimension (LDB, N)
          On entry, the leading M-by-N submatrix of B contains the
          matrix B.
          On exit, B is overwritten.

  LDB     (input) INTEGER
          The leading dimension of the array B. LDB >= max(1, M).

  R       (output) DOUBLE PRECISION array, dimension (MIN(M,N))
          On exit, the first K entries of R contain the diagonal
          elements of the diagonal matrix R, where K is the number of
          diagonal blocks.

  IWORK   (output) INTEGER array, dimension (MAX(1,M+N))
          On exit, IWORK(1) returns the optimal size of the array TAU1.

  TAU1    (output) COMPLEX*16 array, dimension (MAX(1,IWORK(1)))
          On exit, TAU1 contains the scalar factors of the elementary
          reflectors of U.

  TAU2    (output) COMPLEX*16 array, dimension (MAX(1,MIN(M,N)))
          On exit, TAU2 contains the scalar factors of the elementary
          reflectors of V.

  TP      (output) DOUBLE PRECISION array, dimension (MAX(1,MIN(M,N)))

          matrix T.

  TN      (output) DOUBLE PRECISION array, dimension (MAX(1,MIN(M,N)))
          On exit, TN contains the diagonal elements of the diagonal
          matrix N.

  CSD     (output) DOUBLE PRECISION array, dimension (MAX(1,MIN(M,N)))
          On exit, CSD contains the diagonal elements of the diagonal
          matrix S.

  EPS     (input) DOUBLE PRECISION
          The relative machine precision.

  NP      (output) INTEGER

  Further Details:
  ================
  The implementation of this routine is based on the algorithm
  described in [1]. The algorithm uses a sequence of Jacobi rotations
  to reduce the matrices A and B to upper triangular form. The CS
  decomposition is then obtained from the upper triangular form.

  The routine also computes the Schur decomposition of the matrix
  (A*A**H + B*B**H), which is used in the computation of the CS
  decomposition.

  The routine uses a block decomposition of the matrices A and B to
  improve performance. The block size is determined by the dimensions
  of the matrices and the available memory.

  The routine uses a tolerance parameter EPS to control the convergence
  of the Jacobi rotations. The tolerance is set to the relative
  machine precision.

  The routine uses a workspace array RWORK to store intermediate
  results. The size of RWORK is determined by the dimensions of the
  matrices and the block size.

  The routine returns the number of diagonal blocks NP, the number of
  right singular vectors NW, and the dimensions P and Q of the
  matrices X, SX, Y, SY, W, and V.

  The routine also returns the diagonal elements of the matrices R, T,
  N, S, and CSD.

  The routine returns the scalar factors of the elementary reflectors
  of U and V in TAU1 and TAU2, respectively.

  The routine returns the matrices X, SX, Y, SY, W, and V.
