Documentation de la fonction/sous-programme

sous-programme zbdt02 (entier m, entier n, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldc, * ) c, entier ldc, complexe*16, dimension( ldu, * ) u, entier ldu, complexe*16, dimension( * ) work, double precision, dimension( * ) rwork, double precision resid)

ZBDT02

But:

!>
!> ZBDT02 teste le changement de base C = U**H * B en calculant le
!> résidu
!>
!>    RESID = norm(B - U * C) / ( max(m,n) * norm(B) * EPS ),
!>
!> où B et C sont des matrices M par N, U est une matrice orthogonale M par M,
!> et EPS est la précision machine.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes des matrices B et C et l'ordre de
!>          la matrice Q.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes des matrices B et C.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,N)
!>          La matrice B de taille m par n.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,M).
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC,N)
!>          La matrice C de taille m par n, supposée contenir U**H * B.
!>

LDC

!>          LDC est ENTIER
!>          La dimension principale du tableau C.  LDC >= max(1,M).
!>

U

!>          U est un tableau COMPLEX*16, dimension (LDU,M)
!>          La matrice orthogonale U de taille m par m.
!>

LDU

!>          LDU est ENTIER
!>          La dimension principale du tableau U.  LDU >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (M)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (M)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          RESID = norm(B - U * C) / ( max(m,n) * norm(B) * EPS ),
!>
