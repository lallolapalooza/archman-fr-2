NOM

zblocklist - outil de liste de blocage IP pour zmap

SYNTAXE

zblocklist [ -b <liste_de_blocage> ] [ -w <liste_blanche> ] [ OPTIONS... ]

DESCRIPTION

ZBlacklist est un outil réseau pour limiter et dédupliquer une liste d'adresses IP à l'aide d'une liste de blocage ou d'une liste blanche.

OPTIONS

OPTIONS DE BASE

-b, --blocklist-file=chemin
Fichier de sous-réseaux à exclure, en notation CIDR, un par ligne. Il est recommandé de l'utiliser pour exclure les adresses RFC 1918, multicast, les espaces réservés IANA et autres adresses à usage spécial IANA. Un exemple de fichier de liste de blocage blocklist.conf à cet effet.
-w, --allowlist-file=nom
Fichier de sous-réseaux à inclure, en notation CIDR, un par ligne. Tous les autres sous-réseaux seront exclus.
-l, --log-file=nom
Fichier où enregistrer les logs.
--disable-syslog
Désactiver l'enregistrement des messages dans syslog.
-v, --verbosity
Niveau de détail des logs (0-5, par défaut 3)
--no-duplicate-checking
Ne pas dédupliquer les adresses d'entrée. La valeur par défaut est false.
--ignore-blocklist-errors
Ignorer les entrées invalides, malformées ou non résolvables dans la liste de blocage/liste blanche. La valeur par défaut est false.
--ignore-input-errors
Ne pas afficher les entrées invalides dans l'entrée. La valeur par défaut est false.

OPTIONS ADDITIONNELLES

-h, --help
Afficher l'aide et quitter
-V, --version
Afficher la version et quitter
