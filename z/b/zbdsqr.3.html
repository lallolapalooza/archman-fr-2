Documentation de la fonction/sous-routine

sous-routine zbdsqr (character uplo, integer n, integer ncvt, integer nru, integer ncc, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( ldvt, * ) vt, integer ldvt, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( ldc, * ) c, integer ldc, double precision, dimension( * ) rwork, integer info)

ZBDSQR

Objectif:

!>
!> ZBDSQR calcule les valeurs singulières et, éventuellement, les vecteurs singuliers
!> droits et/ou gauches à partir de la décomposition en valeurs singulières (SVD)
!> d'une matrice bidiagonale réelle N-par-N (supérieure ou inférieure) en utilisant
!> l'algorithme QR implicite à décalage zéro. La SVD de B a la forme
!>
!>    B = Q * S * P**H
!>
!> où S est la matrice diagonale des valeurs singulières, Q est une matrice orthogonale
!> de vecteurs singuliers gauches, et P est une matrice orthogonale de vecteurs
!> singuliers droits. Si des vecteurs singuliers gauches sont demandés, cette
!> sous-routine renvoie en fait U*Q au lieu de Q, et, si des vecteurs singuliers
!> droits sont demandés, cette sous-routine renvoie P**H*VT au lieu de
!> P**H, pour des matrices d'entrée complexes données U et VT. Lorsque U et VT sont
!> les matrices unitaires qui réduisent une matrice générale A en forme bidiagonale :
!> A = U*B*VT, comme calculé par ZGEBRD, alors
!>
!>    A = (U*Q) * S * (P**H*VT)
!>
!> est la SVD de A. Éventuellement, la sous-routine peut également calculer Q**H*C
!> pour une matrice d'entrée complexe donnée C.
!>
!> Voir  par J. Demmel et W. Kahan,
!> LAPACK Working Note #3 (ou SIAM J. Sci. Statist. Comput. vol. 11,
!> no. 5, pp. 873-912, sept. 1990) et
!>  par
!> B. Parlett et V. Fernando, Technical Report CPAM-554, Mathematics
!> Department, University of California at Berkeley, juillet 1992
!> pour une description détaillée de l'algorithme.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : B est supérieure bidiagonale ;
!>          = 'L' : B est inférieure bidiagonale.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice B. N >= 0.
!>

NCVT

!>          NCVT est INTEGER
!>          Le nombre de colonnes de la matrice VT. NCVT >= 0.
!>

NRU

!>          NRU est INTEGER
!>          Le nombre de lignes de la matrice U. NRU >= 0.
!>

NCC

!>          NCC est INTEGER
!>          Le nombre de colonnes de la matrice C. NCC >= 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          En entrée, les n éléments diagonaux de la matrice bidiagonale B.
!>          En sortie, si INFO=0, les valeurs singulières de B en ordre décroissant.
!>

E

!>          E est un tableau DOUBLE PRECISION, dimension (N-1)
!>          En entrée, les N-1 éléments hors-diagonaux de la matrice bidiagonale
!>          B.
!>          En sortie, si INFO = 0, E est détruit ; si INFO > 0, D et E
!>          contiendront les éléments diagonaux et superdiagonaux d'une
!>          matrice bidiagonale orthogonalement équivalente à celle fournie
!>          en entrée.
!>

VT

!>          VT est un tableau COMPLEX*16, dimension (LDVT, NCVT)
!>          En entrée, une matrice VT de taille N-par-NCVT.
!>          En sortie, VT est écrasé par P**H * VT.
!>          Non référencé si NCVT = 0.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT.
!>          LDVT >= max(1,N) si NCVT > 0 ; LDVT >= 1 si NCVT = 0.
!>

U

!>          U est un tableau COMPLEX*16, dimension (LDU, N)
!>          En entrée, une matrice U de taille NRU-par-N.
!>          En sortie, U est écrasé par U * Q.
!>          Non référencé si NRU = 0.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= max(1,NRU).
!>

C

!>          C est un tableau COMPLEX*16, dimension (LDC, NCC)
!>          En entrée, une matrice C de taille N-par-NCC.
!>          En sortie, C est écrasé par Q**H * C.
!>          Non référencé si NCC = 0.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C.
!>          LDC >= max(1,N) si NCC > 0 ; LDC >=1 si NCC = 0.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (LRWORK)
!>          LRWORK = 4*N, si NCVT = NRU = NCC = 0, et
!>          LRWORK = 4*(N-1), sinon
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : l'algorithme n'a pas convergé ; D et E contiennent les
!>                éléments d'une matrice bidiagonale qui est orthogonalement
!>                similaire à la matrice d'entrée B ; si INFO = i, i
!>                éléments de E n'ont pas convergé vers zéro.
!>

Paramètres internes :

!>  TOLMUL  DOUBLE PRECISION, défaut = max(10,min(100,EPS**(-1/8)))
!>          TOLMUL contrôle le critère de convergence de la boucle QR.
!>          S'il est positif, TOLMUL*EPS est la précision relative souhaitée
!>             dans les valeurs singulières calculées.
!>          S'il est négatif, abs(TOLMUL*EPS*sigma_max) est la précision absolue souhaitée
!>             dans les valeurs singulières calculées (correspond à une précision relative
!>             abs(TOLMUL*EPS) dans la plus grande valeur singulière.
!>          abs(TOLMUL) doit être compris entre 1 et 1/EPS, et de préférence
!>             entre 10 (pour une convergence rapide) et .1/EPS
!>             (pour qu'il y ait une certaine précision dans les résultats).
!>          Le défaut est de perdre soit un huitième, soit 2 des
!>             chiffres décimaux disponibles dans chaque valeur singulière calculée
!>             (le plus petit des deux).
!>
!>  MAXITR  INTEGER, défaut = 6
!>          MAXITR contrôle le nombre maximal de passes de l'algorithme
!>          dans sa boucle interne. L'algorithme s'arrête
!>          (et donc échoue à converger) si le nombre de passes
!>          dans la boucle interne dépasse MAXITR*N**2.
!>
!>

Note :

!>  Rapport de bug de Cezary Dendek.
!>  Le 3 novembre 2023, la variable INTEGER MAXIT = MAXITR*N**2 est
!>  supprimée car elle peut déborder très facilement (pour N supérieur ou égal
!>  à 18 919). Nous utilisons à la place MAXITDIVN = MAXITR*N.
!>
