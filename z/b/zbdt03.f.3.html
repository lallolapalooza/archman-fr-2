ZBDT03

Documentation de fonction/sous-routine

sous-routine zbdt03 (character uplo, integer n, integer kd, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( ldu, * ) u, integer ldu, double precision, dimension( * ) s, complex*16, dimension( ldvt, * ) vt, integer ldvt, complex*16, dimension( * ) work, double precision resid)

ZBDT03

Objectif :

!>
!> ZBDT03 reconstruit une matrice bidiagonale B à partir de sa SVD :
!>    S = U' * B * V
!> où U et V sont des matrices orthogonales et S est diagonale.
!>
!> Le ratio de test pour tester la décomposition en valeurs singulières est
!>    RESID = norm( B - U * S * VT ) / ( n * norm(B) * EPS )
!> où VT = V' et EPS est la précision machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice B est supérieure ou inférieure bidiagonale.
!>          = 'U' : supérieure bidiagonale
!>          = 'L' : inférieure bidiagonale
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice B.
!>

KD

!>          KD est INTEGER
!>          La largeur de bande de la matrice bidiagonale B. Si KD = 1, la
!>          matrice B est bidiagonale, et si KD = 0, B est diagonale et E n'est
!>          pas référencée. Si KD est supérieur à 1, il est supposé être
!>          1, et si KD est inférieur à 0, il est supposé être 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          Les n éléments diagonaux de la matrice bidiagonale B.
!>

E

!>          E est un tableau DOUBLE PRECISION, dimension (N-1)
!>          Les (n-1) éléments supradiagonaux de la matrice bidiagonale B
!>          si UPLO = 'U', ou les (n-1) éléments sous-diagonaux de B si
!>          UPLO = 'L'.
!>

U

!>          U est un tableau COMPLEX*16, dimension (LDU,N)
!>          La matrice orthogonale n par n, U, dans la réduction B = U'*A*P.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= max(1,N)
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (N)
!>          Les valeurs singulières de la SVD de B, triées par ordre décroissant.
!>

VT

!>          VT est un tableau COMPLEX*16, dimension (LDVT,N)
!>          La matrice orthogonale n par n, V', dans la réduction
!>          B = U * S * V'.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          Le ratio de test : norm(B - U * S * V') / ( n * norm(A) * EPS )
!>
