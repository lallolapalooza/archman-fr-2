programme zblat3

ZBLAT3

Objectif :

!>
!> Programme de test pour les BLAS Complexes*16 de niveau 3.
!>
!> Le programme doit être piloté par un fichier de données court. Les 14 premiers enregistrements
!> du fichier sont lus à l'aide de l'entrée listée, les 10 derniers enregistrements
!> sont lus à l'aide du format ( A6, L2 ). Un exemple annoté d'un fichier de données
!> peut être obtenu en supprimant les 3 premiers caractères des
!> 23 lignes suivantes :
!> 'zblat3.out'      NOM DU FICHIER DE RÉSUMÉ DE SORTIE
!> 6                 NUMÉRO D'UNITÉ DU FICHIER DE RÉSUMÉ
!> 'ZBLAT3.SNAP'     NOM DU FICHIER DE SORTIE INSTANTANÉ
!> -1                NUMÉRO D'UNITÉ DU FICHIER INSTANTANÉ (NON UTILISÉ SI .LT. 0)
!> F        INDICATEUR LOGIQUE, T POUR REMbobiner le FICHIER INSTANTANÉ APRÈS CHAQUE ENREGISTREMENT.
!> F        INDICATEUR LOGIQUE, T POUR S'ARRÊTER EN CAS D'ÉCHEC.
!> T        INDICATEUR LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR SEUIL DU RAPPORT DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 3                 NOMBRE DE VALEURS D'ALPHA
!> (0.0,0.0) (1.0,0.0) (0.7,-0.9)       VALEURS D'ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> (0.0,0.0) (1.0,0.0) (1.3,-1.1)       VALEURS DE BETA
!> ZGEMM  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> ZHEMM  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> ZSYMM  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> ZTRMM  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> ZTRSM  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> ZHERK  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> ZSYRK  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> ZHER2K T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> ZSYR2K T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> ZGEMMTR T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!>

Description

Ces sous-programmes sont des utilitaires de test pour les sous-programmes BLAS de niveau 3.

Usage

call zchk1(sname, eps, thresh, nout, ntra, trace, rewi, fatal, &
           nidim, idim, nalf, alf, nbet, bet, nmax, a, aa, as, &
           b, bb, bs, c, cc, cs, ct, g)
call zchk2(sname, eps, thresh, nout, ntra, trace, rewi, fatal, &
           nidim, idim, nalf, alf, nbet, bet, nmax, a, aa, as, &
           b, bb, bs, c, cc, cs, ct, g)
call zchk3(sname, eps, thresh, nout, ntra, trace, rewi, fatal, &
           nidim, idim, nalf, alf, nmax, a, aa, as, b, bb, bs, &
           ct, g, c)
call zchk4(sname, eps, thresh, nout, ntra, trace, rewi, fatal, &
           nidim, idim, nalf, alf, nbet, bet, nmax, a, aa, as, &
           b, bb, bs, c, cc, cs, ct, g)
call zchk5(sname, eps, thresh, nout, ntra, trace, rewi, fatal, &
           nidim, idim, nalf, alf, nbet, bet, nmax, ab, aa, as, &
           bb, bs, c, cc, cs, ct, g, w)
call zchk6(sname, eps, thresh, nout, ntra, trace, rewi, fatal, &
           nidim, idim, nalf, alf, nbet, bet, nmax, a, aa, as, &
           b, bb, bs, c, cc, cs, ct, g)

Arguments

Tous les sous-programmes prennent les mêmes arguments, à l'exception de zchk3 qui omet nbet, bet, bb, et bs, et ajoute c comme dernier argument, et zchk5 qui utilise ab à la place de a, et ajoute w.

sname
Nom du sous-programme BLAS de niveau 3 testé.
eps
Tolérance de précision relative.
thresh
Seuil de précision.
nout
Nombre de résultats imprimés.
ntra
Nombre de tests effectués.
trace
Indique si les résultats détaillés des tests doivent être imprimés.
rewi
Indique si les fichiers de test doivent être réinitialisés.
fatal
Indique si les erreurs fatales doivent arrêter le programme.
nidim
Nombre de valeurs de dimension dans idim.
idim
Tableau des dimensions utilisées pour les tests.
nalf
Nombre de valeurs dans alf.
alf
Tableau des valeurs scalaires alpha.
nbet
(Non utilisé par zchk3) Nombre de valeurs dans bet.
bet
(Non utilisé par zchk3) Tableau des valeurs scalaires beta.
nmax
Dimension maximale des matrices et vecteurs.
a, aa, as, b, bb, bs, c, cc, cs, ab
Matrices et vecteurs utilisés dans les calculs.
ct
Vecteur de taille nmax.
g
Vecteur de taille nmax.
w
(Utilisé par zchk5 uniquement) Vecteur de taille 2*nmax.

Pour plus de détails sur ces sous-programmes et leur utilisation, veuillez consulter la documentation du LAPACK.
