ZBDT05

Documentation de la fonction/sous-programme

sous-programme zbdt05 (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, integer ns, complex*16, dimension( * ) u, integer ldu, complex*16, dimension( ldvt, * ) vt, integer ldvt, complex*16, dimension( * ) work, double precision resid)

ZBDT05

But:

!>
!> ZBDT05 reconstruit une matrice bidiagonale B à partir de sa SVD (partielle) :
!>    S = U' * B * V
!> où U et V sont des matrices orthogonales et S est diagonale.
!>
!> Le ratio de test pour vérifier la décomposition en valeurs singulières est
!>    RESID = norm( S - U' * B * V ) / ( n * norm(B) * EPS )
!> où VT = V' et EPS est la précision machine.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes des matrices A et U.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes des matrices A et VT.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice A de dimensions m par n.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (NS)
!>          Les valeurs singulières de la SVD (partielle) de B, triées par
!>          ordre décroissant.
!>

NS

!>          NS est un ENTIER
!>          Le nombre de valeurs/vecteurs singuliers de la SVD (partielle)
!>          de B.
!>

U

!>          U est un tableau COMPLEX*16, dimension (LDU,NS)
!>          La matrice orthogonale U de dimensions n par ns dans S = U' * B * V.
!>

LDU

!>          LDU est un ENTIER
!>          La dimension principale du tableau U.  LDU >= max(1,N)
!>

VT

!>          VT est un tableau COMPLEX*16, dimension (LDVT,N)
!>          La matrice orthogonale V de dimensions n par ns dans S = U' * B * V.
!>

LDVT

!>          LDVT est un ENTIER
!>          La dimension principale du tableau VT.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (M,N)
!>

RESID

!>          RESID est un DOUBLE PRECISION
!>          Le ratio de test :  norm(S - U' * A * V) / ( n * norm(A) * EPS )
!>
