NOM

zbxpcp - Module PCP chargeable pour l'agent Zabbix

DESCRIPTION

Le module chargeable zbxpcp étend l'agent Zabbix en rendant les métriques Performance Co-Pilot (PCP) disponibles pour celui-ci. Avec le module zbxpcp configuré dans zabbix_agentd.conf, toutes les métriques PCP sont disponibles à partir de l'agent Zabbix comme n'importe quel autre élément de l'agent. En tant que module chargeable (DSO), zbxpcp ne repose sur aucun programme externe, mais utilise directement les API PCP pour récupérer les métriques PCP lorsqu'elles sont demandées.

Une installation PCP Linux typique offre plus de 1 000 métriques par défaut et est elle-même extensible avec ses propres plugins ou PMDA (``Performance Metrics Domain Agents''). En plus de statistiques très complètes basées sur /proc, les PMDA PCP facilement disponibles prennent en charge des composants système et applicatifs tels que 389 Directory Server, Apache, conteneurs, HAProxy, GFS2, Gluster, libvirt, MySQL, NFS, Oracle, Postfix, PostgreSQL, Samba et Sendmail, entre autres. PCP fonctionne également sur de nombreuses plateformes, notamment Linux, macOS, FreeBSD, NetBSD, Solaris et Windows.

Pour une introduction à PCP, voir PCPIntro(1). Pour examiner les métriques PCP disponibles, utilisez par exemple pminfo(1). Le *Guide de référence rapide PCP* est disponible sur la page d'accueil de PCP https://pcp.io/.

Pour des informations générales sur la collecte de données Zabbix et les modules chargeables, voir https://www.zabbix.com/documentation/3.0/manual/config/items. Pour une introduction à Zabbix et les téléchargements, voir https://www.zabbix.com/.

zbxpcp est compatible avec la version **1** de l'API des modules Zabbix.

CONFIGURATION

Assurez-vous d'abord que PCP est installé et correctement configuré, consultez les références ci-dessus pour les instructions et utilisez par exemple pminfo(1) pour vous assurer que les métriques PCP peuvent être récupérées. Pour activer le module chargeable zbxpcp dans un agent Zabbix, les lignes suivantes doivent être ajoutées au fichier de configuration de l'agent Zabbix zabbix_agentd.conf (assurez-vous d'utiliser le bon LoadModulePath) :

LoadModulePath=/usr/lib64/zabbix/agent/
LoadModule=zbxpcp.so

Après avoir redémarré l'agent Zabbix, toutes les métriques PCP seront disponibles avec le préfixe ``pcp.'' comme tous les autres éléments de l'agent. Cela peut être vérifié avec les commandes suivantes :

$ pminfo -t
$ zabbix_agentd -p
$ pminfo -f kernel.all.sysfork
$ zabbix_get -s 127.0.0.1 -p 10050 -k pcp.kernel.all.sysfork

Ensuite, pour collecter les métriques PCP à partir des agents Zabbix, la configuration côté serveur Zabbix est comme d'habitude (voir la documentation Zabbix si nécessaire).

Le service PCP pmcd doit toujours être en cours d'exécution lors du démarrage d'un agent Zabbix activé avec zbxpcp, sinon le module ne pourra pas être chargé et les métriques PCP ne seront pas disponibles. Une attention particulière doit être portée pour s'assurer que cela se produit également lors du redémarrage du système.

FICHIERS

/etc/zabbix/zabbix_agentd.conf
Emplacement typique du fichier de configuration de l'agent Zabbix.
/etc/zabbix/zbxpcp-derived-metrics.conf
Fichier de configuration optionnel des métriques dérivées PCP pour zbxpcp. Voir pmLoadDerivedConfig(3) pour plus d'informations sur les métriques dérivées.
$PCP_LIB_DIR/zabbix/agent/zbxpcp.so
Module PCP chargeable pour l'agent Zabbix.
