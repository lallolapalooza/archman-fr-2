Objectif :

!>
!> ZBBCSD calcule la décomposition CS d'une matrice unitaire sous forme
!> bidiagonale-par-blocs,
!>
!>
!>     [ B11 | B12 0  0 ]
!>     [  0  |  0 -I  0 ]
!> X = [----------------]
!>     [ B21 | B22 0  0 ]
!>     [  0  |  0  0  I ]
!>
!>                               [  C | -S  0  0 ]
!>                   [ U1 |    ] [  0 |  0 -I  0 ] [ V1 |    ]**H
!>                 = [---------] [---------------] [---------]   .
!>                   [    | U2 ] [  S |  C  0  0 ] [    | V2 ]
!>                               [  0 |  0  0  I ]
!>
!> X est M-par-M, son bloc supérieur gauche est P-par-Q, et Q ne doit pas être
!> plus grand que P, M-P ou M-Q. (Si Q n'est pas l'indice le plus petit, alors X doit
!> être transposé et/ou permuté. Cela peut être fait en temps constant en utilisant
!> les options TRANS et SIGNS. Voir ZUNCSD pour plus de détails.)
!>
!> Les matrices bidiagonales B11, B12, B21 et B22 sont représentées
!> implicitement par les angles THETA(1:Q) et PHI(1:Q-1).
!>
!> Les matrices unitaires U1, U2, V1T et V2T sont en entrée/sortie.
!> Les matrices d'entrée sont pré- ou post-multipliées par les matrices
!> de vecteurs singuliers appropriées.
!>

NOM

ZBBCSD - sous-routine

SYNTAXIS

CALL ZBBCSD( JOB, M, N, R, LDR, T, LDT, X, LDX, Y, LDY,
             B11D, B11E, B12D, B12E, B21D, B21E, B22D, B22E,
             Q, THETA, PHI, TOLMUL, WORK, LWORK, INFO )

DESCRIPTION

ZBBCSD calcule la décomposition CS complète (Complète Décomposition Singulière) de deux matrices unitaires réelles de grande taille disjointes, R et T.

Soient R et T deux matrices unitaires réelles de grande taille de tailles M x M et N x N respectivement. ZBBCSD les transforme en une forme diagonale par blocs par des transformations unitaires à gauche et à droite.

La fonction est définie comme suit :

      R = [ R11  R12 ]  et  T = [ T11  T12 ]
          [ R21  R22 ]            [ T21  T22 ]

où R11 est de taille K x K, R22 est de taille (M-K) x (M-K), T11 est de taille K x K et T22 est de taille (N-K) x (N-K).

ZBBCSD trouve des matrices unitaires X, Y et des matrices diagonales S, C telles que :

      X * R * Y' = [  C*R11   -S*R12 ]
                   [  S*R21    C*R22 ]

      X * T * Y' = [  C*T11    S*T12 ]
                   [ -S*T21    C*T22 ]

où S et C sont des matrices diagonales de la forme :

      S = diag( s1, ..., sQ )
      C = diag( c1, ..., cQ )

et si K > Q, alors :

      S = diag( s1, ..., sQ, 1, ..., 1 )
      C = diag( c1, ..., cQ, 0, ..., 0 )

où si M > K, alors :

      S = diag( s1, ..., sQ, 1, ..., 1 )
      C = diag( c1, ..., cQ, 0, ..., 0 )

et si N > K, alors :

      S = diag( s1, ..., sQ, 1, ..., 1 )
      C = diag( c1, ..., cQ, 0, ..., 0 )

Les valeurs s_i sont comprises entre 0 et 1, et c_i = sqrt(1 - s_i^2).

Si K=0, alors S et C sont des matrices unités.

Si JOB = 'G', alors la fonction calcule la décomposition CS généralisée.

Si JOB = 'N', alors la fonction calcule la décomposition CS normale.

ARGUMENTS

JOB
JOB is CHARACTER*1
          = 'G': La décomposition CS généralisée est calculée.
          = 'N': La décomposition CS normale est calculée.
M
M is INTEGER
          Le nombre de lignes de la matrice R. M >= 0.
N
N is INTEGER
          Le nombre de colonnes de la matrice R. N >= 0.
          R et T doivent être toutes deux carrées si JOB = 'N'.
          Si JOB = 'G', la matrice R est M x N et la matrice T est P x Q.
          Pour que la décomposition CS généralisée soit bien définie, il faut
          que M = P et N = Q.
R
R is DOUBLE PRECISION array, dimension (LDR,N)
          Le début de la matrice R.
LDR
LDR is INTEGER
          Le premier indice de R. LDR >= MAX(1,M).
T
T is DOUBLE PRECISION array, dimension (LDT,Q)
          Le début de la matrice T.
LDT
LDT is INTEGER
          Le premier indice de T. LDT >= MAX(1,P).
X
X is DOUBLE PRECISION array, dimension (LDX,N)
          Le début de la matrice X.
LDX
LDX is INTEGER
          Le premier indice de X. LDX >= MAX(1,M).
Y
Y is DOUBLE PRECISION array, dimension (LDY,Q)
          Le début de la matrice Y.
LDY
LDY is INTEGER
          Le premier indice de Y. LDY >= MAX(1,N).
B11D
B11D is DOUBLE PRECISION array, dimension (K)
          Lorsque ZBBCSD converge, B11D contient les cosinus de THETA(1), ..., THETA(K).
          Si ZBBCSD échoue à converger, alors B11D contient la diagonale du bloc
          supérieur droit partiellement réduit.
B11E
B11E is DOUBLE PRECISION array, dimension (K-1)
          Lorsque ZBBCSD converge, B11E contient des zéros.
          Si ZBBCSD échoue à converger, alors B11E contient la sous-diagonale du bloc
          supérieur droit partiellement réduit.
B12D
B12D is DOUBLE PRECISION array, dimension (K)
          Lorsque ZBBCSD converge, B12D contient les cosinus de THETA(1), ..., THETA(K).
          Si ZBBCSD échoue à converger, alors B12D contient la diagonale du bloc
          supérieur droit partiellement réduit.
B12E
B12E is DOUBLE PRECISION array, dimension (K-1)
          Lorsque ZBBCSD converge, B12E contient des zéros.
          Si ZBBCSD échoue à converger, alors B12E contient la sous-diagonale du bloc
          supérieur droit partiellement réduit.
B21D
B21D is DOUBLE PRECISION array, dimension (Q)
          Lorsque ZBBCSD converge, B21D contient les sinus négatifs de
          THETA(1), ..., THETA(Q).
          Si ZBBCSD échoue à converger, alors B21D contient la diagonale du bloc
          inférieur gauche partiellement réduit.
B21E
B21E is DOUBLE PRECISION array, dimension (Q-1)
          Lorsque ZBBCSD converge, B21E contient des zéros.
          Si ZBBCSD échoue à converger, alors B21E contient la sous-diagonale du bloc
          inférieur gauche partiellement réduit.
B22D
B22D is DOUBLE PRECISION array, dimension (Q)
          Lorsque ZBBCSD converge, B22D contient les sinus négatifs de
          THETA(1), ..., THETA(Q).
          Si ZBBCSD échoue à converger, alors B22D contient la diagonale du bloc
          inférieur droit partiellement réduit.
B22E
B22E is DOUBLE PRECISION array, dimension (Q-1)
          Lorsque ZBBCSD converge, B22E contient des zéros.
          Si ZBBCSD échoue à converger, alors B22E contient la sous-diagonale du bloc
          inférieur droit partiellement réduit.
Q
Q is INTEGER
          Le rang de la matrice triangulaire. 0 <= Q <= MIN(M,N).
THETA
THETA is DOUBLE PRECISION array, dimension (Q)
          Les angles THETA(i) tels que S = diag(sin(THETA(i))) et
          C = diag(cos(THETA(i))).
PHI
PHI is DOUBLE PRECISION array, dimension (MIN(M,N))
          Si ZBBCSD converge, PHI contient les valeurs singulières partielles
          pour le cas général.
          Si ZBBCSD échoue à converger, PHI contient le nombre d'éléments non nuls
          de la matrice partiellement réduite.
TOLMUL
TOLMUL is DOUBLE PRECISION
          TOLMUL contrôle le critère de convergence de la boucle QR.
          Les angles THETA(i), PHI(i) sont arrondis à 0 ou PI/2 lorsqu'ils sont
          dans TOLMUL*EPS de l'une des bornes.
WORK
WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))
          Sur la sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
LWORK
LWORK is INTEGER
          La dimension du tableau WORK. LWORK >= MAX(1,8*Q).
          Si LWORK = -1, alors une requête de dimension de travail est supposée;
          la routine calcule seulement la taille optimale du tableau WORK,
          renvoie cette valeur comme première entrée du tableau WORK, et aucun
          message d'erreur lié à LWORK n'est émis par XERBLA.
INFO
INFO is INTEGER
          = 0: succès.
          < 0: si INFO = -i, alors le i-ème argument est illégal.
          > 0: si ZBBCSD n'a pas convergé, INFO spécifie le nombre
                d'éléments non nuls dans PHI, et B11D, B11E, etc.,
                contiennent la matrice partiellement réduite.
