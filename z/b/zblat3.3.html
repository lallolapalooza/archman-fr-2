program zblat3

ZBLAT3

Objectif :

!>
!> Programme de test pour le niveau 3 de BLAS pour COMPLEX*16.
!>
!> Le programme doit être piloté par un fichier de données court. Les 14 premiers enregistrements
!> du fichier sont lus en utilisant l'entrée dirigée par liste, les 10 derniers enregistrements
!> sont lus en utilisant le format ( A6, L2 ). Un exemple annoté d'un fichier de données
!> peut être obtenu en supprimant les 3 premiers caractères des
!> lignes suivantes de 23 lignes :
!> 'zblat3.out'      NOM DU FICHIER DE SORTIE RÉSUMÉ
!> 6                 NUMÉRO D'UNITÉ DU FICHIER RÉSUMÉ
!> 'ZBLAT3.SNAP'     NOM DU FICHIER DE SORTIE INSTANTANÉ
!> -1                NUMÉRO D'UNITÉ DU FICHIER INSTANTANÉ (NON UTILISÉ SI .LT. 0)
!> F        INDICATEUR LOGIQUE, T POUR REMbobiner LE FICHIER INSTANTANÉ APRÈS CHAQUE ENREGISTREMENT.
!> F        INDICATEUR LOGIQUE, T POUR ARRÊTER EN CAS D'ÉCHEC.
!> T        INDICATEUR LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR SEUIL DU RAPPORT DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 3                 NOMBRE DE VALEURS DE ALPHA
!> (0.0,0.0) (1.0,0.0) (0.7,-0.9)       VALEURS DE ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> (0.0,0.0) (1.0,0.0) (1.3,-1.1)       VALEURS DE BETA
!> ZGEMM  T POUR TESTER. MÊMES COLONNES.
!> ZHEMM  T POUR TESTER. MÊMES COLONNES.
!> ZSYMM  T POUR TESTER. MÊMES COLONNES.
!> ZTRMM  T POUR TESTER. MÊMES COLONNES.
!> ZTRSM  T POUR TESTER. MÊMES COLONNES.
!> ZHERK  T POUR TESTER. MÊMES COLONNES.
!> ZSYRK  T POUR TESTER. MÊMES COLONNES.
!> ZHER2K T POUR TESTER. MÊMES COLONNES.
!> ZSYR2K T POUR TESTER. MÊMES COLONNES.
!> ZGEMMTR T POUR TESTER. MÊMES COLONNES.
!>
!>
!> Détails Supplémentaires
!> ======================
!>
!> Voir :
!>
!>    Dongarra J. J., Du Croz J. J., Duff I. S. et Hammarling S.
!>    Un Ensemble de Sous-programmes de Base pour l'Algèbre Linéaire de Niveau 3.
!>
!>    Note Technique N° 88 (Révision 1), Division Mathématiques et
!>    Informatique, Argonne National Laboratory, 9700
!>    South Cass Avenue, Argonne, Illinois 60439, US.
!>
!> -- Écrit le 8 février 1989.
