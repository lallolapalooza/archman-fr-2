sous-programme zbdsqr (caractère uplo, entier n, entier ncvt, entier nru, entier ncc, double précision, dimension( * ) d, double précision, dimension( * ) e, complexe*16, dimension( ldvt, * ) vt, entier ldvt, complexe*16, dimension( ldu, * ) u, entier ldu, complexe*16, dimension( ldc, * ) c, entier ldc, double précision, dimension( * ) rwork, entier info)

ZBDSQR

But:

!>
!> ZBDSQR calcule les valeurs singulières et, optionnellement, les vecteurs
!> singuliers droits et/ou gauches à partir de la décomposition en valeurs
!> singulières (SVD) d'une matrice réelle N x N (supérieure ou inférieure)
!> bidiagonale B en utilisant l'algorithme QR implicite sans décalage.  La SVD
!> de B a la forme
!>
!>    B = Q * S * P**H
!>
!> où S est la matrice diagonale des valeurs singulières, Q est une matrice
!> orthogonale des vecteurs singuliers gauches, et P est une matrice
!> orthogonale des vecteurs singuliers droits.  Si des vecteurs singuliers
!> gauches sont demandés, ce sous-programme retourne en fait U*Q au lieu de Q,
!> et si des vecteurs singuliers droits sont demandés, ce sous-programme
!> retourne P**H*VT au lieu de P**H, pour des matrices complexes d'entrée
!> données U et VT.  Lorsque U et VT sont les matrices unitaires qui réduisent
!> une matrice générale A à la forme bidiagonale : A = U*B*VT, comme calculé
!> par ZGEBRD, alors
!>
!>    A = (U*Q) * S * (P**H*VT)
!>
!> est la SVD de A.  Optionnellement, le sous-programme peut aussi calculer
!> Q**H*C pour une matrice complexe d'entrée donnée C.
!>
!> Voir  par J. Demmel et W. Kahan,
!> LAPACK Working Note #3 (ou SIAM J. Sci. Statist. Comput. vol. 11,
!> no. 5, pp. 873-912, Sept 1990) et
!>  par
!> B. Parlett et V. Fernando, Technical Report CPAM-554, Mathematics
!> Department, University of California at Berkeley, July 1992
!> pour une description détaillée de l'algorithme.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  B est supérieure bidiagonale ;
!>          = 'L':  B est inférieure bidiagonale.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice B.  N >= 0.
!>

NCVT

!>          NCVT est INTEGER
!>          Le nombre de colonnes de la matrice VT. NCVT >= 0.
!>

NRU

!>          NRU est INTEGER
!>          Le nombre de lignes de la matrice U. NRU >= 0.
!>

NCC

!>          NCC est INTEGER
!>          Le nombre de colonnes de la matrice C. NCC >= 0.
!>

D

!>          D est tableau DOUBLE PRECISION, dimension (N)
!>          En entrée, les N éléments diagonaux de la matrice bidiagonale B.
!>          En sortie, si INFO=0, les valeurs singulières de B dans l'ordre
!>          décroissant.
!>

E

!>          E est tableau DOUBLE PRECISION, dimension (N-1)
!>          En entrée, les N-1 éléments hors-diagonaux de la matrice
!>          bidiagonale B.
!>          En sortie, si INFO = 0, E est détruit ; si INFO > 0, D et E
!>          contiendront les éléments diagonaux et superdiagonaux d'une
!>          matrice bidiagonale orthogonalement équivalente à celle donnée
!>          en entrée.
!>

VT

!>          VT est tableau COMPLEX*16, dimension (LDVT, NCVT)
!>          En entrée, une matrice N x NCVT VT.
!>          En sortie, VT est écrasée par P**H * VT.
!>          Non référencé si NCVT = 0.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT.
!>          LDVT >= max(1,N) si NCVT > 0 ; LDVT >= 1 si NCVT = 0.
!>

U

!>          U est tableau COMPLEX*16, dimension (LDU, N)
!>          En entrée, une matrice NRU x N U.
!>          En sortie, U est écrasée par U * Q.
!>          Non référencé si NRU = 0.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U.  LDU >= max(1,NRU).
!>

C

!>          C est tableau COMPLEX*16, dimension (LDC, NCC)
!>          En entrée, une matrice N x NCC C.
!>          En sortie, C est écrasée par Q**H * C.
!>          Non référencé si NCC = 0.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C.
!>          LDC >= max(1,N) si NCC > 0 ; LDC >=1 si NCC = 0.
!>

RWORK

!>          RWORK est tableau DOUBLE PRECISION, dimension (LRWORK)
!>          LRWORK = 4*N, si NCVT = NRU = NCC = 0, et
!>          LRWORK = 4*(N-1), sinon
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  Si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  l'algorithme n'a pas convergé ; D et E contiennent les
!>                éléments d'une matrice bidiagonale qui est orthogonalement
!>                similaire à la matrice B d'entrée ;  si INFO = i, i
!>                éléments de E n'ont pas convergé vers zéro.
!>

Paramètres internes:

!>  TOLMUL  DOUBLE PRECISION, par défaut = max(10,min(100,EPS**(-1/8)))
!>          TOLMUL contrôle le critère de convergence de la boucle QR.
!>          S'il est positif, TOLMUL*EPS est la précision relative souhaitée
!>             dans les valeurs singulières calculées.
!>          S'il est négatif, abs(TOLMUL*EPS*sigma_max) est la précision absolue
!>             souhaitée dans les valeurs singulières calculées (correspondant
!>             à une précision relative abs(TOLMUL*EPS) sur la plus grande
!>             valeur singulière.
!>          abs(TOLMUL) doit être compris entre 1 et 1/EPS, et de préférence
!>             entre 10 (pour une convergence rapide) et .1/EPS
!>             (pour une certaine précision dans les résultats).
!>          Par défaut, on perd soit un huitième soit 2 des chiffres décimaux
!>             disponibles dans chaque valeur singulière calculée (le plus petit
!>             des deux).
!>
!>  MAXITR  INTEGER, par défaut = 6
!>          MAXITR contrôle le nombre maximum de passes de l'algorithme
!>          dans sa boucle interne. L'algorithme s'arrête
!>          (et donc échoue à converger) si le nombre de passes
!>          dans la boucle interne dépasse MAXITR*N**2.
!>
!>

Note:

!>  Rapport de bug de Cezary Dendek.
!>  Le 3 novembre 2023, la variable INTEGER MAXIT = MAXITR*N**2 est
!>  supprimée car elle peut facilement déborder (pour N supérieur ou égal
!>  à 18 919). Nous utilisons à la place MAXITDIVN = MAXITR*N.
!>
