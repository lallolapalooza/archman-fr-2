Objectif:

!>
!> Programme de test pour les BLAS de niveau 2 COMPLEX*16.
!>
!> Le programme doit être piloté par un fichier de données court. Les 18 premières
!> lignes du fichier sont lues en utilisant une entrée dirigée par liste, les 17
!> dernières lignes sont lues en utilisant le format ( A6, L2 ). Un exemple annoté
!> d'un fichier de données peut être obtenu en supprimant les 3 premiers caractères
!> des 35 lignes suivantes :
!> 'zblat2.out'      NOM DU FICHIER DE SORTIE RESUMEE
!> 6                 NUMERO D'UNITE DU FICHIER RESUME
!> 'CBLA2T.SNAP'     NOM DU FICHIER DE SORTIE INSTANTANEE
!> -1                NUMERO D'UNITE DU FICHIER INSTANTANEE (NON UTILISE SI .LT. 0)
!> F        INDICATEUR LOGIQUE, T POUR REMbobiner le FICHIER INSTANTANEE APRES CHAQUE LIGNE.
!> F        INDICATEUR LOGIQUE, T POUR S'ARRETER EN CAS D'ERREUR.
!> T        INDICATEUR LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR SEUIL DU RAPPORT DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 4                 NOMBRE DE VALEURS DE K
!> 0 1 2 4           VALEURS DE K
!> 4                 NOMBRE DE VALEURS DE INCX ET INCY
!> 1 2 -1 -2         VALEURS DE INCX ET INCY
!> 3                 NOMBRE DE VALEURS DE ALPHA
!> (0.0,0.0) (1.0,0.0) (0.7,-0.9)       VALEURS DE ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> (0.0,0.0) (1.0,0.0) (1.3,-1.1)       VALEURS DE BETA

NOM

ZBLAT2 - sous-routines de bas niveau pour les matrices complexes.

DESCRIPTION

Ce fichier contient les sous-routines suivantes :

La bibliothèque LAPACK est un ensemble de sous-programmes FORTRAN écrit pour résoudre des systèmes d'équations linéaires, des problèmes de moindres carrés linéaires, des problèmes de valeurs propres et de vecteurs singuliers, pour des matrices denses et structurées.

Le sous-programme `ZBLAT2` est une implémentation pour les matrices complexes.
