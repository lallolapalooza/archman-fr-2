NOM

zbarcam - scanner et décoder des codes-barres à partir d'un périphérique vidéo

SYNTAXE

zbarcam [-qv] [--quiet] [--nodisplay] [--xml] [--verbose[=n]] [--prescale=LxH] [-S[symbologie.]config[=valeur]] [--set [symbologie.]config[=valeur]] [périphérique]

zbarcam {-h | --help | --version}

DESCRIPTION

zbarcam scanne une source vidéo video4linux (par ex., une webcam) à la recherche de codes-barres et imprime les données décodées sur la sortie standard. Le flux vidéo est également affiché à l'écran.

périphérique est le chemin d'accès vers le fichier spécial de caractère video4linux (version 1 ou 2) (numéro majeur 81 et numéros mineurs 0 à 63). Il est par défaut /dev/video0

La bibliothèque sous-jacente prend actuellement en charge les symbologies EAN-13 (y compris les sous-ensembles UPC et ISBN), EAN-8, DataBar, DataBar Expanded, Code 128, Code 93, Code 39, Codabar, Interleaved 2 of 5 et QR Code. Le type spécifique de chaque symbole détecté est imprimé avec les données décodées.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU. Les options à une seule lettre peuvent être regroupées, les options longues commencent par deux tirets (`-').

-h, --help

Imprime un court message d'aide décrivant les options de ligne de commande sur la sortie standard et quitte

--version

Imprime les informations de version du programme sur la sortie standard et quitte

-v, --verbose[=n]

Augmente le niveau de sortie de débogage. Plusieurs options -v créent plus de bavardages. Alternativement, spécifiez n pour définir directement le niveau de débogage

-S[symbologie.]config[=valeur], --set [symbologie.]config[=valeur]

Définit l'option de configuration du décodeur config pour symbologie à valeur. valeur est par défaut à 1 si omis. symbologie est l'une des ean13, ean8, upca, upce, isbn13, isbn10, i25, codabar, code39, code93, code128, qrcode ou la valeur spéciale *. Si symbologie est omis ou *, le config sera défini pour toutes les symbologies applicables. Ce sont les configs actuellement reconnus. Préfixez un config avec "no-" pour le nier. Toutes les configs ne conviennent pas à toutes les symbologies.

enable

Contrôle le décodage/reporting d'une symbologie. Pour les symbologies qui ne sont que des sous-ensembles de ean13 (upca, upce, isbn13, isbn10), ce config contrôle si les sous-ensembles sont détectés et rapportés comme tels. Ces cas spéciaux sont désactivés par défaut, toutes les autres symbologies sont activées par défaut

disable

Antonyme de enable

emit-check

Contrôle si les chiffres de contrôle sont inclus dans la sortie décodée. Activé par défaut. Ce config ne s'applique pas à code128, qui ne retourne jamais le chiffre de contrôle. Il ne s'applique pas non plus aux cas où le chiffre de contrôle est désactivé (voir add-check). Les chiffres de contrôle ne sont actuellement pas implémentés pour i25 ou code39

add-check

Active le décodage et la vérification d'un chiffre de contrôle pour les symbologies où il est facultatif : cela inclura code39 et i25, dont aucun n'implémente encore le chiffre de contrôle

ascii

Active les séquences d'échappement qui encodent l'ensemble des caractères ASCII. Cela s'appliquerait à code39, sauf que ce n'est pas implémenté non plus...

position

Active la collecte des informations de position du symbole. Activé par défaut. Actuellement, les informations de position sont inutilisables, vous pouvez donc économiser quelques cycles en désactivant cela.

test-inverted

Spécialement pour les images de code QR, parfois l'image est inversée, par exemple les lignes sont écrites en blanc au lieu de noir. Cette option fait en sorte que ZBar inverse l'image et réanalyse, si elle échoue en utilisant l'ordre normal. L'activer affecte tous les décodeurs.

min-length=n, max-length=n

Limite le nombre de caractères décodés dans un symbole valide. Si un résultat de décodage se situe en dehors de la plage min/max configurée (inclusive), il ne sera pas rapporté. Définir à 0 pour désactiver la vérification correspondante. Ce paramètre s'applique aux symbologies à longueur variable : i25, codabar, code39, code128 et pdf417. min-length est par défaut à 6 pour i25 et 1 pour code39 (selon la recommandation d'autodiscrétion Code 39) ; tous les autres sont par défaut à 0

x-density=n, y-density=n

Ajuste la densité des passes du scanner. Des valeurs plus faibles scannent davantage l'image au détriment des performances. Définir à 0 désactive le scan le long de cet axe. Les deux sont par défaut à 1.

-q, --quiet

Opération silencieuse ; désactive le bip sonore émis autrement lorsqu'un symbole est décodé

--nodisplay

Désactive la fenêtre d'affichage vidéo. L'entrée vidéo sera analysée jusqu'à ce que le programme soit interrompu ou signalé autrement

--xml

Diffuse les résultats en utilisant un format de sortie XML. Ce format encapsule les données brutes du symbole avec des informations sur le scan dans un format facile à analyser. Le dernier schéma est disponible sur http://zbar.sourceforge.net/2008/barcode.xsd

--raw

Utilise le format de sortie des données brutes du symbole. Ce format imprime les données du symbole séparées par des sauts de ligne sans les informations supplémentaires sur le type de symbologie qui sont imprimées par défaut

--prescale=LxH

Demande une mise à l'échelle de l'entrée vidéo du pilote de la caméra. Potentiellement utile pour réduire des images énormes afin d'obtenir une fréquence d'images plus élevée. Notez que le pilote peut ajuster ou ignorer complètement la demande de mise à l'échelle

EXEMPLES

Scanner les codes-barres en utilisant le deuxième périphérique vidéo et rediriger les données résultantes vers un script qui recherche chaque code dans une base de données et fait quelque chose d'utile avec eux :

zbarcam /dev/video1 | upcrpc.py

Le script upcrpc.py inclus dans le sous-répertoire examples/ de la distribution effectuera un appel XMLRPC à une base de données UPC Internet populaire et imprimera la description du produit si elle est trouvée.

Scanner les codes-barres en utilisant le périphérique vidéo par défaut et diffuser les résultats sur stdout au format XML, désactiver également la reconnaissance des codes Interleaved 2 of 5 pour éviter toute confusion avec d'autres symbologies ou des bruits de fond :

zbarcam --xml -Si25.disable

Scanner uniquement le Code 39, sans utiliser la fenêtre de prévisualisation - peut-être pour une installation fixe. Pour activer uniquement le Code 39, toutes les symbologies sont d'abord désactivées, puis le Code 39 est réactivé :

zbarcam --nodisplay -Sdisable -Scode39.enable

STATUT DE SORTIE

zbarcam renvoie un code de sortie pour indiquer le statut de l'exécution du programme. Les codes de sortie actuels sont :

0

Achèvement réussi du programme.

1

Une erreur s'est produite. Cela inclut des arguments invalides et des erreurs d'E/S.

2

Une erreur fatale s'est produite.
