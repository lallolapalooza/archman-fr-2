NOM

zbarimg - scanner et décoder des codes-barres à partir de(s) fichier(s) image

SYNTAXE

zbarimg [-qv] [--polygon] [--quiet] [--verbose[=n]]
{-dD | --display | --nodisplay | --xml | --noxml | -S[symbologie.]config[=valeur] | --set [symbologie.]config[=valeur] | image...}

zbarimg {-h | --help | --version}

DESCRIPTION

Pour chaque fichier image spécifié, zbarimg scanne l'image à la recherche de codes-barres et affiche toutes les données décodées sur la sortie standard. Les images peuvent éventuellement être affichées à l'écran.

La bibliothèque sous-jacente prend actuellement en charge les symbologies EAN-13 (y compris les sous-ensembles UPC et ISBN), EAN-8, DataBar, DataBar Expanded, Code 128, Code 93, Code 39, Codabar, Interleaved 2 of 5 et QR Code. Le type spécifique de chaque symbole détecté est imprimé avec les données décodées.

Notez que "image" dans ce contexte fait référence à tout format pris en charge par ImageMagick, y compris de nombreux formats vectoriels tels que PDF et PostScript. Gardez à l'esprit que les formats vectoriels sont rastérisés avant le balayage ; rastérisez manuellement les images vectorielles avant le balayage pour éviter de corrompre involontairement les bitmaps de codes-barres intégrés.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU. Les options d'une seule lettre peuvent être regroupées, les options longues commencent par deux tirets (`-').

-h, --help

Affiche un court message d'aide décrivant les options de ligne de commande sur la sortie standard et quitte.

--version

Affiche les informations de version du programme sur la sortie standard et quitte.

-v, --verbose[=n]

Augmente le niveau de sortie de débogage. Plusieurs options -v génèrent plus de messages. Alternativement, spécifiez n pour définir directement le niveau de débogage.

-S[symbologie.]config[=valeur], --set [symbologie.]config[=valeur]

Définit l'option de configuration du décodeur config pour la symbologie à valeur. valeur est 1 par défaut si omise. symbologie est l'un de ean13, ean8, upca, upce, isbn13, isbn10, i25, codabar, code39, code93, code128, qrcode ou la valeur spéciale *. Si symbologie est omise ou *, la config sera définie pour toutes les symbologies applicables. Ce sont les config actuellement reconnues. Préfixez une config avec "no-" pour l'invalider. Toutes les configs ne conviennent pas à toutes les symbologies.

enable

Contrôle le décodage/le rapport d'une symbologie. Pour les symbologies qui ne sont que des sous-ensembles de ean13 (upca, upce, isbn13, isbn10), cette config contrôle si les sous-ensembles sont détectés et rapportés comme tels. Ces cas spéciaux sont désactivés par défaut, toutes les autres symbologies sont activées par défaut.

disable

Antonyme de enable.

emit-check

Contrôle si les chiffres de contrôle sont inclus dans la sortie décodée. Activé par défaut. Cette config ne s'applique pas à code128, qui ne renvoie jamais le chiffre de contrôle. Elle ne s'applique pas non plus aux cas où le chiffre de contrôle est désactivé (voir add-check). Les chiffres de contrôle ne sont actuellement pas implémentés pour i25 ou code39.

add-check

Active le décodage et la vérification d'un chiffre de contrôle pour les symbologies où il est facultatif : cela inclura code39 et i25, dont aucun n'implémente encore le chiffre de contrôle.

ascii

Active les séquences d'échappement qui encodent l'ensemble des caractères ASCII. Cela s'appliquerait à code39, sauf que ce n'est pas non plus implémenté...

position

Active la collecte des informations de position du symbole. Activé par défaut. Actuellement, les informations de position sont inutilisables, vous pouvez donc économiser quelques cycles en désactivant cette option.

test-inverted

Spécialement pour les images de code QR, parfois l'image est inversée, par exemple, les lignes sont écrites en blanc au lieu de noir. Cette option demande à ZBar d'inverser l'image et de la réanalyser, au cas où elle échouerait en utilisant l'ordre normal. L'activation affecte tous les décodeurs.

min-length=n, max-length=n

Limite le nombre de caractères décodés dans un symbole valide. Si un résultat de décodage se situe en dehors de la plage min/max configurée (inclusivement), il ne sera pas rapporté. Définir sur 0 désactive la vérification correspondante. Ce réglage s'applique aux symbologies de longueur variable : i25, codabar, code39, code128 et pdf417. min-length est par défaut 6 pour i25 et 1 pour code39 (conformément à la recommandation d'autodiscrémination Code 39) ; tous les autres sont par défaut à 0.

x-density=n, y-density=n

Ajuste la densité des passages du scanner. Des valeurs plus basses scannent une plus grande partie de l'image au détriment des performances. Définir à 0 désactive le balayage le long de cet axe. Les valeurs par défaut sont les deux à 1.

--polygon

Affiche les points du polygone contenant le code-barres. Utilise un format compatible avec l'élément <polygon> du langage de balisage Scalable Vector Graphics (SVG).

-q, --quiet

Fonctionnement silencieux ; affiche uniquement les données décodées du symbole. Plus précisément, cela désactive la ligne de statistiques imprimée (sur stderr) avant de quitter, ainsi que le message d'avertissement imprimé (également sur stderr) lorsqu'aucun code-barres n'est trouvé dans une image.

-d, --display, -D, --nodisplay

Active/désactive l'affichage des fichiers image suivants, jusqu'à ce qu'une autre option --display ou --nodisplay soit rencontrée. Cette option peut apparaître plusieurs fois pour activer l'affichage d'images spécifiques. L'affichage de l'image est désactivé par défaut.

--xml, --noxml

Active/désactive la sortie des résultats en utilisant un format XML. Ce format encapsule les données brutes du symbole avec des informations sur le balayage (telles que les indices de page) dans un format facile à analyser. Le dernier schéma est disponible sur http://zbar.sourceforge.net/2008/barcode.xsd.

--raw

Active la sortie des données brutes du symbole. Ce format imprime les données du symbole séparées par des sauts de ligne sans les informations supplémentaires sur le type de symbologie qui sont imprimées par défaut.

EXEMPLES

Scanner une image PNG d'un symbole de code-barres UPC et transmettre les données résultantes à un script qui recherche le code dans une base de données et fait quelque chose d'utile avec :

zbarimg product.png | upcrpc.py

Le script exemple upcrpc.py inclus dans le sous-répertoire examples/ de la distribution effectuera un appel XMLRPC à une base de données UPC populaire sur Internet et imprimera la description du produit si elle est trouvée.

Scanner une image JPEG contenant plusieurs codes-barres et afficher l'image dans une fenêtre, tout en désactivant la reconnaissance des codes Interleaved 2 of 5 pour éviter la confusion avec d'autres symbologies ou le bruit de fond :

zbarimg --display -Si25.disable label.jpg

Rechercher dans un document numérisé uniquement les codes 39, en utilisant le format de sortie XML afin que les numéros de page soient disponibles. Pour n'activer que le code 39, toutes les symbologies sont d'abord désactivées, puis le code 39 est réactivé :

zbarimg --xml -Sdisable -Scode39.enable scan.tiff

STATUT DE SORTIE

zbarimg renvoie un code de sortie pour indiquer l'état d'exécution du programme. Codes de sortie actuels :

0

Codes-barres détectés avec succès dans toutes les images. Des avertissements peuvent avoir été générés, mais aucune erreur.

1

Une erreur s'est produite lors du traitement d'une ou plusieurs images. Cela inclut les arguments incorrects, les erreurs d'E/S et les erreurs de gestion d'image d'ImageMagick.

2

Erreur fatale d'ImageMagick.

3

L'utilisateur a quitté le programme avant que toutes les images n'aient été numérisées. S'applique uniquement lors de l'exécution en mode interactif (avec --display).

4

Aucun code-barres n'a été détecté dans toutes les images.
