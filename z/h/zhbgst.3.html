Documentation de la fonction/sous-programme

sous-routine zhbgst (character vect, character uplo, integer n, integer ka, integer kb, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldbb, * ) bb, integer ldbb, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZHBGST

Objectif :

!>
!> ZHBGST réduit un problème généralisé d' valeurs propres d'Hermite complexe et défini
!> A*x = lambda*B*x  à la forme standard  C*y = lambda*y,
!> de telle sorte que C ait la même bande passante que A.
!>
!> B doit avoir été préalablement factorisé en S**H*S par ZPBSTF, en utilisant une
!> factorisation de Cholesky divisée. A est écrasé par C = X**H*A*X, où
!> X = S**(-1)*Q et Q est une matrice unitaire choisie pour préserver la
!> bande passante de A.
!>

Paramètres

VECT 
!>          VECT est CHARACTER*1
!>          = 'N':  ne pas former la matrice de transformation X ;
!>          = 'V':  former X.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  le triangle supérieur de A est stocké ;
!>          = 'L':  le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B.  N >= 0.
!>

KA

!>          KA est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KA >= 0.
!>

KB

!>          KB est INTEGER
!>          Le nombre de super-diagonales de la matrice B si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KA >= KB >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, dimension (LDAB,N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande
!>          d'Hermite A, stocké dans les KA+1 premières lignes du tableau. La
!>          colonne j de A est stockée dans la colonne j du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) pour max(1,j-ka) <= i <= j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j <= i <= min(n,j+ka).
!>
!>          En sortie, la matrice transformée X**H*A*X, stockée dans le même
!>          format que A.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KA+1.
!>

BB

!>          BB est un tableau COMPLEX*16, dimension (LDBB,N)
!>          Le facteur bande S de la factorisation de Cholesky divisée de
!>          B, tel que retourné par ZPBSTF, stocké dans les KB+1 premières lignes du
!>          tableau.
!>

LDBB

!>          LDBB est INTEGER
!>          La dimension principale du tableau BB.  LDBB >= KB+1.
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,N)
!>          Si VECT = 'V', la matrice X de taille n x n.
!>          Si VECT = 'N', le tableau X n'est pas référencé.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.
!>          LDX >= max(1,N) si VECT = 'V' ; LDX >= 1 sinon.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>
