Documentation de la fonction/sous-programme

sous-programme zhbgv (character jobz, character uplo, integer n, integer ka, integer kb, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldbb, * ) bb, integer ldbb, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZHBGV

Objectif :

!>
!> ZHBGV calcule toutes les valeurs propres, et éventuellement, les vecteurs propres
!> d'un problème aux valeurs propres généralisé Hermitien-défini et bande complexe,
!> de la forme A*x=(lambda)*B*x. Ici, A et B sont supposées Hermitiennes et
!> en bande, et B est également définie positive.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Les triangles supérieurs de A et B sont stockés ;
!>          = 'L' : Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B.  N >= 0.
!>

KA

!>          KA est INTEGER
!>          Le nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KA >= 0.
!>

KB

!>          KB est INTEGER
!>          Le nombre de superdiagonales de la matrice B si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KB >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, de dimension (LDAB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande
!>          Hermitienne A, stocké dans les KA+1 premières lignes du tableau. La
!>          colonne j de A est stockée dans la colonne j du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) pour max(1,j-ka)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+ka).
!>
!>          En sortie, le contenu de AB est détruit.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KA+1.
!>

BB

!>          BB est un tableau COMPLEX*16, de dimension (LDBB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande
!>          Hermitienne B, stocké dans les KB+1 premières lignes du tableau. La
!>          colonne j de B est stockée dans la colonne j du tableau BB
!>          comme suit :
!>          si UPLO = 'U', BB(kb+1+i-j,j) = B(i,j) pour max(1,j-kb)<=i<=j ;
!>          si UPLO = 'L', BB(1+i-j,j)    = B(i,j) pour j<=i<=min(n,j+kb).
!>
!>          En sortie, le facteur S de la factorisation de Cholesky divisée
!!>          B = S**H*S, tel que retourné par ZPBSTF.
!>

LDBB

!>          LDBB est INTEGER
!>          La dimension principale du tableau BB.  LDBB >= KB+1.
!>

W

!>          W est un tableau DOUBLE PRECISION, de dimension (N)
!>          Si INFO = 0, les valeurs propres dans l'ordre croissant.
!>

Z

!>          Z est un tableau COMPLEX*16, de dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient la matrice Z des
!>          vecteurs propres, où la i-ème colonne de Z contient le
!>          vecteur propre associé à W(i). Les vecteurs propres sont
!>          normalisés de sorte que Z**H*B*Z = I.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= N.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (3*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>          > 0 : si INFO = i, et i est :
!>             <= N : l'algorithme n'a pas convergé :
!>                    i éléments hors diagonale d'une forme
!>                    triangulaire intermédiaire n'ont pas convergé vers zéro ;
!>             > N :   si INFO = N + i, pour 1 <= i <= N, alors ZPBSTF
!>                    a retourné INFO = i : B n'est pas définie positive.
!>                    La factorisation de B n'a pas pu être terminée et
!>                    aucune valeur propre ou vecteur propre n'a été calculé.
!>
