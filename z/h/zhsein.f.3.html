Documentation de la fonction/sous-routine

sous-routine zhsein (caractère side, caractère eigsrc, caractère initv, logique, dimension( * ) select, entier n, complexe*16, dimension( ldh, * ) h, entier ldh, complexe*16, dimension( * ) w, complexe*16, dimension( ldvl, * ) vl, entier ldvl, complexe*16, dimension( ldvr, * ) vr, entier ldvr, entier mm, entier m, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier, dimension( * ) ifaill, entier, dimension( * ) ifailr, entier info)

ZHSEIN

But :

!>
!> ZHSEIN utilise l'itération inverse pour trouver les vecteurs propres
!> propres (droite et/ou gauche) spécifiés d'une matrice complexe
!> de Hessenberg H.
!>
!> Le vecteur propre droit x et le vecteur propre gauche y de la matrice H
!> correspondant à une valeur propre w sont définis par :
!>
!>              H * x = w * x,     y**h * H = w * y**h
!>
!> où y**h représente la transposée conjuguée du vecteur y.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R' : calculer uniquement les vecteurs propres droits ;
!>          = 'L' : calculer uniquement les vecteurs propres gauches ;
!>          = 'B' : calculer les deux vecteurs propres droits et gauches.
!>

EIGSRC

!>          EIGSRC est CHARACTER*1
!>          Spécifie la source des valeurs propres fournies dans W :
!>          = 'Q' : les valeurs propres ont été trouvées en utilisant ZHSEQR ; ainsi, si
!>                 H a des éléments sous-diagonaux nuls, et est donc
!>                 triangulaire par blocs, alors la j-ième valeur propre peut
!>                 être considérée comme une valeur propre du bloc contenant
!>                 la j-ième ligne/colonne. Cette propriété permet à ZHSEIN
!>                 d'effectuer une itération inverse sur un seul bloc diagonal.
!>          = 'N' : aucune hypothèse n'est faite sur la correspondance
!>                 entre les valeurs propres et les blocs diagonaux. Dans ce
!>                 cas, ZHSEIN doit toujours effectuer une itération inverse
!>                 en utilisant toute la matrice H.
!>

INITV

!>          INITV est CHARACTER*1
!>          = 'N' : aucun vecteur initial n'est fourni ;
!>          = 'U' : des vecteurs initiaux fournis par l'utilisateur sont stockés dans les tableaux
!>                 VL et/ou VR.
!>

SELECT

!>          SELECT est un tableau LOGIQUE, dimension (N)
!>          Spécifie les vecteurs propres à calculer. Pour sélectionner le
!>          vecteur propre correspondant à la valeur propre W(j),
!>          SELECT(j) doit être mis à .VRAI..
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice H. N >= 0.
!>

H

!>          H est un tableau COMPLEX*16, dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H.
!>          Si un NaN est détecté dans H, la routine retournera avec INFO=-6.
!>

LDH

!>          LDH est un ENTIER
!>          La dimension principale du tableau H. LDH >= max(1,N).
!>

W

!>          W est un tableau COMPLEX*16, dimension (N)
!>          En entrée, les valeurs propres de H.
!>          En sortie, les parties réelles de W peuvent avoir été modifiées car
!>          des valeurs propres proches sont légèrement perturbées lors de la recherche
!>          de vecteurs propres indépendants.
!>

VL

!>          VL est un tableau COMPLEX*16, dimension (LDVL,MM)
!>          En entrée, si INITV = 'U' et SIDE = 'L' ou 'B', VL doit
!>          contenir des vecteurs de départ pour l'itération inverse des
!>          vecteurs propres gauches ; le vecteur de départ pour chaque vecteur propre
!>          doit être dans la même colonne où le vecteur propre sera
!>          stocké.
!>          En sortie, si SIDE = 'L' ou 'B', les vecteurs propres gauches
!>          spécifiés par SELECT seront stockés consécutivement dans
!>          les colonnes de VL, dans le même ordre que leurs valeurs propres.
!>          Si SIDE = 'R', VL n'est pas référencé.
!>

LDVL

!>          LDVL est un ENTIER
!>          La dimension principale du tableau VL.
!>          LDVL >= max(1,N) si SIDE = 'L' ou 'B' ; LDVL >= 1 sinon.
!>

VR

!>          VR est un tableau COMPLEX*16, dimension (LDVR,MM)
!>          En entrée, si INITV = 'U' et SIDE = 'R' ou 'B', VR doit
!>          contenir des vecteurs de départ pour l'itération inverse des
!>          vecteurs propres droits ; le vecteur de départ pour chaque vecteur propre
!>          doit être dans la même colonne où le vecteur propre sera
!>          stocké.
!>          En sortie, si SIDE = 'R' ou 'B', les vecteurs propres droits
!>          spécifiés par SELECT seront stockés consécutivement dans
!>          les colonnes de VR, dans le même ordre que leurs valeurs propres.
!>          Si SIDE = 'L', VR n'est pas référencé.
!>

LDVR

!>          LDVR est un ENTIER
!>          La dimension principale du tableau VR.
!>          LDVR >= max(1,N) si SIDE = 'R' ou 'B' ; LDVR >= 1 sinon.
!>

MM

!>          MM est un ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est un ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR requis pour
!>          stocker les vecteurs propres (= le nombre d'éléments .VRAI. dans
!>          SELECT).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (N)
!>

IFAILL

!>          IFAILL est un tableau ENTIER, dimension (MM)
!>          Si SIDE = 'L' ou 'B', IFAILL(i) = j > 0 si le vecteur propre gauche
!>          dans la i-ème colonne de VL (correspondant à la valeur propre w(j))
!>          n'a pas convergé ; IFAILL(i) = 0 si le
!>          vecteur propre a convergé de manière satisfaisante.
!>          Si SIDE = 'R', IFAILL n'est pas référencé.
!>

IFAILR

!>          IFAILR est un tableau ENTIER, dimension (MM)
!>          Si SIDE = 'R' ou 'B', IFAILR(i) = j > 0 si le vecteur propre droit
!>          dans la i-ème colonne de VR (correspondant à la valeur propre w(j))
!>          n'a pas convergé ; IFAILR(i) = 0 si le
!>          vecteur propre a convergé de manière satisfaisante.
!>          Si SIDE = 'L', IFAILR n'est pas référencé.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, i est le nombre de vecteurs propres qui
!>                n'ont pas convergé ; voir IFAILL et IFAILR pour plus de
!>                détails.
!>
