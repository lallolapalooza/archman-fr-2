sous-routine zheevd_2stage (caractere jobz, caractere uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, double precision, dimension( * ) w, complexe*16, dimension( * ) work, entier lwork, double precision, dimension( * ) rwork, entier lrwork, entier, dimension( * ) iwork, entier liwork, entier info)

ZHEEVD_2STAGE calcule les valeurs propres et, optionnellement, les vecteurs propres gauche et/ou droite pour les matrices HE

Objectif:

!>
!> ZHEEVD_2STAGE calcule toutes les valeurs propres et, optionnellement, les vecteurs propres d'une
!> matrice hermitienne complexe A en utilisant la technique 2stage pour
!> la réduction à la forme tridiagonale. Si des vecteurs propres sont souhaités, un
!> algorithme de type "diviser pour régner" est utilisé.
!>
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calcul des valeurs propres uniquement ;
!>          = 'V':  Calcul des valeurs propres et des vecteurs propres.
!>                  Non disponible dans cette version.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>          À l'entrée, la matrice hermitienne A.  Si UPLO = 'U', la
!>          partie triangulaire supérieure N-par-N de A contient
!>          la partie triangulaire supérieure de la matrice A.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N-par-N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>          À la sortie, si JOBZ = 'V', alors si INFO = 0, A contient les
!>          vecteurs propres orthonormés de la matrice A.
!>          Si JOBZ = 'N', alors à la sortie le triangle inférieur (si UPLO='L')
!>          ou le triangle supérieur (si UPLO='U') de A, y compris la
!>          diagonale, est détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

W

!>          W est un tableau DOUBLE PRECISION, dimension (N)
!>          Si INFO = 0, les valeurs propres dans l'ordre croissant.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si N <= 1,               LWORK doit être au moins 1.
!>          Si JOBZ = 'N' et N > 1, LWORK doit être interrogé.
!>                                   LWORK = MAX(1, dimension) où
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + N+1
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + N+1
!>                                   où KD est la taille du bloc de la réduction,
!>                                   FACTOPTNB est le bloc utilisé par l'algorithme QR ou LQ
!>                                   généralement FACTOPTNB=128 est un bon choix
!>                                   NTHREADS est le nombre de threads utilisés lors de la
!>                                   compilation openMP activée, sinon =1.
!>          Si JOBZ = 'V' et N > 1, LWORK doit être au moins 2*N + N**2
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION,
!>                                         dimension (LRWORK)
!>          À la sortie, si INFO = 0, RWORK(1) contient la valeur optimale de LRWORK.
!>

LRWORK

!>          LRWORK est INTEGER
!>          La dimension du tableau RWORK.
!>          Si N <= 1,                LRWORK doit être au moins 1.
!>          Si JOBZ  = 'N' et N > 1, LRWORK doit être au moins N.
!>          Si JOBZ  = 'V' et N > 1, LRWORK doit être au moins
!>                         1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK, RWORK
!!>          et IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) contient la valeur optimale de LIWORK.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si N <= 1,                LIWORK doit être au moins 1.
!>          Si JOBZ  = 'N' et N > 1, LIWORK doit être au moins 1.
!>          Si JOBZ  = 'V' et N > 1, LIWORK doit être au moins 3 + 5*N.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK, RWORK
!>          et IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  exécution réussie
!>          < 0:  si INFO = -i, alors le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i et JOBZ = 'N', alors l'algorithme n'a pas convergé ; i éléments
!>                hors diagonale d'une forme tridiagonale intermédiaire n'ont pas convergé vers zéro ;
!>                si INFO = i et JOBZ = 'V', alors l'algorithme n'a pas réussi à calculer
!>                une valeur propre lors du travail sur la sous-matrice
!>                située dans les lignes et colonnes INFO/(N+1) à
!>                mod(INFO,N+1).
!>

NAME

zheevd_2stage - Computes the eigenvalues and eigenvectors of a general complex Hermitian matrix.

SYNOPSIS

  SUBROUTINE zheevd_2stage( JOBZ, UPLO, N, A, LDA, D, Z, LDZ, WORK,
                            LWORK, RWORK, LRWORK, IWORK, LIWORK, INFO )
    CHARACTER * 1   :: JOBZ, UPLO
    INTEGER         :: LDA, LDZ, LWORK, LRWORK, LIWORK
    INTEGER         :: N, INFO
    DOUBLE PRECISION :: D( * )
    DOUBLE PRECISION :: RWORK( * )
    INTEGER         :: IWORK( * )
    COMPLEX*16      :: A( * ), Z( * )
    COMPLEX*16      :: WORK( * )

Function/Subroutine Documentation

This subroutine computes the eigenvalues and eigenvectors of a general complex Hermitian matrix.

This subroutine is a hybrid CPU-GPU implementation of a generalized eigensolver for electronic structure calculations.

Reference:
!>  B. Cai, B. S. Chertov, E. L. Johnson, K. S. B. K. N. L. A. Aidar, R. Solca, S. Tomov, T. Schulthess and J. Dongarra.

!>  calculations based on fine-grained memory aware tasks.
!>  International Journal of High Performance Computing Applications.
!>  Volume 28 Issue 2, Pages 196-209, May 2014.
