Documentation de fonction/sous-routine

sous-routine zhpgvx (entier itype, caractère jobz, caractère range, caractère uplo, entier n, complexe*16, dimension( * ) ap, complexe*16, dimension( * ) bp, double précision vl, double précision vu, entier il, entier iu, double précision abstol, entier m, double précision, dimension( * ) w, complexe*16, dimension( ldz, * ) z, entier ldz, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier, dimension( * ) iwork, entier, dimension( * ) ifail, entier info)

ZHPGVX

Objectif:

!>
!> ZHPGVX calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'un problème propre généralisé hermitien défini complexe, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou B*A*x=(lambda)*x. Ici, A et
!> B sont supposées hermitiennes, stockées au format compacté, et B est également
!> définie positive. Les valeurs propres et les vecteurs propres peuvent être sélectionnés
!> en spécifiant soit un intervalle de valeurs, soit un intervalle d'indices pour les
!> valeurs propres désirées.
!>

Paramètres

ITYPE 
!>          ITYPE est ENTIER
!>          Spécifie le type de problème à résoudre :
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ est CARACTERE*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CARACTERE*1
!>          = 'A': toutes les valeurs propres seront trouvées ;
!>          = 'V': toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées ;
!>          = 'I': les valeurs propres d'indice IL à IU seront trouvées.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          = 'U':  les triangles supérieurs de A et B sont stockés ;
!>          = 'L':  les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A et B.  N >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice hermitienne
!>          A, compacté par colonne dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.
!>
!>          En sortie, le contenu de AP est détruit.
!>

BP

!>          BP est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice hermitienne
!>          B, compacté par colonne dans un tableau linéaire. La j-ème colonne de B
!>          est stockée dans le tableau BP comme suit :
!>          si UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) pour j<=i<=n.
!>
!>          En sortie, le facteur triangulaire U ou L de la factorisation de Cholesky
!>          B = U**H*U ou B = L*L**H, dans le même format de stockage que B.
!>

VL

!>          VL est DOUBLE PRÉCISION
!>
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est DOUBLE PRÉCISION
!>
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est ENTIER
!>
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est ENTIER
!>
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est DOUBLE PRÉCISION
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergente
!>          lorsqu'il est déterminé qu'elle se trouve dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant AP à une forme tridiagonale.
!>
!>          Les valeurs propres seront calculées de manière la plus précise lorsque ABSTOL
!>          est réglé sur deux fois le seuil de sous-flux 2*DLAMCH('S'), et non zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de régler ABSTOL sur
!>          2*DLAMCH('S').
!>

M

!>          M est ENTIER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau DOUBLE PRÉCISION, dimension (N)
!>          En cas de sortie normale, les M premiers éléments contiennent les
!>          valeurs propres sélectionnées par ordre croissant.
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ, N)
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormés de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Les vecteurs propres sont normalisés comme suit :
!>          si ITYPE = 1 ou 2, Z**H*B*Z = I ;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>
!>          Si un vecteur propre ne converge pas, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et l'indice
!>          du vecteur propre est retourné dans IFAIL.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est ENTIER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (7*N)
!>

IWORK

!>          IWORK est un tableau ENTIER, dimension (5*N)
!>

IFAIL

!>          IFAIL est un tableau ENTIER, dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont zéro. Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!>

INFO

!>          INFO est ENTIER
!>          = 0:  la sortie est réussie.
!>          > 0:  un dépassement de capacité s'est produit lors de la mise à l'échelle
!>                de la valeur propre ou un vecteur propre n'a pas convergé.
!>                Retourne le nombre de valeurs propres qui n'ont pas convergé.
!>          < 0:  le i-ème argument (valeur absolue) n'a pas une valeur valide.
!>                Si ITYPE = -1, l'i-ème algorithme de calcul a échoué ;
!>                consulter les spécifications de l'algorithme.
!>

Function/Subroutine Documentation

ZHONGVX computes the eigenvalues and eigenvectors of a complex Hermitian-positive definite matrix H in AP and a complex Hermitian positive semi-definite matrix B in B (in general, B is not required to be positive definite).

For the current problem, these are either the generalized eigenvalues

A*z = lambda*B*z, H*z = lambda*B*z, or the range of eigenvalues

A*z = lambda*B*z, H*z = lambda*B*z.

H is Hermitian with respect to the scalar product defined by B, i.e.,

(A,B) = B*A*B

where A is Hermitian (A**H = A).

Input Parameters

ITYPE
INTEGER. Possible values of ITYPE and the corresponding problem type are:
JOBZ
CHARACTER*1. Possible values of JOBZ and the corresponding values are:
RANGE
CHARACTER*1. Possible values of RANGE and the corresponding values are:
UPLO
CHARACTER*1. Possible values of UPLO and the corresponding values are:
N
INTEGER. The order of the matrices H and B. N >= 0.
AP
COMPLEX*16 array, dimension (N*(N+1)/2). On entry, the upper or lower triangular part of the Hermitian matrix H.
B
COMPLEX*16 array, dimension (LD B, N).
LD B
INTEGER. The leading dimension of the array B. LD B >= (min(N,NB)) where NB is the block size of B.
AB
COMPLEX*16 array, dimension (LAB, N).
LAB
INTEGER. The dimension of the array AB. LAB >= (min(N,NB)) where NB is the block size of B.
VL, VU
DOUBLE PRECISION. If RANGE='V', the lower and upper bounds of the interval to be searched for eigenvalues.
IL, IU
INTEGER. If RANGE='I', the indices of the search range for eigenvalues.
RTOL
DOUBLE PRECISION. Relative accuracy for eigenvalues. See ZHPTRF.
OFFSR, OFFSI
DOUBLE PRECISION. Offset for eigenvalues.
LDZ
INTEGER. The leading dimension of the array Z. LDZ >= (max(1, N)).
WORK
COMPLEX*16 array, dimension (3*N).
RWORK
DOUBLE PRECISION array, dimension (8*N).
IWORK
INTEGER array, dimension (5*N).
BWORK
LOGICAL array, dimension (N).
INFO
INTEGER
= 0: successful exit
< 0: if INFO = -i, the i-th argument had an illegal value
> 0: ZPPTRF or ZHPEVX returned an error code:
<= N: if INFO = i, ZHPEVX failed to converge;
i eigenvectors failed to converge. Their indices
are stored in array IFAIL.
> N: if INFO = N + i, for 1 <= i <= n, then the leading
principal minor of order i of B is not positive.
The factorization of B could not be completed and
no eigenvalues or eigenvectors were computed.
