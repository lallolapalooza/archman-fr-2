Documentation de la fonction/sous-routine

sous-routine zhst01 (integer n, integer ilo, integer ihi, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldh, * ) h, integer ldh, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( 2 ) result)

ZHST01

Objectif :

!>
!> ZHST01 teste la réduction d'une matrice générale A sous forme
!> d'Hessenberg supérieure :  A = Q*H*Q'.  Deux rapports de test sont calculés ;
!>
!> RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!> RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
!> La matrice Q est supposée être donnée explicitement telle qu'elle serait
!> après ZGEHRD + ZUNGHR.
!>
!> Dans cette version, ILO et IHI ne sont pas utilisés, mais ils pourraient l'être
!> pour économiser du travail si cela est souhaité.
!>

Paramètres

N 
!>          N est un entier
!>          L'ordre de la matrice A.  N >= 0.
!>

ILO

!>          ILO est un entier
!>

IHI

!>          IHI est un entier
!>
!>          On suppose que A est triangulaire supérieure en lignes et colonnes
!>          1:ILO-1 et IHI+1:N, donc Q ne diffère de l'identité que dans les
!>          lignes et colonnes ILO+1:IHI.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          La matrice originale A de taille n par n.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

H

!>          H est un tableau COMPLEX*16, de dimension (LDH,N)
!>          La matrice d'Hessenberg supérieure H issue de la réduction
!>          A = Q*H*Q' telle que calculée par ZGEHRD.  On suppose que H
!>          est nulle en dessous de la première sous-diagonale.
!>

LDH

!>          LDH est un entier
!>          La dimension principale du tableau H.  LDH >= max(1,N).
!>

Q

!>          Q est un tableau COMPLEX*16, de dimension (LDQ,N)
!>          La matrice orthogonale Q issue de la réduction A = Q*H*Q'
!>          telle que calculée par ZGEHRD + ZUNGHR.
!>

LDQ

!>          LDQ est un entier
!>          La dimension principale du tableau Q.  LDQ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>          La longueur du tableau WORK.  LWORK >= 2*N*N.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (N)
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, de dimension (2)
!>          RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
