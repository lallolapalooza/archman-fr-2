ZHPSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices AUTRES

Documentation de la fonction/sous-routine

sous-routine zhpsvx (caractère fact, caractère uplo, entier n, entier nrhs, complexe*16, dimension( * ) ap, complexe*16, dimension( * ) afp, entier, dimension( * ) ipiv, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldx, * ) x, entier ldx, double précision rcond, double précision, dimension( * ) ferr, double précision, dimension( * ) berr, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier info)

ZHPSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices HERMITIENNES (au sens des matrices complexes)

Objectif :

!>
!> ZHPSVX utilise la factorisation par pivot de diagonale A = U*D*U**H ou
!> A = L*D*L**H pour calculer la solution d'un système d'équations linéaires complexes A * X = B,
!> où A est une matrice hermitienne N-par-N stockée au format compacté et X et B sont des matrices N-par-NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de la condition sont également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la méthode de pivot de diagonale est utilisée pour factoriser A comme suit :
!>       A = U * D * U**H,  si UPLO = 'U', ou
!>       A = L * D * L**H,  si UPLO = 'L',
!>    où U (ou L) est un produit de matrices de permutation et de matrices triangulaires supérieures (inférieures) unitaires, et D est hermitienne et bloc-diagonale avec des blocs diagonaux de taille 1x1 et 2x2.
!>
!> 2. Si un D(i,i)=0, rendant D singulière, la routine renvoie INFO = i. Sinon, la forme factorisée de A est utilisée pour estimer le nombre de condition de la matrice A. Si l'inverse du nombre de condition est inférieur à la précision de la machine, INFO = N+1 est retourné à titre d'avertissement, mais la routine continue de résoudre pour X et de calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme factorisée de A.
!>
!> 4. Un raffinement itératif est appliqué pour améliorer la solution calculée et déterminer les bornes d'erreur et les estimations d'erreur arrière pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est CARACTÈRE*1
!>          Spécifie si la forme factorisée de A a été fournie ou non à l'entrée.
!>          = 'F' : À l'entrée, AFP et IPIV contiennent la forme factorisée de A. AFP et IPIV ne seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans AFP et factorisée.
!>

UPLO

!>          UPLO est CARACTÈRE*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes des matrices B et X. NRHS >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          Le triangle supérieur ou inférieur de la matrice hermitienne A, compacté colonne par colonne dans un tableau linéaire. La j-ème colonne de A est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>

AFP

!>          AFP est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          Si FACT = 'F', alors AFP est un argument d'entrée et contient à l'entrée la matrice bloc-diagonale D et les multiplicateurs utilisés pour obtenir le facteur U ou L de la factorisation A = U*D*U**H ou A = L*D*L**H calculée par ZHPTRF, stockée comme une matrice triangulaire compactée dans le même format de stockage que A.
!>
!>          Si FACT = 'N', alors AFP est un argument de sortie et contient à la sortie la matrice bloc-diagonale D et les multiplicateurs utilisés pour obtenir le facteur U ou L de la factorisation A = U*D*U**H ou A = L*D*L**H calculée par ZHPTRF, stockée comme une matrice triangulaire compactée dans le même format de stockage que A.
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et contient à l'entrée les détails des échanges et la structure bloc de D, tels que déterminés par ZHPTRF.
!>          Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k) ont été échangées et D(k,k) est un bloc diagonal 1x1.
!>          Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0, alors les lignes et colonnes k-1 et -IPIV(k) ont été échangées et D(k-1:k,k-1:k) est un bloc diagonal 2x2. Si UPLO = 'L' et IPIV(k) = IPIV(k+1) < 0, alors les lignes et colonnes k+1 et -IPIV(k) ont été échangées et D(k:k+1,k:k+1) est un bloc diagonal 2x2.
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et contient à la sortie les détails des échanges et la structure bloc de D, tels que déterminés par ZHPTRF.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          La matrice B de côté droit N-par-NRHS.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N-par-NRHS.
!>

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRÉCISION
!>          L'estimation de l'inverse du nombre de condition de la matrice A. Si RCOND est inférieur à la précision de la machine (en particulier, si RCOND = 0), la matrice est singulière à la précision de travail. Cette condition est indiquée par un code de retour de INFO > 0.
!>

FERR

!>          FERR est un tableau DOUBLE PRÉCISION, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j) est une borne supérieure estimée pour la magnitude du plus grand élément de (X(j) - XTRUE) divisée par la magnitude du plus grand élément de X(j). L'estimation est aussi fiable que l'estimation pour RCOND, et est presque toujours une légère surestimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau DOUBLE PRÉCISION, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur solution X(j) (c'est-à-dire le plus petit changement relatif dans n'importe quel élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, la
i-th argument had an illegal value !> > 0: si INFO = i, et i est !> <= N: D(i,i) est exactement zéro. La factorisation !> a été achevée mais le facteur D est exactement !> singulier, donc la solution et les bornes d'erreur n'ont pas pu !> être calculées. RCOND = 0 est retourné. !> = N+1: D est non singulier, mais RCOND est inférieur à la précision machine, !> ce qui signifie que la matrice est singulière !> à la précision de travail. Néanmoins, la !> solution et les bornes d'erreur sont calculées car !> il existe un certain nombre de situations où la !> solution calculée peut être plus précise que la !> valeur de RCOND ne le suggérerait. !>
