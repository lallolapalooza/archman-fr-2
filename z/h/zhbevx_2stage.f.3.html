Documentation de la fonction/sous-routine

sous-routine zhbevx_2stage (caractère jobz, caractère range, caractère uplo, entier n, entier kd, complexe*16, dimension( ldab, * ) ab, entier ldab, complexe*16, dimension( ldq, * ) q, entier ldq, double précision vl, double précision vu, entier il, entier iu, double précision abstol, entier m, double précision, dimension( * ) w, complexe*16, dimension( ldz, * ) z, entier ldz, complexe*16, dimension( * ) work, entier lwork, double précision, dimension( * ) rwork, entier, dimension( * ) iwork, entier, dimension( * ) ifail, entier info)

ZHBEVX_2STAGE calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres d'une matrice de bande hermitienne complexe A en utilisant la technique 2stage pour la réduction en matrice tridiagonale. Les valeurs propres et les vecteurs propres peuvent être sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices pour les valeurs propres désirées.

Objectif :

!>
!> ZHBEVX_2STAGE calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'une matrice de bande hermitienne complexe A en utilisant la technique 2stage pour
!> la réduction en matrice tridiagonale. Les valeurs propres et les vecteurs propres
!> peuvent être sélectionnés en spécifiant soit une plage de valeurs, soit une plage de
!> d'indices pour les valeurs propres désirées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>                  Non disponible dans cette version.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront trouvées ;
!>          = 'V': toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées ;
!>          = 'I': les IL-ième à IU-ième valeurs propres seront trouvées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est un ENTIER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau de type COMPLEX*16, de dimension (LDAB, N)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice de bande hermitienne
!>          A, stocké dans les KD+1 premières lignes du tableau. La
!>          j-ième colonne de A est stockée dans la j-ième colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>
!>          À la sortie, AB est écrasé par des valeurs générées pendant la
!>          réduction en forme tridiagonale.
!>

LDAB

!>          LDAB est un ENTIER
!>          La dimension principale du tableau AB.  LDAB >= KD + 1.
!>

Q

!>          Q est un tableau de type COMPLEX*16, de dimension (LDQ, N)
!>          Si JOBZ = 'V', la matrice unitaire N x N utilisée dans la
!>                          réduction en matrice tridiagonale.
!>          Si JOBZ = 'N', le tableau Q n'est pas référencé.
!>

LDQ

!>          LDQ est un ENTIER
!>          La dimension principale du tableau Q. Si JOBZ = 'V', alors
!>          LDQ >= max(1,N).
!>

VL

!>          VL est de type DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est de type DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est un ENTIER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est un ENTIER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est de type DOUBLE PRECISION
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergente
!>          lorsqu'elle est déterminée à se trouver dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision de la machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          par réduction de AB en forme tridiagonale.
!>
!>          Les valeurs propres seront calculées avec la plus grande précision lorsque ABSTOL est
!>          défini à deux fois le seuil de sous-flux 2*DLAMCH('S'), pas zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de définir ABSTOL à
!>          2*DLAMCH('S').
!>
!>          Voir  par Demmel et
!>          Kahan, Note de travail LAPACK #3.
!>

M

!>          M est un ENTIER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres sélectionnées par ordre
!>          croissant.
!>

Z

!>          Z est un tableau de type COMPLEX*16, de dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormaux de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre ne parvient pas à converger, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et
!>          l'indice du vecteur propre est retourné dans IFAIL.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est un ENTIER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, de dimension (LWORK)

!>          Si JOBZ = 'N' et N > 1, LWORK doit être interrogé.

NOM

ZHBEVX_2STAGE - Effectue le calcul des valeurs propres et, optionnellement, des vecteurs propres d'une matrice hermitienne complexe bande en utilisant un algorithme en deux étapes.

SYNTAXIS

    subroutine zhbevx_2stage(JOBZ, UPLO, RANGE, N, KD, AB, LDAB, Q, LDQ,
                           VL, VU, IL, IU, M, TRIM, RWORK, LRWORK, IWORK, LIWORK,
                           TAU, WORK, LWORK, INFO)

Pour Fortran :

    SUBROUTINE ZHBEVX_2STAGE(JOBZ, UPLO, RANGE, N, KD, AB, LDAB, Q, LDQ,
                           VL, VU, IL, IU, M, TRIM, RWORK, LRWORK, IWORK, LIWORK,
                           TAU, WORK, LWORK, INFO)

DESCRIPTION

ZHBEVX_2STAGE calcule les valeurs propres et, optionnellement, les vecteurs propres d'une matrice hermitienne complexe bande.

JOBZ
CHARACTER*1. Spécifie si les vecteurs propres doivent être calculés.
'N' : Seulement les valeurs propres sont calculées.
'V' : Les valeurs propres et les vecteurs propres sont calculés.
UPLO
CHARACTER*1. Indique quelle partie de la matrice AB est utilisée.
'U' : La partie supérieure est utilisée.
'L' : La partie inférieure est utilisée.
RANGE
CHARACTER*1. Spécifie quel ensemble de valeurs propres chercher.
'A' : Toutes les valeurs propres.
'V' : Toutes les valeurs propres dans l'intervalle (VL, VU].
'I' : Les IL-ièmes plus petites valeurs propres à IU-ièmes plus petites valeurs propres.
N
INTEGER. L'ordre de la matrice.
KD
INTEGER. Le nombre de super-diagonales ou sous-diagonales dans la bande.
AB
COMPLEX*16 array, dimension (LDAB, N). Contient la matrice hermitienne bande.
LDAB
INTEGER. La dimension de la première dimension de AB.
Q
COMPLEX*16 array, dimension (LDQ, N) if JOBZ = 'V', et (LDQ, M) if JOBZ = 'N'. Contient les vecteurs propres si JOBZ = 'V'.
LDQ
INTEGER. La dimension de la première dimension de Q.
VL
DOUBLE PRECISION. La borne inférieure de l'intervalle.
VU
DOUBLE PRECISION. La borne supérieure de l'intervalle.
IL
INTEGER. L'indice de la plus petite valeur propre à sélectionner.
IU
INTEGER. L'indice de la plus grande valeur propre à sélectionner.
M
INTEGER. Le nombre de valeurs propres sélectionnées.
TRIM
INTEGER. Réservé.
RWORK
DOUBLE PRECISION array, dimension (LRWORK).
LRWORK
INTEGER. La taille de RWORK.
IWORK
INTEGER array, dimension (LIWORK).
LIWORK
INTEGER. La taille de IWORK.
TAU
COMPLEX*16 array, dimension (N). Contient les scalaires nécessaires pour les transformations unitaires.
WORK
COMPLEX*16 array, dimension (LWORK).
LWORK
INTEGER. La taille de WORK.
INFO
INTEGER. Indique le statut de sortie.

Si JOBZ = 'V' et N > 1, LWORK doit être interrogé. Pas encore disponible.

Si LWORK = -1, une interrogation de l'espace de travail est supposée ; la routine calcule seulement les tailles optimales des tableaux WORK, RWORK et IWORK, renvoie ces valeurs comme premières entrées des tableaux WORK, RWORK et IWORK, et aucun message d'erreur relatif à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.

RWORK

!>          RWORK est un tableau de DOUBLE PRECISION, de dimension (7*N)
!>

IWORK

!>          IWORK est un tableau de INTEGER, de dimension (5*N)
!>

IFAIL

!>          IFAIL est un tableau de INTEGER, de dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont zéro. Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, alors i vecteurs propres n'ont pas convergé.
!>                Leurs indices sont stockés dans le tableau IFAIL.
!>
