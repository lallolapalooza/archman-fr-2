Documentation de la fonction/sous-programme

sous-programme zhptri (caractère uplo, entier n, complexe*16, dimension( * ) ap, entier, dimension( * ) ipiv, complexe*16, dimension( * ) work, entier info)

ZHPTRI

But :

!>
!> ZHPTRI calcule l'inverse d'une matrice hermitienne complexe indéfinie
!> A en stockage packé en utilisant la factorisation A = U*D*U**H ou
!> A = L*D*L**H calculée par ZHPTRF.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure, forme A = U*D*U**H;
!>          = 'L':  Triangulaire inférieure, forme A = L*D*L**H.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, dimension (N*(N+1)/2)
!>          En entrée, la matrice diagonale par blocs D et les multiplicateurs
!>          utilisés pour obtenir le facteur U ou L calculé par ZHPTRF,
!>          stockés sous forme de matrice triangulaire packée.
!>
!>          En sortie, si INFO = 0, l'inverse (Hermitienne) de la matrice originale,
!>          stocké sous forme de matrice triangulaire packée. La j-ème colonne
!>          de inv(A) est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = inv(A)(i,j) pour 1<=i<=j;
!>          si UPLO = 'L',
!>             AP(i + (j-1)*(2n-j)/2) = inv(A)(i,j) pour j<=i<=n.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure de blocs de D
!>          tels que déterminés par ZHPTRF.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0: succès de l'exécution
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0: si INFO = i, D(i,i) = 0 ; la matrice est singulière et son
!>               inverse n'a pas pu être calculé.
!>
