Documentation de la fonction/sous-programme

sous-programme zhpgst (integer itype, character uplo, integer n, complex*16, dimension( * ) ap, complex*16, dimension( * ) bp, integer info)

ZHPGST

Objectif:

!>
!> ZHPGST réduit un problème généralisé d' valeurs propres Hermitiennes-définies complexes
!> à la forme standard, en utilisant le stockage compressé (packed).
!>
!> Si ITYPE = 1, le problème est A*x = lambda*B*x,
!> et A est écrasé par inv(U**H)*A*inv(U) ou inv(L)*A*inv(L**H)
!>
!> Si ITYPE = 2 ou 3, le problème est A*B*x = lambda*x ou
!> B*A*x = lambda*x, et A est écrasé par U*A*U**H ou L**H*A*L.
!>
!> B doit avoir été préalablement factorisé en U**H*U ou L*L**H par ZPPTRF.
!>

Paramètres

ITYPE 
!>          ITYPE est un INTEGER
!>          = 1: calcule inv(U**H)*A*inv(U) ou inv(L)*A*inv(L**H);
!>          = 2 ou 3: calcule U*A*U**H ou L**H*A*L.
!>

UPLO

!>          UPLO est un CHARACTER*1
!>          = 'U': le triangle supérieur de A est stocké et B est factorisé comme
!>                  U**H*U;
!>          = 'L': le triangle inférieur de A est stocké et B est factorisé comme
!>                  L*L**H.
!>

N

!>          N est un INTEGER
!>          L'ordre des matrices A et B. N >= 0.
!>

AP

!>          AP est un tableau de COMPLEX*16, de dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice Hermitienne
!>          A, compressé par colonne dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>
!>          En sortie, si INFO = 0, la matrice transformée, stockée dans le
!>          même format que A.
!>

BP

!>          BP est un tableau de COMPLEX*16, de dimension (N*(N+1)/2)
!>          Le facteur triangulaire de la factorisation de Cholesky de B,
!>          stocké dans le même format que A, tel que retourné par ZPPTRF.
!>

INFO

!>          INFO est un INTEGER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
