sous-routine zheevr_2stage (character jobz, character range, character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer lrwork, integer, dimension( * ) iwork, integer liwork, integer info)

ZHEEVR_2STAGE calcule les valeurs propres et, éventuellement, les vecteurs propres de matrices hermitiennes complexes A en utilisant la technique des 2 étapes pour la réduction à la forme tridiagonale. Les valeurs propres et les vecteurs propres peuvent être sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices pour les valeurs propres souhaitées.

Objectif :

!>
!> ZHEEVR_2STAGE calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'une matrice hermitienne complexe A en utilisant la technique des 2 étapes pour
!> la réduction à la forme tridiagonale.  Les valeurs propres et les vecteurs propres
!> peuvent être sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices
!> pour les valeurs propres souhaitées.
!>
!> ZHEEVR_2STAGE réduit d'abord la matrice A à la forme tridiagonale T avec un appel
!> à ZHETRD.  Ensuite, chaque fois que possible, ZHEEVR_2STAGE appelle ZSTEMR pour calculer
!> le spectre des valeurs propres en utilisant des Représentations Relativement Robustes.  ZSTEMR
!> calcule les valeurs propres par l'algorithme dqds, tandis que les vecteurs propres orthogonaux
!> sont calculés à partir de diverses représentations L D L^T
!> (également connues sous le nom de Représentations Relativement Robustes). L'orthogonalisation de Gram-Schmidt
!> est évitée autant que possible. Plus précisément,
!> les différentes étapes de l'algorithme sont les suivantes.
!>
!> Pour chaque bloc non réduit (sous-matrice) de T,
!>    (a) Calculer T - sigma I  = L D L^T, de sorte que L et D
!>        définissent toutes les valeurs propres recherchées avec une haute précision relative.
!>        Cela signifie que de petits changements relatifs dans les entrées de D et L
!>        entraînent de petits changements relatifs dans les valeurs propres et
!>        les vecteurs propres. La représentation standard (non factorisée) de la
!>        matrice tridiagonale T n'a pas cette propriété en général.
!>    (b) Calculer les valeurs propres avec une précision appropriée.
!>        Si les vecteurs propres sont souhaités, l'algorithme atteint une précision complète
!>        des valeurs propres calculées seulement juste avant
!>        que les vecteurs correspondants doivent être calculés, voir les étapes c) et d).
!>    (c) Pour chaque groupe de valeurs propres proches, sélectionner un nouveau
!>        décalage proche du groupe, trouver une nouvelle factorisation, et raffiner
!>        les valeurs propres décalées avec une précision appropriée.
!>    (d) Pour chaque valeur propre avec une séparation relative suffisamment grande, calculer
!>        le vecteur propre correspondant en formant une factorisation torsadée révélatrice de rang.  Revenir à (c) pour les groupes qui restent.
!>
!> La précision souhaitée des résultats peut être spécifiée par le paramètre d'entrée
!> ABSTOL.
!>
!> Pour plus de détails, voir la documentation de ZSTEMR et :
!> - Inderjit S. Dhillon et Beresford N. Parlett : 
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, août 2004.
!> - Inderjit Dhillon et Beresford Parlett :  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004.  Également LAPACK Working Note 154.
!> - Inderjit Dhillon : ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, mai 1997.
!>
!>
!> Note 1 : ZHEEVR_2STAGE appelle ZSTEMR lorsque le spectre complet est demandé
!> sur des machines conformes à la norme de calcul en virgule flottante ieee-754.
!> ZHEEVR_2STAGE appelle DSTEBZ et ZSTEIN sur des machines non-ieee et
!> lorsque des demandes de spectre partiel sont faites.
!>
!> L'exécution normale de ZSTEMR peut créer des NaNs et des infinis et
!> peut donc être interrompue en raison d'une exception de point flottant dans les environnements
!> qui ne gèrent pas les NaNs et les infinis selon la manière par défaut de la norme IEEE.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' :  Calculer uniquement les valeurs propres ;
!>          = 'V' :  Calculer les valeurs propres et les vecteurs propres.
!>                  Non disponible dans cette version.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs propres seront trouvées.
!>          = 'V' : toutes les valeurs propres dans l'intervalle demi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I' : les valeurs propres de rang IL à IU seront trouvées.
!>          Pour RANGE = 'V' ou 'I' et IU - IL < N - 1, DSTEBZ et
!>          ZSTEIN sont appelés
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' :  La partie triangulaire supérieure de A est stockée ;
!>          = 'L' :  La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>          En entrée, la matrice hermitienne A.  Si UPLO = 'U',
!>          la partie triangulaire supérieure N x N de A contient
!>          la partie triangulaire supérieure de la matrice A.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N x N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>          En sortie, le triangle inférieur (si UPLO='L') ou le triangle
!>          supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

VL

!>          VL est DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est DOUBLE PRECISION
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergente
!>          lorsqu'elle est déterminée comme se situant dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision de la machine.  Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T|  sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant A à la forme tridiagonale.
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si une haute précision relative est importante, définissez ABSTOL à
!>          DLAMCH( 'Safe minimum' ). Faire cela garantira que
!>          les valeurs propres sont calculées avec une haute précision rel

NAME

zheevr_2stage - computes the eigenvalues and eigenvectors of a complex general matrix A and optionally computes the left eigenvectors of A.

SYNOPSIS

SUBROUTINE ZHEEVR_2STAGE(
     JOBZ, RANGE, UPLO, N, A, LDA, VL, VU, IL, IU, ABSTOL, M, W, Z, LDZ,
     ISUPPZ, WORK, LWORK, RWORK, LRWORK, IWORK, LIWORK, INFO )

CHARACTER          JOBZ, RANGE, UPLO
INTEGER            N, LDA, IL, IU, M, LDZ, LWORK, LRWORK, LIWORK, INFO
REAL               VL, VU, ABSTOL
COMPLEX*16         A( LDA, * ), Z( LDZ, * )
COMPLEX*16         WORK( * )
REAL               RWORK( * )
INTEGER            ISUPPZ( * ), IWORK( * )

Function/Subroutine Documentation

ZHEEVR_2STAGE performs the following steps:

  1. (Optional) Reduces the complex Hermitian matrix A to real symmetric tridiagonal form T.
  2. Computes the eigenvalues and eigenvectors of T.
  3. (Optional) Computes the eigenvectors of A from the eigenvectors of T.

The two-stage reduction is used to reduce the complex Hermitian matrix A to tridiagonal form. This method is generally more efficient than the one-stage reduction for larger matrices.

Arguments:

JOBZ

JOBZ is CHARACTER*1

= 'N': Do not compute the eigenvectors.

= 'V': Compute the eigenvectors of A.

JOBZ must be character varying length 1. JOBZ = 'N' or 'V'.

RANGE

RANGE is CHARACTER*1

= 'A': all eigenvalues will be found.

= 'V': all eigenvalues in the interval (VL,VU] will be found.

= 'I': the IL-th to IU-th eigenvalues will be found.

RANGE must be character varying length 1. RANGE = 'A', 'V' or 'I'.

UPLO

UPLO is CHARACTER*1

If UPLO = 'U', A uses the upper triangle and its imaginary parts are not referenced.

If UPLO = 'L', A uses the lower triangle and its imaginary parts are not referenced.

UPLO must be character varying length 1. UPLO = 'U' or 'L'.

N

N is INTEGER

The order of the matrix A. N >= 0. To select the best trade off between parallelism and memory usage, the algorithm uses a two-stage reduction from Hessenberg to tridiagonal form. The thresholds between the stages is set based on the matrix size N.

A

A is COMPLEX*16 array, dimension (LDA, *). On entry, the complex Hermitian matrix A.

On exit, the upper or lower triangle of A is overwritten by details of its Schur factorization, which is used to approximate the eigenvectors of A. The other triangle is not modified.

LDA

LDA is INTEGER

LDA is dimension of the array A. LDA >= max(1,N).

VL

VL is REAL

If RANGE='V', the lower bound of the eigenvalue interval.

If RANGE='A' or RANGE='I', VL is not used.

VU

VU is REAL

If RANGE='V', the upper bound of the eigenvalue interval.

If RANGE='A' or RANGE='I', VU is not used.

IL

IL is INTEGER

If RANGE='I', the index of the smallest eigenvalue to be returned.

If RANGE='A' or RANGE='V', IL is not used.

1 <= IL <= IU, if RANGE='I'. IU <= N, if RANGE='I'.

IU

IU is INTEGER

If RANGE='I', the index of the largest eigenvalue to be returned.

If RANGE='A' or RANGE='V', IU is not used.

ABSTOL

ABSTOL is REAL

The absolute tolerance for the eigenvalues and eigenvectors. An eigenvalue W(i) is selected if its value is not less than ABSTOL and difference between W(i) and VL is not more than ABSTOL. The eigenvectors are selected if ABSTOL is positive and the difference between the eigenvalue and VL is not more than ABSTOL.

If ABSTOL is not positive, then the trade-off between accuracy and work is determined by max(N*eps, D(i)*eps), where eps is the machine epsilon for real data type and D(i) is the i-th diagonal element of the matrix T (i.e. tridiagonal matrix).

M

M is INTEGER

The total number of eigenvalues found. 0 <= M <= N.

If RANGE = 'A', M = N, and if RANGE = 'I', M = IU-IL+1.

W

W is DOUBLE PRECISION array, dimension (N)

The first M elements contain the selected eigenvalues in ascending order.

Z

Z is COMPLEX*16 array, dimension (LDZ, max(1,M))

If JOBZ = 'V', then if INFO = 0, the first M columns of Z contain the orthonormal eigenvectors of the matrix A corresponding to the selected eigenvalues, with the i-th column of Z holding the eigenvector associated with W(i).

If JOBZ = 'N', then Z is not referenced.

Note: the user must ensure that at least max(1,M) columns are supplied in the array Z; if RANGE = 'V', the exact value of M is not known in advance and an upper bound must be used.

LDZ

LDZ is INTEGER

The leading dimension of the array Z. LDZ >= 1, and if JOBZ = 'V', LDZ >= max(1,N).

ISUPPZ

ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )

The support of the eigenvectors in Z, i.e., the indices indicating the nonzero elements in Z. The i-th eigenvector is nonzero only in elements ISUPPZ( 2*i-1 ) through ISUPPZ( 2*i ). This is an output of ZSTEMR (tridiagonal matrix). The support of the eigenvectors of A is typically 1:N because of the unitary transformations applied by ZUNMTR.

Implemented only for RANGE = 'A' or 'I' and IU - IL = N - 1

WORK

WORK is COMPLEX*16 array, dimension (MAX(1,LWORK))

On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK

LWORK is INTEGER

The dimension of the array WORK.

If N <= 1, LWORK must be at least 1.

If JOBZ = 'N' and N > 1, LWORK must be queried.

LWORK = MAX(1, 26*N, dimension) where
dimension = max(stage1,stage2) + (KD+1)*N + N
          = N*KD + N*max(KD+1,FACTOPTNB)
            + max(2*KD*KD, KD*NTHREADS)
            + (KD+1)*N + N
where KD is the blocking size of the reduction,
FACTOPTNB is the blocking used by the QR or LQ
algorithm, usually FACTOPTNB=128 is a good choice
NTHREADS is the number of threads used when
openMP compilation is enabled, otherwise =1.

If JOBZ = 'V' and N > 1, LWORK must be queried. Not yet available

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal sizes of the WORK, RWORK and IWORK arrays, returns these values as the first entries of the WORK, RWORK and IWORK arrays, and no error message related to LWORK or LRWORK or LIWORK is issued by XERBLA.

RWORK

RWORK is DOUBLE PRECISION array, dimension (MAX(1,LRWORK))

On exit, if INFO = 0, RWORK(1) returns the optimal (and minimal) LRWORK.

LRWORK

LRWORK is INTEGER

The length of the array RWORK.

If N <= 1, LRWORK >= 1, else LRWORK >= 24*N.

If LRWORK = -1, then a workspace query is assumed; the routine only calculates the optimal sizes of the WORK, RWORK and IWORK arrays, returns these values as the first entries of the WORK, RWORK and IWORK arrays, and no error message related to LWORK or LRWORK or LIWORK is issued by XERBLA.

IWORK

IWORK is INTEGER array, dimension (MAX(1,LIWORK))

On exit, if INFO = 0, IWORK(1) returns the optimal (and minimal) LIWORK.

LIWORK

LIWORK is INTEGER

The dimension of the array IWORK.

If N <= 1, LIWORK >= 1, else LIWORK >= 10*N.

If LIWORK = -1, then a workspace query is assumed; the routine only calculates the optimal sizes of the WORK, RWORK and IWORK arrays, returns these values as the first entries of the WORK, RWORK and IWORK arrays, and no error message related to LWORK or LRWORK or LIWORK is issued by XERBLA.

INFO

INFO is INTEGER

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value

> 0: Internal error
