sous-routine zherfsx (character uplo, character equed, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, double precision, dimension( * ) s, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZHERFSX

Objectif :

!>
!>    ZHERFSX améliore la solution calculée d'un système d'équations linéaires
!>    dont la matrice des coefficients est hermitienne indéfinie, et fournit des bornes d'erreur et des estimations d'erreur arrière pour la
!>    solution. En plus de la borne d'erreur normée, le code fournit
!>    une borne d'erreur composante par composante maximale si possible. Voir les commentaires pour
!>    ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des bornes d'erreur.
!>
!>    Le système d'équations linéaires d'origine peut avoir été équilibré
!>    avant d'appeler cette routine, comme décrit par les arguments EQUED et S
!>    ci-dessous. Dans ce cas, la solution et les bornes d'erreur renvoyées
!>    concernent le système non équilibré d'origine.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment le raffinement est effectué, mais souvent les
!>     valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U':  La partie triangulaire supérieure de A est stockée ;
!>       = 'L':  La partie triangulaire inférieure de A est stockée.
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibrage qui a été effectuée sur A
!>     avant d'appeler cette routine. Ceci est nécessaire pour calculer
!>     la solution et les bornes d'erreur correctement.
!>       = 'N':  Pas d'équilibrage
!>       = 'Y':  Équilibrage des lignes et des colonnes, c'est-à-dire A a été
!>               remplacé par diag(S) * A * diag(S).
!>               Le membre de droite B a été modifié en conséquence.
!>

N

!>          N est INTEGER
!>     L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>     La matrice hermitienne A.  Si UPLO = 'U', la partie supérieure gauche N-par-N
!>     de A contient la partie triangulaire supérieure
!>     de la matrice A, et la partie strictement triangulaire inférieure
!>     de A n'est pas référencée. Si UPLO = 'L', la partie inférieure gauche N-par-N
!>     de A contient la partie triangulaire inférieure
!>     de la matrice A, et la partie strictement triangulaire supérieure
!>     de A n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>     La forme factorisée de la matrice A.  AF contient la matrice diagonale par blocs D et les multiplicateurs utilisés pour obtenir
!>     le facteur U ou L de la factorisation A = U*D*U**H ou A =
!>     L*D*L**H calculée par ZHETRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Détails des échanges et de la structure par blocs de D
!>     tels que déterminés par ZHETRF.
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle pour A.  Si EQUED = 'Y', A est multiplié sur
!>     la gauche et sur la droite par diag(S).  S est un argument d'entrée si FACT =
!>     'F' ; sinon, S est un argument de sortie. Si FACT = 'F' et EQUED
!>     = 'Y', chaque élément de S doit être positif. Si S est une sortie, chaque
!>     élément de S est une puissance de la base. Si S est une entrée, chaque
!>     élément de S devrait être une puissance de la base pour garantir une solution fiable
!>     et des estimations d'erreur. La mise à l'échelle par des puissances de la base ne provoque pas
!>     d'erreurs d'arrondi, sauf si le résultat déborde (sous- ou sur-).
!>     Les erreurs d'arrondi lors de la mise à l'échelle conduisent à un raffinement avec une matrice qui
!>     n'est pas équivalente à la matrice d'entrée, produisant des estimations d'erreur
!>     qui peuvent ne pas être fiables.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>     La matrice du membre de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par ZHETRS.
!>     À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     Conditionnement réciproque mis à l'échelle. Ceci est une estimation du
!>     conditionnement de Skeel réciproque de la matrice A après
!>     équilibrage (si effectué). S'il est inférieur à la précision machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Noter que l'erreur peut toujours être petite même
!>     si ce nombre est très petit et que la matrice semble mal conditionnée.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>     Erreur arrière relative composante par composante. Ceci est l'
!>     erreur arrière relative composante par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire le plus petit changement relatif dans n'importe quel élément de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à retourner pour chaque membre de droite
!>     et chaque type (normé ou composante par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et conditionnements correspondant à l'
!>     erreur relative normée, qui est définie comme suit :
!>
!>     Erreur relative normée dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est

ERR_BNDS_NORM

!>     ERR_BNDS_NORM est un tableau DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     les différentes bornes d'erreur et nombres de conditionnement correspondant à
!>     l'erreur normwise relative, qui est définie comme suit :
!>
!>     Erreur normwise relative dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         norm(XTRUE(j,i) - X(j,i), inf)
!>
!>     Le tableau est indexé par le second membre i (sur lequel l'erreur
!>     normwise relative dépend), et par le type d'informations d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le second indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              nombre de conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur vraie
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de conditionnement réciproque : Norme estimée
!>              du nombre de conditionnement réciproque normwise. Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation
!>              de l'erreur est . Ces nombres de conditionnement
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              matrice Z correctement mise à l'échelle.
!>              Soit Z = S*A, où S met à l'échelle chaque ligne par une puissance
!>              de la base de sorte que toutes les sommes de lignes absolues de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et d'avertissements supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     les différentes bornes d'erreur et nombres de conditionnement correspondant à
!>     l'erreur relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (sur lequel l'erreur
!>     relative composante par composante dépend), et par le type d'erreur
!>     tel que décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations retournées pour chaque second membre. Si
!>     la précision composante par composante n'est pas demandée (PARAMS(3) = 0.0),
!>     alors ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le second indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              nombre de conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur vraie
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de conditionnement réciproque : Composante par composante
!>              estimée du nombre de conditionnement réciproque. Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation
!>              de l'erreur est . Ces nombres de conditionnement
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              matrice Z correctement mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre actuel et S met à l'échelle chaque ligne de
!>              A*diag(x) par une puissance de la base de sorte que toutes les sommes de lignes absolues
!>              de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et d'avertissements supplémentaires.
!>

NPARAMS

!>          NPARAMS est un entier
!>     Spécifie le nombre de paramètres définis dans PARAMS. S'il est <= 0, le
!>     tableau PARAMS n'est jamais référencé et les valeurs par défaut sont utilisées.
!>

PARAMS

!>          PARAMS est un tableau DOUBLE PRECISION de dimension NPARAMS
!>     Spécifie les paramètres de l'algorithme. Si une entrée est < 0.0, alors
!>     cette entrée sera remplie avec la valeur par défaut utilisée pour ce
!>     paramètre. Seules les positions jusqu'à NPARAMS sont accédées ; les valeurs par défaut
!>     sont utilisées pour les paramètres de numéro supérieur.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Indique si l'on doit effectuer un raffinement itératif
!>            ou non.
!>         Par défaut : 1.0D+0
!>            = 0.0 : Aucun raffinement n'est effectué, et aucune borne d'erreur n'est
!>                    calculée.
!>            = 1.0 : Utilise l'algorithme de raffinement en double précision,
!>                    éventuellement avec des calculs en simple précision doublée si
!>                    l'environnement de compilation ne prend pas en charge la DOUBLE
!>                    PRECISION.
!>              (d'autres valeurs sont réservées pour une utilisation future)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Nombre maximum de calculs de résiduels
!>            autorisés pour le raffinement.
!>         Par défaut : 10
!>         Agressif : Défini à 100 pour permettre la convergence en utilisant des
!>                     factorisations approximatives ou des factorisations autres que LU. Si
!>                     la factorisation utilise une technique autre que
!>                     l'élimination gaussienne, les garanties dans
!>                     err_bnds_norm et err_bnds_comp peuvent ne plus être fiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Indicateur déterminant si le code
!>            tentera de trouver une solution avec une petite erreur relative composante par composante
!>            dans l'algorithme de double précision. Positif
!>            est vrai, 0.0 est faux.
!>         Par défaut : 1.0 (tenter la convergence composante par composante)
!>

WORK

!>          WORK est un tableau COMPLEX*16 de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION de dimension (2*N)
!>

INFO

!>          INFO est un entier
!>       = 0 : Sortie réussie. La solution pour chaque second membre est
!>         garantie.
!>       < 0 : Si INFO = -i, alors le i-ème argument avait une valeur illégale.
!>       > 0 et <= N : U(INFO,INFO) est exactement zéro. La factorisation
!>         a été complétée, mais le facteur U est exactement singulier, donc
!>         la solution et les bornes d'erreur n'ont pas pu être calculées. RCOND = 0
!>         est retourné.
!>       = N+J : La solution correspondant au J-ème second membre n'est
!>         pas garantie. Les solutions correspondant aux autres seconds
!>         membres K avec K > J peuvent également ne pas être garanties,
!>         mais seul le premier second membre de ce type est signalé. Si une petite
!>         erreur composante par composante n'est pas demandée (PARAMS(3) = 0.0),
!>         alors le J-ème second membre est le premier pour lequel la borne d'erreur normwise
!>         n'est pas garantie (le plus petit J tel que ERR_BNDS_NORM(J,1) = 0.0). Par défaut (PARAMS(3) = 1.0),
!>         le J-ème second membre est le premier pour lequel la borne d'erreur normwise ou
!>         composante par composante n'est pas garantie (le plus petit
!>         J tel que ERR_BNDS_NORM(J,1) = 0.0 ou
!>         ERR_BNDS_COMP(J,1) = 0.0). Voir la définition de
!>         ERR_BNDS_NORM(:,1) et ERR_BNDS_COMP(:,1). Pour obtenir des informations
!>         sur tous les seconds membres, vérifiez ERR_BNDS_NORM ou
!>         ERR_BNDS_COMP.
!>
