sous-routine zhegvx (entier itype, caractere jobz, caractere range, caractere uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, reel_double vl, reel_double vu, entier il, entier iu, reel_double abstol, entier m, reel_double, dimension( * ) w, complexe*16, dimension( ldz, * ) z, entier ldz, complexe*16, dimension( * ) work, entier lwork, reel_double, dimension( * ) rwork, entier, dimension( * ) iwork, entier, dimension( * ) ifail, entier info)

ZHEGVX

But:

!>
!> ZHEGVX calcule des valeurs propres sélectionnées, et optionnellement, des vecteurs propres
!> d'un problème aux valeurs propres généralisé Hermitien-défini complexe, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou B*A*x=(lambda)*x. Ici, A et
!> B sont supposés Hermitiens et B est aussi défini positif.
!> Les valeurs propres et les vecteurs propres peuvent être sélectionnés en spécifiant soit un
!> intervalle de valeurs, soit un intervalle d'indices pour les valeurs propres désirées.
!>

Paramètres

ITYPE 
!>          ITYPE est ENTIER
!>          Spécifie le type de problème à résoudre :
!>          = 1 :  A*x = (lambda)*B*x
!>          = 2 :  A*B*x = (lambda)*x
!>          = 3 :  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ est CARACTERE*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CARACTERE*1
!>          = 'A' : toutes les valeurs propres seront trouvées.
!>          = 'V' : toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I' : les valeurs propres d'indices IL à IU seront trouvées.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          = 'U' : Les triangles supérieurs de A et B sont stockés ;
!>          = 'L' : Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A et B.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>          En entrée, la matrice Hermitienne A. Si UPLO = 'U', la
!>          partie triangulaire supérieure N-par-N de A contient la
!>          partie triangulaire supérieure de la matrice A. Si UPLO = 'L',
!>          la partie triangulaire inférieure N-par-N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>
!>          En sortie, le triangle inférieur (si UPLO='L') ou le triangle
!>          supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB, N)
!>          En entrée, la matrice Hermitienne B. Si UPLO = 'U', la
!>          partie triangulaire supérieure N-par-N de B contient la
!>          partie triangulaire supérieure de la matrice B. Si UPLO = 'L',
!>          la partie triangulaire inférieure N-par-N de B contient
!>          la partie triangulaire inférieure de la matrice B.
!>
!>          En sortie, si INFO <= N, la partie de B contenant la matrice est
!>          écrasée par le facteur triangulaire U ou L de la factorisation de Cholesky
!>          B = U**H*U ou B = L*L**H.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

VL

!>          VL est REEL DOUBLE
!>
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REEL DOUBLE
!>
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est ENTIER
!>
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est ENTIER
!>
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est REEL DOUBLE
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergée
!>          quand elle est déterminée se trouver dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant C à la forme tridiagonale, où C est la matrice symétrique
!>          du problème symétrique standard auquel le problème généralisé est transformé.
!>
!>          Les valeurs propres seront calculées le plus précisément quand ABSTOL est
!>          fixé à deux fois le seuil de sous-dépassement 2*DLAMCH('S'), pas zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de régler ABSTOL à
!>          2*DLAMCH('S').
!>

M

!>          M est ENTIER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau REEL DOUBLE, dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres sélectionnées
!>          en ordre croissant.
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormés de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Les vecteurs propres sont normalisés comme suit :
!>          si ITYPE = 1 ou 2, Z**T*B*Z = I ;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>
!>          Si un vecteur propre échoue à converger, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et l'indice
!>          du vecteur propre est retourné dans IFAIL.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est ENTIER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension

Nom

ZHEGMX - ZHEGMX permet de calculer les valeurs propres et vecteurs propres d'une matrice hermitienne généralisée.

Documentation Fonction ou Sous-routine

JOBZ

JOBZ is CHARACTER*1

Indique s'il faut calculer les vecteurs propres.

 On entry:
    JOBZ = 'N': ne calcule que les valeurs propres.
    JOBZ = 'V': calcule les valeurs propres et les vecteurs propres.
RANGE

RANGE is CHARACTER*1

Indique quelle plage de valeurs propres calculer.

 On entry:
    RANGE = 'A': toutes les valeurs propres sont calculées.
    RANGE = 'V': toutes les valeurs propres dans la plage [VL, VU] sont calculées.
    RANGE = 'I': les IL plus petites valeurs propres sont calculées.
UPLO

UPLO is CHARACTER*1

Spécifie quelle partie de la matrice A et B utiliser.

 On entry:
    UPLO = 'U': A et B sont triangulaires supérieures.
    UPLO = 'L': A et B sont triangulaires inférieures.
N

N is INTEGER

La taille de la matrice.

A

A is COMPLEX*16 array, dimension (LDA, N)

Sur l'entrée, la matrice hermitienne A.

LDA

LDA is INTEGER

La largeur de la matrice A.

B

B is COMPLEX*16 array, dimension (LDB, N)

Sur l'entrée, la matrice hermitienne définie positive B.

LDB

LDB is INTEGER

La largeur de la matrice B.

VL

VL is DOUBLE PRECISION

La borne inférieure de la plage de valeurs propres.

VU

VU is DOUBLE PRECISION

La borne supérieure de la plage de valeurs propres.

IL

IL is INTEGER

L'indice de la plus petite valeur propre à calculer.

IU

IU is INTEGER

L'indice de la plus grande valeur propre à calculer.

ABSTOL

ABSTOL is DOUBLE PRECISION

La tolérance absolue pour la convergence des valeurs propres.

M

M is INTEGER

Sur la sortie, le nombre de valeurs propres calculées.

W

W is DOUBLE PRECISION array, dimension (N)

Sur la sortie, les valeurs propres triées par ordre croissant.

Z

Z is COMPLEX*16 array, dimension (LDZ, N)

Sur la sortie, les vecteurs propres correspondants aux valeurs propres dans W.

LDZ

LDZ is INTEGER

La largeur de la matrice Z.

WORK

WORK is COMPLEX*16 array, dimension (LWORK)

Espace de travail.

LWORK

LWORK is INTEGER

La taille du tableau WORK.

 LWORK >= max(1, 2*N)
 Pour une efficacité optimale, LWORK >= (NB+1)*N,
 où NB est la taille du bloc pour ZHETRD retournée par ILAENV.
 Si LWORK = -1, alors une requête d'espace de travail est supposée; la routine
 calcule seulement la taille optimale du tableau WORK, retourne
 cette valeur comme première entrée du tableau WORK, et aucune erreur
 de message liée à LWORK n'est émise par XERBLA.
RWORK

RWORK is DOUBLE PRECISION array, dimension (7*N)

IWORK

IWORK is INTEGER array, dimension (5*N)

IFAIL

IFAIL is INTEGER array, dimension (N)

Sur la sortie, si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de IFAIL sont zéro. Si INFO > 0, alors IFAIL contient les indices des vecteurs propres qui n'ont pas convergé. Si JOBZ = 'N', alors IFAIL n'est pas référencé.

INFO

INFO is INTEGER

  • = 0: succès
  • < 0: si INFO = -i, le i-ème argument avait une valeur illégale
  • > 0: ZPOTRF ou ZHEEVX a retourné un code d'erreur:
    • <= N: si INFO = i, ZHEEVX n'a pas convergé; i vecteurs propres n'ont pas convergé. Leurs indices sont stockés dans le tableau IFAIL.
    • > N: si INFO = N + i, pour 1 <= i <= N, alors le mineur principal de tête d'ordre i de B n'est pas positif. La factorisation de B n'a pas pu être complétée et aucune valeur propre ou vecteur propre n'a été calculé.
