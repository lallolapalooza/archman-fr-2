sous-routine zhpgvd (entier itype, caractère jobz, caractère uplo, entier n, complexe*16, dimension( * ) ap, complexe*16, dimension( * ) bp, double précision, dimension( * ) w, complexe*16, dimension( ldz, * ) z, entier ldz, complexe*16, dimension( * ) work, entier lwork, double précision, dimension( * ) rwork, entier lrwork, entier, dimension( * ) iwork, entier liwork, entier info)

ZHPGVD

But:

!>
!> ZHPGVD calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'un problème aux valeurs propres généralisé hermitien-défini complexe, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou B*A*x=(lambda)*x. Ici A et
!> B sont supposées hermitiennes, stockées au format compressé, et B est également
!> définie positive.
!> Si les vecteurs propres sont désirés, il utilise un algorithme de "diviser pour régner".
!>
!>

Paramètres

ITYPE 
!>          ITYPE est ENTIER
!>          Spécifie le type de problème à résoudre:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ est CARACTERE*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          = 'U':  Les triangles supérieurs de A et B sont stockés ;
!>          = 'L':  Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A et B.  N >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice hermitienne
!>          A, compressé par colonne dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.
!>
!>          En sortie, le contenu de AP est détruit.
!>

BP

!>          BP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice hermitienne
!>          B, compressé par colonne dans un tableau linéaire. La j-ème colonne de B
!>          est stockée dans le tableau BP comme suit:
!>          si UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) pour j<=i<=n.
!>
!>          En sortie, le facteur triangulaire U ou L de la factorisation de Cholesky
!>          B = U**H*U ou B = L*L**H, dans le même format de stockage que B.
!>

W

!>          W est un tableau DOUBLE PRÉCISION, de dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!>

Z

!>          Z est un tableau COMPLEX*16, de dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient la matrice Z des
!>          vecteurs propres. Les vecteurs propres sont normalisés comme suit:
!>          si ITYPE = 1 ou 2, Z**H*B*Z = I ;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est ENTIER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie le LWORK requis.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.
!>          Si N <= 1,               LWORK >= 1.
!>          Si JOBZ = 'N' et N > 1, LWORK >= N.
!>          Si JOBZ = 'V' et N > 1, LWORK >= 2*N.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement les tailles requises des tableaux WORK, RWORK et
!>          IWORK, renvoie ces valeurs comme premières entrées
!>          des tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, de dimension (MAX(1,LRWORK))
!>          En sortie, si INFO = 0, RWORK(1) renvoie le LRWORK requis.
!>

LRWORK

!>          LRWORK est ENTIER
!>          La dimension du tableau RWORK.
!>          Si N <= 1,               LRWORK >= 1.
!>          Si JOBZ = 'N' et N > 1, LRWORK >= N.
!>          Si JOBZ = 'V' et N > 1, LRWORK >= 1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule seulement les tailles requises des tableaux WORK, RWORK
!>          et IWORK, renvoie ces valeurs comme premières entrées
!>          des tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (MAX(1,LIWORK))
!>          En sortie, si INFO = 0, IWORK(1) renvoie le LIWORK requis.
!>

LIWORK

!>          LIWORK est ENTIER
!>          La dimension du tableau IWORK.
!>          Si JOBZ  = 'N' ou N <= 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' et N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule seulement les tailles requises des tableaux WORK, RWORK
!>          et IWORK, renvoie ces valeurs comme premières entrées
!>          des tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0:  succès de l'exécution
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  ZPPTRF ou ZHPEVD a renvoyé un code d'erreur:
!>             <= N:  si INFO = i, ZHPEVD n'a pas convergé ;
!>                    i éléments hors diagonale d'une forme tridiagonale intermédiaire
!>                    n'ont pas convergé vers zéro ;
!>             > N:   si INFO = N + i, pour 1 <= i <= n, alors le mineur principal
!>                    de tête d'ordre i de B n'est pas positif.
!>                    La factorisation de B n'a pas pu être complétée et
!>                    aucune valeur propre ou vecteur propre n'a été calculé.
!>
