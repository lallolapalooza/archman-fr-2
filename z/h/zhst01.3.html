sous-programme zhst01 (entier n, entier ilo, entier ihi, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldh, * ) h, entier ldh, complexe*16, dimension( ldq, * ) q, entier ldq, complexe*16, dimension( lwork ) work, entier lwork, double precision, dimension( * ) rwork, double precision, dimension( 2 ) result)

ZHST01

But :

!>
!> ZHST01 teste la réduction d'une matrice générale A en forme Hessenberg supérieure : A = Q*H*Q'. Deux rapports de test sont calculés ;
!>
!> RESULT(1) = norme( A - Q*H*Q' ) / ( norme(A) * N * EPS )
!> RESULT(2) = norme( I - Q'*Q ) / ( N * EPS )
!>
!> La matrice Q est supposée être donnée explicitement telle qu'elle serait
!> suite à ZGEHRD + ZUNGHR.
!>
!> Dans cette version, ILO et IHI ne sont pas utilisés, mais ils pourraient l'être
!> pour économiser du travail si cela est souhaité.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

ILO

!>          ILO est un ENTIER
!>

IHI

!>          IHI est un ENTIER
!>
!>          A est supposée être triangulaire supérieure dans les lignes et colonnes
!>          1:ILO-1 et IHI+1:N, donc Q diffère de l'identité uniquement dans les
!>          lignes et colonnes ILO+1:IHI.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice originale A de taille n par n.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

H

!>          H est un tableau COMPLEX*16, dimension (LDH,N)
!>          La matrice Hessenberg supérieure H issue de la réduction A = Q*H*Q'
!>          telle que calculée par ZGEHRD. H est supposée être nulle sous la
!>          première sous-diagonale.
!>

LDH

!>          LDH est un ENTIER
!>          La dimension principale du tableau H. LDH >= max(1,N).
!>

Q

!>          Q est un tableau COMPLEX*16, dimension (LDQ,N)
!>          La matrice orthogonale Q issue de la réduction A = Q*H*Q' telle que
!>          calculée par ZGEHRD + ZUNGHR.
!>

LDQ

!>          LDQ est un ENTIER
!>          La dimension principale du tableau Q. LDQ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur du tableau WORK. LWORK >= 2*N*N.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, dimension (2)
!>          RESULT(1) = norme( A - Q*H*Q' ) / ( norme(A) * N * EPS )
!>          RESULT(2) = norme( I - Q'*Q ) / ( N * EPS )
!>
