sous-programme zhegvd (entier itype, caractère jobz, caractère uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, double précision, dimension( * ) w, complexe*16, dimension( * ) work, entier lwork, double précision, dimension( * ) rwork, entier lrwork, entier, dimension( * ) iwork, entier liwork, entier info)

ZHEGVD

But :

!>
!> ZHEGVD calcule toutes les valeurs propres, et optionnellement, les vecteurs propres
!> d'un problème de définition hermitien généralisé complexe, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou B*A*x=(lambda)*x. Ici, A et
!> B sont supposées hermitiens et B est aussi définie positive.
!> Si les vecteurs propres sont désirés, il utilise un algorithme de type diviser pour régner.
!>
!>

Paramètres

ITYPE 
!>          ITYPE est un ENTIER
!>          Spécifie le type de problème à résoudre :
!>          = 1 :  A*x = (lambda)*B*x
!>          = 2 :  A*B*x = (lambda)*x
!>          = 3 :  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ est un CARACTÈRE*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est un CARACTÈRE*1
!>          = 'U' : Les triangles supérieurs de A et B sont stockés ;
!>          = 'L' : Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est un ENTIER
!>          L'ordre des matrices A et B.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA, N)
!>          En entrée, la matrice hermitienne A. Si UPLO = 'U', la partie
!>          supérieure triangulaire N par N de A contient la partie
!>          supérieure triangulaire de la matrice A. Si UPLO = 'L', la partie
!>          inférieure triangulaire N par N de A contient la partie
!>          inférieure triangulaire de la matrice A.
!>
!>          En sortie, si JOBZ = 'V', alors si INFO = 0, A contient la
!>          matrice Z des vecteurs propres. Les vecteurs propres sont normalisés
!>          comme suit :
!>          si ITYPE = 1 ou 2, Z**H*B*Z = I ;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>          Si JOBZ = 'N', alors en sortie, le triangle supérieur (si UPLO='U')
!>          ou le triangle inférieur (si UPLO='L') de A, y compris la
!>          diagonale, est détruit.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB, N)
!>          En entrée, la matrice hermitienne B. Si UPLO = 'U', la partie
!>          supérieure triangulaire N par N de B contient la partie
!>          supérieure triangulaire de la matrice B. Si UPLO = 'L', la partie
!>          inférieure triangulaire N par N de B contient la partie
!>          inférieure triangulaire de la matrice B.
!>
!>          En sortie, si INFO <= N, la partie de B contenant la matrice est
!>          écrasée par le facteur triangulaire U ou L de la factorisation de
!>          Cholesky B = U**H*U ou B = L*L**H.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

W

!>          W est un tableau DOUBLE PRÉCISION de dimension (N)
!>          Si INFO = 0, les valeurs propres dans l'ordre croissant.
!>

WORK

!>          WORK est un tableau COMPLEX*16 de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur du tableau WORK.
!>          Si N <= 1,                LWORK >= 1.
!>          Si JOBZ  = 'N' et N > 1, LWORK >= N + 1.
!>          Si JOBZ  = 'V' et N > 1, LWORK >= 2*N + N**2.
!>
!>          Si LWORK = -1, une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des tableaux WORK,
!>          RWORK et IWORK, et aucun message d'erreur lié à LWORK ou LRWORK ou LIWORK
!>          n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION de dimension (MAX(1,LRWORK))
!>          En sortie, si INFO = 0, RWORK(1) contient la taille optimale LRWORK.
!>

LRWORK

!>          LRWORK est un ENTIER
!>          La dimension du tableau RWORK.
!>          Si N <= 1,                LRWORK >= 1.
!>          Si JOBZ  = 'N' et N > 1, LRWORK >= N.
!>          Si JOBZ  = 'V' et N > 1, LRWORK >= 1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK, RWORK
!>          et IWORK, renvoie ces valeurs comme premières entrées des tableaux WORK,
!>          RWORK et IWORK, et aucun message d'erreur lié à LWORK ou LRWORK ou LIWORK
!>          n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau ENTIER de dimension (MAX(1,LIWORK))
!>          En sortie, si INFO = 0, IWORK(1) contient la taille optimale LIWORK.
!>

LIWORK

!>          LIWORK est un ENTIER
!>          La dimension du tableau IWORK.
!>          Si N <= 1,                LIWORK >= 1.
!>          Si JOBZ  = 'N' et N > 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' et N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK, RWORK
!>          et IWORK, renvoie ces valeurs comme premières entrées des tableaux WORK,
!>          RWORK et IWORK, et aucun message d'erreur lié à LWORK ou LRWORK ou LIWORK
!>          n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : Sortie réussie
!>          < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : ZPOTRF ou ZHEEVD a renvoyé un code d'erreur :
!>             <= N : Si INFO = i et JOBZ = 'N', alors l'algorithme
!>                    n'a pas réussi à converger ; i éléments non diagonaux d'une
!>                    forme tridiagonale intermédiaire n'ont pas convergé vers zéro ;
!>                    si INFO = i et JOBZ = 'V', alors l'algorithme
!>                    n'a pas réussi à calculer une valeur propre tout en travaillant sur
!>                    la sous-matrice située dans les lignes et colonnes INFO/(N+1)
!>                    jusqu'à mod(INFO,N+1) ;
!>             > N : Si INFO = N + i, pour 1 <= i <= N, alors le mineur principal
!>                    de tête d'ordre i de B n'est pas positif.
!>                    La factorisation de B n'a pas pu être terminée et
!>                    aucune valeur propre ou vecteur propre n'a été calculé.
!>
