Documentation de fonction/sous-programme

sous-programme zhecon (caractère uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, double précision anorm, double précision rcond, complexe*16, dimension( * ) work, entier info)

ZHECON

Objectif :

!>
!> ZHECON estime la réciproque du nombre de condition d'une matrice hermitienne complexe A
!> en utilisant la factorisation A = U*D*U**H ou
!> A = L*D*L**H calculée par ZHETRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et la réciproque du
!> nombre de condition est calculée comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U' : Triangulaire supérieure, forme A = U*D*U**H ;
!>          = 'L' : Triangulaire inférieure, forme A = L*D*L**H.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>          obtenir le facteur U ou L tels que calculés par ZHETRF.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure par blocs de D
!>          tels que déterminés par ZHETRF.
!>

ANORM

!>          ANORM est DOUBLE PRECISION
!>          La norme 1 de la matrice originale A.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          La réciproque du nombre de condition de la matrice A,
!>          calculée comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>
