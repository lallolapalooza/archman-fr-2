ZHETRD_2STAGE

Documentation de la fonction/sous-routine

subroutine zhetrd_2stage (character vect, character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( * ) tau, complex*16, dimension( * ) hous2, integer lhous2, complex*16, dimension( * ) work, integer lwork, integer info)

ZHETRD_2STAGE

Purpose:

!>
!> ZHETRD_2STAGE réduit une matrice A hermitienne complexe à la forme tridiagonale
!> réelle symétrique T par une transformation de similarité unitaire :
!> Q1**H Q2**H* A * Q2 * Q1 = T.
!>

Paramètres

VECT 
!>          VECT est CHARACTER*1
!>          = 'N':  Pas besoin de la représentation de Householder,
!>                  en particulier pour la deuxième étape (Bande à
!>                  tridiagonale) et donc LHOUS2 a une taille max(1, 4*N);
!>          = 'V':  La représentation de Householder est nécessaire pour
!>                  générer Q1 Q2 ou pour appliquer Q1 Q2,
!>                  alors LHOUS2 doit être interrogé et calculé.
!>                  (PAS DISPONIBLE DANS CETTE VERSION).
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          En entrée, la matrice hermitienne A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire N-par-N de A contient la partie
!>          supérieure triangulaire de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          inférieure triangulaire N-par-N de A contient la partie
!>          inférieure triangulaire de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>          En sortie, si UPLO = 'U', la bande superdiagonale
!>          de A est écrasée par les éléments correspondants de la matrice
!>          bande-diagonale interne AB, et les éléments au-dessus de la KD
!>          superdiagonale, avec le tableau TAU, représentent la matrice unitaire
!>          Q1 comme un produit de réflecteurs élémentaires ; si UPLO
!>          = 'L', la diagonale et la bande sous-diagonale de A sont écrasées
!>          par les éléments correspondants de la matrice bande-diagonale
!>          interne AB, et les éléments sous la KD sous-diagonale, avec
!>          le tableau TAU, représentent la matrice unitaire Q1 comme un produit
!>          de réflecteurs élémentaires. Voir Détails supplémentaires.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          Les éléments diagonaux de la matrice tridiagonale T.
!>

E

!>          E est un tableau DOUBLE PRECISION, dimension (N-1)
!>          Les éléments hors diagonale de la matrice tridiagonale T.
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (N-KD)
!>          Les facteurs scalaires des réflecteurs élémentaires de
!>          la première étape (voir Détails supplémentaires).
!>

HOUS2

!>          HOUS2 est un tableau COMPLEX*16, dimension (MAX(1,LHOUS2))
!>          Stocke la représentation de Householder de l'étape 2
!>          bande à tridiagonale.
!>

LHOUS2

!>          LHOUS2 est INTEGER
!>          La dimension du tableau HOUS2.
!>          LHOUS2 >= 1.
!>
!>          Si LWORK = -1, ou LHOUS2 = -1,
!>          alors une requête est supposée ; la routine
!>          calcule seulement la taille optimale du tableau HOUS2, renvoie
!>          cette valeur comme première entrée du tableau HOUS2, et aucun message
!>          d'erreur lié à LHOUS2 n'est émis par XERBLA.
!>          Si VECT='N', LHOUS2 = max(1, 4*n);
!>          si VECT='V', option pas encore disponible.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si N = 0, LWORK >= 1, sinon LWORK = MAX(1, dimension).
!>
!>          Si LWORK = -1, ou LHOUS2 = -1,
!>          alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>          LWORK = MAX(1, dimension) où
!>          dimension   = max(stage1,stage2) + (KD+1)*N
!>                      = N*KD + N*max(KD+1,FACTOPTNB)
!>                        + max(2*KD*KD, KD*NTHREADS)
!>                        + (KD+1)*N
!>          où KD est la taille du bloc de la réduction,
!>          FACTOPTNB est le bloc utilisé par l'algorithme QR ou LQ
!>          (généralement FACTOPTNB=128 est un bon choix)
!>          NTHREADS est le nombre de threads utilisés lorsque la compilation
!>          openMP est activée, sinon =1.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  fin réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
