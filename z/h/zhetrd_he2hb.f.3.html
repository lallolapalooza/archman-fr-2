subroutine zhetrd_he2hb (uplo, n, kd, a, lda, ab, ldab, tau, work, lwork, info)
ZHETRD_HE2HB

Documentation de la fonction/sous-programme

sous-programme zhetrd_he2hb (caractère uplo, entier n, entier kd, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldab, * ) ab, entier ldab, complexe*16, dimension( * ) tau, complexe*16, dimension( * ) work, entier lwork, entier info)

ZHETRD_HE2HB

Objectif:

!>
!> ZHETRD_HE2HB réduit une matrice hermitienne complexe A en une matrice bande-diagonale hermitienne complexe AB
!> par une transformation unitaire de similarité :
!> Q**H * A * Q = AB.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales de la matrice réduite si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>          La matrice réduite est stockée dans le tableau AB.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          En entrée, la matrice hermitienne A. Si UPLO = 'U', la partie triangulaire
!>          supérieure N-par-N de A contient la partie triangulaire supérieure de
!>          la matrice A, et la partie strictement triangulaire inférieure de A
!>          n'est pas référencée. Si UPLO = 'L', la partie triangulaire inférieure
!>          N-par-N de A contient la partie triangulaire inférieure de la matrice A,
!>          et la partie strictement triangulaire supérieure de A n'est pas référencée.
!>          En sortie, si UPLO = 'U', la diagonale et la première super-diagonale
!>          de A sont écrasées par les éléments correspondants de la matrice
!>          tridiagonale T, et les éléments au-dessus de la première super-diagonale,
!>          avec le tableau TAU, représentent la matrice unitaire Q sous forme d'un
!>          produit de réflecteurs élémentaires ; si UPLO = 'L', la diagonale et la
!>          première sous-diagonale de A sont écrasées par les éléments correspondants
!>          de la matrice tridiagonale T, et les éléments en dessous de la première
!>          sous-diagonale, avec le tableau TAU, représentent la matrice unitaire Q
!>          sous forme d'un produit de réflecteurs élémentaires. Voir Détails supplémentaires.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AB

!>          AB est un tableau COMPLEX*16, de dimension (LDAB,N)
!>          En sortie, le triangle supérieur ou inférieur de la matrice bande hermitienne
!>          A, stocké dans les KD+1 premières lignes du tableau. La j-ième colonne
!>          de A est stockée dans la j-ième colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

TAU

!>          TAU est un tableau COMPLEX*16, de dimension (N-KD)
!>          Les facteurs scalaires des réflecteurs élémentaires (voir Détails supplémentaires).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, ou si LWORK = -1,
!>          WORK(1) contient la taille de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK qui doit être calculée par une requête d'espace de travail.
!>          Si N <= KD+1, LWORK >= 1, sinon LWORK = MAX(1, LWORK_QUERY).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; le sous-programme
!>          calcule uniquement la taille optimale du tableau WORK, renvoie cette valeur
!>          comme première entrée du tableau WORK, et aucun message d'erreur relatif à LWORK
!>          n'est émis par XERBLA.
!>          LWORK_QUERY = N*KD + N*max(KD,FACTOPTNB) + 2*KD*KD
!>          où FACTOPTNB est le blocage utilisé par l'algorithme QR ou LQ,
!>          généralement FACTOPTNB=128 est un bon choix, sinon
!>          mettre LWORK=-1 fournira la taille de WORK.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

!>  calculations based on fine-grained memory aware tasks.
!>  International Journal of High Performance Computing Applications.
!>  Volume 28 Issue 2, Pages 196-209, May 2014.
!>  http://hpc.sagepub.com/content/28/2/196
!>
!> 
!>
!>  Si UPLO = 'U', la matrice Q est représentée par un produit de réflecteurs
!>  élémentaires
!>
!>     Q = H(k)**H . . . H(2)**H H(1)**H, où k = n-kd.
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**H
!>
!>  où tau est un scalaire complexe, et v est un vecteur complexe avec
!>  v(1:i+kd-1) = 0 et v(i+kd) = 1 ; conjg(v(i+kd+1:n)) est stocké en sortie dans
!>  A(i,i+kd+1:n), et tau dans TAU(i).
!>
!>  Si UPLO = 'L', la matrice Q est représentée par un produit de réflecteurs
!>  élémentaires
!>
!>     Q = H(1) H(2) . . . H(k), où k = n-kd.
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**H
!>
!>  où tau est un scalaire complexe, et v est un vecteur complexe avec
!>  v(kd+1:i) = 0 et v(i+kd+1) = 1 ; v(i+kd+2:n) est stocké en sortie dans
!>  A(i+kd+2:n,i), et tau dans TAU(i).
!>
!>  Le contenu de A en sortie est illustré par les exemples suivants
!>  avec n = 5 :
!>
!>  si UPLO = 'U' :                       si UPLO = 'L' :
!>
!>    (  ab  ab/v1  v1      v1     v1    )              (  ab                            )
!>    (      ab     ab/v2   v2     v2    )              (  ab/v1  ab                     )
!>    (             ab      ab/v3  v3    )              (  v1     ab/v2  ab              )
!>    (                     ab     ab/v4 )              (  v1     v2     ab/v3  ab       )
!>    (                            ab    )              (  v1     v2     v3     ab/v4 ab )
!>
!>  où d et e dénotent des éléments diagonaux et hors diagonale de T, et vi
!>  dénote un élément du vecteur définissant H(i).
!> .fi
