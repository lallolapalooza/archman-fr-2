sous-routine zhgeqz (caractère job, caractère compq, caractère compz, entier n, entier ilo, entier ihi, complexe*16, dimension( ldh, * ) h, entier ldh, complexe*16, dimension( ldt, * ) t, entier ldt, complexe*16, dimension( * ) alpha, complexe*16, dimension( * ) beta, complexe*16, dimension( ldq, * ) q, entier ldq, complexe*16, dimension( ldz, * ) z, entier ldz, complexe*16, dimension( * ) work, entier lwork, double précision, dimension( * ) rwork, entier info)

ZHGEQZ

But :

!>
!> ZHGEQZ calcule les valeurs propres d'une paire de matrices complexes (H,T),
!> où H est une matrice de Hessenberg supérieure et T est une matrice triangulaire supérieure,
!> en utilisant la méthode QZ à un seul décalage.
!> Les paires de matrices de ce type sont produites par la réduction à
!> la forme de Hessenberg généralisée d'une paire de matrices complexes (A,B) :
!>
!>    A = Q1*H*Z1**H,  B = Q1*T*Z1**H,
!>
!> comme calculé par ZGGHRD.
!>
!> Si JOB='S', alors la paire de Hessenberg-triangulaire (H,T) est
!> également réduite à la forme de Schur généralisée,
!>
!>    H = Q*S*Z**H,  T = Q*P*Z**H,
!>
!> où Q et Z sont des matrices unitaires et S et P sont triangulaires supérieures.
!>
!> Facultativement, la matrice unitaire Q de la factorisation de Schur
!> généralisée peut être post-multipliée dans une matrice d'entrée Q1, et la
!> matrice unitaire Z peut être post-multipliée dans une matrice d'entrée Z1.
!> Si Q1 et Z1 sont les matrices unitaires de ZGGHRD qui ont réduit
!> la paire de matrices (A,B) à la forme de Hessenberg généralisée, alors les matrices de sortie
!> Q1*Q et Z1*Z sont les facteurs unitaires de la factorisation de Schur généralisée
!> de (A,B) :
!>
!>    A = (Q1*Q)*S*(Z1*Z)**H,  B = (Q1*Q)*P*(Z1*Z)**H.
!>
!> Pour éviter le débordement, les valeurs propres de la paire de matrices (H,T)
!> (équivalemment, de (A,B)) sont calculées comme une paire de valeurs complexes
!> (alpha,beta). Si beta est non nul, lambda = alpha / beta est une valeur propre
!> du problème aux valeurs propres généralisé non symétrique (GNEP)
!>    A*x = lambda*B*x
!> et si alpha est non nul, mu = beta / alpha est une valeur propre de la
!> forme alternative du GNEP
!>    mu*A*y = B*y.
!> Les valeurs de alpha et beta pour la i-ème valeur propre peuvent être lues
!> directement à partir de la forme de Schur généralisée : alpha = S(i,i),
!> beta = P(i,i).
!>
!> Ref : C.B. Moler & G.W. Stewart, , SIAM J. Numer. Anal., 10(1973),
!>      pp. 241--256.
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>          = 'E' : Calculer uniquement les valeurs propres ;
!>          = 'S' : Calculer les valeurs propres et la forme de Schur.
!>

COMPQ

!>          COMPQ est CHARACTER*1
!>          = 'N' : Les vecteurs de Schur gauches (Q) ne sont pas calculés ;
!>          = 'I' : Q est initialisé à la matrice unité et la matrice Q
!>                 des vecteurs de Schur gauches de (H,T) est retournée ;
!>          = 'V' : Q doit contenir une matrice unitaire Q1 à l'entrée et
!>                 le produit Q1*Q est retourné.
!>

COMPZ

!>          COMPZ est CHARACTER*1
!>          = 'N' : Les vecteurs de Schur droits (Z) ne sont pas calculés ;
!>          = 'I' : Q est initialisé à la matrice unité et la matrice Z
!>                 des vecteurs de Schur droits de (H,T) est retournée ;
!>          = 'V' : Z doit contenir une matrice unitaire Z1 à l'entrée et
!>                 le produit Z1*Z est retourné.
!>

N

!>          N est un ENTIER
!>          L'ordre des matrices H, T, Q et Z. N >= 0.
!>

ILO

!>          ILO est un ENTIER
!>

IHI

!>          IHI est un ENTIER
!>          ILO et IHI marquent les lignes et colonnes de H qui sont dans
!>          la forme de Hessenberg. On suppose que A est déjà supérieurement
!>          triangulaire dans les lignes et colonnes 1:ILO-1 et IHI+1:N.
!>          Si N > 0, 1 <= ILO <= IHI <= N ; si N = 0, ILO=1 et IHI=0.
!>

H

!>          H est un tableau COMPLEX*16, dimension (LDH, N)
!>          À l'entrée, la matrice de Hessenberg supérieure N-par-N H.
!>          À la sortie, si JOB = 'S', H contient la matrice triangulaire supérieure
!>          S de la factorisation de Schur généralisée.
!>          Si JOB = 'E', la diagonale de H correspond à celle de S, mais
!>          le reste de H n'est pas spécifié.
!>

LDH

!>          LDH est un ENTIER
!>          La dimension principale du tableau H. LDH >= max( 1, N ).
!>

T

!>          T est un tableau COMPLEX*16, dimension (LDT, N)
!>          À l'entrée, la matrice triangulaire supérieure N-par-N T.
!>          À la sortie, si JOB = 'S', T contient la matrice triangulaire supérieure
!>          P de la factorisation de Schur généralisée.
!>          Si JOB = 'E', la diagonale de T correspond à celle de P, mais
!>          le reste de T n'est pas spécifié.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T. LDT >= max( 1, N ).
!>

ALPHA

!>          ALPHA est un tableau COMPLEX*16, dimension (N)
!>          Les scalaires complexes alpha qui définissent les valeurs propres
!>          du GNEP. ALPHA(i) = S(i,i) dans la factorisation de Schur
!>          généralisée.
!>

BETA

!>          BETA est un tableau COMPLEX*16, dimension (N)
!>          Les scalaires réels non négatifs beta qui définissent les
!>          valeurs propres du GNEP. BETA(i) = P(i,i) dans la factorisation de Schur
!>          généralisée.
!>
!>          Ensemble, les quantités alpha = ALPHA(j) et beta = BETA(j)
!>          représentent la j-ème valeur propre de la paire de matrices (A,B), sous
!>          l'une des formes lambda = alpha/beta ou mu = beta/alpha.
!>          Puisque lambda ou mu peuvent déborder, ils ne devraient généralement pas
!>          être calculés.
!>

Q

!>          Q est un tableau COMPLEX*16, dimension (LDQ, N)
!>          À l'entrée, si COMPQ = 'V', la matrice unitaire Q1 utilisée dans la
!>          réduction de (A,B) à la forme de Hessenberg généralisée.
!>          À la sortie, si COMPQ = 'I', la matrice unitaire des vecteurs de Schur
!>          gauches de (H,T), et si COMPQ = 'V', la matrice unitaire des
!>          vecteurs de Schur gauches de (A,B).
!>          Non référencé si COMPQ = 'N'.
!>

LDQ

!>          LDQ est un ENTIER
!>          La dimension principale du tableau Q. LDQ >= 1.
!>          Si COMPQ='V' ou 'I', alors LDQ >= N.
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ, N)
!>          À l'entrée, si COMPZ = 'V', la matrice unitaire Z1 utilisée dans la
!>          réduction de (A,B) à la forme de Hessenberg généralisée.
!>          À la sortie, si COMPZ = 'I', la matrice unitaire des vecteurs de Schur
!>          droits de (H,T), et si COMPZ = 'V', la matrice unitaire des
!>          vecteurs de Schur droits de (A,B).
!>          Non référencé si COMPZ = 'N'.
!>

LDZ

!>          LDZ est un ENTIER
!>          La dimension principale du tableau Z. LDZ >= 1.
!>          Si COMPZ='V' ou 'I', alors LDZ >= N.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO >= 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucune erreur

NAME

zhgeqz — Generalize eigenvalue problem (complex-to-complex)

SYNOPSIS

   SUBROUTINE ZHGEQZ(
      JOB, COMPQ, COMPZ, N, ILOQ, ILOZ, A, LDA, B, LDB, ALPHA, BETA, Q, LDQ,
      Z, LDZ, WORK, LWORK, RWORK, INFO
   )


      CHARACTER          JOB, COMPQ, COMPZ
      INTEGER            INFO, LDA, LDB, LDQ, LDZ, N, ILOQ, ILOZ
      DOUBLE PRECISION   RWORK( * )
      COMPLEX*16         A( LDA, * ), B( LDB, * ), ALPHA( * ), BETA( * ),
     $                   Q( LDQ, * ), Z( LDZ, * ), WORK( * )

Function/Subroutine Documentation

ZHGEQZ computes the generalized eigenvalues of a pair of complex upper triangular matrices (A,B).

This subroutine is deprecated. Use ZGGES, ZGEESX, ZGGEV, or ZGGHRD instead.

This subroutine is intended to be used after the matrices A and B have been reduced to upper Hessenberg and upper triangular form respectively by ZGEBAL and ZHGEQR.

Arguments

JOB

      CHARACTER*1        JOB

Specifies the computation of the generalized eigenvectors:

      = 'E': compute generalized eigenvalues only.
      = 'V': compute generalized eigenvalues and generalized eigenvectors.

COMPQ

      CHARACTER*1        COMPQ

Specifies whether or not to compute the matrices Q and (Q*A*Z).

      = 'N': do not compute Q.
      = 'I': compute Q and initialize Q with identity matrix.
      = 'V': compute Q and update Q with (Q*A*Z)

COMPZ

      CHARACTER*1        COMPZ

Specifies whether or not to compute the matrices Z and (Q*A*Z).

      = 'N': do not compute Z.
      = 'I': compute Z and initialize Z with identity matrix.
      = 'V': compute Z and update Z with (Q*A*Z)

N

      INTEGER            N

The order of the matrices A and B. N >= 0.

ILOQ

      INTEGER            ILOQ

If N > 0, ILOQ and IHIQ are integers such that A(ILOQ:IHIQ, ILOQ:IHIQ) and B(ILOQ:IHIQ, ILOQ:IHIQ) are the upper triangular part of the matrix of the generalized eigenvalue problem. If N=0, ILOQ=0.

ILOZ

      INTEGER            ILOZ

If N > 0, ILOZ and IHIZ are integers such that A(ILOZ:IHIZ, ILOZ:IHIZ) and B(ILOZ:IHIZ, ILOZ:IHIZ) are the upper triangular part of the matrix of the generalized eigenvalue problem. If N=0, ILOZ=0.

A

      COMPLEX*16         A( LDA, * )

On entry, A is the upper Hessenberg matrix and the upper triangular part of the matrix of the generalized eigenvalue problem.

On exit, A is updated if COMPQ = 'V' or COMPZ = 'V'.

LDA

      INTEGER            LDA

The leading dimension of A. LDA >= max(1, N).

B

      COMPLEX*16         B( LDB, * )

On entry, B is the upper triangular matrix and the upper triangular part of the matrix of the generalized eigenvalue problem.

On exit, B is updated if COMPQ = 'V' or COMPZ = 'V'.

LDB

      INTEGER            LDB

The leading dimension of B. LDB >= max(1, N).

ALPHA

      COMPLEX*16         ALPHA( * )

On exit, ALPHA contains the generalized eigenvalues.

BETA

      COMPLEX*16         BETA( * )

On exit, BETA contains the generalized eigenvalues.

ALPHA and BETA may be complex. If the eigenvalues are complex, then ALPHA(i) and BETA(i) will be such that the ratio ALPHA(i)/BETA(i) is the eigenvalue. If BETA(i) is zero, then the eigenvalue is infinite. If ALPHA(i) is zero, then the eigenvalue is zero.

Q

      COMPLEX*16         Q( LDQ, * )

On entry, if COMPQ = 'I', Q is initialized to the identity matrix. If COMPQ = 'V', Q is updated with the product (Q*A*Z).

On exit, if COMPQ = 'I', Q contains the matrix Q. If COMPQ = 'V', Q contains the updated matrix Q.

LDQ

      INTEGER            LDQ

The leading dimension of Q. LDQ >= max(1, N).

Z

      COMPLEX*16         Z( LDZ, * )

On entry, if COMPZ = 'I', Z is initialized to the identity matrix. If COMPZ = 'V', Z is updated with the product (Q*A*Z).

On exit, if COMPZ = 'I', Z contains the matrix Z. If COMPZ = 'V', Z contains the updated matrix Z.

LDZ

      INTEGER            LDZ

The leading dimension of Z. LDZ >= max(1, N).

WORK

      COMPLEX*16         WORK( * )

Workspace array. The dimension of WORK must be at least max(1, N).

LWORK

      INTEGER            LWORK

The dimension of the array WORK. LWORK must be at least max(1, N). If LWORK = -1, then a workspace query is assumed and the subroutine only computes the optimal size of the array WORK. The optimal size is returned in WORK(1) and no other values are possibly returned.

RWORK

      DOUBLE PRECISION   RWORK( * )

Workspace array.

INFO

      INTEGER            INFO


      = 0: successful exit
      < 0: if INFO = -i, the i-th argument had an illegal value
      = 1,...,N: the QZ iteration did not converge.  (H,T) is not
                 in Schur form, but ALPHA(i) and BETA(i),
                 i=INFO+1,...,N should be correct.
      = N+1,...,2*N: the shift calculation failed.  (H,T) is not
                 in Schur form, but ALPHA(i) and BETA(i),
                 i=INFO-N+1,...,N should be correct.

An error message related to LWORK is issued by XERBLA.
