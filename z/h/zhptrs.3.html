Documentation de la fonction/sous-programme

sous-programme zhptrs (caractère uplo, entier n, entier nrhs, complexe*16, dimension( * ) ap, entier, dimension( * ) ipiv, complexe*16, dimension( ldb, * ) b, entier ldb, entier info)

ZHPTRS

Objectif :

!>
!> ZHPTRS résout un système d'équations linéaires A*X = B avec une matrice
!> complexe hermitienne A stockée au format compacté en utilisant la
!> factorisation A = U*D*U**H ou A = L*D*L**H calculée par ZHPTRF.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure, forme A = U*D*U**H ;
!>          = 'L':  Triangulaire inférieure, forme A = L*D*L**H.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AP

!>          AP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>          obtenir le facteur U ou L calculés par ZHPTRF, stockés comme une
!>          matrice triangulaire compactée.
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          Détails des échanges et de la structure par blocs de D
!>          déterminés par ZHPTRF.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>          En entrée, la matrice du côté droit B.
!>          En sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0: si INFO = -i, le i-ème argument était invalide
!>
