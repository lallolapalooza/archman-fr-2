sous-routine zheevx (character jobz, character range, character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

ZHEEVX calcule les valeurs propres et, éventuellement, les vecteurs propres gauche et/ou droite pour les matrices HE

Objectif :

!>
!> ZHEEVX calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'une matrice hermitienne complexe A. Les valeurs propres et les vecteurs propres peuvent
!> être sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices
!> pour les valeurs propres désirées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront trouvées.
!>          = 'V': toutes les valeurs propres dans l'intervalle demi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I': les IL-èmes à IU-èmes valeurs propres seront trouvées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA, N)
!>          En entrée, la matrice hermitienne A.  Si UPLO = 'U', la
!>          partie triangulaire supérieure N par N en tête de A contient
!>          la partie triangulaire supérieure de la matrice A.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N par N en tête de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>          En sortie, le triangle inférieur (si UPLO='L') ou le triangle
!>          supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

VL

!>          VL est DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est DOUBLE PRECISION
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergée
!>          lorsqu'elle est déterminée comme se situant dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision de la machine.  Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant A à forme tridiagonale.
!>
!>          Les valeurs propres seront calculées de manière la plus précise lorsque ABSTOL
!>          est défini à deux fois le seuil de sous-dépassement 2*DLAMCH('S'), et non
!>          zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de définir ABSTOL à
!>          2*DLAMCH('S').
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau DOUBLE PRECISION, de dimension (N)
!>          En cas de sortie normale, les M premiers éléments contiennent les valeurs propres
!>          sélectionnées par ordre croissant.
!>

Z

!>          Z est un tableau COMPLEX*16, de dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormés de la matrice A
!>          correspondant aux valeurs propres sélectionnées, avec la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre échoue à converger, alors cette colonne de Z
!>          contient l'approximation la plus récente du vecteur propre, et
!>          l'indice du vecteur propre est retourné dans IFAIL.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK.  LWORK >= 1, lorsque N <= 1 ;
!>          sinon 2*N.
!>          Pour une efficacité optimale, LWORK >= (NB+1)*N,
!>          où NB est le maximum de la taille de bloc pour ZHETRD et pour
!>          ZUNMTR tel que retourné par ILAENV.
!>
!>          Si LWORK = -1, alors une requête de capacité de mémoire est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (7*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (5*N)
!>

IFAIL

!>          IFAIL est un tableau INTEGER, de dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont zéro.  Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur

Function/Subroutine Documentation




ZHEEVX computes the desired eigenvalues and eigenvectors of a
    complex Hermitian matrix A.


Arguments




FACT


CHARACTER*1. Required argument.


Specifies whether to compute all eigenvectors, selected eigenvectors, or
        all eigenvectors.
        
    
        
  • 
        
    'V': Compute all eigenvectors.
    
        
    • 
        
  • 
        
    'E': Compute selected eigenvectors.
    
        
    • 
        

        
See also UPLO.




UPLO


CHARACTER*1. Required argument.


'U': Upper triangle of A is stored;
        
'L': Lower triangle of A is stored.




N


INTEGER. Required argument.


The order of the matrix A. N >= 0.


A


COMPLEX*16, ARRAY*1. Required argument.


The Hermitian matrix A, dimension (LDA, N).


LDA


INTEGER. Required argument.


The leading dimension of the array A. LDA >= max(1, N).


VL


COMPLEX*16, ARRAY*1.


If FACT = 'V', VL is not used.


If FACT = 'E', the lower and upper bounds of the
        eigenvalues.


VU


COMPLEX*16, ARRAY*1.


See VL.


IL


INTEGER.


If FACT = 'V', IL is not used.


IU


INTEGER.


If FACT = 'E', the indices of the desired
        eigenvalues.


ABSTOL


REAL*8. Optional argument.


The absolute tolerance for determining convergence. If set to −1.0D0,
        then the tolerance is set to machine precision times the scale of the
        problem.


M


INTEGER. Required argument.


The number of eigenvalues found. 0 <= M <= N.


W


REAL*8, ARRAY*1. Required argument.


The computed eigenvalues, dimension (N).


Z


COMPLEX*16, ARRAY*1. Required argument.


The computed eigenvectors, dimension (LDZ, N).


LDZ


INTEGER. Required argument.


The leading dimension of the array Z. LDZ >= max(1, N).


WORK


COMPLEX*16, ARRAY*1. Required argument.


Workspace array, dimension (LWORK).


LWORK


INTEGER. Required argument.


The dimension of the array WORK. LWORK >= max(1, 2*N).


RWORK


REAL*8, ARRAY*1. Required argument.


Workspace array, dimension (LDWORK).


LDWORK


INTEGER. Required argument.


The dimension of the array RWORK. See description below.


IFAIL


INTEGER, ARRAY*1. Required argument.


If INFO > 0, then IFAIL contains the indices
        of the eigenvectors that failed to converge.


INFO


INTEGER. Required argument.


> 0: A convergence error occurred.
        
    
        
  • 
        
    > 0: if INFO = i, then i eigenvectors failed to converge.
    
        
    Their indices are stored in array IFAIL.
    
        
    •
