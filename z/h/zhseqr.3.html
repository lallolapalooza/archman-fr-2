sous-routine zhseqr (character job, character compz, integer n, integer ilo, integer ihi, complex*16, dimension( ldh, * ) h, integer ldh, complex*16, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, integer info)

ZHSEQR

But:

!>
!>    ZHSEQR calcule les valeurs propres d'une matrice de Hessenberg H
!>    et, optionnellement, les matrices T et Z de la décomposition de Schur
!>    H = Z T Z**H, où T est une matrice triangulaire supérieure (la
!>    forme de Schur), et Z est la matrice unitaire des vecteurs de Schur.
!>
!>    Optionnellement, Z peut être post-multiplié par une matrice unitaire Q
!>    d'entrée de sorte que cette sous-routine puisse donner la factorisation
!>    de Schur d'une matrice A qui a été réduite à la forme de Hessenberg H
!>    par la matrice unitaire Q :  A = Q*H*Q**H = (QZ)*T*(QZ)**H.
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>           = 'E':  calculer uniquement les valeurs propres;
!>           = 'S':  calculer les valeurs propres et la forme de Schur T.
!>

COMPZ

!>          COMPZ est CHARACTER*1
!>           = 'N':  aucun vecteur de Schur n'est calculé;
!>           = 'I':  Z est initialisé à la matrice unité et la matrice Z
!>                   des vecteurs de Schur de H est retournée;
!>           = 'V':  Z doit contenir une matrice unitaire Q à l'entrée, et
!>                   le produit Q*Z est retourné.
!>

N

!>          N est INTEGER
!>           L'ordre de la matrice H.  N >= 0.
!>

ILO

!>          ILO est INTEGER
!>

IHI

!>          IHI est INTEGER
!>
!>           Il est supposé que H est déjà triangulaire supérieure dans les
!>           lignes et colonnes 1:ILO-1 et IHI+1:N. ILO et IHI sont normalement
!>           définis par un appel précédent à ZGEBAL, puis passés à ZGEHRD
!>           lorsque la matrice de sortie de ZGEBAL est réduite à la forme de
!>           Hessenberg. Sinon, ILO et IHI doivent être mis à 1 et N
!>           respectivement.  Si N > 0, alors 1 <= ILO <= IHI <= N.
!>           Si N = 0, alors ILO = 1 et IHI = 0.
!>

H

!>          H est un tableau COMPLEX*16, dimension (LDH,N)
!>           À l'entrée, la matrice de Hessenberg supérieure H.
!>           À la sortie, si INFO = 0 et JOB = 'S', H contient la matrice
!>           triangulaire supérieure T de la décomposition de Schur (la
!>           forme de Schur). Si INFO = 0 et JOB = 'E', le contenu de
!>           H n'est pas spécifié à la sortie.  (La valeur de sortie de H quand
!>           INFO > 0 est donnée sous la description de INFO ci-dessous.)
!>
!>           Contrairement aux versions antérieures de ZHSEQR, cette sous-routine
!>           peut explicitement mettre H(i,j) = 0 pour i > j et j = 1, 2, ... ILO-1
!>           ou j = IHI+1, IHI+2, ... N.
!>

LDH

!>          LDH est INTEGER
!>           La dimension principale du tableau H. LDH >= max(1,N).
!>

W

!>          W est un tableau COMPLEX*16, dimension (N)
!>           Les valeurs propres calculées. Si JOB = 'S', les valeurs propres sont
!>           stockées dans le même ordre que sur la diagonale de la forme
!>           de Schur retournée dans H, avec W(i) = H(i,i).
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ,N)
!>           Si COMPZ = 'N', Z n'est pas référencé.
!>           Si COMPZ = 'I', à l'entrée Z n'a pas besoin d'être défini et à la sortie,
!>           si INFO = 0, Z contient la matrice unitaire Z des vecteurs de Schur
!>           de H.  Si COMPZ = 'V', à l'entrée Z doit contenir une matrice
!>           N-par-N Q, supposée égale à la matrice unité sauf pour la sous-matrice
!>           Z(ILO:IHI,ILO:IHI). À la sortie, si INFO = 0, Z contient Q*Z.
!>           Normalement, Q est la matrice unitaire générée par ZUNGHR
!>           après l'appel à ZGEHRD qui a formé la matrice de Hessenberg
!>           H. (La valeur de sortie de Z quand INFO > 0 est donnée sous
!>           la description de INFO ci-dessous.)
!>

LDZ

!>          LDZ est INTEGER
!>           La dimension principale du tableau Z.  Si COMPZ = 'I' ou
!>           COMPZ = 'V', alors LDZ >= MAX(1,N).  Sinon, LDZ >= 1.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>           À la sortie, si INFO = 0, WORK(1) retourne une estimation de
!>           la valeur optimale pour LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>           La dimension du tableau WORK.  LWORK >= max(1,N)
!>           est suffisant et offre des performances très bonnes, parfois
!>           optimales. Cependant, LWORK aussi grand que 11*N peut être
!>           nécessaire pour des performances optimales.  Une requête d'espace
!>           de travail est recommandée pour déterminer la taille optimale.
!>
!>           Si LWORK = -1, alors ZHSEQR effectue une requête d'espace de travail.
!>           Dans ce cas, ZHSEQR vérifie les paramètres d'entrée et
!>           estime la taille optimale de l'espace de travail pour les
!>           valeurs données de N, ILO et IHI.  L'estimation est retournée
!>           dans WORK(1).  Aucun message d'erreur lié à LWORK n'est émis
!>           par XERBLA. Ni H ni Z ne sont accédés.
!>

INFO

!>          INFO est INTEGER
!>             = 0:  exécution réussie
!>             < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>             > 0:  si INFO = i, ZHSEQR n'a pas réussi à calculer toutes les
!>                valeurs propres. Les éléments 1:ilo-1 et i+1:n de W
!>                contiennent les valeurs propres qui ont été
!>                calculées avec succès.  (Les échecs sont rares.)
!>
!>                Si INFO > 0 et JOB = 'E', alors à la sortie, les
!>                valeurs propres restantes non convergentes sont les valeurs
!>                propres de la matrice de Hessenberg supérieure des lignes et
!>                colonnes ILO à INFO de la valeur finale de H.
!>
!>                Si INFO > 0 et JOB   = 'S', alors à la sortie
!>
!>           (*)  (valeur initiale de H)*U  = U*(valeur finale de H)
!>
!>                où U est une matrice unitaire. La valeur finale
!>                de H est une matrice de Hessenberg supérieure et triangulaire
!>                dans les lignes et colonnes INFO+1 à IHI.
!>
!>                Si INFO > 0 et COMPZ = 'V', alors à la sortie
!>
!>                  (valeur finale de Z)  =  (valeur initiale de Z)*U
!>
!>                où U est la matrice unitaire dans (*) (quelle que
!>                soit la valeur de JOB.)
!>
!>                Si INFO > 0 et COMPZ = 'I', alors à la sortie
!>                      (valeur finale de Z)  = U
!>                où U est la matrice unitaire dans (*) (quelle que
!>                soit la valeur de JOB.)
!>
!>                Si INFO > 0 et COMPZ = 'N', alors Z n'est pas
!>                accédé.
!>

NAME

zhseqr - the recursive double-shift algorithm to compute the eigenvalues and Schur factorization of a bidiagonal matrix.

SYNOPSIS

 subroutine zhseqr( job, compq, n, ilo, ihi, h, ldh, wrt, wri,
                              q, ldq, dwork, sdwork, info )
 integer :: job, n, ilo, ihi, ldh, ldq, info
 logical :: compq
 complex*16 :: h( ldh, * ), q( ldq, * ), dwork( * ), sdwork( * )
 complex*16 :: wrt( * ), wri( * )

Function/Subroutine Documentation

This subroutine implements the QR algorithm for finding the eigenvalues and Schur factorization of a upper Hessenberg matrix.

It is intended to be called from ZHPTRD and ZGEES.

The algorithm is described in:

K. Braman, R. Byers and R. Mathias, The Multi-Shift QR Algorithm Part I: Maintaining Well Focused Shifts, and Level 3 Performance, SIAM Journal of Matrix Analysis, volume 23, pages 929--947, 2002.

K. Braman, R. Byers and R. Mathias, The Multi-Shift QR Algorithm Part II: Aggressive Early Deflation, SIAM Journal of Matrix Analysis, volume 23, pages 948--973, 2002.

Options are specified by the parameters IPARMQ.

 ISPEC=1:  Number of iterations of the basic QR algorithm.
                      Default: 3*N.

           ISPEC=2:  Maximum number of iterations of the multi-shift QR algorithm
                      to be performed in one block.
                      Default: N.

           ISPEC=3:  Maximum number of iterations of the QR algorithm to be performed
                      before shifting.
                      Default: N.

           ISPEC=4:  Minimum number of iterations of the QR algorithm to be performed
                      after shifting.
                      Default: N.

           ISPEC=5:  Number of iterations of the implicit double shift QR algorithm to
                      be performed before shifting.
                      Default: 2*N.

           ISPEC=6:  Minimum number of iterations of the implicit double shift QR
                      algorithm to be performed after shifting.
                      Default: N.

           ISPEC=7:  Maximum number of iterations of the implicit QR algorithm to be
                      performed before shifting.
                      Default: 2*N.

           ISPEC=8:  Minimum number of iterations of the implicit QR algorithm to be
                      performed after shifting.
                      Default: N.

           ISPEC=9:  Number of iterations of the basic QR algorithm.
                      Default: 3*N.

           ISPEC=10: Minimum number of iterations of the QR algorithm to be performed
                       before shifting.
                       Default: N.

           ISPEC=11: Minimum number of iterations of the QR algorithm to be performed
                       after shifting.
                       Default: N.

           ISPEC=12: Whether to use the implicit double shift routine ZLAHQR.
                       Default: 1 (True).

           ISPEC=13: The number of simultaneous shifts returned by ILAENV(ISPEC=15).
                       (See ISPEC=15 below.) The default for (IHI-ILO+1) <= 500 is NS.
                       The default for (IHI-ILO+1) >  500 is 3*NS/2.

           ISPEC=14: Nibble crossover point. (See IPARMQ for
                       details.) Default: 14% of deflation window
                       size.

           ISPEC=15: Number of simultaneous shifts in a multishift
                       QR iteration.

                       If IHI-ILO+1 is ...
                       greater than      ...but less    ... the
                       or equal to ...      than        default is

                            1               30          NS =   2(+)
                           30               60          NS =   4(+)
                           60              150          NS =  10(+)
                          150              590          NS =  **
                          590             3000          NS =  64
                         3000             6000          NS = 128
                         6000             infinity      NS = 256

                   (+)  By default some or all matrices of this order
                        are passed to the implicit double shift routine
                        ZLAHQR and this parameter is ignored.  See
                        ISPEC=12 above and comments in IPARMQ for
                        details.

                  (**)  The asterisks (**) indicate an ad-hoc
                        function of N increasing from 10 to 64.

           ISPEC=16: Select structured matrix multiply.
                       If the number of simultaneous shifts (specified
                       by ISPEC=15) is less than 14, then the default
                       for ISPEC=16 is 0.  Otherwise the default for
                       ISPEC=16 is 2.

References

 Performance, SIAM Journal of Matrix Analysis, volume 23, pages
 929--947, 2002.
