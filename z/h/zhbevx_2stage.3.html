sous-programme zhbevx_2stage (character jobz, character range, character uplo, integer n, integer kd, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldq, * ) q, integer ldq, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

ZHBEVX_2STAGE calcule les valeurs propres et, optionnellement, les vecteurs propres gauches et/ou droits pour d'autres matrices

Objectif :

!>
!> ZHBEVX_2STAGE calcule des valeurs propres sélectionnées et, optionnellement, des vecteurs propres
!> d'une matrice bande Hermitienne complexe A en utilisant la technique 2-étapes pour
!> la réduction en matrice tridiagonale. Les valeurs propres et les vecteurs propres
!> peuvent être sélectionnés en spécifiant soit un intervalle de valeurs, soit un intervalle
!> d'indices pour les valeurs propres désirées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>                  Non disponible dans cette version.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront trouvées ;
!>          = 'V': toutes les valeurs propres dans l'intervalle demi-ouvert (VL,VU]
!>                 seront trouvées ;
!>          = 'I': les IL-ième à IU-ième valeurs propres seront trouvées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KD >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, dimension (LDAB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande Hermitienne
!>          A, stocké dans les KD+1 premières lignes du tableau. La
!>          j-ième colonne de A est stockée dans la j-ième colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>
!>          En sortie, AB est écrasé par les valeurs générées lors de la
!>          réduction en matrice tridiagonale.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension de tête du tableau AB. LDAB >= KD + 1.
!>

Q

!>          Q est un tableau COMPLEX*16, dimension (LDQ, N)
!>          Si JOBZ = 'V', la matrice unitaire N x N utilisée dans la
!>                          réduction en matrice tridiagonale.
!>          Si JOBZ = 'N', le tableau Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension de tête du tableau Q. Si JOBZ = 'V', alors
!>          LDQ >= max(1,N).
!>

VL

!>          VL est DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est DOUBLE PRECISION
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergée
!>          lorsqu'elle est déterminée à se trouver dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant AB en matrice tridiagonale.
!>
!>          Les valeurs propres seront calculées de manière plus précise lorsque ABSTOL est
!>          réglé sur le double du seuil de sous-flux 2*DLAMCH('S'), et non sur zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de régler ABSTOL sur
!>          2*DLAMCH('S').
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées. 0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau DOUBLE PRECISION, dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres sélectionnées par
!>          ordre croissant.
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormaux de la matrice A
!>          correspondant aux valeurs propres sélectionnées, avec la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre ne converge pas, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et
!>          l'indice du vecteur propre est retourné dans IFAIL.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une limite supérieure doit être utilisée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension de tête du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK. LWORK >= 1, si N <= 1 ;
!>          sinon
!>          Si JOBZ = 'N' et N > 1, LWORK doit être interrogé.
!>                                   LWORK = MAX(1, dimension) où
!>                                   dimen

NOM

zhbevx_2stage - effectue le calcul des valeurs propres et, optionnellement, des vecteurs propres d'une matrice hermitienne par blocs bande.

SYNTAXIS

  SUBROUTINE ZHBEVX_2STAGE( JOBZ, RANGE, UPLO, N, KD, AB, LDAB, Q, LDQ,
 &                           VL, VU, IL, IU, GEVL, TOL, M, NS, NCALL,
 &                           WORK, LWORK, RWORK, LRWORK, IWORK, LIWORK,
 &                           IFAIL, INFO )

L'appel peut également être fait avec des variables de type INTEGER pour les paramètres INTEGER et des variables de type DOUBLE PRECISION pour les paramètres DOUBLE PRECISION.

  CHARACTER JOBZ, RANGE, UPLO
  INTEGER   N, KD, LDAB, LDQ, IL, IU, M, NS, NCALL, LWORK, LRWORK,
            LIWORK
  INTEGER   IFAIL( * )
  DOUBLE    PRECISION AB( * ), Q( * ), VL, VU, GEVL, TOL, WORK( * ),
            RWORK( * )
  INTEGER   INFO

PARAMETRES

Les paramètres sont décrits ci-dessous.

JOBZ
CHARACTER*1. Spécifie si les vecteurs propres doivent être calculés.
Si JOBZ = 'N': Seulement les valeurs propres sont calculées.
Si JOBZ = 'V': Les valeurs propres et les vecteurs propres sont calculés.
RANGE
CHARACTER*1. Spécifie quelle(s) valeur(s) propre(s) doit (doivent) être calculée(s).
Si RANGE = 'A': Toutes les valeurs propres sont calculées.
Si RANGE = 'V': Toutes les valeurs propres dans l'intervalle [VL, VU] sont calculées.
Si RANGE = 'I': Les valeurs propres avec les indices IL à IU sont calculées.
UPLO
CHARACTER*1. Spécifie si la matrice est triangulaire supérieure ou inférieure.
Si UPLO = 'U': La matrice est triangulaire supérieure.
Si UPLO = 'L': La matrice est triangulaire inférieure.
N
INTEGER. L'ordre de la matrice.
Condition : N ≥ 0.
KD
INTEGER. Le nombre de sous-diagonales et de supra-diagonales dans la bande.
Condition : KD ≥ 0.
AB
DOUBLE PRECISION tableau, dimension (LDAB, N).
Avant l'appel, AB contient la partie bande (sous les KD sous-diagonales et sur les KD supra-diagonales) de la matrice hermitienne bande A.
LDAB
INTEGER. Le premier indice de AB. C'est-à-dire que la plupart des implémentations ont besoin de LDAB ≥ KD+1.
Q
DOUBLE PRECISION tableau, dimension (LDQ, N).
Si JOBZ = 'V', alors Q contient les vecteurs propres de AB. Les vecteurs propres sont stockés par colonnes.
Si JOBZ = 'N', alors le tableau Q n'est pas référencé.
LDQ
INTEGER. Le premier indice de Q.
Condition : Si JOBZ = 'V', alors LDQ ≥ max(1, N).
VL
DOUBLE PRECISION. La borne inférieure de l'intervalle des valeurs propres.
VU
DOUBLE PRECISION. La borne supérieure de l'intervalle des valeurs propres.
IL
INTEGER. L'indice de la première valeur propre à calculer, si RANGE = 'I'.
IU
INTEGER. L'indice de la dernière valeur propre à calculer, si RANGE = 'I'.
GEVL
DOUBLE PRECISION. Renvoie le nombre de valeurs propres calculées.
TOL
DOUBLE PRECISION. La tolérance pour la convergence.
Si TOL ≤ 0, alors la tolérance de machine par défaut est utilisée.
M
INTEGER. Le nombre de valeurs propres effectivement calculées.
Si RANGE = 'A', alors M = N.
Si RANGE = 'I', alors M = IU - IL + 1.
Si RANGE = 'V', alors M est le nombre de valeurs propres ≥ VL et ≤ VU.
NS
INTEGER. Le nombre de valeurs propres trouvées dans l'intervalle.
Si RANGE = 'A' ou 'I', NS = M.
NCALL
INTEGER. Le nombre d'appels à zhbevx_2stage.
WORK
DOUBLE PRECISION tableau, dimension (LWORK).
Sur la sortie, WORK(1) contient la taille optimale de WORK.
LWORK
INTEGER. La taille du tableau WORK.
Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine calcule seulement la taille optimale du tableau WORK, la renvoie comme première entrée du tableau WORK, et aucun message d'erreur lié à LWORK n'est émis par XERBLA.
RWORK
DOUBLE PRECISION tableau, dimension (LRWORK).
Sur la sortie, RWORK(1) contient la taille optimale de RWORK.
LRWORK
INTEGER. La taille du tableau RWORK.
Si LRWORK = -1, alors une requête d'espace de travail est supposée ; la routine calcule seulement la taille optimale du tableau RWORK, la renvoie comme première entrée du tableau RWORK, et aucun message d'erreur lié à LRWORK n'est émis par XERBLA.
IWORK
INTEGER tableau, dimension (LIWORK).
Sur la sortie, IWORK(1) contient la taille optimale de IWORK.
LIWORK
INTEGER. La taille du tableau IWORK.
Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la routine calcule seulement la taille optimale du tableau IWORK, la renvoie comme première entrée du tableau IWORK, et aucun message d'erreur lié à LIWORK n'est émis par XERBLA.
IFAIL
INTEGER tableau, dimension (N).
Si JOBZ = 'V', alors si INFO = 0, les M premières entrées de IFAIL sont zéro. Si INFO > 0, alors IFAIL contient les indices des vecteurs propres qui n'ont pas convergé.
Si JOBZ = 'N', alors IFAIL n'est pas référencé.
INFO
INTEGER
  • 0: Sortie réussie

  • < 0: Si INFO = -i, alors le i-ème argument avait une valeur illégale.

  • > 0: Si INFO = i, alors i vecteurs propres n'ont pas convergé. Leurs indices sont stockés dans le tableau IFAIL.

DETAILS

!>
!>  La taille de l'espace de travail requis est N * (KD + 1) + N*NTHREADS pour
!>  la transformation de réduction de bande.
!>  La taille de l'espace de travail requis est N * (KD + 1) + N*NTHREADS pour
!>  le calcul des vecteurs propres.
!>  La taille de l'espace de travail requis est N * (KD + 1) + N*NTHREADS pour
!>  la transformation de bande.
!>  où KD est la taille de la bande.
!>  NTHREADS est le nombre de threads utilisés lorsque la compilation openMP est
!>  activée, sinon =1.
!>          Si JOBZ = 'V' et N > 1, LWORK doit être interrogé. Pas encore disponible.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (7*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (5*N)
!>

IFAIL

!>          IFAIL est un tableau INTEGER, de dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières entrées de
!>          IFAIL sont zéro. Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0: Succès
!>          < 0: Si INFO = -i, alors le i-ème argument avait une valeur illégale
!>          > 0: Si INFO = i, alors i vecteurs propres n'ont pas convergé.
!>                Leurs indices sont stockés dans le tableau IFAIL.
!>
