Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>

WANTZ

!>          WANTZ est LOGICAL, indique si les valeurs propres sont demandées ou si
!>          les valeurs propres/vecteurs propres sont demandés.
!>

TTYPE

!>          TTYPE est INTEGER
!>

ST

!>          ST est INTEGER
!>          paramètre interne pour les indices.
!>

ED

!>          ED est INTEGER
!>          paramètre interne pour les indices.
!>

SWEEP

!>          SWEEP est INTEGER
!>          paramètre interne pour les indices.
!>

N

!>          N est INTEGER. L'ordre de la matrice A.
!>

NB

!>          NB est INTEGER. La taille de la bande.
!>

IB

!>          IB est INTEGER.
!>

A

!>          A est un tableau COMPLEX*16. Un pointeur vers la matrice A.
!>

LDA

!>          LDA est INTEGER. La dimension principale de la matrice A.
!>

V

!>          V est un tableau COMPLEX*16, dimension 2*n si seules les valeurs propres
!>          sont demandées ou si les vecteurs sont à interroger.
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (2*n).
!>          Les facteurs scalaires des réflecteurs de Householder sont stockés
!>          dans ce tableau.
!>

LDVT

!>          LDVT est INTEGER.
!>

WORK

!>          WORK est un tableau COMPLEX*16. Espace de travail de taille nb.
