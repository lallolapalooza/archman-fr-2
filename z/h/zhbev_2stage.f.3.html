sous-programme zhbev_2stage (character jobz, character uplo, integer n, integer kd, complex*16, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer info)

ZHBEV_2STAGE calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour d'AUTRES matrices

Objectif :

!>
!> ZHBEV_2STAGE calcule toutes les valeurs propres et, éventuellement, les vecteurs
!> propres d'une matrice bande hermitienne complexe A en utilisant la technique
!> 2stage pour la réduction en matrice tridiagonale.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer seulement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>                  Non disponible dans cette version.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, dimension (LDAB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande
!>          hermitienne A, stocké dans les KD+1 premières lignes du tableau. La
!>          j-ième colonne de A est stockée dans la j-ième colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd) <= i <= j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j <= i <= min(n,j+kd).
!>
!>          En sortie, AB est écrasé par les valeurs générées pendant la
!>          réduction à une forme tridiagonale. Si UPLO = 'U', la première
!>          superdiagonale et la diagonale de la matrice tridiagonale T
!>          sont retournées dans les lignes KD et KD+1 de AB, et si UPLO = 'L',
!>          la diagonale et la première sous-diagonale de T sont retournées dans les
!>          deux premières lignes de AB.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD + 1.
!>

W

!>          W est un tableau DOUBLE PRECISION, dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient les vecteurs propres
!>          orthonormaux de la matrice A, avec la i-ième colonne de Z
!>          contenant le vecteur propre associé à W(i).
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension LWORK
!>          En sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK. LWORK >= 1, quand N <= 1 ;
!>          sinon
!>          Si JOBZ = 'N' et N > 1, LWORK doit être interrogé.
!>                                   LWORK = MAX(1, dimension) où
!>                                   dimension = (2KD+1)*N + KD*NTHREADS
!>                                   où KD est la taille de la bande.
!>                                   NTHREADS est le nombre de threads utilisés lorsque
!>                                   la compilation openMP est activée, sinon =1.
!>          Si JOBZ = 'V' et N > 1, LWORK doit être interrogé. Pas encore disponible.
!>
!>          Si LWORK = -1, alors une requête de mémoire de travail est supposée ; la routine
!>          calcule seulement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, retourne ces valeurs comme les premières entrées des
!>          tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (max(1,3*N-2))
!>

INFO

!>          INFO est INTEGER
!>          = 0:  Sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  si INFO = i, l'algorithme n'a pas convergé ; i
!>                éléments hors diagonale d'une forme tridiagonale intermédiaire
!>                n'ont pas convergé vers zéro.
!>

NOM

zhbev_2stage - Subroutine pour la factorisation de matrices hermitiennes (ou réelles symétriques) de bande à deux étages.

SYNOPSIS

      SUBROUTINE ZHBEV_2STAGE( JOBZ, UPLO, N, KD, AB, LDAB, B, LDB,
     $                       WORK, RWORK, INFO )
      CHARACTER          JOBZ, UPLO
      INTEGER            KD, LDAB, LDB, N
      COMPLEX*16         AB( LDAB, * ), B( LDB, * ), WORK( * )
      DOUBLE PRECISION   RWORK( * )
      INTEGER            INFO

Documentation de la fonction/sous-routine

Cette sous-routine calcule les valeurs propres et, éventuellement, les vecteurs propres d'une matrice hermitienne (ou réelle symétrique) de bande complexe à 2 étages.

Paramètres

JOBZ (CHARACTER)
Indique s'il faut calculer les valeurs propres uniquement, ou les valeurs propres et les vecteurs propres.
  • 'N' : Calculer uniquement les valeurs propres.
  • 'V' : Calculer les valeurs propres et les vecteurs propres.
UPLO (CHARACTER)
Indique si la matrice est triangulaire supérieure ou inférieure.
  • 'U' : La partie triangulaire supérieure de AB est utilisée.
  • 'L' : La partie triangulaire inférieure de AB est utilisée.
N (INTEGER)
La taille de la matrice carrée NxN.
KD (INTEGER)
Le nombre de superdiagonales (ou sous-diagonales) de la bande.
AB (COMPLEX*16, dimension (LDAB, *))
Sur l'entrée, la matrice de bande hermitienne A. Elle est stockée dans un tableau de dimension (LDAB, N).
LDAB (INTEGER)
La longueur de la première dimension du tableau AB. LDAB >= KD+1.
B (COMPLEX*16, dimension (*))
Sur l'entrée, la matrice de bande B. Sur la sortie, contient les vecteurs propres correspondants aux valeurs propres, triés dans l'ordre croissant des valeurs propres. Si JOBZ = 'N', B n'est pas utilisée.
LDB (INTEGER)
La longueur de la première dimension du tableau B. LDB >= max(1, N).
WORK (COMPLEX*16, dimension (*))
Tableau de travail pour les calculs intermédiaires.
RWORK (DOUBLE PRECISION, dimension (*))
Tableau de travail pour les calculs intermédiaires de nombres réels.
INFO (INTEGER)
Sur la sortie, INFO = 0 si l'exécution réussit. Si INFO < 0, le k-ième argument (index 1-basé) avait une valeur invalide. Si INFO > 0, la sous-routine ZHPTRF a échoué à converger. Si INFO = k, alors le k-ième élément de DIAG est nul, ce qui signifie que la matrice est singulière.
