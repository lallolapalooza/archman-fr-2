Documentation de la fonction/sous-routine

sous-routine zhbevd_2stage (character jobz, character uplo, integer n, integer kd, complex*16, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer lrwork, integer, dimension( * ) iwork, integer liwork, integer info)

ZHBEVD_2STAGE calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour AUTRES matrices

Objectif :

!>
!> ZHBEVD_2STAGE calcule toutes les valeurs propres et, éventuellement, les vecteurs propres d'une matrice bande complexe hermitienne A en utilisant la technique 2stage pour la réduction en matrice tridiagonale. Si les vecteurs propres sont souhaités, elle utilise un algorithme de type "diviser pour régner".
!>
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>                  Non disponible dans cette version.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, de dimension (LDAB, N)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice bande hermitienne
!>          A, stocké dans les KD+1 premières lignes du tableau. La
!>          j-ième colonne de A est stockée dans la j-ième colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>
!>          À la sortie, AB est écrasé par des valeurs générées pendant la
!>          réduction en forme tridiagonale. Si UPLO = 'U', la première
!>          super-diagonale et la diagonale de la matrice tridiagonale T
!>          sont retournées dans les lignes KD et KD+1 de AB, et si UPLO = 'L',
!>          la diagonale et la première sous-diagonale de T sont retournées dans les
!>          deux premières lignes de AB.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD + 1.
!>

W

!>          W est un tableau DOUBLE PRECISION, de dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!>

Z

!>          Z est un tableau COMPLEX*16, de dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient les vecteurs propres
!>          orthonormés de la matrice A, avec la i-ième colonne de Z
!>          contenant le vecteur propre associé à W(i).
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK. LWORK >= 1, lorsque N <= 1 ;
!>          sinon
!>          Si JOBZ = 'N' et N > 1, LWORK doit être interrogé.
!>                                   LWORK = MAX(1, dimension) où
!>                                   dimension = (2KD+1)*N + KD*NTHREADS
!>                                   où KD est la taille de la bande.
!>                                   NTHREADS est le nombre de threads utilisés lors de la compilation avec openMP activée, sinon = 1.
!>          Si JOBZ = 'V' et N > 1, LWORK doit être interrogé. Non encore disponible.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION,
!>                                         de dimension (LRWORK)
!>          À la sortie, si INFO = 0, RWORK(1) renvoie le LRWORK optimal.
!>

LRWORK

!>          LRWORK est INTEGER
!>          La dimension du tableau RWORK.
!>          Si N <= 1,               LRWORK doit être au moins 1.
!>          Si JOBZ = 'N' et N > 1, LRWORK doit être au moins N.
!>          Si JOBZ = 'V' et N > 1, LRWORK doit être au moins
!>                        1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK, RWORK
!>          et IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) renvoie le LIWORK optimal.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si JOBZ = 'N' ou N <= 1, LIWORK doit être au moins 1.
!>          Si JOBZ = 'V' et N > 1, LIWORK doit être au moins 3 + 5*N .
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK, RWORK
!>          et IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  Sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  si INFO = i, l'algorithme n'a pas convergé ; i
!>                éléments hors diagonale d'une forme tridiagonale intermédiaire
!>                n'ont pas convergé vers zéro.
!>

SYNOPSIS

SUBROUTINE ZHBEVD_2STAGE(
     JOBZ, UPLO, N, KD, AB, LDAB, W, Z, LDZ, WORK, LWORK, RWORK, LRWORK,
     IWORK, LIWORK, INFO)

Function/Subroutine Documentation

ZHBEVD_2STAGE uses the 2-stage divide-and-conquer method. This is a template routines that calls the other routines to compute the eigenvalues and eigenvectors. It is not a complete routine and is thus not in the LAPACK source code.

JOBZ

CHARACTER*1.

Specifies whether to compute the eigenvalues and eigenvectors or just the eigenvalues.

= 'N': Compute just the eigenvalues of A.

= 'V': Compute the eigenvalues and eigenvectors of A.

UPLO

CHARACTER*1.

Specifies whether the upper or lower triangular part of the banded matrix A is stored.

= 'U': Upper banded: For triangular and upper banded, the array AB must contain the upper band part of A.

= 'L': Lower banded: For triangular and lower banded, the array AB must contain the lower band part of A.

N

INTEGER.

The order of the matrix A. N >= 0.

KD

INTEGER.

The number of super- or subdiagonals of A. KD >= 0.

AB

COMPLEX*16.

On entry to the internal routine ZHBEVD_2STAGE, the (N) x (N) matrix A.

If UPLO = 'U', AB is N x (KD+1). A is stored in the upper band. The k-th superdiagonal is in the k-th row of the array AB. For example, if N=5 and KD=2, the matrix A is: 

                *   a12 a13
                *   a23 a24 a25
                a34 a35
                a45
                a55

and AB is stored as: 

                AB(1,1) = A(1,1)
                AB(1,2) = A(1,2)
                AB(1,3) = A(1,3)
                AB(2,1) = A(2,1)
                AB(2,2) = A(2,2)
                AB(2,3) = A(2,3)
                ...

If UPLO = 'L', AB is N x (KD+1). A is stored in the lower band. The k-th subdiagonal is in the k-th row of the array AB.

LDAB

INTEGER.

The leading dimension of the array AB. LDAB >= KD+1.

W

DOUBLE PRECISION array, DIMENSION (N).

If JOBZ = 'N', W is the output array containing the eigenvalues of A in ascending order.

If JOBZ = 'V', W contains the eigenvalues of A in ascending order.

Z

COMPLEX*16 array, DIMENSION (LDZ, N).

If JOBZ = 'N', Z is not referenced.

If JOBZ = 'V', Z is the output array containing the eigenvectors of A. The column Z(i) is the eigenvector corresponding to the eigenvalue W(i). The eigenvectors are normalized and stored column-by-column in the UNPACKED form.

LDZ

INTEGER.

The leading dimension of the array Z.

If JOBZ = 'N', LDZ is not referenced.

If JOBZ = 'V', LDZ >= max(1, N).

WORK

COMPLEX*16 array, DIMENSION (LWORK).

LWORK

INTEGER.

The dimension of the array WORK.

If LWORK = -1, then a workspace query is assumed and the routine only calculates the optimal size of the WORK array. The optimal size is returned in WORK(1).

If LWORK is sufficiently large, the routine returns the optimal size of WORK in WORK(1).

RWORK

DOUBLE PRECISION array, DIMENSION (LRWORK).

LRWORK

INTEGER.

The dimension of the array RWORK.

If LRWORK = -1, then a workspace query is assumed and the routine only calculates the optimal size of the RWORK array. The optimal size is returned in RWORK(1).

If LRWORK is sufficiently large, the routine returns the optimal size of RWORK in RWORK(1).

IWORK

INTEGER array, DIMENSION (LIWORK).

LIWORK

INTEGER.

The dimension of the array IWORK.

If LIWORK = -1, then a workspace query is assumed and the routine only calculates the optimal size of the IWORK array. The optimal size is returned in IWORK(1).

If LIWORK is sufficiently large, the routine returns the optimal size of IWORK in IWORK(1).

INFO

INTEGER.

= 0: Successful exit.

< 0: If INFO = -i, the i-th argument had an illegal value.

> 0: If INFO = i, then the algorithm failed to converge; i off-diagonal elements of an intermediate tridiagonal matrix could not be processed.
