Documentation de la fonction/sous-programme

sous-routine zhbevd_2stage (caractere jobz, caractere uplo, entier n, entier kd, complexe*16, dimension( ldab, * ) ab, entier ldab, double precision, dimension( * ) w, complexe*16, dimension( ldz, * ) z, entier ldz, complexe*16, dimension( * ) work, entier lwork, double precision, dimension( * ) rwork, entier lrwork, entier, dimension( * ) iwork, entier liwork, entier info)

ZHBEVD_2STAGE calcule les valeurs propres et, éventuellement, les vecteurs propres d'une matrice bande hermitienne complexe A en utilisant la technique 2stage pour la réduction en matrice tridiagonale. S'il faut calculer les vecteurs propres, il utilise un algorithme de division et conquête.

Objectif:

!>
!> ZHBEVD_2STAGE calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice bande hermitienne complexe A en utilisant la technique 2stage pour
!> la réduction en matrice tridiagonale. S'il faut calculer les vecteurs propres, il
!> utilise un algorithme de division et conquête.
!>
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calcul des valeurs propres seulement;
!>          = 'V':  Calcul des valeurs propres et des vecteurs propres.
!>                  Non disponible dans cette version.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, de dimension (LDAB, N)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice bande
!>          hermitienne A, stocké dans les KD+1 premières lignes du tableau. La
!>          j-ième colonne de A est stockée dans la j-ième colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>
!>          À la sortie, AB est écrasé par les valeurs générées lors de la
!>          réduction en matrice tridiagonale. Si UPLO = 'U', la première
!>          super-diagonale et la diagonale de la matrice tridiagonale T
!>          sont retournées dans les lignes KD et KD+1 de AB, et si UPLO = 'L',
!>          la diagonale et la première sous-diagonale de T sont retournées dans les
!>          deux premières lignes de AB.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD + 1.
!>

W

!>          W est un tableau DOUBLE PRECISION, de dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!>

Z

!>          Z est un tableau COMPLEX*16, de dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient les vecteurs propres
!>          orthonormés de la matrice A, la i-ième colonne de Z
!>          contenant le vecteur propre associé à W(i).
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK. LWORK >= 1, si N <= 1;
!>          sinon
!>          Si JOBZ = 'N' et N > 1, LWORK doit être interrogé.
!>                                   LWORK = MAX(1, dimension) où
!>                                   dimension = (2KD+1)*N + KD*NTHREADS
!>                                   où KD est la taille de la bande.
!>                                   NTHREADS est le nombre de threads utilisés lors
!>                                   de la compilation openMP activée, sinon =1.
!>          Si JOBZ = 'V' et N > 1, LWORK doit être interrogé. Pas encore disponible.
!>
!>          Si LWORK = -1, alors une interrogation de l'espace de travail est supposée; la routine
!>          calcule seulement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, les retourne comme premières entrées
!>          des tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION,
!>                                         de dimension (LRWORK)
!>          À la sortie, si INFO = 0, RWORK(1) contient la valeur optimale de LRWORK.
!>

LRWORK

!>          LRWORK est INTEGER
!>          La dimension du tableau RWORK.
!>          Si N <= 1,               LRWORK doit être au moins 1.
!>          Si JOBZ = 'N' et N > 1, LRWORK doit être au moins N.
!>          Si JOBZ = 'V' et N > 1, LRWORK doit être au moins
!>                        1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, alors une interrogation de l'espace de travail est supposée; la
!>          routine calcule seulement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, les retourne comme premières entrées
!>          des tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) contient la valeur optimale de LIWORK.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si JOBZ = 'N' ou N <= 1, LIWORK doit être au moins 1.
!>          Si JOBZ = 'V' et N > 1, LIWORK doit être au moins 3 + 5*N .
!>
!>          Si LIWORK = -1, alors une interrogation de l'espace de travail est supposée; la
!>          routine calcule seulement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, les retourne comme premières entrées
!>          des tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  Succès de l'exécution.
!>          < 0:  Si INFO = -i, le i-ième argument avait une valeur illégale.
!>          > 0:  Si INFO = i, l'algorithme n'a pas convergé; i
!>                éléments hors diagonale d'une matrice tridiagonale intermédiaire
!>                n'ont pas convergé vers zéro.
!>

zhbevd_2stage(3) - LAPACK

NAME

zhbevd_2stage — Computes the eigenvalues and eigenvectors of a complex Hermitian band matrix.

SYNOPSIS

SUBROUTINE ZHBEVD_2STAGE(
  JOBZ, UPLO, N, KD, AB, LDAB, FIBL, LDFIBL, V, LDV, VV, LDVV, WORK, LWORK, IWORK,
  LIWORK, INFO)
INTEGER N, KD, LDAB, LDFIBL, LDV, LDVV, LWORK, LIWORK, INFO
COMPLEX*16 AB(LDAB, *), FIBL(LDFIBL, *), V(LDV, *), VV(LDVV, *)
CHARACTER JOBZ, UPLO

Function/Subroutine Documentation

This subroutine computes the eigenvalues and eigenvectors of a complex Hermitian band matrix. It uses a two-stage algorithm that first reduces the band matrix to a tridiagonal matrix, and then solves the tridiagonal eigenproblem.

Return values

INFO

          = 0: Successful exit
          < 0: If INFO = -i, the i-th argument had an illegal value.
          > 0: If INFO = i, ZHEEV was called with i occurrences of the
               problem that no eigenvalues could be found.

Arguments

JOBZ

          (input) CHARACTER*1
          = ‘N’: Compute eigenvalues only.

UPLO

          (input) CHARACTER*1
          = ‘U’: Upper triangle of A is stored and will be used.
          = ‘L’: Lower triangle of A is stored and will be used.

N

          (input) INTEGER
          The order of the matrix A. N >= 0.

KD

          (input) INTEGER
          The number of super- or subdiagonals of the band matrix A.
          KD >= 0.

AB

          (input/output) COMPLEX*16 array, dimension (LDAB,N)
          On entry, the upper or lower band part of the Hermitian band matrix A.
          On exit, if UPLO = ‘U’, AB is overwritten with the elements of the
          upper bidiagonal matrix Z which reduces A to tridiagonal form:
          A = Z T Z^H.

LDAB

          (input) INTEGER
          The leading dimension of the array AB. LDAB >= max(1, N).

FIBL

          (output) COMPLEX*16 array, dimension (LDFIBL,N)
          On exit, FIBL contains the details of the similarity transformation
          to reduce the band matrix to tridiagonal form.

LDFIBL

          (input) INTEGER
          The leading dimension of the array FIBL. LDFIBL >= max(1, N).

V

          (output) COMPLEX*16 array, dimension (LDV,N)
          On exit, if JOBZ = ‘V’, then V contains the eigenvectors of A.

LDV

          (input) INTEGER
          The leading dimension of the array V.
          If JOBZ = ‘V’, then LDV >= max(1, N).
          If JOBZ = ‘N’, then LDV is not referenced.

VV

          (output) COMPLEX*16 array, dimension (LDVV,N)
          On exit, VV contains the details of the orthogonal transformations
          which reduce A to tridiagonal form.

LDVV

          (input) INTEGER
          The leading dimension of the array VV. LDVV >= max(1, N).

WORK

          (workspace) COMPLEX*16 array, dimension (LWORK)

LWORK

          (input) INTEGER
          The dimension of the array WORK. LWORK >= 1.
          For optimal efficiency, LWORK >= N*NB, where NB is the block size
          of the underlying routines.

IWORK

          (workspace) INTEGER array, dimension (LIWORK)

LIWORK

          (input) INTEGER
          The dimension of the array IWORK. LIWORK >= 1.

INFO

          (output) INTEGER
          Error exit flag.
