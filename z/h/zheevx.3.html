ZHEEVX calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour les matrices HE

Objectif :

!>
!> ZHEEVX calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'une matrice complexe hermitienne A. Les valeurs propres et les vecteurs propres peuvent
!> être sélectionnés en spécifiant soit une plage de valeurs, soit une plage
!> d'indices pour les valeurs propres désirées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront trouvées.
!>          = 'V': toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I': les valeurs propres de l'indice IL à IU seront trouvées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>          En entrée, la matrice hermitienne A. Si UPLO = 'U', la
!>          partie triangulaire supérieure N x N de A contient
!>          la partie triangulaire supérieure de la matrice A. Si UPLO = 'L',
!>          la partie triangulaire inférieure N x N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>          En sortie, le triangle inférieur (si UPLO='L') ou le triangle
!>          supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

VL

!>          VL est DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est DOUBLE PRECISION
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est considérée comme convergée
!>          lorsqu'elle est déterminée comme se situant dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant A à la forme tridiagonale.
!>
!>          Les valeurs propres seront calculées avec le plus de précision lorsque ABSTOL
!>          est défini sur deux fois le seuil de sous-flux 2*DLAMCH('S'), et non zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certaines
!>          vecteurs propres n'ont pas convergé, essayez de définir ABSTOL sur
!>          2*DLAMCH('S').
!>
!>          Voir  par Demmel et
!>          Kahan, Note de travail LAPACK #3.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau DOUBLE PRECISION, dimension (N)
!>          En cas de sortie normale, les M premiers éléments contiennent les valeurs propres
!>          sélectionnées en ordre croissant.
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormaux de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre ne converge pas, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et l'indice
!>          du vecteur propre est retourné dans IFAIL.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la LWORK optimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK.  LWORK >= 1, lorsque N <= 1 ;
!>          sinon 2*N.
!>          Pour une efficacité optimale, LWORK >= (NB+1)*N,
!>          où NB est le maximum de la taille de bloc pour ZHETRD et pour
!>          ZUNMTR tel que retourné par ILAENV.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (7*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (5*N)
!>

IFAIL

!>          IFAIL est un tableau INTEGER, dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont nuls. Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!>

NAME

zheevx - Computes the eigenvalues and eigenvectors of a complex Hermitian matrix.

Function/Subroutine Documentation

SUBROUTINE ZHEEVX

Purpose:

ZHEEVX computes the eigenvalues and eigenvectors of a complex Hermitian matrix A. It also selects a sub-range of the eigenvalues specified by RANGE.

A Hermitian matrix is a complex matrix that is equal to its conjugate transpose.

This subroutine calls the blocking routines DSBGST/ZHEGST, DSBGVX/ZHEGVX, and other related routines.

Arguments:

JOBZ

CHARACTER*1.

Specifies whether to compute the eigenvectors of A:

  • If JOBZ = ‘N’, then only the eigenvalues are computed.

  • If JOBZ = ‘V’, then the eigenvalues and the corresponding eigenvectors are computed.

Constraint: JOBZ = ‘N’ or ‘V’.

RANGE

CHARACTER*1.

Specifies the range of eigenvalues to be computed:

  • If RANGE = ‘A’, then all eigenvalues are computed.

  • If RANGE = ‘V’, then all eigenvalues in the interval (VL, VU] are computed.

  • If RANGE = ‘I’, then the IL-th through IU-th eigenvalues are computed.

Constraint: RANGE = ‘A’, ‘V’, or ‘I’.

UPLO

CHARACTER*1.

Specifies whether the upper or lower triangular part of the Hermitian matrix A is stored:

  • If UPLO = ‘U’, then A stores the upper triangular part.

  • If UPLO = ‘L’, then A stores the lower triangular part.

Constraint: UPLO = ‘U’ or ‘L’.

N

INTEGER.

The order of the matrix A. N >= 0.

A

COMPLEX*16 array, dimension (LDA, N).

On entry, the complex Hermitian matrix A.

On exit, if JOBZ = ‘V’, then the lower triangle of A is overwritten by the matrix B, and the upper triangle of A is overwritten by the corresponding elements of the Schur factorization.

LDA

INTEGER.

The leading dimension of the array A. LDA >= max(1, N).

VL

DOUBLE PRECISION.

If RANGE = ‘V’, the lower bound of the interval for the desired eigenvalues.

VU

DOUBLE PRECISION.

If RANGE = ‘V’, the upper bound of the interval for the desired eigenvalues.

IL

INTEGER.

If RANGE = ‘I’, the index of the smallest eigenvalue in the selection set.

If RANGE = ‘A’ or ‘V’, IL is not used.

IU

INTEGER.

If RANGE = ‘I’, the index of the largest eigenvalue in the selection set.

If RANGE = ‘A’ or ‘V’, IU is not used.

ABSTOL

DOUBLE PRECISION.

The absolute tolerance for the eigenvalues. See "Further Details".

If ABSTOL is set to the largest value of the machine precision, then in all cases the value is enlarged according to the following tolerance by whichTRUE eigenvalues are computed:

MAX(ABSTOL, ULPS * MACHEPS)

where MACHEPS is the machine precision, ULPS is the number of "unit in the last place" of the interval (VL, VU] for the eigenvalue interval computation, and in the case of the IL-th eigenvalue computation ULPS is the number of "unit in the last place" of the computed eigenvalues. See routine DLAMCH for the definition of machine precision and DLAPST for the definition of ULPS.

M

INTEGER.

The total number of eigenvalues found.

If RANGE = ‘A’ or ‘V’, M is the number of eigenvalues in the interval (VL, VU] or all eigenvalues, respectively.

If RANGE = ‘I’, M is equal to IU - IL + 1.

W

DOUBLE PRECISION array, dimension (N).

The computed eigenvalues, unless the latter part of this array is used for picking the eigenvectors. If the eigenvalues are sorted, they are in ascending order.

Z

COMPLEX*16 array, dimension (LDZ, max(1, M)).

On exit, the computed eigenvectors.

The vector stored in the i-th column of Z is the eigenvector corresponding to the eigenvalue W(i).

The eigenvectors are normalized such that:

If eigenvectors are requested with JOBZ = ‘V’ and RANGE = ‘A’ or RANGE = ‘I’, then the eigenvectors are normalized to have Euclidean norm equal to 1.

If eigenvectors are requested with JOBZ = ‘V’ and RANGE = ‘V’, then the eigenvectors are normalized such that Z•*D*Z = I, where D is the diagonal matrix of eigenvalues. In this case the eigenvectors are scaled so that the column norm is equal to 1 if the corresponding eigenvalue is outside the interval (VL, VU], and scaled by 1 / sqrt(lambda_i - VL) if the corresponding eigenvalue is inside the interval (VL, VU].

LDZ

INTEGER.

The leading dimension of the array Z. LDZ >= max(1, N).

WORK

COMPLEX*16 array, dimension (LWORK).

LWORK

INTEGER.

The dimension of the array WORK. LWORK >= max(1, 2*N).

For optimal efficiency, LWORK >= N + N*NB, where NB is the optimal block size.

If LWORK = -1, then LWORK is determined and the workspace is allocated. The output of the WORK array is then not needed.

RWORK

DOUBLE PRECISION array, dimension (max(1, 5*N)).

IWORK

INTEGER array, dimension (N).

INFO

INTEGER.

= 0: all OK.

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: if INFO = i, then i eigenvectors failed to converge. Their indices are stored in array IFAIL.
