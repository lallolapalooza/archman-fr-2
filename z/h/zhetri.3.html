Documentation de la fonction/sous-routine

subroutine zhetri (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( * ) work, integer info)

ZHETRI

But :

!>
!> ZHETRI calcule l'inverse d'une matrice complexe hermitienne indéfinie
!> A en utilisant la factorisation A = U*D*U**H ou A = L*D*L**H calculée par
!> ZHETRF.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U' : Triangulaire supérieure, forme A = U*D*U**H ;
!>          = 'L' : Triangulaire inférieure, forme A = L*D*L**H.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, la matrice diagonale par blocs D et les multiplicateurs
!>          utilisés pour obtenir le facteur U ou L calculés par ZHETRF.
!>
!>          À la sortie, si INFO = 0, l'inverse (hermitienne) de la matrice
!>          d'origine. Si UPLO = 'U', la partie triangulaire supérieure de
!>          l'inverse est formée et la partie de A sous la diagonale n'est pas
!>          référencée ; si UPLO = 'L' la partie triangulaire inférieure de
!>          l'inverse est formée et la partie de A au-dessus de la diagonale n'est pas
!>          référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          Détails des échanges et structure par blocs de D
!>          tels que déterminés par ZHETRF.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) = 0 ; la matrice est singulière et son
!>               inverse n'a pas pu être calculé.
!>
