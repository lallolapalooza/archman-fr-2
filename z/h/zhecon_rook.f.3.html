subroutine zhecon_rook (uplo, n, a, lda, ipiv, anorm, rcond, work, info)
ZHECON_ROOK estime le réciproque du nombre de condition pour les matrices HE en utilisant la factorisation obtenue avec l'une des méthodes de pivotement diagonal borné (max 2 échanges)

Documentation de la fonction/sous-programme

sous-routine zhecon_rook (caractere uplo, entier n, complexe*16, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, double precision anorm, double precision rcond, complexe*16, dimension( * ) work, entier info)

ZHECON_ROOK estime le réciproque du nombre de condition d'une matrice hermitienne complexe A en utilisant la factorisation A = U*D*U**H ou A = L*D*L**H calculée par CHETRF_ROOK.

Objectif :

!>
!> ZHECON_ROOK estime le réciproque du nombre de condition d'une matrice complexe
!> hermitienne A en utilisant la factorisation A = U*D*U**H ou
!> A = L*D*L**H calculée par CHETRF_ROOK.
!>
!> Une estimation de norm(inv(A)) est obtenue, et le réciproque du
!> nombre de condition est calculé comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure, forme est A = U*D*U**H;
!>          = 'L':  Triangulaire inférieure, forme est A = L*D*L**H.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>          obtenir le facteur U ou L calculés par CHETRF_ROOK.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure par blocs de D
!>          tels que déterminés par CHETRF_ROOK.
!>

ANORM

!>          ANORM est DOUBLE PRECISION
!>          La norme 1 de la matrice originale A.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          Le réciproque du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
