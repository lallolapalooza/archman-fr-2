ZHESV_AA calcule la solution du système d'équations linéaires A * X = B pour les matrices HE

Documentation de la fonction/sous-programme

sous-programme zhesv_aa (caractere uplo, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( * ) work, entier lwork, entier info)

ZHESV_AA calcule la solution d'un système complexe d'équations linéaires A * X = B,

Objectif :

!>
!> ZHESV_AA calcule la solution d'un système complexe d'équations linéaires
!>    A * X = B,
!> où A est une matrice hermitienne N par N et X et B sont des matrices N par NRHS.
!>
!> L'algorithme d'Aasen est utilisé pour factoriser A comme suit :
!>    A = U**H * T * U,  si UPLO = 'U', ou
!>    A = L * T * L**H,  si UPLO = 'L',
!> où U (ou L) est un produit de matrices de permutation et triangulaires unitaires supérieures (inférieures),
!> et T est hermitienne et tridiagonale. La forme factorisée de A est ensuite utilisée pour résoudre le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, la matrice hermitienne A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire N par N de A contient la partie
!>          supérieure triangulaire de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée.  Si UPLO = 'L',
!>          la partie inférieure triangulaire N par N de A contient la partie
!>          inférieure triangulaire de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>
!>          À la sortie, si INFO = 0, la matrice tridiagonale T et les
!>          multiplicateurs utilisés pour obtenir le facteur U ou L à partir de
!>          la factorisation A = U**H*T*U ou A = L*T*L**H tels que calculés par
!>          ZHETRF_AA.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          À la sortie, il contient les détails des échanges, c'est-à-dire que
!>          la ligne et la colonne k de A ont été échangées avec la
!>          ligne et la colonne IPIV(k).
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice membre de droite B de dimensions N par NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de dimensions N par NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la taille LWORK optimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur de WORK.  LWORK >= MAX(1,2*N,3*N-2), et pour de meilleures
!>          performances LWORK >= max(1,N*NB), où NB est la taille de bloc optimale
!>          pour ZHETRF_AA.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) est exactement zéro. La factorisation
!>               a été complétée, mais la matrice diagonale par blocs D est
!>               exactement singulière, donc la solution n'a pas pu être calculée.
!>
