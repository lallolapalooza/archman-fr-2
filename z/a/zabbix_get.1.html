ZABBIX_GET(1) Manuel des commandes générales ZABBIX_GET(1)

NOM

zabbix_get - Utilitaire Zabbix get

SYNOPIS

zabbix_get -s nom-hote-ou-IP [-p numero-port] [-I adresse-IP] [-t delai] -k cle-element
zabbix_get -s nom-hote-ou-IP [-p numero-port] [-I adresse-IP] [-t delai] --tls-connect cert --tls-ca-file fichier-CA [--tls-crl-file fichier-CRL] [--tls-agent-cert-issuer emetteur-certificat-agent] [--tls-agent-cert-subject sujet-certificat-agent] --tls-cert-file fichier-certificat --tls-key-file fichier-cle [--tls-cipher13 chaine-chiffrement] [--tls-cipher chaine-chiffrement] -k cle-element
zabbix_get -s nom-hote-ou-IP [-p numero-port] [-I adresse-IP] [-t delai] --tls-connect psk --tls-psk-identity identite-PSK --tls-psk-file fichier-PSK [--tls-cipher13 chaine-chiffrement] [--tls-cipher chaine-chiffrement] -k cle-element
zabbix_get -h
zabbix_get -V

DESCRIPTION

zabbix_get est un utilitaire en ligne de commande pour récupérer des données depuis un agent Zabbix.

OPTIONS

-s, --host nom-hote-ou-IP
Spécifie le nom d'hôte ou l'adresse IP d'un hôte.
-p, --port numero-port
Spécifie le numéro de port de l'agent s'exécutant sur l'hôte. Le défaut est 10050.
-I, --source-address adresse-IP
Spécifie l'adresse IP source.
-t, --timeout secondes
Spécifie le délai d'attente. Plage valide : 1-600 secondes (défaut : 30)
-k, --key cle-element
Spécifie la clé de l'élément dont il faut récupérer la valeur.
-P, --protocol valeur
Protocole utilisé pour communiquer avec l'agent. Valeurs :
auto
se connecte en utilisant le protocole JSON, échoue et réessaie avec le protocole texte (défaut)
json
se connecte en utilisant le protocole JSON
plaintext
se connecte en utilisant le protocole texte où seule la clé de l'élément est envoyée (versions 6.4.x et antérieures)
--tls-connect valeur
Comment se connecter à l'agent. Valeurs :
unencrypted
se connecte sans chiffrement (défaut)
psk
se connecte en utilisant TLS et une clé pré-partagée
cert
se connecte en utilisant TLS et un certificat
--tls-ca-file fichier-CA
Chemin d'accès complet d'un fichier contenant les certificats CA de haut niveau pour la vérification du certificat du pair.
--tls-crl-file fichier-CRL
Chemin d'accès complet d'un fichier contenant les certificats révoqués.
--tls-agent-cert-issuer emetteur-certificat-agent
Émetteur de certificat d'agent autorisé.
--tls-agent-cert-subject sujet-certificat-agent
Sujet de certificat d'agent autorisé.
--tls-cert-file fichier-certificat
Chemin d'accès complet d'un fichier contenant le certificat ou la chaîne de certificats.
--tls-key-file fichier-cle
Chemin d'accès complet d'un fichier contenant la clé privée.
--tls-psk-identity identite-PSK
Chaîne d'identité PSK.
--tls-psk-file fichier-PSK
Chemin d'accès complet d'un fichier contenant la clé pré-partagée.
--tls-cipher13 chaine-chiffrement
Chaîne de chiffrement pour OpenSSL 1.1.1 ou plus récent pour TLS 1.3. Remplace les critères de sélection des suites de chiffrement par défaut. Cette option n'est pas disponible si la version d'OpenSSL est antérieure à 1.1.1.
--tls-cipher chaine-chiffrement
Chaîne de priorité GnuTLS (pour TLS 1.2 et supérieur) ou chaîne de chiffrement OpenSSL (pour TLS 1.2 uniquement). Remplace les critères de sélection des suites de chiffrement par défaut.
-h, --help
Affiche cette aide et quitte.
-V, --version
Affiche les informations de version et quitte.

STATUT DE SORTIE

Le statut de sortie est 0 si zabbix_get récupère avec succès une valeur depuis l'agent Zabbix. Si la récupération de la valeur a échoué, le statut de sortie est 1.

EXEMPLES

zabbix_get -s 127.0.0.1 -p 10050 -k "system.cpu.load[all,avg1]"
zabbix_get -s 127.0.0.1 -p 10050 -k "system.cpu.load[all,avg1]" --tls-connect cert --tls-ca-file /home/zabbix/zabbix_ca_file --tls-agent-cert-issuer "CN=Signing CA,OU=IT operations,O=Example Corp,DC=example,DC=com" --tls-agent-cert-subject "CN=server1,OU=IT operations,O=Example Corp,DC=example,DC=com" --tls-cert-file /home/zabbix/zabbix_get.crt --tls-key-file /home/zabbix/zabbix_get.key
zabbix_get -s 127.0.0.1 -p 10050 -k "system.cpu.load[all,avg1]" --tls-connect psk --tls-psk-identity "PSK ID Zabbix agentd" --tls-psk-file /home/zabbix/zabbix_agentd.psk
