NOM

zathurarc - fichier de configuration de zathura

SYNTAXE

/etc/zathurarc, $XDG_CONFIG_HOME/zathura/zathurarc

DESCRIPTION

Le fichier zathurarc est un simple fichier texte pouvant être rempli de diverses commandes pour modifier le comportement et l'apparence de zathura, que nous allons décrire dans les sous-sections suivantes. Chaque ligne (en dehors des lignes vides et des commentaires qui commencent par un #) est évaluée indépendamment, il n'est donc pas possible d'écrire plusieurs commandes sur une seule ligne.

COMMANDES

set - Changer les options

En plus de la commande intégrée :set, zathura propose plus d'options à modifier et rend ces changements permanents. Pour écraser une option, il suffit d'ajouter une ligne structurée comme suit :

set <option> <nouvelle valeur>

Le champ option doit être remplacé par le nom de l'option à modifier et le champ nouvelle valeur par la nouvelle valeur que l'option devrait recevoir. Le type de la valeur peut être l'un des suivants :

  • INT - Un nombre entier
  • FLOAT - Un nombre à virgule flottante
  • STRING - Une chaîne de caractères
  • BOOL - Une valeur booléenne ("true" pour vrai, "false" pour faux)

De plus, nous vous conseillons de consulter les options pour obtenir une vue plus détaillée des options qui peuvent être modifiées et aux valeurs auxquelles elles devraient être définies.

L'exemple suivant devrait donner un aperçu plus approfondi de la façon dont la commande set peut être utilisée :

set option1 5
set option2 2.0
set option3 hello
set option4 hello\ world
set option5 "hello world"

En particulier pour les options avec des chaînes de caractères comme valeurs, notez que l'échappement des caractères spéciaux et des espaces est nécessaire. Dans l'exemple ci-dessus, option4 et option5 sont toutes deux définies à hello world, mais set option6 hello world ne définirait option6 qu'à hello.

Pour les couleurs, zathura prend en charge les codes couleur HTML et les valeurs de style CSS3 rgb(r,g,b) et rgba(r,g,b,a). Si vous souhaitez utiliser des codes couleur pour certaines options, assurez-vous de les mettre entre guillemets ou d'échapper le symbole dièse.

set default-fg "#CCBBCC"
set default-fg \#CCBBCC

Pour rgba, notez qu'il analyse les composants de couleur comme des entiers entre 0 et 255 et le composant alpha comme un flottant entre 0 et 1.

include - Inclure un autre fichier de configuration

Cette commande permet d'inclure d'autres fichiers de configuration. Si un chemin relatif est donné, le chemin sera résolu par rapport au fichier de configuration en cours de traitement.

include another-config

map - Mapper un raccourci

Il est possible de mapper ou de remapper de nouvelles liaisons de touches à des fonctions de raccourci, ce qui permet un haut niveau de personnalisation. La commande :map peut également être utilisée dans le fichier zathurarc pour rendre ces changements permanents :

map [mode] <liaison> <fonction de raccourci> <argument>
Mode
La commande map attend plusieurs arguments dont seuls les arguments liaison et fonction-raccourci sont requis. Comme zathura utilise plusieurs modes, il est possible de mapper des liaisons uniquement pour un mode spécifique en passant l'argument mode qui peut prendre l'une des valeurs suivantes :
  • normal (par défaut)
  • fullscreen
  • presentation
  • index

Les crochets autour de la valeur sont obligatoires.

Liaison de touche unique
Le deuxième argument (éventuel) définit la liaison de touche utilisée qui doit être mappée à la fonction de raccourci et est structuré comme suit. D'une part, il est possible de lui attribuer simplement des lettres uniques, des chiffres ou des symboles :
map a fonction_raccourci argument_optionnel
map b fonction_raccourci argument_optionnel
map c fonction_raccourci argument_optionnel
map 1 fonction_raccourci argument_optionnel
map 2 fonction_raccourci argument_optionnel
map 3 fonction_raccourci argument_optionnel
map ! fonction_raccourci argument_optionnel
map ? fonction_raccourci argument_optionnel
Utilisation des modificateurs
Il est également possible d'utiliser des modificateurs comme la touche Contrôle ou Alt du clavier. Il est possible d'utiliser les modificateurs suivants :
  • A - Alt
  • C - Contrôle
  • S - Shift

Si l'un des modificateurs doit être utilisé pour une liaison, il est requis de définir la liaison avec la structure suivante :

map <A-a> fonction_raccourci
map <C-a> fonction_raccourci

Commandes de buffer
Si un mappage ne correspond à aucune des définitions précédentes mais est tout de même un mappage valide, il sera mappé comme une commande de buffer :
map abc quitter

CONFIGURATION

Ce document décrit les différentes options qui peuvent être utilisées dans le fichier de configuration. Les options sont divisées en deux sections: la section girara et la section zathura. Les options sont modifiables avec la commande set.

RACCOURCIS

Fonctions de raccourci
Les fonctions de raccourci suivantes peuvent être mappées :
  • abort

    Revenir au mode normal.

  • adjust_window

    Ajuster la largeur de la page. Les arguments possibles sont best-fit et width.

  • change_mode

    Changer le mode actuel. Passer le mode désiré comme argument.

  • cycle_first_column

    En disposition multi-pages, cycler la colonne dans laquelle la première page est affichée.

  • display_link :

    Afficher la cible du lien.

  • exec :

    Exécuter une commande externe. \$FILE s'étend au chemin du document actuel, \$PAGE au numéro de page actuel et \$DBUS au nom du bus de l'interface D-Bus.

  • file_chooser :

    Ouvrir une boîte de dialogue de sélection de fichier. Utilise le sélecteur de fichier natif sous Windows et MacOS, les portails de bureau lorsque disponibles et sinon GtkFileChooser.

  • focus_inputbar

    Mettre le focus sur la barre d'entrée.

  • follow

    Suivre un lien.

  • goto

    Aller à une page spécifique.

  • jumplist

    Se déplacer en avant/en arrière dans la liste de sauts. Passer forward comme argument pour passer à l'entrée suivante et backward pour passer à la précédente.

  • navigate

    Naviguer vers la page suivante/précédente.

  • navigate_index

    Naviguer dans l'index.

  • print

    Afficher la boîte de dialogue d'impression.

  • quit

    Quitter zathura.

  • recolor

    Recolorer les pages.

  • reload

    Recharger le document.

  • rotate

    Faire pivoter la page. Passer rotate-ccw comme argument pour une rotation anti-horaire et rotate-cw pour une rotation horaire.

  • scroll

    Faire défiler.

  • search

    Rechercher l'élément suivant/précédent. Passer forward comme argument pour rechercher la prochaine occurrence et backward pour rechercher l'occurrence précédente.

  • set

    Définir une option.

  • snap_to_page

    S'aligner sur la page actuelle. Équivalent à goto <current_page>

  • toggle_fullscreen

    Basculer en plein écran.

  • toggle_index

    Afficher ou masquer l'index.

  • toggle_inputbar

    Afficher ou masquer la barre d'entrée.

  • toggle_page_mode

    Basculer entre une et plusieurs pages par ligne.

  • toggle_statusbar

    Afficher ou masquer la barre d'état.

  • zoom

    Zoom avant ou arrière.

  • mark_add

    Définir un repère rapide.

  • mark_evaluate

    Aller à un repère rapide.

  • feedkeys

    Simuler des pressions de touches. Notez que toutes les touches seront interprétées comme si elles étaient tapées au clavier. Pour saisir des lettres majuscules, suivez la même convention que pour les liaisons de touches, c'est-à-dire pour X, utilisez <S-X>.

Passage d'arguments
Certaines fonctions de raccourci nécessitent ou ont des arguments optionnels qui influencent leur comportement. Ceux-ci peuvent être passés comme dernier argument :
map <C-i> zoom in
map <C-o> zoom out

Les arguments possibles sont :

  • best-fit
  • bottom
  • backward
  • collapse
  • collapse-recursive
  • collapse-all
  • default
  • down
  • expand
  • expand-recursive
  • expand-all
  • forward
  • full-down
  • full-up
  • half-down
  • half-up
  • in
  • left
  • next
  • out
  • page-bottom
  • page-top
  • previous
  • right
  • rotate-ccw
  • rotate-cw
  • select
  • specific
  • toggle
  • top
  • up
  • width

unmap - Supprimer un raccourci

En plus de mapper ou remapper des liaisons de touches personnalisées, il est possible de supprimer celles qui existent en utilisant la commande :unmap. La commande est utilisée de la manière suivante (l'explication des paramètres est décrite dans la section map de ce document)

unmap [mode] <binding>
