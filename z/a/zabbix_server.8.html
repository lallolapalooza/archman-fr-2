ZABBIX_SERVER(8) Manuel du gestionnaire système ZABBIX_SERVER(8)

NOM

zabbix_server - démon Zabbix server

SYNTAXE

zabbix_server [-c fichier-de-configuration]
zabbix_server [-c fichier-de-configuration] -R option-runtime
zabbix_server [-c fichier-de-configuration] -T
zabbix_server -h
zabbix_server -V

DESCRIPTION

zabbix_server est le démon principal du logiciel Zabbix.

OPTIONS

-c, --config fichier-de-configuration
Utilise le fichier-de-configuration alternatif au lieu de celui par défaut.
-f, --foreground
Exécute Zabbix server en avant-plan.
-R, --runtime-control option-runtime
Effectue des fonctions administratives selon l'option-runtime.
Options de contrôle d'exécution
config_cache_reload
Recharge le cache de configuration. Ignoré si le cache est en cours de chargement. Le fichier de configuration par défaut (sauf si l'option -c est spécifiée) sera utilisé pour trouver le fichier PID et un signal sera envoyé au processus listé dans le fichier PID.
snmp_cache_reload
Recharge le cache SNMP.
housekeeper_execute
Exécute le housekeeper. Ignoré si le housekeeper est en cours d'exécution.
trigger_housekeeper_execute
Exécute le housekeeper des déclencheurs (supprime les problèmes pour les déclencheurs supprimés). Ignoré si le housekeeper des déclencheurs est en cours d'exécution.
secrets_reload
Recharge les secrets depuis Vault. Ignoré si le cache de configuration ou les secrets sont en cours de chargement.
diaginfo[=section]
Enregistre les informations de diagnostic internes de la section spécifiée. La section peut être historycache, preprocessing, alerting, lld, valuecache, locks. Par défaut, les informations de diagnostic de toutes les sections sont enregistrées.
prof_enable[=cible]
Active le profilage, affecte tous les processus si la cible n'est pas spécifiée
prof_disable[=cible]
Désactive le profilage, affecte tous les processus si la cible n'est pas spécifiée
ha_status
Affiche l'état du cluster de haute disponibilité. Ne peut être effectué que sur le nœud actif.
ha_remove_node
ha_remove_node[=nom|ID] Supprime un nœud de haute disponibilité par son nom ou ID listé dans ha_status. Ne peut être effectué que sur le nœud actif.
ha_set_failover_delay[=délai]
Définit le délai de basculement de la haute disponibilité. Le délai peut être spécifié en utilisant des suffixes de temps. Ne peut être effectué que sur le nœud actif.
log_level_increase[=cible]
Augmente le niveau de journalisation, affecte tous les processus si la cible n'est pas spécifiée
log_level_decrease[=cible]
Diminue le niveau de journalisation, affecte tous les processus si la cible n'est pas spécifiée
Cibles de contrôle du niveau de journalisation
type-de-processus
Tous les processus du type spécifié (alerter, alert manager, availability manager, browser poller, configuration syncer, configuration syncer worker, connector manager, connector worker, discovery manager, escalator, ha manager, history poller, history syncer, housekeeper, http poller, icmp pinger, internal poller, ipmi manager, ipmi poller, java poller, odbc poller, poller, agent poller, http agent poller, snmp poller, preprocessing manager, proxy group manager, proxy poller, self-monitoring, service manager, snmp trapper, task manager, timer, trapper, unreachable poller, vmware collector)
type-de-processus,N
Type et numéro de processus (par ex., poller,3)
pid
Identifiant du processus
Cibles de contrôle du profilage
type-de-processus
Tous les processus du type spécifié (alerter, alert manager, availability manager, configuration syncer, connector manager, connector worker, discovery manager, escalator, ha manager, history poller, history syncer, housekeeper, http poller, icmp pinger, internal poller, ipmi manager, ipmi poller, java poller, odbc poller, poller, agent poller, http agent poller, snmp poller, preprocessing manager, proxy group manager, proxy poller, self-monitoring, service manager, snmp trapper, task manager, timer, trapper, unreachable poller, vmware collector)
type-de-processus,N
Type et numéro de processus (par ex., history syncer,1)
pid
Identifiant du processus
scope
(rwlock, mutex, processing) peut être utilisé avec type-de-processus (par ex., history syncer,1,processing)
-T, --test-config
Valide le fichier de configuration et quitte.
-h, --help
Affiche cette aide et quitte.
-V, --version
Affiche les informations de version et quitte.

FICHIERS

/usr/local/etc/zabbix_server.conf
Emplacement par défaut du fichier de configuration de Zabbix server (s'il n'a pas été modifié lors de la compilation).
