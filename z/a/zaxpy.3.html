sous-programme zaxpy (integer n, complex*16 za, complex*16, dimension(*) zx, integer incx, complex*16, dimension(*) zy, integer incy)

ZAXPY

Objectif :

!>
!>    ZAXPY un scalaire fois un vecteur plus un vecteur.
!>

Paramètres

N 
!>          N est un ENTIER
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

ZA

!>          ZA est un COMPLEX*16
!>           À l'entrée, ZA spécifie le scalaire alpha.
!>

ZX

!>          ZX est un tableau COMPLEX*16, de dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est un ENTIER
!>         espacement de stockage entre les éléments de ZX
!>

ZY

!>          ZY est un tableau COMPLEX*16, de dimension ( 1 + ( N - 1 )*abs( INCY ) )
!>

INCY

!>          INCY est un ENTIER
!>         espacement de stockage entre les éléments de ZY
!>
