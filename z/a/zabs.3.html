!>
!> Valeurs réelles pour le test :
!> (1) x = 2**m, où m = MINEXPONENT-DIGITS, ..., MINEXPONENT-1. Arrêter au premier succès.
!>     Attention, toutes les plateformes n'implémentent pas forcément les nombres subnormaux.
!> (2) x = 2**m, où m = MINEXPONENT, ..., 0. Arrêter au premier succès.
!> (3) x = OV, où OV est le seuil de débordement. OV^2 déborde mais la norme est OV.
!> (4) x = 2**m, où m = MAXEXPONENT-1, ..., 1. Arrêter au premier succès.
!>
!> Tests :
!> (a) y = x + 0 * I, |y| = x
!> (b) y = 0 + x * I, |y| = x
!> (c) y = (3/4)*x + x * I, |y| = (5/4)*x lorsque (3/4)*x et (5/4)*x peuvent être stockés exactement
!> (d) y = (1/2)*x + (1/2)*x * I, |y| = (1/2)*x*sqrt(2) lorsque (1/2)*x peut être stocké exactement
!>
!> Cas spéciaux :
!>
!> (i) Propagation Inf
!>    (1) y = Inf + 0 * I, |y| est Inf.
!>    (2) y =-Inf + 0 * I, |y| est Inf.
!>    (3) y = 0 + Inf * I, |y| est Inf.
!>    (4) y = 0 - Inf * I, |y| est Inf.
!>    (5) y = Inf + Inf * I, |y| est Inf.
!>
!> (n) Propagation NaN
!>    (1) y = NaN + 0 * I, |y| est NaN.
!>    (2) y = 0 + NaN * I, |y| est NaN.
!>    (3) y = NaN + NaN * I, |y| est NaN.
!>
!>
