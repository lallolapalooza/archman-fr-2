ZDRGEV

But :

!>
!> ZDRGEV vérifie la routine de pilotage du problème de valeurs propres généralisées non symétriques ZGGEV.
!>
!> ZGGEV calcule pour une paire de matrices non symétriques n-par-n (A,B) les
!> valeurs propres généralisées et, éventuellement, les vecteurs propres gauches et droits.
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un rapport alpha/beta = w, tel que A - w*B est singulier. C'est
!> généralement représenté par la paire (alpha,beta), car il existe une interprétation raisonnable
!> pour beta=0, et même pour les deux étant zéro.
!>
!> Un vecteur propre généralisé droit correspondant à une valeur propre généralisée
!> w pour une paire de matrices (A,B) est un vecteur r tel que
!> (A - wB) * r = 0. Un vecteur propre généralisé gauche est un vecteur l tel que
!> l**H * (A - wB) = 0, où l**H est la conjuguée transposer de l.
!>
!> Lorsque ZDRGEV est appelée, un nombre de tailles de matrices et un
!> nombre de types de matrices sont spécifiés. Pour chaque taille ()
!> et chaque type de matrice, une paire de matrices (A, B) sera générée
!> et utilisée pour les tests. Pour chaque paire de matrices, les tests suivants
!> seront effectués et comparés au seuil THRESH.
!>
!> Résultats de ZGGEV :
!>
!> (1) max sur toutes les paires de valeurs propres/vecteurs propres gauches (alpha/beta,l) de
!>
!>     | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>     où VL**H est la conjuguée transposer de VL.
!>
!> (2) | |VL(i)| - 1 | / ulp et si la composante la plus grande est réelle
!>
!>     VL(i) désigne la i-ème colonne de VL.
!>
!> (3) max sur toutes les paires de valeurs propres/vecteurs propres gauches (alpha/beta,r) de
!>
!>     | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4) | |VR(i)| - 1 | / ulp et si la composante la plus grande est réelle
!>
!>     VR(i) désigne la i-ème colonne de VR.
!>
!> (5) W(complet) = W(partiel)
!>     W(complet) désigne les valeurs propres calculées lorsque l et r
!>     sont également calculés, et W(partiel) désigne les valeurs propres
!>     calculées lorsque seul W, seul W et r, ou seul W et l sont
!>     calculés.
!>
!> (6) VL(complet) = VL(partiel)
!>     VL(complet) désigne les vecteurs propres gauches calculés lorsque l et r
!>     sont calculés, et VL(partiel) désigne le résultat
!>     lorsque seul l est calculé.
!>
!> (7) VR(complet) = VR(partiel)
!>     VR(complet) désigne les vecteurs propres droits calculés lorsque l et r
!>     sont également calculés, et VR(partiel) désigne le résultat
!>     lorsque seul l est calculé.
!>
!>
!> Matrices de test
!> ---- --------
!>
!> Les tailles des matrices de test sont spécifiées par un tableau
!> NN(1:NSIZES) ; la valeur de chaque élément NN(j) spécifie une taille.
!> Les types de matrices sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ; si
!> DOTYPE(j) est .TRUE., alors le type de matrice j sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1) ( 0, 0 ) (une paire de matrices nulles)
!>
!> (2) ( I, 0 ) (une matrice identité et une matrice nulle)
!>
!> (3) ( 0, I ) (une matrice nulle et une matrice identité)
!>
!> (4) ( I, I ) (une paire de matrices identité)
!>
!>        t   t
!> (5) ( J , J  ) (une paire de blocs de Jordan transposés)
!>
!>                                      t                ( I   0  )
!> (6) ( X, Y ) où  X = ( J   0  )  et Y = (      t )
!>                                   ( 0   I  )          ( 0   J  )
!>                        et I est une identité k x k et J un bloc de Jordan (k+1)x(k+1)
!>                        k=(N-1)/2
!>
!> (7) ( D, I ) où D est diag( 0, 1,..., N-1 ) (une matrice diagonale
!>                     avec ces entrées diagonales.)
!> (8) ( I, D )
!>
!> (9) ( big*D, small*I ) où big est proche du dépassement et small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 ) où D1 est diag( 0, 0, 1, ..., N-3, 0 ) et
!>                        D2 est diag( 0, N-3, N-4,..., 1, 0, 0 )
!>        t   t
!> (16) Q ( J , J ) Z     où Q et Z sont des matrices orthogonales aléatoires.
!>
!> (17) Q ( T1, T2 ) Z    où T1 et T2 sont des matrices triangulaires supérieures
!>                        avec des entrées O(1) aléatoires au-dessus de la diagonale
!>                        et des entrées diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) et diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = précision machine.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        où r1,..., r(N-4) sont aléatoires.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     où T1 et T2 sont des matrices triangulaires supérieures aléatoires.
!>
!>

Paramètres

NSIZES 
!>          NSIZES est de type INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il est nul,
!>          ZDRGES ne fait rien. NSIZES >= 0.
!>

NN

!>          NN est un tableau INTEGER, de dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs nulles ne sont pas autorisées.
!>

NTYPES

!>          NTYPES est de type INTEGER
!>          Le nombre de types de matrices à utiliser. Si NTYPES est nul,
!>          ZDRGEV ne fait rien. NTYPES >= 0.
!>

DOTYPE

!>          DOTYPE est un tableau LOGICAL, de dimension (NTYPES)
!>          Si DOTYPE(j) est .TRUE., alors le type de matrice j est testé.
!>

ISEED

!>          ISEED est un tableau INTEGER, de dimension (4)
!>          La graine du générateur de nombres aléatoires utilisé par ZDRGEV
!>          pour générer des matrices aléatoires. L'i-ème élément de ISEED
!>          est utilisé pour générer le j-ème nombre aléatoire pour chaque
!>          type de matrice. Il est mis à jour après chaque utilisation.
!>

THRESH

!>          THRESH est de type DOUBLE PRECISION
!>          Un seuil pour les tests de résidus. Si les résidus calculés
!>          sont supérieurs à THRESH, le test échoue.
!>

NOUNIT

!>          NOUNIT est de type INTEGER
!>          NOUNIT est un entier qui contrôle le calcul des vecteurs propres.
!>          Si NOUNIT = 0, alors les vecteurs propres gauches et droits sont calculés.
!>          Si NOUNIT = 1, seuls les vecteurs propres gauches sont calculés.
!>          Si NOUNIT = 2, seuls les vecteurs propres droits sont calculés.
!>          Si NOUNIT = 3, aucun vecteur propre n'est calculé.
!>

A

!>          A est de type COMPLEX*16, dimension (LDA, *)
!>          La matrice A dans le problème de valeurs propres généralisées.
!>

LDA

!>          LDA est de type INTEGER
!>          La longueur de ligne de la matrice A. LDA >= max(1, N) où N est la taille de la matrice.
!>

B

!>          B est de type COMPLEX*16, dimension (LDA, *)
!>          La matrice B dans le problème de valeurs propres généralisées.
!>

S

!>          S est de type COMPLEX*16, dimension (LDA, *)
!>          Matrice triangulaire supérieure utilisée dans certains types de matrices.
!>

T

!>          T est de type COMPLEX*16, dimension (LDA, *)
!>          Matrice triangulaire supérieure utilisée dans certains types de matrices.
!>

Q

!>          Q est de type COMPLEX*16, dimension (LDQ, *)
!>          Matrice orthogonale utilisée dans certains types de matrices.
!>

LDQ

!>          LDQ est de type INTEGER
!>          La longueur de ligne de la matrice Q. LDQ >= max(1, N).
!>

Z

!>          Z est de type COMPLEX*16, dimension (LDQ, *)
!>          Une autre matrice orthogonale utilisée dans certains types de matrices.
!>

QE

!>          QE est de type COMPLEX*16, dimension (LDQE, *)
!>          Matrice stockant les vecteurs propres gauches calculés par ZGGEV.
!>

LDQE

!>          LDQE est de type INTEGER
!>          La longueur de ligne de la matrice QE. LDQE >= max(1, N).
!>

ALPHA

!>          ALPHA est de type COMPLEX*16, dimension (*)
!>          Tableau stockant la partie alpha des valeurs propres généralisées.
!>

BETA

!>          BETA est de type COMPLEX*16, dimension (*)
!>          Tableau stockant la partie beta des valeurs propres généralisées.
!>

ALPHA1

!>          ALPHA1 est de type COMPLEX*16, dimension (*)
!>          Tableau utilisé pour stocker une partie des valeurs propres calculées.
!>

BETA1

!>          BETA1 est de type COMPLEX*16, dimension (*)
!>          Tableau utilisé pour stocker une partie des valeurs propres calculées.
!>

WORK

!>          WORK est de type COMPLEX*16, dimension (*)
!>          Tableau de travail pour le sous-programme ZGGEV. La taille minimale
!>          requise est stockée dans WORK(1) si LWORK est suffisamment grand.
!>

LWORK

!>          LWORK est de type INTEGER
!>          La taille du tableau de travail WORK. LWORK >= 1.
!>

RWORK

!>          RWORK est de type DOUBLE PRECISION, dimension (*)
!>          Tableau de travail pour les calculs en double précision.
!>

RESULT

!>          RESULT est de type DOUBLE PRECISION, dimension (*)
!>          Tableau stockant les résultats des différents tests effectués.
!>

INFO

!>          INFO est de type INTEGER
!>          INFO = 0: succès
!>          INFO < 0: un des paramètres d'entrée était invalide.
!>          INFO > 0: l'algorithme de ZGGEV a échoué à converger.
!>

Exemple d'utilisation

Ce sous-programme est principalement utilisé comme outil de test pour le sous-programme ZGGEV. Un exemple typique de son utilisation impliquerait de définir les paramètres NSIZES, NN, NTYPES, DOTYPE, ISEED, THRESH, NOUNIT, et de fournir des tableaux de travail suffisamment grands. Ensuite, le sous-programme ZDRGEV serait appelé. Les résultats seraient vérifiés en examinant le tableau RESULT et la valeur INFO.

Voici un exemple schématique :

      PROGRAM TEST_ZDRGEV
      IMPLICIT NONE

      INTEGER NSIZES, NTYPES, NOUNIT, LDA, LDQ, LDQE, LWORK, INFO
      PARAMETER (NSIZES = 2, NTYPES = 3, NOUNIT = 0, LDA = 10, LDQ = 10, LDQE = 10, LWORK = 1000)

      INTEGER NN(NSIZES), ISEED(4), RESULT(20)
      LOGICAL DOTYPE(NTYPES)

      COMPLEX*16 A(LDA, LDA), B(LDA, LDA), S(LDA, LDA), T(LDA, LDA)
      COMPLEX*16 Q(LDQ, LDQ), Z(LDQ, LDQ), QE(LDQE, LDQE)
      COMPLEX*16 ALPHA(LDA), BETA(LDA), ALPHA1(LDA), BETA1(LDA)
      COMPLEX*16 WORK(LWORK)

      DOUBLE PRECISION THRESH
      DOUBLE PRECISION RWORK(LWORK) ! Supposons que LWORK soit suffisant pour RWORK aussi

      ! Initialisation des paramètres
      NN(1) = 5
      NN(2) = 8
      DOTYPE(1) = .TRUE.
      DOTYPE(2) = .TRUE.
      DOTYPE(3) = .FALSE.
      ISEED(1) = 12345
      ISEED(2) = 67890
      ISEED(3) = 13579
      ISEED(4) = 24680
      THRESH = 1.0D-8
      NOUNIT = 0

      ! Appel de ZDRGEV
      CALL ZDRGEV(NSIZES, NN, NTYPES, DOTYPE, ISEED, THRESH, NOUNIT,
     &            A, LDA, B, S, T, Q, LDQ, Z, QE, LDQE,
     &            ALPHA, BETA, ALPHA1, BETA1, WORK, LWORK, RWORK, RESULT, INFO)

      ! Vérification des résultats
      IF (INFO .NE. 0) THEN
         PRINT *, 'ZDRGEV a retourné une erreur : ', INFO
      ELSE
         PRINT *, 'Tests ZDRGEV terminés avec succès.'
         ! Vous pouvez examiner le tableau RESULT ici pour voir les détails des tests
         PRINT *, 'Tableau RESULT :'
         DO I = 1, 20
            PRINT *, 'RESULT(', I, ') = ', RESULT(I)
         END DO
      END IF

      END PROGRAM TEST_ZDRGEV

Note : Cet exemple est simplifié. La dimensionnalité des matrices et la taille des tableaux de travail doivent être gérées correctement en fonction des besoins réels et des tailles spécifiées dans NN.

NAME

zdrgev - Tests the nonsymmetric eigenvalue routines.

SYNOPSIS

CALL ZDRGEV( >
                NTYPES, NSIZES, NN, DOTYPE, NSEED, THRESH, >
                NOUNIT, A, LDA, B, LDB, S, T, >
                Q, LDQ, Z, LDZ, QE, LDQE, ALPHA, BETA, >
                ALPHA1, BETA1, WORK, LWORK, RWORK, RESULT, INFO )

Function/Subroutine Documentation

NTYPES

!>          NTYPES is INTEGER
!>          The number of types of matrices to be generated.  MAXTYP types are
!>          defined.  If NTYPES is smaller than MAXTYP, then types NTYPES+1
!>          through MAXTYP will not be generated.  If NTYPES is larger than
!>          MAXTYP, then DOTYPE(MAXTYP+1) through DOTYPE(NTYPES) will be
!>          ignored.
!>          NTYPES must be at least 0.
!>

NSIZES

!>          NSIZES is INTEGER
!>          The number of matrix sizes to be generated.  If NSIZES is 1, then
!>          only size NN(1) is used.  If NSIZES is 2, then sizes NN(1) and
!>          NN(2) are used.  If NSIZES is 3, then sizes NN(1), NN(2), and
!>          NN(3) are used.
!>          NSIZES must be at least 1.
!>

NN

!>          NN is INTEGER array, dimension (NSIZES)
!>          The sizes of the matrices to be generated.  NN(i) must be at
!>          least 0.  If NN(i) is zero, then the matrix A is 0x0 and ZDRGEV
!>          skips the test. If NN(i) is not zero, the test will be performed.
!>

DOTYPE

!>          DOTYPE is LOGICAL array, dimension (NTYPES)
!>          If DOTYPE(j) is .TRUE., then for each size in NN a matrix
!>          of that size and of type j will be generated.
!>          If NTYPES is smaller than the maximum number of types
!>          defined (PARAMETER MAXTYP), then types NTYPES+1 through
!>          MAXTYP will not be generated. If NTYPES is larger
!>          than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
!>          will be ignored.
!>

NSEED

!>          NSEED is INTEGER array, dimension (4)
!>          On entry NSEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096. Also, NSEED(4) must
!>          be odd.  The random number generator uses a linear
!>          congruential sequence limited to small integers, and so
!>          should produce machine independent random numbers. The
!>          values of NSEED are changed on exit, and can be used in the
!>          next call to ZDRGEV to continue the same random number
!>          sequence.
!>

THRESH

!>          THRESH is DOUBLE PRECISION
!>          A test will count as failed if the relative error, computed as
!>          described above, exceeds THRESH.  Note that the error is
!>          scaled to be O(1), so THRESH should be a reasonably small
!>          multiple of 1, e.g., 10 or 100.  In particular, it should
!>          not depend on the precision (single vs. double) or the size
!>          of the matrix.  It must be at least zero.
!>

NOUNIT

!>          NOUNIT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns INFO not equal to 0.)
!>

A

!>          A is COMPLEX*16 array, dimension(LDA, max(NN))
!>          Used to hold the original A matrix.  Used as input only
!>          if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of A, B, S, and T.
!>          It must be at least 1 and at least max( NN ).
!>

B

!>          B is COMPLEX*16 array, dimension(LDA, max(NN))
!>          Used to hold the original B matrix.  Used as input only
!>          if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!>          S is COMPLEX*16 array, dimension (LDA, max(NN))
!>          The Schur form matrix computed from A by ZGEBAL. On exit, S
!>          contains the Schur form matrix corresponding to the matrix
!>          in A.
!>

T

!>          T is COMPLEX*16 array, dimension (LDA, max(NN))
!>          The upper triangular matrix computed from B by ZGEBAL.
!>

Q

!>          Q is COMPLEX*16 array, dimension (LDQ, max(NN))
!>          The (left) unitary matrix computed by ZGEBAL.
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of Q and Z. It must
!>          be at least 1 and at least max( NN ).
!>

Z

!>          Z is COMPLEX*16 array, dimension( LDQ, max(NN) )
!>          The (right) unitary matrix computed by ZGEBAL.
!>

QE

!>          QE is COMPLEX*16 array, dimension( LDQ, max(NN) )
!>          QE holds the computed right or left eigenvectors.
!>

LDQE

!>          LDQE is INTEGER
!>          The leading dimension of QE. LDQE >= max(1,max(NN)).
!>

ALPHA

!>          ALPHA is COMPLEX*16 array, dimension (max(NN))
!>

BETA

!>          BETA is COMPLEX*16 array, dimension (max(NN))
!>
!>          The generalized eigenvalues of (A,B) computed by ZGEEV.
!>          ( ALPHA(k) ) / BETA(k) is the k-th
!>          generalized eigenvalue of A and B.
!>

ALPHA1

!>          ALPHA1 is COMPLEX*16 array, dimension (max(NN))
!>

BETA1

!>          BETA1 is COMPLEX*16 array, dimension (max(NN))
!>
!>          Like ALPHA, BETA, these arrays contain the
!>          eigenvalues of A and B, but those computed when ZGEEV only
!>          computes a partial eigendecomposition, i.e. not the
!>          eigenvalues and left and right eigenvectors.
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>          The number of entries in WORK.  LWORK >= N*(N+1)
!>

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (8*N)
!>          Real workspace.
!>

RESULT

!>          RESULT is DOUBLE PRECISION array, dimension (2)
!>          The values computed by the tests described above.
!>          The values are currently limited to 1/ulp, to avoid overflow.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  A routine returned an error code.  INFO is the
!>                absolute value of the INFO value returned.
!>
