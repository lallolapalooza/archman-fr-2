Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .VRAI. ; si DOTYPE(j) = .FAUX., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau ENTIER, dimension (NN)
!>          Les valeurs de la dimension de matrice N.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de vecteurs de second membre à générer pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est un DOUBLE PRÉCISION
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque ratio de test soit imprimé, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est un LOGIQUE
!>          Indicateur indiquant si les sorties d'erreur doivent être testées.
!>

A

!>          A est un tableau COMPLEX*16, dimension (NMAX*2)
!>

D

!>          D est un tableau DOUBLE PRÉCISION, dimension (NMAX*2)
!>

E

!>          E est un tableau COMPLEX*16, dimension (NMAX*2)
!>

B

!>          B est un tableau COMPLEX*16, dimension (NMAX*NRHS)
!>

X

!>          X est un tableau COMPLEX*16, dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau COMPLEX*16, dimension (NMAX*NRHS)
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension
!>                      (NMAX*max(3,NRHS))
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (NMAX+2*NRHS)
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro d'unité pour la sortie.
!>
