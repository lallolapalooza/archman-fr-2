Objectif :

!>
!> ZDRVBD vérifie le pilote de décomposition en valeurs singulières (SVD) ZGESVD,
!> ZGESDD, ZGESVJ, ZGEJSV, ZGESVDX, et ZGESVDQ.
!>
!> ZGESVD et ZGESDD factorisent A = U diag(S) VT, où U et VT sont
!> unitaires et diag(S) est diagonale avec les éléments du tableau S sur
!> sa diagonale. Les éléments de S sont les valeurs singulières, non négatives
!> et stockées par ordre décroissant. U et VT peuvent optionnellement ne pas être
!> calculés, être écrasés sur A, ou être calculés partiellement.
!>
!> A est M par N. Soit MNMIN = min( M, N ). S a une dimension MNMIN.
!> U peut être M par M ou M par MNMIN. VT peut être N par N ou MNMIN par N.
!>
!> Lorsque ZDRVBD est appelé, un nombre de tailles de matrice (M et N)
!> et un nombre de types de matrice sont spécifiés. Pour chaque taille (M,N)
!> et chaque type de matrice, et pour l'espace de travail minimal ainsi que
!> pour un espace de travail adéquat pour permettre le blocage, une matrice
!> M x N sera générée et utilisée pour tester les routines SVD. Pour chaque matrice, A sera
!> factorisée en A = U diag(S) VT et les 12 tests suivants seront calculés :
!>
!> Test pour ZGESVD :
!>
!> (1)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (2)   | I - U'U | / ( M ulp )
!>
!> (3)   | I - VT VT' | / ( N ulp )
!>
!> (4)   S contient MNMIN valeurs non négatives par ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (5)   | U - Upartiel | / ( M ulp ) où Upartiel est un U calculé partiellement.
!>
!> (6)   | VT - VTpartiel | / ( N ulp ) où VTpartiel est un VT calculé partiellement.
!>
!> (7)   | S - Spartiel | / ( MNMIN ulp |S| ) où Spartiel est le
!>       vecteur des valeurs singulières de la SVD partielle
!>
!> Test pour ZGESDD :
!>
!> (8)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (9)   | I - U'U | / ( M ulp )
!>
!> (10)  | I - VT VT' | / ( N ulp )
!>
!> (11)  S contient MNMIN valeurs non négatives par ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (12)  | U - Upartiel | / ( M ulp ) où Upartiel est un U calculé partiellement.
!>
!> (13)  | VT - VTpartiel | / ( N ulp ) où VTpartiel est un VT calculé partiellement.
!>
!> (14)  | S - Spartiel | / ( MNMIN ulp |S| ) où Spartiel est le
!>       vecteur des valeurs singulières de la SVD partielle
!>
!> Test pour ZGESVDQ :
!>
!> (36)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (37)  | I - U'U | / ( M ulp )
!>
!> (38)  | I - VT VT' | / ( N ulp )
!>
!> (39)  S contient MNMIN valeurs non négatives par ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> Test pour ZGESVJ :
!>
!> (15)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (16)  | I - U'U | / ( M ulp )
!>
!> (17)  | I - VT VT' | / ( N ulp )
!>
!> (18)  S contient MNMIN valeurs non négatives par ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> Test pour ZGEJSV :
!>
!> (19)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (20)  | I - U'U | / ( M ulp )
!>
!> (21)  | I - VT VT' | / ( N ulp )
!>
!> (22)  S contient MNMIN valeurs non négatives par ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> Test pour ZGESVDX( 'V', 'V', 'A' )/ZGESVDX( 'N', 'N', 'A' )
!>
!> (23)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (24)  | I - U'U | / ( M ulp )
!>
!> (25)  | I - VT VT' | / ( N ulp )
!>
!> (26)  S contient MNMIN valeurs non négatives par ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (27)  | U - Upartiel | / ( M ulp ) où Upartiel est un U calculé partiellement.
!>
!> (28)  | VT - VTpartiel | / ( N ulp ) où VTpartiel est un VT calculé partiellement.
!>
!> (29)  | S - Spartiel | / ( MNMIN ulp |S| ) où Spartiel est le
!>       vecteur des valeurs singulières de la SVD partielle
!>
!> Test pour ZGESVDX( 'V', 'V', 'I' )
!>
!> (30)  | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (31)  | I - U'U | / ( M ulp )
!>
!> (32)  | I - VT VT' | / ( N ulp )
!>
!> Test pour ZGESVDX( 'V', 'V', 'V' )
!>
!> (33)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (34)   | I - U'U | / ( M ulp )
!>
!> (35)   | I - VT VT' | / ( N ulp )
!>
!> Les tailles de matrice (M et N) sont spécifiées par les tableaux MM(1:NSIZES) et
!> NN(1:NSIZES) ; la valeur de chaque paire d'éléments (MM(j),NN(j))
!> spécifie une taille. Les types de matrice sont spécifiés par un tableau logique
!> DOTYPE( 1:NTYPES ) ; si DOTYPE(j) est .VRAI., alors le type de matrice
!> j sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!> (3)  Une matrice de la forme U D V, où U et V sont unitaires et
!>      D a des entrées régulièrement espacées 1, ..., ULP avec des signes aléatoires
!>      sur la diagonale.
!> (4)  Identique à (3), mais multipliée par le seuil de sous-dépassement / ULP.
!> (5)  Identique à (3), mais multipliée par le seuil de dépassement * ULP.
!>

NAME


zdrvbd - test driver routine for ZGESVD






SYNOPSIS



SUBROUTINE ZDRVBD( NSIZES, NN, NMAX, NTYPES, MAXTYP, DOTYPE, NSEED,
                 THRESH, A, LDA, U, LDU, VT, LDVT, ASAV, USAV, VTSAV,
                 S, SSAV, E, WORK, LWORK, RWORK, IWORK, NOUNIT, INFO )



Parameters:




[in] NSIZES


INTEGER

The number of pairs of dimensions to be tested.


[in] NN


INTEGER array, dimension (NSIZES)

Specifies the sizes of the matrices to be tested.


[in] NMAX


INTEGER

The maximum value of NN(j) over all j.


[in] NTYPES


INTEGER

The number of types of matrices to be generated.


[in] MAXTYP


INTEGER

The maximum number of matrix types the driver can handle.


[in] DOTYPE


LOGICAL array, dimension (MAXTYP)

If DOTYPE(k) is true, then matrix type k will be generated and tested.


[in,out] NSEED


INTEGER array, dimension (4)

The seed for the random number generator. It is modified on output.


[in] THRESH


DOUBLE PRECISION

The threshold for the error tolerance.


[out] A


COMPLEX*16 array, dimension (LDA,max(NN))

The matrix whose singular values are to be computed.


[in] LDA


INTEGER

The leading dimension of A.


[out] U


COMPLEX*16 array, dimension (LDU,max(MM))

The matrix of right singular vectors.


[in] LDU


INTEGER

The leading dimension of U.


[out] VT


COMPLEX*16 array, dimension (LDVT,max(NN))

The matrix of left singular vectors.


[in] LDVT


INTEGER

The leading dimension of VT.


[out] ASAV


COMPLEX*16 array, dimension (LDA,max(NN))

A saved copy of matrix A.


[out] USAV


COMPLEX*16 array, dimension (LDU,max(MM))

A saved copy of matrix U.


[out] VTSAV


COMPLEX*16 array, dimension (LDVT,max(NN))

A saved copy of matrix VT.


[out] S


DOUBLE PRECISION array, dimension (max(min(MM,NN)))

The singular values of the matrix.


[out] SSAV


DOUBLE PRECISION array, dimension (max(min(MM,NN)))

A saved copy of the singular values.


[out] E


DOUBLE PRECISION array, dimension (max(min(MM,NN)))

Workspace for ZGESVD.


[out] WORK


COMPLEX*16 array, dimension (LWORK)


[in] LWORK


INTEGER

The size of the WORK array.


[out] RWORK


DOUBLE PRECISION array, dimension ( 5*max(max(MM,NN)) )


[out] IWORK


INTEGER array, dimension at least 8*min(M,N)


[in] NOUNIT


INTEGER

The FORTRAN unit number for printing error messages.


[out] INFO


INTEGER

The status of the operation.

NSIZES


!>          NSIZES is INTEGER
!>          The number of pairs of dimensions to be tested.



NN


!>          NN is INTEGER array, dimension (NSIZES)
!>          Specifies the sizes of the matrices to be tested.  Let NN(j) = M
!>          and then (M, N) = (MM(j), NN(j)) for j = 1, ..., NSIZES.
!>          The driver routine will attempt to test all pairs (MM(j), NN(j))
!>          for j = 1, ..., NSIZES.



NMAX


!>          NMAX is INTEGER
!>          The maximum value of NN(j) over all j.



NTYPES


!>          NTYPES is INTEGER
!>          The number of types of matrices to be generated.  This must be
!>          less than or equal to MAXTYP.  If NTYPES is less than MAXTYP,
!>          then types NTYPES+1 through MAXTYP will not be generated.  If
!>          NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1) through
!>          DOTYPE(NTYPES) will be ignored.



ISEED


!>          ISEED is INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096.  Also, ISEED(4) must
!>          be odd.  The random number generator uses a linear
!>          congruential sequence limited to small integers, and so
!>          should produce machine independent random numbers. The
!>          values of ISEED are changed on exit, and can be used in the
!>          next call to ZDRVBD to continue the same random number
!>          sequence.



THRESH


!>          THRESH is DOUBLE PRECISION
!>          A test will count as OK if the computed error, scaled as
!>          described above, is less than or equal to THRESH. Note that the error
!>          is scaled to be O(1), so THRESH should be a reasonably
!>          small multiple of 1, e.g., 10 or 100.  In particular,
!>          it should not depend on the precision (single vs. double)
!>          or the size of the matrix.  It must be at least zero.



A


!>          A is COMPLEX*16 array, dimension (LDA,max(NN))
!>          Used to hold the matrix whose singular values are to be
!>          computed.  On exit, A contains the last matrix actually
!>          used.



LDA


!>          LDA is INTEGER
!>          The leading dimension of A.  It must be at
!>          least 1 and at least max( MM ).



U


!>          U is COMPLEX*16 array, dimension (LDU,max(MM))
!>          Used to hold the computed matrix of right singular vectors.
!>          On exit, U contains the last such vectors actually computed.



LDU


!>          LDU is INTEGER
!>          The leading dimension of U.  It must be at
!>          least 1 and at least max( MM ).



VT


!>          VT is COMPLEX*16 array, dimension (LDVT,max(NN))
!>          Used to hold the computed matrix of left singular vectors.
!>          On exit, VT contains the last such vectors actually computed.



LDVT


!>          LDVT is INTEGER
!>          The leading dimension of VT.  It must be at
!>          least 1 and at least max( NN ).



ASAV


!>          ASAV is COMPLEX*16 array, dimension (LDA,max(NN))
!>          Used to hold a different copy of the matrix whose singular
!>          values are to be computed.  On exit, A contains the last
!>          matrix actually used.



USAV


!>          USAV is COMPLEX*16 array, dimension (LDU,max(MM))
!>          Used to hold a different copy of the computed matrix of
!>          right singular vectors. On exit, USAV contains the last such
!>          vectors actually computed.



VTSAV


!>          VTSAV is COMPLEX*16 array, dimension (LDVT,max(NN))
!>          Used to hold a different copy of the computed matrix of
!>          left singular vectors. On exit, VTSAV contains the last such
!>          vectors actually computed.



S


!>          S is DOUBLE PRECISION array, dimension (max(min(MM,NN)))
!>          Contains the computed singular values.



SSAV


!>          SSAV is DOUBLE PRECISION array, dimension (max(min(MM,NN)))
!>          Contains another copy of the computed singular values.



E


!>          E is DOUBLE PRECISION array, dimension (max(min(MM,NN)))
!>          Workspace for ZGESVD.



WORK


!>          WORK is COMPLEX*16 array, dimension (LWORK)



LWORK


!>          LWORK is INTEGER

!>          MAX(3*MIN(M,N)+MAX(M,N)**2,5*MIN(M,N),3*MAX(M,N)) for all
!>          pairs  (M,N)=(MM(j),NN(j))



RWORK


!>          RWORK is DOUBLE PRECISION array,
!>                      dimension ( 5*max(max(MM,NN)) )



IWORK


!>          IWORK is INTEGER array, dimension at least 8*min(M,N)



NOUNIT


!>          NOUNIT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns IINFO not equal to 0.)



INFO


!>          INFO is INTEGER
!>          If 0, then everything ran OK.
!>           -1: NSIZES < 0
!>           -2: Some MM(j) < 0
!>           -3: Some NN(j) < 0
!>           -4: NTYPES < 0
!>           -7: THRESH < 0
!>          -10: LDA < 1 or LDA < MMAX, where MMAX is max( MM(j) ).
