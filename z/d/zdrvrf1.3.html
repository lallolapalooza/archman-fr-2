Paramètres

NOUT 
!>          NOUT est un ENTIER
!>                Le numéro de l'unité pour la sortie.
!>

NN

!>          NN est un ENTIER
!>                Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau ENTIER, dimension (NN)
!>                Les valeurs de la dimension de matrice N.
!>

THRESH

!>          THRESH est un DOUBLE PRÉCISION
!>                La valeur seuil pour les ratios de test. Un résultat est
!>                inclus dans le fichier de sortie si RESULT >= THRESH. Pour
!>                imprimer tous les ratios de test, utiliser THRESH = 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,NMAX)
!>

LDA

!>          LDA est un ENTIER
!>                La dimension principale du tableau A. LDA >= max(1,NMAX).
!>

ARF

!>          ARF est un tableau COMPLEX*16, dimension ((NMAX*(NMAX+1))/2).
