subroutine zdrgev (nsizes, nn, ntypes, dotype, iseed, thresh, nounit, a, lda, b, s, t, q, ldq, z, qe, ldqe, alpha, beta, alpha1, beta1, work, lwork, rwork, result, info)

ZDRGEV

Purpose:

!>
!> ZDRGEV vérifie la routine du pilote du problème de valeurs propres généralisé non symétrique
!> ZGGEV.
!>
!> ZGGEV calcule pour une paire de matrices non symétriques n x n (A, B) les
!> valeurs propres généralisées et, éventuellement, les vecteurs propres gauches et droits.
!>
!> Une valeur propre généralisée pour une paire de matrices (A, B) est un scalaire w
!> ou un rapport alpha/beta = w, tel que A - wB soit singulier. Il est
!> généralement représenté par la paire (alpha, beta), car il y a une interprétation raisonnable
!> pour beta = 0, et même pour les deux étant nuls.
!>
!> Un vecteur propre généralisé droit correspondant à une valeur propre généralisée
!> w pour une paire de matrices (A, B) est un vecteur r tel que
!> (A - wB) * r = 0. Un vecteur propre généralisé gauche est un vecteur l tel que
!> l**H * (A - wB) = 0, où l**H est la transposée conjuguée de l.
!>
!> Lorsque ZDRGEV est appelé, un certain nombre de tailles de matrices () et un
!> certain nombre de types de matrices sont spécifiés. Pour chaque taille ()
!> et chaque type de matrice, une paire de matrices (A, B) sera générée
!> et utilisée pour les tests. Pour chaque paire de matrices, les tests suivants
!> seront effectués et comparés au seuil THRESH.
!>
!> Résultats de ZGGEV :
!>
!> (1) max sur toutes les paires de valeurs propres/vecteurs propres gauches (alpha/beta,l) de
!>
!>     | VL**H * (beta A - alpha B) | / ( ulp max(|beta A|, |alpha B|) )
!>
!>     où VL**H est la transposée conjuguée de VL.
!>
!> (2) | |VL(i)| - 1 | / ulp et si le plus grand composant est réel
!>
!>     VL(i) désigne la i-ème colonne de VL.
!>
!> (3) max sur toutes les paires de valeurs propres/vecteurs propres gauches (alpha/beta,r) de
!>
!>     | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4) | |VR(i)| - 1 | / ulp et si le plus grand composant est réel
!>
!>     VR(i) désigne la i-ème colonne de VR.
!>
!> (5) W(full) = W(partial)
!>     W(full) désigne les valeurs propres calculées lorsque l et r
!>     sont également calculés, et W(partial) désigne les valeurs propres
!>     calculées lorsque seuls W, seulement W et r, ou seulement W et l sont
!>     calculés.
!>
!> (6) VL(full) = VL(partial)
!>     VL(full) désigne les vecteurs propres gauches calculés lorsque l et r
!>     sont calculés, et VL(partial) désigne le résultat
!>     lorsque seul l est calculé.
!>
!> (7) VR(full) = VR(partial)
!>     VR(full) désigne les vecteurs propres droits calculés lorsque l et r
!>     sont également calculés, et VR(partial) désigne le résultat
!>     lorsque seul l est calculé.
!>
!>
!> Matrices de Test
!> ---- --------
!>
!> Les tailles des matrices de test sont spécifiées par un tableau
!> NN(1:NSIZES); la valeur de chaque élément NN(j) spécifie une taille.
!> Les types de matrices sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) est .TRUE., alors le type de matrice j sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1) (0, 0) (une paire de matrices zéro)
!>
!> (2) (I, 0) (une matrice identité et une matrice zéro)
!>
!> (3) (0, I) (une matrice zéro et une matrice identité)
!>
!> (4) (I, I) (une paire de matrices identité)
!>
!>         t   t
!> (5) ( J , J  ) (une paire de blocs de Jordan transposés)
!>
!>                                     t                ( I   0  )
!> (6) ( X, Y ) où  X = ( J   0  )  et Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       et I est une identité k x k et J un bloc de Jordan (k+1)x(k+1); k=(N-1)/2
!>
!> (7) ( D, I ) où D est diag(0, 1,..., N-1) (une matrice diagonale avec ces entrées diagonales.)
!> (8) ( I, D )
!>
!> (9) ( big*D, small*I ) où big est proche de l'overflow et small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 ) où D1 est diag(0, 0, 1, ..., N-3, 0) et
!>                        D2 est diag(0, N-3, N-4,..., 1, 0, 0)
!>           t   t
!> (16) Q ( J , J ) Z     où Q et Z sont des matrices orthogonales aléatoires.
!>
!> (17) Q ( T1, T2 ) Z    où T1 et T2 sont des matrices triangulaires supérieures
!>                        avec des entrées aléatoires O(1) au-dessus de la diagonale
!>                        et des entrées diagonales diag(T1) =
!>                        (0, 0, 1, ..., N-3, 0) et diag(T2) =
!>                        (0, N-3, N-4,..., 1, 0, 0)
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = (0, 0, 1, 1, s, ..., s, 0)
!>                        diag(T2) = (0, 1, 0, 1,..., 1, 0)
!>                        s = précision machine.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=(0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0)
!>                        diag(T2) = (0, 1, 0, 1, ..., 1, 0)
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=(0, 0, 1, 1, a, ..., a   =s, 0)
!>                        diag(T2) = (0, 1, 0, 1, ..., 1, 0, 0)
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=(0, 0, 1, r1, r2, ..., r(N-4), 0)
!>                        diag(T2) = (0, 1, 0, 1, ..., 1, 0, 0)
!>                        où r1,..., r(N-4) sont aléatoires.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = (0, 0, 1, ..., N-3, 0)
!>                                  diag(T2) = (0, 1, ..., 1, 0, 0)
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = (0, 0, 1, ..., N-3, 0)
!>                                  diag(T2) = (0, 1, ..., 1, 0, 0)
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = (0, 0, 1, ..., N-3, 0)
!>                                  diag(T2) = (0, 1, ..., 1, 0, 0)
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = (0, 0, 1, ..., N-3, 0)
!>                                  diag(T2) = (0, 1, ..., 1, 0, 0)
!>
!> (26) Q ( T1, T2 ) Z     où T1 et T2 sont des matrices triangulaires supérieures aléatoires.
!>
!>

Parameters

NSIZES 
!>          NSIZES est un entier
!>          Le nombre de tailles de matrices à utiliser. S'il est zéro,
!>          ZDRGES ne fait rien. NSIZES >= 0.
!>

NN

!>          NN est un tableau d'entiers, dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs de NN doivent être comprises entre 0 et N (où N est la
!>          plus grande taille autorisée pour les matrices).
!>

NTYPES

!>          NTYPES est un entier
!>          Le nombre de types de matrices à tester. S'il est zéro, ZDRGEV
!>          ne fait rien. NTYPES >= 0.
!>

DOTYPE

!>          DOTYPE est un tableau logique, dimension (NTYPES)
!>          Si DOTYPE(j) est .TRUE., alors le j-ème type de matrice sera
!>          testé. Si NTYPES est zéro, DOTYPE n'est pas référencé.
!>

ISEED

!>          ISEED est un tableau d'entiers, dimension (4)
!>          Les valeurs initiales du générateur de nombres aléatoires. Il est modifié
!>          par le programme.
!>

THRESH

!>          THRESH est un double précision
!>          Une valeur de seuil pour les tests. Les résultats des tests sont considérés
!>          comme une réussite si leur valeur est inférieure ou égale à THRESH.
!>

NOUNIT

!>          NOUNIT est un entier
!>          Si NOUNIT est égal à zéro, alors les matrices unitaires sont générées
!>          (pour les types 16, 22-26). Sinon, les matrices unitaires ne sont pas
!>          générées et les matrices A et B sont utilisées directement.
!>

A

!>          A est un tableau complex*16, dimension (LDA, N)
!>          La première matrice d'une paire (A,B).
!>

LDA

!>          LDA est un entier
!>          La longueur de la première dimension de A et B. LDA >= max(1, N).
!>

B

!>          B est un tableau complex*16, dimension (LDA, N)
!>          La deuxième matrice d'une paire (A,B).
!>

S

!>          S est un tableau complex*16, dimension (LDA, N)
!>          Matrice de gauche (VL) ou droite (VR).
!>

T

!>          T est un tableau complex*16, dimension (LDA, N)
!>          Matrice de gauche (VL) ou droite (VR).
!>

Q

!>          Q est un tableau complex*16, dimension (LDQ, N)
!>          Matrice de gauche (VL) ou droite (VR).
!>

LDQ

!>          LDQ est un entier
!>          La longueur de la première dimension de Q et Z. LDQ >= max(1, N).
!>

Z

!>          Z est un tableau complex*16, dimension (LDQ, N)
!>          Matrice de gauche (VL) ou droite (VR).
!>

QE

!>          QE est un tableau complex*16, dimension (LDQE, N)
!>          Matrice de gauche (VL) ou droite (VR).
!>

LDQE

!>          LDQE est un entier
!>          La longueur de la première dimension de QE. LDQE >= max(1, N).
!>

ALPHA

!>          ALPHA est un tableau complex*16, dimension (N)
!>          Les numérateurs des valeurs propres généralisées (alpha/beta).
!>

BETA

!>          BETA est un tableau complex*16, dimension (N)
!>          Les dénominateurs des valeurs propres généralisées (alpha/beta).
!>

ALPHA1

!>          ALPHA1 est un tableau complex*16, dimension (N)
!>          Les numérateurs des valeurs propres généralisées (alpha/beta) calculés
!>          avec les vecteurs propres gauches et droits calculés.
!>

BETA1

!>          BETA1 est un tableau complex*16, dimension (N)
!>          Les dénominateurs des valeurs propres généralisées (alpha/beta) calculés
!>          avec les vecteurs propres gauches et droits calculés.
!>

WORK

!>          WORK est un tableau complex*16, dimension (LWORK)
!>          Zone de travail.
!>

LWORK

!>          LWORK est un entier
!>          La taille de la zone de travail WORK. LWORK doit être suffisamment grand
!>          pour contenir toutes les informations requises par ZGGEV.
!>

RWORK

!>          RWORK est un tableau double précision, dimension (N)
!>          Zone de travail réelle.
!>

RESULT

!>          RESULT est un tableau double précision, dimension (21)
!>          Les résultats des 21 tests effectués par ZDRGEV.
!>

INFO

!>          INFO est un entier
!>          INFO = 0: succès
!>          INFO < 0: un des paramètres d'entrée invalides
!>          INFO > 0: un des sous-programmes ZGGEV a retourné un code d'erreur
!>                  spécifique. Voir la documentation de ZGGEV pour plus de détails.
!>

Documentation de la fonction/sous-routine

NTYPES

!>          NTYPES est un entier.
!>          Le nombre d'éléments dans DOTYPE. S'il est égal à zéro, ZDRGEV
!>          ne fait rien. Il doit être supérieur ou égal à zéro. S'il est égal à MAXTYP+1
!>          et que NSIZES est égal à 1, alors un type supplémentaire, MAXTYP+1, est
!>          défini, qui consiste à utiliser la matrice présente dans A. Ceci
!>          n'est utile que si DOTYPE(1:MAXTYP) est .FAUX. et
!>          DOTYPE(MAXTYP+1) est .VRAI. .
!>

DOTYPE

!>          DOTYPE est un tableau logique, de dimension (NTYPES)
!>          Si DOTYPE(j) est .VRAI., alors pour chaque taille dans NN, une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximum de types
!>          définis (PARAMÈTRE MAXTYP), alors les types NTYPES+1 jusqu'à
!>          MAXTYP ne seront pas générés. Si NTYPES est supérieur
!>          à MAXTYP, DOTYPE(MAXTYP+1) jusqu'à DOTYPE(NTYPES)
!>          seront ignorés.
!>

ISEED

!>          ISEED est un tableau entier, de dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une séquence
!>          linéaire congruente limitée à de petits entiers et devrait produire des nombres
!>          aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie et peuvent être utilisées dans l'appel
!>          suivant à ZDRGES pour continuer la même séquence de nombres
!>          aléatoires.
!>

THRESH

!>          THRESH est un double précision.
!>          Un test sera comptabilisé comme si le , calculé comme
!>          décrit ci-dessus, dépassait THRESH. Notez que l'erreur est
!>          normalisée pour être de O(1), donc THRESH devrait être un multiple raisonnablement petit
!>          de 1, par exemple, 10 ou 100. En particulier, il ne devrait pas
!>          dépendre de la précision (simple ou double) ou de la taille
!>          de la matrice. Il doit être supérieur ou égal à zéro.
!>

NOUNIT

!>          NOUNIT est un entier.
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (par exemple, si une routine renvoie IERR différent de 0).
!>

A

!>          A est un tableau COMPLEX*16, de dimension(LDA, max(NN))
!>          Utilisé pour contenir la matrice A d'origine. Utilisé en entrée uniquement
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FAUX., et
!>          DOTYPE(MAXTYP+1)=.VRAI.
!>

LDA

!>          LDA est un entier.
!>          La dimension principale de A, B, S et T.
!>          Elle doit être supérieure ou égale à 1 et au moins égale à max( NN ).
!>

B

!>          B est un tableau COMPLEX*16, de dimension(LDA, max(NN))
!>          Utilisé pour contenir la matrice B d'origine. Utilisé en entrée uniquement
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FAUX., et
!>          DOTYPE(MAXTYP+1)=.VRAI.
!>

S

!>          S est un tableau COMPLEX*16, de dimension (LDA, max(NN))
!>          La matrice de forme de Schur calculée à partir de A par ZGGEV. À la sortie, S
!>          contient la matrice de forme de Schur correspondant à la matrice
!>          dans A.
!>

T

!>          T est un tableau COMPLEX*16, de dimension (LDA, max(NN))
!>          La matrice triangulaire supérieure calculée à partir de B par ZGGEV.
!>

Q

!>          Q est un tableau COMPLEX*16, de dimension (LDQ, max(NN))
!>          La matrice des vecteurs propres (gauche) calculée par ZGGEV.
!>

LDQ

!>          LDQ est un entier.
!>          La dimension principale de Q et Z. Elle doit
!>          être supérieure ou égale à 1 et au moins égale à max( NN ).
!>

Z

!>          Z est un tableau COMPLEX*16, de dimension( LDQ, max(NN) )
!>          La matrice orthogonale (droite) calculée par ZGGEV.
!>

QE

!>          QE est un tableau COMPLEX*16, de dimension( LDQ, max(NN) )
!>          QE contient les vecteurs propres droits ou gauches calculés.
!>

LDQE

!>          LDQE est un entier.
!>          La dimension principale de QE. LDQE >= max(1,max(NN)).
!>

ALPHA

!>          ALPHA est un tableau COMPLEX*16, de dimension (max(NN))
!>

BETA

!>          BETA est un tableau COMPLEX*16, de dimension (max(NN))
!>
!>          Les valeurs propres généralisées de (A,B) calculées par ZGGEV.
!>          ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) est la k-ième
!>          valeur propre généralisée de A et B.
!>

ALPHA1

!>          ALPHA1 est un tableau COMPLEX*16, de dimension (max(NN))
!>

BETA1

!>          BETA1 est un tableau COMPLEX*16, de dimension (max(NN))
!>
!>          Comme ALPHAR, ALPHAI, BETA, ces tableaux contiennent les
!>          valeurs propres de A et B, mais celles calculées lorsque ZGGEV calcule seulement
!>          une décomposition propre partielle, c'est-à-dire pas les
!>          valeurs propres et les vecteurs propres gauches et droits.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est un entier.
!>          Le nombre d'entrées dans WORK. LWORK >= N*(N+1)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (8*N)
!>          Espace de travail réel.
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, de dimension (2)
!>          Les valeurs calculées par les tests décrits ci-dessus.
!>          Les valeurs sont actuellement limitées à 1/ulp, pour éviter le débordement.
!>

INFO

!>          INFO est un entier.
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : une routine a renvoyé un code d'erreur. INFO est la valeur
!>                absolue de la valeur INFO renvoyée.
!>
