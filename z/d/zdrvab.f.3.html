Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, de dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .TRUE. ; si DOTYPE(j) = .FALSE., alors le type j n'est pas utilisé.
!>

NM

!>          NM est un INTEGER
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau INTEGER, de dimension (NM)
!>          Les valeurs de la dimension de ligne de matrice M.
!>

NNS

!>          NNS est un INTEGER
!>          Le nombre de valeurs de NRHS contenues dans le vecteur NSVAL.
!>

NSVAL

!>          NSVAL est un tableau INTEGER, de dimension (NNS)
!>          Les valeurs du nombre de côtés droits NRHS.
!>

THRESH

!>          THRESH est un DOUBLE PRECISION
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.
!>

NMAX

!>          NMAX est un INTEGER
!>          La valeur maximale autorisée pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

AFAC

!>          AFAC est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

B

!>          B est un tableau COMPLEX*16, de dimension (NMAX*NSMAX)
!>          où NSMAX est la plus grande entrée de NSVAL.
!>

X

!>          X est un tableau COMPLEX*16, de dimension (NMAX*NSMAX)
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension
!>                      (NMAX*max(3,NSMAX*2))
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension
!>                      NMAX
!>

SWORK

!>          SWORK est un tableau COMPLEX, de dimension
!>                      (NMAX*(NSMAX+NMAX))
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension
!>                      NMAX
!>

NOUT

!>          NOUT est un INTEGER
!>          Le numéro d'unité pour la sortie.
!>
