Documentation de la fonction/sous-routine

sous-routine zdrvpp (logique, dimension( * ) dotype, entier nn, entier, dimension( * ) nval, entier nrhs, double précision thresh, logique tsterr, entier nmax, complexe*16, dimension( * ) a, complexe*16, dimension( * ) afac, complexe*16, dimension( * ) asav, complexe*16, dimension( * ) b, complexe*16, dimension( * ) bsav, complexe*16, dimension( * ) x, complexe*16, dimension( * ) xact, double précision, dimension( * ) s, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier nout)

ZDRVPP

Objectif :

!>
!> ZDRVPP teste les routines de pilote ZPPSV et -SVX.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .VRAI. ; si DOTYPE(j) = .FAUX., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau ENTIER, dimension (NN)
!>          Les valeurs de la dimension N de la matrice.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de vecteurs de second membre à générer pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est une DOUBLE PRÉCISION
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour
!>          imprimer tous les ratios de test, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est un LOGIQUE
!>          Indicateur qui détermine si les sorties d'erreur doivent être testées.
!>

NMAX

!>          NMAX est un ENTIER
!>          La valeur maximale autorisée pour N, utilisée pour dimensionner les
!>          tableaux de travail.
!>

A

!>          A est un tableau COMPLEX*16, dimension (NMAX*(NMAX+1)/2)
!>

AFAC

!>          AFAC est un tableau COMPLEX*16, dimension (NMAX*(NMAX+1)/2)
!>

ASAV

!>          ASAV est un tableau COMPLEX*16, dimension (NMAX*(NMAX+1)/2)
!>

B

!>          B est un tableau COMPLEX*16, dimension (NMAX*NRHS)
!>

BSAV

!>          BSAV est un tableau COMPLEX*16, dimension (NMAX*NRHS)
!>

X

!>          X est un tableau COMPLEX*16, dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau COMPLEX*16, dimension (NMAX*NRHS)
!>

S

!>          S est un tableau DOUBLE PRÉCISION, dimension (NMAX)
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension
!>                      (NMAX*max(3,NRHS))
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (NMAX+2*NRHS)
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro d'unité pour la sortie.
!>
