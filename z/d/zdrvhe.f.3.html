Documentation de la fonction/sous-programme

sous-programme zdrvhe (logique, dimension( * ) dotype, entier nn, entier, dimension( * ) nval, entier nrhs, double précision thresh, logique tsterr, entier nmax, complexe*16, dimension( * ) a, complexe*16, dimension( * ) afac, complexe*16, dimension( * ) ainv, complexe*16, dimension( * ) b, complexe*16, dimension( * ) x, complexe*16, dimension( * ) xact, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier, dimension( * ) iwork, entier nout)

ZDRVHE

But :

!>
!> ZDRVHE teste les routines de pilote ZHESV et -SVX.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .TRUE. ; si DOTYPE(j) = .FALSE., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau ENTIER, dimension (NN)
!>          Les valeurs de la dimension de matrice N.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de vecteurs de droite à générer pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est une DOUBLE PRÉCISION
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour
!>          avoir chaque rapport de test imprimé, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est LOGIQUE
!>          Indicateur qui signale si les sorties d'erreur doivent être testées.
!>

NMAX

!>          NMAX est un ENTIER
!>          La valeur maximale autorisée pour N, utilisée pour dimensionner les
!>          tableaux de travail.
!>

A

!>          A est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

AFAC

!>          AFAC est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

AINV

!>          AINV est un tableau COMPLEX*16, dimension (NMAX*NMAX)
!>

B

!>          B est un tableau COMPLEX*16, dimension (NMAX*NRHS)
!>

X

!>          X est un tableau COMPLEX*16, dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau COMPLEX*16, dimension (NMAX*NRHS)
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (NMAX*max(2,NRHS))
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (NMAX+2*NRHS)
!>

IWORK

!>          IWORK est un tableau ENTIER, dimension (NMAX)
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro de l'unité pour la sortie.
!>
