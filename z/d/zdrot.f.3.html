Documentation de la fonction/sous-programme

sous-programme zdrot (integer n, complex*16, dimension( * ) zx, integer incx, complex*16, dimension( * ) zy, integer incy, double precision c, double precision s)

ZDROT

But:

!>
!> Applique une rotation de plan, où le cosinus et le sinus (c et s) sont réels
!> et les vecteurs cx et cy sont complexes.
!> jack dongarra, linpack, 3/11/78.
!>

Paramètres

N 
!>          N est un ENTIER
!>           À l'entrée, N spécifie l'ordre des vecteurs cx et cy.
!>           N doit être supérieur ou égal à zéro.
!>

ZX

!>          ZX est un tableau COMPLEX*16, de dimension au moins
!>           ( 1 + ( N - 1 )*abs( INCX ) ).
!>           Avant l'entrée, le tableau incrémenté ZX doit contenir les n
!>           éléments du vecteur cx. À la sortie, ZX est écrasé par le vecteur
!>           mis à jour cx.
!>

INCX

!>          INCX est un ENTIER
!>           À l'entrée, INCX spécifie l'incrément pour les éléments de
!>           ZX. INCX ne doit pas être nul.
!>

ZY

!>          ZY est un tableau COMPLEX*16, de dimension au moins
!>           ( 1 + ( N - 1 )*abs( INCY ) ).
!>           Avant l'entrée, le tableau incrémenté ZY doit contenir les n
!>           éléments du vecteur cy. À la sortie, ZY est écrasé par le vecteur
!>           mis à jour cy.
!>

INCY

!>          INCY est un ENTIER
!>           À l'entrée, INCY spécifie l'incrément pour les éléments de
!>           ZY. INCY ne doit pas être nul.
!>

C

!>          C est un DOUBLE PRÉCISION
!>           À l'entrée, C spécifie le cosinus, cos.
!>

S

!>          S est un DOUBLE PRÉCISION
!>           À l'entrée, S spécifie le sinus, sin.
!>
