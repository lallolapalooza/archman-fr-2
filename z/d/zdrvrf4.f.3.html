Documentation de fonction/sous-programme

sous-programme zdrvrf4 (entier nout, entier nn, entier, dimension( nn ) nval, double précision thresh, complexe*16, dimension( ldc, * ) c1, complexe*16, dimension( ldc, *) c2, entier ldc, complexe*16, dimension( * ) crf, complexe*16, dimension( lda, * ) a, entier lda, double précision, dimension( * ) d_work_zlange)

ZDRVRF4

Objectif :

!>
!> ZDRVRF4 teste les routines RFP de LAPACK :
!>     ZHFRK
!>

Paramètres

NOUT 
!>          NOUT est un ENTIER
!>                Le numéro d'unité pour la sortie.
!>

NN

!>          NN est un ENTIER
!>                Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, dimensionné (NN)
!>                Les valeurs de la dimension N de la matrice.
!>

THRESH

!>          THRESH est de type DOUBLE PRÉCISION
!>                La valeur seuil pour les rapports de test. Un résultat est
!>                inclus dans le fichier de sortie si RESULTAT >= SEUIL. Pour imprimer
!>                chaque rapport de test, utiliser SEUIL = 0.
!>

C1

!>          C1 est un tableau de COMPLEXES*16, dimensionné (LDC,NMAX)
!>

C2

!>          C2 est un tableau de COMPLEXES*16, dimensionné (LDC,NMAX)
!>

LDC

!>          LDC est un ENTIER
!>                La dimension principale du tableau A. LDA >= max(1,NMAX).
!>

CRF

!>          CRF est un tableau de COMPLEXES*16, dimensionné ((NMAX*(NMAX+1))/2).
!>

A

!>          A est un tableau de COMPLEXES*16, dimensionné (LDA,NMAX)
!>

LDA

!>          LDA est un ENTIER
!>                La dimension principale du tableau A. LDA >= max(1,NMAX).
!>

D_WORK_ZLANGE

!>          D_WORK_ZLANGE est un tableau de DOUBLE PRÉCISION, dimensionné (NMAX)
!>
