Objectif:

!>
!> ZDRVRFP teste les routines RFP de LAPACK:
!>     ZPFTRF, ZPFTRS, et ZPFTRI.
!>
!> Cette routine de test suit les mêmes tests que ZDRVPO (test du solveur
!> symétrique défini positif au format complet).
!>
!> Les tests sont effectués au format complet, la conversion de et vers
!> le format RFP est effectuée à l'aide des routines ZTRTTF et
!> ZTFTTR.
!>
!> Tout d'abord, une matrice A spécifique de taille N est créée. Il existe neuf types
!> de matrices différentes possibles.
!>  1. Diagonale                        6. Aléatoire, CNDNUM = sqrt(0.1/EPS)
!>  2. Aléatoire, CNDNUM = 2              7. Aléatoire, CNDNUM = 0.1/EPS
!> *3. Première ligne et colonne nulles   8. Sous-flux mis à l'échelle
!> *4. Dernière ligne et colonne nulles   9. Dépassement de capacité mis à l'échelle
!> *5. Ligne et colonne du milieu nulles
!> (* - teste les sorties d'erreur de ZPFTRF, aucun ratio de test n'est calculé)
!> Une solution XACT de taille N-par-NRHS est créée ainsi que le membre de droite
!> associé B. Ensuite, ZPFTRF est appelée pour calculer L (ou U), le
!> facteur de Cholesky de A. Ensuite, L (ou U) est utilisé pour résoudre le système
!> linéaire d'équations AX = B. Cela donne X. Ensuite, L (ou U) est utilisé pour calculer
!> l'inverse de A, AINV. Les quatre tests suivants sont alors effectués:
!> (1) norm( L*L' - A ) / ( N * norm(A) * EPS ) ou
!>     norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> (2) norm(B - A*X) / ( norm(A) * norm(X) * EPS ),
!> (3) norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> (4) ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS ),
!> où EPS est la précision de la machine, RCOND le nombre de conditionnement de A, et
!> norm( . ) la norme 1 pour (1,2,3) et la norme inf pour (4).
!> Des erreurs se produisent lorsque le paramètre INFO n'est pas celui attendu. Des échecs
!> se produisent lorsque le ratio de test est supérieur à THRES.
!>
