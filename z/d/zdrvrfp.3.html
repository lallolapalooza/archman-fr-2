ZDRVRFP

Objectif :

!>
!> ZDRVRFP teste les sous-programmes RFP de LAPACK :
!>     ZPFTRF, ZPFTRS, et ZPFTRI.
!>
!> Cette routine de test suit les mêmes tests que ZDRVPO (test pour le solveur
!> symétrique défini positif au format complet).
!>
!> Les tests sont effectués au format complet, la conversion aller-retour
!> du format complet au format RFP est effectuée en utilisant les sous-programmes
!> ZTRTTF et ZTFTTR.
!>
!> Premièrement, une matrice A spécifique de taille N est créée. Il existe neuf types
!> de matrices différentes possibles.
!>  1. Diagonale                        6. Aléatoire, CNDNUM = sqrt(0.1/EPS)
!>  2. Aléatoire, CNDNUM = 2              7. Aléatoire, CNDNUM = 0.1/EPS
!> *3. Première ligne et colonne à zéro       8. Scalée proche du sous-dépassement
!> *4. Dernière ligne et colonne à zéro      9. Scalée proche du dépassement
!> *5. Ligne et colonne du milieu à zéro
!> (* - teste les sorties d'erreur de ZPFTRF, aucun ratio de test n'est calculé)
!> Une solution XACT de taille N-par-NRHS est créée et le membre de droite B
!> associé également. Ensuite, ZPFTRF est appelée pour calculer L (ou U), le
!> facteur de Cholesky de A. Ensuite, L (ou U) est utilisé pour résoudre le système
!> linéaire d'équations AX = B. Cela donne X. Ensuite, L (ou U) est utilisé pour calculer
!> l'inverse de A, AINV. Les quatre tests suivants sont alors effectués :
!> (1) norm( L*L' - A ) / ( N * norm(A) * EPS ) ou
!>     norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> (2) norm(B - A*X) / ( norm(A) * norm(X) * EPS ),
!> (3) norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> (4) ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS ),
!> où EPS est la précision machine, RCOND le nombre de condition de A, et
!> norm( . ) est la norme 1 pour (1,2,3) et la norme infini pour (4).
!> Des erreurs se produisent lorsque le paramètre INFO n'est pas celui attendu. Des échecs
!> se produisent lorsque le ratio de test est supérieur à THRES.
!>

NAME

zdrvrfp - double precision general driver routine

SYNOPSIS

SUBROUTINE ZDRVRFP(NI, NJ, NL, NR, A, LDA, B, LDB, C, LDC, D, LDD, WORK, LDWORK, INFO)

Function/Subroutine Documentation

ZDRVRFP is a double precision general driver routine that calls the various LAPACK routines that compute the Schur decomposition of a general matrix A and/or the Schur decomposition of a general matrix pair (A, B).

The following is a list of all the LAPACK routines that ZDRVRFP can call:

  • ZGECON: estimate the condition number of a general matrix.
  • ZGELSD: solve a general least squares problem using the singular value decomposition.
  • ZGEEV: compute the eigenvalues and eigenvectors of a general matrix.
  • ZGEQRF: compute the QR factorization of a general rectangular matrix.
  • ZGELQF: compute the LQ factorization of a general rectangular matrix.
  • ZGESVD: compute the singular value decomposition of a general rectangular matrix.
  • ZGELSX: solve the general least squares problem using QR or LQ factorization.
  • ZGESVX: solve the general system of linear equations AX = B, and compute the solution in terms of the L-in- verse of A.
  • ZGETRF: compute the LRF factorization of a general rectangular matrix.
  • ZGETRI: compute the inverse of a general rectangular matrix.
  • ZPORFS: refines the solution of a system of linear equations AX = B, where A is symmetric positive definite.
  • ZPOSV: solve a symmetric positive definite system of linear equations AX = B.
  • ZPPSV: solve a symmetric positive definite system of linear equations AX = B, where A is stored in packed format.
  • ZPBTRF: compute the Cholesky factorization of a symmetric positive definite band matrix.
  • ZPBTRS: solve a symmetric positive definite system of linear equations AX = B, where A is a band matrix.
  • ZGBTRF: compute the LRF factorization of a general band matrix.
  • ZGBTRS: solve a general system of linear equations AX = B, where A is a band matrix.
  • ZTRTRI: compute the inverse of an upper or lower triangular matrix.
  • ZTBSVX: solve a triangular system of linear equations AX = B, where A is a triangular band matrix.
  • ZTRSNA: compute the condition number of a triangular matrix.
  • ZTRSV: solve a triangular system of linear equations AX = B.
  • ZTBMV: multiply a triangular band matrix by a vector.
  • ZTRRFS: refines the solution of a triangular system of linear equations AX = B.
  • ZLATSY: generate a random symmetric or non-symmetric matrix.
  • ZLATBS: generate a random triangular band matrix.
  • ZGEEQU: compute the equilibrium scaling factors for a general matrix.
  • ZHEEQU: compute the equilibrium scaling factors for a Hermitian matrix.
  • ZSYEQU: compute the equilibrium scaling factors for a symmetric matrix.
  • ZLASCL: scale a general matrix.
  • ZLACON: estimate the norm of a general matrix.
  • ZLACN: estimate the norm of a general matrix.
  • ZLAQSY: scale a symmetric matrix.
  • ZLAQHE: scale a Hermitian matrix.
  • ZLAQGE: scale a general matrix.
  • ZLAQRT: generate a random triangular matrix.
  • ZLACRT: generate a random triangular matrix.
  • ZLATRD: reduce a general matrix to a symmetric or Hermitian tridiagonal form.
  • ZLARRF: generate a random orthogona_l matrix.
  • ZLARRV: generate a random orthogona_l matrix.
  • ZLARRUD: generate a random orthogona_l matrix.
  • ZLARRF: generate a random orthogona_l matrix.
