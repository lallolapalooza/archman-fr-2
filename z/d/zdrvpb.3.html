Documentation de la fonction/sous-routine

sous-routine zdrvpb (logical, dimension( * ) dotype, integer nn, integer, dimension( * ) nval, integer nrhs, double precision thresh, logical tsterr, integer nmax, complex*16, dimension( * ) a, complex*16, dimension( * ) afac, complex*16, dimension( * ) asav, complex*16, dimension( * ) b, complex*16, dimension( * ) bsav, complex*16, dimension( * ) x, complex*16, dimension( * ) xact, double precision, dimension( * ) s, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer nout)

ZDRVPB

Objectif :

!>
!> ZDRVPB teste les routines de pilotage ZPBSV et -SVX.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGICAL, de dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .TRUE. ; si DOTYPE(j) = .FALSE., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un entier
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'entiers, de dimension (NN)
!>          Les valeurs de la dimension N de la matrice.
!>

NRHS

!>          NRHS est un entier
!>          Le nombre de vecteurs du second membre à générer pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est un REAL double précision
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour afficher
!>          chaque ratio de test, utiliser THRESH = 0.
!>

TSTERR

!>          TSTERR est LOGICAL
!>          Indicateur qui spécifie si les sorties d'erreur doivent être testées.
!>

NMAX

!>          NMAX est un entier
!>          La valeur maximale autorisée pour N, utilisée pour dimensionner les
!>          tableaux de travail.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

AFAC

!>          AFAC est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

ASAV

!>          ASAV est un tableau COMPLEX*16, de dimension (NMAX*NMAX)
!>

B

!>          B est un tableau COMPLEX*16, de dimension (NMAX*NRHS)
!>

BSAV

!>          BSAV est un tableau COMPLEX*16, de dimension (NMAX*NRHS)
!>

X

!>          X est un tableau COMPLEX*16, de dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau COMPLEX*16, de dimension (NMAX*NRHS)
!>

S

!>          S est un tableau REAL double précision, de dimension (NMAX)
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension
!>                      (NMAX*max(3,NRHS))
!>

RWORK

!>          RWORK est un tableau REAL double précision, de dimension (NMAX+2*NRHS)
!>

NOUT

!>          NOUT est un entier
!>          Le numéro de l'unité de sortie.
!>
