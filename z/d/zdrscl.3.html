sous-routine zdrscl (integer n, double precision sa, complex*16, dimension( * ) sx, integer incx)

ZDRSCL multiplie un vecteur par l'inverse d'un scalaire réel.

Objectif :

!>
!> ZDRSCL multiplie un vecteur complexe x de n éléments par le scalaire réel
!> 1/a.  Ceci est effectué sans dépassement de capacité ou sous-dépassement de capacité
!> tant que le résultat final x/a ne dépasse pas la capacité ou ne sous-dépasse pas la capacité.
!>

Paramètres

N 
!>          N est un entier
!>          Le nombre de composantes du vecteur x.
!>

SA

!>          SA est en double précision
!>          Le scalaire a qui est utilisé pour diviser chaque composante de x.
!>          SA doit être >= 0, sinon la sous-routine divisera par zéro.
!>

SX

!>          SX est un tableau COMPLEX*16, de dimension
!>                         (1+(N-1)*abs(INCX))
!>          Le vecteur x de n éléments.
!>

INCX

!>          INCX est un entier
!>          L'incrément entre les valeurs successives du vecteur SX.
!>          > 0 :  SX(1) = X(1) et SX(1+(i-1)*INCX) = x(i),     1< i<= n
!>
