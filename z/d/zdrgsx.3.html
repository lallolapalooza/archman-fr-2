ZDRGSX

Objectif :

!>
!> ZDRGSX vérifie le pilote expert ZGGESX pour le problème de valeurs propres généralisées non symétriques (forme de Schur).
!>
!> ZGGES factorise A et B en Q*S*Z' et Q*T*Z', où ' signifie transpose conjuguée, S et T sont triangulaires supérieures (c'est-à-dire sous forme de Schur généralisée), et Q et Z sont unitaires. Il calcule également les valeurs propres généralisées (alpha(j),beta(j)), j=1,...,n. Ainsi,
!> w(j) = alpha(j)/beta(j) est une racine de l'équation caractéristique
!>
!>                 det( A - w(j) B ) = 0
!>
!> Il réorganise éventuellement les valeurs propres pour qu'un cluster sélectionné apparaisse dans le bloc diagonal de tête des formes de Schur ; calcule un nombre de condition réciproque pour la moyenne des valeurs propres sélectionnées ; et calcule un nombre de condition réciproque pour les sous-espaces de déflation droite et gauche correspondant aux valeurs propres sélectionnées.
!>
!> Lorsque ZDRGSX est appelé avec NSIZE > 0, cinq (5) types de paires de matrices intégrées sont utilisés pour tester la routine ZGGESX.
!>
!> Lorsque ZDRGSX est appelé avec NSIZE = 0, il lit les données de la matrice de test pour tester ZGGESX.
!> (besoin de plus de détails sur le type de données lues).
!>
!> Pour chaque paire de matrices, les tests suivants seront effectués et comparés au seuil THRESH, à l'exception des tests (7) et (9) :
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp )
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp )
!>
!> (3)   | I - QQ' | / ( n ulp )
!>
!> (4)   | I - ZZ' | / ( n ulp )
!>
!> (5)   si A est en forme de Schur (c'est-à-dire forme triangulaire)
!>
!> (6)   maximum sur j de D(j) où :
!>
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!> (7)   si le tri a fonctionné et SDIM est le nombre de valeurs propres
!>       qui ont été sélectionnées.
!>
!> (8)   la valeur estimée DIF ne diffère pas des valeurs réelles de
!>       Difu et Difl plus que par un facteur 10*THRESH. Si l'estimation DIF
!>       est égale à zéro, les valeurs réelles correspondantes de Difu et Difl
!>       devraient être inférieures à EPS*norm(A, B). Si la valeur réelle de Difu
!>       et Difl est égale à zéro, l'estimation DIF devrait être inférieure à
!>       EPS*norm(A, B).
!>
!> (9)   Si INFO = N+3 est renvoyé par ZGGESX, la réorganisation
!>       et nous vérifions que DIF = PL = PR = 0 et que la valeur réelle de
!>       Difu et Difl est < EPS*norm(A, B). Nous comptons les événements où
!>       INFO=N+3.
!>
!> Pour les matrices de test lues, les mêmes tests sont effectués, sauf que la
!> valeur exacte de DIF (et PL) est une donnée d'entrée. De plus, un test supplémentaire est effectué pour les matrices de test lues :
!>
!> (10)  la valeur estimée PL ne diffère pas de la valeur réelle de
!>       PLTRU plus que par un facteur THRESH. Si l'estimation PL est égale
!>       à zéro, la valeur réelle correspondante de PLTRU devrait être inférieure à
!>       EPS*norm(A, B). Si la valeur réelle de PLTRU est égale à zéro,
!>       l'estimation PL devrait être inférieure à EPS*norm(A, B).
!>
!> Notez que pour les tests intégrés, un total de 10*NSIZE*(NSIZE-1)
!> paires de matrices sont générées et testées. NSIZE doit rester petit.
!>
!> SVD (routine ZGESVD) est utilisé pour calculer la valeur réelle de DIF_u
!> et DIF_l lors du test des problèmes de test intégrés.
!>
!> Matrices de test intégrées
!> ======================
!>
!> Toutes les matrices de test intégrées sont le bloc 2x2 de matrices triangulaires
!>
!>          A = [ A11 A12 ]    et      B = [ B11 B12 ]
!>              [     A22 ]                 [     B22 ]
!>
!> où pour différents types, A11 et A22 sont donnés comme suit.
!> A12 et B12 sont choisis de sorte que l'équation de Sylvester généralisée
!>
!>          A11*R - L*A22 = -A12
!>          B11*R - L*B22 = -B12
!>
!> aient des solutions prescrites R et L.
!>
!> Type 1 :  A11 = J_m(1,-1) et A_22 = J_k(1-a,1).
!>          B11 = I_m, B22 = I_k
!>          où J_k(a,b) est le bloc de Jordan kxk avec "a" sur la
!>          diagonale et "b" sur la superdiagonale.
!>
!> Type 2 :  A11 = (a_ij) = ( 2(.5-sin(i)) ) et
!>          B11 = (b_ij) = ( 2(.5-sin(ij)) ) pour i=1,...,m, j=i,...,m
!>          A22 = (a_ij) = ( 2(.5-sin(i+j)) ) et
!>          B22 = (b_ij) = ( 2(.5-sin(ij)) ) pour i=m+1,...,k, j=i,...,k
!>
!> Type 3 :  A11, A22 et B11, B22 sont choisis comme pour le Type 2, mais chaque
!>          deuxième bloc diagonal dans A_11 et chaque troisième bloc diagonal
!>          dans A_22 sont des blocs 2x2.
!>
!> Type 4 :  A11 = ( 20(.5 - sin(ij)) ) et B22 = ( 2(.5 - sin(i+j)) )
!>             pour i=1,...,m,  j=1,...,m et
!>          A22 = ( 20(.5 - sin(i+j)) ) et B22 = ( 2(.5 - sin(ij)) )
!>             pour i=m+1,...,k,  j=m+1,...,k
!>
!> Type 5 :  (A,B) ont des valeurs propres potentiellement proches ou communes et
!>          un départ très important de la diagonalité par blocs. A_11 est choisi
!>          comme la sous-matrice principale m x m de A_1 :
!>                  |  1  b                            |
!>                  | -b  1                            |
!>                  |        1+d  b                    |
!>                  |         -b 1+d                   |
!>           A_1 =  |                  d  1            |
!>                  |                 -1  d            |
!>                  |                        -d  1     |
!>                  |                        -1 -d     |
!>                  |                               1  |
!>          et A_22 est choisi comme la sous-matrice principale k x k de A_2 :
!>                  | -1  b                            |
!>                  | -b -1                            |
!>                  |       1-d  b                     |
!>                  |       -b  1-d                    |
!>           A_2 =  |                 d 1+b            |
!>                  |               -1-b d             |
!>                  |                       -d  1+b    |
!>                  |                      -1+b  -d    |
!>                  |                              1-d |
!>          et la matrice B sont choisis comme des matrices identité (voir DLATM5).
!>
!>

THRESH

!>          THRESH est de type DOUBLE PRECISION
!>          Un test sera considéré comme réussi si le rapport, calculé comme
!>          décrit ci-dessus, dépasse THRESH. Noter que l'erreur
!>          est mise à l'échelle pour être O(1), donc THRESH doit être un multiple raisonnablement
!>          petit de 1, par exemple, 10 ou 100. En particulier,
!>          il ne doit pas dépendre de la précision (simple vs double)
!>          ou de la taille de la matrice. THRESH >= 0.
!>

NIN

!>          NIN est un entier
!>          Le numéro d'unité FORTRAN pour la lecture du fichier de données des
!>          problèmes à résoudre.
!>

NOUT

!>          NOUT est un entier
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (par exemple, si une routine retourne INFO différent de 0).
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA, NSIZE)
!>          Utilisé pour stocker la matrice dont les valeurs propres doivent être
!>          calculées. En sortie, A contient la dernière matrice effectivement utilisée.
!>

LDA

!>          LDA est un entier
!>          La dimension principale de A, B, AI, BI, Z et Q,
!>          LDA >= max( 1, NSIZE ). Pour le test de lecture,
!>          LDA >= max( 1, N ), N est la taille des matrices de test.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDA, NSIZE)
!>          Utilisé pour stocker la matrice dont les valeurs propres doivent être
!>          calculées. En sortie, B contient la dernière matrice effectivement utilisée.
!>

AI

!>          AI est un tableau COMPLEX*16, de dimension (LDA, NSIZE)
!>          Copie de A, modifiée par ZGGESX.
!>

BI

!>          BI est un tableau COMPLEX*16, de dimension (LDA, NSIZE)
!>          Copie de B, modifiée par ZGGESX.
!>

Z

!>          Z est un tableau COMPLEX*16, de dimension (LDA, NSIZE)
!>          Z contient les vecteurs de Schur gauches calculés par ZGGESX.
!>

Q

!>          Q est un tableau COMPLEX*16, de dimension (LDA, NSIZE)
!>          Q contient les vecteurs de Schur droits calculés par ZGGESX.
!>

ALPHA

!>          ALPHA est un tableau COMPLEX*16, de dimension (NSIZE)
!>

BETA

!>          BETA est un tableau COMPLEX*16, de dimension (NSIZE)
!>

C

!>          C est un tableau COMPLEX*16, de dimension (LDC, LDC)

LDC

WORK
