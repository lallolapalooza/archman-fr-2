sous-programme zdrvgb (logique, dimension( * ) dotype, entier nn, entier, dimension( * ) nval, entier nrhs, double précision thresh, logique tsterr, complexe*16, dimension( * ) a, entier la, complexe*16, dimension( * ) afb, entier lafb, complexe*16, dimension( * ) asav, complexe*16, dimension( * ) b, complexe*16, dimension( * ) bsav, complexe*16, dimension( * ) x, complexe*16, dimension( * ) xact, double précision, dimension( * ) s, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier, dimension( * ) iwork, entier nout)

ZDRVGBX

Objectif:

!>
!> ZDRVGB teste les sous-programmes de pilote ZGBSV, -SVX, et -SVXX.
!>
!> Notez que ce fichier n'est utilisé que lorsque les XBLAS sont disponibles,
!> sinon zdrvgb.f définit ce sous-programme.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, de dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .VRAI. ; si DOTYPE(j) = .FAUX., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, de dimension (NN)
!>          Les valeurs de la dimension N de la colonne de la matrice.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de vecteurs du second membre à générer pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est un DOUBLE PRÉCISION
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque ratio de test soit imprimé, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est un LOGIQUE
!>          Indicateur qui spécifie si les sorties d'erreur doivent être testées.
!>

A

!>          A est un tableau de COMPLEX*16, de dimension (LA)
!>

LA

!>          LA est un ENTIER
!>          La longueur du tableau A. LA >= (2*NMAX-1)*NMAX
!>          où NMAX est la plus grande entrée de NVAL.
!>

AFB

!>          AFB est un tableau de COMPLEX*16, de dimension (LAFB)
!>

LAFB

!>          LAFB est un ENTIER
!>          La longueur du tableau AFB. LAFB >= (3*NMAX-2)*NMAX
!>          où NMAX est la plus grande entrée de NVAL.
!>

ASAV

!>          ASAV est un tableau de COMPLEX*16, de dimension (LA)
!>

B

!>          B est un tableau de COMPLEX*16, de dimension (NMAX*NRHS)
!>

BSAV

!>          BSAV est un tableau de COMPLEX*16, de dimension (NMAX*NRHS)
!>

X

!>          X est un tableau de COMPLEX*16, de dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau de COMPLEX*16, de dimension (NMAX*NRHS)
!>

S

!>          S est un tableau de DOUBLE PRÉCISION, de dimension (2*NMAX)
!>

WORK

!>          WORK est un tableau de COMPLEX*16, de dimension
!>                      (NMAX*max(3,NRHS,NMAX))
!>

RWORK

!>          RWORK est un tableau de DOUBLE PRÉCISION, de dimension
!>                      (max(2*NMAX,NMAX+2*NRHS))
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, de dimension (NMAX)
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro de l'unité de sortie.
!>
