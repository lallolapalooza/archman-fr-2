sous-routine zgqrts (entier n, entier m, entier p, complexe*16, dimension( lda, * ) a, complexe*16, dimension( lda, * ) af, complexe*16, dimension( lda, * ) q, complexe*16, dimension( lda, * ) r, entier lda, complexe*16, dimension( * ) taua, complexe*16, dimension( ldb, * ) b, complexe*16, dimension( ldb, * ) bf, complexe*16, dimension( ldb, * ) z, complexe*16, dimension( ldb, * ) t, complexe*16, dimension( ldb, * ) bwk, entier ldb, complexe*16, dimension( * ) taub, complexe*16, dimension( lwork ) work, entier lwork, double_precision, dimension( * ) rwork, double_precision, dimension( 4 ) result)

ZGQRTS

But :

!>
!> ZGQRTS teste ZGGQRF, qui calcule la factorisation GQR d'une matrice A
!> de taille N x M et d'une matrice B de taille N x P : A = Q*R et B = Q*T*Z.
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre de lignes des matrices A et B.  N >= 0.
!>

M

!>          M est un ENTIER
!>          Le nombre de colonnes de la matrice A.  M >= 0.
!>

P

!>          P est un ENTIER
!>          Le nombre de colonnes de la matrice B.  P >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,M)
!>          La matrice A de taille N x M.
!>

AF

!>          AF est un tableau COMPLEX*16, de dimension (LDA,N)
!>          Détails de la factorisation GQR de A et B, tels que retournés
!>          par ZGGQRF, voir CGGQRF pour plus de détails.
!>

Q

!>          Q est un tableau COMPLEX*16, de dimension (LDA,N)
!>          La matrice unitaire Q de taille M x M.
!>

R

!>          R est un tableau COMPLEX*16, de dimension (LDA,MAX(M,N))
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, R et Q.
!>          LDA >= max(M,N).
!>

TAUA

!>          TAUA est un tableau COMPLEX*16, de dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires, tels que retournés
!>          par ZGGQRF.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,P)
!>          À l'entrée, la matrice A de taille N x P.
!>

BF

!>          BF est un tableau COMPLEX*16, de dimension (LDB,N)
!>          Détails de la factorisation GQR de A et B, tels que retournés
!>          par ZGGQRF, voir CGGQRF pour plus de détails.
!>

Z

!>          Z est un tableau COMPLEX*16, de dimension (LDB,P)
!>          La matrice unitaire Z de taille P x P.
!>

T

!>          T est un tableau COMPLEX*16, de dimension (LDB,max(P,N))
!>

BWK

!>          BWK est un tableau COMPLEX*16, de dimension (LDB,N)
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale des tableaux B, BF, Z et T.
!>          LDB >= max(P,N).
!>

TAUB

!>          TAUB est un tableau COMPLEX*16, de dimension (min(P,N))
!>          Les facteurs scalaires des réflecteurs élémentaires, tels que retournés
!>          par DGGRQF.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK, LWORK >= max(N,M,P)**2.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (max(N,M,P))
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, de dimension (4)
!>          Les rapports de test :
!>            RESULT(1) = norm( R - Q'*A ) / ( MAX(M,N)*norm(A)*ULP)
!>            RESULT(2) = norm( T*Z - Q'*B ) / (MAX(P,N)*norm(B)*ULP)
!>            RESULT(3) = norm( I - Q'*Q ) / ( M*ULP )
!>            RESULT(4) = norm( I - Z'*Z ) / ( P*ULP )
!>
