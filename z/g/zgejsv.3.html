Documentation de la fonction/sous-programme

subroutine zgejsv (character*1 joba, character*1 jobu, character*1 jobv, character*1 jobr, character*1 jobt, character*1 jobp, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( n ) sva, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( lwork ) cwork, integer lwork, double precision, dimension( lrwork ) rwork, integer lrwork, integer, dimension( * ) iwork, integer info)

ZGEJSV

But :

!>
!> ZGEJSV calcule la décomposition en valeurs singulières (SVD) d'une matrice complexe M par N [A], où M >= N. La SVD de [A] s'écrit :
!>
!>              [A] = [U] * [SIGMA] * [V]^*,
!>
!> où [SIGMA] est une matrice N par N (M par N) qui est nulle sauf pour ses N éléments diagonaux, [U] est une matrice unitaire M par N (ou M par M), et
!> [V] est une matrice unitaire N par N. Les éléments diagonaux de [SIGMA] sont
!> les valeurs singulières de [A]. Les colonnes de [U] et [V] sont les vecteurs singuliers gauches et
!> droits de [A], respectivement. Les matrices [U] et [V]
!> sont calculées et stockées dans les tableaux U et V, respectivement. La diagonale de [SIGMA] est calculée et stockée dans le tableau SVA.
!>

Paramètres

JOBA 
!>          JOBA est CHARACTER*1
!>         Spécifie le niveau de précision :
!>       = 'C' : Cette option fonctionne bien (haute précision relative) si A = B * D,
!>              avec B bien conditionnée et D une matrice diagonale arbitraire.
!>              La précision ne peut pas être détériorée par une mise à l'échelle des COLONNES. La
!>              précision de la sortie calculée dépend de la condition de
!>              B, et la procédure vise la meilleure précision théorique.
!>              L'erreur relative max_{i=1:N}|d sigma_i| / sigma_i est
!>              bornée par f(M,N)*epsilon* cond(B), indépendamment de D.
!>              La matrice d'entrée est prétraitée avec la décomposition QR avec pivotement des colonnes. Ce prétraitement initial et le préconditionnement par
!>              une factorisation QR révélatrice de rang sont communs à toutes les valeurs de
!>              JOBA. Les actions supplémentaires sont spécifiées comme suit :
!>       = 'E' : Calcul comme avec 'C' avec une estimation supplémentaire du
!>              nombre de condition de B. Elle fournit une borne d'erreur réaliste.
!>       = 'F' : Si A = D1 * C * D2 avec des mises à l'échelle diagonales mal conditionnées
!>              D1, D2, et une matrice C bien conditionnée, cette option donne
!>              une plus grande précision que l'option 'C'. Si la structure de la
!>              matrice d'entrée n'est pas connue, et que la précision relative est
!>              souhaitée, alors cette option est conseillée. La matrice d'entrée A
!>              est prétraitée avec une factorisation QR avec pivotement COMPLET (lignes et
!>              colonnes).
!>       = 'G' : Calcul comme avec 'F' avec une estimation supplémentaire du
!>              nombre de condition de B, où A=B*D. Si A a des lignes fortement pondérées,
!>              alors l'utilisation de ce nombre de condition donne une borne d'erreur trop pessimiste.
!>       = 'A' : Les valeurs singulières petites ne sont pas bien déterminées par les données 
!>              et sont considérées comme bruitées ; la matrice est traitée comme
!>              numériquement de rang déficient. L'erreur dans les valeurs singulières calculées
!>              est bornée par f(m,n)*epsilon*||A||.
!>              La SVD calculée A = U * S * V^* restaure A jusqu'à
!>              f(m,n)*epsilon*||A||.
!>              Cela donne à la procédure la licence de rejeter (mettre à zéro)
!>              toutes les valeurs singulières inférieures à N*epsilon*||A||.
!>       = 'R' : Similaire à 'A'. La propriété révélatrice de rang de la factorisation
!>              QR initiale est utilisée pour révéler (en utilisant le facteur triangulaire)
!>              un écart sigma_{r+1} < epsilon * sigma_r auquel cas le
!>              RANG numérique est déclaré comme étant r. La SVD est calculée avec
!>              des bornes d'erreur absolues, mais plus précisément qu'avec 'A'.
!>

JOBU

!>          JOBU est CHARACTER*1
!>         Spécifie si les colonnes de U doivent être calculées :
!>       = 'U' : N colonnes de U sont retournées dans le tableau U.
!>       = 'F' : l'ensemble complet des M vecteurs singuliers gauches est retourné dans le tableau U.
!>       = 'W' : U peut être utilisé comme espace de travail de longueur M*N. Voir la description
!>              de U.
!>       = 'N' : U n'est pas calculé.
!>

JOBV

!>          JOBV est CHARACTER*1
!>         Spécifie si la matrice V doit être calculée :
!>       = 'V' : N colonnes de V sont retournées dans le tableau V ; les rotations de Jacobi
!>              ne sont pas explicitement accumulées.
!>       = 'J' : N colonnes de V sont retournées dans le tableau V, mais elles sont
!>              calculées comme le produit de rotations de Jacobi, si JOBT = 'N'.
!>       = 'W' : V peut être utilisé comme espace de travail de longueur N*N. Voir la description
!>              de V.
!>       = 'N' : V n'est pas calculé.
!>

JOBR

!>          JOBR est CHARACTER*1
!>         Spécifie la PLAGE des valeurs singulières. Donne la licence de
!>         mettre à zéro les petites valeurs singulières positives si elles sont en dehors
!>         de la plage spécifiée. Si A .NE. 0 est mise à l'échelle de sorte que la plus grande valeur singulière
!>         de c*A soit autour de SQRT(BIG), BIG=DLAMCH('O'), alors JOBR donne
!>         la licence de supprimer les colonnes de A dont la norme dans c*A est inférieure à
!>         SQRT(SFMIN) (pour JOBR = 'R'), ou inférieure à SMALL=SFMIN/EPSLN,
!>         où SFMIN=DLAMCH('S'), EPSLN=DLAMCH('E').
!>       = 'N' : Ne supprime pas les petites colonnes de c*A. Cette option suppose que
!>              BLAS et les factorisations QR et les solveurs triangulaires sont
!>              implémentés pour fonctionner dans cette plage. Si la condition de A
!>              est supérieure à BIG, utilisez ZGESVJ.
!>       = 'R' : Plage RESTREINTE pour sigma(c*A) est [SQRT(SFMIN), SQRT(BIG)]
!>              (approximativement, comme décrit ci-dessus). Cette option est recommandée.
!>                                             ===========================
!>         Pour calculer les valeurs singulières dans la plage COMPLÈTE [SFMIN,BIG]
!>         utilisez ZGESVJ.
!>

JOBT

!>          JOBT est CHARACTER*1
!>         Si la matrice est carrée, la procédure peut décider d'utiliser
!>         la transposée A si A^* semble meilleure en termes de convergence.
!>         Si la matrice n'est pas carrée, JOBT est ignoré. 
!>         La décision est basée sur deux valeurs d'entropie sur l'orbite adjointe
!>         de A^* * A. Voir les descriptions de RWORK(6) et RWORK(7).
!>       = 'T' : transposer si le test d'entropie indique une convergence potentiellement plus rapide
!>         du processus de Jacobi si A^* est pris comme entrée. Si A est
!>         remplacé par A^*, alors le pivotement de ligne est inclus automatiquement.
!>       = 'N' : ne pas spéculer.
!>         L'option 'T' peut être utilisée pour calculer uniquement les valeurs singulières, ou
!>         la SVD complète (U, SIGMA et V). Pour un seul ensemble de vecteurs singuliers
!>         (U ou V), l'appelant doit fournir à la fois U et V, car l'une des
!>         matrices est utilisée comme espace de travail si la matrice A est transposée.
!>         L'implémenteur peut facilement supprimer cette contrainte et rendre le
!>         code plus compliqué. Voir les descriptions de U et V.
!>         En général, cette option est considérée comme expérimentale, et 'N'
!>         devrait être préférée. Ceci est sujet à des changements futurs.
!>

JOBP

!>          JOBP est CHARACTER*1
!>         Donne la licence pour introduire des perturbations structurées pour noyer
!>         les nombres dénormalisés. Cette licence doit être active si les
!>         dénormalisés sont

M

!>          M est un entier
!>         Le nombre de lignes de la matrice d'entrée A. M >= 0.
!>

N

!>          N est un entier
!>         Le nombre de colonnes de la matrice d'entrée A. M >= N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, la matrice M-par-N A.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

SVA

!>          SVA est un tableau DOUBLE PRECISION, de dimension (N)
!>          À la sortie,
!>          - Pour RWORK(1)/RWORK(2) = UN: Les valeurs singulières de A. Pendant
!>            le calcul, SVA contient les normes euclidiennes des colonnes des
!>            matrices itérées dans le tableau A.
!>          - Pour RWORK(1) .NE. RWORK(2): Les valeurs singulières de A sont
!>            (RWORK(1)/RWORK(2)) * SVA(1:N). Cette forme factorisée est utilisée si
!>            sigma_max(A) déborde ou si de petites valeurs singulières ont été
!>            sauvegardées contre la sous-dépassement en mettant à l'échelle la matrice d'entrée A.
!>          - Si JOBR='R' alors certaines des valeurs singulières peuvent être retournées
!>            comme des zéros exacts obtenus parce qu'elles sont
!>            en dessous du seuil de rang numérique ou sont des nombres dénormalisés.
!>

U

!>          U est un tableau COMPLEX*16, de dimension ( LDU, N )
!>          Si JOBU = 'U', alors U contient à la sortie la matrice M-par-N des
!>                         vecteurs singuliers gauches.
!>          Si JOBU = 'F', alors U contient à la sortie la matrice M-par-M des
!>                         vecteurs singuliers gauches, y compris une base orthonormée
!>                         du complément orthogonal de Range(A).
!>          Si JOBU = 'W'  .ET. (JOBV = 'V' .ET. JOBT = 'T' .ET. M = N),
!>                         alors U est utilisé comme espace de travail si la procédure
!>                         remplace A par A^*. Dans ce cas, [V] est calculé
!>                         dans U comme vecteurs singuliers gauches de A^* puis
!>                         copié dans le tableau V. Cette option 'W' est juste
!>                         un rappel à l'appelant que dans ce cas U est
!>                         réservé comme espace de travail de longueur N*N.
!>          Si JOBU = 'N'  U n'est pas référencé, sauf si JOBT='T'.
!>

LDU

!>          LDU est un entier
!>          La dimension principale du tableau U, LDU >= 1.
!>          SI  JOBU = 'U' ou 'F' ou 'W',  alors LDU >= M.
!>

V

!>          V est un tableau COMPLEX*16, de dimension ( LDV, N )
!>          Si JOBV = 'V', 'J', alors V contient à la sortie la matrice N-par-N des
!>                         vecteurs singuliers droits;
!>          Si JOBV = 'W', ET (JOBU = 'U' ET JOBT = 'T' ET M = N),
!>                         alors V est utilisé comme espace de travail si la procédure
!>                         remplace A par A^*. Dans ce cas, [U] est calculé
!>                         dans V comme vecteurs singuliers droits de A^* puis
!>                         copié dans le tableau U. Cette option 'W' est juste
!>                         un rappel à l'appelant que dans ce cas V est
!>                         réservé comme espace de travail de longueur N*N.
!>          Si JOBV = 'N'  V n'est pas référencé, sauf si JOBT='T'.
!>

LDV

!>          LDV est un entier
!>          La dimension principale du tableau V, LDV >= 1.
!>          Si JOBV = 'V' ou 'J' ou 'W', alors LDV >= N.
!>

CWORK

!>          CWORK est un tableau COMPLEX*16, de dimension (MAX(2,LWORK))
!>          Si l'appel à ZGEJSV est une requête d'espace de travail (indiquée par LWORK=-1 ou
!>          LRWORK=-1), alors à la sortie CWORK(1) contient la longueur requise de
!>          CWORK pour les paramètres d'emploi utilisés dans l'appel.
!>

LWORK

!>          LWORK est un entier
!>          Longueur de CWORK pour confirmer l'allocation correcte de l'espace de travail.
!>          LWORK dépend de l'emploi :
!>
!>          1. Si seulement SIGMA est nécessaire ( JOBU = 'N', JOBV = 'N' ) et
!>            1.1 .. aucune estimation du nombre de conditionnement mis à l'échelle requise (JOBA.NE.'E'.AND.JOBA.NE.'G'):
!>               LWORK >= 2*N+1. C'est l'exigence minimale.
!>               ->> Pour des performances optimales (code bloqué), la valeur optimale
!>               est LWORK >= N + (N+1)*NB. Ici NB est la taille de bloc optimale
!>               pour ZGEQP3 et ZGEQRF.
!>               En général, LWORK optimal est calculé comme
!>               LWORK >= max(N+LWORK(ZGEQP3),N+LWORK(ZGEQRF), LWORK(ZGESVJ)).
!>            1.2. .. une estimation du nombre de conditionnement mis à l'échelle de A est
!>               requise (JOBA='E', ou 'G'). Dans ce cas, LWORK l'exigence minimale
!>               est LWORK >= N*N + 2*N.
!>               ->> Pour des performances optimales (code bloqué), la valeur optimale
!>               est LWORK >= max(N+(N+1)*NB, N*N+2*N)=N**2+2*N.
!>               En général, la longueur optimale LWORK est calculée comme
!>               LWORK >= max(N+LWORK(ZGEQP3),N+LWORK(ZGEQRF), LWORK(ZGESVJ),
!>                            N*N+LWORK(ZPOCON)).
!>          2. Si SIGMA et les vecteurs singuliers droits sont nécessaires (JOBV = 'V'),
!>             (JOBU = 'N')
!>            2.1   .. aucune estimation du nombre de conditionnement mis à l'échelle requise (JOBE = 'N'):
!>            -> l'exigence minimale est LWORK >= 3*N.
!>            -> Pour des performances optimales,
!>               LWORK >= max(N+(N+1)*NB, 2*N+N*NB)=2*N+N*NB,
!>               où NB est la taille de bloc optimale pour ZGEQP3, ZGEQRF, ZGELQF,
!>               ZUNMLQ. En général, la longueur optimale LWORK est calculée comme
!>               LWORK >= max(N+LWORK(ZGEQP3), N+LWORK(ZGESVJ),
!>                       N+LWORK(ZGELQF), 2*N+LWORK(ZGEQRF), N+LWORK(ZUNMLQ)).
!>            2.2 .. une estimation du nombre de conditionnement mis à l'échelle de A est
!>               requise (JOBA='E', ou 'G').
!>            -> l'exigence minimale est LWORK >= 3*N.
!>            -> Pour des performances optimales,
!>               LWORK >= max(N+(N+1)*NB, 2*N,2*N+N*NB)=2*N+N*NB,
!>               où NB est la taille de bloc optimale pour ZGEQP3, ZGEQRF, ZGELQF,
!>               ZUNMLQ. En général, la longueur optimale LWORK est calculée comme
!>               LWORK >= max(N+LWORK(ZGEQP3), LWORK(ZPOCON), N+LWORK(ZGESVJ),
!>                       N+LWORK(ZGELQF), 2*N+LWORK(ZGEQRF), N+LWORK(ZUNMLQ)).
!>          3. Si SIGMA et les vecteurs singuliers gauches sont nécessaires
!>            3.1  .. aucune estimation du nombre de conditionnement mis à l'échelle requise (JOBE = 'N'):
!>            -> l'exigence minimale est LWORK >= 3*N.
!>            -> Pour des performances optimales:
!>               si JOBU = 'U' :: LWORK >= max(3*N, N+(N+1)*NB, 2*N+N*NB)=2*N+N*NB,
!>               où NB est la taille de bloc optimale pour ZGEQP3, ZGEQRF, ZUNMQR.
!>               En général, la longueur optimale LWORK est calculée comme
!>               LWORK >= max(N+LWORK(ZGEQP3), 2*N+LWORK(ZGEQRF), N+LWORK(ZUNMQR)).
!>            3.2  .. une estimation du nombre de conditionnement mis à l'échelle de A est
!>               requise (JOBA='E', ou 'G').
!>            -> l'exigence minimale est LWORK >= 3*N.
!>            -> Pour des performances optimales:
!>               si JOBU = 'U' :: LWORK >= max(3*N, N+(N+1)*NB, 2*N+N*NB)=2*N+N*NB,
!>               où NB est la taille de bloc optimale pour ZGEQP3, ZGEQRF, ZUNMQR.
!>               En général, la longueur optimale LWORK est calculée comme
!>               LWORK >= max(N+LWORK(ZGEQP3),N+LWORK(ZPOCON),
!>                        2*N+LWORK(ZGEQRF), N+LWORK(ZUNMQR)).
!>          4. Si la SVD complète est nécessaire : (JOBU = 'U' ou JOBU = 'F') et
!>            4.1. si JOBV = 'V'
!>               l'exigence minimale est LWORK >= 5*N+2*N*N.
!>            4.2. si JOBV = 'J', l'exigence minimale est
!>               LWORK >= 4*N+N*N.
!>            Dans les deux cas, CWORK alloué peut accueillir des exécutions bloquées
!>            de ZGEQP3, ZGEQRF, ZGELQF, SUNMQR, ZUNMLQ.
!>
!>          Si l'appel à ZGEJSV est une requête d'espace de travail (indiquée par LWORK=-1 ou
!>          LRWORK=-1), alors à la sortie CWORK(1) contient la longueur optimale et CWORK(2) contient la
!>          longueur minimale de CWORK pour les paramètres d'emploi utilisés dans l'appel.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (MAX(7,LRWORK))
!>          À la sortie,
!>          RWORK(1) = Détermine le facteur d'échelle SCALE = RWORK(2) / RWORK(1)
!>                    tel que SCALE*SVA(1:N) soient les valeurs singulières calculées
!>                    de A. (Voir la description de SVA().)
!>          RWORK(2) = Voir la description de RWORK(1).
!>          RWORK(3) = SCONDA est une estimation du nombre de conditionnement de
!>                    A équilibré par colonne. (Si JOBA = 'E' ou 'G')
!>                    SCONDA est une estimation de SQRT(||(R^* * R)^(-1)||_1).
!>                    Il est calculé en utilisant ZPOCON. Il détient
!>                    N^(-1/4) * SCONDA <= ||R^(-1)||_2 <= N^(1/4) * SCONDA
!>                    où R est le facteur triangulaire de la QRF de A.
!>                    Cependant, si R est tronqué et que le rang numérique est
!>                    déterminé comme étant strictement inférieur à N, SCONDA est
!>                    retourné comme -1, indiquant ainsi que les plus petites
!>                    valeurs singulières pourraient être perdues.
!>
!>          Si la SVD complète est nécessaire, les deux nombres de conditionnement suivants sont
!>          utiles pour l'analyse de l'algorithme. Ils sont fournis pour
!>          un développeur/implémenteur qui connaît les détails
!>          de la méthode.
!>
!>          RWORK(4) = une estimation du nombre de conditionnement mis à l'échelle du
!>                    facteur triangulaire dans la première factorisation QR.
!>          RWORK(5) = une estimation du nombre de conditionnement mis à l'échelle du
!>                    facteur triangulaire dans la seconde factorisation QR.
!>          Les deux paramètres suivants sont calculés si JOBT = 'T'.
!>          Ils sont fournis pour un développeur/implémenteur qui connaît
!>          les détails de la méthode.
!>          RWORK(6) = l'entropie de A^* * A :: c'est l'entropie de Shannon
!>                    de diag(A^* * A) / Trace(A^* * A) pris comme point dans le
!>                    simplexe de probabilité.
!>          RWORK(7) = l'entropie de A * A^*. (Voir la description de RWORK(6).)
!>          Si l'appel à ZGEJSV est une requête d'espace de travail (indiquée par LWORK=-1 ou
!>          LRWORK=-1), alors à la sortie RWORK(1) contient la longueur requise de
!>          RWORK pour les paramètres d'emploi utilisés dans l'appel.
!>

LRWORK

!>          LRWORK est un entier
!>          Longueur de RWORK pour confirmer l'allocation correcte de l'espace de travail.
!>          LRWORK dépend de l'emploi :
!>
!>       1. Si seules les valeurs singulières sont demandées, c'est-à-dire si
!>          LSAME(JOBU,'N') .ET. LSAME(JOBV,'N')
!>          alors :
!>          1.1. Si LSAME(JOBT,'T') .OU . LSAME(JOBA,'F') .OU . LSAME(JOBA,'G'),
!>               alors : LRWORK = max( 7, 2 * M ).
!>          1.2. Sinon, LRWORK = max( 7, N ).
!>       2. Si les valeurs singulières avec les vecteurs singuliers droits sont demandés
!>          c'est-à-dire si
!>          (LSAME(JOBV,'V').OU.LSAME(JOBV,'J')) .ET.
!>          .NON.(LSAME(JOBU,'U').OU.LSAME(JOBU,'F'))
!>          alors :
!>          2.1. Si LSAME(JOBT,'T') .OU. LSAME(JOBA,'F') .OU. LSAME(JOBA,'G'),
!>          alors LRWORK = max( 7, 2 * M ).
!>          2.2. Sinon, LRWORK = max( 7, N ).
!>       3. Si les valeurs singulières avec les vecteurs singuliers gauches sont demandés, c'est-à-dire si
!>          (LSAME(JOBU,'U').OU.LSAME(JOBU,'F')) .ET.
!>          .NON.(LSAME(JOBV,'V').OU.LSAME(JOBV,'J'))
!>          alors :
!>          3.1. Si LSAME(JOBT,'T') .OU. LSAME(JOBA,'F') .OU. LSAME(JOBA,'G'),
!>          alors LRWORK = max( 7, 2 * M ).
!>          3.2. Sinon, LRWORK = max( 7, N ).
!>       4. Si les valeurs singulières avec les vecteurs singuliers gauches et droits sont demandés
!>          c'est-à-dire si
!>          (LSAME(JOBU,'U').OU.LSAME(JOBU,'F')) .ET.
!>          (LSAME(JOBV,'V').OU.LSAME(JOBV,'J'))
!>          alors :
!>          4.1. Si LSAME(JOBT,'T') .OU. LSAME(JOBA,'F') .OU. LSAME(JOBA,'G'),
!>          alors LRWORK = max( 7, 2 * M ).
!>          4.2. Sinon, LRWORK = max( 7, N ).
!>
!>          Si, à l'entrée, LRWORK = -1 ou LWORK=-1, une requête d'espace de travail est supposée et
!>          la longueur de RWORK est retournée dans RWORK(1).
!>

IWORK

!>          IWORK est un tableau de type INTEGER, de dimension au moins 4, qui dépend en outre
!>          du job :
!>
!>          1. Si seules les valeurs singulières sont demandées alors :
!>             Si ( LSAME(JOBT,'T') .OU. LSAME(JOBA,'F') .OU. LSAME(JOBA,'G') )
!>             alors la longueur de IWORK est N+M ; sinon la longueur de IWORK est N.
!>          2. Si les valeurs singulières et les vecteurs singuliers droits sont demandés alors :
!>             Si ( LSAME(JOBT,'T') .OU. LSAME(JOBA,'F') .OU. LSAME(JOBA,'G') )
!>             alors la longueur de IWORK est N+M ; sinon la longueur de IWORK est N.
!>          3. Si les valeurs singulières et les vecteurs singuliers gauches sont demandés alors :
!>             Si ( LSAME(JOBT,'T') .OU. LSAME(JOBA,'F') .OU. LSAME(JOBA,'G') )
!>             alors la longueur de IWORK est N+M ; sinon la longueur de IWORK est N.
!>          4. Si les valeurs singulières avec les vecteurs singuliers gauches et droits
!>             sont demandés, alors :
!>             4.1. Si LSAME(JOBV,'J') la longueur de IWORK est déterminée comme suit :
!>                  Si ( LSAME(JOBT,'T') .OU. LSAME(JOBA,'F') .OU. LSAME(JOBA,'G') )
!>                  alors la longueur de IWORK est N+M ; sinon la longueur de IWORK est N.
!>             4.2. Si LSAME(JOBV,'V') la longueur de IWORK est déterminée comme suit :
!>                  Si ( LSAME(JOBT,'T') .OU. LSAME(JOBA,'F') .OU. LSAME(JOBA,'G') )
!>                  alors la longueur de IWORK est 2*N+M ; sinon la longueur de IWORK est 2*N.
!>
!>          À la sortie,
!>          IWORK(1) = le rang numérique déterminé après la factorisation
!>                     QR initiale avec pivot. Voir les descriptions
!>                     de JOBA et JOBR.
!>          IWORK(2) = le nombre de valeurs singulières non nulles calculées
!>          IWORK(3) = s'il est non nul, un message d'avertissement :
!>                     Si IWORK(3) = 1, alors certaines normes de colonnes de A
!>                     ont été normalisées en nombres flottants. La haute précision demandée
!>                     n'est pas garantie par les données.
!>          IWORK(4) = 1 ou -1. Si IWORK(4) = 1, alors la procédure a utilisé A^* pour
!>                     accomplir le travail spécifié par les paramètres JOB.
!>          Si l'appel à ZGEJSV est une requête d'espace de travail (indiquée par LWORK = -1 ou
!>          LRWORK = -1), alors à la sortie IWORK(1) contient la longueur requise de
!>          IWORK pour les paramètres de job utilisés dans l'appel.

Détails supplémentaires :

!>
!>  ZGEJSV implémente un algorithme de Jacobi SVD préconditionné. Il utilise ZGEQP3,
!>  ZGEQRF et ZGELQF comme préprocesseurs et préconditionneurs. Optionnellement, un
!>  pivotement de ligne supplémentaire peut être utilisé comme préprocesseur, ce qui dans certains
!>  cas conduit à une précision beaucoup plus élevée. Un exemple est la matrice A avec la
!>  structure A = D1 * C * D2, où D1, D2 sont des matrices diagonales arbitrairement mal conditionnées
!>  et C est une matrice bien conditionnée. Dans ce cas, le pivotement complet dans les premières factorisations QR fournit une précision dépendant du
!>  nombre de condition de C, et indépendante de D1, D2. Une telle précision plus élevée n'est pas complètement comprise théoriquement,
!>  mais elle fonctionne bien en pratique.
!>  De plus, si A peut être écrit comme A = B*D, avec B bien conditionné et D diagonal, alors une haute précision est garantie,
!>  à la fois théoriquement et en logiciel, indépendamment de D. Pour plus de détails voir [1], [2].
!>     La plage de calcul pour les valeurs singulières peut être la plage complète
!>  ( SOUS-DÉBORDEMENT, DÉBORDEMENT ), à condition que l'arithmétique de la machine et les routines BLAS
!>  & LAPACK appelées par ZGEJSV soient implémentées pour fonctionner dans cette plage.
!>  Si ce n'est pas le cas, alors la restriction pour un calcul sûr avec
!>  les valeurs singulières dans la plage des nombres flottants normalisés IEEE est que le
!>  nombre de condition spectral kappa(A)=sigma_max(A)/sigma_min(A) ne provoque pas de
!>  dépassement. Ce code (ZGEJSV) est mieux utilisé dans cette plage restreinte,
!>  ce qui signifie que les valeurs singulières de magnitude inférieure à ||A||_2 / DLAMCH('O') sont
!>  retournées comme zéros. Voir JOBR pour plus de détails à ce sujet.
!>     De plus, cette implémentation est quelque peu plus lente que celle décrite
!>  dans [1,2] en raison du remplacement de certains composants non-LAPACK, et parce que
!>  le choix de certains paramètres de réglage dans la partie itérative (ZGESVJ) est
!>  laissé à l'implémenteur sur une machine particulière.
!>     La factorisation QR révélatrice de rang (dans ce code : ZGEQP3) devrait être
!>  implémentée comme dans [3]. Nous avons une nouvelle version de ZGEQP3 en cours de développement
!>  qui est plus robuste que l'actuelle dans LAPACK, avec une coupure plus nette dans
!>  les cas de rang deficient. Elle sera disponible dans la bibliothèque SIGMA [4].
!>  Si M est beaucoup plus grand que N, il est évident que la QRF initiale avec
!>  pivotement de colonnes peut être pré-traitée par la QRF sans pivotement. Ce
!>  truc bien connu n'est pas utilisé dans ZGEJSV car dans certains cas un pondération de ligne importante peut être traitée avec un pivotement complet. Le surcoût dans les cas
!>  M beaucoup plus grand que N est alors dû uniquement au pivotement, mais les bénéfices en
!>  termes de précision l'ont emporté. L'implémenteur/utilisateur peut incorporer
!>  cette étape QRF supplémentaire facilement. L'implémenteur peut également améliorer le mouvement des données
!>  (transposition de matrice, copie de matrice, copie transposée de matrice) - cette
!>  implémentation de ZGEJSV n'utilise que le mouvement de données le plus simple et le plus naïf.
!>
