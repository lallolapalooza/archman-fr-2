Documentation de la fonction/sous-routine

subroutine zgesvj (character*1 joba, character*1 jobu, character*1 jobv, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( n ) sva, integer mv, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( lwork ) cwork, integer lwork, double precision, dimension( lrwork ) rwork, integer lrwork, integer info)

ZGESVJ

Objectif:

!>
!> ZGESVJ calcule la décomposition en valeurs singulières (SVD) d'une matrice
!> complexe A de taille M par N, où M >= N. La SVD de A s'écrit :
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^*,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> où SIGMA est une matrice diagonale de taille N par N, U est une matrice
!> orthonormale de taille M par N, et V est une matrice unitaire de taille N par N.
!> Les éléments diagonaux de SIGMA sont les valeurs singulières de A. Les colonnes
!> de U et V sont les vecteurs singuliers gauches et droits de A, respectivement.
!>

Paramètres

JOBA 
!>          JOBA est CHARACTER*1
!>          Spécifie la structure de A.
!>          = 'L': La matrice d'entrée A est triangulaire inférieure ;
!>          = 'U': La matrice d'entrée A est triangulaire supérieure ;
!>          = 'G': La matrice d'entrée A est une matrice générale M par N, M >= N.
!>

JOBU

!>          JOBU est CHARACTER*1
!>          Spécifie si les vecteurs singuliers gauches (colonnes de U) doivent
!>          être calculés :
!>          = 'U' ou 'F': Les vecteurs singuliers gauches correspondant aux valeurs
!>                 singulières non nulles sont calculés et retournés dans les
!>                 colonnes de tête de A. Voir plus de détails dans la description de A.
!>                 Le seuil d'orthogonalité numérique par défaut est défini à
!>                 environ TOL=CTOL*EPS, CTOL=SQRT(M), EPS=DLAMCH('E').
!>          = 'C': Analogue à JOBU='U', sauf que l'utilisateur peut contrôler le
!>                 niveau d'orthogonalité numérique des vecteurs singuliers gauches
!>                 calculés. TOL peut être défini à TOL = CTOL*EPS, où
!>                 CTOL est fourni en entrée dans le tableau WORK.
!>                 Aucun CTOL inférieur à ONE n'est autorisé. CTOL supérieur
!>                 à 1 / EPS n'a pas de sens. L'option 'C'
!>                 peut être utilisée si M*EPS garantit une orthogonalité
!>                 satisfaisante des vecteurs singuliers gauches calculés, donc CTOL=M
!>                 pourrait économiser quelques rotations de Jacobi.
!>                 Voir les descriptions de A et WORK(1).
!>          = 'N': La matrice U n'est pas calculée. Cependant, voir la
!>                 description de A.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          Spécifie si les vecteurs singuliers droits, c'est-à-dire la matrice V,
!>          doivent être calculés :
!>          = 'V' ou 'J': la matrice V est calculée et retournée dans le tableau V
!>          = 'A':  les rotations de Jacobi sont appliquées à la matrice de taille
!>                  MV par N initialement stockée dans les MV premières lignes de V.
!>                  Autrement dit, la matrice des vecteurs singuliers droits V n'est
!>                  pas calculée explicitement ; elle est appliquée à une matrice
!>                  MV par N initialement stockée dans les MV premières lignes de V.
!>          = 'N':  la matrice V n'est pas calculée et le tableau V n'est pas
!>                  référencé.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. 1/DLAMCH('E') > M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          En entrée, la matrice M par N, A.
!>          En sortie,
!>          Si JOBU = 'U' .OU. JOBU = 'C':
!>                 Si INFO = 0 :
!>                 RANKA colonnes orthonormées de U sont retournées dans les
!>                 colonnes de tête de RANKA dans le tableau A. Ici RANKA <= N
!>                 est le nombre de valeurs singulières calculées de A qui sont
!>                 supérieures au seuil de sous-dépassement DLAMCH('S'). Les valeurs
!>                 singulières correspondant aux valeurs nulles ou en sous-dépassement
!>                 ne sont pas calculées. La valeur de RANKA est retournée
!>                 dans le tableau RWORK sous la forme RANKA=NINT(RWORK(2)). Voir aussi les
!>                 descriptions de SVA et RWORK. Les colonnes calculées de U
!>                 sont mutuellement numériquement orthogonales jusqu'à environ
!>                 TOL=SQRT(M)*EPS (par défaut) ; ou TOL=CTOL*EPS (JOBU = 'C'),
!>                 voir la description de JOBU.
!>                 Si INFO > 0,
!>                 la procédure ZGESVJ n'a pas convergé dans le nombre donné
!>                 d'itérations (passes). Dans ce cas, les colonnes calculées
!>                 de U peuvent ne pas être orthogonales jusqu'à TOL. La sortie
!>                 U (stockée dans A), SIGMA (donnée par les valeurs singulières
!>                 calculées dans SVA(1:N)) et V forment toujours une décomposition de la
!>                 matrice d'entrée A au sens où le résidu
!>                 || A - SCALE * U * SIGMA * V^* ||_2 / ||A||_2 est petit.
!>          Si JOBU = 'N':
!>                 Si INFO = 0 :
!>                 Notez que les vecteurs singuliers gauches sont 'gratuits' dans
!>                 l'algorithme SVD de Jacobi à une seule face. Cependant, si seules les
!>                 valeurs singulières sont nécessaires, le niveau d'orthogonalité
!>                 numérique de U n'est pas un problème et les itérations sont
!>                 arrêtées lorsque les colonnes de la matrice itérée sont
!>                 numériquement orthogonales jusqu'à environ M*EPS. Ainsi,
!>                 en sortie, A contient les colonnes de U mises à l'échelle par les
!>                 valeurs singulières correspondantes.
!>                 Si INFO > 0 :
!>                 la procédure ZGESVJ n'a pas convergé dans le nombre donné
!>                 d'itérations (passes).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

SVA

!>          SVA est un tableau DOUBLE PRECISION, dimension (N)
!>          En sortie,
!>          Si INFO = 0 :
!>          selon la valeur de SCALE = RWORK(1), nous avons :
!>                 Si SCALE = ONE:
!>                 SVA(1:N) contient les valeurs singulières calculées de A.
!>                 Pendant le calcul, SVA contient les normes euclidiennes des colonnes
!>                 des matrices itérées dans le tableau A.
!>                 Si SCALE .NE. ONE:
!>                 Les valeurs singulières de A sont SCALE*SVA(1:N), et cette
!>                 représentation factorisée est due au fait que certaines des
!>                 valeurs singulières de A pourraient sous-dépasser ou dépasser.
!>
!>          Si INFO > 0 :
!>          la procédure ZGESVJ n'a pas convergé dans le nombre donné
!>          d'itérations (passes) et SCALE*SVA(1:N) peut ne pas être exact.
!>

MV

!>          MV est INTEGER
!>          Si JOBV = 'A', alors le produit des rotations de Jacobi dans ZGESVJ
!>          est appliqué aux MV premières lignes de V. Voir la description de JOBV.
!>

V

!>          V est un tableau COMPLEX*16, dimension (LDV,N)
!>          Si JOBV = 'V', alors V contient en sortie la matrice N par N des
!>                         vecteurs singuliers droits ;
!>          Si JOBV = 'A', alors V contient le produit de la matrice des vecteurs
!>                         singuliers droits calculée et de la matrice initiale dans
!>                         le tableau V.
!>          Si JOBV = 'N', alors V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale



NOM


ZGESVJ - une procédure de sous-programme de la bibliothèque LAPACK qui calcule la décomposition en valeurs singulières (SVD) d'une matrice complexe générale.




SUBROUTINE ZGESVJ(
     VJ, VJS, M, N, A, LDA, SVA, MV, V, LDV, CWORK, LWORK, RWORK, LRWORK,
     INFO )

      CHARACTER*1    VJ, VJS
      INTEGER        M, N, LDA, MV, LDV, LWORK, LRWORK, INFO
      COMPLEX*16     A( LDA, * ), V( LDV, * )
      DOUBLE PRECISION SVA( * ), CWORK( * ), RWORK( * )








Description


ZGESVJ calcule la décomposition en valeurs singulières d'une matrice complexe générale A de dimensions M-by-N à l'aide d'une méthode Jacobi à une face.


La SVD est définie comme suit :




      A = U * S * V**H



où S est une matrice diagonale réelle M-by-N dont les éléments diagonaux sont les valeurs singulières de A, U est une matrice unitaire M-by-M, et V est une matrice unitaire N-by-N. Les valeurs singulières S sont calculées dans le tableau SVA. La matrice V est calculée dans le tableau V.


La routine ZGESVJ calcule S et V de manière itérative sans calculer explicitement U.


ZGESVJ peut retourner tout ou partie des matrices V ou des matrices de transformations Jacobi qui la produisent.


L'objectif est de calculer :




      A * V = U * S



et le produit de transformations Jacobi de gauche qui opèrent sur A.


Plus spécifiquement, à la fin de la routine, la matrice A est modifiée comme suit :




      A( 1:M, 1:N ) = U * S



et la matrice V est telle que :




      A_orig * V = A * V = U * S



où A_orig est la matrice d'entrée.


Les singularités V, VJS déterminent les sorties à exécuter.




  VJ - CHARACTER*1.
       Indique si la matrice unitaire V est à calculer.
       VJ='V' : Les N colonnes de V sont calculées.
       VJ='A' : Les MV colonnes de V sont calculées.
       VJ='N' : Aucune colonne de V n'est calculée.

  VJS - CHARACTER*1.
       Indique si le produit des transformations Jacobi de gauche est à
       calculer.
       VJS='J' : Le produit des transformations Jacobi de gauche est calculé
                et retourné dans V.
       VJS='G' : A est transformé en U*S.
       VJS='A' : A est transformé en U*S et le produit des transformations
                Jacobi de gauche est retourné dans V.

  M - INTEGER.
      Ordre de la ligne de la matrice A. M >= 0.

  N - INTEGER.
      Ordre de la colonne de la matrice A. N >= 0.

  A - COMPLEX*16 array, dimension (LDA, N).
      Sur l'entrée, A contient la matrice M-by-N à décomposer.
      Sur la sortie, A est modifié par la transformation de gauche pour
      devenir U*S.

  LDA - INTEGER.
        La largeur de la bande de A. LDA >= MAX(1,M).

  SVA - DOUBLE PRECISION array, dimension (N).
        Sur la sortie, SVA contient les valeurs singulières de A dans l'ordre
        décroissant.

  MV - INTEGER.
       Si VJ='A', alors MV est le nombre de colonnes de V à calculer.
       1 <= MV <= N.

  V - COMPLEX*16 array, dimension (LDV, K).
      Si VJ = 'V', alors K = N. Si VJ = 'A', alors K = MV.
      Sur la sortie, V contient :
      Si VJS = 'J' : le produit des transformations Jacobi de gauche.
      Si VJS = 'A' : le produit des transformations Jacobi de gauche.
      Si VJS = 'G' : V n'est pas utilisé.
      Il est requis que LDV >= MAX(1,M) si VJS = 'J' ou VJS = 'A'.

  LDV - INTEGER.
        La largeur de la bande de V.
        Si VJ = 'N', alors LDV >= 1.
        Si VJ = 'V', alors LDV >= MAX(1,N).
        Si VJ = 'A', alors LDV >= MAX(1,MV).

  CWORK - COMPLEX*16 array, dimension (MAX(1,LWORK))
          Utilisé comme espace de travail.

  LWORK - INTEGER.
          La longueur de CWORK.
          LWORK >= 1, si MIN(M,N) = 0, et LWORK >= M+N, sinon.
          Si à l'entrée LWORK = -1, alors une requête d'espace de travail est
          supposée et aucun calcul n'est effectué ; CWORK(1) est défini à la
          longueur minimale (et optimale) de CWORK.

  RWORK - DOUBLE PRECISION array, dimension (max(6,LRWORK))
          À l'entrée,
          Si JOBU = 'C' :
          RWORK(1) = CTOL, où CTOL définit le seuil de convergence.
                     Le processus s'arrête si toutes les colonnes de A sont
                     mutuellement orthogonales jusqu'à CTOL*EPS, EPS=DLAMCH('E').
                     Il est requis que CTOL >= ONE, c'est-à-dire qu'il n'est
                     pas permis de forcer la routine à obtenir une orthogonalité
                     en dessous d'EPSILON.
          À la sortie,
          RWORK(1) = SCALE est le facteur d'échelle tel que SCALE*SVA(1:N)
                     sont les valeurs singulières calculées de A.
                     (Voir la description de SVA().)
          RWORK(2) = NINT(RWORK(2)) est le nombre de valeurs singulières
                     non nulles calculées.
          RWORK(3) = NINT(RWORK(3)) est le nombre de valeurs singulières
                     calculées qui sont supérieures au seuil de sous-dépassement.
          RWORK(4) = NINT(RWORK(4)) est le nombre de balayages de rotations
                     de Jacobi nécessaires à la convergence numérique.
          RWORK(5) = max_{i.NE.j} |COS(A(:,i),A(:,j))| dans le dernier balayage.
                     Ceci est une information utile dans les cas où ZGESVJ
                     n'a pas convergé, car elle peut être utilisée pour estimer
                     si la sortie est toujours utile et pour une analyse a
                     posteriori.
          RWORK(6) = la plus grande valeur absolue sur tous les sinus des angles
                     de rotation de Jacobi dans le dernier balayage. Elle peut
                     être utile pour une analyse a posteriori.

  LRWORK - INTEGER
           La longueur de RWORK.
           LRWORK >= 1, si MIN(M,N) = 0, et LRWORK >= MAX(6,N), sinon.
           Si à l'entrée LRWORK = -1, alors une requête d'espace de travail est
           supposée et aucun calcul n'est effectué ; RWORK(1) est défini à la
           longueur minimale (et optimale) de RWORK.

  INFO - INTEGER
         = 0 : sortie réussie.
         < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale
         > 0 : ZGESVJ n'a pas convergé dans le nombre maximal autorisé
               (NSWEEP=30) de balayages. La sortie peut toujours être utile.
               Voir la description de RWORK.

Détails supplémentaires :




La matrice unitaire N-par-N V est obtenue comme un produit de rotations planes
de Jacobi. Dans le cas de sous-dépassement de la tangente de l'angle de Jacobi,
une transformation de Jacobi modifiée de Drmac [3] est utilisée. La stratégie
de pivot utilise des échanges de colonnes de de Rijk [1]. La précision relative
des valeurs singulières calculées et la précision des vecteurs singuliers
calculés (en métrique angulaire) sont telles que garanties par la théorie de
Demmel et Veselic [2]. Le conditionnement qui détermine la précision dans le
cas de rang plein est essentiellement min_{D=diag} kappa(A*D), où kappa(.) est le
conditionnement spectral. Les meilleures performances de cette procédure Jacobi SVD
sont obtenues si elle est utilisée dans une version accélérée de Drmac et
Veselic [4,5], et c'est la routine noyau de la bibliothèque SIGMA [6].
Certains paramètres de réglage (marqués avec [TP]) sont disponibles pour l'implémenteur.
La plage de calcul pour les valeurs singulières non nulles est l'intervalle
des nombres machine ( SOUS-DÉPASSEMENT , DÉPASSEMENT ). Dans des cas extrêmes,
même des valeurs singulières dénormalisées peuvent être calculées avec la perte
correspondante de chiffres précis.
