Documentation de la fonction/sous-routine

sous-routine zget08 (caractère trans, entier m, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldx, * ) x, entier ldx, complexe*16, dimension( ldb, * ) b, entier ldb, double précision, dimension( * ) rwork, double précision resid)

ZGET08

But :

!>
!> ZGET08 calcule le résidu pour une solution d'un système d'équations
!> linéaires  A*x = b  ou  A'*x = b :
!>    RESID = norm(B - A*X) / ( norm(A) * norm(X) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N' :  A *x = b
!>          = 'T' :  A^T*x = b, où A^T est la transposée de A
!>          = 'C' :  A^H*x = b, où A^H est la transposée conjuguée de A
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de colonnes de B, la matrice des seconds membres.
!>          NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice originale A de taille M x N.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Les vecteurs solutions calculés pour le système d'équations
!>          linéaires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  Si TRANS = 'N',
!>          LDX >= max(1,N); si TRANS = 'T' ou 'C', LDX >= max(1,M).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          En entrée, les vecteurs du second membre pour le système d'équations
!>          linéaires.
!>          En sortie, B est écrasé par la différence B - A*X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  Si TRANS = 'N',
!>          LDB >= max(1,M); si TRANS = 'T' ou 'C', LDB >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (M)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          Le maximum sur le nombre de seconds membres de
!>          norm(B - A*X) / ( norm(A) * norm(X) * EPS ).
!>
