sous-routine zget52 (logical left, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( lde, * ) e, integer lde, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, double precision, dimension( 2 ) result)

ZGET52

But :

!>
!> ZGET52  effectue une vérification des vecteurs propres pour le
!> problème aux valeurs propres généralisées.
!>
!> Le test de base pour les vecteurs propres droits est :
!>
!>                           | b(i) A E(i) -  a(i) B E(i) |
!>         RESULT(1) = max   -------------------------------
!>                      i    n ulp max( |b(i) A|, |a(i) B| )
!>
!> en utilisant la norme 1. Ici, a(i)/b(i) = w est la i-ème valeur propre
!> généralisée de A - w B, ou, de manière équivalente, b(i)/a(i) = m est
!> la i-ème valeur propre généralisée de m A - B.
!>
!>                         H   H  _      _
!> Pour les vecteurs propres gauches, A , B , a, et b  sont utilisés.
!>
!> ZGET52 teste également la normalisation de E. Chaque vecteur propre est
!> censé être normalisé de telle sorte que le maximum
!> de ses éléments soit 1, où dans ce cas,
!> d'une valeur complexe x est |Re(x)| + |Im(x)| ; appelons cela
!> la norme maximale d'un vecteur v, M(v).
!> Si a(i)=b(i)=0, alors le vecteur propre est défini comme le i-ème vecteur
!> de base canonique. Le test de normalisation est :
!>
!>         RESULT(2) =      max       | M(v(i)) - 1 | / ( n ulp )
!>                    vecteurs propres v(i)
!>
!>

Paramètres

LEFT 
!>          LEFT est LOGICAL
!>          =.TRUE. : Les vecteurs propres dans les colonnes de E sont supposés
!>                    être des vecteurs propres *gauche*.
!>          =.FALSE. : Les vecteurs propres dans les colonnes de E sont supposés
!>                    être des vecteurs propres *droits*.
!>

N

!>          N est INTEGER
!>          La taille des matrices. Si elle est nulle, ZGET52 ne fait
!>          rien. Elle doit être supérieure ou égale à zéro.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>          La matrice A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A. Elle doit être supérieure ou égale à 1
!>          et supérieure ou égale à N.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB, N)
!>          La matrice B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de B. Elle doit être supérieure ou égale à 1
!>          et supérieure ou égale à N.
!>

E

!>          E est un tableau COMPLEX*16, dimension (LDE, N)
!>          La matrice des vecteurs propres. Elle doit être de taille O( 1 ).
!>

LDE

!>          LDE est INTEGER
!>          La dimension principale de E. Elle doit être supérieure ou égale à 1 et
!>          supérieure ou égale à N.
!>

ALPHA

!>          ALPHA est un tableau COMPLEX*16, dimension (N)
!>          Les valeurs a(i) décrites ci-dessus, qui, avec b(i),
!>          définissent les valeurs propres généralisées.
!>

BETA

!>          BETA est un tableau COMPLEX*16, dimension (N)
!>          Les valeurs b(i) décrites ci-dessus, qui, avec a(i),
!>          définissent les valeurs propres généralisées.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N**2)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, dimension (2)
!>          Les valeurs calculées par le test décrit ci-dessus. Si A E ou
!>          B E risque de déborder, alors RESULT(1:2) est mis à
!>          10 / ulp.
!>
