sous-routine zgegs (caractère jobvsl, caractère jobvsr, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( * ) alpha, complexe*16, dimension( * ) beta, complexe*16, dimension( ldvsl, * ) vsl, entier ldvsl, complexe*16, dimension( ldvsr, * ) vsr, entier ldvsr, complexe*16, dimension( * ) work, entier lwork, double précision, dimension( * ) rwork, entier info)

ZGEGS calcule les valeurs propres, la forme de Schur, et, éventuellement, les vecteurs de Schur gauches et/ou droits d'une paire de matrices complexes (A,B)

But :

!>
!> Cette routine est obsolète et a été remplacée par la routine ZGGES.
!>
!> ZGEGS calcule les valeurs propres, la forme de Schur, et, éventuellement, les
!> vecteurs de Schur gauches et/ou droits d'une paire de matrices complexes (A,B).
!> Étant donné deux matrices carrées A et B, la factorisation de Schur généralisée
!> a la forme
!>
!>    A = Q*S*Z**H,  B = Q*T*Z**H
!>
!> où Q et Z sont des matrices unitaires et S et T sont triangulaires supérieures.
!> Les colonnes de Q sont les vecteurs de Schur gauches
!> et les colonnes de Z sont les vecteurs de Schur droits.
!>
!> Si seules les valeurs propres de (A,B) sont nécessaires, la routine pilote
!> ZGEGV doit être utilisée à la place. Voir ZGEGV pour une description des
!> valeurs propres du problème aux valeurs propres généralisées non symétriques
!> (GNEP).
!>

Paramètres

JOBVSL 
!>          JOBVSL est CARACTÈRE*1
!>          = 'N' : ne pas calculer les vecteurs de Schur gauches ;
!>          = 'V' : calculer les vecteurs de Schur gauches (renvoyés dans VSL).
!>

JOBVSR

!>          JOBVSR est CARACTÈRE*1
!>          = 'N' : ne pas calculer les vecteurs de Schur droits ;
!>          = 'V' : calculer les vecteurs de Schur droits (renvoyés dans VSR).
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A, B, VSL et VSR.  N >= 0.
!>

A

!>          A est tableau COMPLEX*16, dimension (LDA, N)
!>          En entrée, la matrice A.
!>          En sortie, la matrice triangulaire supérieure S de la factorisation de Schur
!>          généralisée.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale de A.  LDA >= max(1,N).
!>

B

!>          B est tableau COMPLEX*16, dimension (LDB, N)
!>          En entrée, la matrice B.
!>          En sortie, la matrice triangulaire supérieure T de la factorisation de Schur
!>          généralisée.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale de B.  LDB >= max(1,N).
!>

ALPHA

!>          ALPHA est tableau COMPLEX*16, dimension (N)
!>          Les scalaires complexes alpha qui définissent les valeurs propres
!>          de GNEP.  ALPHA(j) = S(j,j), l'élément diagonal de la forme de Schur
!>          de A.
!>

BETA

!>          BETA est tableau COMPLEX*16, dimension (N)
!>          Les scalaires réels non négatifs beta qui définissent les
!>          valeurs propres de GNEP.  BETA(j) = T(j,j), l'élément diagonal
!>          du facteur triangulaire T.
!>
!>          Ensemble, les quantités alpha = ALPHA(j) et beta = BETA(j)
!>          représentent la j-ème valeur propre de la paire de matrices (A,B), sous
!>          l'une des formes lambda = alpha/beta ou mu = beta/alpha.
!>          Comme lambda ou mu peuvent déborder, elles ne doivent, en général, pas être calculées.
!>

VSL

!>          VSL est tableau COMPLEX*16, dimension (LDVSL,N)
!>          Si JOBVSL = 'V', la matrice des vecteurs de Schur gauches Q.
!>          Non référencé si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL est ENTIER
!>          La dimension principale de la matrice VSL. LDVSL >= 1, et
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR est tableau COMPLEX*16, dimension (LDVSR,N)
!>          Si JOBVSR = 'V', la matrice des vecteurs de Schur droits Z.
!>          Non référencé si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR est ENTIER
!>          La dimension principale de la matrice VSR. LDVSR >= 1, et
!>          si JOBVSR = 'V', LDVSR >= N.
!>

WORK

!>          WORK est tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.  LWORK >= max(1,2*N).
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>          Pour calculer la valeur optimale de LWORK, appelez ILAENV pour obtenir
!>          les tailles de blocs (pour ZGEQRF, ZUNMQR, et CUNGQR.)  Puis calculez :
!>          NB  -- MAX des tailles de blocs pour ZGEQRF, ZUNMQR, et CUNGQR ;
!>          le LWORK optimal est N*(NB+1).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est tableau DOUBLE PRÉCISION, dimension (3*N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          =1,...,N :
!>                L'itération QZ a échoué.  (A,B) ne sont pas sous forme de Schur,
!>                mais ALPHA(j) et BETA(j) devraient être corrects pour
!>                j=INFO+1,...,N.
!>          > N : erreurs qui indiquent généralement des problèmes LAPACK :
!>                =N+1 : retour d'erreur de ZGGBAL
!>                =N+2 : retour d'erreur de ZGEQRF
!>                =N+3 : retour d'erreur de ZUNMQR
!>                =N+4 : retour d'erreur de ZUNGQR
!>                =N+5 : retour d'erreur de ZGGHRD
!>                =N+6 : retour d'erreur de ZHGEQZ (autre que l'itération échouée)
!>                =N+7 : retour d'erreur de ZGGBAK (calcul de VSL)
!>                =N+8 : retour d'erreur de ZGGBAK (calcul de VSR)
!>                =N+9 : retour d'erreur de ZLASCL (divers endroits)
!>
