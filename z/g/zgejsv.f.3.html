Documentation de la fonction/sous-routine

sous-routine zgejsv (caractère*1 joba, caractère*1 jobu, caractère*1 jobv, caractère*1 jobr, caractère*1 jobt, caractère*1 jobp, entier m, entier n, complexe*16, dimension( lda, * ) a, entier lda, double précision, dimension( n ) sva, complexe*16, dimension( ldu, * ) u, entier ldu, complexe*16, dimension( ldv, * ) v, entier ldv, complexe*16, dimension( lwork ) cwork, entier lwork, double précision, dimension( lrwork ) rwork, entier lrwork, entier, dimension( * ) iwork, entier info)

Objectif :

!>
!> ZGEJSV calcule la décomposition en valeurs singulières (SVD) d'une matrice complexe M-par-N [A],
!> où M >= N. La SVD de [A] s'écrit :
!>
!>              [A] = [U] * [SIGMA] * [V]^*,
!>
!> où [SIGMA] est une matrice N-par-N (M-par-N) nulle à l'exception de ses N
!> éléments diagonaux, [U] est une matrice unitaire M-par-N (ou M-par-M), et
!> [V] est une matrice unitaire N-par-N. Les éléments diagonaux de [SIGMA] sont
!> les valeurs singulières de [A]. Les colonnes de [U] et [V] sont les vecteurs singuliers gauches et
!> droits de [A], respectivement. Les matrices [U] et [V]
!> sont calculées et stockées dans les tableaux U et V, respectivement. La diagonale de [SIGMA] est calculée et stockée dans le tableau SVA.
!>

Paramètres

JOBA 
!>          JOBA est CHARACTER*1
!>         Spécifie le niveau de précision :
!>       = 'C' : Cette option fonctionne bien (haute précision relative) si A = B * D,
!>              avec B bien conditionnée et D matrice diagonale arbitraire.
!>              La précision ne peut pas être détériorée par la mise à l'échelle des COLONNES. La
!>              précision du résultat dépend du conditionnement de
!>              B, et la procédure vise la meilleure précision théorique.
!>              L'erreur relative max_{i=1:N}|d sigma_i| / sigma_i est
!>              bornée par f(M,N)*epsilon* cond(B), indépendamment de D.
!>              La matrice d'entrée est prétraitée avec la QR avec pivotement
!>              par colonne. Ce prétraitement initial et le préconditionnement par
!>              une factorisation QR révélatrice de rang sont courants pour toutes les valeurs de
!>              JOBA. Les actions supplémentaires sont spécifiées comme suit :
!>       = 'E' : Calcul comme avec 'C' avec une estimation supplémentaire du
!>              nombre de conditionnement de B. Il fournit une borne d'erreur réaliste.
!>       = 'F' : Si A = D1 * C * D2 avec des mises à l'échelle diagonales mal
!>              conditionnées D1, D2, et une matrice C bien conditionnée, cette option donne
!>              une précision plus élevée que l'option 'C'. Si la structure de la
!>              matrice d'entrée n'est pas connue, et que la précision relative est
!>              souhaitée, alors cette option est conseillée. La matrice d'entrée A
!>              est prétraitée avec la factorisation QR avec pivotement COMPLET (ligne et
!>              colonne).
!>       = 'G' : Calcul comme avec 'F' avec une estimation supplémentaire du
!>              nombre de conditionnement de B, où A=B*D. Si A a des lignes fortement pondérées,
!>              alors l'utilisation de ce nombre de conditionnement donne une borne d'erreur trop pessimiste.
!>       = 'A' : Les valeurs singulières petites ne sont pas bien déterminées par les données
!>              et sont considérées comme bruitées ; la matrice est traitée comme
!>              numériquement de rang déficient. L'erreur dans les valeurs
!>              singulières calculées est bornée par f(m,n)*epsilon*||A||.
!>              La SVD calculée A = U * S * V^* restaure A jusqu'à
!>              f(m,n)*epsilon*||A||.
!>              Ceci donne au procédé la licence de rejeter (mettre à zéro)
!>              toutes les valeurs singulières inférieures à N*epsilon*||A||.
!>       = 'R' : Similaire à 'A'. La propriété révélatrice de rang de la factorisation
!>              QR initiale est utilisée pour révéler (en utilisant le facteur triangulaire)
!>              un écart sigma_{r+1} < epsilon * sigma_r auquel cas le
!>              RANG numérique est déclaré comme étant r. La SVD est calculée avec
!>              des bornes d'erreur absolues, mais plus précisément qu'avec 'A'.
!>

JOBU

!>          JOBU est CHARACTER*1
!>         Spécifie si les colonnes de U doivent être calculées :
!>       = 'U' : N colonnes de U sont retournées dans le tableau U.
!>       = 'F' : l'ensemble complet des M vecteurs singuliers gauches est retourné dans le tableau U.
!>       = 'W' : U peut être utilisé comme espace de travail de longueur M*N. Voir la description
!>              de U.
!>       = 'N' : U n'est pas calculé.
!>

JOBV

!>          JOBV est CHARACTER*1
!>         Spécifie si la matrice V doit être calculée :
!>       = 'V' : N colonnes de V sont retournées dans le tableau V ; les rotations de Jacobi
!>              ne sont pas explicitement accumulées.
!>       = 'J' : N colonnes de V sont retournées dans le tableau V, mais elles sont
!>              calculées comme produit de rotations de Jacobi, si JOBT = 'N'.
!>       = 'W' : V peut être utilisé comme espace de travail de longueur N*N. Voir la description
!>              de V.
!>       = 'N' : V n'est pas calculé.
!>

JOBR

!>          JOBR est CHARACTER*1
!>         Spécifie la PLAGE pour les valeurs singulières. Donne la licence
!>         de mettre à zéro les petites valeurs singulières positives si elles sont hors de
!>         la plage spécifiée. Si A .NE. 0 est mise à l'échelle de sorte que la plus grande valeur
!>         singulière de c*A soit autour de SQRT(BIG), BIG=DLAMCH('O'), alors JOBR donne
!>         la licence de supprimer les colonnes de A dont la norme dans c*A est inférieure à
!>         SQRT(SFMIN) (pour JOBR = 'R'), ou inférieure à SMALL=SFMIN/EPSLN,
!>         où SFMIN=DLAMCH('S'), EPSLN=DLAMCH('E').
!>       = 'N' : Ne supprime pas les petites colonnes de c*A. Cette option suppose que
!>              BLAS et les factorisations QR et les solveurs triangulaires sont
!>              implémentés pour travailler dans cette plage. Si le conditionnement de A
!>              est supérieur à BIG, utilisez ZGESVJ.
!>       = 'R' : Plage RESTREINTE pour sigma(c*A) est [SQRT(SFMIN), SQRT(BIG)]
!>              (approximativement, comme décrit ci-dessus). Cette option est recommandée.
!>                                             ===========================
!>         Pour calculer les valeurs singulières dans la plage COMPLETE [SFMIN,BIG],
!>         utilisez ZGESVJ.
!>

JOBT

!>          JOBT est CHARACTER*1
!>         Si la matrice est carrée, le procédé peut décider d'utiliser
!>         A transposée si A^* semble être meilleure en termes de convergence.
!>         Si la matrice n'est pas carrée, JOBT est ignoré.
!>         La décision est basée sur deux valeurs d'entropie sur l'orbite adjointe
!>         de A^* * A. Voir les descriptions de RWORK(6) et RWORK(7).
!>       = 'T' : transposer si le test d'entropie indique une convergence potentiellement plus rapide
!>         du procédé de Jacobi si A^* est prise comme entrée. Si A est
!>         remplacée par A^*, alors le pivotement de ligne est inclus automatiquement.
!>       = 'N' : ne pas spéculer.
!>         L'option 'T' peut être utilisée pour ne calculer que les valeurs singulières, ou
!>         la SVD complète (U, SIGMA et V). Pour un seul ensemble de vecteurs singuliers
!>         (U ou V), l'appelant doit fournir U et V, car l'une des
!>         matrices est utilisée comme espace de travail si la matrice A est transposée.
!>         L'implémenteur peut facilement supprimer cette contrainte et rendre le
!>         code plus compliqué. Voir les descriptions de U et V.
!>         En général, cette option est considérée comme expérimentale, et 'N'
!>         devrait être préférée. Ceci est sujet à changement à l'avenir.
!>

!>         Donne la licence d'introduire des perturbations structurées pour masquer
!>         les nombres dénormalisés. Cette licence doit être active si le

NAME


ZGEJSV - Computes the singular value decomposition (SVD) of a complex
  general matrix A,


where A = U*SIGMA*V^H.






SYNOPSIS


SUBROUTINE ZGEJSV( JOBA, JOBV, JOBT, JOBP, LWORK, A, LDA, B, LDB, ALPHA,
                     RWORK, LRWORK, IWORK, INFO )
  CHARACTER         JOBA, JOBV, JOBT
  INTEGER           LDA, LDB, LWORK, LRWORK, INFO
  COMPLEX*16        ALPHA
  COMPLEX*16        A( * ), B( * )
  DOUBLE PRECISION  RWORK( * )
  INTEGER           IWORK( * )







Function/Subroutine Documentation


ZGEJSV Computes the singular value decomposition (SVD) of a complex
  general matrix A, where A = U*SIGMA*V^H. The elements of SIGMA are the
  singular values of A, the columns of U are the left singular vectors of A, and
  the columns of V are the right singular vectors of A.


This subroutine is a driver for ZGEJSV, which implements a preconditioned
  Jacobi SVD algorithm. It uses ZGEQP3 and ZGEQRF as pre-processors and
  preconditioners. Optionally, an additional row pivoting can be used as a
  preprocessor, which in some cases results in much higher accuracy.


The matrix A is an M-by-N matrix. If M < N, A is transposed to
  A^H to compute the SVD.

Further Details:




ZGEJSV implements a preconditioned Jacobi SVD algorithm. It uses ZGEQP3,
ZGEQRF, and ZGELQF as preprocessors and preconditioners. Optionally, an
additional row pivoting can be used as a preprocessor, which in some
cases results in much higher accuracy. An example is matrix A with the
structure A = D1 * C * D2, where D1, D2 are arbitrarily ill-conditioned
diagonal matrices and C is well-conditioned matrix. In that case, complete
pivoting in the first QR factorizations provides accuracy dependent on the
condition number of C, and independent of D1, D2. Such higher accuracy is
not completely understood theoretically, but it works well in practice.
Further, if A can be written as A = B*D, with well-conditioned B and some
diagonal D, then the high accuracy is guaranteed, both theoretically and
in software, independent of D. For more details see [1], [2].
The computational range for the singular values can be the full range
( UNDERFLOW,OVERFLOW ), provided that the machine arithmetic and the BLAS
& LAPACK routines called by ZGEJSV are implemented to work in that range.
If that is not the case, then the restriction for safe computation with
the singular values in the range of normalized IEEE numbers is that the
spectral condition number kappa(A)=sigma_max(A)/sigma_min(A) does not
overflow. This code (ZGEJSV) is best used in this restricted range,
meaning that singular values of magnitude below ||A||_2 / DLAMCH('O') are
returned as zeros. See JOBR for details on this.
Further, this implementation is somewhat slower than the one described
in [1,2] due to replacement of some non-LAPACK components, and because
the choice of some tuning parameters in the iterative part (ZGESVJ) is
left to the implementer on a particular machine.
The rank revealing QR factorization (in this code: ZGEQP3) should be
implemented as in [3]. We have a new version of ZGEQP3 under development
that is more robust than the current one in LAPACK, with a cleaner cut in
rank deficient cases. It will be available in the SIGMA library [4].
If M is much larger than N, it is obvious that the initial QRF with
column pivoting can be preprocessed by the QRF without pivoting. That
well known trick is not used in ZGEJSV because in some cases heavy row
weighting can be treated with complete pivoting. The overhead in cases
M much larger than N is then only due to pivoting, but the benefits in
terms of accuracy have prevailed. The implementer/user can incorporate
this extra QRF step easily. The implementer can also improve data movement
(matrix transpose, matrix copy, matrix transposed copy) - this
implementation of ZGEJSV uses only the simplest, naive data movement.
