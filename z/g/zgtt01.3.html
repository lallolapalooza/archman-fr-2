sous-routine zgtt01 (entier n, complexe*16, dimension( * ) dl, complexe*16, dimension( * ) d, complexe*16, dimension( * ) du, complexe*16, dimension( * ) dlf, complexe*16, dimension( * ) df, complexe*16, dimension( * ) duf, complexe*16, dimension( * ) du2, entier, dimension( * ) ipiv, complexe*16, dimension( ldwork, * ) work, entier ldwork, double précision, dimension( * ) rwork, double précision resid)

ZGTT01

Objectif :

!>
!> ZGTT01 reconstruit une matrice tridiagonale A à partir de sa factorisation LU
!> et calcule le résidu
!>    norm(L*U - A) / ( norm(A) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

DL

!>          DL est un tableau COMPLEX*16, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de A.
!>

D

!>          D est un tableau COMPLEX*16, dimension (N)
!>          Les éléments diagonaux de A.
!>

DU

!>          DU est un tableau COMPLEX*16, dimension (N-1)
!>          Les (n-1) éléments super-diagonaux de A.
!>

DLF

!>          DLF est un tableau COMPLEX*16, dimension (N-1)
!>          Les (n-1) multiplicateurs qui définissent la matrice L à partir de la
!>          factorisation LU de A.
!>

DF

!>          DF est un tableau COMPLEX*16, dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire supérieure U à partir de
!>          la factorisation LU de A.
!>

DUF

!>          DUF est un tableau COMPLEX*16, dimension (N-1)
!>          Les (n-1) éléments de la première super-diagonale de U.
!>

DU2

!>          DU2 est un tableau COMPLEX*16, dimension (N-2)
!>          Les (n-2) éléments de la deuxième super-diagonale de U.
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= n, la ligne i de la matrice a été
!>          échangée avec la ligne IPIV(i).  IPIV(i) sera toujours égal à
!>          i ou i+1 ; IPIV(i) = i indique qu'un échange de ligne n'était pas
!>          nécessaire.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LDWORK,N)
!>

LDWORK

!>          LDWORK est ENTIER
!>          La dimension principale du tableau WORK.  LDWORK >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRÉCISION
!>          Le résidu normalisé :  norm(L*U - A) / (norm(A) * EPS)
!>
