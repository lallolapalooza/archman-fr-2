Documentation de la fonction/sous-routine

sous-routine zggrqf (integer m, integer p, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) taua, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) taub, complex*16, dimension( * ) work, integer lwork, integer info)

ZGGRQF

But:

!>
!> ZGGRQF calcule une factorisation généralisée RQ d'une matrice M×N A
!> et d'une matrice P×N B :
!>
!>             A = R*Q,        B = Z*T*Q,
!>
!> où Q est une matrice unitaire N×N, Z est une matrice unitaire P×P,
!> et R et T prennent l'une des formes suivantes :
!>
!> si M <= N,  R = ( 0  R12 ) M,   ou si M > N,  R = ( R11 ) M-N,
!>                  N-M  M                           ( R21 ) N
!>                                                      N
!>
!> où R12 ou R21 est triangulaire supérieure, et
!>
!> si P >= N,  T = ( T11 ) N  ,   ou si P < N,  T = ( T11  T12 ) P,
!>                 (  0  ) P-N                         P   N-P
!>                    N
!>
!> où T11 est triangulaire supérieure.
!>
!> En particulier, si B est carrée et non singulière, la factorisation GRQ
!> de A et B donne implicitement la factorisation RQ de A*inv(B) :
!>
!>              A*inv(B) = (R*inv(T))*Z**H
!>
!> où inv(B) désigne l'inverse de la matrice B, et Z**H désigne la
!> transposée conjuguée de la matrice Z.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B. N >= 0.
!>

A

!>          A est tableau COMPLEX*16, dimension (LDA,N)
!>          En entrée, la matrice M×N A.
!>          En sortie, si M <= N, le triangle supérieur du sous-tableau
!>          A(1:M,N-M+1:N) contient la matrice triangulaire supérieure R M×M ;
!>          si M > N, les éléments sur et au-dessus de la (M-N)-ième sous-diagonale
!>          contiennent la matrice trapézoïdale supérieure R M×N ; les éléments restants,
!>          avec le tableau TAUA, représentent la matrice unitaire
!>          Q comme un produit de réflecteurs élémentaires (voir Détails supplémentaires).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

TAUA

!>          TAUA est tableau COMPLEX*16, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires qui
!>          représentent la matrice unitaire Q (voir Détails supplémentaires).
!>

B

!>          B est tableau COMPLEX*16, dimension (LDB,N)
!>          En entrée, la matrice P×N B.
!>          En sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice trapézoïdale supérieure min(P,N)×N T (T est
!>          triangulaire supérieure si P >= N) ; les éléments sous la diagonale,
!>          avec le tableau TAUB, représentent la matrice unitaire Z comme un
!>          produit de réflecteurs élémentaires (voir Détails supplémentaires).
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,P).
!>

TAUB

!>          TAUB est tableau COMPLEX*16, dimension (min(P,N))
!>          Les facteurs scalaires des réflecteurs élémentaires qui
!>          représentent la matrice unitaire Z (voir Détails supplémentaires).
!>

WORK

!>          WORK est tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la LWORK optimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,N,M,P).
!>          Pour une performance optimale LWORK >= max(N,M,P)*max(NB1,NB2,NB3),
!>          où NB1 est la taille de bloc optimale pour la factorisation RQ
!>          d'une matrice M×N, NB2 est la taille de bloc optimale pour la
!>          factorisation QR d'une matrice P×N, et NB3 est la taille de bloc optimale
!>          pour un appel à ZUNMRQ.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  exécution réussie
!>          < 0:  si INFO=-i, le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires:

!>
!>  La matrice Q est représentée comme un produit de réflecteurs élémentaires
!>
!>     Q = H(1) H(2) . . . H(k), où k = min(m,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - taua * v * v**H
!>
!>  où taua est un scalaire complexe, et v est un vecteur complexe avec
!>  v(n-k+i+1:n) = 0 et v(n-k+i) = 1 ; v(1:n-k+i-1) est stocké en sortie dans
!>  A(m-k+i,1:n-k+i-1), et taua dans TAUA(i).
!>  Pour former Q explicitement, utiliser la sous-routine LAPACK ZUNGRQ.
!>  Pour utiliser Q pour mettre à jour une autre matrice, utiliser la sous-routine LAPACK ZUNMRQ.
!>
!>  La matrice Z est représentée comme un produit de réflecteurs élémentaires
!>
!>     Z = H(1) H(2) . . . H(k), où k = min(p,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - taub * v * v**H
!>
!>  où taub est un scalaire complexe, et v est un vecteur complexe avec
!>  v(1:i-1) = 0 et v(i) = 1 ; v(i+1:p) est stocké en sortie dans B(i+1:p,i),
!>  et taub dans TAUB(i).
!>  Pour former Z explicitement, utiliser la sous-routine LAPACK ZUNGQR.
!>  Pour utiliser Z pour mettre à jour une autre matrice, utiliser la sous-routine LAPACK ZUNMQR.
!>
