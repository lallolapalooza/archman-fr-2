sous-programme zgbt02 (caractere trans, entier m, entier n, entier kl, entier ku, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldx, * ) x, entier ldx, complexe*16, dimension( ldb, * ) b, entier ldb, double precision, dimension( * ) rwork, double precision resid)

ZGBT02

But :

!>
!> ZGBT02 calcule le résidu pour une solution d'un système d'équations bande
!> op(A)*X = B:
!>    RESID = norm(B - op(A)*X) / ( norm(op(A)) * norm(X) * EPS ),
!> où op(A) = A, A**T, ou A**H, selon TRANS, et EPS est l'epsilon machine.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N':  A    * X = B  (Pas de transposer)
!>          = 'T':  A**T * X = B  (Transposer)
!>          = 'C':  A**H * X = B  (Conjugué transposé)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>          Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>          Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de colonnes de B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice originale A en stockage bande, stockée dans les lignes 1 à
!>          KL+KU+1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,KL+KU+1).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Les vecteurs solutions calculés pour le système d'équations
!>          linéaires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  Si TRANS = 'N',
!>          LDX >= max(1,N) ; si TRANS = 'T' ou 'C', LDX >= max(1,M).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          En entrée, les vecteurs du second membre pour le système d'équations
!>          linéaires.
!>          En sortie, B est écrasé par la différence B - A*X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  Si TRANS = 'N',
!>          LDB >= max(1,M) ; si TRANS = 'T' ou 'C', LDB >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LRWORK)),
!>          où LRWORK >= M lorsque TRANS = 'T' ou 'C' ; sinon, RWORK
!>          n'est pas référencé.
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          Le maximum sur le nombre de seconds membres de
!>          norm(B - op(A)*X) / ( norm(op(A)) * norm(X) * EPS ).
!>
