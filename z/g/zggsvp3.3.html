ZGGSVP3

But :

!>
!> ZGGSVP3 calcule les matrices unitaires U, V et Q telles que
!>
!>                    N-K-L  K    L
!>  U**H*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**H*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> où la matrice A12 de taille KxK et la matrice B13 de taille LxL sont inversibles
!> triangulaires supérieures; A23 est triangulaire supérieure LxL si M-K-L >= 0,
!> sinon A23 est trapézoïdale supérieure (M-K)xL. K+L = le rang numérique effectif
!> de la matrice (M+P)xN (A**H,B**H)**H.
!>
!> Cette décomposition est l'étape de prétraitement pour calculer la
!> Décomposition en Valeurs Singulières Généralisées (GSVD), voir la sous-routine
!> ZGGSVD3.
!>

Paramètres

JOBU 
!>          JOBU est CHARACTER*1
!>          = 'U' : la matrice unitaire U est calculée ;
!>          = 'N' : U n'est pas calculée.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          = 'V' : la matrice unitaire V est calculée ;
!>          = 'N' : V n'est pas calculée.
!>

JOBQ

!>          JOBQ est CHARACTER*1
!>          = 'Q' : la matrice unitaire Q est calculée ;
!>          = 'N' : Q n'est pas calculée.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de la matrice B. P >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B. N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          En entrée, la matrice A de taille M x N.
!>          En sortie, A contient la matrice triangulaire (ou trapézoïdale)
!>          décrite dans la section But.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,N)
!>          En entrée, la matrice B de taille P x N.
!>          En sortie, B contient la matrice triangulaire décrite dans
!>          la section But.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,P).
!>

TOLA

!>          TOLA est DOUBLE PRECISION
!>

TOLB

!>          TOLB est DOUBLE PRECISION
!>
!>          TOLA et TOLB sont les seuils pour déterminer le rang numérique effectif
!>          de la matrice B et d'un sous-bloc de A. Généralement,
!>          ils sont définis comme suit :
!>             TOLA = MAX(M,N)*norm(A)*MAZHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MAZHEPS.
!>          La taille de TOLA et TOLB peut affecter les erreurs inverses
!>          de la décomposition.
!>

K

!>          K est INTEGER
!>

L

!>          L est INTEGER
!>
!>          En sortie, K et L spécifient la dimension des sous-blocs
!>          décrits dans la section But.
!>          K + L = rang numérique effectif de (A**H,B**H)**H.
!>

U

!>          U est un tableau COMPLEX*16, dimension (LDU,M)
!>          Si JOBU = 'U', U contient la matrice unitaire U.
!>          Si JOBU = 'N', U n'est pas référencé.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= max(1,M) si
!>          JOBU = 'U' ; LDU >= 1 sinon.
!>

V

!>          V est un tableau COMPLEX*16, dimension (LDV,P)
!>          Si JOBV = 'V', V contient la matrice unitaire V.
!>          Si JOBV = 'N', V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V. LDV >= max(1,P) si
!>          JOBV = 'V' ; LDV >= 1 sinon.
!>

Q

!>          Q est un tableau COMPLEX*16, dimension (LDQ,N)
!>          Si JOBQ = 'Q', Q contient la matrice unitaire Q.
!>          Si JOBQ = 'N', Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q' ; LDQ >= 1 sinon.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (2*N)
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (N)
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>
