subroutine zgbequ (m, n, kl, ku, ab, ldab, r, c, rowcnd, colcnd, amax, info)
ZGBEQU

Documentation de la fonction/sous-programme

sous-programme zgbequ (integer m, integer n, integer kl, integer ku, complex*16, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision rowcnd, double precision colcnd, double precision amax, integer info)

ZGBEQU

Objectif :

!>
!> ZGBEQU calcule des facteurs d'échelle de lignes et de colonnes destinés à équilibrer une
!> matrice bande M par N, A, et à réduire son nombre de conditionnement. R renvoie les
!> facteurs d'échelle de ligne et C les facteurs d'échelle de colonne, choisis pour tenter de
!> rendre le plus grand élément de chaque ligne et colonne de la matrice B avec
!> éléments B(i,j)=R(i)*A(i,j)*C(j) de valeur absolue 1.
!>
!> R(i) et C(j) sont limités aux valeurs comprises entre SMLNUM = plus petit nombre sûr
!> et BIGNUM = plus grand nombre sûr. L'utilisation de ces facteurs d'échelle n'est pas garantie
!> de réduire le nombre de conditionnement de A, mais fonctionne bien en pratique.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

KL

!>          KL est un entier
!>          Le nombre de sous-diagonales dans la bande de A. KL >= 0.
!>

KU

!>          KU est un entier
!>          Le nombre de super-diagonales dans la bande de A. KU >= 0.
!>

AB

!>          AB est un tableau de type COMPLEX*16, de dimension (LDAB,N)
!>          La matrice bande A, stockée dans les lignes 1 à KL+KU+1. La j-ième
!>          colonne de A est stockée dans la j-ième colonne du tableau AB comme suit :
!>          AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku) <= i <= min(m,j+kl).
!>

LDAB

!>          LDAB est un entier
!>          La dimension principale du tableau AB. LDAB >= KL+KU+1.
!>

R

!>          R est un tableau de type DOUBLE PRECISION, de dimension (M)
!>          Si INFO = 0, ou INFO > M, R contient les facteurs d'échelle de ligne
!>          pour A.
!>

C

!>          C est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          Si INFO = 0, C contient les facteurs d'échelle de colonne pour A.
!>

ROWCND

!>          ROWCND est de type DOUBLE PRECISION
!>          Si INFO = 0 ou INFO > M, ROWCND contient le rapport du plus petit R(i)
!>          au plus grand R(i). Si ROWCND >= 0.1 et si AMAX n'est ni trop grand,
!>          ni trop petit, il n'est pas utile de mettre à l'échelle par R.
!>

COLCND

!>          COLCND est de type DOUBLE PRECISION
!>          Si INFO = 0, COLCND contient le rapport du plus petit C(i)
!>          au plus grand C(i). Si COLCND >= 0.1, il n'est pas utile de mettre à l'échelle par C.
!>

AMAX

!>          AMAX est de type DOUBLE PRECISION
!>          Valeur absolue du plus grand élément de la matrice. Si AMAX est très
!>          proche du dépassement de capacité ou très proche du sous-dépassement,
!>          la matrice doit être mise à l'échelle.
!>

INFO

!>          INFO est un entier
!>          = 0 : fin de succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= M : la i-ème ligne de A est exactement zéro
!>                >  M : la (i-M)-ième colonne de A est exactement zéro
!>
