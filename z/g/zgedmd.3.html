ZGEDMD calcule la décomposition de mode dynamique (DMD) pour une paire de matrices d'instantanés de données.

Objectif :

!>    ZGEDMD calcule la décomposition de mode dynamique (DMD) pour
!>    une paire de matrices d'instantanés de données. Pour les matrices d'entrée
!>    X et Y telles que Y = A*X avec une matrice inaccessible
!>    A, ZGEDMD calcule un certain nombre de paires de Ritz de A en utilisant
!>    l'extraction standard de Rayleigh-Ritz d'un sous-espace
!>    de range(X) qui est déterminé à l'aide des vecteurs singuliers gauches principaux
!>    de X. Optionnellement, ZGEDMD retourne les résidus
!>    des paires de Ritz calculées, les informations nécessaires au
!>    raffinage des vecteurs de Ritz, ou les vecteurs propres
!>    de la DMD exacte.
!>    Pour plus de détails, voir les références listées
!>    ci-dessous. Pour plus de détails sur l'implémentation, voir [3].
!>

zgedmd(3) - LAPACK

NAME

ZGEDMD

ZGEDMD performs the singular value decomposition of a general rectangular matrix.

SYNOPSIS

SUBROUTINE ZGEDMD (
  JOBS, M, N, A, LDA, B, LDB, SIGMA, WORK, LWORK, INFO
)
CHARACTER JOBS
INTEGER M, N, LDA, LDB, LWORK, INFO
COMPLEX*16 (&#x2020;) A( LDA, * ), B( LDB, * )
DOUBLE PRECISION SIGMA( * )
COMPLEX*16 (&#x2020;) WORK( * )

Function/Subroutine Documentation

ZGEDMD is a subroutine in LAPACK for computing the singular value decomposition (SVD) of a general rectangular matrix $A$. The SVD is a factorization of the form $A = U \Sigma V^H$, where $U$ and $V$ are unitary matrices, and $\Sigma$ is a rectangular diagonal matrix with nonnegative real numbers (the singular values) on the diagonal.

The subroutine takes the following arguments:

JOBS
Specifies the form of the decomposition requested.
M
The number of rows of the matrix $A$.
N
The number of columns of the matrix $A$.
A
On entry, the $M \times N$ matrix $A$. On exit, the contents depend on the value of JOBS.
LDA
The leading dimension of the array A.
B
On entry, a matrix $B$ used in conjunction with $A$ for generalized SVD computations. The exact role of $B$ depends on JOBS.
LDB
The leading dimension of the array B.
SIGMA
On exit, the singular values of $A$ (or related quantities if generalized SVD is performed).
WORK
A workspace array used for computations.
LWORK
The dimension of the workspace array WORK. If LWORK is too small, the subroutine may fail or be inefficient.
INFO
An integer return code indicating the status of the computation.

The possible values for INFO are:

= 0
Normal termination.
< 0
An illegal value was passed for one of the arguments.
> 0
Indicates a problem during the computation. The specific meaning depends on the algorithm used, but common issues include:
       = 1 :: The computation of the SVD did not converge.
       = 2 :: The input data is inconsistent or requires
              different WHTSVD parameters.
       = 3 :: The eigenvalue computation did not converge.
       = 4 :: If data scaling was requested on input and
              the procedure found inconsistency in the data
              such that for some column index i,
              X(:,i) = 0 but Y(:,i) /= 0, then Y(:,i) is set
              to zero if JOBS=='C'. The computation proceeds
              with original or modified data and warning
              flag is set with INFO=4.
