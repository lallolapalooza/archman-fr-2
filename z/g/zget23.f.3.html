sous-routine zget23 (logical comp, integer isrt, character balanc, integer jtype, double precision thresh, integer, dimension( 4 ) iseed, integer nounit, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( lda, * ) h, complex*16, dimension( * ) w, complex*16, dimension( * ) w1, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, complex*16, dimension( ldlre, * ) lre, integer ldlre, double precision, dimension( * ) rcondv, double precision, dimension( * ) rcndv1, double precision, dimension( * ) rcdvin, double precision, dimension( * ) rconde, double precision, dimension( * ) rcnde1, double precision, dimension( * ) rcdein, double precision, dimension( * ) scale, double precision, dimension( * ) scale1, double precision, dimension( 11 ) result, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer info)

ZGET23

Objectif :

!>
!>    ZGET23  vérifie le pilote de problème de valeurs propres non symétriques CGEEVX.
!>    Si COMP = .FALSE., les 8 premiers des tests suivants seront
!>    effectués sur la matrice d'entrée A, et le test 9 également si LWORK est
!>    suffisamment grand.
!>    si COMP est .TRUE., les 11 tests seront effectués.
!>
!>    (1)     | A * VR - VR * W | / ( n |A| ulp )
!>
!>      Ici VR est la matrice des vecteurs propres droits unitaires.
!>      W est une matrice diagonale dont les entrées diagonales sont W(j).
!>
!>    (2)     | A**H * VL - VL * W**H | / ( n |A| ulp )
!>
!>      Ici VL est la matrice des vecteurs propres gauches unitaires, A**H est la
!>      transposée conjuguée de A, et W est comme ci-dessus.
!>
!>    (3)     | |VR(i)| - 1 | / ulp et composante principale réelle
!>
!>      VR(i) dénote la i-ème colonne de VR.
!>
!>    (4)     | |VL(i)| - 1 | / ulp et composante principale réelle
!>
!>      VL(i) dénote la i-ème colonne de VL.
!>
!>    (5)     0 si W(complet) = W(partiel), 1/ulp sinon
!>
!>      W(complet) dénote les valeurs propres calculées lorsque VR, VL, RCONDV
!>      et RCONDE sont également calculés, et W(partiel) dénote les
!>      valeurs propres calculées lorsque seulement certains de VR, VL, RCONDV, et
!>      RCONDE sont calculés.
!>
!>    (6)     0 si VR(complet) = VR(partiel), 1/ulp sinon
!>
!>      VR(complet) dénote les vecteurs propres droits calculés lorsque VL, RCONDV
!>      et RCONDE sont calculés, et VR(partiel) dénote le résultat
!>      lorsque seulement certains de VL et RCONDV sont calculés.
!>
!>    (7)     0 si VL(complet) = VL(partiel), 1/ulp sinon
!>
!>      VL(complet) dénote les vecteurs propres gauches calculés lorsque VR, RCONDV
!>      et RCONDE sont calculés, et VL(partiel) dénote le résultat
!>      lorsque seulement certains de VR et RCONDV sont calculés.
!>
!>    (8)     0 si SCALE, ILO, IHI, ABNRM (complet) =
!>                 SCALE, ILO, IHI, ABNRM (partiel)
!>            1/ulp sinon
!>
!>      SCALE, ILO, IHI et ABNRM décrivent comment la matrice est équilibrée.
!>      (complet) est lorsque VR, VL, RCONDE et RCONDV sont également calculés, et
!>      (partiel) est lorsque certains ne sont pas calculés.
!>
!>    (9)     0 si RCONDV(complet) = RCONDV(partiel), 1/ulp sinon
!>
!>      RCONDV(complet) dénote les inverses des nombres de condition des
!>      vecteurs propres droits calculés lorsque VR, VL et RCONDE sont également
!>      calculés. RCONDV(partiel) dénote les inverses des nombres de condition
!>      lorsque seulement certains de VR, VL et RCONDE sont calculés.
!>
!>   (10)     |RCONDV - RCDVIN| / cond(RCONDV)
!>
!>      RCONDV est l'inverse du nombre de condition des vecteurs propres droits
!>      calculé par ZGEEVX et RCDVIN (la valeur vraie pré-calculée)
!>      est fournie en entrée. cond(RCONDV) est le nombre de condition de
!>      RCONDV, et prend en compte les erreurs dans le calcul de RCONDV, de sorte
!>      que la quantité résultante devrait être O(ULP). cond(RCONDV) est
!>      essentiellement donné par norm(A)/RCONDE.
!>
!>   (11)     |RCONDE - RCDEIN| / cond(RCONDE)
!>
!>      RCONDE est l'inverse du nombre de condition des valeurs propres
!>      calculé par ZGEEVX et RCDEIN (la valeur vraie pré-calculée)
!>      est fournie en entrée. cond(RCONDE) est le nombre de condition de
!>      RCONDE, et prend en compte les erreurs dans le calcul de RCONDE,
!>      de sorte que la quantité résultante devrait être O(ULP). cond(RCONDE)
!>      est essentiellement donné par norm(A)/RCONDV.
!>

Paramètres

COMP 
!>          COMP est LOGICAL
!>          COMP décrit quels tests d'entrée effectuer :
!>            = .FALSE. si les nombres de condition calculés ne doivent pas
!>                      être testés par rapport à RCDVIN et RCDEIN
!>            = .TRUE.  s'ils doivent être comparés
!>

ISRT

!>          ISRT est INTEGER
!>          Si COMP = .TRUE., ISRT indique comment les valeurs propres
!>          correspondant aux valeurs dans RCDVIN et RCDEIN sont ordonnées :
!>            = 0 signifie que les valeurs propres sont triées par
!>                partie réelle croissante
!>            = 1 signifie que les valeurs propres sont triées par
!>                partie imaginaire croissante
!>          Si COMP = .FALSE., ISRT n'est pas référencé.
!>

BALANC

!>          BALANC est CHARACTER
!>          Décrit l'option d'équilibrage à tester.
!>            = 'N' pour aucune permutation ni mise à l'échelle diagonale
!>            = 'P' pour permutation mais pas de mise à l'échelle diagonale
!>            = 'S' pour aucune permutation mais mise à l'échelle diagonale
!>            = 'B' pour permutation et mise à l'échelle diagonale
!>

JTYPE

!>          JTYPE est INTEGER
!>          Type de matrice d'entrée. Utilisé pour étiqueter la sortie en cas d'erreur.
!>

THRESH

!>          THRESH est DOUBLE PRECISION
!>          Un test sera considéré comme une réussite si le résultat, calculé comme
!>          décrit ci-dessus, dépasse THRESH. Notez que l'erreur
!>          est mise à l'échelle pour être O(1), donc THRESH devrait être un multiple raisonnable
!>          de 1, par exemple 10 ou 100. En particulier,
!>          il ne doit pas dépendre de la précision (simple ou double)
!>          ou de la taille de la matrice. Il doit être au moins zéro.
!>

ISEED

!>          ISEED est un tableau INTEGER, de dimension (4)
!>          Si COMP = .FALSE., la graine du générateur de nombres aléatoires
!>          utilisé pour produire la matrice.
!>          Si COMP = .TRUE., ISEED(1) = le numéro de l'exemple.
!>          Utilisé pour étiqueter la sortie en cas d'erreur.
!>

NOUNIT

!>          NOUNIT est INTEGER
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (par exemple, si une routine renvoie INFO différent de 0.)
!>

N

!>          N est INTEGER
!>          La dimension de A. N doit être au moins 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          Contient la matrice dont les valeurs propres doivent être
!>          calculées.
!>

LDA

!>          LDA est un entier
!>          La dimension principale de A et H. LDA doit être au
!>          moins 1 et au moins N.
!>

H

!>          H est un tableau COMPLEX*16, dimension (LDA,N)
!>          Une autre copie de la matrice de test A, modifiée par ZGEEVX.
!>

W

!>          W est un tableau COMPLEX*16, dimension (N)
!>          Contient les valeurs propres de A.
!>

W1

!>          W1 est un tableau COMPLEX*16, dimension (N)
!>          Comme W, ce tableau contient les valeurs propres de A,
!>          mais celles calculées lorsque ZGEEVX ne calcule qu'une
!>          décomposition propre partielle, c'est-à-dire pas les valeurs
!>          propres et les vecteurs propres gauches et droits.
!>

VL

!>          VL est un tableau COMPLEX*16, dimension (LDVL,N)
!>          VL contient les vecteurs propres gauches calculés.
!>

LDVL

!>          LDVL est un entier
!>          La dimension principale de VL. Doit être au moins max(1,N).
!>

VR

!>          VR est un tableau COMPLEX*16, dimension (LDVR,N)
!>          VR contient les vecteurs propres droits calculés.
!>

LDVR

!>          LDVR est un entier
!>          La dimension principale de VR. Doit être au moins max(1,N).
!>

LRE

!>          LRE est un tableau COMPLEX*16, dimension (LDLRE,N)
!>          LRE contient les vecteurs propres droits ou gauches calculés.
!>

LDLRE

!>          LDLRE est un entier
!>          La dimension principale de LRE. Doit être au moins max(1,N).
!>

RCONDV

!>          RCONDV est un tableau DOUBLE PRECISION, dimension (N)
!>          RCONDV contient les nombres de condition réciproques calculés
!>          pour les vecteurs propres.
!>

RCNDV1

!>          RCNDV1 est un tableau DOUBLE PRECISION, dimension (N)
!>          RCNDV1 contient d'autres nombres de condition réciproques calculés
!>          pour les vecteurs propres.
!>

RCDVIN

!>          RCDVIN est un tableau DOUBLE PRECISION, dimension (N)
!>          Lorsque COMP = .TRUE. RCDVIN contient les nombres de condition
!>          réciproques précalculés pour les vecteurs propres à comparer avec
!>          RCONDV.
!>

RCONDE

!>          RCONDE est un tableau DOUBLE PRECISION, dimension (N)
!>          RCONDE contient les nombres de condition réciproques calculés
!>          pour les valeurs propres.
!>

RCNDE1

!>          RCNDE1 est un tableau DOUBLE PRECISION, dimension (N)
!>          RCNDE1 contient d'autres nombres de condition réciproques calculés
!>          pour les valeurs propres.
!>

RCDEIN

!>          RCDEIN est un tableau DOUBLE PRECISION, dimension (N)
!>          Lorsque COMP = .TRUE. RCDEIN contient les nombres de condition
!>          réciproques précalculés pour les valeurs propres à comparer avec
!>          RCONDE.
!>

SCALE

!>          SCALE est un tableau DOUBLE PRECISION, dimension (N)
!>          Contient des informations décrivant la mise à l'échelle de la matrice.
!>

SCALE1

!>          SCALE1 est un tableau DOUBLE PRECISION, dimension (N)
!>          Contient des informations décrivant la mise à l'échelle de la matrice.
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, dimension (11)
!>          Les valeurs calculées par les 11 tests décrits ci-dessus.
!>          Les valeurs sont actuellement limitées à 1/ulp, pour éviter
!>          les débordements.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>          Le nombre d'entrées dans WORK. Il doit être au moins
!>          2*N, et 2*N+N**2 si les tests 9, 10 ou 11 doivent être effectués.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (2*N)
!>

INFO

!>          INFO est un entier
!>          Si 0, sortie réussie.
!>          Si <0, le paramètre d'entrée -INFO avait une valeur incorrecte.
!>          Si >0, ZGEEVX a retourné un code d'erreur, dont la valeur absolue
!>                 est retournée.
!>
