Documentation de la fonction/sous-programme

sous-routine zgemlq (caractère side, caractère trans, entier m, entier n, entier k, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) t, entier tsize, complexe*16, dimension( ldc, * ) c, entier ldc, complexe*16, dimension( * ) work, entier lwork, entier info)

ZGEMLQ

Objectif :

!>
!>     ZGEMLQ écrase la matrice réelle générale M par N, C, avec
!>
!>                      SIDE = 'L'     SIDE = 'R'
!>      TRANS = 'N':      Q * C          C * Q
!>      TRANS = 'C':      Q**H * C       C * Q**H
!>      où Q est une matrice unitaire complexe définie comme le produit
!>      de réflecteurs élémentaires bloqués calculés par la factorisation
!>      LQ courte et large (ZGELQ)
!>
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer Q ou Q**H depuis la gauche ;
!>          = 'R' : appliquer Q ou Q**H depuis la droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : Pas de transposée, appliquer Q ;
!>          = 'C' : Transposée conjuguée, appliquer Q**H.
!>

M

!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>
!>

A

!>          A est un tableau COMPLEX*16, de dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          Fait partie de la structure de données représentant Q comme retourné par ZGELQ.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

T

!>          T est un tableau COMPLEX*16, de dimension (MAX(5,TSIZE)).
!>          Fait partie de la structure de données représentant Q comme retourné par ZGELQ.
!>

TSIZE

!>          TSIZE est un ENTIER
!>          La dimension du tableau T. TSIZE >= 5.
!>

C

!>          C est un tableau COMPLEX*16, de dimension (LDC,N)
!>          À l'entrée, la matrice M par N C.
!>          À la sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est un ENTIER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          (espace de travail) Tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne le LWORK minimal.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK. LWORK >= 1.
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée. La routine
!>          calcule uniquement la taille du tableau WORK, retourne cette
!>          valeur dans WORK(1), et aucun message d'erreur lié à WORK
!>          n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
