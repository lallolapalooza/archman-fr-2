ZGEQRFP

Documentation de fonction/sous-routine

sous-routine zgeqrfp (entier m, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) tau, complexe*16, dimension( * ) work, entier lwork, entier info)

ZGEQRFP

Objectif:

!>
!> ZGEQR2P calcule une factorisation QR d'une matrice complexe M-par-N A:
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> où :
!>
!>    Q est une matrice orthogonale M-par-M ;
!>    R est une matrice triangulaire supérieure N-par-N avec des entrées diagonales
!>    non négatives ;
!>    0 est une matrice nulle (M-N)-par-N, si M > N.
!>
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, la matrice M-par-N A.
!>          À la sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice trapézoïdale supérieure R de taille min(M,N)-par-N (R est
!>          triangulaire supérieure si m >= n). Les entrées diagonales de R
!>          sont réelles et non négatives ; Les éléments en dessous de la diagonale,
!>          avec le tableau TAU, représentent la matrice unitaire Q comme un
!>          produit de min(m,n) réflecteurs élémentaires (voir Détails supplémentaires).
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEX*16, de dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires (voir Détails supplémentaires).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, et LWORK >= N sinon.
!>          Pour des performances optimales, LWORK >= N*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>

Détails supplémentaires:

!>
!>  La matrice Q est représentée comme un produit de réflecteurs élémentaires
!>
!>     Q = H(1) H(2) . . . H(k), où k = min(m,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**H
!>
!>  où tau est un scalaire complexe, et v est un vecteur complexe avec
!>  v(1:i-1) = 0 et v(i) = 1 ; v(i+1:m) est stocké à la sortie dans A(i+1:m,i),
!!>  et tau dans TAU(i).
!>
!> Voir le document de travail Lapack 203 pour les détails
!>
