Documentation de la fonction/sous-routine

sous-routine zgbt05 (character trans, integer n, integer kl, integer ku, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldxact, * ) xact, integer ldxact, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) reslts)

ZGBT05

Objectif:

!>
!> ZGBT05 teste les bornes d'erreur du raffinement itératif pour la
!> solution calculée d'un système d'équations op(A)*X = B, où A est une
!> matrice bande générale d'ordre n avec kl sous-diagonales et ku
!> superdiagonales et op(A) = A, A**T, ou A**H, selon TRANS.
!>
!> RESLTS(1) = test de la borne d'erreur
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Une grande valeur est retournée si ce rapport n'est pas inférieur à un.
!>
!> RESLTS(2) = résidu de la routine de raffinement itératif
!>           = le maximum de BERR / ( NZ*EPS + (*) ), où
!>             (*) = NZ*UNFL / (min_i (abs(op(A))*abs(X) +abs(b))_i )
!>             et NZ = nombre max. d'éléments non nuls dans une ligne de A, plus 1
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations.
!>          = 'N':  A    * X = B  (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Conjuguée transposée = Transposée)
!>

N

!>          N est INTEGER
!>          Le nombre de lignes des matrices X, B, et XACT, et l'ordre
!>          de la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>          Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>          Le nombre de superdiagonales dans la bande de A.  KU >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de colonnes des matrices X, B, et XACT.
!>          NRHS >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, dimension (LDAB,N)
!>          La matrice bande originale A, stockée dans les lignes 1 à KL+KU+1.
!>          La j-ième colonne de A est stockée dans la j-ième colonne du
!>          tableau AB comme suit :
!>          AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku)<=i<=min(n,j+kl).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          Les vecteurs du second membre pour le système d'équations
!>          linéaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés. Chaque vecteur est stocké comme
!>          une colonne de la matrice X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

XACT

!>          XACT est un tableau COMPLEX*16, dimension (LDXACT,NRHS)
!>          Les vecteurs solution exacts. Chaque vecteur est stocké comme
!>          une colonne de la matrice XACT.
!>

LDXACT

!>          LDXACT est INTEGER
!>          La dimension principale du tableau XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          Les bornes d'erreur estimées pour chaque vecteur solution
!>          X.  Si XTRUE est la vraie solution, FERR borne la magnitude
!>          de la plus grande entrée dans (X - XTRUE) divisée par la magnitude
!>          de la plus grande entrée dans X.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          L'erreur relative composante par composante de chaque vecteur solution
!>          (c'est-à-dire, le plus petit changement relatif dans n'importe quelle entrée de A
!>          ou B qui rend X une solution exacte).
!>

RESLTS

!>          RESLTS est un tableau DOUBLE PRECISION, dimension (2)
!>          Le maximum sur les vecteurs solutions NRHS des rapports :
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( NZ*EPS + (*) )
!>
