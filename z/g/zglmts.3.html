Documentation Fonction/Sous-programme

sous-programme zglmts (entier n, entier m, entier p, complexe*16, dimension( lda, * ) a, complexe*16, dimension( lda, * ) af, entier lda, complexe*16, dimension( ldb, * ) b, complexe*16, dimension( ldb, * ) bf, entier ldb, complexe*16, dimension( * ) d, complexe*16, dimension( * ) df, complexe*16, dimension( * ) x, complexe*16, dimension( * ) u, complexe*16, dimension( lwork ) work, entier lwork, double precision, dimension( * ) rwork, double precision result)

ZGLMTS

Objectif :

!>
!> ZGLMTS teste ZGGGLM - un sous-programme pour résoudre le problème du
!> modèle linéaire généralisé.
!>

Paramètres

N 
!>          N est ENTIER
!>          Le nombre de lignes des matrices A et B.  N >= 0.
!>

M

!>          M est ENTIER
!>          Le nombre de colonnes de la matrice A.  M >= 0.
!>

P

!>          P est ENTIER
!>          Le nombre de colonnes de la matrice B.  P >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,M)
!>          La matrice N x M A.
!>

AF

!>          AF est un tableau COMPLEX*16, de dimension (LDA,M)
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale des tableaux A, AF. LDA >= max(M,N).
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,P)
!>          La matrice N x P A.
!>

BF

!>          BF est un tableau COMPLEX*16, de dimension (LDB,P)
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale des tableaux B, BF. LDB >= max(P,N).
!>

D

!>          D est un tableau COMPLEX*16, de dimension( N )
!>          En entrée, le membre de gauche de GLM.
!>

DF

!>          DF est un tableau COMPLEX*16, de dimension( N )
!>

X

!>          X est un tableau COMPLEX*16, de dimension( M )
!>          vecteur solution X dans le problème GLM.
!>

U

!>          U est un tableau COMPLEX*16, de dimension( P )
!>          vecteur solution U dans le problème GLM.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (M)
!>

RESULT

!>          RESULT est DOUBLE PRECISION
!>          Le rapport de test :
!>                           norme( d - A*x - B*u )
!>            RESULT = -----------------------------------------
!>                     (norme(A)+norme(B))*(norme(x)+norme(u))*EPS
!>
