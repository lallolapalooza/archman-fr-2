Documentation de la fonction/sous-programme

sous-programme zget01 (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldafac, * ) afac, integer ldafac, integer, dimension( * ) ipiv, double precision, dimension( * ) rwork, double precision resid)

ZGET01

But :

!>
!> ZGET01 reconstruit une matrice A à partir de sa factorisation L*U et
!> calcule le résidu
!>    norm(L*U - A) / ( N * norm(A) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de complexes*16, dimension (LDA,N)
!>          La matrice originale M x N, A.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

AFAC

!>          AFAC est un tableau de complexes*16, dimension (LDAFAC,N)
!>          La forme factorisée de la matrice A.  AFAC contient les facteurs
!>          L et U de la factorisation L*U calculée par ZGETRF.
!>          Surécrit avec la matrice reconstruite, puis avec la différence
!>          L*U - A.
!>

LDAFAC

!>          LDAFAC est un entier (INTEGER)
!>          La dimension principale du tableau AFAC.  LDAFAC >= max(1,M).
!>

IPIV

!>          IPIV est un tableau d'entiers, dimension (N)
!>          Les indices de pivot de ZGETRF.
!>

RWORK

!>          RWORK est un tableau de double précision, dimension (M)
!>

RESID

!>          RESID est un double précision
!>          norm(L*U - A) / ( N * norm(A) * EPS )
!>
