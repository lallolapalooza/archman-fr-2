Documentation de la fonction/sous-programme

sous-programme zgelss (entier m, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, double précision, dimension( * ) s, double précision rcond, entier rank, complexe*16, dimension( * ) work, entier lwork, double précision, dimension( * ) rwork, entier info)

ZGELSS résout les systèmes surdéterminés ou sousdéterminés pour les matrices GE

Objectif :

!>
!> ZGELSS calcule la solution de norme minimale d'un problème de moindres carrés linéaires complexes :
!>
!> Minimiser la norme 2 de | b - A*x |.
!>
!> en utilisant la décomposition en valeurs singulières (SVD) de A. A est une matrice M par N
!> qui peut être de rang déficient.
!>
!> Plusieurs vecteurs second membre b et vecteurs solution x peuvent être
!> traités en un seul appel ; ils sont stockés comme colonnes de la
!> matrice second membre B de taille M par NRHS et de la matrice solution X de taille N par NRHS.
!>
!> Le rang effectif de A est déterminé en considérant comme nulles les
!> valeurs singulières inférieures à RCOND fois la plus grande valeur singulière.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          En entrée, la matrice A de taille M par N.
!>          En sortie, les min(m,n) premières lignes de A sont écrasées par
!>          ses vecteurs singuliers droits, stockés ligne par ligne.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>          En entrée, la matrice second membre B de taille M par NRHS.
!>          En sortie, B est écrasée par la matrice solution X de taille N par NRHS.
!>          Si m >= n et RANK = n, la somme des carrés des résidus
!>          pour la solution dans la i-ème colonne est donnée par la somme des
!>          carrés des modules des éléments n+1:m de cette colonne.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,M,N).
!>

S

!>          S est un tableau DOUBLE PRÉCISION de dimension (min(M,N))
!>          Les valeurs singulières de A en ordre décroissant.
!>          Le conditionnement de A dans la norme 2 = S(1)/S(min(m,n)).
!>

RCOND

!>          RCOND est un DOUBLE PRÉCISION
!>          RCOND est utilisé pour déterminer le rang effectif de A.
!>          Les valeurs singulières S(i) <= RCOND*S(1) sont traitées comme nulles.
!>          Si RCOND < 0, la précision machine est utilisée à la place.
!>

RANK

!>          RANK est un ENTIER
!>          Le rang effectif de A, c'est-à-dire le nombre de valeurs singulières
!>          supérieures à RCOND*S(1).
!>

WORK

!>          WORK est un tableau COMPLEX*16 de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK. LWORK >= 1, et aussi :
!>          LWORK >=  2*min(M,N) + max(M,N,NRHS)
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION de dimension (5*min(M,N))
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : l'algorithme de calcul de la SVD n'a pas convergé ;
!>                si INFO = i, i éléments hors diagonale d'une forme
!>                bidiagonale intermédiaire n'ont pas convergé vers zéro.
!>
