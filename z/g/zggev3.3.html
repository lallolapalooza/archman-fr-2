Documentation de la fonction/sous-programme

sous-programme zggev3 (caractère jobvl, caractère jobvr, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( * ) alpha, complexe*16, dimension( * ) beta, complexe*16, dimension( ldvl, * ) vl, entier ldvl, complexe*16, dimension( ldvr, * ) vr, entier ldvr, complexe*16, dimension( * ) work, entier lwork, double précision, dimension( * ) rwork, entier info)

ZGGEV3 calcule les valeurs propres et, éventuellement, les vecteurs propres généraux gauches et/ou droits pour les matrices GE (algorithme bloqué)

Objectif :

!>
!> ZGGEV3 calcule pour une paire de matrices complexes N×N non symétriques
!> (A,B), les valeurs propres généralisées, et éventuellement, les vecteurs propres
!> généralisés gauches et/ou droits.
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire
!> lambda ou un rapport alpha/beta = lambda, tel que A - lambda*B est
!> singulière. Elle est généralement représentée par la paire (alpha,beta), car
!> il existe une interprétation raisonnable pour beta=0, et même pour les deux
!> étant zéro.
!>
!> Le vecteur propre généralisé droit v(j) correspondant à la
!> valeur propre généralisée lambda(j) de (A,B) satisfait
!>
!>              A * v(j) = lambda(j) * B * v(j).
!>
!> Le vecteur propre généralisé gauche u(j) correspondant à la
!> valeur propre généralisée lambda(j) de (A,B) satisfait
!>
!>              u(j)**H * A = lambda(j) * u(j)**H * B
!>
!> où u(j)**H est la transposée conjuguée de u(j).
!>

Paramètres

JOBVL 
!>          JOBVL est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs propres généralisés gauches ;
!>          = 'V' : calculer les vecteurs propres généralisés gauches.
!>

JOBVR

!>          JOBVR est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs propres généralisés droits ;
!>          = 'V' : calculer les vecteurs propres généralisés droits.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A, B, VL et VR.  N >= 0.
!>

A

!>          A est COMPLEX*16 array, dimension (LDA, N)
!>          En entrée, la matrice A dans la paire (A,B).
!>          En sortie, A a été écrasée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A.  LDA >= max(1,N).
!>

B

!>          B est COMPLEX*16 array, dimension (LDB, N)
!>          En entrée, la matrice B dans la paire (A,B).
!>          En sortie, B a été écrasée.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de B.  LDB >= max(1,N).
!>

ALPHA

!>          ALPHA est COMPLEX*16 array, dimension (N)
!>

BETA

!>          BETA est COMPLEX*16 array, dimension (N)
!>          En sortie, ALPHA(j)/BETA(j), j=1,...,N, seront les
!>          valeurs propres généralisées.
!>
!>          Note : les quotients ALPHA(j)/BETA(j) peuvent facilement dépasser
!>          ou sous-dépasser les limites, et BETA(j) peut même être zéro.  Ainsi,
!>          l'utilisateur doit éviter de calculer naïvement le rapport alpha/beta.
!>          Cependant, ALPHA sera toujours inférieur et généralement
!>          comparable à norm(A) en magnitude, et BETA toujours inférieur
!>          et généralement comparable à norm(B).
!>

VL

!>          VL est COMPLEX*16 array, dimension (LDVL,N)
!>          Si JOBVL = 'V', les vecteurs propres généralisés gauches u(j) sont
!>          stockés les uns après les autres dans les colonnes de VL, dans le même
!>          ordre que leurs valeurs propres.
!>          Chaque vecteur propre est mis à l'échelle de sorte que le plus grand composant ait
!>          abs(partie réelle) + abs(partie imaginaire) = 1.
!>          Non référencé si JOBVL = 'N'.
!>

LDVL

!>          LDVL est INTEGER
!>          La dimension principale de la matrice VL. LDVL >= 1, et
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR est COMPLEX*16 array, dimension (LDVR,N)
!>          Si JOBVR = 'V', les vecteurs propres généralisés droits v(j) sont
!>          stockés les uns après les autres dans les colonnes de VR, dans le même
!>          ordre que leurs valeurs propres.
!>          Chaque vecteur propre est mis à l'échelle de sorte que le plus grand composant ait
!>          abs(partie réelle) + abs(partie imaginaire) = 1.
!>          Non référencé si JOBVR = 'N'.
!>

LDVR

!>          LDVR est INTEGER
!>          La dimension principale de la matrice VR. LDVR >= 1, et
!>          si JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK est COMPLEX*16 array, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= MAX(1,2*N).
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est DOUBLE PRECISION array, dimension (8*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          =1,...,N :
!>                L'itération QZ a échoué. Aucun vecteur propre n'a été
!>                calculé, mais ALPHA(j) et BETA(j) devraient être
!>                corrects pour j=INFO+1,...,N.
!>          > N :  =N+1 : échec de l'itération QZ dans ZHGEQZ,
!>                =N+2 : retour d'erreur de ZTGEVC.
!>

    Documentation de la fonction/sous-routine

    zggev calcule les valeurs propres et les vecteurs propres droits et/ou gauches pour un problème généralisé des valeurs propres linéaires, qui est de la forme A*x = lambda*B*x, où A et B sont des matrices carrées complexes.

    Les arguments de la sous-routine sont les suivants :

    • JOBVL (entrée) : Caractère. Indique s'il faut calculer les vecteurs propres gauches. 'N' : aucun vecteur propre gauche n'est calculé. 'V' : les vecteurs propres gauches sont calculés.
    • JOBVR (entrée) : Caractère. Indique s'il faut calculer les vecteurs propres droits. 'N' : aucun vecteur propre droit n'est calculé. 'V' : les vecteurs propres droits sont calculés.
    • N (entrée) : Entier. La taille de la matrice (nombre de colonnes et de lignes).
    • A (entrée) : Tableau complexe de taille (LDA, N). La matrice A.
    • LDA (entrée) : Entier. Le premier indice de la matrice A.
    • B (entrée) : Tableau complexe de taille (LDB, N). La matrice B.
    • LDB (entrée) : Entier. Le premier indice de la matrice B.
    • ALPHAR (sortie) : Tableau de double précision de taille N. La partie réelle des valeurs propres alpha.
    • ALPHAI (sortie) : Tableau de double précision de taille N. La partie imaginaire des valeurs propres alpha.
    • BETA (sortie) : Tableau de double précision de taille N. Les valeurs propres beta.
    • VL (sortie) : Tableau complexe de taille (LDVL, N). Les vecteurs propres gauches, si calculés.
    • LDVL (entrée) : Entier. Le premier indice de la matrice VL.
    • VR (sortie) : Tableau complexe de taille (LDVR, N). Les vecteurs propres droits, si calculés.
    • LDVR (entrée) : Entier. Le premier indice de la matrice VR.
    • WORK (travail) : Tableau complexe de taille LWORK. Un espace de travail.
    • LWORK (entrée) : Entier. La taille du tableau WORK.
    • RWORK (travail) : Tableau de double précision de taille LWORK. Un espace de travail.
    • INFO (sortie) : Entier. Info. 0 si succès, <0 si erreur.
