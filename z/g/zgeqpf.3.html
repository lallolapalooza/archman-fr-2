Documentation de la fonction/sous-programme

sous-routine zgeqpf (entier m, entier n, complexe*16, dimension( lda, * ) a, entier lda, entier, dimension( * ) jpvt, complexe*16, dimension( * ) tau, complexe*16, dimension( * ) work, double precision, dimension( * ) rwork, entier info)

ZGEQPF

Objectif :

!>
!> Cette routine est dépréciée et a été remplacée par la routine ZGEQP3.
!>
!> ZGEQPF calcule une factorisation QR avec pivot de colonnes d'une
!> matrice complexe M-par-N A : A*P = Q*R.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A. N >= 0
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          En entrée, la matrice M-par-N A.
!>          En sortie, le triangle supérieur du tableau contient la
!>          matrice triangulaire supérieure R, de dimensions min(M,N)-par-N ; les éléments
!>          en dessous de la diagonale, avec le tableau TAU,
!>          représentent la matrice unitaire Q comme un produit de
!>          min(m,n) réflecteurs élémentaires.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

JPVT

!>          JPVT est un tableau ENTIER, dimension (N)
!>          En entrée, si JPVT(i) .ne. 0, la i-ème colonne de A est permutée
!>          vers le début de A*P (une colonne de tête) ; si JPVT(i) = 0,
!>          la i-ème colonne de A est une colonne libre.
!>          En sortie, si JPVT(i) = k, alors la i-ème colonne de A*P
!>          était la k-ème colonne de A.
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (2*N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  La matrice Q est représentée comme un produit de réflecteurs élémentaires
!>
!>     Q = H(1) H(2) . . . H(n)
!>
!>  Chaque H(i) a la forme
!>
!>     H = I - tau * v * v**H
!>
!>  où tau est un scalaire complexe, et v est un vecteur complexe avec
!>  v(1:i-1) = 0 et v(i) = 1 ; v(i+1:m) est stocké en sortie dans A(i+1:m,i).
!>
!>  La matrice P est représentée dans jpvt comme suit : Si
!>     jpvt(j) = i
!>  alors la j-ème colonne de P est la i-ème vecteur canonique unitaire.
!>
!>  Stratégie de mise à jour partielle des normes de colonnes modifiée par
!>    Z. Drmac et Z. Bujanovic, Dept. de Mathématiques,
!>    Université de Zagreb, Croatie.
!>  -- Avril 2011                                                      --
!>  Pour plus de détails, voir LAPACK Working Note 176.
!>
