ZGESVDQ calcule la décomposition en valeurs singulières (SVD) de une matrice complexe M par N A, où M >= N. La SVD de A est écrite comme

Objectif :

!>
!> ZCGESVDQ calcule la décomposition en valeurs singulières (SVD) de
!> une matrice complexe A de taille M par N, où M >= N. La SVD de A est écrite
!> comme
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^*,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> où SIGMA est une matrice diagonale N par N, U est une matrice orthonormée M par N
!> et V est une matrice unitaire N par N. Les éléments diagonaux
!> de SIGMA sont les valeurs singulières de A. Les colonnes de U et V sont les
!> vecteurs singuliers gauches et droits de A, respectivement.
!>

Paramètres

JOBA 
!>  JOBA est CHARACTER*1
!>  Spécifie le niveau de précision dans la SVD calculée
!>  = 'A' La précision demandée correspond à une erreur rétrograde
!>        bornée par || delta A ||_F <= f(m,n) * EPS * || A ||_F,
!>        où EPS = DLAMCH('Epsilon'). Ceci autorise ZGESVDQ à
!>        tronquer le facteur triangulaire calculé dans une factorisation
!>        QR révélatrice de rang chaque fois que la partie tronquée est inférieure au
!>        seuil de l'ordre de EPS * ||A||_F. C'est un niveau de troncature agressif.
!>  = 'M' Similaire à 'A', mais la troncature est plus douce : elle
!>        n'est autorisée que lorsqu'il y a une chute sur la diagonale du
!>        facteur triangulaire dans la factorisation QR. C'est un niveau de troncature moyen.
!>  = 'H' Haute précision demandée. Aucune détermination de rang numérique basée
!>        sur la factorisation QR révélatrice de rang n'est tentée.
!>  = 'E' Identique à 'H', et en plus le nombre de condition du A mis à l'échelle par colonne
!>        est estimé et renvoyé dans  RWORK(1).
!>        N^(-1/4)*RWORK(1) <= ||pinv(A_scaled)||_2 <= N^(1/4)*RWORK(1)
!>

JOBP

!>  JOBP est CHARACTER*1
!>  = 'P' Les lignes de A sont ordonnées par ordre décroissant par rapport à
!>        ||A(i,:)||_\infty. Ceci améliore la précision numérique au détriment
!>        d'un mouvement de données supplémentaire. Recommandé pour la robustesse numérique.
!>  = 'N' Pas de pivotement de ligne.
!>

JOBR

!>          JOBR est CHARACTER*1
!>          = 'T' Après la factorisation QR pivotée initiale, ZGESVD est appliquée à
!>          l'adjointe R**H du facteur triangulaire R calculé. Cela implique
!>          un mouvement de données supplémentaire (transpositions de matrices). Utile pour
!>          les expériences, la recherche et le développement.
!>          = 'N' Le facteur triangulaire R est donné en entrée à CGESVD. Ceci peut être
!>          préférable car cela implique moins de mouvement de données.
!>

JOBU

!>          JOBU est CHARACTER*1
!>          = 'A' Tous les M vecteurs singuliers gauches sont calculés et renvoyés dans
!>          la matrice U. Voir la description de U.
!>          = 'S' ou 'U' N = min(M,N) vecteurs singuliers gauches sont calculés et renvoyés
!>          dans la matrice U. Voir la description de U.
!>          = 'R' Le rang numérique NUMRANK est déterminé et seuls NUMRANK vecteurs singuliers
!>          gauches sont calculés et renvoyés dans la matrice U.
!>          = 'F' Les N vecteurs singuliers gauches sont renvoyés sous forme factorisée comme le
!>          produit du facteur Q de la factorisation QR initiale et des
!>          N vecteurs singuliers gauches de (R**H , 0)**H. Si un pivotement de ligne est utilisé,
!>          alors les informations nécessaires sur le pivotement de ligne sont stockées dans
!>          IWORK(N+1:N+M-1).
!>          = 'N' Les vecteurs singuliers gauches ne sont pas calculés.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          = 'A', 'V' Tous les N vecteurs singuliers droits sont calculés et renvoyés dans
!>          la matrice V.
!>          = 'R' Le rang numérique NUMRANK est déterminé et seuls NUMRANK vecteurs singuliers
!>          droits sont calculés et renvoyés dans la matrice V. Cette option est
!>          autorisée uniquement si JOBU = 'R' ou JOBU = 'N' ; sinon elle est illégale.
!>          = 'N' Les vecteurs singuliers droits ne sont pas calculés.
!>

M

!>          M est un ENTIER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice d'entrée A.  M >= N >= 0.
!>

A

!>          A est un tableau COMPLEX*16 de dimensions LDA x N
!>          À l'entrée, la matrice d'entrée A.
!>          À la sortie, si JOBU .NE. 'N' ou JOBV .NE. 'N', le triangle inférieur de A contient
!>          les vecteurs de Householder tels que stockés par ZGEQP3. Si JOBU = 'F', ces vecteurs
!>          de Householder ainsi que CWORK(1:N) peuvent être utilisés pour restaurer les facteurs Q
!>          de la factorisation QR pivotée initiale de A. Voir la description de U.
!>

LDA

!>          LDA est un ENTIER.
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

S

!>          S est un tableau DOUBLE PRECISION de dimension N.
!>          Les valeurs singulières de A, ordonnées de telle sorte que S(i) >= S(i+1).
!>

U

!>          U est un tableau COMPLEX*16, de dimension
!>          LDU x M si JOBU = 'A'; voir la description de LDU. Dans ce cas,
!>          à la sortie, U contient les M vecteurs singuliers gauches.
!>          LDU x N si JOBU = 'S', 'U', 'R' ; voir la description de LDU. Dans ce
!>          cas, U contient les N ou les NUMRANK premiers vecteurs singuliers gauches.
!>          LDU x N si JOBU = 'F' ; voir la description de LDU. Dans ce cas, U
!>          contient une matrice unitaire N x N qui peut être utilisée pour former les vecteurs singuliers gauches.
!>          Si JOBU = 'N', U n'est pas référencé.
!>

LDU

!>          LDU est un ENTIER.
!>          La dimension principale du tableau U.
!>          Si JOBU = 'A', 'S', 'U', 'R',  LDU >= max(1,M).
!>          Si JOBU = 'F',                 LDU >= max(1,N).
!>          Sinon,                      LDU >= 1.
!>

V

!>          V est un tableau COMPLEX*16, de dimension
!>          LDV x N si JOBV = 'A', 'V', 'R' ou si JOBA = 'E' .
!>          Si JOBV = 'A', ou 'V',  V contient la matrice unitaire N x N  V**H ;
!>          Si JOBV = 'R', V contient les NUMRANK premières lignes de V**H (les vecteurs
!>          singuliers droits, stockés ligne par ligne, des NUMRANK plus grandes valeurs singulières).
!>          Si JOBV = 'N' et JOBA = 'E', V est utilisé comme espace de travail.
!>          Si JOBV = 'N', et JOBA.NE.'E', V n'est pas référencé.
!>

LDV

!>          LDV est un ENTIER
!>          La dimension principale du tableau V.
!>          Si JOBV = 'A', 'V', 'R',  ou JOBA = 'E', LDV >= max(1,N).
!>          Sinon,                               LDV >= 1.
!>

NUMRANK

!>          NUMRANK est un ENTIER

NAME

zgesvdq - computes the singular value decomposition (SVD) of a complex rectangular matrix

SYNOPSIS

Function/Subroutine Documentation

Purpose:

!>          The purpose of ZGESVDQ is to compute the singular value decomposition
!>          (SVD) of a real M-by-N matrix A, in the form
!>
!>          A = U * S * V**H
!>
!>          where S is an M-by-N diagonal matrix, S(i,i) = s(i), and s(1)
!>          >= s(2) >= ... >= s(min(M,N)) >= 0. The first min(M,N) diagonal
!>          elements of S are the singular values of A and any remaining
!>          diagonal elements are zero. U is an M-by-M unitary matrix, and V is
!>          an N-by-N unitary matrix (V**H means V conjugate transpose).
!>
!>          ZGESVDQ is implemented using a QR-preconditioned QR SVD method
!>          which computes the SVD with high accuracy.
!>
!>          The routine computes the singular values and optionally the left
!>          singular vectors U and the right singular vectors V.
!>
!>          The implementation of the QR SVD method is based on:
!>          [1] Zlatko Drmac and Kresimir Veselic, "New fast and reliable
!>              methods for the SVD computation," SIAM J. Matrix Anal. Appl.
!>              35(03):995-1025, 2014.
!>          and on the subsequent work on scaling and deflation, and
!>          accuracy assessment.
!>
!>          The code uses an implicitly restarted QR algorithm to compute
!>          the SVD. It is a QR-based method.
!>
!>          The method is based on the QR decomposition of the input matrix
!>          (see ZGEQP3) and subsequently applying a QR iteration based SVD
!>          algorithm. The singular values are computed in INCREASING order.
!>          The final SVD is computed in DECREASING order.
!>
!>          The method aims for high accuracy, especially for ill-conditioned
!>          matrices.
!>
!>          The core part of the algorithm is based on the routine ZGESVD,
!>          but modified to apply QR factorization preconditioning.
!>
!>          The parameter JOBQ is used to control the computation of the
!>          left singular vectors U.
!>          The parameter JOBV is used to control the computation of the
!>          right singular vectors V.
!>
!>          The algorithm is based on the work of Zlatko Drmac and Kresimir Veselic.
!>          The development was supported by the Croatian Science Foundation
!>          under the research project IP-2014-09-7944.
!>
!>          Some parts of the code are borrowed and adapted from ZGESVD, ZGEQPF,
!>          and ZGEQPF algorithms.
!>
!>          This implementation computes the SVD using a QR-based method
!>          which is known for its high accuracy.
!>
!>          It is recommended to use this routine for matrices where high
!>          accuracy is required.
!>
!>          The routine uses ZGEQP3 for the initial QR factorization.
!>
!>          The routine uses CGESVD for the core SVD computation.
!>
!>          The routine uses ZBDSQR for the final bidiagonalization.
