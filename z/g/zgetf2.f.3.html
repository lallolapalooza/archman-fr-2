Documentation de la fonction/sous-routine

sous-routine zgetf2 (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, integer info)

ZGETF2 calcule la factorisation LU d'une matrice m-par-n générale en utilisant le pivotement partiel avec échange de lignes (algorithme non bloqué).

Objectif :

!>
!> ZGETF2 calcule une factorisation LU d'une matrice générale m-par-n A
!> en utilisant le pivotement partiel avec échange de lignes.
!>
!> La factorisation a la forme
!>    A = P * L * U
!> où P est une matrice de permutation, L est triangulaire inférieure avec des
!> éléments diagonaux unitaires (trapézoïdale inférieure si m > n), et U est
!> triangulaire supérieure (trapézoïdale supérieure si m < n).
!>
!> Ceci est la version de l'algorithme de niveau 2 BLAS de type "right-looking".
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          En entrée, la matrice m par n à factoriser.
!>          En sortie, les facteurs L et U de la factorisation
!>          A = P*L*U ; les éléments diagonaux unitaires de L ne sont pas stockés.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

IPIV

!>          IPIV est un tableau ENTIER, de dimension (min(M,N))
!>          Les indices de pivot ; pour 1 <= i <= min(M,N), la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -k, le k-ième argument avait une valeur illégale
!>          > 0 : si INFO = k, U(k,k) est exactement zéro. La factorisation
!>               a été complétée, mais le facteur U est exactement
!>               singulier, et une division par zéro se produira si elle est utilisée
!>               pour résoudre un système d'équations.
!>
