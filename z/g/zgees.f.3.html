subroutine zgees (jobvs, sort, select, n, a, lda, sdim, w, vs, ldvs, work, lwork, rwork, bwork, info)
ZGEES calcule les valeurs propres, la forme de Schur et, facultativement, la matrice des vecteurs de Schur pour les matrices GE

Documentation de fonction/sous-programme

sous-programme zgees (caractère jobvs, caractère sort, externe select, entier n, complexe*16, dimension( lda, * ) a, entier lda, entier sdim, complexe*16, dimension( * ) w, complexe*16, dimension( ldvs, * ) vs, entier ldvs, complexe*16, dimension( * ) work, entier lwork, double précision, dimension( * ) rwork, logique, dimension( * ) bwork, entier info)

ZGEES calcule les valeurs propres, la forme de Schur et, facultativement, la matrice des vecteurs de Schur pour les matrices GE

Objectif:

!>
!> ZGEES calcule pour une matrice complexe A non symétrique de taille N par N,
!> les valeurs propres, la forme de Schur T et, facultativement, la matrice
!> des vecteurs de Schur Z. Cela donne la factorisation de Schur A = Z*T*(Z**H).
!>
!> Facultativement, il ordonne également les valeurs propres sur la diagonale de
!> la forme de Schur de manière à ce que les valeurs propres sélectionnées soient
!> en haut à gauche. Les colonnes de tête de Z forment alors une base orthonormée
!> pour le sous-espace invariant correspondant aux valeurs propres sélectionnées.
!>
!> Une matrice complexe est sous forme de Schur si elle est triangulaire supérieure.
!>

Paramètres

JOBVS 
!>          JOBVS est CHARACTER*1
!>          = 'N': Les vecteurs de Schur ne sont pas calculés ;
!>          = 'V': Les vecteurs de Schur sont calculés.
!>

SORT

!>          SORT est CHARACTER*1
!>          Spécifie si les valeurs propres doivent être ordonnées sur la
!>          diagonale de la forme de Schur.
!>          = 'N': Les valeurs propres ne sont pas ordonnées :
!>          = 'S': Les valeurs propres sont ordonnées (voir SELECT).
!>

SELECT

!>          SELECT est une FONCTION LOGIQUE d'un argument COMPLEX*16
!>          SELECT doit être déclarée EXTERNE dans le sous-programme appelant.
!>          Si SORT = 'S', SELECT est utilisée pour sélectionner les valeurs propres à ordonner
!>          en haut à gauche de la forme de Schur.
!>          Si SORT = 'N', SELECT n'est pas référencée.
!>          La valeur propre W(j) est sélectionnée si SELECT(W(j)) est vrai.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille N par N.
!>          À la sortie, A a été écrasée par sa forme de Schur T.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

SDIM

!>          SDIM est un ENTIER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = nombre de valeurs propres pour lesquelles
!>                         SELECT est vrai.
!>

W

!>          W est un tableau COMPLEX*16, dimension (N)
!>          W contient les valeurs propres calculées, dans le même ordre que
!>          celui où elles apparaissent sur la diagonale de la forme de Schur T de sortie.
!>

VS

!>          VS est un tableau COMPLEX*16, dimension (LDVS,N)
!>          Si JOBVS = 'V', VS contient la matrice unitaire Z des vecteurs de Schur.
!>          Si JOBVS = 'N', VS n'est pas référencé.
!>

LDVS

!>          LDVS est un ENTIER
!>          La dimension principale du tableau VS. LDVS >= 1 ; si
!>          JOBVS = 'V', LDVS >= N.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la taille optimale de LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,2*N).
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (N)
!>

BWORK

!>          BWORK est un tableau LOGIQUE, dimension (N)
!>          Non référencé si SORT = 'N'.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = i, et i est
!>               <= N :  l'algorithme QR n'a pas réussi à calculer toutes les
!>                      valeurs propres ; les éléments 1:ILO-1 et i+1:N de W
!>                      contiennent les valeurs propres qui ont convergé ;
!>                      si JOBVS = 'V', VS contient la matrice qui
!>                      réduit A à sa forme de Schur partiellement convergée.
!>               = N+1 : les valeurs propres n'ont pas pu être réordonnées car
!>                      certaines valeurs propres étaient trop proches pour être séparées (le
!>                      problème est très mal conditionné) ;
!>               = N+2 : après réordonnancement, les erreurs d'arrondi ont modifié les valeurs de
!>                      certaines valeurs propres complexes de sorte que les valeurs propres de tête
!>                      dans la forme de Schur ne satisfont plus
!>                      SELECT = .TRUE.  Ceci pourrait également être causé par
!>                      une sous-dépassement due à une mise à l'échelle.
!>
