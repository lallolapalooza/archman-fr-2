sous-routine zgbsvx (character fact, character trans, integer n, integer kl, integer ku, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, character equed, double precision, dimension( * ) r, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZGBSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices GB

Objectif :

!>
!> ZGBSVX utilise la factorisation LU pour calculer la solution d'un système linéaire complexe
!> A * X = B, A**T * X = B, ou A**H * X = B,
!> où A est une matrice bande d'ordre N avec KL sous-diagonales et KU
!> super-diagonales, et X et B sont des matrices N-par-NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de condition sont également
!> fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées par ce sous-programme :
!>
!> 1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle
!>    de la matrice A, mais si l'équilibrage est utilisé, A est
!>    remplacé par diag(R)*A*diag(C) et B par diag(R)*B (si TRANS='N')
!>    ou diag(C)*B (si TRANS = 'T' ou 'C').
!>
!> 2. Si FACT = 'N' ou 'E', la décomposition LU est utilisée pour factoriser
!>    la matrice A (après équilibrage si FACT = 'E') comme suit :
!>       A = L * U,
!>    où L est un produit de matrices de permutation et triangulaires inférieures unitaires
!>    avec KL sous-diagonales, et U est triangulaire supérieure avec
!>    KL+KU super-diagonales.
!>
!> 3. Si certains U(i,i)=0, de sorte que U soit exactement singulier, le sous-programme
!>    renvoie avec INFO = i. Sinon, la forme factorisée de A est utilisée
!>    pour estimer le nombre de condition de la matrice A. Si le
!>    réciproque du nombre de condition est inférieur à la précision machine,
!>    INFO = N+1 est renvoyé comme avertissement, mais le sous-programme continue
!>    pour résoudre X et calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 5. Un raffinement itératif est appliqué pour améliorer la solution calculée
!>    et calculer les bornes d'erreur et les erreurs arrières pour celle-ci.
!>
!> 6. Si l'équilibrage a été utilisé, la matrice X est prémultipliée par
!>    diag(C) (si TRANS = 'N') ou diag(R) (si TRANS = 'T' ou 'C') de sorte
!>    qu'elle résolve le système original avant l'équilibrage.
!>

Paramètres :

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est fournie en entrée,
!>          et si ce n'est pas le cas, si la matrice A doit être équilibrée avant
!>          d'être factorisée.
!>          = 'F':  En entrée, AFB et IPIV contiennent la forme factorisée de
!>                  A.  Si EQUED n'est pas 'N', la matrice A a été
!>                  équilibrée avec des facteurs d'échelle donnés par R et C.
!>                  AB, AFB et IPIV ne sont pas modifiés.
!>          = 'N':  La matrice A sera copiée dans AFB et factorisée.
!>          = 'E':  La matrice A sera équilibrée si nécessaire, puis
!>                  copiée dans AFB et factorisée.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations.
!>          = 'N':  A * X = B     (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Transposée conjuguée)
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>          Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>          Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, dimension (LDAB,N)
!>          En entrée, la matrice A en stockage bande, dans les lignes 1 à KL+KU+1.
!>          La j-ième colonne de A est stockée dans la j-ième colonne du
!>          tableau AB comme suit :
!>          AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU)<=i<=min(N,j+kl)
!>
!>          Si FACT = 'F' et EQUED n'est pas 'N', alors A doit avoir été
!>          équilibrée par les facteurs d'échelle dans R et/ou C. AB n'est pas
!>          modifié si FACT = 'F' ou 'N', ou si FACT = 'E' et
!>          EQUED = 'N' à la sortie.
!>
!>          À la sortie, si EQUED .ne. 'N', A est mise à l'échelle comme suit :
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est un tableau COMPLEX*16, dimension (LDAFB,N)
!>          Si FACT = 'F', alors AFB est un argument d'entrée et contient à l'entrée
!>          les détails de la factorisation LU de la matrice bande
!>          A, tels que calculés par ZGBTRF. U est stocké comme une matrice bande
!>          triangulaire supérieure avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1,
!>          et les multiplicateurs utilisés pendant la factorisation sont stockés
!>          dans les lignes KL+KU+2 à 2*KL+KU+1. Si EQUED .ne. 'N', alors AFB
!>          est la forme factorisée de la matrice A équilibrée.
!>
!>          Si FACT = 'N', alors AFB est un argument de sortie et renvoie à la sortie
!>          les détails de la factorisation LU de A.
!>
!>          Si FACT = 'E', alors AFB est un argument de sortie et renvoie à la sortie
!>          les détails de la factorisation LU de la matrice A équilibrée
!>          (voir la description de AB pour la forme de la
!>          matrice équilibrée).
!>

LDAFB

!>          LDAFB est INTEGER
!>          La dimension principale du tableau AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et contient à l'entrée
!>          les indices de pivot de la factorisation A = L*U
!>          tels que calculés par ZGBTRF ; la ligne i de la matrice a été échangée
!>          avec la ligne IPIV(i).
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et contient à la sortie
!>          les indices de pivot de la factorisation A = L*U

EQUED

!>          EQUED est CHARACTER*1
!>          Spécifie les équilibrages effectués, le cas échéant, sur la matrice A.
!>          = 'N': Aucun équilibrage n'a été fait.
!>          = 'R': Les lignes ont été mises à l'échelle, c'est-à-dire que A a été
!>                 remplacé par diag(R)*A.
!>          = 'C': Les colonnes ont été mises à l'échelle, c'est-à-dire que A a été
!>                 remplacé par A*diag(C).
!>          = 'B': Les lignes et les colonnes ont été mises à l'échelle, c'est-à-dire que A a été
!>                 remplacé par diag(R)*A*diag(C).
!>

R

!>          R est un tableau DOUBLE PRECISION, dimension (N)
!>          Si EQUED = 'R' ou 'B', R contient les facteurs d'échelle des lignes.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (N)
!>          Si EQUED = 'C' ou 'B', C contient les facteurs d'échelle des colonnes.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          En entrée, le tableau N-par-NRHS contenant les membres de droite B.
!>
!>          Si FACT = 'F' et EQUED est différent de 'N', alors B doit avoir été
!>          mis à l'échelle par les facteurs dans R et/ou C.
!>
!>          À la sortie, si FACT = 'E' et (TRANS='N' ou Trans='T' ou Trans='C'),
!>          alors B est mis à l'échelle comme suit :
!>          EQUED = 'R':  B := diag(R) * B
!>          EQUED = 'C':  B := B * diag(C)
!>          EQUED = 'B':  B := diag(R) * B * diag(C).
!>          Si FACT = 'N' ou 'F', B n'est pas modifié.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          À la sortie, le tableau N-par-NRHS contenant les solutions
!>          X pour les systèmes A*X = B, A**T*X = B, ou A**H*X = B.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          À la sortie, RCOND est une estimation du nombre de condition inverse
!>          de la matrice A. Pour que la matrice soit considérée comme bien conditionnée,
!>          RCOND devrait être proche de 1, et pour qu'elle soit mal conditionnée,
!>          RCOND devrait être petite.
!>

FERR

!>          FERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          À la sortie, FERR contient une estimation des bornes d'erreur relatives
!>          pour chaque colonne de la solution X. Le k-ième élément de FERR
!>          est une borne supérieure de la taille de l'erreur relative dans la k-ième
!>          colonne de X, c'est-à-dire
!>             ||X(k) - X_true||_1 / ||X_true||_1.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          À la sortie, BERR contient les erreurs arrières relatives
!>          estimées pour chaque colonne de la solution X. Le k-ième élément de BERR
!>          est une borne supérieure de la taille de l'erreur arrière relative
!>          dans la k-ième colonne de X, c'est-à-dire
!>             ||delta_A * X(k) + delta_B||_1 / ||A * X(k) + B||_1.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N)
!>          C'est un espace de travail.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>          C'est un espace de travail.
!>

INFO

de la matrice originale A. !> !> Si FACT = 'E', alors IPIV est un argument de sortie et à la sortie !> contient les indices de pivot de la factorisation A = L*U !> de la matrice équilibrée A. !>

EQUED

!>          EQUED est CHARACTER*1
!>          Spécifie la forme d'équilibrage qui a été effectuée.
!>          = 'N':  Aucun équilibrage (toujours vrai si FACT = 'N').
!>          = 'R':  Équilibrage des lignes, c'est-à-dire que A a été pré-multiplié par
!>                  diag(R).
!>          = 'C':  Équilibrage des colonnes, c'est-à-dire que A a été post-multiplié
!>                  par diag(C).
!>          = 'B':  Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>                  remplacé par diag(R) * A * diag(C).
!>          EQUED est un argument d'entrée si FACT = 'F'; sinon, c'est un
!>          argument de sortie.
!>

R

!>          R est un tableau DOUBLE PRECISION, de dimension (N)
!>          Les facteurs d'échelle des lignes pour A. Si EQUED = 'R' ou 'B', A est
!>          multiplié à gauche par diag(R); si EQUED = 'N' ou 'C', R
!>          n'est pas accédé. R est un argument d'entrée si FACT = 'F';
!>          sinon, R est un argument de sortie. Si FACT = 'F' et
!>          EQUED = 'R' ou 'B', chaque élément de R doit être positif.
!>

C

!>          C est un tableau DOUBLE PRECISION, de dimension (N)
!>          Les facteurs d'échelle des colonnes pour A. Si EQUED = 'C' ou 'B', A est
!>          multiplié à droite par diag(C); si EQUED = 'N' ou 'R', C
!>          n'est pas accédé. C est un argument d'entrée si FACT = 'F';
!>          sinon, C est un argument de sortie. Si FACT = 'F' et
!>          EQUED = 'C' ou 'B', chaque élément de C doit être positif.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B du second membre.
!>          À la sortie,
!>          si EQUED = 'N', B n'est pas modifié;
!>          si TRANS = 'N' et EQUED = 'R' ou 'B', B est écrasé par
!>          diag(R)*B;
!>          si TRANS = 'T' ou 'C' et EQUED = 'C' ou 'B', B est
!>          écrasé par diag(C)*B.
!>

LDB

!>          LDB est un entier
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, de dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution N-par-NRHS X
!>          du système d'équations original. Notez que A et B sont
!>          modifiés à la sortie si EQUED .ne. 'N', et la solution du
!>          système équilibré est inv(diag(C))*X si TRANS = 'N' et
!>          EQUED = 'C' ou 'B', ou inv(diag(R))*X si TRANS = 'T' ou 'C'
!>          et EQUED = 'R' ou 'B'.
!>

LDX

!>          LDX est un entier
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est un DOUBLE PRECISION
!>          L'estimation du nombre de condition inverse de la matrice
!>          A après équilibrage (si effectué). Si RCOND est inférieur à la
!>          précision machine (en particulier, si RCOND = 0), la matrice
!>          est singulière à la précision de travail. Cette condition est
!>          indiquée par un code de retour INFO > 0.
!>

FERR

!>          FERR est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ième colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude de la plus grande
!>          élément dans (X(j) - XTRUE) divisée par la magnitude de la plus grande
!>          élément dans X(j). L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          surestimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur
!>          solution X(j) (c'est-à-dire le plus petit changement relatif dans
!>          tout élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (MAX(1,N))
!>          À la sortie, RWORK(1) contient le facteur de croissance des pivots
!>          norm(A)/norm(U). La norme
!>          est utilisée. Si RWORK(1) est beaucoup inférieur à 1, alors la stabilité
!>          de la factorisation LU de la matrice (équilibrée) A
!>          pourrait être médiocre. Cela signifie également que la solution X, l'estimateur
!>          de condition RCOND, et la borne d'erreur avant FERR pourraient être
!>          peu fiables. Si la factorisation échoue avec 0<INFO<=N, alors
!>          RWORK(1) contient le facteur de croissance des pivots pour les
!>          INFO premières colonnes de A.
!>

INFO

!>          INFO est un entier
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ième argument était invalide
!>          > 0:  si INFO = i, et i est
!>                <= N:  U(i,i) est exactement zéro. La factorisation
!>                       a été complétée, mais le facteur U est exactement
!>                       singulier, donc la solution et les bornes d'erreur
!>                       n'ont pas pu être calculées. RCOND = 0 est retourné.
!>                = N+1: U est non singulier, mais RCOND est inférieur à la précision de la machine,
!>                       ce qui signifie que la matrice est singulière
!>                       à la précision de travail. Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car
!>                       il existe un certain nombre de situations où la
!>                       solution calculée peut être plus précise que la
!>                       valeur de RCOND ne le suggérerait.
!>
