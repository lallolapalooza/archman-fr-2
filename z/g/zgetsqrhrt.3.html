Documentation de la fonction/sous-programme

subroutine zgetsqrhrt (integer m, integer n, integer mb1, integer nb1, integer nb2, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( * ) work, integer lwork, integer info)

ZGETSQRHRT

Purpose:

!>
!> ZGETSQRHRT calcule une factorisation QR bloquée de taille NB2
!> de la matrice complexe M-par-N A avec M >= N,
!>
!>    A = Q * R.
!>
!> La routine utilise en interne une factorisation TSQR bloquée en colonnes de taille NB1
!> et bloquée en lignes de taille MB1, et effectue la reconstruction
!> des vecteurs de Householder à partir de la sortie TSQR. La routine convertit également
!> le facteur R_tsqr de la sortie de la factorisation TSQR en
!> le facteur R qui correspond à la factorisation QR de Householder,
!>
!>    A = Q_tsqr * R_tsqr = Q * R.
!>
!> Les facteurs Q et R de sortie sont stockés dans le même format que dans ZGEQRT
!> (Q est en représentation WY bloquée compacte). Voir la documentation
!> de ZGEQRT pour plus de détails sur le format.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

MB1

!>          MB1 est INTEGER
!>          La taille du bloc de lignes à utiliser dans la TSQR bloquée.
!>          MB1 > N.
!>

NB1

!>          NB1 est INTEGER
!>          La taille du bloc de colonnes à utiliser dans la TSQR bloquée.
!>          N >= NB1 >= 1.
!>

NB2

!>          NB2 est INTEGER
!>          La taille du bloc à utiliser dans la QR bloquée de sortie.
!>          NB2 >= 1.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>
!>          En entrée : une matrice A de taille M-par-N.
!>
!>          En sortie :
!>           a) les éléments sur et au-dessus de la diagonale
!>              du tableau contiennent la matrice triangulaire supérieure
!>              N-par-N R correspondant à la QR de Householder ;
!>           b) les éléments sous la diagonale représentent Q par
!>              les colonnes de V bloquées (représentation WY compacte).
!>

LDA

!>          LDA est INTEGER
!>          La dimension de tête du tableau A.  LDA >= max(1,M).
!>

T

!>          T est un tableau COMPLEX*16, de dimension (LDT,N))
!>          Les réflecteurs de blocs triangulaires supérieurs stockés sous forme compacte
!>          comme une séquence de blocs triangulaires supérieurs.
!>

LDT

!>          LDT est INTEGER
!>          La dimension de tête du tableau T.  LDT >= NB2.
!>

WORK

!>          (espace de travail) tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si MIN(M,N) = 0, LWORK >= 1, sinon
!>          LWORK >= MAX( 1, LWT + LW1, MAX( LWT+N*N+LW2, LWT+N*N+N ) ),
!>          où
!>             NUM_ALL_ROW_BLOCKS = CEIL((M-N)/(MB1-N)),
!>             NB1LOCAL = MIN(NB1,N).
!>             LWT = NUM_ALL_ROW_BLOCKS * N * NB1LOCAL,
!>             LW1 = NB1LOCAL * N,
!>             LW2 = NB1LOCAL * MAX( NB1LOCAL, ( N - NB1LOCAL ) ).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée.
!>          La routine calcule uniquement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK, et aucune erreur
!>          liée à LWORK n'est émise par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  succès
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
