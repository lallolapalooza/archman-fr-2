sous-programme zggqrf (integer n, integer m, integer p, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) taua, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) taub, complex*16, dimension( * ) work, integer lwork, integer info)

ZGGQRF

But :

!>
!> ZGGQRF calcule une factorisation QR généralisée d'une matrice A de taille N x M
!> et d'une matrice B de taille N x P :
!>
!>             A = Q*R,        B = Q*T*Z,
!>
!> où Q est une matrice unitaire N x N, Z est une matrice unitaire P x P,
!> et R et T prennent l'une des formes suivantes :
!>
!> si N >= M,  R = ( R11 ) M  ,   ou si N < M,  R = ( R11  R12 ) N,
!>                 (  0  ) N-M                         N   M-N
!>                    M
!>
!> où R11 est triangulaire supérieure, et
!>
!> si N <= P,  T = ( 0  T12 ) N,   ou si N > P,  T = ( T11 ) N-P,
!>                  P-N  N                           ( T21 ) P
!>                                                      P
!>
!> où T12 ou T21 est triangulaire supérieure.
!>
!> En particulier, si B est carrée et non singulière, la factorisation GQR
!> de A et B donne implicitement la factorisation QR de inv(B)*A :
!>
!>              inv(B)*A = Z**H * (inv(T)*R)
!>
!> où inv(B) désigne l'inverse de la matrice B, et Z**H désigne la
!> transposée conjuguée de la matrice Z.
!>

Paramètres

N 
!>          N est INTEGER
!>          Le nombre de lignes des matrices A et B. N >= 0.
!>

M

!>          M est INTEGER
!>          Le nombre de colonnes de la matrice A.  M >= 0.
!>

P

!>          P est INTEGER
!>          Le nombre de colonnes de la matrice B.  P >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,M)
!>          À l'entrée, la matrice A de taille N x M.
!>          À la sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice trapézoïdale supérieure R de taille min(N,M) x M (R est
!>          triangulaire supérieure si N >= M) ; les éléments en dessous de la diagonale,
!>          avec le tableau TAUA, représentent la matrice unitaire Q comme un
!>          produit de min(N,M) réflecteurs élémentaires (voir Détails supplémentaires).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

TAUA

!>          TAUA est un tableau COMPLEX*16, dimension (min(N,M))
!>          Les facteurs scalaires des réflecteurs élémentaires qui
!>          représentent la matrice unitaire Q (voir Détails supplémentaires).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,P)
!>          À l'entrée, la matrice B de taille N x P.
!>          À la sortie, si N <= P, le triangle supérieur du sous-tableau
!>          B(1:N,P-N+1:P) contient la matrice triangulaire supérieure T de taille N x N ;
!>          si N > P, les éléments sur et au-dessus de la (N-P)-ième sous-diagonale
!>          contiennent la matrice trapézoïdale supérieure T de taille N x P ; les éléments restants,
!>          avec le tableau TAUB, représentent la matrice unitaire
!>          Z comme un produit de réflecteurs élémentaires (voir Détails supplémentaires).
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

TAUB

!>          TAUB est un tableau COMPLEX*16, dimension (min(N,P))
!>          Les facteurs scalaires des réflecteurs élémentaires qui
!>          représentent la matrice unitaire Z (voir Détails supplémentaires).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,N,M,P).
!>          Pour une performance optimale, LWORK >= max(N,M,P)*max(NB1,NB2,NB3),
!>          où NB1 est la taille de bloc optimale pour la factorisation QR
!>          d'une matrice N x M, NB2 est la taille de bloc optimale pour la
!>          factorisation RQ d'une matrice N x P, et NB3 est la taille de bloc optimale
!>          pour un appel à ZUNMQR.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>           = 0 : sortie réussie
!>           < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires :

!>
!>  La matrice Q est représentée comme un produit de réflecteurs élémentaires
!>
!>     Q = H(1) H(2) . . . H(k), où k = min(n,m).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - taua * v * v**H
!>
!>  où taua est un scalaire complexe, et v est un vecteur complexe avec
!>  v(1:i-1) = 0 et v(i) = 1 ; v(i+1:n) est stocké à la sortie dans A(i+1:n,i),
!>  et taua dans TAUA(i).
!>  Pour former explicitement Q, utiliser la sous-routine LAPACK ZUNGQR.
!>  Pour utiliser Q pour mettre à jour une autre matrice, utiliser la sous-routine LAPACK ZUNMQR.
!>
!>  La matrice Z est représentée comme un produit de réflecteurs élémentaires
!>
!>     Z = H(1) H(2) . . . H(k), où k = min(n,p).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - taub * v * v**H
!>
!>  où taub est un scalaire complexe, et v est un vecteur complexe avec
!>  v(p-k+i+1:p) = 0 et v(p-k+i) = 1 ; v(1:p-k+i-1) est stocké à la sortie dans
!>  B(n-k+i,1:p-k+i-1), et taub dans TAUB(i).
!>  Pour former explicitement Z, utiliser la sous-routine LAPACK ZUNGRQ.
!>  Pour utiliser Z pour mettre à jour une autre matrice, utiliser la sous-routine LAPACK ZUNMRQ.
!>
