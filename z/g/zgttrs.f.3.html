Documentation de la fonction/sous-programme

sous-programme zgttrs (caractère trans, entier n, entier nrhs, complexe*16, dimension( * ) dl, complexe*16, dimension( * ) d, complexe*16, dimension( * ) du, complexe*16, dimension( * ) du2, entier, dimension( * ) ipiv, complexe*16, dimension( ldb, * ) b, entier ldb, entier info)

ZGTTRS

But:

!>
!> ZGTTRS résout l'un des systèmes d'équations
!>    A * X = B,  A**T * X = B,  ou  A**H * X = B,
!> avec une matrice tridiagonale A en utilisant la factorisation LU calculée
!> par ZGTTRF.
!>

Paramètres

TRANS 
!>          TRANS est de type CHARACTER*1
!>          Spécifie la forme du système d'équations.
!>          = 'N':  A * X = B     (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Conjuguée transposée)
!>

N

!>          N est un entier
!>          L'ordre de la matrice A.
!>

NRHS

!>          NRHS est un entier
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

DL

!>          DL est un tableau de COMPLEX*16, de dimension (N-1)
!>          Les (n-1) multiplicateurs qui définissent la matrice L de la
!>          factorisation LU de A.
!>

D

!>          D est un tableau de COMPLEX*16, de dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire supérieure U de la
!>          factorisation LU de A.
!>

DU

!>          DU est un tableau de COMPLEX*16, de dimension (N-1)
!>          Les (n-1) éléments de la première super-diagonale de U.
!>

DU2

!>          DU2 est un tableau de COMPLEX*16, de dimension (N-2)
!>          Les (n-2) éléments de la deuxième super-diagonale de U.
!>

IPIV

!>          IPIV est un tableau d'entiers, de dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= n, la ligne i de la matrice a été
!>          échangée avec la ligne IPIV(i).  IPIV(i) sera toujours égal à
!>          i ou i+1 ; IPIV(i) = i indique qu'un échange de ligne n'était pas
!>          nécessaire.
!>

B

!>          B est un tableau de COMPLEX*16, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice des vecteurs du côté droit B.
!>          À la sortie, B est écrasé par les vecteurs solution X.
!>

LDB

!>          LDB est un entier
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est un entier
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -k, le k-ième argument avait une valeur illégale
!>
