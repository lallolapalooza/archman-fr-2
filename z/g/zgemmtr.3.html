ZGEMMTR

Documentation de la fonction/sous-programme

sous-routine zgemmtr (caractere uplo, caractere transa, caractere transb, entier n, entier k, complexe*16 alpha, complexe*16, dimension(lda,*) a, entier lda, complexe*16, dimension(ldb,*) b, entier ldb, complexe*16 beta, complexe*16, dimension(ldc,*) c, entier ldc)

ZGEMMTR

Objectif:

!>
!> ZGEMMTR  effectue une des opérations matricielles
!>
!>    C := alpha*op( A )*op( B ) + beta*C,
!>
!> où  op( X ) est l'une des suivantes :
!>
!>    op( X ) = X   ou   op( X ) = X**T,
!>
!> alpha et beta sont des scalaires, et A, B et C sont des matrices, avec op( A )
!> une matrice n x k,  op( B )  une matrice  k x n et  C une matrice n x n.
!> Ainsi, la routine n'accède et ne met à jour que la partie triangulaire supérieure ou inférieure
!> de la matrice résultante C. Ce comportement peut être utilisé si
!> la matrice C résultante est connue pour être hermitienne ou symétrique.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>           En entrée, UPLO spécifie si la partie triangulaire inférieure ou supérieure
!>           de C est accédée et mise à jour.
!>
!>              UPLO = 'L' ou 'l', la partie triangulaire inférieure de C est utilisée.
!>
!>              UPLO = 'U' ou 'u', la partie triangulaire supérieure de C est utilisée.
!>

TRANSA

!>          TRANSA est CHARACTER*1
!>           En entrée, TRANSA spécifie la forme de op( A ) à utiliser dans
!>           la multiplication matricielle comme suit :
!>
!>              TRANSA = 'N' ou 'n',  op( A ) = A.
!>
!>              TRANSA = 'T' ou 't',  op( A ) = A**T.
!>
!>              TRANSA = 'C' ou 'c',  op( A ) = A**H.
!>

TRANSB

!>          TRANSB est CHARACTER*1
!>           En entrée, TRANSB spécifie la forme de op( B ) à utiliser dans
!>           la multiplication matricielle comme suit :
!>
!>              TRANSB = 'N' ou 'n',  op( B ) = B.
!>
!>              TRANSB = 'T' ou 't',  op( B ) = B**T.
!>
!>              TRANSB = 'C' ou 'c',  op( B ) = B**H.
!>

N

!>          N est INTEGER
!>           En entrée, N spécifie le nombre de lignes et de colonnes de
!>           la matrice C, le nombre de colonnes de op(B) et le nombre
!>           de lignes de op(A). N doit être supérieur ou égal à zéro.
!>

K

!>          K est INTEGER
!>           En entrée, K spécifie le nombre de colonnes de la matrice
!>           op( A ) et le nombre de lignes de la matrice op( B ). K doit
!>           être supérieur ou égal à zéro.
!>

ALPHA

!>          ALPHA est COMPLEX*16.
!>           En entrée, ALPHA spécifie le scalaire alpha.
!>

A

!>          A est un tableau COMPLEX*16, dimension ( LDA, ka ), où ka est
!>           k  quand  TRANSA = 'N' ou 'n',  et est  n  sinon.
!>           Avant l'entrée avec  TRANSA = 'N' ou 'n',  la partie principale n x k
!>           du tableau  A  doit contenir la matrice  A,  sinon
!>           la partie principale  k x m  du tableau  A  doit contenir  la
!>           matrice A.
!>

LDA

!>          LDA est INTEGER
!>           En entrée, LDA spécifie la première dimension de A telle que déclarée
!>           dans le programme appelant. Quand  TRANSA = 'N' ou 'n' alors
!>           LDA doit être supérieur ou égal à  max( 1, n ), sinon  LDA doit
!>           être supérieur ou égal à  max( 1, k ).
!>

B

!>          B est un tableau COMPLEX*16, dimension ( LDB, kb ), où kb est
!>           n  quand  TRANSB = 'N' ou 'n',  et est  k  sinon.
!>           Avant l'entrée avec  TRANSB = 'N' ou 'n',  la partie principale  k x n
!>           du tableau  B  doit contenir la matrice  B,  sinon
!>           la partie principale  n x k  du tableau  B  doit contenir  la
!>           matrice B.
!>

LDB

!>          LDB est INTEGER
!>           En entrée, LDB spécifie la première dimension de B telle que déclarée
!>           dans le programme appelant. Quand  TRANSB = 'N' ou 'n' alors
!>           LDB doit être supérieur ou égal à  max( 1, k ), sinon  LDB doit
!>           être supérieur ou égal à  max( 1, n ).
!>

BETA

!>          BETA est COMPLEX*16.
!>           En entrée, BETA spécifie le scalaire beta.  Quand BETA
!>           est fourni comme zéro, C n'a pas besoin d'être initialisé à l'entrée.
!>

C

!>          C est un tableau COMPLEX*16, dimension ( LDC, N )
!>           Avant l'entrée, la partie principale n x n du tableau  C doit
!>           contenir la matrice  C,  sauf lorsque beta est zéro, auquel cas
!>           C n'a pas besoin d'être initialisé à l'entrée.
!>           En sortie, la partie supérieure ou inférieure triangulaire de la matrice
!>           C est écrasée par la matrice n x n
!>           ( alpha*op( A )*op( B ) + beta*C ).
!>

LDC

!>          LDC est INTEGER
!>           En entrée, LDC spécifie la première dimension de C telle que déclarée
!>           dans le programme appelant. LDC doit être supérieur ou égal
!>           à  max( 1, n ).
!>
