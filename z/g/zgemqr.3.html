sous-programme zgemqr (caractère side, caractère trans, entier m, entier n, entier k, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) t, entier tsize, complexe*16, dimension( ldc, * ) c, entier ldc, complexe*16, dimension( * ) work, entier lwork, entier info)

ZGEMQR

Objectif :

!>
!> ZGEMQR écrase la matrice générale réelle M par N de C avec
!>
!>                      SIDE = 'L'     SIDE = 'R'
!>      TRANS = 'N':      Q * C          C * Q
!>      TRANS = 'T':      Q**H * C       C * Q**H
!>
!>
!> où Q est une matrice unitaire complexe définie comme le produit
!> d'une famille de réflecteurs élémentaires calculés par la factorisation
!> QR bloquée (ZGEQR)
!>
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer Q ou Q**H à gauche ;
!>          = 'R' : appliquer Q ou Q**H à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : Pas de transposer, appliquer Q ;
!>          = 'C' : Transposer conjugué, appliquer Q**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >=0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est COMPLEX*16 array, dimension (LDA,K)
!>          Partie de la structure de données pour représenter Q telle que retournée par ZGEQR.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,M) ;
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T est COMPLEX*16 array, dimension (MAX(5,TSIZE)).
!>          Partie de la structure de données pour représenter Q telle que retournée par ZGEQR.
!>

TSIZE

!>          TSIZE est INTEGER
!>          La dimension du tableau T. TSIZE >= 5.
!>

C

!>          C est COMPLEX*16 array, dimension (LDC,N)
!>          En entrée, la matrice M par N de C.
!>          En sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          (espace de travail) COMPLEX*16 array, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la valeur minimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée. La routine
!>          calcule uniquement la taille du tableau WORK, retourne cette
!>          valeur dans WORK(1) et aucun message d'erreur lié à WORK
!>          n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
