Documentation de la fonction/sous-routine

subroutine zgesdd (character jobz, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( ldvt, * ) vt, integer ldvt, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

ZGESDD

But :

!>
!> ZGESDD calcule la décomposition en valeurs singulières (SVD) d'une matrice complexe
!> M par N, A, en calculant éventuellement les vecteurs singuliers gauches et/ou droits,
!> en utilisant la méthode diviser pour régner. La SVD est écrite
!>
!>      A = U * SIGMA * conjugué transposé(V)
!>
!> où SIGMA est une matrice M par N qui est nulle sauf ses
!> éléments diagonaux min(m,n), U est une matrice unitaire M par M, et
!> V est une matrice unitaire N par N. Les éléments diagonaux de SIGMA
!> sont les valeurs singulières de A ; elles sont réelles et non négatives, et
!> sont retournées par ordre décroissant. Les min(m,n) premières colonnes de
!> U et V sont les vecteurs singuliers gauches et droits de A.
!>
!> Notez que la routine retourne VT = V**H, et non V.
!>
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          Spécifie les options pour le calcul de tout ou partie de la matrice U :
!>          = 'A' : toutes les M colonnes de U et toutes les N lignes de V**H
!>                  sont retournées dans les tableaux U et VT ;
!>          = 'S' : les min(M,N) premières colonnes de U et les min(M,N) premières
!>                  lignes de V**H sont retournées dans les tableaux U
!>                  et VT ;
!>          = 'O' : Si M >= N, les N premières colonnes de U sont écrasées
!>                  dans le tableau A et toutes les lignes de V**H sont retournées
!>                  dans le tableau VT ;
!>                  sinon, toutes les colonnes de U sont retournées dans
!>                  le tableau U et les M premières lignes de V**H sont écrasées
!>                  dans le tableau A ;
!>          = 'N' : aucune colonne de U ou ligne de V**H n'est calculée.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A. N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M par N.
!>          À la sortie,
!>          si JOBZ = 'O', A est écrasée par les N premières colonnes
!>                          de U (les vecteurs singuliers gauches, stockés
!>                          par colonnes) si M >= N ;
!>                          A est écrasée par les M premières lignes
!>                          de V**H (les vecteurs singuliers droits, stockés
!>                          par lignes) sinon.
!>          si JOBZ .ne. 'O', le contenu de A est détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (min(M,N))
!>          Les valeurs singulières de A, triées de sorte que S(i) >= S(i+1).
!>

U

!>          U est un tableau COMPLEX*16, dimension (LDU,UCOL)
!>          UCOL = M si JOBZ = 'A' ou JOBZ = 'O' et M < N ;
!>          UCOL = min(M,N) si JOBZ = 'S'.
!>          Si JOBZ = 'A' ou JOBZ = 'O' et M < N, U contient la matrice
!>          unitaire M par M, U ;
!>          si JOBZ = 'S', U contient les min(M,N) premières colonnes de
!>          U (les vecteurs singuliers gauches, stockés par colonnes) ;
!>          si JOBZ = 'O' et M >= N, ou JOBZ = 'N', U n'est pas référencé.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= 1 ;
!>          si JOBZ = 'S' ou 'A' ou JOBZ = 'O' et M < N, LDU >= M.
!>

VT

!>          VT est un tableau COMPLEX*16, dimension (LDVT,N)
!>          Si JOBZ = 'A' ou JOBZ = 'O' et M >= N, VT contient la matrice
!>          unitaire N par N, V**H ;
!>          si JOBZ = 'S', VT contient les min(M,N) premières lignes
!>          de V**H (les vecteurs singuliers droits, stockés par lignes) ;
!>          si JOBZ = 'O' et M < N, ou JOBZ = 'N', VT n'est pas référencé.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT. LDVT >= 1 ;
!>          si JOBZ = 'A' ou JOBZ = 'O' et M >= N, LDVT >= N ;
!>          si JOBZ = 'S', LDVT >= min(M,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur LWORK optimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>          Si LWORK = -1, une requête d'espace de travail est supposée. La taille
!>          optimale pour le tableau WORK est calculée et stockée dans WORK(1),
!>          et aucun autre travail, hormis la vérification des arguments, n'est effectué.
!>
!>          Soit mx = max(M,N) et mn = min(M,N).
!>          Si JOBZ = 'N', LWORK >= 2*mn + mx.
!>          Si JOBZ = 'O', LWORK >= 2*mn*mn + 2*mn + mx.
!>          Si JOBZ = 'S', LWORK >=   mn*mn + 3*mn.
!>          Si JOBZ = 'A', LWORK >=   mn*mn + 2*mn + mx.
!>          Ce ne sont pas des minimums stricts dans tous les cas ; voir les commentaires
!>          à l'intérieur du code.
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand ;
!>          une requête est recommandée.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LRWORK))
!>          Soit mx = max(M,N) et mn = min(M,N).
!>          Si JOBZ = 'N',    LRWORK >= 5*mn (LAPACK <= 3.6 nécessite 7*mn) ;
!>          sinon si mx >> mn, LRWORK >= 5*mn*mn + 5*mn ;
!>          sinon              LRWORK >= max( 5*mn*mn + 5*mn,
!>                                           2*mx*mn + 2*mn*mn + mn ).
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (8*min(M,N))
!>

INFO

!>          INFO est INTEGER
!>          <  0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>          = -4 : si A contenait une entrée NAN.
!>          >  0 : Le processus de mise à jour de DBDSDC n'a pas convergé.
!>          =  0 : sortie réussie.
!>
