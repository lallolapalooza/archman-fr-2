sous-programme zgsvj0 (character*1 jobv, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( n ) d, double precision, dimension( n ) sva, integer mv, complex*16, dimension( ldv, * ) v, integer ldv, double precision eps, double precision sfmin, double precision tol, integer nsweep, complex*16, dimension( lwork ) work, integer lwork, integer info)

ZGSVJ0 préprocesseur de la routine zgesvj.

Objectif:

!>
!> ZGSVJ0 est appelée par ZGESVJ comme préprocesseur et c'est son but principal. Elle applique des rotations de Jacobi de la même manière que ZGESVJ, mais ne vérifie pas la convergence (critère d'arrêt). Quelques paramètres de réglage (marqués par [TP]) sont disponibles pour l'implémenteur.
!>

Paramètres

JOBV 
!>          JOBV est CHARACTER*1
!>          Spécifie si la sortie de cette procédure est utilisée
!>          pour calculer la matrice V :
!>          = 'V' : le produit des rotations de Jacobi est accumulé
!>                 par post-multiplication du tableau N-par-N V.
!>                (Voir la description de V.)
!>          = 'A' : le produit des rotations de Jacobi est accumulé
!>                 par post-multiplication du tableau MV-par-N V.
!>                (Voir les descriptions de MV et V.)
!>          = 'N' : les rotations de Jacobi ne sont pas accumulées.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la matrice M-par-N A, telle que A*diag(D) représente
!>          la matrice d'entrée.
!>          À la sortie,
!>          A_à_la_sortie * diag(D_à_la_sortie) représente la matrice d'entrée A*diag(D)
!>          post-multipliée par une séquence de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de passes sont donnés dans
!>          TOL et NSWEEP, respectivement.
!>          (Voir les descriptions de D, TOL et NSWEEP.)
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

D

!>          D est un tableau COMPLEX*16, dimension (N)
!>          Le tableau D accumule les facteurs de mise à l'échelle des rotations de Jacobi complexes mises à l'échelle.
!>          À l'entrée, A*diag(D) représente la matrice d'entrée.
!>          À la sortie, A_à_la_sortie*diag(D_à_la_sortie) représente la matrice d'entrée
!>          post-multipliée par une séquence de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de passes sont donnés dans
!>          TOL et NSWEEP, respectivement.
!>          (Voir les descriptions de A, TOL et NSWEEP.)
!>

SVA

!>          SVA est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, SVA contient les normes euclidiennes des colonnes de
!>          la matrice A*diag(D).
!>          À la sortie, SVA contient les normes euclidiennes des colonnes de
!>          la matrice A_à_la_sortie*diag(D_à_la_sortie).
!>

MV

!>          MV est INTEGER
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'N',   alors MV n'est pas référencé.
!>

V

!>          V est un tableau COMPLEX*16, dimension (LDV,N)
!>          Si JOBV = 'V' alors N lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'A' alors MV lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'N',   alors V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V, LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!>

EPS

!>          EPS est DOUBLE PRECISION
!>          EPS = DLAMCH('Epsilon')
!>

SFMIN

!>          SFMIN est DOUBLE PRECISION
!>          SFMIN = DLAMCH('Safe Minimum')
!>

TOL

!>          TOL est DOUBLE PRECISION
!>          TOL est le seuil pour les rotations de Jacobi. Pour une paire
!>          A(:,p), A(:,q) de colonnes de pivot, la rotation de Jacobi est
!>          appliquée seulement si ABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!>

NSWEEP

!>          NSWEEP est INTEGER
!>          NSWEEP est le nombre de passes de rotations de Jacobi à effectuer.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          LWORK est la dimension de WORK. LWORK >= M.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, alors le i-ème argument avait une valeur illégale
!>

Détails supplémentaires:

ZGSVJ0 est utilisé simplement pour permettre à ZGESVJ d'appeler une version simplifiée de lui-même pour opérer sur une sous-matrice de la matrice d'origine.
