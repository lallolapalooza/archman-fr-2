sous-programme zgesvd (caractère jobu, caractère jobvt, entier m, entier n, complexe*16, dimension( lda, * ) a, entier lda, double précision, dimension( * ) s, complexe*16, dimension( ldu, * ) u, entier ldu, complexe*16, dimension( ldvt, * ) vt, entier ldvt, complexe*16, dimension( * ) work, entier lwork, double précision, dimension( * ) rwork, entier info)

ZGESVD calcule la décomposition en valeurs singulières (SVD) pour les matrices GE

Objectif :

!>
!> ZGESVD calcule la décomposition en valeurs singulières (SVD) d'une matrice complexe
!> M par N, A, en calculant éventuellement les vecteurs singuliers gauches et/ou droits.
!> La SVD est écrite
!>
!>      A = U * SIGMA * conjugué-transposé(V)
!>
!> où SIGMA est une matrice M par N nulle sauf pour ses éléments diagonaux
!> min(m,n), U est une matrice unitaire M par M, et V est une matrice unitaire
!> N par N. Les éléments diagonaux de SIGMA sont les valeurs singulières de A;
!> elles sont réelles et non négatives, et sont retournées dans l'ordre décroissant.
!> Les premières min(m,n) colonnes de U et V sont les vecteurs singuliers gauche
!> et droit de A.
!>
!> Notez que la routine retourne V**H, et non V.
!>

Paramètres

JOBU 
!>          JOBU est CARACTERE*1
!>          Spécifie les options pour le calcul de tout ou partie de la matrice U:
!>          = 'A':  toutes les M colonnes de U sont retournées dans le tableau U:
!>          = 'S':  les premières min(m,n) colonnes de U (les vecteurs singuliers
!>                  gauches) sont retournées dans le tableau U;
!>          = 'O':  les premières min(m,n) colonnes de U (les vecteurs singuliers
!>                  gauches) sont écrasées sur le tableau A;
!>          = 'N':  aucune colonne de U (aucun vecteur singulier gauche) n'est
!>                  calculée.
!>

JOBVT

!>          JOBVT est CARACTERE*1
!>          Spécifie les options pour le calcul de tout ou partie de la matrice
!>          V**H:
!>          = 'A':  toutes les N lignes de V**H sont retournées dans le tableau VT;
!>          = 'S':  les premières min(m,n) lignes de V**H (les vecteurs singuliers
!>                  droits) sont retournées dans le tableau VT;
!>          = 'O':  les premières min(m,n) lignes de V**H (les vecteurs singuliers
!>                  droits) sont écrasées sur le tableau A;
!>          = 'N':  aucune ligne de V**H (aucun vecteur singulier droit) n'est
!>                  calculée.
!>
!>          JOBVT et JOBU ne peuvent pas être tous deux 'O'.
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice d'entrée A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la matrice M par N, A.
!>          À la sortie,
!>          si JOBU = 'O',  A est écrasée par les premières min(m,n)
!>                          colonnes de U (les vecteurs singuliers
!>                          gauches, stockés par colonne);
!>          si JOBVT = 'O', A est écrasée par les premières min(m,n)
!>                          lignes de V**H (les vecteurs singuliers
!>                          droits, stockés par ligne);
!>          si JOBU .ne. 'O' et JOBVT .ne. 'O', le contenu de A
!>                          est détruit.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

S

!>          S est un tableau DOUBLE PRÉCISION, dimension (min(M,N))
!>          Les valeurs singulières de A, triées de telle sorte que S(i) >= S(i+1).
!>

U

!>          U est un tableau COMPLEX*16, dimension (LDU,UCOL)
!>          (LDU,M) si JOBU = 'A' ou (LDU,min(M,N)) si JOBU = 'S'.
!>          Si JOBU = 'A', U contient la matrice unitaire M par M, U;
!>          si JOBU = 'S', U contient les premières min(m,n) colonnes de
!>          U (les vecteurs singuliers gauches, stockés par colonne);
!>          si JOBU = 'N' ou 'O', U n'est pas référencé.
!>

LDU

!>          LDU est ENTIER
!>          La dimension principale du tableau U.  LDU >= 1; si
!>          JOBU = 'S' ou 'A', LDU >= M.
!>

VT

!>          VT est un tableau COMPLEX*16, dimension (LDVT,N)
!>          Si JOBVT = 'A', VT contient la matrice unitaire N par N,
!>          V**H;
!>          si JOBVT = 'S', VT contient les premières min(m,n) lignes
!>          de V**H (les vecteurs singuliers droits, stockés par ligne);
!>          si JOBVT = 'N' ou 'O', VT n'est pas référencé.
!>

LDVT

!>          LDVT est ENTIER
!>          La dimension principale du tableau VT.  LDVT >= 1; si
!>          JOBVT = 'A', LDVT >= N; si JOBVT = 'S', LDVT >= min(M,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne la taille optimale LWORK.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.
!>          LWORK >=  MAX(1,2*MIN(M,N)+MAX(M,N)).
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (5*min(M,N))
!>          À la sortie, si INFO > 0, RWORK(1:MIN(M,N)-1) contient les
!>          éléments superdiagonaux non convergés d'une matrice bidiagonale
!>          intermédiaire B dont la diagonale est dans S (pas nécessairement triée).
!>          B satisfait A = U * B * VT, elle a donc les mêmes valeurs singulières
!>          que A, et des vecteurs singuliers liés par U et VT.
!>

INFO

!>          INFO est ENTIER
!>          = 0:  exécution réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  si ZBDSQR n'a pas convergé, INFO spécifie combien de
!>                superdiagonales d'une forme bidiagonale intermédiaire B
!>                n'ont pas convergé vers zéro. Voir la description de RWORK
!>                ci-dessus pour les détails.
!>
