sous-routine zgelq2 (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer info)

ZGELQ2 calcule la factorisation LQ d'une matrice rectangulaire générale à l'aide d'un algorithme non bloqué.

Objectif :

!>
!> ZGELQ2 calcule une factorisation LQ d'une matrice complexe m x n, A :
!>
!>    A = ( L 0 ) *  Q
!>
!> où :
!>
!>    Q est une matrice orthogonale n x n ;
!>    L est une matrice triangulaire inférieure m x m ;
!>    0 est une matrice nulle m x (n-m), si m < n.
!>
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          En entrée, la matrice m x n, A.
!>          En sortie, les éléments sur et en dessous de la diagonale du tableau
!>          contiennent la matrice trapézoïdale inférieure L de dimensions m x min(m,n) (L est
!>          triangulaire inférieure si m <= n) ; les éléments au-dessus de la diagonale,
!>          avec le tableau TAU, représentent la matrice unitaire Q comme un
!>          produit de réflecteurs élémentaires (voir Détails supplémentaires).
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEX*16, de dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires (voir Détails
!>          supplémentaires).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (M)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>

Auteur

Univ. du Tennessee

Univ. de Californie Berkeley

Univ. du Colorado Denver

NAG Ltd.

Détails supplémentaires :

!>
!>  La matrice Q est représentée comme un produit de réflecteurs élémentaires
!>
!>     Q = H(k)**H . . . H(2)**H H(1)**H, où k = min(m,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**H
!>
!>  où tau est un scalaire complexe, et v est un vecteur complexe avec
!>  v(1:i-1) = 0 et v(i) = 1 ; conjg(v(i+1:n)) est stocké en sortie dans
!>  A(i,i+1:n), et tau dans TAU(i).
!>

Définition à la ligne 128 du fichier zgelq2.f.
