Documentation de la fonction/sous-routine

subroutine zgeqp3 (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer info)

ZGEQP3

Objectif :

!>
!> ZGEQP3 calcule une factorisation QR avec pivot de colonnes d'une
!> matrice A : A*P = Q*R en utilisant BLAS de niveau 3.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

A

!>          A est un tableau de type COMPLEX*16, dimension (LDA,N)
!>          En entrée, la matrice A de taille M x N.
!>          En sortie, le triangle supérieur du tableau contient la matrice
!>          trapézoïdale supérieure R de taille min(M,N) x N ; les éléments
!>          en dessous de la diagonale, ainsi que le tableau TAU, représentent
!>          la matrice unitaire Q comme un produit de min(M,N) réflecteurs
!>          élémentaires.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

JPVT

!>          JPVT est un tableau d'entiers, dimension (N)
!>          En entrée, si JPVT(J) n'est pas égal à 0, la J-ème colonne de A est
!>          pivotée en tête de A*P (une colonne principale) ; si JPVT(J)=0,
!>          la J-ème colonne de A est une colonne libre.
!>          En sortie, si JPVT(J)=K, alors la J-ème colonne de A*P était la
!>          K-ème colonne de A.
!>

TAU

!>          TAU est un tableau de type COMPLEX*16, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO=0, WORK(1) contient la taille LWORK optimale.
!>

LWORK

!>          LWORK est un entier
!>          La dimension du tableau WORK. LWORK >= N+1.
!>          Pour des performances optimales, LWORK >= ( N+1 )*NB, où NB
!>          est la taille de bloc optimale.
!>
!>          Si LWORK = -1, une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau de type DOUBLE PRECISION, dimension (2*N)
!>

INFO

!>          INFO est un entier
!>          = 0 : succès.
!>          < 0 : si INFO = -i, le i-ème argument était illégal.
!>

Détails supplémentaires :

!>
!>  La matrice Q est représentée comme un produit de réflecteurs élémentaires
!>
!>     Q = H(1) H(2) . . . H(k), où k = min(m,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**H
!>
!>  où tau est un scalaire complexe, et v est un vecteur réel/complexe
!>  avec v(1:i-1) = 0 et v(i) = 1 ; v(i+1:m) est stocké en sortie dans
!>  A(i+1:m,i), et tau dans TAU(i).
!>
