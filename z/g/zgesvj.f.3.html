Documentation de la fonction/sous-programme

subroutine zgesvj (character*1 joba, character*1 jobu, character*1 jobv, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( n ) sva, integer mv, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( lwork ) cwork, integer lwork, double precision, dimension( lrwork ) rwork, integer lrwork, integer info)

ZGESVJ

Purpose:

!>
!> ZGESVJ calcule la décomposition en valeurs singulières (SVD) d'une matrice complexe
!> M par N, A, où M >= N. La SVD de A s'écrit :
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^*,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> où SIGMA est une matrice diagonale N par N, U est une matrice orthonormée M par N,
!> et V est une matrice unitaire N par N. Les éléments diagonaux de SIGMA sont les
!> valeurs singulières de A. Les colonnes de U et V sont les vecteurs singuliers
!> gauches et droits de A, respectivement.
!>

Paramètres

JOBA 
!>          JOBA est CHARACTER*1
!>          Spécifie la structure de A.
!>          = 'L': La matrice d'entrée A est triangulaire inférieure ;
!>          = 'U': La matrice d'entrée A est triangulaire supérieure ;
!>          = 'G': La matrice d'entrée A est une matrice générale M par N, M >= N.
!>

JOBU

!>          JOBU est CHARACTER*1
!>          Spécifie si les vecteurs singuliers gauches
!>          (colonnes de U) doivent être calculés :
!>          = 'U' ou 'F' : Les vecteurs singuliers gauches correspondant aux valeurs
!>                 singulières non nulles sont calculés et retournés dans les
!>                 colonnes principales de A. Voir plus de détails dans la description de A.
!>                 Le seuil d'orthogonalité numérique par défaut est défini à
!>                 environ TOL=CTOL*EPS, CTOL=SQRT(M), EPS=DLAMCH('E').
!>          = 'C' : Analogue à JOBU='U', sauf que l'utilisateur peut contrôler le
!>                 niveau d'orthogonalité numérique des vecteurs singuliers gauches
!>                 calculés. TOL peut être défini à TOL = CTOL*EPS, où
!>                 CTOL est donné en entrée dans le tableau WORK.
!>                 Aucun CTOL inférieur à UN n'est autorisé. CTOL supérieur
!>                 à 1 / EPS n'a pas de sens. L'option 'C'
!>                 peut être utilisée si M*EPS garantit une orthogonalité
!>                 suffisante des vecteurs singuliers gauches calculés, de sorte que CTOL=M
!>                 peut économiser quelques passes de rotations de Jacobi.
!>                 Voir les descriptions de A et WORK(1).
!>          = 'N' : La matrice U n'est pas calculée. Cependant, voir la
!>                 description de A.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          Spécifie si les vecteurs singuliers droits,
!>          c'est-à-dire la matrice V, doivent être calculés :
!>          = 'V' ou 'J' : la matrice V est calculée et retournée dans le tableau V
!>          = 'A' :  les rotations de Jacobi sont appliquées au tableau MV par N
!>                  de V. Autrement dit, la matrice de vecteurs singuliers droits V
!>                  n'est pas calculée explicitement ; elle est plutôt appliquée
!>                  à une matrice MV par N initialement stockée dans les
!>                  MV premières lignes de V.
!>          = 'N' :  la matrice V n'est pas calculée et le tableau V n'est pas
!>                  utilisé.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. 1/DLAMCH('E') > M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la matrice M par N, A.
!>          À la sortie,
!>          Si JOBU = 'U' OU JOBU = 'C':
!>                 Si INFO = 0 :
!>                 Les colonnes orthonormées de rang RANKA de U sont retournées dans les
!>                 colonnes principales de RANKA du tableau A. Ici RANKA <= N
!>                 est le nombre de valeurs singulières calculées de A qui sont
!>                 au-dessus du seuil de sous-dépassement DLAMCH('S'). Les vecteurs singuliers
!>                 correspondant aux valeurs singulières sous-dépassées ou nulles
!>                 ne sont pas calculés. La valeur de RANKA est retournée
!>                 dans le tableau RWORK sous la forme RANKA=NINT(RWORK(2)). Voir aussi les
!>                 descriptions de SVA et RWORK. Les colonnes calculées de U
!>                 sont mutuellement numériquement orthogonales jusqu'à environ
!>                 TOL=SQRT(M)*EPS (par défaut) ; ou TOL=CTOL*EPS (JOBU = 'C'),
!>                 voir la description de JOBU.
!>                 Si INFO > 0,
!>                 la procédure ZGESVJ n'a pas convergé dans le nombre donné
!>                 d'itérations (passes). Dans ce cas, les colonnes calculées de U
!>                 peuvent ne pas être orthogonales jusqu'à TOL. La sortie
!>                 U (stockée dans A), SIGMA (donnée par les valeurs singulières calculées dans SVA(1:N)) et V constitue toujours une décomposition de la
!>                 matrice d'entrée A au sens où le résidu
!>                 || A - SCALE * U * SIGMA * V^* ||_2 / ||A||_2 est petit.
!>          Si JOBU = 'N':
!>                 Si INFO = 0 :
!>                 Notez que les vecteurs singuliers gauches sont "gratuits" dans
!>                 l'algorithme SVD de Jacobi unidimensionnel. Cependant, si seules les
!>                 valeurs singulières sont nécessaires, le niveau d'orthogonalité numérique
!>                 de U n'est pas un problème et les itérations sont arrêtées lorsque les
!>                 colonnes de la matrice itérée sont numériquement orthogonales jusqu'à environ
!>                 M*EPS. Ainsi, à la sortie, A contient les colonnes de U mises à l'échelle
!>                 par les valeurs singulières correspondantes.
!>                 Si INFO > 0:
!>                 la procédure ZGESVJ n'a pas convergé dans le nombre donné
!>                 d'itérations (passes).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

SVA

!>          SVA est un tableau DOUBLE PRECISION, dimension (N)
!>          À la sortie,
!>          Si INFO = 0 :
!>          selon la valeur de SCALE = RWORK(1), nous avons :
!>                 Si SCALE = UN :
!>                 SVA(1:N) contient les valeurs singulières calculées de A.
!>                 Pendant le calcul, SVA contient les normes euclidiennes des colonnes
!>                 des matrices itérées dans le tableau A.
!>                 Si SCALE != UN :
!>                 Les valeurs singulières de A sont SCALE*SVA(1:N), et cette
!>                 représentation factorisée est due au fait que certaines des
!>                 valeurs singulières de A peuvent sous-dépasser ou dépasser.
!>
!>          Si INFO > 0 :
!>          la procédure ZGESVJ n'a pas convergé dans le nombre donné
!>          d'itérations (passes) et SCALE*SVA(1:N) peut ne pas être exact.
!>

MV

!>          MV est INTEGER
!>          Si JOBV = 'A', alors le produit des rotations de Jacobi dans ZGESVJ
!>          est appliqué aux MV premières lignes de V. Voir la description de JOBV.
!>

V

!>          V est un tableau COMPLEX*16, dimension (LDV,N)
!>          Si JOBV = 'V', alors V contient à la sortie la matrice N par N des
!>                         vecteurs singuliers droits ;
!>          Si JOBV = 'A', alors V contient le produit de la matrice de vecteurs singuliers droits calculée et de la matrice initiale dans
!>                         le tableau V.
!>          Si JOBV = 'N', alors V n'est pas utilisé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension p

NOM

ZGESVJ - sous-routine du LAPACK pour calculer la décomposition en valeurs singulières (SVD) d'une matrice complexe.

SYNTAXE

 SUBROUTINE ZGESVJ( JOBV, JOBR, JOBU, M, N, A, LDA, SVA, U, LDU, V, LDV,
                    CWORK, LWORK, RWORK, LRWORK, INFO )

Les arguments sont :

JOBV

CHARACTER*1. Indique comment calculer les vecteurs singuliers droits. Options possibles :

  • 'N' : aucun vecteur singulier droit n'est calculé.
  • 'A' : tous les vecteurs singuliers droits sont calculés.
  • 'S' : les K premiers vecteurs singuliers droits sont calculés, où K = MIN(M,N).
  • 'O' : les K premiers vecteurs singuliers droits sont calculés et renvoyés dans la matrice A. Les vecteurs singuliers gauches ne sont pas renvoyés.
  • 'U' : les K premiers vecteurs singuliers droits sont calculés. Si JOBVU = 'V', alors ces vecteurs sont calculés dans la matrice V. Sinon, ils ne sont pas renvoyés.
JOBR

CHARACTER*1. Indique comment calculer les valeurs singulières. Options possibles :

  • 'N' : les valeurs singulières ne sont pas calculées.
  • 'V' : les valeurs singulières sont calculées.
  • 'L' : les valeurs singulières sont calculées et renvoyées dans la matrice SVA.
JOBU

CHARACTER*1. Indique comment calculer les vecteurs singuliers gauches. Options possibles :

  • 'N' : aucun vecteur singulier gauche n'est calculé.
  • 'A' : tous les vecteurs singuliers gauches sont calculés.
  • 'S' : les K premiers vecteurs singuliers gauches sont calculés, où K = MIN(M,N).
  • 'O' : les K premiers vecteurs singuliers gauches sont calculés et renvoyés dans la matrice A. Les vecteurs singuliers droits ne sont pas renvoyés.
  • 'C' : les K premiers vecteurs singuliers gauches sont calculés. Si JOBUL = 'V', alors ces vecteurs sont calculés dans la matrice U. Sinon, ils ne sont pas renvoyés.
M

INTEGER. Le nombre de lignes de la matrice A.

N

INTEGER. Le nombre de colonnes de la matrice A.

A

COMPLEX*16, dimension (LDA,N). La matrice d'entrée.

LDA

INTEGER. La dimension de la première dimension de A. LDA >= MAX(1,M).

SVA

DOUBLE PRECISION, dimension (MAX(1,N)). Sur la sortie, contient les valeurs singulières de A dans l'ordre décroissant. Si JOBR = 'N', le contenu de SVA n'est pas utilisé.

U

COMPLEX*16, dimension (LDU,MAX(1,M)). Si JOBU = 'A', U contient les M premiers vecteurs singuliers gauches de A. Si JOBU = 'S', U contient les K premiers vecteurs singuliers gauches de A. Si JOBU = 'O', U n'est pas utilisé. Les vecteurs colonnes de U sont mutuellement orthogonaux.

LDU

INTEGER. La dimension de la première dimension de U. Si JOBU = 'A', LDU >= MAX(1,M). Si JOBU = 'S', LDU >= MAX(1,K), où K = MIN(M,N).

V

COMPLEX*16, dimension (LDV,MAX(1,N)). Si JOBV = 'A', V contient les N premiers vecteurs singuliers droits de A. Si JOBV = 'S', V contient les K premiers vecteurs singuliers droits de A. Si JOBV = 'O', V n'est pas utilisé. Les vecteurs colonnes de V sont mutuellement orthogonaux.

LDV

INTEGER. La dimension de la première dimension de V. Si JOBV = 'A', LDV >= MAX(1,N). Si JOBV = 'S', LDV >= MAX(1,K), où K = MIN(M,N).

CWORK

COMPLEX*16, dimension (MAX(1,LWORK)). Tableau de travail.

LWORK

INTEGER. La taille de CWORK. LWORK >= 1, si MIN(M,N) = 0, et LWORK >= M+N, sinon.

Si lors de l'entrée LWORK = -1, une requête de taille de travail est supposée et aucun calcul n'est effectué ; CWORK(1) est mis à la taille minimale (et optimale) de CWORK.

RWORK

DOUBLE PRECISION, dimension (MAX(6,LRWORK)). À l'entrée, si JOBU = 'C' :

 RWORK(1) = CTOL, où CTOL définit le seuil de convergence.
           Le processus s'arrête si toutes les colonnes de A sont mutuellement
           orthogonales jusqu'à CTOL*EPS, EPS=DLAMCH('E').
           Il est requis que CTOL >= ONE, c'est-à-dire qu'il n'est pas
           permis de forcer la routine à obtenir une orthogonalité
           inférieure à EPSILON.

À la sortie :

 RWORK(1) = SCALE est le facteur d'échelle tel que SCALE*SVA(1:N)
           sont les valeurs singulières calculées de A.
           (Voir la description de SVA().)
 RWORK(2) = NINT(RWORK(2)) est le nombre de valeurs singulières non nulles
           calculées.
 RWORK(3) = NINT(RWORK(3)) est le nombre de valeurs singulières calculées
           qui sont supérieures au seuil de sous-dépassement (underflow).
 RWORK(4) = NINT(RWORK(4)) est le nombre de passes de rotations de Jacobi
           nécessaires à la convergence numérique.
 RWORK(5) = max_{i.NE.j} |COS(A(:,i),A(:,j))| lors de la dernière passe.
           Ceci est une information utile dans les cas où ZGESVJ n'a pas
           convergé, car elle peut être utilisée pour estimer si la sortie
           est encore utile et pour une analyse post-factum.
 RWORK(6) = la plus grande valeur absolue sur tous les sinus des angles
           de rotation de Jacobi lors de la dernière passe. Elle peut être
           utile pour une analyse post-factum.
LRWORK

INTEGER. La taille de RWORK. LRWORK >= 1, si MIN(M,N) = 0, et LRWORK >= MAX(6,N), sinon.

Si lors de l'entrée LRWORK = -1, une requête de taille de travail est supposée et aucun calcul n'est effectué ; RWORK(1) est mis à la taille minimale (et optimale) de RWORK.

INFO

INTEGER.

  • = 0 : succès de l'exécution.
  • < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale.
  • > 0 : ZGESVJ n'a pas convergé dans le nombre maximal autorisé (NSWEEP=30) de passes. La sortie peut encore être utile. Voir la description de RWORK.

Détails supplémentaires

La matrice orthogonale N-par-N V est obtenue comme un produit de rotations
planes de Jacobi. Dans le cas de sous-dépassement de la tangente de l'angle
de Jacobi, une transformation de Jacobi modifiée de Drmac [3] est utilisée.
La stratégie de pivot utilise des échanges de colonnes de de Rijk [1].
La précision relative des valeurs singulières calculées et la précision des
vecteurs singuliers calculés (en métrique d'angle) sont telles que garanties
par la théorie de Demmel et Veselic [2]. Le conditionnement qui détermine la
précision dans le cas de rang plein est essentiellement min_{D=diag} kappa(A*D),
où kappa(.) est le conditionnement spectral. La meilleure performance de cette
procédure Jacobi SVD est obtenue si elle est utilisée dans une version
accélérée de Drmac et Veselic [4,5], et c'est la routine noyau de la
bibliothèque SIGMA [6]. Certains paramètres d'ajustement (marqués avec [TP])
sont disponibles pour l'implémenteur.
La plage de calcul pour les valeurs singulières non nulles est l'intervalle
des nombres machine ( SOUS-DÉPASSEMENT , DÉPASSEMENT ). Dans des cas extrêmes,
même des valeurs singulières dénormalisées peuvent être calculées avec une
perte proportionnelle de chiffres précis.
