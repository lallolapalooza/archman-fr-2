Documentation de la fonction/sous-programme

sous-programme zget04 (integer n, integer nrhs, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldxact, * ) xact, integer ldxact, double precision rcond, double precision resid)

ZGET04

Objectif:

!>
!> ZGET04 calcule la différence entre une solution calculée et la
!> vraie solution d'un système d'équations linéaires.
!>
!> RESID =  ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS ),
!> où RCOND est l'inverse du nombre de condition et EPS est l'epsilon machine.
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre de lignes des matrices X et XACT.  N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de colonnes des matrices X et XACT.  NRHS >= 0.
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés. Chaque vecteur est stocké comme une
!>          colonne de la matrice X.
!>

LDX

!>          LDX est un ENTIER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

XACT

!>          XACT est un tableau COMPLEX*16, dimension (LDXACT,NRHS)
!>          Les vecteurs solution exacts. Chaque vecteur est stocké comme une
!>          colonne de la matrice XACT.
!>

LDXACT

!>          LDXACT est un ENTIER
!>          La dimension principale du tableau XACT.  LDXACT >= max(1,N).
!>

RCOND

!>          RCOND est un DOUBLE PRECISION
!>          L'inverse du nombre de condition de la matrice des coefficients
!>          du système d'équations.
!>

RESID

!>          RESID est un DOUBLE PRECISION
!>          Le maximum sur les NRHS vecteurs solution de
!>          ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS )
!>
