ZGBRFSX

But :

!>
!>    ZGBRFSX améliore la solution calculée d'un système d'équations linéaires
!>    et fournit des bornes d'erreur et des estimations d'erreur arrière
!>    pour la solution. En plus de la borne d'erreur normée, le code
!>    fournit une borne d'erreur composante par composante maximale si possible. Voir
!>    les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des
!>    bornes d'erreur.
!>
!>    Le système d'équations linéaires d'origine peut avoir été équilibré
!>    avant d'appeler cette routine, comme décrit par les arguments EQUED, R
!>    et C ci-dessous. Dans ce cas, la solution et les bornes d'erreur retournées
!>    sont pour le système non équilibré d'origine.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment le raffinement est effectué, mais souvent
!>     les valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les
!>     utilisateurs peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N' :  A * X = B     (Pas de transposée)
!>       = 'T' :  A**T * X = B  (Transposée)
!>       = 'C' :  A**H * X = B  (Conjuguée transposée)
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibrage qui a été effectuée sur A
!>     avant d'appeler cette routine. Ceci est nécessaire pour calculer
!>     la solution et les bornes d'erreur correctement.
!>       = 'N' :  Pas d'équilibrage
!>       = 'R' :  Équilibrage des lignes, c'est-à-dire que A a été pré-multiplié par
!>               diag(R).
!>       = 'C' :  Équilibrage des colonnes, c'est-à-dire que A a été post-multiplié
!>               par diag(C).
!>       = 'B' :  Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(R) * A * diag(C).
!>               Le côté droit B a été modifié en conséquence.
!>

N

!>          N est INTEGER
!>     L'ordre de la matrice A. N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A. KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A. KU >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>     des matrices B et X. NRHS >= 0.
!>

AB

!>          AB est COMPLEX*16 array, dimension (LDAB,N)
!>     La matrice bande originale A, stockée dans les lignes 1 à KL+KU+1.
!>     La j-ième colonne de A est stockée dans la j-ième colonne du
!>     tableau AB comme suit :
!>     AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku)<=i<=min(n,j+kl).
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale du tableau AB. LDAB >= KL+KU+1.
!>

AFB

!>          AFB est COMPLEX*16 array, dimension (LDAFB,N)
!>     Détails de la factorisation LU de la matrice bande A, comme
!>     calculé par ZGBTRF. U est stockée comme une matrice bande triangulaire supérieure
!>     avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1, et
!>     les multiplicateurs utilisés lors de la factorisation sont stockés dans
!>     les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale du tableau AFB. LDAFB >= 2*KL*KU+1.
!>

IPIV

!>          IPIV est INTEGER array, dimension (N)
!>     Les indices de pivot de ZGETRF ; pour 1<=i<=N, la ligne i de la
!>     matrice a été échangée avec la ligne IPIV(i).
!>

R

!>          R est DOUBLE PRECISION array, dimension (N)
!>     Les facteurs d'échelle des lignes de A. Si EQUED = 'R' ou 'B', A est
!>     multiplié à gauche par diag(R) ; si EQUED = 'N' ou 'C', R
!>     n'est pas accédé. R est un argument d'entrée si FACT = 'F' ;
!>     sinon, R est un argument de sortie. Si FACT = 'F' et
!>     EQUED = 'R' ou 'B', chaque élément de R doit être positif.
!>     Si R est en sortie, chaque élément de R est une puissance de la base.
!>     Si R est en entrée, chaque élément de R doit être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances de la base ne provoque pas d'erreurs d'arrondi, sauf si le
!>     résultat sousflue ou déborde. Les erreurs d'arrondi pendant la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

C

!>          C est DOUBLE PRECISION array, dimension (N)
!>     Les facteurs d'échelle des colonnes de A. Si EQUED = 'C' ou 'B', A est
!>     multiplié à droite par diag(C) ; si EQUED = 'N' ou 'R', C
!>     n'est pas accédé. C est un argument d'entrée si FACT = 'F' ;
!>     sinon, C est un argument de sortie. Si FACT = 'F' et
!>     EQUED = 'C' ou 'B', chaque élément de C doit être positif.
!>     Si C est en sortie, chaque élément de C est une puissance de la base.
!>     Si C est en entrée, chaque élément de C doit être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances de la base ne provoque pas d'erreurs d'arrondi, sauf si le
!>     résultat sousflue ou déborde. Les erreurs d'arrondi pendant la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est COMPLEX*16 array, dimension (LDB,NRHS)
!>     La matrice côté droit B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est COMPLEX*16 array, dimension (LDX,NRHS)
!>     À l'entrée, la matrice solution X, comme calculé par ZGETRS.
!>     À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>

Function/Subroutine Documentation

RCOND

!>          RCOND est un REAL DOUBLE PRÉCISION
!>     Numéro de condition réciproque mis à l'échelle. C'est une estimation du
!>     numéro de condition de Skeel réciproque de la matrice A après
!>     équilibrage (si effectué). Si celui-ci est inférieur à la précision machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut toujours être faible même
!>     si ce nombre est très petit et que la matrice semble mal
!>     conditionnée.
!>

BERR

!>          BERR est un tableau REAL DOUBLE PRÉCISION, de dimension (NRHS)
!>     Erreur relative par composante sur le terme de droite. C'est l'erreur
!>     relative par composante sur le terme de droite de chaque vecteur solution X(j)
!>     (c'est-à-dire, la plus petite modification relative de n'importe quel élément de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est un INTEGER
!>     Nombre de bornes d'erreur à retourner pour chaque membre de droite
!>     et chaque type (par norme ou par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau REAL DOUBLE PRÉCISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et numéros de condition correspondant à
!>     l'erreur relative par norme, qui est définie comme suit :
!>
!>     Erreur relative par norme dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     renvoyées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              numéro de condition réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur 10 de l'erreur réelle
!>              tant que la prochaine entrée est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              faite confiance que si le booléen précédent est vrai.
!>
!>     err = 3  Numéro de condition réciproque : Numéro de condition réciproque
!>              estimé par norme. Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation d'erreur
!>              est . Ces numéros de condition réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une certaine
!>              matrice Z appropriément mise à l'échelle.
!>              Soit Z = S*A, où S met à l'échelle chaque ligne par une puissance
!>              du radix de sorte que toutes les sommes de lignes absolues de Z soient approximativement 1.
!>
!>     Voir la note de travail Lapack 165 pour plus de détails et des avertissements
!>     supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau REAL DOUBLE PRÉCISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et numéros de condition correspondant à
!>     l'erreur relative par composante, qui est définie comme suit :
!>
!>     Erreur relative par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le membre de droite i (dont dépend l'erreur relative par composante),
!>     et le type d'information d'erreur tel que décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations renvoyées pour chaque membre de droite. Si
!>     la précision par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>     ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les trois champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              numéro de condition réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur 10 de l'erreur réelle
!>              tant que la prochaine entrée est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              faite confiance que si le booléen précédent est vrai.
!>
!>     err = 3  Numéro de condition réciproque : Numéro de condition réciproque
!>              estimé par composante. Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation d'erreur
!>              est . Ces numéros de condition réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une certaine
!>              matrice Z appropriément mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              membre de droite courant et S met à l'échelle chaque ligne de
!>              A*diag(x) par une puissance du radix de sorte que toutes les sommes de lignes absolues de
!>              Z soient approximativement 1.
!>
!>     Voir la note de travail Lapack 165 pour plus de détails et des avertissements
!>     supplémentaires.
!>

NPARAMS

!>          NPARAMS est un INTEGER
!>     Spécifie le nombre de paramètres définis dans PARAMS. Si <= 0, le
!>     tableau PARAMS n'est jamais référencé et les valeurs par défaut sont utilisées.
!>

PARAMS

!>          PARAMS est un tableau REAL DOUBLE PRÉCISION, de dimension NPARAMS
!>     Spécifie les paramètres de l'algorithme. Si une entrée est < 0.0, alors
!>     cette entrée sera remplie avec la valeur par défaut utilisée pour ce
!>     paramètre. Seules les positions jusqu'à NPARAMS sont accédées ; les défauts
!>     sont utilisés pour les paramètres de numéro supérieur.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Indique s'il faut effectuer un raffinement itératif
!>            ou non.
!>         Défaut : 1.0D+0
!>            = 0.0:  Aucun raffinement n'est effectué, et aucune borne d'erreur n'est
!>                    calculée.
!>            = 1.0:  Utilise l'algorithme de raffinement en double précision,
!>                    éventuellement avec des calculs en simple précision doublés si l'environnement
!>                    de compilation ne supporte pas REAL DOUBLE PRÉCISION.
!>              (d'autres valeurs sont réservées pour une utilisation future)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Nombre maximum de calculs de résiduels
!>            autorisés pour le raffinement.
!>         Défaut : 10
!>         Agressif : Défini à 100 pour permettre la convergence en utilisant des factorisations approximatives
!>                     ou des factorisations autres que LU. Si
!>                     la factorisation utilise une technique autre que
!>                     l'élimination de Gauss, les garanties dans
!>                     err_bnds_norm et err_bnds_comp peuvent ne plus être
!>                     fiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Indicateur déterminant si le code
!>            tentera de trouver une solution avec une petite erreur relative par composante
!>            dans l'algorithme en double précision. Positif
!>            signifie vrai, 0.0 signifie faux.
!>         Défaut : 1.0 (tenter la convergence par composante)
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau REAL DOUBLE PRÉCISION, de dimension (2*N)
!>

INFO

!>          INFO est un INTEGER
!>       = 0:  Sortie réussie. La solution pour chaque membre de droite est
!>         garantie.
!>       < 0:  Si INFO = -i, le i-ème argument avait une valeur illégale.
!>       > 0 et <= N :  U(INFO,INFO) est exactement zéro. La factorisation
!>         a été complétée, mais le facteur U est exactement singulier, donc
!>         la solution et les bornes d'erreur n'ont pas pu être calculées. RCOND = 0
!>         est retourné.
!>       = N+J : La solution correspondant au J-ème membre de droite n'est
!>         pas garantie. Les solutions correspondant aux autres membres de droite
!>         K avec K > J peuvent également ne pas être garanties, mais
!>         seul le premier membre de droite de ce type est rapporté. Si une petite
!>         erreur par composante n'est pas demandée (PARAMS(3) = 0.0) alors
!>         le J-ème membre de droite est le premier pour lequel la borne d'erreur par norme
!>         n'est pas garantie (le plus petit J tel que ERR_BNDS_NORM(J,1) = 0.0). Par défaut (PARAMS(3) = 1.0)
!>         le J-ème membre de droite est le premier pour lequel soit la borne d'erreur par norme, soit
!>         la borne d'erreur par composante n'est pas garantie (le plus petit
!>         J tel que soit ERR_BNDS_NORM(J,1) = 0.0, soit
!>         ERR_BNDS_COMP(J,1) = 0.0). Voir la définition de
!>         ERR_BNDS_NORM(:,1) et ERR_BNDS_COMP(:,1). Pour obtenir des informations
!>         sur tous les membres de droite, vérifiez ERR_BNDS_NORM ou
!>         ERR_BNDS_COMP.
!>
