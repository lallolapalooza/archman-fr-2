Documentation de la fonction/sous-programme

sous-programme zget22 (character transa, character transe, character transw, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( lde, * ) e, integer lde, complex*16, dimension( * ) w, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, double precision, dimension( 2 ) result)

ZGET22

Objectif :

!>
!> ZGET22 effectue une vérification de vecteurs propres.
!>
!> Le test de base est :
!>
!>    RESULT(1) = | A E  -  E W | / ( |A| |E| ulp )
!>
!> en utilisant la norme 1. Il vérifie également la normalisation de E :
!>
!>    RESULT(2) = max | m-norm(E(j)) - 1 | / ( n ulp )
!>                 j
!>
!> où E(j) est le j-ième vecteur propre, et m-norm est la max-norm d'un
!> vecteur. La max-norm d'un vecteur complexe n-dimensionnel x dans ce cas est le
!> maximum de |re(x(i)| + |im(x(i)| sur i = 1, ..., n.
!>

Paramètres

TRANSA 
!>          TRANSA est CHARACTER*1
!>          Spécifie si A est transposée ou non.
!>          = 'N':  Pas de transposition
!>          = 'T':  Transposée
!>          = 'C':  Transposée conjuguée
!>

TRANSE

!>          TRANSE est CHARACTER*1
!>          Spécifie si E est transposée ou non.
!>          = 'N':  Pas de transposition, les vecteurs propres sont dans les colonnes de E
!>          = 'T':  Transposée, les vecteurs propres sont dans les lignes de E
!>          = 'C':  Transposée conjuguée, les vecteurs propres sont dans les lignes de E
!>

TRANSW

!>          TRANSW est CHARACTER*1
!>          Spécifie si W est transposée ou non.
!>          = 'N':  Pas de transposition
!>          = 'T':  Transposée, identique à TRANSW = 'N'
!>          = 'C':  Transposée conjuguée, utiliser -WI(j) au lieu de WI(j)
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          La matrice dont les vecteurs propres sont dans E.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau COMPLEX*16, dimension (LDE,N)
!>          La matrice des vecteurs propres. Si TRANSE = 'N', les vecteurs propres
!>          sont stockés dans les colonnes de E, si TRANSE = 'T' ou 'C', les
!>          vecteurs propres sont stockés dans les lignes de E.
!>

LDE

!>          LDE est INTEGER
!>          La dimension principale du tableau E.  LDE >= max(1,N).
!>

W

!>          W est un tableau COMPLEX*16, dimension (N)
!>          Les valeurs propres de A.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (N*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, dimension (2)
!>          RESULT(1) = | A E  -  E W | / ( |A| |E| ulp )
!>          RESULT(2) = max | m-norm(E(j)) - 1 | / ( n ulp )
!>                       j
!>
