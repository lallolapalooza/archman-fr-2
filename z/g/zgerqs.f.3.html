sous-programme zgerqs (entier m, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) tau, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( lwork ) work, entier lwork, entier info)

ZGERQS

But :

!>
!> Calcule une solution de norme minimale
!>     min || A*X - B ||
!> en utilisant la factorisation RQ
!>     A = R*Q
!> calculée par ZGERQF.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= M >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de colonnes de B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          Détails de la factorisation RQ de la matrice originale A retournée
!>          par ZGERQF.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= M.
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (M)
!>          Détails de la matrice orthogonale Q.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          À l'entrée, les vecteurs du membre de droite pour le système linéaire.
!>          À la sortie, les vecteurs solution X. Chaque vecteur solution
!>          est contenu dans les lignes 1:N d'une colonne de B.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur du tableau WORK.  LWORK doit être au moins NRHS,
!>          et devrait être au moins NRHS*NB, où NB est la taille du bloc
!>          pour cet environnement.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
