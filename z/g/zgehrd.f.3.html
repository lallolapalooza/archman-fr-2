subroutine zgehrd (n, ilo, ihi, a, lda, tau, work, lwork, info)
ZGEHRD

Documentation de la fonction/sous-programme

sous-programme zgehrd (entier n, entier ilo, entier ihi, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) tau, complexe*16, dimension( * ) work, entier lwork, entier info)

ZGEHRD

Objectif :

!>
!> ZGEHRD réduit une matrice générale complexe A à la forme de Hessenberg supérieure H
!> par une transformation de similarité unitaire :  Q**H * A * Q = H .
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

ILO

!>          ILO est un ENTIER
!>

IHI

!>          IHI est un ENTIER
!>
!>          On suppose que A est déjà triangulaire supérieure dans les lignes
!>          et colonnes 1:ILO-1 et IHI+1:N. ILO et IHI sont normalement
!>          définis par un appel précédent à ZGEBAL ; sinon, ils devraient être
!>          définis à 1 et N respectivement. Voir Détails supplémentaires.
!>          1 <= ILO <= IHI <= N, si N > 0 ; ILO=1 et IHI=0, si N=0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          En entrée, la matrice générale N x N à réduire.
!>          En sortie, le triangle supérieur et la première sous-diagonale de A
!>          sont écrasés par la matrice de Hessenberg supérieure H, et les
!>          éléments en dessous de la première sous-diagonale, avec le tableau TAU,
!>          représentent la matrice unitaire Q comme un produit de réflecteurs
!>          élémentaires. Voir Détails supplémentaires.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau COMPLEX*16, de dimension (N-1)
!>          Les facteurs scalaires des réflecteurs élémentaires (voir Détails
!>          supplémentaires). Les éléments 1:ILO-1 et IHI:N-1 de TAU sont mis à
!>          zéro.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur du tableau WORK.  LWORK >= max(1,N).
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires :

!>
!>  La matrice Q est représentée comme un produit de (ihi-ilo) réflecteurs
!>  élémentaires
!>
!>     Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**H
!>
!>  où tau est un scalaire complexe, et v est un vecteur complexe avec
!>  v(1:i) = 0, v(i+1) = 1 et v(ihi+1:n) = 0 ; v(i+2:ihi) est stocké en
!>  sortie dans A(i+2:ihi,i), et tau dans TAU(i).
!>
!>  Le contenu de A est illustré par l'exemple suivant, avec
!>  n = 7, ilo = 2 et ihi = 6 :
!>
!>  en entrée,                        en sortie,
!>
!>  ( a   a   a   a   a   a   a )    (  a   a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      h   h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  v4  h   h   h )
!>  (                         a )    (                          a )
!>
!>  où a dénote un élément de la matrice originale A, h dénote un
!>  élément modifié de la matrice de Hessenberg supérieure H, et vi dénote un
!>  élément du vecteur définissant H(i).
!>
!>  Ce fichier est une légère modification de la sous-routine ZGEHRD de LAPACK-3.0
!>  intégrant des améliorations proposées par Quintana-Orti et
!>  Van de Geijn (2006). (Voir ZLAHR2.)
!>
