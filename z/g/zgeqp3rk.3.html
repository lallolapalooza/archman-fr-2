sous-routine zgeqp3rk (integer m, integer n, integer nrhs, integer kmax, double precision abstol, double precision reltol, complex*16, dimension( lda, * ) a, integer lda, integer k, double precision maxc2nrmk, double precision relmaxc2nrmk, integer, dimension( * ) jpiv, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

ZGEQP3RK calcule une factorisation QR tronquée de Householder avec pivotement de colonne d'une matrice complexe m par n A en utilisant le BLAS de niveau 3 et écrase la matrice complexe m par nrhs B avec Q**H * B.

Objectif :

!>
!> ZGEQP3RK effectue deux tâches simultanément :
!>
!> Tâche 1 : La routine calcule une factorisation QR tronquée (rang K) ou de rang plein
!> avec pivotement de colonne d'une matrice complexe
!> M par N A en utilisant le BLAS de niveau 3. K est le nombre de colonnes
!> qui ont été factorisées, c'est-à-dire le rang de factorisation de
!> R, K <= min(M,N).
!>
!>  A * P(K) = Q(K) * R(K)  =
!>
!>        = Q(K) * ( R11(K) R12(K) ) = Q(K) * (   R(K)_approx    )
!>                 ( 0      R22(K) )          ( 0  R(K)_residual ),
!>
!> où :
!>
!>  P(K)            est une matrice de permutation N par N ;
!>  Q(K)            est une matrice unitaire M par M ;
!>  R(K)_approx   = ( R11(K), R12(K) ) est une approximation de rang K de
!>                    la matrice factorielle complète R avec R11(K)
!>                    triangulaire supérieure K par K et R12(K)
!>                    rectangulaire K par N. Les entrées diagonales
!>                    de R11(K) apparaissent dans un ordre non croissant
!>                    de valeur absolue, et les valeurs absolues de toutes
!>                    ces dernières dépassent la norme 2 de colonne maximale de R22(K)
!>                    jusqu'à l'erreur d'arrondi.
!>  R(K)_residual = R22(K) est le résidu d'une approximation de rang K
!>                    de la matrice factorielle complète R. C'est une
!>                    matrice rectangulaire (M-K) par (N-K) ;
!>  0               est une matrice nulle (M-K) par K.
!>
!> Tâche 2 : En même temps, la routine écrase une matrice complexe
!> M par NRHS B avec Q(K)**H * B en utilisant le BLAS de niveau 3.
!>
!> =====================================================================
!>
!> Les matrices A et B sont stockées en entrée dans le tableau A sous forme de
!> blocs gauche et droit A(1:M,1:N) et A(1:M, N+1:N+NRHS)
!> respectivement.
!>
!>                                  N     NRHS
!>             array_A   =   M  [ mat_A, mat_B ]
!>
!> Les critères de troncature (c'est-à-dire quand arrêter la factorisation)
!> peuvent être l'un des suivants :
!>
!>   1) Le paramètre d'entrée KMAX, le nombre maximal de colonnes
!>      KMAX à factoriser, c'est-à-dire que le rang de factorisation est limité
!>      à KMAX. Si KMAX >= min(M,N), le critère n'est pas utilisé.
!>
!>   2) Le paramètre d'entrée ABSTOL, la tolérance absolue pour
!>      la norme 2 de colonne maximale de la matrice résiduelle R22(K). Ceci
!>      signifie que la factorisation s'arrête si cette norme est inférieure ou
!>      égale à ABSTOL. Si ABSTOL < 0.0, le critère n'est pas utilisé.
!>
!>   3) Le paramètre d'entrée RELTOL, la tolérance pour la norme 2 de colonne
!>      maximale de la matrice résiduelle R22(K) divisée
!>      par la norme 2 de colonne maximale de la matrice originale A, qui
!>      est égale à abs(R(1,1)). Ceci signifie que la factorisation s'arrête
!>      lorsque le rapport de la norme 2 de colonne maximale de R22(K) à
!>      la norme 2 de colonne maximale de A est inférieur ou égal à RELTOL.
!>      Si RELTOL < 0.0, le critère n'est pas utilisé.
!>
!>   4) Dans le cas où les critères d'arrêt ABSTOL ou RELTOL ne sont pas utilisés,
!>      et lorsque la matrice résiduelle R22(K) est une matrice nulle dans une
!>      étape de factorisation K. ( Ce critère d'arrêt est implicite. )
!>
!>  L'algorithme s'arrête lorsque l'une de ces conditions est satisfaite en premier,
!>  sinon la matrice entière A est factorisée.
!>
!>  Pour factoriser la matrice entière A, utilisez les valeurs
!>  KMAX >= min(M,N), ABSTOL < 0.0 et RELTOL < 0.0.
!>
!>  La routine retourne :
!>     a) Q(K), R(K)_approx = ( R11(K), R12(K) ),
!>        R(K)_residual = R22(K), P(K), c'est-à-dire les matrices résultantes
!>        de la factorisation ; P(K) est représentée par JPIV,
!>        ( si K = min(M,N), R(K)_approx est la matrice factorielle complète R,
!>        et il n'y a pas de matrice résiduelle R(K)_residual) ;
!>     b) K, le nombre de colonnes qui ont été factorisées,
!>        c'est-à-dire le rang de factorisation ;
!>     c) MAXC2NRMK, la norme 2 de colonne maximale de la matrice résiduelle
!>        R(K)_residual = R22(K),
!>        ( si K = min(M,N), MAXC2NRMK = 0.0 ) ;
!>     d) RELMAXC2NRMK égale MAXC2NRMK divisé par MAXC2NRM, la norme 2 de colonne maximale
!>        de la matrice originale A, qui est égale
!>        à abs(R(1,1)), ( si K = min(M,N), RELMAXC2NRMK = 0.0 ) ;
!>     e) Q(K)**H * B, la matrice B avec la transformation unitaire
!>        Q(K)**H appliquée à gauche.
!>
!> La matrice de permutation P(K) de taille N par N est stockée sous forme compacte dans
!> le tableau d'entiers JPIV. Pour 1 <= j <= N, la colonne j
!> de la matrice A a été échangée avec la colonne JPIV(j).
!>
!> La matrice unitaire Q de taille M par M est représentée comme un produit
!> de réflecteurs de Householder élémentaires
!>
!>     Q(K) = H(1) *  H(2) * . . . * H(K),
!>
!> où K est le nombre de colonnes qui ont été factorisées.
!>
!> Chaque H(j) a la forme
!>
!>     H(j) = I - tau * v * v**H,
!>
!> où 1 <= j <= K et
!>   I    est une matrice identité M par M,
!>   tau  est un scalaire complexe,
!>   v    est un vecteur complexe avec v(1:j-1) = 0 et v(j) = 1.
!>
!> v(j+1:M) est stocké en sortie dans A(j+1:M,j) et tau dans TAU(j).
!>
!> Voir la section Détails supplémentaires pour plus d'informations.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de
!>          colonnes de la matrice B. NRHS >= 0.
!>

KMAX

!>          KMAX est INTEGER
!>
!>          Le premier critère d'arrêt de la factorisation. KMAX >= 0.
!>
!>          Le nombre maximal de colonnes de la matrice A à factoriser,
!>          c'est-à-dire le rang de factorisation maximal.
!>
!>          a) Si KMAX >= min(M,N), alors ce critère d'arrêt
!>                n'est pas utilisé, la routine factorise les colonnes
!>                en fonction de ABSTOL et RELTOL.
!>
!>          b) Si KMAX = 0, alors ce critère d'arrêt est
!>                satisfait à l'entrée et la routine sort immédiatement.
!>                Cela signifie que la factorisation n'est pas effectuée,
!>                les matrices A et B ne sont pas modifiées, et
!>                la matrice A est elle-même le résidu.
!>

ABSTOL

!>          ABSTOL est DOUBLE PRECISION
!>
!>          Le deuxième critère d'arrêt de la factorisation, ne peut pas être NaN.
!>
!>          La tolérance absolue (seuil d'arrêt) pour
!>          la norme 2 de colonne maximale de la matrice résiduelle R22(K).
!>          L'algorithme converge (arrête la factorisation) lorsque
!>          la norme 2 de colonne maximale de la matrice résiduelle R22(K)
!>          est inférieure ou égale à ABSTOL. Soit SAFMIN = DLAMCH('S').
!>
!>          a) Si ABSTOL est NaN, alors aucun calcul n'est effectué
!>
et un message d'erreur ( INFO = -5 ) est émis !> par XERBLA. !> !> b) Si ABSTOL < 0.0, alors ce critère d'arrêt n'est pas !> utilisé, la routine factorise les colonnes en fonction !> de KMAX et RELTOL. !> Cela inclut le cas ABSTOL = -Inf. !> !> c) Si 0.0 <= ABSTOL < 2*SAFMIN, alors ABSTOL = 2*SAFMIN !> est utilisé. Cela inclut le cas ABSTOL = -0.0. !> !> d) Si 2*SAFMIN <= ABSTOL, alors la valeur d'entrée !> de ABSTOL est utilisée. !> !> Soit MAXC2NRM la norme euclidienne maximale des colonnes de !> toute la matrice originale A. !> Si ABSTOL choisi ci-dessus est >= MAXC2NRM, alors ce !> critère d'arrêt est satisfait à l'entrée et la routine se termine !> immédiatement après le calcul de MAXC2NRM. La routine !> retourne MAXC2NRM dans MAXC2NORMK, !> et 1.0 dans RELMAXC2NORMK. !> Cela inclut le cas ABSTOL = +Inf. Cela signifie que la !> factorisation n'est pas effectuée, les matrices A et B ne sont pas !> modifiées, et la matrice A est elle-même le résidu. !>

RELTOL

!>          RELTOL est DOUBLE PRECISION
!>
!>          Le troisième critère d'arrêt de la factorisation, ne peut pas être NaN.
!>
!>          La tolérance (seuil d'arrêt) pour le rapport
!>          abs(R(K+1,K+1))/abs(R(1,1)) de la norme euclidienne maximale des colonnes
!>          de la matrice résiduelle R22(K) à la norme euclidienne maximale des colonnes
!>          de la matrice originale A. L'algorithme converge (arrête la
!>          factorisation) lorsque abs(R(K+1,K+1))/abs(R(1,1)) A est inférieur
!>          ou égal à RELTOL. Soit EPS = DLAMCH('E').
!>
!>          a) Si RELTOL est NaN, alors aucun calcul n'est effectué
!>                et un message d'erreur ( INFO = -6 ) est émis
!>                par XERBLA.
!>
!>          b) Si RELTOL < 0.0, alors ce critère d'arrêt n'est pas
!>                utilisé, la routine factorise les colonnes en fonction
!>                de KMAX et ABSTOL.
!>                Cela inclut le cas RELTOL = -Inf.
!>
!>          c) Si 0.0 <= RELTOL < EPS, alors RELTOL = EPS est utilisé.
!>                Cela inclut le cas RELTOL = -0.0.
!>
!>          d) Si EPS <= RELTOL, alors la valeur d'entrée de RELTOL
!>                est utilisée.
!>
!>          Soit MAXC2NRM la norme euclidienne maximale des colonnes de
!>          toute la matrice originale A.
!>          Si RELTOL choisi ci-dessus est >= 1.0, alors ce critère d'arrêt
!>          est satisfait à l'entrée et la routine se termine
!>          immédiatement après le calcul de MAXC2NRM.
!>          La routine retourne MAXC2NRM dans MAXC2NORMK,
!>          et 1.0 dans RELMAXC2NORMK.
!>          Cela inclut le cas RELTOL = +Inf. Cela signifie que la
!>          factorisation n'est pas effectuée, les matrices A et B ne sont pas
!>          modifiées, et la matrice A est elle-même le résidu.
!>
!>          NOTE : Nous recommandons que RELTOL satisfasse
!>                min( 10*max(M,N)*EPS, sqrt(EPS) ) <= RELTOL
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N+NRHS)
!>
!>          À l'entrée :
!>
!>          a) Le sous-tableau A(1:M,1:N) contient la matrice A de taille M x N.
!>          b) Le sous-tableau A(1:M,N+1:N+NRHS) contient la matrice B de taille M x NRHS.
!>
!>                                  N     NRHS
!>              tableau_A   =   M  [ mat_A, mat_B ]
!>
!>          À la sortie :
!>
!>          a) Le sous-tableau A(1:M,1:N) contient des parties des facteurs
!>             de la matrice A :
!>
!>            1) Si K = 0, A(1:M,1:N) contient la matrice originale A.
!>            2) Si K > 0, A(1:M,1:N) contient des parties des
!>               facteurs :
!>
!>              1. Les éléments sous la diagonale du sous-tableau
!>                 A(1:M,1:K) représentent ensemble avec TAU(1:K) la
!>                 matrice unitaire Q(K) comme un produit de K réflecteurs élémentaires de Householder.
!>
!>              2. Les éléments sur et au-dessus de la diagonale du
!>                 sous-tableau A(1:K,1:N) contiennent la matrice
!>                 supérieure trapézoïdale de taille K x N
!>                 R(K)_approx = ( R11(K), R12(K) ).
!>                 NOTE : Si K=min(M,N), c'est-à-dire factorisation de rang plein,
!>                       alors R_approx(K) est le facteur R complet qui
!>                       est supérieur trapézoïdal. Si, en plus, M>=N,
!>                       alors R est triangulaire supérieure.
!>
!>              3. Le sous-tableau A(K+1:M,K+1:N) contient la matrice
!>                 rectangulaire de taille (M-K) x (N-K)
!>                 R(K)_residuelle = R22(K).
!>
!>          b) Si NRHS > 0, le sous-tableau A(1:M,N+1:N+NRHS) contient
!>             le produit de taille M x NRHS Q(K)**H * B.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>          C'est la dimension principale pour les deux matrices, A et B.
!>

K

!>          K est un entier
!>          Rang de factorisation de la matrice A, c'est-à-dire le rang de
!>          du facteur R, qui est le même que le nombre de lignes non nulles
!>          du facteur R. 0 <= K <= min(M,KMAX,N).
!>
!>          K représente également le nombre de vecteurs de Householder non nuls.
!>
!>          NOTE : Si K = 0, a) les tableaux A et B ne sont pas modifiés ;
!>                          b) le tableau TAU(1:min(M,N)) est mis à ZÉRO,
!>                             si la matrice A ne contient pas de NaN,
!>                             sinon les éléments TAU(1:min(M,N))
!>                             sont indéfinis ;
!>                          c) les éléments du tableau JPIV sont définis
!>                             comme suit : pour j = 1:N, JPIV(j) = j.
!>

MAXC2NRMK

!>          MAXC2NRMK est un DOUBLE PRECISION
!>          La norme euclidienne maximale des colonnes de la matrice résiduelle R22(K),
!>          lorsque la factorisation s'est arrêtée au rang K. MAXC2NRMK >= 0.
!>
!>          a) Si K = 0, c'est-à-dire que la factorisation n'a pas été effectuée,
!>             la matrice A n'a pas été modifiée et est elle-même une matrice résiduelle,
!>             alors MAXC2NRMK est égale à la norme euclidienne maximale des colonnes
!>             de la matrice originale A.
!>
!>          b) Si 0 < K < min(M,N), alors MAXC2NRMK est retourné.
!>
!>          c) Si K = min(M,N), c'est-à-dire que toute la matrice A a été
!>             factorisée et qu'il n'y a pas de matrice résiduelle,
!>             alors MAXC2NRMK = 0.0.
!>
!>          NOTE : MAXC2NRMK à l'étape de factorisation K serait égal à
!>                R(K+1,K+1) à l'étape de factorisation K+1 suivante.
!>

RELMAXC2NRMK

!>          RELMAXC2NRMK est un DOUBLE PRECISION
!>          Le rapport MAXC2NRMK / MAXC2NRM de la norme euclidienne maximale des colonnes
!>          de la matrice résiduelle R22(K) (lorsque la factorisation
!>          s'est arrêtée au rang K) à la norme euclidienne maximale des colonnes
!>          de toute la matrice originale A. RELMAXC2NRMK >= 0.
!>
!>          a) Si K = 0, c'est-à-dire que la factorisation n'a pas été effectuée,
!>             la matrice A n'a pas été modifiée et est elle-même une matrice résiduelle,
!>             alors RELMAXC2NRMK = 1.0.
!>
!>          b) Si 0 < K < min(M,N), alors
!>                RELMAXC2NRMK = MAXC2NRMK / MAXC2NRM est retourné.
!>
!>          c) Si K = min(M,N), c'est-à-dire que toute la matrice A a été
!>             factorisée et qu'il n'y a pas de matrice résiduelle,
!>             alors RELMAXC2NRMK = 0.0.
!>
!>         NOTE : RELMAXC2NRMK à l'étape de factorisation K serait égal à
!>               abs(R(K+1,K+1))/abs(R(1,1)) à l'étape de factorisation K+1 suivante.
!>

JPIV

!>          JPIV est un tableau d'entiers, dimension (N)
!>          Indices de pivotement des colonnes. Pour 1 <= j <= N, la colonne j
!>          de la matrice A a été échangée avec la colonne JPIV(j).
!>
!>          Les éléments du tableau JPIV(1:N) sont toujours définis
!>          par la routine, par exemple, même lorsque aucune colonne
!>          n'a été factorisée, c'est-à-dire lorsque K = 0, les éléments sont
!>          définis comme JPIV(j) = j pour j = 1:N.
!>

TAU

!>          TAU est un tableau COMPLEX*16, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>
!>          Si 0 < K <= min(M,N), seuls les éléments TAU(1:K) du
!>          tableau TAU sont modifiés par la factorisation.
!>          Après le calcul de la factorisation, si aucun NaN n'a été trouvé
!>          pendant la factorisation, les éléments restants
!>          TAU(K+1:min(M,N)) sont mis à zéro, sinon les
!>          éléments TAU(K+1:min(M,N)) ne sont pas définis et sont donc
!>          indéfinis.
!>          ( Si K = 0, tous les éléments de TAU sont mis à zéro, si
!>          la matrice A ne contient pas de NaN. )
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est un entier
!>          La dimension du tableau WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, et
!>          LWORK >= N+NRHS-1, sinon.
!>          Pour des performances optimales, LWORK >= NB*( N+NRHS+1 ),
!>          où NB est la taille de bloc optimale pour ZGEQP3RK renvoyée
!>          par ILAENV. Taille de bloc minimale MINNB=2.
!>
!>          NOTE : La décision d'utiliser le code BLAS 2 non bloqué
!>          ou le code BLAS 3 bloqué est basée non seulement sur la dimension
!>          LWORK de l'espace de travail disponible WORK, mais aussi sur la
!>          dimension N de la matrice A via le point de croisement NX renvoyé
!>          par ILAENV. (Pour N inférieur à NX, le code non bloqué doit être
!>          utilisé.)
!>
!>          Si LWORK = -1, une requête d'espace de travail est supposée ;
!>          la routine calcule seulement la taille optimale du tableau WORK,
!>          renvoie cette valeur comme première entrée du tableau WORK,
!>          et aucun message d'erreur lié à LWORK n'est émis
!>          par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (2*N)
!>

IWORK

!>          IWORK est un tableau d'entiers, dimension (N-1).
!>          Est un tableau de travail. (IWORK est utilisé pour stocker les indices
!>          des colonnes pour la mise à jour descendante de la norme dans la matrice résiduelle
!>          dans la sous-routine auxiliaire ZLAQP3RK de l'étape bloquée).
!>

INFO

!>          INFO est un entier
!>          1) INFO = 0 : sortie réussie.
!>          2) INFO < 0 : si INFO = -i, alors le i-ème argument avait une
!>                       valeur illégale.
!>          3) Si INFO = j_1, où 1 <= j_1 <= N, alors NaN a été
!>             détecté et la routine arrête le calcul.
!>             La j_1-ème colonne de la matrice A ou le j_1-ème
!>             élément du tableau TAU contient la première occurrence
!>             de NaN dans l'étape de factorisation K+1 (quand K colonnes
!>             ont été factorisées).
!>
!>             À la sortie :
!>             K                  est mis à jour au nombre de
!>                                   colonnes factorisées sans
!>                                   aucune exception.
!>             MAXC2NRMK          est mis à NaN.
!>             RELMAXC2NRMK       est mis à NaN.
!>             TAU(K+1:min(M,N))  n'est pas défini et contient des valeurs
!>                                   indéfinies.
!>
zgeqp3rk(3) - LAPACK

NAME

zgeqp3rk - Computes the rank-revealing QR factorization of a complex distributed M-by-N matrix A, A = Q * R,

SYNOPSIS

SUBROUTINE ZGEQP3RK(
     M, N, NB, A, LDA, JPVT, TAU, WORK, LWORK, INFO )

INTEGER            M, N, NB, LDA, LWORK, INFO
COMPLEX*16         A( LDA, * ), TAU( * ), WORK( * )
INTEGER            JPVT( * )

Function/Subroutine Documentation

ZGEQP3RK performs rank-revealing QR factorization of a complex distributed M-by-N matrix A, such that

A = Q * R,

where Q is an M-by-M unitary matrix, and R is an M-by-N upper trapezoidal matrix.

The factorization is computed using a blocked QR factorization algorithm with column pivoting. The matrix R is computed with a rank-revealing property, meaning that the diagonal elements of R are decreasing in magnitude. This property is useful for determining the rank of the matrix A and for computing approximate null spaces.

The routine returns the matrices Q and R, and also information about the rank of A and the numerical stability of the factorization.

The following is a description of the parameters:

M
    (input) INTEGER
    The number of rows of the matrix A. M >= 0.

N
    (input) INTEGER
    The number of columns of the matrix A. N >= 0.

NB
    (input) INTEGER
    The block size to be used in the blocked QR algorithm. NB >= 1.

A
    (input/output) COMPLEX*16 array, dimension (LDA,N)
    On entry, the M-by-N matrix A to be factorized.
    On exit, the upper trapezoidal factor R of A. The elements below the
    subdiagonal are overwritten by information about the unitary matrix Q.

LDA
    (input) INTEGER
    The leading dimension of the array A. LDA >= max(1,M).

JPVT
    (input/output) INTEGER array, dimension (min(M,N))
    On entry, if JPVT(i) is positive, then the i-th column of A is not
    permuted by the algorithm. If JPVT(i) is zero, then the i-th column of A
    is permuted by the algorithm.
    On exit, if JPVT(i) is positive, then the i-th column of A is the
    JPVT(i)-th column of the original matrix A. If JPVT(i) is zero, then
    the i-th column of A is the column of the original matrix A corresponding
    to the permutation.
    This array is used to determine the column pivoting strategy.

    (output) COMPLEX*16 array, dimension (min(M,N))
    The scalar factors of the elementary reflectors.

WORK
    (workspace) COMPLEX*16 array, dimension (LWORK)
    On exit, WORK(1) contains the optimal value of LWORK.

LWORK
    (input) INTEGER
    The dimension of the array WORK. LWORK >= max(1,M).
    For optimum performance, LWORK should be approximately max(1,M)*NB.

INFO
    (output) INTEGER
    = 0:  The execution is successful.
    < 0:  If INFO = -i, the i-th parameter had an illegal value.
    > 0:  If INFO = i, the (i+1)-th column of A is the first column
          that is linearly dependent on the preceding columns.
          The rank of A is considered to be i.
          The factorization has been completed up to the (i+1)-th column.
          The columns j from i+1 to N should be discarded.
          TAU(i+1) may contain NaN.
    > N:  If INFO = j, where N+1 <= j <= 2*N, then no NaN
          was detected, but +Inf (or -Inf) was detected and
          the routine continues the computation until completion.
          The (j-N)-th column of the matrix A contains the first
          occurrence of +Inf (or -Inf) in the factorization
          step K+1 ( when K columns have been factorized ).

!> ZGEQP3RK is based on the same BLAS3 Householder QR factorization
!> algorithm with column pivoting as in ZGEQP3 routine which uses
!> ZLARFG routine to generate Householder reflectors
!> for QR factorization.
!>
!> We can also write:
!>
!>   A = A_approx(K) + A_residual(K)
!>
!> The low rank approximation matrix A(K)_approx from
!> the truncated QR factorization of rank K of the matrix A is:
!>
!>   A(K)_approx = Q(K) * ( R(K)_approx ) * P(K)**T
!>                        (     0     0 )
!>
!>               = Q(K) * ( R11(K) R12(K) ) * P(K)**T
!>                        (      0      0 )
!>
!> The residual A_residual(K) of the matrix A is:
!>
!>   A_residual(K) = Q(K) * ( 0              0 ) * P(K)**T =
!>                          ( 0  R(K)_residual )
!>
!>                 = Q(K) * ( 0        0 ) * P(K)**T
!>                          ( 0   R22(K) )
!>
!> The truncated (rank K) factorization guarantees that
!> the maximum column 2-norm of A_residual(K) is less than
!> or equal to MAXC2NRMK up to roundoff error.
!>
!> NOTE: An approximation of the null vectors
!>       of A can be easily computed from R11(K)
!>       and R12(K):
!>
!>       Null( A(K) )_approx = P * ( inv(R11(K)) * R12(K) )
!>                                 (         -I           )
!>
!>
