Documentation de la fonction/sous-programme

sous-programme zgemlqt (caractère side, caractère trans, entier m, entier n, entier k, entier mb, complexe*16, dimension( ldv, * ) v, entier ldv, complexe*16, dimension( ldt, * ) t, entier ldt, complexe*16, dimension( ldc, * ) c, entier ldc, complexe*16, dimension( * ) work, entier info)

ZGEMLQT

Objectif :

!>
!> ZGEMLQT écrase la matrice complexe générale M-par-N C avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q C            C Q
!> TRANS = 'C':   Q**H C            C Q**H
!>
!> où Q est une matrice unitaire complexe définie comme le produit de K
!> réflecteurs élémentaires :
!>
!>       Q = H(1) H(2) . . . H(K) = I - V T V**H
!>
!> générée en utilisant la représentation WY compacte telle que retournée par ZGELQT.
!>
!> Q est de taille M si SIDE = 'L' et de taille N si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**H à gauche ;
!>          = 'R': appliquer Q ou Q**H à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': Pas de transposée, appliquer Q ;
!>          = 'C': Transposée conjuguée, appliquer Q**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

MB

!>          MB est INTEGER
!>          La taille de bloc utilisée pour le stockage de T. K >= MB >= 1.
!>          Ce doit être la même valeur de MB utilisée pour générer T
!>          dans ZGELQT.
!>

V

!>          V est un tableau COMPLEX*16, de dimension
!>                               (LDV,M) si SIDE = 'L',
!>                               (LDV,N) si SIDE = 'R'
!>          La i-ème ligne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          ZGELQT dans les K premières lignes de son argument tableau A.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V. LDV >= max(1,K).
!>

T

!>          T est un tableau COMPLEX*16, de dimension (LDT,K)
!>          Les facteurs triangulaires supérieurs des réflecteurs de bloc
!>          tels que retournés par ZGELQT, stockés comme une matrice MB-par-K.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= MB.
!>

C

!>          C est un tableau COMPLEX*16, de dimension (LDC,N)
!>          À l'entrée, la matrice C M-par-N.
!>          À la sortie, C est écrasée par Q C, Q**H C, C Q**H ou C Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX*16. La dimension de
!>          WORK est N*MB si SIDE = 'L', ou M*MB si SIDE = 'R'.
!>

INFO

!>          INFO est INTEGER
!>          = 0: sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
