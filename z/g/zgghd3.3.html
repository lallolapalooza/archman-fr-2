subroutine zgghd3 (character compq, character compz, integer n, integer ilo, integer ihi, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, integer info)

ZGGHD3

Objectif :

!>
!> ZGGHD3 réduit une paire de matrices complexes (A,B) à la forme de Hessenberg généralisée
!> en utilisant des transformations unitaires, où A est une matrice générale
!> et B est triangulaire supérieure. La forme du problème de valeurs propres généralisé est
!>    A*x = lambda*B*x,
!> et B est typiquement rendu triangulaire supérieur en calculant sa factorisation QR
!> et en déplaçant la matrice unitaire Q du côté gauche de l'équation.
!>
!> Cette sous-routine réduit simultanément A en une matrice de Hessenberg H :
!>    Q**H*A*Z = H
!> et transforme B en une autre matrice triangulaire supérieure T :
!>    Q**H*B*Z = T
!> afin de réduire le problème à sa forme standard
!>    H*y = lambda*T*y
!> où y = Z**H*x.
!>
!> Les matrices unitaires Q et Z sont déterminées comme des produits de rotations de Givens.
!> Elles peuvent être formées explicitement, ou elles peuvent être post-multipliées
!> aux matrices d'entrée Q1 et Z1, de sorte que
!>      Q1 * A * Z1**H = (Q1*Q) * H * (Z1*Z)**H
!>      Q1 * B * Z1**H = (Q1*Q) * T * (Z1*Z)**H
!> Si Q1 est la matrice unitaire issue de la factorisation QR de B dans l'équation
!> originale A*x = lambda*B*x, alors ZGGHD3 réduit le problème original à la forme
!> de Hessenberg généralisée.
!>
!> Ceci est une variante bloquée de CGGHRD, utilisant des multiplications matrice-matrice
!> pour certaines parties du calcul afin d'améliorer les performances.
!>

Paramètres

COMPQ 
!>          COMPQ est CHARACTER*1
!>          = 'N': ne pas calculer Q ;
!>          = 'I': Q est initialisée à la matrice unité, et la
!>                 matrice unitaire Q est retournée ;
!>          = 'V': Q doit contenir une matrice unitaire Q1 à l'entrée,
!>                 et le produit Q1*Q est retourné.
!>

COMPZ

!>          COMPZ est CHARACTER*1
!>          = 'N': ne pas calculer Z ;
!>          = 'I': Z est initialisée à la matrice unité, et la
!>                 matrice unitaire Z est retournée ;
!>          = 'V': Z doit contenir une matrice unitaire Z1 à l'entrée,
!>                 et le produit Z1*Z est retourné.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B. N >= 0.
!>

ILO

!>          ILO est INTEGER
!>

IHI

!>          IHI est INTEGER
!>
!>          ILO et IHI marquent les lignes et colonnes de A à réduire.
!>          On suppose que A est déjà triangulaire supérieure
!>          aux lignes et colonnes 1:ILO-1 et IHI+1:N. ILO et IHI sont
!>          normalement définis par un appel précédent à ZGGBAL ; sinon, ils
!>          devraient être définis à 1 et N respectivement.
!>          1 <= ILO <= IHI <= N, si N > 0 ; ILO=1 et IHI=0, si N=0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>          À l'entrée, la matrice générale N*N à réduire.
!>          À la sortie, le triangle supérieur et la première sous-diagonale de A
!>          sont écrasés avec la matrice de Hessenberg supérieure H, et le
!>          reste est mis à zéro.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB, N)
!>          À l'entrée, la matrice triangulaire supérieure B de dimension N*N.
!>          À la sortie, la matrice triangulaire supérieure T = Q**H B Z. Les
!>          éléments sous la diagonale sont mis à zéro.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

Q

!>          Q est un tableau COMPLEX*16, dimension (LDQ, N)
!>          À l'entrée, si COMPQ = 'V', la matrice unitaire Q1, typiquement
!>          issue de la factorisation QR de B.
!>          À la sortie, si COMPQ='I', la matrice unitaire Q, et si
!>          COMPQ = 'V', le produit Q1*Q.
!>          Non référencé si COMPQ='N'.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q.
!>          LDQ >= N si COMPQ='V' ou 'I' ; LDQ >= 1 sinon.
!>

Z

!>          Z est un tableau COMPLEX*16, dimension (LDZ, N)
!>          À l'entrée, si COMPZ = 'V', la matrice unitaire Z1.
!>          À la sortie, si COMPZ='I', la matrice unitaire Z, et si
!>          COMPZ = 'V', le produit Z1*Z.
!>          Non référencé si COMPZ='N'.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.
!>          LDZ >= N si COMPZ='V' ou 'I' ; LDZ >= 1 sinon.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK. LWORK >= 1.
!>          Pour des performances optimales, LWORK >= 6*N*NB, où NB est la
!>          taille de bloc optimale.
!>
!>          Si LWORK = -1, une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur dans la première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  Sortie réussie.
!>          < 0:  Si INFO = -i, le i-ème argument avait une valeur illégale.
!>

    NAME

    zgghd3 - Solves the generalized real eigenvalue problem of the form

    A x = lambda B x,

    where A and B are N x N matrices and x is N x NRHS. B must be symmetric and positive definite.

    SYNOPSIS

    
#include <gsl/gsl_linalg.h>

int
gsl_linalg_zgghd3 (
    gsl_matrix_complex * A,
    gsl_matrix_complex * B,
    gsl_vector_complex * x,
    int * info
);

    Function/Subroutine Documentation

    The function gsl_linalg_zgghd3 computes the eigenvalues and right eigenvectors of a real generalized eigenvalue problem.

    The problem is defined as:

    $$ A x = \lambda B x $$

    where A and B are N x N matrices, x is the N x NRHS matrix of right eigenvectors, and $\lambda$ is the vector of eigenvalues. The matrix B must be symmetric and positive definite.

    The matrices A and B are overwritten by the algorithm. The eigenvectors are normalized to the unit length.

    The function returns an integer error code:

    • 0: success
    • -i: if the i-th element of the diagonal is zero (for B), indicating B is singular.

    Arguments:

    • A: The N x N matrix A.
    • B: The N x N symmetric positive definite matrix B.
    • x: The N x NRHS matrix where the right eigenvectors will be stored.
    • info: A pointer to an integer where the success/failure code will be stored.
