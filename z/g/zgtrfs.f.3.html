ZGTRFS

Objectif

!>
!> ZGTRFS améliore la solution calculée d'un système d'équations linéaires
!> lorsque la matrice des coefficients est tridiagonale, et fournit
!> des bornes d'erreur et des estimations d'erreur arrière pour la solution.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N':  A * X = B     (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Conjuguée transposée)
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

DL

!>          DL est COMPLEX*16 array, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de A.
!>

D

!>          D est COMPLEX*16 array, dimension (N)
!>          Les éléments diagonaux de A.
!>

DU

!>          DU est COMPLEX*16 array, dimension (N-1)
!>          Les (n-1) éléments superdiagonaux de A.
!>

DLF

!>          DLF est COMPLEX*16 array, dimension (N-1)
!>          Les (n-1) multiplicateurs qui définissent la matrice L de la
!>          factorisation LU de A calculée par ZGTTRF.
!>

DF

!>          DF est COMPLEX*16 array, dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire supérieure U de la
!>          factorisation LU de A.
!>

DUF

!>          DUF est COMPLEX*16 array, dimension (N-1)
!>          Les (n-1) éléments de la première superdiagonale de U.
!>

DU2

!>          DU2 est COMPLEX*16 array, dimension (N-2)
!>          Les (n-2) éléments de la deuxième superdiagonale de U.
!>

IPIV

!>          IPIV est INTEGER array, dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= n, la ligne i de la matrice a été
!>          échangée avec la ligne IPIV(i).  IPIV(i) sera toujours égal à
!>          i ou i+1 ; IPIV(i) = i indique qu'un échange de ligne n'a pas
!>          été requis.
!>

B

!>          B est COMPLEX*16 array, dimension (LDB,NRHS)
!>          La matrice des membres de droite B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est COMPLEX*16 array, dimension (LDX,NRHS)
!>          À l'entrée, la matrice solution X, telle que calculée par ZGTTRS.
!>          À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

FERR

!>          FERR est DOUBLE PRECISION array, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ième colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j).  L'estimation est aussi fiable que
!>          l'estimation de RCOND, et est presque toujours une légère
!>          surostimation de l'erreur réelle.
!>

BERR

!>          BERR est DOUBLE PRECISION array, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire le plus petit changement relatif dans
!>          n'importe quel élément de A ou B qui fait de X(j) une solution exacte).
!>

WORK

!>          WORK est COMPLEX*16 array, dimension (2*N)
!>

RWORK

!>          RWORK est DOUBLE PRECISION array, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Paramètres internes :

!>  ITMAX est le nombre maximum d'étapes de raffinement itératif.
!>
