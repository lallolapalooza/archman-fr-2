ZGGEV calcule les valeurs propres et, optionnellement, les vecteurs propres gauche et/ou droite pour les matrices GE

Objectif:

!>
!> ZGGEV calcule pour une paire de matrices complexes non symétriques N-par-N
!> (A,B), les valeurs propres généralisées, et optionnellement, les vecteurs propres généralisés gauche et/ou droite.
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire
!> lambda ou un rapport alpha/beta = lambda, tel que A - lambda*B est
!> singulier. Elle est généralement représentée par la paire (alpha,beta), car
!> il existe une interprétation raisonnable pour beta=0, et même pour les deux
!> étant nuls.
!>
!> Le vecteur propre généralisé droit v(j) correspondant à la
!> valeur propre généralisée lambda(j) de (A,B) satisfait
!>
!>              A * v(j) = lambda(j) * B * v(j).
!>
!> Le vecteur propre généralisé gauche u(j) correspondant à la
!> valeur propre généralisée lambda(j) de (A,B) satisfait
!>
!>              u(j)**H * A = lambda(j) * u(j)**H * B
!>
!> où u(j)**H est la transposée conjuguée de u(j).
!>

Paramètres

JOBVL 
!>          JOBVL est CHARACTER*1
!>          = 'N':  ne pas calculer les vecteurs propres généralisés gauches ;
!>          = 'V':  calculer les vecteurs propres généralisés gauches.
!>

JOBVR

!>          JOBVR est CHARACTER*1
!>          = 'N':  ne pas calculer les vecteurs propres généralisés droits ;
!>          = 'V':  calculer les vecteurs propres généralisés droits.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A, B, VL, et VR.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>          En entrée, la matrice A dans la paire (A,B).
!>          En sortie, A a été écrasée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB, N)
!>          En entrée, la matrice B dans la paire (A,B).
!>          En sortie, B a été écrasée.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de B.  LDB >= max(1,N).
!>

ALPHA

!>          ALPHA est un tableau COMPLEX*16, dimension (N)
!>

BETA

!>          BETA est un tableau COMPLEX*16, dimension (N)
!>          En sortie, ALPHA(j)/BETA(j), j=1,...,N, seront les
!>          valeurs propres généralisées.
!>
!>          Note : les quotients ALPHA(j)/BETA(j) peuvent facilement
!>          déborder ou sous-déborder, et BETA(j) peut même être zéro.
!>          Par conséquent, l'utilisateur doit éviter de calculer naïvement
!>          le rapport alpha/beta.
!>          Cependant, ALPHA sera toujours inférieur et généralement
!>          comparable à norm(A) en magnitude, et BETA toujours inférieur
!>          et généralement comparable à norm(B).
!>

VL

!>          VL est un tableau COMPLEX*16, dimension (LDVL,N)
!>          Si JOBVL = 'V', les vecteurs propres généralisés gauches u(j) sont
!>          stockés les uns après les autres dans les colonnes de VL, dans le même
!>          ordre que leurs valeurs propres.
!>          Chaque vecteur propre est mis à l'échelle de sorte que le composant le plus grand ait
!>          abs(partie réelle) + abs(partie imaginaire) = 1.
!>          Non référencé si JOBVL = 'N'.
!>

LDVL

!>          LDVL est INTEGER
!>          La dimension principale de la matrice VL. LDVL >= 1, et
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR est un tableau COMPLEX*16, dimension (LDVR,N)
!>          Si JOBVR = 'V', les vecteurs propres généralisés droits v(j) sont
!>          stockés les uns après les autres dans les colonnes de VR, dans le même
!>          ordre que leurs valeurs propres.
!>          Chaque vecteur propre est mis à l'échelle de sorte que le composant le plus grand ait
!>          abs(partie réelle) + abs(partie imaginaire) = 1.
!>          Non référencé si JOBVR = 'N'.
!>

LDVR

!>          LDVR est INTEGER
!>          La dimension principale de la matrice VR. LDVR >= 1, et
!>          si JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.  LWORK >= max(1,2*N).
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête de capacité est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (8*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          =1,...,N:
!>                L'itération QZ a échoué. Aucun vecteur propre n'a été
!>                calculé, mais ALPHA(j) et BETA(j) devraient être
!>                corrects pour j=INFO+1,...,N.
!>          > N:  =N+1: échec de l'itération QZ dans ZHGEQZ,
!>                =N+2: retour d'erreur de ZTGEVC.
!>

zggev(3)

ZGGEV Computes the generalized eigenvalues and eigenvectors of a complex pair of matrices.

SYNOPSIS

SUBROUTINE ZGGEV( JOBVL, JOBVR, N, A, LDA, B, LDB, ALPHAR, ALPHAI, BETA, VL, LDVL, VR, LDVR, WORK, LWORK, RWORK, INFO )

ZGGEV computes for the generalized eigenvalue problem A*x = lambda*B*x, the eigenvalues lambda and, optionally, the left and right eigenvectors.

Parameters

JOBVL – CHARACTER*1

='N': no computation of left eigenvectors; ='V': computation of left eigenvectors.

JOBVR – CHARACTER*1

='N': no computation of right eigenvectors; ='V': computation of right eigenvectors.

N – INTEGER

The order of the matrices A and B. N >= 0.

A – COMPLEX*16

A(LDA,N). On entry, the first N rows of this matrix contain the upper triangular part of the matrix A in Henselian form. On exit, A is overwritten by its upper Schur form, defining the eigenvalues on its diagonal.

LDA – INTEGER

The leading dimension of the array A. LDA >= max(1,N).

B – COMPLEX*16

B(LDB,N). On entry, the first N rows of this matrix contain the upper triangular part of the matrix B in Henselian form. On exit, B is overwritten by its upper Schur form, defining the eigenvalues on its diagonal.

LDB – INTEGER

The leading dimension of the array B. LDB >= max(1,N).

ALPHAR – DOUBLE PRECISION

ALPHAR(N). The real parts of the complex eigenvalues of A.

ALPHAI – DOUBLE PRECISION

ALPHAI(N). The imaginary parts of the complex eigenvalues of A.

BETA – COMPLEX*16

BETA(N). The complex eigenvalues of B.

VL – COMPLEX*16

VL(LDVL,N). If JOBVL ='V', the matrix VL is used to store the left eigenvectors of A and B such that the j-th column VL(j) is the eigenvector v_j satisfying A*v_j = lambda_j*B*v_j.

LDVL – INTEGER

The leading dimension of the array VL. LDVL >= N.

VR – COMPLEX*16

VR(LDVR,N). If JOBVR ='V', the matrix VR is used to store the right eigenvectors of A and B such that the j-th column VR(j) is the eigenvector u_j satisfying A*u_j = lambda_j*B*u_j.

LDVR – INTEGER

The leading dimension of the array VR. LDVR >= N.

WORK – COMPLEX*16

WORK(LWORK). On exit, WORK(1) contains the optimal value of LWORK.

LWORK – INTEGER

The dimension of the array WORK. LWORK >= 1. For optimal efficiency, LWORK may be specified to obtain 1, which is the minimum dimension of WORK.

RWORK – DOUBLE PRECISION

RWORK(LRWORK). Workspace array.

INFO – INTEGER

INFO = 0: successful exit. INFO < 0: if INFO = -i, the i-th argument had an illegal value. INFO = 1: the algorithm failed to compute the Schur factorization. INFO = 2: the algorithm failed to compute the Schur vectors. INFO = 3: the algorithm did not converge. The Schur vectors are not computed. INFO = 4: the algorithm failed to compute the eigenvalues. INFO = 5: the algorithm failed to compute the eigenvectors.

Function/Subroutine Documentation

The generalized eigenvalue problem A*x = lambda*B*x is to find the eigenvalues lambda and the corresponding eigenvectors x for a pair of matrices (A, B).

ZGGEV computes the eigenvalues and eigenvectors of a complex generalized eigenvalue problem A*x = lambda*B*x.

The subroutine first reduces the matrices A and B to generalized upper triangular form using an orthogonal transformation.

If JOBVL is set to 'V', the subroutine computes the left eigenvectors.

If JOBVR is set to 'V', the subroutine computes the right eigenvectors.

The computed eigenvalues lambda are returned in the arrays ALPHAR, ALPHAI, and BETA.

The computed eigenvectors are stored in the arrays VL and VR if requested.
