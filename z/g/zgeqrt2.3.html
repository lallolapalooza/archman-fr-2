Documentation de la fonction/sous programme

sous programme zgeqrt2 (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldt, * ) t, integer ldt, integer info)

ZGEQRT2 calcule une factorisation QR d'une matrice complexe M par N A, en utilisant la représentation WY compacte de Q.

But :

!>
!> ZGEQRT2 calcule une factorisation QR d'une matrice complexe M par N A,
!> en utilisant la représentation WY compacte de Q.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= N.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, la matrice complexe M par N A. À la sortie, les éléments sur et
!>          au-dessus de la diagonale contiennent la matrice triangulaire supérieure N par N R ; les
!>          éléments en dessous de la diagonale sont les colonnes de V. Voir ci-dessous pour
!>          plus de détails.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

T

!>          T est un tableau COMPLEX*16, de dimension (LDT,N)
!>          La matrice triangulaire supérieure N par N du réflecteur de bloc.
!>          Les éléments sur et au-dessus de la diagonale contiennent le bloc
!>          réflecteur T ; les éléments en dessous de la diagonale ne sont pas utilisés.
!>          Voir ci-dessous pour plus de détails.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T.  LDT >= max(1,N).
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  La matrice V stocke les réflecteurs élémentaires H(i) dans la i-ème colonne
!>  en dessous de la diagonale. Par exemple, si M=5 et N=3, la matrice V est
!>
!>               V = (  1       )
!>                   ( v1  1    )
!>                   ( v1 v2  1 )
!>                   ( v1 v2 v3 )
!>                   ( v1 v2 v3 )
!>
!>  où les vi représentent les vecteurs qui définissent H(i), qui sont renvoyés
!>  dans la matrice A. Les 1 le long de la diagonale de V ne sont pas stockés dans A. Le
!>  réflecteur de bloc H est alors donné par
!>
!>               H = I - V * T * V**H
!>
!>  où V**H est la transposée conjuguée de V.
!>
