ZGEEQUB

Documentation de la fonction/sous-routine

sous-routine zgeequb (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision rowcnd, double precision colcnd, double precision amax, integer info)

ZGEEQUB

But :

!>
!> ZGEEQUB calcule les facteurs d'échelle des lignes et des colonnes destinés à équilibrer
!> une matrice M par N, A, et à réduire son nombre de conditionnement. R renvoie les
!> facteurs d'échelle des lignes et C les facteurs d'échelle des colonnes, choisis pour
!> tenter de rendre la valeur absolue de l'élément le plus grand de chaque ligne et colonne
!> de la matrice B, dont les éléments sont B(i,j)=R(i)*A(i,j)*C(j), au plus égale à la base.
!>
!> R(i) et C(j) sont restreints à être une puissance de la base entre
!> SMLNUM = plus petit nombre sûr et BIGNUM = plus grand nombre sûr. L'utilisation de
!> ces facteurs d'échelle n'est pas garantie de réduire le nombre de conditionnement de A
!> mais fonctionne bien en pratique.
!>
!> Cette routine diffère de ZGEEQU par la restriction des facteurs d'échelle à une puissance de la base.
!> En l'absence de dépassement (overflow) ou de sous-dépassement (underflow), la mise à l'échelle
!> par ces facteurs n'introduit pas d'erreurs d'arrondi supplémentaires. Cependant, les magnitudes
!> des éléments mis à l'échelle ne sont plus approximativement égales à 1 mais se situent
!> entre sqrt(base) et 1/sqrt(base).
!>

Paramètres

M 
!>          M est de type INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est de type INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>          La matrice M par N dont les facteurs d'équilibrage doivent être
!>          calculés.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

R

!>          R est un tableau de type DOUBLE PRECISION, de dimension (M)
!>          Si INFO = 0 ou INFO > M, R contient les facteurs d'échelle des lignes
!>          pour A.
!>

C

!>          C est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          Si INFO = 0,  C contient les facteurs d'échelle des colonnes pour A.
!>

ROWCND

!>          ROWCND est de type DOUBLE PRECISION
!>          Si INFO = 0 ou INFO > M, ROWCND contient le rapport du plus petit R(i)
!>          au plus grand R(i).  Si ROWCND >= 0.1 et AMAX n'est ni trop grand
!>          ni trop petit, il n'est pas utile de mettre à l'échelle avec R.
!>

COLCND

!>          COLCND est de type DOUBLE PRECISION
!>          Si INFO = 0, COLCND contient le rapport du plus petit C(i) au plus grand C(i).
!>          Si COLCND >= 0.1, il n'est pas utile de mettre à l'échelle avec C.
!>

AMAX

!>          AMAX est de type DOUBLE PRECISION
!>          La valeur absolue de l'élément matriciel le plus grand. Si AMAX est très
!>          proche du dépassement (overflow) ou du sous-dépassement (underflow),
!>          la matrice doit être mise à l'échelle.
!>

INFO

!>          INFO est de type INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= M: la i-ème ligne de A est exactement nulle
!>                >  M: la (i-M)-ème colonne de A est exactement nulle
!>
