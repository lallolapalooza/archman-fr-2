Documentation de la fonction/sous-programme

sous-programme zgesc2 (integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) rhs, integer, dimension( * ) ipiv, integer, dimension( * ) jpiv, double precision scale)

ZGESC2 résout un système d'équations linéaires en utilisant la factorisation LU avec pivotement complet calculée par sgetc2.

But :

!>
!> ZGESC2 résout un système d'équations linéaires
!>
!>           A * X = scale* RHS
!>
!> avec une matrice carrée A de taille N x N en utilisant la factorisation LU avec
!> pivotement complet calculée par ZGETC2.
!>
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A.
!>

A

!>          A est un tableau de type COMPLEX*16, de dimension (LDA, N)
!>          En entrée, la partie LU de la factorisation de la matrice A de taille n x n
!>          calculée par ZGETC2 : A = P * L * U * Q
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1, N).
!>

RHS

!>          RHS est un tableau de type COMPLEX*16, de dimension N.
!>          En entrée, le vecteur du second membre b.
!>          En sortie, le vecteur solution X.
!>

IPIV

!>          IPIV est un tableau d'entiers (INTEGER), de dimension (N).
!>          Les indices de pivot ; pour 1 <= i <= N, la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

JPIV

!>          JPIV est un tableau d'entiers (INTEGER), de dimension (N).
!>          Les indices de pivot ; pour 1 <= j <= N, la colonne j de la
!>          matrice a été échangée avec la colonne JPIV(j).
!>

SCALE

!>          SCALE est un réel double précision (DOUBLE PRECISION)
!>           En sortie, SCALE contient le facteur d'échelle. SCALE est choisi tel que
!>           0 <= SCALE <= 1 pour éviter un débordement dans la solution.
!>
