subroutine zget37 (double precision, dimension( 3 ) rmax, integer, dimension( 3 ) lmax, integer, dimension( 3 ) ninfo, integer knt, integer nin)

ZGET37

Objectif :

!>
!> ZGET37 teste ZTRSNA, une routine pour estimer les nombres de condition
!> des valeurs propres et/ou des vecteurs propres droits d'une matrice.
!>
!> Les matrices de test sont lues à partir d'un fichier avec l'unité logique NIN.
!>

Paramètres

RMAX 
!>          RMAX est un tableau DOUBLE PRECISION, de dimension (3)
!>          Valeur du rapport de test le plus grand.
!>          RMAX(1) = rapport le plus grand comparant différents appels à ZTRSNA
!>          RMAX(2) = erreur la plus grande dans les nombres de condition réciproques
!>                    en tenant compte de leur conditionnement
!>          RMAX(3) = erreur la plus grande dans les nombres de condition réciproques
!>                    ne tenant pas compte de leur conditionnement (peut être plus grand que RMAX(2))
!>

LMAX

!>          LMAX est un tableau INTEGER, de dimension (3)
!>          LMAX(i) est le numéro de l'exemple où le rapport de test le plus grand
!>          RMAX(i) est atteint. Aussi :
!>          Si ZGEHRD retourne INFO non nul à l'exemple i, LMAX(1)=i
!>          Si ZHSEQR retourne INFO non nul à l'exemple i, LMAX(2)=i
!>          Si ZTRSNA retourne INFO non nul à l'exemple i, LMAX(3)=i
!>

NINFO

!>          NINFO est un tableau INTEGER, de dimension (3)
!>          NINFO(1) = Nombre de fois que ZGEHRD a retourné INFO non nul
!>          NINFO(2) = Nombre de fois que ZHSEQR a retourné INFO non nul
!>          NINFO(3) = Nombre de fois que ZTRSNA a retourné INFO non nul
!>

KNT

!>          KNT est un INTEGER
!>          Nombre total d'exemples testés.
!>

NIN

!>          NIN est un INTEGER
!>          Numéro de l'unité logique d'entrée
!>
