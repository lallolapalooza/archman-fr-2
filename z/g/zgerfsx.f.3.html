sous-programme zgerfsx (caractère trans, caractère equed, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldaf, * ) af, entier ldaf, entier, dimension( * ) ipiv, double précision, dimension( * ) r, double précision, dimension( * ) c, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldx , * ) x, entier ldx, double précision rcond, double précision, dimension( * ) berr, entier n_err_bnds, double précision, dimension( nrhs, * ) err_bnds_norm, double précision, dimension( nrhs, * ) err_bnds_comp, entier nparams, double précision, dimension( * ) params, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier info)

ZGERFSX

Objectif :

!>
!>    ZGERFSX améliore la solution calculée d'un système d'équations linéaires
!>    et fournit des bornes d'erreur et des estimations d'erreur arrière
!>    pour la solution. En plus de la borne d'erreur normwise, le code
!>    fournit une borne d'erreur composante maximale si possible. Voir
!>    les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des
!>    bornes d'erreur.
!>
!>    Le système d'équations linéaires original peut avoir été équilibré
!>    avant d'appeler cette routine, comme décrit par les arguments EQUED, R
!>    et C ci-dessous. Dans ce cas, la solution et les bornes d'erreur retournées
!>    sont pour le système original non équilibré.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment le raffinement est effectué, mais souvent les
!>     valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N' :  A * X = B     (Pas de transposée)
!>       = 'T' :  A**T * X = B  (Transposée)
!>       = 'C' :  A**H * X = B  (Conjuguée transposée)
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibration qui a été effectuée sur A
!>     avant d'appeler cette routine. Ceci est nécessaire pour calculer
!>     la solution et les bornes d'erreur correctement.
!>       = 'N' :  Pas d'équilibration
!>       = 'R' :  Équilibrage des lignes, c'est-à-dire que A a été multipliée
!>               par diag(R).
!>       = 'C' :  Équilibrage des colonnes, c'est-à-dire que A a été post-multipliée
!>               par diag(C).
!>       = 'B' :  Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacée par diag(R) * A * diag(C).
!>               Le second membre B a été modifié en conséquence.
!>

N

!>          N est INTEGER
!>     L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>     La matrice originale A de taille N par N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>     Les facteurs L et U de la factorisation A = P*L*U
!>     tels que calculés par ZGETRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Les indices de pivot de ZGETRF ; pour 1<=i<=N, la ligne i de la
!>     matrice a été échangée avec la ligne IPIV(i).
!>

R

!>          R est un tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle des lignes pour A.  Si EQUED = 'R' ou 'B', A est
!>     multipliée à gauche par diag(R) ; si EQUED = 'N' ou 'C', R
!>     n'est pas accédé.
!>     Si R est accédé, chaque élément de R doit être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. L'échelle par
!>     puissances de la base ne cause pas d'erreurs d'arrondi, sauf si le
!>     résultat sous-flotte ou surflotte. Les erreurs d'arrondi lors de l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle des colonnes pour A.  Si EQUED = 'C' ou 'B', A est
!>     multipliée à droite par diag(C) ; si EQUED = 'N' ou 'R', C
!>     n'est pas accédé.
!>     Si C est accédé, chaque élément de C doit être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. L'échelle par
!>     puissances de la base ne cause pas d'erreurs d'arrondi, sauf si le
!>     résultat sous-flotte ou surflotte. Les erreurs d'arrondi lors de l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>     La matrice du second membre B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>     En entrée, la matrice solution X, telle que calculée par ZGETRS.
!>     En sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     Conditionnement relatif réciproque mis à l'échelle. C'est une estimation du
!>     conditionnement de Skeel relatif réciproque de la matrice A après
!>     équilibration (si effectuée). S'il est inférieur à la précision machine
!>     (en particulier s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut encore être faible même
!>     si ce nombre est très petit et que la matrice semble mal conditionnée.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>     Erreur arrière relative composante par composante. C'est l'erreur
!>     arrière relative composante par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire le plus petit changement relatif dans un élément de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à retourner pour chaque second membre
!>     et chaque type (normwise ou composante par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre,

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre,

NPARAMS

!>          NPARAMS est INTEGER
!>     Le nombre de paramètres optionnels dans le tableau PARAMS.
!>

PARAMS

!>          PARAMS est un tableau DOUBLE PRECISION, dimension (NPARAMS)
!>     Tableau contenant des paramètres optionnels.
!>     Les paramètres actuels sont :
!>       PARAMS(1) : Précision relative demandée pour le raffinement. Si le raffinement
!>                   n'est pas arrivé à la précision demandée, le raffinement s'arrête.
!>                   Une valeur typique est EPS*100, où EPS est la précision machine.
!>       PARAMS(2) : Tolérance pour le test de singularité de la matrice. Si le
!>                   conditionnement relatif estimé est inférieur à ce seuil, la
!>                   routine s'arrêtera et retournera une erreur. Une valeur typique
!>                   est EPS.
!>       PARAMS(3) : Tolérance pour la détection de l'absence de convergence de l'erreur
!>                   arrière composante par composante. Si l'erreur arrière composante
!>                   n'a pas diminué de manière significative après une itération,
!>                   le raffinement s'arrête. Une valeur typique est 100*EPS.
!>       PARAMS(4) : Tolérance pour la détection de l'absence de convergence de l'erreur
!>                   normwise. Si l'erreur normwise n'a pas diminué de manière
!>                   significative après une itération, le raffinement s'arrête. Une
!>                   valeur typique est 100*EPS.
!>       PARAMS(5) : Tolérance pour la détection de l'absence de convergence du calcul de
!>                   borne d'erreur composante par composante. Si la borne d'erreur
!>                   composante par composante n'a pas diminué de manière significative
!>                   après une itération, le calcul s'arrête. Une valeur typique est
!>                   100*EPS.
!>       PARAMS(6) : Tolérance pour la détection de l'absence de convergence du calcul de
!>                   borne d'erreur normwise. Si la borne d'erreur normwise n'a pas
!>                   diminué de manière significative après une itération, le calcul
!>                   s'arrête. Une valeur typique est 100*EPS.
!>
!>     Si NPARAMS = 0, les valeurs par défaut sont utilisées.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (*)
!>     Tableau de travail de taille suffisante.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (*)
!>     Tableau de travail de taille suffisante.
!>

INFO

!>          INFO est INTEGER
!>     = 0 : succès.
!>     < 0 : si INFO = -i, le i-ème argument était invalide.
!>     > 0 : si INFO = i, le calcul a échoué. La solution n'est pas garantie.
!>         Le i-ème paramètre de PARAMS était trop petit.
!>

NAME

zgerfsx

higham's normwise, componentwise and mixed error bounds for the solution of a complex linear system

SYNOPSIS

SUBROUTINE ZGERFSX(
                       TRANS, N, NRHS, A, LDA, AF, LDAF, IPIV, EQUED,
                       R, C, RR, RC, X, LDX, XTRUE, LDXTRUE, FERR,
                       BERR, PERM_SPEC, PERM_COPY, INFO )

  INTEGER            :: N, NRHS, LDA, LDAF, LDX, LDXTRUE
  INTEGER            :: IPIV( * )
  CHARACTER          * 1       :: EQUED
  DOUBLE PRECISION   :: R( * ), C( * ), RR( * ), RC( * ), FERR( * ),
                      BERR( * )
  COMPLEX*16        :: A( * ), AF( * ), X( * ), XTRUE( * )
  INTEGER            :: PERM_SPEC( * ), PERM_COPY( * )

Function/Subroutine Documentation

TRANS

!>          TRANS is CHARACTER*1
!>          Specifies the form of the system of equations:
!>          = 'N':  A * X = B         (No transpose)
!>          = 'T':  A**T * X = B      (Transpose)
!>          = 'C':  A**H * X = B      (Conjugate transpose)
!

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrices B, X, XTRUE, FERR and BERR. NRHS >= 0.
!

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          On entry to the routine, the N-by-N coefficient matrix A.
!

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!

AF

!>          AF is COMPLEX*16 array, dimension (LDAF,N)
!>          On entry to the routine, the factors L and U from the
!>          factorization A = P*L*U as computed by ZGETRF.
!

LDAF

!>          LDAF is INTEGER
!>          The leading dimension of the array AF. LDAF >= max(1,N).
!

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>          The pivot indices from the factorization. IPIV[i] is the row
!>          index of the row that was interchanged with row i in
!>          step i of the factorization.
!

EQUED

!>          EQUED is CHARACTER*1
!>          SPECIFIES WHETHER THE MATRICES ARE SCALED OR NOT:
!>          = 'N': None of the rows or columns were scaled.
!>          = 'R': The rows of A were scaled by the vector R.
!>          = 'C': The columns of A were scaled by the vector C.
!>          = 'B': Both the rows and the columns of A were scaled by the
!>                 vectors R and C respectively.
!>          This is an output argument. This argument is used only if
!>          componentwise error bounds are requested.
!

R

!>          R is DOUBLE PRECISION array, dimension (N)
!>          The array R. The elements of R are not used if EQUED is
!>          'N' or 'C'.
!>          This is an output argument. This argument is used only if
!>          componentwise error bounds are requested.
!

C

!>          C is DOUBLE PRECISION array, dimension (N)
!>          The array C. The elements of C are not used if EQUED is
!>          'N' or 'R'.
!>          This is an output argument. This argument is used only if
!>          componentwise error bounds are requested.
!

RR

!>          RR is DOUBLE PRECISION array, dimension (N)
!>          The array RR. The elements of RR are not used if EQUED is
!>          'N' or 'C'.
!>          This is an output argument. This argument is used only if
!>          componentwise error bounds are requested.
!

RC

!>          RC is DOUBLE PRECISION array, dimension (N)
!>          The array RC. The elements of RC are not used if EQUED is
!>          'N' or 'R'.
!>          This is an output argument. This argument is used only if
!>          componentwise error bounds are requested.
!

X

!>          X is COMPLEX*16 array, dimension (LDX,NRHS)
!>          On entry to the routine, the solution vectors X to the system
!>          of equations A*X = B.
!

LDX

!>          LDX is INTEGER
!>          The leading dimension of the array X. LDX >= max(1,N).
!

XTRUE

!>          XTRUE is COMPLEX*16 array, dimension (LDXTRUE,NRHS)
!>          On entry to the routine, the basic solution vectors XTRUE to
!>          the system of equations A*X = B.
!

LDXTRUE

!>          LDXTRUE is INTEGER
!>          The leading dimension of the array XTRUE. LDXTRUE >= max(1,N).
!

FERR

!>          FERR is DOUBLE PRECISION array, dimension (NRHS)
!>          On exit, FERR(j) is an estimate of the relative error in
!>          the jth solution vector, if the user is solving the i-th
!>          system.
!>          The calculation of FERR(j) depends on the value of
!>          PARAMS(LA_LINRX_CWISE_I). If PARAMS(LA_LINRX_CWISE_I) = 0.0,
!>          then FERR(j) is an estimate of the normwise relative error.
!>          If PARAMS(LA_LINRX_CWISE_I) = 1.0, then FERR(j) is an
!>          estimate of the componentwise relative error.
!

BERR

!>          BERR is DOUBLE PRECISION array, dimension (NRHS)
!>          On exit, BERR(j) is an estimate of the relative backward
!>          error in the jth solution vector, if the user is solving the
!>          i-th system.
!>          The calculation of BERR(j) depends on the value of
!>          PARAMS(LA_LINRX_CWISE_I). If PARAMS(LA_LINRX_CWISE_I) = 0.0,
!>          then BERR(j) is an estimate of the normwise relative backward
!>          error.
!>          If PARAMS(LA_LINRX_CWISE_I) = 1.0, then BERR(j) is an
!>          estimate of the componentwise relative backward error.
!

PERM_SPEC

!>          PERM_SPEC is INTEGER array, dimension (N)
!>          On entry, PERM_SPEC contains permutation information on how
!>          to permute the matrix A in the calculation of the reciprocal
!>          condition number.
!>          On exit, PERM_SPEC is updated with the permutation required
!>          for the solution vectors.
!

PERM_COPY

!>          PERM_COPY is INTEGER array, dimension (N)
!>          This is a workspace array used for permuting the matrix A.
!

INFO

!>          INFO is INTEGER
!>       = 0:  Successful exit. The solution to every right-hand side is
!>         guaranteed.
!>       < 0:  If INFO = -i, the i-th argument had an illegal value
!>       > 0 and <= N:  U(INFO,INFO) is exactly zero.  The factorization
!>         has been completed, but the factor U is exactly singular, so
!>         the solution and error bounds could not be computed. RCOND = 0
!>         is returned.
!>       = N+J: The solution corresponding to the Jth right-hand side is
!>         not guaranteed. The solutions corresponding to other right-
!>         hand sides K with K > J may not be guaranteed as well, but
!>         only the first such right-hand side is reported. If a small
!>         componentwise error is not requested (PARAMS(3) = 0.0) then
!>         the Jth right-hand side is the first with a normwise error
!>         bound that is not guaranteed (the smallest J such
!>         that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
!>         the Jth right-hand side is the first with either a normwise or
!>         componentwise error bound that is not guaranteed (the smallest
!>         J such that either ERR_BNDS_NORM(J,1) = 0.0 or
!>         ERR_BNDS_COMP(J,1) = 0.0). See the definition of
!>         ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
!>         about all of the right-hand sides check ERR_BNDS_NORM or
!>         ERR_BNDS_COMP.
!

ERR_BNDS_NORM

!>          ERR_BNDS_NORM is DOUBLE PRECISION array, dimension (NRHS, 3)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     normwise relative error, which is defined as follows:
!>
!>     Normwise relative error in the ith solution vector:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     The array is indexed by the type of error information as described
!>     below. There currently are up to three pieces of information
!>     returned.
!>
!>     The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_NORM(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * dlamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated normwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * dlamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*A, where S scales each row by a power of the
!>              radix so all absolute row sums of Z are approximately 1.
!>
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!

ERR_BNDS_COMP

!>          ERR_BNDS_COMP is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     componentwise relative error, which is defined as follows:
!>
!>     Componentwise relative error in the ith solution vector:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     The array is indexed by the right-hand side i (on which the
!>     componentwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_COMP(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * dlamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated componentwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * dlamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*(A*diag(x)), where x is the solution for the
!>              current right-hand side and S scales each row of
!>              A*diag(x) by a power of the radix so all absolute row
!>              sums of Z are approximately 1.
!>
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!

NPARAMS

!>          NPARAMS is INTEGER
!>     Specifies the number of parameters set in PARAMS.  If <= 0, the
!>     PARAMS array is never referenced and default values are used.
!

PARAMS

!>          PARAMS is DOUBLE PRECISION array, dimension NPARAMS
!>     Specifies algorithm parameters.  If an entry is < 0.0, then
!>     that entry will be filled with default value used for that
!>     parameter.  Only positions up to NPARAMS are accessed; defaults
!>     are used for higher-numbered parameters.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
!>            refinement or not.
!>         Default: 1.0D+0
!>            = 0.0:  No refinement is performed, and no error bounds are
!>                    computed.
!>            = 1.0:  Use the double-precision refinement algorithm,
!>                    possibly with doubled-single computations if the
!>                    compilation environment does not support DOUBLE
!>                    PRECISION.
!>              (other values are reserved for future use)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual
!>            computations allowed for refinement.
!>         Default: 10
!>         Aggressive: Set to 100 to permit convergence using approximate
!>                     factorizations or factorizations other than LU. If
!>                     the factorization uses a technique other than
!>                     Gaussian elimination, the guarantees in
!>                     err_bnds_norm and err_bnds_comp may no longer be
!>                     trustworthy.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code
!>            will attempt to find a solution with small componentwise
!!>            relative error in the double-precision algorithm.  Positive
!>            is true, 0.0 is false.
!>         Default: 1.0 (attempt componentwise convergence)
!

WORK

!>          WORK is COMPLEX*16 array, dimension (2*N)
!

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (2*N)
!

INFO

!>          INFO is INTEGER
