sous-routine zgsvj1 (character*1 jobv, integer m, integer n, integer n1, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( n ) d, double precision, dimension( n ) sva, integer mv, complex*16, dimension( ldv, * ) v, integer ldv, double precision eps, double precision sfmin, double precision tol, integer nsweep, complex*16, dimension( lwork ) work, integer lwork, integer info)

ZGSVJ1 pré-processeur pour la routine zgesvj, applique des rotations de Jacobi ciblant uniquement des pivots particuliers.

But :

!>
!> ZGSVJ1 est appelée depuis ZGESVJ en tant que pré-processeur et c'est son
!> objectif principal. Elle applique des rotations de Jacobi de la même manière
!> que ZGESVJ, mais elle cible uniquement des pivots particuliers et ne vérifie
!> pas la convergence (critère d'arrêt). Quelques paramètres de réglage (marqués
!> par [TP]) sont disponibles pour l'implémenteur.
!>
!> Détails supplémentaires
!> ~~~~~~~~~~~~~~~~~~~
!> ZGSVJ1 applique quelques balayages de rotations de Jacobi dans l'espace
!> des colonnes de la matrice d'entrée M-par-N A. Les paires de pivots sont
!> prises dans le bloc hors diagonale (1,2) de la matrice de Gram correspondante
!> N-par-N A^T * A. Les blocs-entrées (tuiles) du bloc hors diagonale (1,2) sont
!> marqués par les [x] dans le schéma suivant :
!>
!>    | *  *  * [x] [x] [x]|
!>    | *  *  * [x] [x] [x]|    Balayage de lignes dans les blocs [x] de taille nblr-par-nblc.
!>    | *  *  * [x] [x] [x]|    Pivots cycliques de lignes à l'intérieur de chaque bloc [x].
!>    |[x] [x] [x] *  *  * |
!>    |[x] [x] [x] *  *  * |
!>    |[x] [x] [x] *  *  * |
!>
!> En termes de colonnes de A, les N1 premières colonnes sont pivotées 'contre'
!> les N-N1 colonnes restantes, essayant d'augmenter l'angle entre les
!> sous-espaces correspondants. Le bloc hors diagonale est de taille N1-par-(N-N1)
!> et il est découpé en tuiles quadratiques de côté KBL. Ici, KBL est un paramètre
!> de réglage. Le nombre de balayages est donné dans NSWEEP et le seuil d'orthogonalité
!> est donné dans TOL.
!>

Paramètres

JOBV 
!>          JOBV est CHARACTER*1
!>          Spécifie si le résultat de cette procédure est utilisé
!>          pour calculer la matrice V :
!>          = 'V' : le produit des rotations de Jacobi est accumulé
!>                 en post-multipliant le tableau N-par-N V.
!>                (Voir la description de V.)
!>          = 'A' : le produit des rotations de Jacobi est accumulé
!>                 en post-multipliant le tableau MV-par-N V.
!>                (Voir les descriptions de MV et V.)
!>          = 'N' : les rotations de Jacobi ne sont pas accumulées.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!>

N1

!>          N1 est INTEGER
!>          N1 spécifie la partition du bloc 2x2, les N1 premières colonnes sont
!>          pivotées 'contre' les N-N1 colonnes restantes de A.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          En entrée, matrice M-par-N A, telle que A*diag(D) représente
!>          la matrice d'entrée.
!>          En sortie,
!>          A_en_sortie * D_en_sortie représente la matrice d'entrée A*diag(D)
!>          post-multipliée par une séquence de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de balayages sont donnés dans
!>          TOL et NSWEEP, respectivement.
!>          (Voir les descriptions de N1, D, TOL et NSWEEP.)
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

D

!>          D est un tableau COMPLEX*16, dimension (N)
!>          Le tableau D accumule les facteurs d'échelle des rotations de Jacobi
!>          rapides et mises à l'échelle.
!>          En entrée, A*diag(D) représente la matrice d'entrée.
!>          En sortie, A_en_sortie*diag(D_en_sortie) représente la matrice d'entrée
!>          post-multipliée par une séquence de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de balayages sont donnés dans
!>          TOL et NSWEEP, respectivement.
!>          (Voir les descriptions de N1, A, TOL et NSWEEP.)
!>

SVA

!>          SVA est un tableau DOUBLE PRECISION, dimension (N)
!>          En entrée, SVA contient les normes euclidiennes des colonnes de
!>          la matrice A*diag(D).
!>          En sortie, SVA contient les normes euclidiennes des colonnes de
!>          la matrice A_en_sortie*diag(D_en_sortie).
!>

MV

!>          MV est INTEGER
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'N',   alors MV n'est pas référencé.
!>

V

!>          V est un tableau COMPLEX*16, dimension (LDV,N)
!>          Si JOBV = 'V', alors N lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'N',   alors V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V,  LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!>

EPS

!>          EPS est DOUBLE PRECISION
!>          EPS = DLAMCH('Epsilon')
!>

SFMIN

!>          SFMIN est DOUBLE PRECISION
!>          SFMIN = DLAMCH('Safe Minimum')
!>

TOL

!>          TOL est DOUBLE PRECISION
!>          TOL est le seuil pour les rotations de Jacobi. Pour une paire
!>          de colonnes de pivot A(:,p), A(:,q), la rotation de Jacobi est
!>          appliquée uniquement si ABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!>

NSWEEP

!>          NSWEEP est INTEGER
!>          NSWEEP est le nombre de balayages de rotations de Jacobi à effectuer.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          LWORK est la dimension de WORK. LWORK >= M.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, alors le i-ème argument avait une valeur illégale
!>
