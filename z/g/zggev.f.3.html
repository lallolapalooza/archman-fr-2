ZGGEV calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour les matrices GE

But :

!>
!> ZGGEV calcule pour une paire de matrices complexes N-par-N non symétriques
!> (A,B), les valeurs propres généralisées, et éventuellement, les vecteurs propres généralisés gauches et/ou droits.
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire
!> lambda ou un rapport alpha/beta = lambda, tel que A - lambda*B est
!> singulier. Elle est généralement représentée par la paire (alpha,beta), car
!> il existe une interprétation raisonnable pour beta=0, et même pour les deux
!> étant zéro.
!>
!> Le vecteur propre généralisé droit v(j) correspondant à la valeur propre généralisée
!> lambda(j) de (A,B) satisfait
!>
!>              A * v(j) = lambda(j) * B * v(j).
!>
!> Le vecteur propre généralisé gauche u(j) correspondant à la valeur propre généralisée
!> lambda(j) de (A,B) satisfait
!>
!>              u(j)**H * A = lambda(j) * u(j)**H * B
!>
!> où u(j)**H est la transposée conjuguée de u(j).
!>

Paramètres

JOBVL 
!>          JOBVL est CHARACTER*1
!>          = 'N':  ne pas calculer les vecteurs propres généralisés gauches ;
!>          = 'V':  calculer les vecteurs propres généralisés gauches.
!>

JOBVR

!>          JOBVR est CHARACTER*1
!>          = 'N':  ne pas calculer les vecteurs propres généralisés droits ;
!>          = 'V':  calculer les vecteurs propres généralisés droits.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A, B, VL, et VR.  N >= 0.
!>

A

!>          A est COMPLEX*16 array, dimension (LDA, N)
!>          En entrée, la matrice A de la paire (A,B).
!>          En sortie, A a été écrasée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A.  LDA >= max(1,N).
!>

B

!>          B est COMPLEX*16 array, dimension (LDB, N)
!>          En entrée, la matrice B de la paire (A,B).
!>          En sortie, B a été écrasée.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de B.  LDB >= max(1,N).
!>

ALPHA

!>          ALPHA est COMPLEX*16 array, dimension (N)
!>

BETA

!>          BETA est COMPLEX*16 array, dimension (N)
!>          En sortie, ALPHA(j)/BETA(j), j=1,...,N, seront les
!>          valeurs propres généralisées.
!>
!>          Note : les quotients ALPHA(j)/BETA(j) peuvent facilement
!>          déborder ou sous-fluer, et BETA(j) peut même être zéro.  Ainsi, l'utilisateur
!>          devrait éviter de calculer naïvement le rapport alpha/beta.
!>          Cependant, ALPHA sera toujours inférieur et généralement
!>          comparable à norm(A) en magnitude, et BETA toujours inférieur
!>          et généralement comparable à norm(B).
!>

VL

!>          VL est COMPLEX*16 array, dimension (LDVL,N)
!>          Si JOBVL = 'V', les vecteurs propres généralisés gauches u(j) sont
!>          stockés les uns après les autres dans les colonnes de VL, dans le même
!>          ordre que leurs valeurs propres.
!>          Chaque vecteur propre est mis à l'échelle de sorte que le composant le plus grand ait
!>          abs(partie réelle) + abs(partie imaginaire) = 1.
!>          Non référencé si JOBVL = 'N'.
!>

LDVL

!>          LDVL est INTEGER
!>          La dimension principale de la matrice VL. LDVL >= 1, et
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR est COMPLEX*16 array, dimension (LDVR,N)
!>          Si JOBVR = 'V', les vecteurs propres généralisés droits v(j) sont
!>          stockés les uns après les autres dans les colonnes de VR, dans le même
!>          ordre que leurs valeurs propres.
!>          Chaque vecteur propre est mis à l'échelle de sorte que le composant le plus grand ait
!>          abs(partie réelle) + abs(partie imaginaire) = 1.
!>          Non référencé si JOBVR = 'N'.
!>

LDVR

!>          LDVR est INTEGER
!>          La dimension principale de la matrice VR. LDVR >= 1, et
!>          si JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK est COMPLEX*16 array, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.  LWORK >= max(1,2*N).
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est DOUBLE PRECISION array, dimension (8*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          =1,...,N:
!>                L'itération QZ a échoué. Aucun vecteur propre n'a été
!>                calculé, mais ALPHA(j) et BETA(j) devraient être
!>                corrects pour j=INFO+1,...,N.
!>          > N:  =N+1: l'itération QZ a échoué dans ZHGEQZ,
!>                =N+2: retour d'erreur de ZTGEVC.
!>

Documentation de la fonction/sous-routine

ZGGEV calcule les valeurs propres et les vecteurs propres gauches et/ou droits d'une paire de matrices complexes généralisées.

ZGGEV calcule les valeurs propres (ALPHA et BETA) et les vecteurs propres (VL et VR) d'une paire de matrices complexes généralisées (A, B) de la forme :

A*v = lambda*B*v

où lambda est une valeur propre et v est un vecteur propre correspondant.

Les paramètres sont les suivants :

  • JOBVL : Indique s'il faut calculer les vecteurs propres gauches.
    • 'N' : Aucun vecteur propre gauche n'est calculé.
    • 'V' : Les vecteurs propres gauches sont calculés.
  • JOBVR : Indique s'il faut calculer les vecteurs propres droits.
    • 'N' : Aucun vecteur propre droit n'est calculé.
    • 'V' : Les vecteurs propres droits sont calculés.
  • N : La taille de la matrice.
  • A : La première matrice.
  • LDA : Le premier indice de ligne de A.
  • B : La deuxième matrice.
  • LDB : Le premier indice de ligne de B.
  • ALPHA : Un tableau de taille N pour stocker les premières composantes des valeurs propres.
  • BETA : Un tableau de taille N pour stocker les deuxièmes composantes des valeurs propres.
  • VL : La matrice des vecteurs propres gauches.
  • LDVL : Le premier indice de ligne de VL.
  • VR : La matrice des vecteurs propres droits.
  • LDVR : Le premier indice de ligne de VR.
  • WORK : Un tableau de travail. La taille minimale est déterminée par LWORK.
  • LWORK : La taille du tableau WORK.
  • RWORK : Un tableau de travail réel.
  • INFO : Renvoie 0 si tout s'est bien passé, un code d'erreur sinon.
