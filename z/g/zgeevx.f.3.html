sous-routine zgeevx (caractère balanc, caractère jobvl, caractère jobvr, caractère sense, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) w, complexe*16, dimension( ldvl, * ) vl, entier ldvl, complexe*16, dimension( ldvr, * ) vr, entier ldvr, entier ilo, entier ihi, double précision, dimension( * ) scale, double précision abnrm, double précision, dimension( * ) rconde, double précision, dimension( * ) rcondv, complexe*16, dimension( * ) work, entier lwork, double précision, dimension( * ) rwork, entier info)

ZGEEVX calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour les matrices GE

Objectif :

!>
!> ZGEEVX calcule pour une matrice complexe non symétrique A de taille N x N,
!> les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits.
!>
!> Optionnellement, il calcule une transformation d'équilibrage pour améliorer
!> le conditionnement des valeurs propres et des vecteurs propres (ILO, IHI,
!> SCALE et ABNRM), les inverses des nombres de conditionnement des valeurs propres
!> (RCONDE), et les inverses des nombres de conditionnement des vecteurs propres droits
!> (RCONDV).
!>
!> Le vecteur propre droit v(j) de A satisfait
!>                  A * v(j) = lambda(j) * v(j)
!> où lambda(j) est sa valeur propre.
!> Le vecteur propre gauche u(j) de A satisfait
!>               u(j)**H * A = lambda(j) * u(j)**H
!> où u(j)**H désigne la transposée conjuguée de u(j).
!>
!> Les vecteurs propres calculés sont normalisés pour avoir une norme euclidienne
!> égale à 1 et un composant réel maximum.
!>
!> L'équilibrage d'une matrice signifie la permutation des lignes et des colonnes pour la rendre plus proche d'une matrice triangulaire supérieure, et l'application d'une transformation de similarité diagonale D * A * D**(-1), où D est une matrice diagonale, pour rendre les normes de ses lignes et colonnes plus proches et les nombres de conditionnement de ses valeurs propres et vecteurs propres plus petits. Les inverses des nombres de conditionnement calculés correspondent à la matrice équilibrée. La permutation des lignes et des colonnes ne changera pas les nombres de conditionnement (en arithmétique exacte), mais la mise à l'échelle diagonale le fera. Pour plus d'explications sur l'équilibrage, voir la section 4.10.2 du Guide des utilisateurs de LAPACK.
!>

Paramètres

BALANC 
!>          BALANC est CHARACTER*1
!>          Indique comment la matrice d'entrée doit être mise à l'échelle
!>          diagonale et/ou permutée pour améliorer le conditionnement de ses
!>          valeurs propres.
!>          = 'N' : Ne pas mettre à l'échelle ou permuter diagonalement ;
!>          = 'P' : Effectuer des permutations pour rendre la matrice plus proche
!>                 d'une matrice triangulaire supérieure. Ne pas mettre à l'échelle diagonalement ;
!>          = 'S' : Mettre à l'échelle diagonalement la matrice, c'est-à-dire remplacer A par
!>                 D*A*D**(-1), où D est une matrice diagonale choisie
!>                 pour rendre les lignes et les colonnes de A plus égales en norme. Ne pas permuter ;
!>          = 'B' : Mettre à l'échelle diagonalement et permuter A.
!>
!>          Les inverses des nombres de conditionnement calculés seront pour la matrice
!>          après équilibrage et/ou permutation. Les permutations ne changent pas
!>          les nombres de conditionnement (en arithmétique exacte), mais l'équilibrage le fait.
!>

JOBVL

!>          JOBVL est CHARACTER*1
!>          = 'N' : les vecteurs propres gauches de A ne sont pas calculés ;
!>          = 'V' : les vecteurs propres gauches de A sont calculés.
!>          Si SENSE = 'E' ou 'B', JOBVL doit être = 'V'.
!>

JOBVR

!>          JOBVR est CHARACTER*1
!>          = 'N' : les vecteurs propres droits de A ne sont pas calculés ;
!>          = 'V' : les vecteurs propres droits de A sont calculés.
!>          Si SENSE = 'E' ou 'B', JOBVR doit être = 'V'.
!>

SENSE

!>          SENSE est CHARACTER*1
!>          Détermine quels inverses de nombres de conditionnement sont calculés.
!>          = 'N' : Aucun n'est calculé ;
!>          = 'E' : Calculé pour les valeurs propres uniquement ;
!>          = 'V' : Calculé pour les vecteurs propres droits uniquement ;
!>          = 'B' : Calculé pour les valeurs propres et les vecteurs propres droits.
!>
!>          Si SENSE = 'E' ou 'B', les vecteurs propres gauches et droits
!>          doivent également être calculés (JOBVL = 'V' et JOBVR = 'V').
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          En entrée, la matrice A de taille N x N.
!>          En sortie, A a été écrasé. Si JOBVL = 'V' ou
!>          JOBVR = 'V', A contient la forme de Schur de la version
!>          équilibrée de la matrice A.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

W

!>          W est un tableau COMPLEX*16, de dimension (N)
!>          W contient les valeurs propres calculées.
!>

VL

!>          VL est un tableau COMPLEX*16, de dimension (LDVL,N)
!>          Si JOBVL = 'V', les vecteurs propres gauches u(j) sont stockés un
!>          par un dans les colonnes de VL, dans le même ordre
!>          que leurs valeurs propres.
!>          Si JOBVL = 'N', VL n'est pas référencé.
!>          u(j) = VL(:,j), la j-ième colonne de VL.
!>

LDVL

!>          LDVL est un ENTIER
!>          La dimension principale du tableau VL. LDVL >= 1 ; si
!>          JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR est un tableau COMPLEX*16, de dimension (LDVR,N)
!>          Si JOBVR = 'V', les vecteurs propres droits v(j) sont stockés un
!>          par un dans les colonnes de VR, dans le même ordre
!>          que leurs valeurs propres.
!>          Si JOBVR = 'N', VR n'est pas référencé.
!>          v(j) = VR(:,j), la j-ième colonne de VR.
!>

LDVR

!>          LDVR est un ENTIER
!>          La dimension principale du tableau VR. LDVR >= 1 ; si
!>          JOBVR = 'V', LDVR >= N.
!>

ILO

!>          ILO est un ENTIER
!>

IHI

!>          IHI est un ENTIER
!>          ILO et IHI sont des valeurs entières déterminées lors de l'équilibrage de A.
!>          La matrice équilibrée A(i,j) = 0 si I > J et
!>          J = 1,...,ILO-1 ou I = IHI+1,...,N.
!>

SCALE

!>          SCALE est un tableau DOUBLE PRÉCISION, de dimension (N)
!>          Détails des permutations et des facteurs de mise à l'échelle appliqués
!>          lors de l'équilibrage de A. Si P(j) est l'indice de la ligne et de la colonne
!>          échangée avec la ligne et la colonne j, et D(j) est le facteur de
!>          mise à l'échelle appliqué à la ligne et à la colonne j, alors
!>          SCALE(J) = P(J),    pour J = 1,...,ILO-1
!>                   = D(J),    pour J = ILO,...,IHI
!>                   = P(J)     pour J = IHI+1,...,N.
!>          L'ordre dans lequel les échanges sont effectués est N à IHI+1,
!>          puis 1 à ILO-1.
!>

ABNRM

!>          ABNRM est DOUBLE PRÉCISION
!>          La norme 1 de la matrice équilibrée (la somme maximale
!>          des valeurs absolues des éléments de chaque colonne).
!>

RCONDE

!>          RCONDE est un tableau DOUBLE PRÉCISION, de dimension (N)
!>          RCONDE(j) est l'inverse du nombre de conditionnement de la j-ième
!>          valeur propre.
!>

NAME

zgeevx

general complex-to-complex advanced eigenvalue and eigenvector routine

SYNOPSIS

  SUBROUTINE ZGEEVX(
        PATH,       COMPZ,      ORDER,      JL,         JR,
        SENSE,      N,          A,          LDA,        VL,
        LDA,        VR,         LDA,        LOE,        S       ,
        RCONDV,     WORK,       LWORK,      RWORK,      INFO )
    CHARACTER      PATH, COMPZ, ORDER, JL, JR, SENSE
    INTEGER        N, LDA, LWORK, INFO
    COMPLEX*16     A( LDA, * ), VL( LDA, * ), VR( LDA, * )
    COMPLEX*16     WORK( * )
    DOUBLE         PRECISION LOE( * ), S( * ), RCONDV( * ), RWORK( * )

Function/Subroutine Documentation

zgeevx computes the eigenvalues and, optionally, the left and right eigenvectors for a general complex matrix. It also computes a condition number for the matrix A, and condition numbers for the individual eigenvalues and eigenvectors.

Arguments:

PATH
CHARACTER*1. Path of the singular value decomposition.
COMPZ
CHARACTER*1. Flag indicating whether to compute eigenvectors.
ORDER
CHARACTER*1. Flag indicating the order of the eigenvalues.
JL
CHARACTER*1. Flag indicating whether to compute left eigenvectors.
JR
CHARACTER*1. Flag indicating whether to compute right eigenvectors.
SENSE
CHARACTER*1. Flag indicating which condition numbers to compute.
N
INTEGER. The order of the matrix A.
A
COMPLEX*16 array, dimension (LDA, N). On entry, the N-by-N general complex matrix A. On exit, A is overwritten by information about the Schur decomposition.
LDA
INTEGER. The leading dimension of the arrays A, VL, and VR.
VL
COMPLEX*16 array, dimension (LDA, N). On exit, if JL = 'V' or 'B', VL contains the left eigenvectors of A.
VR
COMPLEX*16 array, dimension (LDA, N). On exit, if JR = 'V' or 'B', VR contains the right eigenvectors of A.
LOE
DOUBLE PRECISION array, dimension (N). On exit, if SENSE = 'V' or 'B', LOE(j) is the condition number of the j-th eigenvalue.
S
DOUBLE PRECISION array, dimension (N). On exit, if SENSE = 'E' or 'B', S(j) is the condition number of the j-th eigenvalue.
RCONDV
DOUBLE PRECISION array, dimension (N). RCONDV(j) is the reciprocal condition number of the j-th right eigenvector.
WORK
COMPLEX*16 array, dimension (MAX(1,LWORK)). On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
LWORK
INTEGER. The dimension of the array WORK. If SENSE = 'N' or 'E', LWORK >= max(1,2*N), and if SENSE = 'V' or 'B', LWORK >= N*N+2*N. For good performance, LWORK must generally be larger. If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.
RWORK
DOUBLE PRECISION array, dimension (2*N).
INFO
INTEGER. = 0: successful exit < 0: if INFO = -i, the i-th argument had an illegal value. > 0: if INFO = i, the QR algorithm failed to compute all the eigenvalues, and no eigenvectors or condition numbers have been computed; elements 1:ILO-1 and i+1:N of W contain eigenvalues which have converged.
