Documentation de la fonction/sous-programme

sous-programme zgesvx (caractère fact, caractère trans, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldaf, * ) af, entier ldaf, entier, dimension( * ) ipiv, caractère equed, double précision, dimension( * ) r, double précision, dimension( * ) c, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldx, * ) x, entier ldx, double précision rcond, double précision, dimension( * ) ferr, double précision, dimension( * ) berr, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier info)

ZGESVX calcule la solution du système d'équations linéaires A * X = B pour les matrices GE

Objectif :

!>
!> ZGESVX utilise la factorisation LU pour calculer la solution d'un système
!> linéaire complexe :
!>    A * X = B,
!> où A est une matrice N-par-N et X et B sont des matrices N-par-NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de la condition
!> sont également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour
!>    équilibrer le système :
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle
!>    de la matrice A, mais si l'équilibrage est utilisé, A est
!>    remplacée par diag(R)*A*diag(C) et B par diag(R)*B (si TRANS='N')
!>    ou diag(C)*B (si TRANS = 'T' ou 'C').
!>
!> 2. Si FACT = 'N' ou 'E', la décomposition LU est utilisée pour factoriser
!>    la matrice A (après équilibrage si FACT = 'E') en :
!>       A = P * L * U,
!>    où P est une matrice de permutation, L est une matrice triangulaire
!>    inférieure unitaire, et U est triangulaire supérieure.
!>
!> 3. Si certains U(i,i)=0, donc U est singulier, la routine
!>    retourne avec INFO = i. Sinon, la forme factorisée de A est utilisée
!>    pour estimer le nombre de condition de la matrice A. Si l'inverse
!>    du nombre de condition est inférieur à la précision machine,
!>    INFO = N+1 est retourné comme avertissement, mais la routine continue
!>    à résoudre pour X et calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 5. Un raffinement itératif est appliqué pour améliorer la solution calculée
!>    et calculer les bornes d'erreur et les estimations d'erreur arrière
!>    pour celle-ci.
!>
!> 6. Si l'équilibrage a été utilisé, la matrice X est pré-multipliée par
!>    diag(C) (si TRANS = 'N') ou diag(R) (si TRANS = 'T' ou 'C') de sorte
!>    qu'elle résolve le système original avant équilibrage.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est fournie
!>          en entrée, et si ce n'est pas le cas, si la matrice A doit être
!>          équilibrée avant d'être factorisée.
!>          = 'F':  En entrée, AF et IPIV contiennent la forme factorisée de A.
!>                  Si EQUED n'est pas 'N', la matrice A a été
!>                  équilibrée avec les facteurs d'échelle donnés par R et C.
!>                  A, AF et IPIV ne sont pas modifiés.
!>          = 'N':  La matrice A sera copiée dans AF et factorisée.
!>          = 'E':  La matrice A sera équilibrée si nécessaire, puis
!>                  copiée dans AF et factorisée.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N':  A * X = B     (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Conjuguée transposée)
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          En entrée, la matrice A de taille N-par-N. Si FACT = 'F' et EQUED
!>          n'est pas 'N', alors A doit avoir été équilibrée par les facteurs
!>          d'échelle de R et/ou C. A n'est pas modifié si FACT = 'F' ou
!>          'N', ou si FACT = 'E' et EQUED = 'N' en sortie.
!>
!>          En sortie, si EQUED .ne. 'N', A est mise à l'échelle comme suit :
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>          Si FACT = 'F', alors AF est un argument d'entrée et contient en
!>          entrée les facteurs L et U de la factorisation
!>          A = P*L*U calculée par ZGETRF. Si EQUED .ne. 'N', alors
!>          AF est la forme factorisée de la matrice A équilibrée.
!>
!>          Si FACT = 'N', alors AF est un argument de sortie et retourne en
!>          sortie les facteurs L et U de la factorisation A = P*L*U
!>          de la matrice originale A.
!>
!>          Si FACT = 'E', alors AF est un argument de sortie et retourne en
!>          sortie les facteurs L et U de la factorisation A = P*L*U
!>          de la matrice équilibrée A (voir la description de A pour
!>          la forme de la matrice équilibrée).
!>

LDAF

!>          LDAF est INTEGER
!>          La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et contient en
!>          entrée les indices de pivot de la factorisation A = P*L*U
!>          calculée par ZGETRF ; la ligne i de la matrice a été échangée
!>          avec la ligne IPIV(i).
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et contient en
!>          sortie les indices de pivot de la factorisation A = P*L*U
!>          de la matrice originale A.
!>
!>          Si FACT = 'E', alors IPIV est un argument de sortie et contient en
!>          sortie les indices de pivot de la factorisation A = P*L*U
!>          de la matrice équilibrée A.
!>

EQUED

!>          EQUED est CHARACTER*1
!>          Spécifie la forme d'équilibrage qui a été effectuée.
!>          = 'N':  Aucun équilibrage (toujours vrai si FACT = 'N').
!>          = 'R':  Équilibrage des lignes, c'est-à-dire que A a été pré-multipliée
!>                  par diag(R).
!>          = 'C':  Équilibrage des colonnes, c'est-à-dire que A a été post-multipliée
!>                  par diag(C).
!>          = 'B':  Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>                  remplacée par diag(R) * A * diag(C).
!>          EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un
!>          argument de sortie.
!>

R

!>          R est un tableau REAL*8, dimension (*)
!>          Si EQUED = 'R' ou 'B', R contient les facteurs d'échelle des lignes
!>          utilisés pour équilibrer la matrice A. Tant que FACT = 'F', R est un
!>          argument d'entrée.
!>
!>          Si FACT = 'E', R est un argument de sortie contenant les facteurs
!>          d'échelle des lignes (si l'équilibrage des lignes a été effectué).
!>

C

!>          C est un tableau REAL*8, dimension (*)
!>          Si EQUED = 'C' ou 'B', C contient les facteurs d'échelle des colonnes
!>          utilisés pour équilibrer la matrice A. Tant que FACT = 'F', C est un
!>          argument d'entrée.
!>
!>          Si FACT = 'E', C est un argument de sortie contenant les facteurs
!>          d'échelle des colonnes (si l'équilibrage des colonnes a été effectué).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          Sur l'entrée, le membre de droite de la matrice d'équations
!>          linéaires.
!>
!>          Sur la sortie, si la mise à l'échelle est effectuée, B est mise à
!>          l'échelle comme suit :
!>          EQUED = 'R':  B := diag(R)*B
!>          EQUED = 'C':  B := B * diag(C)
!>          EQUED = 'B':  B := diag(R)*B*diag(C)
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>          Sur la sortie, la solution de l'équation A*X = B. La forme de X
!>          dépend de la valeur de EQUED et TRANS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL*8
!>          L'inverse du nombre de condition de la matrice A, estimé par la
!>          routine. Les matrices sont bien conditionnées si RCOND est proche
!>          de un, et mal conditionnées si RCOND est proche de zéro.
!>

FERR

!>          FERR est un tableau REAL*8, dimension (*)
!>          La borne d'erreur avant calculée pour chaque colonne de X, FERR(j)
!>          = norm(X*j - b(j)) / norm(b(j)). Le vecteur b(j) est le vecteur
!>          initial avant mise à l'échelle.
!>

BERR

!>          BERR est un tableau REAL*8, dimension (*)
!>          L'erreur arrière estimée pour chaque colonne de X, BERR(j), par
!>          rapport à la norme de A(j), l'élément j-ième de la colonne de A,
!>          c'est-à-dire BERR(j) = norm( U(j) ) / ( norm( A(j) )*norm( X(j) ) ).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (*)
!>          Sur la sortie, WORK(1) contient la norme déterminée par l'appelant
!>          de l'une des fonctions de norme de matrice.
!>

RWORK

!>          RWORK est un tableau REAL*8, dimension (*)
!>          Un tableau de travail, de dimension au moins (N) pour le calcul
!>          du raffinement itératif et des bornes d'erreur.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  Problème résolu avec succès.
!>          < 0 :  Si INFO = -i, l'argument i-ème avait une valeur interdite.
!>          > 0 :  Si INFO = i, et i <= N, alors U(i,i) est nul. Le facteur
!>                 U est singulier, et l'unique solution n'existe pas.
!>                 Si INFO = N+1, U est non singulier, mais RCOND est très
!>                 petit. Ce qui signifie que la matrice est singulière ou
!>                 quasiment singulière.
!>

NAME

ZGESVX - the general complex dense matrix
ZGESVX uses the full pivoting LU factorization of A to solve the
complex system of linear equations A*X = B,

SYNOPSIS

SUBROUTINE ZGESVX(
FACT, TRANS, EQUED, N, NRHS, A, LDA, AF, LDAF,
IPIV,
EQUED, R, C, B, LDB, X, LDX, RCOND, FERR, BERR,
WORK, RWORK, INFO
)

CHARACTER *1

INTEGER N, NRHS, LDA, LDAF, LDB, LDX, INFO

INTEGER IPIV( N )

COMPLEX*16 A( LDA, * ), AF( LDAF, * ), B( LDB, * ), X( LDX, * )

COMPLEX*16 WORK( * )

DOUBLE PRECISION R( N ), C( N ), RCOND, FERR( NRHS ), BERR( NRHS )

DOUBLE PRECISION RWORK( * )

Function/Subroutine Documentation

FACT

CHARACTER*1 FACT
        FACT is CHARACTER*1
        On entry, FACT specifies the form of the problem to be solved.
        = 'E':  The driver routine computes the equilibration factors
                of A and estimates the condition number of the
                (equilibrated) matrix A.      
        = 'N':  The driver routine does not compute the
                equilibration factors.  A is assumed to be already
                equilibrated and the preconditioner is not computed.
        = 'F':  The driver routine computes the equilibration factors
                of A.

TRANS

CHARACTER*1 TRANS
        TRANS is CHARACTER*1
        Specifies the form of the system of equations:
        = 'N':  A*X = B       (No transpose)
        = 'T':  A**T*X = B     (Transpose)
        = 'C':  A**H*X = B     (Conjugate transpose)

EQUED

CHARACTER*1 EQUED
        EQUED is CHARACTER*1
        Specifies the types of equilibration that were done:
        = 'N':  No equilibration was performed, or equilibration was not
                needed.
        = 'R':  Row equilibration was performed, i.e., A was replaced by
                diag(R)*A.
        = 'C':  Column equilibration was performed, i.e., A was replaced by
                A*diag(C).
        = 'B':  Both row and column equilibration were performed, i.e., A
                was replaced by diag(R)*A*diag(C).

N

INTEGER N
        N is INTEGER
        The order of the matrix A.  N >= 0.

NRHS

INTEGER NRHS
        NRHS is INTEGER
        The number of right hand sides, i.e., the number of columns of
        the matrices B and X.  NRHS >= 0.

A

COMPLEX*16 A( LDA, * )
        A is COMPLEX*16 array, dimension (LDA, N)
        On entry, the N-by-N coefficient matrix A.
        On exit, if ..., the contents of A are overwritten by the LU
        factorization of A unless FACT = 'N' and EQUED = 'N'.

LDA

INTEGER LDA
        LDA is INTEGER
        The leading dimension of A.  LDA >= max(1,N).

AF

COMPLEX*16 AF( LDAF, * )
        AF is COMPLEX*16 array, dimension (LDAF, N)
        On entry, the N-by-N coefficient matrix A.
        On exit, the factors L and U from the factorization
        A = P*L*U; the factor P is implicitly given by the pivoting
        in the array IPIV.

LDAF

INTEGER LDAF
        LDAF is INTEGER
        The leading dimension of the array AF. LDAF >= max(1,N).

IPIV

INTEGER IPIV( N )
        IPIV is INTEGER array, dimension (N)
        The pivot indices of the factorization; for at each i, the pivot
        in column i is in row IPIV(i).

R

DOUBLE PRECISION R( N )
        R is DOUBLE PRECISION array, dimension (N)
        The row scale factors for A.  If EQUED = 'R' or 'B', A is
        multiplied on the left by diag(R); if EQUED = 'N' or 'C', R
        is not accessed.  R is an input argument if FACT = 'F';
        otherwise, R is an output argument.  If FACT = 'F' and
        EQUED = 'R' or 'B', each element of R must be positive.

C

DOUBLE PRECISION C( N )
        C is DOUBLE PRECISION array, dimension (N)
        The column scale factors for A.  If EQUED = 'C' or 'B', A is
        multiplied on the right by diag(C); if EQUED = 'N' or 'R', C
        is not accessed.  C is an input argument if FACT = 'F';
        otherwise, C is an output argument.  If FACT = 'F' and
        EQUED = 'C' or 'B', each element of C must be positive.

B

COMPLEX*16 B( LDB, * )
        B is COMPLEX*16 array, dimension (LDB,NRHS)
        On entry, the N-by-NRHS right hand side matrix B.
        On exit,
        if EQUED = 'N', B is not modified;
        if TRANS = 'N' and EQUED = 'R' or 'B', B is overwritten by
        diag(R)*B;
        if TRANS = 'T' or 'C' and EQUED = 'C' or 'B', B is
        overwritten by diag(C)*B.

LDB

INTEGER LDB
        LDB is INTEGER
        The leading dimension of the array B.  LDB >= max(1,N).

X

COMPLEX*16 X( LDX, * )
        X is COMPLEX*16 array, dimension (LDX,NRHS)
        If INFO = 0 or INFO = N+1, the N-by-NRHS solution matrix X
        to the original system of equations.  Note that A and B are
        modified on exit if EQUED .ne. 'N', and the solution to the
        equilibrated system is inv(diag(C))*X if TRANS = 'N' and
        EQUED = 'C' or 'B', or inv(diag(R))*X if TRANS = 'T' or 'C'
        and EQUED = 'R' or 'B'.

LDX

INTEGER LDX
        LDX is INTEGER
        The leading dimension of the array X.  LDX >= max(1,N).

RCOND

DOUBLE PRECISION RCOND
        RCOND is DOUBLE PRECISION
        The estimate of the reciprocal condition number of the matrix
        A after equilibration (if done).  If RCOND is less than the
        machine precision (in particular, if RCOND = 0), the matrix
        is singular to working precision.  This condition is
        indicated by a return code of INFO > 0.

FERR

DOUBLE PRECISION FERR( NRHS )
        FERR is DOUBLE PRECISION array, dimension (NRHS)
        The estimated forward error bound for each solution vector
        X(j) (the j-th column of the solution matrix X).
        If XTRUE is the true solution corresponding to X(j), FERR(j)
        is an estimated upper bound for the magnitude of the largest
        element in (X(j) - XTRUE) divided by the magnitude of the
        largest element in X(j).  The estimate is as reliable as
        the estimate for RCOND, and is almost always a slight
        overestimate of the true error.

BERR

DOUBLE PRECISION BERR( NRHS )
        BERR is DOUBLE PRECISION array, dimension (NRHS)
        The componentwise relative backward error of each solution
        vector X(j) (i.e., the smallest relative change in
        any element of A or B that makes X(j) an exact solution).

WORK

COMPLEX*16 WORK( * )
        WORK is COMPLEX*16 array, dimension (2*N)

RWORK

DOUBLE PRECISION RWORK( * )
        RWORK is DOUBLE PRECISION array, dimension (MAX(1,2*N))
        On exit, RWORK(1) contains the reciprocal pivot growth
        factor norm(A)/norm(U). The  norm is
        used. If RWORK(1) is much less than 1, then the stability
        of the LU factorization of the (equilibrated) matrix A
        could be poor. This also means that the solution X, condition
        estimator RCOND, and forward error bound FERR could be
        unreliable. If factorization fails with 0<INFO<=N, then
        RWORK(1) contains the reciprocal pivot growth factor for the
        leading INFO columns of A.

INFO

INTEGER INFO
        INFO is INTEGER
        = 0:  successful exit
        < 0:  if INFO = -i, the i-th argument had an illegal value
        > 0:  if INFO = i, and i is
                <= N:  U(i,i) is exactly zero.  The factorization has
                       been completed, but the factor U is exactly
                       singular, so the solution and error bounds
                       could not be computed. RCOND = 0 is returned.
                = N+1: U is nonsingular, but RCOND is less than machine
                       precision, meaning that the matrix is singular
                       to working precision.  Nevertheless, the
                       solution and error bounds are computed because
                       there are a number of situations where the
                       computed solution can be more accurate than the
                       value of RCOND would suggest.
