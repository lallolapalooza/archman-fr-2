Documentation de la fonction/sous-programme

sous-programme zget51 (integer itype, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, double precision result)

ZGET51

But :

!>
!>      ZGET51  vérifie généralement une décomposition de la forme
!>
!>              A = U B V**H
!>
!>      où **H signifie conjugué transposé et U et V sont unitaires.
!>
!>      Spécifiquement, si ITYPE=1
!>
!>              RESULT = | A - U B V**H | / ( |A| n ulp )
!>
!>      Si ITYPE=2, alors :
!>
!>              RESULT = | A - B | / ( |A| n ulp )
!>
!>      Si ITYPE=3, alors :
!>
!>              RESULT = | I - U U**H | / ( n ulp )
!>

Paramètres

ITYPE 
!>          ITYPE est un entier (INTEGER)
!>          Spécifie le type de tests à effectuer.
!>          =1 : RESULT = | A - U B V**H | / ( |A| n ulp )
!>          =2 : RESULT = | A - B | / ( |A| n ulp )
!>          =3 : RESULT = | I - U U**H | / ( n ulp )
!>

N

!>          N est un entier (INTEGER)
!>          La taille de la matrice. Si elle est nulle, ZGET51 ne fait rien.
!>          Elle doit être supérieure ou égale à zéro.
!>

A

!>          A est un tableau de type COMPLEX*16, dimension (LDA, N)
!>          La matrice originale (non factorisée).
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale de A. Elle doit être supérieure ou égale à 1
!>          et supérieure ou égale à N.
!>

B

!>          B est un tableau de type COMPLEX*16, dimension (LDB, N)
!>          La matrice factorisée.
!>

LDB

!>          LDB est un entier (INTEGER)
!>          La dimension principale de B. Elle doit être supérieure ou égale à 1
!>          et supérieure ou égale à N.
!>

U

!>          U est un tableau de type COMPLEX*16, dimension (LDU, N)
!>          La matrice unitaire du côté gauche de la
!>          décomposition.
!>          Non référencée si ITYPE=2
!>

LDU

!>          LDU est un entier (INTEGER)
!>          La dimension principale de U. LDU doit être supérieure ou égale à N et
!>          supérieure ou égale à 1.
!>

V

!>          V est un tableau de type COMPLEX*16, dimension (LDV, N)
!>          La matrice unitaire du côté gauche de la
!>          décomposition.
!>          Non référencée si ITYPE=2
!>

LDV

!>          LDV est un entier (INTEGER)
!>          La dimension principale de V. LDV doit être supérieure ou égale à N et
!>          supérieure ou égale à 1.
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, dimension (2*N**2)
!>

RWORK

!>          RWORK est un tableau de type DOUBLE PRECISION, dimension (N)
!>

RESULT

!>          RESULT est un DOUBLE PRECISION
!>          Les valeurs calculées par le test spécifié par ITYPE. La
!>          valeur est actuellement limitée à 1/ulp, pour éviter le débordement.
!>          Les erreurs sont signalées par RESULT=10/ulp.
!>
