Documentation de la fonction/sous-routine

sous-routine zgtt01 (integer n, complex*16, dimension( * ) dl, complex*16, dimension( * ) d, complex*16, dimension( * ) du, complex*16, dimension( * ) dlf, complex*16, dimension( * ) df, complex*16, dimension( * ) duf, complex*16, dimension( * ) du2, integer, dimension( * ) ipiv, complex*16, dimension( ldwork, * ) work, integer ldwork, double precision, dimension( * ) rwork, double precision resid)

ZGTT01

But:

!>
!> ZGTT01 reconstruit une matrice tridiagonale A à partir de sa factorisation LU
!> et calcule le résidu
!>    norme(L*U - A) / ( norme(A) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice A.  N >= 0.
!>

DL

!>          DL est un tableau de complexes*16 (COMPLEX*16), dimension (N-1)
!>          Les éléments sous-diagonaux (n-1) de A.
!>

D

!>          D est un tableau de complexes*16 (COMPLEX*16), dimension (N)
!>          Les éléments diagonaux de A.
!>

DU

!>          DU est un tableau de complexes*16 (COMPLEX*16), dimension (N-1)
!>          Les éléments super-diagonaux (n-1) de A.
!>

DLF

!>          DLF est un tableau de complexes*16 (COMPLEX*16), dimension (N-1)
!>          Les multiplicateurs (n-1) qui définissent la matrice L à partir de
!>          la factorisation LU de A.
!>

DF

!>          DF est un tableau de complexes*16 (COMPLEX*16), dimension (N)
!>          Les éléments diagonaux (n) de la matrice triangulaire supérieure U issue
!>          de la factorisation LU de A.
!>

DUF

!>          DUF est un tableau de complexes*16 (COMPLEX*16), dimension (N-1)
!>          Les éléments (n-1) de la première super-diagonale de U.
!>

DU2

!>          DU2 est un tableau de complexes*16 (COMPLEX*16), dimension (N-2)
!>          Les éléments (n-2) de la deuxième super-diagonale de U.
!>

IPIV

!>          IPIV est un tableau d'entiers (INTEGER), dimension (N)
!>          Les indices de pivot; pour 1 <= i <= n, la ligne i de la matrice a
!>          été échangée avec la ligne IPIV(i).  IPIV(i) sera toujours égal à
!>          i ou i+1; IPIV(i) = i indique qu'aucun échange de ligne n'a été
!>          nécessaire.
!>

WORK

!>          WORK est un tableau de complexes*16 (COMPLEX*16), dimension (LDWORK,N)
!>

LDWORK

!>          LDWORK est un entier (INTEGER)
!>          La dimension principale du tableau WORK.  LDWORK >= max(1,N).
!>

RWORK

!>          RWORK est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>

RESID

!>          RESID est un double précision (DOUBLE PRECISION)
!>          Le résidu mis à l'échelle:  norme(L*U - A) / (norme(A) * EPS)
!>
