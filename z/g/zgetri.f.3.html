Documentation de la fonction/sous-programme

sous-programme zgetri (entier n, complexe*16, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, complexe*16, dimension( * ) work, entier lwork, entier info)

ZGETRI

But :

!>
!> ZGETRI calcule l'inverse d'une matrice à l'aide de la factorisation LU
!> calculée par ZGETRF.
!>
!> Cette méthode inverse U puis calcule inv(A) en résolvant le système
!> inv(A)*L = inv(U) pour inv(A).
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, les facteurs L et U de la factorisation
!>          A = P*L*U calculée par ZGETRF.
!>          À la sortie, si INFO = 0, l'inverse de la matrice originale A.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N)
!>          Les indices de pivot de ZGETRF ; pour 1<=i<=N, la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO=0, alors WORK(1) contient la valeur LWORK optimale.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.  LWORK >= max(1,N).
!>          Pour une performance optimale, LWORK >= N*NB, où NB est
!>          la taille de bloc optimale retournée par ILAENV.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, U(i,i) est exactement zéro ; la matrice est
!>                singulière et son inverse n'a pas pu être calculée.
!>
