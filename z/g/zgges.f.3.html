sous-routine zgges (character jobvsl, character jobvsr, character sort, external selctg, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, integer sdim, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( ldvsl, * ) vsl, integer ldvsl, complex*16, dimension( ldvsr, * ) vsr, integer ldvsr, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, logical, dimension( * ) bwork, integer info)

ZGGES calcule les valeurs propres, la forme de Schur, et, optionnellement, la matrice des vecteurs de Schur pour les matrices GE

Objectif :

!>
!> ZGGES calcule pour une paire de matrices complexes N par N non symétriques
!> (A,B), les valeurs propres généralisées, la forme de Schur généralisée
!> (S, T), et optionnellement les vecteurs de Schur gauches et/ou droits (VSL
!> et VSR). Ceci donne la factorisation de Schur généralisée
!>
!>         (A,B) = ( (VSL)*S*(VSR)**H, (VSL)*T*(VSR)**H )
!>
!> où (VSR)**H est la transposée conjuguée de VSR.
!>
!> Optionnellement, elle ordonne également les valeurs propres de sorte qu'un
!> cluster sélectionné de valeurs propres apparaisse dans les blocs diagonaux
!> principaux de la matrice triangulaire supérieure S et de la matrice
!> triangulaire supérieure T. Les colonnes principales de VSL et VSR forment
!> alors une base unitaire pour les sous-espaces gauches et droits
!> correspondants (sous-espaces déflationnés).
!>
!> (Si seules les valeurs propres généralisées sont nécessaires, utiliser le
!> pilote ZGGEV à la place, qui est plus rapide.)
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un rapport alpha/beta = w, tel que A - w*B est singulière. Elle est
!> généralement représentée par la paire (alpha,beta), car il existe une
!> interprétation raisonnable pour beta=0, et même pour les deux étant zéro.
!>
!> Une paire de matrices (S,T) est en forme de Schur complexe généralisée si S
!> et T sont triangulaires supérieures et, de plus, les éléments diagonaux
!> de T sont des nombres réels non négatifs.
!>

Paramètres

JOBVSL 
!>          JOBVSL est CHARACTER*1
!>          = 'N':  ne pas calculer les vecteurs de Schur gauches ;
!>          = 'V':  calculer les vecteurs de Schur gauches.
!>

JOBVSR

!>          JOBVSR est CHARACTER*1
!>          = 'N':  ne pas calculer les vecteurs de Schur droits ;
!>          = 'V':  calculer les vecteurs de Schur droits.
!>

SORT

!>          SORT est CHARACTER*1
!>          Spécifie si les valeurs propres doivent être ordonnées sur la
!>          diagonale de la forme de Schur généralisée.
!>          = 'N':  Les valeurs propres ne sont pas ordonnées ;
!>          = 'S':  Les valeurs propres sont ordonnées (voir SELCTG).
!>

SELCTG

!>          SELCTG est une FONCTION LOGIQUE de deux arguments COMPLEX*16
!>          SELCTG doit être déclarée EXTERNE dans la sous-routine appelante.
!>          Si SORT = 'N', SELCTG n'est pas référencée.
!>          Si SORT = 'S', SELCTG est utilisée pour sélectionner les valeurs propres à trier
!>          en haut à gauche de la forme de Schur.
!>          Une valeur propre ALPHA(j)/BETA(j) est sélectionnée si
!>          SELCTG(ALPHA(j),BETA(j)) est vrai.
!>
!>          Notez qu'une valeur propre complexe sélectionnée peut ne plus satisfaire
!>          SELCTG(ALPHA(j),BETA(j)) = .TRUE. après ordonnancement, puisque
!>          l'ordonnancement peut modifier la valeur des valeurs propres
!>          complexes (en particulier si la valeur propre est mal conditionnée),
!>          dans ce cas INFO est mis à N+2 (Voir INFO ci-dessous).
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A, B, VSL et VSR.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>          En entrée, la première de la paire de matrices.
!>          En sortie, A a été écrasée par sa forme de Schur généralisée
!>          S.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB, N)
!>          En entrée, la deuxième de la paire de matrices.
!>          En sortie, B a été écrasée par sa forme de Schur généralisée
!>          T.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de B.  LDB >= max(1,N).
!>

SDIM

!>          SDIM est INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = nombre de valeurs propres (après ordonnancement)
!>          pour lesquelles SELCTG est vrai.
!>

ALPHA

!>          ALPHA est un tableau COMPLEX*16, dimension (N)
!>

BETA

!>          BETA est un tableau COMPLEX*16, dimension (N)
!>          En sortie,  ALPHA(j)/BETA(j), j=1,...,N, seront les
!>          valeurs propres généralisées.  ALPHA(j), j=1,...,N  et  BETA(j),
!>          j=1,...,N  sont les éléments diagonaux de la forme de Schur complexe (A,B)
!>          renvoyée par ZGGES. Les  BETA(j) seront des réels non négatifs.
!>
!>          Note : les quotients ALPHA(j)/BETA(j) peuvent facilement déborder
!>          ou sous-déborder, et BETA(j) peut même être zéro.  Ainsi, l'utilisateur
!>          doit éviter de calculer naïvement le rapport alpha/beta.
!>          Cependant, ALPHA sera toujours inférieur et généralement
!>          comparable à la norme(A) en magnitude, et BETA toujours inférieur
!>          et généralement comparable à la norme(B).
!>

VSL

!>          VSL est un tableau COMPLEX*16, dimension (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contiendra les vecteurs de Schur gauches.
!>          Non référencé si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL est INTEGER
!>          La dimension principale de la matrice VSL. LDVSL >= 1, et
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR est un tableau COMPLEX*16, dimension (LDVSR,N)
!>          Si JOBVSR = 'V', VSR contiendra les vecteurs de Schur droits.
!>          Non référencé si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR est INTEGER
!>          La dimension principale de la matrice VSR. LDVSR >= 1, et
!>          si JOBVSR = 'V', LDVSR >= N.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie la valeur LWORK optimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.  LWORK >= max(1,2*N).
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête de mémoire est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (8*N)
!>

BWORK

!>          BWORK est un tableau LOGICAL, dimension (N)
!>          Non référencé si SORT = 'N'.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  exécution réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>

NAME

zgges — computes for the generalized eigenvalue problem A*x = lambda*B*x the matrices A and B in generalized Schur form, and optionally the matrix of (row) generalized eigenvalues.

SYNOPSIS

This subroutine computes the generalized Schur decomposition of two complex matrices A and B, and optionally returns the matrix of generalized eigenvalues.

Function/Subroutine Documentation

ZGGES computes the eigenvalues and Schur vectors of a general complex matrix pair (A, B).

This routine uses the QZ algorithm to compute the generalized Schur decomposition of A and B.

The generalized Schur decomposition is defined as:

A = Q*S*ZH
B = Q*T*ZH

where S and T are upper triangular matrices, and Q and Z are unitary matrices. The diagonal entries of S and T specify the generalized eigenvalues lambda = alpha/beta.

The routine also offers the option to sort the eigenvalues in the generalized Schur decomposition so that selected eigenvalues are at the top left of the decomposition. This can be useful for computing condition numbers for eigenvalues and eigenvectors.

Parameters:

A (Input/Output)
COMPLEX*16, dimension (LDA, *). On entry, the matrix A.
On exit, A is overwritten by its generalized Schur form S.
B (Input/Output)
COMPLEX*16, dimension (LDB, *). On entry, the matrix B.
On exit, B is overwritten by its generalized Schur form T.
ALPHA (Output)
COMPLEX*16, dimension (N). The vector ALPHA contains the generalized eigenvalues alpha.
BETA (Output)
COMPLEX*16, dimension (N). The vector BETA contains the generalized eigenvalues beta.
LWORK (Input)
INTEGER. The dimension of the array WORK.
WORK (Workspace)
COMPLEX*16, dimension (LWORK). On exit, WORK(1) contains the optimal value of LWORK.
RWORK (Workspace)
DOUBLE PRECISION. Workspace array of size N.
BWORK (Input)
LOGICAL, dimension (N). This array is used to specify which eigenvalues are to be sorted to the top left of the generalized Schur form.
INFO (Output)
INTEGER.
0
successful exit
>0
If INFO is a positive integer k, then the QZ iteration failed to compute the generalized Schur decomposition. The generalized Schur form and the eigenvalues may not be computed correctly.

More specific error conditions are indicated as follows:

=1,...,N:
The QZ iteration failed. (A,B) are not in Schur form, but ALPHA(j) and BETA(j) should be correct for j=INFO+1,...,N.
>N:
Other than QZ iteration failed in ZHGEQZ =N+2: after reordering, roundoff changed values of some complex eigenvalues so that leading eigenvalues in the Generalized Schur form no longer satisfy SELCTG=.TRUE. This could also be caused due to scaling. =N+3: reordering failed in ZTGSEN.
