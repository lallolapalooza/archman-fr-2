sous-programme zget35 (double precision rmax, integer lmax, integer ninfo, integer knt, integer nin)

ZGET35

But:

!>
!> ZGET35 teste ZTRSYL, une routine pour résoudre l'équation matricielle de Sylvester
!>
!>    op(A)*X + ISGN*X*op(B) = scale*C,
!>
!> A et B sont supposés être sous forme canonique de Schur, op() représente une
!> transposée optionnelle, et ISGN peut être -1 ou +1. Scale est une sortie
!> inférieure ou égale à 1, choisie pour éviter les dépassements dans X.
!>
!> Le code de test vérifie que le résidu suivant est de l'ordre de 1 :
!>
!>    norm(op(A)*X + ISGN*X*op(B) - scale*C) /
!>        (EPS*max(norm(A),norm(B))*norm(X))
!>

Paramètres

RMAX 
!>          RMAX est DOUBLE PRECISION
!>          Valeur du plus grand rapport de test.
!>

LMAX

!>          LMAX est INTEGER
!>          Numéro de l'exemple où le plus grand rapport de test a été atteint.
!>

NINFO

!>          NINFO est INTEGER
!>          Nombre d'exemples où INFO est non nul.
!>

KNT

!>          KNT est INTEGER
!>          Nombre total d'exemples testés.
!>

NIN

!>          NIN est INTEGER
!>          Numéro d'unité logique d'entrée.
!>
