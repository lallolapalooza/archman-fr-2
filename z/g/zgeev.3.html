sous-routine zgeev (caractère jobvl, caractère jobvr, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( * ) w, complexe*16, dimension( ldvl, * ) vl, entier ldvl, complexe*16, dimension( ldvr, * ) vr, entier ldvr, complexe*16, dimension( * ) work, entier lwork, double précision, dimension( * ) rwork, entier info)

ZGEEV calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour les matrices GE

Objectif:

!>
!> ZGEEV calcule pour une matrice complexe non symétrique N par N A, les
!> valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits.
!>
!> Le vecteur propre droit v(j) de A satisfait
!>                  A * v(j) = lambda(j) * v(j)
!> où lambda(j) est sa valeur propre.
!> Le vecteur propre gauche u(j) de A satisfait
!>               u(j)**H * A = lambda(j) * u(j)**H
!> où u(j)**H dénote la transposée conjuguée de u(j).
!>
!> Les vecteurs propres calculés sont normalisés pour avoir une norme euclidienne
!> égale à 1 et un composant réel maximal.
!>

Paramètres

JOBVL 
!>          JOBVL est CHARACTER*1
!>          = 'N': les vecteurs propres gauches de A ne sont pas calculés ;
!>          = 'V': les vecteurs propres gauches de A sont calculés.
!>

JOBVR

!>          JOBVR est CHARACTER*1
!>          = 'N': les vecteurs propres droits de A ne sont pas calculés ;
!>          = 'V': les vecteurs propres droits de A sont calculés.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          En entrée, la matrice N par N A.
!>          En sortie, A a été écrasée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

W

!>          W est un tableau COMPLEX*16, dimension (N)
!>          W contient les valeurs propres calculées.
!>

VL

!>          VL est un tableau COMPLEX*16, dimension (LDVL,N)
!>          Si JOBVL = 'V', les vecteurs propres gauches u(j) sont stockés un par
!>          un dans les colonnes de VL, dans le même ordre que leurs valeurs propres.
!>          Si JOBVL = 'N', VL n'est pas référencé.
!>          u(j) = VL(:,j), la j-ième colonne de VL.
!>

LDVL

!>          LDVL est INTEGER
!>          La dimension principale du tableau VL.  LDVL >= 1 ; si
!>          JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR est un tableau COMPLEX*16, dimension (LDVR,N)
!>          Si JOBVR = 'V', les vecteurs propres droits v(j) sont stockés un par
!>          un dans les colonnes de VR, dans le même ordre que leurs valeurs propres.
!>          Si JOBVR = 'N', VR n'est pas référencé.
!>          v(j) = VR(:,j), la j-ième colonne de VR.
!>

LDVR

!>          LDVR est INTEGER
!>          La dimension principale du tableau VR.  LDVR >= 1 ; si
!>          JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.  LWORK >= max(1,2*N).
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (2*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  si INFO = i, l'algorithme QR a échoué à calculer toutes les
!>                valeurs propres, et aucun vecteur propre n'a été calculé ;
!>                les éléments i+1:N de W contiennent les valeurs propres qui ont
!>                convergé.
!>
