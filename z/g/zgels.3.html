subroutine zgels (trans, m, n, nrhs, a, lda, b, ldb, work, lwork, info)
ZGELS résout des systèmes surdéterminés ou sous-déterminés pour les matrices GE

Documentation de la fonction/sous-programme

sous-routine zgels (caractère trans, entier m, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( * ) work, entier lwork, entier info)

ZGELS résout des systèmes linéaires complexes surdéterminés ou sous-déterminés impliquant une matrice A de taille M par N, ou sa transposée conjuguée, en utilisant une factorisation QR ou LQ de A.

Objectif :

!>
!> ZGELS résout des systèmes linéaires complexes surdéterminés ou sous-déterminés
!> impliquant une matrice A de taille M par N, ou sa transposée conjuguée, en utilisant une factorisation QR ou LQ de A.
!>
!> On suppose que A a un rang complet, et seule une protection rudimentaire contre les matrices de rang déficient est fournie. Ce sous-programme ne détecte que la déficience de rang exacte, où un élément diagonal du facteur triangulaire de A est exactement zéro.
!>
!> Il est concevable qu'un (ou plusieurs) des éléments diagonaux du facteur triangulaire de A soient des nombres anormalement petits sans que ce sous-programme ne signale une erreur. Les solutions calculées pour de telles matrices presque de rang déficient peuvent être moins précises en raison d'une perte de précision numérique.
!>
!> Les options suivantes sont fournies :
!>
!> 1. Si TRANS = 'N' et m >= n : trouver la solution des moindres carrés d'un système surdéterminé, c'est-à-dire résoudre le problème des moindres carrés
!>    minimiser || B - A*X ||.
!>
!> 2. Si TRANS = 'N' et m < n : trouver la solution de norme minimale d'un système sous-déterminé A * X = B.
!>
!> 3. Si TRANS = 'C' et m >= n : trouver la solution de norme minimale d'un système sous-déterminé A**H * X = B.
!>
!> 4. Si TRANS = 'C' et m < n : trouver la solution des moindres carrés d'un système surdéterminé, c'est-à-dire résoudre le problème des moindres carrés
!>    minimiser || B - A**H * X ||.
!>
!> Plusieurs vecteurs de second membre b et vecteurs de solution x peuvent être
!> gérés en un seul appel ; ils sont stockés sous forme de colonnes des
!> matrices B de taille M x NRHS et X de taille N x NRHS.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N' : le système linéaire implique A ;
!>          = 'C' : le système linéaire implique A**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          En entrée, la matrice A de taille M x N.
!>            si M >= N, A est écrasée par les détails de sa factorisation QR
!>                       renvoyée par ZGEQRF ;
!>            si M <  N, A est écrasée par les détails de sa factorisation LQ
!>                       renvoyée par ZGELQF.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          En entrée, la matrice B des seconds membres, stockée
!>          en colonnes ; B est de taille M x NRHS si TRANS = 'N', ou N x NRHS
!>          si TRANS = 'C'.
!>          En sortie, si INFO = 0, B est écrasée par les vecteurs de solution,
!>          stockés en colonnes :
!>          si TRANS = 'N' et m >= n, les lignes 1 à n de B contiennent les vecteurs
!>          de solution des moindres carrés ; la somme des carrés des résidus pour
!>          la solution dans chaque colonne est donnée par la somme des carrés
!>          des modules des éléments N+1 à M dans cette colonne ;
!>          si TRANS = 'N' et m < n, les lignes 1 à N de B contiennent les
!>          vecteurs de solution de norme minimale ;
!>          si TRANS = 'C' et m >= n, les lignes 1 à M de B contiennent les
!>          vecteurs de solution de norme minimale ;
!>          si TRANS = 'C' et m < n, les lignes 1 à M de B contiennent les
!>          vecteurs de solution des moindres carrés ; la somme des carrés des résidus
!>          pour la solution dans chaque colonne est donnée par la somme des
!>          carrés des modules des éléments M+1 à N dans cette colonne.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= MAX(1,M,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= max( 1, MN + max( MN, NRHS ) ).
!>          Pour des performances optimales,
!>          LWORK >= max( 1, MN + max( MN, NRHS )*NB ).
!>          où MN = min(M,N) et NB est la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête de mémoire est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  exécution réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  si INFO =  i, le i-ème élément diagonal du
!>                facteur triangulaire de A est exactement zéro, donc A n'a pas
!>                de rang complet ; la solution des moindres carrés n'a pas pu être
!>                calculée.
!>
