subroutine zggevx (character balanc, character jobvl, character jobvr, character sense, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, integer ilo, integer ihi, double precision, dimension( * ) lscale, double precision, dimension( * ) rscale, double precision abnrm, double precision bbnrm, double precision, dimension( * ) rconde, double precision, dimension( * ) rcondv, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, logical, dimension( * ) bwork, integer info)

ZGGEVX calcule les valeurs propres, et éventuellement, les vecteurs propres généralisés gauches et/ou droits pour les matrices GE

Objectif:

!>
!> ZGGEVX calcule pour une paire de matrices complexes non symétriques N-par-N
!> (A,B) les valeurs propres généralisées, et éventuellement, les vecteurs propres
!> généralisés gauches et/ou droits.
!>
!> En option, il calcule également une transformation de mise à l'échelle pour améliorer
!> le conditionnement des valeurs propres et des vecteurs propres (ILO, IHI,
!> LSCALE, RSCALE, ABNRM, et BBNRM), les réciproques des nombres de conditionnement
!> pour les valeurs propres (RCONDE), et les réciproques des nombres de conditionnement
!> pour les vecteurs propres droits (RCONDV).
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire
!> lambda ou un ratio alpha/beta = lambda, tel que A - lambda*B est
!> singulier. Elle est généralement représentée par la paire (alpha,beta), car
!> il existe une interprétation raisonnable pour beta=0, et même pour que les deux
!> soient nuls.
!>
!> Le vecteur propre généralisé droit v(j) correspondant à la valeur propre lambda(j)
!> de (A,B) satisfait
!>                  A * v(j) = lambda(j) * B * v(j) .
!> Le vecteur propre généralisé gauche u(j) correspondant à la valeur propre lambda(j)
!> de (A,B) satisfait
!>                  u(j)**H * A  = lambda(j) * u(j)**H * B.
!> où u(j)**H est la transposée conjuguée de u(j).
!>
!>

Paramètres

BALANC 
!>          BALANC est de type CHARACTER*1
!>          Spécifie l'option de mise à l'échelle à effectuer :
!>          = 'N' : ne pas mettre à l'échelle ou permuter diagonalement ;
!>          = 'P' : permuter uniquement ;
!>          = 'S' : mettre à l'échelle uniquement ;
!>          = 'B' : permuter et mettre à l'échelle les deux.
!>          Les réciproques des nombres de conditionnement calculés le seront
!>          pour les matrices après permutation et/ou mise à l'échelle. La permutation
!>          ne change pas les nombres de conditionnement (en arithmétique exacte),
!>          mais la mise à l'échelle le fait.
!>

JOBVL

!>          JOBVL est de type CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs propres généralisés gauches ;
!>          = 'V' : calculer les vecteurs propres généralisés gauches.
!>

JOBVR

!>          JOBVR est de type CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs propres généralisés droits ;
!>          = 'V' : calculer les vecteurs propres généralisés droits.
!>

SENSE

!>          SENSE est de type CHARACTER*1
!>          Détermine quelles réciproques de nombres de conditionnement sont calculées.
!>          = 'N' : aucune n'est calculée ;
!>          = 'E' : calculée pour les valeurs propres uniquement ;
!>          = 'V' : calculée pour les vecteurs propres uniquement ;
!>          = 'B' : calculée pour les valeurs propres et les vecteurs propres.
!>

N

!>          N est de type INTEGER
!>          L'ordre des matrices A, B, VL et VR. N >= 0.
!>

A

!>          A est un tableau de COMPLEX*16, de dimension (LDA, N)
!>          En entrée, la matrice A de la paire (A,B).
!>          En sortie, A a été écrasée. Si JOBVL='V' ou JOBVR='V'
!>          ou les deux, alors A contient la première partie de la forme de Schur
!>          complexe des versions d'entrée de A et B.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale de A. LDA >= max(1,N).
!>

B

!>          B est un tableau de COMPLEX*16, de dimension (LDB, N)
!>          En entrée, la matrice B de la paire (A,B).
!>          En sortie, B a été écrasée. Si JOBVL='V' ou JOBVR='V'
!>          ou les deux, alors B contient la seconde partie de la forme de Schur
!>          complexe des versions d'entrée de A et B.
!>

LDB

!>          LDB est de type INTEGER
!>          La dimension principale de B. LDB >= max(1,N).
!>

ALPHA

!>          ALPHA est un tableau de COMPLEX*16, de dimension (N)
!>

BETA

!>          BETA est un tableau de COMPLEX*16, de dimension (N)
!>          En sortie, ALPHA(j)/BETA(j), j=1,...,N, seront les valeurs propres
!>          généralisées.
!>
!>          Note : le quotient ALPHA(j)/BETA(j) peut facilement dépasser ou
!>          sous-dépasser les limites, et BETA(j) peut même être zéro. Ainsi, l'utilisateur
!>          devrait éviter de calculer naïvement le ratio ALPHA/BETA.
!>          Cependant, ALPHA sera toujours inférieur et généralement comparable
!>          à norm(A) en magnitude, et BETA toujours inférieur et généralement comparable
!>          à norm(B).
!>

VL

!>          VL est un tableau de COMPLEX*16, de dimension (LDVL,N)
!>          Si JOBVL = 'V', les vecteurs propres généralisés gauches u(j) sont
!>          stockés les uns après les autres dans les colonnes de VL, dans le même
!>          ordre que leurs valeurs propres.
!>          Chaque vecteur propre sera mis à l'échelle de sorte que le composant le plus grand
!>          ait abs(partie réelle) + abs(partie imaginaire) = 1.
!>          Non référencé si JOBVL = 'N'.
!>

LDVL

!>          LDVL est de type INTEGER
!>          La dimension principale de la matrice VL. LDVL >= 1, et
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR est un tableau de COMPLEX*16, de dimension (LDVR,N)
!>          Si JOBVR = 'V', les vecteurs propres généralisés droits v(j) sont
!>          stockés les uns après les autres dans les colonnes de VR, dans le même
!>          ordre que leurs valeurs propres.
!>          Chaque vecteur propre sera mis à l'échelle de sorte que le composant le plus grand
!>          ait abs(partie réelle) + abs(partie imaginaire) = 1.
!>          Non référencé si JOBVR = 'N'.
!>

LDVR

!>          LDVR est de type INTEGER
!>          La dimension principale de la matrice VR. LDVR >= 1, et
!>          si JOBVR = 'V', LDVR >= N.
!>

ILO

!>          ILO est de type INTEGER
!>

IHI

!>          IHI est de type INTEGER
!>          ILO et IHI sont des valeurs entières telles qu'en sortie
!>          A(i,j) = 0 et B(i,j) = 0 si i > j et
!>          j = 1,...,ILO-1 ou i = IHI+1,...,N.
!>          Si BALANC = 'N' ou 'S', ILO = 1 et IHI = N.
!>

LSCALE

Détails




!>
!> L'équilibrage d'une paire de matrices (A,B) inclut, d'abord, la permutation des lignes et des colonnes pour isoler les valeurs propres, ensuite, l'application d'une transformation de similarité diagonale aux lignes et aux colonnes pour rendre les lignes et les colonnes aussi proches que possible en norme. Les nombres de conditionnement réciproques calculés correspondent à la matrice équilibrée. La permutation des lignes et des colonnes ne changera pas les nombres de conditionnement (en arithmétique exacte) mais la mise à l'échelle diagonale le fera. Pour plus d'explications sur l'équilibrage, voir la section 4.11.1.2 du manuel de l'utilisateur LAPACK.
!>
!> Une borne d'erreur approximative sur la distance chordale entre la i-ème valeur propre généralisée calculée w et la valeur propre exacte correspondante lambda est
!>
!>       chord(w, lambda) <= EPS * norm(ABNRM, BBNRM) / RCONDE(I)
!>
!> Une borne d'erreur approximative pour l'angle entre le i-ème vecteur propre calculé VL(i) ou VR(i) est donnée par
!>
!>       EPS * norm(ABNRM, BBNRM) / DIF(i).
!>
!> Pour plus d'explications sur les nombres de conditionnement réciproques RCONDE et RCONDV, voir la section 4.11 du manuel de l'utilisateur LAPACK.
!>
