ZGTSVX calcule la solution du système linéaire A * X = B pour les matrices GT

Objectif :

!>
!> ZGTSVX utilise la factorisation LU pour calculer la solution d'un système
!> linéaire complexe A * X = B, A**T * X = B ou A**H * X = B, où A est une
!> matrice tridiagonale d'ordre N et X et B sont des matrices de taille N x NRHS.
!>
!> Les bornes d'erreur sur la solution et une estimation de condition sont
!> également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la décomposition LU est utilisée pour factoriser la matrice A
!>    en A = L * U, où L est un produit de matrices de permutation et
!>    bidiagonales inférieures unitaires et U est triangulaire supérieure
!>    avec des éléments non nuls uniquement sur la diagonale principale et les deux
!>    superdiagonales.
!>
!> 2. Si certains U(i,i) sont nuls, rendant U singulière, la routine
!>    retourne avec INFO = i. Sinon, la forme factorisée de A est utilisée
!>    pour estimer le nombre de condition de la matrice A. Si l'inverse
!>    du nombre de condition est inférieur à la précision machine,
!>    INFO = N+1 est retourné comme un avertissement, mais la routine continue
!>    à résoudre pour X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 4. Le raffinement itératif est appliqué pour améliorer la solution
!>    calculée et calculer les bornes d'erreur et les estimations d'erreur
!>    a posteriori pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est de type CHARACTER*1
!>          Spécifie si la forme factorisée de A a été fournie ou non à l'entrée.
!>          = 'F' : DLF, DF, DUF, DU2 et IPIV contiennent la forme factorisée
!>                  de A ; DL, D, DU, DLF, DF, DUF, DU2 et IPIV ne seront pas
!>                  modifiés.
!>          = 'N' : La matrice sera copiée dans DLF, DF et DUF
!>                  et factorisée.
!>

TRANS

!>          TRANS est de type CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N' : A * X = B     (Pas de transposée)
!>          = 'T' : A**T * X = B  (Transposée)
!>          = 'C' : A**H * X = B  (Transposée conjuguée)
!>

N

!>          N est de type INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est de type INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B. NRHS >= 0.
!>

DL

!>          DL est un tableau de type COMPLEX*16, dimension (N-1)
!>          Les éléments sous-diagonaux (n-1) de A.
!>

D

!>          D est un tableau de type COMPLEX*16, dimension (N)
!>          Les éléments diagonaux n de A.
!>

DU

!>          DU est un tableau de type COMPLEX*16, dimension (N-1)
!>          Les éléments superdiagonaux (n-1) de A.
!>

DLF

!>          DLF est un tableau de type COMPLEX*16, dimension (N-1)
!>          Si FACT = 'F', alors DLF est un argument d'entrée et contient à l'entrée
!>          les multiplicateurs (n-1) qui définissent la matrice L de la
!>          factorisation LU de A, calculée par ZGTTRF.
!>
!>          Si FACT = 'N', alors DLF est un argument de sortie et contient à la sortie
!>          les multiplicateurs (n-1) qui définissent la matrice L de la
!>          factorisation LU de A.
!>

DF

!>          DF est un tableau de type COMPLEX*16, dimension (N)
!>          Si FACT = 'F', alors DF est un argument d'entrée et contient à l'entrée
!>          les éléments diagonaux n de la matrice triangulaire supérieure
!>          U de la factorisation LU de A.
!>
!>          Si FACT = 'N', alors DF est un argument de sortie et contient à la sortie
!>          les éléments diagonaux n de la matrice triangulaire supérieure
!>          U de la factorisation LU de A.
!>

DUF

!>          DUF est un tableau de type COMPLEX*16, dimension (N-1)
!>          Si FACT = 'F', alors DUF est un argument d'entrée et contient à l'entrée
!>          les éléments (n-1) de la première superdiagonale de U.
!>
!>          Si FACT = 'N', alors DUF est un argument de sortie et contient à la sortie
!>          les éléments (n-1) de la première superdiagonale de U.
!>

DU2

!>          DU2 est un tableau de type COMPLEX*16, dimension (N-2)
!>          Si FACT = 'F', alors DU2 est un argument d'entrée et contient à l'entrée
!>          les éléments (n-2) de la deuxième superdiagonale de U.
!>
!>          Si FACT = 'N', alors DU2 est un argument de sortie et contient à la sortie
!>          les éléments (n-2) de la deuxième superdiagonale de U.
!>

IPIV

!>          IPIV est un tableau de type INTEGER, dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et contient à l'entrée
!>          les indices de pivot de la factorisation LU de A, calculés par ZGTTRF.
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et contient à la sortie
!>          les indices de pivot de la factorisation LU de A ; la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>          IPIV(i) sera toujours égal à i ou i+1 ; IPIV(i) = i indique
!>          qu'aucun échange de ligne n'était requis.
!>

B

!>          B est un tableau de type COMPLEX*16, dimension (LDB,NRHS)
!>          La matrice des seconds membres B de taille N x NRHS.
!>

LDB

!>          LDB est de type INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau de type COMPLEX*16, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N x NRHS.
!>

LDX

!>          LDX est de type INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est de type DOUBLE PRECISION
!>          L'estimation de l'inverse du nombre de condition de la matrice
!>          A. Si RCOND est inférieur à la précision machine (en
!>          particulier, si RCOND = 0), la matrice est singulière à la
!>          précision de travail. Cette condition est indiquée par un code
!>          de retour INFO > 0.
!>

FERR

!>          FERR est un tableau de type DOUBLE PRECISION, dimension (NRHS)
!>          La borne d'erreur a posteriori estimée pour chaque vecteur solution
!>          X(j) (la j-ième colonne de la matrice solution X).
!>

Si XTRUE est la solution vraie correspondant à X(j), FERR(j) !> est une borne supérieure estimée pour la magnitude du plus grand !> élément de (X(j) - XTRUE) divisée par la magnitude du plus grand !> élément de X(j). L'estimation est aussi fiable que !> l'estimation pour RCOND, et est presque toujours une légère !> sur-estimation de l'erreur vraie. !>

BERR

!>          BERR est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>          L'erreur retournée relative composante par composante de chaque vecteur
!>          solution X(j) (c'est-à-dire le plus petit changement relatif dans
!>          n'importe quel élément de A ou B qui fait de X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (N)
!>

INFO

!>          INFO est un INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= N : U(i,i) est exactement zéro. La factorisation
!>                       n'a pas été complétée sauf si i = N, mais le
!>                       facteur U est exactement singulier, donc la solution
!>                       et les bornes d'erreur n'ont pas pu être calculées.
!>                       RCOND = 0 est retourné.
!>                = N+1 : U est non singulier, mais RCOND est inférieur à la précision machine,
!>                       signifiant que la matrice est singulière
!>                       à la précision de travail. Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car
!>                       il existe un certain nombre de situations où la
!>                       solution calculée peut être plus précise que la
!>                       valeur de RCOND ne le suggérerait.
!>
