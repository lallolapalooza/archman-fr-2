Documentation de la fonction/sous-programme

sous-programme zgtsv (entier n, entier nrhs, complexe*16, dimension( * ) dl, complexe*16, dimension( * ) d, complexe*16, dimension( * ) du, complexe*16, dimension( ldb, * ) b, entier ldb, entier info)

ZGTSV calcule la solution du système d'équations linéaires A * X = B pour les matrices GT

Objectif :

!>
!> ZGTSV  résout l'équation
!>
!>    A*X = B,
!>
!> où A est une matrice tridiagonale N par N, par élimination de Gauss avec
!> pivotage partiel.
!>
!> Notez que l'équation  A**T *X = B  peut être résolue en échangeant l'ordre
!> des arguments DU et DL.
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

DL

!>          DL est un tableau COMPLEX*16, dimension (N-1)
!>          À l'entrée, DL doit contenir les (n-1) éléments sous-diagonaux de
!>          A.
!>          À la sortie, DL est écrasé par les (n-2) éléments de la
!>          deuxième superdiagonale de la matrice triangulaire supérieure U de
!>          la factorisation LU de A, dans DL(1), ..., DL(n-2).
!>

D

!>          D est un tableau COMPLEX*16, dimension (N)
!>          À l'entrée, D doit contenir les éléments diagonaux de A.
!>          À la sortie, D est écrasé par les n éléments diagonaux de U.
!>

DU

!>          DU est un tableau COMPLEX*16, dimension (N-1)
!>          À l'entrée, DU doit contenir les (n-1) éléments superdiagonaux
!>          de A.
!>          À la sortie, DU est écrasé par les (n-1) éléments de la première
!>          superdiagonale de U.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          À l'entrée, la matrice B de membre de droite de taille N par NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N par NRHS.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, U(i,i) est exactement zéro, et la solution
!>                n'a pas été calculée. La factorisation n'a pas été
!>                complétée sauf si i = N.
!>
