ZGGSVD calcule la décomposition en valeurs singulières (SVD) pour d'AUTRES matrices

Objectif:

!>
!> Cette routine est obsolète et a été remplacée par la routine ZGGSVD3.
!>
!> ZGGSVD calcule la décomposition généralisée en valeurs singulières (GSVD)
!> d'une matrice complexe M par N, A, et d'une matrice complexe P par N, B :
!>
!>       U**H*A*Q = D1*( 0 R ),    V**H*B*Q = D2*( 0 R )
!>
!> où U, V et Q sont des matrices unitaires.
!> Soit K+L = le rang numérique effectif de la
!> matrice (A**H,B**H)**H, alors R est une matrice triangulaire supérieure non singulière de taille (K+L)-par-(K+L), D1 et D2 sont des matrices de taille M-par-(K+L) et P-par-(K+L) 
!> et de structures respectives :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N), et R33 est stocké
!!>   ( 0  R22 R23 )
!>   dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> La routine calcule C, S, R, et éventuellement les matrices de transformation
!> unitaires U, V et Q.
!>
!> En particulier, si B est une matrice carrée non singulière N-par-N, alors la GSVD de
!> A et B donne implicitement la SVD de A*inv(B) :
!>                      A*inv(B) = U*(D1*inv(D2))*V**H.
!> Si ( A**H,B**H)**H a des colonnes orthonormées, alors la GSVD de A et B est aussi
!> égale à la décomposition CS de A et B. De plus, la GSVD peut
!> être utilisée pour dériver la solution du problème de valeurs propres :
!>                      A**H*A x = lambda* B**H*B x.
!> Dans certaines littératures, la GSVD de A et B est présentée sous la forme
!>                  U**H*A*X = ( 0 D1 ),   V**H*B*X = ( 0 D2 )
!> où U et V sont orthogonales et X est non singulière, et D1 et D2 sont
!> « diagonales ». La forme GSVD précédente peut être convertie en la forme
!> suivante en prenant la matrice non singulière X comme
!>
!>                       X = Q*(  I   0    )
!>                             (  0 inv(R) )
!>

Informations générales

!>
!> La taille de LWORK et LRWORK est calculée en appelant
!> ZGGSVD avec WORK(1) = SPACE( ).
!> En sortie, WORK(1) contient la taille requise pour LWORK, et RWORK(1)
!> contient la taille requise pour LRWORK.
!>
!> Les arguments LWORK et LRWORK doivent être au moins les valeurs spécifiées
!> par WORK(1) et RWORK(1) respectivement.
!>
!> En sortie, WORK(2) contient la taille requise pour LIWORK.
!> L'argument LIWORK doit être au moins la valeur spécifiée par WORK(2).
!>
!> Algorithme :
!>
!> Le GSVD est calculé en effectuant une séquence de réductions de matrice,
!> utilisant le QR échelonné (une décomposition RS) sur A et B, puis une
!> réduction de bidimensionnalité à l'aide de transformations de Householder
!> et enfin une décomposition QR et des itérations de valeurs singulières
!> pour obtenir la SVD de matrices triangulaires appropriées.
!>
!> Le GSVD de A et B est utilisé pour résoudre :
!>
!>  1. A x = lambda B x  (Système généralisé de valeurs propres)
!>
!>     Si B est inversible, la solution est obtenue à partir de la SVD de
!>     inv(B)*A. Si A et B sont des matrices carrées, les valeurs propres
!>     de lambda sont obtenues à partir de ALPHA(I)/BETA(I).
!>
!>  2. Résolution des systèmes linéaires compatibles :
!>     A*x = b, B*x = c
!>
!>     La solution est calculée à partir de :
!>
!>     x = Q * inv(R)*( D1_inv*U_H*b )
!>         ( 0  S_inv*V_H*c )
!>
!>     où D1 et D2 sont les matrices diagonales issues de la GSVD.
!>
!>  3. Calcul des pseudo-inverses de Moore-Penrose :
!>     A_plus et B_plus peuvent être calculées à partir de leurs GSVDs respectives.
!>
!> La procédure de décomposition QR est exécutée pour les matrices A et B.
!> La matrice A est ensuite réduite à une forme triangulaire supérieure par
!> la méthode de Householder. La matrice B est également réduite par la même
!> transformation unitaire gauche.
!>
!> Une autre séquence de réductions unitaires est appliquée pour obtenir
!> une forme triangulaire supérieure commune pour A et B.
!>
!> Finalement, la matrice A est utilisée pour obtenir la SVD de deux matrices
!> triangulaires appropriées.
!>
!> Les matrices unitaires U, V et Q sont construites en combinant les
!> transformations de Householder utilisées dans les étapes de réduction.
!>
!> Les valeurs ALPHA et BETA sont calculées à l'aide de la fonction LAPACK
!> DPSTEMR, qui implémente une méthode basée sur le théorème des valeurs
!> propres des matrices tridiagonales.
!>
!> La routine est conforme à la spécification LAPACK.
!>
!> Elle est obsolète et a été remplacée par ZGGSVD3.
!> ZGGSVD3 utilise une approche différente, notamment la décomposition QR
!> échelonnée des deux matrices, et est généralement plus stable numériquement.
!> Il est fortement recommandé d'utiliser ZGGSVD3 à la place de ZGGSVD.
!>
!> En cas de doute sur l'utilisation de ce code, consultez la documentation
!> de LAPACK pour obtenir des détails et des exemples.
!>
