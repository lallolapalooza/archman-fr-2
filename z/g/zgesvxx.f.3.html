Documentation de la fonction/sous-programme

sous-programme zgesvxx (caractère fact, caractère trans, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldaf, * ) af, entier ldaf, entier, dimension( * ) ipiv, caractère equed, double précision, dimension( * ) r, double précision, dimension( * ) c, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldx , * ) x, entier ldx, double précision rcond, double précision rpvgrw, double précision, dimension( * ) berr, entier n_err_bnds, double précision, dimension( nrhs, * ) err_bnds_norm, double précision, dimension( nrhs, * ) err_bnds_comp, entier nparams, double précision, dimension( * ) params, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier info)

ZGESVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices GE

Objectif :

!>
!>    ZGESVXX utilise la décomposition LU pour calculer la solution d'un
!>    système d'équations linéaires complexe*16  A * X = B,  où A est une
!>    matrice N-par-N et X et B sont des matrices N-par-NRHS.
!>
!>    Si demandé, des bornes d'erreur normées et des bornes d'erreur
!>    maximales par composante sont retournées. ZGESVXX retournera une
!>    solution avec une erreur garantie très faible (O(eps) où eps est la
!>    précision de la machine de travail) à moins que la matrice ne soit
!>    très mal conditionnée, auquel cas un avertissement est retourné.
!>    Les nombres de condition pertinents sont également calculés et retournés.
!>
!>    ZGESVXX accepte des factorisations et des facteurs d'équilibration
!>    fournis par l'utilisateur ; voir les définitions des options FACT et
!>    EQUED.
!>    La résolution avec raffinement et l'utilisation d'une factorisation
!>    d'un appel précédent à ZGESVXX produiront également une solution avec
!>    soit des erreurs O(eps), soit des avertissements, mais nous ne pouvons
!>    pas affirmer cela pour des factorisations et des facteurs
!>    d'équilibration généraux fournis par l'utilisateur s'ils diffèrent de
!>    ce que ZGESVXX produirait lui-même.
!>

Description :

!>
!>    Les étapes suivantes sont effectuées :
!>
!>    1. Si FACT = 'E', des facteurs de mise à l'échelle en double
!>    précision sont calculés pour équilibrer le système :
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle
!>    de la matrice A, mais si l'équilibration est utilisée, A est
!>    remplacée par diag(R)*A*diag(C) et B par diag(R)*B (si TRANS='N')
!>    ou diag(C)*B (si TRANS = 'T' ou 'C').
!>
!>    2. Si FACT = 'N' ou 'E', la décomposition LU est utilisée pour factoriser
!>    la matrice A (après équilibration si FACT = 'E') comme suit :
!>
!>      A = P * L * U,
!>
!>    où P est une matrice de permutation, L est une matrice triangulaire
!>    inférieure unitaire, et U est triangulaire supérieure.
!>
!>    3. Si certains U(i,i)=0, de sorte que U soit exactement singulier, alors le
!>    sous-programme retourne avec INFO = i. Sinon, la forme factorisée de A
!>    est utilisée pour estimer le nombre de condition de la matrice A (voir
!>    l'argument RCOND). Si l'inverse du nombre de condition est inférieur à la
!>    précision de la machine, le sous-programme continue à résoudre pour X
!>    et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!>    4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!>    5. Par défaut (sauf si PARAMS(LA_LINRX_ITREF_I) est mis à zéro),
!>    le sous-programme utilisera le raffinement itératif pour tenter
!>    d'obtenir une petite erreur et des bornes d'erreur. Le raffinement
!>    calcule le résidu avec une précision au moins double de celle de travail.
!>
!>    6. Si l'équilibration a été utilisée, la matrice X est pré-multipliée par
!>    diag(C) (si TRANS = 'N') ou diag(R) (si TRANS = 'T' ou 'C') de sorte
!>    qu'elle résolve le système original avant équilibration.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS.
!>     Ces paramètres déterminent comment le raffinement est effectué, mais
!>     souvent les valeurs par défaut sont acceptables. Si les valeurs par défaut
!>     sont acceptables, les utilisateurs peuvent passer NPARAMS = 0, ce qui
!>     empêche le code source d'accéder à l'argument PARAMS.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>     Spécifie si la forme factorisée de la matrice A est fournie à
!>     l'entrée, et sinon, si la matrice A doit être équilibrée avant d'être
!>     factorisée.
!>       = 'F' : À l'entrée, AF et IPIV contiennent la forme factorisée de A.
!>               Si EQUED n'est pas 'N', la matrice A a été
!>               équilibrée avec les facteurs de mise à l'échelle donnés par R et C.
!>               A, AF et IPIV ne sont pas modifiés.
!>       = 'N' : La matrice A sera copiée dans AF et factorisée.
!>       = 'E' : La matrice A sera équilibrée si nécessaire, puis
!>               copiée dans AF et factorisée.
!>

TRANS

!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N' :  A * X = B     (Pas de transposée)
!>       = 'T' :  A**T * X = B  (Transposée)
!>       = 'C' :  A**H * X = B  (Conjuguée Transposée)
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

A

!>          A est une matrice COMPLEX*16, dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N-par-N.  Si FACT = 'F' et EQUED
!>     n'est pas 'N', alors A doit avoir été équilibrée par les facteurs de
!>     mise à l'échelle dans R et/ou C.  A n'est pas modifiée si FACT = 'F' ou
!>     'N', ou si FACT = 'E' et EQUED = 'N' à la sortie.
!>
!>     À la sortie, si EQUED .ne. 'N', A est mise à l'échelle comme suit :
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est une matrice COMPLEX*16, dimension (LDAF,N)
!>     Si FACT = 'F', alors AF est un argument d'entrée et à l'entrée
!>     contient les facteurs L et U de la décomposition
!>     A = P*L*U calculée par ZGETRF. Si EQUED .ne. 'N', alors
!>     AF est la forme factorisée de la matrice équilibrée A.
!>
!>     Si FACT = 'N', alors AF est un argument de sortie et à la sortie
!>     retourne les facteurs L et U de la décomposition A = P*L*U
!>     de la matrice originale A.
!>
!>     Si FACT = 'E', alors AF est un argument de sortie et à la sortie
!>     retourne les facteurs L et U de la décomposition A = P*L*U
!>     de la matrice équilibrée A (voir la description de A pour
la forme de la matrice équilibrée).
!>

LDAF

!> LDAF est un entier
!> La dimension principale du tableau AF. LDAF >= max(1,N).
!>

IPIV

!> IPIV est un tableau d'entiers, de dimension (N)
!> Si FACT = 'F', alors IPIV est un argument d'entrée et à l'entrée
!> contient les indices des pivots de la factorisation A = P*L*U
!> telle que calculée par ZGETRF ; la ligne i de la matrice a été échangée
!> avec la ligne IPIV(i).
!>
!> Si FACT = 'N', alors IPIV est un argument de sortie et à la sortie
!> contient les indices des pivots de la factorisation A = P*L*U
!> de la matrice originale A.
!>
!> Si FACT = 'E', alors IPIV est un argument de sortie et à la sortie
!> contient les indices des pivots de la factorisation A = P*L*U
!> de la matrice équilibrée A.
!>

EQUED

!> EQUED est un caractère de longueur 1
!> Spécifie la forme d'équilibration qui a été effectuée.
!> = 'N' : Aucune équilibration (toujours vrai si FACT = 'N').
!> = 'R' : Équilibrage par lignes, c'est-à-dire que A a été pré-multiplié par
!> diag(R).
!> = 'C' : Équilibrage par colonnes, c'est-à-dire que A a été post-multiplié
!> par diag(C).
!> = 'B' : Équilibrage par lignes et par colonnes, c'est-à-dire que A a été
!> remplacé par diag(R) * A * diag(C).
!> EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un
!> argument de sortie.
!>

R

!> R est un tableau de type DOUBLE PRECISION, de dimension (N)
!> Les facteurs d'échelle des lignes de A. Si EQUED = 'R' ou 'B', A est
!> multiplié à gauche par diag(R) ; si EQUED = 'N' ou 'C', R
!> n'est pas accédé. R est un argument d'entrée si FACT = 'F' ;
!> sinon, R est un argument de sortie. Si FACT = 'F' et
!> EQUED = 'R' ou 'B', chaque élément de R doit être positif.
!> Si R est une sortie, chaque élément de R est une puissance de la base.
!> Si R est une entrée, chaque élément de R doit être une puissance de la base
!> pour assurer une solution et des estimations d'erreur fiables. La mise à l'échelle par
!> des puissances de la base ne provoque pas d'erreurs d'arrondi à moins que le
!> résultat ne sous-flotte ou ne surflotte. Les erreurs d'arrondi pendant la mise à l'échelle
!> conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!> matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!> fiables.
!>

C

!> C est un tableau de type DOUBLE PRECISION, de dimension (N)
!> Les facteurs d'échelle des colonnes de A. Si EQUED = 'C' ou 'B', A est
!> multiplié à droite par diag(C) ; si EQUED = 'N' ou 'R', C
!> n'est pas accédé. C est un argument d'entrée si FACT = 'F' ;
!> sinon, C est un argument de sortie. Si FACT = 'F' et
!> EQUED = 'C' ou 'B', chaque élément de C doit être positif.
!> Si C est une sortie, chaque élément de C est une puissance de la base.
!> Si C est une entrée, chaque élément de C doit être une puissance de la base
!> pour assurer une solution et des estimations d'erreur fiables. La mise à l'échelle par
!> des puissances de la base ne provoque pas d'erreurs d'arrondi à moins que le
!> résultat ne sous-flotte ou ne surflotte. Les erreurs d'arrondi pendant la mise à l'échelle
!> conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!> matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!> fiables.
!>

B

!> B est un tableau de type COMPLEX*16, de dimension (LDB,NRHS)
!> À l'entrée, la matrice B du second membre, de dimensions N x NRHS.
!> À la sortie,
!> si EQUED = 'N', B n'est pas modifié ;
!> si TRANS = 'N' et EQUED = 'R' ou 'B', B est écrasé par
!> diag(R)*B ;
!> si TRANS = 'T' ou 'C' et EQUED = 'C' ou 'B', B est
!> écrasé par diag(C)*B.
!>

LDB

!> LDB est un entier
!> La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!> X est un tableau de type COMPLEX*16, de dimension (LDX,NRHS)
!> Si INFO = 0, la matrice X de solution, de dimensions N x NRHS, du système
!> d'équations original. Notez que A et B sont modifiés à la sortie
!> si EQUED .ne. 'N', et la solution du système équilibré est
!> inv(diag(C))*X si TRANS = 'N' et EQUED = 'C' ou 'B', ou
!> inv(diag(R))*X si TRANS = 'T' ou 'C' et EQUED = 'R' ou 'B'.
!>

LDX

!> LDX est un entier
!> La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!> RCOND est un DOUBLE PRECISION
!> Conditionnement réciproque mis à l'échelle. C'est une estimation du
!> conditionnement réciproque de Skeel de la matrice A après
!> équilibration (si effectuée). Si celui-ci est inférieur à la précision de la machine
!> (en particulier, s'il est nul), la matrice est singulière
!> à la précision de travail. Notez que l'erreur peut toujours être petite même
!> si ce nombre est très petit et que la matrice semble mal conditionnée.
!>

RPVGRW

!> RPVGRW est un DOUBLE PRECISION
!> Croissance réciproque des pivots. À la sortie, ceci contient le facteur de
!> croissance réciproque des pivots norm(A)/norm(U). La norme
!> est utilisée. Si ceci est beaucoup inférieur à 1, alors la stabilité de
!> la factorisation LU de la matrice A (équilibrée) pourrait être médiocre.
!> Cela signifie également que la solution X, les conditionnements estimés,
!> et les bornes d'erreur pourraient être peu fiables. Si la factorisation échoue avec
!> 0<INFO<=N, alors ceci contient le facteur de croissance réciproque des pivots
!> pour les INFO premières colonnes de A. Dans ZGESVX, cette quantité est
!> retournée dans WORK(1).
!>

BERR

!> BERR est un tableau de DOUBLE PRECISION, de dimension (NRHS)
!> Erreur arrière relative composante par composante. C'est l'erreur
!> relative composante par composante de chaque vecteur solution X(j)
!> (c'est-à-dire le plus petit changement relatif dans un élément de A ou B qui
!> fait de X(j) une solution exacte).
!>

N_ERR_BNDS

!> N_ERR_BNDS est un entier
!> Nombre de bornes d'erreur à retourner pour chaque second membre
!> et chaque type (normale ou composante par composante). Voir ERR_BNDS_NORM et
!> ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!> ERR_BNDS_NORM est un tableau de DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!> Pour chaque second membre, ce tableau contient des informations sur
!> diverses bornes d'erreur et conditionnements correspondant à l'erreur normale
!> relative, qui est définie comme suit :
!>
!> Erreur relative normale dans le i-ème vecteur solution :
!> max_j (abs(XTRUE(j,i) - X(j,i)))
!> ------------------------------
!> max_j abs(X(j,i))
!>
!> Le tableau est indexé par le type d'information d'erreur tel que décrit
!> ci-dessous. Il y a actuellement jusqu'à trois informations
!> retournées.
!>
!> Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!> second membre.
!>
!> Le second indice dans ERR_BNDS_NORM(:,err) contient les trois champs suivants :
!> err = 1 booléen. Faites confiance à la réponse si le
!> conditionnement réciproque est inférieur au seuil
!> sqrt(n) * dlamch('Epsilon').
!>
!> err = 2 borne d'erreur : L'erreur avant estimée,
!> presque certainement dans un facteur 10 de l'erreur réelle
!> tant que la prochaine entrée est supérieure au seuil
!> sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne doit être
!> fiable que si le booléen précédent est vrai.
!>
!> err = 3 Conditionnement réciproque : Conditionnement
!> réciproque normal estimé. Comparé au seuil
!> sqrt(n) * dlamch('Epsilon') pour déterminer si l'erreur
!> l'estimation est . Ces conditionnements réciproques
!> sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une certaine
!> matrice Z correctement mise à l'échelle.
!> Soit Z = S*A, où S met à l'échelle chaque ligne par une puissance de la
!> base de sorte que toutes les sommes de lignes absolues de Z soient approximativement 1.
!>
!> Voir la note de travail 165 de Lapack pour plus de détails et des avertissements supplémentaires.
!>

ERR_BNDS_COMP

!> ERR_BNDS_COMP est un tableau de DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!> Pour chaque second membre, ce tableau contient des informations sur
!> diverses bornes d'erreur et conditionnements correspondant à l'erreur relative composante par composante, qui est définie comme suit :
!>
!> Erreur relative composante par composante dans le i-ème vecteur solution :
!> abs(XTRUE(j,i) - X(j,i))
!> max_j ----------------------
!> abs(X(j,i))
!>
!> Le tableau est indexé par le second membre i (dont dépend l'erreur relative composante par composante), et le type d'information d'erreur tel que décrit ci-dessous. Il y a actuellement jusqu'à trois informations retournées pour chaque second membre. Si
!> la précision composante par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!> ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!> les premières (:,N_ERR_BNDS) entrées sont retournées.
!>
!> Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!> second membre.
!>
!> Le second indice dans ERR_BNDS_COMP(:,err) contient les trois champs suivants :
!> err = 1 booléen. Faites confiance à la réponse si le
!> conditionnement réciproque est inférieur au seuil
!> sqrt(n) * dlamch('Epsilon').
!>
!> err = 2 borne d'erreur : L'erreur avant estimée,
!> presque certainement dans un facteur 10 de l'erreur réelle
!> tant que la prochaine entrée est supérieure au seuil
!> sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne doit être
!> fiable que si le booléen précédent est vrai.
!>
!> err = 3 Conditionnement réciproque : Conditionnement
!> réciproque composante par composante estimé. Comparé au seuil
!> sqrt(n) * dlamch('Epsilon') pour déterminer si l'erreur
!> l'estimation est . Ces conditionnements réciproques
!> sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une certaine
!> matrice Z correctement mise à l'échelle.
!> Soit Z = S*(A*diag(x)), où x est la solution pour
!> le second membre courant et S met à l'échelle chaque ligne de
!> A*diag(x) par une puissance de la base de sorte que toutes les sommes de lignes absolues de
!> Z soient approximativement 1.
!>
!> Voir la note de travail 165 de Lapack pour plus de détails et des avertissements supplémentaires.
!>

NPARAMS

!> NPARAMS est un entier
!> Spécifie le nombre de paramètres définis dans PARAMS. Si <= 0, le
!> tableau PARAMS n'est jamais référencé et les valeurs par défaut sont utilisées.
!>

PARAMS

!> PARAMS est un tableau de DOUBLE PRECISION, de dimension NPARAMS
!> Spécifie les paramètres de l'algorithme. Si une entrée est < 0.0, alors
!> cette entrée sera remplie avec la valeur par défaut utilisée pour ce
!> paramètre. Seules les positions jusqu'à NPARAMS sont accédées ; les valeurs par défaut
!> sont utilisées pour les paramètres de rang supérieur.
!>
!> PARAMS(LA_LINRX_ITREF_I = 1) : Indique s'il faut effectuer un raffinement itératif
!> ou non.
!> Valeur par défaut : 1.0D+0
!> = 0.0 : Aucun raffinement n'est effectué, et aucune borne d'erreurs sont
!>                    calculés.
!>            = 1.0 : Utilise l'algorithme de raffinement de précision étendue.
!>              (d'autres valeurs sont réservées pour une utilisation future)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Nombre maximum de calculs
!>            résiduels autorisés pour le raffinement.
!>         Par défaut : 10
!>         Agressif : Défini à 100 pour permettre la convergence en utilisant
!>                     des factorisations approximatives ou des factorisations
!>                     autres que LU. Si la factorisation utilise une
!>                     technique autre que l'élimination de Gauss, les
!>                     garanties dans err_bnds_norm et err_bnds_comp peuvent
!>                     ne plus être fiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Indicateur déterminant si le code
!>            tente de trouver une solution avec une petite erreur relative
!>            composante par composante dans l'algorithme en double précision.
!>            Une valeur positive signifie vrai, 0.0 signifie faux.
!>         Par défaut : 1.0 (tenter la convergence composante par composante)
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (2*N)
!>

INFO

!>          INFO est un entier
!>       = 0 : Sortie réussie. La solution pour chaque membre du second membre
!>         est garantie.
!>       < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>       > 0 et <= N : U(INFO,INFO) est exactement zéro. La factorisation
!>         a été complétée, mais le facteur U est exactement singulier,
!>         donc la solution et les bornes d'erreur n'ont pas pu être calculées.
!>         RCOND = 0 est retourné.
!>       = N+J : La solution correspondant au J-ème membre du second membre
!>         n'est pas garantie. Les solutions correspondant aux autres membres
!>         du second membre K avec K > J peuvent également ne pas être
!>         garanties, mais seul le premier membre de ce type est signalé.
!>         Si une petite erreur composante par composante n'est pas demandée
!>         (PARAMS(3) = 0.0), alors le J-ème membre du second membre est le
!>         premier pour lequel la borne d'erreur normwise n'est pas garantie
!>         (le plus petit J tel que ERR_BNDS_NORM(J,1) = 0.0). Par défaut
!>         (PARAMS(3) = 1.0), le J-ème membre du second membre est le premier
!>         pour lequel la borne d'erreur normwise OU composante par composante
!>         n'est pas garantie (le plus petit J tel que ERR_BNDS_NORM(J,1) = 0.0
!>         ou ERR_BNDS_COMP(J,1) = 0.0). Voir la définition de
!>         ERR_BNDS_NORM(:,1) et ERR_BNDS_COMP(:,1). Pour obtenir des
