sous-routine zgbsv (n, kl, ku, nrhs, ab, ldab, ipiv, b, ldb, info)


ZGBSV calcule la solution du système d'équations linéaires A * X = B pour les matrices GB (pilote simple)

Documentation de la fonction/sous-routine

sous-routine zgbsv (integer n, integer kl, integer ku, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZGBSV calcule la solution du système d'équations linéaires A * X = B pour les matrices GB (pilote simple)

Objectif :

!>
!> ZGBSV calcule la solution d'un système d'équations linéaires complexes
!> A * X = B, où A est une matrice bande d'ordre N avec KL sous-diagonales
!> et KU super-diagonales, et X et B sont des matrices N par NRHS.
!>
!> La décomposition LU avec pivot partiel et échanges de lignes est
!> utilisée pour factoriser A en A = L * U, où L est un produit de matrices de permutation
!> et de matrices triangulaires inférieures unitaires avec KL sous-diagonales, et U est
!> triangulaire supérieure avec KL+KU super-diagonales. La forme factorisée de A
!> est ensuite utilisée pour résoudre le système d'équations A * X = B.
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A. N >= 0.
!>

KL

!>          KL est un ENTIER
!>          Le nombre de sous-diagonales dans la bande de A. KL >= 0.
!>

KU

!>          KU est un ENTIER
!>          Le nombre de super-diagonales dans la bande de A. KU >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B. NRHS >= 0.
!>

AB

!>          AB est un tableau de type COMPLEX*16, de dimension (LDAB,N)
!>          À l'entrée, la matrice A en stockage bande, dans les lignes KL+1 à
!>          2*KL+KU+1 ; les lignes 1 à KL du tableau n'ont pas besoin d'être définies.
!>          La j-ème colonne de A est stockée dans la j-ème colonne du
!>          tableau AB comme suit :
!>          AB(KL+KU+1+i-j,j) = A(i,j) pour max(1,j-KU) <= i <= min(N,j+KL)
!>          À la sortie, détails de la factorisation : U est stockée comme une
!>          matrice bande triangulaire supérieure avec KL+KU super-diagonales dans
!>          les lignes 1 à KL+KU+1, et les multiplicateurs utilisés pendant la
!>          factorisation sont stockés dans les lignes KL+KU+2 à 2*KL+KU+1.
!>          Voir ci-dessous pour plus de détails.
!>

LDAB

!>          LDAB est un ENTIER
!>          La dimension principale du tableau AB. LDAB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau de type ENTIER, de dimension (N)
!>          Les indices de pivot qui définissent la matrice de permutation P ;
!>          la ligne i de la matrice a été échangée avec la ligne IPIV(i).
!>

B

!>          B est un tableau de type COMPLEX*16, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B de membre de droite N par NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de N par NRHS.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, U(i,i) est exactement zéro. La factorisation
!>                a été complétée, mais le facteur U est exactement
!>                singulier, et la solution n'a pas été calculée.
!>

Détails supplémentaires :

!>
!>  Le schéma de stockage bande est illustré par l'exemple suivant, lorsque
!>  M = N = 6, KL = 2, KU = 1 :
!>
!>  À l'entrée :                       À la sortie :
!>
!>      *    *    *    +    +    +       *    *    *   u14  u25  u36
!>      *    *    +    +    +    +       *    *   u13  u24  u35  u46
!>      *   a12  a23  a34  a45  a56      *   u12  u23  u34  u45  u56
!>     a11  a22  a33  a44  a55  a66     u11  u22  u33  u44  u55  u66
!>     a21  a32  a43  a54  a65   *      m21  m32  m43  m54  m65   *
!>     a31  a42  a53  a64   *    *      m31  m42  m53  m64   *    *
!>
!>  Les éléments du tableau marqués * ne sont pas utilisés par la sous-routine ; les éléments marqués
!>  + n'ont pas besoin d'être définis à l'entrée, mais sont requis par la sous-routine pour stocker
!>  des éléments de U en raison du remplissage résultant des échanges de lignes.
!>
