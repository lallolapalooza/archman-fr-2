Documentation de la fonction/sous-routine

sous-routine zgges3 (character jobvsl, character jobvsr, character sort, external selctg, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, integer sdim, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( ldvsl, * ) vsl, integer ldvsl, complex*16, dimension( ldvsr, * ) vsr, integer ldvsr, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, logical, dimension( * ) bwork, integer info)

ZGGES3 calcule pour une paire de matrices complexes non symétriques N-par-N (A,B), les valeurs propres généralisées, la forme de Schur généralisée (S, T), et optionnellement les vecteurs de Schur gauche et/ou droit (VSL et VSR). Ceci donne la factorisation de Schur généralisée

Objectif:

!>
!> ZGGES3 calcule pour une paire de matrices complexes non symétriques N-par-N
!> (A,B), les valeurs propres généralisées, la forme de Schur généralisée (S, T),
!> et optionnellement les vecteurs de Schur gauches et/ou droits (VSL et VSR). Ceci
!> donne la factorisation de Schur généralisée
!>
!>         (A,B) = ( (VSL)*S*(VSR)**H, (VSL)*T*(VSR)**H )
!>
!> où (VSR)**H est la conjuguée transposée de VSR.
!>
!> Optionnellement, il ordonne également les valeurs propres de sorte qu'un cluster
!> sélectionné de valeurs propres apparaisse dans les blocs diagonaux principaux de la
!> matrice triangulaire supérieure S et de la matrice triangulaire supérieure T. Les
!> colonnes principales de VSL et VSR forment alors une base unitaire pour les
!> sous-espaces gauches et droits correspondants (sous-espaces défléchissants).
!>
!> (Si seules les valeurs propres généralisées sont nécessaires, utilisez le pilote
!> ZGGEV à la place, qui est plus rapide.)
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un rapport alpha/beta = w, tel que A - w*B est singulière. Elle est
!> généralement représentée par la paire (alpha,beta), car il existe une
!> interprétation raisonnable pour beta=0, et même pour les deux étant zéro.
!>
!> Une paire de matrices (S,T) est en forme de Schur complexe généralisée si S
!> et T sont triangulaires supérieures et, en plus, les éléments diagonaux
!> de T sont des nombres réels non négatifs.
!>

Paramètres

JOBVSL 
!>          JOBVSL est CHARACTER*1
!>          = 'N':  ne pas calculer les vecteurs de Schur gauches ;
!>          = 'V':  calculer les vecteurs de Schur gauches.
!>

JOBVSR

!>          JOBVSR est CHARACTER*1
!>          = 'N':  ne pas calculer les vecteurs de Schur droits ;
!>          = 'V':  calculer les vecteurs de Schur droits.
!>

SORT

!>          SORT est CHARACTER*1
!>          Spécifie si les valeurs propres doivent être ordonnées ou non sur
!>          la diagonale de la forme de Schur généralisée.
!>          = 'N':  Les valeurs propres ne sont pas ordonnées ;
!>          = 'S':  Les valeurs propres sont ordonnées (voir SELCTG).
!>

SELCTG

!>          SELCTG est une FONCTION LOGIQUE de deux arguments COMPLEX*16
!>          SELCTG doit être déclarée EXTERNE dans la sous-routine appelante.
!>          Si SORT = 'N', SELCTG n'est pas référencée.
!>          Si SORT = 'S', SELCTG est utilisée pour sélectionner les valeurs propres à trier
!>          en haut à gauche de la forme de Schur.
!>          Une valeur propre ALPHA(j)/BETA(j) est sélectionnée si
!>          SELCTG(ALPHA(j),BETA(j)) est vrai.
!>
!>          Notez qu'une valeur propre complexe sélectionnée peut ne plus satisfaire
!>          SELCTG(ALPHA(j),BETA(j)) = .TRUE. après ordonnancement, car
!>          l'ordonnancement peut changer la valeur des valeurs propres
!>          complexes (surtout si la valeur propre est mal conditionnée), dans ce
!>          cas INFO est mis à N+2 (Voir INFO ci-dessous).
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A, B, VSL et VSR.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>          À l'entrée, la première matrice de la paire.
!>          À la sortie, A a été écrasé par sa forme de Schur généralisée
!>          S.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB, N)
!>          À l'entrée, la seconde matrice de la paire.
!>          À la sortie, B a été écrasé par sa forme de Schur généralisée
!>          T.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de B.  LDB >= max(1,N).
!>

SDIM

!>          SDIM est INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = nombre de valeurs propres (après ordonnancement)
!>          pour lesquelles SELCTG est vrai.
!>

ALPHA

!>          ALPHA est un tableau COMPLEX*16, dimension (N)
!>

BETA

!>          BETA est un tableau COMPLEX*16, dimension (N)
!>          À la sortie, ALPHA(j)/BETA(j), j=1,...,N, seront les
!>          valeurs propres généralisées. ALPHA(j), j=1,...,N et BETA(j),
!>          j=1,...,N sont les éléments diagonaux de la forme de Schur complexe (A,B)
!>          renvoyée par ZGGES3. Les BETA(j) seront des réels non négatifs.
!>
!>          Note: les quotients ALPHA(j)/BETA(j) peuvent facilement dépasser ou
!>          sous-dépasser les limites, et BETA(j) peut même être zéro. Ainsi, l'utilisateur
!>          doit éviter de calculer naïvement le rapport alpha/beta.
!>          Cependant, ALPHA sera toujours inférieur, et généralement comparable,
!>          à la norme(A) en magnitude, et BETA toujours inférieur, et généralement comparable,
!>          à la norme(B).
!>

VSL

!>          VSL est un tableau COMPLEX*16, dimension (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contiendra les vecteurs de Schur gauches.
!>          Non référencé si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL est INTEGER
!>          La dimension principale de la matrice VSL. LDVSL >= 1, et
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR est un tableau COMPLEX*16, dimension (LDVSR,N)
!>          Si JOBVSR = 'V', VSR contiendra les vecteurs de Schur droits.
!>          Non référencé si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR est INTEGER
!>          La dimension principale de la matrice VSR. LDVSR >= 1, et
!>          si JOBVSR = 'V', LDVSR >= N.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= MAX(1,2*N)
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (8*N)
!>

BWORK

!>          BWORK est un tableau LOGICAL, dimension (N)
!>          Non référencé si SORT = 'N'.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  exécution réussie
!>          < 0:  si INFO = -i,
