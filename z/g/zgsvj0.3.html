sous-programme zgsvj0 (caractère*1 jobv, entier m, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( n ) d, double précision, dimension( n ) sva, entier mv, complexe*16, dimension( ldv, * ) v, entier ldv, double précision eps, double précision sfmin, double précision tol, entier nsweep, complexe*16, dimension( lwork ) work, entier lwork, entier info)

ZGSVJ0 préprocesseur de la routine zgesvj.

Objectif:

!>
!> ZGSVJ0 est appelé par ZGESVJ comme préprocesseur et c'est son but principal. Il applique des rotations de Jacobi de la même manière que ZGESVJ, mais il ne vérifie pas la convergence (critère d'arrêt). Peu de paramètres d'ajustement (marqués par [TP]) sont disponibles pour l'implémenteur.
!>

Paramètres

JOBV 
!>          JOBV est CHARACTER*1
!>          Spécifie si la sortie de cette procédure est utilisée
!>          pour calculer la matrice V :
!>          = 'V' : le produit des rotations de Jacobi est accumulé
!>                 par post-multiplication du tableau N par N V.
!>                (Voir la description de V.)
!>          = 'A' : le produit des rotations de Jacobi est accumulé
!>                 par post-multiplication du tableau MV par N V.
!>                (Voir les descriptions de MV et V.)
!>          = 'N' : les rotations de Jacobi ne sont pas accumulées.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, matrice A de taille M par N, telle que A*diag(D) représente
!>          la matrice d'entrée.
!>          À la sortie,
!>          A_sortie * diag(D_sortie) représente la matrice d'entrée A*diag(D)
!>          post-multipliée par une séquence de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de passes sont donnés dans
!>          TOL et NSWEEP, respectivement.
!>          (Voir les descriptions de D, TOL et NSWEEP.)
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

D

!>          D est un tableau COMPLEX*16, dimension (N)
!>          Le tableau D accumule les facteurs de mise à l'échelle des rotations
!>          de Jacobi complexes mises à l'échelle.
!>          À l'entrée, A*diag(D) représente la matrice d'entrée.
!>          À la sortie, A_sortie*diag(D_sortie) représente la matrice d'entrée
!>          post-multipliée par une séquence de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de passes sont donnés dans
!>          TOL et NSWEEP, respectivement.
!>          (Voir les descriptions de A, TOL et NSWEEP.)
!>

SVA

!>          SVA est un tableau DOUBLE PRÉCISION, dimension (N)
!>          À l'entrée, SVA contient les normes euclidiennes des colonnes de
!>          la matrice A*diag(D).
!>          À la sortie, SVA contient les normes euclidiennes des colonnes de
!>          la matrice A_sortie*diag(D_sortie).
!>

MV

!>          MV est INTEGER
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'N',   alors MV n'est pas référencé.
!>

V

!>          V est un tableau COMPLEX*16, dimension (LDV,N)
!>          Si JOBV = 'V', alors N lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'N',   alors V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V, LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!>

EPS

!>          EPS est DOUBLE PRÉCISION
!>          EPS = DLAMCH('Epsilon')
!>

SFMIN

!>          SFMIN est DOUBLE PRÉCISION
!>          SFMIN = DLAMCH('Safe Minimum')
!>

TOL

!>          TOL est DOUBLE PRÉCISION
!>          TOL est le seuil pour les rotations de Jacobi. Pour une paire
!>          de colonnes de pivot A(:,p), A(:,q), la rotation de Jacobi est
!>          appliquée seulement si ABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!>

NSWEEP

!>          NSWEEP est INTEGER
!>          NSWEEP est le nombre de passes de rotations de Jacobi à effectuer.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          LWORK est la dimension de WORK. LWORK >= M.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires:

ZGSVJ0 est utilisé uniquement pour permettre à ZGESVJ d'appeler une version simplifiée de lui-même pour travailler sur une sous-matrice de la matrice originale.

NAME

xz - compress or expand files with the xz/lzma/lcaj format

SYNOPSIS

xz [ OPTION ... ] [ FILE ... ]

DESCRIPTION

xz is a command-line tool that compresses or decompresses files. It supports the xz, lzma, and lzma2 file formats. The primary use is to compress or decompress files, similar to gzip or bzip2.

OPTIONS

-z, --compress Compress. This is the default operation.
-d, --decompress Decompress.
-k, --keep Keep input files intact instead of deleting them after processing.
-f, --force Force overwrite of output files.
-t, --test Test the integrity of compressed files.
-c, --stdout Write output on standard output; keep original files unchanged.
-l, --list List information about the compressed file.
-v, --verbose Be verbose.
-q, --quiet Suppress warnings and diagnostic messages.
--version Display version information and exit.
--help Display this help text and exit.

EXAMPLES

Compress a file:
$ xz mydocument.txt
This will create mydocument.txt.xz.
Decompress a file:
$ xz -d mydocument.txt.xz
This will create mydocument.txt.
Compress a file and send output to stdout:
$ xz -c mydocument.txt > mydocument.txt.xz
Decompress a file and send output to stdout:
$ xz -dc mydocument.txt.xz > mydocument.txt
List information about a compressed file:
$ xz -l mydocument.txt.xz
