ZGESVDX calcule la décomposition en valeurs singulières (SVD) pour les matrices GE

Objectif :

!>
!>  ZGESVDX calcule la décomposition en valeurs singulières (SVD) d'une matrice complexe
!>  M par N, A, en calculant éventuellement les vecteurs singuliers gauches et/ou droits.
!>  La SVD est écrite
!>
!>      A = U * SIGMA * transpose(V)
!>
!>  où SIGMA est une matrice M par N qui est nulle sauf pour ses
!>  min(m,n) éléments diagonaux, U est une matrice unitaire M par M, et
!>  V est une matrice unitaire N par N. Les éléments diagonaux de SIGMA
!>  sont les valeurs singulières de A; elles sont réelles et non négatives,
!>  et sont retournées dans l'ordre décroissant. Les min(m,n) premières colonnes de
!>  U et V sont les vecteurs singuliers gauches et droits de A.
!>
!>  ZGESVDX utilise un problème de valeurs propres pour obtenir la SVD, ce qui
!>  permet le calcul d'un sous-ensemble de valeurs et de vecteurs singuliers.
!>  Voir DBDSVDX pour plus de détails.
!>
!>  Notez que la routine retourne V**T, et non V.
!>

Paramètres

JOBU 
!>          JOBU est CHARACTER*1
!>          Spécifie les options pour calculer tout ou partie de la matrice U :
!>          = 'V' : les min(m,n) premières colonnes de U (les vecteurs singuliers
!>                  gauches) ou comme spécifié par RANGE sont retournées dans
!>                  le tableau U ;
!>          = 'N' : aucune colonne de U (aucun vecteur singulier gauche) n'est
!>                  calculée.
!>

JOBVT

!>          JOBVT est CHARACTER*1
!>           Spécifie les options pour calculer tout ou partie de la matrice
!>           V**T :
!>           = 'V' : les min(m,n) premières lignes de V**T (les vecteurs singuliers
!>                   droits) ou comme spécifié par RANGE sont retournées dans
!>                   le tableau VT ;
!>           = 'N' : aucune ligne de V**T (aucun vecteur singulier droit) n'est
!>                   calculée.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs singulières seront trouvées.
!>          = 'V' : toutes les valeurs singulières dans l'intervalle ouvert (VL,VU]
!>                  seront trouvées.
!>          = 'I' : les valeurs singulières de rang IL à IU seront trouvées.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A. N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          En entrée, la matrice A de taille M par N.
!>          En sortie, le contenu de A est détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

VL

!>          VL est DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs singulières. VU > VL.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs singulières. VU > VL.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur singulière à retourner.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur singulière à retourner.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

NS

!>          NS est INTEGER
!>          Le nombre total de valeurs singulières trouvées,
!>          0 <= NS <= min(M,N).
!>          Si RANGE = 'A', NS = min(M,N); si RANGE = 'I', NS = IU-IL+1.
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (min(M,N))
!>          Les valeurs singulières de A, triées de telle sorte que S(i) >= S(i+1).
!>

U

!>          U est un tableau COMPLEX*16, dimension (LDU,UCOL)
!>          Si JOBU = 'V', U contient les colonnes de U (les vecteurs singuliers
!>          gauches, stockés par colonne) comme spécifié par RANGE ; si
!>          JOBU = 'N', U n'est pas référencé.
!>          Note : L'utilisateur doit s'assurer que UCOL >= NS ; si RANGE = 'V',
!>          la valeur exacte de NS n'est pas connue à l'avance et une limite
!>          supérieure doit être utilisée.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= 1 ; si
!>          JOBU = 'V', LDU >= M.
!>

VT

!>          VT est un tableau COMPLEX*16, dimension (LDVT,N)
!>          Si JOBVT = 'V', VT contient les lignes de V**T (les vecteurs singuliers
!>          droits, stockés par ligne) comme spécifié par RANGE ; si JOBVT = 'N',
!>          VT n'est pas référencé.
!>          Note : L'utilisateur doit s'assurer que LDVT >= NS ; si RANGE = 'V',
!>          la valeur exacte de NS n'est pas connue à l'avance et une limite
!>          supérieure doit être utilisée.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT. LDVT >= 1 ; si
!>          JOBVT = 'V', LDVT >= NS (voir ci-dessus).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne le LWORK optimal ;
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= MAX(1,MIN(M,N)*(MIN(M,N)+4)) pour les chemins (voir
!>          les commentaires dans le code) :
!>             - CHEMIN 1  (M beaucoup plus grand que N)
!>             - CHEMIN 1t (N beaucoup plus grand que M)
!>          LWORK >= MAX(1,MIN(M,N)*2+MAX(M,N)) pour les autres chemins.
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LRWORK))
!>          LRWORK >= MIN(M,N)*(MIN(M,N)*2+15*MIN(M,N)).
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (12*MIN(M,N))
!>          Si INFO = 0, les NS premiers éléments de IWORK sont nuls. Si INFO > 0,
!>          alors IWORK contient les indices des vecteurs propres qui n'ont pas
!>          convergé dans DBDSVDX/DSTEVX.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution.
!>          < 0 : si le i-ème argument était illégal.
!>          > 0 : si le sous-programme d'appel de valeurs propres DBDSVDX/DSTEVX
!>                ou ses sous-programmes d'équilibrage et de réduction a
!>                rencontré un problème lors de la convergence, et
!>                IWORK(I) contient l'indice du vecteur propre qui n'a pas
!>                convergé.
!>
