!>
!>    ZGERFSX améliore la solution calculée d'un système d'équations
!>    linéaires et fournit des bornes d'erreur et des estimations d'erreur
!>    rétrograde pour la solution. En plus de la borne d'erreur normwise,
!>    le code fournit une borne d'erreur composante par composante maximale
!>    si possible. Voir les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP
!>    pour les détails des bornes d'erreur.
!>
!>    Le système d'équations linéaires original peut avoir été équilibré
!>    avant d'appeler cette routine, comme décrit par les arguments EQUED, R
!>    et C ci-dessous. Dans ce cas, la solution et les bornes d'erreur retournées
!>    sont pour le système original non équilibré.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment le raffinement est effectué, mais souvent
!>     les valeurs par défaut sont acceptables. Si les valeurs par défaut sont
!>     acceptables, les utilisateurs peuvent passer NPARAMS = 0, ce qui empêche
!>     le code source d'accéder à l'argument PARAMS.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N':  A * X = B     (Pas de transposée)
!>       = 'T':  A**T * X = B  (Transposée)
!>       = 'C':  A**H * X = B  (Conjuguée transposée)
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibrage qui a été effectuée sur A
!>     avant d'appeler cette routine. Ceci est nécessaire pour calculer
!>     correctement la solution et les bornes d'erreur.
!>       = 'N':  Aucun équilibrage
!>       = 'R':  Équilibrage des lignes, c'est-à-dire que A a été pré-multiplié par
!>               diag(R).
!>       = 'C':  Équilibrage des colonnes, c'est-à-dire que A a été post-multiplié
!>               par diag(C).
!>       = 'B':  Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(R) * A * diag(C).
!>               Le membre de droite B a été modifié en conséquence.
!>

N

!>          N est INTEGER
!>     L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>     La matrice originale N-par-N A.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEX*16, dimension (LDAF,N)
!>     Les facteurs L et U de la factorisation A = P*L*U
!>     tels que calculés par ZGETRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Les indices de pivot de ZGETRF ; pour 1<=i<=N, la ligne i de la
!>     matrice a été échangée avec la ligne IPIV(i).
!>

R

!>          R est un tableau DOUBLE PRÉCISION, dimension (N)
!>     Les facteurs d'échelle des lignes de A. Si EQUED = 'R' ou 'B', A est
!>     multiplié à gauche par diag(R) ; si EQUED = 'N' ou 'C', R
!>     n'est pas accédé.
!>     Si R est accédé, chaque élément de R doit être une puissance du radix
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à
!>     l'échelle par puissances du radix ne provoque pas d'erreurs d'arrondi,
!>     sauf si le résultat sous-dépasse ou sur-dépasse. Les erreurs d'arrondi
!>     lors de la mise à l'échelle conduisent à un raffinement avec une matrice
!>     qui n'est pas équivalente à la matrice d'entrée, produisant des
!>     estimations d'erreur qui peuvent ne pas être fiables.
!>

C

!>          C est un tableau DOUBLE PRÉCISION, dimension (N)
!>     Les facteurs d'échelle des colonnes de A. Si EQUED = 'C' ou 'B', A est
!>     multiplié à droite par diag(C) ; si EQUED = 'N' ou 'R', C
!>     n'est pas accédé.
!>     Si C est accédé, chaque élément de C doit être une puissance du radix
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à
!>     l'échelle par puissances du radix ne provoque pas d'erreurs d'arrondi,
!>     sauf si le résultat sous-dépasse ou sur-dépasse. Les erreurs d'arrondi
!>     lors de la mise à l'échelle conduisent à un raffinement avec une matrice
!>     qui n'est pas équivalente à la matrice d'entrée, produisant des
!>     estimations d'erreur qui peuvent ne pas être fiables.
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>     La matrice du membre de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX*16, dimension (LDX,NRHS)
!>     En entrée, la matrice solution X, telle que calculée par ZGETRS.
!>     En sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRÉCISION
!>     Condition number réciproque échelonné. C'est une estimation du
!>     condition number de Skeel réciproque de la matrice A après
!>     équilibrage (si effectué). Si ceci est inférieur à la précision de la machine
!>     (en particulier, si c'est zéro), la matrice est singulière
!>     à la précision de travail. Noter que l'erreur peut encore être faible même
!>     si ce nombre est très petit et que la matrice apparaît mal
!>     conditionnée.
!>

BERR

!>          BERR est un tableau DOUBLE PRÉCISION, dimension (NRHS)
!>     Erreur rétrograde relative composante par composante. C'est l'erreur
!>     rétrograde relative composante par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire le plus petit changement relatif dans tout élément de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>

Function/Subroutine Documentation

 !>
 !> \brief \b ZGERFSX
 !>
 !> \par Purpose
 !> ==
 !>
 !> ZGERFSX computes the error bounds and estimates of the reciprocal
 !> condition number(s) for solving a general complex linear system
 !> Z*X = B. For each right hand side, ZGERFSX also computes an
 !> estimate of the componentwise forward error vector.
 !>
 !> \par Arguments
 !> ==
 !>
 !> @param[in] MATRIX_TYPE
 !>           MATRIX_TYPE is CHARACTER*1
 !>           Specifies the form of the system of equations:
 !>           = 'G': Undefined.
 !>           = 'U': A is upper triangular.
 !>           = 'L': A is lower triangular.
 !>           = 'S': A is symmetric or Hermitian.
 !>           = 'H': A is symmetric or Hermitian positive definite.
 !>           = 'P': A is symmetric or Hermitian positive definite banded.
 !>           = 'R': A is a rectangular matrix.
 !>           = 'B': A is banded.
 !>           = 'T': A is tridiagonal.
 !>           = 'Z': A is general band.
 !>
 !> @param[in] TRANSPOSE
 !>           TRANSPOSE is CHARACTER*1
 !>           Specifies the form of the system of equations:
 !>           = 'N': None.
 !>           = 'T': Transpose.
 !>           = 'C': Conjugate transpose.
 !>
 !> @param[in] N
 !>           N is INTEGER
 !>           The order of the matrix A. N >= 0.
 !>
 !> @param[in] NRHS
 !>           NRHS is INTEGER
 !>           The number of right hand sides, i.e., the number of columns
 !>           of the matrices B and X. NRHS >= 0.
 !>
 !> @param[in] DLAMDA
 !>           DLAMDA is REAL (Kind=8)
 !>           DLAMDA is the smallest eigenvalue of A if A is symmetric
 !>           or Hermitian positive definite. Not used otherwise.
 !>
 !> @param[in] A
 !>           A is COMPLEX*16 array, dimension (LDA,N)
 !>           The coefficient matrix A of the linear system.
 !>
 !> @param[in] LDA
 !>           LDA is INTEGER
 !>           The leading dimension of the array A. LDA >= max(1,N).
 !>
 !> @param[in] AF
 !>           AF is COMPLEX*16 array, dimension (LDAF,N)
 !>           The factors of the matrix A from the factorization.
 !>
 !> @param[in] LDAF
 !>           LDAF is INTEGER
 !>           The leading dimension of the array AF. LDAF >= max(1,N).
 !>
 !> @param[in] IPIV
 !>           IPIV is INTEGER array, dimension (N)
 !>           The pivot indices from the factorization.
 !>
 !> @param[in] B
 !>           B is COMPLEX*16 array, dimension (LDB,NRHS)
 !>           The right-hand side matrix B.
 !>
 !> @param[in] LDB
 !>           LDB is INTEGER
 !>           The leading dimension of the array B. LDB >= max(1,N).
 !>
 !> @param[out] X
 !>           X is COMPLEX*16 array, dimension (LDX,NRHS)
 !>           The solution matrix X.
 !>
 !> @param[in] LDX
 !>           LDX is INTEGER
 !>           The leading dimension of the array X. LDX >= max(1,N).
 !>
 !> @param[out] RCOND
 !>           RCOND is REAL (Kind=8) array, dimension (NRHS)
 !>           The estimated reciprocal condition number for each right-
 !>           hand side.
 !>
 !> @param[out] BERR
 !>           BERR is REAL (Kind=8) array, dimension (NRHS)
 !>           The componentwise forward error estimate for each right-
 !>           hand side.
 !>
 !> @param[out] RES
 !>           RES is REAL (Kind=8) array, dimension (NRHS)
 !>           The estimated residual for each right-hand side.
 !>
 !> @param[out] WORK
 !>           WORK is COMPLEX*16 array, dimension (2*N)
 !>
 !> @param[out] RWORK
 !>           RWORK is DOUBLE PRECISION array, dimension (2*N)
 !>
 !> @param[out] PARAMS
 !>           PARAMS is DOUBLE PRECISION array, dimension NPARAMS
 !>           Specifies algorithm parameters.
 !>
 !> @param[in] NPARAMS
 !>           NPARAMS is INTEGER
 !>           Specifies the number of parameters set in PARAMS.
 !>
 !> @param[out] INFO
 !>           INFO is INTEGER
 !>           = 0:  Successful exit. The solution to every right-hand side is
 !>           guaranteed.
 !>           < 0:  If INFO = -i, the i-th argument had an illegal value
 !>           > 0 and <= N:  U(INFO,INFO) is exactly zero. The factorization
 !>           has been completed, but the factor U is exactly singular, so
 !>           the solution and error bounds could not be computed. RCOND = 0
 !>           is returned.
 !>           = N+J: The solution corresponding to the Jth right-hand side is
 !>           not guaranteed. The solutions corresponding to other right-
 !>           hand sides K with K > J may not be guaranteed as well, but
 !>           only the first such right-hand side is reported. If a small
 !>           componentwise error is not requested (PARAMS(3) = 0.0) then
 !>           the Jth right-hand side is the first with a normwise error
 !>           bound that is not guaranteed (the smallest J such
 !>           that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
 !>           the Jth right-hand side is the first with either a normwise or
 !>           componentwise error bound that is not guaranteed (the smallest
 !>           J such that either ERR_BNDS_NORM(J,1) = 0.0 or
 !>           ERR_BNDS_COMP(J,1) = 0.0). See the definition of
 !>           ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
 !>           about all of the right-hand sides check ERR_BNDS_NORM or
 !>           ERR_BNDS_COMP.
 !>
 !> \par Details
 !> ==
 !>
 !> The normwise relative error is defined as follows:
 !>
 !>            max_j (abs(XTRUE(j,i) - X(j,i)))
 !>           ------------------------------
 !>                 max_j abs(X(j,i))
 !>
 !> The componentwise relative error is defined as follows:
 !>
 !>                    abs(XTRUE(j,i) - X(j,i))
 !>            max_j ----------------------
 !>                         abs(X(j,i))
 !>
 !> See Lapack Working Note 165 for further details and extra cautions.
 !>
 !> \par Constants
 !> ==
 !>
 !> The following constants are used in PARAMS:
 !> LA_LINRX_ITREF_I = 1
 !> LA_LINRX_ITHRESH_I = 2
 !> LA_LINRX_CWISE_I = 3
 !>
 !> \par ERR_BNDS_NORM
 !>
 !> ERR_BNDS_NORM is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
 !> For each right-hand side, this array contains information about
 !> various error bounds and condition numbers corresponding to the
 !> normwise relative error, which is defined as follows:
 !>
 !> Normwise relative error in the ith solution vector:
 !>         max_j (abs(XTRUE(j,i) - X(j,i)))
 !>        ------------------------------
 !>              max_j abs(X(j,i))
 !>
 !> The array is indexed by the type of error information as described
 !> below. There currently are up to three pieces of information
 !> returned.
 !>
 !> The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
 !> right-hand side.
 !>
 !> The second index in ERR_BNDS_NORM(:,err) contains the following
 !> three fields:
 !> err = 1  boolean. Trust the answer if the
 !>          reciprocal condition number is less than the threshold
 !>          sqrt(n) * dlamch('Epsilon').
 !>
 !> err = 2  error bound: The estimated forward error,
 !>          almost certainly within a factor of 10 of the true error
 !>          so long as the next entry is greater than the threshold
 !>          sqrt(n) * dlamch('Epsilon'). This error bound should only
 !>          be trusted if the previous boolean is true.
 !>
 !> err = 3  Reciprocal condition number: Estimated normwise
 !>          reciprocal condition number.  Compared with the threshold
 !>          sqrt(n) * dlamch('Epsilon') to determine if the error
 !>          estimate is . These reciprocal condition
 !>          numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
 !>          appropriately scaled matrix Z.
 !>          Let Z = S*A, where S scales each row by a power of the
 !>          radix so all absolute row sums of Z are approximately 1.
 !>
 !> See Lapack Working Note 165 for further details and extra
 !> cautions.
 !>

ERR_BNDS_COMP


!>          ERR_BNDS_COMP is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     componentwise relative error, which is defined as follows:
!>
!>     Componentwise relative error in the ith solution vector:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     The array is indexed by the right-hand side i (on which the
!>     componentwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_COMP(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * dlamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated componentwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * dlamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some

!>
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

WORK
