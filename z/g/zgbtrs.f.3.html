Documentation de la fonction/sous-programme

sous-programme zgbtrs (caractère trans, entier n, entier kl, entier ku, entier nrhs, complexe*16, dimension( ldab, * ) ab, entier ldab, entier, dimension( * ) ipiv, complexe*16, dimension( ldb, * ) b, entier ldb, entier info)

ZGBTRS

But :

!>
!> ZGBTRS résout un système d'équations linéaires
!>    A * X = B,  A**T * X = B,  ou  A**H * X = B
!> avec une matrice bande générale A en utilisant la factorisation LU calculée
!> par ZGBTRF.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations.
!>          = 'N':  A * X = B     (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Transposée conjuguée)
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>          Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>          Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, dimension (LDAB,N)
!>          Détails de la factorisation LU de la matrice bande A, tels que
!>          calculés par ZGBTRF.  U est stockée comme une matrice bande triangulaire
!>          supérieure avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1, et
!>          les multiplicateurs utilisés pendant la factorisation sont stockés dans
!>          les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= N, la ligne i de la matrice a été
!>          échangée avec la ligne IPIV(i).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          En entrée, la matrice des seconds membres B.
!>          En sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
