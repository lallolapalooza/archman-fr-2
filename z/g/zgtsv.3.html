sous-routine zgtsv (n, nrhs, dl, d, du, b, ldb, info)
ZGTSV calcule la solution du système d'équations linéaires A * X = B pour les matrices GT

Documentation de la fonction/sous-routine

sous-routine zgtsv (integer n, integer nrhs, complex*16, dimension( * ) dl, complex*16, dimension( * ) d, complex*16, dimension( * ) du, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZGTSV résout l'équation A*X = B, où A est une matrice tridiagonale N x N, par élimination de Gauss avec pivotage partiel. Notez que l'équation A**T *X = B peut être résolue en échangeant l'ordre des arguments DU et DL.

But :

!>
!> ZGTSV résout l'équation
!>
!>    A*X = B,
!>
!> où A est une matrice tridiagonale N x N, par élimination de Gauss avec
!> pivotage partiel.
!>
!> Notez que l'équation  A**T *X = B  peut être résolue en échangeant l'ordre
!> des arguments DU et DL.
!>

Paramètres

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

DL

!>          DL est un tableau COMPLEX*16, de dimension (N-1)
!>          À l'entrée, DL doit contenir les (N-1) éléments sous-diagonaux
!>          de A.
!>          À la sortie, DL est écrasé par les (N-2) éléments de la
!>          deuxième supradiagonale de la matrice triangulaire supérieure U de
!>          la factorisation LU de A, dans DL(1), ..., DL(N-2).
!>

D

!>          D est un tableau COMPLEX*16, de dimension (N)
!>          À l'entrée, D doit contenir les éléments diagonaux de A.
!>          À la sortie, D est écrasé par les N éléments diagonaux de U.
!>

DU

!>          DU est un tableau COMPLEX*16, de dimension (N-1)
!>          À l'entrée, DU doit contenir les (N-1) éléments supradiagonaux
!>          de A.
!>          À la sortie, DU est écrasé par les (N-1) éléments de la première
!>          supradiagonale de U.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice de côtés droits B de taille N x NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N x NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, U(i,i) est exactement zéro, et la solution
!>                n'a pas été calculée. La factorisation n'est pas complétée
!>                sauf si i = N.
!>
