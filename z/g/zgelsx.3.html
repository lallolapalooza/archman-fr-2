Documentation de la fonction/sous-programme

sous-programme zgelsx (entier m, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, entier, dimension( * ) jpvt, double précision rcond, entier rank, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier info)

ZGELSX résout les systèmes surdéterminés ou sousdéterminés pour les matrices GE

Objectif :

!>
!> Cette routine est obsolète et a été remplacée par la routine ZGELSY.
!>
!> ZGELSX calcule la solution de norme minimale d'un problème de moindres carrés
!> linéaires complexes :
!>     minimiser || A * X - B ||
!> en utilisant une factorisation orthogonale complète de A. A est une matrice
!> M par N qui peut être de rang déficient.
!>
!> Plusieurs vecteurs second membre b et vecteurs solution x peuvent être
!> traités en un seul appel ; ils sont stockés sous forme de colonnes des
!> matrices second membre B (M x NRHS) et solution X (N x NRHS).
!>
!> La routine calcule d'abord une factorisation QR avec pivotement de colonnes :
!>     A * P = Q * [ R11 R12 ]
!>                 [  0  R22 ]
!> où R11 est la plus grande sous-matrice principale dont le numéro de condition
!> estimé est inférieur à 1/RCOND. L'ordre de R11, RANK, est le rang effectif de A.
!>
!> Ensuite, R22 est considéré comme négligeable, et R12 est annihilé
!> par des transformations unitaires à droite, arrivant à la
!> factorisation orthogonale complète :
!>    A * P = Q * [ T11 0 ] * Z
!>                [  0  0 ]
!> La solution de norme minimale est alors
!>    X = P * Z**H [ inv(T11)*Q1**H*B ]
!>                 [        0         ]
!> où Q1 contient les RANK premières colonnes de Q.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau de type COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la matrice A de M lignes et N colonnes.
!>          À la sortie, A a été écrasée par les détails de sa
!>          factorisation orthogonale complète.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

B

!>          B est un tableau de type COMPLEX*16, dimension (LDB,NRHS)
!>          À l'entrée, la matrice B de M lignes et NRHS colonnes.
!>          À la sortie, la matrice solution X de N lignes et NRHS colonnes.
!>          Si m >= n et RANK = n, la somme des carrés résiduels pour
!>          la solution dans la i-ème colonne est donnée par la somme des
!>          carrés des éléments N+1:M de cette colonne.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,M,N).
!>

JPVT

!>          JPVT est un tableau de type ENTIER, dimension (N)
!>          À l'entrée, si JPVT(i) .ne. 0, la i-ème colonne de A est une
!>          colonne initiale, sinon c'est une colonne libre. Avant
!>          la factorisation QR de A, toutes les colonnes initiales sont
!>          permutées vers les positions principales ; seules les colonnes
!>          libres restantes sont déplacées suite au pivotement de colonnes
!>          pendant la factorisation.
!>          À la sortie, si JPVT(i) = k, alors la i-ème colonne de A*P
!>          était la k-ième colonne de A.
!>

RCOND

!>          RCOND est de type DOUBLE PRÉCISION
!>          RCOND est utilisé pour déterminer le rang effectif de A, qui
!>          est défini comme l'ordre de la plus grande sous-matrice triangulaire
!>          principale R11 dans la factorisation QR avec pivotement de A,
!>          dont le numéro de condition estimé est < 1/RCOND.
!>

RANK

!>          RANK est un ENTIER
!>          Le rang effectif de A, c'est-à-dire l'ordre de la sous-matrice
!>          R11. Ceci est identique à l'ordre de la sous-matrice T11
!>          dans la factorisation orthogonale complète de A.
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, dimension
!>                      (min(M,N) + max( N, 2*min(M,N)+NRHS )),
!>

RWORK

!>          RWORK est un tableau de type DOUBLE PRÉCISION, dimension (2*N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
