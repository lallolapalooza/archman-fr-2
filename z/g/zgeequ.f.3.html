subroutine zgeequ (m, n, a, lda, r, c, rowcnd, colcnd, amax, info)
ZGEEQU

Documentation de la fonction/sous-programme

sous-programme zgeequ (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision rowcnd, double precision colcnd, double precision amax, integer info)

ZGEEQU

But:

!>
!> ZGEEQU calcule les échelles de lignes et de colonnes destinées à équilibrer
!> une matrice A de taille M par N et à réduire son nombre de conditionnement.
!> R renvoie les facteurs d'échelle de ligne et C les facteurs d'échelle de
!> colonne, choisis pour tenter de rendre l'élément de plus grande valeur
!> absolue dans chaque ligne et colonne de la matrice B, où
!> B(i,j)=R(i)*A(i,j)*C(j), égale à 1 en valeur absolue.
!>
!> R(i) et C(j) sont limités aux valeurs comprises entre SMLNUM = plus petit
!> nombre sûr et BIGNUM = plus grand nombre sûr. L'utilisation de ces
!> facteurs d'échelle n'est pas garantie de réduire le nombre de
!> conditionnement de A, mais fonctionne bien en pratique.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

A

!>          A est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>          La matrice M par N dont les facteurs d'équilibrage doivent
!>          être calculés.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

R

!>          R est un tableau de type DOUBLE PRECISION, de dimension (M)
!>          Si INFO = 0 ou INFO > M, R contient les facteurs d'échelle
!>          de ligne pour A.
!>

C

!>          C est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          Si INFO = 0, C contient les facteurs d'échelle de colonne pour A.
!>

ROWCND

!>          ROWCND est de type DOUBLE PRECISION
!>          Si INFO = 0 ou INFO > M, ROWCND contient le rapport du plus
!>          petit R(i) au plus grand R(i). Si ROWCND >= 0.1 et que AMAX
!>          n'est ni trop grand ni trop petit, il n'est pas nécessaire
!>          d'effectuer une mise à l'échelle par R.
!>

COLCND

!>          COLCND est de type DOUBLE PRECISION
!>          Si INFO = 0, COLCND contient le rapport du plus petit C(i)
!>          au plus grand C(i). Si COLCND >= 0.1, il n'est pas nécessaire
!>          d'effectuer une mise à l'échelle par C.
!>

AMAX

!>          AMAX est de type DOUBLE PRECISION
!>          La valeur absolue de l'élément de matrice le plus grand. Si AMAX
!>          est très proche du dépassement de capacité (overflow) ou très
!>          proche du sous-dépassement de capacité (underflow), la matrice
!>          doit être mise à l'échelle.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= M : la i-ème ligne de A est exactement zéro
!>                >  M : la (i-M)-ème colonne de A est exactement zéro
!>
