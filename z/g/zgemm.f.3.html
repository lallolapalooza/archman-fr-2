sous-routine zgemm (transa, transb, m, n, k, alpha, a, lda, b, ldb, beta, c, ldc)
ZGEMM

Documentation de la fonction/sous-routine

sous-routine zgemm (caractère transa, caractère transb, entier m, entier n, entier k, complexe*16 alpha, complexe*16, dimension(lda,*) a, entier lda, complexe*16, dimension(ldb,*) b, entier ldb, complexe*16 beta, complexe*16, dimension(ldc,*) c, entier ldc)

ZGEMM

Objectif :

!>
!> ZGEMM  effectue une des opérations matricielles
!>
!>    C := alpha*op( A )*op( B ) + beta*C,
!>
!> où  op( X ) est l'une des opérations suivantes :
!>
!>    op( X ) = X   ou   op( X ) = X**T   ou   op( X ) = X**H,
!>
!> alpha et beta sont des scalaires, et A, B et C sont des matrices, avec op( A )
!> une matrice de taille m par k, op( B ) une matrice de taille k par n et C une matrice de taille m par n.
!>

Paramètres

TRANSA 
!>          TRANSA est CHARACTER*1
!>           À l'entrée, TRANSA spécifie la forme de op( A ) à utiliser dans
!>           la multiplication matricielle comme suit :
!>
!>              TRANSA = 'N' ou 'n',  op( A ) = A.
!>
!>              TRANSA = 'T' ou 't',  op( A ) = A**T.
!>
!>              TRANSA = 'C' ou 'c',  op( A ) = A**H.
!>

TRANSB

!>          TRANSB est CHARACTER*1
!>           À l'entrée, TRANSB spécifie la forme de op( B ) à utiliser dans
!>           la multiplication matricielle comme suit :
!>
!>              TRANSB = 'N' ou 'n',  op( B ) = B.
!>
!>              TRANSB = 'T' ou 't',  op( B ) = B**T.
!>
!>              TRANSB = 'C' ou 'c',  op( B ) = B**H.
!>

M

!>          M est INTEGER
!>           À l'entrée, M spécifie le nombre de lignes de la matrice
!>           op( A ) et de la matrice C. M doit être supérieur ou égal à zéro.
!>

N

!>          N est INTEGER
!>           À l'entrée, N spécifie le nombre de colonnes de la matrice
!>           op( B ) et le nombre de colonnes de la matrice C. N doit être
!>           supérieur ou égal à zéro.
!>

K

!>          K est INTEGER
!>           À l'entrée, K spécifie le nombre de colonnes de la matrice
!>           op( A ) et le nombre de lignes de la matrice op( B ). K doit
!>           être supérieur ou égal à zéro.
!>

ALPHA

!>          ALPHA est COMPLEX*16
!>           À l'entrée, ALPHA spécifie le scalaire alpha.
!>

A

!>          A est un tableau COMPLEX*16, de dimension ( LDA, ka ), où ka est
!>           k  lorsque  TRANSA = 'N' ou 'n',  et est  m  sinon.
!>           Avant l'entrée avec  TRANSA = 'N' ou 'n', la partie principale de m par k
!>           du tableau A doit contenir la matrice A, sinon
!>           la partie principale de k par m du tableau A doit contenir la
!>           matrice A.
!>

LDA

!>          LDA est INTEGER
!>           À l'entrée, LDA spécifie la première dimension de A telle que déclarée
!>           dans le programme appelant (sub)routine. Lorsque  TRANSA = 'N' ou 'n' alors
!>           LDA doit être au moins  max( 1, m ), sinon  LDA doit être au
!>           moins  max( 1, k ).
!>

B

!>          B est un tableau COMPLEX*16, de dimension ( LDB, kb ), où kb est
!>           n  lorsque  TRANSB = 'N' ou 'n',  et est  k  sinon.
!>           Avant l'entrée avec  TRANSB = 'N' ou 'n', la partie principale de k par n
!>           du tableau B doit contenir la matrice B, sinon
!>           la partie principale de n par k du tableau B doit contenir la
!>           matrice B.
!>

LDB

!>          LDB est INTEGER
!>           À l'entrée, LDB spécifie la première dimension de B telle que déclarée
!>           dans le programme appelant (sub)routine. Lorsque  TRANSB = 'N' ou 'n' alors
!>           LDB doit être au moins  max( 1, k ), sinon  LDB doit être au
!>           moins  max( 1, n ).
!>

BETA

!>          BETA est COMPLEX*16
!>           À l'entrée, BETA spécifie le scalaire beta. Lorsque BETA
!>           est fourni comme zéro, C n'a pas besoin d'être défini à l'entrée.
!>

C

!>          C est un tableau COMPLEX*16, de dimension ( LDC, N )
!>           Avant l'entrée, la partie principale de m par n
!>           du tableau C doit contenir la matrice C, sauf lorsque beta est zéro,
!>           auquel cas C n'a pas besoin d'être défini à l'entrée.
!>           À la sortie, le tableau C est écrasé par la matrice m par n
!>           ( alpha*op( A )*op( B ) + beta*C ).
!>

LDC

!>          LDC est INTEGER
!>           À l'entrée, LDC spécifie la première dimension de C telle que déclarée
!>           dans le programme appelant (sub)routine. LDC doit être au moins
!>           max( 1, m ).
!>
