sous-programme zgtts2 (entier itrans, entier n, entier nrhs, complexe*16, dimension( * ) dl, complexe*16, dimension( * ) d, complexe*16, dimension( * ) du, complexe*16, dimension( * ) du2, entier, dimension( * ) ipiv, complexe*16, dimension( ldb, * ) b, entier ldb)

ZGTTS2 résout un système d'équations linéaires avec une matrice tridiagonale en utilisant la factorisation LU calculée par sgttrf.

Objectif :

!>
!> ZGTTS2 résout l'un des systèmes d'équations
!>    A * X = B,  A**T * X = B,  ou  A**H * X = B,
!> avec une matrice tridiagonale A en utilisant la factorisation LU calculée
!> par ZGTTRF.
!>

Paramètres

ITRANS 
!>          ITRANS est ENTIER
!>          Spécifie la forme du système d'équations.
!>          = 0 :  A * X = B     (Pas de transposée)
!>          = 1 :  A**T * X = B  (Transposée)
!>          = 2 :  A**H * X = B  (Conjuguée transposée)
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

DL

!>          DL est un tableau COMPLEX*16, de dimension (N-1)
!>          Les (n-1) multiplicateurs qui définissent la matrice L de la
!>          factorisation LU de A.
!>

D

!>          D est un tableau COMPLEX*16, de dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire supérieure U de
!>          la factorisation LU de A.
!>

DU

!>          DU est un tableau COMPLEX*16, de dimension (N-1)
!>          Les (n-1) éléments de la première super-diagonale de U.
!>

DU2

!>          DU2 est un tableau COMPLEX*16, de dimension (N-2)
!>          Les (n-2) éléments de la deuxième super-diagonale de U.
!>

IPIV

!>          IPIV est un tableau ENTIER, de dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= n, la ligne i de la matrice a
!>          été échangée avec la ligne IPIV(i).  IPIV(i) sera toujours égal à
!>          i ou i+1 ; IPIV(i) = i indique qu'un échange de ligne n'était pas
!>          requis.
!>

B

!>          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice des vecteurs de membre de droite B.
!>          À la sortie, B est écrasé par les vecteurs solution X.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>
