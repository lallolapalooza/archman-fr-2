sous-programme zgelsy (entier m, entier n, entier nrhs, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( ldb, * ) b, entier ldb, entier, dimension( * ) jpvt, double précision rcond, entier rank, complexe*16, dimension( * ) work, entier lwork, double précision, dimension( * ) rwork, entier info)

ZGELSY résout les systèmes surdéterminés ou sous-déterminés pour les matrices GE

Objectif :

!>
!> ZGELSY calcule la solution de norme minimale du problème des moindres carrés linéaires complexes :
!>     minimiser || A * X - B ||
!> en utilisant une factorisation orthogonale complète de A. A est une matrice M par N
!> qui peut être de rang-déficient.
!>
!> Plusieurs vecteurs second membre b et vecteurs solution x peuvent être
!> traités en un seul appel ; ils sont stockés comme colonnes de la
!> matrice second membre B (M par NRHS) et de la matrice solution X (N par NRHS).
!>
!> La routine calcule d'abord une factorisation QR avec pivotement de colonnes :
!>     A * P = Q * [ R11 R12 ]
!>                 [  0  R22 ]
!> avec R11 défini comme la plus grande sous-matrice principale dont le numéro de condition estimé
!> est inférieur à 1/RCOND. L'ordre de R11, RANK,
!> est le rang effectif de A.
!>
!> Ensuite, R22 est considéré comme négligeable, et R12 est annihilé
!> par des transformations unitaires par la droite, arrivant à la
!> factorisation orthogonale complète :
!>    A * P = Q * [ T11 0 ] * Z
!>                [  0  0 ]
!> La solution de norme minimale est alors
!>    X = P * Z**H [ inv(T11)*Q1**H*B ]
!>                 [        0         ]
!> où Q1 est constitué des RANK premières colonnes de Q.
!>
!> Cette routine est essentiellement identique à la xGELSX originale, sauf
!> trois différences :
!>   o La permutation de la matrice B (le second membre) est plus rapide et
!>     plus simple.
!>   o L'appel à la sous-routine xGEQPF a été remplacé par l'appel
!>     à la sous-routine xGEQP3. Cette sous-routine est une version Blas-3
!>     de la factorisation QR avec pivotement de colonnes.
!>   o La matrice B (le second membre) est mise à jour avec Blas-3.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M par N.
!>          À la sortie, A est écrasée par les détails de sa
!>          factorisation orthogonale complète.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          À l'entrée, la matrice second membre B de taille M par NRHS.
!>          À la sortie, la matrice solution X de taille N par NRHS.
!>          Si M = 0 ou N = 0, B n'est pas référencé.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,M,N).
!>

JPVT

!>          JPVT est un tableau ENTIER, dimension (N)
!>          À l'entrée, si JPVT(i) .ne. 0, la i-ème colonne de A est permutée
!>          au début de AP, sinon la colonne i est une colonne libre.
!>          À la sortie, si JPVT(i) = k, alors la i-ème colonne de A*P
!>          était la k-ème colonne de A.
!>

RCOND

!>          RCOND est un DOUBLE PRÉCISION
!>          RCOND est utilisé pour déterminer le rang effectif de A, qui
!>          est défini comme l'ordre de la plus grande sous-matrice triangulaire
!>          principale R11 dans la factorisation QR avec pivotement de A,
!>          dont le numéro de condition estimé est < 1/RCOND.
!>

RANK

!>          RANK est un ENTIER
!>          Le rang effectif de A, c'est-à-dire l'ordre de la sous-matrice
!>          R11. C'est aussi l'ordre de la sous-matrice T11
!>          dans la factorisation orthogonale complète de A.
!>          Si NRHS = 0, RANK = 0 en sortie.
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille optimale LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>          La stratégie non-bloquée nécessite que :
!>            LWORK >= MN + MAX( 2*MN, N+1, MN+NRHS )
!>          où MN = min(M,N).
!>          L'algorithme bloqué nécessite que :
!>            LWORK >= MN + MAX( 2*MN, NB*(N+1), MN*NB, MN+NB*NRHS )
!>          où NB est une borne supérieure de la taille de bloc renvoyée
!>          par ILAENV pour les routines ZGEQP3, ZTZRZF, CTZRQF, ZUNMQR,
!>          et ZUNMRZ.
!>
!>          Si LWORK = -1, alors une requête de dimension de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          concernant LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (2*N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : exécution réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
