Documentation de la fonction/sous-routine

sous-routine zgeequ (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision rowcnd, double precision colcnd, double precision amax, integer info)

ZGEEQU

But :

!>
!> ZGEEQU calcule les mises à l'échelle des lignes et des colonnes destinées à équilibrer une
!> matrice A de taille M par N et à réduire son nombre de conditionnement. R retourne les
!> facteurs d'échelle des lignes et C ceux des colonnes, choisis pour tenter de faire en sorte que
!> l'élément de plus grande valeur absolue dans chaque ligne et chaque colonne de la matrice B,
!> dont les éléments sont B(i,j)=R(i)*A(i,j)*C(j), ait une valeur absolue de 1.
!>
!> R(i) et C(j) sont limités entre SMLNUM = le plus petit nombre sûr
!> et BIGNUM = le plus grand nombre sûr. L'utilisation de ces facteurs de mise à l'échelle
!> n'est pas garantie de réduire le nombre de conditionnement de A mais
!> fonctionne bien en pratique.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

A

!>          A est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>          La matrice M par N dont les facteurs d'équilibrage doivent être
!>          calculés.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

R

!>          R est un tableau de type DOUBLE PRECISION, de dimension (M)
!>          Si INFO = 0 ou INFO > M, R contient les facteurs d'échelle des lignes
!>          pour A.
!>

C

!>          C est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          Si INFO = 0, C contient les facteurs d'échelle des colonnes pour A.
!>

ROWCND

!>          ROWCND est de type DOUBLE PRECISION
!>          Si INFO = 0 ou INFO > M, ROWCND contient le rapport du plus petit R(i)
!>          au plus grand R(i). Si ROWCND >= 0.1 et AMAX n'est ni trop grand ni trop petit,
!>          il n'est pas utile de mettre à l'échelle par R.
!>

COLCND

!>          COLCND est de type DOUBLE PRECISION
!>          Si INFO = 0, COLCND contient le rapport du plus petit C(i)
!>          au plus grand C(i). Si COLCND >= 0.1, il n'est pas
!>          utile de mettre à l'échelle par C.
!>

AMAX

!>          AMAX est de type DOUBLE PRECISION
!>          La valeur absolue de l'élément de matrice le plus grand. Si AMAX est très
!>          proche du dépassement ou de la sous-valeur, la matrice
!>          devrait être mise à l'échelle.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= M : la i-ème ligne de A est exactement nulle
!>                >  M : la (i-M)-ème colonne de A est exactement nulle
!>
