Documentation de la fonction/sous-routine

sous-routine zgelqs (integer m, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( lwork ) work, integer lwork, integer info)

ZGELQS

But :

!>
!> Calculer une solution de norme minimale
!>     min || A*X - B ||
!> en utilisant la factorisation LQ
!>     A = L*Q
!> calculée par ZGELQF.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice A.  N >= M >= 0.
!>

NRHS

!>          NRHS est un entier
!>          Le nombre de colonnes de B.  NRHS >= 0.
!>

A

!>          A est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>          Détails de la factorisation LQ de la matrice originale A retournés
!>          par ZGELQF.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A.  LDA >= M.
!>

TAU

!>          TAU est un tableau de type COMPLEX*16, de dimension (M)
!>          Détails de la matrice orthogonale Q.
!>

B

!>          B est un tableau de type COMPLEX*16, de dimension (LDB,NRHS)
!>          En entrée, la matrice B de membre droit de dimension m-par-nrhs.
!>          En sortie, la matrice solution X de dimension n-par-nrhs.
!>

LDB

!>          LDB est un entier
!>          La dimension principale du tableau B. LDB >= N.
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, de dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>          La longueur du tableau WORK.  LWORK doit être au moins NRHS,
!>          et devrait être au moins NRHS*NB, où NB est la taille de bloc
!>          pour cet environnement.
!>

INFO

!>          INFO est un entier
!>          = 0: succès
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
