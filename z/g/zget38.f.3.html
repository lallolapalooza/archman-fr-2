sous-programme zget38 (double precision, dimension( 3 ) rmax, integer, dimension( 3 ) lmax, integer, dimension( 3 ) ninfo, integer knt, integer nin)

ZGET38

But :

!>
!> ZGET38 teste ZTRSEN, une routine pour estimer les nombres de conditionnement
!> d'un cluster de valeurs propres et/ou de son sous-espace invariant à droite associé.
!>
!> Les matrices de test sont lues à partir d'un fichier avec le numéro logique NIN.
!>

Paramètres

RMAX 
!>          RMAX est un tableau DOUBLE PRECISION, dimension (3)
!>          Valeurs des plus grands rapports de test.
!>          RMAX(1) = plus grands résidus de ZHST01 ou comparaison
!>                    entre différents appels à ZTRSEN
!>          RMAX(2) = plus grande erreur dans les nombres de conditionnement réciproques
!>                    en tenant compte de leur conditionnement
!>          RMAX(3) = plus grande erreur dans les nombres de conditionnement réciproques
!>                    sans tenir compte de leur conditionnement (peut être plus grand que RMAX(2))
!>

LMAX

!>          LMAX est un tableau INTEGER, dimension (3)
!>          LMAX(i) est le numéro de l'exemple où le plus grand rapport de test
!>          RMAX(i) est atteint. Aussi :
!>          Si ZGEHRD renvoie INFO non nul sur l'exemple i, LMAX(1)=i
!>          Si ZHSEQR renvoie INFO non nul sur l'exemple i, LMAX(2)=i
!>          Si ZTRSEN renvoie INFO non nul sur l'exemple i, LMAX(3)=i
!>

NINFO

!>          NINFO est un tableau INTEGER, dimension (3)
!>          NINFO(1) = Nombre de fois où ZGEHRD a renvoyé INFO non nul
!>          NINFO(2) = Nombre de fois où ZHSEQR a renvoyé INFO non nul
!>          NINFO(3) = Nombre de fois où ZTRSEN a renvoyé INFO non nul
!>

KNT

!>          KNT est un INTEGER
!>          Nombre total d'exemples testés.
!>

NIN

!>          NIN est un INTEGER
!>          Numéro logique d'entrée.
!>
