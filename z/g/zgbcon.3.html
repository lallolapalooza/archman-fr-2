sous-programme zgbcon (caractere norm, entier n, entier kl, entier ku, complexe*16, dimension( ldab, * ) ab, entier ldab, entier, dimension( * ) ipiv, double precision anorm, double precision rcond, complexe*16, dimension( * ) work, double precision, dimension( * ) rwork, entier info)

ZGBCON

But:

!>
!> ZGBCON estime l'inverse du nombre de condition d'une matrice bande générale
!> complexe A, dans la norme 1 ou la norme infinie, en utilisant la
!> factorisation LU calculée par ZGBTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et l'inverse du nombre de
!> condition est calculé comme suit :
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Paramètres

NORM 
!>          NORM est CHARACTER*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme
!>          infinie est requis :
!>          = '1' ou 'O':  Norme 1 ;
!>          = 'I':         Norme infinie.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>          Nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>          Nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

AB

!>          AB est un tableau de type COMPLEX*16, dimension (LDAB,N)
!>          Détails de la factorisation LU de la matrice bande A, tels
!>          que calculés par ZGBTRF.  U est stockée comme une matrice bande
!>          triangulaire supérieure avec KL+KU super-diagonales dans les
!>          lignes 1 à KL+KU+1, et les multiplicateurs utilisés pendant
!>          la factorisation sont stockés dans les lignes KL+KU+2 à
!>          2*KL+KU+1.
!>

LDAB

!>          LDAB est INTEGER
!>          Dimension principale du tableau AB.  LDAB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau de type INTEGER, dimension (N)
!>          Indices de pivot ; pour 1 <= i <= N, la ligne i de la matrice a
!>          été échangée avec la ligne IPIV(i).
!>

ANORM

!>          ANORM est DOUBLE PRECISION
!>          Si NORM = '1' ou 'O', la norme 1 de la matrice originale A.
!>          Si NORM = 'I', la norme infinie de la matrice originale A.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'inverse du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK est un tableau de type COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau de type DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'opération
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
