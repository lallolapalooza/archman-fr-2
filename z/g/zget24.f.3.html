sous-programme zget24 (logique comp, entier jtype, double précision thresh, entier, dimension( 4 ) iseed, entier nounit, entier n, complexe*16, dimension( lda, * ) a, entier lda, complexe*16, dimension( lda, * ) h, complexe*16, dimension( lda, * ) ht, complexe*16, dimension( * ) w, complexe*16, dimension( * ) wt, complexe*16, dimension( * ) wtmp, complexe*16, dimension( ldvs, * ) vs, entier ldvs, complexe*16, dimension( ldvs, * ) vs1, double précision rcdein, double précision rcdvin, entier nslct, entier, dimension( * ) islct, entier isrt, double précision, dimension( 17 ) result, complexe*16, dimension( * ) work, entier lwork, double précision, dimension( * ) rwork, logique, dimension( * ) bwork, entier info)

ZGET24

Objectif:

!>
!>    ZGET24 vérifie le problème de valeurs propres non symétriques (forme de Schur)
!>    du pilote expert ZGEESX.
!>
!>    Si COMP = .FAUX., les 13 premiers tests parmi les suivants seront
!>    effectués sur la matrice d'entrée A, ainsi que les tests 14 et 15
!>    si LWORK est suffisamment grand.
!>    Si COMP = .VRAI., les 17 tests seront effectués.
!>
!>    (1)     0 si T est sous forme de Schur, 1/ulp sinon
!>           (pas de tri des valeurs propres)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Ici VS est la matrice des vecteurs propres de Schur, et T est sous forme de Schur
!>      (pas de tri des valeurs propres).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (pas de tri des valeurs propres).
!>
!>    (4)     0     si W sont les valeurs propres de T
!>            1/ulp sinon
!>            (pas de tri des valeurs propres)
!>
!>    (5)     0     si T(avec VS) = T(sans VS),
!>            1/ulp sinon
!>            (pas de tri des valeurs propres)
!>
!>    (6)     0     si les valeurs propres(avec VS) = les valeurs propres(sans VS),
!>            1/ulp sinon
!>            (pas de tri des valeurs propres)
!>
!>    (7)     0 si T est sous forme de Schur, 1/ulp sinon
!>            (avec tri des valeurs propres)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Ici VS est la matrice des vecteurs propres de Schur, et T est sous forme de Schur
!>      (avec tri des valeurs propres).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (avec tri des valeurs propres).
!>
!>    (10)    0     si W sont les valeurs propres de T
!>            1/ulp sinon
!>            Si l'espace de travail est suffisant, comparer également W avec et
!>            sans nombres de condition inverses
!>            (avec tri des valeurs propres)
!>
!>    (11)    0     si T(avec VS) = T(sans VS),
!>            1/ulp sinon
!>            Si l'espace de travail est suffisant, comparer également T avec et sans
!>            nombres de condition inverses
!>            (avec tri des valeurs propres)
!>
!>    (12)    0     si les valeurs propres(avec VS) = les valeurs propres(sans VS),
!>            1/ulp sinon
!>            Si l'espace de travail est suffisant, comparer également VS avec et sans
!>            nombres de condition inverses
!>            (avec tri des valeurs propres)
!>
!>    (13)    si le tri a fonctionné et SDIM est le nombre de
!>            valeurs propres qui ont été SÉLECTIONNÉES
!>            Si l'espace de travail est suffisant, comparer également SDIM avec et sans
!>            nombres de condition inverses
!>
!>    (14)    si RCONDE est le même, peu importe si VS et/ou RCONDV sont calculés
!>
!>    (15)    si RCONDV est le même, peu importe si VS et/ou RCONDE sont calculés
!>
!>    (16)  |RCONDE - RCDEIN| / cond(RCONDE)
!>
!>       RCONDE est le nombre de condition moyen inverse des valeurs propres
!>       calculé par ZGEESX et RCDEIN (la valeur vraie pré-calculée)
!>       est fourni en entrée. cond(RCONDE) est le nombre de condition
!>       de RCONDE, et prend en compte les erreurs dans le calcul de RCONDE,
!>       de sorte que la quantité résultante devrait être de l'ordre de ULP. cond(RCONDE)
!>       est essentiellement donné par norm(A)/RCONDV.
!>
!>    (17)  |RCONDV - RCDVIN| / cond(RCONDV)
!>
!>       RCONDV est le nombre de condition inverse du sous-espace invariant à droite
!>       calculé par ZGEESX et RCDVIN (la valeur vraie pré-calculée)
!>       est fourni en entrée. cond(RCONDV) est le nombre de condition
!>       de RCONDV, et prend en compte les erreurs dans le calcul de RCONDV,
!>       de sorte que la quantité résultante devrait être de l'ordre de ULP.
!>       cond(RCONDV) est essentiellement donné par norm(A)/RCONDE.
!>

Paramètres

COMP 
!>          COMP est LOGIQUE
!>          COMP décrit quels tests d'entrée effectuer :
!>            = .FAUX.  si les nombres de condition calculés ne doivent pas
!>                      être testés par rapport à RCDVIN et RCDEIN
!>            = .VRAI.  s'ils doivent être comparés
!>

JTYPE

!>          JTYPE est ENTIER
!>          Type de matrice d'entrée. Utilisé pour étiqueter la sortie en cas d'erreur.
!>

ISEED

!>          ISEED est un tableau ENTIER, dimension (4)
!>          Si COMP = .FAUX., la graine du générateur de nombres aléatoires
!>          utilisée pour produire la matrice.
!>          Si COMP = .VRAI., ISEED(1) = le numéro de l'exemple.
!>          Utilisé pour étiqueter la sortie en cas d'erreur.
!>

THRESH

!>          THRESH est DOUBLE PRÉCISION
!>          Un test sera considéré comme réussi si le résultat, calculé comme
!>          décrit ci-dessus, ne dépasse pas THRESH. Notez que l'erreur
!>          est mise à l'échelle pour être de l'ordre de O(1), donc THRESH devrait être un multiple raisonnablement
!>          petit de 1, par exemple, 10 ou 100. En particulier,
!>          il ne doit pas dépendre de la précision (simple ou double)
!>          ou de la taille de la matrice. Il doit être au moins zéro.
!>

NOUNIT

!>          NOUNIT est ENTIER
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (par exemple, si une routine renvoie INFO différent de 0.)
!>

N

!>          N est ENTIER
!>          La dimension de A. N doit être au moins 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>          Utilisé pour contenir la matrice dont les valeurs propres doivent être
!>          calculées.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale de A et H. LDA doit être
!>          au moins 1 et au moins N.
!>

H

!>          H est un tableau COMPLEX*16, dimension (LDA, N)
!>          Une autre copie de la matrice de test A, modifiée par ZGEESX.
!>

HT

!>          HT est un tableau COMPLEX*16, dimension (LDA, N)
!>          Encore une autre copie de la matrice de test A, modifiée par ZGEESX.
!>

W

!>          W est un tableau COMPLEX*16, dimension (N)
!>          Les valeurs propres calculées de A.
!>

WT

!>          WT est un tableau COMPLEX*16, dimension (N)
!>          Comme W, ce tableau contient les valeurs propres de A,
!>          mais celles calculées lorsque ZGEESX ne calcule qu'une décomposition
!>          partielle des valeurs propres, c'est-à-dire sans vecteurs de Schur.
!>

WTMP

!>          WTMP est un tableau COMPLEX*16, dimension (N)
!>
!>          Un tampon pour W.
!>

VS

!>          VS est un tableau COMPLEX*16, dimension (LDVS, N)
!>          La matrice des vecteurs propres de Schur de A.
!>

LDVS

!>          LDVS est ENTIER
!>          La dimension principale de VS et VS1. LDVS doit être
!>          au moins N.
!>

VS1

!>          VS1 est un tableau COMPLEX*16, dimension (LDVS, N)
!>          Une autre copie de VS.
!>

RCDEIN

!>          RCDEIN est DOUBLE PRÉCISION
!>          La valeur vraie pré-calculée du nombre de condition moyen inverse des valeurs propres.
!>

RCDVIN

!>          RCDVIN est DOUBLE PRÉCISION
!>          La valeur vraie pré-calculée du nombre de condition inverse du sous-espace invariant à droite.
!>

NSLCT

!>          NSLCT est ENTIER
!>          Le nombre de valeurs propres sélectionnées.
!>

ISLCT

!>          ISLCT est un tableau ENTIER, dimension (N)
!>          Indique quelles valeurs propres sont sélectionnées.
!>

ISRT

!>          ISRT est ENTIER
!>          Indique si les valeurs propres sont triées.
!>

RESULT

!>          RESULT est DOUBLE PRÉCISION, dimension (17)
!>          Les résultats des tests.
!>

WORK

!>          WORK est COMPLEX*16, dimension (LWORK)
!>          Espace de travail pour le sous-programme.
!>

LWORK

!>          LWORK est ENTIER
!>          La taille de l'espace de travail WORK.
!>

RWORK

!>          RWORK est DOUBLE PRÉCISION, dimension (N)
!>          Espace de travail pour le sous-programme.
!>

BWORK

!>          BWORK est LOGIQUE, dimension (N)
!>          Espace de travail booléen pour le sous-programme.
!>

INFO

!>          INFO est ENTIER
!>          Indique l'état de sortie.
!>          = 0: succès
!>          < 0: un des paramètres d'entrée invalides
!>          > 0: un des sous-programmes internes a signalé une erreur
!>

; Comme W, ce tableau contient les valeurs propres de A, !> mais triées par partie réelle ou imaginaire croissante. !>

VS

!>          VS est un tableau COMPLEX*16, de dimension (LDVS, N)
!>          VS contient les vecteurs de Schur calculés.
!>

LDVS

!>          LDVS est un entier
!>          Dimension principale de VS. Doit être au moins max(1, N).
!>

VS1

!>          VS1 est un tableau COMPLEX*16, de dimension (LDVS, N)
!>          VS1 contient une autre copie des vecteurs de Schur calculés.
!>

RCDEIN

!>          RCDEIN est un DOUBLE PRECISION
!>          Lorsque COMP = .TRUE., RCDEIN contient le nombre de conditionnement réciproque précalculé
!>          pour la moyenne des valeurs propres sélectionnées.
!>

RCDVIN

!>          RCDVIN est un DOUBLE PRECISION
!>          Lorsque COMP = .TRUE., RCDVIN contient le nombre de conditionnement réciproque précalculé
!>          pour le sous-espace invariant droit sélectionné.
!>

NSLCT

!>          NSLCT est un entier
!>          Lorsque COMP = .TRUE., le nombre de valeurs propres sélectionnées
!>          correspondant aux valeurs précalculées RCDEIN et RCDVIN.
!>

ISLCT

!>          ISLCT est un tableau d'entiers, de dimension (NSLCT)
!>          Lorsque COMP = .TRUE., ISLCT sélectionne les valeurs propres de la
!>          matrice d'entrée correspondant aux valeurs précalculées RCDEIN
!>          et RCDVIN. Pour I=1, ..., NSLCT, si ISLCT(I) = J, alors la
!>          valeur propre avec la J-ème plus grande partie réelle ou imaginaire est
!>          sélectionnée. La partie réelle est utilisée si ISRT = 0, et la
!>          partie imaginaire si ISRT = 1.
!>          Non référencé si COMP = .FALSE.
!>

ISRT

!>          ISRT est un entier
!>          Lorsque COMP = .TRUE., ISRT décrit comment ISLCT est utilisé pour
!>          choisir un sous-ensemble du spectre.
!>          Non référencé si COMP = .FALSE.
!>

RESULT

!>          RESULT est un tableau de DOUBLE PRECISION, de dimension (17)
!>          Les valeurs calculées par les 17 tests décrits ci-dessus.
!>          Les valeurs sont actuellement limitées à 1/ulp, pour éviter
!>          les dépassements.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N*N)
!>

LWORK

!>          LWORK est un entier
!>          Le nombre d'entrées dans WORK à passer à ZGEESX. Doit être au moins 2*N,
!>          et N*(N+1)/2 si les tests 14 à 16 doivent être effectués.
!>

RWORK

!>          RWORK est un tableau de DOUBLE PRECISION, de dimension (N)
!>

BWORK

!>          BWORK est un tableau LOGIQUE, de dimension (N)
!>

INFO

!>          INFO est un entier
!>          Si 0, sortie réussie.
!>          Si <0, le paramètre d'entrée -INFO avait une valeur incorrecte.
!>          Si >0, ZGEESX a retourné un code d'erreur, dont la valeur absolue est retournée.
!>
