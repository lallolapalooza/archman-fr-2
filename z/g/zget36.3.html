Documentation de la fonction/sous-routine

sous-routine zget36 (double precision rmax, integer lmax, integer ninfo, integer knt, integer nin)

ZGET36

Objectif :

!>
!> ZGET36 teste ZTREXC, une routine pour réordonner les entrées diagonales
!> d'une matrice sous forme de Schur complexe. Ainsi, ZLAEXC calcule une
!> matrice unitaire Q telle que
!>
!>    Q' * T1 * Q  = T2
!>
!> et où l'un des blocs diagonaux de T1 (celui à la ligne IFST) a été déplacé
!> à la position ILST.
!>
!> Le code de test vérifie que le résidu Q'*T1*Q-T2 est petit, que T2 est
!> sous forme de Schur, et que la position finale du bloc IFST est ILST.
!>
!> Les matrices de test sont lues à partir d'un fichier avec le numéro
!> logique d'unité NIN.
!>

Paramètres

RMAX 
!>          RMAX est DOUBLE PRECISION
!>          Valeur du plus grand ratio de test.
!>

LMAX

!>          LMAX est INTEGER
!>          Numéro de l'exemple où le plus grand ratio de test a été atteint.
!>

NINFO

!>          NINFO est INTEGER
!>          Nombre d'exemples où INFO est non nul.
!>

KNT

!>          KNT est INTEGER
!>          Nombre total d'exemples testés.
!>

NIN

!>          NIN est INTEGER
!>          Numéro logique d'unité d'entrée.
!>
