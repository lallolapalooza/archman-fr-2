Documentation de la fonction/sous-routine

subroutine zgelst (character trans, integer m, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) work, integer lwork, integer info)

ZGELST résout les systèmes linéaires réels surdéterminés ou sous-déterminés pour les matrices GE en utilisant la factorisation QR ou LQ avec représentation compacte WY de Q.

Objectif :

!>
!> ZGELST résout des systèmes linéaires réels surdéterminés ou sous-déterminés
!> impliquant une matrice M-par-N A, ou sa transposée conjuguée, en utilisant une factorisation QR
!> ou LQ de A avec une représentation compacte WY de Q.
!>
!> On suppose que A a un rang plein, et seule une protection rudimentaire contre les matrices
!> de rang déficient est fournie. Cette sous-routine ne détecte
!> que la déficience de rang exacte, où un élément diagonal du facteur triangulaire
!> de A est exactement zéro.
!>
!> Il est concevable qu'un (ou plusieurs) des éléments diagonaux du facteur triangulaire
!> de A soit un nombre subnormalement minuscule sans que cette sous-routine ne signale
!> d'erreur. Les solutions calculées pour de telles matrices presque de rang déficient peuvent
!> être moins précises en raison d'une perte de précision numérique.
!>
!> Les options suivantes sont fournies :
!>
!> 1. Si TRANS = 'N' et m >= n : trouver la solution des moindres carrés
!>    d'un système surdéterminé, c'est-à-dire résoudre le problème des moindres carrés
!>                 minimiser || B - A*X ||.
!>
!> 2. Si TRANS = 'N' et m < n : trouver la solution de norme minimale
!>    d'un système sous-déterminé A * X = B.
!>
!> 3. Si TRANS = 'C' et m >= n : trouver la solution de norme minimale
!>    d'un système sous-déterminé A**T * X = B.
!>
!> 4. Si TRANS = 'C' et m < n : trouver la solution des moindres carrés
!>    d'un système surdéterminé, c'est-à-dire résoudre le problème des moindres carrés
!>                 minimiser || B - A**T * X ||.
!>
!> Plusieurs vecteurs de second membre b et vecteurs solution x peuvent
!> être gérés en un seul appel ; ils sont stockés sous forme de colonnes de
!> la matrice B de second membre M-par-NRHS et de la matrice solution X N-par-NRHS.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N' : le système linéaire implique A ;
!>          = 'C' : le système linéaire implique A**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes des matrices B et X. NRHS >=0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M-par-N.
!>          À la sortie,
!>            si M >= N, A est écrasé par les détails de sa factorisation QR
!>                       renvoyés par ZGEQRT ;
!>            si M < N, A est écrasé par les détails de sa factorisation LQ
!>                       renvoyés par ZGELQT.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB,NRHS)
!>          À l'entrée, la matrice B des vecteurs de second membre, stockée
!>          par colonnes ; B est de taille M-par-NRHS si TRANS = 'N', ou N-par-NRHS
!>          si TRANS = 'C'.
!>          À la sortie, si INFO = 0, B est écrasé par les vecteurs solution,
!>          stockés par colonnes :
!>          si TRANS = 'N' et m >= n, les lignes 1 à n de B contiennent les vecteurs
!>          solution des moindres carrés ; la somme des carrés résiduels pour la
!>          solution dans chaque colonne est donnée par la somme des carrés des
!>          modules des éléments n+1 à M de cette colonne ;
!>          si TRANS = 'N' et m < n, les lignes 1 à N de B contiennent les vecteurs
!>          solution de norme minimale ;
!>          si TRANS = 'C' et m >= n, les lignes 1 à M de B contiennent les vecteurs
!>          solution de norme minimale ;
!>          si TRANS = 'C' et m < n, les lignes 1 à M de B contiennent les vecteurs
!>          solution des moindres carrés ; la somme des carrés résiduels
!>          pour la solution dans chaque colonne est donnée par la somme des
!>          carrés des modules des éléments M+1 à N de cette colonne.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= MAX(1,M,N).
!>

WORK

!>          WORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= max( 1, MN + max( MN, NRHS ) ).
!>          Pour une performance optimale,
!>          LWORK >= max( 1, (MN + max( MN, NRHS ))*NB ).
!>          où MN = min(M,N) et NB est la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO =  i, le i-ème élément diagonal du facteur triangulaire
!>                de A est exactement zéro, de sorte que A n'a pas de rang plein ;
!>                la solution des moindres carrés n'a pas pu être calculée.
!>
