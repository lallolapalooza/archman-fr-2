sous-routine zggesx (character jobvsl, character jobvsr, character sort, external selctg, character sense, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, integer sdim, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( ldvsl, * ) vsl, integer ldvsl, complex*16, dimension( ldvsr, * ) vsr, integer ldvsr, double precision, dimension( 2 ) rconde, double precision, dimension( 2 ) rcondv, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer liwork, logical, dimension( * ) bwork, integer info)

ZGGESX calcule les valeurs propres, la forme de Schur et, éventuellement, la matrice des vecteurs de Schur pour les matrices GE

Objectif :

!>
!> ZGGESX calcule pour une paire de matrices complexes non symétriques N-par-N
!> (A,B), les valeurs propres généralisées, la forme de Schur complexe (S,T),
!> et, éventuellement, les matrices gauche et/ou droite des vecteurs de Schur (VSL
!> et VSR). Cela donne la factorisation généralisée de Schur
!>
!>      (A,B) = ( (VSL) S (VSR)**H, (VSL) T (VSR)**H )
!>
!> où (VSR)**H est la conjuguée transposée de VSR.
!>
!> Éventuellement, elle ordonne également les valeurs propres de sorte qu'un cluster sélectionné
!> de valeurs propres apparaisse dans les blocs diagonaux principaux de la matrice triangulaire supérieure
!> S et de la matrice triangulaire supérieure T ; calcule
!> un nombre conditionnel réciproque pour la moyenne des valeurs propres sélectionnées
!> (RCONDE) ; et calcule un nombre conditionnel réciproque pour
!> les sous-espaces défléchissants droits et gauches correspondant aux
!> valeurs propres sélectionnées (RCONDV). Les colonnes principales de VSL et VSR forment alors
!> une base orthonormale pour les espaces propres gauches et droits correspondants
!> (sous-espaces défléchissants).
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un rapport alpha/beta = w, tel que A - w*B est singulière. Elle est
!> généralement représentée par la paire (alpha,beta), car il existe une
!> interprétation raisonnable pour beta=0 ou pour les deux étant nuls.
!>
!> Une paire de matrices (S,T) est en forme de Schur généralisée complexe si T est
!> triangulaire supérieure avec une diagonale non négative et S est triangulaire
!> supérieure.
!>

Paramètres

JOBVSL 
!>          JOBVSL est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur gauches ;
!>          = 'V' : calculer les vecteurs de Schur gauches.
!>

JOBVSR

!>          JOBVSR est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur droits ;
!>          = 'V' : calculer les vecteurs de Schur droits.
!>

SORT

!>          SORT est CHARACTER*1
!>          Spécifie si les valeurs propres doivent être ordonnées ou non sur la
!>          diagonale de la forme de Schur généralisée.
!>          = 'N' : les valeurs propres ne sont pas ordonnées ;
!>          = 'S' : les valeurs propres sont ordonnées (voir SELCTG).
!>

SELCTG

!>          SELCTG est une fonction LOGIQUE de deux arguments COMPLEX*16
!>          SELCTG doit être déclarée EXTERNE dans la sous-routine appelante.
!>          Si SORT = 'N', SELCTG n'est pas référencée.
!>          Si SORT = 'S', SELCTG est utilisée pour sélectionner les valeurs propres à trier
!>          en haut à gauche de la forme de Schur.
!>          Notez qu'une valeur propre complexe sélectionnée peut ne plus satisfaire
!>          SELCTG(ALPHA(j),BETA(j)) = .TRUE. après l'ordonnancement, car
!>          l'ordonnancement peut changer la valeur des valeurs propres complexes
!>          (surtout si la valeur propre est mal conditionnée), dans ce
!>          cas INFO est défini à N+3 voir INFO ci-dessous).
!>

SENSE

!>          SENSE est CHARACTER*1
!>          Détermine quels nombres conditionnels réciproques sont calculés.
!>          = 'N' : Aucun n'est calculé ;
!>          = 'E' : Calculé pour la moyenne des valeurs propres sélectionnées uniquement ;
!>          = 'V' : Calculé pour les sous-espaces défléchissants sélectionnés uniquement ;
!>          = 'B' : Calculé pour les deux.
!>          Si SENSE = 'E', 'V', ou 'B', SORT doit être égal à 'S'.
!>

N

!>          N est un ENTIER
!>          L'ordre des matrices A, B, VSL et VSR. N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, dimension (LDA, N)
!>          En entrée, la première de la paire de matrices.
!>          En sortie, A a été écrasé par sa forme de Schur généralisée
!>          S.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale de A. LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX*16, dimension (LDB, N)
!>          En entrée, la deuxième de la paire de matrices.
!>          En sortie, B a été écrasé par sa forme de Schur généralisée
!>          T.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale de B. LDB >= max(1,N).
!>

SDIM

!>          SDIM est un ENTIER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = nombre de valeurs propres (après tri)
!>          pour lesquelles SELCTG est vrai.
!>

ALPHA

!>          ALPHA est un tableau COMPLEX*16, dimension (N)
!>

BETA

!>          BETA est un tableau COMPLEX*16, dimension (N)
!>          En sortie, ALPHA(j)/BETA(j), j=1,...,N, seront les
!>          valeurs propres généralisées. ALPHA(j) et BETA(j), j=1,...,N sont
!>          les diagonales de la forme de Schur complexe (S,T). BETA(j) sera
!>          un nombre réel non négatif.
!>
!>          Note : les quotients ALPHA(j)/BETA(j) peuvent facilement déborder ou
!>          sous-déborder, et BETA(j) peut même être zéro. Ainsi, l'utilisateur
!>          doit éviter de calculer naïvement le rapport alpha/beta.
!>          Cependant, ALPHA sera toujours inférieur et généralement
!>          comparable à norm(A) en magnitude, et BETA toujours inférieur
!>          et généralement comparable à norm(B).
!>

VSL

!>          VSL est un tableau COMPLEX*16, dimension (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contiendra les vecteurs de Schur gauches.
!>          Non référencé si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL est un ENTIER
!>          La dimension principale de la matrice VSL. LDVSL >=1, et
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR est un tableau COMPLEX*16, dimension (LDVSR,N)
!>          Si JOBVSR = 'V', VSR contiendra les vecteurs de Schur droits.
!>          Non référencé si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR est un ENTIER
!>          La dimension principale de la matrice VSR. LDVSR >= 1, et
!>          si JOBVSR = 'V', LDVSR >= N.
!>

RCONDE

!>          RCONDE est un tableau DOUBLE PRECISION, dimension ( 2 )
!>          Si SENSE = 'E' ou 'B', RCONDE(1) et RCONDE(2) contiennent les
!>          nombres conditionnels réciproques pour la moyenne des valeurs propres sélectionnées
es.
!>          Non référencé si SENSE = 'N' ou 'V'.
!>

RCONDV

!>          RCONDV est un tableau DOUBLE PRECISION, de dimension ( 2 )
!>          Si SENSE = 'V' ou 'B', RCONDV(1) et RCONDV(2) contiennent le
!>          nombre conditionnel réciproque pour les sous-espaces défléchissants
!>          sélectionnés.
!>          Non référencé si SENSE = 'N' ou 'E'.
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient le LWORK optimal.
!>

LWORK

!>          LWORK est un entier.
!>          La dimension du tableau WORK.
!>          Si N = 0, LWORK >= 1, sinon si SENSE = 'E', 'V', ou 'B',
!>          LWORK >= MAX(1,2*N,2*SDIM*(N-SDIM)), sinon
!>          LWORK >= MAX(1,2*N). Notez que 2*SDIM*(N-SDIM) <= N*N/2.
!>          Notez également qu'une erreur n'est retournée que si
!>          LWORK < MAX(1,2*N), mais si SENSE = 'E' ou 'V' ou 'B', cela peut
!>          ne pas être suffisant.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée; la
!>          routine calcule uniquement la borne de la taille optimale du
!>          tableau WORK et la taille minimale du tableau IWORK, retourne ces
!>          valeurs comme premières entrées des tableaux WORK et IWORK, et
!>          aucun message d'erreur lié à LWORK ou LIWORK n'est émis par
!>          XERBLA.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension ( 8*N )
!>          Espace de travail réel.
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) contient le LIWORK minimum.
!>

LIWORK

!>          LIWORK est un entier.
!>          La dimension du tableau IWORK.
!>          Si SENSE = 'N' ou N = 0, LIWORK >= 1, sinon
!>          LIWORK >= N+2.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée; la
!>          routine calcule uniquement la borne de la taille optimale du
!>          tableau WORK et la taille minimale du tableau IWORK, retourne ces
!>          valeurs comme premières entrées des tableaux WORK et IWORK, et
!>          aucun message d'erreur lié à LWORK ou LIWORK n'est émis par
!>          XERBLA.
!>

BWORK

!>          BWORK est un tableau LOGICAL, de dimension (N)
!>          Non référencé si SORT = 'N'.
!>

INFO

!>          INFO est un entier.
!>          = 0:  terminaison réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          = 1,...,N:
!>                L'itération QZ a échoué.  (A,B) ne sont pas sous forme de Schur
!>                mais ALPHA(j) et BETA(j) devraient être corrects pour
!>                j=INFO+1,...,N.
!>          > N:  =N+1: l'échec de l'itération QZ dans ZHGEQZ
!>                =N+2: après réordonnancement, l'arrondi a modifié les valeurs de
!>                      certaines valeurs propres complexes de sorte que les
!>                      valeurs propres principales sous forme de Schur généralisée
!>                      ne satisfont plus SELCTG=.TRUE. Ceci pourrait aussi
!>                      être causé par la mise à l'échelle.
!>                =N+3: réordonnancement a échoué dans ZTGSEN.
!>
