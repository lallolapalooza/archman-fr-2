sous-programme zgbrfsx (caractère trans, caractère equed, entier n, entier kl, entier ku, entier nrhs, complexe*16, dimension( ldab, * ) ab, entier ldab, complexe*16, dimension( ldafb, * ) afb, entier ldafb, entier, dimension( * ) ipiv, double précision, dimension( * ) r, double précision, dimension( * ) c, complexe*16, dimension( ldb, * ) b, entier ldb, complexe*16, dimension( ldx , * ) x, entier ldx, double précision rcond, double précision, dimension( * ) berr, entier n_err_bnds, double précision, dimension( nrhs, * ) err_bnds_norm, double précision, dimension( nrhs, * ) err_bnds_comp, entier nparams, double précision, dimension( * ) params, complexe*16, dimension( * ) work, double précision, dimension( * ) rwork, entier info)

ZGBRFSX

But:

!>
!>    ZGBRFSX améliore la solution calculée d'un système d'équations linéaires
!>    et fournit des bornes d'erreur et des estimations d'erreur à posteriori
!>    pour la solution. En plus de la borne d'erreur normwise, le code
!>    fournit une borne d'erreur composante maximale si possible. Voir
!>    les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des
!>    bornes d'erreur.
!>
!>    Le système d'équations linéaires d'origine peut avoir été équilibré
!>    avant d'appeler cette routine, tel que décrit par les arguments EQUED, R
!>    et C ci-dessous. Dans ce cas, la solution et les bornes d'erreur retournées
!>    sont pour le système original non équilibré.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent la manière dont le raffinement est effectué, mais
!>     souvent les valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N':  A * X = B     (Pas de transposée)
!>       = 'T':  A**T * X = B  (Transposée)
!>       = 'C':  A**H * X = B  (Transposée conjuguée)
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibration qui a été effectuée sur A
!>     avant d'appeler cette routine. Ceci est nécessaire pour calculer
!>     la solution et les bornes d'erreur correctement.
!>       = 'N':  Aucune équilibration
!>       = 'R':  Équilibrage des lignes, c'est-à-dire que A a été multiplié par
!>               diag(R).
!>       = 'C':  Équilibrage des colonnes, c'est-à-dire que A a été post-multiplié
!>               par diag(C).
!>       = 'B':  Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(R) * A * diag(C).
!>               Le côté droit B a été modifié en conséquence.
!>

N

!>          N est ENTIER
!>     L'ordre de la matrice A. N >= 0.
!>

KL

!>          KL est ENTIER
!>     Le nombre de sous-diagonales dans la bande de A. KL >= 0.
!>

KU

!>          KU est ENTIER
!>     Le nombre de super-diagonales dans la bande de A. KU >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>     Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>     des matrices B et X. NRHS >= 0.
!>

AB

!>          AB est tableau COMPLEX*16, dimension (LDAB,N)
!>     La matrice de bande originale A, stockée dans les lignes 1 à KL+KU+1.
!>     La j-ième colonne de A est stockée dans la j-ième colonne du
!>     tableau AB comme suit :
!>     AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku) <= i <= min(n,j+kl).
!>

LDAB

!>          LDAB est ENTIER
!>     La dimension principale du tableau AB. LDAB >= KL+KU+1.
!>

AFB

!>          AFB est tableau COMPLEX*16, dimension (LDAFB,N)
!>     Détails de la factorisation LU de la matrice de bande A, tels que
!>     calculés par ZGBTRF. U est stockée comme une matrice triangulaire supérieure avec
!>     KL+KU super-diagonales dans les lignes 1 à KL+KU+1, et
!>     les multiplicateurs utilisés pendant la factorisation sont stockés dans
!>     les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAFB

!>          LDAFB est ENTIER
!>     La dimension principale du tableau AFB. LDAFB >= 2*KL*KU+1.
!>

IPIV

!>          IPIV est tableau ENTIER, dimension (N)
!>     Les indices de pivot de ZGETRF ; pour 1<=i<=N, la ligne i de la
!>     matrice a été échangée avec la ligne IPIV(i).
!>

R

!>          R est tableau DOUBLE PRÉCISION, dimension (N)
!>     Les facteurs d'échelle des lignes de A. Si EQUED = 'R' ou 'B', A est
!>     multiplié à gauche par diag(R); si EQUED = 'N' ou 'C', R
!>     n'est pas accédé. R est un argument d'entrée si FACT = 'F';
!>     sinon, R est un argument de sortie. Si FACT = 'F' et
!>     EQUED = 'R' ou 'B', chaque élément de R doit être positif.
!>     Si R est une sortie, chaque élément de R est une puissance du radix.
!>     Si R est une entrée, chaque élément de R doit être une puissance du radix
!>     pour assurer une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances du radix ne cause pas d'erreurs d'arrondi, sauf si le
!>     résultat sous-flotte ou sur-flotte. Les erreurs d'arrondi pendant la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

C

!>          C est tableau DOUBLE PRÉCISION, dimension (N)
!>     Les facteurs d'échelle des colonnes de A. Si EQUED = 'C' ou 'B', A est
!>     multiplié à droite par diag(C); si EQUED = 'N' ou 'R', C
!>     n'est pas accédé. C est un argument d'entrée si FACT = 'F';
!>     sinon, C est un argument de sortie. Si FACT = 'F' et
!>     EQUED = 'C' ou 'B', chaque élément de C doit être positif.
!>     Si C est une sortie, chaque élément de C est une puissance du radix.
!>     Si C est une entrée, chaque élément de C doit être une puissance du radix
!>     pour assurer une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances du radix ne cause pas d'erreurs d'arrondi, sauf si le
!>     résultat sous-flotte ou sur-flotte. Les erreurs d'arrondi pendant la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est tableau COMPLEX*16, dimension (LDB,NRHS)
!>     La matrice du côté droit B.
!>

LDB

!>          LDB est ENTIER
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est tableau COMPLEX*16, dimension (LDX,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par ZGETRS.
!>     À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est ENTIER
!>     La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND est DOUBLE PRECISION !> Nombre de condition réciproque échelonné. Ceci est une estimation du !> nombre de condition de Skeel réciproque de la matrice A après !> équilibrage (si effectué). S'il est inférieur à la précision machine !> (en particulier, s'il est zéro), la matrice est singulière !> à la précision de travail. Noter que l'erreur peut encore être faible même !> si ce nombre est très petit et que la matrice semble mal !> conditionnée. !>

BERR

!>          BERR est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>     Erreur arrière relative composante par composante. Ceci est l'erreur
!>     arrière relative composante par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire, le plus petit changement relatif dans n'importe quel élément de A ou B qui
!>     fait de X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à retourner pour chaque membre de droite
!>     et chaque type (norme ou composante par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à l'erreur
!>     relative par norme, qui est définie comme suit :
!>
!>     Erreur relative par norme dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur comme décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     renvoyées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur directe estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que la prochaine entrée est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne devrait
!>              être utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Norme estimée
!>              nombre de condition réciproque par norme. Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces nombres de condition
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              matrice Z appropriée et échelonnée.
!>              Soit Z = S*A, où S échelonne chaque ligne par une puissance de la
!>              base de sorte que toutes les sommes absolues de lignes de Z soient
!>              approximativement 1.
!>
!>     Voir le Lapack Working Note 165 pour plus de détails et des mises en garde
!>     supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à l'erreur
!>     relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le membre de droite i (dont dépend l'erreur
!>     relative composante par composante), et le type d'information d'erreur
!>     comme décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations retournées pour chaque membre de droite. Si la précision
!>     composante par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>     ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur directe estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que la prochaine entrée est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne devrait
!>              être utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Nombre de condition
!>              réciproque composante par composante estimé. Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces nombres de condition
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              matrice Z appropriée et échelonnée.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              membre de droite courant et S échelonne chaque ligne de
!>              A*diag(x) par une puissance de la base de sorte que toutes les sommes absolues de lignes de Z soient
!>              approximativement 1.
!>
!>     Voir le Lapack Working Note 165 pour plus de détails et des mises en garde
!>     supplémentaires.
!>

NPARAMS

!>          NPARAMS est INTEGER
!>     Spécifie le nombre de paramètres définis dans PARAMS. Si <= 0, le
!>     tableau PARAMS n'est jamais référencé et les valeurs par défaut sont utilisées.
!>

PARAMS

!>          PARAMS est un tableau DOUBLE PRECISION, de dimension NPARAMS
!>     Spécifie les paramètres de l'algorithme. Si une entrée est < 0.0, alors
!>     cette entrée sera remplie avec la valeur par défaut utilisée pour ce
!>     paramètre. Seules les positions jusqu'à NPARAMS sont accédées ; les valeurs par défaut
!>     sont utilisées pour les paramètres de numéro supérieur.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Indique s'il faut effectuer un raffinement itératif
!>            ou non.
!>         Défaut : 1.0D+0
!>            = 0.0 : Aucun raffinement n'est effectué, et aucune borne d'erreur
!>                    n'est calculée.
!>            = 1.0 : Utilise l'algorithme de raffinement en double précision,
!>                    éventuellement avec des calculs en simple précision doublée si
!>                    l'environnement de compilation ne prend pas en charge DOUBLE
!>                    PRECISION.
!>              (d'autres valeurs sont réservées pour un usage futur)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Nombre maximum de calculs de résidu
!>            autorisés pour le raffinement.
!>         Défaut : 10
!>         Agressif : Défini à 100 pour permettre la convergence en utilisant des
!>                     factorisations approchées ou des factorisations autres que LU. Si
!>                     la factorisation utilise une technique autre que
!>                     l'élimination gaussienne, les garanties dans
!>                     err_bnds_norm et err_bnds_comp peuvent ne plus être
!>                     fiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Indicateur déterminant si le code
!>            tentera de trouver une solution avec une petite erreur relative composante par composante
!>            dans l'algorithme en double précision. Positif
!>            signifie vrai, 0.0 signifie faux.
!>         Défaut : 1.0 (tenter la convergence composante par composante)
!>

WORK

!>          WORK est un tableau COMPLEX*16, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, de dimension (2*N)
!>

INFO

!>          INFO est INTEGER
!>       = 0 : Sortie réussie. La solution de chaque membre de droite est
!>         garantie.
!>       < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>       > 0 et <= N : U(INFO,INFO) est exactement zéro. La factorisation
!>         a été complétée, mais le facteur U est exactement singulier, donc
!>         la solution et les bornes d'erreur n'ont pas pu être calculées. RCOND = 0
!>         est retourné.
!>       = N+J : La solution correspondant au J-ème membre de droite n'est
!>         pas garantie. Les solutions correspondant aux autres membres de
!>         droite K avec K > J peuvent également ne pas être garanties,
!>         mais seul le premier membre de droite de ce type est rapporté. Si une petite
!>         erreur composante par composante n'est pas demandée (PARAMS(3) = 0.0),
!>         alors le J-ème membre de droite est le premier avec une borne d'erreur
!>         par norme qui n'est pas garantie (le plus petit J tel que
!>         ERR_BNDS_NORM(J,1) = 0.0). Par défaut (PARAMS(3) = 1.0),
!>         le J-ème membre de droite est le premier avec une borne d'erreur par norme ou
!>         composante par composante qui n'est pas garantie (le plus petit
!>         J tel que ERR_BNDS_NORM(J,1) = 0.0 ou
!>         ERR_BNDS_COMP(J,1) = 0.0). Voir la définition de
!>         ERR_BNDS_NORM(:,1) et ERR_BNDS_COMP(:,1). Pour obtenir des informations
!>         sur tous les membres de droite, vérifiez ERR_BNDS_NORM ou
!>         ERR_BNDS_COMP.
!>
