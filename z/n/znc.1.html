ZNC(1) Manuel des commandes générales ZNC(1)

NOM

znc - Un retransmetteur IRC avancé

SYNTAXE

znc --help
znc --version
znc --makepass
znc [-n] [-d datadir] [-D] [-f]
znc [-n] [-d datadir] [-D] [-f] --makeconf
znc [-n] [-d datadir] [-D] [-f] --makepem

DESCRIPTION

znc est un proxy IRC. Il s'exécute comme un démon et se connecte au serveur IRC, puis vous permet de vous connecter depuis une station de travail et de travailler en tant qu'utilisateur connecté au serveur IRC. Après votre déconnexion, il maintient la connexion au serveur. Il agit comme n'importe quel serveur IRC normal, vous pouvez donc utiliser n'importe quel client IRC pour vous y connecter.

OPTIONS

-h, --help
Affiche un bref message d'aide.
-v, --version
Affiche le numéro de version complet.
-n, --no-color
N'utilise aucune séquence d'échappement de couleur.
-f, --foreground
Ne détache pas le processus ZNC en arrière-plan.
-D, --debug
Affiche les informations de débogage sur la console. Implique --foreground.
-d DATADIR, --datadir=DATADIR
Spécifie un autre répertoire de données. C'est là que znc sauvegarde tout.
-c, --makeconf
Crée interactivement une nouvelle configuration.
-s, --makepass
Hache un mot de passe pour utilisation dans znc.conf.
-p, --makepem
Génère znc.pem. C'est le certificat serveur que znc utilise. Vous en avez besoin pour SSL.
-r, --allow-root
Ne se plaint pas si ZNC est exécuté avec des privilèges root.

SIGNaux

Cette section explique comment znc réagit aux différents signaux :

SIGINT
Quitte ZNC. Équivalent à /znc shutdown
SIGHUP
Recharge znc.conf. Équivalent à /znc rehash. NE PAS faire cela trop souvent, les choses peuvent mal tourner !
SIGUSR1
Réécrit znc.conf. Équivalent à /znc saveconfig

FICHIERS

/usr/local/share/znc/
Données statiques des modules comme les skins webadmin
/usr/local/lib/znc/
znc installe ses modules dans ce répertoire.
/usr/local/include/znc/
Ce sont les en-têtes nécessaires à la compilation de vos propres modules.
~/.znc
C'est le répertoire de données par défaut. Les chemins suivants supposent que vous l'utilisez. Si vous le changez via --datadir, les lignes suivantes seront relatives à ce répertoire.
~/.znc/znc.pem
C'est le certificat serveur que znc utilise pour écouter sur les ports SSL. Vous pouvez le générer via --makepem et le remplacer par votre propre certificat si vous le souhaitez.
~/.znc/modules/
Si vous compilez vos propres modules, vous pouvez les enregistrer ici.
~/.znc/configs/znc.conf
C'est le chemin vers znc.conf. Utilisez --makeconf pour un moyen facile de le générer.
~/.znc/users/NOMUTILISATEUR/
Les données de chaque utilisateur sont enregistrées dans ce répertoire. NOMUTILISATEUR fait référence au nom d'utilisateur de cet utilisateur.
~/.znc/users/NOMUTILISATEUR/moddata/NOMMODULE/
C'est là que chaque module peut enregistrer des éléments. Principalement utilisé pour se souvenir des paramètres du module qui ne font pas partie de znc.conf.
~/.znc/moddata/NOMMODULE/
C'est là que les modules globaux peuvent enregistrer leurs paramètres.
