NOM

znc-buildmod - compiler les modules ZNC

SYNTAXE

znc-buildmod FICHIER...

DESCRIPTION

znc-buildmod compile un module ZNC pour vous. Il suffit de lui fournir une liste de fichiers source et chaque fichier est compilé en un module.

CODE DE RETOUR

Normalement, le code de retour est 0 si tout s'est bien passé. En cas d'erreur du compilateur lors de la compilation d'un module, le code de retour est 1.

ENVIRONNEMENT

Les variables

CXXFLAGS

LDFLAGS

MODLINK

INCLUDES

LIBS

peuvent être utilisées.
