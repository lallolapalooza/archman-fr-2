ZNEW(1) Manuel des commandes générales ZNEW(1)

NOM

znew - recompresser les fichiers .Z en fichiers .gz

SYNTAXE

znew [ -ftv9PK] [ nom.Z ... ]

DESCRIPTION

La commande Znew recompresse les fichiers du format .Z (compress) au format .gz (gzip). Si vous souhaitez recompresser un fichier déjà au format gzip, renommez le fichier pour lui donner une extension .Z puis appliquez znew.

OPTIONS

-f
Force la recompression du format .Z au format .gz même si un fichier .gz existe déjà.
-t
Teste les nouveaux fichiers avant de supprimer les originaux.
-v
Verbeux. Affiche le nom et le pourcentage de réduction pour chaque fichier compressé.
-9
Utilise la méthode de compression la plus lente (compression optimale).
-P
Utilise des tuyaux pour la conversion afin de réduire l'utilisation de l'espace disque.
-K
Conserve un fichier .Z lorsqu'il est plus petit que le fichier .gz ; implique -t.

VOIR AUSSI

gzip(1), zmore(1), zdiff(1), zgrep(1), zforce(1), gzexe(1), compress(1)

BOGUES

Si l'option -P est utilisée, znew ne maintient pas l'horodatage si touch(1) ne prend pas en charge l'option -r, et ne maintient pas les permissions si chmod(1) ne prend pas en charge l'option --reference.
