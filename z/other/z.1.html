Z(1) Commandes utilisateur Z(1)

NOM

z - se déplacer rapidement

SYNOPSIS

z [-chlrtx] [regex1 regex2 ... regexn]

DISPONIBILITÉ

bash, zsh

DESCRIPTION

Suit vos répertoires les plus utilisés, basé sur la 'fréquence'.

Après une courte phase d'apprentissage, z vous amènera au répertoire le plus 'fréquent' qui correspond à TOUTES les expressions régulières données en ligne de commande, dans l'ordre.

Par exemple, z foo bar correspondrait à /foo/bar mais pas à /bar/foo.

OPTIONS

-c
limite les correspondances aux sous-répertoires du répertoire courant
-e
affiche la meilleure correspondance, ne change pas de répertoire
-h
affiche un bref message d'aide
-l
liste seulement
-r
correspondance par rang seulement
-t
correspondance par accès récent seulement
-x
supprime le répertoire courant du fichier de données

EXEMPLES

z foo
chdir au répertoire le plus fréquent correspondant à foo
z foo bar
chdir au répertoire le plus fréquent correspondant à foo, puis bar
z -r foo
chdir au répertoire le mieux classé correspondant à foo
z -t foo
chdir au répertoire accédé le plus récemment correspondant à foo
z -l foo
liste tous les répertoires correspondant à foo (par fréquence)

NOTES

Installation :

Placez quelque chose comme ceci dans votre $HOME/.bashrc ou $HOME/.zshrc :

. /usr/share/z/z.sh

Faites des cd pendant un moment pour construire la base de données.

PROFITEZ !!

Optionnellement :

Définissez $_Z_CMD pour changer le nom de la commande (par défaut z).
Définissez $_Z_DATA pour changer le fichier de données (par défaut $HOME/.z).
Définissez $_Z_MAX_SCORE plus bas pour que les entrées expirent plus rapidement (par défaut 9000).
Définissez $_Z_NO_RESOLVE_SYMLINKS pour empêcher la résolution des liens symboliques.
Définissez $_Z_NO_PROMPT_COMMAND pour gérer vous-même PROMPT_COMMAND/precmd.
Définissez $_Z_EXCLUDE_DIRS comme un tableau des arbres de répertoires à exclure.
Définissez $_Z_OWNER pour permettre l'utilisation en mode 'sudo -s'.
(Ces paramètres doivent être placés dans .bashrc/.zshrc avant la ligne ajoutée ci-dessus.)
Installez la page de manuel fournie z.1 quelque part dans votre MANPATH, comme /usr/local/man/man1.

Vieillissement :

Le rang des répertoires maintenus par z subit un vieillissement basé sur une formule simple. Le rang de chaque entrée est incrémenté chaque fois qu'elle est accédée. Lorsque la somme des rangs dépasse 9000, tous les rangs sont multipliés par 0,99. Les entrées dont le rang est inférieur à 1 sont oubliées.

Fréquence :

La fréquence est un mot-valise de 'récent' et 'fréquence'. C'est un rang pondéré qui dépend de la fréquence et de la récence d'un événement. Autant que je sache, Mozilla a inventé le terme.

Pour z, un répertoire de faible rang mais accédé récemment aura rapidement un rang plus élevé qu'un répertoire accédé fréquemment il y a longtemps.

La fréquence est déterminée à l'exécution.

Commun :

Lorsque plusieurs répertoires correspondent à toutes les requêtes, et qu'ils ont un préfixe commun, z se déplacera vers le répertoire correspondant le plus court, sans tenir compte de la priorité. Ceci est en vigueur, bien qu'indocumenté, depuis un certain temps, mais devrait probablement être configurable ou reconsidéré.

Complétion par Tabulation :

z prend en charge la complétion par tabulation. Après un nombre quelconque d'arguments, appuyez sur TAB pour compléter les répertoires qui correspondent à chaque argument. En raison des limitations des implémentations de complétion, seul le dernier argument sera complété dans le shell.

En interne, z décide que vous avez demandé une complétion si le dernier argument passé est un chemin absolu vers un répertoire existant. Cela peut entraîner un comportement inattendu si le dernier argument de z commence par /.

ENVIRONNEMENT

Une fonction _z() est définie.

Le contenu de la variable $_Z_CMD est aliasé à _z 2>&1. Si elle n'est pas définie, $_Z_CMD prend par défaut la valeur z.

La variable d'environnement $_Z_DATA peut être utilisée pour contrôler l'emplacement du fichier de données. Si elle n'est pas définie, l'emplacement par défaut est $HOME/.z.

La variable d'environnement $_Z_NO_RESOLVE_SYMLINKS peut être définie pour empêcher la résolution des liens symboliques. Si elle n'est pas définie, les liens symboliques seront résolus lors de leur ajout au fichier de données.

Dans bash, z ajoute une commande à la variable d'environnement PROMPT_COMMAND pour maintenir sa base de données. Dans zsh, z ajoute une fonction _z_precmd au tableau precmd_functions.

La variable d'environnement $_Z_NO_PROMPT_COMMAND peut être définie si vous souhaitez gérer vous-même PROMPT_COMMAND ou precmd.

La variable d'environnement $_Z_EXCLUDE_DIRS peut être définie comme un tableau d'arbres de répertoires à exclure du suivi. $HOME est toujours exclu. Les répertoires doivent être des chemins complets sans slash final.

La variable d'environnement $_Z_OWNER peut être définie avec votre nom d'utilisateur, pour permettre l'utilisation de z lorsque votre environnement sudo conserve $HOME.

FICHIERS

Les données sont stockées dans $HOME/.z. Ceci peut être écrasé en définissant la variable d'environnement $_Z_DATA. Lors de l'initialisation, z générera une erreur si ce chemin est un répertoire et ne fonctionnera pas correctement.

Une page de manuel (z.1) est fournie.
