fwide(3) Manuel des fonctions de bibliothèque fwide(3)

NOM

fwide - définir et déterminer l'orientation d'un flux FILE

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <wchar.h>
int fwide(FILE *stream, int mode);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

fwide() :

    _XOPEN_SOURCE >= 500 || _ISOC99_SOURCE
        || _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Lorsque mode est zéro, la fonction fwide() détermine l'orientation actuelle de stream. Elle renvoie une valeur positive si stream est orienté caractères larges, c'est-à-dire si les E/S de caractères larges sont autorisées mais les E/S de caractères sont interdites. Elle renvoie une valeur négative si stream est orienté octets — c'est-à-dire si les E/S de caractères sont autorisées mais les E/S de caractères larges sont interdites. Elle renvoie zéro si stream n'a pas encore d'orientation ; dans ce cas, la prochaine opération d'E/S peut changer l'orientation (vers une orientation octet si c'est une opération d'E/S de caractères, ou vers une orientation caractères larges si c'est une opération d'E/S de caractères larges).

Une fois qu'un flux a une orientation, celle-ci ne peut pas être modifiée et persiste jusqu'à ce que le flux soit fermé.

Lorsque mode est non nul, la fonction fwide() tente d'abord de définir l'orientation de stream (vers une orientation caractères larges si mode est supérieur à 0, ou vers une orientation octet si mode est inférieur à 0). Elle renvoie ensuite une valeur indiquant l'orientation actuelle, comme ci-dessus.

VALEUR DE RETOUR

La fonction fwide() renvoie l'orientation du flux, après l'avoir éventuellement modifiée. Une valeur de retour positive signifie orienté caractères larges. Une valeur de retour négative signifie orienté octets. Une valeur de retour de zéro signifie indéterminée.

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C99.

NOTES

La sortie en caractères larges vers un flux orienté octets peut être effectuée via la fonction fprintf(3) avec les directives %lc et %ls.

La sortie en caractères vers un flux orienté caractères larges peut être effectuée via la fonction fwprintf(3) avec les directives %c et %s.

VOIR AUSSI

fprintf(3), fwprintf(3)
