uint32_t LIBMTP_Create_Folder (LIBMTP_mtpdevice_t * device, char * name, uint32_t parent_id, uint32_t

storage_id)

Cette fonction crée un dossier sur le périphérique MTP courant. Le nom PTP pour un dossier est 'association'. Les périphériques PTP/MTP n'ont pas vraiment de concept interne de 'dossier', ils contiennent une liste plate de tous les fichiers et certains fichiers sont des 'associations' auxquelles d'autres fichiers et dossiers peuvent se référer comme leur

'parent'.

Paramètre

s
device un pointeur vers le périphérique sur lequel créer le dossier.
name le nom du nouveau dossier. Notez que cela peut être modifié si le périphérique ne prend pas en charge tous les caractères du nom.
parent_id l'id du dossier parent auquel ajouter le nouveau dossier, ou 0xFFFFFFFF pour le placer dans le répertoire racine.
storage_id l'id du stockage auquel ajouter ce nouveau dossier. Notez que vous ne pouvez pas faire correspondre l'id de stockage et l'id parent de manière erronée : ils doivent tous deux se trouver sur le même stockage ! Passez 0 si vous souhaitez créer ce dossier sur le stockage par
défaut.

Renvoi

e
l'id du nouveau dossier ou 0 si une erreur est
survenue
