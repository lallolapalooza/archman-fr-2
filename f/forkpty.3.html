openpty(3) Manuel des fonctions de bibliothèque openpty(3)

NOM

openpty, login_tty, forkpty - Fonctions utilitaires de terminal

BIBLIOTHÈQUE

Bibliothèque des utilitaires système (libutil, -lutil)

SYNTAXE

#include <pty.h>
int openpty(int *amaster, int *aslave, char *name,
              const struct termios *termp,
              const struct winsize *winp);
pid_t forkpty(int *amaster, char *name,
              const struct termios *termp,
              const struct winsize *winp);
#include <utmp.h>
int login_tty(int fd);

DESCRIPTION

La fonction openpty() trouve un pseudoterminal disponible et renvoie des descripteurs de fichiers pour le maître et l'esclave dans amaster et aslave. Si name n'est pas NULL, le nom de fichier de l'esclave est renvoyé dans name. Si termp n'est pas NULL, les paramètres du terminal de l'esclave seront définis selon les valeurs de termp. Si winp n'est pas NULL, la taille de la fenêtre de l'esclave sera définie selon les valeurs de winp.

La fonction login_tty() prépare une connexion sur le terminal référencé par le descripteur de fichier fd (qui peut être un périphérique de terminal réel, ou l'esclave d'un pseudoterminal retourné par openpty()) en créant une nouvelle session, en faisant de fd le terminal de contrôle du processus appelant, en définissant fd comme flux standard d'entrée, de sortie et d'erreur du processus courant, et en fermant fd.

La fonction forkpty() combine openpty(), fork(2), et login_tty() pour créer un nouveau processus fonctionnant dans un pseudoterminal. Un descripteur de fichier faisant référence au côté maître du pseudoterminal est renvoyé dans amaster. Si name n'est pas NULL, le tampon auquel il pointe est utilisé pour renvoyer le nom de fichier de l'esclave. Les arguments termp et winp, s'ils ne sont pas NULL, détermineront les attributs du terminal et la taille de la fenêtre du côté esclave du pseudoterminal.

VALEUR DE RETOUR

Si un appel à openpty(), login_tty(), ou forkpty() échoue, -1 est renvoyé et errno est défini pour indiquer l'erreur. Sinon, openpty(), login_tty(), et le processus enfant de forkpty() retournent 0, et le processus parent de forkpty() retourne l'ID de processus du processus enfant.

ERREURS

openpty() échoue si :

ENOENT
Il n'y a pas de terminaux disponibles.

login_tty() échoue si ioctl(2) échoue à définir fd comme terminal de contrôle du processus appelant.

forkpty() échoue si openpty() ou fork(2) échoue.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
forkpty (), openpty () Sécurité des threads MT-Safe locale
login_tty () Sécurité des threads MT-Unsafe race:ttyname

NORMES

BSD.

HISTORIQUE

Les modificateurs const ont été ajoutés aux pointeurs de structure des arguments de openpty() et forkpty() dans glibc 2.8.

Avant glibc 2.0.92, openpty() renvoyait des descripteurs de fichiers pour une paire de pseudoterminaux BSD ; depuis glibc 2.0.92, il tente d'abord d'ouvrir une paire de pseudoterminaux UNIX 98, et se rabat sur l'ouverture d'une paire de pseudoterminaux BSD en cas d'échec.

BOGUES

Personne ne sait quelle taille réserver pour name. Par conséquent, appeler openpty() ou forkpty() avec un name non NULL peut ne pas être sécurisé.

VOIR AUSSI

fork(2), ttyname(3), pty(7)
