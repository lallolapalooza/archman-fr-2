FREELOCALE(3P) Manuel du programmeur POSIX FREELOCALE(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

freelocale — libérer les ressources allouées pour un objet locale

SYNTAXE

#include <locale.h>
void freelocale(locale_t locobj);

DESCRIPTION

La fonction freelocale() doit libérer les ressources allouées pour un objet locale retourné par un appel aux fonctions newlocale() ou duplocale().

Le comportement est indéfini si l'argument locobj est l'objet locale spécial LC_GLOBAL_LOCALE ou s'il ne s'agit pas d'un handle d'objet locale valide.

Toute utilisation d'un objet locale qui a été libéré entraîne un comportement indéfini.

VALEUR DE RETOUR

Aucune.

ERREURS

Aucune.

Les sections suivantes sont informatives.

EXEMPLES

Libérer un objet locale

L'exemple suivant montre un fragment de code pour libérer un objet locale créé par newlocale():

#include <locale.h>
...
/* Chaque objet locale alloué avec newlocale() doit être
 * libéré en utilisant freelocale():
 */
locale_t loc;
/* Obtenir la locale. */
loc = newlocale (LC_CTYPE_MASK | LC_TIME_MASK, "locname", NULL);
/* ... Utiliser l'objet locale ... */
...
/* Libérer les ressources de l'objet locale. */
freelocale (loc);
