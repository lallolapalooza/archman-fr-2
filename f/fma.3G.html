NOM

fma - effectuer une opération de multiplication-addition fusionnée

DÉCLARATION

genType fma(genType a, genType b, genType c);

genDType fma(genDType a, genDType b, genDType c);

PARAMÈTRES

a

Spécifie le premier multiplicande.

b

Spécifie le second multiplicande.

c

Spécifie la valeur à ajouter au résultat.

DESCRIPTION

fma effectue, lorsque cela est possible, une opération de multiplication-addition fusionnée, retournant a \* b + c. Dans les cas d'utilisation où la valeur de retour est finalement consommée par une variable déclarée comme précise :

•fma() est considérée comme une seule opération, tandis que l'expression a \* b + c consommée par une variable déclarée comme précise est considérée comme deux opérations.
•La précision de fma() peut différer de la précision de l'expression a \* b + c.
•fma() sera calculée avec la même précision que toute autre fma() consommée par une variable précise, donnant des résultats invariants pour les mêmes valeurs d'entrée de a, b et c.

Sinon, en l'absence de consommation précise, il n'y a pas de contraintes spéciales sur le nombre d'opérations ou la différence de précision entre fma() et l'expression a \* b + c.
