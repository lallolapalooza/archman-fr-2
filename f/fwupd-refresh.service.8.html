NOM

fwupd-refresh.service - intégration du message du jour.

DESCRIPTION

L'intégration du message du jour est utilisée pour afficher la disponibilité des mises à jour lors de la connexion à une console distante.

Elle comporte deux éléments :

•
Rafraîchissement automatique des métadonnées du firmware
•
Affichage du message du jour

Cela utilise un timer systemd pour s'exécuter à une cadence régulière. Pour activer cela, exécutez :

  systemctl enable fwupd-refresh.timer

NOTES

L'affichage du message du jour dépend de la disponibilité du service de consommation de snippets update-motd tel que pam_motd.

Pour activer un proxy, définissez l'environnement global systemd dans /etc/systemd/system.conf afin que tous les processus enfants systemd aient les paramètres du proxy appliqués :

[Manager]
DefaultEnvironment=http_proxy=“http://internal.corp:3128/ ”https_proxy=“http://internal.corp:3128/”
