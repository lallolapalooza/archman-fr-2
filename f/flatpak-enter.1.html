NOM

flatpak-enter - Entrer dans le bac à sable d'une application ou d'un runtime

SYNTAXE

flatpak enter [OPTION...] INSTANCE COMMANDE [ARG...]

DESCRIPTION

Entrer dans un bac à sable en cours d'exécution.

INSTANCE doit être soit le PID d'un processus s'exécutant dans un bac à sable flatpak, soit l'ID d'une application en cours d'exécution, soit l'ID d'instance d'un bac à sable en cours d'exécution. Vous pouvez utiliser flatpak ps pour trouver les ID d'instance des flatpaks en cours d'exécution.

COMMANDE est la commande à exécuter dans le bac à sable. Les arguments supplémentaires sont transmis à la commande.

Cela crée un nouveau processus au sein du bac à sable en cours d'exécution, avec le même environnement. Ceci est utile lorsque vous souhaitez déboguer un problème avec une application en cours d'exécution.

Cette commande fonctionne en tant qu'utilisateur ordinaire si le système prend en charge les espaces de noms utilisateur sans privilèges. Si ce n'est pas le cas, vous devez l'exécuter comme suit : sudo -E flatpak enter.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Afficher les options d'aide et quitter.

-v, --verbose

Afficher les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Afficher les informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak enter 15345 sh
