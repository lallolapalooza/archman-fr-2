floor(3) Manuel des fonctions de bibliothèque floor(3)

NOM

floor, floorf, floorl - plus grande valeur entière ne dépassant pas l'argument

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double floor(double x);
float floorf(float x);
long double floorl(long double x);
Exigences relatives aux macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

floorf(), floorl() :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions retournent la plus grande valeur entière qui n'est pas supérieure à x.

Par exemple, floor(0.5) est 0.0, et floor(-0.5) est -1.0.

VALEUR DE RETOUR

Ces fonctions retournent le plancher de x.

Si x est un entier, +0, -0, NaN ou l'infini, x lui-même est retourné.

ERREURS

Aucune erreur ne se produit.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
floor (), floorf (), floorl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C99, POSIX.1-2001.

La variante retournant double est également conforme à SVr4, 4.3BSD, C89.

SUSv2 et POSIX.1-2001 contiennent un texte sur le dépassement (qui pourrait définir errno sur ERANGE, ou déclencher une exception FE_OVERFLOW). En pratique, le résultat ne peut pas dépasser sur aucune machine actuelle, donc ces absurdités de gestion d'erreurs n'étaient que du non-sens. (Plus précisément, le dépassement ne peut se produire que lorsque la valeur maximale de l'exposant est inférieure au nombre de bits du mantisse. Pour les nombres à virgule flottante 32 bits et 64 bits selon la norme IEEE-754, la valeur maximale de l'exposant est de 127 (respectivement, 1023), et le nombre de bits du mantisse, y compris le bit implicite, est de 24 (respectivement, 53).) Ceci a été supprimé dans POSIX.1-2008.

VOIR AUSSI

ceil(3), lrint(3), nearbyint(3), rint(3), round(3), trunc(3)
