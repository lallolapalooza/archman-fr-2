NOM

flatpakref - Référence à un dépôt pour une application ou un runtime

DESCRIPTION

Flatpak utilise des fichiers flatpakref pour partager des informations sur un dépôt pour une application unique. Le fichier flatpakref contient suffisamment d'informations pour ajouter le dépôt et installer l'application. Utilisez la commande flatpak install --from à cet effet.

Les fichiers flatpakref peuvent également contenir des informations supplémentaires qui sont utiles lors de l'affichage de l'application à l'utilisateur, par exemple dans un magasin d'applications.

L'extension de fichier couramment utilisée pour les fichiers flatpakref est .flatpakref.

Un fichier flatpakref peut également faire référence à un dépôt pour un runtime.

FORMAT DU FICHIER

Le fichier flatpakref utilise le même format de fichier .ini que celui utilisé pour les fichiers d'unité systemd ou les fichiers .desktop d'application.

[Flatpak Ref]

Toutes les informations sont contenues dans le groupe [Flatpak Ref].

Les clés suivantes peuvent être présentes dans ce groupe :

Version (uint64)

La version du format de fichier, doit être 1 si présente.

Name (string)

Le nom complet du runtime ou de l'application. Cette clé est obligatoire.

Url (string)

L'URL du dépôt. Cette clé est obligatoire.

Branch (string)

Le nom de la branche à partir de laquelle installer l'application ou le runtime. Si cette clé n'est pas spécifiée, la branche "master" est utilisée.

Title (string)

Le titre de l'application ou du runtime. Il doit s'agir d'un nom convivial qui peut être affiché, par exemple, dans un magasin d'applications.

Comment (string)

Un bref résumé de l'application ou du runtime, à afficher, par exemple, dans un magasin d'applications.

Description (string)

Une description plus longue de l'application ou du runtime, à afficher, par exemple, dans un magasin d'applications.

Icon (string)

L'URL d'une icône qui peut être utilisée pour représenter l'application ou le runtime.

Homepage (string)

L'URL d'une page web décrivant l'application ou le runtime.

DeploySideloadCollectionID (string)

L'ID de collection du dépôt, s'il en a un. Cela identifie de manière unique la collection d'applications dans le dépôt, pour permettre la redistribution de pair à pair (voir flatpak(1)). Il est recommandé d'utiliser cette clé plutôt que DeployCollectionID ou CollectionID car seuls les clients plus récents (Flatpak 1.12.8 ou plus récent) y prêtent attention (et les clients plus anciens ne gèrent pas correctement les ID de collection).

DeployCollectionID (string)

Ceci est déprécié mais toujours pris en charge pour la compatibilité ascendante. Utilisez DeploySideloadCollectionID à la place.

CollectionID (string)

Ceci est déprécié mais toujours pris en charge pour la compatibilité ascendante. Utilisez DeploySideloadCollectionID à la place.

IsRuntime (boolean)

Indique si ce fichier fait référence à un runtime. Si cette clé n'est pas spécifiée, le fichier est supposé faire référence à une application.

GPGKey (string)

La clé gpg encodée en base64 pour le dépôt.

RuntimeRepo (string)

L'URL d'un fichier .flatpakrepo pour le dépôt où le runtime peut être trouvé. Notez que si le runtime est disponible dans le dépôt qui fournit l'application, ce dépôt peut être utilisé à la place, mais celui spécifié par cette option sera toujours ajouté.

SuggestRemoteName (string)

Un nom suggéré pour le dépôt.
