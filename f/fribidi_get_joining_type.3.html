NOM

fribidi_get_joining_type - obtenir le type de jointure d'un caractère

SYNTAXE

#include <../fribidi/lib/fribidi.h>

FriBidiJoiningType fribidi_get_joining_type(FriBidiChar ch);

PARAMÈTRES

FriBidiChar ch
Caractère d'entrée.

DESCRIPTION

Cette fonction retourne le type de jointure d'un caractère tel que défini dans le Tableau 8-2 Classes de jointure arabes primaires de la norme Unicode disponible sur http://www.unicode.org/versions/Unicode4.0.0/ch08.pdf#G7462, en utilisant les données fournies dans les fichiers ArabicShaping.txt et UnicodeData.txt de la base de données de caractères Unicode disponible sur http://www.unicode.org/Public/UNIDATA/ArabicShaping.txt et http://www.unicode.org/Public/UNIDATA/UnicodeData.txt.

Il existe quelques macros définies dans fribidi-joining-types.h pour interroger un type de jointure.

RETOURNE

Les valeurs possibles pour un FriBidiJoiningType sont les suivantes :

FRIBIDI_JOINING_TYPE_U
Non-jointure, par exemple le Point final.
FRIBIDI_JOINING_TYPE_R
Jointure à droite, par exemple la lettre arabe Dal.
FRIBIDI_JOINING_TYPE_D
Double jointure, par exemple la lettre arabe Ain.
FRIBIDI_JOINING_TYPE_C
Qui cause la jointure, par exemple Tatweel, ZWJ.
FRIBIDI_JOINING_TYPE_T
Transparent, par exemple Fatha arabe.
FRIBIDI_JOINING_TYPE_L
Jointure à gauche, c'est-à-dire fictive.
FRIBIDI_JOINING_TYPE_G
Ignoré, par exemple LRE, RLE, ZWNBSP.
