fseeko(3) Manuel des fonctions de bibliothèque fseeko(3)

NOM

fseeko, ftello - se positionner ou signaler la position d'un fichier

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdio.h>
int fseeko(FILE *stream, off_t offset, int whence);
off_t ftello(FILE *stream);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

fseeko(), ftello() :

    _FILE_OFFSET_BITS == 64 || _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Les fonctions fseeko() et ftello() sont identiques à fseek(3) et ftell(3) (voir fseek(3)), respectivement, sauf que l'argument offset de fseeko() et la valeur de retour de ftello() sont de type off_t au lieu de long.

Sur certaines architectures, off_t et long sont des types 32 bits, mais définir _FILE_OFFSET_BITS avec la valeur 64 (avant d'inclure toute bibliothèque d'en-tête) transformera off_t en un type 64 bits.

VALEUR DE RETOUR

En cas de succès, fseeko() retourne 0, tandis que ftello() retourne le décalage actuel. Sinon, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

Voir les ERREURS dans fseek(3).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
fseeko (), ftello () Thread safety MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.1. POSIX.1-2001, SUSv2.

NOTES

Les déclarations de ces fonctions peuvent également être obtenues en définissant la macro de test de fonctionnalité obsolète _LARGEFILE_SOURCE.
