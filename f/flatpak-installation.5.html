NOM

flatpak-installation - Configuration d'un emplacement d'installation

DESCRIPTION

flatpak peut fonctionner en mode système complet ou par utilisateur. Les données du système complet sont situées dans $prefix/var/lib/flatpak/ et les données par utilisateur dans $HOME/.local/share/flatpak/.

En plus des emplacements d'installation par défaut, d'autres installations système complet peuvent être définies via des fichiers de configuration dans /etc/flatpak/installations.d/, qui doivent avoir l'extension .conf et suivre le format décrit ci-dessous.

FORMAT DES FICHIERS

Le format de fichier de configuration d'installation utilise le même format de fichier .ini que celui utilisé pour les fichiers d'unité systemd ou les fichiers .desktop d'application.

[Installation ...]

Toute la configuration de l'emplacement d'installation nommé NOM est contenue dans le groupe [Installation "NOM"].

Les clés suivantes sont reconnues :

Path (chaîne de caractères)

Le chemin pour cette installation. Cette clé est obligatoire.

DisplayName (chaîne de caractères)

Le nom à utiliser lors de l'affichage de cette installation dans l'interface utilisateur.

Priority (entier)

Une priorité pour cette installation.

StorageType (chaîne de caractères)

Le type de stockage utilisé pour cette installation. Les valeurs possibles incluent : network, mmc, sdcard, harddisk.

EXEMPLES

[Installation "extra"]
Path=/emplacement/de/la/carte_sd
DisplayName=Installation supplémentaire
StorageType=sdcard
flatpak
