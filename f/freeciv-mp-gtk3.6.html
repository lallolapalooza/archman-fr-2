NOM

freeciv-mp-gtk4, freeciv-mp-gtk3, freeciv-mp-qt, freeciv-mp-cli - Installateurs de contenu personnalisé pour le jeu Freeciv

SYNTAXE

freeciv-mp-XXX [ -d|--debug niveau ] [ -h|--help ] [ -i|--install URL ] [ -L|--List URL ] [ -p|--prefix répertoire ] [ -v|--version ]

DESCRIPTION

Freeciv est un jeu de stratégie multijoueur en tour par tour, gratuit, dans lequel chaque joueur devient le chef d'une civilisation, luttant pour atteindre l'objectif ultime : devenir la plus grande civilisation.

Les joueurs de Civilization II® par Microprose® devraient se sentir chez eux, car l'un des objectifs de Freeciv est d'avoir des règles compatibles.

Freeciv est maintenu par une équipe internationale de programmeurs et d'enthousiastes, et est sans doute l'un des jeux en réseau les plus amusants et addictifs qui existent !

Ceci est le programme d'installation de contenu personnalisé - voir également freeciv-server(6) freeciv-client(6) .

Ce programme permet aux utilisateurs de sélectionner et de télécharger du contenu supplémentaire ("modpacks") pour Freeciv depuis Internet, soit à partir d'une liste maintenue par l'équipe Freeciv, soit en utilisant une URL obtenue par d'autres moyens. Il se charge d'installer les fichiers au bon endroit sous le répertoire personnel de l'utilisateur pour cette version de Freeciv ; il n'installe rien pour une utilisation à l'échelle du système.

freeciv-mp-cli est une version de l'installateur de modpack utilisable depuis la ligne de commande. Par défaut, il liste les modpacks de la liste par défaut ou de la liste spécifiée avec --List. On peut ensuite le relancer en fournissant l'URL appropriée de la liste pour le paramètre --install.

Cette page de manuel ne liste que les arguments de la ligne de commande. Pour plus de détails sur le fonctionnement de freeciv-mp-XXX, consultez le fichier README.modpack_installer dans la distribution Freeciv et la documentation sur le site Web de Freeciv

OPTIONS

Toutes les options ont une forme courte (un seul tiret et une seule lettre) et une forme longue (deux tirets et un mot complet) ; leurs effets sont identiques.

-d niveau, --debug niveau
Définit la quantité d'informations de débogage à enregistrer. Les valeurs acceptables pour le niveau sont :

fatal pour les messages fatals uniquement.

error pour les messages fatals et d'erreur.

warning pour les messages fatals, d'erreur et d'avertissement.

normal pour les messages fatals, d'erreur, d'avertissement et normaux (par défaut).

verbose pour les messages fatals, d'erreur, d'avertissement, normaux et verbeux.

-h, --help
Affiche un bref résumé des options de la ligne de commande.
-i URL, --install URL
Installe automatiquement le modpack à partir de l'URL donnée.
-L URL, --List URL
Récupère la liste des modpacks à partir de l'URL donnée, plutôt que de l'emplacement standard sur les serveurs de l'équipe Freeciv.
-p répertoire, --prefix répertoire
Installe les modpacks sous la hiérarchie de répertoires donnée.
-v, --version
Affiche le numéro de version et quitte.

FICHIERS

L'installateur de modpack freeciv installe les fichiers dans les sous-répertoires suivants du répertoire personnel de l'utilisateur (ou un autre répertoire spécifié avec --prefix), le cas échéant :

• .freeciv/scenarios/

• .freeciv/"3.2"/

L'installateur de modpack maintient un enregistrement des noms et versions des modpacks installés dans ces fichiers :

• .freeciv/scenarios/.control/mp.db

• .freeciv/"3.2"/.control/mp.db

Ces informations sont utilisées pour l'affichage et pour décider si les dépendances de nouveaux modpacks sont déjà satisfaites. Elles ne sont pas utilisées par les autres programmes Freeciv et peuvent être supprimées sans risque si elles ne correspondent plus à l'état réel des modpacks installés. Ce sont des fichiers sqlite dont le format est susceptible de changer.

ENVIRONNEMENT

L'installateur de modpack freeciv accepte les variables d'environnement suivantes :

HOME
Spécifie le répertoire personnel de l'utilisateur.
http_proxy
Définissez cette variable en conséquence lorsque vous utilisez un proxy.
LANG ou LANGUAGE
Définit la langue et la localisation sur certaines plateformes.
LC_ALL ou LC_CTYPE
Similaire à LANG (voir la documentation de votre système).
USER
Spécifie le nom d'utilisateur de l'utilisateur actuel.
