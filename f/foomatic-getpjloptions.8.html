FOOMATIC-GETPJLOPTIONS(8) Manuel de l'administrateur système FOOMATIC-GETPJLOPTIONS(8)

NOM

foomatic-getpjloptions - <mettre une courte description ici>

SYNTAXE

foomatic-getpjloptions périphérique

foomatic-getpjloptions nom_hote port

DESCRIPTION

foomatic-getpjloptions envoie un ensemble de commandes PJL et lit les options et l'état PJL à partir d'une imprimante via une connexion réseau ou une interface bidirectionnelle telle que les ports parallèle, USB, série. L'outil écrit les informations sur la sortie standard. La sortie peut être redirigée vers foomatic-addpjloptions pour ajouter des options à la base de données.

Options

périphérique
L'interface à laquelle une imprimante locale est connectée, par exemple /dev/lp0, /dev/usb/lp0, /dev/tty00, etc. Pour un port parallèle, vous devez avoir activé le support bidirectionnel au niveau du BIOS et le pilote du port parallèle doit prendre en charge le mode bidirectionnel. Vérifiez les paramètres du BIOS de votre port parallèle pour le mode EPP/bidirectionnel.
nom_hote
Nom d'hôte ou adresse IP d'une imprimante réseau (HP JetDirect, DLINK, etc.).
port
Port sur lequel votre imprimante réseau écoute les connexions socket (Appsocket). Les ports les plus courants sont 9100 (JetDirect), 10000 (DLINK). Généralement, vous pouvez configurer le port via une interface de configuration.

AUTEUR

Manfred Wassmann <manolo@NCC-1701.B.Shuttle.de> pour le projet foomatic, utilisant la sortie du binaire associé. Modifié par Patrick Powell <papowell at lprng.com> pour un meilleur support des imprimantes réseau, des messages d'erreur, et pour supprimer les retours caractère (CR) et saut de page (FF) de la sortie.

AVERTISSEMENTS

Les protocoles unidirectionnels comme le LPD distant ne sont pas supportés car aucun état n'est retourné. Certains serveurs d'impression réseau qui se connectent au port parallèle d'une imprimante ne supportent pas le mode bidirectionnel.
