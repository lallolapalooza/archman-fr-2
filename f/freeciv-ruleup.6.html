NOM

freeciv-ruleup - Met à jour les ensembles de règles de Freeciv

SYNTAXE

freeciv-ruleup [option ...]

-h, --help
Affiche un résumé des options
-F, --Fatal SIGNAL
Lève un signal SIGNAL en cas d'échec d'une assertion

-r, --ruleset ENSEMBLE_REGLES Met à jour ENSEMBLE_REGLES

-o, --output RÉPERTOIRE
Crée le répertoire OUTPUT pour la sortie
-c, --clean
Nettoie l'ensemble de règles avant de l'enregistrer

DESCRIPTION

freeciv-ruleup met à jour les ensembles de règles compatibles avec une ancienne version de freeciv-server(6) vers ceux compatibles avec la version actuelle. Il fait cela simplement en chargeant et en enregistrant l'ensemble de règles. Il peut charger un ensemble de règles dans le format d'une ancienne version de freeciv, et il enregistre dans le format de la version actuelle de freeciv. Comme il est destiné à charger des ensembles de règles qui ne sont pas destinés à être utilisés avec la version actuelle de freeciv, on souhaite généralement définir la variable d'environnement FREECIV_DATA_PATH pour qu'elle pointe vers le datadir de l'ancienne version de freeciv avant de l'utiliser. Par défaut, il enregistre l'ensemble de règles mis à jour dans un répertoire nommé d'après le nom de l'ensemble de règles avec le préfixe ".ruleup" ajouté.

BOGUES

La nécessité de configurer FREECIV_DATA_PATH pour pointer vers le répertoire de données de l'ancienne version de freeciv rend l'utilisation de l'outil quelque peu fastidieuse.

SIGNALEMENT DES BOGUES

Signalez les bogues sur "https://redmine.freeciv.org/projects/freeciv" (mais voir les mises en garde ci-dessus).

VOIR AUSSI

freeciv-server(6) et le Manuel du Client sur la page d'accueil de Freeciv.
