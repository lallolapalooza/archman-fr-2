flopen(3bsd)

Paquet: libbsd

Licences: custom

flopen(3bsd) 3bsd flopen(3bsd)

NOM

flopen, flopenat — Ouvrir et verrouiller un fichier de manière fiable

BIBLIOTHEQUE

bibliothèque « libbsd »

SYNTAXE

#include <sys/fcntl.h>
#include <libutil.h> (Voir libbsd(7) pour l'utilisation des includes.)
int
flopen(const char *chemin, int drapeaux);

int
flopen(const char *chemin, int drapeaux, mode_t mode);

int
flopenat(int fd, const char *chemin, int drapeaux);

int
flopenat(int fd, const char *chemin, int drapeaux, mode_t mode);

DESCRIPTION

La fonction flopen() ouvre ou crée un fichier et acquiert un verrou exclusif dessus. Elle est essentiellement équivalente à l'appel de open() avec les mêmes paramètres suivi de flock() avec un argument d'opération de LOCK_EX, à la différence que flopen() tentera de détecter et de gérer les courses qui peuvent survenir entre l'ouverture / la création du fichier et son verrouillage. Ainsi, elle est bien adaptée pour ouvrir des fichiers de verrouillage, des fichiers PID, des fichiers spool, des boîtes aux lettres et d'autres types de fichiers utilisés pour la synchronisation entre processus.

Si drapeaux inclut O_NONBLOCK et que le fichier est déjà verrouillé, flopen() échouera et définira errno à EWOULDBLOCK.

Comme avec open(), l'argument supplémentaire mode est requis si drapeaux inclut O_CREAT.

La fonction flopenat() est équivalente à la fonction flopen() sauf dans le cas où le chemin spécifie un chemin relatif. Dans ce cas, le fichier à ouvrir est déterminé par rapport au répertoire associé au descripteur de fichier fd au lieu du répertoire de travail courant. Si flopenat() reçoit la valeur spéciale AT_FDCWD dans le paramètre fd, le répertoire de travail courant est utilisé et le comportement est identique à un appel à flopen().

VALEURS DE RETOUR

En cas de succès, flopen() renvoie un descripteur de fichier valide. Sinon, elle renvoie -1 et définit errno comme décrit dans flock(2) et open(2).

VOIR AUSSI

errno(2), flock(2), open(2)
