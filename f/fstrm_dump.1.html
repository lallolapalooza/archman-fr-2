fstrm_dump(1) Manuel des commandes générales fstrm_dump(1)

NOM

fstrm_dump - Affiche les métadonnées et le contenu d'un fichier Frame Streams.

SYNTAXE

fstrm_dump fichier-entrée [fichier-sortie]

DESCRIPTION

fstrm_dump ouvre le fichier-entrée et imprime ses métadonnées de cadrage sur stderr et les données des trames sur stdout. Le fichier-entrée peut être "-" pour lire les données Frame Streams depuis l'entrée standard.

Les données des trames sont imprimées sous forme d'une chaîne entre guillemets à ligne unique, avec les caractères non imprimables remplacés par des séquences d'échappement hexadécimales précédées d'une barre oblique inverse. Par exemple, une trame contenant "Hello, world\n" aurait ses données imprimées comme suit :

"Hello, world\x0a"

Les seules métadonnées de cadrage attendues dans un fichier Frame Streams sont la trame de début avec un champ de type de contenu, les longueurs des trames de données et la trame d'arrêt. Celles-ci sont imprimées, respectivement, comme suit :

FSTRM_CONTROL_START

FSTRM_CONTROL_FIELD_CONTENT_TYPE (N octets)
"type-contenu"

Trame de données (N) octets

FSTRM_CONTROL_STOP

Si fstrm_dump reçoit le second paramètre fichier-sortie, les trames d'entrée sont également écrites dans fichier-sortie. Ceci est principalement utile pour les tests de régression du code fstrm_file_writer.
