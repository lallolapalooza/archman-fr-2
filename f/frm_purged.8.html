NOM

frm_purged - Démon de purge du gestionnaire de résidence de fichiers

SYNTAXE

frm_purged [options] [paramètres]

DESCRIPTION

Le démon frm_purged supprime automatiquement les fichiers résidents sur disque en fonction d'un ensemble de règles locales. Il fait partie de la suite logicielle File Residency Manager. La syntaxe d'utilisation peut être affichée en tapant « frm_purged -h ». La documentation HTML complète se trouve à l'adresse :


https://xrootd.web.cern.ch/doc/dev50/frm_config.htm

NOTES

La documentation de tous les composants associés à frm_purged se trouve à l'adresse https://xrootd.org/docs.html

DIAGNOSTICS

Les erreurs de configuration génèrent un message d'erreur et un statut de sortie non nul. Le programme ne se termine jamais en cas de succès. Utilisez la commande kill ou « /etc/init.d/frm_purged stop » pour terminer le programme.

LICENCE

Les conditions de licence peuvent être affichées en tapant « xrootd -H ».

NIVEAU DE SUPPORT

Le démon frm_purged est pris en charge par la collaboration xrootd. Les informations de contact se trouvent à l'adresse :


https://xrootd.org/contact.html
