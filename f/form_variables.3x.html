form_variables(3X) Appels système de bibliothèque form_variables(3X)

NOM

TYPE_ALNUM, TYPE_ALPHA, TYPE_ENUM, TYPE_INTEGER, TYPE_IPV4, TYPE_NUMERIC, TYPE_REGEXP - variables globales du système de formulaire

SYNTAXE

#include <form.h>
FIELDTYPE * TYPE_ALNUM;
FIELDTYPE * TYPE_ALPHA;
FIELDTYPE * TYPE_ENUM;
FIELDTYPE * TYPE_INTEGER;
FIELDTYPE * TYPE_IPV4;
FIELDTYPE * TYPE_NUMERIC;
FIELDTYPE * TYPE_REGEXP;

DESCRIPTION

Ce sont des blocs de construction pour la bibliothèque de formulaires, définissant les champs qui peuvent être créés à l'aide des fonctions form_fieldtype(3X). Chacun fournit des fonctions de validation de champ et de caractère, conformément au type de données donné.

TYPE_ALNUM

Contient des données alphanumériques.

TYPE_ALPHA

Contient des données alphabétiques.

TYPE_ENUM

Contient un type énuméré.

TYPE_INTEGER

Contient un entier décimal.

TYPE_IPV4

Contient une adresse Internet IPv4, par exemple "127.0.0.1".

TYPE_NUMERIC

Contient un nombre décimal, avec un signe et un point décimal optionnels.

TYPE_REGEXP

Contient une expression régulière.

PORTABILITÉ

La variable TYPE_IPV4 est une extension non fournie par les anciennes implémentations de la bibliothèque de formulaires.
