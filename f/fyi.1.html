DESCRIPTIO

N

fyi est une utilitaire en ligne de commande pour envoyer des notifications de bureau à l'utilisateur via un démon de notifications implémentant les notifications de bureau

XDG.

Elle est similaire à l'utilitaire bien connu notify-send(1). En effet, la plupart des options sont

identiques.

Lorsqu'elle est utilisée sans aucune option, fyi envoie la notification et se termine immédiatement, sans rien afficher sur

stdout.

Utilisez --print-id pour que fyi affiche l'identifiant de notification attribué par le démon sur stdout, au format

:
id=I
D

Pour voir pourquoi la notification a été fermée, utilisez --print-reason. La raison est affichée sur stdout, au format

:
reason=REASO
N

fyi peut aussi bloquer jusqu'à ce que la notification ait été fermée, en utilisant l'option --wait. L'envoi de SIGINT au processus fyi fermera de force la

notification.

fyi bloquera aussi si la notification a des actions. Lorsqu'une action est déclenchée, fyi affiche le nom de l'action sur stdout, au format

:
action=NAM
E

Certains démons de notifications peuvent envoyer un « jeton d'activation ». Cela se fait généralement lorsque l'utilisateur clique sur la notification, ou déclenche l'action par défaut. Le jeton peut être utilisé pour focaliser (activer) une fenêtre. Pour voir le jeton, utilisez --print-token. Le jeton est affiché sur stdout, au format

:
xdgtoken=TO
K
EN

-a,--app-name=NAM

E
Nom de l'application. Les démons de notifications afficheront soit celui-ci en tant que texte, soit l'utiliseront pour sélectionner une icône à afficher (sauf si --icon est utilisé). Par défaut : fy

N
Icône à afficher, soit comme nom d'icône symbolique (par ex. firefox) soit comme nom de fichier. Par défaut : non

l
Urgence de la notification. Raccourci pour --hint=byte:urgency:0|1|2. Par défaut : normal
.

-c,--category=CATEGOR

Y
Catégorie de la notification. Raccourci pour --hint=string:category:CATEGORY. Par défaut : none
.

-A,--action=NAME:LABE

L
Définit une action à afficher (par ex. sous forme de bouton, ou dans une liste, selon le démon de notifications). LABEL est ce que le démon de notifications affichera pour l'utilisateur. Lorsque l'utilisateur déclenche une action, fyi affichera le NAME correspondant, au format :
action=NAM
E

Cette option peut être spécifiée plusieurs fois, pour définir plusieurs

actions.

-H,--hint=TYPE:NAME:VALU

E
Définit un indice personnalisé. La façon dont ceux-ci sont interprétés dépend du démon de notifications. Un cas d'utilisation courant est d'afficher une barre de progression de quelque type ; la plupart des démons de notifications reconnaissent int:value:<percent>.

Un autre indice courant est string:x-canonical-private-synchronous:<name>. Beaucoup de démons de notifications remplaceront toute notification existante avec le même name. Cela est similaire à --replaces, sauf que vous n'avez pas besoin d'un identifiant de

notification.

-T,--print-toke

n
Afficher le jeton d'activation, le cas échéant, au format :
xdgtoken=TOKE
N

Certains démons de notifications envoient un jeton d'activation lorsque la notification est rejetée ; soit lorsque la notification est cliquée, soit lorsque l'action par défaut est invoquée. D'autres l'envoient quel que soit l'action invoquée. Certains ne l'envoient que lorsqu'une action est invoquée, tandis que d'autres l'envoient lorsque la notification est rejetée, quelle qu'en soit la

raison.

Le jeton peut être utilisé pour focaliser (activer, mettre au premier plan) une fenêtre. Il n'est pas directement utilisable par fyi, mais les programmes utilisant fyi comme assistant pour afficher des notifications peuvent

l'utiliser.
