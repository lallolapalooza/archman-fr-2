NOM

fixcvsdiff - corrige les fichiers diff problématiques

SYNTAXE

fixcvsdiff [-p] [-b] [fichier...]

DESCRIPTION

fixcvsdiff modifie les fichiers diff créés à partir de la commande cvs diff, où des fichiers ont été ajoutés ou supprimés. CVS a tendance à créer des fichiers diff que patch(1) interprète mal. Le fichier diff doit conserver les lignes commençant par « Index : » pour que la correction fonctionne.

OPTIONS

-b

Conserve un fichier de sauvegarde .bak.

-p

Affiche les commandes cvs add et cvs remove qui doivent être exécutées après l'application du diff, mais avant l'exécution de cvs commit.

VOIR AUSSI

diff(1), patch(1), cvs(1)
