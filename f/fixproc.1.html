NOM

fixproc - Corrige un processus en effectuant l'action spécifiée.

SYNTAXE

fixproc [-min n] [-max n] [-check | -kill | -restart | -exist | -fix] proc ...

DESCRIPTION

Corrige un processus nommé « proc » en effectuant l'action spécifiée. Les actions peuvent être check, kill, restart, exist ou fix. L'action est spécifiée sur la ligne de commande ou lue à partir d'une base de données par défaut, qui décrit l'action par défaut à effectuer pour chaque processus. Le format de la base de données et la signification de chaque action sont décrits ci-dessous.

OPTIONS

-min n
nombre minimum de processus qui devraient être en cours d'exécution, par défaut 1
-max n
nombre maximum de processus qui devraient être en cours d'exécution, par défaut 1
-check
vérifie le processus par rapport à la base de données /local/etc/fixproc.conf.
-kill
tue le processus, attend 5 secondes, puis kill -9 s'il existe toujours
-restart
tue le processus, attend 5 secondes, puis kill -9 s'il existe toujours, puis le redémarre
-exist
vérifie si le processus existe dans ps ET (min <= nombre de processus <= max)
-fix
vérifie le processus par rapport à la base de données /local/etc/fixproc.conf. Effectue l'action définie si la vérification échoue.
