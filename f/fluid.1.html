fluid(1) Manuel des commandes générales fluid(1)

NOM

fluid - le concepteur d'interface utilisateur rapide et léger

SYNTAXE

fluid [ -c [ -o nom-fichier-code -h nom-fichier-en-tête ] ] [ nom-fichier.fl ]

DESCRIPTION

fluid est un concepteur d'interface graphique interactif pour FLTK. Lorsqu'il est exécuté sans arguments ou avec un nom de fichier, fluid affichera la hiérarchie de l'interface graphique et toutes les fenêtres définies dans le fichier. Les fonctions, classes, fenêtres et composants d'interface graphique peuvent être manipulés selon les besoins.

Lorsqu'il est utilisé avec l'option -c, fluid créera les fichiers d'en-tête C++ et de code nécessaires dans le répertoire courant. Vous pouvez remplacer les extensions, les noms de fichiers et les répertoires par défaut en utilisant les options -o et -h.
