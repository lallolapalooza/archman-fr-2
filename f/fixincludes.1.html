NOM

fixincludes - Réduit le nombre de #includes dans les fichiers sources KDE

SYNTAXE

fixincludes [-v, --verbose] [-e, --experimental] [-m, --modify] [fichier] [--help]

DESCRIPTION

fixincludes tente de réduire le nombre de #includes dans les fichiers sources C++. Une grande partie de son traitement est spécifique aux sources KDE et il pourrait donc ne pas fonctionner aussi bien avec les sources d'applications non-KDE.

Les problèmes suivants sont identifiés par fixincludes :

•Inclusion d'en-têtes qui ne sont plus pris en charge mais qui existent pour la compatibilité avec d'anciennes versions de Qt/KDE ;
•Inclusion du même fichier plusieurs fois.

Il existe également un mode expérimental qui tente de supprimer chaque #include un par un (avec quelques exceptions) pour voir si la source compile toujours. Notez que ce mode expérimental modifiera les sources originales.

Par défaut, les sources ne seront pas modifiées ; les problèmes identifiés seront simplement écrits sur la sortie standard.

La liste des sources C++ à examiner doit être fournie sur la ligne de commande. Si aucun fichier n'est spécifié, toutes les sources C++ du répertoire courant ou de ses sous-répertoires seront examinées (à l'exception des répertoires dont le Makefile.am contient -UQT_NO_COMPAT ou -UKDE_NO_COMPAT).

Cet utilitaire fait partie du kit de développement logiciel KDE.

OPTIONS

-v, --verbose

Mode verbeux. Des informations de débogage supplémentaires sont écrites sur la sortie standard.

-e, --experimental

Mode expérimental, comme décrit ci-dessus en détail. Notez que cette option implique --modify.

-m, --modify

En plus d'écrire des messages sur la sortie standard, modifie réellement les sources originales pour corriger les problèmes rencontrés.
