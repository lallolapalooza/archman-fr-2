FSCK.CRAMFS(8) Administration Système FSCK.CRAMFS(8)

NOM

fsck.cramfs - vérifie le système de fichiers cramfs compressé

SYNTAXE

fsck.cramfs [options] fichier

DESCRIPTION

fsck.cramfs est utilisé pour vérifier le système de fichiers cramfs.

OPTIONS

-v, --verbose

Active les messages détaillés.

-b, --blocksize taille_bloc

Utilise cette taille de bloc, par défaut la taille de page. Doit être égale à ce qui était défini lors de la création. Utilisé uniquement pour --extract.

--extract[=répertoire]

Tente de décompresser l'intégralité du système de fichiers. Extrait éventuellement le contenu du fichier dans le répertoire.

-a

Cette option est ignorée silencieusement.

-y

Cette option est ignorée silencieusement.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

STATUT DE SORTIE

0

succès

4

le système de fichiers a été laissé sans correction

8

erreur d'opération, comme l'incapacité d'allouer de la mémoire

16

les informations d'utilisation ont été affichées

VOIR AUSSI

mount(8), mkfs.cramfs(8)

SIGNELER LES BOGUES

Pour les rapports de bogues, utilisez le suivi des problèmes https://github.com/util-linux/util-linux/issues.

DISPONIBILITÉ

La commande fsck.cramfs fait partie du paquet util-linux qui peut être téléchargé depuis le Linux Kernel Archive https://www.kernel.org/pub/linux/utils/util-linux/.
