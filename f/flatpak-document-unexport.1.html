NOM

flatpak-document-unexport - Arrêter l'exportation d'un fichier

SYNTAXE

flatpak document-unexport [OPTION...] FICHIER

DESCRIPTION

Supprime l'identifiant du document pour le fichier du portail de documents. Cela rendra le document indisponible pour toutes les applications sandboxées.

OPTIONS

Les options suivantes sont comprises :

--doc-id

Interpréter FICHIER comme un identifiant de document plutôt que comme un chemin de fichier. Ceci est utile par exemple lorsque le fichier a été supprimé.

-h, --help

Afficher les options d'aide et quitter.

-v, --verbose

Afficher les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Afficher les informations de débogage OSTree pendant le traitement de la commande.
