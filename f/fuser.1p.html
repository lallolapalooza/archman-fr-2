FUSER(1P) Manuel du programmeur POSIX FUSER(1P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

fuser — lister les identifiants de processus de tous les processus qui ont un ou plusieurs fichiers ouverts

SYNTAXE

fuser [-cfu] fichier...

DESCRIPTION

L'utilitaire fuser doit écrire sur la sortie standard les identifiants de processus des processus en cours d'exécution sur le système local qui ont un ou plusieurs des fichiers nommés ouverts. Pour les périphériques spéciaux à blocs, tous les processus utilisant un fichier sur ce périphérique sont listés.

L'utilitaire fuser doit écrire sur la sortie d'erreur standard des informations supplémentaires sur les fichiers nommés indiquant comment le fichier est utilisé.

Toute sortie concernant les processus s'exécutant sur des systèmes distants qui ont un fichier nommé ouvert est non spécifiée.

Un utilisateur peut avoir besoin des privilèges appropriés pour invoquer l'utilitaire fuser.

OPTIONS

L'utilitaire fuser doit être conforme au volume Définitions de base de POSIX.1‐2017, Section 12.2, Lignes directrices de syntaxe des utilitaires.

Les options suivantes doivent être prises en charge :

-c
Le fichier est traité comme un point de montage et l'utilitaire doit signaler tous les fichiers ouverts dans le système de fichiers.
-f
Le rapport ne concerne que les fichiers nommés.
-u
Le nom d'utilisateur, entre parenthèses, associé à chaque identifiant de processus écrit sur la sortie standard doit être écrit sur la sortie d'erreur standard.

OPERANDES

L'opérande suivant doit être pris en charge :

fichier
Un chemin sur lequel le fichier ou le système de fichiers doit être rapporté.

ENTRÉE STANDARD

Non utilisé.

FICHIERS ENTRANTS

La base de données utilisateur.

VARIABLES ENVIRONNEMENT

Les variables d'environnement suivantes doivent affecter l'exécution de fuser :

LANG
Fournit une valeur par défaut pour les variables d'internationalisation qui sont non définies ou vides. (Voir le volume Définitions de base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation pour la précédence des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de locale.)
LC_ALL
Si définie à une chaîne de caractères non vide, elle remplace les valeurs de toutes les autres variables d'internationalisation.
LC_CTYPE
Détermine la locale pour l'interprétation des séquences d'octets de données textuelles en caractères (par exemple, caractères mono-octet par opposition aux caractères multi-octets dans les arguments).
LC_MESSAGES

Détermine la locale qui doit être utilisée pour affecter le format et le contenu des messages de diagnostic écrits sur la sortie d'erreur standard.
NLSPATH
Détermine l'emplacement des catalogues de messages pour le traitement de LC_MESSAGES.

ÉVÉNEMENTS ASYNCHRONES

Par défaut.

SORTIE STANDARD

L'utilitaire fuser doit écrire l'identifiant de processus pour chaque processus utilisant chaque fichier donné comme opérande sur la sortie standard dans le format suivant :

"%d", <identifiant_processus>

ERREUR STANDARD

L'utilitaire fuser doit écrire les messages de diagnostic sur la sortie d'erreur standard.

L'utilitaire fuser doit également écrire ce qui suit sur la sortie d'erreur standard :

*
Le nom du chemin de chaque fichier nommé est écrit, suivi immédiatement d'un <deux-points>.
*
Pour chaque identifiant de processus écrit sur la sortie standard, le caractère 'c' doit être écrit sur la sortie d'erreur standard si le processus utilise le fichier comme répertoire courant et le caractère 'r' doit être écrit sur la sortie d'erreur standard si le processus utilise le fichier comme répertoire racine. Les implémentations peuvent écrire d'autres caractères alphabétiques pour indiquer d'autres utilisations de fichiers.
*
Lorsque l'option -u est spécifiée, les caractères indiquant l'utilisation du fichier sont suivis immédiatement du nom d'utilisateur, entre parenthèses, correspondant à l'identifiant d'utilisateur réel du processus. Si le nom d'utilisateur ne peut pas être résolu à partir de l'identifiant d'utilisateur réel du processus, l'identifiant d'utilisateur réel du processus doit être écrit à la place du nom d'utilisateur.

Lorsque la sortie standard et la sortie d'erreur standard sont dirigées vers le même fichier, la sortie sera entrelacée de sorte que le nom de fichier apparaisse au début de chaque ligne, suivi de l'identifiant du processus et des caractères indiquant l'utilisation du fichier. Ensuite, si l'option -u est spécifiée, le nom d'utilisateur ou l'identifiant utilisateur de chaque processus utilisant ce fichier sera écrit.

Un <nouvelle ligne> doit être écrit sur la sortie d'erreur standard après la dernière sortie décrite ci-dessus pour chaque opérande fichier.

STATUT SORTIE

Les valeurs de sortie suivantes doivent être retournées :

 0
Achèvement réussi.
>0
Une erreur s'est produite.

EXEMPLES

La commande :

fuser -fu .

écrit sur la sortie standard les identifiants des processus qui utilisent le répertoire courant et écrit sur la sortie d'erreur standard une indication de la manière dont ces processus utilisent le répertoire et les noms d'utilisateur associés aux processus qui utilisent le répertoire courant.

fuser -c <point de montage>

écrit sur la sortie standard les identifiants des processus qui utilisent un fichier dans le système de fichiers monté sur <point de montage> et écrit sur la sortie d'erreur standard une indication de la manière dont ces processus utilisent les fichiers.

fuser <point de montage>

écrit sur la sortie standard les identifiants des processus qui utilisent le fichier nommé par <point de montage> et écrit sur la sortie d'erreur standard une indication de la manière dont ces processus utilisent le fichier.

fuser <périphérique bloc>

écrit sur la sortie standard les identifiants des processus qui utilisent un fichier situé sur le périphérique nommé par <périphérique bloc> et écrit sur la sortie d'erreur standard une indication de la manière dont ces processus utilisent le fichier.

fuser -f <périphérique bloc>

écrit sur la sortie standard les identifiants des processus qui utilisent le fichier <périphérique bloc> lui-même et écrit sur la sortie d'erreur standard une indication de la manière dont ces processus utilisent le fichier.

fuser -uv /dev/sda1

écrit sur la sortie standard les identifiants des processus qui utilisent des fichiers sur le système de fichiers monté sur /dev/sda1. Sur la sortie d'erreur standard, il écrit le nom de fichier, suivi d'un signe deux-points, puis pour chaque PID, un caractère indiquant l'utilisation du fichier (par exemple, 'c' pour répertoire courant, 'r' pour répertoire racine), suivi du nom d'utilisateur entre parenthèses.

tion>
