Une chaîne contenant une liste de « capacités » fournies par le serveur. La valeur par défaut compilée devrait être correcte pour la plupart des usages, mais si vous êtes familier avec la fonctionnalité de capacités dans le code source, vous pouvez l'utiliser pour imposer certaines contraintes entre les clients et le

standard.
FREECIV_INTERNAL_ENCOD
ING
Définit l'encodage de caractères utilisé en interne par le client freeciv. Cela doit généralement correspondre à la boîte à outils d'interface graphique, donc sa valeur par défaut dépend du client spécifique ; la plupart des clients utilisent UTF-8 par
défaut.
FREECIV_LOCAL_ENCOD
ING
Définit l'encodage de caractères local (utilisé pour la ligne de commande et la sortie du terminal ). La valeur par défaut est déduite des autres aspects de
l'environnement.

LAN).

ATH
Une liste de répertoires séparés par des deux-points pointant vers les répertoires de données freeciv. Par défaut, Freeciv cherche dans les répertoires suivants, dans l'ordre, pour tout fichier de données : le répertoire courant ; le sous-répertoire « data » du répertoire courant ; le sous-répertoire « .freeciv/"3.2" » dans le répertoire personnel de l'utilisateur ; et le répertoire où les fichiers sont placés en exécutant « make install ». Si ce n'est pas défini, FREECIV_SAVE_PATH Une liste de répertoires séparés par des deux-points pointant vers les répertoires de sauvegarde freeciv. Par défaut, Freeciv cherche dans les répertoires suivants, dans l'ordre, pour les fichiers de sauvegarde : le répertoire courant ; et le sous-répertoire « .freeciv/saves » dans le répertoire personnel de l'utilisateur.

(Cela n'affecte pas l'endroit où le serveur lancé par le client cr

ée les fichiers de sauvegarde de partie ; ceux-ci sont toujours créés dans
« .freeciv/saves » dans le répertoire personnel de l'utilisateur.)
FREECIV_SCENARIO_P
ATH
Une liste de répertoires séparés par des deux-points pointant vers les répertoires de scénarios freeciv. Par défaut, Freeciv cherche dans les répertoires suivants, dans l'ordre, pour les fichiers de scénarios : le répertoire courant ; le sous-répertoire « data/scenarios » du répertoire courant ; les sous-répertoires « .freeciv/"3.2"/scenarios » puis « .freeciv/scenarios » dans le répertoire personnel de l'utilisateur ; et le répertoire où les fichiers sont placés en exécutant « make install ».

(Cela n'affecte pas l'endroit où le serveur lancé par le client

« .freeciv/scenarios » dans le répertoire personnel de l'utilisateur.)
