NOM

pos_form_cursor - positionne le curseur d'un formulaire

SYNTAXE

#include <form.h>
int pos_form_cursor(FORM *form);

DESCRIPTION

La fonction pos_form_cursor restaure le curseur à la position requise pour que le pilote de formulaire puisse continuer à traiter les demandes. Ceci est utile après l'appel des routines curses pour effectuer la peinture d'écran en réponse à une opération de formulaire.

VALEUR DE RETOUR

Cette routine renvoie l'une des valeurs suivantes :

E_OK
La routine a réussi.
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.
E_NOT_POSTED
Le formulaire n'a pas été affiché.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).

PORTABILITÉ

Ces routines émulent la bibliothèque de formulaires System V. Elles n'étaient pas prises en charge sur les versions Version 7 ou BSD.
