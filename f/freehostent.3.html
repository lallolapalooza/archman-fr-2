getipnodebyname(3) Manuel des fonctions de bibliothèque getipnodebyname(3)

NOM

getipnodebyname, getipnodebyaddr, freehostent - obtenir les noms d'hôte et adresses réseau

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/types.h>
#include <sys/socket.h>
#include <netdb.h>
[[deprecated]] struct hostent *getipnodebyname(const char *name, int af,
                                            int flags, int *error_num);
[[deprecated]] struct hostent *getipnodebyaddr(size_t size;
                                            const void addr[size],
                                            size_t size, int af,
                                            int *error_num);
[[deprecated]] void freehostent(struct hostent *ip);

DESCRIPTION

Ces fonctions sont obsolètes (et indisponibles dans glibc). Utilisez getaddrinfo(3) et getnameinfo(3) à la place.

Les fonctions getipnodebyname() et getipnodebyaddr() renvoient les noms et adresses d'un hôte réseau. Ces fonctions renvoient un pointeur vers la structure suivante :


struct hostent {
    char  *h_name;
    char **h_aliases;
    int    h_addrtype;
    int    h_length;
    char **h_addr_list;
};

Ces fonctions remplacent les fonctions gethostbyname(3) et gethostbyaddr(3), qui ne pouvaient accéder qu'à la famille d'adresses réseau IPv4. Les fonctions getipnodebyname() et getipnodebyaddr() peuvent accéder à plusieurs familles d'adresses réseau.

Contrairement aux fonctions gethostby, ces fonctions renvoient des pointeurs vers de la mémoire allouée dynamiquement. La fonction freehostent() est utilisée pour libérer la mémoire allouée dynamiquement après que l'appelant n'ait plus besoin de la structure hostent.

arguments de getipnodebyname()

La fonction getipnodebyname() recherche les adresses réseau pour l'hôte spécifié par l'argument name. L'argument af spécifie l'une des valeurs suivantes :

AF_INET
L'argument name pointe vers une adresse IPv4 en notation décimale pointée ou le nom d'un hôte réseau IPv4.
AF_INET6
L'argument name pointe vers une adresse IPv6 hexadécimale ou le nom d'un hôte réseau IPv6.

L'argument flags spécifie des options supplémentaires. Plus d'une option peut être spécifiée en les combinant avec un OU binaire. flags doit être défini à 0 si aucune option n'est souhaitée.

AI_V4MAPPED
Cet indicateur est utilisé avec AF_INET6 pour demander une requête d'adresses IPv4 au lieu d'adresses IPv6 ; les adresses IPv4 seront mappées en adresses IPv6.
AI_ALL
Cet indicateur est utilisé avec AI_V4MAPPED pour demander une requête pour les adresses IPv4 et IPv6. Toute adresse IPv4 trouvée sera mappée en adresse IPv6.
AI_ADDRCONFIG
Cet indicateur est utilisé avec AF_INET6 pour demander en outre que les requêtes d'adresses IPv6 ne soient pas effectuées à moins que le système n'ait au moins une adresse IPv6 assignée à une interface réseau, et que les requêtes d'adresses IPv4 ne soient pas effectuées à moins que le système n'ait au moins une adresse IPv4 assignée à une interface réseau. Cet indicateur peut être utilisé seul ou avec l'indicateur AI_V4MAPPED.
AI_DEFAULT
Cet indicateur est équivalent à (AI_ADDRCONFIG | AI_V4MAPPED).

arguments de getipnodebyaddr()

La fonction getipnodebyaddr() recherche le nom de l'hôte dont l'adresse réseau est spécifiée par l'argument addr. L'argument af spécifie l'une des valeurs suivantes :

AF_INET
L'argument addr pointe vers une struct in_addr et size doit être défini à sizeof(struct in_addr).
AF_INET6
L'argument addr pointe vers une struct in6_addr et size doit être défini à sizeof(struct in6_addr).

VALEUR DE RETOUR

NULL est renvoyé si une erreur s'est produite, et error_num contiendra un code d'erreur de la liste suivante :

HOST_NOT_FOUND
Le nom d'hôte ou l'adresse réseau n'a pas été trouvé.
NO_ADDRESS
Le serveur de noms de domaine a reconnu l'adresse ou le nom réseau, mais aucune réponse n'a été retournée. Cela peut se produire si l'hôte réseau n'a que des adresses IPv4 et qu'une requête a été faite uniquement pour des informations IPv6, ou vice versa.
NO_RECOVERY
Le serveur de noms de domaine a renvoyé une réponse d'échec permanent.
TRY_AGAIN
Le serveur de noms de domaine a renvoyé une réponse d'échec temporaire. Vous pourriez avoir plus de succès la prochaine fois.

Une requête réussie renvoie un pointeur vers une structure hostent qui contient les champs suivants :

h_name
C'est le nom officiel de cet hôte réseau.
h_aliases
C'est un tableau de pointeurs vers des alias non officiels pour le même hôte. Le tableau est terminé par un pointeur nul.
h_addrtype
C'est une copie de l'argument af passé à getipnodebyname() ou getipnodebyaddr(). h_addrtype sera toujours AF_INET si l'argument af était AF_INET. h_addrtype sera toujours AF_INET6 si l'argument af était AF_INET6.
h_length
Ce champ sera défini à sizeof(struct in_addr) si h_addrtype est AF_INET, et à sizeof(struct in6_addr) si h_addrtype est AF_INET6.
h_addr_list
C'est un tableau d'un ou plusieurs pointeurs vers des structures d'adresses réseau pour l'hôte réseau. Le tableau est terminé par un pointeur nul.

NORMES

Aucune.

HISTORIQUE

RFC 2553.

Présent dans glibc 2.1.91-95, mais retiré à nouveau. Plusieurs systèmes de type UNIX les prennent en charge, mais tous les considèrent comme obsolètes.

VOIR AUSSI
