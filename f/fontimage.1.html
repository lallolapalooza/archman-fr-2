FONTIMAGE(1) Manuel général des commandes FONTIMAGE(1)

NOM

fontimage - produit une image miniature de police

SYNOPSIS

fontimage [--help] [--width num] [--height num] [--pixelsize num] [--text chaîne] [--o fichier_sortie] [--usage] [--version] fichier_police

DESCRIPTION

Le programme fontimage charge une police, qui peut être dans n'importe quel format que fontforge(1) peut lire, puis produit une image montrant des glyphes représentatifs de la police.

OPTIONS

--help
Fournit une description avec la liste des options disponibles.
--width num
Spécifie la largeur de l'image de sortie. Si ceci est omis, l'image sera aussi large que nécessaire pour afficher le texte.
--height num
Spécifie la hauteur de l'image de sortie. Si ceci est omis, l'image sera aussi haute que nécessaire pour afficher le texte.
--pixelsize num
Spécifie la taille en pixels utilisée pour afficher le texte. Cet argument peut être spécifié plusieurs fois et chacun se réfère aux lignes --text qui le suivent.
--text chaîne
Spécifie une ligne de texte à afficher. La chaîne doit être en UTF-8. Cet argument peut être spécifié plusieurs fois pour fournir plusieurs lignes de texte. Si aucun argument --text n'est fourni, fontimage examinera la police, recherchant divers scripts qu'il connaît, et essaiera d'afficher quelque chose d'approprié pour chacun.
-o fichier_sortie
Spécifie le nom du fichier de sortie pour l'image. Le type d'image sera déterminé par l'extension du fichier. Actuellement, seuls ".bmp" et ".png" sont reconnus. Si omis, fontimage choisira un nom de sortie basé sur le champ fontname de la police.
--usage
Affiche la description de l'utilisation.
--version
Affiche la version actuelle
