NOM

fish_indent - indenteur et nettoyeur

SYNTAXE

fish_indent [OPTIONS] [FICHIER ...]

DESCRIPTION

fish_indent est utilisé pour indenter un bloc de code fish. fish_indent lit les commandes depuis l'entrée standard ou les noms de fichiers donnés et les affiche sur la sortie standard ou dans un fichier spécifié (si -w est utilisé).

Les options suivantes sont disponibles :

-w ou --write
Indente un fichier spécifié et écrit immédiatement dans ce fichier.
-i ou --no-indent
N'indente pas les commandes ; reformate uniquement pour avoir une tâche par ligne.
--only-indent
Ne reformate pas, indente uniquement chaque ligne.
--only-unindent
Ne reformate pas, désindente uniquement chaque ligne.
-c ou --check
N'indente pas, retourne uniquement 0 si le code est déjà indenté comme fish_indent le ferait, sinon retourne le nombre de fichiers échoués. Affiche également les noms des fichiers échoués si l'on ne lit pas depuis l'entrée standard.
-v ou --version
Affiche la version actuelle de fish puis quitte.
--ansi
Colorise la sortie en utilisant des séquences d'échappement ANSI avec les couleurs définies dans l'environnement (comme fish_color_command <#envvar-fish_color_command>).
--html
Produit du HTML, qui prend en charge la mise en évidence syntaxique si le CSS approprié est défini. Les noms des classes CSS sont les mêmes que les noms des variables, comme fish_color_command.
--dump-parse-tree
Affiche des informations sur les instructions analysées sur la sortie d'erreur standard. Ceci intéressera probablement uniquement les personnes travaillant sur le code source de fish.
-h ou --help
Affiche l'aide sur l'utilisation de cette commande.
