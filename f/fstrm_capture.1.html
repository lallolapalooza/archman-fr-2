fstrm_capture(1) Manuel des commandes générales fstrm_capture(1)

NOM

fstrm_capture - Réceptionne et enregistre les données Frame Streams depuis une socket.

SYNOPIS

fstrm_capture -t type-contenu -w nom-fichier
[ -u chemin-socket ] [ -a IP -p port ]
[ -c max-connexions ] [ -b taille-tampon ]
[ -s secondes ] [ --gmtime ] [ --localtime ]
[ -d [-d ...] ]

fstrm_capture --type type-contenu --write nom-fichier
[ --unix chemin-socket ] [ --tcp IP --port port ]
[ --maxconns max-connexions ] [ --buffersize taille-tampon ]
[ --split secondes ] [ --gmtime ] [ --localtime ]
[ --debug [--debug ...] ]

DESCRIPTION

fstrm_capture écoute sur une socket de domaine UNIX ou TCP, reçoit les données Frame Streams et écrit les données dans un fichier.

OPTIONS

-w nom-fichier | --write nom-fichier
Écrit les données dans le fichier nom-fichier.

Si l'option --gmtime ou --localtime est spécifiée, nom-fichier est traité par strftime(). Cela permet de spécifier une chaîne de format incluant la date et l'heure, par exemple, pour le nom de fichier créé.

Si nom-fichier est "-" et que la sortie standard n'est pas connectée à un terminal, fstrm_capture écrira sur la sortie standard. La division de la sortie (-s) ne peut pas être utilisée avec un nom-fichier de "-".

Envoyer SIGHUP à fstrm_capture videra les données tamponnées dans le fichier. Envoyer SIGUSR1 fermera et rouvrira le fichier.

-t type-contenu | --type type-contenu
Spécifie le type-contenu à recevoir depuis la socket et à écrire dans le nom-fichier de sortie.
-u chemin-socket | --unix chemin-socket
Écoute sur la socket de domaine Unix chemin-socket pour recevoir les données Frame Streams. Seul l'un des deux options -u ou -a peut être spécifié.
-a IP | --tcp IP
Écoute les connexions TCP sur l'adresse IP pour recevoir les données Frame Streams. Seul l'un des deux options -u ou -a peut être spécifié. L'utilisation de -a nécessite un port spécifié avec -p.
-p port | --port port
Si -a est spécifié, écoute sur le port TCP port pour recevoir les données Frame Streams.
-c max-connexions | --maxconns max-connexions
Autorise au maximum max-connexions connexions simultanées. Si non spécifié, les connexions simultanées ne sont pas limitées.
-b taille-tampon | --buffersize taille-tampon
Définit la taille du tampon de lecture à taille-tampon octets. Combiné avec -c, cela peut être utilisé pour limiter l'utilisation mémoire totale de fstrm_capture. La taille-tampon affecte également la taille maximale de trame que fstrm_capture acceptera. Les trames plus grandes que taille-tampon, y compris les 4 octets d'en-tête de tramage, seront rejetées.

La taille-tampon par défaut est de 262144 (256 Kio).

-s intervalle | --split intervalle
Rouvre le fichier de sortie toutes les intervalle secondes. Nécessite l'utilisation des options --gmtime ou --localtime.

Notez que cette rotation de fichier est déclenchée par les données entrantes, elle peut donc être retardée après l'intervalle.

--gmtime
Traite le nom de fichier de --write via strftime() avec l'heure actuelle en GMT. Cette option --gmtime peut être utilisée pour fournir un fichier de sortie horodaté lors du démarrage de fstrm_capture, lors de la réouverture d'un fichier de sortie en utilisant l'option --split, ou lors de la réception d'un signal SIGUSR1.
--localtime
Traite le nom de fichier de --write via strftime() avec l'heure actuelle dans le fuseau horaire local du système. Cette option --localtime peut être utilisée pour fournir un fichier de sortie horodaté lors du démarrage de fstrm_capture, lors de la réouverture d'un fichier de sortie en utilisant l'option --split, ou lors de la réception d'un signal SIGUSR1.
-d [ -d ... ] | --debug [ --debug ]
Augmente le niveau de débogage. Sans -d, fstrm_capture n'affiche que les messages d'erreur critiques. Jusqu'à cinq options -d peuvent être spécifiées, après quoi des répétitions supplémentaires n'auront aucun effet.

EXEMPLES

Réceptionner des données dnstap et les sauvegarder dans des fichiers rotatifs horaires (avec un nom de fichier converti tel que /var/log/dnstap/dnstap-2018-05-04-12:58:48.fstrm).

fstrm_capture -t protobuf:dnstap.Dnstap \
	-u /var/run/named/dnstap.sock \
	-w /var/log/dnstap/dnstap-%F-%T.fstrm \
	-s 3600 --gmtime
