NOM

fzy - Un sélecteur de texte flou pour le terminal.

SYNTAXE

fzy [OPTION]...

DESCRIPTION

fzy est un sélecteur de texte / chercheur de fichiers flou pour le terminal utilisant une recherche similaire à celle de TextMate ou CmdT.

fzy lit une liste d'éléments séparés par des sauts de ligne depuis l'entrée standard pour les afficher sous forme de menu dans le terminal. En appuyant sur ENTRÉE, l'élément actuellement sélectionné est imprimé sur la sortie standard.

La saisie de texte réduit la liste des éléments grâce à une correspondance floue. Les résultats sont triés à l'aide d'heuristiques pour la meilleure correspondance.

OPTIONS

-l, --lines=LIGNES
Nombre de lignes d'éléments à afficher. Si non spécifié, la valeur par défaut est 10 lignes.
-p, --prompt=INVITE
Invite de saisie (défaut : '> ')
-s, --show-scores
Afficher les scores pour chaque élément.
-t, --tty=TTY
Utiliser TTY au lieu du périphérique tty par défaut (/dev/tty).
-q, --query=REQUETE
Utiliser REQUETE comme requête de recherche initiale.
-e, --show-matches=REQUETE
Mode non interactif. Imprimer les correspondances dans l'ordre trié pour REQUETE sur la sortie standard.
-0, --read-null
Lire l'entrée délimitée par des caractères ASCII NUL.
-i, --show-info
Afficher la ligne d'informations de sélection.
-h, --help
Aide à l'utilisation.
-v, --version
Aide à l'utilisation.

TOUCHES

ENTRÉE
Imprimer l'élément sélectionné sur la sortie standard et quitter
Ctrl+c, Ctrl+g, Échap
Quitter avec le statut 1, sans effectuer de sélection.
Flèche Haut, Ctrl+p, Ctrl+k
Sélectionner l'élément précédent
Flèche Bas, Ctrl+n, Ctrl+j
Sélectionner l'élément suivant
Tabulation
Remplacer la chaîne de recherche actuelle par l'élément sélectionné
Retour arrière, Ctrl+h
Supprimer le caractère avant le curseur
Ctrl+w
Supprimer le mot avant le curseur
Ctrl+u
Supprimer toute la ligne

EXEMPLES D'UTILISATION

ls | fzy
Présenter un menu des éléments du répertoire courant
ls | fzy -l 25
Identique à ci-dessus, mais afficher 25 lignes d'éléments
vi $(find -type f | fzy)
Lister les fichiers sous le répertoire courant et ouvrir celui sélectionné dans vi.
cd $(find -type d | fzy)
Présenter tous les répertoires sous le chemin courant, et changer pour celui sélectionné.
ps aux | fzy | awk '{ print $2 }' | xargs kill
Lister les processus en cours, tuer le processus sélectionné
git checkout $(git branch | cut -c 3- | fzy)
Identique à ci-dessus, mais pour basculer entre les branches git.
