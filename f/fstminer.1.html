FSTMINER(1) Extraction de données de fichiers dumpfile FSTMINER(1)

NOM

fst2miner - Extraction de données à partir de fichiers FST

SYNTAXE

fstminer [option]... [FICHIERFST]

DESCRIPTION

Extrait des données spécifiques de fichiers FST et génère des fichiers de sauvegarde gtkwave vers la sortie standard pour un rechargement ultérieur.

OPTIONS

-d,--dumpfile <nom_fichier>
Spécifie le fichier dumpfile FST d'entrée.
-m,--match <valeur>
Spécifie les données de correspondance « bitwise » (binaire, réel, chaîne).
-x,--hex <valeur>
Spécifie les données de correspondance hexadécimales qui seront automatiquement converties en binaires pour les recherches.
-n,--namesonly
Indique que seuls les noms de facilités (facnames) doivent être imprimés dans un format compatible avec les fichiers de sauvegarde gtkwave. En faisant cela, le fichier peut être utilisé pour spécifier quelles traces doivent être importées dans gtkwave.
-c,--comprehensive
Indique que les résultats ne doivent pas s'arrêter après la première correspondance. Ceci peut être utilisé pour extraire toutes les valeurs correspondantes de la trace.
-h,--help
Affiche l'écran d'aide.

EXEMPLES

fstminer dumpfile.fst --hex 20470000 -n

Ceci tente de trouver la valeur hexadécimale 20470000 parmi toutes les facilités et, lorsque la valeur est rencontrée, seul le nom de la facilité est imprimé sur la sortie standard afin de générer un fichier de sauvegarde compatible avec gtkwave.

LIMITATIONS

fstminer n'imprime que la première fois qu'une valeur est rencontrée pour un réseau spécifique. Ceci est fait afin de réduire la taille des fichiers de sortie et d'aider à suivre les données telles que les adresses à travers un modèle de simulation.
