NOM

freecell-solver-range-parallel-solve - L'utilitaire Freecell Solver pour résoudre une plage de plateaux Microsoft Freecell/Freecell Pro

SYNTAXE

freecell-solver-range-parallel-solve début fin pas_impression [--binary-output-to nom_fichier] [arguments fc-solve...]

DESCRIPTION

freecell-solver-range-parallel-solve est une application en ligne de commande qui résout une plage de donnes Freecell de Microsoft Freecell et Freecell Pro.

début est le premier plateau à résoudre ; fin est le dernier (inclus) et pas_impression est la division des numéros de plateaux à laquelle un message de statut sera imprimé.

Après ces trois paramètres obligatoires, plusieurs options spécifiques à la résolution de plage sont disponibles. (voir la section OPTIONS pour plus d'informations)

Ensuite, vous pouvez lui fournir une ligne de commande fc-solve qu'il utilisera pour résoudre chaque plateau. Référez-vous à la page de manuel fc-solve(6) pour des informations sur ses options.

OPTIONS

--binary-output-to définit le nom du fichier dans lequel sortir le nombre d'itérations nécessaires pour résoudre chaque plateau. Ce fichier peut être utilisé ultérieurement avec des optimiseurs prédéfinis statistiques tels que ceux trouvés dans le dépôt de contrôle de version de Freecell Solver.
