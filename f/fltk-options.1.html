NOM

fltk-options - application pour obtenir et modifier les options d'exécution de FLTK.

SYNTAXE

fltk-options [ -Soption[=valeur] ] [ -Uoption[=valeur] ] [ -L ] [ -LS ] [ -LU ] [ -f ] [ -v ] [ --verbose ] [ -h[option] ] [ --help [option] ]

DESCRIPTION

fltk-options est un outil qui vous permet d'accéder et de modifier les paramètres liés à l'interface utilisateur dans les applications construites avec FLTK. Ces paramètres seront appliqués lors du lancement du programme. Ils peuvent être définis au niveau du système ou par l'utilisateur individuel. Les paramètres utilisateur ont la priorité sur les paramètres système.

Les arguments de ligne de commande suivants sont pris en charge :

-Soption[=valeur]

Modifier ou afficher une option globale du système.
-Uoption[=valeur]

Modifier ou afficher une option utilisateur. Les valeurs peuvent être « 0 » ou « OFF » pour effacer, ou « 1 » ou « ON » pour définir l'option. La valeur « -1 » ou « DEFAULT » définit l'option à sa valeur par défaut. Si aucune valeur n'est donnée, le réglage actuel est retourné comme « -1 », « 0 » ou « 1 ».
-L

Lister la valeur de toutes les options.
-LS

Lister la valeur de toutes les options système.
-LU

Lister la valeur de toutes les options utilisateur.
-f

Supprimer les messages d'erreur concernant les permissions d'accès aux fichiers.
-v, --verbose

Afficher des informations supplémentaires en mode ligne de commande.
-h[option], --help [option]

Affiche une page d'aide. Si une option est donnée, affiche des informations détaillées pour cette option.

Les options FLTK suivantes sont prises en charge :

OPTION_VISIBLE_FOCUS

Dessine un rectangle pointillé dans le widget ayant le focus clavier.
OPTION_ARROW_FOCUS

Les touches fléchées déplaceront le focus au-delà du champ de saisie de texte.
OPTION_SHOW_TOOLTIPS

Affiche ou masque les infobulles.
OPTION_DND_TEXT

L'utilisateur peut faire glisser du texte depuis FLTK vers d'autres applications.
OPTION_FNFC_USES_GTK

Utilise le sélecteur de fichiers GTK au lieu de FLTK si disponible.
OPTION_PRINTER_USES_GTK

Utilise la boîte de dialogue d'impression GTK au lieu de FLTK si disponible.
OPTION_SHOW_SCALING

Affiche le facteur de zoom dans une fenêtre contextuelle transitoire.

Appeler fltk-options sans options lancera le mode interactif de fltk-options.
