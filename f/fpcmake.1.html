fpcmake(1) Constructeur de Makefile pour Free Pascal fpcmake(1)

NOM

fpcmake - Le programme de construction de makefile pour Free Pascal.

SYNTAXE

fpcmake [-Tcible] [-pwhrqvV] [fichier [fichier [fichier]]]

DESCRIPTION

fpcmake lit un fichier Makefile.fpc et le convertit en un Makefile approprié pour GNU make afin de compiler vos projets. Il est similaire en fonctionnalité à GNU autoconf ou Imake pour la construction de projets X.

UTILISATION

fpcmake accepte les noms de fichiers de description de makefile comme arguments de ligne de commande. Pour chacun de ces fichiers, il créera un Makefile dans le même répertoire où se trouve le fichier, écrasant tout fichier existant portant le même nom.

Si aucune option n'est donnée, il tente simplement de lire le fichier Makefile.fpc dans le répertoire courant et essaie de construire un Makefile à partir de celui-ci. Tout Makefile existant précédemment sera effacé. Voir fpcmake(5) pour une description du format du fichier Makefile.fpc.

OPTIONS

fpcmake possède un petit nombre d'options pour contrôler son comportement :

-h
Émet un court texte d'aide décrivant l'utilisation de fpcmake
-p
Si cette option est donnée, un fichier de description de paquet est généré en plus du makefile.
-q
Indique à fpcmake d'être plus silencieux, c'est-à-dire d'émettre moins de messages.
-r
Si cette option est donnée, fpcmake analysera récursivement les sous-répertoires à la recherche de fichiers makefile.fpc et générera des makefiles pour eux.
-T
Spécifie les cibles pour lesquelles fpcmake doit générer des makefiles. Il peut s'agir d'une liste de systèmes cibles séparés par des virgules, ou de l'identifiant spécial all qui indique qu'un makefile doit être généré pour toutes les plateformes supportées.
-v
Cette option demande à fpcmake d'être plus verbeux.
-V
Affiche la version de fpcmake et quitte.
-w
Ceci est l'option standard et indique à fpcmake de générer un makefile.
