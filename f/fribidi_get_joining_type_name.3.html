NOM

fribidi_get_joining_type_name - obtenir le nom du type de jonction

SYNTAXE

#include <../fribidi/lib/fribidi.h>

const char *fribidi_get_joining_type_name(FriBidiJoiningType j);

PARAMÈTRES

FriBidiJoiningType j
Type de jonction en entrée.

Les valeurs possibles pour un FriBidiJoiningType sont les suivantes :

FRIBIDI_JOINING_TYPE_U
Non-jonction, par ex. Point final.
FRIBIDI_JOINING_TYPE_R
Jonction à droite, par ex. Lettre arabe Dal.
FRIBIDI_JOINING_TYPE_D
Jonction double, par ex. Lettre arabe Ain.
FRIBIDI_JOINING_TYPE_C
Causing Join, par ex. Tatweel, ZWJ.
FRIBIDI_JOINING_TYPE_T
Transparent, par ex. Fatha arabe.
FRIBIDI_JOINING_TYPE_L
Jonction à gauche, c'est-à-dire Fictif.
FRIBIDI_JOINING_TYPE_G
Ignoré, par ex. LRE, RLE, ZWNBSP.

DESCRIPTION

Cette fonction renvoie le nom du type de jonction d'un type de jonction. La chaîne renvoyée est une chaîne statique et ne doit pas être libérée.

Les noms de type sont identiques à ceux définis dans le Tableau 8-2 Classes de jonction arabes primaires de la norme Unicode disponibles à l'adresse http://www.unicode.org/versions/Unicode4.0.0/ch08.pdf#G7462.
