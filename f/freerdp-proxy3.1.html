NOM

freerdp-proxy - Un binaire serveur permettant le proxy MITM des connexions RDP

SYNOPSIS

freerdp-proxy [-h] [--help] [--buildconfig] [--dump-config <fichier de configuration>] [-v] [--version] [<fichier de configuration>]

DESCRIPTION

freerdp-proxy peut être utilisé pour proxifier une connexion RDP entre un serveur cible et les clients connectés. Les scénarios d'utilisation possibles sont :

Proxy
Connecter des serveurs RDP obsolètes/non sécurisés depuis derrière un proxy (plus sécurisé)
Analyse
Permettre l'analyse détaillée du protocole de nombreuses fonctionnalités inconnues du protocole (canaux)
Inspection
Proxy MITM pour l'inspection et l'enregistrement de sessions

OPTIONS

-h,--help
Afficher un texte d'aide expliquant l'utilisation.
--buildconfig
Imprimer la configuration de compilation du proxy et quitter.
-v,--version
Imprimer la version du proxy et quitter.
--dump-config
Exporter un modèle de configuration dans <fichier-ini-de-configuration>
<fichier-ini-de-configuration>
Démarrer le proxy avec les paramètres lus depuis <fichier-ini-de-configuration>

AVERTISSEMENT

Le proxy ne prend pas en charge l'authentification telle quelle mais agit simplement comme un intermédiaire. Seuls les modes de sécurité RDP et TLS sont pris en charge, NLA échouera pour les connexions au proxy. Pour implémenter l'authentification, un module proxy peut être implémenté qui peut s'authentifier auprès d'un backend et mapper les utilisateurs et identifiants connectés aux utilisateurs et identifiants du serveur cible.

EXEMPLES

freerdp-proxy /quelque/fichier/de/configuration

freerdp-proxy --dump-config /quelque/fichier/de/configuration

PREPARATIFS

1. générer des certificats pour le proxy

winpr-makecert -rdp -path . proxy

2. générer la configuration du proxy

freerdp-proxy --dump-config proxy.ini

3. éditer la configuration et :


* fournir les chemins (de préférence absolus) pour CertificateFile et PrivateKeyFile générés précédemment
* supprimer CertificateContents et PrivateKeyContents
* Ajuster les paramètres [Server] Host et Port pour lier un port spécifique sur une interface réseau
* Ajuster les paramètres [Target] Host et Port vers le serveur cible RDP
* Ajuster (ou supprimer si inutilisé) les paramètres Plugins

3. démarrer le serveur proxy


freerdp-proxy proxy.ini
