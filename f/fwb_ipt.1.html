NOM

fwb_ipt - Compilateur de politique pour iptables

SYNTAXE

fwb_ipt -ffichier_donnees.xml [-4] [-6] [-V] [-drep_travail] [-i] [-osortie.fw] [-Oid_fw1,sortie_fw1.fw[,id_fw2,sortie_fw2.fw]] [-v] [-xc] [-xnN] [-xpN] [-xt] nom_objet

DESCRIPTION

fwb_ipt est un composant de compilation de politique de pare-feu de Firewall Builder (voir fwbuilder(1)). Le compilateur lit les définitions d'objets et la description du pare-feu à partir du fichier de données spécifié avec l'option "-f" et génère le script iptables résultant. Le script est écrit dans le fichier portant le même nom que l'objet pare-feu, avec l'extension ".fw".

Le fichier de données et le nom de l'objet pare-feu doivent être spécifiés sur la ligne de commande. Les autres paramètres de la ligne de commande sont optionnels.

OPTIONS

-4
Génère le script iptables pour la partie IPv4 de la politique. Si certaines règles du pare-feu font référence à des adresses IPv6, le compilateur ignorera ces règles. Les options "-4" et "-6" sont exclusives. Si aucune des deux options n'est utilisée, le compilateur essaie de générer les deux parties du script, bien que la génération de la partie IPv6 soit contrôlée par l'option "Enable IPv6 support" dans l'onglet "IPv6" de la boîte de dialogue des paramètres avancés de l'objet pare-feu. Cette option est désactivée par défaut.
-6
Génère le script iptables pour la partie IPv6 de la politique. Si certaines règles du pare-feu font référence à des adresses IPv6, le compilateur ignorera ces règles.
-f FICHIER
Spécifie le nom du fichier de données à traiter.
-o sortie.fw
Spécifie le nom du fichier de sortie.
-O id_fw1,sortie_fw1.fw[,id_fw2,sortie_fw2.fw]
L'argument est une liste séparée par des virgules d'identifiants d'objets pare-feu et de leurs noms de fichiers de sortie correspondants. Cette option est utilisée par l'interface graphique de fwbuilder lors de la compilation de clusters de pare-feu.
-d rep_travail
Spécifie le répertoire de travail. Le compilateur crée le fichier avec le script iptables dans ce répertoire. Si ce paramètre est absent, le script iptables sera placé dans le répertoire de travail courant.
-v
Verbeux : le compilateur affiche des messages de diagnostic pendant son exécution.
-V
Affiche le numéro de version et quitte.
-i
Lorsque cette option est présente, le dernier argument de la ligne de commande est censé être l'identifiant de l'objet pare-feu plutôt que son nom.
-xc
Lorsque le nom du fichier de sortie est déterminé automatiquement (c'est-à-dire que les options -o ou -O ne sont pas présentes), le nom du fichier est composé du nom du cluster et du nom du pare-feu membre, plutôt que seulement du nom du pare-feu membre. Ceci est principalement utilisé pour les tests lorsque le même objet pare-feu membre peut faire partie de différents clusters avec des configurations différentes.
-xt
Ce drapeau fait en sorte que le compilateur traite toutes les erreurs fatales comme des avertissements et continue à traiter les règles. Le script de configuration généré sera très probablement incorrect mais inclura le message d'erreur sous forme de commentaire ; ce drapeau est utilisé pour les tests et le débogage.
-xp N
Drapeau de débogage : cela amène le compilateur à imprimer une description détaillée de la règle de politique numéro "N" lors de son traitement, étape par étape.
-xn N
Drapeau de débogage : cela amène le compilateur à imprimer une description détaillée de la règle NAT numéro "N" lors de son traitement, étape par étape.
