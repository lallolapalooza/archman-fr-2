NOM

fzf-tmux - ouvre fzf dans un volet divisé tmux

SYNTAXE

fzf-tmux [OPTIONS_DE_MISE_EN_PAGE] [--] [OPTIONS_FZF]

DESCRIPTION

fzf-tmux est un script enveloppant pour fzf qui ouvre fzf dans un volet divisé tmux ou dans une fenêtre popup tmux. Il est conçu pour fonctionner exactement comme fzf, sauf qu'il n'occupe pas tout l'écran. Vous pouvez utiliser fzf-tmux en toute sécurité à la place de fzf dans vos scripts car les options supplémentaires seront ignorées silencieusement si vous n'êtes pas sur tmux.

OPTIONS DE MISE EN PAGE

(mise en page par défaut : -d 50%)

Fenêtre popup

(nécessite tmux 3.2 ou supérieur)

-p [LARGEUR[%][,HAUTEUR[%]]]
-w LARGEUR[%]
-h LARGEUR[%]
-x COL
-y LIGNE

Volet divisé

-u [hauteur[%]]
Diviser au-dessus (en haut)
-d [hauteur[%]]
Diviser en dessous (en bas)
-l [largeur[%]]
Diviser à gauche
-r [largeur[%]]
Diviser à droite
