NOM

fprintd - démon de gestion des empreintes digitales, et applications de test

SYNTAXE

fprintd-enroll [-f doigt] [nomutilisateur]

fprintd-list nomutilisateur [nomsutilisateurs...]

fprintd-verify [-f doigt] [nomutilisateur]

fprintd-delete nomutilisateur [nomsutilisateurs...]

DESCRIPTION

Cette page de manuel documente brièvement les utilitaires en ligne de commande de fprintd.

Le démon fprintd est accédé via D-Bus par ces utilitaires en ligne de commande.

ARGUMENTS

nomutilisateur
Le nom d'utilisateur pour lequel vous souhaitez interroger ou modifier la base de données d'empreintes digitales.

Notez que fprintd-list et fprintd-delete nécessitent au moins un nom d'utilisateur, et supportent plusieurs noms d'utilisateur.

fprintd-enroll et fprintd-verify utiliseront le nom d'utilisateur actuel si aucun n'est passé en ligne de commande.

-f doigt
Pour fprintd-enroll, le doigt à enregistrer. Valeurs possibles :

pouce-gauche, index-gauche, majeur-gauche, annulaire-gauche, auriculaire-gauche, pouce-droit, index-droit, majeur-droit, annulaire-droit, auriculaire-droit.

Par défaut, le choix est automatique, sélectionnant le premier doigt disponible pour les périphériques à glissement, ou tous les doigts enregistrés pour les périphériques à pression.

APPLICATIONS DE TEST

fprintd-enroll

Enregistrera l'index droit de l'utilisateur dans la base de données.

fprintd-list

Affichera les empreintes digitales enregistrées de l'utilisateur.

fprintd-verify

Vérifiera les empreintes digitales de l'utilisateur par rapport à la base de données.

fprintd-delete

Supprimera l'index droit de l'utilisateur de la base de données.

AUTEUR

fprintd a été écrit par Bastien Nocera et Daniel Drake.

RÉPERTOIRES

Par défaut, fprintd stocke les empreintes digitales dans /var/lib/fprint/
