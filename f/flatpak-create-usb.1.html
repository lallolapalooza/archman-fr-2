NOM

flatpak-create-usb - Copier des applications et/ou des runtimes sur des supports amovibles.

SYNTAXE

flatpak create-usb [OPTION...] CHEMIN-MONTAGE REF...

DESCRIPTION

Copie les REFs d'applications et/ou de runtimes spécifiés sur le support amovible monté à CHEMIN-MONTAGE, ainsi que toutes les dépendances et métadonnées nécessaires pour leur installation. C'est une méthode de transfert de flatpaks entre ordinateurs qui ne nécessite pas de connexion Internet. Après avoir utilisé cette commande, la clé USB peut être connectée à un autre ordinateur sur lequel les dépôts pertinents sont déjà configurés, et Flatpak installera ou mettra à jour depuis le lecteur hors ligne (voir ci-dessous). Si vous êtes en ligne, le lecteur sera utilisé comme un cache, ce qui signifie que certains objets seront extraits de celui-ci et d'autres de l'Internet. Pour que ce processus fonctionne, un identifiant de collection doit être configuré sur les dépôts pertinents sur les ordinateurs source et destination, ainsi que sur le serveur distant.

Sur l'ordinateur de destination, on peut installer depuis la clé USB (ou tout autre système de fichiers monté) en utilisant l'option --sideload-repo avec flatpak install. Il est également possible de configurer des chemins de sideload à l'aide de liens symboliques ; voir flatpak(1). Flatpak inclut également des unités systemd pour effectuer automatiquement le sideload à partir de clés USB branchées à chaud, mais celles-ci peuvent être activées ou non en fonction de votre distribution Linux.

Chaque argument REF est un identifiant complet ou partiel au format de référence flatpak, qui ressemble à "(app|runtime)/ID/ARCH/BRANCH". Tous les éléments sauf ID sont facultatifs et peuvent être omis, y compris les barres obliques, donc la plupart du temps, vous n'avez besoin de spécifier que l'ID. Toute partie omise sera comparée à ce qui est installé, et s'il y a plusieurs correspondances, un message d'erreur indiquera les alternatives.

Par défaut, cela recherche les applications et les runtimes installés avec la REF donnée, mais vous pouvez limiter cela en utilisant l'option --app ou --runtime.

Toutes les REFs doivent provenir de la même installation (utilisateur, système ou autre). Sinon, il est ambigu de savoir quelles métadonnées de dépôt mettre sur la clé USB.

Par défaut, flatpak create-usb utilise .ostree/repo comme répertoire de destination sous CHEMIN-MONTAGE, mais si vous spécifiez un autre emplacement en utilisant --destination-repo, un lien symbolique sera créé pour vous dans .ostree/repos.d. Cela garantit que dans les deux cas, le dépôt sera trouvé par flatpak (et d'autres consommateurs de libostree) pour les opérations d'installation/mise à jour.

Sauf indication contraire avec les options --system, --user, ou --installation, cette commande recherche dans l'installation système et dans celle de l'utilisateur la REF et génère une erreur si elle existe dans plus d'une.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

-u, --user

Copie les refs de l'installation par utilisateur.

--system

Copie les refs de l'installation système par défaut.

--installation=NOM

Copie les refs d'une installation système spécifiée par NOM parmi celles définies dans /etc/flatpak/installations.d/. Utiliser --installation=default équivaut à utiliser --system.

--app

Suppose que toutes les REFs sont des applications si elles ne sont pas explicitement spécifiées.

--runtime

Suppose que toutes les REFs sont des runtimes si elles ne sont pas explicitement spécifiées.

--destination-repo=DEST

Crée le dépôt dans DEST sous CHEMIN-MONTAGE, plutôt qu'à l'emplacement par défaut.

--allow-partial

N'affiche pas d'avertissement lors de l'exportation de commits partiellement installés, par exemple les extensions de langue sans toutes les langues. Celles-ci peuvent causer des problèmes lors de leur installation, par exemple si la configuration linguistique est différente du côté de l'installation.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak create-usb /run/media/mwleeds/1a9b4cb2-a7ef-4d9b-91a5-6eaf8fdd2bf6/ com.endlessm.wiki_art.en
