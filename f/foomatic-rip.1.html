NOM

foomatic-rip — moteur de rendu PostScript de Foomatic

SYNTAXE

foomatic-rip [-h] [-v] [-P printer] [-J jobname] [-p printer-info] [-t tray] [-l locale] [-M media] [-n orientation] [-o option=value] [-m mediatype] [-r resolution] [-d destination] [-c copies] [-F fcdir] [-e encoding] [-q quality] [-u unparsed-options] [-I] [-O output-file] [document ...]

DESCRIPTION

Le programme foomatic-rip est le moteur de rendu principal de Foomatic. Il prend une description d'impression au format PostScript ou PCL et la convertit en un format compréhensible par une imprimante. Il peut être utilisé soit comme un programme autonome pour l'impression directe, soit comme un filtre pour le système d'impression CUPS.

IMPRESSION DIRECTE, SANS SPOOLER

Pour imprimer directement un fichier sans utiliser de spooler, vous pouvez appeler foomatic-rip comme suit:

  foomatic-rip -P nom_imprimante -o media=A4 -o sides=two-sided-long-edge mon_document.ps

Cela enverra le fichier mon_document.ps à l'imprimante nommée nom_imprimante, en utilisant la taille de papier A4 et l'impression recto-verso sur le grand côté.

IMPRESSION AVEC SPOOLER

Si vous utilisez CUPS, vous n'avez généralement pas besoin d'appeler foomatic-rip directement. CUPS s'occupe de l'appeler en tant que filtre lorsqu'il est configuré pour le faire.

Pour utiliser foomatic-rip avec CUPS, vous devez créer un fichier de configuration d'imprimante dans /etc/cups/printers.conf ou dans le répertoire d'imprimantes de CUPS. Ce fichier doit spécifier que foomatic-rip est le moteur de rendu.

FICHIER DE CONFIGURATION

foomatic-rip utilise plusieurs fichiers de configuration pour déterminer le comportement de l'imprimante et les options d'impression disponibles. Les fichiers de configuration principaux sont les suivants :

FICHIERS

/etc/cups/printers.conf
Fichier de configuration principal de CUPS, où les imprimantes et leurs configurations sont définies.
/etc/cups/cupsd.conf
Fichier de configuration du démon CUPS.
/etc/foomatic/foomatic-rip.conf
Fichier de configuration spécifique pour le comportement de foomatic-rip. Il peut être utilisé pour surcharger les paramètres par défaut ou définir des comportements spécifiques aux imprimantes qui ne sont pas gérés par le fichier printers.conf de CUPS.
/etc/foomatic/filter.conf

Fichier de configuration pour le filtre foomatic-rip.

STATUT DE SORTIE

foomatic-rip retourne 0 sauf si quelque chose d'inattendu se produit.
