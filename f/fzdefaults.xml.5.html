NOM

fzdefaults.xml - Options par défaut pour FileZilla

SYNTAXE

/etc/filezilla/fzdefaults.xml
~/.filezilla/fzdefaults.xml

DESCRIPTION

Ce fichier de configuration peut être utilisé pour spécifier certaines options par défaut à l'échelle du système pour FileZilla :

  • Emplacement du répertoire de configuration de l'utilisateur
  • Liste prédéfinie d'entrées du gestionnaire de sites
  • Mode kiosque pour empêcher FileZilla de sauvegarder des mots de passe
  • Désactivation de la vérification des mises à jour

Veuillez rechercher le fichier fzdefaults.xml.example pour plus d'informations. Il se trouve souvent dans le répertoire /usr/share/filezilla/docs.

SUPPORT

Veuillez visiter https://filezilla-project.org/ pour plus d'informations. Ne signalez les bugs que si vous utilisez la dernière version disponible sur le site Web de FileZilla.
