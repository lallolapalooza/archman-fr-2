DESCRIPTIO

N

Freeciv est un jeu de stratégie multijoueur gratuit au tour par tour, dans lequel chaque joueur devient le chef d'une civilisation, luttant pour atteindre l'objectif ultime : devenir la plus grande

civilisation.

Les joueurs de Civilization II® par Microprose® devraient se sentir chez eux, car l'un des buts de Freeciv est d'avoir des règles

compatibles.

Freeciv est maintenu par une équipe internationale de codeurs et d'enthousiastes, et est facilement l'un des jeux en réseau les plus amusants et addictifs qui soient

!

Ceci est le programme client utilisé pour se connecter à un serveur Freeciv - voir aussi freeciv-server(6) . freeciv-gtk3.22, freeciv-gtk4, freeciv-qt, freeciv-sdl2, et freeciv-sdl3 peuvent aussi lancer leur propre serveur local pour les parties en joueur

unique.

Cette page de manuel ne liste que les arguments de ligne de commande. Pour plus de détails sur l'utilisation de freeciv-gtk3.22, freeciv-gtk4, freeciv-sdl2, freeciv-sdl3, ou freeciv-qt, voir le Manuel du Client qui peut être trouvé sur le site web de Freeciv ainsi que la document

ation qui fait partie de
la distribution Freeciv.

Les options suivantes sont acceptées par tous les clients. Elles ne peuvent pas être combinées ; c'est-à-dire que « -np caesar 5557 » ne fonctionnera pas, à la place vous devrez saisir « -n caesar -p 5557 ». Toutes les options ont une forme courte (un tiret et une lettre) et une forme longue (deux tirets et un mot complet) ; leurs effets sont

identiques.

Une chaîne contenant une liste de « capacités » fournies par le serveur. La valeur par défaut compilée devrait être correcte pour la plupart des usages, mais si vous êtes familier avec le mécanisme de capacités dans le code source, vous pouvez l'utiliser pour imposer certaines contraintes entre les clients et le

FREECIV_INTERNAL_ENCOD
ING
Définit l'encodage de caractères utilisé en interne par le client freeciv. Cela doit généralement correspondre à la boîte à outils d'interface graphique, donc sa valeur par défaut dépend du client spécifique ; la plupart des clients utilisent UTF-8 par
défaut.

ING
Définit l'encodage de caractères local (utilisé pour la ligne de commande et la sortie du terminal). La valeur par défaut est déduite d'autres aspects de l'

Une liste de répertoires séparés par des deux-points pointant vers les répertoires de données de freeciv. Par défaut, Freeciv recherche les fichiers de données dans les répertoires suivants, dans l'ordre : le répertoire courant ; le sous-répertoire « data » du répertoire courant ; le sous-répertoire « .freeciv/"3.2" » dans le répertoire personnel de l'utilisateur ; et le répertoire où les fichiers sont placés en exécutant « make install ». Si non défini, FREECIV_SAVE_PATH Une liste de répertoires séparés par des deux-points pointant vers les répertoires de sauvegarde de freeciv. Par défaut, Freeciv recherche les fichiers de sauvegarde dans les répertoires suivants, dans l'ordre : le répertoire courant ; et le sous-répertoire « .freeciv/saves » dans le répertoire personnel de l'utilisateur.
