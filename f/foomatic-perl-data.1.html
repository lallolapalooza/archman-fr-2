FOOMATIC-PERL-DATA(1) Manuel des commandes générales FOOMATIC-PERL-DATA(1)

NOM

foomatic-perl-data - générer des structures de données Perl à partir de XML

SYNTAXE

foomatic-perl-data [ -O ] [ -C ] [ -P ] [ -D ] [ -o option=réglage ] [ -o ... ] [ -v ] [ nom_de_fichier ]

Options

-O Analyser les données XML de synthèse

-C Analyser les données XML des combinaisons imprimante/pilote (par défaut)

-P Analyser les données XML des entrées imprimante

-D Analyser les données XML des entrées pilote

-o option=réglage Réglages d'options par défaut pour les données Perl générées (combinaisons uniquement)

-v Mode verbeux (débogage)

nom_de_fichier Lire l'entrée depuis un fichier et non depuis l'entrée standard

STATUT DE SORTIE

foomatic-perl-data retourne ...
