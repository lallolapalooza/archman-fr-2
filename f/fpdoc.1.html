fpdoc - Le générateur d

e documentation pour le
s unités Pascal de FPC.

SYNOPSI

S

fpdoc --input=inputcommand [--output=output] [--format=fmt]

[--descr=descriptionfile] [-
-package=packagename] [options]

Descriptio

n

fpdoc analyse un fichier source d'unité Free Pascal et génère la documentation pour celui-ci. La documentation peut être dans différents formats (actuellem

ent HTML et LaTeX). Il peut lire différents fichiers de description qui conti
ennent la description des différents symboles trouvés dans le fichier d'unité.

Utilisati

on

Vous pouvez invoquer fpdoc avec comme seuls arguments requis les arguments 'input' et 'package'. Il doit au moins contenir le nom du

fichier d'unité pour lequel la documentation doit être
générée et le nom du paquet auquel l'unité appartient.

Option

s

fpdoc a plusieurs options, la plupart étant facultatives, les valeurs par défaut seront utilisées dans la plupart des

cas.
--conte
nt
Cette option indique à fpdoc de générer un fichier de contenu. Un fichier de contenu contient une liste de toutes les ancres (étiquettes) possibles dans le fichier de documentation généré, et peut être utilisé pour créer des liens croisés dans la documentation pour différentes unités, en utilisant l'option --import
.
--cputarget=va
lue
Cette option indique à fpdoc pour quel CPU générer la documentation. Cela définit simplement les macros CPU
appropriées.
--descr=descf
ile
Cette option spécifie le nom d'un fichier de description descfile qui contient la documentation réelle pour l'unité. Cette option peut être donnée plusieurs fois, pour plusieurs fichiers de
description.
--descr-dir=
dir
Cette option spécifie le nom d'un répertoire avec des fichiers de description XML, nommé dir Cette option peut être donnée plusieurs fois, pour plusieurs répertoires de description. Cette option est équivalente à spécifier tous les fichiers du répertoire avec l'option
--descr.
--dont-tr
im
Cette option indique à fpdoc de ne pas supprimer les espaces blancs dans les fichiers XML. Par défaut, les espaces blancs sont supprimés de l'entrée, ce qui peut avoir des effets secondaires indésirables dans des balises PRE par
exemple.
--dry-r
un
Cette option indique à fpdoc de ne générer aucune sortie, mais simplement d'analyser toute l'entrée. Cela peut être utilisé avec l'option verbose pour vérifier quelles erreurs restent dans la documentation, ou ce qui manque
encore.
--format=f
mt
Spécifie le format fmt dans lequel la documentation sera généré

--he
lp
Affiche un résumé des options de la ligne de

--hide-protec
ted
Par défaut, la documentation inclura les descriptions et les listes des champs et méthodes protégés dans les classes ou les objets. Cette option change ce comportement ; si elle est spécifiée, aucune documentation ne sera générée pour ces méthodes. Notez que les méthodes ou propriétés publiques qui font référence à ces méthodes protégées auront alors un lien orphelin (c'est-à-dire indisponible)
.
--html-search=l
ink
Ajoute une entrée pour une page de recherche HTML à l'emplacement link dans les en-têtes des pages HTML générées. Aucune page de recherche n'est fournie, celle-ci doit être créée et fournie par
l'utilisateur.
--import=impf
ile
importe un fichier de contenu impfile d'un autre ensemble de documentation. Cela peut être utilisé pour résoudre les références aux éléments dans cet autre fichier de documentation
;
--input=c
md
Cette option indique à fpdoc quel fichier d'entrée doit être utilisé. L'argument cmd peut être juste un nom de fichier, mais peut aussi être une ligne de commande complète du compilateur avec des options concernant l'analyse de la source pascal : définitions, fichiers d'inclusion, options de syntaxe, telles qu'elles seraient spécifiées au compilateur free pascal lors de la compilation du fichier. Si une commande complète est utilisée, elle doit être entourée de guillemets simples ou doubles, afin que le shell ne la divise pas en parties. Il est possible de spécifier plusieurs commandes d'entrée ; elles seront traitées une par une, et la documentation sera générée pour chacune
d'elles.
--input-dir=
dir
Cette option indique à fpdoc d'ajouter tous les fichiers .pas et .pp du répertoire nommé cmd comme fichiers d'entrée pour le documenteur. Cela est équivalent à spécifier tous les fichiers du répertoire avec la commande --input
.
--lang=langu
age
Définit la langue du fichier de sortie. Cela définira principalement les chaînes
utilisées pour les en-têtes dans les différentes parties des fichiers de documen
tation (par défaut elles sont en anglais). Actuellement, les options valides sont
d
e
Allema
nd.
f
r
França
is.
n
l

a
is
.
--latex-extension=
ext
Définit l'extension à utiliser pour le fichier LaTeX à ext la valeur par défaut est .tex (avec le . (point) inclus)
.
--latex-highli
ght
Active un colorateur de syntaxe latex interne. Cela n'est pas encore implémenté. Par défaut, la coloration syntaxique est fournie par le paquet syntax qui accompagne
fpc.
--mo-dir=d
ir
Cette option indique à fpdoc où chercher les fichiers de traduction qui peuvent être utilisés pour internationaliser la sortie de
fpdoc.
--ostarget=va
lue
Cette option indique à fpdoc pour quel système d'exploitation générer la documentation. Cela définit simplement les macros de système d'exploitation
appropriées.
--output=na
me
Cette option indique à fpdoc où le fichier de sortie doit être généré. La manière dont cette option est interprétée dépend du format utilisé. Pour latex, name est interprété comme le nom de fichier pour le fichier tex. Pour tous les autres formats, name est interprété comme le répertoire où tous les fichiers de documentation seront écrits. Le répertoire sera créé s'il n'existe pas encore. Par défaut, cela équivaut au nom du
paquet.
--package=packagen
ame
Spécifie le nom du paquet. Toutes les unités seront documentées comme faisant partie de packagename , qui est aussi le nom de fichier de sortie par défaut ou le répertoire. Seuls les nœuds de documentation à l'intérieur d'un nœud de paquet avec ce nom seront pris en compte lors de la
documentation.
--parse-im
pl
(Expérimental) essaie d'analyser également l'implémentation d'une unité, cela peut être utilisé pour la vérification
syntaxique.
--project=fich
ier
Cette option indique à fpdoc de lire toutes les options depuis un fichier projet. Il s'agit d'un fichier XML, veuillez consulter la documentation pour plus d'informations sur le format de ce
fichier.
--show-priva
te
Par défaut, aucune documentation n'est générée pour les méthodes ou les champs privés. Cette option fait que fpdoc génère également la documentation pour ces
méthodes.
--verbo
se
Par défaut, fpdoc produit peu de sorties. Cette option indique à fpdoc de générer davantage d'informations sur ce qu'il
fait.
--warn-no-no
de
Si cette option est spécifiée, fpdoc émettra un avertissement s'il ne trouve pas de nœud de description pour un identifiant qu'il
documente.
--write-project=fich
ier
Si cette option est spécifiée, fpdoc écrira un fichier projet fpdoc (vers le nom
de fichier spécifié) qui cor
respond aux options de ligne
de commande fournies.
