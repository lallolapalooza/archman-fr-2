FSSTAT(1) Manuel des commandes générales FSSTAT(1)

NOM

fsstat - Affiche les détails généraux d'un système de fichiers

SYNTAXE

fsstat [-f fstype ] [-i imgtype] [-o imgoffset] [-b dev_sector_size] [-tvV] image [images]

DESCRIPTION

fsstat affiche les détails associés à un système de fichiers. La sortie de cette commande est spécifique au système de fichiers. Au minimum, la plage des valeurs de métadonnées (numéros d'inode) et des unités de contenu (blocs ou clusters) est donnée. Les détails du Super Bloc, tels que les temps de montage et les fonctionnalités, sont également fournis. Pour les systèmes de fichiers qui utilisent des groupes (FFS et EXT2FS), la disposition de chaque groupe est listée.

Pour un système de fichiers FAT, la table FAT est affichée dans un format condensé. Notez que les données sont en secteurs et non en clusters.

ARGUMENTS

-t type
Affiche uniquement le type de système de fichiers.
-f fstype
Spécifie le type de système de fichiers. Utilisez '-f list' pour lister les types de systèmes de fichiers pris en charge. Si non spécifié, des méthodes de détection automatique sont utilisées.
-i imgtype
Identifie le type de fichier image, tel que brut. Utilisez '-i list' pour lister les types pris en charge. Si non spécifié, des méthodes de détection automatique sont utilisées.
-o imgoffset
Le décalage de secteur où le système de fichiers commence dans l'image.
-b dev_sector_size
La taille, en octets, des secteurs du périphérique sous-jacent. Si non spécifié, la valeur dans le format de l'image est utilisée (si elle existe) ou 512 octets sont supposés.
-v
Sortie verbeuse des instructions de débogage vers stderr
-V
Affiche la version
image [images]
L'image disque ou partition à lire, dont le format est donné avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné et que son nom est le premier d'une séquence (par exemple, indiqué par une terminaison en '.001'), les segments d'image suivants seront inclus automatiquement.
