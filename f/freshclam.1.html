OPTION

S

FreshClam lit sa configuration depuis freshclam.conf. Les paramètres peuvent être remplacés par les options de ligne de

commande.
-h,
--help
Affiche les informations d'aide et
quitte.
-V,
--version
Affiche le numéro de version et
quitte.
-v,
--verbose
Mode verbeux. Cette option fait que freshclam affiche beaucoup d'informations
supplémentaires.
--deb
ug
Active les messages de débogage de
LibClamAV.
--qui
et
Mode silencieux - n'affiche que les messages
d'erreur.
--no-warnin
gs
N'affiche ni n'enregistre les
avertissements.
--stdo
ut
Écrit tous les messages sur
stdout.
--show-progr
ess
Affiche le pourcentage de progression du
téléchargement.
--config-file=FICH
IER
Lit la configuration depuis
FICHIER.
-l FICHIER,
--log=FICHIER
Enregistre le rapport dans
FICHIER.
-d,
--daemon
Exécute en mode démon. Par défaut, effectue 12 vérifications par jour, sauf si spécifié autrement par --checks ou freshclam.
conf.
-p FICHIER,
--pid=FICHIER
Écrit le pid du démon dans
FICHIER.
-F,
--foreground
Ne se détache pas en arrière-plan (pour utilisation en mode
démon).
-u UTILISATEUR, --user
UTILISATEUR
Exécute en tant qu'UTILISATEUR. Par défaut (lorsqu'il est démarré par root), freshclam abandonne ses privilèges et fonctionne en tant qu'utilisateur
'clamav'.
--no-d
ns
Cette option force l'ancienne méthode de vérification non-DNS (sans délai
TTL).
-c #n,
--checks=#n
Vérifie #n fois par jour s'il y a une nouvelle base de données. #n doit être compris entre 1 et
50.
--datadir=RÉPERTO
IRE
Installe la nouvelle base de données dans RÉPERTOIRE. Le répertoire doit être inscriptible pour l'utilisateur 'clamav' ou l'utilisateur non privilégié exécutant freshclam, doit déjà exister et doit être un chemin
absolu.
--daemon-notify=/chemin/vers/clamd.
conf
Notifie le démon de la nouvelle base de données. Par défaut, il lit un fichier de configuration codé en dur, mais vous pouvez en utiliser un différent. Les sockets locaux et TCP sont pris en
charge.
-a IP, --local-address
=IP
Utilise l'IP (locale) pour les téléchargements HTTP. Utile pour les systèmes multi-homés. Si la liaison échoue pour quelque raison que ce soit, un avertissement est émis et freshclam se comporte comme sans cet
indicateur.
--on-update-execute=COMMA
NDE
Exécute COMMANDE après une mise à jour
réussie.
--on-error-execute=COMMA
NDE
Exécute COMMANDE si une erreur s'est produite. Rappelez-vous que la fraîcheur des bases de données de virus est la chose la plus importante dans un système antivirus. Avec cette option, freshclam peut vous alerter (par ex. envoyer un SMS) lorsque quelque chose ne va
pas.
--on-outdated-execute=COMMA
NDE
Exécute COMMANDE lorsque freshclam signale une version obsolète. Dans la chaîne de commande, %v sera remplacé par le nouveau numéro de
version.
--update-db=NOM
BD
Avec cette option, vous pouvez limiter les mises à jour à un sous-ensemble de fichiers de base de données. Le NOMBD doit ê
tre "main", "daily", "bytecode", "safebrowsing" ou l'un des noms de bases de données tierces. Cette option peut être utilis
ée plusieurs fois et ne fonctionne qu'avec les bases de données officielles et tierces distribuées via les miroirs ClamAV ;
vos bases de données personnalisées (spécifiées avec DatabaseCustomURL dans freshclam.conf) ne seront pas ignorées.

VARIABLES

D'ENVIRONNEMENT

freshclam utilise les variables d'environnement suivantes

:
CURL_CA_BUND
LE
(Uniquement Linux/Unix, à l'exclusion de macOS) Peut être défini sur le chemin d'un fichier (bundle) contenant un ou plusieurs certificats CA. Cela remplacera le chemin par défaut du certificat
openssl.
FRESHCLAM_CLIENT_C
ERT
Peut être défini sur le chemin d'un fichier (PEM) contenant le certificat client. Cela peut être utilisé pour l'authentification
client.
FRESHCLAM_CLIENT_
KEY
Peut être défini sur le chemin d'un fichier (PEM) contenant la clé privée du client. Cela est requis si FRESHCLAM_CLIENT_CERT est
défini.
FRESHCLAM_CLIENT_KEY_PAS
SWD
Peut être défini sur un mot de passe pour le fichier PEM de la clé client. Cela est requis si FRESHCLAM_CLIENT_KEY est défini et que le fichier PEM est protégé par un mot de
passe.
CVD_CERTS_D
IR
Spécifie un répertoire contenant le certificat racine CA nécessaire pour vérifier les signatures numériques CVD détachées. Si non fourni, freshclam cherchera dans le répertoire par
défaut.
Notez que la variable d'environnement CURL_CA_BUNDLE est également utilisée par l'outil en ligne de commande curl pour le même
objectif.

CODES DE

RETOUR

Certains codes de retour de freshclam peuvent être remplacés par une commande intégrée EXIT_n qui peut être passée à --on-*-execute, par ex. --on-update-execute=EXIT_1 forcera freshclam à toujours retourner 1 après une mise à jour réussie de la base de

données.
0 : La base de données est à jour ou a été mise à jour avec
succès.
40: Option inconnue
passée.
50: Impossible de changer de
répertoire.
51: Impossible de vérifier la somme
MD5.
52: Problème de connexion (réseau)
.
53: Impossible de supprimer le
fichier.
54: Erreur de vérification de la somme MD5 ou de la signature
numérique.
55: Erreur de lecture du
fichier.
56: Erreur du fichier de
configuration.
57: Impossible de créer un nouveau
fichier.
58: Impossible de lire la base de données depuis le serveur
distant.
59: Les miroirs ne sont pas entièrement synchronisés (réessayez plus
tard).
60: Impossible d'obtenir des informations sur l'utilisateur 'clamav' depuis
/etc/passwd.
61: Impossible d'abandonner les
privilèges.
62: Impossible d'initialiser le
journal.
