FUSERMOUNT3(1) Système de fichiers dans l'espace utilisateur (FUSE) FUSERMOUNT3(1)

NOM

fusermount3 - monter et démonter les systèmes de fichiers FUSE

SYNTAXE

fusermount3 [OPTIONS] POINT_DE_MONTAGE

DESCRIPTION

Filesystem in Userspace (FUSE) est une interface simple permettant aux programmes de l'espace utilisateur d'exporter un système de fichiers virtuel au noyau Linux. Il vise également à fournir une méthode sécurisée pour que les utilisateurs non privilégiés puissent créer et monter leurs propres implémentations de systèmes de fichiers.

fusermount3 est un programme permettant de monter et démonter les systèmes de fichiers FUSE. Il ne doit être appelé directement que pour démonter les systèmes de fichiers FUSE. Pour permettre le montage et le démontage par des utilisateurs non privilégiés, fusermount3 doit être installé avec le bit setuid root.

OPTIONS

-h
affiche l'aide.
-V
affiche la version.
-o OPTION[,OPTION...]
options de montage.
-u
démonter.
-q
mode silencieux.
-z
démontage paresseux.
