NOM

flatpak remote-add - Ajoute un dépôt distant

SYNOPSIS

flatpak remote-add [OPTION...] NOM EMPLACEMENT

DESCRIPTION

Ajoute un dépôt distant à la configuration des dépôts flatpak. NOM est le nom du nouveau dépôt distant, et EMPLACEMENT est une URL ou un chemin d'accès. L'EMPLACEMENT est soit un dépôt flatpak, soit un fichier .flatpakrepo qui décrit un dépôt. Dans le premier cas, vous devrez peut-être également spécifier des options supplémentaires, telles que la clé GPG du dépôt.

Sauf si elles sont remplacées par les options --user ou --installation, cette commande modifie l'installation par défaut à l'échelle du système.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

--from

Suppose que l'URI est un fichier .flatpakrepo plutôt que le dépôt lui-même. Ceci est activé par défaut si l'extension est .flatpakrepo, donc généralement vous n'avez pas besoin de cette option.

-u, --user

Modifie la configuration par utilisateur.

--system

Modifie la configuration système par défaut.

--installation=NOM

Modifie une installation système spécifiée par NOM parmi celles définies dans /etc/flatpak/installations.d/. L'utilisation de --installation=default est équivalente à l'utilisation de --system.

--no-gpg-verify

Désactive la vérification GPG pour le dépôt ajouté.

--prio=PRIO

Définit la priorité du dépôt distant. La valeur par défaut est 1, une valeur plus élevée signifie une priorité plus grande. Ceci est principalement utilisé par les outils d'installation graphiques. Il est également utilisé lors de la recherche d'un dépôt pour fournir le runtime d'une application. L'origine de l'application est vérifiée avant les autres dépôts de même priorité.

--subset=SUBSET

Limite les refs disponibles à partir du dépôt distant à celles qui font partie du sous-ensemble nommé.

--no-enumerate

Marque le dépôt distant comme non énuméré. Cela signifie que le dépôt distant ne sera pas utilisé pour lister les applications, par exemple dans les outils d'installation graphiques.

--no-use-for-deps

Marque le dépôt distant comme ne devant pas être utilisé pour la résolution automatique des dépendances de runtime.

--if-not-exists

Ne fait rien si le dépôt distant fourni existe déjà.

--disable

Désactive le dépôt distant ajouté.

--title=TITRE

Un titre pour le dépôt distant, par exemple pour un affichage dans une interface utilisateur.

--comment=COMMENTAIRE

Un commentaire sur une seule ligne pour le dépôt distant, par exemple pour un affichage dans une interface utilisateur.

--description=DESCRIPTION

Une description en paragraphe complet pour le dépôt distant, par exemple pour un affichage dans une interface utilisateur.

--homepage=URL

URL d'un site Web pour le dépôt distant, par exemple pour un affichage dans une interface utilisateur.

--icon=URL

URL d'une icône pour le dépôt distant, par exemple pour un affichage dans une interface utilisateur.

--default-branch=BRANCH

Une branche par défaut pour le dépôt distant, principalement pour une utilisation dans une interface utilisateur.

--filter=CHEMIN

Ajoute un filtre local au dépôt distant. Un fichier de filtre est une liste de lignes, chacune commençant par "allow" ou "deny", suivie d'un glob pour la ref à autoriser ou refuser. Les globs spécifient une ref partielle (c'est-à-dire que vous pouvez omettre les parties finales qui correspondront alors à tout), mais sinon seul "*" est spécial, correspondant à tout dans cette partie de la ref.

Par défaut, toutes les refs sont autorisées, mais si une ref correspond à une règle "deny", elle est refusée à moins qu'elle ne corresponde spécifiquement à une règle "allow". Cela signifie que vous pouvez l'utiliser pour implémenter à la fois des listes blanches et des listes noires.

Voici un exemple de fichier de filtre :

# Ceci est un filtre de style allowlist car il refuse tout d'abord
deny *
allow runtime/org.freedesktop.*
allow org.some.app/arm
allow org.signal.Signal/*/stable
allow org.signal.Signal.*/*/stable

--gpg-import=FICHIER

Importe les clés GPG du fichier de trousseau spécifié comme étant de confiance pour le nouveau dépôt distant. Si le fichier est -, le trousseau est lu depuis l'entrée standard.

--authenticator-name=NOM

Spécifie l'authentificateur à utiliser pour le dépôt distant.

--authenticator-option=CLEF=VALEUR

Spécifie une option d'authentificateur pour le dépôt distant.

--authenticator-install

Active l'installation automatique de l'authentificateur.

--no-authenticator-install

Désactive l'installation automatique de l'authentificateur.

--no-follow-redirect

Ne suit pas xa.redirect-url défini dans le fichier résumé.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak remote-add gnome https://sdk.gnome.org/gnome.flatpakrepo

$ flatpak --user remote-add --no-gpg-verify test-repo https://people.gnome.org/~alexl/gnome-sdk/repo/
