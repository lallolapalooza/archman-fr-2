NOM

flatpak-build-commit-from - Créer de nouveaux commits basés sur un commit existant (potentiellement depuis un autre dépôt)

SYNOPIS

flatpak build-commit-from [OPTION...] REPO-DEST REF-DEST...

DESCRIPTION

Crée de nouveaux commits sur la branche REF-DEST dans le REPO-DEST, avec le contenu (et la plupart des métadonnées) provenant d'une autre branche, soit d'un autre dépôt, soit d'une autre branche du même dépôt.

L'identifiant de collection défini sur REPO-DEST (s'il est défini) sera utilisé pour les commits nouvellement créés.

Cette commande est très utile lorsque vous souhaitez maintenir une branche avec un historique propre, sans commits non signés ou cassés. Par exemple, vous pouvez importer la tête d'un autre dépôt d'un constructeur automatique une fois que vous avez vérifié qu'il a fonctionné. Le nouveau commit n'aura pas de parents ni de signatures du constructeur automatique, et pourra être correctement signé avec la clé officielle.

Tous les deltas qui affectent le commit d'origine et qui correspondent aux commits parents dans le dépôt de destination sont copiés et réécrits pour le nouvel identifiant de commit.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

--src-repo=SRC-REPO

Le dépôt (local) à partir duquel extraire la branche source. Par défaut, il s'agit du dépôt de destination.

--src-ref=SRC-REF

La branche à utiliser comme source pour le nouveau commit. Par défaut, elle est identique à la référence de destination, ce qui n'est utile que si un dépôt source différent a été spécifié.

--extra-collection-id=COLLECTION-ID

Ajoute une liaison de collection-référence supplémentaire pour cette collection, en plus de ce qui serait normalement ajouté en raison de l'identifiant de collection du dépôt de destination. Cette option peut être utilisée plusieurs fois.

--subset=SUBSET

Marque le commit à inclure dans le sous-ensemble nommé. Cela entraînera la mise du commit dans le résumé du sous-ensemble nommé (en plus du résumé principal), permettant aux utilisateurs de voir uniquement ce sous-ensemble au lieu du dépôt entier.

--untrusted

Le dépôt source n'est pas fiable, tous les objets sont copiés (pas liés en dur) et toutes les sommes de contrôle sont vérifiées.

-s, --subject=SUBJECT

Sujet sur une ligne pour le message de commit. S'il n'est pas spécifié, il sera pris à partir du commit source.

-b, --body=BODY

Description complète du message de commit. S'il n'est pas spécifié, il sera pris à partir du commit source.

--update-appstream

Met à jour la branche appstream après la construction.

--no-update-summary

Ne met pas à jour le fichier de résumé après l'ajout du nouveau commit. Cela signifie que le dépôt ne pourra pas être servi via HTTP tant que build-update-repo n'aura pas été exécuté. Ceci est utile si vous souhaitez effectuer plusieurs opérations sur le dépôt avant de finalement mettre à jour le résumé.

--force

Crée un nouveau commit même si le contenu n'a pas changé par rapport à la tête de branche existante.

--disable-fsync

N'exécute pas fsync lors de l'écriture dans le dépôt. Cela peut entraîner une perte de données dans des situations exceptionnelles, mais peut améliorer les performances lors du travail avec des dépôts temporaires ou de test.

--gpg-sign=KEYID

Signe le commit avec cette clé GPG. Cette option peut être utilisée plusieurs fois.

--gpg-homedir=PATH

Répertoire GPG à utiliser lors de la recherche d'annuaires de clés.

--end-of-life=REASON

Marque la construction comme fin de vie.

--end-of-life-rebase=OLDID=NEWID

Marque les nouvelles références comme fin de vie. Contrairement à --end-of-life, celle-ci prend un identifiant qui remplace l'actuel. Sur demande de l'utilisateur, les données de l'application peuvent être conservées pour la nouvelle application. Notez qu'il s'agit en fait d'une correspondance de préfixe, donc si vous dites org.the.app=org.new.app, alors quelque chose comme org.the.app.Locale sera rebasé sur org.new.app.Locale.

--timestamp=TIMESTAMP

Remplace l'horodatage du commit. Utilisez une date formatée ISO 8601, ou NOW pour l'heure actuelle.

--disable-fsync

N'exécute pas fsync lors de l'écriture dans le dépôt. Cela peut entraîner une perte de données dans des situations exceptionnelles, mais peut améliorer les performances lors du travail avec des dépôts temporaires ou de test.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

Pour annuler un commit vers le commit précédent :

$ flatpak build-commit-from --timestamp=NOW --src-ref=app/org.gnome.gedit/x86_64/master^ repo app/org.gnome.gedit/x86_64/master
