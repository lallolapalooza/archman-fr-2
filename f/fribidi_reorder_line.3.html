NOM

fribidi_reorder_line - réordonne une ligne de chaîne logique en visuel

SYNOPSIS

#include <../fribidi/lib/fribidi.h>

FriBidiLevel fribidi_reorder_line
(
FriBidiFlags flags,
const FriBidiCharType *bidi_types,
const FriBidiStrIndex len,
const FriBidiStrIndex off,
const FriBidiParType base_dir,
FriBidiLevel *embedding_levels,
FriBidiChar *visual_str,
FriBidiStrIndex *map
);

PARAMÈTRES

FriBidiFlags flags
Drapeaux de réordonnancement.
const FriBidiCharType *bidi_types
Liste d'entrée des types bidi tels que retournés par fribidi_get_bidi_types().

Comme il y a 23 valeurs possibles pour un const FriBidiCharType, elles ne sont pas toutes listées ici.

const FriBidiStrIndex len
Longueur d'entrée de la ligne.
const FriBidiStrIndex off
Décalage d'entrée du début de la ligne dans le paragraphe.
const FriBidiParType base_dir
Direction de base du paragraphe résolue.

Les valeurs possibles pour un const FriBidiParType sont les suivantes :

FRIBIDI_PAR_LTR
Paragraphe Gauche-À-Droite.
FRIBIDI_PAR_RTL
Paragraphe Droite-À-Gauche.
FRIBIDI_PAR_ON
Paragraphe Direction-Neutre.
FRIBIDI_PAR_WLTR
Paragraphe Faible Gauche À Droite.
FRIBIDI_PAR_WRTL
Paragraphe Faible Droite À Gauche.
FriBidiLevel *embedding_levels
Liste d'entrée des niveaux d'imbrication, tels que retournés par fribidi_get_par_embedding_levels.
FriBidiChar *visual_str
Chaîne visuelle à réordonner.
FriBidiStrIndex *map
Une carte des indices de chaîne qui est réordonnée pour refléter où chaque glyphe finit.

DESCRIPTION

Cette fonction réordonne les caractères d'une ligne de texte du logique vers l'ordre visuel final. Cette fonction implémente une partie de la règle L1, et les règles L2 et L3 de l'Algorithme de Bidirectionnalité Unicode disponible à l'adresse http://www.unicode.org/reports/tr9/#Reordering_Resolved_Levels.

En tant qu'effet secondaire, elle définit également les cartes de position si elles ne sont pas NULL.

Vous devez fournir la direction du paragraphe résolue et les niveaux d'imbrication tels que définis par fribidi_get_par_embedding_levels(). Notez également que les niveaux d'imbrication peuvent changer légèrement. Pour être précis, le niveau d'imbrication de toute séquence d'espaces à la fin de la ligne est réinitialisé au niveau d'imbrication du paragraphe (C'est la partie 4 de la règle L1).

Notez que les types bidi et les niveaux d'imbrication ne sont pas réordonnés. Vous pouvez réordonner ces tableaux (ou tout autre) en utilisant la carte plus tard. L'utilisateur est responsable d'initialiser la carte à quelque chose de sensé, comme une cartographie d'identité, ou de passer NULL si aucune carte n'est nécessaire.

Il y a une partie optionnelle à cette fonction, qui est de savoir si les marques non espacées pour les parties droite-à-gauche du texte doivent être réordonnées pour apparaître après leurs caractères de base dans la chaîne visuelle ou non. La plupart des moteurs de rendu s'attendent à ce comportement, mais les systèmes basés sur la console, par exemple, ne l'apprécient pas. Ceci est contrôlé par le drapeau FRIBIDI_FLAG_REORDER_NSM. Le drapeau est activé dans FRIBIDI_FLAGS_DEFAULT.

RETOURNE

Niveau maximal trouvé dans cette ligne plus un, ou zéro si une erreur s'est produite (échec d'allocation mémoire très probable).
