NOM

flatpak-kill - Arrête une application en cours d'exécution

SYNOPIS

flatpak kill INSTANCE

DESCRIPTION

Arrête une instance Flatpak en cours d'exécution.

INSTANCE peut être soit l'identifiant numérique de l'instance, soit l'identifiant de l'application d'un Flatpak en cours d'exécution. Vous pouvez utiliser flatpak ps pour trouver les identifiants d'instance des flatpaks en cours d'exécution.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak kill org.gnome.Todo
