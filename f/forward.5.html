FORWARD(5) Manuel des formats de fichiers FORWARD(5)

NOM

forward — fichier d'informations de redirection d'e-mails

DESCRIPTION

Les utilisateurs peuvent placer un fichier .forward dans leur répertoire personnel. Si ce fichier existe, smtpd(8) redirige les e-mails vers les destinations qui y sont spécifiées.

Un fichier .forward contient une liste de valeurs d'expansion, comme décrit dans aliases(5). Chaque valeur d'expansion doit être sur sa propre ligne. L'expansion est effectuée sous l'identifiant utilisateur du propriétaire du fichier .forward.

Les permissions sur le fichier .forward sont très strictes et l'expansion est rejetée si le fichier est inscriptible par le groupe ou par tout le monde ; si le répertoire personnel est inscriptible par le groupe ; ou si le fichier n'appartient pas à l'utilisateur.

Les utilisateurs doivent éviter de modifier directement le fichier .forward, afin d'éviter des échecs de remise si un message arrive pendant que le fichier n'est pas entièrement écrit. La meilleure option est d'utiliser un fichier temporaire et la commande mv(1) pour écraser atomiquement l'ancien fichier .forward. Alternativement, définir le bit sticky(8) sur le répertoire personnel entraînera un échec temporaire lors de la recherche de .forward, ce qui provoquera le report des e-mails.

FICHIERS

~/.forward
Informations de redirection d'e-mails.

EXEMPLES

Le fichier suivant redirige les e-mails vers “user@example.com”, et transmet les mêmes e-mails à “examplemda”.

# les lignes vides sont ignorées

user@example.com	# tout ce qui suit # est ignoré
"|/path/to/examplemda"

VOIR AUSSI

aliases(5), smtpd(8)

LIMITATIONS

Les mécanismes de pipe ‘|’ et :include: ne sont pas autorisés pour l'utilisateur root.
