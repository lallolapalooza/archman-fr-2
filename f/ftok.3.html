ftok(3) Manuel des fonctions de bibliothèque ftok(3)

NOM

ftok - convertir un nom de chemin et un identifiant de projet en une clé IPC System V

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/ipc.h>

key_t ftok(const char *path, int proj_id);

DESCRIPTION

La fonction ftok() utilise l'identité du fichier nommé par le path donné (qui doit faire référence à un fichier existant et accessible) et les 8 bits de poids faible de proj_id (qui doit être non nul) pour générer une clé IPC System V de type key_t, utilisable avec msgget(2), semget(2), ou shmget(2).

La valeur résultante est la même pour tous les noms de chemin qui nomment le même fichier, lorsque la même valeur de proj_id est utilisée. La valeur retournée doit être différente lorsque les fichiers (existants simultanément) ou les identifiants de projet diffèrent.

VALEUR DE RETOUR

En cas de succès, la valeur key_t générée est retournée. En cas d'échec, -1 est retourné, avec errno indiquant l'erreur comme pour l'appel système stat(2).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
ftok () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

NOTES

Sur certains systèmes anciens, le prototype était :


key_t ftok(char *path, char proj_id);

Aujourd'hui, proj_id est un int, mais seuls 8 bits sont toujours utilisés. L'utilisation typique implique un caractère ASCII pour proj_id, d'où le comportement indéfini lorsque proj_id est zéro.

Bien entendu, aucune garantie ne peut être donnée quant à l'unicité de la key_t résultante. Typiquement, une tentative de faire de son mieux combine l'octet proj_id fourni, les 16 bits de poids faible du numéro d'inode et les 8 bits de poids faible du numéro de périphérique pour obtenir un résultat sur 32 bits. Des collisions peuvent facilement se produire, par exemple entre des fichiers sur /dev/hda1 et des fichiers sur /dev/sda1.

EXEMPLES

Voir semget(2).

VOIR AUSSI

msgget(2), semget(2), shmget(2), stat(2), sysvipc(7)
