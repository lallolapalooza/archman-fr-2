NOM

freerdp-shadow-cli - Un utilitaire pour partager un affichage X via RDP.

SYNTAXE

freerdp-shadow-cli [/port:<numéro de port>] [/ipc-socket:<socket ipc>] [/monitors:<0,1,2,...>] [/rect:<x,y,w,h>] [+auth] [-may-view] [-may-interact] [/sec:<rdp|tls|nla|ext>] [-sec-rdp] [-sec-tls] [-sec-nla] [-sec-ext] [/sam-file:<fichier>] [/version] [/help]

DESCRIPTION

freerdp-shadow-cli peut être utilisé pour partager un affichage X en cours d'exécution comme avec VNC mais en utilisant RDP à la place. Il est également possible de ne partager que des parties (rect) de l'affichage.

OPTIONS

/ipc-socket:<socket ipc>
Si cette option est activée, un socket ipc avec le chemin socket ipc est utilisé à la place d'un socket TCP.
/port:<port>
Définit le port à utiliser. Par défaut, 3389. Cette option est ignorée si ipc-socket est utilisé.
/monitors:<1,2,3,...>
Sélectionne le(s) moniteur(s) à partager.
/rect:<x,y,w,h>
Sélectionne le rectangle dans le moniteur à partager.
-auth
Désactive l'authentification. Si l'authentification est activée, PAM est utilisé avec le sous-système X11. L'exécution en tant que root n'est pas nécessaire, cependant si exécuté en tant qu'utilisateur, seul le même utilisateur qui a démarré freerdp-shadow-cli peut s'authentifier.
Attention : Si l'authentification est désactivée, tout le monde peut se connecter.
-may-view
Les clients peuvent voir sans invite.
-may-interact
Les clients peuvent interagir sans invite.
/sec:<rdp|tls|nla|ext>
Force une sécurité de protocole spécifique
-sec-rdp
Désactive la sécurité RDP (par défaut : activé)
-sec-tls
Désactive la sécurité du protocole TLS (par défaut : activé)
-sec-nla
Désactive la sécurité du protocole NLA (par défaut : activé)
+sec-ext
Utilise la sécurité étendue du protocole NLA (par défaut : désactivé)
/sam-file:<fichier>
Fichier SAM NTLM pour l'authentification NLA
/version
Affiche la version et quitte.
/help
Affiche l'aide et quitte.

UTILISATION

#NOM_PAGE_MAN@ - démarre le serveur shadow sur le port 3389 avec la sécurité NLA, base de données SAM à /etc/winpr/SAM
freerdp-shadow-cli /sam-file:SAM.db - identique à ci-dessus, mais avec une base de données SAM personnalisée fournie en argument
freerdp-shadow-cli -sec-nla - démarre le serveur shadow sur le port 3380 avec la sécurité TLS/NLA. Cela permet de s'authentifier auprès de PAM avec des utilisateurs Unix. Sachez que le mot de passe est transmis en texte brut, comme avec l'authentification HTTP basique.

EXEMPLES

freerdp-shadow-cli /port:12345

Lorsqu'il est exécuté en tant qu'utilisateur dans une session X (par exemple depuis un xterm), un socket sur le port 12345 est ouvert et l'affichage actuel est partagé via RDP.
