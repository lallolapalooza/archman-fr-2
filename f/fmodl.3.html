fmod(3) Manuel des fonctions de bibliothèque fmod(3)

NOM

fmod, fmodf, fmodl - fonction de reste en virgule flottante

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double fmod(double x, double y);
float fmodf(float x, float y);
long double fmodl(long double x, long double y);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

fmodf(), fmodl() :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions calculent le reste en virgule flottante de la division de x par y. La valeur de retour est x - n * y, où n est le quotient de x / y, arrondi vers zéro en un entier.

Pour obtenir le modulo, plus précisément le plus petit résidu positif, vous devrez ajuster le résultat de fmod() comme suit :


z = fmod(x, y);
if (z < 0)
	z += fabs(y);

Une autre façon d'exprimer cela est avec fmod(fmod(x, y) + y, y), mais le second fmod() coûte généralement beaucoup plus cher que la seule branche.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent la valeur x - n*y, pour un entier n quelconque, telle que la valeur retournée ait le même signe que x et une magnitude inférieure à la magnitude de y.

Si x ou y est un NaN, un NaN est retourné.

Si x est une valeur infinie, une erreur de domaine se produit et un NaN est retourné.

Si y est zéro, une erreur de domaine se produit et un NaN est retourné.

Si x est +0 (-0), et que y n'est pas zéro, +0 (-0) est retourné.

ERREURS

Voir math_error(7) pour des informations sur la manière de déterminer si une erreur s'est produite lors de l'appel à ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de domaine : x est une valeur infinie
errno est défini sur EDOM (mais voir BUGS). Une exception en virgule flottante invalide (FE_INVALID) est déclenchée.
Erreur de domaine : y est zéro
errno est défini sur EDOM. Une exception en virgule flottante invalide (FE_INVALID) est déclenchée.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
fmod (), fmodf (), fmodl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C99, POSIX.1-2001.

La variante retournant double est également conforme aux normes SVr4, 4.3BSD, C89.

BOGUES

Avant glibc 2.10, l'implémentation glibc ne définissait pas errno sur EDOM lorsqu'une erreur de domaine se produisait pour un x infini.

EXEMPLES

L'appel fmod(372, 360) retourne 12.

L'appel fmod(-372, 360) retourne -12.

L'appel fmod(-372, -360) retourne également -12.
