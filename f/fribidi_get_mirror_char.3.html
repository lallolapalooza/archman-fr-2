NOM

fribidi_get_mirror_char - obtenir le caractère miroir

SYNTAXE

#include <../fribidi/lib/fribidi.h>

fribidi_boolean fribidi_get_mirror_char
(
FriBidiChar ch,
FriBidiChar *mirrored_ch
);

PARAMETRES

FriBidiChar ch
Caractère d'entrée.
FriBidiChar *mirrored_ch
Caractère miroir de sortie.

DESCRIPTION

Cette fonction recherche l'équivalent miroir d'un caractère tel que défini dans le fichier BidiMirroring.txt de la base de données des caractères Unicode disponible à l'adresse http://www.unicode.org/Public/UNIDATA/BidiMirroring.txt.

Si le caractère d'entrée est déclaré comme un caractère de mise en miroir dans la norme Unicode et possède un équivalent miroir. Le caractère miroir correspondant est placé dans la sortie, sinon le caractère d'entrée lui-même est placé.

VALEURS DE RETOUR

Indique si le caractère a un équivalent miroir ou non.
