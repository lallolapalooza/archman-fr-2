FOOMATIC-PPDFILE(1) Manuel des commandes générales FOOMATIC-PPDFILE(1)

NOM

foomatic-ppdfile - Génère un fichier PPD pour une combinaison imprimante/pilote donnée

SYNTAXE

foomatic-ppdfile [-w] [-d <pilote>] -p <identifiant_imprimante>
foomatic-ppdfile [-A] [-P motif]
foomatic-ppdfile -h

DESCRIPTION

La première forme de foomatic-ppdfile permet de calculer le fichier PPD indépendant du spooler pour toute combinaison imprimante/pilote valide disponible dans la base de données Foomatic, à la fois pour l'impression avec foomatic-rip(1) et pour que les applications/clients puissent accéder aux options de l'imprimante. Le fichier PPD est renvoyé sur la sortie standard. Si le pilote n'est pas spécifié, le pilote par défaut est utilisé.

La deuxième forme du programme foomatic-ppdfile recherchera dans la base de données des imprimantes et renverra soit toutes les entrées d'imprimantes, soit celles dont le nom et/ou les informations de modèle correspondent à une expression régulière.

La dernière forme affiche un message d'aide et se termine.

Options

-d nom_pilote
Le nom (optionnel) du pilote à utiliser. Si le nom du pilote n'est pas fourni, le pilote par défaut ou le premier pilote de la liste des pilotes compatibles de l'imprimante est utilisé.
-p
identifiant_imprimante L'identifiant de l'imprimante.
-w
Renvoie un fichier PPD qui respecte les limitations du format Microsoft Windows.
-A
Renvoie toutes les entrées d'imprimantes dans la base de données.
-Pmotif
Renvoie toutes les entrées d'imprimantes dans la base de données qui correspondent à l'expression régulière.

VOIR AUSSI

foomatic-rip(1)

VALEUR DE RETOUR

foomatic-ppdfile renvoie 0 en cas de succès, 1 sinon.
