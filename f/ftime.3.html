ftime(3) Manuel des fonctions de bibliothèque ftime(3)

NOM

ftime - retourner la date et l'heure

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/timeb.h>
[[deprecated]] int ftime(struct timeb *tp);

DESCRIPTION

NOTE : Cette fonction n'est plus fournie par la bibliothèque C GNU. Utilisez clock_gettime(2) à la place.

Cette fonction retourne l'heure actuelle en secondes et millisecondes depuis l'Epoch, le 1970-01-01 00:00:00 +0000 (UTC). L'heure est retournée dans tp, qui est déclaré comme suit :


struct timeb {
    time_t         time;
    unsigned short millitm;
    short          timezone;
    short          dstflag;
};

Ici, time est le nombre de secondes depuis l'Epoch, et millitm est le nombre de millisecondes depuis les secondes time depuis l'Epoch. Le champ timezone est le fuseau horaire local mesuré en minutes de temps à l'ouest de Greenwich (une valeur négative indiquant des minutes à l'est de Greenwich). Le champ dstflag est un drapeau qui, s'il n'est pas nul, indique que l'heure d'été s'applique localement pendant la partie appropriée de l'année.

POSIX.1-2001 indique que le contenu des champs timezone et dstflag n'est pas spécifié ; évitez de vous y fier.

VALEUR DE RETOUR

Cette fonction retourne toujours 0. (POSIX.1-2001 spécifie, et certains systèmes documentent, un retour d'erreur -1.)

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
ftime () Sécurité des threads MT-Safe

NORMES

Aucune.

HISTORIQUE

4.2BSD. Marqué comme LEGACY dans POSIX.1-2001 ; supprimé dans POSIX.1-2008. Supprimé dans glibc 2.33.

Cette fonction est obsolète. Ne l'utilisez pas. Si le temps en secondes suffit, time(2) peut être utilisé ; gettimeofday(2) donne des microsecondes ; clock_gettime(2) donne des nanosecondes mais n'est pas aussi largement disponible.

BOGUES

Les premières versions de glibc2 sont boguées et retournent 0 dans le champ millitm ; glibc 2.1.1 est à nouveau correct.

VOIR AUSSI

gettimeofday(2), time(2)
