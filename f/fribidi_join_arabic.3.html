NOM

fribidi_join_arabic - effectuer la jointure arabe

SYNTAXE

#include <../fribidi/lib/fribidi.h>

void fribidi_join_arabic
(
const FriBidiCharType *bidi_types,
const FriBidiStrIndex len,
const FriBidiLevel *embedding_levels,
FriBidiArabicProp *ar_props
);

PARAMETRES

const FriBidiCharType *bidi_types
Liste d'entrée des types bidi tels que retournés par fribidi_get_bidi_types().

Comme il existe 23 valeurs possibles pour un const FriBidiCharType, elles ne sont pas toutes listées ici.

const FriBidiStrIndex len
Longueur de la chaîne d'entrée.
const FriBidiLevel *embedding_levels
Liste d'entrée des niveaux d'imbrication, tels que retournés par fribidi_get_par_embedding_levels.
FriBidiArabicProp *ar_props
Propriétés arabes à analyser, initialisées par les types de jointure, tels que retournés par fribidi_get_joining_types.

DESCRIPTION

Cette fonction effectue l'algorithme de jointure arabe. Cela signifie que, étant donné les types de jointure arabe des caractères dans ar_props (ne vous inquiétez pas, FriBidiJoiningType peut être converti en FriBidiArabicProp automatiquement), cette fonction modifie ces propriétés pour tenir compte de l'effet des caractères voisins. Vous aurez probablement besoin de ces informations plus tard pour effectuer le façonnage arabe.

Cette fonction implémente les règles R1 à R7 inclusives (toutes les règles) de l'algorithme de jointure cursive arabe de la norme Unicode tel que disponible sur http://www.unicode.org/versions/Unicode4.0.0/ch08.pdf#G7462. Elle interagit également correctement avec l'algorithme bidirectionnel tel que défini dans la section
3.5 Façonnage de l'algorithme bidirectionnel Unicode disponible sur http://www.unicode.org/reports/tr9/#Shaping.

Il existe quelques macros définies dans fribidi-joining-types.h pour interroger les propriétés arabes calculées par cette fonction.
