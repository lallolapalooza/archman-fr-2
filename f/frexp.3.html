frexp(3) Manuel des fonctions de bibliothèque frexp(3)

NOM

frexp, frexpf, frexpl - convertir un nombre à virgule flottante en composantes fractionnaires et entières

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double frexp(double x, int *e);
float frexpf(float x, int *e);
long double frexpl(long double x, int *e);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

frexpf(), frexpl() :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions sont utilisées pour décomposer le nombre x en une fraction normalisée et un exposant qui est stocké dans e.

VALEUR DE RETOUR

Ces fonctions retournent la fraction normalisée. Si l'argument x n'est pas zéro, la fraction normalisée est x multiplié par une puissance de deux, et sa valeur absolue est toujours dans l'intervalle [1/2 (inclusif), 1 (exclusif)), c'est-à-dire, [0.5,1).

Si x est zéro, alors la fraction normalisée est zéro et zéro est stocké dans e.

Si x est un NaN, un NaN est retourné, et la valeur de *e est indéterminée.

Si x est l'infini positif (l'infini négatif), l'infini positif (l'infini négatif) est retourné, et la valeur de *e est indéterminée.

ERREURS

Aucune erreur ne se produit.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
frexp (), frexpf (), frexpl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C99, POSIX.1-2001.

La variante retournant double est également conforme à SVr4, 4.3BSD, C89.

EXEMPLES

Le programme ci-dessous produit des résultats tels que les suivants :


$ ./a.out 2560
frexp(2560, &e) = 0.625: 0.625 * 2^12 = 2560
$ ./a.out -4
frexp(-4, &e) = -0.5: -0.5 * 2^3 = -4

Source du programme

#include <float.h>
#include <math.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    double x, r;
    int e;
    x = strtod(argv[1], NULL);
    r = frexp(x, &e);
    printf("frexp(%g, &e) = %g: %g * %d^%d = %g\n", x, r, r, 2, e, x);
    exit(EXIT_SUCCESS);
}
