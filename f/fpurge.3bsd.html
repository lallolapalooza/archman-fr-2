fpurge(3bsd)

Paquet: libbsd

Licences: custom

fpurge(3bsd) 3bsd fpurge(3bsd)

NOM

fpurge — vider un flux

BIBLIOTHÈQUE

bibliothèque « libbsd »

SYNTAXE

#include <stdio.h> (Voir libbsd(7) pour l'utilisation de l'include.)
int
fpurge(FILE *stream);

DESCRIPTION

La fonction fpurge() efface toute entrée ou sortie mise en mémoire tampon dans le stream donné. Pour les flux de sortie, cela rejette toute sortie non écrite. Pour les flux d'entrée, cela rejette toute entrée lue depuis l'objet sous-jacent mais pas encore obtenue via getc(3) ; cela inclut tout texte repoussé via ungetc(3).

VALEURS DE RETOUR

En cas de succès, 0 est retourné. Sinon, EOF est retourné et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

[EBADF]
stream n'est pas un flux ouvert.

VOIR AUSSI

fclose(3), fopen(3), setvbuf(3)

HISTORIQUE

La fonction fpurge() est apparue pour la première fois dans 4.4BSD-Lite.
