FSTATVFS(3P) Manuel du programmeur POSIX FSTATVFS(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement de Linux), ou l'interface peut ne pas être implémentée sur Linux.

NOM

fstatvfs, statvfs — obtenir des informations sur le système de fichiers

SYNOPSIS

#include <sys/statvfs.h>
int fstatvfs(int fildes, struct statvfs *buf);
int statvfs(const char *restrict path, struct statvfs *restrict buf);

DESCRIPTION

La fonction fstatvfs() doit obtenir des informations sur le système de fichiers contenant le fichier référencé par fildes.

La fonction statvfs() doit obtenir des informations sur le système de fichiers contenant le fichier nommé par path.

Pour les deux fonctions, l'argument buf est un pointeur vers une structure statvfs qui doit être remplie. Les permissions de lecture, d'écriture ou d'exécution du fichier nommé ne sont pas requises.

Les drapeaux suivants peuvent être retournés dans le membre f_flag :

ST_RDONLY
Système de fichiers en lecture seule.
ST_NOSUID
Les bits setuid/setgid sont ignorés par exec.

Il n'est pas spécifié si tous les membres de la structure statvfs ont des valeurs significatives sur tous les systèmes de fichiers.

VALEUR RENVOYÉE

À l'issue d'une exécution réussie, statvfs() doit renvoyer 0. Sinon, elle doit renvoyer -1 et définir errno pour indiquer l'erreur.

ERREURS

Les fonctions fstatvfs() et statvfs() doivent échouer si :

EIO
Une erreur d'entrée/sortie s'est produite lors de la lecture du système de fichiers.
EINTR
Un signal a été capturé pendant l'exécution de la fonction.
EOVERFLOW
L'une des valeurs à retourner ne peut pas être représentée correctement dans la structure pointée par buf.

La fonction fstatvfs() doit échouer si :

EBADF
L'argument fildes n'est pas un descripteur de fichier ouvert.

La fonction statvfs() doit échouer si :

EACCES
La permission de recherche est refusée sur un composant du préfixe de chemin.
ELOOP
Une boucle existe dans les liens symboliques rencontrés lors de la résolution de l'argument path .
ENAMETOOLONG

La longueur d'un composant d'un chemin d'accès est supérieure à {NAME_MAX}.
ENOENT
Un composant de path ne nomme pas un fichier existant ou path est une chaîne vide.
ENOTDIR
Un composant du préfixe de chemin nomme un fichier existant qui n'est ni un répertoire ni un lien symbolique vers un répertoire, ou l'argument path contient au moins un caractère non-<slash> et se termine par un ou plusieurs caractères <slash> finaux et le dernier composant du chemin d'accès nomme un fichier existant qui n'est ni un répertoire ni un lien symbolique vers un répertoire.

La fonction statvfs() peut échouer si :

ELOOP
Plus de {SYMLOOP_MAX} liens symboliques ont été rencontrés lors de la résolution de l'argument path .
ENAMETOOLONG

La longueur d'un chemin d'accès dépasse {PATH_MAX}, ou la résolution d'un chemin d'accès d'un lien symbolique a produit un résultat intermédiaire dont la longueur dépasse {PATH_MAX}.

EXEMPLES

Obtention d'informations sur le système de fichiers à l'aide de fstatvfs()

L'exemple suivant montre comment obtenir des informations sur le système de fichiers sur lequel se trouve le fichier nommé /home/cnd/mod1 , en utilisant la fonction fstatvfs() . Le fichier /home/cnd/mod1 est ouvert avec les privilèges lecture/écriture et le descripteur de fichier ouvert est passé à la fonction fstatvfs() .

#include <sys/statvfs.h>
#include <fcntl.h>
struct statvfs buffer;
int            status;
...
fildes = open("/home/cnd/mod1", O_RDWR);
status  = fstatvfs(fildes, &buffer);

Obtention d'informations sur le système de fichiers à l'aide de statvfs()

L'exemple suivant montre comment obtenir des informations sur le système de fichiers sur lequel se trouve le fichier nommé /home/cnd/mod1 , en utilisant la fonction statvfs() .

#include <sys/statvfs.h>
struct statvfs buffer;
int            status;
...
status = statvfs("/home/cnd/mod1", &buffer);
