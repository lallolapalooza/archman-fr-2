FPUTWS(3P) Manuel du programmeur POSIX FPUTWS(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

fputws — écrire une chaîne de caractères larges sur un flux

SYNOPIS

#include <stdio.h>
#include <wchar.h>
int fputws(const wchar_t *restrict ws, FILE *restrict stream);

DESCRIPTION

Les fonctionnalités décrites sur cette page de référence sont alignées sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

La fonction fputws() écrit une chaîne de caractères correspondant à la chaîne de caractères larges (terminée par un caractère nul) pointée par ws dans le flux pointé par stream. Aucun caractère correspondant au code de caractère large nul de terminaison n'est écrit.

Les horodatages de la dernière modification des données et du dernier changement d'état du fichier sont marqués pour mise à jour entre l'exécution réussie de fputws() et la prochaine complétion réussie d'un appel à fflush() ou fclose() sur le même flux ou d'un appel à exit() ou abort().

VALEUR RETOURNÉE

En cas de succès, fputws() retourne un nombre non négatif. Sinon, elle retourne -1, définit un indicateur d'erreur pour le flux et définit errno pour indiquer l'erreur.

ERREURS

Se référer à fputwc().

UTILISATION DE L'APPLICATION

La fonction fputws() n'ajoute pas de <nouvelle ligne>.

Ce volume de POSIX.1‐2017 exige que le succès retourne simplement un entier non négatif. Il existe au moins trois conventions d'implémentation différentes connues pour cette exigence :

*
Retourner une valeur constante.
*
Retourner le dernier caractère écrit.
*
Retourner le nombre d'octets écrits. Notez que cette convention d'implémentation ne peut pas être respectée pour les chaînes de plus de {INT_MAX} octets car la valeur ne serait pas représentable dans le type de retour de la fonction. Pour des raisons de compatibilité ascendante, les implémentations peuvent retourner le nombre d'octets pour les chaînes allant jusqu'à {INT_MAX} octets, et retourner {INT_MAX} pour toutes les chaînes plus longues.
