DESCRIPTIO

N

fpathconf() obtient la valeur de l'option de configuration name pour le descripteur de fichier ouvert fd

.

pathconf() obtient la valeur de l'option de configuration name pour le nom de fichier path

.

Les macros correspondantes définies dans <unistd.h> sont des valeurs minimales ; si une application souhaite tirer parti de valeurs qui peuvent changer, un appel à fpathconf() ou pathconf() peut être effectué, ce qui peut donner des résultats plus

permissifs.

VALEUR

RENVOYÉE

La valeur de retour de ces fonctions est l'une des suivantes

:
•
En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur (par exemple, EINVAL, indiquant que name est invalide)
.
•
Si name correspond à une limite maximale ou minimale et que cette limite est indéterminée, -1 est renvoyé et errno n'est pas modifié. (Pour distinguer une limite indéterminée d'une erreur, définissez errno à zéro avant l'appel, puis vérifiez si errno est non nul lorsque -1 est renvoyé.
)
•
Si name correspond à une option, une valeur positive est renvoyée si l'option est prise en charge, et -1 est renvoyé si l'option n'est pas prise en
charge.
•
Sinon, la valeur courante de l'option ou de la limite est renvoyée. Cette valeur ne sera pas plus restrictive que la valeur correspondante qui a été décrite à l'application dans <unistd.h> ou <limits.h> lorsque
l'applicat
ion a été
compilée.
