FSADM(8) Manuel du gestionnaire système FSADM(8)

NOM

fsadm — utilitaire pour redimensionner ou vérifier un système de fichiers sur un périphérique

SYNTAXE

fsadm
[options] check périphérique
fsadm
[options] resize périphérique [nouvelle_taille]

DESCRIPTION

L'utilitaire fsadm vérifie ou redimensionne le système de fichiers sur un périphérique (qui peut également être un périphérique chiffré dm-crypt). Il essaie d'utiliser la même API pour les systèmes de fichiers ext2, ext3, ext4, ReiserFS et XFS.

OPTIONS

-e|--ext-offline
Démonte le système de fichiers ext2/ext3/ext4 avant d'effectuer le redimensionnement.
-f|--force
Ignore certaines vérifications de cohérence.
-h|--help
Affiche le texte d'aide.
-l|--lvresize
Redimensionne également le volume logique lvm2 donné. Plus de fonctionnalités de gestion de volume sont fournies avec les commandes complémentaires lvresize(8) et l'option -r|--resizefs.
-n|--dry-run
Affiche les commandes sans les exécuter.
-v|--verbose
Soit plus verbeux.
-y|--yes
Répond "oui" à toutes les invites.
-c|--cryptresize
Redimensionne le mappage dm-crypt ainsi que le système de fichiers détecté sur le périphérique. Le périphérique dm-crypt doit être reconnaissable par cryptsetup(8).
nouvelle_taille[B|K|M|G|T|P|E]
Nombre absolu de blocs de système de fichiers à contenir dans le système de fichiers, ou une taille absolue utilisant un suffixe (en puissances de 1024). Si nouvelle_taille n'est pas fournie, l'intégralité du périphérique est utilisée.

DIAGNOSTICS

En cas de succès, le code de statut est 0. Un code de statut de 2 indique que l'opération a été interrompue par l'utilisateur. Un code de statut de 3 indique que l'opération de vérification demandée n'a pas pu être effectuée car le système de fichiers est monté et ne supporte pas un fsck(8) en ligne. Un code de statut de 1 est utilisé pour les autres échecs.

EXEMPLES

Redimensionner le système de fichiers sur le volume logique /dev/vg/test à 1000 MiB. Si /dev/vg/test contient un système de fichiers ext2/ext3/ext4, il sera démonté avant le redimensionnement. Toutes les questions [o/n] recevront la réponse 'o'.

fsadm -e -y resize /dev/vg/test 1000M

VARIABLES D'ENVIRONNEMENT

TMPDIR
Le nom du répertoire temporaire pour les points de montage. Par défaut, "/tmp".
DM_DEV_DIR
Le nom du répertoire des périphériques. Par défaut, "/dev" et doit être un chemin absolu.
