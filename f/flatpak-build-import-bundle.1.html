NOM

flatpak build-import-bundle - Importer un paquet de fichiers dans un dépôt local

SYNOPIS

flatpak build-import-bundle [OPTION...] LOCATION FICHIER

DESCRIPTION

Importe un paquet de fichiers depuis un fichier nommé FICHIER dans le dépôt situé à LOCATION.

Le format du fichier paquet est celui généré par build-bundle.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage OSTree pendant le traitement de la commande.

--ref=REF

Remplace la référence spécifiée dans le paquet.

--oci

Importe une image OCI au lieu d'un paquet Flatpak.

--update-appstream

Met à jour la branche appstream après la construction.

--no-update-summary

Ne met pas à jour le fichier de résumé après l'ajout du nouveau commit. Cela signifie que le dépôt ne sera pas utilisable pour être servi via http tant que build-update-repo n'aura pas été exécuté. Ceci est utile si vous souhaitez effectuer plusieurs opérations sur le dépôt avant de mettre enfin à jour le résumé.

--gpg-sign=KEYID

Signe le commit avec cette clé GPG. Cette option peut être utilisée plusieurs fois.

--gpg-homedir=PATH

Répertoire d'accueil GPG à utiliser lors de la recherche des trousseaux de clés.
