SYNOPS

IS

Le fichier free

tds.
conf

décrit les serveurs de bases de données Sybase et Microsoft à la bibliothèque FreeTDS. Il comprend des sections commençant par un nom de serveur, suivies d'une liste de propriétés de connexion désignées sous forme de paires nom-valeur. Les valeurs par défaut sont définies via une

section [global]. Ce fichier remplace le

interfaces défini par Sybase pour le même but, bien que ce dernier soit toujours pris en charge. DESCRI

PT
ION

Une section commence par un nom de serveur — le nom du serveur — entre crochets. Le nom de serveur est choisi à la discrétion du client. (Une exception : avec Sybase ASA, le nom de serveur doit correspondre au nom de la base

de données à utiliser.)

Les sections contiennent des propriétés, une par ligne, sous la

forme

nom =

valeur
o
ù

nom est la propriété de connexion à décrire. Les noms de serveurs et les propriétés ne sont pas sensibles à la casse. Les valeurs préservent la casse, c'est-à-dire qu'elles sont copiées littéralement. Les

commentaires commencent par un point-virgule (« ; ») ou une dièse (« # ») et se poursuivent jus
qu'à la fin de la ligne. Les lignes vides sont ignorées. Les espaces autour du « = » sont ignorés.

NAMES AND LOCATIONS

TDSDATADIR
overrides name and location of the system-wide conf file
TDSDUMP
overrides the name and location of the FreeTDS log file
TDSDUMPCONFIG
specifies a name and location of a file that logs the search of configuration files
TDSHOST
overrides the host property
TDSPORT
overrides the port property
TDSQUERY
synonym for DSQUERY, the default servername
TDSVER
overrides the version specified in the freetds.conf

The environment variables TDSVER, TDSDUMP, TDSPORT, TDSQUERY, and TDSHOST override values set by a .conf or interfaces file.
