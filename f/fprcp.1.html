fprcp(1) Préprocesseur de windres fprcp(1)

NOM

fprcp - Programme de préprocesseur windres de Free Pascal.

SYNTAXE

fprcp -i nom_fichier [-n] [-C] [-l PASCAL|C] [-p <chemin_inclusion>]

DESCRIPTION

fprcp lit un fichier .rc et le préprocesse, écrivant le résultat sur la sortie standard au fur et à mesure. Il remplace les constantes définies par leurs valeurs, afin que windres puisse traiter le fichier résultant et créer une ressource.

UTILISATION

fprcp nécessite au minimum l'option -i nom_fichier, qui est le fichier à traiter.

OPTIONS

fprcp dispose d'un petit nombre d'options pour contrôler son comportement :

-C
Définit le symbole symbole avant le début du traitement.
-i fichier
Spécifie le nom du fichier d'entrée. Cet argument est obligatoire.
-l langage
Définit le langage de programmation pour les fichiers inclus. La constante langage peut être l'une des suivantes :
C
Le langage de programmation C.
PASCAL
Le langage de programmation Pascal.
-n
Ne prend pas en charge les commentaires imbriqués. Par défaut, les commentaires imbriqués de Pascal sont activés.
-p chemin
Définit le chemin d'inclusion. Il peut contenir plusieurs fichiers, séparés par des points-virgules.
