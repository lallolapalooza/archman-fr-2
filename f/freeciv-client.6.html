NOM

freeciv-gtk3.22, freeciv-gtk4, freeciv-sdl2, freeciv-sdl3, freeciv-qt - Les clients pour le jeu Freeciv

SYNOPSIS

freeciv-gtk3.22|freeciv-gtk4|freeciv-sdl2|freeciv-sdl3|freeciv-qt [ -A|--Announce protocole ] [ -a|--autoconnect ] [ -d|--debug niveau ] [ -F|--Fatal [ numero_signal ] ] [ -f|--file nom_fichier ] [ -h|--help ] [ -l|--log nom_fichier ] [ -M|--Meta URL ] [ -n|--name nom ] [ -p|--port port ] [ -P|--Plugin chaine ] [ -r|--read nom_fichier ] [ -s|--server adresse ] [ -S|--Sound nom ] [ -t|--tiles nom ] [ -v|--version ] [ -- parametres_specifiques_client ]

freeciv-gtk3.22 accepte les paramètres standards Gtk après -- ; voir la documentation Gtk. Il accepte également [ -h|--help ] [ -r|--resolution LARGEURxHAUTEUR ]

freeciv-gtk4 accepte les paramètres suivants après -- : [ -h|--help ] [ -r|--resolution LARGEURxHAUTEUR ]

freeciv-qt accepte les paramètres standards Qt après -- ; voir la documentation Qt. Il accepte également [ -h|--help ] [ -f|--flags ]

freeciv-sdl2 accepte les paramètres suivants après -- : [ -f|--fullscreen ] [ -F|--Font ize ] [ -h|--help ] [ -s|--swrenderer ] [ -t|--theme chaine ]

freeciv-sdl3 accepte les paramètres suivants après -- : [ -f|--fullscreen ] [ -F|--Font ize ] [ -h|--help ] [ -t|--theme chaine ]

DESCRIPTION

Freeciv est un jeu de stratégie multijoueur en tour par tour, libre, dans lequel chaque joueur devient le chef d'une civilisation, luttant pour atteindre le but ultime : devenir la plus grande civilisation.

Les joueurs de Civilization II® par Microprose® devraient se sentir chez eux, car l'un des objectifs de Freeciv est d'avoir des règles compatibles.

Freeciv est maintenu par une équipe internationale de codeurs et de passionnés, et est facilement l'un des jeux en réseau les plus amusants et addictifs qui existent !

Ceci est le programme client utilisé pour se connecter à un serveur Freeciv - voir aussi freeciv-server(6) . freeciv-gtk3.22, freeciv-gtk4, freeciv-qt, freeciv-sdl2, et freeciv-sdl3 peuvent également lancer leur propre serveur local pour des parties en solo.

Cette page de manuel ne liste que les arguments de la ligne de commande. Pour plus de détails sur l'utilisation de freeciv-gtk3.22, freeciv-gtk4, freeciv-sdl2, freeciv-sdl3, ou freeciv-qt, consultez le Manuel du Client qui peut être trouvé sur le site Web de Freeciv ainsi que la documentation qui fait partie de la distribution Freeciv.

OPTIONS

Les options suivantes sont acceptées par tous les clients. Elles ne peuvent pas être combinées ; c'est-à-dire que "-np caesar 5557" ne fonctionnera pas, vous devrez plutôt entrer "-n caesar -p 5557". Toutes les options ont une forme courte (un tiret et une seule lettre) et une forme longue (deux tirets et un mot complet) ; leurs effets sont identiques.

-A protocole, --Announce protocole
Utilise protocole lors de la recherche de parties sur un réseau local (LAN). Les valeurs possibles pour protocole sont :

IPv4

IPv6

none

-a, --autoconnect
Ignore la boîte de dialogue de connexion, insérant automatiquement les valeurs par défaut. Ceci est assez pratique lorsque tout a été correctement configuré.
-d niveau, --debug niveau
Définit la quantité d'informations de débogage à enregistrer dans le fichier nommé par l'option -l. Les valeurs acceptables pour le niveau sont :

fatal pour les messages fatals uniquement.

error pour les messages fatals et d'erreur.

warning pour les messages fatals, d'erreur et d'avertissement

normal pour les messages fatals, d'erreur, d'avertissement et normaux (par défaut).

verbose pour les messages fatals, d'erreur, d'avertissement, normaux et verbeux.

-F [ numero_signal ], --Fatal [ numero_signal ]
Lève un signal personnalisé en cas d'échec d'assertion. Si numero_signal n'est pas spécifié, alors le signal ABRT sera utilisé.
-f nom_fichier, --file nom_fichier
Charge un fichier de sauvegarde de partie (nom_fichier). Ceci est pour recharger des parties précédemment sauvegardées, ou pour démarrer des scénarios depuis la ligne de commande.
-h, --help
Affiche un bref résumé des options standards de la ligne de commande.
-l nom_fichier, --log nom_fichier
Définit un fichier journal, nom_fichier, à produire pendant le traitement. Utilisez l'option -d pour définir la quantité d'informations enregistrées. Par défaut, les messages fatals, d'erreur, d'avertissement et normaux sont affichés sur la sortie standard. Avec un fichier journal, ces messages vont plutôt dans le journal. Si nom_fichier existe déjà, il est ajouté.
-M URL, --Meta URL
Spécifie l'URL du métaserver auquel se connecter. Un métaserver est un endroit où les serveurs Freeciv peuvent publier leur présence. Les clients Freeciv consultent le métaserver pour offrir aux utilisateurs une sélection de parties à rejoindre. Par défaut, le métaserver standard géré par les mainteneurs de Freeciv sera utilisé.
-n nom, --name nom
Spécifie le nom d'utilisateur (nom) à utiliser pour se connecter au serveur. Cette option est critique lors de la reconnexion à une partie. Veuillez noter que vous pourriez avoir besoin de mettre votre nom d'utilisateur entre guillemets.
-p port, --port port
Spécifie le port du serveur auquel se connecter. Par défaut, c'est 5556, en cas de doute demandez à l'administrateur du serveur.
-P chaine, --Plugin chaine
Spécifie le plugin à utiliser pour la sortie sonore. Les options disponibles pour chaine sont :

none

sdl

-r nom_fichier, --read nom_fichier
Spécifie un fichier, nom_fichier, de commandes serveur qu'un serveur lancé par le client lira et traitera automatiquement, comme si vous les aviez tapées à l'invite du serveur.
-s adresse, --server adresse
Spécifie l'adresse du serveur de jeu auquel se connecter. Ce serveur peut facilement tourner sur la même machine que le client.
-S nom, --Sound nom
Spécifie le jeu de sons à utiliser. Un fichier appelé nom.soundspec est recherché aux endroits habituels (voir la section FICHIERS).
-t nom, --tiles nom
Spécifie les graphiques de carte ("tuiles") à utiliser dans le jeu. Un fichier appelé nom.tilespec est recherché aux endroits habituels (voir la section FICHIERS). Actuellement, les tilespecs suivants sont distribués avec Freeciv :

• amplio2.tilespec

• cimpletoon.tilespec

• hex2t.tilespec

• isophex.tilespec

• isotrident.tilespec

• trident.tilespec

-v, --version
Affiche le numéro de version et quitte.
--
Tous les paramètres suivant ce -- seront considérés comme des paramètres spécifiques au client.
-- -f, -- --fullscreen
Démarre le client en mode plein écran. Uniquement implémenté dans les clients freeciv-sdl2 et freeciv-sdl3.
-- -h, -- --help
Affiche l'aide des paramètres spécifiques au client.
-- -r LARGEURxHAUTEUR, -- --resolution LARGEURxHAUTEUR
Se comporte comme si la résolution de l'écran était LARGEURxHAUTEUR. Uniquement implémenté dans les clients freeciv-gtk3.22 et freeciv-gtk4.
-- -t theme, -- --theme

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

thème
Utilise un thème d'interface graphique particulier. Implémenté uniquement dans les clients freeciv-sdl2 et freeciv-sdl3.

EXEMPLES

freeciv-gtk3.22 --name "Roi Richard" --server io.daimi.aau.dk
Démarre le client GTK3.22 en utilisant le nom Roi Richard et se connecte au serveur à io.daimi.aau.dk.
freeciv-sdl3 -a -t trident
Démarre le client SDL3 avec les tuiles trident et se connecte automatiquement à localhost.

FICHIERS

~/.freeciv/freeciv-client-rc-[numéro-de-version]
C'est là que vos paramètres locaux seront stockés.
tuilespecs
Ceux-ci sont recherchés dans le chemin des données ; voir ENVIRONNEMENT.
sonspecs
Ceux-ci sont recherchés dans le chemin des données ; voir ENVIRONNEMENT.

L'utilitaire freeciv-modpack(6) peut être utilisé pour localiser et télécharger du contenu supplémentaire tel que des ensembles de tuiles et des ensembles de sons, et (pour les serveurs lancés par le client uniquement) des scénarios et des ensembles de règles ; il enregistre les fichiers sous ~/.freeciv .

ENVIRONNEMENT

Le client Freeciv accepte les variables d'environnement suivantes :

FREECIV_CAPS
Une chaîne contenant une liste de « capacités » fournies par le serveur. La valeur par défaut intégrée devrait suffire dans la plupart des cas, mais si vous connaissez le système de capacités dans le code source, vous pouvez l'utiliser pour imposer certaines contraintes entre les clients et le serveur.
FREECIV_COMPRESSION_LEVEL
Définit le niveau de compression pour le trafic réseau.
FREECIV_DATA_ENCODING
Définit le codage de caractères utilisé pour les fichiers de données, les sauvegardes et les chaînes réseau. Il ne doit normalement pas être modifié par rapport à la valeur par défaut UTF-8, car c'est le format des ensembles de règles fournis et le protocole réseau standard.
FREECIV_INTERNAL_ENCODING
Définit le codage de caractères utilisé en interne par le client freeciv. Il doit généralement correspondre à la boîte à outils GUI, donc sa valeur par défaut dépend du client spécifique ; la plupart des clients utilisent UTF-8 par défaut.
FREECIV_LOCAL_ENCODING
Définit le codage de caractères local (utilisé pour la ligne de commande et la sortie du terminal). La valeur par défaut est déduite d'autres aspects de l'environnement.
FREECIV_MULTICAST_GROUP
Définit le groupe de multidiffusion (pour l'onglet LAN).
FREECIV_DATA_PATH
Une liste de répertoires séparés par des deux-points pointant vers les répertoires de données freeciv. Par défaut, Freeciv recherche dans les répertoires suivants, dans l'ordre, les fichiers de données : le répertoire courant ; le sous-répertoire « data » du répertoire courant ; le sous-répertoire « .freeciv/3.2 » dans le répertoire personnel de l'utilisateur ; et le répertoire où les fichiers sont placés en exécutant « make install ». S'il n'est pas défini, FREECIV_SAVE_PATH Une liste de répertoires séparés par des deux-points pointant vers les répertoires de sauvegarde freeciv. Par défaut, Freeciv recherche dans les répertoires suivants, dans l'ordre, les fichiers de sauvegarde : le répertoire courant ; et le sous-répertoire « .freeciv/saves » dans le répertoire personnel de l'utilisateur.

(Cela n'affecte pas l'emplacement où le serveur lancé par le client crée les fichiers de sauvegarde ; ceux-ci sont toujours créés dans « .freeciv/saves » dans le répertoire personnel de l'utilisateur.)

FREECIV_SCENARIO_PATH
Une liste de répertoires séparés par des deux-points pointant vers les répertoires de scénarios freeciv. Par défaut, Freeciv recherche dans les répertoires suivants, dans l'ordre, les fichiers de scénarios : le répertoire courant ; le sous-répertoire « data/scenarios » du répertoire courant ; les sous-répertoires « .freeciv/3.2/scenarios » et ensuite « .freeciv/scenarios » dans le répertoire personnel de l'utilisateur ; et le répertoire où les fichiers sont placés en exécutant « make install ».

(Cela n'affecte pas l'emplacement où le serveur lancé par le client crée les fichiers de scénarios ; ceux-ci sont toujours créés dans « .freeciv/scenarios » dans le répertoire personnel de l'utilisateur.)

FREECIV_OPT
Spécifie un fichier pour contenir les paramètres locaux, au lieu de ~/.freeciv/freeciv-client-rc-[numéro-de-version].
HOME
Spécifie le répertoire personnel de l'utilisateur.
http_proxy
Définissez cette variable en conséquence lors de l'utilisation d'un proxy.
LANG ou LANGUAGE
Définit la langue et la locale sur certaines plateformes.
LC_ALL ou LC_CTYPE
Similaire à LANG (voir la documentation de votre système).
USER
Spécifie le nom d'utilisateur de l'utilisateur courant.
