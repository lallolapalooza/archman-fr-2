NAME

flatpak build-update-repo - Créer un dépôt à partir d'un répertoire de build

SYNOPSIS

flatpak build-update-repo [OPTION...] LOCATION

DESCRIPTION

Met à jour les métadonnées du dépôt à l'emplacement LOCATION. Cette commande génère un fichier de résumé OSTree qui liste le contenu du dépôt. Le résumé est utilisé par `flatpak remote-ls` et d'autres commandes pour afficher le contenu des dépôts distants.

Après cette commande, LOCATION peut être utilisé comme emplacement de dépôt pour `flatpak remote-add`, soit en l'exportant via http, soit directement avec une URL `file:`.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Afficher les options d'aide et quitter.

--redirect-url=URL

Rediriger ce dépôt vers une nouvelle URL.

--title=TITLE

Un titre pour le dépôt, par exemple pour affichage dans une interface utilisateur. Le titre est stocké dans le résumé du dépôt.

--comment=COMMENT

Un commentaire sur une seule ligne pour le dépôt distant, par exemple pour affichage dans une interface utilisateur. Le commentaire est stocké dans le résumé du dépôt.

--description=DESCRIPTION

Une description complète sous forme de paragraphe pour le dépôt distant, par exemple pour affichage dans une interface utilisateur. La description est stockée dans le résumé du dépôt.

--homepage=URL

URL d'un site web pour le dépôt distant, par exemple pour affichage dans une interface utilisateur. L'URL est stockée dans le résumé du dépôt.

--icon=URL

URL d'une icône pour le dépôt distant, par exemple pour affichage dans une interface utilisateur. L'URL est stockée dans le résumé du dépôt.

--default-branch=BRANCH

Une branche par défaut pour le dépôt, principalement pour utilisation dans une interface utilisateur.

--gpg-import=FILE

Importer une nouvelle clé publique GPG par défaut à partir du fichier donné.

--collection-id=COLLECTION-ID

L'identifiant unique global du dépôt distant, pour permettre le regroupement des miroirs. Ceci doit être défini sur une chaîne de caractères DNS inversé unique globalement si le dépôt doit être rendu publiquement disponible. Si un identifiant de collection est déjà défini sur un dépôt existant, cela le mettra à jour. Si non spécifié, l'identifiant de collection existant ne sera pas modifié.

--deploy-collection-id

Déploie l'identifiant de collection (défini via --collection-id) dans la configuration statique du dépôt distant pour tous les clients. Ceci est irrévocable une fois publié dans un dépôt. Utilisez-le pour décider quand déployer un identifiant de collection aux utilisateurs d'un dépôt existant. Si vous construisez un nouveau dépôt qui possède un identifiant de collection, vous devriez généralement toujours passer cette option.

--deploy-sideload-collection-id

Ceci est similaire à `--deploy-collection-id`, mais il applique le déploiement uniquement aux clients plus récents que flatpak 1.7, qui prennent en charge la nouvelle forme de sideloads.

--gpg-sign=KEYID

Signer le commit avec cette clé GPG. Cette option peut être utilisée plusieurs fois.

--gpg-homedir=PATH

Répertoire d'accueil GPG à utiliser lors de la recherche des porte-clés.

--generate-static-deltas

Générer des deltas statiques pour toutes les références. Ceci génère des fichiers statiques "from-empty" et delta qui permettent un téléchargement plus rapide.

--static-delta-jobs=NUM-JOBS

Limiter le nombre de travaux parallèles créant des deltas statiques. La valeur par défaut est le nombre de CPUs.

--static-delta-ignore-ref=PATTERN

Ne pas générer de deltas pour les identifiants de runtime ou d'application correspondant à ce modèle. Par exemple, `--static-delta-ignore-ref=*.Sources` signifie qu'il n'y aura pas de deltas pour les références sources.

--prune

Supprimer les objets non référencés dans le dépôt.

--prune-depth

Conserver au maximum ce nombre de versions anciennes pour une référence donnée. La valeur par défaut est -1, ce qui signifie infini.

-v, --verbose

Afficher des informations de débogage pendant le traitement de la commande.

--ostree-verbose

Afficher des informations de débogage OSTree pendant le traitement de la commande.
