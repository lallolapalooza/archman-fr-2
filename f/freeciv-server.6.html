NOM

freeciv-server - Le serveur pour le jeu Freeciv

SYNTAXE

freeciv-server [ -A|--Announce protocole ] [ -b|--bind adresse ] [ -B|--Bind-meta adresse ] [ -d|--debug niveau ] [ -e|--exit-on-end ] [ -F|--Fatal [ numéro_signal ] ] [ -f|--file nom_fichier ] [ -h|--help ] [ -i|--identity adresse ] [ -k|--keep ] [ -l|--log nom_fichier ] [ -M|--Metaserver adresse ] [ -m|--meta ] [ -p|--port port ] [ -q|--quitidle temps ] [ -R|--Ranklog nom_fichier ] [ -r|--read nom_fichier ] [ -S|--Serverid id ] [ -s|--saves répertoire ] [ --scenarios répertoire ] [ -v|--version ]

Les serveurs conscients de l'authentification ont des paramètres supplémentaires : [ -a|--auth ] [ -D|--Database fichier ] [ -G|--Guests ] [ -N|--Newusers ]

Les serveurs prenant en charge le module IA ont un paramètre supplémentaire : [ -L|--LoadAI module ]

DESCRIPTION

Freeciv est un jeu de stratégie multijoueur au tour par tour, gratuit, dans lequel chaque joueur devient le chef d'une civilisation, se battant pour atteindre le but ultime : devenir la plus grande civilisation.

Les joueurs de Civilization II® de Microprose® devraient se sentir chez eux, car l'un des objectifs de Freeciv est d'avoir des règles compatibles.

Freeciv est maintenu par une équipe internationale de codeurs et d'enthousiastes, et est sans aucun doute l'un des jeux en réseau les plus amusants et addictifs qui existent !

Ceci est le programme serveur utilisé pour établir un serveur Freeciv - voir également freeciv-client(6).

Cette page de manuel ne liste que les arguments de ligne de commande. Pour plus de détails sur les directives nécessaires pour configurer freeciv-server, consultez le Manuel du Serveur qui se trouve sur le site web de Freeciv ainsi que la documentation qui fait partie de la distribution Freeciv.

OPTIONS

Les options suivantes sont acceptées sur la ligne de commande du serveur. Elles ne peuvent pas être combinées ; par exemple, « freeciv-server -fp savegame.sav 5557 » ne fonctionnera pas, vous devrez plutôt entrer « freeciv-server -f savegame.sav -p 5557 ». La plupart des options ont une forme courte (un seul tiret et une seule lettre) et une forme longue (deux tirets et un mot complet) ; leurs effets sont identiques.

-A protocole, --Announce protocole
Utilise protocole lors de l'annonce du jeu sur le réseau local. Les valeurs possibles pour protocole sont :

IPv4

IPv6

none

-a, --auth
Active l'authentification du serveur et n'autorise l'accès qu'aux joueurs enregistrés. Nécessite que l'option --Database soit spécifiée.
-b adresse, --bind adresse
Définit l'adresse sur laquelle le serveur écoutera les clients.
-B adresse, --Bind-meta adresse
Définit l'adresse depuis laquelle les requêtes au métaserveur sont envoyées. Par défaut, l'adresse donnée par l'option -b est utilisée.
-d niveau, --debug niveau
Définit la quantité d'informations de débogage à enregistrer dans le fichier nommé par l'option -l. Les valeurs acceptables pour le niveau sont :

fatal pour les messages fatals uniquement.

error pour les messages fatals et d'erreur.

warning pour les messages fatals, d'erreur et d'avertissement

normal pour les messages fatals, d'erreur, d'avertissement et normaux (par défaut).

verbose pour les messages fatals, d'erreur, d'avertissement, normaux et verbeux.

-D nom_fichier, --Database nom_fichier
Spécifie un fichier de configuration de base de données pour l'authentification. Ce fichier spécifie les détails de la base de données. Voir README.fcdb dans la distribution Freeciv pour les détails de son format.
-e, --exit-on-end
Lorsqu'une partie se termine, quitte au lieu de redémarrer.
-F [ numéro_signal ], --Fatal [ numéro_signal ]
Lève un signal personnalisé en cas d'échec d'assertion. Si numéro_signal n'est pas spécifié, le signal ABRT sera utilisé.
-f nom_fichier, --file nom_fichier
Charge une partie sauvegardée (nom_fichier) dans le serveur avant l'initialisation, au lieu de commencer une nouvelle partie. Ceci est pour recharger des parties sauvegardées, ou pour charger des scénarios. Voir ENVIRONNEMENT pour savoir où le serveur recherche ces fichiers.

La distribution est fournie avec plusieurs scénarios, généralement stockés dans /usr/local/share/freeciv/scenarios, par exemple :

• british-isles-85x80-v2.80.sav

• earth-160x90-v2.sav

• earth-80x50-v3.sav

• europe-200x100-v2.sav

• hagworld-120x60-v1.2.sav

• iberian-peninsula-136x100-v1.0.sav

-G, --Guests
Autorise les invités à se connecter en tant que 'guest' lorsque l'authentification est activée.
-h, --help
Affiche une description des options de ligne de commande et quitte.
-i adresse, --identity adresse
Rapporte l'adresse au métaserveur. Ensuite, le métaserveur utilisera cette adresse pour rediriger les utilisateurs.
-L module, --LoadAI module
Charge un module d'IA. Cette option peut apparaître plusieurs fois pour charger différents modules.
-l nom_fichier, --log nom_fichier
Définit un fichier journal, nom_fichier, à produire pendant le traitement. Utilisez l'option -d pour définir la quantité de journalisation. Par défaut, les messages fatals, d'erreur, d'avertissement et normaux sont affichés sur la sortie standard. Avec un fichier journal, ces messages sont envoyés au journal à la place. Si nom_fichier existe déjà, il est ajouté.
-M adresse, --Metaserver adresse
Spécifie l'adresse du métaserveur auquel envoyer les informations de votre serveur. Par défaut, le métaserveur standard géré par les mainteneurs de Freeciv sera utilisé.
-m, --meta
Ordonne au serveur de communiquer avec un métaserveur, un endroit où les serveurs Freeciv peuvent annoncer leur présence. Les clients Freeciv consultent le métaserveur pour offrir aux utilisateurs une sélection de jeux à rejoindre. Par défaut, le métaserveur Freeciv standard est utilisé. Vous pouvez spécifier un métaserveur alternatif avec l'option -M.
-k, --keep
Habituellement, le serveur freeciv arrête d'envoyer des mises à jour au métaserveur en cas de problèmes de connexion. Avec cette option, il continue d'essayer d'envoyer d'autres mises à jour même après avoir échoué une fois. Cette option implique l'option -m.
-N, --Newusers
Autorise les nouveaux utilisateurs à se connecter et à être enregistrés dans la base de données des joueurs si l'authentification est activée.
-p port, --port port
Spécifie le numéro de port TCP auquel les clients se connecteront ; les joueurs doivent connaître ce numéro pour pouvoir se connecter s'ils n'utilisent pas le port par défaut de 5556 décimal. Vous pourriez avoir besoin de l'utiliser si le port 5556 n'est pas disponible pour votre usage sur votre système, ou si vous souhaitez exécuter plusieurs serveurs sur le même système.
-q temps, --quitidle temps
Quitte si aucun joueur n'est présent pendant la durée spécifiée temps, en secondes, et redémarre un nouveau serveur.
-R nom_fichier, --Ranklog nom_fichier
Définit un fichier journal, nom_fichier, à produire pendant le traitement. Ce journal contient des informations pour le classement des joueurs.
-r nom_fichier, --read nom_fichier
Spécifie un fichier, nom_fichier, de commandes serveur que le serveur lira et traitera automatiquement, comme si vous les aviez tapées dans
à l'invite du serveur. La distribution est livrée avec quelques exemples, y compris des fichiers qui définissent des options similaires à Civilization I® et Civilization II®. Les fichiers sont nommés civ1.serv et civ2.serv, et se trouvent généralement dans /usr/local/share/freeciv/.
-S id, --Serverid i
d
Définit le id du serveur. Cela est utilisé pour identifier un jeu en cours d'exécution
particulier.
-s répertoire, --saves répertoi
re
Spécifie le répertoire où placer les fichiers de sauvegarde créés par le serveur. C'est particulièrement utile lorsque vous exécutez plus d'un serveur sur le même système, car cela empêche vos serveurs d'écraser les fichiers de sauvegarde des autres.

(Cela n'influence pas l'endroit où le serveur cherche lors du chargement des fichiers de sauvegarde ; voir FREECIV_SAVE_PATH pour

cela.
)
--scenarios répertoi
re
Spécifie le répertoire où placer les scénarios enregistrés par le serveur (par exemple, ceux créés avec l'éditeur intégré au jeu).

(Cela n'influence pas l'endroit où le serveur cherche lors du chargement des fichiers de scénario ; voir FREECIV_SCENARIO_PATH pour

cela.
)
-v,
--version
Fait afficher au
serveur son numéro de version et se terminer.

EXEMPLE

S
freeciv-server --file oldgame.sav --port
2244
Démarre un serveur sur le port 2244, en chargeant le fichier de sauvegarde oldgame.
sav.
freeciv-server -R ranklog -l logfile -r script -f oldgame.sav.gz -p
2244
Démarre un serveur sur le port 2244, en chargeant le fichier de sauvegarde oldgame.sav.gz. Les événements liés au classement sont écrits dans ranklog, les autres informations de journalisation sont écrites dans logfile. Lorsque le serveur démarre, il exécute immédiatement les commandes contenues dans scrip
t.
freeciv-server -m -a -D fc_auth.conf -q 60 -p 2244 -d normal -l logfile -r script -s
~/saves
Démarre un serveur sur le port 2244 avec l'authentification activée et communique son existence au métaserveur standard de Freeciv. Les messages d'échec, d'erreur, d'avertissement et normaux sont écrits dans logfile. Lorsque le serveur démarre, il exécute immédiatement les commandes contenues dans script. Les fichiers de sauvegarde sont stockés dans le répertoire ~/saves. Lorsqu'il n'y a pas d'utilisateurs sur le serveur pendant 60 secondes, le s
erveur
redé
marrera.
