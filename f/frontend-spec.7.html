NOM

jw(1) - spécification de l'interface entre jw et ses frontends

DESCRIPTION

jw(1) appelle des frontends comme frontends/docbook pour obtenir les informations spécifiques à un format d'entrée donné. Le frontend sait quelles informations retourner à partir du premier paramètre de ligne de commande. Il reçoit toutes les données nécessaires via les variables d'environnement, prêtes à l'emploi.

Ce document décrit ce paramètre de ligne de commande et ces variables d'environnement.

Le frontend doit retourner 0 en cas d'absence de problème, et une valeur positive en cas d'erreur.

VARIABLES

$1
Le paramètre de ligne de commande, spécifiant quelles informations retourner. Il peut prendre les valeurs suivantes :
catalogue-centralisé
Le frontend doit retourner le nom du catalogue centralisé spécifique à la DTD. Les catalogues centralisés résident normalement dans /etc/sgml et fournissent l'emplacement de tous les fichiers de catalogue utiles pour traiter ce type d'entrée (le catalogue de la DTD, le catalogue des feuilles de style, le catalogue des entités,
feuille-de-style
Le frontend doit retourner le nom du fichier de la feuille de style à utiliser pour ce type de document et avec le backend choisi.
SGML_CATALOGS_DIR
Le répertoire où résident les catalogues centralisés. Il s'agit normalement de /etc/sgml.

(Cette variable n'est valide que lors de la détermination du catalogue centralisé à utiliser.)

SGML_BASE_DIR
Le répertoire de base du système SGML. Il s'agit normalement de /usr/share/sgml.

(Cette variable n'est valide que lors de la détermination de la feuille de style à utiliser.)

SGML_FILE
Le nom du fichier à convertir.

(Cette variable n'est valide que lors de la détermination du catalogue centralisé à utiliser.)

SGML_TYPE
Le type de backend à utiliser, qu'il produise des fichiers de sortie à afficher en ligne ou à imprimer. Il peut prendre la valeur html ou print.

(Cette variable n'est valide que lors de la détermination de la feuille de style à utiliser).

SGML_STYLESHEETS
Le type de feuille de style personnalisée souhaité, soit none (aucune) soit default (par défaut). Si none, le frontend doit retourner le nom du fichier de la feuille de style fournie par le système sous docbook-utils. Si default, le frontend doit retourner la feuille de style personnalisée fournie par docbook-utils.

(Cette variable n'est valide que lors de la détermination de la feuille de style à utiliser).

SGML_XML
Le métalangage du fichier à convertir, soit sgml soit xml.

(Cette variable n'est valide que lors de la détermination du catalogue centralisé à utiliser).
