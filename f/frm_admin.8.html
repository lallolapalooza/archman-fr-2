NOM

frm_admin - administrer les paramètres de résidence des fichiers

SYNTAXE

frm_admin [options] [commande [options_cmd]]

DESCRIPTION

L'utilitaire frm_admin affiche et modifie les attributs d'espace du serveur de données associés à la résidence des fichiers. Ces attributs sont utilisés par les démons frm_purged, frm_xfrd et xrootd pour gérer la résidence des fichiers. La description de l'utilisation peut être affichée en tapant "frm_admin -h". La documentation HTML complète se trouve à l'adresse


https://xrootd.web.cern.ch/doc/dev50/frm_config.htm

NOTES

La documentation pour tous les composants associés à frm_admin se trouve à l'adresse https://xrootd.org/docs.html

DIAGNOSTICS

Les erreurs de configuration génèrent un message d'erreur et un statut de sortie non nul.

LICENCE

Les conditions de licence peuvent être affichées en tapant "xrootd -H".

NIVEAU DE SUPPORT

La commande frm_admin est supportée par la collaboration xrootd. Les informations de contact se trouvent à l'adresse
https://xrootd.org/contact.html
