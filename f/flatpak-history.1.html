FLATPAK HISTORY(1) flatpak history FLATPAK HISTORY(1)

NOM

flatpak-history - Afficher l'historique

SYNTAXE

flatpak history [OPTION...]

DESCRIPTION

Affiche les modifications apportées aux installations Flatpak sur le système. Cela inclut les installations, mises à jour et suppressions d'applications et de runtimes.

Par défaut, les installations individuelles et globales sont affichées. Utilisez les options --user, --installation ou --system pour modifier ce comportement.

Les informations pour la commande history proviennent du journal systemd, et peuvent également être consultées en utilisant par exemple journalctl MESSAGE_ID=c7b39b1e006b464599465e105b361485

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

-u, --user

Affiche les modifications apportées à l'installation utilisateur.

--system

Affiche les modifications apportées à l'installation système par défaut.

--installation=NAME

Affiche les modifications apportées à l'installation spécifiée par NAME parmi celles définies dans /etc/flatpak/installations.d/. L'utilisation de --installation=default est équivalente à l'utilisation de --system.

--since=TIME

N'affiche que les modifications plus récentes que l'heure spécifiée par TIME.

TIME peut être une date et heure absolue dans un format tel que AAAA-MM-JJ HH:MM:SS, ou une durée relative comme "2h", "7jours", "4jours 2heures".

--until=TIME

N'affiche que les modifications plus anciennes que l'heure spécifiée par TIME.

--reverse

Affiche les entrées les plus récentes en premier.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage OSTree pendant le traitement de la commande.

--columns=FIELD,...

Spécifie quelles informations afficher pour chaque référence. Vous pouvez lister plusieurs champs, ou utiliser cette option plusieurs fois.

Ajoutez :s[tart], :m[iddle], :e[nd] ou :f[ull] aux noms de colonnes pour modifier l'élision.

CHAMPS

Les champs suivants sont compris par l'option --columns :

time

Affiche quand la modification a eu lieu

change

Affiche le type de modification

ref

Affiche la référence

application

Affiche l'ID de l'application/runtime

arch

Affiche l'architecture

branch

Affiche la branche

installation

Affiche l'installation affectée.

Ce sera soit l'ID d'une installation Flatpak, soit le chemin vers un dépôt OSTree temporaire.

remote

Affiche le dépôt distant utilisé.

Ce sera soit le nom d'un dépôt distant configuré, soit le chemin vers un dépôt OSTree temporaire.

old-commit

Affiche le commit précédent. Pour les téléchargements (pulls), c'est le HEAD précédent de la branche. Pour les déploiements, c'est le commit précédemment actif.

commit

Affiche le commit actuel. Pour les téléchargements (pulls), c'est le HEAD de la branche. Pour les déploiements, c'est le commit actif.

url

Affiche l'URL du dépôt distant

user

Affiche l'utilisateur effectuant la modification.

Si c'est le démon système opérant en tant que root, affiche également quel utilisateur a déclenché la modification.

tool

Affiche l'outil utilisé.

Si c'est le démon système, affiche également quel outil a été utilisé pour déclencher la modification.

all

Affiche toutes les colonnes

help

Affiche la liste des colonnes disponibles

Notez que les noms de champs peuvent être abrégés jusqu'à un préfixe unique.
