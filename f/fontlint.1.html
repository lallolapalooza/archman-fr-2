NOM

fontlint - vérifier une police de caractères

SYNTAXE

fontlint fichier_police ...

DESCRIPTION

Le programme fontlint charge une police de caractères (ou plusieurs), qui peut être dans n'importe quel format que fontforge(1) peut lire, et vérifie la police pour certaines erreurs courantes :
* Contours qui se croisent
* Contours mal orientés
* Extrémités non marquées par des points
Et pour les polices PostScript :
* Trop de points dans un glyphe
* Trop d'indications dans un glyphe
* Nom de glyphe incorrect

OPTIONS

Aucune.
