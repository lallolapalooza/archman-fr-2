NOM

freshclam.conf - Fichier de configuration de l'outil de mise à jour des bases de données de Clam AntiVirus

DESCRIPTION

Le fichier freshclam.conf configure le programme de mise à jour des bases de données de Clam AntiVirus, freshclam(1).

FORMAT DU FICHIER

Le fichier se compose de commentaires et d'options avec arguments. Chaque ligne commençant par un symbole dièse (#) est ignorée par l'analyseur. Les options et les arguments sont sensibles à la casse et sont de la forme Option Argument. Les arguments sont des types suivants :

BOOL
Valeur booléenne (oui/non ou vrai/faux ou 1/0).
CHAINE
Chaîne de caractères sans espaces.
TAILLE
Taille en octets. Vous pouvez utiliser les modificateurs 'M' ou 'm' pour les mégaoctets et 'K' ou 'k' pour les kilo-octets.
NOMBRE
Entier non signé.

DIRECTIVES

Lorsqu'une option n'est pas utilisée (commentée ou n'existe pas dans le fichier de configuration), freshclam prend une action par défaut.

Exemple
Si cette option est définie, freshclam ne s'exécutera pas.
TailleMaxLogFichier TAILLE
Limite la taille du fichier journal. Le module de journalisation sera automatiquement désactivé si le fichier dépasse TAILLE. Une valeur de 0 désactive la limite.
Par défaut : 1M
LogTemps BOOL
Journalise l'heure avec chaque message.
Par défaut : non
LogSyslog BOOL
Active la journalisation vers Syslog. Peut être utilisé en combinaison avec UpdateLogFile.
Par défaut : désactivé.
FacilityLog CHAINE
Spécifie le type de messages syslog - veuillez vous référer à 'man syslog' pour les noms de facility.
Par défaut : LOG_LOCAL6
LogVerbeux BOOL
Active la journalisation détaillée.
Par défaut : désactivé
RotationLog BOOL
Fait tourner le fichier journal. Nécessite que l'option TailleMaxLogFichier soit définie avant cette option.
Par défaut : non
PidFile CHAINE
Écrit le pid du démon dans le fichier spécifié.
Par défaut : désactivé
RepertoireBasesDonnees CHAINE
Chemin vers un répertoire contenant les fichiers de bases de données. Ce répertoire doit déjà exister, être un chemin absolu, être accessible en écriture par freshclam et lisible par clamd/clamscan.
Par défaut : /var/lib/clamav
RepertoireCertificatsCVD CHAINE
Chemin vers un répertoire contenant les fichiers de certificats CA de ClamAV utilisés pour vérifier les archives de bases de données signées (par exemple, les fichiers CVD). Ce répertoire doit déjà exister, être un chemin absolu, être lisible par freshclam, clamd, clamscan et sigtool.
Par défaut : /etc/clamav/certs
LimitesHashChiffrementFIPS BOOL
Applique des limites de type FIPS sur l'utilisation des algorithmes de hachage à des fins cryptographiques. Désactivera les signatures FP MD5 et SHA1 et nécessitera des fichiers '.sign' pour vérifier l'authenticité des CVD.
Par défaut : non
PremierPlan BOOL
Ne pas se détacher en arrière-plan.
Par défaut : non
Debug BOOL
Active les messages de débogage dans libclamav.
Par défaut : non
LogMisesAJour CHAINE
Active la journalisation dans un fichier spécifié. Fortement recommandé.
Par défaut : désactivé.
ProprietaireBaseDonnees CHAINE
Lorsque démarré par root, abandonne les privilèges à l'utilisateur spécifié.
Par défaut : clamav
Vérifications NOMBRE
Nombre de vérifications de bases de données par jour.
Par défaut : 12
InfosBaseDonneesDNS CHAINE
Utilise le DNS pour vérifier la version de la base de données virale. FreshClam utilise les enregistrements TXT du DNS pour vérifier les versions de la base de données et du logiciel lui-même. Avec cette directive, vous pouvez modifier le domaine de vérification de la base de données.
ATTENTION : Ne la modifiez pas à moins que vous ne configuriez freshclam pour utiliser votre propre domaine de vérification de base de données.
Par défaut : activé, pointe vers current.cvd.clamav.net
MiroirBaseDonnees CHAINE
MiroirBaseDonnees spécifie à quels miroirs freshclam doit se connecter. Vous devriez avoir au moins une entrée : database.clamav.net. Maintenant que CloudFlare est utilisé comme notre réseau de diffusion de contenu (CDN), ce seul nom de domaine fonctionne dans le monde entier pour diriger freshclam vers le point d'extrémité géographique le plus proche.
Par défaut : database.clamav.net
MiroirPrive CHAINE
Cette option vous permet de diriger facilement freshclam vers des miroirs privés. Si MiroirPrive est défini, freshclam n'essaie pas d'utiliser le DNS pour déterminer si ses bases de données sont obsolètes, il utilisera plutôt la requête If-Modified-Since ou vérifiera directement les en-têtes des fichiers de base de données distants. Pour chaque base de données, freshclam tente d'abord de télécharger le fichier CLD. Si cela échoue, il essaie de télécharger le fichier CVD. Cette option remplace MiroirBaseDonnees, InfosBaseDonneesDNS et MisesAJourScriptées. Elle peut être utilisée plusieurs fois pour fournir des miroirs de repli.
Par défaut : désactivé
TentativesMax NOMBRE
Nombre de tentatives (par miroir) avant d'abandonner.
Par défaut : 3 (par miroir)
MisesAJourScriptées BOOL
Avec cette option, vous pouvez contrôler les mises à jour scriptées. Il est fortement recommandé de la laisser activée.
Par défaut : oui
TesterBasesDonnees BOOL
Avec cette option activée, freshclam tentera de charger les nouvelles bases de données en mémoire pour s'assurer qu'elles sont correctement traitées par libclamav avant de remplacer les anciennes.
Par défaut : activé
CompresserBaseLocale BOOL
Par défaut, freshclam conserve les bases de données locales (.cld) non compressées pour accélérer leur traitement. Avec cette option, vous pouvez activer la compression ; le changement prendra effet lors de la prochaine mise à jour de la base de données.
Par défaut : non
BaseDonneesSupplementaire CHAINE
Télécharge une base de données de signatures tierce supplémentaire distribuée via les miroirs ClamAV. Cette option peut être utilisée plusieurs fois.
Par défaut : désactivé
ExclureBaseDonnees CHAINE
Exclure une base de données de signatures standard (désinscription). Cette option peut être utilisée plusieurs fois.
Par défaut : désactivé
URLPersonnaliséeBaseDonnees CHAINE
Avec cette option, vous pouvez fournir des sources personnalisées pour les fichiers de base de données. Cette option peut être utilisée plusieurs fois. Support pour :
http(s)://, ftp(s)://, ou file:// Exemple d'utilisation :
URLPersonnaliséeBaseDonnees https://myserver.com:4567/allow_list.wdb
Par défaut : désactivé
ServeurProxyHTTP CHAINE, PortProxyHTTP NOMBRE
Utilise le serveur proxy et le port TCP donnés pour les téléchargements de bases de données. Le ServeurProxyHTTP peut être préfixé par [scheme]:// pour spécifier le type de proxy utilisé.
http:// Proxy HTTP. Par défaut lorsque aucun schéma ni type de proxy n'est spécifié.
https:// Proxy HTTPS. (Ajouté dans 7.52.0 pour OpenSSL, GnuTLS et NSS)
socks4:// Proxy SOCKS4.
socks4a:// Proxy SOCKS4a. Le proxy résout le nom d'hôte de l'URL.

freshclam.conf(5) — Arch Linux man pages

NAME

freshclam.conf — freshclam configuration file

DESCRIPTION

The freshclam.conf file is used to configure the behavior of the freshclam(1) utility. The file is located in /etc/clamav/freshclam.conf. It is parsed on startup by freshclam. Directives are one per line. Lines starting with # or ; are commented out. Blank lines are ignored.

All directives are case-insensitive. Values that are strings and contain spaces should be enclosed in quotes.

FILE FORMAT

The configuration file is a plain text file. Each line contains a single directive, followed by its value. The format is:

Directive Value

Directives are case-insensitive. Values may be case-sensitive.

DIRECTIVES

DatabaseMirror STRING
Specifies the server from which to download the virus database. You can specify multiple mirrors. The first mirror in the list will be used. If it fails, the next mirror will be tried. By default, mirrors from mirrors.clamav.net are used. Check the ClamAV website for a list of mirrors.
ScriptedAntiVirus STRING
Specifies the URL of the scripted antivirus database. Default is http://*.clamav.net/bloatware.cvd.
LocalSocket PATH
Specifies the path to the Unix domain socket used by clamd to communicate with freshclam. Default: /var/run/clamav/clamd.sock.
NotifyClamd STRING
Notify a running clamd(8) to reload its database after a download has occurred. The path for clamd.conf file must be provided.
Default: The default is to not notify clamd. See clamd.conf(5)'s option SelfCheck for how clamd(8) handles database updates in this case.
DatabaseDirectory PATH
Specifies the directory where the virus database is stored. Default: /var/lib/clamav.
DNSDatabaseInfo STRING
Use DNS records to get database version information. Default: DatabaseDirectory.
AllowSupplementaryAnnounces BOOL
Allow supplementary announces. Default: yes.
AllowMissingHaveAll BOOL
Allow missing have all. Default: no.
PidFile PATH
Specifies the path to the PID file. Default: /run/freshclam.pid.
LogRotate NUMBER
Enable log rotation. Specifies the maximum number of log files to keep. 0 disables rotation. Default: 0.
LogSyslog BOOL
Send log messages to syslog. Default: no.
LogFacility STRING
Specify the syslog facility to use. Default: LOG_LOCAL6.
LogFile PATH
Specifies the path to the log file. If not set, logging is disabled. Default: disabled.
ExtendedLogging BOOL
Enable extended logging. Default: no.
Verbose BOOL
Enable verbose logging. Default: no.
Debug BOOL
Enable debug logging. Default: no.
CheckLiveDNS BOOL
Check if the DNS server is alive. Default: yes.
PrivateMirror STRING
Specifies a private mirror to download databases from. This option can be specified multiple times. Useful for organizations that want to host their own mirror.
HTTPProxy STRING
Use HTTP proxy. Format: http://[user:password@]host:port.
HTTPProxyUsername STR,HTTPProxyPassword STRING
Proxy usage is authenticated through given username and password.
Default: disabled
HTTPProxyTimeout NUMBER
Timeout in seconds for the HTTP proxy connection. Default: 10.
HTTPUserAgent STRING
If your servers are behind a firewall/proxy which applies User-Agent filtering, you can use this option to force the use of a different User-Agent header. As of ClamAV 0.103.3, this setting may not be used when updating from the clamav.net CDN and can only be used when updating from a private mirror.
Default: clamav/version_number
MaxAttempts NUMBER
Maximum download attempts. Default: 3.
Bytecode BOOL
This option enables downloading of bytecode.cvd, which includes additional detection mechanisms and improvements to the ClamAV engine.
Default: yes
OnUpdateExecute STRING
Execute this command after the database has been successfully updated.
Default: disabled
OnErrorExecute STRING
Execute this command after a database update has failed.
Default: disabled
OnOutdatedExecute STRING
Execute this command when freshclam reports outdated version. In the command string %v will be replaced by the new version number.
Default: disabled
LocalIPAddress IP
Use IP as client address for downloading databases. Useful for multi homed systems.
Default: Use OS'es default outgoing IP address.
ConnectTimeout NUMBER
Timeout in seconds when connecting to database server.
Default: 10
ReceiveTimeout NUMBER
Maximum time in seconds for each download operation. 0 means no timeout.
Default: 0
socks5:// SOCKS5 Proxy.

socks5h:// SOCKS5 Proxy. Proxy resolves URL hostname.

FILES

/etc/clamav/freshclam.conf
