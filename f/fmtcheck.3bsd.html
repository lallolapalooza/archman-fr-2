fmtcheck(3bsd) 3bsd fmtcheck(3bsd)

NOM

fmtcheck — nettoie une chaîne de format de type printf() fournie par l'utilisateur

BIBLIOTHÈQUE

bibliothèque “libbsd”

SYNTAXE

#include <stdio.h> (Voir libbsd(7) pour l'utilisation de l'inclusion.)
const char *
fmtcheck(const char *fmt_suspect, const char *fmt_default);

DESCRIPTION

La fonction fmtcheck analyse fmt_suspect et fmt_default pour déterminer si fmt_suspect consommera les mêmes types d'arguments que fmt_default et pour s'assurer que fmt_suspect est une chaîne de format valide.

La famille de fonctions printf(3) ne peut pas vérifier les types d'arguments qui lui sont passés à l'exécution. Dans certains cas, comme catgets(3), il est utile ou nécessaire d'utiliser une chaîne de format fournie par l'utilisateur sans garantie que la chaîne de format corresponde aux paramètres spécifiés.

La fonction fmtcheck a été conçue pour être utilisée dans ces cas, comme suit :

printf(fmtcheck(user_format, standard_format), arg1, arg2);

Dans la vérification, les largeurs de champ, les remplissages, les précisions, etc. sont ignorés (sauf si la largeur de champ ou la précision est un astérisque ‘*’ au lieu d'une chaîne de chiffres). De plus, tout texte autre que les spécificateurs de format est complètement ignoré.

Notez que les formats peuvent être assez différents tant qu'ils acceptent les mêmes paramètres. Par exemple, « %ld %o %30s %#llx %-10.*e %n » est compatible avec « This number %lu %d%% and string %s has %qd numbers and %.*g floats (%n). ». Cependant, « %o » n'est pas équivalent à « %lx » car le premier nécessite un entier et le second nécessite un long, et « %p » n'est pas équivalent à « %lu » car le premier nécessite un pointeur et le second nécessite un long.

VALEURS DE RETOUR

Si fmt_suspect est un format valide et consomme les mêmes types d'arguments que fmt_default, alors la fonction fmtcheck retournera fmt_suspect. Sinon, elle retournera fmt_default.

VOIR AUSSI

printf(3)
