NOM

fwb_ipt - Compilateur de politiques pour Cisco PIX

SYNTAXE

fwb_pix -ffichier_donnees.xml [-V] [-drep_travail] [-i] [-v] [-xc] [-xt] nom_objet

DESCRIPTION

fwb_pix est le composant compilateur de politiques de Firewall Builder (voir fwbuilder(1)). Le compilateur lit les définitions d'objets et la description du pare-feu à partir du fichier de données spécifié avec l'option "-f" et génère le fichier de configuration Cisco PIX résultant. La configuration est écrite dans le fichier portant le même nom que l'objet pare-feu, avec l'extension ".fw".

Le fichier de données et le nom de l'objet pare-feu doivent être spécifiés sur la ligne de commande. Les autres paramètres de ligne de commande sont optionnels.

OPTIONS

-f FICHIER
Spécifie le nom du fichier de données à traiter.
-d rep_travail
Spécifie le répertoire de travail. Le compilateur crée le fichier de configuration PIX dans ce répertoire. Si ce paramètre est absent, la configuration PIX sera placée dans le répertoire de travail courant.
-v
Être verbeux : le compilateur affiche des messages diagnostiques pendant son exécution.
-V
Affiche le numéro de version et quitte.
-i
Lorsque cette option est présente, le dernier argument de la ligne de commande est supposé être l'ID de l'objet pare-feu plutôt que son nom.
-xc
Lorsque le nom du fichier de sortie est déterminé automatiquement (c'est-à-dire que les drapeaux -o ou -O ne sont pas présents), le nom du fichier est composé du nom du cluster et du nom du pare-feu membre plutôt que du seul nom du pare-feu membre. Ceci est utilisé principalement pour les tests lorsque le même objet pare-feu membre peut faire partie de clusters différents avec des configurations différentes.
-xt
Ce drapeau fait en sorte que le compilateur traite toutes les erreurs fatales comme des avertissements et continue le traitement des règles. Le script de configuration généré sera très probablement incorrect mais inclura le message d'erreur sous forme de commentaire ; ce drapeau est utilisé pour les tests et le débogage.
