fmin(3) Manuel des fonctions de bibliothèque fmin(3)

NOM

fmin, fminf, fminl - déterminer le minimum de deux nombres à virgule flottante

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double fmin(double x, double y);
float fminf(float x, float y);
long double fminl(long double x, long double y);
Conditions de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

fmin(), fminf(), fminl() :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Ces fonctions retournent la plus petite des valeurs x et y.

VALEUR DE RETOUR

Ces fonctions retournent le minimum de x et y.

Si l'un des arguments est un NaN, l'autre argument est retourné.

Si les deux arguments sont des NaN, un NaN est retourné.

ERREURS

Aucune erreur ne se produit.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
fmin (), fminf (), fminl () Thread safety MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

glibc 2.1. C99, POSIX.1-2001.

VOIR AUSSI

fdim(3), fmax(3)
