NOM

flatpak-info - Afficher des informations sur une application ou un runtime installé

SYNTAXE

flatpak info [OPTION...] NOM [BRANCHE]

DESCRIPTION

Affiche des informations sur une application ou un runtime installé.

Par défaut, la sortie est formatée d'une manière conviviale. Si vous spécifiez l'une des options --show-... ou --file-access, la sortie est formatée d'une manière lisible par machine.

Par défaut, les installations par utilisateur et globales sont interrogées. Utilisez les options --user, --system ou --installation pour modifier ce comportement.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Afficher les options d'aide et quitter.

-u, --user

Interroger les installations par utilisateur.

--system

Interroger l'installation globale par défaut.

--installation=NOM

Interroger une installation globale par NOM parmi celles définies dans /etc/flatpak/installations.d/. Utiliser --installation=default équivaut à utiliser --system.

--arch=ARCH

Interroger pour cette architecture. Voir flatpak --supported-arches pour les architectures supportées par l'hôte.

-r, --show-ref

Afficher la référence installée.

-o, --show-origin

Afficher la source distante d'où la référence est installée.

-c, --show-commit

Afficher l'ID du commit installé.

-s, --show-size

Afficher la taille installée.

-m, --show-metadata

Afficher les métadonnées.

--show-runtime

Afficher le runtime.

--show-sdk

Afficher le SDK.

-M, --show-permissions

Afficher les permissions.

--file-access=CHEMIN

Afficher le niveau d'accès au chemin donné.

-e, --show-extensions

Afficher les extensions correspondantes.

-l, --show-location

Afficher l'emplacement sur disque de l'application ou du runtime. Voir les exemples ci-dessous.

-v, --verbose

Afficher les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Afficher les informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak info org.gnome.Builder//master

$ tree `flatpak info -l org.gnome.Builder//master`/files
