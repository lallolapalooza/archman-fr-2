NOM

flowblade - Éditeur vidéo non linéaire

SYNTAXE

flowblade [options] [fichier]

DESCRIPTION

Flowblade est un éditeur vidéo non linéaire multipiste publié sous licence GPL3.

Des débutants aux experts, Flowblade vous aide à donner vie à votre vision d'image et de son.

Plus d'informations

Site web du projet : https://github.com/jliljebl/flowblade
Site web utilisateur : https://github.com/jliljebl/flowblade
Guide de référence : https://jliljebl.github.io/flowblade/webhelp/help.html

OPTIONS

-xdg
Utilise la spécification XDG et relocalise les paramètres du programme dans $XDG_CONFIG_DIR/flowblade/

FICHIERS

/home/votre_utilisateur/.flowblade/

Ce dossier stocke les préférences utilisées par Flowblade, sauf si le flag -xdg est activé.
