DESCRIPTIO

N

La commande frame crée une nouvelle fenêtre (donnée par l'argument pathName) et en fait un widget cadre. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects du cadre tels que sa couleur d'arrière-plan et son relief. La commande frame retourne le chemin de nom de la nouvelle

fenêtre.

Un cadre est un widget simple. Son but principal est d'agir comme un espaceur ou un conteneur pou

r des dispositions de fenêtres complexes. Les seules caractéristiques d'un cadre sont sa couleur
d'arrière-plan et une bordure 3D optionnelle pour faire apparaître le cadre comme suré encastré.

COMMANDE

WIDGET

La commande frame crée une nouvelle commande Tcl dont le nom est le même que le chemin de nom de la fenêtre du cadre. Cette commande peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante

: 
pathName option ?arg arg ..
.
?

PathName est le nom de la commande, qui est le même que le chemin de nom du widget cadre. Option et les args déterminent le comportement exact de la commande. Les commandes suivantes sont possibles pour les widgets cadre

:
pathName cget opti
on
Retourne la valeur actuelle de l'option de configuration donnée par option. Option peut avoir l'une des valeurs acceptées par la commande f
rame.
pathName configure ?option? ?value option value .
..?
Interroge ou modifie les options de configuration du widget. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour pathName (voir Tk_ConfigureInfo pour des informations sur le format de cette liste). Si option est spécifiée sans value, alors la commande retourne une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur retournée si aucune option n'est spécifiée). Si une ou plusieurs paires option-value sont spécifiées, alors la commande modifie la ou les options du widget données pour avoir les valeurs données ; dans ce cas, la commande retourne une chaîne vide. Option peut avoir l'une des valeurs acceptées par la comman
