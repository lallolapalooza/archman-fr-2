NOM

flatpak-build-bundle - Créer un paquet unique à partir d'un dépôt local

SYNTAXE

flatpak build-bundle [OPTION...] LOCATION FILENAME NAME [BRANCH]

DESCRIPTION

Crée un fichier unique nommé FILENAME pour l'application (ou le runtime) nommée NAME dans le dépôt à l'emplacement LOCATION. Si une branche BRANCH est spécifiée, c'est cette branche de l'application qui est utilisée.

L'ID de collection défini sur le dépôt à l'emplacement LOCATION (s'il est défini) sera utilisé pour le paquet.

Sauf si l'option --oci est utilisée, le format du fichier de paquet est celui d'un delta statique ostree (par rapport à une base vide) avec des métadonnées spécifiques à flatpak pour les icônes et les metadonnées des applications.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

--runtime

Exportez un runtime au lieu d'une application.

--arch=ARCH

L'architecture pour laquelle créer un paquet. Voir flatpak --supported-arches pour les architectures supportées par l'hôte.

--repo-url=URL

L'URL du dépôt à partir duquel l'application peut être mise à jour. L'installation du paquet configurera automatiquement un distant pour cette URL.

--runtime-repo=URL

L'URL d'un fichier .flatpakrepo contenant les informations sur le dépôt qui fournit les runtimes requis par l'application.

--gpg-keys=FILE

Ajoute la clé GPG du fichier FILE (utilisez - pour stdin).

--gpg-homedir=PATH

Le répertoire GPG (Homedir) à utiliser lors de la recherche des trousseaux de clés.

--from-commit=COMMIT

Le commit OSTree à partir duquel créer un paquet delta.

--oci

Exportez vers une image OCI au lieu d'un paquet Flatpak.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage d'OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak build-bundle /var/lib/flatpak/repo gnome-calculator.flatpak org.gnome.Calculator stable

$ flatpak build-bundle ~/.local/share/flatpak/repo gnome-calculator.flatpak org.gnome.Calculator stable
