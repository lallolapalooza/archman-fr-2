fnottctl(1) Manuel des commandes générales fnottctl(1)

NOM

fnottctl - utilitaire pour interagir avec fnott(1)

SYNTAXE

fnottctl dismiss [id]
fnottctl dismiss-with-default-action [id]
fnottctl actions [id]
fnottctl list
fnottctl pause
fnottctl unpause
fnottctl quit
fnottctl --version

OPTIONS

id

L'identifiant de notification à rejeter ou pour lequel afficher les actions. Utilisez fnottctl list pour voir les identifiants des notifications actives.

-v,--version

Afficher le numéro de version et quitter

DESCRIPTION

fnottctl est utilisé pour interagir (rejeter des notifications, afficher et sélectionner des actions pour les notifications) avec fnott(1).

L'opération la plus courante est fnottctl dismiss. Cela rejettera la notification de priorité la plus élevée. Vous pourriez vouloir lier ceci à un raccourci clavier dans la configuration de votre compositeur Wayland. Ceci est identique à un clic droit sur la notification.

Pour voir, et choisir parmi, les actions associées à la notification, utilisez fnottctl actions. Ceci nécessite qu'un utilitaire de type dmenu ait été configuré dans fnott.ini(5).

Enfin, vous pouvez déclencher l'action par défaut de la notification (une action nommée default) et la rejeter simultanément avec dismiss-with-default-action. Ceci est identique à un clic gauche sur la notification.

Vous pouvez spécifier facultativement un identifiant de notification, pour rejeter (ou afficher les actions pour) une notification spécifique au lieu de celle de priorité la plus élevée.

Pour dismiss, il existe également l'identifiant spécial all qui rejettera, sans surprise, toutes les notifications.

VOIR AUSSI

fnott(1), fnott.ini(5)
