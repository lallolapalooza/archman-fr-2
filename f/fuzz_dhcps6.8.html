NOM

fuzz_dhcps6

SYNOPSIS

fuzz_dhcps6 [-t nombre | -T nombre] [-e nombre | -T nombre] [-p nombre] [-md] [-1|-2|-3|-4|-5|-6|-7|-8] interface [nom-de-domaine]

OPTIONS

 -1         fuzz DHCPv6 Solicit (par défaut)
 -2         fuzz DHCPv6 Request
 -3         fuzz DHCPv6 Confirm
 -4         fuzz DHCPv6 Renew
 -5         fuzz DHCPv6 Rebind
 -6         fuzz DHCPv6 Release
 -7         fuzz DHCPv6 Decline
 -8         fuzz DHCPv6 Information Request
 -m         fuzzifie également le type de message
 -t nombre  continue à partir du test no. nombre
 -e nombre  continue jusqu'au test no. nombre
 -T nombre  n'effectue que le test no. nombre
 -n nombre  combien de fois envoyer chaque paquet (par défaut : 1)
 -f         usurper la mac
 -F         usurper l'adresse de lien
 -w sec     attendre nombre secondes entre les paquets (par défaut : 0)
 -p nombre  effectue une vérification d'activité tous les nombre de tests (par défaut : aucune)
 -d         Utilisez -d pour forcer les mises à jour DNS, vous pouvez spécifier un nom de domaine sur la ligne de commande.
Fuzzifie des paquets DHCPv6 vers un serveur
Vous ne pouvez définir qu'un seul type parmi -0 ... -4, par défaut c'est -1.
Retourne -1 en cas d'erreur, 0 si les tests sont terminés et la cible vivante, ou 1 si la cible plante.
