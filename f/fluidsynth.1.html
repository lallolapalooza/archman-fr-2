FluidSynth(1) Manuel des commandes générales FluidSynth(1)

NOM

FluidSynth - un synthétiseur SoundFont

SYNTAXE

fluidsynth [options] [ SoundFonts ] [ fichiers_midi ]

DESCRIPTION

FluidSynth est un synthétiseur MIDI en temps réel basé sur les spécifications SoundFont(R) 2. Il peut être utilisé pour rendre des entrées MIDI ou des fichiers MIDI en audio. Les événements MIDI sont lus à partir d'un périphérique MIDI. Le son est rendu en temps réel vers le périphérique de sortie audio.

La manière la plus simple de démarrer le synthétiseur est de lui fournir un SoundFont sur la ligne de commande : 'fluidsynth soundfont.sf2'. fluidsynth chargera le SoundFont et lira les événements MIDI à partir du périphérique MIDI par défaut en utilisant le pilote MIDI par défaut. Une fois FluidSynth en cours d'exécution, il lit les commandes depuis l'entrée standard. Il existe des commandes pour envoyer des événements MIDI manuellement, charger ou décharger des SoundFonts, etc. Toutes les commandes disponibles sont discutées ci-dessous.

FluidSynth peut également être utilisé pour lire une liste de fichiers MIDI. Lancez simplement FluidSynth avec le SoundFont et la liste des fichiers MIDI à lire. Dans ce cas, vous pourriez ne pas vouloir ouvrir le périphérique MIDI pour lire les événements externes. Utilisez l'option -n pour désactiver l'entrée MIDI. Si vous souhaitez également désactiver l'utilisation du shell, lancez FluidSynth avec l'option -i : 'fluidsynth -ni soundfont.sf2 midifile1.mid midifile2.mid'.

Exécutez fluidsynth avec l'option --help pour vérifier les modifications apportées à la liste des options.

OPTIONS

fluidsynth accepte les options suivantes :

-a, --audio-driver=[étiquette]
Le pilote audio à utiliser. "-a help" pour lister les options valides
-b, --bank-offset=[num]
Un indicateur positionnel qui spécifie le décalage de banque pour tout Soundfont suivant cet indicateur. Peut être spécifié plusieurs fois.
-c, --audio-bufcount=[compte]
Nombre de tampons audio
-C, --chorus
Activer ou désactiver le chorus [0|1|yes|no, défaut = activé]
-d, --dump
Afficher les événements MIDI entrants et sortants sur la sortie standard
-E, --audio-file-endian
Boutisme du fichier audio pour le rendu rapide ou le pilote aufile ("-E help" pour la liste)
-f, --load-config
Charger le fichier de configuration des commandes (commandes shell)
-F, --fast-render=[fichier]
Rendre le fichier MIDI en données audio brutes et les stocker dans [fichier]
-g, --gain
Définir le gain maître [0 < gain < 10, défaut = 0.2]
-G, --audio-groups
Définit le nombre de nœuds audio LADSPA
-h, --help
Afficher ce résumé d'aide
-i, --no-shell
Ne pas lire les commandes depuis le shell [défaut = oui]
-j, --connect-jack-outputs
Tenter de connecter les sorties JACK aux ports physiques
-K, --midi-channels=[num]
Le nombre de canaux MIDI [défaut = 16]
-L, --audio-channels=[num]
Le nombre de canaux audio stéréo [défaut = 1]
-m, --midi-driver=[étiquette]
Le nom du pilote MIDI à utiliser. "-m help" pour lister les options valides.
-n, --no-midi-in
Ne pas créer de pilote MIDI pour lire les événements d'entrée MIDI [défaut = oui]
-o
Définir un réglage, -o nom=valeur ("-o help" pour afficher les valeurs actuelles)
-O, --audio-file-format
Format de fichier audio pour le rendu rapide ou le pilote aufile ("-O help" pour la liste)
-p, --portname=[étiquette]
Définir le nom du port MIDI (pilotes alsa_seq, coremidi)
-q, --quiet
Ne pas afficher le message de bienvenue ou d'autres informations
-r, --sample-rate
Définir le taux d'échantillonnage
-R, --reverb
Activer ou désactiver la réverbération [0|1|yes|no, défaut = activé]
-s, --server
Démarrer FluidSynth en tant que processus serveur
-T, --audio-file-type
Type de fichier audio pour le rendu rapide ou le pilote aufile ("-T help" pour la liste)
-v, --verbose
Afficher des messages détaillés sur les événements MIDI (synth.verbose=1) ainsi que d'autres messages de débogage
-V, --version
Afficher la version du programme
-z, --audio-bufsize=[taille]
Taille de chaque tampon audio

PARAMETRES

Les paramètres à spécifier avec -o sont documentés dans le fichier fluidsettings.xml, qui est généralement fourni avec cette distribution ou disponible en ligne à l'adresse https://www.fluidsynth.org/api/fluidsettings.xml . Nous recommandons de consulter ce fichier dans un navigateur web, de préférence Firefox.

COMMANDES SHELL

GENERAL
help
Affiche la liste des sujets d'aide (tapez "help <sujet>" pour voir les détails sur les commandes disponibles)
quit
Quitter le synthétiseur
SOUNDFONTS
load filename [reset] [bankofs]
Charge un SoundFont dans la pile SoundFont. Si reset est 1 (ce qui est la valeur implicite par défaut), tous les presets SoundFont actuellement utilisés seront réévalués en tenant compte du SoundFont nouvellement chargé. Facultativement, vous pouvez spécifier un décalage de banque non nul pour le nouveau SoundFont. Par exemple, la commande load soundfont.sf2 0 10 chargera le soundfont.sf2 avec un décalage de banque de 10 sans réévaluer les presets.
unload number
Décharge un SoundFont. Le nombre est l'index du SoundFont dans la pile.
fonts
Liste les SoundFonts actuels dans la pile
inst number
Affiche les instruments disponibles pour le SoundFont.
MESSAGES MIDI
noteon channel key velocity
Envoie un événement note-on
noteoff channel key
Envoie un événement note-off
cc channel ctrl value
Envoie un événement de changement de contrôle
prog chan num
Envoie un message de changement de programme
select chan sfont bank prog
Combinaison de sélection de banque et de changement de programme
channels
Affiche les presets de tous les canaux.
SYNTHÈSE AUDIO
gain value
Définit le gain maître (0 < gain < 5)
interp num
Choisir la méthode d'interpolation pour tous les canaux
interpc chan num
Choisir la méthode d'interpolation pour un canal
