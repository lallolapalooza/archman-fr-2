NOM

freeipmi.conf - spécifier les valeurs par défaut pour FreeIPMI

DESCRIPTION

Le fichier de configuration FreeIPMI peut être utilisé pour définir d'autres valeurs par défaut pour de nombreux outils FreeIPMI, afin de ne pas avoir à les spécifier sur la ligne de commande. Cela permet aux utilisateurs d'éviter de taper une longue liste d'options de commande chaque fois qu'une commande est exécutée. Il peut également être utilisé pour masquer les noms d'utilisateur, les mots de passe et d'autres informations sensibles de la commande ps(1).

Actuellement, les outils qui peuvent être configurés avec le fichier de configuration sont : bmc-device(8), bmc-info(8), bmc-watchdog(8), ipmi-chassis(8), ipmi-config(8), ipmi-fru(8), ipmi-oem(8), ipmi-pet(8), ipmi-raw(8), ipmi-sel(8), ipmi-sensors(8), ipmiconsole(8), et ipmipower(8).

Par défaut, le fichier de configuration est stocké dans /etc/freeipmi//freeipmi.conf. Mais les utilisateurs peuvent sélectionner un autre fichier de configuration en ligne de commande avec l'option --config-file.

Les valeurs spécifiées sur la ligne de commande remplacent les valeurs de configuration spécifiées dans le fichier de configuration.

FORMAT

Les options de configuration qui peuvent être spécifiées dans le fichier de configuration sont listées ci-dessous. Chaque option de configuration doit être inscrite sur une ligne séparée. Les arguments d'une option sont séparés par n'importe quelle quantité d'espace blanc. Plusieurs arguments sont également séparés par des espaces blancs. Les commentaires peuvent être marqués en utilisant le caractère dièse ("#"), et les lignes peuvent être continuées sur la ligne suivante en utilisant une barre oblique inverse ("\").

Il est possible de lister le nom d'utilisateur, le mot de passe et d'autres informations potentiellement sensibles dans le fichier de configuration. Si ces données sont stockées dans un fichier de configuration, les administrateurs système doivent limiter l'accès à ce fichier.

OPTIONS GÉNÉRALES

Les options suivantes sont généralement disponibles pour tous les outils, bien que des options spécifiques puissent être ignorées par certains. (Par exemple, ipmiconsole(8) et ipmipower(8) n'effectuent pas de communication en bande, donc ils ignoreraient les options de communication en bande. De même, bmc-watchdog(8) n'effectue pas de communication hors bande, donc il ignorerait toutes les options hors bande).

driver-type IPMIDRIVER
Spécifie le type de pilote par défaut à utiliser.
disable-auto-probe ENABLE|DISABLE
Spécifie si les périphériques IPMI doivent être sondés pour les paramètres par défaut.
driver-address DRIVER-ADDRESS
Spécifie l'adresse du pilote en bande par défaut à utiliser.
driver-device DEVICE
Spécifie le chemin du périphérique pilote en bande par défaut à utiliser.
register-spacing REGISTER-SPACING
Spécifie l'espacement des registres du pilote en bande par défaut à utiliser.
target-channel-number CHANNEL-NUMBER
Spécifie le numéro de canal cible du pilote en bande par défaut.
target-slave-address SLAVE-ADDRESS
Spécifie l'adresse esclave cible du pilote en bande par défaut.
username USERNAME
Spécifie le nom d'utilisateur par défaut à utiliser.
password PASSWORD
Spécifie le mot de passe par défaut à utiliser.
k_g str
Spécifie la clé BMC par défaut (K_g) à utiliser. Préfixer avec '0x' pour entrer la clé en hexadécimal.
session-timeout MILLISECONDS
Spécifie la durée du délai d'expiration de session par défaut en millisecondes.
retransmission-timeout MILLISECONDS
Spécifie la durée du délai de retransmission par défaut en millisecondes.
authentication-type AUTHENTICATION-TYPE
Spécifie le type d'authentification par défaut à utiliser. Les types d'authentification suivants sont pris en charge : NONE, STRAIGHT_PASSWORD_KEY, MD2, et MD5.
cipher-suite-id CIPHER-SUITE-ID
Spécifie l'identifiant de la suite de chiffrement par défaut à utiliser. Les identifiants de suite de chiffrement suivants sont pris en charge : 0, 1, 2, 3, 6, 7, 8, 11, 12.
privilege-level PRIVILEGE-LEVEL
Spécifie le niveau de privilège par défaut à utiliser. Les niveaux de privilège suivants sont pris en charge : USER, OPERATOR, ADMIN.
workaround-flags WORKAROUNDS
Spécifie les indicateurs de contournement par défaut à utiliser. Plusieurs contournements peuvent être spécifiés séparés par des espaces blancs. Veuillez consulter les pages de manuel des outils pour plus de détails sur les contournements disponibles pour chaque outil. Les contournements suivants sont pris en charge : assumeio, spinpoll, idzero, forcepermsg, unexpectedauth, endianseq, noauthcodecheck, authcap, nochecksumcheck, intel20, supermicro20, sun20, opensesspriv, integritycheckvalue, assumemaxsdrrecordcount, solpayloadsize, solport, solstatus, solchannelsupport, serialalertsdeferred, solpacketseq, skipchecks, assumesystemevent, discretereading, ignorescanningdisabled, assumebmcowner, ignoreauthcode, slowcommit, veryslowcommit, solchannelassumelanchannel, ignorestateflag, malformedack, guidformat, ipmiping.

OPTIONS SDR

Les options suivantes sont spécifiques aux outils qui utilisent le répertoire des données de capteurs (SDR). Elles seront ignorées par tous les autres outils.

quiet-cache ENABLE|DISABLE
Spécifie si les informations de création/suppression de cache ne doivent pas être affichées par défaut.
sdr-cache-directory DIRECTORY
Spécifie le répertoire de cache SDR par défaut à utiliser.

OPTIONS TEMPORELLES

Les options suivantes sont spécifiques aux outils qui peuvent afficher des valeurs temporelles. Elles seront ignorées par tous les autres outils.

utc-to-localtime ENABLE|DISABLE
Spécifie si l'heure doit être convertie de l'UTC supposé à l'heure locale par défaut.
localtime-to-utc ENABLE|DISABLE
Spécifie si l'heure doit être convertie de l'heure locale à l'UTC par défaut.
utc-offset SECONDS
Spécifie un décalage UTC par défaut à ajouter aux horodatages.

OPTIONS HOSTRANGED

Les options suivantes sont spécifiques aux outils qui prennent en charge la sortie hostranged. Elles seront ignorées par tous les autres outils.

buffer-output ENABLE|DISABLE
Spécifie si la sortie hostranged doit être mise en mémoire tampon par défaut.
consolidate-output ENABLE|DISABLE
Spécifie si la sortie hostranged doit être consolidée par défaut.
fanout COUNT
Spécifie la diffusion multiple d'hôtes par défaut à utiliser.
eliminate ENABLE|DISABLE
Spécifie si les hôtes non détectés doivent être éliminés par défaut.
always-prefix ENABLE|DISABLE
Spécifie si la sortie doit toujours être préfixée par défaut.
