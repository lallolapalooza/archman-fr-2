FLS(1) Manuel des commandes générales FLS(1)

NOM

fls - Lister les noms de fichiers et de répertoires dans une image disque.

SYNTAXE

fls [-adDFlpruvV] [-m mnt ] [-z zone ] [-f fstype ] [-s secondes ] [-i imgtype ] [-o imgoffset ] [-b taille_secteur_dev] image [images] [ inode ]

DESCRIPTION

fls liste les noms de fichiers et de répertoires dans l'image et peut afficher les noms de fichiers récemment supprimés pour le répertoire en utilisant l'inode donné. Si l'argument inode n'est pas fourni, la valeur de l'inode pour le répertoire racine est utilisée. Par exemple, sur un système de fichiers NTFS, ce serait 5 et sur un système de fichiers Ext3, ce serait 2.

Les arguments sont les suivants :

-a
Affiche les entrées de répertoire "." et ".." (par défaut, il ne le fait pas).
-d
Affiche uniquement les entrées supprimées.
-D
Affiche uniquement les entrées de répertoire.
-f fstype
Le type de système de fichiers. Utilisez '-f list' pour lister les types de systèmes de fichiers supportés. S'il n'est pas fourni, des méthodes de détection automatique sont utilisées.
-F
Affiche uniquement les entrées de fichiers (non-répertoires).
-l
Affiche les détails des fichiers au format long. Les contenus suivants sont affichés :

type_fichier inode nom_fichier mod_time acc_time chg_time cre_time taille uid gid

-m mnt
Affiche les fichiers au format time machine afin qu'une chronologie puisse être créée avec mactime(1). La chaîne fournie comme mnt sera préférée aux noms de fichiers en tant que point de montage (par exemple /usr).
-p
Affiche le chemin complet pour chaque entrée. Par défaut, il indique la profondeur du répertoire lors des exécutions récursives avec un signe '+'.
-r
Affiche récursivement les répertoires. Cela ne suivra pas les répertoires supprimés, car il ne le peut pas.
-s secondes
Le décalage temporel du système d'origine en secondes. Par exemple, si le système d'origine était lent de 100 secondes, cette valeur serait de -100. Ceci n'est utilisé que si -l ou -m sont fournis.
-i imgtype
Identifie le type de fichier image, comme 'raw'. Utilisez '-i list' pour lister les types supportés. S'il n'est pas fourni, des méthodes de détection automatique sont utilisées.
-o imgoffset
Le décalage de secteur où commence le système de fichiers dans l'image.
-b taille_secteur_dev
La taille, en octets, des secteurs du périphérique sous-jacent. S'il n'est pas fourni, la valeur dans le format d'image est utilisée (si elle existe) ou 512 octets sont supposés.
-u
Affiche uniquement les entrées non supprimées.
-v
Sortie verbeuse sur stderr.
-V
Affiche la version.
-z zone
La chaîne ASCII du fuseau horaire du système d'origine. Par exemple, EST ou GMT. Ces chaînes doivent être définies par votre système d'exploitation et peuvent varier.
image [images]
L'image disque ou partition à lire, dont le format est donné avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné et que son nom est le premier d'une séquence (par exemple, se terminant par '.001'), les segments d'image suivants seront inclus automatiquement.

Une fois l'inode déterminé, le fichier peut être récupéré en utilisant icat(1) de The Coroners Toolkit. La quantité d'informations récupérées des entrées de fichiers supprimées varie en fonction du système. Par exemple, sous Linux, un fichier récemment supprimé peut être facilement récupéré, tandis que sous Solaris, même l'inode ne peut pas être déterminé. Si vous voulez juste trouver quel nom de fichier appartient à un inode, il est plus facile d'utiliser ffind(1).

EXEMPLES

Pour obtenir une liste de tous les fichiers et répertoires dans une image, utilisez :

# fls -r image 2

ou simplement (si aucun inode n'est spécifié, l'inode du répertoire racine est utilisé) :

# fls -r image

Pour obtenir le chemin complet des fichiers supprimés dans un répertoire donné :

# fls -d -p image 29

Pour obtenir la sortie mactime, faites :

# fls -m /usr/local image 2

Si vous avez une image disque et que le système de fichiers commence au secteur 63, utilisez :

# fls -o 63 disk-img.dd

Si vous avez une image disque divisée, utilisez :

# fls -i "split" -o 63 disk-1.dd disk-2.dd disk-3.dd

VOIR AUSSI

ffind(1), icat(1)
