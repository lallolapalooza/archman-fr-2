FTP(1) Commandes utilisateur FTP(1)

NOM

ftp - Client du protocole de transfert de fichiers.

SYNTAXE

ftp [OPTION...] [HÔTE [PORT]]

DESCRIPTION

Transfert de fichiers à distance.

-4, --ipv4
contacter les hôtes IPv4
-6, --ipv6
contacter les hôtes IPv6
-A, --active
activer le transfert en mode actif
-d, --debug
activer la sortie de débogage
-e, --no-edit
désactiver l'édition de la ligne de commande
-g, --no-glob
désactiver le globbing des noms de fichiers
-i, --no-prompt
ne pas demander de confirmation lors de transferts de plusieurs fichiers
-n, --no-login
ne pas se connecter automatiquement au système distant
-N, --netrc=NETRC
sélectionner un fichier d'initialisation spécifique
--prompt[=PROMPT]
afficher une invite de ligne de commande PROMPT (facultativement), même si elle n'est pas sur un tty
-p, --passive
activer le transfert en mode passif, par défaut pour `pftp'
-t, --trace
activer le traçage des paquets
-v, --verbose
sortie détaillée
-?, --help
donner cette liste d'aide
--usage
donner un court message d'utilisation
-V, --version
afficher la version du programme

Les arguments obligatoires ou facultatifs des options longues sont également obligatoires ou facultatifs pour les options courtes correspondantes.
