NOM

fribidi_shape_mirroring - effectue la mise en forme par miroir

SYNTAXE

#include <../fribidi/lib/fribidi.h>

void fribidi_shape_mirroring
(
const FriBidiLevel *embedding_levels,
const FriBidiStrIndex len,
FriBidiChar *str
);

PARAMETRES

const FriBidiLevel *embedding_levels
Liste d'entrée des niveaux d'intégration, telle que retournée par fribidi_get_par_embedding_levels.
const FriBidiStrIndex len
Longueur de la chaîne d'entrée.
FriBidiChar *str
Chaîne à mettre en forme.

DESCRIPTION

Cette fonction remplace les caractères miroirs dans les intégrations de droite à gauche dans la chaîne par leur équivalent miroir tel que retourné par fribidi_get_mirror_char().

Cette fonction implémente la règle L4 de l'algorithme Unicode bidirectionnel disponible sur http://www.unicode.org/reports/tr9/#L4.
