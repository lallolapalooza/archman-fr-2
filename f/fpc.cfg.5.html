fpc.cfg - fichier de configuration

du Free Pascal Compiler (FPC), nom
dérivé de Free Pascal Compiler.

DESCRIPTIO

N

Ceci est le fichier de configuration principal du Free Pascal Compiler

(FPC)

Toutes les options en ligne de commande du compilateur (décrites dans fpc(1)) peuvent être spécifiées dans fpc.

cfg

Lorsque le fichier de configuration est trouvé, il est lu, et les lignes qu'il contient sont traitées comme si vous les aviez saisies sur la ligne de commande, voir fpc(1), avec quelques possibilités conditionnelles

supplémentaires
.

SYNTAX

E

Vous pouvez spécifier des commentaires dans le fichier de configuration avec le signe #. Tout ce qui suit le # sera ignoré, sauf s'il s'agit de l'un des mots-clés (voir ci-dessous)

.

Le compilateur recherche le fichier fpc.cfg aux endroits suivants

:

- Sous Linux et unix
- Le répertoire courant.
- Le répertoire personnel, recherche .fpc.cfg
- Le répertoire spécifié dans la variable d'environnement
PPC_CONFIG_PATH, et si elle n'est pas
définie, sous compilerdir/../etc.
- S'il n'est toujours pas trouvé : dans

/etc.

- Sous tous les autres systèmes d'exploitation :
- Le répertoire courant.
- Le répertoire spécifié dans la variable d'environnement
PPC_CONFIG_PATH.
- Le répertoire où se trouve le binaire du

compilateur.

Lorsque le compilateur a terminé la lecture du fichier de configuration, il continue de traiter les options de la ligne de

commande.

L'une des options en ligne de commande vous permet de spécifier un deuxième fichier de configuration : spécifier @foo sur la ligne de commande utilisera le fichier foo à la place de fpc.cfg et lira les options supplémentaires à partir de celui-ci. Lorsque le compilateur a terminé la lecture de ce fichier, il continue de traiter la ligne de

commande.

Le fichier de configuration permet une certaine forme de prétraitement. Il comprend les directives suivantes, que vous devez placer sur la première colonne d'une ligne

:

#IFDEF
#IFNDEF
#ELSE
#ENDIF
#DEFINE
#UNDEF
#WRITE
#INCLUDE
#SECTION
Elles fonctionnent de la même manière que leurs équivalents de directive $... en Pascal

#INCLUDE indique au compilateur de lire le contenu de "filename" avant de continuer à traiter les options dans le fichier
