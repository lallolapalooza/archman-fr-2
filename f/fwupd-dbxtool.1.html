NOM

dbxtool - modifier la liste de révocation dbx

SYNTAXE

dbxtool [CMD]

DESCRIPTION

Cette page de manuel documente brièvement la commande dbxtool.

dbxtool permet à un utilisateur d'opérer sur la liste de révocation dbx de l'UEFI. Cet outil peut être utilisé pour lister le contenu actuel de dbx ou pour le mettre à jour vers une version plus récente.

OPTIONS

La commande dbxtool accepte diverses options en fonction de l'action. Exécutez dbxtool --help pour la liste complète.

BOGUES
