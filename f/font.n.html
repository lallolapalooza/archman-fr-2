DESCRIPTIO

N

La commande font fournit plusieurs fonctionnalités pour traiter les polices, telles que la définition de polices nommées et l'inspection des attributs réels d'une police. La commande possède plusieurs formes différentes, déterminées par le premier argument. Les formes suivantes sont actuellement prises en charge

:
font actual font ?-displayof window? ?option? ?--? ?cha
r?
Renvoie des informations sur les attributs réels obtenus lorsque font est utilisé sur l'affichage de window ; les attributs réels obtenus peuvent différer des attributs demandés en raison de limitations dépendantes de la plateforme, telles que la disponibilité des familles de polices et des tailles de points. font est une description de police ; voir DESCRIPTIONS DE POLICE ci-dessous. Si l'argument window est omis, il vaut par défaut la fenêtre principale. Si option est spécifié, renvoie la valeur de cet attribut ; s'il est omis, la valeur de retour est une liste de tous les attributs et de leurs valeurs. Voir OPTIONS DE POLICE ci-dessous pour une liste des attributs possibles. Si l'argument char est fourni, il doit être un seul caractère. Les attributs de police renvoyés seront ceux de la police spécifique utilisée pour rendre ce caractère, qui sera différent de la police de base si la police de base ne contient pas le caractère donné. Si char peut être un tiret, il doit être précédé de -- pour le distinguer d'une option mal orthog
raphiée.
font configure fontname ?option? ?value option value .
..?
Interroge ou modifie les attributs souhaités pour la police nommée appelée fontname. Si aucune option n'est spécifiée, renvoie une liste décrivant toutes les options et leurs valeurs pour fontname. Si une seule option est spécifiée sans valeur, renvoie alors la valeur actuelle de cet attribut. Si une ou plusieurs pairesoption-valeur sont spécifiées, la commande modifie la police nommée donnée pour avoir les valeurs données ; dans ce cas, tous les widgets utilisant cette police se réafficheront en utilisant les nouveaux attributs de la police. Pour obtenir l'effet de la modification, utilisez font actual pour obtenir leur configuration et font create pour synthétiser une cop

Crée une nouvelle police nommée et renvoie son nom. fontname spécifie le nom de la police ; s'il est omis, Tk génère un nouveau nom de la forme fontx, où x est un entier. Il peut y avoir un nombre quelconque de pairesoption-valeur qui fournissent les attributs souhaités pour la nouvelle police nommée. Voir OPTIONS DE POLICE ci-dessous pour une liste des attributs
possibles.

Ces widgets continueront de s'afficher en utilisant les dernières valeurs connues pour la police nommée. Si une police nommée supprimée est recréée ultérieurement avec un autre appel à font create, les widgets utiliseront la nouvelle police nommée et se réafficheront en utilisant les nouveaux attributs de cette

DESCRIPTIONS DE

POLICE

Les formats suivants sont acceptés comme description de police partout où font est spécifié comme argument ci-dessus ; ces mêmes formes sont également autorisées lors de la spécification de l'option -font pour les

widgets.
[1] fontna
me
Le nom d'une police nommée, créée à l'aide de la commande font create. Lorsqu'un widget utilise une police nommée, il est garanti que cela ne causera jamais d'erreur, tant que la police nommée existe, quel que soit l'ensemble potentiellement invalide ou sans signification d'attributs que la police nommée possède. Si la police nommée ne peut pas être affichée avec exactement les attributs spécifiés, une autre police proche sera substituée
automatiquement.
[2] systemfo
nt
Le nom spécifique à la plateforme d'une police, interprété par le serveur graphique. Cela inclut également, sous X, un XLFD (voir [4]) pour lequel un seul caractère «* » a été utilisé pour omettre plus d'un champ au milieu du nom. Voir POLICES SPÉCIFIQUES À LA PLATEFORME pour une liste des polices
système.
[3] family ?size? ?style? ?style ..
.?
Une liste correctement formée dont le premier élément est la famille de polices souhaitée et dont le deuxième élément optionnel est la taille souhaitée. L'interprétation de l'attribut size suit les mêmes règles décrites pour -size dans OPTIONS DE POLICE ci-dessous. Tout argument optionnel supplémentaire suivant le size est un style de police. Les valeurs possibles pour les arguments style sont
les s
uivantes : 
normal	bold	roman	italic
underline	ov
ers
tri
ke
[4] Noms de polices X
(XLFD)
Un nom de police centré sur Unix de la forme -foundry-family-weight-slant-setwidth-addstyle-pixel-point-resx-resy-spacing-width-charset-encoding. Le caractère «* » peut être utilisé pour ignorer des champs individuels dont l'utilisateur ne se soucie pas. Il doit y avoir exactement un «* » pour chaque champ ignoré, sauf qu'un «* » à la fin du XLFD ignore tous les champs restants ; le XLFD valide le plus court est simplement «* », signifiant que tous les champs sont par défaut. Tout champ qui a été ignoré reçoit des valeurs par défaut. Par compatibilité, un XLFD choisit toujours une police de la taille de pixel spécifiée (et non de point) ; bien que cette interprétation ne soit pas strictement correcte, toutes les applications existantes utilisant des XLFDs supposaient qu'un « point » était en fait un pixel et s'afficheraient incorrectement (généralement plus grand) si la police de taille correcte était réellement
utilisée.
[5] option value ?option valu
e ...?
Une liste correctement formée de pairesoption-valeur qui spécifient les attributs souhaités de la police, dans le même format utilisé lors de la définition d'une police nommée ; voir OPTIONS DE POL
ICE ci-d
essous.

Lorsque la description de police font est utilisée, le système tente de parser la description selon chacune des cinq règles ci-dessus, dans l'ordrer spécifié. Les cas [1] et [2] doivent correspondre au nom d'une police nommée existante ou d'une police système. Les cas [3], [4] et [5] sont acceptés sur toutes les plateformes et la

police disponible la plus proche sera utilisée. Dans certaines situations, il peut ne pas être possible de trouver une police proche (par exemple, la famille de polices était une val
eur invalide) ; dans ce cas, une police par défaut dépendante du système est choisie. Si la description de la police ne correspond à aucun des motifs ci-dessus, une erreur est générée.

MÉTRIQUES DE LA

POLICE

Les options suivantes sont utilisées par la commande font metrics pour interroger les données spécifiques à la police déterminées lors de la création de la police. Ces propriétés concernent la police elle-même et non les caractères individuels dessinés avec cette police. Dans les définitions suivantes, la « ligne de base » d'une police est la ligne horizontale où le bas de la plupart des lettres s'aligne ; certaines lettres, comme le « g » minuscule, dépassent sous la ligne de

base.
-asce
nt
La quantité en pixels dont la lettre la plus haute dépasse au-dessus de la ligne de base de la police, plus tout espace vide supplémentaire ajouté par le concepteur de la
police.
-desce
nt
La plus grande quantité en pixels dont une lettre dépasse en dessous de la ligne de base de la police, plus tout espace vide supplémentaire ajouté par le concepteur de la
police.
-linespa
ce
Renvoie la distance verticale en pixels à laquelle deux lignes de texte utilisant la même police doivent être placées pour qu'aucun des caractères d'une ligne ne chevauche aucun des caractères de l'autre ligne. C'est généralement la somme de l'ascendante au-dessus de la ligne de base plus la descendante en dessous de la ligne de
base.
-fix
ed
Renvoie un indicateur booléen qui vaut «1 » si c'est une police à chasse fixe, où chaque caractère normal a la même largeur que tous les autres caractères, ou «0 » si c'est une police à chasse proportionnelle, où les caractères individuels ont des largeurs différentes
. Les largeurs des caractères de contrôle, des caractères d
e tabulation et des autres caractères non imprimables
ne sont pas prises en compte lors du calcul de cette valeur.

OPTIONS DE LA

POLICE

Les options suivantes sont prises en charge sur toutes les plateformes et sont utilisées lors de la construction d'une police nommée ou lors de la spécification d'une police en utilisant le style [5] comme ci-dessus

:
-family na
me
Le nom de la famille de polices, insensible à la casse. Tk garantit de prendre en charge les familles de polices nommées Courier (une police de « machine à écrire » à chasse fixe), Times (une police « de journal » à empattements), et Helvetica (une police « européenne » sans empattements). La famille de polices natives la plus proche sera automatiquement substituée lorsque l'une des familles de polices ci-dessus est utilisée. Le name peut aussi être le nom d'une famille de polices native, spécifique à la plateforme ; dans ce cas, elle fonctionnera comme souhaité sur une plateforme mais peut ne pas s'afficher correctement sur d'autres plateformes. Si la famille n'est pas spécifiée ou n'est pas reconnue, une police par défaut spécifique à la plateforme sera
choisie.
-size si
ze
La taille souhaitée de la police. Si l'argument size est un nombre positif, il est interprété comme une taille en points. Si size est un nombre négatif, sa valeur absolue est interprétée comme une taille en pixels. Si une police ne peut pas être affichée à la taille spécifiée, une taille proche sera choisie. Si size n'est pas spécifiée ou est égale à zéro, une taille p
ar défaut dépendante de la
plateforme sera choisie.

Les tailles devraient normalement être spécifiées en points afin que l'application reste de la même taille à l'écran, même lors du changement de résolution de l'écran ou du déplacement des scripts entre les plateformes. Cependant, la spécification en pixels est utile dans certaines circonstances, comme lorsqu'un texte doit s'aligner par rapport à un bitmap de taille fixe. La correspondance entre les points et les pixels est définie au démarrage de l'application, en fonction des propriétés du moniteur installé, mais elle peut être remplacée en appelant la commande t

k sca
ling.

ht
L'épaisseur nominale des caractères dans la police. La valeur normal spécifie une police de graisse normale, tandis que bold spécifie une police en gras. La graisse disponible la plus proche de celle spécifiée sera choisie. La graisse par défaut est norma
l.
-slant sla
nt
L'inclinaison des caractères de la police par rapport à la verticale. Les valeurs valides pour slant sont roman et italic. Une police romaine est l'apparence normale et droite d'une police, tandis qu'une police italique est inclinée d'un certain nombre de degrés par rapport à la verticale. L'inclinaison disponible la plus proche de celle spécifiée sera choisie. L'inclinaison par défaut est roma
n.

an

EXEMPL

E

Remplissez un widget texte avec de nombreux démonstrateurs de polices, un pour chaque famille de polices installée sur votre système

: 
pack [text .t -wrap none] -fill both -expand 1
set count 0
set tabwidth 0
foreach family [lsort -dictionary [font families]] {
    .t tag configure f[incr count] -font [list $family 10]
    .t insert end ${family}:\t {} \
            "This is a simple sampler\n" f$count
    set w [font measure [.t cget -font] ${family}:]
    if {$w + 5 > $tabwidth} {
        set tabwidth [expr {$w + 5}]
        .t configure -tabs $tabwidth
}
}
