fsck.exfat(8) Manuel du gestionnaire système fsck.exfat(8)

NOM

fsck.exfat - vérifie un système de fichiers exFAT

SYNTAXE

fsck.exfat [ -a ] [ -n ] [ -r ] [ -v ] [ -y ] [ -b ] [ -v ] périphérique
fsck.exfat -V

DESCRIPTION

fsck.exfat vérifie un système de fichiers exFAT et répare le système de fichiers en fonction des options passées. Les corruptions suivantes peuvent être réparées, voir l'option '-s'.

-
Le secteur de démarrage a des paramètres invalides. Si le secteur de démarrage de sauvegarde est valide, le secteur de démarrage est remplacé par celui-ci.
-
Le cluster est marqué comme libre mais appartenait à un fichier, ou vice versa. Le bitmap du cluster est correctement marqué.
-
La taille du fichier est anormalement grande compte tenu du nombre de clusters. La taille est modifiée.
-
La taille du fichier est anormalement petite compte tenu du nombre de clusters. Les clusters restants sont supprimés.
-
La chaîne de clusters d'un fichier contient un numéro de cluster invalide. Le numéro est changé en EOF, et la taille du fichier est également modifiée.
-
La chaîne de clusters d'un fichier contient une boucle. La boucle est rompue.
-
Des fichiers partagent le même cluster. Les chaînes de clusters des fichiers, à l'exception d'un, sont rompues.
-
Le numéro de cluster de départ est invalide. Le numéro de cluster et la taille du fichier sont changés à 0.
-
La valeur de checksum de l'ensemble d'entrées de répertoire est invalide. L'ensemble d'entrées de répertoire est supprimé.
-
Mauvaise valeur de hachage d'un nom de fichier. La valeur de hachage est correctement modifiée.
-
Les champs d'un ensemble d'entrées de répertoire ont des valeurs invalides. L'ensemble d'entrées de répertoire est supprimé.

OPTIONS

-a
Cette option fait la même chose que l'option -p. Elle est fournie uniquement pour des raisons de compatibilité ascendante ; il est suggéré d'utiliser l'option -p autant que possible.
-n
Vérifie le système de fichiers mais ne tente pas de le réparer.
-p
Répare le système de fichiers sans interaction de l'utilisateur si cela peut être fait sans risque.
-r
Répare le système de fichiers de manière interactive.
-s
Crée des fichiers dans /LOST+FOUND pour les clusters orphelins. Ces fichiers ont des clusters alloués mais n'appartiennent à aucun fichier lors de la réparation du système de fichiers. Les clusters inutilisés et contigus dans le bitmap sont alloués au même fichier.
-v
Affiche des informations de débogage détaillées lors de la vérification du système de fichiers exFAT.
-V
Affiche le numéro de version et quitte.
-y
Répare le système de fichiers en répondant oui à toutes les questions.
-b
Tente de réparer le système de fichiers même si le système de fichiers exFAT n'est pas trouvé.

EXEMPLES

Réparer un périphérique corrompu et créer des fichiers dans /LOST+FOUND, qui ont des clusters alloués mais n'appartiennent à aucun fichier lors de la réparation du périphérique.

$ fsck.exfat -p -s /dev/sda1
