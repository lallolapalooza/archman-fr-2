NOM

fwb_pf - Compilateur de politique pour le filtre de paquets OpenBSD "pf"

SYNTAXE

fwb_pf [-vVx] [-d wdir] [-o output.fw] [-i] -f data_file.xml nom_objet

DESCRIPTION

fwb_pf est un composant du compilateur de politique de pare-feu de Firewall Builder (voir fwbuilder(1)). Ce compilateur génère du code pour le filtre de paquets d'OpenBSD (pf). Le compilateur lit les définitions d'objets et la description du pare-feu à partir du fichier de données spécifié avec l'option "-f" et génère les fichiers de configuration pf et un script d'activation du pare-feu.

Tous les fichiers générés portent des noms qui commencent par le nom de l'objet de pare-feu. Le script d'activation du pare-feu a l'extension ".fw" et est un simple script shell qui vide la politique actuelle, charge les nouvelles règles de filtrage et de NAT, puis active pf. Le nom du fichier de configuration PF commence par le nom de l'objet de pare-feu, plus "-pf.conf". Le nom du fichier de configuration NAT commence également par le nom de l'objet de pare-feu, plus "-nat.conf". Par exemple, si l'objet de pare-feu a le nom "monparefeu", le compilateur créera trois fichiers : "monparefeu.fw", "monparefeu-pf.conf", "monparefeu-nat.conf".

Le fichier de données et le nom de l'objet de pare-feu doivent être spécifiés sur la ligne de commande. Les autres paramètres de la ligne de commande sont facultatifs.

OPTIONS

-f FICHIER
Spécifie le nom du fichier de données à traiter.
-o output.fw
Spécifie le nom du fichier de sortie
-d wdir
Spécifie le répertoire de travail. Le compilateur crée le script d'activation du pare-feu et les fichiers de configuration PF dans ce répertoire. Si ce paramètre est manquant, tous les fichiers seront placés dans le répertoire de travail actuel.
-v
Soyez verbeux : le compilateur affiche des messages diagnostiques lorsqu'il travaille.
-V
Affiche le numéro de version et quitte.
-i
Lorsque cette option est présente, le dernier argument de la ligne de commande est censé être l'identifiant de l'objet de pare-feu plutôt que son nom.
-x
Génère des informations de débogage pendant le travail. Cette option est destinée au débogage uniquement et peut produire de nombreux messages cryptiques.

NOTES

Le support de PF a été introduit dans la version 1.0.1 de Firewall Builder.

Fonctionnalités prises en charge :

o
les deux fichiers pf.conf et nat.conf sont générés
o
négation dans la politique et les règles NAT
o
regroupement dans les "from", "to" et les ports en utilisant la syntaxe '{' '}'
o
si la case "Scrub" est cochée dans la boîte de dialogue des options de règle, et que l'action de la règle est Accepter, le compilateur génère deux règles (presque) identiques : la première avec l'action 'scrub' et la seconde avec l'action 'pass quick'
o
l'inspection d'état dans une règle individuelle peut être désactivée dans la boîte de dialogue des options de règle. Par défaut, le compilateur ajoute "keep state" ou "modulate state" à chaque règle avec l'action 'pass'
o
la boîte de dialogue des options de règle propose un choix de réponses icmp ou tcp rst pour les règles avec l'action "Reject"
o
le compilateur ajoute le drapeau "allow-opts" si une correspondance sur les options ip est nécessaire
o
le compilateur peut générer des règles correspondant aux drapeaux TCP
o
le compilateur peut générer un script ajoutant des alias ip pour les règles NAT en utilisant des adresses qui n'appartiennent à aucune interface du pare-feu
o
le compilateur ajoute toujours la règle "block quick all" tout en bas du script pour assurer une politique "block all par défaut" même si la politique est vide.
o
plages d'adresses dans la politique et NAT

Fonctionnalités qui ne sont pas prises en charge (encore)

o
services personnalisés

Ce qui ne sera pas pris en charge (du moins pas de sitôt)

o
routage de politique
