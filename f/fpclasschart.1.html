fpclasschart(1) Générateur d'arbre de classes Free Pascal fpclasschart(1)

NOM

fpclasschart - Le générateur d'arbre de classes Free Pascal.

SYNOPIS

fpclasschart --input=cmdline --output=nom_fichier [--merge=nom_fichier] [--kind=objectkind] [--lang=langue] [--help]

Description

fpclasschart Crée un arbre de classes à partir d'une source Pascal

Utilisation

Vous pouvez appeler fpclasschart avec une ou plusieurs options.

Options

fpclasschart a plusieurs options, la plupart sont facultatives, les valeurs par défaut seront utilisées dans la plupart des cas.

--input=cmdline
Cette option indique à fpclasschart de générer un fichier d'arbre. La ligne de commande est la même que celle utilisée par le compilateur pour compiler le fichier source.
--output=nom_fichier
Cette option spécifie le nom du fichier généré descfile qui contient le graphique réel de l'arbre objet.
--merge=nom_fichier
Donne un chemin vers un fichier contenant déjà un arbre objet à fusionner.
--kind=objectkind
Spécifie le type d'objet. L'un des choix : object, class, interface.
--lang=langue
Définit la langue du fichier de sortie. Cela définira principalement les chaînes de caractères utilisées pour les en-têtes dans diverses parties des fichiers de documentation (par défaut, elles sont en anglais). Actuellement, les options valides sont :
de
Allemand.
fr
Français.
nl
Néerlandais.
--help
Écrit un message d'aide.
