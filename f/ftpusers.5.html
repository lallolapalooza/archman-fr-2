ftpusers(5) Manuel des formats de fichiers ftpusers(5)

NOM

ftpusers - liste des utilisateurs qui ne peuvent pas se connecter via le démon FTP

DESCRIPTION

Le fichier texte ftpusers contient une liste des utilisateurs qui ne peuvent pas se connecter en utilisant le démon du serveur File Transfer Protocol (FTP). Ce fichier est utilisé non seulement à des fins d'administration système, mais aussi pour améliorer la sécurité dans un environnement réseau TCP/IP.

Le fichier ftpusers contiendra généralement une liste des utilisateurs qui n'ont aucune raison d'utiliser ftp ou qui ont trop de privilèges pour être autorisés à se connecter via le démon du serveur FTP. Ces utilisateurs incluent généralement root, daemon, bin, uucp et news.

Si votre démon de serveur FTP n'utilise pas ftpusers, il est suggéré de lire sa documentation pour savoir comment bloquer l'accès à certains utilisateurs. Le démon FTP de Washington University (wuftpd) et le démon FTP Professionnel (proftpd) sont connus pour utiliser ftpusers.

Format

Le format de ftpusers est très simple. Il y a un nom de compte (ou nom d'utilisateur) par ligne. Les lignes commençant par un # sont ignorées.

FICHIERS

/etc/ftpusers

VOIR AUSSI

passwd(5), proftpd(8), wuftpd(8)
