NOM

fwupdtool - outil autonome de mise à jour du firmware

SYNTAXE

fwupdtool [CMD]

DESCRIPTION

Cet outil permet à un administrateur d'utiliser directement les plugins fwupd sans utiliser le processus de démon, ce qui peut être plus rapide ou plus facile à utiliser lors de la création ou du débogage de plugins spécifiques. Pour la plupart des utilisateurs finaux, fwupdmgr est un programme plus adapté à utiliser dans presque tous les cas.

De plus, fwupdtool peut être utilisé pour convertir le firmware à partir de divers formats différents, ou pour modifier les images contenues dans le fichier firmware conteneur. Par exemple, vous pouvez convertir du firmware DFU ou Intel HEX dans le format spécifique au vendeur.

OPTIONS

La commande fwupdtool prend diverses options en fonction de l'action. Exécutez fwupdtool --help pour la liste complète. Notez que certains échecs d'exécution peuvent être ignorés en utilisant --force.

STATUT DE SORTIE

Les commandes qui s'exécutent avec succès retourneront « 0 », avec un échec générique « 1 ».

Il existe également plusieurs autres codes de sortie utilisés : Un code de retour « 2 » est utilisé pour les commandes qui n'ont pas d'actions mais qui ont été exécutées avec succès, et « 3 » est utilisé lorsqu'une ressource n'a pas été trouvée.

BOGUES
