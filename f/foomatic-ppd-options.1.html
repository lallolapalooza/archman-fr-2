NOM

foomatic-ppd-options - afficher les options PPD

SYNTAXE

foomatic-ppd-options [-d=niveau_debug] [ fichiers_ppd ]

DESCRIPTION

Le programme foomatic-ppd-options lit les fichiers PPD spécifiés ou l'entrée standard et décode le fichier PPD pour produire une liste d'options. Il s'agit en réalité d'une version textuelle d'autres outils de configuration d'impression.

Le format de sortie consiste en un ensemble de lignes, chacune commençant par un mot-clé, suivi d'un ensemble d'options et de la valeur par défaut. Par exemple :

makemodel = Tektronix Phaser 350 Foomatic/Postscript (recommandé)
name=PageSize; default=Letter; options=Letter (US Letter), \
    A4 (A4), 11x17 (11x17), A3 (A3), A5 (A5), B5 (B5 \(JIS\)),...
name=PageRegion; default=Letter; options=Letter (US Letter), A4 (A4), ...

Chaque option commence par la balise name, suivie d'une valeur par défaut (le cas échéant), suivie de l'ensemble des options et d'un commentaire les décrivant. La ponctuation dans le commentaire est échappée.

Options

-dniveau_debug
Définit le niveau de débogage. 0 désactive les messages de débogage.
[ fichiers ]
La liste des fichiers PPD à lire pour les options. Un '-' provoque la lecture de l'entrée standard (STDIN).

CODE DE SORTIE

foomatic-ppd-options se termine avec un code de statut 0 en cas de succès, et non nul en cas d'erreur. Un message d'erreur est également imprimé sur la sortie d'erreur standard (STDERR).
