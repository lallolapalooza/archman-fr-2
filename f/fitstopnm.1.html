NOM

fitstopnm - convertir un fichier FITS en image PNM

SYNTAXE

fitstopnm [-image=N] [-scanmax] [-printmax] [-min=f] [-max=f] [-omaxval=N [FITSfile]

L'abréviation unique minimale de l'option est acceptable. Vous pouvez utiliser des doubles tirets au lieu de tirets simples pour désigner les options. Vous pouvez utiliser des espaces à la place du signe égal pour séparer un nom d'option de sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

fitstopnm lit un fichier FITS (Flexible Image Transport System) en entrée et produit une image PPM si le fichier FITS se compose de 3 plans d'image (NAXIS = 3 et NAXIS3 = 3), ou une image PGM si le fichier FITS se compose de 2 plans d'image (NAXIS = 2), ou si vous spécifiez l'option -image.

Le programme vous indique quel type d'image PNM il écrit.

OPTIONS

-image=N
Ceci concerne les fichiers FITS avec trois axes. L'hypothèse est que le troisième axe est pour plusieurs images, et cette option vous permet de sélectionner celle que vous voulez. -omaxval=N

Ceci est la valeur maximale que l'image PNM de sortie doit avoir.

Par défaut, la valeur maximale est la plus petite possible pour conserver toute la précision de l'entrée FITS. C'est-à-dire la différence entre la valeur d'échantillon la plus haute et la plus basse dans l'entrée. Si les valeurs vont de -5 à 100, par exemple, la valeur maximale par défaut serait 106 et chaque valeur d'échantillon PNM correspondrait à une valeur d'échantillon FITS.

Pour une entrée FITS avec des valeurs d'échantillon en virgule flottante, la précision est virtuellement illimitée, donc ce n'est pas possible. Dans ce cas, la valeur maximale par défaut est simplement 255.

Cette option est nouvelle dans Netpbm 10.39 (juin 2007). Avant cela, la valeur maximale de sortie est toujours la valeur par défaut.

-min=flottant
-max=flottant

Vous pouvez utiliser ces options pour remplacer les valeurs min et max lues dans l'en-tête FITS ou les données de l'image si l'en-tête n'a pas de mots-clés DATAMIN et DATAMAX.

-scanmax
Utilisez cette option pour forcer le programme à scanner les données même lorsque l'en-tête contient DATAMIN et DATAMAX.
-printmax
Avec cette option, le programme affiche simplement les valeurs min et max et se quitte sans effectuer son travail normal.

Ceci est destiné à être utilisé dans des programmes shell. Exemple :


    eval 'fitstopnm -printmax $filename | \
    awk {min = $1; max = $2} \
          END {print "min=" min; " max=" max}'

NOTES

Ordre des pixels

Vous devrez peut-être passer la sortie de fitstopnm à travers pamflip -topbottom. Voir pamtofits
