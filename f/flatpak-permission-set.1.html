NOM

flatpak-permission-set - Définir les permissions

SYNOPIS

flatpak permission-set [OPTION...] TABLE ID APP_ID [PERMISSION...]

DESCRIPTION

Définit les permissions d'une application dans une entrée du stockage de permissions. L'entrée est identifiée par TABLE et ID, l'application par APP_ID. Les chaînes PERMISSION doivent être dans un format adapté à la table.

Le stockage de permissions est utilisé par les portails. Chaque portail a généralement sa propre table dans le stockage de permissions, et le format des entrées de table est spécifique à chaque portail.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

--data=DATA

Associe DATA à l'entrée. Les données doivent être un GVariant sérialisé.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage d'OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak permission-set --data "{'always-ask':<true>}" desktop-used-apps text/plain org.mozilla.Firefox org.gnome.gedit 0 3
