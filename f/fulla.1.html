NOM

fulla - Corrige la distorsion de l'objectif, le vignettage et l'aberration chromatique

SYNTAXE

fulla [options] fichiers d'entrée

DESCRIPTION

Applique une correction du vignettage radial ou à champ plat, ainsi qu'une correction de la distorsion radiale géométrique et de l'aberration chromatique transversale.

fulla peut être utilisé pour corriger en lot un grand nombre de fichiers. Les coefficients de distorsion radiale peuvent être lus à partir d'une base de données d'objectifs.

La correction du vignettage est effectuée de la même manière que décrit dans la documentation des scripts nona, ou à partir d'une base de données d'objectifs. La correction du vignettage peut être basée sur un champ plat ou une mise à l'échelle radiale.

Correction du vignettage par division de champ plat :
I = I / c, c = champ plat / moyenne(champ plat)

Correction du vignettage radial :
I = I / c, c = a + b*r^2 + c*r^4 + d*r^6

La correction de la distorsion radiale est identique à celle implémentée par PanoTools :

r_nouveau = a*r^4 + b*r^3 + c*r^2 + d*r [1]

Étant donné que les aberrations chromatiques transversales (TCA) entraînent des objets différemment mis à l'échelle dans les canaux rouge, vert et bleu, elles peuvent être corrigées en mettant à l'échelle les canaux rouge et bleu de sorte qu'ils correspondent au canal vert. La plupart des applications, comme Photoshop ou Picture Window Pro, offrent une correction des TCA par mise à l'échelle linéaire. Ceci est égal à faire varier le paramètre d dans l'équation [1].

Voir http://hugin.sf.net/tutorials/tca pour une méthode de détermination de ces paramètres.

OPTIONS

--vert=db|a:b:c:d
Corrige le coefficient de distorsion radiale pour tous les canaux, (a, b, c, d). Spécifiez 'db' pour une recherche dans la base de données ou les 4 coefficients a:b:c:d
--bleu=db|a:b:c:d
Corrige les coefficients de distorsion radiale pour le canal bleu, (a, b, c, d). Ceci est appliqué par-dessus les coefficients de distorsion de --vert, utilisez pour la correction TCA. Spécifiez 'db' pour une recherche dans la base de données ou les 4 coefficients a:b:c:d
--rouge=db|a:b:c:d
Corrige les coefficients de distorsion radiale pour le canal rouge, (a, b, c, d). Ceci est appliqué par-dessus les coefficients de distorsion de --vert, utilisez pour la correction TCA. Spécifiez 'db' pour une recherche dans la base de données ou les 4 coefficients a:b:c:d
--fabricant-camera=Fabricant
Fabricant de l'appareil photo, pour la requête dans la base de données
--modele-camera=Appareil
Nom de l'appareil photo, pour la requête dans la base de données
--nom-objectif=Objectif
Nom de l'objectif, pour la requête dans la base de données
Spécifiez --fabricant-camera et --modele-camera pour les appareils photo à objectif fixe ou --nom-objectif pour les objectifs interchangeables.
--focale=50
Spécifie la longueur focale en mm, pour la requête dans la base de données
--ouverture=3.5
Spécifie l'ouverture pour la requête dans la base de données de données de vignettage
--ne-pas-remettre-a-l-echelle
Ne pas remettre à l'échelle l'image pour éviter les bordures noires.
--champ-plat=nomfichier
Correction du vignettage par division de champ plat I = I / c, c = champ-plat / moyenne(champ-plat)
--vignettage=db|a:b:c:d
Corrige le vignettage (par division). Spécifiez db pour une recherche dans la base de données ou les 4 coefficients a:b:c:d. I = I / ( a + b*r^2 + c*r^4 + d*r^6)
--lineaire
Effectue la correction du vignettage dans l'espace colorimétrique linéaire
--gamma=valeur
Gamma des données d'entrée. Utilisé pour la correction gamma avant et après la correction de champ plat
threads=n
Nombre de threads à utiliser
-h|--aide
Affiche l'aide
--sortie=nom
Définit le nom du fichier de sortie. Si plusieurs images sont données, le nom sera utilisé comme suffixe. (suffixe par défaut : _corr)
--compression=valeur
Compression des fichiers de sortie. Pour la sortie jpeg : 0-100. Pour la sortie tiff : PACKBITS, DEFLATE, LZW
--decalage=X:Y
Décalage horizontal et vertical
--verbeux
Mode verbeux
