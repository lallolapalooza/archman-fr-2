NOM

freeciv-ruledit - Éditeur de règles de jeu Freeciv

SYNTAXE

freeciv-ruledit [ -d|--debug niveau ] [ -F|--Fatal [ numéro_signal ] ] [ -h|--help ] [ -r|--ruleset règles ] [ -v|--version ]

DESCRIPTION

Cet outil peut être utilisé pour éditer les règles de jeu de freeciv.

OPTIONS

Toutes les options ont une forme courte (un trait d'union et une lettre) et une forme longue (deux traits d'union et un mot complet) ; leurs effets sont identiques.

-d niveau, --debug niveau
Définit la quantité d'informations de débogage à enregistrer. Les valeurs acceptables pour le niveau sont :

fatal pour les messages fatals uniquement.

error pour les messages fatals et d'erreur.

warning pour les messages fatals, d'erreur et d'avertissement.

normal pour les messages fatals, d'erreur, d'avertissement et normaux (par défaut).

verbose pour les messages fatals, d'erreur, d'avertissement, normaux et détaillés.

-F [ numéro_signal ], --Fatal [ numéro_signal ]
Lève un signal personnalisé en cas d'échec d'une assertion. Si numéro_signal n'est pas spécifié, alors le signal ABRT sera utilisé.
-h, --help
Affiche un bref résumé des options standard de la ligne de commande.
-r règles, --ruleset règles
Charge l'ensemble de règles spécifié comme point de départ pour l'édition.
-v, --version
Affiche le numéro de version et quitte.

SIGNIFICATION DES BOGUES

Signalez les bugs à "https://redmine.freeciv.org/projects/freeciv"
