NOM

flatpak document-export - Exporter un fichier vers une application isolée

SYNTAXE

flatpak document-export [OPTION...] FICHIER

DESCRIPTION

Crée un identifiant de document pour un fichier local qui peut être exposé à des applications isolées, leur permettant d'accéder à des fichiers qu'elles ne verraient pas autrement. Les fichiers exportés sont exposés dans un système de fichiers fuse sur /run/user/$UID/doc/.

Cette commande vous permet également de modifier les permissions par application des documents, accordant ou révoquant l'accès au fichier de manière individuelle pour chaque application.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

-u, --unique

Ne pas réutiliser un identifiant de document existant pour le fichier. Cela permet de supprimer le document en toute sécurité une fois que vous avez terminé.

-t, --transient

Le document n'existera que pendant la durée de la session. Ceci est utile pour les autorisations temporaires.

-n, --noexist

Ne pas exiger que le fichier existe déjà.

-a, --app=APPID

Accorde l'accès en lecture à l'application spécifiée. Les options --allow et --forbid peuvent être utilisées pour accorder ou révoquer des privilèges supplémentaires. Cette option peut être utilisée plusieurs fois.

-r, --allow-read

Accorde l'accès en lecture aux applications spécifiées avec --app. Ceci est défini sur TRUE par défaut.

--forbid-read

Révoque l'accès en lecture pour les applications spécifiées avec --app.

-w, --allow-write

Accorde l'accès en écriture aux applications spécifiées avec --app.

--forbid-write

Révoque l'accès en écriture pour les applications spécifiées avec --app.

-d, --allow-delete

Accorde la capacité de supprimer le document du portail de documents aux applications spécifiées avec --app.

--forbid-delete

Révoque la capacité de supprimer le document du portail de documents pour les applications spécifiées avec --app.

-g, --allow-grant-permission

Accorde la capacité d'accorder des permissions supplémentaires aux applications spécifiées avec --app.

--forbid-grant-permission

Révoque la capacité d'accorder des permissions supplémentaires pour les applications spécifiées avec --app.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak document-export --app=org.gnome.gedit ~/test.txt

/run/user/1000/doc/e52f9c6a/test.txt
