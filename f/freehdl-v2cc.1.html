FreeHDL-V2CC(1) Commandes utilisateur FreeHDL-V2CC(1)

NOM

FreeHDL-V2CC - Convertisseur VHDL vers C++.

SYNTAXE

freehdl-v2cc [OPTION] ... [FICHIER] ...

DESCRIPTION

FreeHDL est une suite d'analyseur/compilateur/simulateur pour le langage de description matérielle VHDL. Les fichiers VHDL'93 ainsi que VHDL'87 sont pris en charge.

FreeHDL-V2CC traduit les FICHIERs sources VHDL d'origine en C++.

OPTIONS

-o FICHIER
Écrit le code C++ généré dans FICHIER.
-n
Exécution à blanc (dry run).
-R
Émet le code des registres.
-v
Active la verbosité.
-g
Émet le code de débogage.
-D
Émet le code CDFG.
-l LIBRAIRIE
Utilise LIBRAIRIE comme bibliothèque WORK, par défaut le répertoire de la bibliothèque ".".
--visibilite-composant-relachee
Autorise les liaisons par défaut invisibles depuis WORK.
--depend FICHIER
Écrit les informations de dépendance dans FICHIER.
-m FICHIER
Émet le code C++ du fichier principal main() dans FICHIER.
-L BIBLIO_VHDL
Chemin vers le répertoire racine de la bibliothèque VHDL. Dans ce répertoire, le compilateur recherche un fichier nommé v2cc.libs. Le fichier de mappage v2cc.libs traduit les noms des unités de bibliothèque en répertoires. Notez que plusieurs BIBLIO_VHDL peuvent être fournies.

VARIABLES ENVIRONNEMENT

CHEMIN_BIBLIOTHEQUE_V2CC
La variable CHEMIN_BIBLIOTHEQUE_V2CC est constituée de noms de fichiers séparés par des ":". En plus de la variable d'environnement, vous pouvez utiliser l'option de ligne de commande "-L libdir" avec v2cc. Les répertoires spécifiés avec "-L" sont ajoutés devant ceux spécifiés par CHEMIN_BIBLIOTHEQUE_V2CC. Dans le chemin final de la bibliothèque, ils apparaissent dans le même ordre que sur la ligne de commande.
