FREECIV(6) Commandes utilisateur FREECIV(6)

NOM

freeciv-manual - Générer le manuel HTML ou wiki pour freeciv-server(6)

SYNTAXE

freeciv-manual [option ...]

-d, --debug NIVEAU
Définir le niveau de journal de débogage (l'un de f,e,w,n,v)
-h, --help
Afficher un résumé des options
-l, --log FICHIER
Utiliser FICHIER comme fichier journal

-r, --ruleset REGLE Générer le manuel pour REGLE

-v, --version
Afficher le numéro de version
-w, --wiki
Écrire le manuel au format wiki

DESCRIPTION

freeciv-manual génère un sous-ensemble de la documentation pour freeciv-server(6) et les règles du jeu d'un ensemble de règles sélectionné qu'il exécute. Actuellement, il génère 8 fichiers :

manual1.html
Options du serveur
manual2.html
Commandes du serveur
manual3.html
Terrain
manual4.html
Bâtiments
manual5.html
Merveilles
manual6.html
Gouvernements
manual7.html
Types d'unités
manual8.html
Technologies

BOGUES

Cet outil est actuellement surtout utile aux mainteneurs de Freeciv, comme point de départ pour les pages sur le wiki principal de Freeciv ; il n'est pas très utile aux utilisateurs finaux.

Les lacunes connues incluent le fait qu'il manque de nombreuses fonctionnalités des ensembles de règles.

SIGNALEMENT DES BOGUES

Signalez les bogues sur "https://redmine.freeciv.org/projects/freeciv" (mais voir les réserves ci-dessus).

VOIR AUSSI

freeciv-server(6) et le Manuel du Client sur la page d'accueil de Freeciv.
