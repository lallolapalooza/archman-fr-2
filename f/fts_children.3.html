NOM

fts, fts_open, fts_read, fts_children, fts_set, fts_close - parcourir une hiérarchie de fichiers

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <sys/types.h>
#include <sys/stat.h>
#include <fts.h>
FTS *fts_open(char *const *path_argv, int options,
              typeof(int (const FTSENT **, const FTSENT **))
                  *_Nullable compar);
FTSENT *fts_read(FTS *ftsp);
FTSENT *fts_children(FTS *ftsp, int instr);
int fts_set(FTS *ftsp, FTSENT *f, int instr);
int fts_close(FTS *ftsp);

DESCRIPTION

Les fonctions fts sont fournies pour parcourir les hiérarchies de fichiers. Un aperçu simple est que la fonction fts_open() renvoie une « poignée » (de type FTS *) qui fait référence à un flux de hiérarchie de fichiers. Cette poignée est ensuite fournie aux autres fonctions fts. La fonction fts_read() renvoie un pointeur vers une structure décrivant l'un des fichiers de la hiérarchie de fichiers. La fonction fts_children() renvoie un pointeur vers une liste chaînée de structures, chacune décrivant l'un des fichiers contenus dans un répertoire de la hiérarchie.

En général, les répertoires sont visités deux fois discernables ; en préordre (avant que l'un de leurs descendants ne soit visité) et en postordre (après que tous leurs descendants aient été visités). Les fichiers sont visités une fois. Il est possible de parcourir la hiérarchie « logiquement » (en visitant les fichiers vers lesquels les liens symboliques pointent) ou physiquement (en visitant les liens symboliques eux-mêmes), d'ordonner le parcours de la hiérarchie ou d'élaguer et/ou de revisiter des portions de la hiérarchie.

Deux structures (et types associés) sont définies dans le fichier d'en-tête <fts.h>. Le premier type est FTS, la structure qui représente la hiérarchie de fichiers elle-même. Le second type est FTSENT, la structure qui représente un fichier dans la hiérarchie de fichiers. Normalement, une structure FTSENT est renvoyée pour chaque fichier de la hiérarchie. Dans cette page de manuel, « fichier » et « structure FTSENT » sont généralement interchangeables.

La structure FTSENT contient des champs décrivant un fichier. La structure contient au moins les champs suivants (il y a des champs supplémentaires qui devraient être considérés comme privés à l'implémentation) :


typedef struct _ftsent {
    unsigned short  fts_info;     /* indicateurs pour la structure FTSENT */
    char           *fts_accpath;  /* chemin d'accès */
    char           *fts_path;     /* chemin racine */
    short           fts_pathlen;  /* strlen(fts_path) +
                                     strlen(fts_name) */
    char           *fts_name;     /* nom de fichier */
    short           fts_namelen;  /* strlen(fts_name) */
    short           fts_level;    /* profondeur (-1 à N) */
    int             fts_errno;    /* errno du fichier */
    long            fts_number;   /* valeur numérique locale */
    void           *fts_pointer;  /* valeur d'adresse locale */
    struct _ftsent *fts_parent;   /* répertoire parent */
    struct _ftsent *fts_link;     /* prochaine structure de fichier */
    struct _ftsent *fts_cycle;    /* structure de cycle */
    struct stat    *fts_statp;    /* informations de [l]stat(2) */
} FTSENT;

Ces champs sont définis comme suit :

fts_info
L'une des valeurs suivantes décrivant la structure FTSENT renvoyée et le fichier qu'elle représente. À l'exception des répertoires sans erreur (FTS_D), toutes ces entrées sont terminales, c'est-à-dire qu'elles ne seront pas revues, ni aucun de leurs descendants ne sera revu.
FTS_D
Un répertoire visité en préordre.
FTS_DC
Un répertoire qui provoque un cycle dans l'arbre. (Le champ fts_cycle de la structure FTSENT sera également rempli.)
FTS_DEFAULT
Toute structure FTSENT représentant un type de fichier non explicitement décrit par l'une des autres valeurs fts_info.
FTS_DNR
Un répertoire qui ne peut pas être lu. Il s'agit d'un retour d'erreur, et le champ fts_errno sera défini pour indiquer la cause de l'erreur.
FTS_DOT
Un fichier nommé « . » ou « .. » qui n'a pas été spécifié comme nom de fichier à fts_open() (voir FTS_SEEDOT).
FTS_DP
Un répertoire visité en postordre. Le contenu de la structure FTSENT sera inchangé par rapport au moment où elle a été renvoyée en préordre, c'est-à-dire avec le champ fts_info défini à FTS_D.
FTS_ERR
Il s'agit d'un retour d'erreur, et le champ fts_errno sera défini pour indiquer la cause de l'erreur.
FTS_F
Un fichier régulier.
FTS_NS
Un fichier pour lequel aucune information [l]stat(2) n'était disponible. Le contenu du champ fts_statp est indéfini. Il s'agit d'un retour d'erreur, et le champ fts_errno sera défini pour indiquer la cause de l'erreur.
FTS_NSOK
Un fichier pour lequel aucune information [l]stat(2) n'a été demandée. Le contenu du champ fts_statp est indéfini.
FTS_SL
Un lien symbolique.
FTS_SLNONE
Un lien symbolique avec une cible inexistante. Le contenu du champ fts_statp fait référence aux informations de caractéristiques du fichier pour le lien symbolique lui-même.
fts_accpath
Un chemin pour accéder au fichier depuis le répertoire courant.
fts_path
Le chemin du fichier par rapport à la racine du parcours. Ce chemin contient le chemin spécifié à fts_open() comme préfixe.
fts_pathlen
La somme des longueurs des chaînes référencées par fts_path et fts_name.
fts_name
Le nom du fichier.
fts_namelen
La longueur de la chaîne référencée par fts_name.
fts_level
La profondeur du parcours, numérotée de -1 à N, où ce fichier a été trouvé. La structure FTSENT représentant le parent du point de départ (ou racine) du parcours est numérotée -1, et la structure FTSENT pour la racine elle-même est numérotée 0.
fts_errno
Si fts_children() ou fts_read() renvoie une structure FTSENT dont le champ fts_info est défini à FTS_DNR, FTS_ERR, ou FTS_NS, le champ fts_errno contient le numéro d'erreur (c'est-à-dire la valeur errno) spécifiant l'erreur. Sinon, le contenu du champ fts_errno est indéfini.
fts_number
Ce champ est fourni pour l'utilisation par le programme applicatif et n'est pas modifié par les fonctions fts. Il est initialisé à 0.
fts_pointer
Ce champ est fourni pour l'utilisation par le programme applicatif et n'est pas modifié par les fonctions fts. Il est initialisé à NULL.
fts_parent
Un pointeur vers la structure FTSENT faisant référence au fichier dans la hiérarchie immédiatement au-dessus du fichier courant, c'est-à-dire le répertoire dont ce fichier est membre. Une structure parente pour le point d'entrée initial est également fournie, cependant, seuls les champs fts_level, fts_number, et fts_pointer sont garantis d'être remplis pour le parent.
