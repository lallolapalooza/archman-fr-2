NOM

form_field_attributes - contrôle des couleurs et attributs des champs de formulaire

SYNTAXE

#include <form.h>
int set_field_fore(FIELD *field, chtype attr);
chtype field_fore(const FIELD *field);
int set_field_back(FIELD *field, chtype attr);
chtype field_back(const FIELD *field);
int set_field_pad(FIELD *field, int pad);
int field_pad(const FIELD *field);

DESCRIPTION

La fonction set_field_fore définit l'attribut de premier plan du field. C'est la mise en évidence utilisée pour afficher le contenu du champ. La fonction field_fore retourne l'attribut de premier plan. Par défaut, il s'agit de A_STANDOUT.

La fonction set_field_back définit l'attribut d'arrière-plan du form. C'est la mise en évidence utilisée pour afficher les champs d'étendue du formulaire. La fonction field_back retourne l'attribut d'arrière-plan. Par défaut, il s'agit de A_NORMAL.

La fonction set_field_pad définit le caractère utilisé pour remplir le champ. La fonction field_pad retourne le caractère de remplissage du formulaire donné. Par défaut, il s'agit d'un espace.

VALEUR DE RETOUR

Ces routines retournent l'une des valeurs suivantes :

E_OK
La routine a réussi.
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).

PORTABILITÉ

Ces routines émulent la bibliothèque de formulaires System V. Elles n'étaient pas prises en charge sur les versions 7 ou BSD.
