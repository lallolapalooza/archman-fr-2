NOM

flatpak-spawn - Exécute des commandes dans un bac à sable

SYNTAXE

flatpak-spawn [OPTION...] COMMANDE [ARGUMENT...]

DESCRIPTION

Contrairement aux autres commandes flatpak, flatpak-spawn est disponible pour les applications à l'intérieur du bac à sable. Il exécute COMMANDE en dehors du bac à sable : soit dans un autre bac à sable, soit sur l'hôte.

Lorsqu'il est appelé sans --host, flatpak-spawn utilise le portail Flatpak pour créer une copie du bac à sable à partir duquel il a été appelé, en utilisant éventuellement des permissions plus restrictives et éventuellement la dernière version de l'application et du runtime (voir --latest-version).

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

-v, --verbose

Affiche les informations de débogage

--forward-fd=FD

Transmet un descripteur de fichier

--clear-env

Exécute avec un environnement propre

--watch-bus

Fait en sorte que la commande lancée se termine si l'appelant disparaît du bus de session

--env=VAR=VALEUR

Définit une variable d'environnement

--latest-version

Utilise la dernière version des références utilisées pour configurer le bac à sable

--no-network

Exécute sans accès réseau

--sandbox

Exécute entièrement en bac à sable. Voir la documentation de l'option --sandbox dans flatpak-run(1)

Voir les options --sandbox-expose et --sandbox-expose-ro pour un accès sélectif aux fichiers.

--sandbox-expose=NOM

Expose un accès en lecture/écriture à un fichier dans le bac à sable.

Notez que les chemins absolus ou les sous-répertoires ne sont pas autorisés. Les fichiers doivent se trouver dans le sous-répertoire sandbox du répertoire d'instance (c'est-à-dire ~/.var/app/$ID_APP/sandbox).

Cette option est utile en combinaison avec --sandbox (sinon le répertoire d'instance est accessible de toute façon).

--sandbox-expose-ro=NOM

Expose un accès en lecture seule à un fichier dans le bac à sable.

Notez que les chemins absolus ou les sous-répertoires ne sont pas autorisés. Les fichiers doivent se trouver dans le sous-répertoire sandbox du répertoire d'instance (c'est-à-dire ~/.var/app/$ID_APP/sandbox).

Cette option est utile en combinaison avec --sandbox (sinon le répertoire d'instance est accessible de toute façon).

--host

Exécute la commande sans bac à sable sur l'hôte. Cela nécessite un accès à l'interface D-Bus org.freedesktop.Flatpak.

--directory=DIR

Le répertoire de travail dans lequel exécuter la commande.

Notez que le répertoire spécifié doit exister dans le bac à sable ou, lorsqu'il est utilisé en conjonction avec --host, sur l'hôte.

EXEMPLES

$ flatpak-spawn ls /var/run
