FLATPAK PERMISSION-(1) flatpak permission-remove FLATPAK PERMISSION-(1)

NOM

flatpak-permission-remove - Supprimer des permissions

SYNTAXE

flatpak permission-remove [OPTION...] TABLE ID [APP_ID]

DESCRIPTION

Supprime une entrée pour l'objet dont l'identifiant est ID du tableau de permissions TABLE. L'ID doit être dans un format approprié pour le tableau. Si APP_ID est spécifié, seule l'entrée pour cette application est supprimée.

Le magasin de permissions est utilisé par les portails. Chaque portail a généralement son propre tableau dans le magasin de permissions, et le format des entrées du tableau est spécifique à chaque portail.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Afficher les options d'aide et quitter.

-v, --verbose

Afficher des informations de débogage pendant le traitement de la commande.

--ostree-verbose

Afficher des informations de débogage OSTree pendant le traitement de la commande.
