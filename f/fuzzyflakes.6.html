NOM

fuzzyflakes - flocons de neige/formes de fleurs qui tombent

SYNTAXE

fuzzyflakes [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--mono] [--install] [--visual visuel] [--delay usecs] [--speed int] [--arms int] [--thickness int] [--bthickness int] [--radius int] [--layers int] [--density int] [--no-db] (-color chaîne) (-random-colors) [--fps]

DESCRIPTION

Le programme fuzzyflakes dessine des formes de flocons de neige/fleurs aux couleurs pastel qui tombent. Inspiré par le générique de l'anime "Azumanga Daioh".

OPTIONS

fuzzyflakes accepte les options suivantes :

--window
Dessine sur une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id numéro
Dessine sur la fenêtre spécifiée.
--mono
Si sur un écran couleur, fait comme si l'on était sur un écran monochrome.
--install
Installe une carte de couleurs privée pour la fenêtre.
--visual visuel
Spécifie quel visuel utiliser. Les valeurs valides sont le nom d'une classe de visuel, ou le numéro d'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--delay usecs
Le délai entre les étapes de l'animation, en microsecondes. Défaut : 250000.
--speed int
La vitesse, de 1 à 50. Défaut : 10.
--arms int
Le nombre de branches sur les flocons ; défaut : 5.
--thickness int
L'épaisseur des lignes ; défaut : 10 pixels.
--bthickness int
L'épaisseur des bordures ; défaut : 3 pixels.
--radius int
Le rayon des objets ; défaut : 20 pixels.
--layers int
Le nombre de couches d'objets ; défaut : 3.
--density int
Défaut : 5.
--no-db
Désactive le double buffer.
--color chaîne
La couleur de base pour le schéma de couleurs. Saisir comme un triplet hexadécimal avec ou sans le '#' initial. Par ex. fa4563 et #43cd12 sont tous deux acceptables. Si la saturation de votre couleur est trop faible (<0.03), le générateur de couleurs aléatoires s'activera. La couleur par défaut est #efbea5
--random-colors
Active la génération de couleurs aléatoires. Elle est désactivée par défaut. Elle écrase tout ce qui vient de -color
--fps
Affiche le taux d'images par seconde actuel et la charge CPU.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.
