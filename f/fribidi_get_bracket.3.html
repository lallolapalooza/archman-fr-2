NOM

fribidi_get_bracket - obtenir le caractère entre crochets

SYNTAXE

#include <../fribidi/lib/fribidi.h>

FriBidiBracketType fribidi_get_bracket(FriBidiChar ch);

PARAMETRES

FriBidiChar ch
Caractère d'entrée.

DESCRIPTION

Cette fonction trouve l'équivalent entre crochets d'un caractère tel que défini dans le fichier BidiBrackets.txt de la base de données des caractères Unicode disponible sur http://www.unicode.org/Public/UNIDATA/BidiBrackets.txt.

Si le caractère d'entrée est déclaré comme un caractère entre crochets dans la norme Unicode et possède un équivalent entre crochets. Le caractère entre crochets correspondant est mis dans la sortie, sinon le caractère d'entrée lui-même est mis.

VALEUR DE RETOUR

Le type de crochet du caractère. Utilisez le macro FRIBIDI_IS_BRACKET(FriBidiBracketType) pour tester si c'est une propriété valide.
