NOM

flatpak-document-info - Afficher des informations sur les fichiers exportés

SYNTAXE

flatpak document-info [OPTION...] FICHIER

DESCRIPTION

Affiche des informations sur un fichier exporté, telles que l'identifiant du document, le chemin fuse, l'emplacement d'origine dans le système de fichiers et les autorisations par application.

FICHIER peut être un fichier dans le système de fichiers fuse à l'adresse /run/user/$UID/doc/, ou un fichier n'importe où ailleurs.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Afficher les options d'aide et quitter.

-v, --verbose

Afficher des informations de débogage pendant le traitement de la commande.

--ostree-verbose

Afficher des informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak document-info ~/Sources/gtk/gail-3.0.pc

id: dd32c34a
path: /run/user/1000/doc/dd32c34a/gail-3.0.pc
origin: /home/mclasen/Sources/gtk/gail-3.0.pc
permissions:
        org.gnome.gedit read, write
