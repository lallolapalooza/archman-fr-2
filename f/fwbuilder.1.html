NOM

fwbuilder - Outil de configuration de pare-feu multiplateforme

SYNTAXE

/usr/bin/fwbuilder [-ffichier.fwb] [-d] [-h] [-ofichier] [-Pnom_objet] [-r] [-v]

DESCRIPTION

fwbuilder est le composant d'interface graphique utilisateur (GUI) de Firewall Builder.

Firewall Builder est composé d'une interface graphique et d'un ensemble de compilateurs de politiques pour diverses plateformes de pare-feu. Il aide les utilisateurs à maintenir une base de données d'objets et permet l'édition des politiques à l'aide d'opérations simples de glisser-déposer. L'interface graphique génère la description du pare-feu sous la forme d'un fichier XML, que les compilateurs interprètent ensuite pour générer du code spécifique à la plateforme. Plusieurs algorithmes sont fournis pour la découverte automatisée d'objets réseau et l'importation en masse de données. L'interface graphique et les compilateurs de politiques sont complètement indépendants, ce qui permet un modèle abstrait cohérent et la même interface graphique pour différentes plateformes de pare-feu.

Firewall Builder prend en charge les pare-feux basés sur iptables (noyau Linux 2.4.x et 2.6.x, voir fwb_ipt(1)), ipfilter (variété de plateformes dont *BSD, Solaris et autres, voir fwb_ipf(1)), pf (OpenBSD et FreeBSD, voir fwb_pf(1)), ipfw (FreeBSD et autres), Cisco PIX (v6.x et 7.x) et les listes de contrôle d'accès étendues Cisco IOS.

OPTIONS

-f FICHIER
Spécifie le nom du fichier à charger au démarrage du programme.
-r
Lorsque cette option de ligne de commande est donnée en combinaison avec -f fichier, le programme ouvre automatiquement la révision principale RCS du fichier si le fichier est en RCS. Si le fichier n'est pas en RCS, cette option ne fait rien et le fichier est ouvert comme d'habitude.
-d
Active le mode de débogage. Notez que dans ce mode, le programme génère beaucoup de sortie sur la sortie standard. Ceci est utilisé pour le débogage.
-h
Affiche un bref message d'aide
-o fichier
Spécifie le nom du fichier pour la sortie imprimée, voir l'option "-P".
-P nom_objet
Imprime les règles et les objets pour l'objet de pare-feu "nom_objet" et quitte immédiatement. Le programme ne passe pas en mode interactif. La sortie imprimée sera placée dans le fichier spécifié avec l'option "-o". Si le nom de fichier n'est pas donné avec l'option "-o", la sortie imprimée est stockée dans le fichier "print.pdf" dans le répertoire courant.
