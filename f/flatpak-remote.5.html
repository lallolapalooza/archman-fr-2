NOM

flatpak-remote - Configuration d'un dépôt distant

DESCRIPTION

Flatpak stocke les informations sur les dépôts distants configurés pour un emplacement d'installation dans $installation/repo/config. Par exemple, les dépôts pour l'installation globale par défaut se trouvent dans $prefix/var/lib/flatpak/repo/config, et les dépôts pour l'installation par utilisateur se trouvent dans $HOME/.local/share/flatpak/repo/config.

Normalement, il n'est pas nécessaire de modifier directement les fichiers de configuration des dépôts distants ; la commande flatpak remote-modify doit être utilisée pour modifier les propriétés des dépôts distants.

Les dépôts distants globaux peuvent être préconfigurés de manière statique en plaçant des fichiers flatpakrepo(5) dans /usr/share/flatpak/remotes.d/ et /etc/flatpak/remotes.d/. Si un fichier portant le même nom existe dans les deux répertoires, le fichier situé dans /etc aura la priorité.

FORMAT DU FICHIER

Le format du fichier de configuration des dépôts distants utilise le même format de fichier .ini que celui utilisé pour les fichiers d'unité systemd ou les fichiers .desktop d'application.

[remote ...]

Toute la configuration du dépôt distant portant le nom NAME est contenue dans le groupe [remote "NAME"].

Les clés suivantes sont reconnues par OSTree, entre autres :

url (chaîne de caractères)

L'URL du dépôt distant. Une URL de la forme oci+https:// ou oci+http:// est une extension Flatpak qui indique que le dépôt distant n'est pas un dépôt ostree, mais plutôt une URL vers un index d'images OCI stockées dans un registre d'images de conteneurs.

Pour les dépôts OCI, les certificats client et CA sont lus à partir de /etc/containers/certs.d et ~/.config/containers/certs.d comme documenté dans containers-certs.d(5).

gpg-verify (booléen)

Indique s'il faut utiliser la vérification GPG pour le contenu de ce dépôt distant.

gpg-verify-summary (booléen)

Indique s'il faut utiliser la vérification GPG pour le résumé de ce dépôt distant.

Ceci est ignoré si collection-id est défini, car les références sont vérifiées dans les métadonnées de commit dans ce cas. L'activation de gpg-verify-summary romprait la distribution pair à pair des références.

collection-id (chaîne de caractères)

L'identifiant unique global du dépôt de collection en amont, pour permettre le regroupement des miroirs.

Toutes les clés spécifiques à Flatpak portent le préfixe xa. :

xa.disable (booléen)

Indique si le dépôt distant est désactivé. Par défaut, false.

xa.prio (entier)

La priorité du dépôt distant. Elle est utilisée lors de la liste des dépôts distants et lors de la recherche du runtime nécessaire à une application. Le dépôt distant fournissant l'application est recherché pour son runtime avant les autres ayant une priorité égale. Par défaut, 1.

xa.noenumerate (booléen)

Indique si ce dépôt distant doit être ignoré lors de la présentation des applications/runtimes disponibles, ou lors de la recherche d'une dépendance de runtime. Par défaut, false.

xa.nodeps (booléen)

Indique si ce dépôt distant doit être exclu lors de la recherche des dépendances. Par défaut, false.

xa.title (chaîne de caractères)

Un titre facultatif à utiliser lors de la présentation de ce dépôt distant dans une interface utilisateur.

xa.title-is-set (booléen)

Cette clé est définie à true si xa.title a été explicitement défini.

xa.comment (chaîne de caractères)

Un commentaire facultatif sur une seule ligne à utiliser lors de la présentation de ce dépôt distant dans une interface utilisateur.

xa.comment-is-set (booléen)

Cette clé est définie à true si xa.comment a été explicitement défini.

xa.description (chaîne de caractères)

Un texte facultatif de plusieurs paragraphes à utiliser lors de la présentation de ce dépôt distant dans une interface utilisateur.

xa.description-is-set (booléen)

Cette clé est définie à true si xa.description a été explicitement défini.

xa.homepage (chaîne de caractères)

Une URL facultative pointant vers un site Web pour ce dépôt à utiliser lors de la présentation de ce dépôt distant dans une interface utilisateur.

xa.homepage-is-set (booléen)

Cette clé est définie à true si xa.homepage a été explicitement défini.

xa.icon (chaîne de caractères)

Une URL facultative pointant vers une icône pour ce dépôt à utiliser lors de la présentation de ce dépôt distant dans une interface utilisateur.

xa.icon-is-set (booléen)

Cette clé est définie à true si xa.icon a été explicitement défini.

xa.default-branch (chaîne de caractères)

La branche par défaut à utiliser lors de l'installation à partir de ce dépôt distant.

xa.default-branch-is-set (booléen)

Cette clé est définie à true si xa.default-branch a été explicitement défini.

xa.main-ref (chaîne de caractères)

La référence principale servie par ce dépôt distant. Elle est utilisée pour les dépôts d'origine des applications installées via un fichier flatpakref.

EXEMPLES

[remote "gnome-nightly-apps"]
gpg-verify=true
gpg-verify-summary=true
url=https://sdk.gnome.org/nightly/repo-apps/
xa.title=GNOME Applications
[remote "flathub"]
gpg-verify=true
gpg-verify-summary=false
collection-id=org.flathub.Stable
url=https://dl.flathub.org/repo/
xa.title=Flathub
