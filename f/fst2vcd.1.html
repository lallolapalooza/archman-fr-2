FST2VCD(1) Conversion de type de fichier FST2VCD(1)

NOM

fst2vcd - Convertit les fichiers FST en VCD

SYNTAXE

fst2vcd [option]... [FICHIER_FST]

DESCRIPTION

Convertit les fichiers FST en fichiers VCD. Si aucun nom de fichier de sortie n'est spécifié, le fichier VCD est émis sur la sortie standard.

OPTIONS

-f,--fstname <nom_fichier>
Spécifie le nom du fichier d'entrée FST.
-o,--output <nom_fichier>
Spécifie le nom du fichier de sortie VCD optionnel.
-e,--extensions
Émet les extensions FST vers VCD. L'activation de cette option peut créer des fichiers VCD illisibles par d'autres outils. Ceci est généralement destiné à être utilisé comme outil de débogage lors du développement d'interfaces d'écriture FST pour les simulateurs.
-h,--help
Affiche l'aide puis quitte.

EXEMPLES

Pour exécuter ce programme de manière standard, tapez :

fst2vcd nom_fichier.fst
La conversion VCD est émise sur la sortie standard.
