NOM

fribidi_get_par_embedding_levels - obtenir les niveaux d'intégration bidirectionnelle d'un paragraphe

SYNTAXE

#include <../fribidi/lib/fribidi.h>

FriBidiLevel fribidi_get_par_embedding_levels
(
const FriBidiCharType *bidi_types,
const FriBidiStrIndex len,
FriBidiParType *pbase_dir,
FriBidiLevel *embedding_levels
);

PARAMÈTRES

const FriBidiCharType *bidi_types
Liste d'entrée des types bidirectionnels tels que retournés par fribidi_get_bidi_types().

Comme il y a 23 valeurs possibles pour un const FriBidiCharType, elles ne sont pas toutes listées ici.

const FriBidiStrIndex len
Longueur de la chaîne d'entrée du paragraphe.
FriBidiParType *pbase_dir
Direction de base du paragraphe demandée et résolue.

Les valeurs possibles pour un FriBidiParType sont les suivantes :

FRIBIDI_PAR_LTR
Paragraphe de Gauche-à-Droite.
FRIBIDI_PAR_RTL
Paragraphe de Droite-à-Gauche.
FRIBIDI_PAR_ON
Paragraphe à direction neutre (Direction-Neutral).
FRIBIDI_PAR_WLTR
Paragraphe Faible Gauche à Droite.
FRIBIDI_PAR_WRTL
Paragraphe Faible Droite à Gauche.
FriBidiLevel *embedding_levels
Liste de sortie des niveaux d'intégration.

DESCRIPTION

Interface obsolète pour fribidi_get_par_embedding_levels_ex(). Reportez-vous à celle-ci pour la documentation.
