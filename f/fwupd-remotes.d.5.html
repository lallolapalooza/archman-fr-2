NOM

fwupd-remotes.d - Remotes utilisés pour le démon fwupd.

SYNTAXE

Les répertoires /etc/fwupd/remotes.d et /var/fwupd/remotes.d sont utilisés pour lire des informations sur les sources de métadonnées distantes. La description complète du format de fichier et des paramètres possibles sont documentés ici à titre de référence.

FORMAT DE FICHIER

Le fichier se compose de plusieurs sections avec des paramètres optionnels. Les paramètres sont de la forme :

[section]
clé = valeur

Le fichier est basé sur des lignes, chaque ligne terminée par un saut de ligne représente soit un commentaire, soit un nom de section, soit un paramètre.

Les noms de section et de paramètre sont sensibles à la casse.

Seulement le premier signe égal dans un paramètre est significatif. Les espaces avant ou après le premier signe égal sont ignorés, tout comme les espaces en début et en fin de ligne dans une valeur de paramètre. Les espaces internes dans une valeur de paramètre sont conservés.

Toute ligne commençant par un caractère dièse (#) est ignorée, tout comme les lignes ne contenant que des espaces.

Les valeurs suivant le signe égal dans les paramètres sont toutes soit une chaîne de caractères (pas besoin de guillemets), des entiers non signés, soit booléennes, qui peuvent être données comme true ou false. La casse n'est pas significative dans les valeurs booléennes, mais est conservée dans les valeurs de chaînes de caractères.

PARAMÈTRES DISTANTS

La section [fwupd Remote] peut contenir les paramètres suivants :

Enabled=false


Si le remote doit être pris en compte lors de la recherche de versions pour les appareils. Seuls les remotes activés sont rafraîchis lors de l'utilisation de fwupdmgr refresh et lors de la considération des mises à jour disponibles pour chaque appareil. Cette valeur peut être modifiée en utilisant fwupdmgr enable-remote.

Title=


La description sur une seule ligne à afficher dans les outils d'interface utilisateur.

MetadataURI=


L'URL des métadonnées AppStream à télécharger et utiliser. Cela doit avoir un suffixe de .xml.gz pour les métadonnées héritées et .xml.xz pour le format plus moderne. Seuls les préfixes http://, https:// et file:// sont pris en charge ici.

FirmwareBaseURI=


L'URL de base optionnelle des archives cabinet à télécharger. Si non spécifié, l'URL de base de MetadataURI est utilisée. Seuls les préfixes http://, https:// et file:// sont pris en charge ici.

ApprovalRequired=false


Si défini sur true, seules les versions autorisées avec fwupdmgr set-approved-firmware seront affichées dans les outils CLI et GUI.

ReportURI=


Le point de terminaison à utiliser pour envoyer des rapports de succès pour le firmware obtenu à partir de ce remote, ou vide pour désactiver cette fonctionnalité.

AutomaticReports=false


Si true, envoie automatiquement des rapports de succès pour le firmware obtenu à partir de ce remote après la fin de la mise à jour du firmware.

AutomaticSecurityReports=false


Si true, envoie automatiquement des rapports de sécurité HSI de plateforme lors de l'exécution de fwupdmgr security.

NoPhasedUpdates=false


Si true, ignore la vérification d'éligibilité pour le déploiement progressif aléatoire du client.


L'éligibilité d'un système à une mise à jour progressive est déterminée en semant le générateur de nombres aléatoires avec /etc/machine-id, le nom de fichier de l'archive et le mtime du cache distant. Si la graine divisée par la valeur phased_update fournie par les métadonnées n'a pas de reste, la version est prise en compte. Cela implique également que la graine sera différente sur une machine différente, pour une mise à jour différente ou si les métadonnées sont rafraîchies.

OrderBefore=


Ce remote sera ordonné avant tous les remotes listés ici, en utilisant des virgules comme délimiteur.


NOTE : Lorsque la même version de firmware est disponible à partir de plusieurs remotes, celle avec la priorité la plus élevée sera utilisée.

OrderAfter=


Ce remote sera ordonné après tous les remotes listés ici, en utilisant des virgules comme délimiteur.

Username=


Le nom d'utilisateur à utiliser pour l'authentification BASIC lors du téléchargement des métadonnées et du firmware à partir de ce remote, et pour le téléchargement des rapports de succès.

Password=


Le mot de passe (bien qu'en pratique il s'agisse d'un *jeton* utilisateur) à utiliser pour l'authentification BASIC lors du téléchargement des métadonnées et du firmware à partir de ce remote, et pour le téléchargement des rapports de succès.

RefreshInterval=


Le temps en secondes après lequel les outils front-end doivent re-télécharger la signature des métadonnées, ou 0 pour re-télécharger à chaque fois.

NOTES

Le nom de base du chemin sans l'extension est utilisé pour l'ID du remote. Par exemple, le fichier remote /etc/fwupd/remotes.d/lvfs.conf aura l'ID lvfs.
