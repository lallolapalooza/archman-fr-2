NOM

fwb_ipf - Compilateur de politique pour ipfilter

SYNTAXE

fwb_ipf [-vVx] [-d wdir] [-o fichier.fw] [-i] -f fichier_donnees.xml nom_objet

DESCRIPTION

fwb_ipf est un composant de compilation de politique de pare-feu de Firewall Builder (voir fwbuilder(1)). Ce compilateur génère du code pour ipfilter. Le compilateur lit les définitions d'objets et la description du pare-feu à partir du fichier de données spécifié avec l'option « -f » et génère des fichiers de configuration ipfilter et un script d'activation du pare-feu.

Tous les fichiers générés portent un nom commençant par le nom de l'objet pare-feu. Le script d'activation du pare-feu a l'extension « .fw » et est un script shell simple qui vide la politique actuelle, charge les nouvelles règles de filtre et de NAT, puis active ipfilter. Le nom du fichier de configuration IPFilter commence par le nom de l'objet pare-feu, suivi de « -ipf.conf ». Le nom du fichier de configuration NAT commence également par le nom de l'objet pare-feu, suivi de « -nat.conf ». Par exemple, si l'objet pare-feu s'appelle « monparefeu », le compilateur créera trois fichiers : « monparefeu.fw », « monparefeu-pf.conf », « monparefeu-nat.conf ».

Le fichier de données et le nom des objets pare-feu doivent être spécifiés sur la ligne de commande. Les autres paramètres de la ligne de commande sont facultatifs.

OPTIONS

-f FICHIER
Spécifie le nom du fichier de données à traiter.
-o fichier.fw
Spécifie le nom du fichier de sortie.
-d wdir
Spécifie le répertoire de travail. Le compilateur crée le script d'activation du pare-feu et les fichiers de configuration ipfilter dans ce répertoire. Si ce paramètre est manquant, tous les fichiers seront placés dans le répertoire de travail actuel.
-v
Être verbeux : le compilateur affiche des messages de diagnostic lorsqu'il travaille.
-V
Affiche le numéro de version et quitte.
-i
Lorsque cette option est présente, le dernier argument de la ligne de commande est censé être l'identifiant de l'objet pare-feu plutôt que son nom.
-x
Génère des informations de débogage pendant le travail. Cette option est destinée au débogage uniquement et peut produire de nombreux messages cryptiques.

NOTES

Le support d'ipf a été réintroduit dans la version 1.0.1 de Firewall Builder

Fonctionnalités prises en charge :

o
les fichiers ipf.conf et nat.conf sont générés
o
négation dans les règles de politique
o
l'inspection avec état dans une règle individuelle peut être désactivée dans la boîte de dialogue des options de règle. Par défaut, le compilateur ajoute « keep state » ou « modulate state » à chaque règle avec l'action « pass »
o
la boîte de dialogue des options de règle fournit un choix de réponses icmp ou tcp rst pour les règles avec l'action « Reject »
o
le compilateur ajoute le drapeau « allow-opts » si une correspondance sur les options IP est nécessaire
o
le compilateur peut générer des règles correspondant aux drapeaux TCP
o
le compilateur peut générer un script ajoutant des alias IP pour les règles NAT en utilisant des adresses n'appartenant à aucune interface du pare-feu
o
le compilateur ajoute toujours la règle « block quick all » tout en bas du script pour garantir une politique de « bloquer tout par défaut » même si la politique est vide.
o
plages d'adresses en politique et en NAT

Fonctionnalités qui ne sont pas prises en charge (encore)

o
négation en NAT
o
services personnalisés

Fonctionnalités qui ne seront pas prises en charge (du moins pas de sitôt)

o
routage de politique
