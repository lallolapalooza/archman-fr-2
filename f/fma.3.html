fma(3) Manuel des fonctions de bibliothèque fma(3)

NOM

fma, fmaf, fmal - multiplication et addition en virgule flottante

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double fma(double x, double y, double z);
float fmaf(float x, float y, float z);
long double fmal(long double x, long double y, long double z);
Exigences concernant les macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

fma(), fmaf(), fmal():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Ces fonctions calculent x * y + z. Le résultat est arrondi comme une seule opération ternaire selon le mode d'arrondi actuel (voir fenv(3)).

VALEUR DE RETOUR

Ces fonctions renvoient la valeur de x * y + z, arrondie comme une opération ternaire.

Si x ou y est un NaN, un NaN est renvoyé.

Si x multiplié par y est un infini exact, et z est un infini de signe opposé, une erreur de domaine se produit et un NaN est renvoyé.

Si l'un des x ou y est un infini, l'autre est 0, et z n'est pas un NaN, une erreur de domaine se produit et un NaN est renvoyé.

Si l'un des x ou y est un infini, et l'autre est 0, et z est un NaN, une erreur de domaine se produit et un NaN est renvoyé.

Si x multiplié par y n'est pas un infini multiplié par zéro (ou vice versa), et z est un NaN, un NaN est renvoyé.

Si le résultat dépasse, une erreur de plage se produit et un infini avec le signe correct est renvoyé.

Si le résultat est trop petit, une erreur de plage se produit et un 0 signé est renvoyé.

ERREURS

Voir math_error(7) pour des informations sur la façon de déterminer si une erreur s'est produite lors de l'appel de ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de domaine : x * y + z ou x * y est invalide.
Une exception de virgule flottante invalide (FE_INVALID) est déclenchée.
Erreur de plage : dépassement de capacité du résultat
Une exception de virgule flottante de dépassement (FE_OVERFLOW) est déclenchée.
Erreur de plage : sous-dépassement du résultat
Une exception de virgule flottante de sous-dépassement (FE_UNDERFLOW) est déclenchée.

Ces fonctions ne définissent pas errno.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
fma (), fmaf (), fmal () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

glibc 2.1. C99, POSIX.1-2001.

VOIR AUSSI

remainder(3), remquo(3)
