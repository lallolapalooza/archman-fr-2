NOM

fixkrf - Corrige les fichiers keyrec de DNSSEC-Tools dont les fichiers de clés de chiffrement ont été déplacés

SYNTAXE

fixkrf [options] <fichier-keyrec> <rép 1> ... <rép N>

DESCRIPTION

fixkrf vérifie un fichier keyrec spécifié pour s'assurer que les fichiers de clés de chiffrement référencés existent là où ils sont listés. Si une clé n'est pas là où le keyrec indique qu'elle devrait être, alors fixkrf recherchera dans les répertoires donnés ces clés et ajustera le keyrec pour qu'il corresponde à la réalité. Si une clé portant un nom de fichier particulier est trouvée dans plusieurs endroits, un avertissement sera affiché et le fichier keyrec ne sera pas modifié pour cette clé.

OPTIONS

-list
Affiche des informations sur les clés manquantes, mais ne corrige pas le fichier keyrec.
-verbose
Affiche des informations sur les clés trouvées ainsi que sur les clés manquantes.
-Version
Affiche les informations de version pour fixkrf et DNSSEC-Tools.
-help
Affiche un message d'utilisation.
