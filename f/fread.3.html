fread(3) Manuel des fonctions de bibliothèque fread(3)

NOM

fread, fwrite — entrée/sortie de flux binaire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdio.h>
size_t fread(size_t size, size_t n;
             void ptr[restrict size * n],
             size_t size, size_t n,
             FILE *restrict stream);
size_t fwrite(size_t size, size_t n;
             const void ptr[restrict size * n],
             size_t size, size_t n,
             FILE *restrict stream);

DESCRIPTION

La fonction fread() lit n éléments de données, chacun de size octets de long, depuis le flux pointé par stream, en les stockant à l'emplacement indiqué par ptr.

La fonction fwrite() écrit n éléments de données, chacun de size octets de long, dans le flux pointé par stream, en les obtenant de l'emplacement indiqué par ptr.

Pour les fonctions non verrouillées, voir unlocked_stdio(3).

VALEUR DE RETOUR

En cas de succès, fread() et fwrite() retournent le nombre d'éléments lus ou écrits. Ce nombre est égal au nombre d'octets transférés uniquement lorsque size est égal à 1. Si une erreur se produit, ou si la fin du fichier est atteinte, la valeur de retour est un nombre d'éléments inférieur au nombre demandé (ou zéro).

L'indicateur de position du fichier pour le flux est avancé par le nombre d'octets lus ou écrits avec succès.

fread() ne fait pas de distinction entre la fin de fichier et une erreur, et les appelants doivent utiliser feof(3) et ferror(3) pour déterminer ce qui s'est produit.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
fread (), fwrite () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C89.

EXEMPLES

Le programme ci-dessous démontre l'utilisation de fread() en analysant l'exécutable ELF /bin/sh en mode binaire et en affichant sa magie et sa classe :


$ ./a.out;
ELF magic: 0x7f454c46
Class: 0x02

Source du programme

#include <stdio.h>
#include <stdlib.h>
#define NITEMS(arr)  (sizeof(arr) / sizeof((arr)[0]))
int
main(void)
{
    FILE           *fp;
    size_t         ret;
    unsigned char  buffer[4];
    fp = fopen("/bin/sh", "rb");
    if (!fp) {
        perror("fopen");
        return EXIT_FAILURE;
    }
    ret = fread(buffer, sizeof(*buffer), NITEMS(buffer), fp);
    if (ret != NITEMS(buffer)) {
        fprintf(stderr, "fread() failed: %zu\n", ret);
        exit(EXIT_FAILURE);
    }
    printf("ELF magic: %#04x%02x%02x%02x\n", buffer[0], buffer[1],
           buffer[2], buffer[3]);
    ret = fread(buffer, 1, 1, fp);
    if (ret != 1) {
        fprintf(stderr, "fread() failed: %zu\n", ret);
        exit(EXIT_FAILURE);
    }
    printf("Class: %#04x\n", buffer[0]);
    fclose(fp);
    exit(EXIT_SUCCESS);
}
