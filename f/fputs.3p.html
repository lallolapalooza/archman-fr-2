FPUTS(3P) Manuel du programmeur POSIX FPUTS(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

fputs — écrire une chaîne sur un flux

SYNOPIS

#include <stdio.h>
int fputs(const char *restrict s, FILE *restrict stream);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

La fonction fputs() écrit la chaîne terminée par un caractère nul pointée par s sur le flux pointé par stream. L'octet nul de terminaison n'est pas écrit.

Les horodatages de dernière modification des données et de dernier changement de statut du fichier sont marqués pour être mis à jour entre l'exécution réussie de fputs() et la prochaine complétion réussie d'un appel à fflush() ou fclose() sur le même flux ou un appel à exit() ou abort().

VALEUR DE RETOUR

En cas de succès, fputs() renvoie un nombre non négatif. Sinon, elle renvoie EOF, définit un indicateur d'erreur pour le flux et définit errno pour indiquer l'erreur.

ERREURS

Se référer à fputc().

Les sections suivantes sont informatives.

EXEMPLES

Impression sur la sortie standard

L'exemple suivant récupère l'heure actuelle, la convertit en chaîne à l'aide de localtime() et asctime(), et l'imprime sur la sortie standard à l'aide de fputs(). Il imprime ensuite le nombre de minutes avant un événement attendu.

#include <time.h>
#include <stdio.h>
...
time_t now;
int minutes_to_event;
...
time(&now);
printf("L'heure est ");
fputs(asctime(localtime(&now)), stdout);
printf("Il reste %d minutes avant l'événement.\n",
    minutes_to_event);
...

UTILISATION PAR L'APPLICATION

La fonction puts() ajoute une <nouvelle ligne>, tandis que fputs() ne le fait pas.

Ce volume de POSIX.1‐2017 exige qu'une complétion réussie renvoie simplement un entier non négatif. Il existe au moins trois conventions d'implémentation différentes pour cette exigence :

*
Retourner une valeur constante.
*
Retourner le dernier caractère écrit.
*
Retourner le nombre d'octets écrits. Notez que cette convention d'implémentation ne peut pas être respectée pour les chaînes plus longues que {INT_MAX} octets car la valeur ne serait pas représentable dans le type de retour de la fonction. Pour des raisons de compatibilité ascendante, les implémentations peuvent retourner le nombre d'octets pour les chaînes allant jusqu'à {INT_MAX} octets, et retourner {INT_MAX} pour toutes les chaînes plus longues.

RATIONALE

La fonction fputs() est l'une dont le code source était spécifié dans The C Programming Language référencé. Dans l'édition originale, la fonction n'avait pas de valeur de retour définie, mais de nombreuses implémentations pratiques renvoyaient, comme effet secondaire, la valeur du dernier caractère écrit, car c'était la valeur restant dans l'accumulateur utilisé comme valeur de retour. Dans la deuxième édition du livre, 0 (valeur fixe) ou EOF était renvoyé selon la valeur de retour de ferror() ; cependant, pour la compatibilité avec les implémentations existantes, plusieurs implémentations renvoyaient, en cas de succès, une valeur positive représentant le dernier octet écrit.
