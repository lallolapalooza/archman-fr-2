double_t(3type) double_t(3type)

NOM

float_t, double_t - types à virgule flottante les plus efficaces

BIBLIOTHÈQUE

Bibliothèque mathématique (libm)

SYNTAXE

#include <math.h>
typedef /* ... */ float_t;
typedef /* ... */ double_t;

DESCRIPTION

Les types à virgule flottante les plus efficaces de l'implémentation, au moins aussi larges que float et double respectivement. Leur type dépend de la valeur de la macro FLT_EVAL_METHOD (définie dans <float.h>) :

FLT_EVAL_METHOD float_t double_t
0 float double
1 double double
2 long double long double

Pour les autres valeurs de FLT_EVAL_METHOD, les types de float_t et double_t sont définis par l'implémentation.

NORMES

C11, POSIX.1-2024.

HISTORIQUE

C99, POSIX.1-2001.

VOIR AUSSI

float.h(0p), math.h(0p)
