FTVIEW(1) Manuel des commandes générales FTVIEW(1)

NOM

ftview - visualiseur de glyphes simple

SYNTAXE

ftview [options] [pt] police ...

DESCRIPTION

ftview affiche tous les glyphes d'une police, permettant de modifier interactivement divers paramètres de rendu et de mise en forme.

pt
La taille en points pour la résolution donnée. Si la résolution est de 72 ppp, cela donne directement la valeur ppem (pixels par EM).
police
Le(s) fichier(s) de police à afficher. Pour les fichiers de polices Type 1, ftview essaie également de joindre le fichier de métriques correspondant (avec l'extension `.afm' ou `.pfm').

Ce programme fait partie du paquet de démos FreeType.

OPTIONS

-d LxH[xP]
Définit la largeur de la fenêtre à L px, la hauteur à H px et éventuellement la profondeur à P ppp (par défaut : 640x480x24).
-r r
Utilise la résolution r ppp (par défaut : 72 ppp).
-f indice
Spécifie l'indice du premier glyphe à afficher (par défaut : 0).
-e enc
Spécifie le tag d'encodage (par défaut : pas d'encodage). Valeurs courantes : unic (Unicode), symb (symbole), ADOB (standard Adobe), ADBC (personnalisé Adobe), ou un indice de charmap numérique.
-m texte
Utilise texte pour le rendu.
-l mode
Définit le mode de rendu au démarrage (0 <= mode <= 6). Ceci correspond aux frappes 'A' à 'G' dans le programme.
-L P1,P2,P3,P4,P5
-L Rx,Ry,Gx,Gy,Bx,By
Selon la méthode de rendu subpixel implémentée et le nombre d'arguments fournis, définit soit cinq poids de filtre LCD, soit six coordonnées subpixel (comme spécifié dans les fonctions FT_Library_SetLcdFilterWeights ou FT_Library_SetLcdGeometry respectivement).
-k touches
Émule une séquence de frappes au démarrage. Si les frappes contiennent 'q', le programme fonctionne en mode batch. Les touches Fx sont mappées aux codes de caractères 0xFx ; par exemple, -k $'\xF3q' représente la touche F3 suivie du caractère 'q'.
-p
Précharge le fichier en mémoire pour simuler le mappage mémoire.
-v
Affiche la version.
