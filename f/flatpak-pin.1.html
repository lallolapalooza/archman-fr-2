NOM

flatpak-pin - Épingler des runtimes pour empêcher leur suppression automatique

SYNTAXE

flatpak pin [OPTION...] MOTIF...

DESCRIPTION

Flatpak maintient une liste de motifs qui définissent quels refs sont épinglés. Un ref épinglé ne sera jamais désinstallé automatiquement (comme le sont les runtimes inutilisés périodiquement). Cela peut être utile si, par exemple, vous utilisez un runtime à des fins de développement.

Les runtimes qui sont explicitement installés, plutôt qu'installés comme dépendance de quelque chose d'autre, sont automatiquement épinglés.

Les motifs sont simplement une partie du ref, le caractère * correspondant à n'importe quoi dans cette partie du ref. Seuls les runtimes peuvent être épinglés, pas les applications. Voici quelques exemples de motifs :

org.some.Runtime
org.some.Runtime//unstable
runtime/org.domain.*
org.some.Runtime/arm

Pour lister l'ensemble actuel des épingles, exécutez cette commande sans aucun motif.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Afficher les options d'aide et quitter.

--remove

Au lieu d'ajouter les motifs, supprimez les motifs correspondants.

-u, --user

Épingler les refs dans une installation par utilisateur.

--system

Épingler les refs dans l'installation système par défaut.

--installation=NOM

Épingler les refs dans une installation système spécifiée par NOM parmi celles définies dans /etc/flatpak/installations.d/. L'utilisation de --installation=default est équivalente à l'utilisation de --system.

-v, --verbose

Afficher les informations de débogage pendant le traitement de la commande.

EXEMPLES

$ flatpak pin

$ flatpak pin org.freedesktop.Platform//19.08

$ flatpak pin --remove org.freedesktop.Platform//19.08
