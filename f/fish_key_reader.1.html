NOM

fish_key_reader - explorer les caractères envoyés par les touches du clavier

SYNTAXE

fish_key_reader [OPTIONS]

DESCRIPTION

fish_key_reader est utilisé pour expliquer comment lier une séquence de touches particulière. Par défaut, il affiche la commande bind <> pour une séquence de touches lue interactivement sur l'entrée standard.

Les options suivantes sont disponibles :

-c ou --continuous
Démarre une session où plusieurs séquences de touches peuvent être inspectées. Par défaut, le programme se termine après avoir capturé une seule séquence de touches.
-h ou --help
Affiche l'aide sur l'utilisation de cette commande.
-V ou --verbose
Explique quelle séquence a été reçue en plus de la touche décodée.
-v ou --version
Affiche la version actuelle de fish puis se termine.

NOTES D'UTILISATION

fish_key_reader désactive intentionnellement la gestion de nombreux signaux. Pour terminer fish_key_reader en mode --continuous, faites :

  • appuyez deux fois sur ctrl-c, ou
  • appuyez deux fois sur ctrl-d, ou
  • tapez exit, ou
  • tapez quit

EXEMPLE

> fish_key_reader
Appuyez sur une touche:
# appuyez sur la flèche haut
bind up 'faire quelque chose'
