NOM

flatpak-remote-ls - Afficher les runtimes et applications disponibles

SYNTAXE

flatpak remote-ls [OPTION...] [RÉFÉRENTIEL]

DESCRIPTION

Affiche les runtimes et applications disponibles dans le dépôt distant nommé RÉFÉRENTIEL, ou dans tous les dépôts s'il n'y en a pas de spécifié. Vous pouvez trouver tous les dépôts distants configurés avec flatpak remotes.

RÉFÉRENTIEL peut être une URI file:// pointant vers un dépôt local au lieu d'un nom de dépôt distant.

Sauf indication contraire avec les options --system, --user, ou --installation, cette commande utilise soit l'installation système par défaut, soit celle par utilisateur, en fonction de celle qui contient le RÉFÉRENTIEL spécifié.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

-u, --user

Utilise la configuration par utilisateur.

--system

Utilise la configuration système par défaut.

--installation=NOM

Utilise une installation système spécifiée par NOM parmi celles définies dans /etc/flatpak/installations.d/. Utiliser --installation=default équivaut à utiliser --system.

--cached

Préfère utiliser les informations mises en cache localement si possible, même si elles peuvent être obsolètes. C'est plus rapide, mais risque de retourner des informations périmées.

-d, --show-details

Affiche les architectures, les branches et les identifiants de commit, en plus des noms. Équivalent à --columns=all.

--runtime

N'affiche que les runtimes, omet les applications.

--app

N'affiche que les applications, omet les runtimes.

--all, -a

Affiche tout. Par défaut, les extensions de locale et de débogage ainsi que les architectures secondaires lorsque l'architecture primaire est disponible sont masquées.

--updates

N'affiche que ceux pour lesquels des mises à jour sont disponibles.

--arch=ARCH

N'affiche que ceux correspondant à l'architecture spécifiée. Par défaut, seules les architectures prises en charge sont affichées. Utilisez --arch=* pour afficher toutes les architectures. Voir flatpak --supported-arches pour les architectures prises en charge par l'hôte.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage OSTree pendant le traitement de la commande.

--app-runtime=RUNTIME

Liste les applications qui utilisent le runtime donné

--columns=CHAMP,...

Spécifie quelles informations afficher sur chaque référence. Vous pouvez lister plusieurs champs, ou utiliser cette option plusieurs fois.

Ajoutez :s[tart], :m[iddle], :e[nd] ou :f[ull] aux noms de colonnes pour changer l'élision.

CHAMPS

Les champs suivants sont compris par l'option --columns :

name

Affiche le nom

description

Affiche la description de l'application

application

Affiche l'identifiant de l'application ou du runtime

arch

Affiche l'architecture

branch

Affiche la branche

version

Affiche la version

ref

Affiche la référence

origin

Affiche le dépôt distant d'origine

commit

Affiche le commit actif

runtime

Affiche le runtime utilisé

installed-size

Affiche la taille installée

download-size

Affiche la taille de téléchargement

options

Affiche les options

all

Affiche toutes les colonnes

help

Affiche la liste des colonnes disponibles

Notez que les noms de champs peuvent être abrégés en un préfixe unique.

EXEMPLES

$ flatpak --user remote-ls --app testrepo
