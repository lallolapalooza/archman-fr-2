FTBENCH(1) Manuel des commandes générales FTBENCH(1)

NOM

ftbench - benchmark certains chemins FreeType courants

SYNTAXE

ftbench [options] nom_police

DESCRIPTION

L'outil ftbench mesure les performances de certaines opérations FreeType courantes.

Ce programme fait partie du paquet de démos FreeType.

OPTIONS

-a axe1,axe2,...
Pour les polices Multiple Master, GX ou à variations OpenType, spécifiez les coordonnées de conception pour chaque axe au démarrage. Ignoré pour tous les autres formats de polices.
-b tests
Effectuer les tests choisis :
a charger les glyphes (FT_Load_Glyph)
b charger les largeurs d'avancement (FT_Get_Advances)
c rendre les glyphes (FT_Render_Glyph)
d charger les glyphes (FT_Get_Glyph)
e obtenir les indices des glyphes (FT_Get_Char_Index)
f itérer sur la CMap (FT_Get_{First,Next}_Char)
g ouvrir une nouvelle face (FT_New_Face ou FT_New_Memory_Face)
h épaissir les glyphes (FT_GlyphSlot_Embolden)
i tracer les glyphes (FT_Glyph_Stroke)
j obtenir les boîtes englobantes des glyphes (FT_Outline_Get_BBox)
k obtenir les boîtes de caractères des glyphes (FT_Glyph_Get_CBox)
l ouvrir une nouvelle face et charger les glyphes
(par défaut, abcdefghijkl, c'est-à-dire tous les tests).
Le nombre de glyphes utilisés par test (dans une seule itération) est donné par l'option -i.
-C
Comparer avec la version mise en cache si disponible.
-c N
Utiliser au maximum N itérations pour chaque test (0 signifie limité par le temps).
-e E
Utiliser la table de caractères avec l'indice E au lieu de l'unicode par défaut.
-f L
Utiliser le nombre L en hexadécimal (pas décimal) comme indicateurs de chargement (voir les macros `FT_LOAD_XXX' dans la référence FreeType).
-H nom
Utiliser le moteur d'hinting CFF nom. Les versions disponibles dépendent des options de compilation de FreeType ; appeler ftbench sans argument pour obtenir la liste réelle.
-I ver
Utiliser la version de l'interpréteur TT ver. Les versions disponibles dépendent des options de compilation de FreeType ; appeler ftbench sans argument pour obtenir la liste réelle.
-i I-J
Plage d'indices de glyphes à utiliser, en ordre croissant ou décroissant (par défaut de 0 au nombre total de glyphes moins un).
-m M
Définir la taille maximale du cache à M KiOctet (par défaut 1024).
-p
Pré-charger le fichier de police en mémoire (c'est-à-dire tester FT_New_Memory_Face au lieu de FT_New_Face).
-r R
Définir le mode de rendu à R :
0 normal
1 léger
2 mono
3 LCD horizontal
4 LCD vertical
(par défaut 0). Cela correspond aux valeurs des indicateurs `FT_RENDER_MODE_XXX'.
-s S
Utiliser S ppem comme taille de face (par défaut 10ppem). Si réglé sur zéro, n'appelle pas FT_Set_Pixel_Sizes. Utiliser la valeur 0 avec l'option `-f 1' ou similaire pour charger les glyphes sans mise à l'échelle, sinon des erreurs apparaîtront.
-t T
Utiliser au maximum T secondes par test (par défaut 2).
-v
Afficher la version.
