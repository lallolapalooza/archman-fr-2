form_win(3X) Appels de bibliothèque form_win(3X)

NOM

form_win - établir et rompre les associations de fenêtre et de sous-fenêtre de formulaire

SYNTAXE

#include <form.h>
int set_form_win(FORM *form, WINDOW *win);
WINDOW *form_win(const FORM *form);
int set_form_sub(FORM *form, WINDOW *sub);
WINDOW *form_sub(const FORM *form);
int scale_form(const FORM *form, int *rows, int *columns);

DESCRIPTION

Chaque formulaire possède une paire de fenêtres curses associée. La fenêtre du formulaire affiche le titre et la bordure associés à la fenêtre ; la sous-fenêtre du formulaire affiche les éléments du formulaire actuellement disponibles pour la sélection.

Les quatre premières fonctions obtiennent et définissent ces fenêtres. Il n'est pas nécessaire de définir l'une ou l'autre fenêtre ; par défaut, le code du pilote utilise stdscr pour les deux.

Dans les fonctions set_, un argument de fenêtre de NULL est traité comme s'il s'agissait de stsdcr. Un argument de formulaire de NULL est traité comme une demande de modification de la fenêtre ou de la sous-fenêtre de formulaire par défaut du système.

La fonction scale_form renvoie la taille minimale requise pour la sous-fenêtre du formulaire form.

VALEUR DE RETOUR

Les routines renvoyant des pointeurs renvoient NULL en cas d'erreur. Les routines renvoyant un entier renvoient l'un des codes d'erreur suivants :

E_OK
La routine a réussi.
E_SYSTEM_ERROR
Erreur système survenue (voir errno(3)).
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.
E_POSTED
Le formulaire a déjà été affiché.
E_NOT_CONNECTED
Aucun élément n'est connecté au formulaire.

PORTABILITÉ

Ces routines émulent la bibliothèque de formulaires System V. Elles n'étaient pas prises en charge dans les versions Version 7 ou BSD.

AUTEURS

Juergen Pfeifer. Pages de manuel et adaptation pour new curses par Eric S. Raymond.
