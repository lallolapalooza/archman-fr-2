NOM

fsck.f2fs - vérifier un système de fichiers F2FS Linux

SYNOPSIS

fsck.f2fs [ -a activer la correction automatique ] [ -f activer la correction forcée ] [ -M afficher la carte des fichiers ] [ -p activer le mode préen ] [ -t afficher l'arbre des répertoires stocké ] [ -d niveau de débogage ] périphérique

DESCRIPTION

fsck.f2fs est utilisé pour vérifier un système de fichiers f2fs (généralement dans une partition de disque). périphérique est le fichier spécial correspondant au périphérique (par exemple, /dev/sdXX).

Le code de sortie retourné par fsck.f2fs est 0 en cas de succès et -1 en cas d'échec.

OPTIONS

-a activer la correction automatique
Active la vérification du système de fichiers uniquement si un bogue a été signalé par le module noyau F2FS. Désactivé par défaut.
-f activer la correction forcée
Active la correction de toutes les incohérences dans la partition.
-M afficher la carte des fichiers
Active l'affichage de tous les noms de fichiers et numéros d'inodes stockés dans l'image.
-p activer le mode préen
Identique à "-a" pour prendre en charge la convention générale de fsck.
-t afficher l'arbre des répertoires stocké
Active l'affichage de toutes les entrées de répertoire dans la partition.
-d niveau de débogage
Spécifie le niveau des options de débogage. Le numéro par défaut est 0, ce qui affiche les messages de débogage de base.
