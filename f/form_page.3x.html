form_page(3X) Appels de bibliothèque form_page(3X)

NOM

form_page - définir et obtenir le numéro de page du formulaire

SYNOPSIS

#include <form.h>
int set_current_field(FORM *form, FIELD *field);
FIELD *current_field(const FORM *form);
int unfocus_current_field(FORM *form);
int set_form_page(FORM *form, int n);
int form_page(const FORM *form);
int field_index(const FIELD *field);

DESCRIPTION

La fonction set_current_field définit le champ courant du formulaire donné ; current_field renvoie le champ courant du formulaire donné.

La fonction unfocus_current_field retire le focus du champ courant du formulaire. Dans cet état, les interrogations via current_field renverront un pointeur NULL.

La fonction set_form_page définit le numéro de page du formulaire (passe à la page n du formulaire).

La fonction form_page renvoie le numéro de page courant du formulaire.

La fonction field_index renvoie l'index du champ dans le tableau de champs du formulaire auquel il est connecté. Elle renvoie ERR si l'argument est le pointeur nul ou si le champ n'est pas connecté.

VALEUR DE RETOUR

À l'exception de form_page, chaque routine renvoie l'un des éléments suivants :

E_OK
La routine a réussi.
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors plage.
E_BAD_STATE
La routine a été appelée depuis une fonction d'initialisation ou de terminaison.
E_INVALID_FIELD
Le contenu d'un champ n'est pas valide.
E_REQUEST_DENIED
Le pilote de formulaire n'a pas pu traiter la requête.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).

PORTABILITÉ

Ces routines émulant la bibliothèque de formulaires System V. Elles n'étaient pas prises en charge sur les versions 7 ou BSD.

La fonction unfocus_current_field est une extension d' ncurses.

AUTEURS
