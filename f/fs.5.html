filesystems(5) Manuel des formats de fichiers filesystems(5)

NOM

filesystems - Types de systèmes de fichiers Linux : ext, ext2, ext3, ext4, hpfs, iso9660, JFS, minix, msdos, ncpfs nfs, ntfs, proc, Reiserfs, smb, sysv, umsdos, vfat, XFS, xiafs

DESCRIPTION

Lorsque, comme c'est la coutume, le système de fichiers proc est monté sur /proc, vous pouvez trouver dans le fichier /proc/filesystems quels systèmes de fichiers votre noyau supporte actuellement ; voir proc(5) pour plus de détails. Il existe également un appel système sysfs(2) hérité (dont la disponibilité est contrôlée par l'option de configuration de compilation du noyau CONFIG_SYSFS_SYSCALL depuis Linux 3.15) qui permet l'énumération des types de systèmes de fichiers actuellement disponibles, que /proc soit disponible et/ou sain ou non.

Si vous avez besoin d'un système de fichiers non supporté actuellement, insérez le module noyau correspondant ou recompilez le noyau.

Afin d'utiliser un système de fichiers, vous devez le monter ; voir mount(2) et mount(8).

La liste suivante fournit une courte description des systèmes de fichiers disponibles ou historiquement disponibles dans le noyau Linux. Consultez la documentation du noyau pour une description complète de toutes les options et limitations.

erofs
est le système de fichiers en lecture seule amélioré (Enhanced Read-Only File System), stable depuis Linux 5.4. Voir erofs(5).
ext
est une extension élaborée du système de fichiers minix. Il a été complètement remplacé par la deuxième version du système de fichiers étendu (ext2) et a été retiré du noyau (dans Linux 2.1.21).
ext2
est un système de fichiers de disque utilisé par Linux pour les disques fixes ainsi que les médias amovibles. Le deuxième système de fichiers étendu a été conçu comme une extension du système de fichiers étendu (ext). Voir ext2(5).
ext3
est une version avec journalisation du système de fichiers ext2. Il est facile de passer de ext2 à ext3 et vice versa. Voir ext3(5).
ext4
est un ensemble d'améliorations par rapport à ext3, incluant des améliorations substantielles de performance et de fiabilité, ainsi que des augmentations importantes des limites de taille de volume, de fichier et de répertoire. Voir ext4(5).
hpfs
est le système de fichiers haute performance (High Performance Filesystem), utilisé dans OS/2. Ce système de fichiers est en lecture seule sous Linux en raison du manque de documentation disponible.
iso9660
est un type de système de fichiers pour CD-ROM conforme à la norme ISO/IEC 9660.
High Sierra
Linux supporte High Sierra, le précurseur de la norme ISO/IEC 9660 pour les systèmes de fichiers de CD-ROM. Il est automatiquement reconnu dans la prise en charge du système de fichiers iso9660 sous Linux.
Rock Ridge
Linux supporte également les enregistrements du protocole de partage d'utilisation du système spécifiés par le protocole d'échange Rock Ridge. Ils sont utilisés pour décrire davantage les fichiers dans le système de fichiers iso9660 à un hôte UNIX, et fournissent des informations telles que les noms de fichiers longs, UID/GID, les permissions POSIX et les périphériques. Il est automatiquement reconnu dans la prise en charge du système de fichiers iso9660 sous Linux.
JFS
est un système de fichiers avec journalisation, développé par IBM, qui a été intégré dans Linux 2.4.24.
minix
est le système de fichiers utilisé dans le système d'exploitation Minix, le premier à fonctionner sous Linux. Il présente un certain nombre de défauts, notamment une limite de taille de partition de 64 Mo, des noms de fichiers courts et une seule horodatage. Il reste utile pour les disquettes et les disques RAM.
msdos
est le système de fichiers utilisé par DOS, Windows et certains ordinateurs OS/2. Les noms de fichiers msdos ne peuvent pas dépasser 8 caractères, suivis d'un point optionnel et d'une extension de 3 caractères.
ncpfs
est un système de fichiers réseau qui supporte le protocole NCP, utilisé par Novell NetWare. Il a été retiré du noyau dans Linux 4.17.
Pour utiliser ncpfs, vous avez besoin de programmes spéciaux, que vous pouvez trouver à ftp://ftp.gwdg.de/pub/linux/misc/ncpfs.
nfs
est le système de fichiers réseau utilisé pour accéder aux disques situés sur des ordinateurs distants.
ntfs
est le système de fichiers natif de Microsoft Windows NT, supportant des fonctionnalités comme les ACL, la journalisation, le chiffrement, etc.
proc
est un pseudo-système de fichiers utilisé comme interface aux structures de données du noyau plutôt qu'à la lecture et l'interprétation de /dev/kmem. En particulier, ses fichiers ne prennent pas d'espace disque. Voir proc(5).
Reiserfs
est un système de fichiers avec journalisation, conçu par Hans Reiser, qui a été intégré dans Linux 2.4.1.
smb
est un système de fichiers réseau qui supporte le protocole SMB, utilisé par Windows. Voir https://www.samba.org/samba/smbfs/.
sysv
est une implémentation du système de fichiers System V/Coherent pour Linux. Il implémente tout le FS Xenix, le FS System V/386, et le FS Coherent.
umsdos
est un système de fichiers DOS étendu utilisé par Linux. Il ajoute la possibilité de noms de fichiers longs, UID/GID, permissions POSIX, et fichiers spéciaux (périphériques, tubes nommés, etc.) sous le système de fichiers DOS, sans sacrifier la compatibilité avec DOS.
tmpfs
est un système de fichiers dont le contenu réside dans la mémoire virtuelle. Comme les fichiers sur de tels systèmes résident généralement en RAM, l'accès aux fichiers est extrêmement rapide. Voir tmpfs(5).
vfat
est un système de fichiers FAT étendu utilisé par Microsoft Windows95 et Windows NT. vfat ajoute la possibilité d'utiliser des noms de fichiers longs sous le système de fichiers MSDOS.
XFS
est un système de fichiers avec journalisation, développé par SGI, qui a été intégré dans Linux 2.4.20.
xiafs
a été conçu et implémenté pour être un système de fichiers stable et sûr en étendant le code du système de fichiers Minix. Il fournit les fonctionnalités de base les plus demandées sans complexité excessive. Le système de fichiers xiafs n'est plus activement développé ou maintenu. Il a été retiré du noyau dans Linux 2.1.21.
