NOM

fribidi_get_bidi_type_name - obtenir le nom du type bidi

SYNTAXE

#include <../fribidi/lib/fribidi.h>

const char *fribidi_get_bidi_type_name(FriBidiCharType t);

PARAMÈTRES

FriBidiCharType t
Type bidi d'entrée.

Comme il y a 23 valeurs possibles pour un FriBidiCharType, elles ne sont pas toutes listées ici.

DESCRIPTION

Cette fonction renvoie le nom du type bidi d'un type de caractère. La chaîne renvoyée est une chaîne statique et ne doit pas être libérée.

Les noms des types sont les mêmes que ceux définis dans le Tableau 3.7 Types de caractères bidirectionnels de l'Algorithme bidirectionnel Unicode disponible à http://www.unicode.org/reports/tr9/#Bidirectional_Character_Types, avec quelques modifications : L->LTR, R->RTL, B->BS, S->SS.
