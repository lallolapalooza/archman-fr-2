foreach(n) Commandes intégrées Tcl foreach(n)

NOM

foreach - Itérer sur tous les éléments d'une ou plusieurs listes

SYNTAXE

foreach nom_var liste corps
foreach liste_vars1 liste1 ?liste_vars2 liste2 ...? corps

DESCRIPTION

La commande foreach implémente une boucle où la ou les variables de boucle prennent des valeurs d'une ou plusieurs listes. Dans le cas le plus simple, il y a une variable de boucle, nom_var, et une liste, liste, qui est une liste de valeurs à assigner à nom_var. L'argument corps est un script Tcl. Pour chaque élément de liste (de la première à la dernière), foreach assigne le contenu de l'élément à nom_var comme si la commande lindex avait été utilisée pour extraire l'élément, puis appelle l'interpréteur Tcl pour exécuter corps.

Dans le cas général, il peut y avoir plus d'une liste de valeurs (par exemple, liste1 et liste2), et chaque liste de valeurs peut être associée à une liste de variables de boucle (par exemple, liste_vars1 et liste_vars2). Au cours de chaque itération de la boucle, les variables de chaque liste_vars sont assignées à des valeurs consécutives de la liste correspondante. Les valeurs de chaque liste sont utilisées dans l'ordre, de la première à la dernière, et chaque valeur est utilisée exactement une fois. Le nombre total d'itérations de la boucle est suffisant pour utiliser toutes les valeurs de toutes les listes de valeurs. Si une liste de valeurs ne contient pas assez d'éléments pour chacune de ses variables de boucle à chaque itération, des valeurs vides sont utilisées pour les éléments manquants.

Les instructions break et continue peuvent être appelées à l'intérieur de corps, avec le même effet que dans la commande for. Foreach renvoie une chaîne vide.

EXEMPLES

Cette boucle imprime chaque valeur d'une liste ainsi que son carré et son cube :

set values {1 3 5 7 2 4 6 8}	;# Nombres impairs d'abord, pour le fun !
puts "Valeur\tCarré\tCube"	;# En-tête soigné
foreach x $values {	;# Puis la boucle et l'impression...
    puts " $x\t [expr {$x**2}]\t [expr {$x**3}]"
}

La boucle suivante utilise i et j comme variables de boucle pour itérer sur des paires d'éléments d'une seule liste.

set x {}
foreach {i j} {a b c d e f} {
    lappend x $j $i
}
# La valeur de x est "b a d c f e"
# Il y a 3 itérations de la boucle.

La boucle suivante utilise i et j pour itérer sur deux listes en parallèle.

set x {}
foreach i {a b c} j {d e f g} {
    lappend x $i $j
}
# La valeur de x est "a d b e c f {} g"
# Il y a 4 itérations de la boucle.

Les deux formes sont combinées dans l'exemple suivant.

set x {}
foreach i {a b c} {j k} {d e f g} {
    lappend x $i $j $k
}
# La valeur de x est "a d e b f g c {} {}"
# Il y a 3 itérations de la boucle.
