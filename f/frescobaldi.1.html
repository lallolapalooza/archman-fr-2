FRESCOBALDI(1) Manuel des commandes générales FRESCOBALDI(1)

NOM

frescobaldi - Éditeur de musique LilyPond

SYNTAXE

frescobaldi [options] fichiers

DESCRIPTION

Éditeur de musique LilyPond

OPTIONS

Arguments :

fichiers
Fichiers LilyPond à ouvrir, peuvent aussi être des URL textedit

Options :

-v, --version
Afficher les informations de version
-V, --version-debug
Afficher les informations de version de tous les modules de support
-h, --help
Afficher l'aide sur les options et quitter
-e ENC, --encoding=ENC
Encodage à utiliser
-l NUM, --line=NUM
Numéro de ligne à atteindre, à partir de 1
-c NUM, --column=NUM
Colonne à atteindre, à partir de 1
--start <session>
Session à démarrer (`-' pour une session vide)
--list-sessions
Lister les noms de sessions et quitter
-n, --new
Toujours démarrer une nouvelle instance

VOIR AUSSI

Frescobaldi propose un manuel utilisateur accessible via l'entrée Guide de l'utilisateur dans le menu Aide.
