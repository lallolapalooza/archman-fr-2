DESCRIPTIO

N

Cette fonction affiche un message décrit par ses arguments sur le(s) périphérique(s) spécifié(s) dans l'argument classification. Pour les messages écrits vers stderr, le format dépend de la variable d'environnement MSGVERB

.

L'argument label identifie la source du message. La chaîne doit se composer de deux parties séparées par deux-points, la première partie ne comportant pas plus de 10 caractères et la seconde pas plus de 14

caractères.

L'argument text décrit la condition de

l'erreur.

L'argument action décrit les étapes possibles pour se remettre de l'erreur. S'il est imprimé, il est préfixé par « TO FIX: »

.

L'argument tag est une référence vers la documentation en ligne où plus d'informations peuvent être trouvées. Il devrait contenir la valeur label et un numéro d'identification

unique.

Arguments

factices

Chacun des arguments peut avoir une valeur factice. La valeur de classification factice MM_NULLMC (0L) ne spécifie aucune sortie, donc rien n'est imprimé. La valeur de gravité factice NO_SEV (0) indique qu'aucune gravité n'est fournie. Les valeurs MM_NULLLBL, MM_NULLTXT, MM_NULLACT, MM_NULLTAG sont des synonymes pour ((char *) 0), la chaîne vide, et MM_NULLSEV est un synonyme pour NO_S

ENVIRONNEMEN

T

La variable d'environnement MSGVERB (« message verbosity ») peut être utilisée pour supprimer des parties de la sortie vers stderr. (Elle n'influence pas la sortie vers la console.) Lorsque cette variable est définie, non-NULL, et est une liste de mots-clés valides séparés par des deux-points, alors seulement les parties du message correspondant à ces mots-clés sont imprimées. Les mots-clés valides sont « label », « severity », « text », « action » et « tag »

.

La variable d'environnement SEV_LEVEL peut être utilisée pour introduire de nouveaux niveaux de gravité. Par défaut, seulement les cinq niveaux de gravité décrits ci-dessus sont disponibles. Toute autre valeur numérique ferait que fmtmsg() n'imprime rien. Si l'utilisateur place SEV_LEVEL avec un format

comme
SEV_LEVEL=[description[:description[:...]]
]

dans l'environnement du processus avant le premier appel à fmtmsg(), où chaque description est de la

forme
severity-keyword,level,
printstring

alors fmtmsg() acceptera aussi les valeurs indiquées pour le niveau (en plus des niveaux standards 0–4), et utilisera la printstring indiquée lorsqu'un tel niveau se

produit.

La partie severity-keyword n'est pas utilisée par fmtmsg() mais elle doit être présente. La partie level est une représentation textuelle d'un nombre. La valeur numérique doit être un nombre supérieur à 4. Cette valeur doit être utilisée dans l'argument severity de fmtmsg() pour sélectionner cette classe. Il n'est pas possible d'écraser l'une des classes prédéfinies. La printstring est la chaîne imprimée lorsqu'un message de cette classe est traité par fmtm

sg(

EXEMPLE

S 
#include <fmtmsg.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    long class = MM_PRINT | MM_SOFT | MM_OPSYS | MM_RECOVER;
    int err;
    err = fmtmsg(class, "util-linux:mount", MM_ERROR,
                 "unknown mount option", "See mount(8).",
                 "util-linux:mount:017");
    switch (err) {
    case MM_OK:
        break;
    case MM_NOTOK:
        printf("Nothing printed\n");
        break;
    case MM_NOMSG:
        printf("Nothing printed to stderr\n");
        break;
    case MM_NOCON:
        printf("No console output\n");
        break;
    default:
        printf("Unknown error from fmtmsg()\n");
    }
    exit(EXIT_SUCCESS);
}
