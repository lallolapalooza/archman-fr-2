NOM

flatpak-remotes - Liste les dépôts distants

SYNOPSIS

flatpak remotes [OPTION...]

DESCRIPTION

Liste les dépôts distants connus, dans l'ordre de priorité.

Par défaut, les installations pour l'utilisateur et pour tout le système sont affichées. Utilisez les options --user, --system ou --installation pour modifier ce comportement.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

-u, --user

Affiche la configuration spécifique à l'utilisateur.

--system

Affiche la configuration système par défaut.

--installation=NOM

Affiche une installation système par NOM parmi celles définies dans /etc/flatpak/installations.d/. L'utilisation de --installation=default est équivalente à l'utilisation de --system.

-d, --show-details

Affiche plus d'informations pour chaque dépôt en plus du nom. Équivalent à --columns=all.

--show-disabled

Affiche les dépôts désactivés.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage OSTree pendant le traitement de la commande.

--columns=CHAMP,...

Spécifie quelles informations afficher sur chaque référence. Vous pouvez lister plusieurs champs, ou utiliser cette option plusieurs fois.

Ajoutez :s[tart], :m[iddle], :e[nd] ou :f[ull] aux noms de colonne pour modifier l'élision.

CHAMPS

Les champs suivants sont compris par l'option --columns :

name

Affiche le nom du dépôt distant

title

Affiche le titre du dépôt distant

url

Affiche l'URL du dépôt distant

filter

Affiche le chemin du filtre côté client du dépôt.

collection

Affiche l'ID de la collection du dépôt

priority

Affiche la priorité du dépôt

options

Affiche les options

comment

Affiche le commentaire

description

Affiche la description

homepage

Affiche la page d'accueil

icon

Affiche l'icône

all

Affiche toutes les colonnes

help

Affiche la liste des colonnes disponibles

Notez que les noms de champ peuvent être abrégés en un préfixe unique.

EXEMPLES

$ flatpak remotes --user --show-details

testrepo	Test Repository	 http://209.132.179.91/repo/ no-gpg-verify
