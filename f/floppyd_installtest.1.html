Nom

floppyd_installtest - teste si floppyd est installé et en cours d'exécution

Note de mise en garde

Cette page de manuel a été générée automatiquement à partir de la documentation texinfo de mtools, et peut ne pas être entièrement exacte ou complète. Voir la fin de cette page de manuel pour plus de détails.

Description

Floppyd_installtest est utilisé pour vérifier la présence d'un démon floppyd en cours d'exécution. Ceci est utile si vous avez un petit script frontal pour mtools, qui décide d'utiliser ou non floppyd.

floppyd_installtest [-f] ChaîneDeConnexion

Si l'option -f est spécifiée, floppyd_installtest effectue une authentification X-Cookie complète et se plaint si cela ne fonctionne pas.

La ChaîneDeConnexion a le format décrit dans la section floppyd : nom_hote:numerodisplay[/portbase]
