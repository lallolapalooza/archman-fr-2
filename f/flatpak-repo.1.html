NOM

flatpak-repo - Afficher des informations sur un dépôt local

SYNTAXE

flatpak repo [OPTION...]EMPLACEMENT

DESCRIPTION

Affiche des informations sur un dépôt local.

Si vous devez modifier un dépôt local, consultez la commande flatpak build-update-repo, ou utilisez l'outil ostree.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

--info

Affiche des informations générales sur un dépôt local.

--branches

Liste les branches dans un dépôt local.

--metadata=BRANCH

Affiche les métadonnées d'une branche dans le dépôt.

--commits=BRANCH

Affiche les commits et les deltas pour une branche dans le dépôt.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak repo --info ~/my-repo
