NOM

getaddrinfo, freeaddrinfo, gai_strerror - résolution d'adresse réseau indépendante du protocole

SYNTAXE

#include <sys/types.h>
#include <sys/socket.h>
#include <netdb.h>

int getaddrinfo(const char *node, const char *service,
                const struct addrinfo *hints,
                struct addrinfo **res);

void freeaddrinfo(struct addrinfo *ai);

const char *gai_strerror(int errcode);

DESCRIPTION

La fonction getaddrinfo() est une interface de résolution d'adresse réseau qui traduit un nom d'hôte et un nom de service en une liste de structures d'adresses de socket, utilisables avec les fonctions socket d'interface de programmation d'application (API) de bas niveau. La fonction freeaddrinfo() libère la mémoire allouée par getaddrinfo(). La fonction gai_strerror() traduit les codes d'erreur retournés par getaddrinfo() en une chaîne de caractères lisible par l'homme.

Les paramètres sont les suivants :

node
Désigne le nœud d'hôte. Il s'agit soit d'un nom d'hôte textuel, soit d'une adresse réseau textuelle (voir inet_addr(3), inet_ntop(3) pour les formats). Si node est NULL, alors la structure d'adresse sera retournée pour un nœud local.
service
Désigne le service. Il s'agit soit d'un nom de service textuel (par exemple, "http"), soit d'un nombre décimal textuel représentant la valeur de port. Si service est NULL, alors la valeur de port est laissée indéterminée.
hints
Il s'agit d'un pointeur vers une structure addrinfo qui spécifie les exigences pour les adresses retournées. Si hints est NULL, alors aucune exigence particulière n'est spécifiée.
res
Il s'agit d'un pointeur vers un pointeur de structure addrinfo. Si getaddrinfo() réussit, ce pointeur pointera vers une liste chaînée de structures addrinfo, représentant toutes les adresses réseau disponibles pour le nœud et le service spécifiés. La liste est terminée par un pointeur NULL.

La structure addrinfo est définie comme suit :

struct addrinfo {
    int     ai_flags;     // Flags (voir ci-dessous).
    int     ai_family;    // Famille d'adresses (AF_UNSPEC, AF_INET, AF_INET6, ...).
    int     ai_socktype;  // Type de socket (SOCK_STREAM, SOCK_DGRAM, ...).
    int     ai_protocol;  // Protocole (IPPROTO_TCP, IPPROTO_UDP, ...).
    size_t  ai_addrlen;   // Longueur de l'adresse.
    struct sockaddr *ai_addr; // Pointeur vers la structure d'adresse du socket.
    char    *ai_canonname; // Nom canonique du nœud.
    struct addrinfo *ai_next; // Pointeur vers la prochaine structure addrinfo dans la liste.
};

Le champ hints.ai_family spécifie la famille d'adresses souhaitée. Les valeurs possibles sont :

AF_UNSPEC
Aucune préférence pour la famille d'adresses (accepte IPv4 ou IPv6).
AF_INET
IPv4.
AF_INET6
IPv6.

Le champ hints.ai_socktype spécifie le type de socket souhaité. Les valeurs courantes sont :

SOCK_STREAM
Socket de flux (TCP).
SOCK_DGRAM
Socket de datagramme (UDP).
0
Accepte n'importe quel type de socket.

Le champ hints.ai_protocol spécifie le protocole souhaité (par exemple, IPPROTO_TCP ou IPPROTO_UDP). Si 0, n'importe quel protocole est accepté.

Les drapeaux suivants peuvent être spécifiés dans hints.ai_flags :

AI_PASSIVE
Indique que le socket sera utilisé pour un appel bind(2). Si node est NULL, alors l'adresse de l'interface locale sera utilisée. Si AI_PASSIVE est spécifié et que node est NULL, getaddrinfo() retournera une adresse qui peut être utilisée pour lier un socket afin d'écouter les connexions entrantes.
AI_CANONNAME
Si cet indicateur est défini, alors le champ ai_canonname de la première structure retournée contiendra le nom canonique du nœud.
AI_NUMERICHOST
Si cet indicateur est défini, alors node doit être une adresse numérique valide. Cela empêche la résolution de nom et permet d'éviter les délais en cas d'échec de résolution.
AI_NUMERICSERV
Si cet indicateur est défini, alors service doit être une chaîne numérique représentant un port. Cela empêche la recherche dans la base de données des services (par exemple, getservbyname(3)).
AI_ADDRCONFIG
Si le drapeau AI_ADDRCONFIG est spécifié, alors les adresses IPv4 sont retournées dans la liste pointée par res uniquement si le système local possède au moins une adresse IPv4 configurée, et les adresses IPv6 sont retournées uniquement si le système local possède au moins une adresse IPv6 configurée. L'adresse de bouclage n'est pas considérée comme valide dans ce cas. Ce drapeau est utile sur, par exemple, les systèmes uniquement IPv4, pour s'assurer que getaddrinfo() ne retourne pas d'adresses de socket IPv6 qui échoueraient toujours lors de connect(2) ou bind(2).
AI_V4MAPPED
Si hints.ai_flags spécifie le drapeau AI_V4MAPPED, et que hints.ai_family a été spécifié comme AF_INET6, et qu'aucune adresse IPv6 correspondante n'a pu être trouvée, alors retourner des adresses IPv6 mappées en IPv4 dans la liste pointée par res. Si AI_V4MAPPED et AI_ALL sont tous deux spécifiés dans hints.ai_flags, alors retourner à la fois des adresses IPv6 et IPv6 mappées en IPv4 dans la liste pointée par res. AI_ALL est ignoré si AI_V4MAPPED n'est pas également spécifié.
AI_ALL
Voir la description du drapeau AI_V4MAPPED ci-dessus.

La fonction freeaddrinfo() libère la mémoire qui a été allouée pour la liste chaînée dynamique res.

Extensions de getaddrinfo() pour les Noms de Domaine Internationalisés

Depuis glibc 2.3.4, getaddrinfo() a été étendu pour permettre sélectivement la conversion transparente des noms d'hôte entrants et sortants au format Noms de Domaine Internationalisés (IDN) et vice-versa (voir RFC 3490, Internationalizing Domain Names in Applications (IDNA)). Quatre nouveaux drapeaux sont définis :

AI_IDN
Si ce drapeau est spécifié, alors le nom de nœud donné dans node est converti au format IDN si nécessaire. Le codage source est celui de la locale actuelle.
Si le nom d'entrée contient des caractères non-ASCII, alors le codage IDN est utilisé. Les parties du nom de nœud (délimitées par des points) qui contiennent des caractères non-ASCII sont encodées en ASCII Compatible Encoding (ACE) avant d'être passées aux fonctions de résolution de nom.
AI_CANONIDN
Après une recherche de nom réussie, et si le drapeau AI_CANONNAME a été spécifié, getaddrinfo() retournera le nom canonique du nœud correspondant à la valeur de la structure addrinfo renvoyée. La valeur de retour est une copie exacte de la valeur renvoyée par la fonction de résolution de nom.
Si le nom est encodé en utilisant ACE, alors il contiendra le préfixe xn-- pour un ou plusieurs composants du nom. Pour convertir ces composants en une forme lisible, le drapeau AI_CANONIDN peut être passé en plus de AI_CANONNAME. La chaîne résultante est encodée en utilisant le codage de la locale actuelle.
AI_IDN_ALLOW_UNASSIGNED
AI_IDN_USE_STD3_ASCII_RULES
La définition de ces drapeaux activera respectivement les drapeaux IDNA_ALLOW_UNASSIGNED (autoriser les points de code Unicode non assignés) et IDNA_USE_STD3_ASCII_RULES (vérifier que la sortie est un nom d'hôte conforme à STD3) pour être utilisés dans la gestion IDNA.

VALEUR RENVOYÉE

getaddrinfo() renvoie 0 en cas de succès, ou l'un des codes d'erreur non nuls suivants :

EAI_ADDRFAMILY
L'hôte réseau spécifié n'a aucune adresse réseau dans la famille d'adresses demandée.
EAI_AGAIN
Le serveur de noms a renvoyé une indication d'échec temporaire. Réessayez plus tard.
EAI_BADFLAGS
hints.ai_flags contient des drapeaux invalides ; ou, hints.ai_flags incluait AI_CANONNAME et node était NULL.
EAI_FAIL
Le serveur de noms a renvoyé une indication d'échec permanent.
EAI_FAMILY
La famille d'adresses demandée n'est pas supportée.
EAI_MEMORY
Mémoire insuffisante.
EAI_NODATA
L'hôte réseau spécifié existe, mais n'a pas d'adresses réseau définies.
EAI_NONAME
Le node ou le service n'est pas connu ; ou le node et le service sont tous deux NULL ; ou AI_NUMERICSERV a été spécifié dans hints.ai_flags et service n'était pas une chaîne numérique représentant un numéro de port.
EAI_SERVICE
Le service demandé n'est pas disponible pour le type de socket demandé. Il peut être disponible via un autre type de socket. Par exemple, cette erreur pourrait se produire si service était "shell" (un service disponible uniquement sur les sockets de flux), et que soit hints.ai_protocol était IPPROTO_UDP, soit hints.ai_socktype était SOCK_DGRAM ; ou l'erreur pourrait se produire si service n'était pas NULL, et hints.ai_socktype était SOCK_RAW (un type de socket qui ne supporte pas le concept de services).
EAI_SOCKTYPE
Le type de socket demandé n'est pas supporté. Cela pourrait se produire, par exemple, si hints.ai_socktype et hints.ai_protocol sont incohérents (par exemple, SOCK_DGRAM et IPPROTO_TCP, respectivement).
EAI_SYSTEM
Autre erreur système ; errno est défini pour indiquer l'erreur.

La fonction gai_strerror() traduit ces codes d'erreur en une chaîne lisible par l'homme, adaptée au rapport d'erreurs.

#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/socket.h>
#include <sys/types.h>
#include <unistd.h>
#define BUF_SIZE 500
int
main(int argc, char *argv[])
{
    int              sfd, s;
    char             buf[BUF_SIZE];
    size_t           size;
    ssize_t          nread;
    struct addrinfo  hints;
    struct addrinfo  *result, *rp;
    if (argc < 3) {
        fprintf(stderr, "Usage: %s host port msg...\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /* Obtenir l'adresse(s) correspondant à host/port.  */
    memset(&hints, 0, sizeof(hints));
    hints.ai_family = AF_UNSPEC;    /* Autoriser IPv4 ou IPv6 */
    hints.ai_socktype = SOCK_DGRAM; /* Socket datagramme */
    hints.ai_flags = 0;
    hints.ai_protocol = 0;          /* Tout protocole */
    s = getaddrinfo(argv[1], argv[2], &hints, &result);
    if (s != 0) {
        fprintf(stderr, "getaddrinfo: %s\n", gai_strerror(s));
        exit(EXIT_FAILURE);
    }
    /* getaddrinfo() renvoie une liste de structures d'adresses.
       Essayer chaque adresse jusqu'à ce que nous réussissions à nous connecter.
       Si socket(2) (ou connect(2)) échoue, nous (fermons le socket
       et) essayons la prochaine adresse.  */
    for (rp = result; rp != NULL; rp = rp->ai_next) {
        sfd = socket(rp->ai_family, rp->ai_socktype,
                     rp->ai_protocol);
        if (sfd == -1)
            continue;
        if (connect(sfd, rp->ai_addr, rp->ai_addrlen) != -1)
            break;                  /* Succès */
        close(sfd);
    }
    freeaddrinfo(result);           /* Plus nécessaire */
    if (rp == NULL) {               /* Aucune adresse n'a réussi */
        fprintf(stderr, "Impossible de se connecter\n");
        exit(EXIT_FAILURE);
    }
    /* Envoyer les arguments restants de la ligne de commande en tant que
       datagrammes distincts, et lire les réponses du serveur.  */
    for (size_t j = 3; j < argc; j++) {
        size = strlen(argv[j]) + 1;
                /* +1 pour le caractère nul de fin */
        if (size > BUF_SIZE) {
            fprintf(stderr,
                    "Ignorer le long message dans l'argument %zu\n", j);
            continue;
        }
        if (write(sfd, argv[j], size) != size) {
            fprintf(stderr, "écriture partielle/échouée\n");
            exit(EXIT_FAILURE);
        }
        nread = read(sfd, buf, BUF_SIZE);
        if (nread == -1) {
            perror("read");
            exit(EXIT_FAILURE);
        }
        printf("Reçu %zd octets : %s\n", nread, buf);
    }
    exit(EXIT_SUCCESS);
}
