fragrouter6(8)

Paquet: thc-ipv6

Licences: AGPL3

fragrouter6(8) IPv6 fragrouter6(8)

NOM

fragrouter6

SYNOPSIS

fragrouter6 [-dv -f len -e count -t count] INTERFACE METHODE-EVASION

OPTIONS

  -f len    taille des mini fragments (option 64, défaut 8)
  -e count  compteur de sauts vers l'IDS pour l'évasion (option 256 & 512)
  -t count  compteur de sauts vers la cible pour l'atteindre
  -v        mode verbeux, affiche tous les paquets traités pour l'évasion

METHODES EVASION


0 aucune manipulation
1-31 le nombre d'en-têtes de fragmentation atomique à insérer
32 utilisation des en-têtes de destination pour 1-31 au lieu des en-têtes de fragmentation
64 fragmente chaque paquet en morceaux de 8 octets (ou modifiable avec -f)
128 un grand en-tête de destination qui fragmente le paquet
256 insertion d'un faux paquet de données TCP avec un compteur de sauts juste pour l'IDS (-e)
512 insertion d'un paquet de réinitialisation de connexion TCP avec un compteur de sauts juste pour l'IDS (-e)
1024 insertion de fausses données de fragmentation avec un compteur de sauts juste pour l'IDS (-e)
2048 insertion d'un paquet TCP avec des données seq/ack falsifiées

Effectue l'évasion NIDS/NIPS sur tous les paquets définis qui proviennent de votre système ou le traversent. Toutes les méthodes d'évasion peuvent être combinées (additionnées) à l'exception que seule l'une des options 64 ou 128 peut être utilisée à la fois. L'option 1024 peut être utilisée avec 1..31 et 64. Les méthodes d'évasion sont traitées dans l'ordre suivant : 256, 512, 2048, 1..31/33..63 puis soit 64 soit 128 puis 1024. Nécessite la configuration de règles ip6table qui sautent vers NFQUEUE, utilisez fragrouter6.sh qui est un wrapper pour ip6tables et fragrouter6 !
