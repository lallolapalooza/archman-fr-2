DESCRIPTIO

N

Les fonctions fts sont fournies pour parcourir des hiérarchies de fichiers. Un aperçu simple est que la fonction fts_open() renvoie un « descripteur » (de type FTS *) qui fait référence à un « flux » de hiérarchie de fichiers. Ce descripteur est ensuite fourni aux autres fonctions fts. La fonction fts_read() renvoie un pointeur vers une structure décrivant l'un des fichiers de la hiérarchie de fichiers. La fonction fts_children() renvoie un pointeur vers une liste chaînée de structures, chacune décrivant l'un des fichiers contenus dans un répertoire de la

hiérarchie.

En général, les répertoires sont visités deux fois de manière distinguable ; en préordre (avant que l'un de leurs descendants soit visité) et en postordre (après que tous leurs descendants ont été visités). Les fichiers sont visités une seule fois. Il est possible de parcourir la hiérarchie « logiquement » (en visitant les fichiers vers lesquels pointent les liens symboliques) ou physiquement (en visitant les liens symboliques eux-mêmes), d'ordonner le parcours de la hiérarchie ou de tailler et/ou de revisiter des parties de la

hiérarchie.

Deux structures (et types associés) sont définies dans le fichier d'inclusion <fts.h>. Le premier type est FTS, la structure qui représente la hiérarchie de fichiers elle-même. Le deuxième type est FTSENT, la structure qui représente un fichier dans la hiérarchie de fichiers. Normalement, une structure FTSENT est renvoyée pour chaque fichier de la hiérarchie de fichiers. Dans cette page de manuel, « fichier » et « structure FTSENT » sont généralement interchangeables

.

La structure FTSENT contient des champs décrivant un fichier. La structure contient au moins les champs suivants (il existe des champs supplémentaires qui doivent être considérés comme privés à l'implémentation) 

: 


typedef struct _ftsent {
    unsigned short  fts_info;     /* drapeaux pour la structure FTSENT */
    char           *fts_accpath;  /* chemin d'accès */
    char           *fts_path;     /* chemin racine */
    short           fts_pathlen;  /* strlen(fts_path) +
                                     strlen(fts_name) */
    char           *fts_name;     /* nom de fichier */
    short           fts_namelen;  /* strlen(fts_name) */
    short           fts_level;    /* profondeur (-1 à N) */
    int             fts_errno;    /* errno du fichier */
    long            fts_number;   /* valeur numérique locale */
    void           *fts_pointer;  /* valeur d'adresse locale */
    struct _ftsent *fts_parent;   /* répertoire parent */
    struct _ftsent *fts_link;     /* structure du fichier suivant */
    struct _ftsent *fts_cycle;    /* structure de cycle */
    struct stat    *fts_statp;    /* informations [l]stat(2) */
}
