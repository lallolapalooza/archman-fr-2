NOM

flatpak-update - Met à jour une application ou un runtime

SYNTAXE

flatpak update [OPTION...] [REF...]

flatpak update [OPTION...] --appstream [REMOTE]

DESCRIPTION

Met à jour les applications et les runtimes. REF est une référence vers l'application ou le runtime à mettre à jour. Si aucun REF n'est donné, tout est mis à jour, ainsi que les informations appstream pour toutes les sources.

Chaque argument REF est un identifiant complet ou partiel au format de référence flatpak, qui ressemble à "(app|runtime)/ID/ARCH/BRANCH". Tous les éléments sauf ID sont facultatifs et peuvent être omis, y compris les barres obliques, donc la plupart du temps vous n'avez besoin de spécifier que l'ID. Toute partie omise sera comparée à ce qui est installé, et s'il y a plusieurs correspondances, un message d'erreur listera les alternatives.

Par défaut, ceci recherche les applications et les runtimes avec le REF donné, mais vous pouvez limiter cela en utilisant l'option --app ou --runtime, ou en fournissant l'élément initial dans le REF.

Normalement, cette commande met à jour l'application vers la dernière version de sa branche. Mais il est possible de basculer vers un autre commit, avec l'option --commit.

Si la source configurée pour un ref en cours de mise à jour a un ID de collection configuré, Flatpak recherchera dans les répertoires sideload-repos configurés soit avec l'option --sideload-repo, soit par installation individuelle ou globale (voir flatpak(1)).

Notez que la mise à jour d'un runtime est différente de l'installation d'une branche différente, et les mises à jour de runtimes sont censées maintenir une compatibilité stricte. Si une mise à jour d'application cause un problème, il est possible de revenir à la version précédente, avec l'option --commit.

En plus des mises à jour, cette commande proposera de désinstaller tous les runtimes obsolètes inutilisés. Les runtimes qui ont été explicitement installés (pas en tant que dépendance) ou explicitement épinglés (voir flatpak-pin(1)) restent installés même s'ils sont inutilisés et obsolètes.

Sauf indication contraire avec les options --user, --system ou --installation, cette commande met à jour tous les refs correspondants dans l'installation système par défaut et celle par utilisateur.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

-u, --user

Met à jour une installation par utilisateur.

--system

Met à jour l'installation système par défaut.

--installation=NOM

Met à jour une installation système spécifiée par NOM parmi celles définies dans /etc/flatpak/installations.d/. L'utilisation de --installation=default est équivalente à l'utilisation de --system.

--arch=ARCH

L'architecture à mettre à jour. Voir flatpak --supported-arches pour les architectures prises en charge par l'hôte.

--subpath=CHEMIN

Installe uniquement une sous-partie du ref. Ceci est principalement utilisé pour installer un sous-ensemble de locales. Ceci peut être ajouté plusieurs fois pour installer plusieurs sous-parties. Si ceci n'est pas spécifié, les sous-parties spécifiées lors de l'installation sont réutilisées.

--commit=COMMIT

Met à jour vers ce commit, au lieu de la dernière version de la branche. Vous pouvez trouver les commits en utilisant flatpak remote-info --log REMOTE REF.

--no-deploy

Télécharge la dernière version, mais ne la déploie pas.

--no-pull

Ne télécharge pas la dernière version, déploie ce qui est localement disponible.

--no-related

Ne télécharge pas les extensions associées, telles que les données de locale.

--no-deps

Ne met pas à jour ou n'installe pas les dépendances du runtime lors de l'installation.

--app

Ne recherche qu'une application portant le nom donné.

--appstream

Met à jour appstream pour REMOTE, ou toutes les sources si aucune source n'est spécifiée.

--runtime

Ne recherche qu'un runtime portant le nom donné.

--sideload-repo=CHEMIN

Ajoute un dépôt ostree local supplémentaire comme source pour l'installation. Ceci est équivalent à utiliser les répertoires sideload-repos (voir flatpak(1)), mais peut être fait sur une base commande par commande. Tout chemin ajouté ici est utilisé en plus de ceux présents dans ces répertoires.

-y, --assumeyes

Répond automatiquement oui à toutes les questions (ou choisit la réponse la plus prioritaire). Ceci est utile pour l'automatisation.

--noninteractive

Produit une sortie minimale et évite la plupart des questions. Ceci est adapté à une utilisation dans des situations non interactives, par exemple dans un script de construction.

--force-remove

Supprime les anciens fichiers même s'ils sont utilisés par une application en cours d'exécution.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak --user update org.gnome.gedit
