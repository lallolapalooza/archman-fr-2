NOM

flatpak-repair - Répare une installation flatpak

SYNTAXE

flatpak repair [OPTION...)

DESCRIPTION

Réparer une installation flatpak en élaguant et réinstallant les objets invalides. La commande de réparation effectue toutes les actions suivantes :

•Analyse toutes les références disponibles localement, en supprimant celles qui ne correspondent à aucune référence déployée.
•Vérifie chaque commit auquel elles pointent, en supprimant les objets invalides et en notant les objets manquants.
•Supprime toutes les références qui avaient un objet invalide, et toutes les références non partielles qui avaient des objets manquants.
•Élague tous les objets non référencés par une référence, ce qui élimine les objets potentiellement invalides non analysés.
•Énumère toutes les références déployées et réinstalle celles qui ne sont pas dans le dépôt (ou qui sont partielles pour un déploiement de sous-répertoire).

Notez que flatpak repair doit être exécuté avec les privilèges root pour opérer sur l'installation système.

Une commande alternative pour réparer les dépôts OSTree est ostree fsck.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

-u, --user

Réparer l'installation par utilisateur.

--system

Réparer l'installation à l'échelle du système.

--installation=NOM

Réparer l'installation à l'échelle du système spécifiée par NOM parmi celles définies dans /etc/flatpak/installations.d/. Utiliser --installation=default est équivalent à utiliser --system.

--dry-run

Signaler uniquement les incohérences, sans apporter de modifications.

--reinstall-all

Réinstaller toutes les références, qu'elles aient été supprimées du dépôt ou non.

-v, --verbose

Afficher les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Afficher les informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

$ sudo flatpak repair

$ flatpak repair --user
