form_field_info(3x)

Paquet: ncurses

Licences: MIT-open-group

form_field_info(3X) Appels de bibliothèque form_field_info(3X)

NOM

dynamic_field_info, field_info - récupérer les caractéristiques d'un champ

SYNTAXE

#include <form.h>
int field_info(const FIELD *field,
               int *rows, int *cols,
               int *frow, int *fcol,
               int *nrow, int *nbuf);
int dynamic_field_info(const FIELD *field,
                       int *rows, int *cols, int *max);

DESCRIPTION

La fonction field_info renvoie les tailles et autres attributs passés lors de la création du champ. Les attributs sont : la hauteur, la largeur, la ligne du coin supérieur gauche, la colonne du coin supérieur gauche, le nombre de lignes hors écran et le nombre de tampons de travail.

La fonction dynamic_field_info renvoie la taille réelle du champ et sa taille maximale possible. Si le champ n'a pas de limite de taille, l'emplacement pointé par le troisième argument sera mis à 0. Un champ peut être rendu dynamique en désactivant l'option O_STATIC avec field_opts_off.

VALEUR DE RETOUR

Ces routines renvoient l'une des valeurs suivantes :

E_OK
La routine a réussi.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors plage.

PORTABILITE

Ces routines imitent la bibliothèque de formulaires System V. Elles n'étaient pas prises en charge sur les versions 7 ou BSD.

Un pointeur nul (zéro) est accepté pour n'importe laquelle des valeurs de retour, afin d'ignorer cette valeur. Toutes les implémentations ne l'autorisent pas, par exemple, Solaris 2.7 ne le permet pas.
