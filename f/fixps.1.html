FIXPS(1) Commandes utilisateur FIXPS(1)

NOM

fixps - assainir les fichiers PostScript

SYNTAXE

fixps [OPTIONS] FICHIER

DESCRIPTION

Essayer de corriger les problèmes courants de PostScript qui bloquent le post-traitement.

OPTIONS

-h, --help
afficher cette aide et quitter
-v, --version
afficher les informations de version et quitter
-q, --quiet
ne pas afficher les messages d'information
-o, --output=FICHIER
sauvegarder le résultat dans FICHIER. Si FICHIER est `-', envoyer sur la sortie standard
-c, --check, --dry-run
ne réaliser aucune action
