FreeHDL-CONFIG(1) Commandes utilisateur FreeHDL-CONFIG(1)

NOM

FreeHDL-CONFIG - Script de configuration de FreeHDL.

SYNTAXE

freehdl-config [OPTION] ...

DESCRIPTION

FreeHDL est une suite d'analyseur/compilateur/simulateur pour le langage de description matérielle VHDL. Les fichiers VHDL'93 ainsi que VHDL'87 sont supportés.

FreeHDL-CONFIG peut être utilisé pour obtenir la configuration d'installation (chemins) du paquet FreeHDL.

OPTIONS

-v, --version
afficher la version installée de FreeHDL
-h, --help
afficher les informations d'utilisation
-l, --ldflags
afficher les bibliothèques à lier
-libs, --libtool
afficher les bibliothèques libtool à lier
-ieee, --ieee
afficher les bibliothèques libtool IEEE à lier
-c, --cxxflags
afficher les indicateurs du compilateur C++ pour compiler
-cxx, --cxx
afficher le compilateur C++ -linker, --linker afficher l'éditeur de liens libtool

VOIR AUSSI

gvhdl(1), freehdl-v2cc(1), v2cc.libs(5)

DISPONIBILITÉ
