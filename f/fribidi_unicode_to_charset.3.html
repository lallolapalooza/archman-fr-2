NOM

fribidi_unicode_to_charset - convertir une chaîne de l'Unicode

SYNTAXE

#include <../fribidi/lib/fribidi.h>

FriBidiStrIndex fribidi_unicode_to_charset
(
FriBidiCharSet char_set,
const FriBidiChar *us,
FriBidiStrIndex len,
char *s
);

PARAMETRES

FriBidiCharSet char_set
Ensemble de caractères vers lequel convertir.

Les valeurs possibles pour un FriBidiCharSet sont les suivantes :

FRIBIDI_CHAR_SET_UTF8
UTF-8 (Unicode).
FRIBIDI_CHAR_SET_CAP_RTL
CapRTL (Test).
FRIBIDI_CHAR_SET_ISO8859_6
ISO8859-6 (Arabe).
FRIBIDI_CHAR_SET_ISO8859_8
ISO8859-8 (Hébreu).
FRIBIDI_CHAR_SET_CP1255
CP1255 (MS Hébreu/Yiddish).
FRIBIDI_CHAR_SET_CP1256
CP1256 (MS Arabe).
const FriBidiChar *us
Chaîne Unicode d'entrée.
FriBidiStrIndex len
Longueur de la chaîne d'entrée.
char *s
Chaîne de sortie encodée dans char_set.

DESCRIPTION

Cette fonction convertit une chaîne Unicode en une chaîne dans un autre ensemble de caractères. Elle termine également la chaîne de sortie par un caractère nul.

RETOUR

La longueur de la nouvelle chaîne.
