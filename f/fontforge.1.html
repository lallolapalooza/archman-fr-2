DESCRIPTIO

N

FontForge lira les polices PostScript (pfa, pfb, ps, cid), OpenType (otf), TrueType (ttf, ttc), polices de ressources Macintosh (dfont, bin, hqx), Scaled Vector Graphics (svg), bitmap TeX (pk), Glyph Bitmap Distribution Format (bdf), et bitmap X11 (pcf). Les fichiers de polices peuvent être compressés avec gzip (par exemple, mapolice.pcf.gz). FontForge lira également son propre format : les fichiers Spline Font Database (sfd)

.

Si la liste d'arguments contient un nom de fichier de police (ou plusieurs), fontforge ouvrira une fenêtre de visualisation de police pour chaque police affichant les caractères de cette police. En l'absence d'options ou d'arguments, le programme ouvre une fenêtre de sélection de fichier, vous permettant de parcourir votre disque pour trouver un fichier de police, ou d'en créer un

nouveau.

Cette page de manuel n'est destinée qu'à un aperçu rudimentaire ; voir le manuel utilisateur HTML pour des informations plus

complètes.

Si aucun fichier de police n'est spécifié, et que ni -new n'est spécifié, et qu'il n'y a rien à récupérer, alors FontForge produira une boîte de dialogue d'ouverture de

police.

Si un fichier de script est spécifié, alors FontForge n'ouvrira pas l'affichage X, et ne traitera aucun argument supplémentaire. Il exécutera le fichier de script et lui transmettra tous les arguments

restants.

Si le premier argument est un nom de fichier exécutable, et que la première ligne de ce fichier contient "fontforge", alors il sera traité comme un fichier d

e scr
ipt.
