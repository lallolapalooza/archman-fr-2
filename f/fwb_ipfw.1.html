NOM

fwb_ipfw - Compilateur de politiques pour ipfw

SYNTAXE

fwb_ipfw [-vVx] [-d wdir] [-o output.fw] [-i] -f data_file.xml nom_objet

DESCRIPTION

fwb_ipfw est un composant compilateur de politiques de pare-feu de Firewall Builder (voir fwbuilder(1)). Ce compilateur génère du code pour ipfw, un pare-feu et un configureur de trafic sous FreeBSD (voir ipfw(8)). Le compilateur lit les définitions d'objets et la description du pare-feu à partir du fichier de données spécifié avec l'option « -f » et génère un script d'activation et de configuration du pare-feu.

Le fichier généré porte un nom qui commence par le nom de l'objet du pare-feu, avec l'extension « .fw ». C'est un script shell qui efface la politique actuelle, puis charge les nouvelles règles de filtrage et de NAT.

Le fichier de données et le nom de l'objet du pare-feu doivent être spécifiés sur la ligne de commande. Les autres paramètres de la ligne de commande sont optionnels.

OPTIONS

-f FICHIER
Spécifie le nom du fichier de données à traiter.
-o output.fw
Spécifie le nom du fichier de sortie.
-d wdir
Spécifie le répertoire de travail. Le compilateur crée le script d'activation du pare-feu dans ce répertoire. Si ce paramètre est absent, tous les fichiers seront placés dans le répertoire de travail courant.
-v
Être verbeux : le compilateur affiche des messages diagnostiques pendant son exécution.
-V
Affiche le numéro de version et quitte.
-i
Lorsque cette option est présente, le dernier argument de la ligne de commande est supposé être l'identifiant de l'objet du pare-feu plutôt que son nom.
-x
Génère des informations de débogage pendant l'exécution. Cette option est destinée uniquement au débogage et peut produire de nombreux messages cryptiques.

NOTES

Le support d'ipfw a été ajouté dans la version 1.0.10 de Firewall Builder.
