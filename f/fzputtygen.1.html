NOM

fzputtygen - Convertisseur de clé privée SFTP de FileZilla

DESCRIPTION

fzputtygen fait partie de FileZilla. Il est utilisé pour convertir les clés privées des formats OpenSSH ou ssh.com dans un format compréhensible par fzsftp. Il est généralement appelé par FileZilla et n'est pas destiné à être utilisé directement.

fzputtygen est basé sur le composant puttygen de PuTTY.

SUPPORT

Veuillez visiter https://filezilla-project.org/ pour plus d'informations. Ne signalez les bogues que si vous utilisez la dernière version disponible sur le site web de FileZilla.
