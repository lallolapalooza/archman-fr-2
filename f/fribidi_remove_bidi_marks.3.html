NOM

fribidi_remove_bidi_marks - supprimer les marques bidi d'une chaîne

SYNTAXE

#include <../fribidi/lib/fribidi.h>

FriBidiStrIndex fribidi_remove_bidi_marks
(
FriBidiChar *str,
const FriBidiStrIndex len,
FriBidiStrIndex *positions_to_this,
FriBidiStrIndex *position_from_this_list,
FriBidiLevel *embedding_levels
);

PARAMETRES

FriBidiChar *str
Chaîne d'entrée à nettoyer.
const FriBidiStrIndex len
Longueur de la chaîne d'entrée.
FriBidiStrIndex *positions_to_this
Liste mappant les positions à l'ordre utilisé dans str.
FriBidiStrIndex *position_from_this_list
Liste mappant les positions depuis l'ordre utilisé dans str.
FriBidiLevel *embedding_levels
Liste des niveaux d'intégration.

DESCRIPTION

Cette fonction supprime les marques bidi et neutres de limites d'une chaîne et des listes associées. Elle implémente la règle X9 de l'algorithme bidirectionnel Unicode disponible à l'adresse http://www.unicode.org/reports/tr9/#X9, à l'exception qu'elle supprime également les marques U+200E GAUCHE-À-DROITE et U+200F DROITE-À-GAUCHE.

Si l'une des listes d'entrée est NULL, la liste est ignorée. Si str est la chaîne visuelle, alors positions_to_this est positions_L_to_V et position_from_this_list est positions_V_to_L ; si str est la chaîne logique, c'est l'inverse. De plus, les cartes de position doivent être remplies avec des entrées valides.

Une carte de position pointant vers un caractère supprimé est remplie avec −1. Soit dit en passant, vous ne devriez pas utiliser embedding_levels si str est une chaîne visuelle.

Pour de meilleurs résultats, cette fonction doit être exécutée sur un paragraphe entier, pas sur des lignes ; mais n'hésitez pas à faire autrement si vous savez ce que vous faites.

RETOURNE

Nouvelle longueur de la chaîne, ou −1 en cas d'erreur (échec d'allocation mémoire très probablement).
