for(n) Commandes intégrées Tcl for(n)

NOM

for - Boucle 'For'

SYNOPSIS

for début test suivant corps

DESCRIPTION

For est une commande de boucle, similaire en structure à l'instruction C for. Les arguments début, suivant, et corps doivent être des chaînes de commandes Tcl, et test est une chaîne d'expression. La commande for invoque d'abord l'interpréteur Tcl pour exécuter début. Ensuite, elle évalue répétitivement test comme une expression ; si le résultat est non nul, elle invoque l'interpréteur Tcl sur corps, puis invoque l'interpréteur Tcl sur suivant, puis répète la boucle. La commande se termine lorsque test est évalué à 0. Si une commande continue est invoquée dans corps, les commandes restantes de l'exécution actuelle de corps sont sautées ; le traitement continue en invoquant l'interpréteur Tcl sur suivant, puis en évaluant test, et ainsi de suite. Si une commande break est invoquée dans corps ou suivant, la commande for se terminera immédiatement. Le fonctionnement de break et continue est similaire aux instructions correspondantes en C. For renvoie une chaîne vide.

Note : test devrait presque toujours être entouré d'accolades. Sinon, des substitutions de variables seront effectuées avant que la commande for ne commence son exécution, ce qui signifie que les modifications de variables effectuées par le corps de la boucle ne seront pas prises en compte dans l'expression. Cela risque de provoquer une boucle infinie. Si test est entouré d'accolades, les substitutions de variables sont retardées jusqu'à ce que l'expression soit évaluée (avant chaque itération de boucle), de sorte que les changements dans les variables seront visibles. EXEMPLES

Afficher une ligne pour chacun des entiers de 0 à 9 :

for {set x 0} {$x<10} {incr x} {
    puts "x est $x"
}

Soit une boucle infinie, soit aucune boucle car l'expression évaluée est en fait la constante, ou même une erreur ! Le comportement réel dépendra de l'existence de la variable x avant l'exécution de la commande for et de sa valeur (inférieure ou supérieure/égale à dix), car l'expression sera substituée avant l'exécution de la commande for.

for {set x 0} $x<10 {incr x} {
    puts "x est $x"
}

Afficher les puissances de deux de 1 à 1024 :

for {set x 1} {$x<=1024} {set x [expr {$x * 2}]} {
    puts "x est $x"
}
