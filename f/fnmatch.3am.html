FNMATCH(3am) Modules d'extension GNU Awk FNMATCH(3am)

NOM

fnmatch - comparer une chaîne à un caractère générique de nom de fichier

SYNTAXE

@load "fnmatch"

resultat = fnmatch(modele, chaine, drapeaux)

DESCRIPTION

L'extension fnmatch fournit une interface AWK à la routine fnmatch(3). Elle ajoute une seule fonction nommée fnmatch(), une variable prédéfinie (FNM_NOMATCH), et un tableau de valeurs de drapeaux nommé FNM.

Le premier argument est le caractère générique de nom de fichier à faire correspondre, le second est la chaîne de nom de fichier, et le troisième est soit zéro, soit le OU bit à bit d'un ou plusieurs des drapeaux du tableau FNM.

La valeur de retour est zéro en cas de succès, FNM_NOMATCH si la chaîne ne correspond pas au modèle, ou une autre valeur non nulle si une erreur s'est produite.

Les drapeaux sont les suivants :

FNM["CASEFOLD"]
Correspond au drapeau FNM_CASEFOLD tel que défini dans fnmatch(3).
FNM["FILE_NAME"]
Correspond au drapeau FNM_FILE_NAME tel que défini dans fnmatch(3).
FNM["LEADING_DIR"]
Correspond au drapeau FNM_LEADING_DIR tel que défini dans fnmatch(3).
FNM["NOESCAPE"]
Correspond au drapeau FNM_NOESCAPE tel que défini dans fnmatch(3).
FNM["PATHNAME"]
Correspond au drapeau FNM_PATHNAME tel que défini dans fnmatch(3).
FNM["PERIOD"]
Correspond au drapeau FNM_PERIOD tel que défini dans fnmatch(3).

NOTES

Rien n'empêche le code AWK de modifier la variable prédéfinie FNM_NOMATCH, mais le faire peut entraîner des résultats étranges.

EXEMPLE

@load "fnmatch"
...
drapeaux = or(FNM["PERIOD"], FNM["NOESCAPE"])
if (fnmatch("*.a", "foo.c", drapeaux) == FNM_NOMATCH)
	print "pas de correspondance"
