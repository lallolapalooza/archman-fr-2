full(4) Manuel des pilotes de périphériques full(4)

NOM

full - périphérique toujours plein

CONFIGURATION

Si votre système ne dispose pas déjà de /dev/full, il peut être créé avec les commandes suivantes :


mknod -m 666 /dev/full c 1 7
chown root:root /dev/full

DESCRIPTION

Le fichier /dev/full a le numéro de périphérique majeur 1 et le numéro de périphérique mineur 7.

Les écritures sur le périphérique /dev/full échouent avec une erreur ENOSPC. Ceci peut être utilisé pour tester comment un programme gère les erreurs de disque plein.

Les lectures depuis le périphérique /dev/full retourneront des caractères NULL.

Les recherches (seeks) sur /dev/full réussiront toujours.

FICHIERS

/dev/full

VOIR AUSSI

mknod(1), null(4), zero(4)
