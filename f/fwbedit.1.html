NOM

fwbedit - Outil d'édition d'arborescence d'objets polyvalent

SYNOPSIS

fwbedit commande [options]

DESCRIPTION

fwbedit est un outil d'édition d'arborescence d'objets polyvalent pour Firewall Builder (voir fwbuilder(1)). Cet outil peut être utilisé dans des scripts shell écrits pour le traitement par lot des fichiers de données de Firewall Builder. Fwbedit peut effectuer les opérations suivantes sur les objets et l'arborescence : créer un nouvel objet, supprimer un objet existant, modifier les attributs d'un objet, ajouter une référence à un objet donné dans un groupe, supprimer la référence à un objet d'un groupe, mettre à jour un fichier de données et vérifier l'arborescence d'objets dans le fichier et la réparer si nécessaire. L'objet et le groupe peuvent être définis par leur ID ou par leur nom et leur chemin complet dans l'arborescence (voir la section EXEMPLES ci-dessous).

COMMANDES ET OPTIONS :

new -f fichier.fwb -t type_objet -n nom -p parent [-c commentaire] [-a attributs]

Crée un nouvel objet.


-f fichier.fwb fichier de données
-t type_objet crée un nouvel objet de ce type
-p parent crée le nouvel objet comme enfant de cet objet.
Ce paramètre est obligatoire. Si vous ajoutez une adresse
à une interface, l'interface correspondante doit être
spécifiée comme parent. De même, si vous devez ajouter une
interface à un hôte ou un pare-feu, l'objet hôte ou
pare-feu correspondant est le parent. Si vous ajoutez un
objet à l'un des dossiers standard, le parent est la
bibliothèque à laquelle vous souhaitez ajouter l'objet ou le
chemin complet correct vers le dossier dans l'arborescence.
-n nom le nom du nouvel objet
-c texte spécifie le commentaire pour le nouvel objet
-a attribut1[,attribut2...] : spécifie les attributs qui
définissent les paramètres du nouvel objet (voir ci-dessous)

delete -f fichier.fwb -o objet

Supprime l'objet spécifié par son chemin complet dans l'arborescence ou par son ID.


-f fichier.fwb fichier de données
-o objet objet à supprimer, chemin complet ou ID

modify -f fichier.fwb -o objet -c commentaire [-a attributs]

Modifie l'objet spécifié par son chemin complet dans l'arborescence ou par son ID. L'objet ne peut pas être renommé à l'aide de cette opération.


-f fichier.fwb fichier de données
-o objet objet à supprimer, chemin complet ou ID
-c texte spécifie le commentaire pour le nouvel objet
-a attribut1[,attribut2...] : spécifie les attributs qui
définissent les paramètres du nouvel objet (voir ci-dessous)

list -f fichier.fwb -o objet [-r|-c] [-d|-Fformat]

Affiche le nom et l'ID d'un objet.


-f fichier.fwb fichier de données
-o objet objet à afficher, chemin complet ou ID
-r affiche l'objet spécifié et tous les objets situés en dessous dans l'arborescence
-c affiche uniquement les objets enfants de l'objet donné mais n'affiche
pas l'objet lui-même.
-d affiche le dump complet de tous les attributs de l'objet, y compris les
informations de débogage internes si disponibles, cela peut être très
verbeux.
-Fformat_string Le programme reconnaît les macros dans la chaîne de format
et les remplace par les valeurs des attributs correspondants de l'objet.
Une macro est le nom de l'attribut entouré
de '%', comme '%name%' ou '%address%'. Voici la
liste de quelques noms d'attributs : "id", "name", "path",
"comment", "type", "address", "netmask", "dnsname". Les objets de service TCP
et UDP fournissent les attributs
"src_range_start", "src_range_end", "dst_range_start",
"dst_range_end" pour les plages de ports source et
destination. Les objets de service ICMP et ICMP6 ont les attributs
"icmp_type" et "icmp_code".

add -f fichier.fwb -g groupe -o objet

Ajoute l'objet spécifié par chemin ou ID à un groupe, également spécifié par son chemin ou son ID.


-f fichier.fwb fichier de données
-g groupe groupe auquel l'objet doit être ajouté,
chemin complet ou ID
-o objet objet à supprimer, chemin complet ou ID

remove -f fichier.fwb -g groupe -o objet

Supprime un objet d'un groupe.


-f fichier.fwb fichier de données
-g groupe groupe duquel l'objet doit être retiré,
chemin complet ou ID
-o objet objet à supprimer, chemin complet ou ID

upgrade -f fichier.fwb

Met à jour le fichier de données vers la dernière version de format de données.


-f fichier.fwb fichier de données

checktree -f fichier.fwb

Vérifie la cohérence et la correction de l'arborescence d'objets dans le fichier de données donné et la répare si nécessaire.


-f fichier.fwb fichier de données

merge -f fichier1.fwb -i fichier2.fwb

Les objets du fichier fichier2.fwb sont fusionnés avec les objets du fichier fichier1 et l'arborescence d'objets combinée est enregistrée dans fichier1.fwb


-f fichier.fwb fichier de données n°1
-i fichier.fwb fichier de données n°2

import -f fichier1.fwb -i firewall_config.txt -o chemin_vers_objet_pare-feu [-d]

La configuration du pare-feu du fichier firewall_config.txt est analysée et importée dans le fichier de données fichier1.fwb. Le programme crée un nouvel objet pare-feu situé dans la bibliothèque et avec le nom défini par son chemin chemin_vers_objet_pare-feu.


-f fichier.fwb fichier de données n°1
-i config.txt fichier de configuration du pare-feu
-o chemin_objet chemin complet vers l'objet pare-feu qui sera
créé. Il doit s'agir d'un chemin complet, commençant
par le nom de la bibliothèque, comme
"/User/Firewalls/my_new_firewall"
-d évite la création d'objets en double lors de l'importation

actuellement (à partir de la v4.2.0) fwbuilder prend en charge l'importation de la configuration iptables enregistrée avec la commande iptables-save, ainsi que l'importation de la configuration IOS des routeurs Cisco, des pare-feu Cisco PIX, ASA et FWSM enregistrés avec la commande "show run".

ATTRIBUTS POUR LES NOUVEAUX OBJETS, PAR TYPE

-t Firewall -a plateforme, OS hôte

-t IPv4 -a adresse IP [,masque]

-t IPv6 -a adresse IPv6 [,longueur_masque]

-t DNSName -a enregistrement DNS,temps d'exécution

-t AddressRange -a adresse de début, adresse de fin

-t ObjectGroup

-t Network -a adresse,masque

-t NetworkIPv6 -a ipv6_address,netmask_length

-t Interval -a heure de début,date de début,jour de début,heure de fin, date de fin, jour de fin

-t Interface -a niveau de sécurité,type d'adresse (dynamique ou sans numéro),gestion

-t Host

-t TCPService -a plage de ports source début,fin,plage de ports destination début,fin,UAPRSF,UAPRSF

-t UDPService -a plage de ports source début,fin,plage de ports destination début,fin

-t ICMPService -a type ICMP,code ICMP

-t IPService -a numéro de protocole,lsrr/ssrr/rr/ts/fragm/short_fragm

EXEMPLES

Affiche le contenu de l'objet /User/Firewalls/firewall/eth0 selon le format fourni. Notez que l'objet de type "Interface" n'a pas d'attribut qui définirait son adresse, l'adresse IP est définie par son objet enfant de type IPv4 ou IPv6.

fwbedit list -f x.fwb -o /User/Firewalls/firewall/eth0 -F "type=%type% name=%name% id=%id% %comment%"

Affiche le contenu de l'objet /User/Firewalls/firewall/eth0 et tous ses objets enfants. C'est la façon de voir les adresses et les masques. L'objet Interface n'a pas l'attribut "address" donc le programme ignore la macro "%address%" lorsqu'il affiche l'interface.

fwbedit list -f x.fwb -o /User/Firewalls/firewall/eth0 -F "type=%type% name=%name% id=%id% %comment% %address%" -r

Affiche l'objet groupe /User/Objects/Addresses

fwbedit list -f x.fwb -o /User/Objects/Addresses -F "type=%type% name=%name% id=%id% %comment%"

Affiche l'objet groupe /User/Objects/Addresses et tous les objets d'adresse à l'intérieur de celui-ci :

fwbedit list -f x.fwb -o /User/Objects/Addresses -F "type=%type% name=%name% id=%id% %comment%" -r

Affiche les objets d'adresse à l'intérieur du groupe /User/Objects/Addresses mais n'affiche pas l'objet groupe lui-même :

fwbedit list -f x.fwb -o /User/Objects/Addresses -F "type=%type% name=%name% id=%id% %comment%" -c

Affiche les adresses et les massks de toutes les interfaces de tous les pare-feu sous la forme de leur chemin complet dans l'arbre d'objets, suivi du type, de l'id, de l'adresse et du masque de sous-réseau :

fwbedit list -f x.fwb -o /User/Firewalls -F "%path% %type% %id% %address% %netmask%" -r | grep IP

Affiche les noms, la plateforme et les informations de version pour tous les objets pare-feu définis dans le fichier de données :

fwbedit list -f x.fwb -o /User/Firewalls -F "%name% platform: %platform% version: %version%" -c

Affiche le nom et les plages de ports source et destination pour tous les services TCP dans le dossier TCP du groupe défini par l'utilisateur User :

fwbedit list -f x.fwb -o /User/Services/TCP -c -F "name='%name%' est=%established% %src_range_start%-%src_range_end% : %dst_range_start%-%dst_range_end%"

Affiche le type et le code icmp pour tous les services ICMP dans le dossier ICMP du groupe défini par l'utilisateur User :

fwbedit list -f x.fwb -o /User/Services/ICMP -c -F "name='%name%' icmp_type=%icmp_type% icmp_code=%icmp_code%"

Ajoute une adresse IPv6 à l'une des interfaces de l'objet pare-feu "firewall" :

fwbedit new -f x.fwb -p /User/Firewalls/firewall/eth3 -t IPv6 -n eth3-v6-addr -a 2001:470:1f05:590::2,64

Ajoute une référence à l'objet Host 'A' au groupe 'B' :

fwbedit add -f x.fwb -g /User/Objects/Groups/B -o /User/Objects/Hosts/A

Ajoute une référence à l'objet avec l'ID id3D71A1BA au groupe avec l'ID id3D151943. Si les objets avec les IDs donnés n'existent pas, fwbedit affiche un message d'erreur et ne fait aucune modification dans le fichier de données.

fwbedit add -f x.fwb -o id3D71A1BA -g id3D151943

Ajoute une référence à l'objet avec l'ID id3D71A1BA au groupe 'testgroup' :

fwbedit add -f x.fwb -o id3D71A1BA -g /User/Objects/Groups/testgroup

Le script suivant utilise la commande "list" de fwbedit pour afficher les IDs de tous les objets Address dans le dossier /User/Objects/Addresses, puis parcourt la liste obtenue et utilise fwbedit pour les ajouter au groupe "group1".


fwbedit list -f x.fwb -o /User/Objects/Addresses -F "%id%" -c | \
while read id; do \
fwbedit add -f x.fwb -g /User/Objects/Groups/group1 -o $id; \
done

Voici un exemple légèrement plus complexe. Le script suivant utilise la commande "list" de fwbedit pour afficher les types et les IDs de tous les objets Address dans le dossier /User/Objects/Addresses, puis les filtre à l'aide de grep pour n'obtenir que les objets IPv6 et enfin parcourt la liste obtenue et utilise fwbedit pour les ajouter au groupe "group1".


fwbedit list -f x.fwb -o /User/Objects/Addresses -F "%type% %id%" -c | \
grep IPv6 | \
while read type id; do \
fwbedit add -f x.fwb -g /User/Objects/Groups/group1 -o $id; \
done
