NOM

foomatic-compiledb - Compiler la base de données des imprimantes/pilotes Foomatic

SYNTAXE

foomatic-compiledb [ -t type ] [ -f ] [ -j n ] [  pilote ...  ]

DESCRIPTION

foomatic-compiledb génère tous les fichiers PPD ou les fichiers XML combinés Foomatic pour toutes les combinaisons d'imprimantes/pilotes possibles, ou seulement pour une plage sélectionnée de pilotes. Il n'est généralement pas nécessaire, sauf pour ceux qui souhaitent générer un ensemble de fichiers de données Foomatic pour distribution. Pour configurer des imprimantes individuelles, foomatic-ppdfile(1) et en particulier foomatic-configure(1) calculeront automatiquement ce dont ils ont besoin.

Options

-t type
Type de fichier de sortie, soit ppd, soit xml.
-f
Forcer : écrire dans le répertoire de destination même s'il existe déjà.
-j n
n = nombre de processus de travail à exécuter
pilote ...
générer uniquement les fichiers de données pour ces pilotes.

VOIR AUSSI

foomatic-ppdfile(1),foomatic-configure(1)

STATUT DE SORTIE

foomatic-compiledb renvoie 0 sauf si quelque chose d'inattendu se produit.

AUTEURS

Manfred Wassmann <manolo@NCC-1701.B.Shuttle.de> et Till Kamppeter <till.kamppeter@gmail.com> pour le projet foomatic en utilisant la sortie du binaire associé.

BOGUES

Les fichiers existants sont toujours conservés au lieu d'écraser les fichiers plus anciens. Il est donc recommandé de supprimer le répertoire de destination (rm -rf dir) et d'appeler foomatic-compiledb sans l'option -f.

Veuillez signaler les bogues sur
