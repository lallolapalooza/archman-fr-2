fuse-zip(1) Système de fichiers FUSE pour lire et modifier des archives ZIP fuse-zip(1)

NOM

fuse-zip - un système de fichiers FUSE pour les archives zip avec prise en charge de l'écriture

SYNTAXE

fuse-zip [options] fichier_zip point_de_montage

OPTIONS

-h
afficher l'aide
-V
afficher la version
-r
ouvrir l'archive en mode lecture seule
-o opt[,opt...]
options de montage (voir mount.fuse(8) pour les détails)
-f
ne pas se détacher du terminal
-d
activer le débogage, implique aussi -f

Options de montage spécifiques :

force_precise_time
Par défaut, l'horodatage de haute précision est enregistré dans l'archive uniquement pour les nouveaux fichiers ou les fichiers dont l'heure de création est connue. Vous pouvez forcer l'enregistrement de l'heure de haute précision en spécifiant l'option '-o force_precise_time'. Dans ce cas, l'heure de création sera égale à la première heure de modification de fichier connue.

DESCRIPTION

fuse-zip est un système de fichiers FUSE qui permet à n'importe quel programme de travailler avec une archive ZIP comme s'il s'agissait d'un simple répertoire. Contrairement à KIO ou Gnome VFS, il peut être utilisé dans n'importe quelle application sans modifications.

Contrairement aux autres systèmes de fichiers FUSE, fuse-zip offre une prise en charge de l'écriture des archives ZIP. De plus, fuse-zip est plus rapide que toutes les implémentations connues sur les grandes archives contenant de nombreux fichiers.

Depuis la version 0.3.0, fuse-zip prend en charge les chemins absolus et relatifs au parent dans les noms de fichiers, mais uniquement en mode lecture seule (commutateur de commande -r). Les chemins absolus sont affichés sous le répertoire "ROOT", chaque ".." dans le chemin est remplacé par "UP" dans le nom du répertoire et les fichiers "normaux" sont placés sous le répertoire "CUR".

La prise en charge des permissions de fichiers UNIX et des informations de propriétaire a été ajoutée dans la version 0.4.0. Voir PERMISSIONS pour les détails.

Depuis la version 0.5.0, fuse-zip force l'ouverture en mode lecture seule si le fichier archive ou son répertoire parent ne sont pas inscriptibles.

Les commentaires de fichier/archive sont pris en charge depuis la version 0.7.0. Pour lire/modifier le commentaire d'un fichier, utilisez l'attribut étendu "user.comment". Le commentaire de l'archive est accessible via l'attribut étendu du point de montage.

Si vous souhaitez spécifier la conversion de jeux de caractères pour les noms de fichiers dans l'archive, utilisez les options fusermount suivantes :


-omodules=iconv,from_code=$charset1,to_code=$charset2

Voir la documentation FUSE pour les détails.

UTILISATION

L'utilisation générale ressemblerait à ceci :

1 mkdir /tmp/archiveZip
2 fuse-zip foobar.zip /tmp/archiveZip
3 (faire quelque chose avec le système de fichiers monté)
4 fusermount -u /tmp/archiveZip

Soyez patient. Attendez que le processus fuse-zip se termine après le démontage, surtout pour les grosses archives.

PERMISSIONS

La vérification des accès ne sera pas effectuée à moins que l'option de montage -o default_permissions ne soit donnée.
