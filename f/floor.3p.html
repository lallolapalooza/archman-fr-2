FLOOR(3P) Manuel du programmeur POSIX FLOOR(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

floor, floorf, floorl — fonction partie entière inférieure

SYNTAXE

#include <math.h>
double floor(double x);
float floorf(float x);
long double floorl(long double x);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est conforme à la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1-2017 s'en remet à la norme ISO C.

Ces fonctions calculent la plus grande valeur entière qui n'est pas supérieure à x.

VALEUR DE RETOUR

Le résultat aura le même signe que x.

En cas de succès, ces fonctions retournent la plus grande valeur entière qui n'est pas supérieure à x, exprimée en tant que double, float ou long double, selon ce qui convient au type de retour de la fonction.

Si x est NaN, un NaN est retourné.

Si x est ±0 ou ±Inf, x est retourné.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION PAR L'APPLICATION

La valeur entière retournée par ces fonctions peut ne pas être exprimable en tant que intmax_t. La valeur de retour doit être vérifiée avant d'être assignée à un type entier pour éviter les résultats indéfinis d'un dépassement entier.

Ces fonctions peuvent déclencher l'exception de virgule flottante inexacte si le résultat diffère en valeur de l'argument.
