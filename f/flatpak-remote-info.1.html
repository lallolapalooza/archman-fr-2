NOM

flatpak-remote-info - Afficher des informations sur une application ou un runtime dans un dépôt distant

SYNTAXE

flatpak remote-info [OPTION...] REMOTE RÉFÉRENCE

DESCRIPTION

Affiche des informations sur le runtime ou l'application RÉFÉRENCE provenant du dépôt distant nommé REMOTE. Vous pouvez trouver tous les dépôts distants configurés avec flatpak remotes.

Par défaut, la sortie est formatée de manière conviviale. Si vous spécifiez l'une des options --show-..., la sortie est plutôt formatée d'une manière lisible par machine.

Sauf si elles sont remplacées par les options --system, --user ou --installation, cette commande utilise soit l'installation système par défaut, soit celle par utilisateur, en fonction de laquelle possède le REMOTE spécifié.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Afficher les options d'aide et quitter.

-u, --user

Utiliser la configuration par utilisateur.

--system

Utiliser la configuration système par défaut.

--installation=NOM

Utiliser une installation système spécifiée par NOM parmi celles définies dans /etc/flatpak/installations.d/. Utiliser --installation=default équivaut à utiliser --system.

--cached

Préférer utiliser les informations mises en cache localement si possible, même si elles peuvent être obsolètes. C'est plus rapide, mais risque de retourner des informations périmées. De plus, certaines informations ne sont pas mises en cache et ne seront donc pas disponibles.

--runtime

Supposer que RÉFÉRENCE est un runtime si elle n'est pas explicitement spécifiée.

--app

Supposer que RÉFÉRENCE est une application si elle n'est pas explicitement spécifiée.

--arch=ARCH

L'architecture par défaut à rechercher, si elle n'est pas donnée explicitement dans la RÉFÉRENCE. Voir flatpak --supported-arches pour les architectures prises en charge par l'hôte.

--commit=COMMIT

Afficher les informations sur le commit spécifique, plutôt que la dernière version.

--log

Afficher un journal des versions précédentes.

-r, --show-ref

Afficher la référence correspondante.

-c, --show-commit

Afficher l'identifiant du commit.

-p, --show-parent

Afficher l'identifiant du commit parent.

-m, --show-metadata

Afficher les métadonnées.

-v, --verbose

Afficher les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Afficher les informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak --user remote-info flathub org.gnome.gedit
