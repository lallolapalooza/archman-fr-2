FN(1) Manuel des commandes générales FN(1)

NOM

fn — imprime le plus récent horodatage dans un répertoire, récursivement

SYNTAXE

fn dir [...]

DESCRIPTION

fn parcourt récursivement les répertoires indiqués sur la ligne de commande et imprime l'horodatage UNIX (secondes depuis l'époque UNIX) du fichier le plus récent trouvé.

fn ignore tout sauf les fichiers ordinaires (en particulier, les répertoires et les liens symboliques).

En cas d'erreurs, 0 est imprimé.

VOIR AUSSI

date(1)

VALEURS DE RETOUR

L'utilitaire fn se termine avec le code 0 en cas de succès, et >0 si une erreur se produit.
