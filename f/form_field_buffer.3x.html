NOM

form_field_buffer - contrôle du tampon de champ

SYNOPSIS

#include <form.h>
int set_field_buffer(FIELD *field, int buf, const char *value);
char *field_buffer(const FIELD *field, int buffer);
int set_field_status(FIELD *field, bool status);
bool field_status(const FIELD *field);
int set_max_field(FIELD *field, int max);

DESCRIPTION

La fonction set_field_buffer définit le tampon numéroté du champ donné pour contenir une chaîne de caractères donnée :

  • Le tampon 0 est la valeur affichée du champ.
  • D'autres tampons numérotés peuvent être alloués par les applications via l'argument nbuf de (voir form_field_new(3X)) mais ne sont pas manipulés par la bibliothèque des formulaires.

La fonction field_buffer renvoie un pointeur vers le contenu du tampon numéroté donné :

  • Le contenu du tampon a toujours la même longueur et est complété par des espaces de fin pour garantir cette longueur.
  • Le tampon peut contenir des espaces de début, en fonction de la manière dont il a été défini.
  • Le contenu du tampon est défini avec set_field_buffer, ou comme effet de bord de toute opération d'édition sur le champ correspondant.
  • Les opérations d'édition sont basées sur la fenêtre qui affiche le champ, plutôt que sur une chaîne. La fenêtre ne contient que des caractères imprimables et est remplie d'espaces. Si vous voulez les données brutes, vous devez écrire votre propre routine qui copie la valeur du tampon et supprime les espaces de début et de fin.
  • Étant donné que les opérations d'édition modifient le contenu du tampon pour qu'il corresponde à la fenêtre, vous ne devez pas vous fier à l'utilisation des tampons pour le stockage à long terme des données du formulaire.

La fonction set_field_status définit l'indicateur de statut associé au champ ; field_status obtient la valeur actuelle. L'indicateur de statut est mis à une valeur non nulle chaque fois que le champ change.

La fonction set_max_field définit la taille maximale d'un champ dynamique. Un argument de 0 désactive tout seuil de taille maximale pour ce champ.

VALEUR DE RETOUR

La fonction field_buffer renvoie NULL en cas d'erreur. Elle définit errno en fonction de leur succès :

E_OK
La routine a réussi.
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.

La fonction field_status renvoie TRUE ou FALSE.

Les autres routines renvoient l'une des valeurs suivantes :

E_OK
La routine a réussi.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.

NOTES

Lorsqu'il est configuré pour les caractères larges, field_buffer renvoie un pointeur vers un stockage temporaire (alloué et libéré par la bibliothèque). L'application ne doit pas tenter de modifier les données. Il sera libéré lors du prochain appel à field_buffer pour renvoyer le même tampon.

PORTABILITÉ

Ces routines émulent la bibliothèque des formulaires System V. Elles n'étaient pas prises en charge sur les versions 7 ou BSD.

La fonction set_max_field vérifie une extension ncurses O_INPUT_FIELD qui permet à un champ dynamique de se réduire si la nouvelle limite est inférieure à la taille actuelle du champ.
