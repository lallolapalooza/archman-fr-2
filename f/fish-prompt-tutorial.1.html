Avertissement

:
Ce document utilise un formatage pour montrer à quoi ressemblerait un invite. Si vous consultez ceci dans la page man, vous souhaiterez probablement plutôt consulter la version HTML. Exécutez help custom-prompt pour la vis
ualiser dans un
navigateur web.

Fish fournit un certain nombre d'invites que vous pouvez consulter avec la commande fish_config <>, et de nombreux utilisateurs ont partagé leurs invites en

ligne.

Cependant, vous pouvez aussi en écrire une vous-même, ou ajuster une invite existante. C'est un bon moyen de vous familiariser avec le langage de script de fish <>

.

Contrairement aux autres shells, l'invite de fish est construite en exécutant une fonction - fish_prompt <>. Ou, plus précisément, trois fonctions

:
  • fish_prompt <>, qui est la fonction d'invite
    • principale
  • fish_right_prompt <>, qui est affichée sur le côté droit du
    • terminal.
  • fish_mode_prompt <>
    • , qui est affichée
si le mode vi <#vi
-mode> est utilisé.

Ces fonctions sont exécutées, et ce qu'elles affichent est affiché comme invite (moins un retour à la ligne final)

.

Ici, nous allons simplement écrire un fish_prompt

simple.

NOTRE PREMIÈRE

INVITE

Regardons un exemple très simple

: 
function f
ish_prompt
echo $P
WD '>' end

Cela affiche le répertoire de travail courant (PWD <#envvar-PWD>) et un symbole > pour montrer où l'invite se termine. Le > est entre guillemets <#quotes> car sinon il signifierait une redirection <#redirects>

.

Parce que nous avons utilisé echo <>, il ajoute des espaces entre les deux, donc cela finit par ressembler à (en supposant que _ est votre curseur)

: 
/ho
me/t
uto
rial
>_

FORMATAG

E

echo ajoute des espaces entre ses arguments. Si vous ne les voulez pas, vous pouvez utiliser string join <> comme ceci

: 
function fish_
prompt str
ing join '' -
- $PWD '>' end

Le -- indique à string qu'aucune option ne peut venir après lui, au cas où nous étendrions cela avec quelque chose qui peut commencer par un -

.

Il y a d'autres façons de supprimer l'espace, y compris echo -s et printf

<>
.

AJOUTER DE LA

COULEUR

Cette invite est fonctionnelle, mais un peu ennuyeuse. Nous pourrions ajouter un peu de

couleur.

Heureusement, fish offre la commande set_color <>, donc vous pouvez faire

: 
echo (
set_co
lor r
ed)foo

set_color peut aussi gérer les couleurs RVB comme set_color 23b455, et d'autres options de formatage y compris le gras et

l'italique.

Donc, en prenant notre invite précédente et en ajoutant un peu de couleur

: 
function fish_prompt
string join '' -- (se
t_color green) $PWD (se
t_color normal) '>' end

Une couleur "normale" dit au terminal de revenir à ses options de formatage

normales.

set_color fonctionne en produisant une séquence d'échappement, qui est un morceau spécial de texte que les terminaux interprètent comme des instructions - par exemple, pour changer de couleur. Donc set_color red produit le même effet que

: 
ech
o \
e\[
31m

Bien que vous puissiez écrire vos propres séquences d'échappement à la main, c'est beaucoup plus facile d'utiliser set_c

olo
r.

RACCOURCIR LE RÉPERTOIRE DE

TRAVAIL

C'est bien, mais notre PWD <#envvar-PWD> peut être un peu long, et nous sommes généralement seulement intéressés par les derniers répertoires. Nous pouvons raccourcir cela avec l'aide prompt_pwd <> qui nous donnera un répertoire de travail raccourci

: 
function fish_prompt
string join '' -- (set_co
lor green) (prompt_pwd) (
set_color normal) '>' end

prompt_pwd prend des options pour contrôler combien raccourcir. Par exemple, si nous voulons afficher les deux derniers répertoires, nous utiliserions prompt_pwd --full-length-dirs 2

: 
function fish_prompt
    strin
g join '' -- (set_color green)
(prompt_pwd --full-length-dirs
2) (set_color normal) '>' end

Avec un répertoire courant de "/home/tutorial/Music/Lena Raine/Oneknowing", cela

afficherait 
~/M/L
ena Ra
ine/O
neknow
ing>_

STATU

T

Une information importante que chaque commande renvoie est le statut <#variables-status>. C'est un nombre entier de 0 à 255, et habituellement il est utilisé comme code d'erreur - 0 si la commande a réussi, ou un nombre de 1 à 255

sinon.

C'est utile d'afficher cela dans votre invite, mais le montrer quand il est 0 semble un peu

gaspilleur.

Premièrement, puisque chaque commande (sauf set <>) change le statut, vous devez le stocker pour une utilisation ultérieure comme première chose dans votre invite. Utilisez une variable locale <#variables-scope> pour qu'elle soit confinée à votre fonction d'invite

: 
set -l
last_s
tatus $
status

Et après cela, vous pouvez définir une chaîne si ce n'est pas zéro

: 
# Invite du statut seulement si ce n'e
st pas 0 set -l stat if test $last_sta
tus -ne 0 set stat (set_color red)
"[$last_status]"(set_color normal) end

Et pour l'afficher, nous l'ajoutons à notre string jo

in : 
string join '' -- (
set_color green) (p
rompt_pwd) (set_colo
r normal) $stat '>'

Si $last_status était 0, $stat est vide, et donc elle disparaîtra

simplement.

Donc notre invite entière est maintenant

: 
function fish_prompt
    set -l last_status $status
    # Invite du statut seu
lement si ce n'est pas 0 set -l stat if test $last_status -ne 0
set stat (set_color red)"[$last_status]"(set_color normal) end str
ing join '' -- (set_color green) (prompt_pwd) (set_color normal) $stat '>' end

Et elle ressemble à

: 
~/M/L/Onekn
owing>false
~/M/L/Onek
nowing[1]>_

après que nous ayons exécuté false (qui renvoie

1)
.

INVITE

TRANSITOIRE

Pour activer la fonctionnalité d'invite transitoire, définissez la variable fish_transient_prompt <#envvar-fish_transient_prompt> à 1

: 
set -g f
ish_tra
nsient_
prompt 1

Avec ceci défini, fish ré-exécute les fonctions d'invite avec un argument --final-rendering avant d'exécuter une ligne de commande. Vous pouvez donc l'utiliser pour désencombrer vos anciennes invites. Par exemple, si vous voulez voir seulement le nom du répertoire courant lorsque vous faites défiler vers le haut

: 
function fish_prompt
    set -l last_status $status
    set -l stat
    set -l pwd
    # Vérifier si c'est une invite transitoire
ou finale if contains -- --final-rendering $argv set pwd (path basename $PWD) else set pwd (prompt_pwd)
# Invite du statut seulement si ce n'est pas 0 if test $last_status -ne 0 set stat (set_color red)"[$
last_status]"(set_color normal) end end string join '' -- (set_color green) $pwd (set_color normal) $stat '>' end

Maintenant, exécuter deux commandes dans le même répertoire pourrait résulter en cet écran

: 
Oneknowi
ng>fals
e ~/M/L/
Oneknow
ing[1]>_

SAUVEGARDER

L'INVITE

Une fois que vous êtes satisfait de votre invite, vous pouvez la sauvegarder avec funcsave fish_prompt (voir funcsave - save the definition of a function to the user's autoload directory <>) ou l'écrire vous-même dans ~/.config/fish/functions/fish_prompt.

fish.

Si vous voulez la modifier à nouveau, ouvrez ce fichier ou utilisez funced fish_prompt (voir funced - edit a function interactively <>

    • root.
  • fish_vcs_prompt pour afficher les informations de contrôle de version (ou fish_git_prompt / fish_hg_prompt / fish_svn_prompt pour
