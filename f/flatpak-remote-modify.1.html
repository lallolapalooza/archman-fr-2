NOM

flatpak-remote-modify - Modifier un dépôt distant

SYNTAXE

flatpak remote-modify [OPTION...] NOM

DESCRIPTION

Modifie les options d'un dépôt distant existant dans la configuration des dépôts flatpak. NOM est le nom du dépôt distant.

Sauf indication contraire avec les options --system, --user, ou --installation, cette commande utilise soit l'installation système par défaut, soit celle par utilisateur, en fonction de celle qui contient le DÉPÔT spécifié.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

-u, --user

Modifie la configuration par utilisateur.

--system

Modifie la configuration système par défaut.

--installation=NOM

Modifie une installation système spécifiée par NOM parmi celles définies dans /etc/flatpak/installations.d/. Utiliser --installation=default est équivalent à utiliser --system.

--no-gpg-verify

Désactive la vérification GPG pour le dépôt ajouté.

--gpg-verify

Active la vérification GPG pour le dépôt ajouté.

--prio=PRIO

Définit la priorité du dépôt. La valeur par défaut est 1, une valeur plus élevée signifie une priorité plus importante. Ceci est principalement utilisé par les outils d'installation graphiques.

--subset=SUBSET

Limite les références disponibles depuis le dépôt à celles qui font partie du sous-ensemble nommé.

--no-enumerate

Marque le dépôt comme non énuméré. Cela signifie que le dépôt ne sera pas utilisé pour lister les applications, par exemple dans les outils d'installation graphiques. Il ne sera pas non plus utilisé pour la résolution des dépendances des runtimes (comme avec --no-use-for-deps).

--no-use-for-deps

Marque le dépôt comme ne devant pas être utilisé pour la résolution automatique des dépendances des runtimes.

--disable

Désactive le dépôt. Les dépôts désactivés ne seront pas mis à jour automatiquement.

--enable

Active le dépôt.

--enumerate

Marque le dépôt comme énuméré. Cela signifie que le dépôt sera utilisé pour lister les applications, par exemple dans les outils d'installation graphiques.

--use-for-deps

Marque le dépôt comme devant être utilisé pour la résolution automatique des dépendances des runtimes.

--title=TITLE

Un titre pour le dépôt, par exemple pour affichage dans une interface utilisateur.

--comment=COMMENT

Un commentaire sur une seule ligne pour le dépôt, par exemple pour affichage dans une interface utilisateur.

--description=DESCRIPTION

Une description complète sous forme de paragraphe pour le dépôt, par exemple pour affichage dans une interface utilisateur.

--homepage=URL

URL d'un site web pour le dépôt, par exemple pour affichage dans une interface utilisateur.

--icon=URL

URL d'une icône pour le dépôt, par exemple pour affichage dans une interface utilisateur.

--default-branch=BRANCH

Une branche par défaut pour le dépôt, principalement pour une utilisation dans une interface utilisateur.

--collection-id=COLLECTION-ID

L'identifiant unique global du dépôt distant, pour permettre le regroupement des miroirs. Ceci doit uniquement être défini sur l'identifiant de collection fourni par le dépôt, et ne doit pas être défini si le dépôt ne fournit pas d'identifiant de collection.

--url=URL

Définit une nouvelle URL.

--update-metadata

Met à jour les métadonnées supplémentaires du dépôt à partir du fichier résumé du dépôt OSTree. Seuls xa.title et xa.default-branch sont pris en charge pour le moment.

--no-filter, --filter=FILE

Modifie le chemin (ou le désactive) pour le filtre local utilisé pour ce dépôt. Voir flatpak-remote-add(1) pour les détails sur le format du fichier de filtre.

--gpg-import=FILE

Importe les clés gpg du fichier keyring spécifié comme fiables pour le nouveau dépôt. Si le fichier est -, le keyring est lu depuis l'entrée standard.

--authenticator-name=NAME

Spécifie l'authentificateur à utiliser pour le dépôt.

--authenticator-option=KEY=VALUE

Spécifie une option d'authentificateur pour le dépôt.

--authenticator-install

Active l'installation automatique de l'authentificateur.

--no-authenticator-install

Désactive l'installation automatique de l'authentificateur.

--follow-redirect

Suit xa.redirect-url défini dans le fichier résumé.

--no-follow-redirect

Ne suit pas xa.redirect-url défini dans le fichier résumé.

-v, --verbose

Affiche des informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche des informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak --user remote-modify --no-gpg-verify test-repo
