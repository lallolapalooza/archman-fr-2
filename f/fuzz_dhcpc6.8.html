fuzz_dhcpc6(8) IPv6 fuzz_dhcpc6(8)

NOM

fuzz_dhcpc6 Partiellement basé sur le code de Brandon Hutcheson et Graeme Neilson

SYNTAXE

fuzz_dhcpc6 [-1|-2|-3|-4|-5|-6|-7|-8|-9|-A|-B|-C|-D|-m] -f mac -l link -v ipv6 -x xid -c client -o options interface

OPTIONS

  -1         Fuzz DHCPv6 Solicit
  -2         Fuzz DHCPv6 Advertise (par défaut)
  -3         Fuzz DHCPv6 Request
  -4         Fuzz DHCPv6 Confirm
  -5         Fuzz DHCPv6 Renew
  -6         Fuzz DHCPv6 Rebind
  -7         Fuzz DHCPv6 Reply
  -8         Fuzz DHCPv6 Release
  -9         Fuzz DHCPv6 Decline
  -A         Fuzz DHCPv6 Reconfigure
  -B         Fuzz DHCPv6 Information Request
  -C         Fuzz DHCPv6 Relay-Forward
  -D         Fuzz DHCPv6 Relay-reply
  -m         Fuzz également le type de message
  -v ipv6    Adresse IPv6 de la victime (si non spécifié, les clients DHCP envoyant des messages sont attaqués)
  -x xid     ID de transaction de la victime - zéro pour aléatoire (ignoré si -v non spécifié) 
  -c client  ID client de la victime - zéro pour aléatoire (ignoré si -v non spécifié) 
  -f mac     usurper l'adresse mac
  -l link    usurper l'adresse de lien
  -o options Options de message DHCPv6 à envoyer (par défaut: abcdefghijklmonpqr)
       a  OPTION_SERVERID
       b  OPTION_IA_NA
       c  OPTION_IA_TA
       d  OPTION_IAADR
       e  OPTION_ORO
       f  OPTION_PREFERENCE
       g  OPTION_ELAPSED_TIME
       h  OPTION_RELAY_MSG
       i  OPTION_AUTH
       j  OPTION_UNICAST
       k  OPTION_STATUS_CODE
       l  OPTION_RAPID_COMMIT
       m  OPTION_USER_CLASS
       n  OPTION_VENDOR_CLASS
       o  OPTION_VENDOR_OPTS
       p  OPTION_INTERFACE_ID
       q  OPTION_RECONF_MSG
       r  OPTION_RECONF_ACCEPT
Messages Fuzz envoyés à un client DHCPv6
