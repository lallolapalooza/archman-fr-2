NOM

flatpak-ps - Énumérer les instances en cours d'exécution

SYNTAXE

flatpak ps [OPTION...]

DESCRIPTION

Liste les informations utiles sur les instances Flatpak en cours d'exécution.

Pour voir les détails complets d'une instance en cours d'exécution, vous pouvez ouvrir le fichier /run/user/$UID/.flatpak/$INSTANCE/info, où $INSTANCE est l'ID de l'instance rapporté par flatpak ps.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage d'OSTree pendant le traitement de la commande.

--columns=CHAMP,...

Spécifie quelles informations afficher sur chaque instance. Vous pouvez lister plusieurs champs, ou utiliser cette option plusieurs fois.

Ajoutez :s[tart], :m[iddle], :e[nd] ou :f[ull] aux noms de colonnes pour modifier l'élision.

CHAMPS

Les champs suivants sont compris par l'option --columns :

instance

Affiche l'ID de l'instance

application

Affiche l'ID de l'application

arch

Affiche l'architecture

branch

Affiche la branche de l'application

commit

Affiche le commit de l'application

runtime

Affiche l'ID du runtime

runtime-branch

Affiche la branche du runtime

runtime-commit

Affiche le commit du runtime

pid

Affiche le PID du processus wrapper

child-pid

Affiche le PID du processus sandbox

active

Indique si l'application est active (c'est-à-dire si elle a une fenêtre active)

background

Indique si l'application est en arrière-plan (sans fenêtre ouverte)

all

Affiche toutes les colonnes

help

Affiche la liste des colonnes disponibles

Notez que les noms de champs peuvent être abrégés en un préfixe unique.

EXEMPLES

$ flatpak ps --columns=application,pid,runtime,runtime-branch
