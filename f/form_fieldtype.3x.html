NOM

form_fieldtype - définir les types de champs de validation

SYNTAXE

#include <form.h>
FIELDTYPE *new_fieldtype(
    bool (* const field_check)(FIELD *, const void *),
    bool (* const char_check)(int, const void *));
int free_fieldtype(FIELDTYPE *fieldtype);
int set_fieldtype_arg(
    FIELDTYPE *fieldtype,
    void *(* const make_arg)(va_list *),
    void *(* const copy_arg)(const void *),
    void  (* const free_arg)(void *));
int set_fieldtype_choice(
    FIELDTYPE *fieldtype,
    bool (* const next_choice)(FIELD *, const void *),
    bool (* const prev_choice)(FIELD *, const void *));
FIELDTYPE *link_fieldtype(FIELDTYPE *type1,
                          FIELDTYPE *type2);

DESCRIPTION

new_fieldtype

La fonction new_fieldtype crée un nouveau type de champ utilisable pour la validation de données. Ses paramètres sont des pointeurs de fonction :

field_check
Cette fonction vérifie la validité d'une chaîne de données saisie chaque fois que l'utilisateur tente de quitter un champ. Elle possède deux arguments :
  • L'argument (FIELD *) est passé afin que le prédicat de validation puisse voir le tampon du champ, ses tailles et d'autres attributs.
  • Le second argument est une structure de bloc d'arguments, dont nous parlerons plus bas.
char_check
Cette fonction valide les caractères d'entrée au fur et à mesure de leur saisie. La bibliothèque forms la contacte avec le caractère à vérifier et un pointeur vers une structure de bloc d'arguments.

free_fieldtype

La fonction free_fieldtype libère l'espace alloué pour un type de validation donné par new_fieldtype.

set_fieldtype_arg

La fonction set_fieldtype_arg associe trois fonctions de gestion du stockage à un type de champ :

make_arg
Cette fonction est automatiquement appliquée à la liste d'arguments que vous donnez à set_field_type lors de l'attachement de la validation à un champ. Elle stocke les arguments dans un objet bloc d'arguments alloué qui est utilisé lors de la validation des entrées.
copy_arg
Cette fonction peut être utilisée par les applications pour copier des blocs d'arguments.
free_arg
Libère une structure de bloc d'arguments.

Vous devez fournir la fonction make_arg. Les deux autres sont facultatives : vous pouvez fournir NULL pour elles. Dans ce cas, la bibliothèque forms suppose que make_arg n'alloue pas de mémoire mais charge simplement l'argument dans une seule valeur scalaire.

set_fieldtype_choice

Le pilote de forms demande REQ_NEXT_CHOICE et REQ_PREV_CHOICE et suppose que les valeurs possibles d'un champ forment un ensemble ordonné, et fournit à l'utilisateur des formulaires un moyen de parcourir l'ensemble.

La fonction set_fieldtype_choice permet aux programmeurs de forms de définir des fonctions successeurs et prédécesseurs pour le type de champ. Ces fonctions prennent le pointeur de champ et une structure de bloc d'arguments comme arguments.

link_fieldtype

La fonction link_fieldtype crée un nouveau type de champ à partir des deux types donnés. Ils sont connectés par un 'OU' logique.

VALEUR DE RETOUR

Les routines retournant un pointeur renvoient NULL en cas d'erreur. Elles définissent errno en fonction de leur succès :

E_OK
La routine a réussi.
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.
E_SYSTEM_ERROR
Une erreur système s'est produite, par exemple, échec de malloc.

Les routines retournant un entier renvoient l'un des codes suivants en cas d'erreur :

E_OK
La routine a réussi.
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.
E_CONNECTED
Le champ est déjà connecté à un formulaire.
E_CURRENT
Le champ est le champ courant.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).

PORTABILITE

Ces routines émulent la bibliothèque de forms de System V. Elles n'étaient pas prises en charge sur les versions 7 ou BSD.
