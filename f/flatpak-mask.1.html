FLATPAK MASK(1) flatpak mask FLATPAK MASK(1)

NOM

flatpak-mask - Masquer les mises à jour et l'installation automatique

SYNTAXE

flatpak mask [OPTION...] MOTIF...

DESCRIPTION

Flatpak maintient une liste de motifs qui définissent quels refs sont masqués. Un ref masqué ne sera jamais mis à jour ni installé automatiquement (par exemple, une extension masquée marquée pour téléchargement automatique ne sera pas téléchargée). Vous pouvez toujours installer manuellement de tels refs, mais une fois installés, la version sera épinglée.

Les motifs sont simplement une partie du ref, avec le caractère * correspondant à n'importe quoi dans cette partie du ref. Voici quelques exemples de motifs :

org.some.App
org.some.App//unstable
app/org.domain.*
org.some.App/arm

Pour lister l'ensemble actuel des masques, exécutez cette commande sans aucun motif.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

--remove

Au lieu d'ajouter les motifs, supprime les motifs correspondants.

-u, --user

Masque les refs dans une installation par utilisateur.

--system

Masque les refs dans l'installation système par défaut.

--installation=NOM

Masque les refs dans une installation système spécifiée par NOM parmi celles définies dans /etc/flatpak/installations.d/. Utiliser --installation=default est équivalent à utiliser --system.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

EXEMPLES

$ flatpak mask

$ flatpak mask org.broken.App

$ flatpak mask --remove org.broken.App
