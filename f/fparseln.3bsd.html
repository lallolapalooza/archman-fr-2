fparseln(3bsd)

Paquet: libbsd

Licences: custom

fparseln(3bsd) 3bsd fparseln(3bsd)

NOM

fparseln — retourne la prochaine ligne logique d'un flux

BIBLIOTHÈQUE

bibliothèque « libbsd »

SYNTAXE

#include <stdio.h> (Voir libbsd(7) pour l'utilisation de l'include.)
char *
fparseln(FILE *stream, size_t *len, size_t *lineno, const char delim[3], int flags);

DESCRIPTION

La fonction fparseln() retourne un pointeur vers la prochaine ligne logique depuis le flux référencé par stream. Cette chaîne est terminée par NUL et est allouée dynamiquement à chaque invocation. Il incombe à l'appelant de libérer le pointeur.

Par défaut, si un caractère est échappé, lui-même et le caractère d'échappement précédent seront présents dans la chaîne retournée. Divers flags modifient ce comportement.

La signification des arguments est la suivante :

stream
Le flux à lire.
len
Si non NULL, la longueur de la chaîne est stockée à l'emplacement mémoire pointé.
lineno
Si non NULL, la valeur de l'emplacement mémoire pointé est incrémentée par le nombre de lignes effectivement lues depuis le fichier.
delim
Contient les caractères d'échappement, de continuation et de commentaire. Si un caractère est NUL, le traitement de ce caractère est désactivé. Si NULL, tous les caractères prennent les valeurs par défaut spécifiées ci-dessous. Le contenu de delim est le suivant :
delim[0]
Le caractère d'échappement, qui par défaut est \, est utilisé pour supprimer toute signification spéciale du caractère suivant.
delim[1]
Le caractère de continuation, qui par défaut est \, est utilisé pour indiquer que la ligne suivante doit être concaténée avec la ligne actuelle si ce caractère est le dernier caractère de la ligne actuelle et n'est pas échappé.
delim[2]
Le caractère de commentaire, qui par défaut est #, s'il n'est pas échappé, indique le début d'un commentaire qui s'étend jusqu'à la fin de la ligne actuelle.
flags
Si non nul, modifie le fonctionnement de fparseln(). Les différents drapeaux, qui peuvent être ou-és ensemble, sont :
FPARSELN_UNESCCOMM
Supprime l'échappement précédant un commentaire échappé.
FPARSELN_UNESCCONT
Supprime l'échappement précédant une continuation échappée.
FPARSELN_UNESCESC
Supprime l'échappement précédant un échappement échappé.
FPARSELN_UNESCREST
Supprime l'échappement précédant tout autre caractère.
FPARSELN_UNESCALL
Tous les éléments ci-dessus.

VALEURS DE RETOUR

En cas de succès, un pointeur vers la ligne analysée est retourné ; sinon, NULL est retourné.

La fonction fparseln() utilise en interne getline(3), donc toutes les conditions d'erreur qui s'appliquent à getline(3), s'appliquent à fparseln(). De plus, fparseln() peut définir errno à [ENOMEM] et retourner NULL si elle manque de mémoire.

VOIR AUSSI

getline(3)

HISTORIQUE

La fonction fparseln() est apparue pour la première fois dans NetBSD 1.4 et FreeBSD 4.0.
