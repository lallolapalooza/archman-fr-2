FOOMATIC-PRINTJOB(1) Manuel des commandes générales FOOMATIC-PRINTJOB(1)

NOM

foomatic-printjob - gérer les travaux d'impression d'une manière indépendante du spooler

SYNTAXE

foomatic-printjob [ -s spooler ] [ -P nom_file ] [ -o option1=valeur1 -o option2 ... ] [ -i ] [ fichier1 fichier2 ... ]

foomatic-printjob -Q [ -s spooler ] [ -P nom_file ] [ -i ] [ -a ] [ utilisateur1 utilisateur2 ... ]

foomatic-printjob -R [ -s spooler ] [ -P nom_file ] [ -i ] [ - | id_travail1 id_travail2 ... ]

foomatic-printjob -C [ -s spooler ] [ -i ] commande [ arguments ]

foomatic-printjob -S [ -s spooler ] [ -i ]

foomatic-printjob -h [ -s spooler ] [ -P nom_file ] [ -i ]

DESCRIPTION

foomatic-printjob fournit une interface indépendante du spooler pour la création et la gestion des travaux d'impression et des files d'attente d'impression. Notez que le premier argument change le mode de la commande, car il combine la fonctionnalité de plusieurs commandes d'impression de style System V.

OPTIONS

-sspooler
Type de spooler explicite.
-Pnom_file
Toutes les commandes spécifiées s'appliqueront à cette file d'attente au lieu de la file par défaut.
-ooption=valeur
Définir l'option à la valeur
-ooption
Définir l'option de commutation
-#n
Imprimer n copies
fichier1  fichier2  ...
Fichiers à imprimer. S'il n'y a pas de fichier spécifié, l'entrée standard sera imprimée.
-Q
Interroger les travaux dans une file d'attente. Si une liste d'utilisateurs est spécifiée, seuls les travaux de ces utilisateurs seront interrogés.
-Q -a
Interroger les travaux dans toutes les files d'attente. Si une liste d'utilisateurs est spécifiée, seuls les travaux de ces utilisateurs seront interrogés.
-R [ - | id_travail1 id_travail2 ... ]
Supprimer un travail d'une file d'attente. L'utilisation de - supprimera tous les travaux.
-C commande [ arguments ]
Exécuter des commandes de contrôle pour la manipulation des files d'attente/travaux. Les commandes sont celles de l'utilitaire BSD "lpc". Utilisez la commande de contrôle "help" pour obtenir une liste des commandes prises en charge. Note : le nombre de commandes varie selon le spooler, mais les mêmes commandes données sous différents spoolers font la même chose.
-i
Mode interactif : vous serez invité à répondre si foomatic-printjob a un doute sur quelque chose. Sinon, foomatic-printjob utilise la détection automatique ou se termine avec une erreur.
-S
Enregistrer le spooler choisi comme spooler par défaut.
-h
Afficher ce message ou afficher une liste des options disponibles si une file d'attente est spécifiée.

VOIR AUSSI

foomatic-configure(1) et la documentation de votre spooler d'impression.
