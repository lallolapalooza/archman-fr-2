DESCRIPTIO

N

foomatic-configure est un programme pour configurer et mettre en place des files d'attente d'impression pour chaque spouleur connu (CUPS, LPRng, LPD, GNUlpr, PPR, PDQ. CPS, aucun spouleur) et chaque combinaison imprimante/pilote valide dans la base de données Foomatic ou chaque fichier PPD fourni avec les imprimantes PostScript. En tant que filtre RIP (Raster Image Processor, traduction de PostScript vers le langage natif de l'imprimante), toujours foomatic-rip(1) sera utilisé, sauf pour les fichiers PPD des imprimantes PostScript sous CUPS ou PPR, qui seront utilisés sans filtre

RIP.

Il comprend également la moitié d'une API programmatique pour les outils utilisateur : vous pouvez apprendre et contrôler tout ce qui concerne les propriétés statiques des files d'attente d'impression ici. Avec le programme sœur foomatic-printjob(1), vous pouvez faire tout ce qui concerne l'état dynamique de la file d'attente d'impression : soumettre des travaux, et interroger, annuler, réorganiser et rediriger ces

derniers.

BOGUE

S

foomatic-configure ne peut actuellement pas gérer les fichiers printcap dans le style lprng. Comme lprng peut utiliser les printcaps de style BSD, ce n'est pas vraiment un problème, tant que le gestionnaire d'impression basé sur l'interface graphique lprngtool n'est pas utilisé. La différence entre ces formats est que le style BSD exige que les lignes de continuation dans les définitions d'imprimante se terminent par deux-points et que le caractère de nouvelle ligne soit échappé avec une barre oblique inverse. Lprng n'a pas cette

restriction.

Pour utiliser un fichier printcap généré ou édité avec lprngtool avec foomatic-configure, il est nécessaire d'ajouter :\ à la fin de toutes les lignes sauf la dernière de chaque définition d'imprimante, comme montré ci-dessous

: 
#commentaire
# nom principal de l'imprimante
lp
#noms alternatifs
 |lp2|lp3
 |Exemple d'une imprimante
 :sd=/usr/spool/LPD/lp
 :rw:lp=/dev/lp:mx#100
:

doit être converti en

: 
#commentaire
# nom principal de l'imprimante
lp\
 |lp2|lp3\
 |Exemple d'une imprimante\
 :sd=/usr/spool/LPD/lp:\
 :rw:lp=/dev/lp:
mx#100:
