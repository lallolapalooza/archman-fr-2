fpurge(3) Manuel des fonctions de bibliothèque fpurge(3)

NOM

fpurge, __fpurge - purger un flux

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

/* non pris en charge */
#include <stdio.h>
int fpurge(FILE *stream);
/* pris en charge */
#include <stdio.h>
#include <stdio_ext.h>
void  __fpurge(FILE *stream);

DESCRIPTION

La fonction fpurge() vide les tampons du flux donné. Pour les flux de sortie, cela supprime toute sortie non écrite. Pour les flux d'entrée, cela supprime toute entrée lue depuis l'objet sous-jacent mais pas encore obtenue via getc(3) ; cela inclut tout texte repoussé via ungetc(3). Voir aussi fflush(3).

La fonction __fpurge() fait exactement la même chose, mais sans retourner de valeur.

VALEUR DE RETOUR

En cas de succès, fpurge() retourne 0. En cas d'erreur, elle retourne -1 et définit errno pour indiquer l'erreur.

ERREURS

EBADF
stream n'est pas un flux ouvert.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
__fpurge () Sécurité des threads MT-Safe race:stream

NORMES

Aucune.

HISTORIQUE

fpurge()
4.4BSD. Non disponible sous Linux.
__fpurge()
Solaris, glibc 2.1.95.

NOTES

Il est généralement une erreur de vouloir supprimer les tampons d'entrée.

VOIR AUSSI

fflush(3), setbuf(3), stdio_ext(3)
