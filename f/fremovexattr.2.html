removexattr(2) Manuel des appels système removexattr(2)

NOM

removexattr, lremovexattr, fremovexattr - supprimer un attribut étendu

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/xattr.h>
int removexattr(const char *path, const char *name);
int lremovexattr(const char *path, const char *name);
int fremovexattr(int fd, const char *name);

DESCRIPTION

Les attributs étendus sont des paires nom:valeur associées aux inodes (fichiers, répertoires, liens symboliques, etc.). Ce sont des extensions aux attributs normaux associés à tous les inodes du système (c'est-à-dire les données de stat(2)). Un aperçu complet des concepts d'attributs étendus se trouve dans xattr(7).

removexattr() supprime l'attribut étendu identifié par name et associé au path donné dans le système de fichiers.

lremovexattr() est identique à removexattr(), sauf dans le cas d'un lien symbolique, où l'attribut étendu est supprimé du lien lui-même, et non du fichier auquel il fait référence.

fremovexattr() est identique à removexattr(), seul l'attribut étendu est supprimé du fichier ouvert référencé par fd (tel que renvoyé par open(2)) à la place de path.

Un nom d'attribut étendu est une chaîne terminée par un caractère nul. Le name inclut un préfixe d'espace de noms ; il peut y avoir plusieurs espaces de noms disjoints associés à un inode individuel.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'échec, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

ENODATA
L'attribut nommé n'existe pas.
ENOTSUP
Les attributs étendus ne sont pas pris en charge par le système de fichiers, ou sont désactivés.

De plus, les erreurs documentées dans stat(2) peuvent également survenir.

NORMES

Linux.

HISTORIQUE

Linux 2.4, glibc 2.3.

VOIR AUSSI

getfattr(1), setfattr(1), getxattr(2), listxattr(2), open(2), setxattr(2), stat(2), symlink(7), xattr(7)
