NOM

fluxbox-remote - accès en ligne de commande aux commandes clés de fluxbox(1)

SYNTAXE

fluxbox-remote commande

DESCRIPTION

fluxbox-remote(1) est conçu pour permettre aux scripts d'exécuter la plupart des commandes clés de fluxbox(1). fluxbox-remote(1) ne fonctionnera qu'avec fluxbox(1) : ses communications avec fluxbox(1) ne sont pas standardisées de quelque manière que ce soit. Il est recommandé d'utiliser un outil basé sur des standards tel que wmctrl(1) lorsque cela est possible, afin que les scripts fonctionnent avec d'autres gestionnaires de fenêtres.

AVERTISSEMENTS

fluxbox-remote(1) utilise le protocole X11 pour communiquer avec fluxbox(1). Par conséquent, il est possible pour tout utilisateur ayant accès au serveur X(7) d'utiliser fluxbox-remote(1). Pour cette raison, plusieurs commandes clés ont été désactivées. Les utilisateurs doivent être conscients des implications de sécurité lors de l'activation de fluxbox-remote(1), surtout lors de l'utilisation d'une connexion X(7) transmise.

RESSOURCES

session.screen0.allowRemoteActions: <booléen>

Cette ressource dans ~/.fluxbox/init doit être définie sur « true » pour que fluxbox-remote(1) fonctionne. Veuillez lire les AVERTISSEMENTS au préalable.

ENVIRONNEMENT

Afin de communiquer avec fluxbox(1), la variable d'environnement DISPLAY doit être correctement définie. Habituellement, la valeur devrait être « :0.0 ».
