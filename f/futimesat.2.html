futimesat(2) Manuel des appels système futimesat(2)

NOM

futimesat - modifier les horodatages d'un fichier par rapport à un descripteur de fichier de répertoire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <fcntl.h>            /* Définition des constantes AT_* */
#include <sys/time.h>
[[deprecated]] int futimesat(int dirfd, const char *path,
                             const struct timeval times[2]);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

futimesat():

    _GNU_SOURCE

DESCRIPTION

Cet appel système est obsolète. Utilisez plutôt utimensat(2).

L'appel système futimesat() fonctionne exactement de la même manière que utimes(2), à l'exception des différences décrites dans cette page de manuel.

Si path est relatif, il est interprété par rapport au répertoire référencé par le descripteur de fichier dirfd (plutôt que par rapport au répertoire de travail courant du processus appelant, comme le fait utimes(2) pour un nom de chemin relatif).

Si path est relatif et que dirfd est la valeur spéciale AT_FDCWD, alors path est interprété par rapport au répertoire de travail courant du processus appelant (comme utimes(2)).

Si path est absolu, alors dirfd est ignoré. (Voir openat(2) pour une explication de l'utilité de l'argument dirfd.)

VALEUR DE RETOUR

En cas de succès, futimesat() renvoie 0. En cas d'erreur, il renvoie -1 et errno est défini pour indiquer l'erreur.

ERREURS

Les mêmes erreurs qui surviennent pour utimes(2) peuvent également survenir pour futimesat(). Les erreurs supplémentaires suivantes peuvent survenir pour futimesat():

EBADF
path est relatif mais dirfd n'est ni AT_FDCWD ni un descripteur de fichier valide.
ENOTDIR
path est relatif et dirfd est un descripteur de fichier se référant à un fichier autre qu'un répertoire.

VERSIONS

glibc

Si path est NULL, alors la fonction enveloppe futimesat() de glibc met à jour les temps pour le fichier référencé par dirfd.

NORMES

Aucune.

HISTORIQUE

Linux 2.6.16, glibc 2.4.

Il a été implémenté à partir d'une spécification qui a été proposée pour POSIX.1, mais cette spécification a été remplacée par celle de utimensat(2).

Un appel système similaire existe sur Solaris.

NOTES

VOIR AUSSI

stat(2), utimensat(2), utimes(2), futimes(3), path_resolution(7)
