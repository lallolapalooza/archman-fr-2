FTVALID(1) Manuel des commandes générales FTVALID(1)

NOM

ftvalid - validateur de tables de mise en page de polices

SYNTAXE

ftvalid [options] fichier_police

DESCRIPTION

ftvalid est un validateur de tables de mise en page OpenType.

Ce programme fait partie du paquet de démonstrations FreeType.

OPTIONS

-f index
Sélectionne l'index de la police (par défaut : 0).
-t validateur
Sélectionne le validateur. Les validateurs disponibles sont ot, gx et ckern.
Notez que la disponibilité des validateurs dépend des options de compilation de FreeType (c'est-à-dire si les modules `otvalid' et `gxvalid' sont compilés dans la bibliothèque).
-T tables
[ot, gx] Sélectionne les étiquettes de nom de table sfnt à valider. Utilisez `:' pour séparer les étiquettes.
Les tables prises en charge dans le validateur ot sont BASE, GDEF, GPOS, GSUB, JSTF et MATH.
Les tables prises en charge dans le validateur gx sont feat, mort, morx, bsln, just, kern, opbd, trak, prop et lcar.
Exemple : -T "feat:morx"
-T dialecte
[ckern] Sélectionne le dialecte kern classique pour la validation. Utilisez `:' pour séparer les noms de dialectes. Si plus d'un dialecte est spécifié, tous les dialectes sont acceptés lors de la validation.
Les dialectes pris en charge dans le validateur ckern sont ms et apple.
-l
Liste les tables SFNT liées à la mise en page disponibles dans le fichier de police. Le validateur sélectionné (avec l'option -t) affecte la liste.
ckern est applicable uniquement à la table `kern'. L'option -L liste les dialectes pris en charge dans le validateur ckern uniquement si la table `kern' est disponible dans le fichier de police.
-V niveau
Niveau de validation. Les valeurs possibles sont 0 (par défaut), 1 (strict) et 2 (paranoïaque).
-v
Affiche la version.

VARIABLES D'ENVIRONNEMENT

FT2_DEBUG
Vous pouvez spécifier des paires `composant:niveau' pour le suivi. Le niveau doit être compris entre 1 et 7.
Les composants disponibles pour le validateur ot sont otvmodule, otvcommon, otvbase, otvgdef, otvgpos, otvgsub et otvjstf.
Les composants disponibles pour le validateur gx sont gxvmodule, gxvcommon, gxvfeat, gxvmort, gxvmorx, gxvbsln, gxvjust, gxvkern, gxvopbd, gxvtrak, gxvprop et gxvlcar.
Le composant disponible pour le validateur ckern est uniquement gxvkern.
Exemple : FT2_DEBUG="otvcommon:5 gxvkern:7"
FT2_DEBUG ne fonctionne que si le support de suivi est compilé dans FreeType.
