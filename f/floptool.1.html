FLOPTOOL(1) Outil générique de manipulation d'images de disquettes MESS FLOPTOOL(1)

NOM

floptool - Outil générique de manipulation d'images de disquettes MESS

SYNTAXE

floptool option

DESCRIPTION

floptool est un outil pour la maintenance et la manipulation des images de disquettes dont les utilisateurs de MESS ont besoin de traiter.

COMMANDES

identifier fichier_entree [fichier_entree ... ]
Détermine le format d'une image de disquette.
convertir [format_entree|auto] format_sortie fichier_entree fichier_sortie
Convertit une image de disquette dans un autre format.

EXEMPLES

floptool identifier image.dsk
