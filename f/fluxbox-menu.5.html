DESCRIPTIO

N

Il existe deux types de menus dans fluxbox qui peuvent être

configurés.

Le premier est le menu racine, qui apparaît normalement lorsque vous faites un clic droit sur le

bureau.

Le premier est le MENU RACINE (ou menu du clic droit), généralement lié à un clic droit sur le bureau, bien que cette liaison puisse être modifiée dans le fichier « keys » (fluxbox-keys(5)). Cette même syntaxe est utilisée pour la commande CustomMenu, également mentionnée dans fluxbox-key

s(5).

Fluxbox installe un fichier de menu racine par défaut dans /usr/share/fluxbox/menu. Vous pouvez également utiliser fluxbox -i pour confirmer cet emplacement. Bien sûr, ce menu système peut être personnalisé pour tous les utilisateurs à la fois, mais il est également possible de créer un fichier de menu individuel pour chaque utilisateur. Par convention, les utilisateurs créent un fichier de menu dans ~/.fluxbox/menu. Une fois que vous avez créé votre propre fichier de menu, vous devrez vous assurer de déclarer correctement cet emplacement dans votre fichier « init » afin que fluxbox sache où chercher. Voir RESSOURCES, ci-dessous pour plus de

détails.

Le deuxième type est le MENU DE FENÊTRE, qui définit le contenu du menu qui apparaît lorsque vous faites un clic droit sur la barre de titre ou la barre d'icônes d'une fenêtre. Cela ouvre un fichier de menu défini par ~/.fluxbox/windowmenu. Si ce fichier n'existe pas, fluxbox copiera le fichier par défaut depuis /usr/share/fluxbox/windowmenu

.

Vous n'avez pas besoin de « recharger » fluxbox après avoir modif

ié l'un ou l'autre des fichiers de menu ; les changements devraie
nt être pris en compte la prochaine fois que vous ouvrez le menu.

MENU

RACINE

Le menu racine doit commencer par une balise [begin] et se terminer par une balise [end], et chaque balise doit être sur sa propre

ligne.

Il y a jusqu'à quatre champs dans une ligne de menu. Ils sont de la

forme
[balise] (libellé) {commande}
<'icône'>

Le champ <'icône'> est toujours facultatif lorsqu'il est affiché ci-dessous. S'il est spécifié, l' icône sera mise à l'échelle et affichée dans le menu à côté du libellé textuel de l'élément. Elle doit être au format .xpm ou .

png.

Toute ligne commençant par un # ou ! est considérée comme un commentaire et ignorée par fluxbox. De plus, dans les champs libellé/commande/nom de fichier, vous pouvez échapper n'importe quel caractère. En utilisant \\, vous insérez une barre oblique inverse littérale dans le champ libellé/commande/nom de

fichier.

Vous pouvez saisir des libellés, des commandes et des icônes en utilisant des caractères de n'importe quelle langue/paramètres régionaux iconv(1) en spécifiant l'encodage utilisé via la balise [encoding], détaillée

ci-dessous.

Balises

structurelles

[begin] (titre

)
Cela indique à fluxbox de commencer à analyser le fichier de menu. Cette balise est requise pour que fluxbox lise votre fichier de menu. S'il ne peut pas le trouver, le menu par défaut du système est utilisé à la place. Le titre apparaît en haut du menu. Et la balise [end] est requise pour terminer le
menu.

[submenu] (libellé) {titre}

<'icône'>
Cela indique à fluxbox de créer et d'analyser un nouveau menu, qui est inséré en tant que sous-menu dans le menu parent. Ces menus sont analysés récursivement, il n'y a donc pas de limite au nombre de niveaux ou de sous-menus imbriqués que vous pouvez avoir. Le libellé est le texte qui apparaîtra dans le menu parent, et le titre est affiché en haut du sous-menu. S'il est omis, le titre sera le même que le libellé. Une balise [end] est requise pour terminer le
sous-menu.

[end

]
Cela indique à fluxbox qu'il est à la fin d'un menu. Cela peut être soit un [submenu], soit la balise [begin] du menu racine principal. Il doit y avoir au moins une de ces balises dans votre menu pour correspondre à la balise [begin] requise, et une pour chaque [submen
u].

[encoding] {encodage

}
Cela commence une section [encoding] et spécifie l'encodage de chaîne de toutes les chaînes jusqu'à la balise [endencoding] correspondante. Pour une liste des encodages disponibles sur votre système, exécutez iconv
-l.

[endencoding

]
Cela termine une section [encodi
ng].

[include] (chemin

)
Analyse le fichier spécifié par le nom de fichier en ligne avec le menu courant. Le chemin peut être le chemin complet vers un fichier ou il peut commencer par ~/, qui sera développé vers votre répertoire personnel. Si le chemin est un répertoire, alors tous les fichiers de ce répertoire sont
inclus.

[separator

]
Cela créera une belle ligne de séparation. Utile pour séparer les sections de manière « esthétique ». Le commentaire facultatif n'est pas affiché, mais peut être utile pour la documentation interne ou l'analyse de scripts des fichiers de
menu.

[nop] (libellé)

<'icône'>
Insère un élément non opérationnel dans le menu courant. C'est très similaire à [separator], mais au lieu d'une ligne, il insère un libellé. Cela peut être utilisé pour aider à formater le menu en blocs ou en sections si vous le souhaitez. Le libellé est facultatif, et s'il est
omis, un élément
vide sera inséré.

Application

s

[exec] (libellé) {commande...}

<'icône'>
Insère un élément de commande dans le menu. Lorsque vous sélectionnez l'élément de menu, fluxbox exécute commande... dans votre $SHELL (ou /bin/sh si $SHELL n'est pas défini). Vous pouvez utiliser cela pour lancer des applications, exécuter des scripts shell, etc. Puisque tous les arguments sont passés tels quels au shell, vous pouvez utiliser des variable
s d'environnement, des pipes, ou n'importe quoi d'autre que le shell peut faire. Notez que les processus ne voient q
ue les variables d'environnement qui ont été définies avant le démarrage de fluxbox (comme dans ~/.fluxbox/startup).

Fonctions de

Fluxbox

[config] (libellé)

<'icône'>
Insère un élément de sous-menu natif de fluxbox, contenant de nombreuses options de configuration concernant le placement des fenêtres, le style de focus, le style de déplacement des fenêtres, etc. Voir Menu de configuration dans fluxbox(1) pour plus de
détails.

[reconfig] (libellé)

<'icône'>
Lorsque cet élément est sélectionné, il relit le style courant et les fichiers de menu et applique les changements. C'est utile pour créer un nouveau style ou thème, car vous n'avez pas à redémarrer fluxbox constamment à chaque fois que vous enregistrez votre style. Cependant, fluxbox relit automatiquement le menu chaque fois qu'il
change.

[restart] (libellé) {commande}

<'icône'>
Cela indique à fluxbox de redémarrer. Si une commande est fournie, il s'arrête et exécute la commande (qui est généralement le nom d'un autre gestionnaire de fenêtres). Si la commande est omise, fluxbox se redémarre
lui-même.

[exit] (libellé)

<'icône'>
Insère un élément qui arrête et quitte fluxbox. Toutes les fenêtres ouvertes sont ré-attachées à la fenêtre racine avant que fluxbox ne
quitte.

[style] (libellé) {nom de fichier}

<'icône'>
Cela indique à fluxbox d'insérer un élément qui, lorsqu'il est sélectionné, lit le fichier de style nommé nom de fichier et applique les nouvelles textures, couleurs et polices à la session en cours
d'exécution.

[stylesmenu] (répertoire)

<'icône'>
Lit tous les noms de fichiers du répertoire spécifié, en supposant qu'ils sont tous des fichiers de style valides, et crée des éléments de menu en ligne dans le menu courant pour chaque nom de fichier, qui, lorsqu'ils sont sélectionnés par l'utilisateur, appliqueront le fichier de style sélectionné à la session courante. Les libellés créés dans le menu sont les noms de fichiers des fichiers de
style.

[stylesdir] (libellé) {répertoire}

<'icône'>
Crée une entrée de sous-menu avec le libellé (qui est aussi le titre du nouveau sous-menu), et insère dans ce sous-menu tous les noms de fichiers du répertoire spécifié, en supposant qu'ils sont tous des fichiers de style valides (les répertoires sont ignorés) de la même manière que la commande [stylesdir]. Les commandes [stylesdir] et [stylesmenu] permettent d'installer des fichiers de style sans modifier votre fichier d'initialisation
.

[wallpapers] (répertoire) {commande}

<'icône'>
Cela insère un élément de menu pour définir le fond d'écran pour chaque fichier du répertoire donné. La commande est facultative et par défaut vaut fbsetbg
.

[workspaces] (libellé)

<'icône'>
Cela indique à fluxbox d'insérer un lien vers le menu des espaces de travail directement dans votre menu. Voir Menu des espaces de travail dans fluxbox(1) pour plus de
détails.

[commande] (libellé)

<'icône'>
En plus des commandes ci-dessus, toute commande valide de fichier de touches peut être utilisée comme élément de menu. Voir fluxbox-keys(5) p
our plus
d'info
rmations.

MENU DE LA

FENÊTRE

La syntaxe du menu de la fenêtre est en grande partie identique à celle du MENU RACINE ; il doit commencer par [begin] et se terminer par [end], et peut contenir n'importe laquelle des balises ci-dessus. Cependant, il peut aussi contenir l'une des balises spécifiques à la fenêtre suivantes [balise*]*s, qui doivent chacune se trouver sur une ligne seule, sans libellés, commandes ni

icônes.

Les balises supplémentaires disponibles dans ce menu sont

:

[shade

]
Fournit un élément de menu pour ombrer ou désombrer (ou dérouler) la fenêtre. Cela équivaut au bouton de la barre de titre pour
ombrer.

[stick

]
Fournit un élément de menu pour épingler ou désépingler la fenêtre. Les fenêtres épinglées sont affichées sur tous les espaces de travail. Cela équivaut au bouton de la barre de titre pour
épingler.

[maximize

]
Fournit un élément de menu pour maximiser ou dés-maximiser la fenêtre, équivalent au bouton de maximisation de la barre de titre. Le bouton avec lequel vous cliquez modifie le comportement de cet élément comme suit :
•Bouton 1 : (Dés)Maximiser
normalement.
•Bouton 2 : (Dés)Maximiser la fenêtre
verticalement.
•Bouton 3 : (Dés)Maximiser la fenêtre
horizontalement
.

[iconify

]
Fournit un élément de menu pour réduire (ou iconifier) la fenêtre, équivalent au bouton de réduction de la barre de
titre.

[close

]
Ferme la fenêtre proprement, équivalent au bouton de la barre de
titre.

[kill

]
Tue le processus de la fenêtre, comme xkill(
1).

[raise

]
Élève la fenêtre au sommet de la pile au sein de sa
couche.

[lower

]
Abaisse la fenêtre au bas de la pile au sein de sa
couche.

[settitledialog

]
Ouvre une boîte de dialogue qui peut être utilisée pour définir le titre de la fenêtre. Certaines applications peuvent rétablir leur propre titre de temps à autre, effaçant votre
réglage.

[sendto

]
Envoie la fenêtre vers un autre espace de travail. Lorsque vous sélectionnez l'espace de travail avec un clic du bouton du milieu, fluxbox changera aussi vers le nouvel espace de travail. Un clic simple n'envoie que la
fenêtre.

[layer

]
Ajoute un sous-menu « Layer... » qui vous permet de changer la couche de cette
fenêtre.

[alpha

]
Ajoute un sous-menu « Transparency... » qui vous permet de changer la transparence de cette fenêtre lorsqu'elle est focalisée ou non
focalisée.

[extramenus

]
Ajoute l'élément de menu « Remember... », qui vous permet de spécifier quels réglages doivent être enregistrés dans le fichier « apps » (voir fluxbox-apps(5) pour plus de détails)
.

[separator

]
Ajoute une l
igne horizon
tale au menu
