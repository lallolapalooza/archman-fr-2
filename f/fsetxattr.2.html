setxattr(2) Manuel des appels système setxattr(2)

NOM

setxattr, lsetxattr, fsetxattr - définir la valeur d'un attribut étendu

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/xattr.h>
int setxattr(size_t size;
              const char *path, const char *name,
              const void value[size], size_t size, int flags);
int lsetxattr(size_t size;
              const char *path, const char *name,
              const void value[size], size_t size, int flags);
int fsetxattr(size_t size;
              int fd, const char *name,
              const void value[size], size_t size, int flags);

DESCRIPTION

Les attributs étendus sont des paires nom:valeur associées aux inodes (fichiers, répertoires, liens symboliques, etc.). Ce sont des extensions aux attributs normaux qui sont associés à tous les inodes du système (c'est-à-dire les données de stat(2)). Un aperçu complet des concepts d'attributs étendus se trouve dans xattr(7).

setxattr() définit la valeur de l'attribut étendu identifié par name et associé au path donné dans le système de fichiers. L'argument size spécifie la taille (en octets) de value ; une valeur de longueur nulle est permise.

lsetxattr() est identique à setxattr(), sauf dans le cas d'un lien symbolique, où l'attribut étendu est défini sur le lien lui-même, et non sur le fichier auquel il fait référence.

fsetxattr() est identique à setxattr(), seul l'attribut étendu est défini sur le fichier ouvert auquel fait référence fd (tel que retourné par open(2)) à la place de path.

Un nom d'attribut étendu est une chaîne terminée par un caractère nul. Le name inclut un préfixe d'espace de noms ; il peut y avoir plusieurs espaces de noms disjoints associés à un inode individuel. La valeur d'un attribut étendu est un bloc de données textuelles ou binaires arbitraires de longueur spécifiée.

Par défaut (c'est-à-dire si flags est zéro), l'attribut étendu sera créé s'il n'existe pas, ou la valeur sera remplacée si l'attribut existe déjà. Pour modifier ces sémantiques, l'une des valeurs suivantes peut être spécifiée dans flags :

XATTR_CREATE
Effectuer une création pure, qui échoue si l'attribut nommé existe déjà.
XATTR_REPLACE
Effectuer une opération de remplacement pure, qui échoue si l'attribut nommé n'existe pas déjà.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'échec, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EDQUOT
Les limites de quota disque signifiaient qu'il n'y avait pas assez d'espace restant pour stocker l'attribut étendu.
EEXIST
XATTR_CREATE a été spécifié et l'attribut existe déjà.
ENODATA
XATTR_REPLACE a été spécifié et l'attribut n'existe pas.
ENOSPC
Il n'y a pas assez d'espace restant pour stocker l'attribut étendu.
ENOTSUP
Le préfixe d'espace de noms de name n'est pas valide.
ENOTSUP
Les attributs étendus ne sont pas pris en charge par le système de fichiers, ou sont désactivés.
EPERM
Le fichier est marqué comme immuable ou en ajout uniquement. (Voir FS_IOC_SETFLAGS(2const).)

En outre, les erreurs documentées dans stat(2) peuvent également se produire.

ERANGE
La taille de name ou value dépasse une limite spécifique au système de fichiers.

NORMES

Linux.

HISTORIQUE

Linux 2.4, glibc 2.3.
