NOM

fping - envoie des paquets ICMP ECHO_REQUEST à des hôtes réseau

SYNTAXE

fping [ options ] [ systèmes... ]

DESCRIPTION

fping est un programme similaire à ping qui utilise le protocole ICMP (Internet Control Message Protocol) de requête d'écho pour déterminer si un hôte cible répond. fping diffère de ping en ce que vous pouvez spécifier n'importe quel nombre de cibles sur la ligne de commande, ou spécifier un fichier contenant la liste des cibles à pinger. Au lieu d'envoyer des requêtes à une seule cible jusqu'à ce qu'elle expire ou réponde, fping envoie un paquet de ping et passe à la cible suivante dans un ordre cyclique. En mode par défaut, si une cible répond, cela est noté et elle est retirée de la liste des cibles à vérifier ; si une cible ne répond pas dans un délai imparti et/ou un nombre de tentatives définis, elle est désignée comme inaccessible. fping supporte également l'envoi d'un nombre spécifié de pings à une cible, ou la boucle indéfinie (comme dans ping). Contrairement à ping, fping est conçu pour être utilisé dans des scripts, donc sa sortie est conçue pour être facile à analyser. Les statistiques actuelles peuvent être obtenues sans terminer le processus avec le signal SIGQUIT (^\ depuis le clavier sur la plupart des systèmes).

OPTIONS

-4, --ipv4
Restreint la résolution de noms et les adresses IP aux adresses IPv4.
-6, --ipv6
Restreint la résolution de noms et les adresses IP aux adresses IPv6.
-a, --alive
Affiche les systèmes qui sont actifs. (Les options -c et -C remplacent -a.)
-A, --addr
Affiche les cibles par adresse plutôt que par nom DNS. Combiné avec -d, la sortie sera à la fois l'IP et (si disponible) le nom d'hôte.
-b, --size=OCTETS
Nombre d'octets de données de ping à envoyer. La taille minimale (normalement 12) laisse de la place pour les données dont fping a besoin pour fonctionner (numéro de séquence, horodatage). La taille des données reçues rapportées inclut l'en-tête IP (normalement 20 octets) et l'en-tête ICMP (8 octets), donc la taille totale minimale est de 40 octets. Par défaut 56, comme dans ping. Le maximum est la taille maximale théorique d'une datagramme IP (64 Ko), bien que la plupart des systèmes la limitent à un nombre plus petit, dépendant du système. Ne peut pas être utilisé avec --icmp-timestamp.
-B, --backoff=N
Facteur de recul. En mode par défaut, fping envoie plusieurs requêtes à une cible avant d'abandonner, attendant plus longtemps une réponse pour chaque requête successive. Ce paramètre est la valeur par laquelle le temps d'attente (-t) est multiplié à chaque requête successive ; il doit être entré comme un nombre à virgule flottante (x.y). La valeur par défaut est 1.5.
-c, --count=N
Nombre de paquets de requête à envoyer à chaque cible. Dans ce mode, une ligne est affichée pour chaque réponse reçue (cela peut être supprimé avec -q ou -Q). De plus, des statistiques sur les réponses pour chaque cible sont affichées lorsque toutes les requêtes ont été envoyées (ou lorsqu'elles sont interrompues). Cette option remplace -a ou -u.
-C, --vcount=N
Similaire à -c, mais les statistiques par cible sont affichées dans un format conçu pour la collecte automatisée des statistiques de temps de réponse. Par exemple : 
$ fping -C 5 -q somehost
somehost : 91.7 37.0 29.2 - 36.8

affiche le temps de réponse en millisecondes pour chacune des cinq requêtes, avec le "-" indiquant qu'aucune réponse n'a été reçue pour la quatrième requête. Cette option remplace -a ou -u.

--check-source
Ignore les réponses Echo provenant d'une adresse différente de l'adresse cible. Cela évite des résultats de joignabilité erronés sur des systèmes de surveillance chargés où deux instances de fping avec les mêmes 16 bits inférieurs de l'ID de processus peuvent s'exécuter simultanément.
-d, --rdns
Utilise le DNS pour rechercher l'adresse de la cible de ping. Cela vous permet de fournir à fping une liste d'adresses IP en entrée et d'afficher les noms d'hôte dans la sortie. C'est similaire à l'option -n/--name, mais forcera une recherche DNS inversée même si vous donnez des noms d'hôte comme cible (NOM->IP->NOM).
-D, --timestamp
Ajoute des horodatages Unix au début des lignes de sortie générées en mode boucle ou comptage (-l, -c, ou -C).

Sous-commande : --timestamp-format=ctime|iso|rfc3339

Permet de changer le format de l'horodatage de l'option -D aux types de format suivants.

ctime = "%c" (Exemple : Lun 10 Juin 07:50:00 2024)

iso = "%Y-%m-%dT%T%z" (Exemple : 2024-06-10T07:50:00+0200)

rfc3339 = "%Y-%m-%d %H:%M:%S" (Exemple : 2024-06-10 07:50:00)

-e, --elapsed
Affiche le temps écoulé (aller-retour) des paquets.
-f, --file
Lit la liste des cibles à partir d'un fichier.
-g, --generate addr/masque
Génère une liste de cibles à partir d'un masque réseau IP fourni, ou d'une IP de début et de fin. Spécifiez le masque ou le début/fin dans la partie cibles de la ligne de commande. Si un réseau avec masque est donné, les adresses réseau et de diffusion seront exclues. ex. Pour pinger le réseau 192.168.1.0/24, la ligne de commande spécifiée pourrait ressembler à : 
$ fping -g 192.168.1.0/24

ou

$ fping -g 192.168.1.1 192.168.1.254
-h, --help
Affiche le message d'utilisation.
-H, --ttl=N
Définit le champ TTL IP (durée de vie en sauts).
--print-ttl
Affiche la valeur TTL IPv4 de l'en-tête IP dans la sortie. Si fping ne peut pas lire la valeur TTL, "(TTL inconnu)" est retourné. Uniquement IPv4, nécessite les privilèges root ou cap_net_raw.
-i, --interval=MSECS
La durée minimale (en millisecondes) entre l'envoi d'un paquet de ping à une cible quelconque (par défaut 10, minimum 1).
-I, --iface=IFACE
Définit l'interface (nécessite le support de SO_BINDTODEVICE).
--icmp-timestamp
Envoie des requêtes ICMP timestamp (type ICMP 13) au lieu de requêtes ICMP Echo. Affiche les timestamps ICMP pour l'origine, la réception et la transmission, ainsi que l'heure de réception locale dans le même format, en plus de la sortie normale. Ne peut pas être utilisé avec -b car les messages ICMP timestamp ont une taille fixe. Uniquement IPv4, nécessite les privilèges root ou cap_net_raw.
-k, --fwmark=FWMARK
Définit FWMARK sur les paquets de ping pour le routage basé sur les politiques. Nécessite le noyau Linux 2.6.25<=, et les privilèges root ou cap_net_admin.
-l, --loop
Envoie des paquets en boucle à chaque cible indéfiniment. Peut être interrompu avec Ctrl-C ; les statistiques sur les réponses pour chaque cible sont alors affichées.
-m, --all
Envoie des pings à chaque adresse IP multiple d'un hôte cible (l'utilisation de l'option '-A' est recommandée).
-M, --dontfrag
Définit le bit "Ne pas fragmenter" dans l'en-tête IP (utilisé pour déterminer/tester le MTU).
-n, --name
Si les cibles sont spécifiées comme adresses IP, effectue une recherche DNS inversée pour afficher les noms d'hôte dans la sortie.
-N, --netdata
Formate la sortie pour netdata (-l -Q sont requis). Voir : https://netdata.cloud/
-o, --outage
Calcule le "temps d'interruption" basé sur le nombre de pings perdus et l'intervalle utilisé (utile pour les tests de convergence réseau).

Exemples

Pinger indéfiniment une liste d'hôtes et afficher les temps de réponse :

fping -l -e -a -q 192.168.1.1 192.168.1.2

Pinger une plage d'adresses IP, générer une liste d'hôtes actifs et les enregistrer dans un fichier :

fping -a -g 192.168.1.0/24 > active_hosts.txt

Pinger 5 fois chaque hôte d'une liste et afficher les temps de réponse dans un format parsable :

fping -C 5 -q -e -f host_list.txt

Pinger 5 fois chaque hôte d'une liste et afficher les statistiques de temps de réponse dans un format parsable :

fping -C 5 -q -e -f host_list.txt

Pinger une plage d'adresses IP et afficher les hôtes actifs avec leur TTL :

fping -a -g --print-ttl 192.168.0.0/23

Pinger une plage d'adresses IP et afficher les hôtes actifs avec leur TTL :

fping -a -g --print-ttl 192.168.0.0/23

Pinger un hôte avec des paquets de 1024 octets et avec une durée de vie de 64 sauts :

fping -b 1024 -H 64 google.com

Pinger 10 fois chaque hôte et afficher les statistiques dans un format adapté à netdata :

fping -c 10 -N -l -Q < ips.txt

AVERTISSEMENTS

L'envoi de paquets ICMP requiert parfois des privilèges root (par exemple, pour lire le TTL ou utiliser les timestamps ICMP).

SIGNAL

SIGQUIT (^\) : affiche les statistiques actuelles de tous les hôtes.
