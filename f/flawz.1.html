flawz(1) Manuel des commandes générales flawz(1)

NOM

flawz - Une interface utilisateur en terminal pour parcourir les CVE

SYNOPIS

flawz [--url] [-f|--feeds] [-d|--db] [-u|--force-update] [-o|--offline] [-q|--query] [-t|--theme] [-h|--help] [-V|--version]

DESCRIPTION

Une interface utilisateur en terminal pour parcourir les CVE

OPTIONS

--url=URL [par défaut : https://nvd.nist.gov/feeds/json/cve/1.1/]
Une URL où trouver les flux CVE 1.1 du NIST
Peut également être spécifié avec la variable d'environnement URL.
-f, --feeds=FLUX [par défaut : 2002:2024,recent,modified]
Liste des flux qui seront synchronisés
Peut également être spécifié avec la variable d'environnement FEEDS.
-d, --db=DB
Chemin vers la base de données SQLite utilisée pour stocker les données CVE synchronisées
Peut également être spécifié avec la variable d'environnement DB.
-u, --force-update
Toujours récupérer les flux
-o, --offline
Ne pas récupérer les flux
-q, --query=REQUÊTE
Démarrer avec une requête de recherche
Peut également être spécifié avec la variable d'environnement QUERY.
-t, --theme=THÈME [par défaut : dracula]
Définir le thème

Valeurs possibles :

  • dracula: Dracula
  • nord: Nord
  • one-dark: One Dark
  • solarized-dark: Solarized Dark
  • gruvbox-light: Gruvbox Light
-h, --help
Afficher l'aide (voir un résumé avec '-h')
-V, --version
Afficher la version
