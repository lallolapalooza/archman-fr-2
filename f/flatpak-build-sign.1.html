NOM

flatpak build-sign - Signer une application ou un runtime

SYNTAXE

flatpak build-sign [OPTION...] LIEU ID [BRANCHE]

DESCRIPTION

Signe le commit d'une application ou d'un runtime spécifié dans un dépôt local. LIEU est l'emplacement du dépôt. ID est le nom de l'application, ou du runtime si --runtime est spécifié. Si BRANCHE n'est pas spécifié, il est supposé être "master".

Les applications peuvent également être signées lors de l'exportation de la construction, mais il est parfois utile d'ajouter des signatures supplémentaires ultérieurement.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

--gpg-sign=KEYID

Signer le commit avec cette clé GPG. Cette option peut être utilisée plusieurs fois.

--gpg-homedir=CHEMIN

Répertoire d'accueil GPG à utiliser lors de la recherche de trousses de clés.

--runtime

Signer un runtime au lieu d'une application.

--arch=ARCH

L'architecture à utiliser. Voir flatpak --supported-arches pour les architectures prises en charge par l'hôte.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak build-sign --gpg-sign=D8BA6573DDD2418027736F1BC33B315E53C1E9D6 /quelque/repo org.my.App
