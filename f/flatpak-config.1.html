FLATPAK CONFIG(1) flatpak config FLATPAK CONFIG(1)

NOM

flatpak config - Gérer la configuration

SYNTAXE

flatpak config [OPTION...]

flatpak config [OPTION...] --set CLÉ VALEUR

flatpak config [OPTION...] --unset|--get CLÉ

DESCRIPTION

La commande flatpak config affiche ou modifie la configuration d'une installation flatpak. Les clés suivantes sont supportées :

languages

Les langues incluses lors de l'installation des extensions de locale. La valeur est une liste de codes de langue à deux lettres séparés par des points-virgules, ou l'une des valeurs spéciales * ou *all*. Si cette clé n'est pas définie, flatpak inclut par défaut la clé extra-languages et la locale actuelle.

extra-languages

Cette clé est utilisée lorsque languages n'est pas définie, et elle définit des extensions de locale supplémentaires en plus des langues configurées par le système. La valeur est une liste d'identifiants de locale séparés par des points-virgules (langue, locale optionnelle, codeset optionnel, modificateur optionnel) tels que documentés par setlocale(3) (par exemple, en;en_DK;zh_HK.big5hkscs;uz_UZ.utf8@cyrillic).

Pour la configuration des dépôts individuels, voir flatpak-remote-modify(1). Pour la configuration des applications individuelles, voir flatpak-override(1).

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche les options d'aide et quitte.

--list

Affiche toutes les clés et leurs valeurs.

--set

Définit la clé CLÉ à VALEUR.

--unset

Supprime la clé CLÉ.

--get

Affiche la valeur de CLÉ.

-u, --user

Configure l'installation par utilisateur.

--system

Configure l'installation système.

--installation=NOM

Configure l'installation système spécifiée par NOM parmi celles définies dans /etc/flatpak/installations.d/. Utiliser --installation=default est équivalent à utiliser --system.

-v, --verbose

Affiche des informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche des informations de débogage OSTree pendant le traitement de la commande.

EXEMPLES

$ flatpak config --set languages "sv;en;fi"
