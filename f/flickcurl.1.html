DESCRIPTIO

N

flickcurl est un programme utilitaire pour appeler les API Flickr via la bibliothèque flickcurl. Exécutez flickcurl -h pour obtenir une liste des commandes prises en charge et de leurs

arguments.

Le programme nécessite une configuration avant utilisation pour fonctionner avec les API Flickr. Exécutez flickcurl sans aucune option pour obtenir les instructions pour enregistrer l'application et créer le fichier de configuration initial ~/.flickcurl.conf à partir des informations d'enregistremen

t
.
