form_requestname(3X) Appels de bibliothèque form_requestname(3X)

NOM

form_request_by_name, form_request_name - gérer les noms de requêtes de formulaire imprimables

SYNTAXE

#include <form.h>
const char *form_request_name(int request);
int form_request_by_name(const char *name);

DESCRIPTION

La fonction form_request_name renvoie le nom imprimable d'un code de requête de formulaire. La fonction form_request_by_name recherche dans la table des noms une requête avec le nom donné et renvoie son code de requête. Sinon, E_NO_MATCH est renvoyé.

VALEUR DE RETOUR

form_request_name renvoie NULL en cas d'erreur et définit errno sur E_BAD_ARGUMENT.

form_request_by_name renvoie E_NO_MATCH en cas d'erreur. Elle ne définit pas errno.

PORTABILITÉ

Ces routines sont spécifiques à ncurses. Elles n'étaient pas supportées sur les implémentations Version 7, BSD ou System V. Il est recommandé de conditionner tout code dépendant de celles-ci en utilisant NCURSES_VERSION.
