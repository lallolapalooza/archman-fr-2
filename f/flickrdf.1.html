NOM

flickrdf - appeler l'API Flickr

SYNTAXE

flickrdf [-d DELAI] [-a FROB] [-h] [-v]

DESCRIPTION

flickrdf est un utilitaire qui utilise l'API photos.getInfo pour interpréter les champs de description et les tags d'une URI de photo en triples RDF. Si raptor est présent, il sera utilisé pour fournir une sérialisation correcte en RDF plutôt que la sortie intégrée et peu fiable en ntriples/turtle.

Les balises machine lorsqu'elles sont trouvées sont analysées pour xmlns:préfix=uri puis toutes les autres balises machine avec ce préfixe se transforment en triples. Plusieurs préfixes sont également prédéfinis par la bibliothèque pour être automatiquement transformés en triples sans xmlns, tels que blue:, cell:, filter: et geo:. Les balises non machine ne sont pas encore interprétées.

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-h, --help
Afficher un résumé des options et quitter.
-v, --version
Afficher la version du programme et quitter.
-d DELAI, --delay DELAI
Définir le délai entre les requêtes à DELAI millisecondes.
-D, --debug
Afficher beaucoup de messages de débogage.
-o, --output FORMAT
Définir le format de sortie à FORMAT. FORMAT est l'un des suivants :
ntriples N-Triples (par défaut)
turtle Turtle
rdfxml-xmp RDF/XML (Profil XMP)
rdfxml-abbrev RDF/XML (Abrégé)
rdfxml RDF/XML
rss-1.0 RSS 1.0
dot Format GraphViz DOT La liste exacte dépend de la version de Raptor à laquelle flickcurl est lié.
