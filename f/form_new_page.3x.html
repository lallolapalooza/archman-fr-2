NOM

set_new_page, new_page - fonctions de pagination de formulaire

SYNOPSIS

#include <form.h>
int set_new_page(FIELD *champ, bool indicateur_nouvelle_page);
bool new_page(const FIELD *champ);

DESCRIPTION

La fonction set_new_page définit ou réinitialise un indicateur marquant le champ donné comme début d'une nouvelle page sur son formulaire.

La fonction new_page est un prédicat qui teste si un champ donné marque le début d'une page sur son formulaire.

VALEUR DE RETOUR

La fonction new_page retourne TRUE ou FALSE.

La fonction set_new_page retourne l'une des valeurs suivantes :

E_OK
La routine a réussi.
E_CONNECTED
Le champ donné est déjà connecté à un formulaire.

PORTABILITÉ

Ces routines émulent la bibliothèque de formulaires System V. Elles n'étaient pas prises en charge sur les versions 7 ou BSD.
