NOM

form_field - établir et rompre les connexions entre les champs et les formulaires

SYNOPSIS

#include <form.h>
int set_form_fields(FORM *form, FIELD **fields);
FIELD **form_fields(const FORM *form);
int field_count(const FORM *form);
int move_field(FIELD *field, int frow, int fcol);

DESCRIPTION

La fonction set_form_fields modifie le tableau de pointeurs de champs du form donné. Le tableau doit être terminé par un NULL.

La fonction form_fields renvoie le tableau de champs du formulaire donné.

La fonction field_count renvoie le nombre de champs dans form.

La fonction move_field déplace le champ donné (qui doit être déconnecté) à un emplacement spécifié sur l'écran.

VALEUR DE RETOUR

La fonction form_fields renvoie un pointeur (qui peut être NULL). Elle ne définit pas errno.

La fonction field_count renvoie ERR si le paramètre form est NULL.

Les fonctions set_form_fields et move_field renvoient l'un des codes suivants en cas d'erreur :

E_OK
La routine a réussi.
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.
E_CONNECTED
Le champ est déjà connecté à un formulaire.
E_POSTED
Le formulaire est déjà affiché.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).

PORTABILITÉ

Ces routines imitent la bibliothèque de formulaires System V. Elles n'étaient pas prises en charge sur les versions Version 7 ou BSD.

La documentation de la bibliothèque de formulaires SVr4 spécifie la valeur d'erreur de field_count comme étant -1 (qui est la valeur de ERR).
