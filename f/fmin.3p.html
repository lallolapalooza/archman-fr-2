FMIN(3P) Manuel du programmeur POSIX FMIN(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

fmin, fminf, fminl — déterminer la valeur numérique minimale de deux nombres à virgule flottante

SYNTAXE

#include <math.h>
double fmin(double x, double y);
float fminf(float x, float y);
long double fminl(long double x, long double y);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Ces fonctions déterminent la valeur numérique minimale de leurs arguments. Les arguments NaN (Not a Number) sont traités comme des données manquantes : si un argument est un NaN et l'autre numérique, ces fonctions choisissent la valeur numérique.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent la valeur numérique minimale de leurs arguments.

Si un seul argument est un NaN, l'autre argument est retourné.

Si x et y sont des NaN, un NaN est retourné.

ERREURS

Aucune erreur n'est définie.
