NOM

flurry - un système de particules colorées

SYNTAXE

flurry [--display hôte:écran.numéro] [--visual visuel] [--window] [--root] [--window-id numéro] [--preset <arg>] [--fps]

DESCRIPTION

Ceci est un portage de l'économiseur d'écran OSX flurry.

OPTIONS

--visual visuel
Spécifie quel visuel utiliser. Les valeurs valides sont le nom d'une classe visuelle, ou l'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--window
Dessiner dans une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessiner dans la fenêtre racine.
--window-id numéro
Dessiner dans la fenêtre spécifiée.
--preset <arg>
Sélectionner un préréglage (classic, fire, water, psychedelic, rgb, binary, random, insane)

(Insane ne sera jamais sélectionné au hasard, car il nécessite beaucoup de puissance CPU/GPU)

--fps
Afficher le taux de rafraîchissement actuel, la charge CPU et le nombre de polygones.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui surcharge les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de la fenêtre à utiliser avec --root.

VOIR AUSSI

X(1), xscreensaver(1)
