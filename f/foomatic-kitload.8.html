NOM

foomatic-kitload - installe un kit de données dans la base de données foomatic.

SYNOPIS

foomatic-kitload [ -k kit-dir] [ -d dest-dir]...

DESCRIPTION

foomatic-kitload installe un kit de données foomatic dans la bibliothèque de données locale. Il prend une option -k dirname, où dirname est le répertoire de niveau supérieur d'un "kit" de pilote foomatic. Un "kit" est une sélection de fichiers sources XML organisés exactement comme dans la section source/ de la base de données maître (c'est-à-dire, sous-répertoires opt/driver/printer/).

Le générateur foomatic de Gimp-Print produit exactement un tel kit.

Foomatic-kitload est modérément paranoïaque concernant les kits : le kit doit contenir au moins l'un des répertoires printer, driver ou opt ; le kit doit contenir uniquement des fichiers se terminant par .xml, le kit ne peut pas être la bibliothèque locale elle-même, etc. Mais il n'inspecte en aucun cas le contenu des fichiers du kit.

Options

-k dirname
dirname est le répertoire de niveau supérieur d'un "kit" de pilote foomatic.
-d destdir
destdir est un préfixe à ajouter au chemin d'installation. Ceci ne sera normalement pas nécessaire, mais est utile si vous installez dans une 'zone de staging' temporaire avant l'installation dans la destination finale.

STATUT DE SORTIE

foomatic-kitload retourne 0 en cas de succès, 255 ou autre chose en cas d'erreur.
