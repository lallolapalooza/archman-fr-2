form_field_opts(3X) Appels de bibliothèque form_field_opts(3X)

NOM

set_field_opts, field_opts_on, field_opts_off, field_opts - définir et obtenir les options de champ

SYNOPSIS

#include <form.h>
int set_field_opts(FIELD *field, Field_Options opts);
Field_Options field_opts(const FIELD *field);
int field_opts_on(FIELD *field, Field_Options opts);
int field_opts_off(FIELD *field, Field_Options opts);

DESCRIPTION

La fonction set_field_opts définit tous les bits d'options du champ donné (les bits d'options de champ peuvent être combinés par un OU logique).

La fonction field_opts_on active les bits d'options donnés et laisse les autres inchangés.

La fonction field_opts_off désactive les bits d'options donnés et laisse les autres inchangés.

La fonction field_opts retourne les bits d'options actuels du champ.

Les options standard suivantes sont définies (toutes sont activées par défaut) :

O_ACTIVE
Le champ est visité pendant le traitement. Si cette option est désactivée, le champ ne sera pas accessible par les touches de navigation. Veuillez noter qu'un champ invisible apparaît également comme inactif.
O_AUTOSKIP
Passer au champ suivant lorsque celui-ci est rempli.
O_BLANK
Le champ est effacé chaque fois qu'un caractère est entré dans la première position.
O_EDIT
Le champ peut être modifié.
O_NULLOK
Autoriser un champ vide.
O_PASSOK
Valider le champ uniquement s'il a été modifié par l'utilisateur.
O_PUBLIC
Le contenu du champ est affiché au fur et à mesure de la saisie des données.
O_STATIC
Les tampons de champ sont fixés à la taille d'origine du champ. Désactivez cette option pour créer un champ dynamique.
O_VISIBLE
Le champ est affiché. Si cette option est désactivée, l'affichage du champ est supprimé.
O_WRAP
Les mots qui ne rentrent pas sur une ligne sont renvoyés à la ligne suivante. Les mots sont séparés par des espaces.

Ces options d'extension sont définies (les extensions sont désactivées par défaut) :

O_DYNAMIC_JUSTIFY
Permet aux champs dynamiques d'être justifiés, comme les champs statiques.
O_NO_LEFT_STRIP
Préserve les espaces blancs de début dans le tampon de champ, qui sont normalement ignorés.
O_EDGE_INSERT_STAY
Lors de l'insertion dans un champ jusqu'à la position limite, permet éventuellement de retarder le défilement, de sorte que le dernier caractère inséré reste visible, mais avance le curseur pour refléter l'insertion. Cela permet à la bibliothèque de formulaires d'afficher le caractère inséré dans des champs d'un seul caractère et permet également à la bibliothèque de maintenir un état cohérent.
O_INPUT_FIELD
La fonction set_max_field vérifie cette extension, qui permet à un champ dynamique de se rétrécir si la nouvelle limite est inférieure à la taille actuelle du champ.

VALEUR DE RETOUR

À l'exception de field_opts, chaque routine retourne l'une des valeurs suivantes :

E_OK
La routine a réussi.
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.
E_CURRENT
Le champ est le champ courant.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).

PORTABILITÉ

Ces routines émulent la bibliothèque de formulaires System V. Elles n'étaient pas prises en charge sur les versions 7 ou BSD.
