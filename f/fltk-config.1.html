fltk-config(1) Manuel des commandes générales fltk-config(1)

NOM

fltk-config - script pour obtenir des informations sur la version installée de fltk.

SYNTAXE

fltk-config [ --prefix [=DIR] ] [ --exec-prefix [=DIR] ] [ --version ] [ --api-version ] [ --use-gl ] [ --use-images ] [ --use-glut ] [ --cc ] [ --cxx ] [ --cflags ] [ --cxxflags ] [ --ldflags ] [ --ldstaticflags ] [ --libs ] [ -Dname[=value] ] [ -g ] [ --compile programme.cxx ]

DESCRIPTION

fltk-config est un script utilitaire qui peut être utilisé pour obtenir des informations sur la version actuelle de FLTK installée sur le système, sur le compilateur et les options de liaison à utiliser lors de la compilation d'applications basées sur FLTK, et pour compiler de simples applications FLTK.

Les options suivantes sont supportées :

--api-version

Affiche le numéro de version de l'API FLTK actuel, par exemple "1.1".
--cc
--cxx

Affiche le compilateur C/C++ qui a été utilisé pour compiler FLTK.
--cflags
--cxxflags

Affiche les options du compilateur C/C++ à utiliser lors de la compilation des fichiers source qui utilisent FLTK.
--compile programme.cxx

Compile le fichier source programme.cxx en programme. Cette option implique "--post programme".
-g

Active les informations de débogage lors de la compilation avec l'option --compile.
--ldflags

Affiche les options de l'éditeur de liens à utiliser lors de la liaison d'une application FLTK.
--ldstaticflags

Affiche les options de l'éditeur de liens à utiliser lors de la liaison d'une application FLTK aux bibliothèques statiques FLTK.
--libs

Affiche le chemin complet des fichiers de la bibliothèque FLTK, à utiliser pour la vérification des dépendances.
--use-gl

Active le support OpenGL.
--use-glut

Active le support GLUT.
--use-images

Active le support des fichiers images.
--version

Affiche le numéro de version de FLTK actuel, par exemple "1.1.0".
