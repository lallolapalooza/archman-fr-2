NOM

ftpd - Serveur de protocole de transfert de fichiers.

SYNTAXE

ftpd [OPTION...]

DESCRIPTION

Démon du protocole de transfert de fichiers, offrant le service PAM 'ftp'.

-4, --ipv4
restreindre le démon à IPv4
-6, --ipv6
restreindre le démon à IPv6
-a, --auth=AUTH
utiliser AUTH pour l'authentification
-A, --anonymous-only
le serveur est configuré pour le service anonyme uniquement
-d, --debug
mode débogage
-D, --daemon
démarrer ftpd en tant que démon autonome
-l, --logging
augmenter la verbosité des messages syslog
--non-rfc2577
ignorer la RFC 2577 en donnant des informations sur les utilisateurs manquants
-p, --pidfile[=FICHIERPID]
changer l'emplacement par défaut du fichier PID
-q, --no-version
ne pas afficher la version dans la bannière
-t, --timeout=DELAI
définir le délai d'inactivité par défaut
-T, --max-timeout=MAX_DELAI
définir la valeur maximale de délai autorisée
-u, --umask=VALEUR
définir l'umask par défaut
AUTH peut être l'un des suivants:
défaut
authentification passwd
pam
utilisation du service PAM 'ftp'
-?, --help
afficher cette liste d'aide
--usage
afficher un court message d'utilisation
-V, --version
afficher la version du programme

Les arguments obligatoires ou optionnels aux options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.
