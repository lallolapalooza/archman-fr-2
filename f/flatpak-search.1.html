NOM

flatpak-search - Recherche d'applications et de runtimes

SYNTAXE

flatpak search TEXT

DESCRIPTION

Recherche des applications et des runtimes correspondant à TEXT. Notez que ceci utilise les données AppStream qui peuvent être mises à jour avec la commande flatpak update. Les données AppStream ne sont mises à jour automatiquement que si elles ont au moins un jour.

OPTIONS

Les options suivantes sont comprises :

-u, --user

Recherche uniquement dans les dépôts de l'installation par utilisateur.

--system

Recherche uniquement dans les dépôts de l'installation système globale par défaut.

--installation=NOM

Affiche une installation système globale par NOM parmi celles définies dans /etc/flatpak/installations.d/. Utiliser --installation=default est équivalent à utiliser --system.

-h, --help

Affiche les options d'aide et quitte.

-v, --verbose

Affiche les informations de débogage pendant le traitement de la commande.

--ostree-verbose

Affiche les informations de débogage OSTree pendant le traitement de la commande.

--columns=CHAMP,...

Spécifie quelles informations afficher pour chaque résultat. Vous pouvez lister plusieurs champs, ou utiliser cette option plusieurs fois.

Ajoutez :s[tart], :m[iddle], :e[nd] ou :f[ull] aux noms de colonne pour changer la troncature.

CHAMPS

Les champs suivants sont compris par l'option --columns :

name

Affiche le nom

description

Affiche la description

application

Affiche l'identifiant de l'application

version

Affiche la version

branch

Affiche la branche

remotes

Affiche les dépôts

all

Affiche toutes les colonnes

help

Affiche la liste des colonnes disponibles

Notez que les noms de champs peuvent être abrégés en un préfixe unique.
