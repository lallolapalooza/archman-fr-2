NOM

fpcjres - page de manuel pour fpcjres : un convertisseur de fichiers de ressources

DESCRIPTION

fpcjres Ce programme est appelé par le compilateur Free Pascal et est utilisé pour traduire les directives {$R xxx} en ressources Java qui peuvent être incluses dans une classe Java.

Syntaxe : fpcjres [options] <fichier_entrée> [<fichier_entrée>...] [-o <fichier_sortie>]

OPTIONS

--aide, -h -?
Affiche un message d'aide.
--version, -V
Affiche la version du programme.
--verbeux, -v
Soyez verbeux.
--entrée, -i <x>
Ignoré pour la compatibilité avec d'autres outils.
--sortie, -o <x>
Définit le nom du fichier de sortie.
@<fichier>
Lire d'autres options depuis le fichier <fichier>
