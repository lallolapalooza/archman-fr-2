NOM

flatpakrepo - Référence à un dépôt distant

DESCRIPTION

Flatpak utilise des fichiers flatpakrepo pour partager des informations sur les dépôts distants. Le fichier flatpakrepo contient les informations nécessaires pour ajouter le dépôt distant. Utilisez la commande flatpak remote-add --from pour ce faire.

Les fichiers flatpakrepo peuvent également contenir des informations supplémentaires utiles lors de l'affichage d'un dépôt distant à l'utilisateur, par exemple dans un magasin d'applications.

L'extension de fichier couramment utilisée pour les fichiers flatpakrepo est .flatpakrepo.

Les fichiers flatpakrepo peuvent également être placés dans /usr/share/flatpak/remotes.d/ et /etc/flatpak/remotes.d/ pour préconfigurer statiquement des dépôts à l'échelle du système. Ces fichiers doivent utiliser l'extension .flatpakrepo. Si un fichier portant le même nom existe dans les deux emplacements, le fichier sous /etc aura la priorité.

FORMAT DU FICHIER

Le fichier flatpakrepo utilise le même format de fichier .ini que celui utilisé pour les fichiers unit systemd ou les fichiers .desktop d'application.

[Dépôt Flatpak]

Toutes les informations sont contenues dans le groupe [Flatpak Repo].

Les clés suivantes peuvent être présentes dans ce groupe :

Version (uint64)

La version du format de fichier, doit être 1 si présente.

Url (string)

L'URL du dépôt distant. Cette clé est obligatoire.

GPGKey (string)

La clé gpg codée en base64 pour le dépôt distant.

DefaultBranch (string)

La branche par défaut à utiliser pour ce dépôt distant.

Subset (string)

Limiter le dépôt distant au sous-ensemble nommé de références.

Title (string)

Le titre du dépôt distant. Il doit s'agir d'un nom convivial qui peut être affiché, par exemple, dans un magasin d'applications.

Comment (string)

Un bref résumé du dépôt distant, à afficher par exemple dans un magasin d'applications.

Description (string)

Une description plus longue du dépôt distant, à afficher par exemple dans un magasin d'applications.

Icon (string)

L'URL d'une icône qui peut être utilisée pour représenter le dépôt distant.

Homepage (string)

L'URL d'une page web décrivant le dépôt distant.

Filter (string)

Le chemin d'un fichier local à utiliser pour filtrer les références du dépôt distant. Voir flatpak-remote-add(1) pour plus de détails sur le format du fichier.

Remarque : Ce champ est traité un peu spécial par flatpak remote-add. Si vous installez un dépôt distant avec --if-not-exists, et que le dépôt est déjà configuré, alors le champ filter de la configuration du dépôt distant sera mis à jour de toute façon. Et, si le champ filter n'est *pas* spécifié, alors tous les filtres existants sont effacés. Le but ici est de permettre à un dépôt distant filtré préconfiguré d'être remplacé par celui normal si vous ajoutez le fichier flatpakrepo principal (non filtré).

DeploySideloadCollectionID (string)

L'ID de collection du dépôt distant, s'il en a un. Cela identifie de manière unique la collection d'applications dans le dépôt, pour permettre la redistribution pair à pair (voir flatpak(1)). Il est recommandé d'utiliser cette clé plutôt que DeployCollectionID ou CollectionID, car seuls les clients plus récents (Flatpak 1.12.8 ou plus récent) y prêtent attention (et les clients plus anciens ne gèrent pas correctement les IDs de collection).

DeployCollectionID (string)

Ceci est déprécié mais toujours pris en charge pour des raisons de compatibilité descendante. Utilisez DeploySideloadCollectionID à la place.

CollectionID (string)

Ceci est déprécié mais toujours pris en charge pour des raisons de compatibilité descendante. Utilisez DeploySideloadCollectionID à la place.
