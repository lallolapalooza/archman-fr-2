NOM

fmtutil.cnf - fichier de configuration pour fmtutil

DESCRIPTION

Le fichier fmtutil.cnf contient les informations de configuration pour fmtutil(8). Chaque ligne contient le nom du format (par exemple, ``tex´´, ``latex´´, ``omega´´), le nom du moteur utilisé par ce format (par exemple, ``tex´´, ``etex´´, ``omega´´), le fichier de modèle (par exemple, language.dat, language.def), et tout argument (nom d'un fichier .ini).

Les champs sont séparés par des espaces blancs et les lignes complètes peuvent être commentées avec ``#´´. Le champ ``fichier de modèle´´ ne peut pas être utilisé pour définir un fichier qui est utilisé lors de la construction du format. Il indique à fmtutil quels fichiers (séparés par des virgules) la procédure de création de format lit et il a un effet sur les options --showhyphen et --byhyphen. Si le format n'a aucun moyen de personnaliser la césure, un ``-´´ peut être utilisé pour indiquer cela.

NOTES

Les formats tex(1) et amstex(1) chargent toujours hyphen.tex. Aucune personnalisation par fichier de modèle n'est disponible pour ces formats. Par conséquent, le champ fichier de modèle pour tex et amstex est généralement indiqué comme vide (``-´´).

Vous pouvez cependant construire des formats personnalisés par-dessus tex(1) ou amstex(1) de base en utilisant bplain.tex au lieu de plain.tex (b pour le système Babel). Voir, par exemple, le fichier bplain.ini pour le format bplain).

etex(1) charge language.def, pas language.dat.

Les liens symboliques vers les bons moteurs (par exemple, bplain -> tex) sont générés par le script texlinks(8). N'oubliez pas d'exécuter texlinks(8) si vous exécutez fmtutil(8) vous-même, plutôt que d'utiliser l'option FORMATS dans texconfig(8).
