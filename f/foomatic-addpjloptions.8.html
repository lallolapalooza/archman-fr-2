NOM

foomatic-addpjloptions - Formate les informations d'options PJL pour la base de données Foomatic

SYNTAXE

foomatic-addpjloptions [-dafis][-o dir] -p printer_ID [pjl_info_file]

foomatic-addpjloptions [-dafq] [pjl_info_file]

foomatic-addpjloptions -h

DESCRIPTION

foomatic-addpjloptions formate le fichier d'informations PJL (ou STDIN) dans un format utilisable par la base de données Foomatic.

OPTIONS

-a
Convertir toutes les options PJL du fichier d'informations.
-d
Activer les informations de débogage.
-f
Ne pas demander la permission, forcer la conversion.
-h
Afficher un message d'aide et quitter.
-q
Afficher un résumé des informations PJL. Cette sortie n'est pas compatible avec la base de données foomatic et est utile pour le débogage.
-s
Produire un seul fichier d'options contenant toutes les valeurs d'options.
-o dir
Le répertoire où les fichiers d'informations d'options sont écrits.
-p printer_ID
Nom de l'imprimante dans la base de données foomatic. Ceci est utilisé pour extraire les informations du fabricant et du modèle de l'imprimante.
pjl_info_file
Fichier contenant les informations PJL retournées par l'imprimante. Si ce nom de fichier n'est pas fourni, les options PJL sont prises depuis l'entrée standard.

FICHIERS

/usr/share/foomatic/templates/pjl*.xml
Fichiers modèles pour les informations d'options.
./foomatic-db/opts
Informations d'options stockées dans ce répertoire.

STATUT DE SORTIE

foomatic-addpjloptions retourne 0 en cas de succès et une valeur non nulle en cas d'échec.
