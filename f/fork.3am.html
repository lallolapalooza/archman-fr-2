Paquet: gawk

FORK(3am) Modules d'extension GNU Awk FORK(3am)

NOM

fork, wait, waitpid - gestion de base des processus

SYNTAXE

@load "fork"

pid = fork()

ret = waitpid(pid)

ret = wait();

DESCRIPTION

L'extension fork ajoute trois fonctions, comme suit.

fork()
Cette fonction crée un nouveau processus. La valeur de retour est zéro dans l'enfant et le numéro d'identification du processus de l'enfant dans le parent, ou -1 en cas d'erreur. Dans ce dernier cas, ERRNO indique le problème. Dans l'enfant, PROCINFO["pid"] et PROCINFO["ppid"] sont mis à jour pour refléter les valeurs correctes.
waitpid()
Cette fonction prend un argument numérique, qui est l'identifiant du processus à attendre. La valeur de retour est celle de l'appel système waitpid(2).
wait()
Cette fonction attend que le premier enfant meure. La valeur de retour est celle de l'appel système wait(2).

BOGUES

Il n'y a pas de fonction exec() correspondante.

Les interfaces pourraient être améliorées pour fournir plus de fonctionnalités, y compris pour extraire les différents bits du statut de retour.

EXEMPLE

@load "fork"
...
if ((pid = fork()) == 0)
    print "bonjour depuis l'enfant"
else
    print "bonjour depuis le parent"
