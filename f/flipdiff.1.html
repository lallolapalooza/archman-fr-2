NOM

flipdiff - échange l'ordre de deux correctifs incrémentaux

SYNTAXE

flipdiff [[-p n] | [--strip-match=n]] [[-U n] | [--unified=n]] [[-d PAT] | [--drop-context=PAT]] [[-q] | [--quiet]] [[-z] | [--decompress]] [[-b] | [--ignore-space-change]] [[-B] | [--ignore-blank-lines]] [[-i] | [--ignore-case]] [[-w] | [--ignore-all-space]] [--in-place] diff1 diff2

flipdiff {[--help] | [--version]}

DESCRIPTION

flipdiff échange l'ordre de deux fichiers de correctifs qui s'appliquent l'un après l'autre. Les correctifs doivent être « propres » : les lignes de contexte doivent correspondre et il ne doit y avoir aucun décalage incorrect.

Les correctifs échangés sont envoyés à la sortie standard, avec une ligne marqueur (« === 8< === cut here === 8< ===”) entre eux, sauf si l'option --in-place est passée. Dans ce cas, la sortie est réécrite dans les fichiers d'entrée d'origine.

OPTIONS

-p n, --strip-match=n

Lors de la comparaison des noms de fichiers, ignorez les n premiers composants du chemin des deux correctifs. (Ceci est similaire à l'option -p de patch(1) de GNU.)

-q, --quiet

Sortie plus silencieuse. N'émettez pas de lignes de raisonnement au début de chaque correctif.

-U n, --unified=n

Tente d'afficher n lignes de contexte (nécessite au moins n lignes de contexte dans les deux fichiers d'entrée). (Ceci est similaire à l'option -U de diff(1) de GNU.)

-d pattern, --drop-context=PATTERN

N'affichez aucun contexte pour les fichiers qui correspondent au motif de caractères génériques du shell pattern. Cette option peut être donnée plusieurs fois.

Notez que l'interprétation du motif de caractères génériques du shell ne considère pas les barres obliques ou les points comme spéciaux (en d'autres termes, aucun drapeau n'est donné à fnmatch). Ceci afin que les motifs de type “*/basename” puissent être donnés sans limiter le nombre de composants du chemin.

-i, --ignore-case

Considérez les majuscules et les minuscules comme identiques.

-w, --ignore-all-space

Ignorez les changements d'espacement dans les correctifs.

-b, --ignore-space-change

Ignorez les changements dans la quantité d'espacement.

-B, --ignore-blank-lines

Ignorez les changements dont les lignes sont toutes vides.

-z, --decompress

Décompressez les fichiers avec les extensions .gz et .bz2.

--in-place

Écrivez la sortie dans les fichiers d'entrée d'origine.

--help

Affiche un court message d'utilisation.

--version

Affiche le numéro de version de flipdiff.

LIMITATIONS

Ceci n'a été testé que très légèrement, et pourrait même ne pas fonctionner. L'utilisation de --in-place n'est pas recommandée pour le moment.

Il existe certains cas où il n'est pas possible d'échanger significativement des correctifs sans comprendre la sémantique du contenu. Ce programme n'utilise que des lignes complètes qui apparaissent à une étape donnée lors de l'application des deux correctifs, et ne compose jamais une ligne à partir de parties.

Pour cette raison, il est généralement conseillé de lire la sortie pour vérifier qu'elle est cohérente.
