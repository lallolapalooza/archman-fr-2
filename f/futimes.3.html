futimes(3) Manuel des fonctions de bibliothèque futimes(3)

NOM

futimes, lutimes - modifier les horodatages de fichiers

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/time.h>
int futimes(int fd, const struct timeval tv[2]);
int lutimes(const char *path, const struct timeval tv[2]);
Exigences pour les macros de test de fonctionnalités de glibc (voir feature_test_macros(7)) :

futimes(), lutimes() :

    Depuis glibc 2.19 :
        _DEFAULT_SOURCE
    glibc 2.19 et versions antérieures :
        _BSD_SOURCE

DESCRIPTION

futimes() modifie les heures d'accès et de modification d'un fichier de la même manière que utimes(2), à la différence que le fichier dont les horodatages doivent être modifiés est spécifié via un descripteur de fichier, fd, plutôt qu'un nom de chemin.

lutimes() modifie les heures d'accès et de modification d'un fichier de la même manière que utimes(2), à la différence que si path fait référence à un lien symbolique, le lien n'est pas déréférencé : ce sont les horodatages du lien symbolique qui sont modifiés.

VALEUR DE RETOUR

En cas de succès, zéro est renvoyé. En cas d'erreur, -1 est renvoyé, et errno est définie pour indiquer l'erreur.

ERREURS

Les erreurs sont les mêmes que pour utimes(2), avec les ajouts suivants pour futimes() :

EBADF
fd n'est pas un descripteur de fichier valide.
ENOSYS
Le système de fichiers /proc n'a pas pu être accédé.

L'erreur suivante peut également survenir pour lutimes() :

ENOSYS
Le noyau ne prend pas en charge cet appel ; Linux 2.6.22 ou ultérieur est requis.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
futimes (), lutimes () Sécurité des threads MT-Safe

NORMES

Linux, BSD.

HISTORIQUE

futimes()
glibc 2.3.
lutimes()
glibc 2.6.

NOTES

lutimes() est implémenté à l'aide de l'appel système utimensat(2).

VOIR AUSSI

utime(2), utimensat(2), symlink(7)
