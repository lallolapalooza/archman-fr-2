NOM

fsck.btrfs - ne rien faire, avec succès

SYNTAXE

fsck.btrfs [-aApy] [<périphérique>...]

DESCRIPTION

fsck.btrfs est un type d'utilitaire qui devrait exister pour tout système de fichiers et qui est appelé lors de la configuration du système lorsque les entrées correspondantes de /etc/fstab contiennent une valeur non nulle pour fs_passno, voir fstab(5) https://man7.org/linux/man-pages/man5/fstab.5.html pour plus d'informations.

Les systèmes de fichiers traditionnels nécessitent l'exécution de leur utilitaire fsck respectif dans le cas où le système de fichiers n'a pas été démonté proprement et que le journal doit être rejoué avant le montage. Ceci n'est pas nécessaire pour BTRFS. Vous devriez définir fs_passno à 0.

Si vous souhaitez vérifier la cohérence d'un système de fichiers BTRFS ou réparer un système de fichiers endommagé, voir btrfs-check(8) <>. Par défaut, la cohérence du système de fichiers est vérifiée, le mode de réparation est activé via l'option --repair (à utiliser avec précaution !).

OPTIONS

Toutes les options sont identiques et détectent si fsck.btrfs est exécuté en mode non interactif et se termine avec succès, sinon affiche un message concernant la vérification btrfs.

STATUT DE SORTIE

Deux codes de sortie possibles sont retournés :

0
Aucune erreur
8
Erreur opérationnelle, par ex. le périphérique n'existe pas

FICHIERS

/etc/fstab
